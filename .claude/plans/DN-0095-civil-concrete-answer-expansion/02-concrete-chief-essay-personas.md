# コンクリート主任技士「実務立場別」小論文32答案

## 1. 既存商品との棲み分け

既存の`cce-essay-magazine`は、解法ガイド＋耐久性・品質管理・環境配慮・施工トラブルの4テーマを持つ入口商品として維持する。2026-08-13公開で観測期間が短いため、売上ゼロを理由に廃止・値下げしない。

新商品は同じ4テーマを、受験者の実務立場ごとの権限、対象、判断、指標へ具体化する上位版とする。単なる所属名の置換ではなく、「自分の立場に近い答案を選べる」ことを価値にする。

## 2. 8ペルソナ×4テーマ

| # | 実務ペルソナ | 固有の判断対象 |
|---:|---|---|
| 1 | 生コンクリート工場・品質管理 | 材料受入、配合、製造変動、出荷判定、顧客対応 |
| 2 | プレキャストコンクリート製品工場 | 製造、養生、寸法、脱型、製品検査、不適合処置 |
| 3 | ゼネコン・土木施工 | 打込み計画、施工性、品質確保、協力会社、発注者協議 |
| 4 | ゼネコン・建築施工 | 躯体品質、ポンプ圧送、仕上がり、工程、専門工事会社 |
| 5 | 発注者・監督員 | 要求性能、承認、立会、変更協議、説明責任 |
| 6 | 設計・建設コンサルタント | 性能照査、材料・配合条件、施工条件、維持管理性 |
| 7 | 試験・検査機関 | サンプリング、試験精度、判定、トレーサビリティ、中立性 |
| 8 | 維持管理・補修 | 変状、劣化機構、調査、補修材料、再劣化防止 |

各ペルソナに次の4テーマを作る。

1. 品質変動・不適合をどう管理したか。
2. 耐久性をどう確保・評価したか。
3. 環境負荷・脱炭素と品質・コストをどう両立したか。
4. 製造・施工・供用上のトラブルへどう対応し再発防止したか。

合計32記事と、無料のペルソナ選択ガイド1記事を新設する。

## 3. バッチ

- Batch A（16答案）: 生コン工場、プレキャスト工場、土木施工、維持管理・補修。受験者が実務を具体化しやすい4立場を先行する。
- Batch B（16答案）: 建築施工、発注者、設計コンサル、試験・検査機関。
- Batch A公開4週間後に、売上、単品閲覧、検索語、問い合わせでBatch Bの公開順を調整する。8ペルソナの完成方針は維持する。

## 4. 1記事の仕様

1. 想定する立場、業務範囲、権限外を明示する。
2. オリジナル想定課題を掲示し、実在過去問の逐語再現ではないと明示する。
3. 答案方針、序論・本論・結論のフル模範小論文、採点者視点、置換ガイドを持つ。
4. 具体的な課題、原因分析、実施策、確認指標、残課題までつなぐ。
5. 数値・固有条件は一次資料で裏付けるか、購入者が置換するプレースホルダにする。
6. 著者の実体験を装わず、「想定した立場の答案モデル」と明記する。

既存商品の1200〜1700字級という規格を基準にするが、実装時点の公式案内、既存原稿、試験用紙の条件を再確認して最終字数ゲートを決める。

## 5. 商品と導線

- 既存テーマ別4本: 初学者向け入口として維持する。
- 新規実務立場別32本: 上位の買い切りパックとする。
- 無料ペルソナ選択ガイド: 「勤務先 → 主な業務 → 近い答案」の3段で1ペルソナへ案内する。
- 既存商品から新商品へ、また新商品から既存解法ガイドへ相互導線を設ける。
- 32商品カードを同列表示せず、8ペルソナのカードから各4テーマへ入る。

価格はBatch A時3,980円、32本完成時5,980円を仮説とし、既存2,480円商品との価格差、noteのライブ価格、競合、制作量を実装時に確認して決定する。本文へ価格を直書きしない。

## 6. QAと受入条件

- 32記事の課題・施策・確認指標がペルソナ固有で、名詞置換になっていない。
- 8ペルソナそれぞれの権限外行為が答案へ混入していない。
- JIS、JASS、コンクリート標準示方書、法令、環境制度などの名称・数値は一次資料で確認する。
- GeneratorとEvaluatorを分離し、事実確認が必要な専門主張は別途ファクトチェックする。
- article、カバー、hashtags、PDF、カタログ、note収録、無料選択ガイド、売上productIdが一致する。
- 「過去問そのもの」「必ず出る」「そのまま提出できる」という訴求を使わない。
