# コンクリート技士の商品線＋発売後の計測

## 1. 小論文商品を作らない

2026年度の日本コンクリート工学会の試験案内では、コンクリート技士の試験方法は四肢択一式である。したがって、次の表現・商品は作らない。

- コンクリート技士 小論文対策
- コンクリート技士 模範小論文
- コンクリート技士 記述式予想問題

これらは受験者を誤認させ、主任技士との差を壊す。既存コード、本文、カバー、メタデータに誤表記があれば公開前にゼロにする。

## 2. 代替する商品仮説

### E1: 四肢択一・頻出論点完成パック

- 材料、配合、フレッシュ性状、硬化コンクリート、製造・品質管理、施工、構造、耐久性の論点別に構成する。
- 公式出題範囲を実装時に再確認し、独自問題・全選択肢解説・引っかけポイントで作る。
- 過去問の逐語転載や、出典不明の問題コピーをしない。

### E2: 現場判断ケース演習

- スランプ、空気量、温度、圧送、締固め、養生、強度試験、不適合などの短いケースから最適な判断を選ぶ。
- 「小論文」ではなく、択一知識を実務場面で定着させる補助教材として販売する。

### E3: 主任技士へのステップアップ導線

- 技士合格後に主任技士を目指す人へ、知識学習と小論文対策の違いを説明する無料ガイドを作る。
- 技士商品から主任技士小論文へ直接「同じ試験形式」と誤認させる導線を作らない。

## 3. パイロット手順

1. 公式の受験案内、出題範囲、直近試験の公開情報を一次資料で棚卸しする。
2. 既存サイトのコンクリート技士コンテンツ数、検索需要、競合商品、主任技士との重複を調べる。
3. E1の2論点・各20問、計40問をパイロット生成する。
4. 正答、全選択肢の正誤理由、規格名・数値、著作権、モバイル可読性を独立QAする。
5. 無料サンプル10問と有料30問で需要を観測する。価格はこの時点で競合と制作原価から決める。
6. 4週間で無料閲覧、有料転換、問い合わせ、誤問率を確認し、全論点展開の可否を決める。

全論点展開は、パイロットの品質が合格し、販売導線と更新方法が定義できた場合だけ行う。問題数だけを先に増やさない。

## 4. 共通計測

発売時に、各商品・単品へ一意なproductIdと資格・商品線・工種/ペルソナの属性を付ける。4週・8週で次を比較する。

| 指標 | 見る単位 | 判断 |
|---|---|---|
| 販売数・売上 | 商品、単品、工種、ペルソナ | 追加制作・公開順・訴求を調整 |
| 単品→パック転換 | 入口記事と旗艦商品 | パック内導線と価格差を調整 |
| 無料ガイド→商品クリック | 選択ガイドの分岐 | 分類・カード順・文言を改善 |
| 検索・問い合わせ | 工事名、立場、論点 | 次の候補を需要順へ並べる |
| 返金・誤認・修正 | 商品説明と実体 | 直ちに停止し説明・内容を是正 |

1級150、2級60、主任技士32は完成到達点であり、その後の151件目・61件目・33答案目は自動生成しない。次の追加は、未充足需要があり、既存との差別化を説明できる場合に別TODOとして起票する。
