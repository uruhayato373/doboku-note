# 1級150工事・2級60工事への拡張手順

## 1. 着手前棚卸し

コンテンツ移行完了後のパスを再取得し、次を機械集計する。

1. マガジン配下の`article.md`数、frontmatterのslug、工事名、5管理の見出し数をJSONへ一時出力する。
2. `src/lib/note-magazines.ts`の収録数・価格・公開URLとnoteライブの収録記事数を突合する。
3. 1級台帳100、2級台帳36の自己申告ではなく、原稿とライブの実数を確定する。
4. 工事名の正規化キーを`工種｜構造物｜施工条件｜主要課題`で作り、同義語と実質重複を検出する。
5. 売れた個別記事、GSCクエリ、ココナラ相談、サイト内検索があれば候補へスコアを付ける。

不一致があれば数量拡張へ進まず、既存商品の欠損を先に直す。

## 2. 1級土木：100から150へ

### 採用枠

### バッチ

- Batch A: 売上・検索・相談シグナル上位25工事。既存価格のまま追加する。
- Batch B: 残り25工事。Batch A公開4週間後のデータで順序だけ調整する。
- 各記事は1工事×5管理、各管理の設問1・2、置換ガイド、NG→OK、2テーマ早見表を持つ。
- 既存購入者が追加50本を読めることをライブで確認する。買い直しを要求する別マガジン化はしない。

### 1級受入条件

- 150件すべてに異なる正規化キーと固有の主要課題がある。
- 5管理×2答案の字数、法令・基準名、工事固有性、監理技術者の権限を検証している。
- `/keiken-charcount --strict`、`note-lint`、U+FFFD、本文価格直書き、兄弟記事重複の全ゲートが合格する。
- 150記事の索引、カタログ説明、収録数、PDF仕様が一致する。

## 3. 2級土木：36から60へ

2級は1級の縮小コピーにしない。中小規模工事で主任技術者・現場代理人が自然に担当できる24工事を追加する。

### 優先候補24

| 群 | 追加候補 |
|---|---|
| 道路・付帯（6） | 側溝更新、縁石・歩道切下げ、区画線を伴う舗装修繕、ガードレール更新、狭あい道路拡幅、駐車場舗装 |
| 小構造物・補修（5） | 小規模擁壁、プレキャスト函渠、小橋梁断面修復、伸縮装置取替、落石防護柵 |
| 河川・斜面（5） | かご工護岸、根固め工、河川堆積土撤去、法面植生、集水井・横ボーリング |
| 上下水道（4） | 水道耐震管更新、公共桝・取付管、マンホール更生、小規模雨水排水施設 |
| 農業・生活基盤（4） | 農業用水路補修、ため池小規模改修、林道補修、公園園路・排水整備 |
| 合計 | 24工事 |

棚卸しで既存36と重なる候補は、同じ群の「規模・施工条件・主要課題が異なる」候補へ置換する。大規模シールド、ケーソン、山岳トンネル、長大橋架設、空港造成は採用しない。

### バッチと答案仕様

- Batch A: 12工事。個別記事で既に売れた上下水道・河川に近い工事と、汎用性の高い道路付帯を優先する。
- Batch B: 12工事。Batch A公開4週間後に順序を調整する。
- 1記事は5管理だが、品質・安全・工程を「主」、施工計画・環境を「備え」と明示する。
- 現行2級の字数・4要素・主任技術者/現場代理人視点へ全面的に書き直す。1級答案の貼り付けは禁止する。
- 既存購入者が追加24本を読める形で、現行マガジンへ追加する。

### 2級受入条件

- 原稿・索引・カタログ・noteライブが60工事で一致する。
- 全記事が2級用の字数、設問構造、権限、規模感を満たす。
- 施工計画・環境を「頻出」「出題される」と表現していない。
- `/keiken-charcount --strict`、`note-lint`、U+FFFD、価格直書き、重複検査が合格する。

## 4. 制作・QAの分離

1. 工事ごとのdossierを先に作り、工事概要、施工条件、主要課題、管理指標、禁止表現、一次資料を定義する。
2. `civil-keiken-essay-writer`で1工事ずつ生成する。
3. 別コンテキストの`civil-keiken-essay-qa`で、形式適合、捏造、工事固有性、類似答案を採点する。
4. 不合格は公開せず修正と再QAを行う。
5. バッチ全件合格後にカバー、hashtags、PDF、カタログ、索引を生成する。
6. note操作は1記事ずつ公開結果を読み戻し、最後にマガジン収録数を検証する。
