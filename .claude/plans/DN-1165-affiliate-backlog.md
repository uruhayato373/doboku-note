# アフィリエイト素材と配置の整備

読者の課題は、土木の資格・経験に合う転職先を判断すること（A・M）。対象に合う広告だけを出し、条件を読める導線を提供する。成果の増加は未検証で、既存の比較実験と成果収集で確認する。

1. 台帳に広告 URL を集約し、許可検査に台帳の素材を含める（DN-1166）。
2. 素材の表示内容を確認し、使用不可の理由を記録する（DN-1167）。
3. 実験中の面を保ち、サイズ指定と共通の画像描画を既存面へ適用する（DN-1165）。
4. 提携・成果収集・記事・実験判定の残りのカードを現物と照合し、実行できる作業を処理する。未到来の観測や未取得の ASP 情報を完了にしない。

受入: check-affiliate-mats / check-affiliate-wiring / check-affiliate-placements / check-datasets、関連テスト、型検査。UI 変更は PC・スマホと SSR の main・主要語を確認する。
