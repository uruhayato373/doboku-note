# 公開記事の配布PDFを修正版へ更新する

- Drive台帳とバイト数・SHA-256が一致する保管済みPDFを使う。再生成はしない。
- 残りの模範解答20記事を10記事ずつ、予想模試2記事を同じ永続プロファイルで直列反映する。本文更新後にPDFを再添付し、有料境界・公開後の添付リンクを検証する。
- 更新前に対象を数え、当日のアップロードを安全上限90件以内に収める。停止した場合はログと対象を記録する。
- 先行反映分を含めた75記事のIDを復元できれば `npm run check-note-attachments:live -- --only <ID一覧>` で確定不足0を確認する。対象が確定できなければ残り22記事の実測を記録し、カードは保持する。
