# 過去問起点校正サイクル: R04 Ⅰ-1-5

## 起点過去問の論点

R04 Ⅰ-1-5 はサービスの特性問題（5 肢択一、最も**不適切**なものを選ぶ形式、正答 3）。

- 選択肢 1: 事前に在庫・流通不可 → 消滅性 ✅
- 選択肢 2: 顧客が必要とする場所・時間に生産と同時に消費 → 同時性 ✅
- 選択肢 3: **「同一のサービスを安定して繰り返し提供することが容易」** → 変動性と真逆で**不適切** ❌
- 選択肢 4: 生産者と顧客の共同作業・相互作用で便益 → 共同生産性 ✅
- 選択肢 5: 提供後に元に戻せない → 不可逆性 ✅

論点配列:
1. サービスの 4 大特性（IHIP）: 無形性・同時性／不可分性・変動性／異質性・消滅性
2. 変動性の核心: **同一品質で安定して繰り返し提供することは困難**（正答 3 の逆転）
3. 派生特性: 共同生産性（選択肢 4）・不可逆性（選択肢 5）
4. 工業製品 vs サービスの品質管理手法の違い（再現性前提 vs 変動性前提）
