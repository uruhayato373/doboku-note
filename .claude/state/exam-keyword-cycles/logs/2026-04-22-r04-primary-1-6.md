# 過去問起点校正サイクル: R04 Ⅰ-1-6

## 起点過去問の論点

R04 Ⅰ-1-6 は TOC の活用問題（最も**不適切**なものを選ぶ、正答 2）。

- 選択肢 1: 改善でボトルネックが移動 → 正しい（POOGI）
- 選択肢 2: **ボトルネック工程のスケジュールが最終工程に通知** → **不適切**（ロープは先頭工程への情報伝達が正）
- 選択肢 3: 全体工程をボトルネックのペースに合わせる → 正しい（ドラム）
- 選択肢 4: バッファを用いた管理 → 正しい
- 選択肢 5: 非ボトルネック工程の改善は全体スループット向上に貢献しない → 正しい（TOC 核心原則）

論点配列:
1. TOC の基本: ボトルネック特定・集中改善で全体最適
2. DBR: **ドラム**（全体ペース）・**バッファ**（ボトルネック前の時間余裕）・**ロープ**（先頭工程への投入ペース制御）
3. 5 集中ステップ（POOGI）: 特定 → 活用 → 従属 → 強化 → 繰り返し
4. 非ボトルネック改善の無効性
5. JIT vs TOC の哲学的違い（全工程改善 vs 制約集中）
