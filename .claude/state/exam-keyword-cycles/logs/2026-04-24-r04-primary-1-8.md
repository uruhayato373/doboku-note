# full-cycle サイクル: R04 Ⅰ-1-8

## 起点過去問の論点

- $EFT = EST + t$（最早完了時刻 = 最早開始時刻 + 作業時間）
- $LST = LFT - t = EST + TF$（最遅開始時刻）
- $TF = LST - EST = LFT - EFT$（全余裕時間）
- クリティカルパス ⟺ $TF = 0$
- 作業時間延長で TF ≤ 0 になるとクリティカルパス上へ移動
