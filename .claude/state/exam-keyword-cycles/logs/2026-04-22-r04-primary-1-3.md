# 過去問起点校正サイクル: R04 Ⅰ-1-3

## 起点過去問の論点

R04 Ⅰ-1-3 は時系列予測の計算問題（5 肢択一、正答 5）。4 期の需要データから移動平均法と単純指数平滑法で第 5 期予測値を計算。以下 5 論点が問われた:

1. **移動平均法の計算式**: $FI_{t+1} = \frac{1}{k}(Y_t + Y_{t-1} + \cdots + Y_{t-k+1})$
2. **単純指数平滑法の計算式**: $FS_{t+1} = \alpha Y_t + (1-\alpha) FS_t$（0 < α < 1）
3. **α の性質**: α 小 → 過去に引きずられる、α 大 → 直近に敏感
4. **逆算ロジック**（正答 5 の本質）: $FS_{t+1}$・$Y_t$・$\alpha$ から $FS_t$ を逆算。$FS_3 = 354,\ Y_2 = 340,\ \alpha = 0.3$ のとき $FS_2 = 360 > Y_2$
5. **移動平均の次数 k の影響**（選択肢 1・2 の罠）: k を増やすと平滑化は強まるが、予測値は単調減少/増加しない
