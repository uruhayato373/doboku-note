# 2級土木 第2次検定 予想模擬試験 問題冊子

## 受験上の注意

- **構成**：本冊子は2部構成です。**第1部（問題1〜9）が時間を計って解く本番形式の模擬試験**、**第2部（問題10〜19）が頻出論点の穴埋め特訓**（時間外の追加演習）です。まず第1部を通しで解いてください。
- **配点・満点**：第1部は問題1（施工経験記述）40点、問題2〜5（必須）各20点、問題6・7から1問と問題8・9から1問（選択）各15点の**合計150点満点**。第2部は各10点の**合計100点満点**です。配点はいずれも本冊子独自の目安であり、本試験の実際の配点・合格基準ではありません。
- **解答時間の目安**：本冊子の目安は、問題1を40分、問題2〜9（必須4問＋選択2問）を80分、**合計120分**です。本試験の試験時間は年度により変わるため、必ず受験年度の受検の手引でご確認ください。
- **記入方法**：各設問の下にある記入欄・解答欄に、黒の鉛筆またはボールペンで記入してください。語群から選ぶ問題は**記号（ア〜オ）**で答えます。問題1（施工経験記述）の記入欄は、2級の解答欄の目安（1項目あたり約250字）に合わせた各10行です。問題2以降の記入欄の行数は本冊子独自のもので、本試験の解答用紙とは体裁が異なります。
- **持ち物**：時計（時間を計るため）、筆記用具、消しゴム。
- **自己採点**：解き終えたら別冊「解答解説」で採点し、巻末の自己採点シートに得点を記入してください。

## この模擬試験の使い方

本冊子は、2級土木施工管理技士 第2次検定（旧・実地試験）の対策として、当方が独自に作成した**予想模擬試験**です。本試験の出題を保証するものではなく、過去問（R03〜R07）の出題傾向・頻出論点をもとに、論点の理解度を確認する目的で自主的に作成した教材です。設問文・数値・語群は当方のオリジナルであり、本試験の設問を転載したものではありません。

- 問題1は施工経験記述です。実際の第2次検定と同様、設問1・設問2の2テーマ構成で出題します。模範解答は付けていません（別冊「解答解説」に採点ポイントのみ掲載）。ご自身の経験工事にあてはめて、記入欄に手書きで書き出してください。
- 問題2〜9は学科記述です。問題2〜5は必須、問題6・7からいずれか1問、問題8・9からいずれか1問を選択して解答してください（実際の第2次検定と同じ選択方式を採用しています）。
- 時間を計って通して解いてから、別冊の解答解説で自己採点してください。
- 配点は本予想模擬試験独自の目安であり、本試験の実際の配点・合格基準を示すものではありません。
