# 1級土木 第2次検定 予想模擬試験 問題冊子

## 受験上の注意

- **配点・満点**：問題1（施工経験記述）40点、問題2〜10（学科記述）各10点、**合計130点満点**です。配点はいずれも本冊子独自の目安であり、本試験の実際の配点ではありません。
- **解答時間の目安**：本試験（1級土木施工管理技術検定 第2次検定）の試験時間は**2時間45分**です（令和7年度時点。年度により変わるため、必ず受験年度の受験要項でご確認ください）。本冊子は演習量を確保するため本試験より問題数を多くしているので、**問題1に45分、問題2〜10に2時間**を目安に進めてください。
- **記入方法**：各設問の下にある記入欄・解答欄に、黒の鉛筆またはボールペンで記入してください。記入欄の行数・枠の大きさは本冊子独自のもので、本試験の解答用紙とは体裁が異なります。
- **持ち物**：時計（時間を計るため）、筆記用具、消しゴム。
- **自己採点**：解き終えたら別冊「解答解説」で採点し、巻末の自己採点シートに得点を記入してください。

## この模擬試験の使い方

この冊子は、1級土木施工管理技士 第2次検定の対策として、過去5年間（令和3〜7年度）の出題傾向をもとに作成した予想模擬試験です。**本試験の出題内容を保証するものではなく、過去の出題実績から論点を予想して構成した自主教材**である点を、まずご理解のうえお使いください。

- **問題構成**：問題1が施工経験記述、問題2〜10が学科記述（穴埋め・記述）です。本試験では問題2以降は選択問題を含みますが、本模擬試験は演習量を確保するため、テーマ別の予想問題をまとめて収録しています。得意なテーマ・苦手なテーマを自分で選んで解いても構いません。
- **取り組み方**：時計を用意し、上記の時間配分を目安に通しで解いてください。まず何も見ずに解答欄を埋め、そのあとで解答解説（別冊）を使って自己採点する、という順番を推奨します。
- **経験記述について**：問題1は、あなたご自身が経験した工事の内容をもとに解答する設問です。この冊子には模範解答を記載していません。ご自身の工事経験に沿って、正直に記入してください。経験していない工事を記述すると、本試験では失格になる可能性があるため、あくまで自分の経験の整理・練習用としてお使いください。
- **自己採点**：採点の考え方・解答の要点・配点目安は、すべて別冊「解答解説」にまとめています。
