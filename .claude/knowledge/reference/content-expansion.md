# 教材からのコンテンツ展開

事業の判断基準は `business-direction.json` と `docs/strategy/01_プロダクト戦略.md`。
本書は、所蔵教材の論点を既存記事・図解・SNSに対応づけ、未確認を残したまま完了と呼ばないための手順。

## 真実源と確認範囲

- 教材の母数・権利区分は `.claude/config/reference-sources.json` の commercial-book / operator-owned。原本と全文OCRはDrive vault。
- 意味評価の記録は `.claude/state/content-expansion.json`。学習課題、原本の箇所、対応する成果物、図解・SNSの要否と理由を記録する。書籍の本文や目次を公開用コンテンツへ複製しない。
- 過去の総監398概念評価は `pe-textbook-keyword-coverage.json` を根拠として参照する。今回読んでいない本文を今回検証済みとしない。
- 単発の実装作業はbacklog、作業実績はdispatch-log。公開・予約は各チャネルの既存SSOT、効果は事業レビュー。対応表へ公開日や売上の別台帳を作らない。

`body-reviewed` は今回の本文突合、`prior-review` は明示された以前の意味評価、`topic-map` は概念名・主題だけの対応、`source-unavailable` は原典不足を表す。概念名の一致、図ファイルの存在、OCR取得成功は、内容の充足を単独では証明しない。

## 実行

1. 全教材の章・論点を私有の作業領域へ取り出し、末尾欠損・遮蔽・OCRの誤りを記録する。原本が欠ける場合、現存範囲の調査と全巻の確認を区別する。
2. 資格・学習段階の課題から既存本文を探す。別教材や別資格の説明を適切に使える場合は共有する。見出しごとに新記事を増やさない。
3. 内容の判定に加え、図解が必要か、図が既存の別記事にないか、SNS単体で伝える学習価値があるかを理由付きで判断する。定義一文で足りる語に機械的な図を足さない。
4. 必要な制作をbacklogへ登録し、作成・原典確認・描画検証を行う。記事は `writeMdxFile` と既存インデックス生成、図は `create-svg`、SNSは各チャネルの制作スキルを使う。
5. 成果物の確認時sha256を記録する。変更を見つけても機械で再承認せず、変更箇所を再確認して更新する。未実施作業を「追加不要」へ移して残数を減らさない。

## 管理画面と継続レビュー

管理画面の「教材」グループで見る。`/materials` は教材ごとの展開状況（本文・図解・SNS・商品・展開予定・要確認）の一覧、`/materials?id=<教材id>` は論点ごとの展開先と展開予定（`backlogIds` のカード）。集計は `sourceSummary`。商品の列は、成果物に記録した note / Kindle / ココナラ原稿と、論点の記事へリンクしている note / Kindle（`linkedProductsByUnit`・台帳には書かない派生情報で、論点そのものを使った商品という意味ではない）を合わせたもの。展開予定は新しい台帳を作らず、論点の `backlogIds` にバックログのカード番号を書く。論点の行を開くと判定の理由・根拠の箇所・成果物が確認後に変わったかを出し、`&only=attention` で未確認・原典待ち・確認後の変更だけに絞る（一覧の「要確認」の件数から開ける。旧 `/content/expansion` はここへ転送）。サイドバーは教材一覧の下に棚ごとに各教材を並べ、棚と短い表示名は `reference-sources.json` の `shelf`・`shortTitle`（未設定は台帳の確認事項に出る）。
`npm run check-content-expansion` は台帳・母数・成果物の整合を検査し、未完の件数も表示する。
`-- --complete` は未確認・必要制作・原典待ち・確認後の変更が一つでもあれば失敗する。
通常検査の成功は意味評価の完了宣言ではない。読取不能はexit 2、構造不整合はexit 1。

週次レビューでは未確認・原典待ち・変更後の再確認を見て、次の単発作業をbacklogから選ぶ。
月次レビューでは資格別の学習行動と販売・運営負担に照らして追加制作の必要性を見直す。
公開後の7日・28日の確認は既存の事業レビューへ接続し、制作枚数やファイル存在を効果の代用にしない。

原典不足で `partial` の論点は判定を保持し、管理画面では「原典待ち」に集計する。通常の制作待ちから分けるが、全体の完了判定には含めない。原典待ちの実行先は各論点の `backlogIds`。教材原典の復旧・再照合は DN-0224。
