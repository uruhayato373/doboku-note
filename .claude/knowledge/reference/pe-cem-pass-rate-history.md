# 技術士第二次試験 総合技術監理部門 年度別合格率（H26-R7）

「技術士・総合技術監理部門」の **最終合格率（筆記＋口頭の通算）** を、IPEJ（公益社団法人 日本技術士会）公表の公式統計から抽出・集計したもの。記事・SNS・マガジンでの数値引用の SSoT（Single Source of Truth）として使う。

## 1. データ表（H26 / 2014 〜 R7 / 2025）

| 年度 | 受験申込 | 受験者 | 合格者 | 対受験者合格率 |
|---|---:|---:|---:|---:|
| H26 (2014) | 4,135 | 3,206 | 562 | **17.5%** |
| H27 (2015) | 4,084 | 3,293 | 664 | **20.2%** |
| H28 (2016) | 3,990 | 3,147 | 473 | **15.0%** |
| H29 (2017) | 4,102 | 3,343 | 326 | **9.8%** |
| H30 (2018) | 4,043 | 3,279 | 209 | **6.4%** |
| R元 (2019) | 3,890 | 3,180 | 490 | **15.4%** |
| R2 (2020) | 3,192 | 2,582 | 325 | **12.6%** |
| R3 (2021) | 3,473 | 2,742 | 398 | **14.5%** |
| R4 (2022) | 3,393 | 2,735 | 501 | **18.3%** |
| R5 (2023) | 3,247 | 2,618 | 543 | **20.7%** |
| R6 (2024) | 3,070 | 2,521 | 382 | **15.2%** |
| R7 (2025) | 3,157 | 2,575 | 584 | **22.7%** |

## 2. サマリー指標（12 年間）

| 指標 | 値 |
|---|---|
| 加重平均合格率（総合格者 ÷ 総受験者） | **15.5%** |
| 単純平均（年率の単純平均） | 15.7% |
| 最高 | 22.7%（R7 / 2025） |
| 最低 | 6.4%（H30 / 2018） |
| 標準偏差（参考） | 約 ±4.6 ポイント |
| 累計受験者（H26-R7） | 35,221 名 |
| 累計合格者（H26-R7） | 5,457 名 |

## 3. 算出方法（透明性のため）

IPEJ 公表 PDF「[技術士第二次試験結果一覧表（S33-R7）](https://www.engineer.or.jp/c_topics/010/attached/attach_10868_1.pdf)」は次の 2 系列を併記している:

- **「全体」**: 21 部門（20 技術部門 + 総合技術監理部門）合計
- **「( ) の値」**: 総監を **除いた** 20 部門の小計

したがって **総監単独の数値 = 全体 − 20部門** で算出できる。

例: R6（令和6年度）
- 受験申込: 29,846 − 26,776 = 3,070
- 受験者: 23,043 − 20,522 = 2,521
- 合格者: 2,395 − 2,013 = 382
- 合格率: 382 / 2,521 = 15.15% ≈ **15.2%**

この計算結果は別の詳細 PDF「[令和6年度技術士第二次試験統計（部門別詳細）](https://www.engineer.or.jp/c_topics/001/attached/attach_1013_2.pdf)」の総監直接表記（受験者 2,521 / 合格者 382 / 合格率 15.2%）と完全一致するため、計算ロジックの妥当性は検証済み。

## 4. 重要な注意点（数値を引用するときに必読）

1. **「最終合格率」と「筆記試験合格率」は別物**
   - 本表は「筆記 + 口頭」を通算した **最終合格率**
   - 筆記試験のみの合格率は別途。例: R7 筆記合格 615 名 → 最終 584 名（口頭で 31 名落ち）
   - 記事で「合格率」と書くときは必ず筆記/最終を明記する

2. **「対受験者」と「対申込者」は別指標**
   - 本表は「対受験者」（実際に試験を受けた人ベース）
   - 「対申込者」は実受験率を考慮した数字でやや低くなる（R6 で全体 8.0% vs 10.4%）
   - 業界の慣行として「合格率」は通常「対受験者」を指すが、明示する方が誠実

3. **H30 (6.4%) の異常値の背景**
   - 技術士法改正に伴う **新試験制度初年度**
   - H30 〜 R元 あたりは合格率変動が大きく、長期トレンド議論では除外推奨

4. **総監は他 20 部門より合格率が高い**
   - H26-R7 加重平均: 総監 **15.5%** vs 20 部門 **約 9.4%**
   - 理由: 受験層が「他部門 PE 既取得者」中心で経験値・記述力が一定水準以上ある
   - 「総監は難関」という訴求は正しいが、20 部門との比較では緩い

5. **直近 3 年（R5-R7）の上昇傾向**
   - R5: 20.7% / R6: 15.2% / R7: 22.7% → 平均 **19.5%**
   - 母集団の質変化 or 採点基準の変化が考えられる
   - 「直近 3 年の平均合格率は約 20%」という表現は事実
