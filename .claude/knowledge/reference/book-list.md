# 紹介書籍リスト（Amazonアソシエイト用）

doboku-note のコンテンツから紹介する書籍の手動キュレーション台帳。資格別×用途別に整理し、後日 PA-API 通過後に `src/config/amazon-books.json` へ機械可読化する前段の真実源。

> [!warning]
> **書籍アフィリエイトは 2026-06-25 に完全廃止**（note 有料商品とのカニバリ回避）。`BookCard` / `BookSection` コンポーネント・`affiliate-flags.ts` / `affiliate-books.json`・MDX 内の `<BookCard>` / `BOOKCARD-TODO` は全て撤去済み。本ファイルは**過去の手動キュレーション記録（参考用の歴史資料）**として残すが、再有効化の予定はない。再開する場合は新規に配線し直す。決定の背景は `docs/project/04_運営/02_アフィリエイト提携状況.md`。

## 運用ルール

1. **追加条件**: 運営者が実際に読み込んだ・受験対策に有効と判断した書籍のみ掲載（未読書籍の推測掲載は禁止）
2. **ASIN/ISBN**: ブラウザでAmazon商品ページを開いて手入力（WebFetch ではbot対策で取れないことが多い）
3. **アソシエイトタグ**: 列には**含めない**（リンク生成時に動的付与する想定）。書誌情報のみ管理
4. **用途メモ**: 「どのページから紹介するか」「どの章が刺さるか」を必ず記録（紹介文の根拠になる）
5. **改訂版が出たら**: 旧版は行を残しつつ「絶版/旧版」マーク、新版を別行で追加
6. **PA-API 移行時**: この表の `ASIN` 列を seed として `scripts/fetch-amazon-books.mjs` で取得 → JSON 化

## 現フェーズ方針（2026-05-19 決定）

**ASIN 蓄積に専念し、リンク生成は後回し**。理由は以下:

- もしも経由「Amazon.co.jp 商品購入」は 2026-05-16 申請、**承認待ち**（→ `docs/project/04_運営/02_アフィリエイト提携状況.md`）
- Amazon直接アソシエイトは未申請
- 承認結果が出るまでリンクURL形式（もしも経由 vs Amazon直接）が確定しない

このため当面の作業は:

1. ASIN 列を手入力で埋める（ブラウザでAmazon商品ページを開いて URL の `/dp/XXXXXXXXXX` 部分をコピー）
2. リンク生成（`<BookCard asin="..." />` コンポーネント実装、もしもURL組み立て）は**もしも承認後に着手**
3. 環境変数 `.claude/config/affiliate-ids.json`（.gitignore 配下）に ID を保管する設計はその時点で確定させる

ASIN が分かれば後の自動化はすべて可能なので、いまは ASIN 取得が最優先タスク。

## 列定義

| 列名 | 説明 |
|---|---|
| ASIN | Amazon商品識別子（書籍は ISBN-10 と一致することが多い） |
| ISBN-13 | 国際標準図書番号13桁（OpenBD等の外部API突合用） |
| タイトル | 書誌タイトル（副題まで含む） |
| 著者 | 主著者または編者 |
| 出版社 | 発行元 |
| 版/年 | 「第◯版 / YYYY年」形式 |
| 用途 | textbook補助 / 過去問演習 / 法令確認 / 論文対策 等 |
| 紹介先 | 紹介を入れる予定の slug または「未定」 |
| 状態 | 候補（未読・要確認） / active（採用） / 旧版 / 絶版 |
| メモ | 推薦理由・特筆事項（1〜2行） |
