# 建設材料シリーズで確かめた一次資料（執筆担当が引く）

シリーズ `construction-materials`（`config/content-series.json`）の章を書くとき、執筆担当と QA はまずここを読む。ここに無い値だけを WebSearch / WebFetch で確かめる。手順は [book-coverage-expansion.md](./book-coverage-expansion.md) §4。コンクリートと鋼材の値は [concrete-practice-sources.md](./concrete-practice-sources.md) を先に見る。

- 担当が新しく確かめた値は、返答の `factsVerified` に「値 — 出典 URL（版・条・頁）」で書く。親がここへ足す（担当はこのファイルを編集しない）。
- 改正を見つけたら、古い行を消さずに「（令和◯年◯月に改正）」と書き足し、新しい行を足す。
