# SNS リパーパス戦略（6切り口フレームワーク）

**真実源**: 本ファイル。X / Instagram / YouTube 全チャネル共通。各チャネル policy はここを参照する。

同一のコアコンテンツ（キーワード・過去問・note 記事）を6つの切り口で展開し、
同一フォロワーへの繰り返し配信を可能にするクロスチャネル共通原則。

---

## 1. 6切り口

| # | 切り口 | 問いの形 | フォロワーへの効果 |
|---|---|---|---|
| 1 | **結論** | 「〇〇が合否を分ける」と断言する | 注目・権威付け |
| 2 | **理由** | なぜそれが重要か、論拠1つに絞る | 理解促進 |
| 3 | **体験** | つまずき・気づき・学習過程の断片 | 共感・信頼 |
| 4 | **反論** | 「〇〇は不要」という通説を覆す | 興味・議論喚起 |
| 5 | **数字** | データ・統計・具体的な量で示す | 信頼性・共有性 |
| 6 | **ハウツー** | 手順・方法・再現できる型で示す | 保存・実用性 |

---

## 2. チャネル別の適用方法

### X（テキスト中心）

1本のツイートが1切り口を担う。同一 `topic` × `angle` 違いで最大6本展開できる。

| 切り口 | 書き出し例 |
|---|---|
| 結論 | 「品質管理と経済性管理の順番を間違えると不合格になる」 |
| 理由 | 「総監でトレードオフを書かない人が落ちる理由」 |
| 体験 | 「自分が2回目でやっと気づいた5管理の読み方」 |
| 反論 | 「暗記は意味ない、と思っていたが違った話」 |
| 数字 | 「合格率20.7%。上位2割の答案に共通する構造は…」 |
| ハウツー | 「設問(2)を15分で骨子化する手順」 |

### Instagram カルーセル

1パック（slide-data.json）が1切り口の世界観を持つ。切り口は `cover.hook` と
スライド構成の流れに影響する。

| 切り口 | 構成の特徴 |
|---|---|
| 結論 | 断言スライドから始まり根拠を積み上げる |
| 理由 | 「なぜ重要か」の論拠を1つの軸に展開 |
| 体験 | ストーリー弧（問題→詰まり→解決）で構成 |
| 反論 | 「よくある誤解」スライドから入る |
| 数字 | データ・比率スライドを前半に配置 |
| ハウツー | ステップ番号付きの順序立てた構成 |

### Instagram Reels

script.json の冒頭 narration（Hook、最初の6秒）が切り口を決める。

| 切り口 | 冒頭 narration パターン |
|---|---|
| 結論 | 「〇〇が合否を分ける理由、今から話します」 |
| 理由 | 「なぜ5管理を全部書かなければいけないのか」 |
| 体験 | 「自分が2回目でやっと気づいたことを話します」 |
| 反論 | 「〇〇は不要、と思っていませんか？実は違います」 |
| 数字 | 「合格率20.7%。上位2割が共通してやっていること」 |
| ハウツー | 「この3ステップで設問(2)の骨子が作れます」 |

### Instagram Stories

4枚の流れが切り口のミニストーリーを形成する。

| 切り口 | 4枚の流れ |
|---|---|
| 結論 | ①断言 ②根拠 ③補強 ④CTA |
| 理由 | ①なぜ重要か ②論拠 ③応用 ④CTA |
| 体験 | ①状況提示 ②詰まった場面 ③気づき ④CTA |
| 反論 | ①よくある誤解 ②「でも実は」 ③正しい理解 ④CTA |
| 数字 | ①データ提示 ②意味の解釈 ③対策 ④CTA |
| ハウツー | ①問い ②Step1 ③Step2 ④CTA |

### YouTube Shorts

タイトルと冒頭3秒のテロップが切り口を示す。過去問1問完結型という
フォーマット制約から「結論」「数字」「ハウツー」が特に適合しやすい。

---

## 3. エージェント共通パラメータ

全 SNS writer エージェントで共通の `angle` パラメータを受け付ける。

| `angle` 値 | 動作 |
|---|---|
| `結論` / `理由` / `体験` / `反論` / `数字` / `ハウツー` | 指定した切り口で1本生成 |
| 未指定 | 文脈から最適な切り口を1つ選んで生成 |
| `all`（X のみ） | 全6切り口で1本ずつ、計6本生成 |

---

## 4. 運用ルール

- **同一コアの連投は間隔を開ける** — 同日に同一キーワードを6切り口で出し切らない。
- **切り口の明示は任意** — 「結論から言うと」等のリード文はなくてよい。自然に切り口が出るように書く。
- **どの切り口でも必ず1本作れる** — 「そのキーワードには数字がない」と諦めない。合格率・出題年度・定義の字数など何らかの数字は必ずある。
