doboku-note の広告・アフィリエイトの現状を監査し、収益最適化とUX改善の提案を行う。

## 引数

```
/audit-ads [--focus AREA]
```

- `--focus`（任意）: 監査の重点領域（省略時: 全領域）
  - `adsense`: Google AdSense の配置・設定
  - `affiliate`: アフィリエイトリンクの状況
  - `ux`: 広告のUXへの影響
  - `compliance`: 法令・規約遵守

## 手順

### Phase 1: 現状調査（並列サブエージェント）

#### Agent A: AdSense 設定・配置調査

```
調査項目:
- docusaurus.config.js の AdSense 設定（ca-pub-7995274743017484）
- 広告コード（<script> タグ）の配置場所
- 自動広告 or 手動配置
- 広告ユニットの種類（ディスプレイ/記事内/インフィード等）
- モバイル/デスクトップ別の表示状況
```

調査ファイル:
- `docusaurus.config.js` — AdSense スクリプト設定
- `src/` 配下の全コンポーネント — 広告コンポーネントの有無
- `src/css/` — 広告関連のスタイル
- `static/` — ads.txt の有無

#### Agent B: アフィリエイトリンク調査

```
調査項目:
- docs/ 配下の全 .mdx ファイルからアフィリエイトリンクを検出
  - Amazon アソシエイト（amzn.to, amazon.co.jp/...tag=）
  - A8.net リンク
  - もしもアフィリエイトリンク
  - その他 ASP リンク
- リンクの配置パターン（記事内/サイドバー/フッター）
- rel 属性の確認（nofollow, sponsored）
- リンク切れチェック
```

#### Agent C: UX・パフォーマンス影響調査

```
調査項目:
- 広告による CLS（Cumulative Layout Shift）リスク
- 広告スクリプトの読み込み遅延影響
- モバイルでの広告表示面積比率
- ファーストビューの広告占有率
- GA4 データ（利用可能な場合）: 広告表示ページの直帰率
```

### Phase 2: AdSense 最適化分析

#### 2.1 配置の最適性

| 配置パターン | 推奨度 | 理由 |
|---|---|---|
| 記事タイトル下 | ★★★★☆ | 視認性高い、CTR 期待大 |
| 目次の後 | ★★★★★ | 読者が内容を把握した後 |
| 記事末（関連記事の前） | ★★★★☆ | 記事完読後の自然な位置 |
| サイドバー | ★★★☆☆ | デスクトップのみ、視認性中 |
| 段落間（自動広告） | ★★☆☆☆ | 読書体験を阻害するリスク |

#### 2.2 広告タイプの最適化

| ページタイプ | 推奨広告タイプ | 理由 |
|---|---|---|
| 技術ノート（長文） | 記事内ネイティブ | 読了率が高い |
| カテゴリ一覧 | ディスプレイ | ブラウジング中 |
| トップページ | インフィード | コンテンツと自然に混在 |
