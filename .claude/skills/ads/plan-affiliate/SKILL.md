doboku-note のコンテンツとマッチするアフィリエイト商材を調査し、記事企画・配置戦略を立案する。

## 引数

```
/plan-affiliate [--category CATEGORY] [--product PRODUCT]
```

- `--category`（任意）: 対象カテゴリ（省略時: 全カテゴリ）
  - `books`: 技術書籍（Amazon）
  - `courses`: 通信講座・eラーニング
  - `materials`: 学習教材・問題集
  - `tools`: 業務用ツール・ソフトウェア
  - `services`: 転職・キャリアサービス
- `--product`（任意）: 特定商材名を指定して分析

## 手順

### Phase 1: 商材調査（並列サブエージェント）

#### Agent A: Amazon 書籍調査

WebSearch で対象カテゴリの売れ筋書籍を調査:

```
検索クエリ:
- "土木施工管理技士 参考書 おすすめ {YYYY}"
- "技術士 建設部門 参考書"
- "コンクリート技士 テキスト"
- "行政書士 テキスト おすすめ"
- "土木 教科書 おすすめ"
```

各書籍について:
- タイトル、著者、価格
- Amazon レビュー評価
- 対象読者層
- doboku-note のどのページと関連が深いか

#### Agent B: 通信講座・ASP 調査

WebSearch で主要 ASP の土木・建設系プログラムを調査:

```
検索クエリ:
- "施工管理技士 通信講座 比較"
- "技術士 講座 おすすめ"
- "A8.net 建設 資格"
```

各プログラムについて:
- サービス名、価格帯
- 報酬単価/報酬率
- 成果条件
- EPC（1クリックあたり報酬期待値）

#### Agent C: 既存コンテンツの収益化ポテンシャル

```
調査項目:
- GSC で高トラフィックのページ（利用可能な場合）
- docs/ の各ページの購買意図の有無
- 「おすすめ」「比較」「選び方」系のクエリの有無
```

### Phase 2: コンテンツ × 商材マッチング

既存の各ページに最適な商材をマッピング:

| ページ | 月間 PV（推定） | 購買意図 | 推奨商材 | 配置方法 |
|---|---|---|---|---|

### Phase 3: 新規コンテンツ企画

高収益が見込めるアフィリエイト記事の企画:

| 記事タイプ | 例 | 収益モデル |
|---|---|---|
| **比較記事** | "施工管理技士 通信講座 比較 {YYYY}" | 講座アフィリエイト |
| **おすすめ記事** | "土木技術者におすすめの参考書10選" | Amazon |
| **体験レビュー** | "スタディングで技術士対策した結果" | 講座アフィリエイト |
| **学習ロードマップ** | "1級土木施工管理技士 独学ロードマップ" | 書籍+講座 |

### Phase 4: 配置戦略

#### 4.1 自然な導線設計

技術ノートからアフィリエイト記事への自然な導線:
```
技術ノート（知識提供）
  → 関連する参考書の紹介（サイドバー or 記事末）
  → 比較・おすすめ記事（内部リンク）
  → アフィリエイトリンク
```

#### 4.2 配置ルール

| 配置場所 | 適切な商材 | UX 影響 |
|---|---|---|
| 記事末「参考文献」 | 書籍 | 低（自然） |
| サイドバー | 通信講座バナー | 低〜中 |
| 専用比較記事 | 講座・書籍 | 低（訪問意図と一致） |
| 記事内インライン | 直接関連する書籍 | 要注意 |

### Phase 5: 収益シミュレーション

| 商材 | 想定月間クリック | CVR | 報酬単価 | 想定月間収益 |
|---|---|---|---|---|

### Phase 6: 出力

`docs/reviews/affiliate-plan/YYYY-MM.md` に保存する。

## 注意事項

- アフィリエイトリンクは常に `rel="nofollow sponsored"` を付与
- 「PR」「広告」等の表示を適切に行う（景品表示法遵守）
- ユーザーの信頼を損なう過度な商材推しは避ける
- 技術コンテンツの中立性を維持する

## 推奨実行頻度

- **四半期ごと**: フル商材調査
- **月次**: 既存配置の効果検証
- **試験シーズン前**: 該当試験の教材特集（`--category materials`）
