設計便覧の既存MDXファイルで、図の品質問題（テキスト映り込み、出典欠落）を検出・修正する。

## 引数

```
/fix-design-manual-figures <MDXファイルパス>       # 検出＋修正
/fix-design-manual-figures <MDXファイルパス> --dry-run  # 検出のみ（修正しない）
/fix-design-manual-figures status                  # 全ファイルの品質状況一覧
```

## 背景

設計便覧PDFは本文領域と出典欄が縦線で分割されたレイアウトを持つ:

```
┌──────────────────────────┬─────────┐
│  本文テキスト             │ 出典：   │
│  ┌────────────────┐      │ [1-3]   │
│  │  図・表の内容    │      │ 文献名  │
│  └────────────────┘      │         │
└──────────────────────────┴─────────┘
```

初期変換で以下の問題が発生している:

1. **図のテキスト映り込み**: 図画像に本文テキスト・見出しが含まれ、MDXと二重表示になる
2. **出典欠落**: 縦線右側の出典情報がMDXの `:::note[出典]` として記載されていない
3. **出典の画像映り込み**: 出典テキストが図画像の右端に写っている

## 実行フロー

```
Phase 1: 検出（read-only）
  ├── 全画像を Read で確認 → テキスト映り込みチェック
  ├── 出典情報の有無を画像から検出
  └── 検出レポートを生成

Phase 2: ユーザー確認
  └── レポートを提示し、修正方針を確認

Phase 3: 修正
  ├── 画像の再トリミング（PIL crop）
  ├── :::note[出典] ブロックの追加
  └── MDXテキストの重複除去（必要に応じて）
```

## Phase 1: 検出

### 1-1. 画像テキスト映り込みチェック

MDXファイルから全 `<img>` タグを抽出し、各画像を Read ツールで確認する。

**チェック基準:**

| 画像内の要素 | 判定 | 対応 |
|---|---|---|
| 図の描画要素（線、枠、寸法線） | OK | そのまま |
| 図内のラベル（軸名、凡例、注記） | OK | そのまま |
| 図のキャプション（「図1-1-1 ...」） | 許容 | MDX側にもキャプションがあれば問題なし |
| 本文テキスト（「…である。」「…とする。」） | NG | 再トリミング必要 |
| 見出し（「1-5 輪郭と余白」等） | NG | 再トリミング必要 |
| 出典テキスト（「出典：[X-X] ...」） | NG | 再トリミング＋:::note追加 |
| 別の図・表の内容 | NG | 再トリミング必要 |

**効率化**: 1エージェントあたり最大10画像を担当。画像が多い場合は並列起動（最大3並列）。

### 1-2. 出典欠落チェック

- 画像内に出典テキストが写っている → その出典がMDXの `:::note` に記載されているか確認
- PDFソースがある場合は、ページごとに右欄の出典を網羅的に確認

### 1-3. 検出レポートフォーマット

```
=== 図品質レポート: {MDXファイル名} ===

## テキスト映り込み (N件)
| # | 画像ファイル | 映り込み内容 | 位置 | 対応 |
|---|------------|------------|------|------|
| 1 | 01-fig-01.png | 本文「の長辺を横方向に…」 | 上部 | 再トリミング |
| 2 | 01-fig-02.png | 見出し「1-5 輪郭と余白」＋本文 | 上部 | 再トリミング |
| 3 | 01-fig-02.png | 出典「CAD… P7」 | 右端 | 再トリミング＋:::note追加 |

## 出典欠落 (N件)
| # | 画像ファイル | 出典テキスト | MDXの挿入位置（行） |
|---|------------|------------|------------------|
| 1 | 01-fig-02.png | [1-5] CAD製図基準（H20.5）P7 | L94の後 |

## サマリー
- 画像総数: N
- テキスト映り込み: N件
- 出典欠落: N件
- 要修正画像: N件
```

## Phase 2: ユーザー確認

レポートを提示し、以下を確認:
- 全件修正 / 選択修正 / 修正不要
- PDFソースの有無（再トリミングにはPDFからの再レンダリングが理想）

## Phase 3: 修正

### 3-1. 画像の再トリミング

**PDFソースがある場合（推奨）:**
```python
import fitz
from PIL import Image

doc = fitz.open(pdf_path)
page = doc[page_num]
# 150 DPI でレンダリング
pix = page.get_pixmap(dpi=150)
img = Image.frombytes("RGB", [pix.width, pix.height], pix.samples)
# 図・表の領域のみ crop（縦線の左側、本文テキスト除外）
cropped = img.crop((left, top, right, bottom))
cropped.save(output_path)
```

**PDFソースがない場合（既存画像からのcrop）:**
```python
from PIL import Image
img = Image.open(existing_image_path)
# 上部のテキスト映り込み部分、右端の出典部分を切り落とし
# 映り込みの境界は目視で判断（Readで確認）
cropped = img.crop((left, top, right, bottom))
cropped.save(existing_image_path)  # 上書き保存
```

修正後は**必ず Read で再確認**。

### 3-2. 出典 :::note の追加

出典が欠落している箇所に `:::note[出典]` を追加する。

**挿入位置の決定:**
- 出典が対応する段落・項目の直後
- 図・表の直後（図に対する出典の場合）
- 解説ブロック (`> **（解 説）**`) の直後ではなく、本文側に配置

```mdx
#### 1-5 輪郭と余白

図面には輪郭を設ける。輪郭線は実線とし、線の太さは1.4mmとする。

輪郭外の余白は20mm以上とする。

:::note[出典]
[1-5] CAD製図基準（H20.5）P7
:::

<img src="..." alt="図1-1-2 輪郭と余白" />
<p className="text-center">図1-1-2 輪郭と余白</p>
```

### 3-3. MDXテキスト重複の除去

画像にテキストが映り込んでおり、同じテキストがMDX本文にもある場合:
- **MDXテキストは残す**（正）
- **画像を再トリミングして映り込みを除去**（修正）
- MDX側のテキストを削除するのは**NG**

## エージェント戦略

| 画像数 | 検出エージェント | 修正エージェント |
|---|---|---|
| 1-10 | 1 | 1 |
| 11-20 | 2（並列） | 1-2 |
| 21+ | 3（並列） | 2-3 |
