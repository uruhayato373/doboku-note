pdf-to-mdx で変換した MDX ファイルから、PDF 由来のアーティファクトを検出・除去する。

## 引数

```
/clean-pdf-artifacts <対象パス>
```

- ファイルパス: 単一の MDX ファイルをクリーンアップ
- ディレクトリパス: 配下の全 MDX ファイルを一括処理

## 背景

PDF を MDX に変換すると、以下のアーティファクトが混入しやすい:

- PDF のページヘッダー/フッターが本文中に紛れ込む
- ページ境界で見出しが途中で切れる
- 同じ章見出しがページごとに繰り返される
- ページ番号や「目次 N」が残る

これらは Docusaurus のレンダリングを壊し、ドキュメント構造を破壊する。

## 検出・修正項目

### 1. 重複ページヘッダーの除去（最重要）

PDF の各ページ上部に印刷される章タイトルが、変換時に `##` 見出しとして取り込まれる問題。

**検出方法:**
- 同一テキストの `##` 見出しが3回以上出現する場合、2回目以降は重複の疑い
- 直前・直後の行が空行や短い断片的テキスト（`第N編`、節番号のみ等）なら確定

**修正:**
- 各 `##` 見出しの最初の出現のみ残し、2回目以降を削除
- 削除対象の前後にある PDF ヘッダー付随行（`第N編`、ページ番号等）も一緒に削除

**実例（01-common.mdx で発生）:**
```
正常: ## 第1章 総則（1回目 → 残す）
不正: ## 第1章 総則（2回目以降 → 削除）
不正: ## 第1章 総則（3回目以降 → 削除）
```

### 2. 壊れた見出しの除去

ページ境界で見出しテキストが途中で切れたもの。

**検出パターン:**
- `## 第N章 ` + 2〜4文字で終わる不完全な見出し（例: `## 第7章 ポーラスア`）
- `## 第N章 ` + 明らかに見出しではないテキスト（例: `## 第2章 60分以内`）
- `## 第N編 ` のみで章名がない

**修正:** 該当行を削除

### 3. h1 見出しの h2 への変換

Docusaurus では frontmatter の `title` が h1 になるため、本文中の `# 見出し` は `## 見出し` にすべき。

**検出:** `^# [^#]` にマッチする行（`##` 以上は対象外）
**修正:** `# ` → `## `

### 4. 孤立したページヘッダー行の除去

PDF のヘッダー/フッターが独立した行として残っているもの。

**検出パターン:**
- `^第N編$` のみの行（前後が空行）
- `^第N編 [^\n]{1,10}$` で、前後に `##` 見出しがない
- `^目次 \d+$` や `^\d+-\d+$`（ページ番号）

**修正:** 該当行を削除

### 5. 表のヘッダー行混入

PDF の表がページをまたぐ際、表のヘッダー行が本文中に重複して現れる。

**検出:** 同一のテーブルヘッダー行（`| 項目 | 規格値 | ...`）が近接して繰り返される
**修正:** 重複するテーブルヘッダー＋セパレーター行を削除

## 手順

### Step 1: ファイル読み込みと構造把握

1. 対象ファイルを Read で読み込む（大きなファイルは分割）
2. 全 `##` 見出しを抽出してリストアップ
3. 各見出しの出現回数をカウント

### Step 2: 重複ヘッダーの特定

1. 3回以上出現する `##` 見出しを抽出
2. 各出現箇所の前後のコンテキスト（±3行）を確認
3. 最初の出現を「本物」、それ以降を「重複」と判定
4. 付随するヘッダー行（`第N編`、ページ番号等）も特定

### Step 3: その他のアーティファクト検出

- 壊れた見出し（短い・不完全なもの）
- h1 見出し
- 孤立したページヘッダー行

### Step 4: レポート出力

修正前に検出結果を一覧表示する:

```
=== clean-pdf-artifacts: 01-common.mdx ===

[重複ヘッダー] 35件
  - "## 第1章 総則" × 36回 → 35件削除予定
  - "## 第2章 土工" × 14回 → 13件削除予定

[壊れた見出し] 2件
  - L2649: "## 第2章 明"
  - L3753: "## 第3章 機械式鉄筋継手工法技術検討委員会"

[h1見出し] 0件

[孤立ヘッダー] 81件
  - "第1編" が81行で出現

合計: 118件の修正候補
```

### Step 5: ユーザー確認後に修正実行

ユーザーの確認を得てから Edit で修正を適用する。

### Step 6: ビルド確認

修正後に `npm run build` でビルドが通ることを確認する。

## 注意

- `###`（節）や `####`（項）の見出しは削除対象外。`##`（章）レベルのみ対象
- 見出し直後に本文が続く場合、見出し行のみ削除し本文は残す
- 判断に迷う場合はユーザーに確認する
- 大きなファイル（200KB+）は分割読み込みが必要
