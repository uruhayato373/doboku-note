## 文書の特徴

### テキスト抽出

PyMuPDFで**良好**。文字化けは少ない。

```python
import fitz, sys, io
sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8')

doc = fitz.open('第１章_設計一般.pdf')
for i in range(start_page, end_page):
    text = doc[i].get_text()
    print(f'--- Page {i+1} ---')
    print(text)
```

### ページヘッダ・フッタ

- **ヘッダなし**（ページ上端はコンテンツ）
- **フッタ**: `X-NN` 形式のページ番号（例: `1-1`, `1-60`, `2-15`）→ 除去する

### 出典注記

右欄外に「出典：[X-X] 文献名（年） PXX」形式の注記がある。PDFの縦線より右側に配置されている。

**変換方針**: MDXでは `:::note` ブロックに変換する:

```mdx
:::note[出典]
[1-3] CAD製図基準（H20.5）P5
:::
```

**出典の配置ルール:**
1. 出典が対応する段落・項目の**直後**に配置する
2. 同じ項目に複数の出典がある場合は1つの `:::note` にまとめる
3. **図・表の画像には出典を含めない** → 画像からは除外し、MDXテキストとして記載

```mdx
:::note[出典]
[1-5] CAD製図基準（H20.5）P7
[1-6] CAD製図基準（H20.5）P8
:::
```

**出典の抽出方法:**
- PDFページをPNG化してReadで読み取り、縦線右側のテキストを確認
- PyMuPDFのテキスト抽出で右端領域（x座標が大きい）のテキストブロックを拾う
- 出典が図の画像内に映り込んでいる場合は、画像を再トリミングして除去し、:::noteとしてMDXに追加

### 見出し体系

原文の見出し階層:

```
第X章 タイトル      → 章見出し（ファイル先頭のfrontmatter title）
第X節 タイトル      → h2: ## 第X節 タイトル
X. 小見出し         → h3: ### X. 小見出し
X－X 項目名         → h4: #### X-X 項目名
```

例:
```mdx
## 第1節 設計書添付図面（標準）

### 1. 設計書添付図面の作成要領

#### 1-1 適用範囲
```

### （解 説）ブロック

原文には多数の「（解 説）」ブロックがある。これは規定の解説であり、以下のように変換する:

```mdx
> **（解 説）**
>
> 解説の内容をここに記載する。複数段落にわたる場合も
> blockquote内に含める。
```

### 表

- **単純な表**: Markdownテーブル（`<div className="table-wrapper">` で囲む）
- **中程度の複雑さの表**（セル結合・rowspan/colspanあり、データ量が少ない）: **インラインSVG**で再現
- **複雑な表**（大量データ、斜線ヘッダ等）: PNG画像として抽出
- **表タイトル**: `<p className="table-title">表X-X-X タイトル</p>`

#### 表の形式選択基準

| 条件 | 形式 | 理由 |
|---|---|---|
| セル結合なし、単純な格子 | Markdownテーブル | 最もシンプル |
| colspan/rowspanあり、行数20以下 | インラインSVG | テキスト検索可、拡大しても鮮明 |
| 大量データ（行数20超）でセル結合あり | PNG画像 | SVGだと冗長すぎる |
| 斜線ヘッダ、複雑な装飾 | PNG画像 | SVGでの再現コストが高い |

**Markdownテーブルでセル結合が必要な場合は必ずSVGまたはPNG画像に切り替える。**Markdownテーブルはcolspan/rowspanを表現できないため、無理にMarkdownで書くと構造が崩れる。

#### SVG表の書き方

```mdx
<svg viewBox="0 0 600 300" xmlns="http://www.w3.org/2000/svg"
  style={{maxWidth: '600px', width: '100%', display: 'block', margin: '0 auto'}}>
  <style>{`
    text { font-family: sans-serif; font-size: 11px; }
    .hdr { font-weight: bold; }
    line, rect { stroke: #333; }
  `}</style>
  {/* 外枠 */}
  <rect x="0" y="0" width="600" height="280" fill="none" strokeWidth="1.5"/>
  {/* 罫線・テキストを配置 */}
</svg>
```

**SVG表の注意点:**
- `style` はJSX記法（`style={{}}`）で記述
- 中央揃え: `display: 'block', margin: '0 auto'`
- テキストは `textAnchor="middle"` で列中央に配置
- 結合セルはテキストを結合範囲の中央y座標に配置し、内部の罫線を省略する

### 図

- 線画・構造図: PDFページをPNG化してPILでトリミング（150 DPI）
- フロー図: 単純ならMermaidで再現、複雑ならPNG
- **図キャプション**: `<p className="text-center">図X-X-X タイトル</p>`
- **命名**: `{編番号2桁}-fig-{連番2桁}.png`

#### 図・表のトリミング基準（重要）

この文書は**本文領域**と**出典欄**が縦線で分割されたレイアウトを持つ。

```
┌──────────────────────────┬─────────┐
│                          │ 出典：   │
│  本文テキスト             │ [1-3]   │
│                          │ CAD製図  │
│  ┌────────────────┐      │ 基準    │
│  │  図・表の内容    │      │ (H20.5) │
│  │                │      │ P5      │
│  └────────────────┘      │         │
│  図1-1-1 キャプション     │         │
│                          │         │
└──────────────────────────┴─────────┘
         ↑ 縦線（右端の区切り線）
```

**トリミングルール:**

1. **縦線より右側（出典欄）は画像に含めない** → 出典はMDXの `:::note[出典]` で記載
2. **本文テキスト・見出しは画像に含めない** → これらはMDXのマークダウンで記載済み
3. **図・表の外枠ぎりぎりで切る**（図のキャプションは含めてよいが、MDX側にも記載する）
4. **切り出し対象**: 図の罫線・描画要素・寸法線・凡例のみ

**NG例（テキスト映り込み）:**
- 図の上に「1-5 輪郭と余白」等の見出しが写っている
- 図の上に「図面には輪郭を設ける。輪郭線は…」等の本文が写っている
- 図の右端に「出典：[1-6] CAD製図基準」が写っている

**トリミング手順:**
```python
from PIL import Image
img = Image.open(page_png)
# 1. 縦線のx座標を検出（右端の区切り線）→ 右端をそこで切る
# 2. 図・表の上端・下端を特定 → 本文テキスト行を除外
# 3. crop で切り出し
cropped = img.crop((left, top, right, bottom))
cropped.save(output_path)
```

トリミング後は**必ずReadツールで確認**し、以下をチェック:
- 本文テキストが映り込んでいないか
- 出典欄が含まれていないか
- 図・表が切れていないか
