MDX ファイルの内容をソース PDF と照合し、抽出の正確性を検証する。

## 引数

```
/verify-content <MDXファイルパス> <ソースPDFパス> [ページ範囲]
```

- `MDXファイルパス`（必須）: 検証対象の MDX ファイル
- `ソースPDFパス`（必須）: 変換元の PDF ファイル
- `ページ範囲`（任意）: PDF のページ範囲（例: `100-150`）。省略時は MDX の内容から該当ページを推定

## チェック項目

### 1. 構造の完全性

- PDF の全章・節・項が MDX に存在するか
- 見出しの番号体系が PDF と一致するか（例: `3-2-6-1` → `3-2-6-19`）
- 章・節の順序が正しいか

### 2. 内容の正確性

- 条文番号・項番号が欠落していないか
- 数値（寸法、基準値、温度等）が正確か
- 技術用語が正しく変換されているか
- 「参照：第○編...」の相互参照が正しいか

### 3. 表の完全性

- PDF の表が MDX にすべて変換されているか
- 表の行数・列数が一致するか
- 表中の数値が正確か

### 4. 抽出漏れの検出

- PDF のページ数・文字量と MDX のサイズを比較し、大幅な差異がないか
- 連続する節番号に欠番がないか（例: 3-2-6-7 の次が 3-2-6-9 → 3-2-6-8 が欠落）
- ページ境界付近のテキストが途切れていないか

### 5. 誤変換の検出

- OCR 由来の誤字（例: 「工」↔「エ」、「ロ」↔「口」）
- 数式の誤変換（上付き・下付きの欠落等）
- 全角/半角の混在

## 手順

### Phase 1: MDX の構造把握

1. MDX ファイルを Read で読み込む
2. 全見出し（`##`, `###`, `####`）を抽出してアウトラインを作成
3. 節番号の連続性を確認

### Phase 2: PDF との照合

1. PDF の該当ページ範囲を Read で読み込む（20ページずつ）
2. PDF の目次・見出し構造を抽出
3. MDX のアウトラインと PDF の構造を突き合わせ

### Phase 3: サンプリング検証

全文照合はコスト高なので、以下のサンプリング戦略で検証する:

1. **各節の冒頭**: 最初の段落が正しく抽出されているか
2. **各節の末尾**: 最後の項目が欠落していないか
3. **表**: ランダムに 3〜5 個の表を抽出して行数・数値を照合
4. **数式**: 数式を含む箇所をランダムに 3〜5 個チェック
5. **ページ境界**: PDF のページ切れ目付近のテキストを確認

### Phase 4: 結果レポート

```
=== verify-content: <MDXファイル名> ===

## 構造チェック
- 章: 3/3 ✓
- 節: 18/18 ✓
- 項: 145/148 — 3件欠落

## 欠落の疑い
- [MISSING] 3-2-6-8 半たわみ性舗装工 — MDX に見出しなし
  → PDF p.87 に存在

## サンプリング検証（N箇所）
- [OK] 3-2-3-1 冒頭段落: 一致
- [WARN] 3-2-6-7 表: PDF は 12行、MDX は 10行（2行欠落の可能性）
- [ERROR] 3-2-7-3 数値: PDF「50mm」→ MDX「500mm」（誤変換）

## サマリー
- 構造完全性: 98% (145/148)
- サンプリング正確性: 90% (9/10)
- 要修正: 4件
```

### Phase 5: 修正提案

欠落・誤変換が見つかった場合、PDF の該当ページを再読み込みして修正内容を提案する。ユーザーの確認後に修正を適用する。

## 注意

- PDF の Read は 20 ページ/回の制限がある。大きな PDF では Phase 2 に時間がかかる
- 完全な全文照合ではなく、サンプリングベースの検証である旨をユーザーに伝える
- 修正時は原文の意味を変えない（`pdf-to-mdx` の変換ルールに準拠）
