## 使い方

```
/common-specs-import              # 進捗確認し、未変換の次の編を1件変換

/common-specs-import 4            # 第4編を変換
/common-specs-import 13           # 第13編を変換
/common-specs-import verify 6     # 第6編のMDXをPDFと照合
```

## エージェント戦略

### 原則: 1編 = 1エージェント

- 各編は独立したサブエージェントで処理する
- 複数編を並列で起動可能（Agent tool を1メッセージに複数含める）

### 大きな編の分割基準

100ページ超の編はさらに**章単位で分割**する:

| 編 | 分割方法 |
|---|---|
| 第3編 (172P) | 第1章 + 第2章前半 / 第2章後半 の2〜3エージェント |
| 第10編 (162P) | 第1-5章 / 第6-10章 / 第11-16章 の3エージェント |
| 第14編 (104P) | 章数に応じて2エージェント |
| その他 (100P未満) | 1エージェント |

## テキスト抽出

### PyMuPDF（Windows環境）

```python
import fitz, sys, io
sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8')

doc = fitz.open('土木工事共通仕様書【令和6年10月改定】.pdf')
for i in range(start_page - 1, end_page):
    text = doc[i].get_text()
    print(f'--- Page {i+1} ---')
    print(text)
```

> PyMuPDFのテキスト抽出はこの文書では比較的良好（文字化けが少ない）。ただしページヘッダ・フッタ（「第X編 XX編 第Y章 YY」「X-NN」形式）の除去が必要。

### テキスト抽出の注意点

- **ページヘッダを除去**: 各ページ冒頭の「第X編 XX編 第Y章 YY」行とページ番号（「X-NN」形式）を除去
- **改行の結合**: PyMuPDF は原稿の行末で改行するため、文の途中の改行を結合する
- **表の認識**: 表はPyMuPDFでは崩れやすい → ページPNG化して確認し、Markdownテーブルまたは画像で対応

## 変換ルール

### 見出し階層

```
# 第{N}編 {タイトル}         → ファイル先頭のみ（frontmatterのtitleと重複する場合は省略可）
## 第{M}章 {タイトル}        → h2
### 第{K}節 {タイトル}       → h3
#### {番号} {タイトル}       → h4（例: 1-1-1-1 適用）
```

### 条項番号の扱い

原文の条項番号（例: `1-1-1-1`）は見出しに含める:

```mdx
#### 1-1-1-1 適用
```

箇条書き番号（例: `1.適用工事`）は太字:

```mdx
**1.適用工事**
```

### frontmatter

```yaml
---
sidebar_position: {編番号}
title: "第{N}編 {タイトル}"
description: "{内容の要約、120文字以内}"
source:
  title: "土木工事共通仕様書"
  author: "兵庫県土木部"
  date: "令和6年10月改定"
---
```

### 表

- Markdownテーブルで変換
- 複雑な表（セル結合、斜線ヘッダ等）はPNG画像にする

### 図

- この文書には図は少ない
- 必要な場合はPNG化して `content/general/common-specs/img/` に配置
- 命名: `fig-{編番号}-{連番}.png`

### 「参考」「注」ブロック

```mdx
:::note
注記の内容
:::
```

## ワークフロー

### Phase 2: 既存編の照合・更新

既存の近畿地方整備局版MDXと兵庫県版PDFを照合し、差異を確認:
- 共通部分はそのまま
- 兵庫県固有の追記・変更があれば更新
- source のメタデータを更新

### Phase 3: index.mdx の更新

全編の変換完了後、`index.mdx` を更新して新しい編へのリンクを追加。

| ステータス | 意味 |

| 未着手 | まだ取りかかっていない |

| 変換中 | MDX変換作業中 |
