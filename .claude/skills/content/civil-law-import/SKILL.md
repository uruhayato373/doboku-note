## 画像抽出

### PyMuPDF（画像ベースPDF対応）

```python
import fitz, sys, io
sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8')

doc = fitz.open('C:/Users/m004195/doboku-note/第３部_民法.pdf')
for i in range(start_page - 1, end_page):
    pix = doc[i].get_pixmap(dpi=200)
    pix.save(f'C:/Users/m004195/doboku-note/_minpo_p{i+1}.png')
```

その後、Read ツールでPNG画像を読み取りテキスト化。

### 注意点

- 画像ベースPDFのためテキスト抽出不可、Claudeビジョンで読取
- 1回のRead呼出しで1ページずつ読み取り
- 図表・イラストはテキストで説明、図そのものは省略
- ページヘッダ・フッタ（「第X章 - XXXX 第X節 - XXXX NNN」形式）を除去

## 変換ルール

### 見出し階層

```
## {節タイトル}           → h2（大見出し番号付き：1, 2, 3...）
### {中見出し}            → h3（(1), (2)...）
#### {小見出し}           → h4（①, ②...）
```

### frontmatter

```yaml
---
sidebar_position: {通し番号}
title: "{章番号}-{節番号}. {タイトル}"
description: "{内容の要約、120文字以内}"
---
```

### コンテンツ変換ルール

- 本文テキストはそのまま転記
- **太字**・重要語句は `**太字**` で表現
- 表はMarkdownテーブル
- 「学習のPOINT」「重要判例」ボックスは `:::tip` / `:::info` で囲む
- 「注意」ボックスは `:::warning` で囲む
- 確認テストは `:::note[確認テスト]` で囲む
- 条文参照は `（XXX条）` の形式をそのまま保持
- イラスト・図解は省略し、テキストで内容を補完
- 色付き表は Markdown テーブルで再現（色情報は省略）
