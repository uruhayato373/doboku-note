## テキスト抽出

### PyMuPDF（Windows環境）

```python
import fitz, sys, io
sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8')

doc = fitz.open('C:/Users/m004195/doboku-note/hikkei-{N}.pdf')
for i in range(start_page - 1, end_page):
    text = doc[i].get_text()
    print(f'--- Page {i+1} ---')
    print(text)
```

### テキスト抽出の注意点

- テキスト抽出可能率: ~89%（残り11%は図表・様式）
- 図表が多いページ（様式、標示板図、施工管理基準表）はPNG画像化を検討
- ページヘッダ・フッタ（「{番号}-{ページ}」形式）を除去

## 変換ルール

### 見出し階層

各項目は独立文書のため、内部構造に応じて柔軟に対応:

```
## {章タイトル}          → h2
### {節タイトル}         → h3
#### {項タイトル}        → h4
```

### frontmatter

```yaml
---
sidebar_position: {項目番号}
title: "{項目番号}. {タイトル}"
description: "{内容の要約、120文字以内}"
source:
  title: "土木請負工事必携"
  author: "兵庫県土木部"
  date: "令和7年10月改定"
---
```

### 共通ルール

- 表はMarkdownテーブルで変換
- 「注」「参考」ブロックは `:::note ... :::` で囲む
- 様式（フォーム）はテキスト変換が困難な場合、構造の説明のみ記載
- 図は `content/general/hyogo-hikkei/img/` に配置
- 1ファイル3,000行を超える場合は分割

## エージェント戦略

### 原則: PDF単位でフェーズ分割

- フェーズ1: PDF 1/4 → 項目1〜9
- フェーズ2: PDF 2/4 → 項目10〜21
- フェーズ3: PDF 3/4 → 項目22〜37
- フェーズ4: PDF 4/4 → 項目38〜43

### エージェント分割

- 小さい項目（~30P以下）: 2〜4項目を1エージェントにまとめる
- 大きい項目（100P超）: 章単位で分割
- 図表主体の項目: 1エージェントで対応（テキスト少量）
