## エージェント戦略

### 基本: 1セクション = 1エージェント

各年度の問題A / 問題B を1エージェントで処理。

### OCR品質による戦略分岐

| 品質 | 年度 | 方法 |
|---|---|---|
| 良好 | R2, R1 | PyMuPDFテキスト抽出 → エージェントで変換 |
| 概ね良好 | H30 | テキスト抽出 + 一部ページ画像確認 |
| 不良 | H29-H26 | PDFページを画像化（Read tool）→ 画像から直接変換 |

### テキスト抽出（良好な年度）

```python
import fitz, sys, io
sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8')

doc = fitz.open('{PDFパス}')
for i in range(start_page - 1, end_page):
    text = doc[i].get_text()
    print(f'--- Page {i+1} ---')
    print(text)
```

### 画像変換（品質不良の年度）

```bash
pdftoppm -png -r 150 -f {ページ} -l {ページ} '{PDFパス}' /tmp/exam-p
# → Read tool で画像を読んで内容を変換
```

## ワークフロー

### 推奨変換順序（OCR品質順）

1. **令和2年度** 問題A → 問題B（最新・最高品質、パターン確立）
2. **令和元年度** 問題A → 問題B
3. **平成30年度** 問題A → 問題B
4. **平成29年度**〜**平成26年度**（OCR不良、画像変換が必要）

### 各セクションの変換手順

1. テキスト抽出（良好な年度）or ページ画像化（不良な年度）
2. エージェントでMDX変換
3. `[問題 No.XX]` `[正解]` パターンで構造を検証
4. `/check-mdx --rules syntax` で構文チェック
5. SKILL.md の状態欄を更新
