PDF→MDX変換の品質を体系的に検証し、問題を修正する。

## 引数

```
/qa-pdf-mdx <MDXファイルパス> <ソースPDFパス> [ページ範囲]
```

- `MDXファイルパス`（必須）: 検証対象の MDX ファイル
- `ソースPDFパス`（必須）: 変換元の PDF ファイル
- `ページ範囲`（任意）: PDF のページ範囲（例: `1-50`）。省略時は全ページ

## アーキテクチャ

```
メイン（オーケストレーター）
  │
  ├── Phase 1: 照合agent（Agent tool, read-only）
  │   └── PDFとMDXを比較 → 差分レポートを生成
  │
  ├── Phase 2: ユーザー確認
  │   └── 差分レポートをユーザーに提示し承認を得る
  │
  └── Phase 3: 修正agent（Agent tool, 編集あり）
      └── 承認された項目を修正
```

## Phase 1: 照合agent

### 起動方法

照合agentは **PDFのページ数に応じて分割起動** する。1agentあたり最大20ページを担当。

```
Agent tool (subagent_type: general-purpose)
  prompt: 照合指示 + PDFパス + ページ範囲 + MDXパス + チェック項目
```

複数agentを **並列起動** してよい（最大3並列）。

### チェック項目（6カテゴリ）

#### 1. コンテンツ完全性チェック

PDFの各ページを読み取り、MDXに対応するテキストが存在するか確認する。

- PDF の各見出し（章・節・項）が MDX に存在するか
- PDF の各段落の冒頭文がMDXに存在するか
- PDF の箇条書き・番号付きリストがMDXに存在するか
- **欠落の疑いがある場合**: PDFページ番号・該当テキストの冒頭50文字を記録

#### 2. 図の完全性チェック

- PDF 内の全ての図（図番号付き）が MDX で参照されているか
- MDX の `<img>` タグの図番号と、本文中の「図 X-X-X」参照が一致するか
- 図の挿入位置が、本文中の参照位置の直後にあるか（参照行と画像行の距離を確認）
- 図番号に重複・欠番がないか

#### 3. 画像トリミングチェック

MDX から参照されている全画像ファイルを Read ツールで読み取り、以下を確認:

- 画像の上部・下部に本文テキストが映り込んでいないか
- 画像の上部・下部に別の図のキャプションが映り込んでいないか
- 図のタイトル（「図 X-X-X ...」）が画像内に含まれていないか（キャプションはMDX側で記述すべき）

**判定基準:**
- 図の内容に必要なラベル（軸名、凡例、寸法等）→ OK（図の一部）
- 本文の文章（「...である。」「...とする。」）→ NG（トリミング必要）
- 見出し（「3.1.12 周期による...」）→ NG（トリミング必要）
- 数式（式 X-X-X）→ NG（MDX側でKaTeXとして記述すべき）

#### 4. 表チェック

- PDF の表がMDXにMarkdownテーブルとして変換されているか
- 表と同内容の画像が重複して存在していないか（民法テキストで発見されたパターン）
- 表の行数・列数がPDFと一致するか（サンプリング）

#### 5. 数式チェック

- PDF の数式がMDXでKaTeX記法に変換されているか
- 式番号（`\tag{}`）がPDFと一致するか
- 式番号に重複・欠番がないか

#### 6. キャプション・参照チェック

- 図のキャプション（`<p className="text-center">`）がPDFのキャプションと一致するか
- 表のタイトル（`<p className="table-title">`）がPDFと一致するか
- 本文中の「図 X-X」「表 X-X」「式 X-X」参照が実在するか

## Phase 2: ユーザー確認

メインが照合レポートをユーザーに提示する。ユーザーは以下を選択:
- 全件修正
- 選択的に修正（番号指定）
- 修正不要

## Phase 3: 修正agent

承認された修正項目を実行する。修正agentも **問題の種類ごとに分割起動** してよい。

### 修正能力

#### 画像トリミング修正
```python
from PIL import Image
# Read ツールで画像を確認 → 切り取り座標を決定 → PIL で crop → 保存
# 必ず修正後に Read で再確認
```

#### 図の挿入位置修正
- MDX内の `<img>` タグを正しい位置に移動（Edit ツール）

#### 欠落コンテンツの追加
- PDFの該当ページを再読み取り
- MDX の適切な位置にテキストを挿入（Edit ツール）
- 数式はKaTeX記法に変換

#### 重複画像の削除
- MDXから `<img>` 参照行を削除
- 画像ファイルを削除

#### 図番号の修正
- MDX内のキャプションを修正

### 修正後の確認

修正agentは修正完了後に以下を確認:
- 修正した画像を Read で再確認（トリミングが適切か）
- MDXの構文が壊れていないか

## 運用ガイド

### 1ファイルの実行時間目安

| PDF ページ数 | 照合agent数 | 推定時間 |
|-----------|-----------|---------|
| 1-20 | 1 | 3-5分 |
| 21-40 | 2（並列） | 5-8分 |
| 41-60 | 3（並列） | 8-12分 |

### コンテキスト管理

- 照合agentはPDF読み取りでコンテキストを消費するため、20ページ/agentを上限とする
- 修正agentは問題件数が多い場合（10件超）、種類ごとに分割する
- 大きなファイル（100KB超のMDX）は `/compact` を実行してから修正agentを起動する

### 既存スキルとの関係

| スキル | 役割 | `/qa-pdf-mdx` との関係 |
|--------|------|----------------------|
| `/fishery-port-import` | PDF→MDX変換（新規作成） | 変換後に `/qa-pdf-mdx` で検証 |
| `/verify-content` | サンプリング検証 | `/qa-pdf-mdx` が上位互換（全量検証） |
| `/clean-pdf-artifacts` | PDF残骸除去 | `/qa-pdf-mdx` に統合（図番号チェック追加） |
| `/check-mdx` | MDX構文チェック | `/qa-pdf-mdx` の修正後に実行推奨 |

## 注意

- PDFがスキャン画像ベースの場合、Read ツールで画像として読み取る（テキスト抽出不可）
- 照合agentは **編集を一切行わない**（read-only）。修正はPhase 3でのみ実行
- 修正agentは **ユーザー承認後にのみ** 実行する
- 画像のトリミングは必ず修正前後で Read による目視確認を行う
