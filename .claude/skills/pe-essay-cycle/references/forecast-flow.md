# 総監 記述式の予想フロー（テーマ予測 → 予想問題 → ペルソナ模範解答）

`/pe-essay-cycle forecast` の手順書。年度 R{NN}（例: R9＝令和9年度・2027年7月実施）ごとに同じ型で回す。
元は 「06_R8記述式予測フロー」（docs/editorial）（2026-05-18 策定・R8 で運用・2026-09-27 にこのスキルへ移管）。
R8 当時の原文は commit 747fab5d9 の「06_R8記述式予測フロー」 で読める。

## 1. 3 段階と担当

| 段階 | 入力 | 出力 | 担当 |
|---|---|---|---|
| Stage 1 テーマ予測 | 前年度（R{NN-1}）の白書・閣議決定・国家戦略、過去 17 年の出題テーマ表 | 3 軸スコア付きの候補テーマ N 本（R8 は 6 本） | 親（このスキル）。白書の根拠は NotebookLM 白書ノートブック |
| Stage 2 予想問題 | Stage 1 で 3 軸 ◎ 以上のテーマ・過去問形式（II-2 / III） | テーマごとに公式形式の予想設問（4 設問・各 600 字相当・計 5 枚） | `cem-essay-writer`（生成）→ `cem-essay-qa`（採点） |
| Stage 3 模範解答 | Stage 2 の予想問題・既存の pattern-essay / r0X-essay | 固定 3 ペルソナ × テーマの三層構造答案 | サイトの思考フレームは `pe-essay-draft` → `pe-essay-review`、note 有料は `cem-essay-writer` → `cem-essay-qa` |

次の段へ進めるのは、Stage 1 で 3 軸 ◎ 以上のテーマと、Stage 2 で固定 3 ペルソナすべてで「管理対象 → 施策 → 将来展望」が組めるテーマだけ。

## 2. 判定基準

### Stage 1: 3 軸スコア

| 軸 | ◎ | ○ | △ |
|---|---|---|---|
| A. 根拠 | 前年度白書 2 冊以上で直接特集 | 1 冊で言及 | 扱いが間接的 |
| B. 立案 | 直近 5 年から派生でき、3 ペルソナに対応 | 一部ペルソナに偏る | 5 管理の対立が読み取りにくい |
| C. 解答 | 既存の pattern-essay / r0X-essay を流用できる | 一部新規執筆 | 既存資源が薄く新規負荷大 |

判定の入力: (A) サイト `/exam/pe-comprehensive-management/` の白書マップ（whitepaper-study-map）と NotebookLM 白書ノートブック（ID `2bf7f0dd-3935-49be-8cef-2d428c59eaa9`・使う前に `notebooklm login` を確認。認証は週 1 回程度で切れる）、(B) 記述式の試験戦略ページ（出題テーマ表・三層構造）、(C) 既存の pattern-essay 3 本と r0X-essay の棚卸し。

3 軸スコアの目的は数の絞り込みではなく「なぜこのテーマか」の透明化。テーマ数を増やすより、同じ本数で根拠を説明する方が note の購買動機が立つ。

### Stage 2: 予想問題の検証

- 直近 5 年のメインテーマ軸と重複しない
- 5 管理のペアが主軸と副軸の 2 つ以上で描ける
- 設問構造が公式形式（4 設問・各 600 字相当・計 5 枚）に合う
- 固定 3 ペルソナそれぞれで管理対象を具体的に設定できる

### Stage 3: 三層構造の採点

- Ⅰ 管理対象と前提条件（1 枚目）／Ⅱ 施策＝5 管理の対立解決（2〜4 枚目）／Ⅲ 将来展望（5 枚目）
- 管理対象の具体化（ペルソナ業務に即した固有名詞）・トレードオフの統合解決（ALARP・リスクベース・LCA・段階的実施・合意形成）・残余リスクの監視計画

## 3. サイトと note の分け方

| 段階 | サイト（無料） | note（有料） |
|---|---|---|
| Stage 1 | 候補テーマの俯瞰・3 軸スコア（◎○△）・関連キーワード・関連白書 | 予想問題集の序章「なぜこのテーマか」の根拠詳細 |
| Stage 2 | 想定問題文・解答の方向性・固定 3 ペルソナ別の管理対象設定例・業界外受験者へのアレンジ 1 行 | 全テーマの完全な予想問題 |
| Stage 3 | pattern-essay / r0X-essay の思考フレーム（抽象） | 固定 3 ペルソナのフル解答骨子 |

- サイトは思考フレーム（抽象）、note は具体数字 × ペルソナ展開（Red Line #7）。3 軸 ◎ のテーマでも、採点基準とフル解答はサイトに載せない。
- 根拠を示せない予測（「なんとなく出そう」）を有料コンテンツに入れない。
- ペルソナは固定 3 種（ゼネコン / 河川コンサル / 道路発注者）で縦串を揃える。テーマごとに業界ペルソナを増やさない（content-principles.md §21）。業界外受験者は spoke 末尾の 1 行と note の解答テンプレ 3D マトリクスで救う。
- 予想は横断の「R{NN} 予想問題集」（テーマ駆動）に一本化する。ペルソナ別マガジンの扱いは `content/note/技術士総監/総監マガジン構成_決定2026.md` と `note-essay-review-checklist.md` に従う。

## 4. 手順（1 年度分）

1. 前年度白書の特集を NotebookLM で引き、候補テーマを出して 3 軸で採点する（統合できるテーマは単独にしない。R8 ではエネルギー安保・経済安保・AI ガバナンスを既存テーマへ統合し、災害復旧×レジリエンスは独立の価値ありと判断した）
2. サイトの予想ハブ（R{NN} essay keyword forecast）に候補テーマと 3 軸スコアを反映する
3. ◎ のテーマごとに `cem-essay-writer` で予想設問を作り、`cem-essay-qa` で公式形式・重複・ペルソナ適合を採点する
4. 合格した設問で三層構造の模範解答を作る（サイト＝`draft` モード、note＝`cem-essay-writer`）。採点は `review` モード／`cem-essay-qa`
5. note の予想問題集を `publish` モードの公開ゲートに通す。価格の正本は `src/lib/note-magazines.ts`
6. 試験後に的中を振り返る。的中の帰属は設問(3)のバンクだけで数える

## 5. R8 の実績（2026-05〜07）

- 候補 6 テーマ（A〜F）で予想ハブを公開し、無料のリード磁石 2 本（気候変動適応・資源循環サプライチェーン）から note「R8 予想問題集」へ送客した
- 予想は横断のフラッグシップに一本化し、ペルソナ別マガジンは過去問 R03〜R07 の evergreen に純化した（決定2026）
