土木・建設業界のニュースやトレンドを収集し、doboku-note のコンテンツ機会を特定する。

## 引数

```
/discover-trends-civil [--source SOURCE] [--days N]
```

- `--source`（任意）: 情報ソースの指定（省略時: 全ソース）
  - `mlit`: 国土交通省プレスリリース
  - `news`: 建設系ニュースサイト
  - `search`: Google 検索トレンド
  - `disaster`: 災害関連速報
- `--days`（任意）: 取得期間（デフォルト: 7日）

## 情報ソース

### 1. 国土交通省

WebFetch で以下を取得:
- 報道発表資料
- 新たな基準・指針の公表
- 防災関連発表

### 2. 建設系ニュース

WebSearch で以下のクエリを実行:
```
検索クエリ:
- "土木 ニュース 最新"
- "建設業界 動向"
- "インフラ 老朽化 対策"
- "防災 減災 最新"
- "道路 橋梁 補修"
- "河川 氾濫 対策"
```

### 3. Google 検索トレンド

WebSearch で急上昇中の土木関連キーワードを検出:
```
検索クエリ:
- "施工管理技士 2026"
- "技術士 2026"
- "建設DX"
- "i-Construction"
- "BIM/CIM"
```

### 4. 災害・自然現象関連

直近の災害・自然現象に関連するコンテンツ需要:
```
検索クエリ:
- "地震 液状化"
- "豪雨 土砂災害"
- "台風 河川氾濫"
```

## 手順

### Phase 1: トレンド収集（並列サブエージェント）

4つのサブエージェントで各ソースからトレンドを収集。

各トレンドについて記録:
- トレンドタイトル
- ソース（URL）
- 関連キーワード
- 推定検索需要（高/中/低）
- 関連する doboku-note カテゴリ

### Phase 2: doboku-note コンテンツとのマッチング

収集したトレンドを doboku-note の既存コンテンツと突合:

| 分類 | 説明 |
|---|---|
| **既存コンテンツで対応可** | 記事はあるが更新・拡充で対応できる |
| **新規コンテンツが必要** | トレンドに対応するページがない |
| **関連性低** | doboku-note のスコープ外 |

### Phase 3: 機会の優先度付け

```
優先度スコア = 検索需要(1-5) × 時事性(1-5) × 既存コンテンツ活用度(1-3)
```

| 要素 | 説明 |
|---|---|
| 検索需要 | トレンドの検索ボリューム規模 |
| 時事性 | タイムリーに対応する重要性（ニュースは高、基準改定は中） |
| 既存コンテンツ活用度 | 既存ページの拡充で対応可能なら高スコア |

### Phase 4: アクション提案

上位 5-10 件のトレンドについて:
- 対応するコンテンツ案（タイトル・概要・配置先）
- 既存ページの更新提案（該当する場合）
- SEO 効果の見込み

### Phase 5: 出力

`docs/reviews/trends/YYYY-MM-DD.md` に保存する。
