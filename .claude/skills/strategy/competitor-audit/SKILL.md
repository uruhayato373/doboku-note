doboku-note の競合サイトを調査し、コンテンツ・SEO・収益モデルの観点で比較分析する。

## 引数

```
/competitor-audit [--target URL] [--focus AREA]
```

- `--target`（任意）: 特定の競合サイトを指定（省略時: 主要競合を自動選定）
- `--focus`（任意）: 分析の重点領域
  - `content`: コンテンツ量・品質・カバレッジ
  - `seo`: SEO 戦略・キーワード・被リンク
  - `monetization`: 収益化手法

## プロジェクトコンテキスト

- **サイト**: doboku-note.com（土木工学ドキュメントサイト）
- **カテゴリ**: 一般（土木工学・施工管理）/ 道路 / 河川 / 法律
- **収益**: Google AdSense（最適化未実施）
- **競争領域**: 土木系技術ノート、資格試験対策（施工管理技士・技術士）、法律解説

## 手順

### Phase 1: 競合サイトの特定（並列サブエージェント）

3つのサブエージェントで競合カテゴリ別に調査する。

#### Agent A: 技術ノート系競合

WebSearch で以下のクエリを検索し、上位に出現するサイトを特定:

```
検索クエリ例:
- "土木工学 まとめ"
- "施工管理 技術ノート"
- "コンクリート 配合設計 解説"
- "河川工学 基礎"
- "道路構造令 解説"
```

各サイトについて記録:
- サイト名・URL
- コンテンツ形式（ブログ / Wiki / ドキュメント / 動画）
- 推定ページ数（site:ドメイン で概算）
- カバー分野

#### Agent B: 資格試験対策系競合

```
検索クエリ例:
- "施工管理技士 勉強法"
- "技術士 二次試験 対策"
- "土木施工管理技士 過去問 解説"
- "コンクリート技士 試験対策"
```

各サイトについて記録:
- 無料/有料の境界
- 過去問解説の有無
- 学習教材の提供形態

#### Agent C: 法律・行政系競合

```
検索クエリ例:
- "国家賠償法 解説"
- "行政事件訴訟法 わかりやすく"
- "土木 法律 まとめ"
```

### Phase 2: 競合分析マトリクス

各競合サイトを以下の軸で評価する:

| 評価軸 | 評価方法 |
|---|---|
| **コンテンツ量** | サイト規模・カテゴリ数・更新頻度 |
| **コンテンツ品質** | 専門性・正確性・図表の充実度 |
| **SEO 強度** | 検索順位の競合状況・ドメインの強さ |
| **収益モデル** | 広告/アフィリエイト/有料コンテンツ/書籍販売 |
| **UX** | サイト速度・モバイル対応・ナビゲーション |
| **差別化要素** | 独自の価値提供 |

### Phase 3: GSC データとの突合

doboku-note の GSC データ（利用可能な場合）と競合を突き合わせる:

1. doboku-note が上位表示できているクエリ vs 競合が上位のクエリ
2. 競合がカバーしているが doboku-note にないトピック
3. doboku-note の強み（競合にない独自コンテンツ）

### Phase 4: 差別化戦略の提案

#### 4.1 コンテンツギャップ
- 競合がカバーし doboku-note にないテーマ
- 優先度（検索ボリューム × 競合の弱さ）

#### 4.2 収益化の学び
- 競合の収益モデルから学べること
- doboku-note に適用可能な手法

#### 4.3 SEO 戦略の示唆
- 競合のキーワード戦略から学べること
- 狙うべきキーワードカテゴリ
