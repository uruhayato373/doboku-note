土木系資格試験の日程と検索需要の季節変動を分析し、コンテンツ公開・更新の最適タイミングを設計する。

## 引数

```
/discover-exam-season [--quarter Q] [--year YYYY]
```

- `--quarter`（任意）: 対象四半期（省略時: 今四半期 + 次四半期）
  - `Q1`: 1-3月、`Q2`: 4-6月、`Q3`: 7-9月、`Q4`: 10-12月
- `--year`（任意）: 対象年（デフォルト: 今年）

## 手順

### Phase 1: 現在地の確認

#### 1.1 カレンダー確認
- 今日の日付から直近3ヶ月以内の試験を特定
- 各試験までの残り日数を算出

#### 1.2 GSC データ分析（利用可能な場合）

試験関連クエリの季節変動を取得:
- 前年同時期との比較
- 直近の検索トレンドの上昇/下降

#### 1.3 既存コンテンツの棚卸し

試験対策に関連する既存コンテンツを確認:
```
docs/ 配下の .mdx ファイルで以下を検索:
- "施工管理" "品質管理" "工程管理" "安全管理"
- "技術士" "口頭試験" "筆記試験"
- "過去問" "試験対策"
```

### Phase 2: 季節戦略の設計

#### 2.1 直近3ヶ月のコンテンツカレンダー

各週で「何を公開・更新すべきか」を設計:

| 週 | 対象試験 | 残り | アクション | コンテンツ内容 |
|---|---|---|---|---|
| W1 | 施工管理技士 | 8週 | 新規作成 | 頻出問題解説 |
| W2 | 施工管理技士 | 7週 | 既存更新 | 品質管理の強化 |

#### 2.2 コンテンツタイプ別戦略

| 試験までの期間 | 需要の高いコンテンツ | 形式 |
|---|---|---|
| 3ヶ月前 | 勉強法・学習計画 | 解説記事 |
| 2ヶ月前 | 科目別要点まとめ | 技術ノート |
| 1ヶ月前 | 頻出問題・過去問解説 | 問題+解説 |
| 2週間前 | 直前チェックリスト | まとめ |
| 試験後 | 解答速報・合格率 | 速報記事 |

### Phase 3: 収益化タイミング

各試験シーズンに最適な収益化施策:

| タイミング | 施策 | 収益モデル |
|---|---|---|
| 学習開始期（3ヶ月前） | 参考書・教材アフィリエイト | Amazon |
| 直前期（1ヶ月前） | 通信講座・模試アフィリエイト | A8/もしも |
| 合格発表後 | 次のステップ提案（上位資格） | アフィリエイト |

### Phase 4: 出力

`docs/reviews/exam-season/YYYY-QN.md` に保存する。

## 推奨実行頻度

- **四半期初め**: 次四半期の季節戦略を立案
- **月次**: `/weekly-plan` の入力として季節性を更新
- **試験日直後**: 速報コンテンツの検討
