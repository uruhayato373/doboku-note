土木系資格試験の検索需要を調査し、doboku-note に不足しているコンテンツを特定・提案する。

## 引数

```
/exam-demand [--exam EXAM] [--season]
```

- `--exam`（任意）: 特定の試験に絞る（省略時: 主要試験を網羅）
  - `sekoukanri-1`: 1級土木施工管理技士
  - `sekoukanri-2`: 2級土木施工管理技士
  - `gijutsushi`: 技術士（建設部門）
  - `concrete`: コンクリート技士/主任技士
  - `rvce`: RCCM
  - `gyousei`: 行政書士（法律カテゴリ）
- `--season`: 試験日程を起点に季節性の需要変動を分析

### doboku-note のカテゴリとの対応

| 試験 | 関連カテゴリ | 関連コンテンツ |
|---|---|---|
| 施工管理技士 | general/（施工管理） | 品質管理、工程管理、安全管理 |

| 行政書士 | low/（法律） | 憲法、行政法 |

## 手順

### Phase 1: 需要調査（並列サブエージェント）

#### Agent A: 検索需要の把握

WebSearch で各試験に関する検索トレンドを調査:

```
検索クエリ例（各試験について）:
- "{試験名} 勉強法"
- "{試験名} 過去問"
- "{試験名} 参考書 おすすめ"
- "{試験名} 合格率"
- "{試験名} {科目名} 解説"
```

各クエリについて:
- 検索結果上位サイトの内容・品質
- 上位サイトのコンテンツ形式（ブログ/動画/PDF）
- 有料コンテンツの有無と価格帯

#### Agent B: 既存コンテンツの試験関連度マッピング

```
調査項目:
- docs/ 配下の全 .mdx ファイルと frontmatter
- 各ファイルが対応する試験科目のマッピング
- 試験範囲に対するカバレッジ率
```

#### Agent C: GSC データから試験関連クエリを抽出

GSC API（利用可能な場合）から試験関連キーワードのパフォーマンスを取得:

```
フィルタ例:
- query contains "施工管理"
- query contains "技術士"
- query contains "過去問"
- query contains "試験"
```

### Phase 2: 試験別カバレッジ分析

各試験の出題範囲と doboku-note のコンテンツを突合:

#### 施工管理技士の出題範囲

| 分野 | 主要トピック | doboku-note カバレッジ |
|---|---|---|
| 土木一般 | 土工、コンクリート、基礎工 | ○/△/× |
| 専門土木 | 道路、河川、ダム、トンネル | ○/△/× |
| 法規 | 建設業法、労働安全衛生法 | ○/△/× |
| 施工管理 | 品質、工程、安全、原価 | ○/△/× |

#### 技術士（建設部門）の出題範囲

| 分野 | 主要トピック | doboku-note カバレッジ |
|---|---|---|
| 土質及び基礎 | 地盤調査、基礎設計 | ○/△/× |
| 鋼構造及びコンクリート | 設計、維持管理 | ○/△/× |
| 都市及び地方計画 | 都市計画、交通計画 | ○/△/× |
| 河川、砂防及び海岸・海洋 | 治水、利水、海岸保全 | ○/△/× |
| 道路 | 道路計画、設計、維持管理 | ○/△/× |
| 建設環境 | 環境影響評価、自然環境保全 | ○/△/× |

### Phase 3: 需要-供給ギャップの特定

| ギャップタイプ | 説明 |
|---|---|
| **完全未カバー** | 試験範囲だが doboku-note に該当コンテンツなし |
| **薄いカバー** | コンテンツはあるが試験対策として不十分 |
| **構成不足** | 情報はあるが試験対策としての体系化がない |
| **形式不足** | 解説はあるが問題演習・まとめがない |

### Phase 4: コンテンツ提案

各ギャップについて優先度スコアを算出:

```
優先度 = 検索需要(1-5) × 試験重要度(1-5) × 作成容易性(1-5) × 季節緊急度(1-3)
```

季節緊急度: 直近3ヶ月以内に試験がある場合に高スコア

### Phase 5: 出力

`docs/reviews/exam-demand/YYYY-MM.md` に保存する。

## 推奨実行頻度

- **四半期ごと**: フル需要調査
- **試験2ヶ月前**: 該当試験に絞った緊急分析（`--exam` 指定）
