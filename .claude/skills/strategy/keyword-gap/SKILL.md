doboku-note の GSC データと競合サイトを比較し、未カバーのキーワード・コンテンツのギャップを特定する。

## 引数

```
/keyword-gap [--category CATEGORY] [--period PERIOD]
```

- `--category`（任意）: 分析対象カテゴリ（省略時: 全カテゴリ）
  - `general`: 一般（土木工学・施工管理）
  - `road`: 道路
  - `river`: 河川
  - `low`: 法律
- `--period`（任意）: GSC データ期間（デフォルト: `last28d`）

## 手順

### Phase 1: データ収集（並列サブエージェント）

#### Agent A: GSC データ取得

GSC API から以下を取得:

1. **クエリ別パフォーマンス（上位500）**
   - dimensions: query
   - metrics: clicks, impressions, ctr, position

2. **クエリ×ページ（上位1000）**
   - dimensions: query, page
   - カニバリゼーション・未対応クエリ検出用

3. **高インプレッション低クリックのクエリ**
   - impressions > 100 かつ ctr < 2% のクエリを抽出

#### Agent B: 既存コンテンツインベントリ

```
調査項目:
- docs/ 配下の全 .mdx ファイルのパスとタイトル（frontmatter の title）
- カテゴリ別のコンテンツ数
- 各ファイルの主要キーワード（タイトル + 見出し h2/h3 から抽出）
```

#### Agent C: 競合キーワード調査

WebSearch で土木系の主要キーワードカテゴリを検索し、競合がカバーしているトピックを収集:

```
キーワードカテゴリ:
- 土木一般: 土質力学、構造力学、水理学、測量、材料力学
- 施工管理: 品質管理、工程管理、安全管理、原価管理
- コンクリート: 配合設計、耐久性、ひび割れ、補修補強
- 道路: 道路構造令、舗装設計、交通工学
- 河川: 河川計画、堤防設計、ダム、砂防
- 法律: 建設業法、入札契約適正化法、品確法
- 資格試験: 施工管理技士、技術士、コンクリート技士
```

### Phase 2: ギャップ分析

#### 2.1 検索需要 vs 既存コンテンツのマッピング

GSC のインプレッションデータと既存コンテンツを突合:

| 分類 | 説明 |
|---|---|
| **カバー済み（強い）** | 既存ページがあり、順位 1-10 |
| **カバー済み（改善余地）** | 既存ページがあるが、順位 11-30 |
| **部分カバー** | 関連ページはあるが専用ページなし |
| **未カバー** | インプレッションがあるが対応ページなし |

#### 2.2 競合カバレッジとの差分

競合がカバーし doboku-note にないトピック:

| トピック | 競合のカバー状況 | 推定検索ボリューム | 作成難易度 |
|---|---|---|---|

#### 2.3 カニバリゼーション検出

同一クエリで複数ページが表示されているケース:
- クエリ、対象ページ、それぞれの順位
- 統合 or 差別化の推奨

### Phase 3: 優先度スコアリング

各ギャップに対して優先度を算出:

```
優先度スコア = 検索需要(1-5) × 競合の弱さ(1-5) × 作成容易性(1-5)
```

| 要素 | 評価基準 |
|---|---|
| 検索需要 | GSC インプレッション or 推定検索ボリューム |
| 競合の弱さ | 競合コンテンツの品質・量が低いほど高評価 |
| 作成容易性 | 既存知識の転用可能性、必要な調査量 |

### Phase 4: コンテンツ提案

上位 10-15 件のギャップについて具体的なコンテンツ提案:

| 項目 | 内容 |
|---|---|
| タイトル案 | SEO を意識したページタイトル |
| 配置先 | docs/{category}/ 内のパス |
| 概要 | 300文字程度の内容説明 |
| 想定見出し構成 | h2/h3 レベルの見出し案 |
| 推定作成工数 | S/M/L |

### Phase 5: 出力

`docs/reviews/keyword-gap/YYYY-MM.md` に保存する。

