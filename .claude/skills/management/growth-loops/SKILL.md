doboku-note の持続的成長ループ（フライホイール）を設計・評価する。

原典: [phuryn/pm-skills](https://github.com/phuryn/pm-skills) (MIT License) の `growth-loops` をカスタマイズ。

## 引数

```
/growth-loops [focus]
```

- `focus`（任意）: 特定のループタイプに絞る場合（例: `seo`, `content`, `exam`）

## プロジェクトコンテキスト

doboku-note は土木工学ドキュメントサイト（Next.js 16 + next-mdx-remote + Cloudflare Pages）。以下の特性を前提に分析すること:

- **プロダクト**: 土木工学・施工管理・河川・道路・法律の技術ノートを無料提供
- **コンテンツ**: MDX ベースの技術解説ページ（100+ ページ）
- **現在の成長チャネル**: SEO（検索流入が主）
- **収益モデル**: Google AdSense + note.com有料記事販売 + 転職アフィリ + PWA 過去問アプリ（教材/講座アフィリは 2026-06-25 廃止＝[[affiliate-career-only]]）
- **ユーザー**: 土木系技術者、資格試験受験者、学生
- **技術基盤**: Next.js 16 + next-mdx-remote + Cloudflare Pages

## 手順

### Step 1: 現状の成長チャネル調査

以下を調査する:
- docs/ 配下のコンテンツ数（カテゴリ別）
- GA4/GSC の流入データ（利用可能な場合）
- 既存の被リンク・引用状況

### Step 2: 5つの成長ループを評価

#### 1. 資格試験 SEO ループ
試験対策コンテンツ公開 → 受験者が検索 → サイト訪問 → 合格後に後輩に共有 → 口コミ拡大 → さらに検索流入

#### 2. 技術リファレンス SEO ループ
技術ノート公開 → 技術者が業務中に検索 → ブックマーク・社内共有 → 被リンク増加 → ドメイン権威向上

#### 3. 教育機関引用ループ
大学・高専の講義で引用 → 学生がアクセス → レポート・論文で参照 → 被リンク増加

#### 4. コンテンツ拡張ループ
既存ページ → 関連トピック追加 → ロングテールキーワード増加 → 検索流入増 → ユーザーフィードバック → 更にコンテンツ改善

#### 5. 季節性ループ
試験シーズン（施工管理技士: 6月・11月、技術士: 7月・10月）→ 受験者大量流入 → コンテンツ充実 → 翌年も流入増

#### 6. note有料コンテンツ収益ループ
無料リファレンスで信頼構築 → 試験対策の切り口で有料記事（note.com）を販売 → 収益で運営継続・コンテンツ投資 → 無料コンテンツさらに充実 → SEO流入増 → 有料記事の見込み客増加
- **棲み分け原則**: 無料=リファレンス・基礎知識、有料=再構成・要点整理・テンプレート
- **季節性との連動**: 試験直前期に販売が集中（需要予測が立てやすい）
- **複利効果**: 記事は一度作れば毎年の試験シーズンに繰り返し売れる（年度更新コストは小）

### Step 3: 各ループの評価基準

| 基準 | 説明 |
|---|---|
| **適合度** | doboku-note のプロダクト特性との整合性（1-5） |
| **現在の成熟度** | 既に機能しているか、これから構築か（1-5） |
| **実装コスト** | 必要な開発・運用コスト（S/M/L） |
| **成長速度** | 効果が出るまでの期間（短期/中期/長期） |
| **複利効果** | 時間とともに加速するか |

### Step 4: ループ係数の推定

最も有望なループについて:
- 1ページあたりの平均検索流入
- 資格試験シーズンの流入倍率
- 被リンク獲得率
- サイクル1回あたりの期間

### Step 5: 実装ロードマップ

| 期間 | アクション |
|---|---|
| 30日 | 最優先ループの仕組みを実装 |
| 60日 | 計測・最適化、第2ループの準備 |
| 90日 | 第2ループ稼働、複合効果の検証 |

```markdown
- **複利効果**: 高
- **具体的アクション**: ...

## 推奨実装順序
1. 最優先: ...
2. 第2優先: ...

## 30-60-90日ロードマップ
...

## 計測指標
| ループ | 計測指標 | 現在値 | 目標値 |

```
