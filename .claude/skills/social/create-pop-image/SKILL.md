## 用途

原稿／販売カタログ → ★本スキル（画像制作・保存）→ 各媒体の公開スキル。
共通方針は [POP画像の正典](../../../knowledge/reference/pop-image-policy.md)。新たな専任エージェントは使わず、現在の担当が媒体スキルと画像生成ツールを組み合わせる。

## 手順

1. 共通方針と対象媒体の画像仕様を読む。商品ID・対象資格・用途・文言・出力先を既存原稿から確定する。数字、資格、提供内容は原稿／カタログで裏付ける。未指定の媒体だけが制作を左右する場合は質問し、既知の媒体から進める。
2. 承認画像台帳から同資格の参照PNGを解決し、実画像を見る。人物の同一性はキャラクター設定に合わせる。原本が無ければ `/asset-route` の復元手順を使う。
3. `pop-image.json` に入力コピー・根拠・参照画像・媒体寸法を記録する。同一画像の再出力なら承認原本をコピーする。新規／別媒体なら以下のプロンプトを具体的な文字列で埋め、利用環境の画像生成スキル／ツールで作る。画像編集はそのツールの参照画像指定を使う。
4. 原寸と幅360pxで画像を開き、コピーとの一致・資格名と主題の判読・対象資格と総監肩書きの区別・人物同一性・切れを確認する。誤字や根拠のない表現があれば修正する。媒体固有の安全域は実表示に合わせる。
5. 正典の保存項目を埋め、媒体の制作ディレクトリと用途別の保存先へ保存する。動画表紙はDrive原本、CIへの採用画像転送だけprivate R2（後述）。参照画像・入力コピー・プロンプト・出力SHAを残す。完成画像を表示して報告する。外部反映は依頼範囲に含まれる場合だけ既存公開スキルへ渡す。

## 通常動画・Shorts

- 2級土木の動画は [動画ポリシー §4](../../../knowledge/reference/video-content-policy.md) の `diagram-led` を優先する。以下の先生・肩書き入り骨格をそのまま適用せず、図解主体・控えめな配色・著者名なし、人物は説明に必要な作業場面だけにする。原本を縮めて余白を足さず `full-frame-v1` で採用する。
- 通常動画で「表紙はPOP・本文は図解」の指定がある場合、描画前に `storyboard.imageDesign` の `mode=codex-pop`・`scope=all-body`・`layout=diagram-led`・`coverRevision` と、`pop-image.json` の採用改訂を接続する。表紙は `cover-design.json` の `design=pop-poster-v3` と採用PNGを指定する。`npm run check-video-content` の B20 と `npm run media -- verify-render --work <資格>/<作品>` が通るまで旧カード版を完成品として扱わない。
- `node scripts/video-scene-sheet.mjs <packId>` は render-manifest の全場面を記録順に1枚ずつ載せる。出力の `場面 N/N 件` が storyboard の表紙を含む場面数と一致し、1枚目が採用POP表紙、残り全場面が指定した図解であることを確認する。10秒間隔の `contact-sheet.jpg` は画面の継続時間を見るために使い、短い表紙と全場面の意匠確認には使わない。

- 共通方針の「通常動画・Shortsの承認見本」から内容に合う `revisions` を選び、参照PNGを開いてから制作する。全面画像生成版 `pop-poster-v3` を、既存 `youtube-covers --all` の `pop-v2` 組版で代用しない。
- 同一画像を再利用するときは保存PNGを復元し、`output.sha256` と照合する。文言・資格・ポーズを変更するときは参照画像と全文プロンプトを引き継いだ新版にする。同一プロンプトからの画素一致は保証しない。
- 生成された実寸を記録し、媒体仕様の寸法と別に扱う。採用時は媒体寸法・安全域を整えた最終PNGを保存し、採用入力とSHAを更新する。画像だけのレビュー段階では既存動画の音声・字幕を再生成しない。
- Shortsの安全域は文字・顔の配置制約であり、右側・下側を大きな無地領域にしない。背景は四辺まで続け、主題と人物を中央に大きく配置する。全場面の原寸・幅360pxと字幕入り完成フレームを対応付け、採用画像SHA・動画SHA・確認場面数を残す。実際の操作UIの確認は別に記録し、寸法検査や原画像だけで代用しない。
- 保存・復元・採用PNGの検査・CI転送は [VIDEO-RENDER.md](../../../../content/sns/youtube/VIDEO-RENDER.md)。意匠承認、操作UI確認、動画への採用、外部反映を `review` / `publication` で区別する。
- 全場面の差し替えレシピがあるShortsは `youtube-shorts:restore` で現在の採用動画と全素材を照合・復元する。通常のテンプレート再生成は本文・締めを戻すため停止される。同じ画像や動画の再利用に画像生成・TTSを再実行しない。
- 既存QAへ渡す情報は、用途・コピー・ポーズ・参照PNG・実画像・生成指示。AI素材の文字／人物の忠実性は `ai-image-fidelity-auditor`、Shortsの表紙と操作UIは `yt-shorts-publisher-qa` の画像確認を使う。画像のみなら動画4軸の合格にはしない。

## 生成プロンプトの骨格

```text
添付の承認済み画像をデザインの参照に、doboku-noteの資格学習用POP画像を制作。
媒体: {channel}、出力: {width}×{height}、安全域: {媒体仕様}。
最も大きく見せる資格名: 「{examLabel}」。主題: 「{headline}」。
補足は「{benefit}」だけ。著者資格の強調帯: 「{authority}」。
文字列は指定どおり。対象資格と著者資格を別領域に配置する。
資格の主色: {既存の資格色}。白・黄色の極太文字、適度な輪郭、少量の赤。
余分な空白を減らし文字と人物を大きくする。文字・顔は安全域内。
背景は上下左右の四辺まで連続させる。安全域を無地の余白帯として描かない。
縦画面の左上に小さなポスターを置かず、画面全体の左右の重心を整える。
先生の同一性は参照画像を保持。{役割に合うポーズ}。ヘルメットは無地。
ブランド名、URL、価格、指定外の説明、根拠のない実績、合格保証は足さない。
参照画像を引き伸ばさず、媒体の縦横比に合わせて構成し直す。
```

画像生成ツールが使えないときは生成済みと報告せず、保存済み原本の再利用または入力原稿の整備までを示す。既存のSatori等を使う場合もPOP方針に対応済みか確認する。新規PNGを既存の自動生成器へ接続していない場合は、その状態を記録する。
