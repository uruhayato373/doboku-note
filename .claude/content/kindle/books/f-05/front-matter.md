# はじめに

本書は、技術士第二次試験（総合技術監理部門）の必須科目（記述式）について、令和3年度から令和7年度までの5年分の問題を、市区町村の公園緑地課（都市公園・緑地の整備・管理を担う発注者）の立場から解いた模範論文集です。各年度とも「A案：都市公園施設の維持管理・老朽遊具更新版」「B案：都市公園新設・グリーンインフラ整備版」の2バージョンを併記しており、5年分×2案で計10本の3,000字級フル論文を収録しています。

対象読者は、市区町村や都道府県の公園緑地担当として都市公園・緑地の整備または管理に携わり、総合技術監理部門の受験を予定している方です。指定管理制度の運用・遊具の点検発注・長寿命化計画の策定といった維持管理業務が中心の方はA案を、都市公園の新設・グリーンインフラ整備・防災公園整備といった建設プロジェクトが中心の方はB案を、まずご自身の業務経験に近いほうから読み進めることを想定しています。

総合技術監理部門の必須科目は、経済性管理・人的資源管理・情報管理・安全管理・社会環境管理という5つの管理分野の視点から、自身の業務経験に基づいて論じる記述式試験です。毎年度テーマは変わりますが、問われる構成（現状の把握、近い将来の施策、より広い視点からの考察という三層構造が基本形）と、施策ごとに複数の管理分野にまたがるトレードオフを明示する要求は年度を通じて共通しています。本書はその年度ごとのテーマの違いに対して、公園緑地担当という一貫した立場からどう答案を組み立てるかを示すものです。

使い方としては、まず次章「自治体公園緑地担当の立場で総監記述式をどう書くか」で、この立場ならではの強み・頻出する管理分野の組み合わせを把握したうえで、続く「模範論文の読み方・活用ガイド」で答案の型と自分の業務への置き換え方をつかみ、本編（令和3〜7年度・各A案B案）を通しで読むという順序を推奨します。本書の論文はそのまま暗記して使うものではなく、ご自身が管轄する公園の数・予算規模・指定管理制度の運用実態・整備事業の内容に置き換えて再構成するためのテンプレートとして提示しています。

# 自治体公園緑地担当の立場で総監記述式をどう書くか

以下は、本書に収録した5年分・10本の論文に共通して現れる構成上の傾向を、実際の記述内容に基づいて整理したものです。

**経済性管理と社会環境管理の組み合わせが最も頻出する**。市区町村の公園緑地担当は、限られた維持管理予算・整備予算のなかで施設の安全性や緑地機能を確保しつつ、その施策を議会・住民に説明し理解を得る立場にある。このため、施策のコスト（初期投資・ランニングコスト・指定管理費の増加）と、住民合意・情報公開・公平性（Park-PFIにおける商業化と公共性のバランス、損傷情報の公開が招く風評リスクなど）を対立させる「経済性管理×社会環境管理」のトレードオフが、5年分の論文を通じて最も多く採用されている型である。公園は道路や河川と異なり住民が日常的に立ち入り・利用する施設であるため、社会環境管理の視点（合意形成・情報公開・公平な受益）がとりわけ前面に出やすい。

**人的資源管理は、指定管理者との関係と職員減少の両面から立つ**。A案（維持管理）では、指定管理者ごとの点検品質のばらつきや技術継承の属人化、職員の高齢化・減少という制約が繰り返し課題として設定されている。B案（新設・整備）では、BIM/CIM等の新技術を審査・活用できる発注者側の人材不足や、設計コンサルの対応力格差が同様の位置づけで扱われている。いずれも「発注者としての監督・審査能力をどう担保するか」という論点に収れんしており、公園緑地担当に特有の観点として活用しやすい。

**安全管理は主にA案（維持管理）で軸になる**。老朽遊具の損傷・事故リスク、点検の見落としといった安全管理の論点はA案で中心的な位置を占める一方、B案（新設・整備）では設計基準・防災機能の観点で登場する頻度がA案よりやや低い。自身の業務が維持管理寄りかA案、新設・整備寄りかB案かで、安全管理をどこまで前面に出すかの重みづけは変わる。

**情報管理は将来施策・国家施策の設問で存在感を増す**。IoTセンサーやAIカメラによる常時監視・行動データ収集を扱う設問では、収集データの目的外利用やプライバシー保護が課題として設定されやすく、情報管理の視点が必要になる。また台帳・点検記録が指定管理者ごとに分散管理されている現状の課題を情報管理の切り口で記述する構成も繰り返し使われている。

**発注者としての権限を施策に織り込む**。指定管理仕様書への条件明記（義務化）、指定管理者選定評価での加点、社会資本整備総合交付金をはじめとする補助制度の活用、近隣自治体との広域連携・共同調達は、収録した10本の論文を通じて繰り返し登場する打ち手である。これらは発注者という立場だからこそ行使できる手段であり、総合技術監理の視点から見た「組織を俯瞰し具体的な権限で課題を動かす」姿勢を示す材料になる。

これらの傾向は、公園緑地担当という立場の業務実態（住民接点の多さ、指定管理制度の運用、予算制約下での老朽化対応、グリーンインフラ整備の広がり）から必然的に導かれるものであり、他分野の担当者が同じテーマを論じる場合とは異なる管理分野の組み合わせになりやすい。自身の答案を組み立てる際は、まず自分の業務が維持管理寄りかA案、新設・整備寄りかB案かを見極め、経済性管理×社会環境管理を基本線としつつ、自分の実務でより強く経験している管理分野（人的資源管理での指定管理者対応、安全管理での事故対応など）を厚く記述するとよい。

# 模範論文の読み方・活用ガイド

**答案構成の型**。収録した論文はいずれも、(1)取り上げる事業・組織の内容と現状（現在の取組状況・現在の課題を含む）、(2)近い将来（おおむね5年以内）に導入すべき施策を複数（多くは2つ）、(3)より広い視点からの考察、という三層構造で組み立てられている。ただし年度によって(3)の位置づけは異なる。取り上げた事業・組織の枠を超えた国としての施策を問う年度もあれば、5〜10年後の将来技術を問う年度、組織のSWOT分析と戦略立案という別形式を取る年度もある。年度ごとの設問要求は本書の各章冒頭に問題文を再掲しているので、まず設問の型を確認してから論文本文を読むことを勧める。

**トレードオフの書き方**。(2)以降の設問では、多くの年度で「2つ以上の管理分野の視点を含めること」「解答欄にどの分野の視点かを明記すること」が明示的に求められている。収録論文はこの要求に沿って、各施策の効果と課題をそれぞれ異なる管理分野から記述し、施策を進める際に生じる管理分野間の対立（例：経済性管理を優先すれば社会環境管理上のリスクが残る、といった構造）を明示している。答案を書く際は、効果を書く管理分野と課題を書く管理分野をあえて変え、両者の対立関係を一文で示す練習をすると型が身につきやすい。

**A案・B案の使い分けと数値の置き換え**。A案・B案は同じテーマに対する2つの異なる業務背景（維持管理と新設・整備）からの解答例であり、どちらか一方をそのまま覚えるのではなく、自分の実際の業務に近いほうを選び、管轄する公園数・予算規模・指定管理者数・整備面積といった数値を自分の職場の実態に置き換えて書き直すことを前提としている。前提条件を差し替えても、三層構造とトレードオフの明示という骨格はそのまま流用できる。

**採点者視点でのチェックポイントの使い方**。各年度の論文末尾には、その年度で採点者が確認すると考えられる要点を整理して付している。答案を書き終えたら、まずこのチェックポイントと照らして、要求されている要素（管理分野の明記、項目数の過不足、トレードオフの有無など）が抜けていないかを確認する使い方を想定している。
