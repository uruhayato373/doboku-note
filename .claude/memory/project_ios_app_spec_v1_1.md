2026-09-29 に運営者が「iOS も総監・技術士・1級土木でまず試す」と判断し、凍結していた iOS アプリを試作へ転換した（backlog DN-0453）。2026-10-09 に方針を `docs/products/07_iOS択一アプリ試作方針.md` に決めた: アプリは系統で 2 本（運営者の提案で同日に決定）: 技術士（第一次試験＋総監）と土木施工管理技士（1級＋2級）。技術士を第一次試験だけで先に出し（試験 2026-11-22）→ 総監をアップデートで追加 → 土木アプリは 2027 春。SwiftUI＋問題表示だけ WKWebView、無料・広告なし・課金なし・日本のみ・分析 SDK なし。問題データは既存の `scripts/build-quiz-data.mjs`（Web 演習と同じ正規化）を使い、アプリは別リポジトリ。

**Why:** 目的は「作る手間・使い心地・App Store の反応」の感触を掴むこと。技術士一次は試験が近く、競合が部門別の 3 年分程度（建設部門 ¥300）で収録量で勝てる。総監専用アプリは無く、1級土木は TK office（¥1,600・18 年分・★4.5/381 件）が強い。

**How to apply:**
- 順番（backlog）: DN-0453 技術士アプリ（🔴・期日 2026-11-08）→ DN-0624 試験後の判断（2026-12）→ DN-0627 総監追加・DN-0628 土木アプリ（2027 春）。データは DN-0623（土木）・DN-0454（管工事）。戦略は 03・04・06 の判断の記録（2026-10-09）に反映済み
- iOS の価格・範囲・順番を問われたら 07 を Read。旧仕様 DN-0400（総監 ¥1,800 買い切り・Free/Premium 境界・サーバ差分取得）は引き継がない。原文は `git show 747fab5d9:docs/products/<ファイル名>`
- 運営者の作業が前提: Apple Developer Program 登録（個人だと販売者名に本名）・Xcode 導入（2026-10-09 時点で Command Line Tools のみ）。過去問の転載条件は未確認で、App Store 公開前に確認する
- 審査提出の期限は 2026-11-08。過ぎたら技術士アプリは TestFlight 止まり、総監を足して 2027 春に公開
- 試験ごとの単独アプリは作らない（受験者が系統内で順に進むため）。系統をまたぐ技術士と土木は混ぜない。施工管理は種目ごとに別アプリ（土木と管工事を混ぜない）。1級・2級は同じアプリにまとめる（運営者判断 2026-10-09: 級ごと¥1,870の競合より「2級から1級まで1本」が買う理由になる＝仮説。検索で埋もれたら分けずに名前・キーワードで対処）
- 管工事は空白市場ではない: ドリルラボ「過去問ドリル」が 1級★4.7/1,422件・2級★4.6/1,032件で更新継続（全問¥1,870）。作るかは土木アプリで「全問無料」が有料の既存アプリに効くかを見てから（07 §3.3）
- 収録量: 公式の過去問を Wayback 保存版（JCTC の問題 PDF と合格発表の answer.html）から集められるだけ集める（07 §3.4・DN-0454・DN-0623）。公式正答なしの年度は表示で明示できる場合だけ載せる
- 機能: 2026-10-09 に約 20 本の資格アプリを調査（07 §4.3）。無料で入れる=間違い/未実施の絞り込み・全選択肢解説＋誤り報告・進捗常時表示・試験日通知・履歴を消さない。有料候補=復習ナビ・模試・弱点分析・暗記ノート・計算のヒント段階表示。総監は書き下ろし 1,000 問の RUMAHSAKU が同日公開（実過去問で差別化）
- 有料化は 06_PWA §5 の価値の境界（問題は無料・学習管理に値付け）から考える。note の購入導線はアプリに置かない（App Store 規約 3.1 を確認してから）
