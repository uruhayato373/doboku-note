図表・数式・歴史セクションに関する構成判断。content-principles.md の原則8〜10として反映済み。

**Why:** 損益分岐点ページの校正で、「図解」見出しが唐突、KaTeX分数のフォントサイズ不統一、歴史セクション不要という判断が出た。試験対策サイトとして「得点に直結するか」が情報の取捨選択基準。

**How to apply:**
- 図表は独立セクションにせず本文の流れに統合する
- `<ArticleImage>` の caption は使わない。図の説明は本文で行う（caption と本文の重複を避ける）
- 分数は ÷ 表記にしてSVG化を優先（KaTeX の \frac はモバイルで読みにくい）
- 歴史・背景は試験で問われない限り省く
- データ表は計算例として計算過程とセットにする
- これらのルールは content-principles.md 原則8〜10に追記済み。サブエージェントも次回から適用する
