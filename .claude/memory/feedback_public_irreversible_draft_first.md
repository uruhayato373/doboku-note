公開されて取り消せない投稿（ココナラ購入者評価・公開コメント等）は、ユーザーが「もう評価する」「送って」と言っても、まず draft-first（スクリプト既定の入力止め）で文面を見せ、明示の確認を得てから `--submit` する。

**Why:** 2026-09-25、「もう評価する」を送信指示と解釈し `coconala-rate-buyer --submit` で公開評価を即送信した直後に、ユーザーから「下書きで止めてね」と来た。評価は取消不可で、文面を事前に見せる機会を失った。

**How to apply:** 公開・取消不可の送信系 CLI（`--submit` / `--commit` で公開されるもの）は、既定の下書き/入力止めで一度止め、文面を提示してから送信する。ユーザーが文面まで指定して「送信して」と明言した場合だけ直接送る。[[no-confirmation]] の「確認せず一気に処理」は取消可能な作業の話で、公開・取消不可の送信には適用しない。
