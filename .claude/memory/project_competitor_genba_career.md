**genba-career.com（現場技術者のキャリアノート）＝ doboku-note と運営者ペルソナが正面から重なる唯一の競合。** 記録 SSOT は [docs/strategy/07_競合調査.md](../../../../doboku-note/docs/strategy/07_競合調査.md) の「現場技術者のキャリアノート」節、模倣企画は 13_土木公務員SEO戦略2026-08.md の「キャリア記事ラインナップ」節（2026-08-24 に全71記事実読・欠測0）。

運営者は RION（ペンネーム）＝地場コンサル→地方公務員→発注者支援。RCCM 保有・**技術士は受験中**。記事 71 本（実務解説45／キャリア転職14／資格6／発注者と受注者6）。有料商品なし・アフィリ単独。

**Why:** 競合の主体は予備校・過去問DB・求人メディアだが、ここだけは「発注者と受注者の両方を経験した個人技術者の一人称」で、同じ土俵に立つ。しかも**ビルドジョブ（A8・EPC942円）を双方が同一キーワードに置く＝成果を直接取り合う**。さらに経験記述では相手が独学サポート事務局（A8）で稼ぎ、doboku-note は同案件を自社商品カニバリで Red Line 判定済み（2026-08-04）＝「他社講座へ送る側」と「自社商品を売る側」の競合。

**How to apply:**
- **論点の網羅では負けていない**（doboku-note のキャリア記事は既に10本＝guide-quit-or-stay / guide-public-servant / guide-hatchu-shien / guide-career-path / public-engineer-qualification-map 等）。負けているのは**読者が「この人の話」として読む力**。相手は24〜38歳の年収を実額で開示し全記事からそこを参照する「証拠置き場」を持つ。doboku-note は公的データ＋三人称
- **一人称の具体性は Red Line ではない**（禁止は他者の成功例・想定年収・未利用サービスの体験談）。運営者の真正な座（元自治体土木＝発注者・技術士両部門含む10資格の取得当事者）の範囲で踏み込む。相手のアーク（コンサル→公務員→出戻り）は流用せず発注者の座に置換
- **権威性は doboku-note が上**（相手は技術士受験中）。「取った人が書いている」は相手が原理的に出せない差
- **転職アフィリの前提が崩れている（2026-08-24 実測・最重要）**: GA4 2026-07-24〜08-20 で career タグ39本のうち上位100に入るのは1本のみ（guide-grade-comparison 18セッション／全体5,110）。上位100の最小が8なので**残り38本は28日で8セッション以下**。affiliate-creatives.ts:211 に既に同趣旨の記録あり（実流入は学習系＝guide-strategy 641 等）。**模倣記事を足す前に「増やすか畳むか」を決める**＝DN-0120
- 脅威は**キャリア1領域に限定**。試験対策本体は競合しない（相手は過去問0本・総監0本）
- 相手固有の空白＝会計検査/臨時協議/設計変更の発注者心理（doboku-note は会計検査0件・臨時協議0件）と実務設計解説45本（片勾配・視距・縦断曲線・排水計算・集水桝はいずれも0件）。後者は試験対策ハブの事業定義の外だが道路構造令の数値だけは出題範囲と重なる
