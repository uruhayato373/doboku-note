2026-11-28 の運営者決定: **分冊と中身が重なる合本は廃止**（A-00・d-00）。b-reiwa・e-02 は Kindle に分冊が無いので対象外の案（計画書で承認待ち）。

事実: 日本の70%は税込 ¥250〜¥1,650 かつ KDP セレクト登録。セレクトは電子版を Amazon 以外（自サイト含む・試し読み約10%を除く）で配らない条件。2026-11 時点で 70% の本（c 系・d-01/02・A・e・b-reiwa・g 系）はほぼ全部が note かサイトと中身が重なり、11月の受取のほぼ全額がそこから出ている。i・j・h 系は note 併売のためセレクト外の35%（実測 ¥1,980 で1冊 ¥630）。

**Why:** 同日、私は「¥1,650超の本は分冊すれば70%」と勧めたが、セレクトの独占条件を見落とした誤り。35%の本は価格が高いほど受取が増え、分冊は効かない。
**How to apply:** Kindle の価格・構成を決める前に「その本の中身が note・サイトにあるか」を先に見る。重なるなら35%前提で値付けし、¥1,650上限・分冊はセレクトに入れられる Kindle 独自の本だけに当てはめる。計画の正本は `docs/products/10_Kindle_価格と分冊と販売形態の計画.md`。ASIN の扱いは [[feedback_kindle_dup_prevention]]、価格改定の罠は [[reference_kdp_price_change_gotchas]]。
