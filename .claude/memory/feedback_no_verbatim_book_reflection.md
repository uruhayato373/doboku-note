技術士（建設部門）「論文対策キーワード」書籍スキャン → site B系統 `*-ronbun-keyword` 記事への反映は、**スキャン書籍本文の逐語複製をしない／書籍スキャン図（figNN.png）のクロップ埋込もしない**。textbook は**出典**として使い、事実（計画名・法令名・数値・年月・施策名）だけを引いて**自分の言葉のオリジナル散文で不足論点を増補**する。図が要るなら原典が政府機関のものを原典から直接取得＋出典明記（政府標準利用規約）、または本文でテキスト化。

**Why:** 市販書籍の逐語テキスト＋書籍ページ写真クロップを一般公開サイトに複製するのは、OCR整形しても「元表現をほぼ再現」で著作権リスク。事実自体は自由に使えるので、オリジナルに書き直せば同等に濃く・かつ既存の良質なオリジナル記事も壊さない。

**How to apply:** 真実源＝`docs/textbook/技術士（建設部門）/論文対策キーワード/README.md` の warning ブロック（2026-07-02 再確定）。不足論点の洗い出し（「03〜06 gap分析」）は旧 handoff にあったが 2026-07-11 に _archive ごと削除＝必要なら git 履歴 `docs/handoffs/_archive/2026-06-22-pe-construction-verbatim-reflection.md` から復元（手法パートは失効・全6節統一完了済みなので通常不要）。**2026-07-02 に全6節(02〜06)を現行方式へ統一完了**：02(iji-kanri)は逐語版(125k字＋書籍図6枚)をオリジナル散文版へ復元＋書籍クロップ図撤去、03〜06は各節の不足論点をオリジナル散文で増補。image-policy の「書籍スキャン図クロップ埋込」例外も撤回済み（政府原典から直接取得する正当部分のみ残置）。この方式を実装する skill/agent は存在しない（手動作業）。以降の追補も同方式で。
