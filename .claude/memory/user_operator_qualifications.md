運営者は元・地方自治体の土木職（発注者）。プロフィール記載分: 1級土木施工管理技士・1級舗装施工管理技術者・コンクリート主任技士・診断士・技術士（建設部門・総合技術監理部門）。2026-09-26 に本人から、技術士（上下水道部門・選択科目 上水道及び工業用水道・2024年取得）と測量士（2020年取得）も取得済みと聞き、src/config/author.ts（サイトの正本）・/about・content/note/プロフィール.md に反映した。

取得年（2026-09-27 本人申告）: 技術士（建設部門）2014・技術士（総合技術監理部門）2022・1級舗装施工管理技術者 2010・技術士（上下水道部門）2024・測量士 2020。1級土木・コンクリート主任技士・診断士の取得年と自治体の在職期間は未申告（推測で埋めない）。ココナラの資格・検定欄に使う。

**Why:** 資格展開の可否は「運営者の経験で答案の真正性を担保できるか」で決まる。取得済みの資格は展開の強い根拠になる（上下水道・舗装・測量士はこの申告で展開決定）。

**How to apply:** 展開候補を評価するとき、保有資格なら信頼性の懸念を外す。保有資格の正本は src/config/author.ts。推測で書き足さない。関連: [[project_qualification_expansion_ssot]]、[[project_v3_strategy]]。
