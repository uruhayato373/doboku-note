**Why:** 中核差別化「合格者視点」の信頼性の根拠。受験予定の人の意見と合格者の意見では商品価値が大きく違う。6 資格取得は土木・舗装・コンクリートを横断する E-A-T を最大化し、1 級土木 / 総監 / 舗装 / コンクリート系コンテンツすべての権威性を担保する。

**How to apply:**
- サイト側 SSoT: `src/config/author.ts`（jobTitle / bio / qualifications / knowsAbout）。`<AuthorCard>` と `/about` ページは AUTHOR を直接参照する
