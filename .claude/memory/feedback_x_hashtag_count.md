X ツイートのハッシュタグは **3-4個推奨**（IG/note の20-30個運用とは別系統）。

**ベース（2026-05-29 改訂・ユーザー指示）**: `#技術士 #総監`（先頭固定・計12 weight=#技術士7/#総監5）＋種別タグ1-2個＝計3-4個。当初（2026-05-25）のベースは `#技術士 #技術士総監` だったが、ユーザーが目視で `#技術士` の流入有効性を確認し、`#技術士総監`（11 weight）をベースから外した。`#総合技術監理部門`（17 weight）は重いので告知・節目（W-3/W-2/W-1 等）の要点投稿に限定。軽量タグで 280字の余白を確保し種別タグ枠を広げたい意向。X は日本語2/字・URL23固定・上限280で重いタグは即オーバー（実例: 035-① が2タグで既に274/280）。今後の X 投稿（tweets.md）から適用し、予約済みの投稿は遡及変更しない。

**Why（個数）:** X 公式のスパム判定にハッシュタグ数の直接ルールは無いが、5個以上は業者・自動投稿の印象でエンゲージメントが下がる傾向（Buffer/HubSpot 2015-2019 の研究と Musk 体制後の For You アルゴリズム挙動）。1個だけだと検索面の取りこぼしが大きい。

**種別ごとの追加1-2個:**
- D 過去問クイズ: `#過去問対策 #<該当管理>`
- N note 予告: `#模範論文 #<テーマ>`
- C カウントダウン: `#試験対策 #社会人の勉強垢`
- M 合格者メタ: `#勉強法 #リスキリング` or `#論文対策`
- S 応援: `#勉強垢 #受験勉強`
