総監記述式模範論文をレビュー・新規執筆するときは、**字数制約を最初の評価軸として提示する**。内容質・専門度・散文性・事実誤認の評価は字数制約に整合してから着手する。

**字数制約**：
- 設問(1): 答案用紙 1 枚以内 = **600 字以内**
- 設問(2): 各組合せ 1 枚以内 × 2 施策 = **各施策 600 字以内 / 計 1,200 字**
- 設問(3): 各組合せ 1 枚以内 × 2 施策 = **各施策 600 字以内 / 計 1,200 字**
- **合計 3,000 字以内**

**R7 A案実測値**（参照基準）：
- 設問(1): 619 字
- 設問(2) 施策1: 578 字 / 施策2: 618 字
- 設問(3) 施策1: 624 字 / 施策2: 657 字
- 合計: 3,153 字

**「答案用紙 1 枚以内」は厳密な上限**。各設問・各施策とも **600 字以内厳守**（許容範囲なし）。R7 A案も 618〜657 字で超過しているが、それは超過例として参考にせず、新規執筆・既存校正は 600 字以内厳守で評価する。マージン確保のため **目標 585〜600 字** を狙う。

**Why:** 2026-05-25 の R8 予想問題集レビューで、当初「R7 A案も 660 字程度なので同水準まで許容」としていたが、これは誤り。R7 A案を超過例として基準にしてしまい、模範論文として「本番では書ききれない量」を公開しかけた。「答案用紙 1 枚以内」は採点対象になるための物理的上限であり、許容範囲は存在しない。AI 社会記事の初版は各施策 860〜920 字あり大幅圧縮が必要だった。残 5 記事もすべて設問(3) で 600 字超過しており、再圧縮を実施。

**How to apply:**
- レビュー時の最初の出力は字数表（各設問・各施策別、上限との差）
- 600 字を超える施策があれば、内容修正の前に「**まず圧縮、その後に内容質を議論**」と順序を宣言する
- 字数計測スクリプト（Python）を使う：
  ```python
  import re
  def count_between(path, start, end):
      with open(path, encoding='utf-8') as f:
          text = f.read()
      s = text.find(start); e = text.find(end, s+1) if end else len(text)
      body = re.sub(r'[#*`\-|\[\]()>]+', '', text[s:e])
      return len(re.sub(r'\s+', '', body))
  ```
