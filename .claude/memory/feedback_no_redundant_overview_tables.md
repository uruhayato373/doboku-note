キーワードページで「法律の概要」「基本情報」等のキーバリュー表（正式名称・目的・所管・適用範囲など）を作らない。冒頭の散文と情報が重複し、読者に同じ内容を2回読ませることになる。

**Why:** 労働基準法ページで冒頭の散文と「法律の概要」表が5項目中2項目で完全重複していた。表の性質も「比較・一覧」ではなくキーバリュー羅列であり、表を使う利点がなかった。

**How to apply:** 正式名称・目的・所管・適用範囲・監督機関などの基本属性は冒頭セクションの散文に統合する。表は比較対象がある場合（分類表、制度比較など）にのみ使用する。`/keyword-page` スキルの SKILL.md にもルールを追記済み。
