総監模範論文ペルソナ（総監模範論文-自治体○○担当）の「専門分野」枠付け（こんな人のため／前提／立場 等の "○○分野の発注・監督経験" 表現）は、**そのペルソナの分野に正しく対応する技術士選択科目**を使う。他部門・他科目の選択科目名を流用しない。

**正しい対応例**:
- 河川 → 河川砂防及び海岸・海洋（建設部門）
- 都市計画 → 都市及び地方計画（建設部門）
- 港湾 → 港湾及び空港（建設部門）
- 上水道 → 上水道及び工業用水道（上下水道部門）
- 下水道 → 下水道（**上下水道部門**）。建設部門ではない

**2026-06-10 是正**: 下水道担当に「施工計画・施工設備及び積算または建設環境分野」（＝建設部門の選択科目）が誤って全面的に枠付けされていた（commit 3884d7bc0）。ユーザー（技術士 建設・総監 保有）指摘で不適切と判明。対応＝**選択科目ラベルを外して役割ベースに一般化**（「下水道事業の発注・監督」「工事の積算審査・施工監督／環境配慮など発注者としての実務経験」）。全7記事26箇所。業務記述としての施工計画・積算・建設環境（騒音/濁水対策）の語は維持（選択科目ラベルとしての枠付けのみ除去）。

**How to apply**: 新規ペルソナ生成・既存校正時、こんな人のため/前提/立場の「○○分野」表現がそのペルソナの正しい技術士選択科目になっているか確認。判断に迷う／その分野が建設部門外（上下水道・農業・森林等）なら、選択科目名を出さず役割ベース（「○○事業の発注・監督経験」）に一般化するのが安全。テンプレ流用時に他ペルソナの選択科目が紛れ込む事故に注意。関連 [[feedback_essay_persona_authentic_seat]]。
