## 実装内容（2026-04-01 完了）

**背景**：複数資格対応（1級土木→コンクリート技士・技術士・測量士）に伴い、スキルが試験ごとに個別実装されるリスク。ハーネス設計原則4「スキルを増やすより既存スキルのパラメータ化を優先」に従い、テンプレート駆動アプローチを採用。

### 1. テンプレートフォルダ構造

`.claude/skills/content/templates/exam-guide/` を新規作成：

```
templates/
├── README.md              # フォルダの目的・運用ルール・Phase移行方針
├── _schema.md             # 試験別設定の仕様書（6変数）
├── civil-construction-1.md # 1級土木施工管理技士の設定（稼働中）
├── pe.md                  # 技術士建設部門の設定（稼働中）
└── _new-exam-template.md  # 新資格追加時のコピー用雛形
```

### 2. 設定ファイルの6変数（_schema.mdで定義）

1. **exam_name** — 試験の正式名称
2. **source_paths** — 参照するコンテンツディレクトリ（分野別）
3. **external_sources** — 著作権フリーの公開情報源テーブル
4. **exam_structure** — 試験科目・出題形式テーブル
5. **output_dir** — ガイド出力先ディレクトリ
6. **sidebar_slug** — サイドバー登録ID

### 3. CLAUDE.md更新

- **スキル一覧テーブルの分類化**：
  - 試験対策ガイド生成（対応試験・汎用化状況を明記）
  - 試験問題集インポート
  - 汎用スキル
  - 教材インポート系
  
- **新セクション追加**：「複数資格対応の進め方（Phase別）」

### 4. exam-guide/SKILL.md へ参照追記

末尾に「テンプレート設定ファイル」セクション追加。
Phase 1/2/3の移行方針を明記。

## Phase別戦略

### Phase 1（現在 2026-04-01）：テンプレート外部化

スキル本体は試験特化。設定ファイルは `templates/` で一元管理。

```
/exam-guide         → civil-construction-1.md 参照
/pe-exam-guide      → pe.md 参照
```

**新資格追加時**: `templates/exam-guide/{exam-id}.md` を追加（スキル追加不要）

### Phase 2（2026年秋予定）：スキル汎用化

スキル側でパラメータ化。複数試験を1つのスキルで処理。

```
/exam-guide --exam {exam-id} --topic {topic}
  ↓ 内部で templates/exam-guide/{exam-id}.md を読み込み
```

### Phase 3（2027年以降）：他分野対応

医師・弁護士など他分野資格にも同じテンプレート駆動アプローチで対応可能。

## 運用ルール

### 新資格追加の手順

1. `_new-exam-template.md` をコピー
2. ファイル名を `{exam-id}.md` に変更
3. `_schema.md` の6変数を埋める
4. ファイルを templates/exam-guide/ に配置
5. 対応するスキル側で参照を更新（軽微）

### 試験制度変更時

該当する `.md` ファイルの `exam_structure` セクションのみ更新。
スキル本体への変更は不要。

---

## 理由

**Why**: スキルを試験ごとに増殖させると、保守複雑性が急速に増加。
ハーネス設計原則4に従い、差分を外部化することで、スケーラビリティを確保。

**How to apply**: 新資格追加は設定ファイル追加で対応。
Phase 2でスキル側を汎用化すれば、さらに保守性が向上。
