## スクレイパーの教訓（scripts/coconala-research.mjs）
- **長時間 I/O は必ず逐次永続化**（初版は一括保存で、613件まで進んだ実行を中断して全ロス）。出力自体をチェックポイントにする設計が正解。
- **「空白を全除去して数字が連結する」バグを2回踏んだ**（ページャ→1234198／セラー名"道路プロ0609"+価格→6,091,000）。数字を含むテキストのパースで `replace(/\s/g,'')` は禁物。
- networkidle 待ちは律速（SPAでは到達しない）。**セレクタ待ちに置換で数十倍速い**。
- 検証は「本文の最初の一致」でなく**構造（class）で照合**する（雑な検証が誤検知を生んだ）。

## 初売上と商品再構成（2026-08-05・このセッション）
**初受注 = C8 1級二次予想模試 ¥2,500**（08-04）。購入者が直後に「出題分析とは全く違うのか」と DM で質問し、**C系9単品は外から買い分けできない**という設計欠陥が実売1件目で露呈。これを起点に再構成した。

- **級ごとの3段はしご**: 模試（¥2,500/¥2,000）→ 模範答案セット（¥5,000/¥4,000・旧完成答案集+過去問模範答案を統合）→ 教材フルパック（¥10,000/¥7,000・18冊115p/15冊）。最上位に **C12 プレミアム ¥15,000**（教材18冊＋経験記述添削2テーマ・週1枠）
- **価格の天井は実測 ¥10,000**（建築士製図ノート¥10,000×31件が純教材の最上位／PDF556頁でも¥6,500）。物量では超えられず**労働を足して初めて上の帯**に入る。ちゃんさとの高単価は「添削だから」ではなく**問題数に完全比例する純労働**（添削2問¥12,000/4問¥24,000・作成代行はその1.33倍）で**教材が付かない**
- **廃止5件は archived**（C1 分析・C4/C5 過去問模範答案・C6/C7 学科攻略）。公開済みサービスに削除導線は無く、アーカイブが「棚から消す」操作（検索/カテゴリ/プロフィールから消え「受付終了」表示・URLは残る・**解除導線が見つからず実質片道**）
- **ココナラの価格刻み**: ¥10,000以下=500円刻み／超=1,000円刻み。`¥9,800` 等の端数は**入力できず** publish が拒否する
- **見積りは相手ユーザー宛**（`/direct_offers/add/{userId}`＝DM からのみ。トークルームに機能なし・添付5個上限）

## 長期不在プロトコル（2026-08-06〜16 に初適用）
購入から**48時間以内に連絡しないと取引が自動キャンセル**され、**PDF商品も手作業送付**なので無人で売れる商品は無い。ココナラに休暇モードは無い（スケジュール欄は表示だけ）。→ **全件受付休止が既定**。
- `paused` は多義なので **`pauseReason`（`retired`=恒久廃止 / `absence`=一時休止）で必ず区別**する。区別が無いと一括復帰で廃止商品まで復活し、再構成が巻き戻る（実際に危なかった）
- 復帰は `npm run coconala-pause -- --resume --absence --commit` の1コマンド（カタログの戻しも script が行う）。**`--all-listed` は使わない**
- 戻し忘れは `check-coconala-wiring` が `resumeOn` 超過で警告。判定は `scripts/lib/coconala-guards.mjs`＋`tests/coconala-guards.test.mjs`（25件）で固定

## 計測の教訓（2026-08-05）
- **受注の実体は機械で採る**（`npm run coconala-orders`→`check-coconala-orders`）。「何が売れたか」を記憶や推測で決めない。購入者名・本文は保存しない
- **受注一覧だけ見ると購入前 DM を落とす**（売上機会そのもの）。DM 一覧も同時に採る（スレッドは開かない＝既読にしない）
- **納品予定日を登録するだけで coconala の「未返信」フラグが false に反転する**が、48h 期限バナーは残る。`unreplied` で期限判定すると偽陰性になる → 期限が採れている限り surface する
- **出品一覧は1ページ10件でページ送り**。1ページ目しか見ないと11件目以降が「見つからない」に化ける
