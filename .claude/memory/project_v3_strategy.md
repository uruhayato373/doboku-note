**決定**: サイト運営者は**技術士総合技術監理部門に合格済み**（土木系公務員〔発注者〕の退職者。1級土木/1級舗装/コンクリート主任技士/コンクリート診断士/技術士〔建設〕/技術士〔総監〕の6資格保有）。合格体験（学習ログ・解答再現・論文全文・口頭対策）を中核差別化に据えた戦略。

**重要な改訂（2026-05-22）**: 旧版（2026-04-13策定）は「運営者が2026-07受験中・不合格時の信頼崩壊リスクを避ける段階投下」が前提だった。**運営者の合格判明により全段階が完了済み**となり、以下が失効：
- 旧「合格前は模範解答・解答のコツを売らない」（Red Line #1）→ 失効。模範解答を合格者の成果物として正面販売可
- 旧「不合格時は2週間以内に有料停止→不合格体験記へピボット」（Red Line #3）→ 失効。P-07不合格体験記は廃止
- 旧「勉強時間の30%超でnote執筆しない」→ 失効（退職者で受験勉強なし。ただしRed Line #2「note執筆でサイトMDX整備を止めない」は継続）
- **公開タイミングだけは買い手（受験生）の試験季節（毎年7月）に合わせる** — これは顧客都合であり段階性は「受験季節カレンダー」として維持

**Why**: 競合（pejp.net・通信講座・情報整理系ブログ）は情報整理屋中心で一次ソースの合格者が少ない。運営者の合格体験・論文全文は「他人が絶対書けない独占コンテンツ」でE-E-A-T全軸を埋める。

**How to apply**:
- 模範解答・解答再現・論文全文・受験記はすべて**合格者の成果物として今すぐ執筆可**（受験タイミングに縛られない）。公開のみ7月前後の需要ピークに合わせる
- E-01〜E-04（解答再現¥1,980/論文「私はこう書いた」¥2,480/学習ログ¥1,480/口頭対策¥2,980）は試験後Phase R-1〜R-3で投入
- X/SNSの体験軸は「合格者の権威」を使ってよい（私が2026-06に作った051-056のX体験軸は旧記憶で過度に保守化した＝「合格と断定しない」。合格者ポジションで強化する余地あり）

**真実源**: `docs/project/01_戦略/04_収益化戦略.md`（§コンテンツ価値〔運営者は総監合格済み〕・2026-05-22改訂）／`docs/note/技術士総監/noteコンテンツ計画.md`（Context・Red Line・段階別投下プラン、運営者ステータス改訂2026-05-22）。関連: [[project_note_write_automation]] / [[project_note_essay_magazines_2026_05]]

## 統合: 3層アーキテクチャ（旧 architecture）
- 資格ごとに「ここだけで合格できる」体験を提供する試験対策ハブ。Obsidian（ステージング）→ doboku-note（プロダクション）→ PWA 過去問アプリ（資格別 PWA × 共通エンジン）の3層。真実源は CLAUDE.md と `docs/strategy/02_設計思想.md`。
- 現況（2026-07）: 単一資格特化ではなく複数 vertical を直接整備＝1級/2級土木・技術士（総監・建設部門）・コンクリート主任技士・診断士。旧「1級土木特化・他分野は Obsidian のみ・月間10,000ユーザーで他分野公開」（2026-03-31）は失効。

## 統合: 運営者ステータスと言及ルール（旧 operator_pe_pass_framing / operator_pe_comprehensive_pass）
- 運営者の総監ステータスは「過去に合格済み（R8＝令和8年度/2026年7月とは別年）」（2026-07-23 ユーザー明言）。経歴は地方自治体の土木職（発注者）退職者。
- **Why:** 初期コンテンツ7記事に「2026年7月に総監を受験する／受験中の運営者／合格発表前のため断定できない」という未合格ペルソナが残り、v3 の合格体験ポジションと矛盾していた（2026-07-23 一掃）。
- **How to apply:** 自己言及は必ず合格者フレーム。「受験する／受験中／まだ合格していない」は使わない。ただし次の2つは正しいので直さない＝読者ペルソナ「令和8年度総監記述式を受験する方」・学習日程「8月〜10月（合格発表前）」。年度は出さない。検出 sweep は `grep -rnE "受験中の運営者|現在進行形の受験者|まだ合格体験者|合格発表前のため|総監を受験しました|総監を受験した運営者|受験する立場で" docs/note/技術士総監/`。修正後は `note-update-body --commit` でライブ反映（本文・H2見出し・結びの3点セットで残りやすい）、検証は `?_=<nonce>` でキャッシュバスト。解答ペルソナ（自治体道路担当/ゼネコン/河川コンサル）と運営者ペルソナは別系統で混同しない。
- 保有資格の正本は `src/config/author.ts`（旧メモの「6資格」「10資格」の列挙は古い。行政書士は 2026-10-01 に「取得予定」と決定済みなので列挙は author.ts で確認する）。他の SSOT: `docs/note/プロフィール.md`・`public/llms.txt`・総監対策ハブ案内記事。
- 残（優先度低・非公開）: `docs/note/技術士総監/noteコンテンツ計画.md:399` に「運営者が受験生でなくなり」の旧前提 prose。
