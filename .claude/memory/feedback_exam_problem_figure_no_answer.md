過去問記事の**問題文位置に置く図**には、解答情報を一切描き込まない。具体的にはクリティカルパスの色強調・正答・工期/余裕日数の集計・「最長経路＝○○日」等のサマリー。これらは設問を見た瞬間に答えが分かり設問が成立しなくなる。

**Why:** 2026-06-21、1級土木 primary のネットワーク工程表図3本（h26-b/h27-b/h29-b）を補完した際、最初に問題図へ CP 赤強調＋工期サマリーを描き込み、ユーザーから「問題文なのに解答の図が必要なのか」と指摘された。試験問題は答えを伏せて出すのが大原則。

**How to apply:** 問題図は原則 PDF（過去問/問題集）からのクロップ（原図そのまま＝解答情報が入らない）。原図が取れず新規 SVG で描く場合も、全矢線同色・作業記号＋日数のみの「素図」にする。CP強調・経路サマリー等の解答補助図が有用なら、別図として `<details>解答・解説` 内に置く。alt にも正解誘導語を入れない（[[1-2-pdf]] / civil-exam-figure-extractor の Step4・「答え漏らし禁止」と同趣旨）。
