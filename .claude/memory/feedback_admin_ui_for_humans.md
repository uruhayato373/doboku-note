管理画面（tools/admin-app）は人が見る画面として、必要な値だけを適切な密度で出す。ページ見出しの説明（正本のパス・判定の説明）、照合記録・出典・未確認の理由・データ上の長いラベル・id は出さない。それらはエージェントが正本（JSON）とレポート（例: `npm run exam-ssot-status`）で管理する。グルーピングはスクロールを減らすためタブ（`.filterbar a.chip`）にする。KPI カードはラベルと値だけ（アイコン・装飾線なし）。警告は正本の不整合など人が動く必要があるときだけ出す。カード（`.card`）の中にカードや枠付きの折りたたみを入れない（枠はページの区切りだけ。中は区切り線・余白・左罫で整理）。詳細はトップに折りたたまず別ページへ「詳しく見る」カードで送る。

**Why:** 2026-09-26、資格一覧画面に説明文・照合列・出典・注記を並べたら「冗長・人には不要・スクロールが多い」と指摘され、KPI のアイコンも「意味がない」と言われた。2026-09-27 にはカード内カードを「やめた方が良くない？」と指摘された。

**How to apply:** 新しい管理画面を作るときは、まず「人がこの画面で判断すること」に要る列だけを決め、エージェント向けの情報は正本とレポートに置く。関連: [[feedback_ssot_no_hand_copies_self_verify]]
