総監記述式の論文骨子テンプレートを「安全管理軸」「経済性管理軸」のように **5 管理のうち 1 つを固定するアプローチで作らない**。

**Why:** 総監記述式の試験構造は「テーマ × 5 管理 × 専門部門」の 3D マトリクス:
- **テーマ**は出題側が決める（少子高齢化 / DX / 働き方改革 / カーボンニュートラル / インフラ老朽化 等）
- **5 管理**は普遍（経済性 / 人的資源 / 情報 / 安全 / 社会環境）
- **専門部門**は受験者が持ち込む（建設部門：道路・河川・コンクリート…/ 機械 / 電気電子）

評価軸は「**テーマに対し 5 管理を横串で書く**」こと。管理を 1 つ固定してテンプレ化しても、出題テーマがその管理軸とズレた瞬間に機能しない。

**How to apply:**
- 論文骨子テンプレ・答案構成を設計するときは「テーマ非依存・5 管理均等扱い」のフレームを基本に
- 具体例として 1 つの管理を題材に使うのは OK だが、それを「軸」と呼んで商品化しない
- 細分化したいなら「**テーマ別マッピング**」+「**専門部門別具体例**」の方向に展開する（管理軸並列ではない）
