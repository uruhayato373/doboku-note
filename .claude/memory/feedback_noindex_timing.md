新規ドメイン + 季節性のある事業（受験期等）では、「インデックス済 + 過去 N 日 impressions=0」を機械的に「価値なし」「noindex 化候補」と判定してはならない。実態は **「まだ Google に評価されていない」** ページが大半。

**Why**: 2026-04-27 セッションで GSC API 診断後に「low-value 200-400 ページの noindex 化」を推奨したが、ユーザーから訂正された。doboku-note は v1.0 立ち上げ後 3 ヶ月の新規ドメイン、主戦場は 6-7 月の受験期。本番ピーク前の 4 月時点で noindex 化すると、受験期流入の機会を捨てることになる。さらに真因はドメイン権威性不足であり、noindex で権威が上がるわけではない。

**How to apply**:
- 「impressions=0 のページは **いま価値が無い** のか、**まだ評価されていない** のか？」を必ず問う
- 新規サイト + 季節性事業では後者が大半 → 時間で解決する可能性が高いので即時 noindex は推奨しない
- noindex の代替: ①何もしない（権威性が育つのを待つ）②既存 hub 強化 ③外部被リンク獲得 ④独自データ構築
- noindex 判断のタイミング: トラフィックピーク後（受験期後の 8-9 月）の実データを見てから
- noindex を解除しても再インデックスに数週〜数ヶ月かかるため、誤判定のコストが高い
