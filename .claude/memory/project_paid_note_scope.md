`docs/note/5管理-*/article.md`（精読ガイド5本＝magazine `総監テキスト精読ガイド` 収録）のスコープは以下の3点に限定されている。販売文言・冒頭バナー・末尾CTA で「記述式の論述指南」を匂わせない。

**精読ガイドのスコープ**
- キーワード集の主要項目を試験頻出順に体系的解説（優先度: 高／中／低で仕分け）
- 択一の頻出論点・引っかけパターン・R3〜R7 出題例
- doboku-note キーワードページへの直リンク（学習動線）

**含まれない（=別商品）**
- 記述式の論文骨子・章立て・答案構成・定型フレーズ → **「総監記述式 論文骨子テンプレート（A-1）¥1,980」** に分離
- 「記述式で5管理のトレードオフをどう書けばいいか」レベルの論述指南は精読ガイドのスコープ外

**How to apply**
- magazine 訴求文言を書くときは「論点整理」「試験での問われ方」「優先順位」「択一の引っかけ」レベルに留め、「論述指南」「論文構成」「どう書くか」のニュアンスを避ける
- 精読ガイドの「こんな人」リード（各記事 L10-15 付近）に既存の痛点が並んでいる：範囲広くて優先順位が迷う／択一の計算と定義の区別が曖昧／全体像を素早く頭に入れたい等。これらと整合させる
- 「記述式で経済性管理を選択肢に入れているが、コスト・品質・工程のトレードオフ論点が整理できていない」レベルの「論点整理」言及は OK（精読ガイドの実リードに存在）

**経緯**: 2026-05-12 にユーザー指摘「有料noteは記述式の視点の部分は除いたはずだが」を受けて、9記事の冒頭バナー文言「記述式で5管理のトレードオフをどう書けばいいかわからない」を「5管理の範囲が広すぎてどこから手を付ければいいか優先順位がつかない」に差し替え（commit 9831064d）。
