## 教材外の「建設現場での活用」等の H2 を追加しない
総合技術監理（`pe-comprehensive-management`）キーワードページに、標準テキスト（情報管理・安全管理・社会環境管理・経済性管理・人的資源管理等）に**書かれていない実務応用セクション**を追加しない。
- **禁止 H2 例**: 建設現場での活用/適用/留意点、建設プロジェクトでの適用、建設分野での活用、建設・インフラ分野での活用事例、建設部門での活用/活用実務/事例/適用事例/実務上の留意点、業務での適用例、実務応用、現場での活用 等。
- **Why:** 総監は5つの管理を横断的・抽象的に統合するのが本質で、建設実務の具体例を入れると一般部門（建設）との区別が崩れる。教材原典に無い内容は過去問との整合性を欠き誤知識を植え付けるリスク。LLM の執筆バイアス（抽象概念を具体例で補強）と doboku-note のサイト性格（土木・建設系）が結合して生成的に追加されやすい。2026-04-28 の personal-communication ページレビューで発覚、pe-comprehensive-management 配下15ページに同種セクションが残存していた。
- **How to apply:** 新規作成・校正時は該当 H2 を原則削除。教材本文に明示されている事例（例: BCP の建設業の事例）は教材どおり記載可。真実源 `.claude/content-principles.md` §15。機械検知: `lint-mdx-mobile.mjs` ルール 9-7（MEDIUM・`pe-comprehensive-management/` 限定・pre-commit と cem-qa「コンテンツ原則」軸）。`civil-construction-1` 等の建設実務系資格ではこのルールは適用しない。

## 「5管理トレードオフ」H3 は現場・運用判断キーワードに限定
CEM キーワードページの「5管理トレードオフの観点」H3 は**現場・運用判断系（工事計画・設備管理・リスク評価等）に限定**。歴史的国際会議（国連人間環境会議・地球サミット等）・政策概念（SDGs・リオ宣言等）・法令制度キーワードには当てはめない。
- **Why:** 5管理（経済性・人的資源・情報・安全・社会環境）の相克は技術監理者が現場で意思決定する場面のフレームワーク。1972年ストックホルム会議に「経済性 vs 社会環境のトレードオフを初めて整理した」と書くのは contrived で教材外の哲学的解釈（上記「教材外応用 H2 を足さない」と同じ精神）。
- **How to apply:** cem-qa が `description` の「5管理トレードオフ」boilerplate を根拠に H3 追加を指摘してきても自動採用せず、キーワードの性質を先に判定（現場で5管理のいずれかを天秤にかける場面を含むか）。含まなければ description 側の boilerplate を削除する方向で修正。歴史・政策・法令キーワードは「総合技術監理における位置づけ」H2 直下の散文で系譜・分類上の位置を1-2段落示すだけで十分。

## 総監キーワードページは新規作成しない
`.local/r2/posts/pe-comprehensive-management/{slug}/article.mdx` の新規作成は行わない（2026-04-18 ユーザー明示）。マッピング表で「新規作成候補」の33-34件も実装しない。既存690ページで試験範囲の大半はカバー済みで、新規追加より既存の品質向上を優先。
- 教科書 §○-(X) の内容が既存ページに無い場合は最も近い既存ページに統合（例: `moving-average` → `correlation-analysis`、`v-model` → `waterfall` or `agile`）。統合先が無ければマッピング表に「統合先検討中」「補強対象外」と明記して放置可。cem-qa 再採点・教科書補強は既存204マッピングのみ対象。関連: [[feedback_hub_strengthening_approach]]

## 横断ガイドの5管理間トレードオフは核同士の対称関係で書く
横断ガイド（`management-tradeoffs` 等の `group: guide`）の `### {管理A}×{管理B}` H3 は、**A と B の「核となる目標」が衝突する対称関係**として書く。解決手段の選択肢の二極化（「事後保全 vs 一律予防保全」）をトレードオフとして書かない。
- **Why:** 2026-05-28、`management-tradeoffs` の経済性×安全節を初稿で解決手段の対称関係（「事後保全に偏れば事故、一律予防保全は予算破綻」）で書いてしまい「経済性×安全のトレードオフになっていない」と指摘された。受験生がこのまま論文化すると「保全方式の選択」の議論に滑る。
- **How to apply:** 編集前に [[content-principles]] §23 を Read。散文冒頭に「{管理A}は X を核、{管理B}は Y を核とし、両者は…で衝突する」型の1文。5管理の核: 経済性=コスト/工期/原価、人的資源=労働力確保/育成、情報=CIA/業務効率化、安全=人命/健康/第三者影響、社会環境=環境保全/景観/合意形成。構造順: (1)対立構造化 (2)具体的トレードオフ (3)複数解決策の組み合わせ (4)SpecSheetList。評価軸の独立段落（「評価軸は X 対 Y の二軸」型のメタ解説）は作らず散文に内在化。固有事業名（i-Construction・CCUS・群マネ・PLATEAU 等）・特定インシデント（八潮市・成瀬ダム等）・特定数値（30%縮減・18.1万人等）・白書名直接引用は入れない（§23.4）。解決フレームは現場・運用判断レベルの語彙（ALARP・RBM・LCA・ミティゲーション階層・PoC・PI・勤務間インターバル等）。cem-qa で 23-1〜23-5 として機械検知。

## 校正時は過去問の核心 Callout を確認する
「校正して」と依頼されたら、PE キーワードページで毎回標準チェック（明示指示がなくても実施）: (1) `src/config/past-exam-backlinks.json` で対象キーワードを lookup (2) 過去問あり→該当過去問 MDX の `<details>` 解説から誤答パターン・引っかけ論点を把握 (3) 既存 `<Callout type="warn">` がカバーしているか確認 (4) 未カバーで読み飛ばすと失点する論点があれば Callout 追加候補を提案（content-principles.md §7: 単なる補足は追加しない・1記事3個まで）。
- **Why:** PastExamBacklinks（過去問逆引きカード）は build-time 自動注入で548ページ全てに付くが、引っかけ警告 Callout は手動で51ページのみ。この差を校正のたびに埋めて editorial 品質を底上げ。
- 対象は主に PE keyword ページ（civil-construction-1 等は構造が異なれば別途判断）。過去問が無い／引っかけ要素が無いキーワードは「追加なし」と明示してスキップ。真実源 `.claude/content-principles.md` §16。関連: [[feedback_pe_pastexam_answer_compromise]]
