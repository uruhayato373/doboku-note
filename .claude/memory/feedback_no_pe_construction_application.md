総合技術監理（`pe-comprehensive-management`）キーワードページに、教材『情報管理』『安全管理』『社会環境管理』『経済性管理』『人的資源管理』等の標準テキストに **書かれていない実務応用セクション** を追加しない。

**禁止される H2 タイトル例**:
- 建設現場での活用 / 建設現場での適用 / 建設現場での留意点
- 建設プロジェクトでの適用 / 建設分野での活用 / 建設・インフラ分野での活用事例
- 建設部門での活用 / 建設部門における活用実務 / 建設部門における事例
- 建設部門における適用事例 / 建設部門における実務上の留意点
- 業務での適用例 / 実務応用 / 現場での活用 等

**Why**:
- 総監は 5 つの管理を **横断的・抽象的に統合する** ことが本質。建設実務の具体例を入れると **一般部門（建設）との区別が崩れ**、ページの存在意義が薄れる
- 教材原典に無い内容は **過去問との整合性を欠く** 危険があり、誤った知識を植え付けるリスクがある
- LLM の執筆バイアス（「抽象概念を具体例で補強する」）と doboku-note のサイト性格（土木・建設系試験対策）が誤って結合し、生成的に追加されやすい既知パターン
- 過去事例: 2026-04-28 の personal-communication ページレビュー時に発覚。pe-comprehensive-management 配下の 15 ページに同種セクションが残存していた

**How to apply**:
- 新規ページ作成・既存ページ校正時、該当する H2 セクションを **原則削除** する
- 教材本文に明示的に書かれている事例（例: BCP の建設業の事例）であれば、教材どおりの内容として記載してよい
- 真実源: `.claude/content-principles.md` §15「総監ページに教材外の実務応用セクションを追加しない」
- 機械検知: `lint-mdx-mobile.mjs` のルール 9-7（MEDIUM、`pe-comprehensive-management/` 限定）。pre-commit と `cem-qa` エージェントの 5 軸ルーブリック「コンテンツ原則」軸で自動指摘される
- `civil-construction-1`（1 級土木）等、建設実務系資格のページではこのルールは適用しない（建設実務の活用例は正当）
