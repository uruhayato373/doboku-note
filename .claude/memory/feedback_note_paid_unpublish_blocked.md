note は「**下書きに戻す**（可逆な非公開化）」を、**有料記事／過去に販売実績がある記事／有料・定期購読マガジンに追加したことがある記事**には許可しない（編集UIがダイアログ「この記事は下書きに戻せません」でブロック・2026-06-20 BK-I で実機確認）。これらを公開停止する唯一の手段は**不可逆「削除」**。

**Why:** 販売中商品ラインの有料記事を「本文大改稿して差し替え」したいとき、編集画面は paste 不可（全面差し替え不可）かつ旧版を綺麗に非公開化もできない、という二重制約があるため。

**How to apply:** 販売中有料記事の大改稿差し替えは「**新規 /new で公開 → マガジン入替（新追加＋旧を追加済toggleでoff）→ 旧版は孤児化（マガジン外で放置）**」が現実解。旧版の削除は不可逆＋販売履歴ゆえユーザー確認必須、原則は孤児化で実害最小。マガジン購入者は新版（マガジン経由）でアクセス継続。手順詳細は update-mode.md 「対象の制約」＋ Phase U-B 手段3、handoff `docs/handoffs/2026-06-20-bki-i2-draft-staging.md`。関連: [[note_html_unsupported]]
