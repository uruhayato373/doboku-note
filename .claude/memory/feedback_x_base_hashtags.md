X（総監系）の共通ベースハッシュタグは **`#技術士 #総監`**（先頭に置く）+ 種別タグ 1-2 個 = 計 3-4 個。`#技術士総監`(11 weight) はベースから外した（2026-05-29 ユーザー指示）。`#総合技術監理部門`(17 weight) は重いので告知・節目など要点投稿に限定。

**Why:** ユーザーが目視で `#技術士` の流入有効性を確認。軽量タグ（#技術士=7 / #総監=5 weight）で 280 字の余白を確保し、種別タグ枠を広げたい意向。X は日本語2/字・URL23固定・上限280なので重いタグは即オーバーにつながる（実例: 035-① が 2 タグで既に 274/280）。

**How to apply:** 今後の X 投稿（tweets.md）から適用。既に予約済みの投稿は遡及変更しない。真実源は `docs/sns/x/README.md`「ハッシュタグ運用ルール（2026-05-29 改訂）」。個数の最適レンジは [[feedback_x_hashtag_count]]（1-3 中心、X は IG/note の 20+ と別系統）。
