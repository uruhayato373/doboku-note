過去問 MDX（`.local/r2/posts/**/primary-*/article.mdx`・`secondary-*/article.mdx`）は、**生成時も修正時も全問を原典 PDF と視覚突合する**。問題文・選択肢・設問極性（適当な/適当でない）・正解番号・各選択肢の ❌/✅ を1問ずつ PDF 画像で確認する。

**Why（事例）:**
1. **修正時（2026-04-20）**: R06 Ⅰ-1-38 の誤記指摘時、推測修正を避け PDF 視覚突合したことで同設問内の4 OCR エラーを同時発見（疑わしい1箇所の周辺も潜在エラーを持つ）。
2. **生成時の大規模ハルシネーション（2026-05-28、2級土木 過去問15本）**: PDF→MDX 生成サブエージェントが OCR 不良 PDF から問題文・選択肢を捏造。全15本を突合し**約240箇所の相違**を是正（r04-kouki/r05-zenki は実質全面再構築）。
   - **正解番号の正答 PDF 一致は品質保証にならない**（正解番号は合っているのに問題文・選択肢が別問題・設問極性が逆・選択肢文言が意味反転が多発）。
   - **content-qa の構造採点では検出できない**（構造・解答整合・frontmatter・MDX互換・モバイルを見るが問題文の PDF 一致は検証しない。content-qa 3.0 満点の r03-zenki でも4問、2.3 の r05-zenki は約45問捏造）。
   - **OCR 品質に関わらず発生**（公式 PDF・OCR良好の R07 でも一次に46問）。**二次（記述式）は相対的に安全**（R04二次は0問）、一次（選択式）が高リスク。
3. **2026-09-30、2級土木 一次前期 r03〜r06 を公式問題と照合**: 4年度で数百行の転記崩れ。「適当なもの／適当でないもの」の取り違え、「堆積させなければならない」→「させてはならない」（正答と矛盾）、表の中身が別内容など。正答表との不一致は0＝**正答だけ照合しても設問の崩れは見つからない**。解説・ExamPoint を書いても設問文が誤りなら読者は誤知識を覚える。残る年度の照合は backlog DN-0475。関連: [[feedback_workflow_orchestration_gotchas]] [[project_civil1_primary_answer_key_errors]]

**How to apply:**
- 原典 PDF は `docs/textbook/{資格名}/過去問/RXX/`。pdftotext は CID 埋込フォントで日本語抽出不能なことが多い→PyMuPDF で 250-300dpi 画像化して Read で視覚転記: `python -c "import fitz; d=fitz.open(...); d[p].get_pixmap(dpi=250).save(...)"`。PDF のテキスト層が崩れている年度（数字が別字に化ける等）は画像で読む。jctc 現行ページが404なら Wayback Machine。
- 正答 PDF とは別に問題 PDF の本文を視覚転記し、問題文・選択肢・設問極性を1問ずつ照合。生成直後の品質ゲートに「全問原典視覚突合」を含め、正解番号の機械突合だけで合格としない。

## 取得直後に PDF 表紙の年度を確認（ファイル名と中身の入れ替わり）
再配布サイト（土木のトリセツ等）の PDF は年度が入れ替わっていることがある。**2026-05-28、2級土木で R05 と R06 の PDF（前期・後期・二次の全5ペア）がファイル名と中身で入れ替わっていた**（`R05_第一次検定_後期.pdf` の表紙が令和6年度）。問題数でも判別可能（真のR05=61問、真のR06=66問。2級土木 R03-R05=61問、R06-R07=66問）。気づかず MDX 化すると年度ラベルと内容が全て食い違う（サブエージェントが表紙を読んで検出したが、取得直後なら MDX スワップ+frontmatter再修正の手戻りを防げた）。
- 取得直後に全 PDF の表紙（1ページ目）を `python -c "import fitz; [fitz.open(p)[0].get_pixmap(dpi=120).save(...) for p in pdfs]"` で画像化して年度を目視。pdfinfo のページ数や最終問題番号でも検算。
- 食い違えば PDF をリネーム/スワップして正しい年度に揃えてから import（MDX 生成後の是正は手戻りが大きい）。

## サブエージェントで PDF 図を抽出する運用
PDF→MDX変換スキル（fishery-port-import, river-design-import, noise-manual-import）で図抽出をサブエージェントに委任する場面すべてに適用。
1. 解像度は **150dpi**（200dpi だと A4→2339px で複数画像閲覧時に2000px制限エラー。2026-03-21 に 200dpi+11枚/エージェントで "image dimension limit" エラー→150dpi+3〜6枚で全成功）。
2. 1エージェントあたり **3〜6枚**（多いとコンテキスト圧迫・エラー時の損失大）。
3. `/tmp` 名にグループ番号を付与（`/tmp/fp{編番号}g{グループ番号}-`）。
4. 全グループを並列起動（Agent ツールを1メッセージに複数）。
5. `mode: bypassPermissions` で権限確認を省略。
