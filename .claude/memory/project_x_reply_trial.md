2026-11-07、運営者の判断で X の返信候補を毎日用意する試行を始めた（EXP-059・DN-1037）。期間は 11/7〜11/21、間隔 5 分以上。1 日の上限は運営者の判断で撤廃した（人が操作しても多く返信することはある、という判断）。手順は `/x-reply`、上限は `config/x-reply-trial.json`。

**Why:** 発表後に手で返信すると、確認した 6 人中 3 人は送らないほうがよい状況だった（失格の判明、強い落ち込み、趣味のアカウント）。候補探しは仕組みにできるが、判断は人に残す必要がある。運営者は「人が確認を依頼しているので自動ではない」と考え、無人の定期送信は X の Automation rules に触れるため作らないと合意した。

運営者が相手と文面を先に承認した分は、`/loop` で 5 分おき以上の時間差で送ってよい（2026-11-08 に運営者の判断で 60 分→5 分）（1 回 5 件まで・24 時間以内）。

**How to apply:** 送信は `x-reply-log --check` を通し、1 件ごとの承認があるものだけ。運営者が急いで間隔を詰める指示を出すことがあるので、間隔を割るときは一言伝えてから従う。3 分おきの一括送信のような大量の一方的な返信は実行を控える。11/21 の後に続けるかを判定する。[[feedback_x_suspension_guardrail]]

**質問には答える（2026-11-08 運営者の判断）**: 同じ相手へこちらから返すのは 1 回だけだが、返信した相手から質問が来たら答える。`x-reply-log --check --user <id> --answer` が OK なら、承認された答えを送って `--kind answer` で記録する。

**資格横断と取り先（2026-11-08 運営者の指示）**: 技術士だけでなく土木施工管理・コンクリートにも広げ、X のタイムライン（フォロー中）と検索（最新）も候補の取り先にした。資格は `config/x-reply-trial.json` の `topics`、仕分けと下書きは `x-reply-drafter`。11/8 の実測: 検索語 7→17、判定 220→472 件。コンクリートの検索結果はクイズ・学習アプリの宣伝が多く、本人の投稿はフォロー中のタイムラインのほうが多かった。
