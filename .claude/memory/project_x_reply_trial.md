2026-11-07、運営者の判断で X の返信候補を毎日用意する試行を始めた（EXP-059・DN-1037）。期間は 11/8〜11/21、1 日 3 件まで、間隔 60 分以上。手順は `/x-reply`、上限は `config/x-reply-trial.json`。

**Why:** 発表後に手で返信すると、確認した 6 人中 3 人は送らないほうがよい状況だった（失格の判明、強い落ち込み、趣味のアカウント）。候補探しは仕組みにできるが、判断は人に残す必要がある。運営者は「人が確認を依頼しているので自動ではない」と考え、無人の定期送信は X の Automation rules に触れるため作らないと合意した。

**How to apply:** 送信は `x-reply-log --check` を通し、1 件ごとの承認があるものだけ。運営者が急いで間隔を詰める指示を出すことがあるので、上限を超えるときは一言伝えてから従う。3 分おきの一括送信のような大量の一方的な返信は実行を控える。11/21 の後に続けるかを判定する。[[feedback_x_suspension_guardrail]]
