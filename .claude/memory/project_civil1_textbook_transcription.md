1級・2級土木のアクセス増（サイト・note）と品質改善の検討の一環で、`docs/textbook/１級土木施工管理技士/テキスト（施工管理・法規編）/` 全7章327pを高解像度OCRで章別MD化完了（2026-06-24, commit 5d4f7bb2a）。総監/建設部門がテキストMD化済なのに1級土木だけ未着手だったギャップを埋めた**内部リファレンス**（公開禁止・著作権、二次writer/経験記述/guideページ執筆の根拠SSOT）。

**方法**: PyMuPDF 2200pxレンダリング → `scanned-textbook-transcriber` 59バッチ(6p/agent)をWorkflowでファンアウト → 章別連結。

**土木一般編(385p・6章)も完了（2026-06-24 commit ac57d5c7a）**: 同パイプライン（65バッチOCR・369k字）＋図320点クロップ埋め込み。図は322点中320埋め込み（確信度0.55未満の誤検出1＋自動検出不能1=未クロップ・原典参照）。bbox Workflowは図が多い(322)ためレート制限対策として「章別ジョブをファイル読込→40図ずつ順次グループ処理(parallel barrier)」に改良＝135図一括時の29失敗(レート制限)を回避。これで1級土木テキスト両編（施工管理・法規編＋土木一般編）が揃った。

**品質の留保（重要）**: スキャンPDFのLLM-OCRのため**字句は近似**。高解像度でも漢字誤読(例: 築造→施造=補正済)と密段落の言い換え/節落ち(例 第1章 三大管理の相互関係)が残存。条文・数値・定義の一字一句は**必ず原典PDFで照合**。詳細はディレクトリ内 README.md。ユーザー選択で校正QAパスは省略済（コスト優先）。

**Phase2 図クロップ完了（2026-06-24 commit 72d16f940）**: 実図135点を `civil-exam-figure-extractor`(Workflow・候補±3窓キャプション照合)で領域検出→2600px再レンダリングで比率クロップ→`img/{章}-fig{NN}.png`→本文の各`（図:）`直前に`![図番号](img/...)`埋め込み(Obsidian相対パス表示可)。bboxはLLM自動判定=隣接本文が一部入る場合あり。表セル内注記1件は実図でなく除外。docs/textbook配下はr2-sync対象外(`.local/r2/posts/**/img/**`のみ)=公開R2非同期で内部限定維持。

**未着手（次工程＝アクセス増の本丸）**: ①この素材を使ったguideページ品質改善・note無料集客記事への展開。②当初推奨は「GSCデータ先行で品質ボトルネック特定→該当ページ改善」だが、ユーザーは「まず素材化(文字起こし＋図)して検討」を選択し素材は完成。③土木一般編(385p)は未着手。
