position が 5-15 で頭打ちの hub ページを強化するときは、本文を大規模に書き直さず **seoTitle + リード文（最初の 200 字）の "検索クエリ整合"** に絞る。

**Why**: 2026-04-27 セッションで HIGH 2 件（scraper, histogram）+ MEDIUM 1 件（keyword-2026）を強化。事前に `npm run fetch-gsc-data --dimension query --page <slug>` で各ページの実クエリを取得し、最頻クエリと title/seoTitle/リード文の整合を確認したうえで最小編集した。本文は既に十分（FAQ 5、参考資料、図解あり）なので触る必要なかった。「動いてるものを壊さない」原則。

**How to apply**:
1. 対象ページの実 GSC クエリを取得（90 日、上位 30）
2. 主要クエリ（impr 上位 1-3 件）を確認
3. 検索意図を判定（例: 「○○とは」= 定義+概要、「○○ 計算」= 公式+例題）
4. seoTitle を主要クエリに整合させる（複数クエリを「｜」区切りで含める）
5. リード文先頭に「○○とは…」の明確な定義を 1 文追加
6. 本文は触らない（または最小限の追記のみ）

**避けるべき**:
- 主要クエリと無関係な大規模リライト
- タイトルを完全変更（既存の被リンクや評価を失う）
- FAQ の追加削除（pos 動かなくても OK なら維持）

**例**:
- scraper: 旧 seoTitle「スクレーパ」→ 新「スクレーパとは｜3 種類の特徴と運搬距離」（クエリ「スクレーパとは」8 imp に整合）
- histogram: 旧「ヒストグラム・工程能力図」→ 新「工程能力図とは｜ヒストグラムとの違い・Cp Cpk」（クエリ「工程能力図」7 imp が最大、ヒストグラムよりも前面に出す）

**効果検証**:
- デプロイ 2-4 週後に GSC で position 変化を確認
- impressions が下がっていない（クエリマッチ範囲が狭まっていない）ことを必ず併記確認
- 改善判定: position が 1-3 ポイント上昇 ＋ impressions 横ばい以上
