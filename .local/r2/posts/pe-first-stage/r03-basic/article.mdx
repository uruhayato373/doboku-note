## Ⅰ-1-1

次のうち、ユニバーサルデザインの特性を備えた製品に関する記述として、最も不適切なものはどれか。

1. 小売店の入り口のドアを、ショッピングカートやベビーカーを押していて手がふさがっている人でも通りやすいよう、自動ドアにした。

2. 録音再生機器（オーディオプレーヤーなど）に、利用者がゆっくり聴きたい場合や速度を速めて聴きたい場合に対応できるよう、再生速度が変えられる機能を付けた。

3. 駅構内の施設を案内する表示に、利用者が外国人や子供でも内容を軽減し素早く効果的に情報が伝えられるよう、ピクトグラム（図記号）を付けた。

4. 冷蔵庫の扉の取っ手を、子どもがいたずらしないよう、扉の上の方に付けた。

5. 電子機器の取扱説明書を、個々の利用者の能力や好みに合うように、大きな文字で印刷したり、点字や音声・映像で提供したりした。

<details>
<summary>解答・解説</summary>

**正答：4**

ユニバーサルデザイン（UD）は、年齢・能力・状況を問わず、できるだけ多くの人が利用できることを目指す設計思想である。

1. 手がふさがっていても通れる自動ドアは、多様な利用者の利便性を高めるUDの考え方に沿う ✅
2. 利用者の好みに合わせて再生速度を変えられる機能は、能力や状況に応じた柔軟な利用を可能にしUDに沿う ✅
3. 外国人や子供でも直感的に理解できるピクトグラムは、言語に依存しない情報伝達でUDに沿う ✅
4. 取っ手を扉の上方に付けて子どもが使えないようにする設計は、特定の利用者を意図的に排除するものであり、誰もが使えることを目指すUDの考え方に反する。これが最も不適切 ❌
5. 文字の拡大・点字・音声・映像など複数の手段で情報を提供することは、能力や好みの多様性に対応するUDに沿う ✅

## Ⅰ-1-2

下図に示した、互いに独立な3個の要素が接続されたシステムA〜Eを考える。3個の要素の信頼度はそれぞれ0.9、0.8、0.7である。各システムを信頼度が高い順に並べたものとして、最も適切なものはどれか。

<ArticleImage src="/posts/pe-first-stage/r03-basic/img/q-I1-2.webp" alt="システムA〜Eの構成図。各要素の信頼度0.9・0.8・0.7の直列／並列の組み方が異なる5つのシステム構成" width={1523} height={647} />

1. C ＞ B ＞ E ＞ A ＞ D

2. C ＞ B ＞ A ＞ E ＞ D

3. C ＞ E ＞ B ＞ D ＞ A

4. E ＞ D ＞ A ＞ B ＞ C

5. E ＞ D ＞ C ＞ B ＞ A

<details>
<summary>解答・解説</summary>

**正答：2**

各システムは「直列2要素」と「単独1要素」を並列にした構成である。並列系の信頼度は $R=1-(1-R_1 R_2)(1-R_3)$ で求める。

- システムA：直列(0.9×0.8=0.72)と0.7の並列 → $1-(1-0.72)(1-0.7)=1-0.28\times0.3=0.916$
- システムB：直列(0.9×0.7=0.63)と0.8の並列 → $1-(1-0.63)(1-0.8)=1-0.37\times0.2=0.926$
- システムC：直列(0.8×0.7=0.56)と0.9の並列 → $1-(1-0.56)(1-0.9)=1-0.44\times0.1=0.956$
- システムD：0.8と並列(0.9, 0.7)の直列 → $0.8\times[1-(1-0.9)(1-0.7)]=0.8\times0.97=0.776$
- システムE：0.9と並列(0.8, 0.7)の直列 → $0.9\times[1-(1-0.8)(1-0.7)]=0.9\times0.94=0.846$

信頼度の高い順は C(0.956) ＞ B(0.926) ＞ A(0.916) ＞ E(0.846) ＞ D(0.776)。

1. E・Aの順序が誤り ❌
2. C ＞ B ＞ A ＞ E ＞ D で正しい ✅
3. 並び順が誤り ❌
4. 高低が逆で誤り ❌
5. 高低が逆で誤り ❌

## Ⅰ-1-3

設計や計画のプロジェクトを管理する方法として知られる、PDCAサイクルに関する次の（ア）〜（エ）の記述について、それぞれの正誤の組合せとして、最も適切なものはどれか。

（ア）Pは、Planの頭文字を取ったもので、プロジェクトの目標とそれを達成するためのプロセスを計画することである。

（イ）Dは、Doの頭文字を取ったもので、プロジェクトを実施することである。

（ウ）Cは、Changeの頭文字を取ったもので、プロジェクトで変更される事項を列挙することである。

（エ）Aは、Adjustの頭文字を取ったもので、プロジェクトを調整することである。

1. ア：正　イ：誤　ウ：正　エ：正

2. ア：正　イ：正　ウ：誤　エ：誤

3. ア：正　イ：正　ウ：正　エ：誤

4. ア：誤　イ：正　ウ：誤　エ：正

5. ア：誤　イ：誤　ウ：正　エ：正

<details>
<summary>解答・解説</summary>

**正答：2**

PDCAは Plan（計画）・Do（実施）・Check（評価・確認）・Act（改善・処置）の4段階からなる管理サイクルである。

- （ア）PはPlanで、目標とプロセスを計画する段階という説明は正しい 正

- （ウ）CはChangeではなくCheck（評価・確認）の頭文字であり誤り 誤

したがって ア正・イ正・ウ誤・エ誤 となる。

2. ア正・イ正・ウ誤・エ誤 で正しい ✅
3. ウを正とする点が誤り ❌
4. ア・ウを誤、エを正とする点が誤り ❌
5. ア・イを誤とする点が誤り ❌

## Ⅰ-1-4

ある装置において、平均故障間隔（MTBF：Mean Time Between Failures）がA時間、平均修復時間（MTTR：Mean Time To Repair）がB時間のとき、この装置の定常アベイラビリティ（稼働率）の式として、最も適切なものはどれか。

1. A／（A−B）

2. B／（A−B）

3. A／（A＋B）

4. B／（A＋B）

5. A／B

<details>
<summary>解答・解説</summary>

**正答：3**

アベイラビリティ（稼働率）は、装置が稼働できる時間の割合を表し、

$$A_v=\frac{\text{MTBF}}{\text{MTBF}+\text{MTTR}}=\frac{A}{A+B}$$

で与えられる。MTBF（平均故障間隔A）は稼働している時間、MTTR（平均修復時間B）は修復に要する時間であり、全体（稼働＋修復）に占める稼働の割合が稼働率となる。

1. 分母がA−Bで誤り ❌
2. 分子がB・分母がA−Bで誤り ❌
3. A／（A＋B）で正しい ✅
4. 分子がBで誤り（これは不稼働率に相当） ❌
5. 分母がBのみで誤り ❌

<ExamPoint
  summary="稼働率＝MTBF／（MTBF＋MTTR）。分母は稼働＋修復の全時間"
  items={[
    "MTBF＝平均故障間隔（稼働時間）、MTTR＝平均修復時間",
    "アベイラビリティ＝A／（A＋B）、不稼働率＝B／（A＋B）",
    "信頼性はMTBF、保全性はMTTRで評価する",
  ]}

## Ⅰ-1-5

構造設計に関する次の（ア）〜（エ）の記述について、それぞれの正誤の組合せとして、最も適切なものはどれか。ただし、応力とは単位面積当たりの力を示す。

（ア）両端がヒンジで圧縮力を受ける細長い棒部材について、オイラー座屈に対する安全性を向上させるためには部材長を長くすることが有効である。

（イ）引張強度の異なる、2つの細長い棒部材を考える。幾何学的形状と縦弾性係数、境界条件が同一とすると、2つの棒部材の、オイラーの座屈荷重は等しい。

（ウ）許容応力とは、応力で表した基準強度に安全率を掛けたものである。

（エ）構造物は、設定された限界状態に対して設計される。考慮すべき限界状態は1つの構造物につき必ず1つである。

1. ア：正　イ：誤　ウ：正　エ：正

2. ア：正　イ：正　ウ：誤　エ：正

3. ア：誤　イ：正　ウ：誤　エ：正

4. ア：誤　イ：正　ウ：正　エ：誤

5. ア：誤　イ：正　ウ：誤　エ：誤

<details>
<summary>解答・解説</summary>

**正答：5**

- （ア）オイラー座屈荷重は $P_{cr}=\dfrac{\pi^2 EI}{(L_k)^2}$ で、部材長 $L$ を長くすると座屈荷重は小さくなり安全性は低下する。「部材長を長くすると安全性が向上」は誤り 誤

- （ウ）許容応力は基準強度を安全率で**割った**ものであり、「掛けたもの」は誤り 誤

したがって ア誤・イ正・ウ誤・エ誤 となる。

1. ア・ウ・エを正とする点が誤り ❌
2. ア・エを正、ウを誤とする組合せが誤り ❌
3. エを正とする点が誤り ❌
4. ウを正・エを誤とする点が誤り ❌
5. ア誤・イ正・ウ誤・エ誤 で正しい ✅

## Ⅰ-2-2

次の論理式と等価な論理式はどれか。

$$\overline{\overline{A}\cdot\overline{B}+A\cdot B}$$

ただし、論理式中の＋は論理和、・は論理積を表し、論理変数Xに対して $\overline{X}$ はXの否定を表す。2変数の論理和の否定は各変数の否定の論理積に等しく、2変数の論理積の否定は各変数の否定の論理和に等しい。また、論理変数Xの否定の否定は論理変数Xに等しい。

1. $(A+B)\cdot(A+B)$

2. $(A+B)\cdot(\overline{A}+\overline{B})$

3. $(A\cdot B)\cdot(\overline{A}\cdot\overline{B})$

4. $(A\cdot B)\cdot\overline{(A\cdot B)}$

5. $(A+B)+(\overline{A}+\overline{B})$

<details>
<summary>解答・解説</summary>

**正答：2**

与式の内側 $\overline{A}\cdot\overline{B}+A\cdot B$ は、$A$ と $B$ がともに偽、またはともに真のときに1となる（一致回路＝XNOR）。その否定である与式は、$A$ と $B$ が異なるときに1となる排他的論理和（XOR）$A\oplus B$ に等しい。

XOR は $A\oplus B=(A+B)\cdot\overline{A\cdot B}$ と書け、ド・モルガンの法則 $\overline{A\cdot B}=\overline{A}+\overline{B}$ を用いると

$$A\oplus B=(A+B)\cdot(\overline{A}+\overline{B})$$

となる。これは選択肢2に一致する。

1. $(A+B)\cdot(A+B)=A+B$ となり、$A=B=1$ で1を返すためXORと一致せず誤り ❌
2. $(A+B)\cdot(\overline{A}+\overline{B})$ はXORに一致し正しい ✅
3. $(A\cdot B)\cdot(\overline{A}\cdot\overline{B})=0$（恒偽）となり誤り ❌
4. $(A\cdot B)\cdot\overline{(A\cdot B)}=0$（恒偽）となり誤り ❌
