## Ⅰ-1-2

ある問屋が取り扱っている製品Aの在庫管理の問題を考える。製品Aの1年間の総需要は $d$ ［単位］と分かっており、需要は時間的に一定、すなわち、製品Aの在庫量は一定量ずつ減少していく。この問題は在庫量がゼロになった時点で発注し、1回当たりの発注量 $q$ ［単位］（ただし $q \le d$ ）が瞬時的に入って即座に納入されると仮定する。このとき、年間の発注回数は $d/q$ ［回］、平均在庫量は $q/2$ ［単位］となる。1回当たりの発注費用は発注量 $q$ ［単位］には無関係で $K$ ［円］、製品Aの平均在庫量1単位当たりの年間在庫維持費用（倉庫費用、保険費用、税金、利息など）を $h$ ［円／単位］とする。

年間総費用 $C(q)$ ［円］は1回当たりの発注量 $q$ ［単位］の関数で、年間総発注費用と年間在庫維持費用の和で表すものとする。このとき年間総費用 $C(q)$ ［円］を最小とする発注量を求める。なお、製品Aの購入費は需要 $d$ ［単位］には比例するが、1回当たりの発注量 $q$ ［単位］とは関係ないので、ここでは無視する。

$K = 20{,}000$ ［円］、$d = 1{,}350$ ［単位］、$h = 15{,}000$ ［円／単位］とするとき、年間総費用を最小とする1回当たりの発注量 $q$ ［単位］として最も適切なものはどれか。

1. 50単位

2. 60単位

3. 70単位

4. 80単位

5. 90単位

<details>
<summary>解答・解説</summary>

**正答：2**

年間総費用は、年間総発注費用 $K\cdot\dfrac{d}{q}$ と年間在庫維持費用 $h\cdot\dfrac{q}{2}$ の和で表される。

$$C(q) = K\frac{d}{q} + h\frac{q}{2}$$

$\dfrac{dC}{dq}=0$ より経済的発注量（EOQ）は

$$q^* = \sqrt{\frac{2Kd}{h}}$$

数値を代入すると

$$q^* = \sqrt{\frac{2 \times 20000 \times 1350}{15000}} = \sqrt{3600} = 60 \text{［単位］}$$

1. $q=50$ では最小にならず誤り ❌
2. $q=60$ 単位でEOQと一致し正しい ✅
3. $q=70$ では最小にならず誤り ❌
4. $q=80$ では最小にならず誤り ❌
5. $q=90$ では最小にならず誤り ❌

## Ⅰ-1-5

ある銀行に1台のATMがあり、このATMを利用するために到着する利用者の数は1時間当たり平均40人のポアソン分布に従う。また、このATMでの1人当たりの処理に要する時間は平均40秒の指数分布に従う。このとき、利用者がATMに並んでから処理が終了するまで系内に滞在する時間の平均値として最も近い値はどれか。

トラフィック密度（利用率）＝到着率÷サービス率

平均系内列長＝トラフィック密度÷（1−トラフィック密度）

平均系内滞在時間＝平均系内列長÷到着率

1. 68秒

2. 72秒

3. 85秒

4. 90秒

5. 100秒

<details>
<summary>解答・解説</summary>

**正答：2**

M/M/1待ち行列の問題である。到着率とサービス率を同じ単位（毎秒）に揃える。

- 到着率 $\lambda = \dfrac{40}{3600} = \dfrac{1}{90}$ ［人／秒］
- サービス率 $\mu = \dfrac{1}{40}$ ［人／秒］（1人40秒）

トラフィック密度（利用率）は

$$\rho = \frac{\lambda}{\mu} = \frac{1/90}{1/40} = \frac{40}{90} = \frac{4}{9} \approx 0.444$$

平均系内列長は

$$L = \frac{\rho}{1-\rho} = \frac{4/9}{5/9} = \frac{4}{5} = 0.8$$

平均系内滞在時間は

$$W = \frac{L}{\lambda} = 0.8 \times 90 = 72 \text{［秒］}$$

1. 計算値と一致せず誤り ❌
2. 72秒で計算値と一致し正しい ✅
3. 計算値と一致せず誤り ❌
4. 計算値と一致せず誤り ❌
5. 計算値と一致せず誤り ❌

（ウ）関数 $f(x)$ と $g(x)$ が、 $c$ を端点とする閉区間において微分可能で $\displaystyle\lim_{x\to c}f(x)=\lim_{x\to c}g(x)=0$ あるいは $\displaystyle\lim_{x\to c}f(x)=\lim_{x\to c}g(x)=\infty$ のいずれかが満たされるとする。このとき、 $f(x)$ 、 $g(x)$ の1階微分を $f'(x)$ 、 $g'(x)$ として、 $g'(x)\ne 0$ の場合に、 $\displaystyle\lim_{x\to c}\frac{f'(x)}{g'(x)}=L$ が存在すれば、 $\displaystyle\lim_{x\to c}\frac{f(x)}{g(x)}=L$ となる。

## Ⅰ-2-1

基数変換に関する次の記述の、　　　　に入る表記の組合せとして、最も適切なものはどれか。

私たちの日常生活では主に10進数で数を表現するが、コンピュータで数を表現する場合、「0」と「1」の数字で表す2進数や、「0」から「9」までの数字と「A」から「F」までの英字を使って表す16進数などが用いられる。10進数、2進数、16進数は相互に変換できる。例えば10進数の15.75は、2進数では $(1111.11)_2$ 、16進数では $(F.C)_{16}$ である。同様に10進数の11.5を2進数で表すと　ア　、16進数で表すと　イ　である。

1. ア：$(1011.1)_2$　イ：$(B.8)_{16}$

2. ア：$(1011.0)_2$　イ：$(C.8)_{16}$

3. ア：$(1011.1)_2$　イ：$(B.5)_{16}$

4. ア：$(1011.0)_2$　イ：$(B.8)_{16}$

5. ア：$(1011.1)_2$　イ：$(C.5)_{16}$

<details>
<summary>解答・解説</summary>

- 整数部 11 は2進数で $(1011)_2$

1. ア：$(1011.1)_2$・イ：$(B.8)_{16}$ で正しい ✅
2. ア「$(1011.0)_2$」・イ「$(C.8)_{16}$」が誤り ❌
3. イ「$(B.5)_{16}$」が誤り ❌
4. ア「$(1011.0)_2$」が誤り ❌
5. イ「$(C.5)_{16}$」が誤り ❌

我が国では、1960年代から1980年代にかけて工場からの大量の　ア　等が排出され、工業地帯など工場が集中する地域を中心として著しい大気汚染が発生した。その対策として、大気汚染防止法の制定（1968年）、大気環境基準の設定（1969年より順次）、大気汚染物質の排出規制、全国的な大気汚染モニタリングの実施などの結果、　ア　と一酸化炭素による汚染は大幅に改善されました。

1970年代後半からは大都市地域を中心とした都市・生活型の大気汚染が問題となりました。その発生源は、工場・事業場のほか年々増加している自動車であり、特にディーゼル車から排出される　イ　や　ウ　の対策が重要な課題となり、より一層の対策の実施や国民の理解と協力が求められています。

現在においても、　イ　や炭化水素が反応を起こして発生する　エ　の環境基準達成率は低いレベルにとどまっています。対策が求められています。

1. ア：硫黄酸化物　イ：光化学オキシダント　ウ：浮遊粒子状物質　エ：二酸化炭素

2. ア：窒素酸化物　イ：光化学オキシダント　ウ：二酸化炭素　エ：浮遊粒子状物質

3. ア：硫黄酸化物　イ：窒素酸化物　ウ：浮遊粒子状物質　エ：光化学オキシダント

4. ア：窒素酸化物　イ：硫黄酸化物　ウ：二酸化炭素　エ：光化学オキシダント

5. ア：硫黄酸化物　イ：窒素酸化物　ウ：浮遊粒子状物質　エ：二酸化炭素

<summary>解答・解説</summary>

**正答：3**

- ア：1960〜1980年代の工場からの大量排出で問題となり、その後大幅に改善されたのは「硫黄酸化物（SOx）」（脱硫対策で改善）

- エ：窒素酸化物や炭化水素が光化学反応で生成するのは「光化学オキシダント」

したがって ア：硫黄酸化物・イ：窒素酸化物・ウ：浮遊粒子状物質・エ：光化学オキシダント で選択肢3。

1. ア・イ・エが誤り ❌

5. エ「二酸化炭素」が誤り ❌

## Ⅰ-5-2

環境保全、環境管理に関する次の記述のうち、最も不適切なものはどれか。

1. 我が国が提案し実施している二国間オフセット・クレジット制度とは、途上国への優れた低炭素技術等の普及や対策実施を通じて温室効果ガス排出削減・吸収などへの我が国の貢献を定量的に評価し、我が国の削減目標の達成に活用する制度である。

2. 地球温暖化防止に向けた対策は大きく緩和策と適応策に分けられる。適応策は地球温暖化の原因となる温室効果ガスの排出を抑制して地球温暖化の進行を食い止める、大気中の温室効果ガス濃度を安定させる対策のことをいう。

3. カーボンフットプリントとは、食品や日用品等について、原料調達から製造・流通・販売・使用・廃棄を通じて排出される温室効果ガス量を二酸化炭素に換算して「見える化」したものである。

4. 製品に関するライフサイクルアセスメントとは、資源の採取から製造・廃棄・輸送などの各段階を通して環境影響を定量的、客観的に評価することである。

5. 環境基本法に基づく環境基準は、大気の汚染、水質の汚濁、土壌の汚染及び騒音に係る環境上の条件について、それぞれ、人の健康を保護し、及び生活環境を保全する上で維持されることが望ましい基準である。

3. カーボンフットプリントの説明として適切 ✅
4. ライフサイクルアセスメント（LCA）の説明として適切 ✅
5. 環境基本法の環境基準（大気・水質・土壌・騒音）の説明として適切 ✅

## Ⅰ-5-4

総合エネルギー統計によれば、2017年度の我が国における一次エネルギー国内供給は20,095PJであり、その内訳は、石炭5,044PJ、石油7,831PJ、天然ガス・都市ガス4,696PJ、原子力279PJ、水力710PJ、再生可能エネルギー（水力を除く）938PJ、未活用エネルギー596PJである。ただし、石油の非エネルギー利用分の約1,600PJを含む。2017年度の我が国でのエネルギー起源二酸化炭素（CO₂）排出量に最も近い値はどれか。ただし、エネルギー起源二酸化炭素（CO₂）排出量は、燃料の燃焼で発生・排出されるCO₂であり、非エネルギー利用分は含めない。石炭24t−C／TJ、石油19t−C／TJ、天然ガス・都市ガス14t−C／TJとする。t−Cは炭素換算トン（Cの原子量12）、t−CO₂はCO₂換算トン（CO₂の分子量44）である。P（ペタ）は10の15乗、T（テラ）は10の12乗、M（メガ）は10の6乗の接頭辞である。

1. 100 Mt−CO₂

2. 300 Mt−CO₂

3. 500 Mt−CO₂

4. 1,100 Mt−CO₂

5. 1,600 Mt−CO₂

<details>
<summary>解答・解説</summary>

**正答：4**

エネルギー起源CO₂は石炭・石油・天然ガスの燃焼分から計算する。石油は非エネルギー利用分1,600PJを除く。各エネルギー量（PJ＝10³TJ）に炭素排出係数（t−C／TJ）を掛けて炭素量を求め、44/12 倍してCO₂換算する。

- 石炭：$5044\times10^3\ \text{TJ}\times24=1.211\times10^8\ \text{t−C}$
- 石油（非エネ分を除く）：$(7831-1600)\times10^3=6231\times10^3\ \text{TJ}\times19=1.184\times10^8\ \text{t−C}$
- 天然ガス・都市ガス：$4696\times10^3\ \text{TJ}\times14=0.657\times10^8\ \text{t−C}$

炭素量の合計は約 $3.05\times10^8$ t−C。これをCO₂換算すると

$$3.05\times10^8\times\frac{44}{12}\approx1.12\times10^9\ \text{t−CO}_2 = 1{,}120\ \text{Mt−CO}_2$$

最も近いのは1,100 Mt−CO₂。

2. 計算値と大きくずれ誤り ❌
3. 計算値と大きくずれ誤り ❌
4. 約1,120 Mt−CO₂ で最も近く正しい ✅
5. 計算値より大きく誤り ❌
