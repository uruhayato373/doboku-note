# 測距と測角

1級土木施工管理技士の試験では、**対回観測で消去できる誤差/できない誤差**の区別、**GNSS 観測方法の使い分け**（スタティック／RTK）、**最低衛星数**が頻出。数値暗記だけでなく、どの方法をどの場面で使うかを問う実務型の問題が年々増えている。

<Callout type="warning" title="頻出論点：測距・測角の試験ポイント">
- **対回観測で消去できる誤差**: **視準軸誤差・水平軸誤差・外心誤差**（正位 R と反位 L を平均）
- **対回観測で消去できない誤差**: **鉛直軸誤差**（整準の精度で決まる。対回観測では消えない）
- **目盛盤の偏心誤差**: 対称位置の読みの平均で消去
- **倍角差・観測差**: 1 対回内で許容範囲超え → 再観測
- **GNSS 観測方法の使い分け**
  - 基準点測量（高精度重視）→ **スタティック法**（1〜2 時間以上）
  - 工事測量（効率重視）→ **RTK 法**（数秒〜数十秒）
- **GNSS 最低衛星数**: スタティック法 = **4 衛星以上**、RTK・キネマティック・短縮スタティック = **5 衛星以上**
- **水平距離と斜距離**: TS は **斜距離** を測定 → 器械側で傾斜補正・気象補正 → **水平距離** を自動算出
</Callout>

## 測距と測角

**水平距離**とは、2点間を水平面上に投影した距離をいう。**斜距離**とは、2点間の直線距離をいう。

**水平角**とは、2方向の鉛直面がなす角を水平面上に投影した角度をいう。**鉛直角**とは、水平面と視準方向のなす角度をいい、水平面より上を仰角（＋）、下を俯角（−）という。

### 距離の測定（測距）

#### 鋼巻尺による測距

鋼巻尺を用いた距離測定では、尺定数の補正、温度補正、傾斜補正等の各種補正が必要である。

**表 5.1 鋼巻尺の許容差**

| 巻尺の長さ | 許容差 |
|:--|:--|
| 10m | ±1.0mm |
| 20m | ±1.5mm |
| 30m | ±2.0mm |
| 50m | ±2.5mm |
| 100m | ±5.0mm |

鋼巻尺で測定した斜距離 $S$ を水平距離 $D$ に補正する計算式は、以下のとおりである。

$$D = S + \frac{\Delta l}{l} S + \alpha (t - t_0) \cdot S + [C_i] + C_h + C_s$$

各変数の意味は以下のとおりである。

- $D$ — 水平距離（補正後）
- $S$ — 測定した斜距離
- $\Delta l / l$ — 尺定数補正（尺の実長と公称長の差の比）
- $\alpha$ — 鋼の線膨張係数（$\alpha = 0.0000112$ /℃）
- $t$ — 観測時の温度
- $t_0$ — 標準温度（尺の検定温度）
- $C_i$ — 傾斜補正
- $C_h$ — 気差補正（球差補正）
- $C_s$ — たるみ補正

各補正の計算式は以下のとおりである。

- 傾斜補正: $C_i = -\frac{h^2}{2L}$（$h$: 高低差、$L$: 斜距離）
- 気差補正: $C_h = -\frac{HL}{R}$（$H$: 標高、$R$: 地球の曲率半径）
- たるみ補正: $C_s = -\frac{w^2 L}{24p^2}$（$w$: 尺の単位長さ当たりの重量、$p$: 張力）

#### 光波測距儀による測距

光波測距儀は、**GaAs（ガリウム砒素）半導体レーザー**や**HeNe（ヘリウムネオン）レーザー**等の変調光を発射し、目標点に設置した**反射プリズム**で反射させ、往復に要した時間から距離を算出する機器である。

<ArticleImage
  src="/posts/civil-construction-1/textbook-surveying/img/fig-5-3.png"
  alt="図5.3 光波測距儀による距離測定の原理"
  width={1500}

/>

光波測距儀による距離の計算式は以下のとおりである。

$$L = \frac{1}{2}(n\lambda + l)$$

- $L$ — 測定距離
- $n$ — 波長の整数倍
- $\lambda$ — 変調光の波長
- $l$ — 端数距離（位相差から求める）

### 角の測定

#### セオドライトの構造概要

**セオドライト**（トランシット）は、**水平角**および**鉛直角**を測定する器械である。

<ArticleImage
  src="/posts/civil-construction-1/textbook-surveying/img/fig-5-4-photo-5-1.png"
  alt="写真5.1 セオドライトの外観と各部の名称 / 図5.4 セオドライトの構造"
  width={1900}
  height={1000}
/>

セオドライトの構造には、以下の**4軸の条件**がある。

1. **鉛直軸** — 器械の回転中心となる軸で、正しく鉛直でなければならない
2. **水平軸** — 望遠鏡を支持し、鉛直方向に回転させる軸で、鉛直軸に直角でなければならない
3. **視準軸** — 望遠鏡の光軸で、水平軸に直角でなければならない
4. **気泡管軸** — 気泡管の接線方向の軸で、鉛直軸に直角でなければならない

#### セオドライトの調整

セオドライトは、以下の3つの条件を満たすよう調整する必要がある。

1. **気泡管軸⊥鉛直軸** — 気泡管軸は鉛直軸に直角でなければならない
2. **視準軸⊥水平軸** — 視準軸は水平軸に直角でなければならない
3. **水平軸⊥鉛直軸** — 水平軸は鉛直軸に直角でなければならない

#### セオドライト使用上の留意点

1. 器械の据付けは、三脚を確実に踏み込み、**整準台**の中心が測点の直上にくるようにする
2. **整準**は、整準ねじを用いて気泡管の気泡を中央に合わせる
3. **求心**は、求心望遠鏡または下げ振りにより、鉛直軸を測点の直上に合わせる
4. 望遠鏡の**焦点合わせ**は、まず接眼レンズで十字線を明瞭にし、次に対物レンズで目標を明瞭にする
5. **視差**（パララックス）がないことを確認する。視差があると、目の位置により十字線と目標のずれが生じる
6. 観測は**正位（R）と反位**（L）の対回観測を行い、器械誤差を消去する
7. 1対回の観測における**倍角差**と**観測差**が許容範囲内であることを確認する
8. 水平角の観測は**方向観測法**または**単測法**により行う
9. 鉛直角の観測は、正位・反位の観測値の平均をとる

#### セオドライトの器械誤差

**表 5.2 セオドライトの器械誤差と消去・軽減の方法**

- **鉛直軸誤差**: 鉛直軸が正しく鉛直でないために生じる誤差 → 整準を正しく行う
- **水平軸誤差**: 水平軸が鉛直軸に直角でないために生じる誤差 → 正・反の対回観測で消去
- **視準軸誤差**: 視準軸が水平軸に直角でないために生じる誤差 → 正・反の対回観測で消去
- **目盛盤の偏心誤差**: 目盛盤の中心と回転軸が一致しないために生じる誤差 → 対称位置の読みの平均で消去
- **目盛盤の目盛誤差**: 目盛の刻みが不均一なために生じる誤差 → 各対回の始点を変えて観測
- **鉛直軸と水平目盛盤中心の不一致**: 鉛直軸と水平目盛盤の中心がずれている誤差 → 対称位置の読みの平均で消去
- **外心誤差**: 望遠鏡の視準軸が水平軸と交わらないために生じる誤差 → 正・反の対回観測で消去

#### セオドライトを用いた角観測に伴う誤差

角観測における**不定誤差**（偶然誤差）の主な要因は以下の8つである。

1. **整準の不完全** — 気泡の振動や微小なずれ
2. **求心の不完全** — 鉛直軸と測点のずれ
3. **目標の視準誤差** — 目標への照準の不完全
4. **目盛の読取り誤差** — マイクロメータ等の読取りのばらつき
5. **大気の揺らぎ（陽炎）** — 気温差による光の屈折
6. **風による振動** — 器械や三脚の微小な振動
7. **焦点合わせの不完全** — ピント合わせのずれ
8. **三脚の不安定** — 地盤の沈下や三脚の滑り

### トータルステーションによる測量

**トータルステーション**（TS）は、セオドライトと光波測距儀を一体化した器械であり、**水平角**、**鉛直角**および**斜距離**を同時に測定できる。測定データは内蔵コンピュータで処理され、水平距離、高低差、座標値等が自動計算される。

#### 距離の測定

トータルステーションによる距離の測定は、以下の手順で行う。

1. 器械を三脚に取り付け、測点上に整準・求心する
2. 目標点に反射プリズムを設置する
3. 望遠鏡で反射プリズムを視準する
4. 距離測定ボタンを押し、斜距離を測定する
5. 器械が自動的に気象補正・傾斜補正を行い、水平距離を算出する
6. データを内蔵メモリに記録する

#### 角の測定

トータルステーションによる角の測定は、以下の手順で行う。

1. 器械を三脚に取り付け、測点上に整準・求心する
2. 基準方向の目標を視準し、水平角を0°に設定する
3. 測定方向の目標を視準し、水平角を読み取る
4. 鉛直角を読み取る
5. 正位・反位の対回観測を行う
6. データを内蔵メモリに記録する

#### TS使用時の留意点

[測量法第 34 条](https://laws.e-gov.go.jp/law/324AC0000000188#Mp-At_34)に基づく「**作業規程の準則**」に定められた、TS使用時の留意点は以下の9項目である。

1. 観測は、**気象条件の良い時間帯**に行う
2. 観測中は、器械に**日傘**を使用し、直射日光を避ける
3. **気温と気圧**を測定し、気象補正を行う
4. 反射プリズムの**定数補正**を正しく設定する
5. 距離測定では、**2読定の較差**が許容範囲内であることを確認する
6. 角度測定では、**対回観測**を行い、倍角差・観測差を確認する
7. 器械高および目標高を正確に測定する
8. 観測データは、**データコレクタ**に自動記録する
9. 観測終了後、既知点による**点検測量**を行う

### GNSSによる測量

#### 概要

**GNSS**（Global Navigation Satellite System: 全球測位衛星システム）とは、人工衛星からの電波を利用して位置を求めるシステムの総称である。以下の衛星システムが運用されている。

- **GPS**（アメリカ）
- **準天頂衛星**（日本）
- **GLONASS**（ロシア）
- **Galileo**（EU）
- **北斗**（中国）
- **IRNSS**（インド）

GNSSによる測量の特徴は、以下の5つである。

1. 観測点間の**視通が不要**である
2. **天候の影響を受けにくい**（雨天・曇天でも観測可能）
3. **長距離の測量**に適している
4. **24時間**いつでも観測可能である
5. **3次元の位置**（緯度・経度・高さ）が同時に求められる

#### GNSSによる測量

GNSSによる測量には、**単独測位**と**相対測位**がある。

<ArticleImage
  src="/posts/civil-construction-1/textbook-surveying/img/fig-5-9.png"
  alt="図5.9 GNSSを利用した測量のイメージ"
  width={1800}
  height={950}
/>

**単独測位**（1 台の受信機で 4 個以上の衛星からの電波を受信して位置を求める方法）は、精度が数 m 程度のためカーナビゲーション等に用いられ、測量用途には適さない。

測量で用いるのは **相対測位**（2 台以上の受信機で同時に電波を受信して基線ベクトル＝2 点間の相対位置を求める方法）で、精度はおおむね **100 万分の 1**（10 km で 1 cm）に達する。

**表 5.3 相対測位の各方式**

- **スタティック法（静的干渉測位）**: 2 点以上で同時に長時間観測（1〜2 時間以上）→ **最高精度**、基準点測量に用いる
- **短縮スタティック法**: スタティック法の時間を短縮（20 分〜1 時間）→ 高精度
- **キネマティック法**: 固定局・移動局で同時観測し **後処理** で位置決定（数秒〜数分）→ 中精度
- **リアルタイムキネマティック法（RTK 法）**: 既知点の **固定局** から補正データを **移動局** に送信し **リアルタイム** で位置決定（数秒〜数十秒）→ 中精度、工事測量で多用
- **ネットワーク型 RTK 法**: 電子基準点網を利用した RTK（数秒〜数十秒）→ 中精度
- **VRS 方式**: 仮想基準点を用いた RTK（数秒〜数十秒）→ 中精度

**表 5.4 観測方法による使用 GNSS 衛星数**

| 観測方法 | 使用衛星数 |
|:--|:--|
| スタティック法 | 4衛星以上 |
| 短縮スタティック法 | 5衛星以上 |
| キネマティック法 | 5衛星以上 |
| RTK法 | 5衛星以上 |
