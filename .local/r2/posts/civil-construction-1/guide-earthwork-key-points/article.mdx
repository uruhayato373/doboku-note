土質試験は種類が多く、どの試験で何の値（N値・コーン指数・K値…）を求めるのかが紛らわしい——そんな不安はないでしょうか。土工は第1次検定の「土木一般」から毎年 **4〜5問** 出題される主要分野で、試験名と求める値の対応を正確に覚えていれば確実に得点できます。本ガイドでは、土質試験・土量変化率・盛土施工・軟弱地盤対策・のり面保護工という頻出の骨格を、出題の切り口に沿って整理します。

## 出題傾向と学習戦略

### 出題数と配点

土工分野は、第1次検定の「土木一般」から毎年 **4〜5問** 程度出題される主要分野です。選択問題のため、得意分野として確実に得点源にしたいところです。

### 頻出テーマ

R2〜H26 の7年度分の過去問を分析した主要テーマ別の出題頻度と優先度は次のとおり。

- **土質試験（原位置試験の名称・求められるもの・利用）**: **毎年出題** — 優先度 ★★★
- **土量変化率（L・Cの定義・計算・運搬計画への適用）**: **毎年出題** — 優先度 ★★★
- **盛土施工（締固め機械の選定・建設発生土・情報化施工）**: **毎年出題** — 優先度 ★★★
- **軟弱地盤対策（各工法の原理と適用）**: **毎年出題** — 優先度 ★★★
- **のり面保護工（植生工・構造物保護工の種類と選定）**: **隔年出題** — 優先度 ★★☆

### 学習の優先順位

効率よく得点を積み上げるための優先順位は次のとおりです。

1. まず **土量変化率** の計算を確実にする（計算問題は確実な得点源）
2. **原位置試験** の名称・求められるもの・利用の3点セットを暗記する
3. **軟弱地盤対策工法** の原理と分類を体系的に理解する
4. **盛土の締固め管理** の品質規定方式・工法規定方式の違いを理解する
5. **のり面保護工** は植生工と構造物保護工の使い分けを整理する

試験までの時期に応じて、本ピラー＋テキスト＋過去問の組合せ方を切り替えましょう。

**フェーズ 1: 概念把握期（試験 6〜3 ヶ月前）**

## 土質試験の種類と利用

土質試験は「どの試験で何を測り、その値を何に使うか」を対応づけて覚えるのが要点です。原位置試験を中心に、頻出の試験名・求める値・利用場面を整理します。

<Callout type="note" title="試験のポイント">
原位置試験の「名称」「求められるもの」「利用」の3点セットが頻出です。 特に標準貫入試験、平板載荷試験、ポータブルコーン貫入試験、ベーン試験の4つは必ず覚えておきましょう。「試験の名称」と「求められるもの」の組合せの正誤を問う形式が定番です。
</Callout>

### 主な原位置試験の一覧

出題頻度の高い原位置試験について、「求められるもの」と「試験結果の利用」を並べた一覧が次のとおり。

- **標準貫入試験**: N値 — 土の硬軟・締まり具合の判定
- **ポータブルコーン貫入試験**: コーン指数 $q_c$ — **トラフィカビリティ**の判定
- **機械式コーン貫入試験**（オランダ式二重管コーン貫入試験）: コーン指数 $q_c$ — 土の硬軟・締まり具合の判定
- **スクリューウエイト貫入試験**（旧：スウェーデン式サウンディング試験）: $W_{sw}$ および $N_{sw}$ 値 — 土の硬軟・締まり具合の判定
- **ベーン試験**: 粘着力 $c$ — 細粒土の斜面・基礎地盤の**安定計算**
- **平板載荷試験**: 地盤反力係数 $K$ — 締固めの**施工管理**
- **現場CBR試験**: CBR（支持力値） — 締固めの施工管理
- **現場透水試験**: 透水係数 $k$ — 透水関係の設計計算、地盤改良工法の設計
- **弾性波探査**: 地盤の弾性波速度 $V$ — 地層の種類・性質の推定、**リッパビリティ**の判定
- **単位体積質量試験**（砂置換法等）: 湿潤密度 $\rho_t$、乾燥密度 $\rho_d$ — 締固めの施工管理

### 暗記のコツ：よく出る引っかけパターン

試験で繰り返し問われる「求めるもの」の混同パターンを整理します。

- **ポータブルコーン貫入試験** → 求めるのは「コーン指数」で、利用は「トラフィカビリティの判定」（「N値」や「支持力の判定」ではない）
- **平板載荷試験** → 求めるのは「地盤反力係数（K値）」（「CBR」ではない）
- **ベーン試験** → 求めるのは「粘着力 $c$」（「N値」や「コーン指数」ではない）
- **弾性波探査** → 利用は「リッパビリティの判定」にも使われる

### N値と地盤の関係

N値の大小で判定される地盤の硬軟・安定性は、土質（粘性土／砂質土）別に次のとおり。

- **粘性土 — N値 0〜4**: 注意を要する**軟弱地盤**（精密な土質調査が必要）
- **粘性土 — N値 5〜14**: 安定は問題ないが**沈下の可能性**あり
- **粘性土 — N値 15以上**: 安定・沈下の対象としなくてよい
- **砂質土 — N値 0〜10**: **液状化のおそれ**あり
- **砂質土 — N値 10〜30**: 中位（中小構造物の基礎としては不十分）
- **砂質土 — N値 30以上**: 密（大構造物の基礎には50以上が望ましい）

## 土量変化率 L・C

土は地山・ほぐし・締固めの各状態で体積が変わり、その比が変化率 L・C です。定義と換算を押さえれば運搬計画や所要台数の計算問題を確実に取れます。

<Callout type="note" title="試験のポイント">
**L・Cの定義と計算問題が毎年出題。** 変化率の定義式、L/Cの換算、ダンプトラックの所要台数の算定が頻出。定義を正確に覚え、計算を確実にできるようにしましょう。
</Callout>

### 変化率の定義

土は、地山の状態・ほぐした状態・締め固めた状態で体積が異なる。

$$
L = \dfrac{\text{ほぐした土量}(\mathrm{m^3})}{\text{地山の土量}(\mathrm{m^3})}
$$

$$
C = \dfrac{\text{締固め土量}(\mathrm{m^3})}{\text{地山の土量}(\mathrm{m^3})}
$$

土量の3つの状態と、それぞれに対応する作業の関係を示す。

- **地山の土量**: 基準（= 1） — **掘削**すべき土量
- **ほぐした土量**: 地山より大きい（L > 1） — **運搬**すべき土量
- **締固め土量**: 一般に地山より小さい（C < 1） — **できあがりの盛土量**

### 変化率の一般的性質

L・C の大小関係と土質による違いは次の3点が基本です。

1. $L$ は常に1より大きい（$L = 1.1 \sim 2.0$）
2. $C$ は一般に1より小さい。ただし、**岩や固結した礫質土**では $C > 1$ となることがある
3. 岩は $L$ が大きい（$L = 1.3 \sim 2.0$）。砂は $L$ が小さい（$L = 1.1 \sim 1.2$）

### 変化率の用途

各変化率（L／C／L/C）の用途と換算式を整理します。

- **L**: **運搬計画**（ダンプトラックの台数算定） — 地山土量 × L = ほぐした土量
- **C**: **土量配分計画**（切土→盛土の換算） — 地山土量 × C = 締固め土量
- **L/C**: 盛土量（締固め後）→ ほぐした土量への換算 — 締固め土量 × L/C = ほぐした土量

### 計算例

変化率を使った代表的な2パターンを解いておきます。手順を覚えれば数値が変わっても同じ流れで解けます。

#### 例題1：土取場の掘削土量

13,000 m<sup>3</sup> の盛土に対して、切土（砂質土、C = 0.85）から 10,000 m<sup>3</sup>（地山土量）を流用し、不足分は土取場（礫質土、C = 0.90）から運搬する場合、土取場での掘削土量を求めます。

- 切土（砂質土）の盛土換算量：10,000 × 0.85 = **8,500 m<sup>3</sup>**
- 盛土の不足量：13,000 $-$ 8,500 = **4,500 m<sup>3</sup>**
- 土取場での掘削土量：4,500 $\div$ 0.90 = **5,000 m<sup>3</sup>**

#### 例題2：ダンプトラックの所要台数

7,800 m<sup>3</sup> の盛土工事で、粘性土の変化率 L = 1.2、C = 0.9、ダンプ1台の積載量 6.5 m<sup>3</sup>（ほぐし土量）のとき、所要延べ台数を求めます。締固め土量からほぐした土量へ L/C で換算してから台数を出します。

$$
\text{ほぐした土量} = 7{,}800 \times \frac{L}{C} = 7{,}800 \times \frac{1.2}{0.9} = 10{,}400 \text{ m}^3
$$

$$
\text{所要延べ台数} = 10{,}400 \div 6.5 = \textbf{1,600 \text{台}}
$$

### 土質別の変化率の目安

土質ごとのほぐし率 L と締固め率 C の代表値を示します。

| 土質 | L | C |
| --- | --- | --- |
| 硬岩 | 1.65〜2.00 | 1.30〜1.50 |
| 軟岩 | 1.30〜1.70 | 1.00〜1.30 |
| 礫 | 1.10〜1.20 | 0.85〜1.05 |
| 砂 | 1.10〜1.20 | 0.85〜0.95 |
| 砂質土 | 1.20〜1.30 | 0.85〜0.95 |
| 粘性土 | 1.20〜1.45 | 0.85〜0.95 |

## 盛土の施工

盛土は敷均し・締固めの管理が品質を左右します。締固め機械の選定、品質規定方式と工法規定方式の違い、建設発生土の区分といった管理の勘所を順に見ていきます。

<Callout type="note" title="試験のポイント">
**締固め機械の土質に応じた選定**、**品質規定方式と工法規定方式の違い**、**建設発生土の土質区分**、**TS/GNSSによる情報化施工**が頻出です。敷均し厚さ・締固め後の仕上り厚さの数値も覚えておきましょう。
</Callout>

### 敷均し・締固めの基本

盛土施工の基本事項と部位別の管理厚さは以下のとおりです。

- **高まきを避け**、水平の層に**薄く敷き均し**、均等に締め固める
- 含水比が規定の施工含水比の範囲内にあるように調節する（ばっ気乾燥、散水など）

| 部位 | 敷均し厚さ | 締固め後の仕上り厚さ |
| --- | --- | --- |
| 道路盛土 路体 | 35〜45 cm以下 | **30 cm以下** |
| 道路盛土 路床 | 25〜30 cm以下 | **20 cm以下** |
| 河川堤防 | 35〜45 cm以下 | **30 cm以下** |

### 締固め機械の選定

土質特性により適する締固め機械が変わる。

| 土質 | 適する締固め機械 |
| --- | --- |
| 岩塊（容易に細粒化しない硬岩） | **タイヤローラ** |
| 軟岩、砂質土、粘性土（細粒分適度） | **タイヤローラ（大型）**、振動ローラ、ロードローラ |
| 含水比が高くトラフィカビリティ不良の土 | **湿地型ブルドーザ** |
| 裏込め・法面（狭い箇所） | **振動コンパクタ**、**タンパ** |

### 締固め品質の規定方式

締固め管理には「品質規定方式」と「工法規定方式」の2方式があり、土質や施工条件により使い分ける。

- **品質規定方式**: 盛土に必要な品質（締固め度、空気間隙率等）を仕様書に明示し、施工方法は施工者に委ねる — 一般的な土質
- **工法規定方式**: 機種、まき出し厚さ、締固め回数など工法そのものを規定 — **岩塊・玉石**など品質規定が困難な場合

#### 品質規定方式の3つの方法

品質規定方式は規定する指標により 3 種類に分かれ、適する土質が異なる。

| 方法 | 規定する指標 | 適する土質 |
| --- | --- | --- |
| 1) 乾燥密度で規定 | 締固め度 $D_c$ | **砂質土、礫質土**（最も一般的） |
| 2) 空気間隙率・飽和度で規定 | $V_a$、$S_r$ | **高含水比の粘性土、シルト** |
| 3) 強度特性で規定 | CBR、地盤反力係数 $K$ 等 | **岩塊、玉石、礫、砂** |

$$
\text{締固め度} D_c = \frac{\rho_d}{\rho_{d\max}} \times 100 \text{ (\%)}
$$

#### 日常管理の基準値の目安

日常の締固め管理で用いられる基準値（締固め度 $D_c$、空気間隙率 $V_a$）を部位・土質別に整理します。砂質土は $D_c$、粘性土は $V_a$ で管理するのが原則です。

- **路体 — 砂質土**: 締固め度 $D_c$ **90%以上**（空気間隙率 $V_a$ の規定なし）
- **路体 — 粘性土**: 空気間隙率 $V_a$ **10%以下**（締固め度 $D_c$ の規定なし）
- **路床 — 砂質土**: 締固め度 $D_c$ **95%以上**（空気間隙率 $V_a$ の規定なし）
- **路床 — 粘性土**: 空気間隙率 $V_a$ **8%以下**（締固め度 $D_c$ の規定なし）

### 情報化施工

TS・GNSS を用いた締固め管理の要点は以下のとおり。

- **TS（トータルステーション）** を用いた締固め管理 → 締固め機械とTSが **1対1** の組合せ
- **GNSS** を用いた締固め管理 → **複数台の締固め機械に対して基準局を兼用**できる
- 品質の均一化、**過転圧の防止**、工程短縮が図られる
- 高含水比の粘性土や鋭敏比の大きい土は、締固め回数管理に**適さない**

### 建設発生土の土質区分

建設発生土は、コーン指数 $q_c$ により第1種〜第4種・泥土の5区分に分類され、盛土利用の可否が決まる。

- **第1種（砂、礫）**: コーン指数 $q_c$ の規定なし — そのまま利用可能
- **第2種（砂質土、礫質土）**: $q_c$ 800 kN/m<sup>2</sup> 以上 — そのまま利用可能
- **第3種（通常の粘性土）**: $q_c$ 400 kN/m<sup>2</sup> 以上 — そのまま利用可能
- **第4種（粘性土）**: $q_c$ 200 kN/m<sup>2</sup> 以上 — 土質改良で利用可能
- **泥土**: $q_c$ 200 kN/m<sup>2</sup> 未満 — 改良必要またはそのまま利用不可

### 盛土材料の要件

盛土材料として要求される一般的性質：

1. 施工機械の**トラフィカビリティ**が確保できること
2. 所定の**締固め**が行いやすいこと
3. せん断強さが大きく、圧縮性（沈下量）が小さいこと
4. **有機物**を含まないこと
5. 吸水による**膨潤性**が低いこと

使用できない材料の例：ベントナイト、温泉余土、凍土、腐植土など

## 軟弱地盤対策工法

軟弱地盤対策は、圧密・排水／締固め／固結などの原理別に多数の工法があります。原理と代表工法の対応を体系立てて覚えるのが得点の近道です。

<Callout type="note" title="試験のポイント">
**各工法の「原理」と「代表的な工法名」の組合せが頻出です。** 特に、圧密・排水工法（バーチカルドレーン工法、盛土載荷重工法）、締固め工法（サンドコンパクションパイル工法）、固結工法（深層混合処理工法）の4つは必ず覚えておきましょう。液状化対策の出題も増加傾向にあります。
</Callout>

### 軟弱地盤の定義

軟弱地盤は、土質により大きく2種類に分類できる。

1. **粘性土や有機質土**からなる、含水量の極めて大きい軟弱な地盤
2. **砂質土**からなる、緩い飽和状態の軟弱な地盤

### 対策工法の分類と代表工法

軟弱地盤対策は原理別に7分類され、それぞれ代表工法と覚え方のポイントを整理します。試験では「原理」と「工法名」の組合せが頻出です。

- **圧密・排水**: サンドドレーン工法、ペーパードレーン工法、盛土載荷重工法、緩速載荷工法、真空圧密工法 — 排水距離を短縮して圧密を促進
- **締固め**: **サンドコンパクションパイル工法**、振動棒工法、バイブロフローテーション工法 — 振動や圧入で密度を増加
- **固結**: **深層混合処理工法**、表層混合処理工法、石灰パイル工法、薬液注入工法 — セメント等で固結させる
- **掘削置換**: 掘削置換工法 — 軟弱土を良質土に置き換え
- **間隙水圧消散**: グラベルドレーン工法 — 液状化対策として排水柱を設置
- **荷重軽減**: **軽量盛土工法**（EPSブロック工法）、カルバート工法 — 軽い材料で荷重を軽減
- **盛土補強**: 押え盛土工法、ジオテキスタイル補強 — 側方変位を抑制

### 主要工法の詳細

#### バーチカルドレーン工法

排水距離を短縮して圧密を促進する工法で、代表的なものを以下に示す。

- **原理：** 圧密に要する時間は**排水距離の2乗に比例**する。軟弱地盤中に鉛直の排水路を設け、排水距離を短縮して圧密を促進する
- **サンドドレーン工法：** 透水性の高い**砂**を用いた砂柱を打設
- **ペーパードレーン工法（PVD工法）：** ペーパーやプラスチック製のドレーン材を使用。施工速度が速く経済的

#### 盛土載荷重工法

盛土荷重で圧密を促進する2方式。

- **プレローディング工法：** 将来の荷重と同等以上の荷重を盛土で載荷し、圧密沈下を促進。その後除去して構造物を構築
- **サーチャージ（余盛り）工法：** 計画荷重以上を載荷して放置後、余盛り分を除去する

#### サンドコンパクションパイル工法

砂杭の造成により地盤を密度増加させる工法で、地盤種別ごとの効果を以下に示す。

- **原理：** 振動・衝撃で砂を打ち込み、密度の高い**砂杭**を造成
- **砂地盤：** 間隙比を減少させ密度増加 → **液状化対策**に有効
- **粘性土地盤：** 砂杭と粘性土の**複合地盤**として機能。砂杭が排水路の役割も果たす

#### 深層混合処理工法

固化材で地盤を改良する工法で、原理と種類を以下に示す。

- **原理：** セメント系固化材を地中で軟弱土と強制混合し、**円柱状の改良体**を造成
- **機械撹拌工法** と **高圧噴射撹拌工法** がある
- すべり抵抗の増加、沈下量の低減、液状化対策に効果

#### 押え盛土工法

本工法の適用条件と施工上の留意点は次のとおりです。

- 本体盛土の側方に盛土して、すべりに対する**抵抗を増加**させる
- 押え盛土は本体盛土より**先に**または**同時に**施工する（後からでは効果がない）
- 余分な**用地と土砂**が必要

#### 軽量盛土工法

EPSブロックを用いる場合の特性と留意点を整理します。

- **EPSブロック**の単位体積重量は **0.1〜0.3 kN/m<sup>3</sup>**（土砂の1/50〜1/100）
- 地下水位が高い場所では**浮き上がり**の検討が必要

### 液状化とその対策

**液状化**とは、地震時に間隙水圧が上昇して有効応力が減少し、飽和砂質土がせん断強さを失う現象。N値10以下の飽和砂地盤で発生リスクが高い。

| 対策の原理 | 工法例 |
| --- | --- |
| 過剰間隙水圧を上昇させない | 密度増加（SCP）、良質土への置換、地下水位低下 |
| 発生した過剰間隙水圧を速やかに消散 | **グラベルドレーン工法** |
| 砂粒子間のずれ変位を防ぐ | 薬液注入・固化 |
| 地盤の残留変形を拘束 | 地中連続壁、シートパイル |

## のり面保護工

のり面保護工は植生工・構造物保護工・法面排水工の3分類で整理します。工法の目的と適用条件、特に植生工と構造物保護工の使い分けが問われます。

<Callout type="note" title="試験のポイント">
**植生工と構造物保護工の使い分け**、各工法の目的と適用条件が出題されます。特に「植生工の種類と特徴」の正誤問題、「法面排水工」との組合せ問題に注意しましょう。
</Callout>

### 法面保護工の分類

法面保護工は植生工・構造物保護工・法面排水工の 3 大分類に整理できます。

| 分類 | 主な工法 |
| --- | --- |
| **植生工** | 種子散布工、客土吹付工、植生基材吹付工、張芝工、植生マット工、筋芝工、植生土のう工、植栽工 |
| **構造物保護工** | 編柵工、じゃかご工、プレキャスト枠工、モルタル・コンクリート吹付工、石張工・ブロック張工、吹付枠工、現場打ちコンクリート枠工、擁壁工、補強土工、グラウンドアンカー工 |
| **法面排水工** | 表面排水工（法肩排水溝、小段排水溝、縦排水溝）、地下排水工（地下排水溝、水平排水孔） |

### 植生工の選定と留意点

植生工を採用する際の主な基準と各工法の特徴は以下のとおりです。

- 法面勾配は **1:0.8 より緩やか** にする（急勾配では活着が悪い）
- 寒冷地の凍上対策では **1:1.5 より緩やか** にする
- 播種の適期は **春・秋**
- **客土吹付工** → 切土法面に適し、急勾配でも施工可能
- **張芝工** → 完成と同時に保護効果が出る
- **植生土のう工** → 不良土、硬質土法面に適する

### 構造物保護工の選定

現場条件（風化・湧水・落石リスク等）により適する工法を選定します。

| 条件 | 適する工法 |
| --- | --- |
| 風化が進行する岩法面 | モルタル・コンクリート吹付工 |
| 湧水のある法面 | **法枠工**（吹付工は不適）、じゃかご工 |
| 大きな落石のおそれ | グラウンドアンカー工 |
| 土圧・滑動力に対抗 | グラウンドアンカー工、補強土工（**抑止力**） |
| 侵食防止・表層すべり防止 | 編柵工、プレキャスト枠工（**抑制力**） |

<Callout type="warn" title="抑止力と抑制力の違い">
- **抑止力**：土圧や滑動力に**直接対抗**する工法（グラウンドアンカー工、補強土工、擁壁工）
- **抑制力**：風化・侵食を防止し、法面の安定を**間接的に確保**する工法（植生工、編柵工、吹付工等）
</Callout>

### 法面排水工

表面排水工と地下排水工の種類と留意点を整理します。

- **表面排水工：** 法肩排水溝、小段排水溝、縦排水溝で表面水を法面外に導く
- **地下排水工：** 地下排水溝（砂利・粗砂を詰めた溝）、水平排水孔（湧水のある法面に有効）
- 高含水比粘性土の高盛土では **水平排水層**（砂の厚さ20〜30 cm）を設ける

## 合格者視点のコラム

土工は 1 級土木の中で **最も得点源化しやすい分野**。理由は 3 つあります。第 1 に、出題テーマが過去 7 年でほぼ固定されており、土量変化率・原位置試験・軟弱地盤・のり面の 4 領域を押さえれば毎年 4〜5 問のうち 3〜4 問は確実に取れます。第 2 に、計算問題（土量変化率・所要台数）は手順が定型化しており、暗記より演習が効く。第 3 に、用語の引っかけパターン（「コーン指数 vs N 値」「平板載荷の K 値 vs CBR」）が固定化されているので、本ピラー「暗記のコツ」セクションを直前に見直すだけで取りこぼしを防げます。

第 2 次（記述式）では、土工は **経験記述の素材として最頻出** です。盛土施工の品質管理・軟弱地盤対策の安全管理・建設発生土のリサイクルなど、4 大管理（品質・工程・原価・安全）の **どの軸で書くか** によって採点で差がつきます。直前期は [経験記述ガイド](/docs/civil-construction-1-secondary-experience-writing-guide) と [経験記述例](/docs/civil-construction-1-secondary-experience-writing-examples) で型を作りましょう。
