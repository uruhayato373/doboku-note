## 3. 基礎解説

### 3.1 盛土の締固めの管理

#### 3.1.1 締固めの目的

良質な土をローラなどの締固め機械で締め固めると、土は圧縮され、破砕されながら配列を変え大きな粒子の間隙をより細かい粒子が埋めて**密な状態**に移行する。こうした高密度に締め固められた土は、外部からの水浸の影響を受けにくくなり、**安定した状態**を保つことができる。

最適含水比で**最大乾燥密度**に締め固められた土は、その締固め条件のもとで間隙が最小となっている。土を締め固める目的を以下に示す。

1. 土の空気間隙を少なくして透水性を低下させ、水の浸入による軟化、膨張を小さくして、土を**最も安定した状態**にする。
2. 盛土のり面の安定、荷重に対する支持力など、盛土として必要な**強度特性**を持たせる。
3. 盛土完成後の圧密沈下など、**変形**を少なくする。

#### 3.1.2 締固め品質の規定

締固めは、重要な作業であり、盛土の施工にあたっては、締固めの程度、締固め時の含水比、施工層厚など締固めに関する仕様を定め、これに沿った施工が行われているかどうかを管理する必要がある。

締固めの品質を規定する方法は、大別すると、品質規定方式と工法規定方式になる。いずれの方法によるかは、それぞれの規定方式をよく理解し、盛土の構造物としての重要度、規模、土質条件など、現場の状況に適した規定方式を採用する。

##### （1） 品質規定方式

品質規定方式は、盛土に必要な**品質**を仕様書に明示し、締固め方法については**施工者にゆだねる方式**である。

###### 1） 乾燥密度で規定する方法

**① 規定の概要**

室内での締固め試験で得られた最大乾燥密度と現場の締め固められた土の乾燥密度の比を**締固め度**と呼び、この数値が規定値以上になっていること、施工含水比がその**最適含水比**を基準として規定された範囲内にあることを要求する方法である。

土の現場測定は、一般に、①砂置換による土の密度試験方法、② RI 計器による方法が用いられている。

$$
\text{締固め度} = \frac{\text{現場における締固め後の乾燥密度}（\rho_d）}{\text{基準となる室内締固め試験における最大乾燥密度}（\rho_{d\text{max}}）} \times 100 \text{ (%)}
$$

盛土が将来水浸されるおそれが少なく、しかも高い強度を要求する場合は、最適含水比よりやや乾燥側で、水の浸入を受けても安定を期待したい道路盛土などの場合は、最適含水比における施工が最も望ましい（**図5.1**）。

{/* 図5.1 乾燥密度で規定する方法（締固め曲線） */}

**② 適用される土質**

乾燥密度で規定する方法は、最も一般的な方法で、特に自然含水比の比較的低い**良質土**（砂質土、レキ質土）に適する方法である。自然含水比の大きい粘性土などでは、**こね返し**により強度低下（オーバーコンパクション）をきたし、基準となる最大乾燥密度が定められない。

###### 2） 空気間げき率または飽和度を施工含水比で規定する方法

**① 規定の概要**

締め固めた土が安定な状態である条件として、**空気間げき率**または**飽和度**が一定の範囲内にあるように規定し、一方締め固めた土の強度、変形特性が設計を満足する範囲に施工含水比を規定する方法である。

{/* 図5.2 最適領域の説明 */}

**② 適用される土質**

乾燥密度により規定するのが困難な、自然含水比が高い**シルト**または**粘性土**に適用される例が多い。

このような場合には、施工含水比の規定としては、その上限の含水比をトラフィカビリティや、設計上要求される力学的性質を満足し得る限界で定めるのが一般的である。

**図5.2** に示すように、同じ土に対しても突固めエネルギーを変えると異なった締固め曲線が得られるが、その各々の最大乾燥密度の状態を含め、土が最も安定した状態がその範囲に存在している。

###### 3） 強度特性、変形特性で規定する方法

**① 規定の概要**

締め固めた土の**強度特性**は、土粒子あるいは土粒子構造間の水分の量によって変化するが、**図5.3** に示すように、締固め直後の状態では最適含水比よりやや低い含水比のときに、強度、変形抵抗は最大で、圧縮性が最小となることが知られている。しかし、乾燥側で締め固めた土に水が浸水すると、締固めが不十分な場合には、相対的に大きな空気間隙を残しているため強度は低下し、上載荷重による沈下を生じることもある。

{/* 図5.3 土の締固めと強度の関係（模式図） */}

この方法は、締め固めた盛土の強度あるいは**変形特性**を現場 CBR、地盤反力係数、貫入抵抗、プルーフローリングによるたわみ等により規定する方法である。締固めを規定する値が盛土に要求される力学的性質を直接示すと考えられるところに特徴があり、測定が比較的容易で迅速に行えるなどの長所がある。

**② 適用される土質**

水の浸入により膨張、強度低下などの起こりにくい安定した盛土材料、すなわち岩塊、玉石、礫、砂、砂質土などに適し、特に乾燥密度の測定が困難な岩塊、玉石には便利な方法である。

#### 5） 工法規定方式

**1) 試験施工と工法規定**

試験施工は、品質規定方式と工法規定方式のいずれの場合にも、使用する土質材料、締固め機械の機種、まき出し厚、締固め回数および施工含水比の範囲を事前に確認するために行う。工法規定方式は、試験施工により決定された工法（工種、まき出し厚、締固め回数等）の規定を現場で確実に遵守するものである。

工法規定方式の管理項目には、次のものがある。

- 敷き均し厚さと仕上がり厚さの関係
- 締固め機種と締固め回数と締固め度の関係
- 含水量の適否
- 基礎工の排水状況の良否 など

施工に先立ち材料、機種、まき出し厚、締固め回数と盛土の品質の関係を試験施工によって確認する試験盤を設ける。試験盤では、盛土の締固めに不足する場合の含量材料の補給を含む配合の割合の確認や品質特性に基づく施工含水比の範囲（すなわち適切な含水量をまとめる管理図等を用いた品質管理の方法を含む）を確認するとともに、工法（施工機械の機種、まき出し厚、締固め回数等）の確認と日常管理方法を決定する。

盛土は、材料を均一にまき出し、正確に締固め、土工管理の密度と含水比、沈下量の小さな盛土を造成できるよう管理する。情報化施工の活用により、日常管理の効率化と管理の品質向上を図ることも重要である。

**2) 情報化施工（工法規定方式の管理手法）**

建設機械の走行位置を GNSS（全地球測位衛星システム）や TS（トータルステーション）により計測し、走行軌跡を記録することにより締固め回数の管理を行うものであり、盛土の締固めの管理を効率的に行うことが可能である。

TS や GNSS を搭載した管理システムを用いて盛土転圧管理を行うにあたっては、まず目標の管理値（まき出し厚、締固め層厚、締固め回数）を試験施工により定める必要がある。試験施工は、実際の工事に先立ち、情報化施工を試行して定められた工法を遵守することにより、目的とする品質を確保するために実施する。

上記を実施するために、事前に適切な方法を選定したうえで、試験施工を実施し、適正な管理値を定める。施工管理のための重要な事項を試験施工によって確認するのであるから、試験施工は慎重に行い、結果は必ず記録として残す。

TS・GNSS を用いた盛土の締固め管理には、規定回数だけ転圧されたことを面的に把握でき、転圧の過不足を防ぐことが可能であること、計測作業の大幅な省力化が可能であること、面的に精度の高い施工が可能であること、データの電子化により施工管理帳票の整理・保管が効率化されること、一般にモニターにて確認するため作業者の技量によらず安定した品質を確保することが可能であるなどのメリットがある。

希望する仕上り面の設計データを入力し、TS や GNSS を用いた締固め管理面（まき出し面）での面的な管理をリアルタイムに把握でき、目視により判断されていた各種管理項目を座標データにより数値化することで、施工品質のトレーサビリティを容易に確保することができる。

希望する仕上り面の設計データと TS による測定値を比較すると、まき出し厚が部分的に薄かったり厚かったりすることがある。この場合の修正要領としては、まき出し厚が薄いところでは、不足分の土を補充し、まき出し厚が厚いところでは余分な土を取り除く。まき出し厚が不均一な部分は再度まき出しを行い、規定のまき出し厚に整形する。

TS や GNSS を用いた盛土の品質管理では、面的な管理が可能であり、日常管理のとりまとめにあたっても、TS を用いた場合は TS からの情報としてまき出し厚の管理、締固め回数の管理のデータを使用し、GNSS を用いた場合は GNSS からの情報として締固め回数のデータを使用する。

TS や GNSS を用いた品質管理では工法規定方式に従い盛土施工を行い、盛土の締固めの管理基準を目標値に設定し転圧を行う。

### 3.2 コンクリート工の品質管理

完成したコンクリート構造物が所要の性能を有することが確認できるように、合理的かつ経済的な検査計画を立て、工事の各段階で必要な検査を行い、確認する。検査としては「検査」は、製造、施工、配合、完成時の検査を行うのが一般的である。

検査の一般的な手順は次のとおりとなっている。

1. 材料の品質の検査
2. 計画に基づく施工の確認
3. 製品の品質の検査（でき形寸法の検査、位置の検査、強度の検査、仕上がり検査）
4. 構造物の完成の検査

#### 3.2.1 検査計画

検査計画の立案に際しては、検査する項目の選定、必要な人員配置、試験・検査方法の選定、試験・検査頻度の設定についてそれぞれ検討する。試験・検査の頻度は検査・検査結果の信頼度によって決まり、頻度が多いほど信頼性は高くなる。検査項目の設定にあたっては、工事の規模と工期を考慮したうえで、一般的な工事に対して必要な項目を設定するとともに、特殊な構造形式や材料、施工方法の構造物に対しては、特別な品質管理を行うための検査項目を追加する。

検査の種類は、一般に、次のとおりとする。

1. 不良品が施工工程に混入されることを防止する入口の検査

##### （2） 空気量試験

フレッシュコンクリートでは、同じコンクリート材料を用い、同じ配合のコンクリートで作業を進めている場合でも、骨材の粒度、気温などが変化すると空気量が相当変わることがある。**空気量の変動**は、コンクリートのワーカビリティー、強度および耐久性などに影響を与える。そのため、フレッシュコンクリートを用いる場合には、空気量が適切かどうかを確かめるために、試験を行う。

| 軽量コンクリート | 5.0 | $\pm 1.5$ |
| 舗装コンクリート | 4.5 | $\pm 1.5$ |

##### （3） 塩化物含有量試験

特に、鋼材腐食の点に対する塩化物による影響を考え、鋼材腐食性能に対する塩化物含有量を検査する。

コンクリートに含まれる塩化物含有量は、原則として塩化物イオンとして、0.30 kg/m³ 以下とする。ただし、購入者の承認を受けた場合は、0.60 kg/m³ 以下とすることができる。

コンクリート中の塩化物含有量の試験は、JIS A 1144 に基づくもので行うことを原則とし、フレッシュコンクリートから塩化物含有量を測る方法によるのが一般的であるが、この場合は、使用する測定器の精度を事前に確認しておくことが大切である。

##### （4） 単位水量試験

コンクリートの運搬中は、コンクリートを分離させないように注意しなければならない。特に乾燥してはならない。

コンクリートの所定の品質が確保されるように、単位水量試験で確認する。

##### （5） 圧縮強度試験

圧縮強度試験は、コンクリートの強度を確認するための試験であり、検査の中でも最も重要で基本的な試験である。試験の要点は次のとおりである。

**表5.10 レディーミクストコンクリートの単位水量試験**

| 項目 | 内容 |
|---|---|
| 測定方法 | 静電容量法、エアメータ法、乾燥炉法（電子レンジ法含む）等 |
| 測定頻度 | コンクリートの打込み日ごと、かつ午前・午後の少なくとも1回ずつ |
| 管理値 | 単位水量は、管理値を超えた場合（管理値はコンクリート配合設計時の単位水量に対して $\pm$ 15 kg/m³ 又は $\pm$ 20 kg/m³ に設定されることが多い）は、その原因を調査し、対策を講じた後に再試験を行い、管理値の範囲内にあることを確認する |

##### （6） 強度試験

強度の検査は、コンクリートの配合を確認するとともに強度を確認するために行う。配合条件を判定し、配合の良い場合は、JIS A 1108 の方法に従って、圧縮強度試験を行って確認することが必要であるが、現在では圧縮試験を行うことが標準的である。

JIS A 5308「レディーミクストコンクリート」に基づいて行う。

試験回数は、普通コンクリートは普通エコセメントを使用するコンクリートでは、150 m³ ごとに又はその端数について1回、その他のコンクリートについては 100 m³ ごとに又はその端数について1回行う。

1回の試験の結果は、購入者が指定した呼び強度の値の 85 % 以上、

3回の試験結果の平均値は、購入者が指定した呼び強度の値以上。

1回の試験結果とは、適当な間隔をおいた3台の運搬車から1個ずつ、合計3個の供試体（1組の供試体ともいう）の試験値の平均値とする。

3回の試験結果の平均値は、3組の供試体の各1回の試験結果の平均値とする。

{/* 図5.6 強度試験の合否判定 */}

$$
\text{判定基準：} \quad \bar{x} \geq \text{呼び強度の値の} 85\% \text{ 以上}
$$

$$
\text{平均値} = \frac{\bar{x}_1 + \bar{x}_2 + \bar{x}_3}{3} \geq \text{呼び強度の値以上}
$$

**表5.11 圧縮強度試験の合否判定例**

| 判定回 | 1回の試験結果 | 3回の試験結果の平均値 |
|---|---|---|
| 呼び強度の指定値 | $f_q = 24$ N/mm² | $f_q = 24$ N/mm² |
| 判定基準 | $\geq f_q \times 0.85 = 20.4$ | $\geq f_q = 24$ |
| 1回目 | 25.2 | - |
| 2回目 | 23 | - |
| 3回目 | 17 | $(25.2+23+17)/3=21.7$ |
| 判定 | 3回目 $17 < 20.4$（不合格） | $21.7 < 24$（不合格） |
| 対応 | $\times$ 2点不合格 = 不合格 |

（注） $\times$ 2＝不合格＝$\times$ 2

##### （1） 表面状態の検査

表面状態の検査としては、欠陥、空洞、すき間等の程度を取り定めたうえで、検査項目を **表5.14** のように設定して行う。

| ひび割れ | ひび割れの位置、長さ、幅などを調査し記録する |

##### （2） 非破壊検査

コンクリート構造物の設計どおりの性能を有しているかどうかの適判検査で、立面・内部等を直接目視する適判検査が困難な場合の非破壊検査を行う。また、コンクリート構造物の補修・補強計画に必要な現状の把握のための情報収集にあたっては、ひび割れ等の測定が必要となる場合があり、その方法としては非破壊検査がある。

**表5.15 コンクリート構造物の非破壊検査の種類**

| 区分 | 検査方法 | 検査概要 |
|---|---|---|
| 強度推定 | テストハンマー（反発度法、リバウンドハンマー法） | コンクリート表面の反発度から圧縮強度を推定する。JIS A 1155 |
| | コア採取による圧縮強度試験 | 構造物からコアを採取して圧縮強度を直接測定する |
| 内部探査 | 電磁波レーダ法 | 電磁波の反射により内部の鉄筋やかぶり等を探査 |
| | 電磁誘導法 | 電磁誘導により鉄筋の位置やかぶりを測定 |
| | X線透過法 | X線により内部の鉄筋や空洞を透過撮影 |
| | 超音波法 | 超音波の伝搬速度からひび割れ深さ等を推定 |
| | 赤外線法 | 赤外線サーモグラフィにより表面温度分布からはく離等を検出 |
| | 自然電位法 | 鉄筋の腐食状態を自然電位により測定 |
| ひび割れ | クラックスケール | ひび割れ幅をスケールにより目視測定 |
| | 超音波法 | 超音波の伝搬時間によりひび割れ深さを推定 |

- コンクリートの簡易な強度推定には、**テストハンマー（リバウンドハンマー、シュミットハンマー）** が用いられる。
- コアの抜取り：構造物の種類、大きさ及び部材の断面寸法に応じ、径 100 mm 以上又は粗骨材の最大寸法の3倍以上のうち大きい方の径の供試体を標準とし、高さ直径比は、1.00（径 100 mm 以上）を標準とする。抜き取ったコアは、径 100 mm 又は 150 mm のコアによる強度を用い、径 100 mm 又は 150 mm 以外のコアの場合は径の違いの影響を考慮する。

##### テストハンマーによる強度推定の方法

1. 測定面の選定
   - a） コンクリートの材齢は、原則として 28 日以上 1 年以下とする。ただし、材齢の小さいコンクリートの場合は、型枠取り外し後、直ちに測定することが望ましい。
   - b） 測定面のコンクリートの厚さは 100 mm 以上とする。
   - c） 測定面は乾燥した状態にある平たんな面とする。
   - d） 測定箇所は、露出砂利などの部分および表面はく離、凹凸のある部分を避ける。
2. ハンマの角度
   - a） ハンマの打撃方向は、測定面に直角とする。
   - b） ハンマの先端は、測定面に強く押しつけてから打撃する。
3. コンクリート表面の処理
   - a） 測定面にある凹凸や付着物は、研磨処理装置などで平滑に磨いて取り除き、コンクリート表面の粉末その他の付着物を拭き取ってから測定する。
   - b） 測定面に仕上げ層や上塗り層がある場合には、これを除きコンクリート面を露出させた後、上記の処理を行ってから測定する。
4. 測定方法
   - a） 測定は、環境温度が 0 ～ 40 ℃ の範囲内で行う。
   - b） ハンマの作動を円滑にさせるため、測定に先立ち数回の試し打撃を行う。
   - c） ハンマが測定面に常に垂直方向になるよう保持し、ゆっくり押して打撃する。
   - d） 一か所の測定では、互いに 25 ～ 50 mm の間隔をもった9点について測定する。
   - e） 測定後のリバウンドハンマの点検によって、リバウンドハンマの反発度が製造時の反発度より 3 % 以上異なっていたら、直前に行った点検以後の測定値は用いてはならない。
