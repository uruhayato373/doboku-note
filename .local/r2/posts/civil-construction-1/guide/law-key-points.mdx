## 1. 出題傾向と選択戦略

### 出題形式

問題A No.50〜61 の **12問** から **8問を選択** して解答する。各法規から1〜2問ずつ出題される。

### 出題法規と頻出テーマ

| 法規 | 出題数（目安） | 頻出テーマ |
|---|:---:|---|
| 労働基準法 | 1〜2問 | 労働時間、年少者・女性の就業制限 |
| 労働安全衛生法 | 2〜3問 | 安全管理体制、特定元方事業者の義務、作業主任者、計画届 |
| 建設業法 | 1〜2問 | 主任技術者・監理技術者の配置、建設業の許可 |
| 道路法 | 1問 | 道路占用許可、車両制限令 |
| 河川法 | 1問 | 河川区域の行為許可 |
| 建築基準法 | 1問 | 確認申請、仮設建築物 |
| 火薬類取締法 | 1問 | 火薬の貯蔵・取扱い |
| 港則法 | 1問 | 港内での作業許可 |
| 騒音規制法・振動規制法 | 1問 | 特定建設作業の届出・規制基準 |

### 選択戦略

:::tip[得点戦略]
12問中8問を選択できるため、**得意な法規を確実に得点する**ことが重要である。

1. **労働安全衛生法**（2〜3問）と**建設業法**（1〜2問）は出題数が多く、施工管理の学習内容と重複するため最優先で学習する
2. **騒音・振動規制法**、**道路法**、**河川法**は数値の暗記で対応しやすく、コストパフォーマンスが高い
3. 苦手な法規が1〜2つあっても、残りで8問を確保できるので、全法規を均等に学習する必要はない
:::

## 2. 法規別の重要ポイント

### 2.1 労働基準法

:::note[試験のポイント]
労働時間・休憩時間・休日の具体的な数値、年少者（18歳未満）の就業制限、解雇予告の日数が頻出。数値の正誤を問う問題が多い。
:::

#### 労働時間・休憩・休日

| 項目 | 基準 |
|---|---|
| 労働時間 | 休憩時間を除き **1週40時間**、**1日8時間** 以内 |
| 休憩時間 | 6時間超 → **45分以上**、8時間超 → **1時間以上** |
| 休日 | **週1日以上**、または4週間を通じ **4日以上** |
| 時間外労働の上限 | 月 **100時間未満**、年 **720時間** 以内 |

#### 割増賃金

| 区分 | 割増率 |
|---|---|
| 時間外労働 | **2割5分以上** |
| 深夜労働（22時〜5時） | **2割5分以上** |
| 休日労働 | **3割5分以上** |
| 月60時間超の時間外労働 | **5割以上** |

#### 解雇の制限と予告

- 業務上の負傷・疾病で休業中およびその後 **30日間** は解雇不可
- 解雇は少なくとも **30日前** に予告するか、**予告手当**（平均賃金の30日分以上）を支払う
- 打切補償（平均賃金の **1,200日分**）を支払えば解雇制限が解除される

#### 年少者（18歳未満）の就業制限

- **坑内労働** の禁止
- **深夜業**（午後10時〜午前5時）の禁止（交替制の満16歳以上男性を除く）
- クレーン・デリックの運転、土木建築用機械の運転の禁止
- 高さ **5m以上** の箇所で墜落のおそれがある業務の禁止
- 足場の組立て・解体・変更の禁止（地上・床上の補助作業を除く）
- 土砂崩壊のおそれがある場所・深さ **5m以上** の地穴の業務の禁止

#### 災害補償

| 補償の種類 | 金額 |
|---|---|
| 休業補償 | 平均賃金の **60%** |
| 遺族補償 | 平均賃金の **1,000日分** |
| 打切補償 | 平均賃金の **1,200日分**（療養開始後 **3年** 経過） |

### 2.2 労働安全衛生法

:::note[試験のポイント]
安全管理体制の選任要件（人数の閾値）、特定元方事業者の義務、作業主任者を選任すべき作業の種類、計画届の届出先と期限が頻出。体系的に整理して数値を押さえる。
:::

#### 安全衛生管理組織（事業場単位）

| 管理者 | 選任要件（建設業） |
|---|---|
| 総括安全衛生管理者 | 常時 **100人以上** |
| 安全管理者 | 常時 **50人以上** |
| 衛生管理者 | 常時 **50人以上** |

#### 下請混在現場の管理組織

| 管理者 | 選任要件 |
|---|---|
| 統括安全衛生責任者 | 全労働者数が常時 **50人以上**（ずい道・橋梁・圧気工法は **30人以上**） |
| 元方安全衛生管理者 | 統括安全衛生責任者を選任した事業所（専属） |
| 安全衛生責任者 | 統括安全衛生責任者を選任すべき事業者**以外の**請負人 |

#### 特定元方事業者の義務（6つの主要措置）

1. すべての関係請負人が参加する **協議組織の設置**、定期的な会議の開催
2. 関係請負人との間および相互間の **連絡・調整**
3. 毎作業日に少なくとも **1回** の作業場所の **巡視**
4. 関係請負人が行う安全衛生 **教育への指導・援助**
5. 仕事の工程・機械設備配置に関する **計画の作成**
6. クレーン等の運転に関する **合図の統一**

#### 作業主任者の選任が必要な作業（建設業の主なもの）

- 掘削面の高さが **2m以上** となる地山の掘削
- 土止め支保工の切りばり・腹起しの取付け・取外し
- ずい道等の掘削、覆工
- 型枠支保工の組立て・解体
- つり足場・張出し足場、高さ **5m以上** の足場の組立て・解体・変更
- 高さ **5m** または支間 **30m以上** の橋梁上部構造の架設・解体・変更
- 高さ **5m以上** のコンクリート造工作物の解体・破壊
- 酸素欠乏危険場所における作業

#### 計画の届出

| 届出先 | 届出期限 | 対象となる仕事 |
|---|---|---|
| **厚生労働大臣** | 開始の **30日前** | 高さ300m以上の塔、堤高150m以上のダム、最大支間500m以上（つり橋1,000m以上）の橋梁、長さ3,000m以上のずい道 |
| **労働基準監督署長** | 開始の **14日前** | 最大支間50m以上の橋梁、ずい道等、掘削高さ・深さ10m以上の地山掘削 等 |

### 2.3 建設業法

:::note[試験のポイント]
許可の区分（大臣 vs 知事、一般 vs 特定）の金額基準、主任技術者と監理技術者の配置要件、専任が必要となる請負金額が頻出。特に金額基準の改正に注意。
:::

#### 建設業の許可

| 区分 | 内容 |
|---|---|
| **国土交通大臣** 許可 | **2以上** の都道府県に営業所を設置 |
| **都道府県知事** 許可 | **1つ** の都道府県にのみ営業所を設置 |
| 許可不要 | **軽微な建設工事** のみを請け負う場合 |

#### 軽微な建設工事

| 工事の種類 | 範囲 |
|---|---|
| 建築一式工事以外 | 請負金額 **500万円未満** |
| 建築一式工事 | 請負金額 **1,500万円未満** または延べ面積 **150m&sup2;未満** の木造住宅 |

#### 一般建設業と特定建設業

| 許可の区分 | 下請に出す金額 |
|---|---|
| 一般建設業 | 下請金額が **4,500万円未満**（建築一式は **7,000万円未満**） |
| 特定建設業 | 下請金額が **4,500万円以上**（建築一式は **7,000万円以上**） |

#### 技術者の配置

| 技術者 | 配置要件 |
|---|---|
| **主任技術者** | すべての建設工事に配置（元請・下請を問わない） |
| **監理技術者** | 特定建設業者が元請として、下請金額の合計が **4,500万円以上**（建築一式は **7,000万円以上**）の工事を施工する場合 |

- 公共性のある施設・工作物に関する重要な建設工事で、請負金額が **4,000万円以上**（建築一式は **8,000万円以上**）の場合、主任技術者・監理技術者は **専任** でなければならない

### 2.4 道路法

:::note[試験のポイント]
道路占用許可と道路使用許可の違い、占用許可の手続き（道路管理者＋警察署長）、車両制限令の数値がよく出題される。「道路の占用」の定義を正確に理解しておく。
:::

#### 道路の占用

- **道路の占用** とは、道路の地上または地下に一定の工作物・物件・施設を設けて **継続的に使用** すること
- 道路占用には **道路管理者の許可**（道路占用許可）と **警察署長の許可**（道路使用許可）の **両方** が必要

#### 主な占用物件

- 電柱、電線、広告物等の工作物
- 水管、下水道管、ガス管等
- 工事用板囲、足場、詰所等の工事用施設
- 土石、竹木等の工事用材料

#### 占用工事の遵守事項

- 道路の一方の側は、常に **通行できる** ようにすること
- 夜間は **赤色灯または黄色灯** を設置・点灯
- ガス管等の埋設物は **試掘等** により確認してから工事を実施
- 掘削面積は **当日中に復旧可能な範囲** とすること

#### 車両制限令

- 道路管理者は、車両の幅・重量・高さ・長さ・最小回転半径の最高限度を超える車両の通行を禁止・制限できる
- **特殊車両通行許可**: やむを得ない場合、道路管理者の許可を受けて通行可能。許可証を車両に **備え付け** なければならない
- 道路管理者を異にする2つ以上の道路を通行する場合のルールにも注意

#### 道路の種類と道路管理者

| 道路の種類 | 道路管理者 |
|---|---|
| 高速自動車国道 | 国土交通大臣 |
| 直轄国道（指定区間） | 国土交通大臣 |
| 補助国道（指定区間外） | 都道府県または政令指定市 |
| 都道府県道 | 都道府県または政令指定市 |
| 市町村道 | 市町村 |

### 2.5 河川法

:::note[試験のポイント]
河川区域内の行為には河川管理者の許可が必要。占用・土石採取・工作物の新築・土地の掘削の4つの許可対象と、それぞれ官有地のみか民有地も含むかの区別が頻出。河川保全区域の数値も要注意。
:::

#### 河川の区分と河川管理者

| 河川の区分 | 河川管理者 |
|---|---|
| 一級河川・指定区間外 | 国土交通大臣 |
| 一級河川・指定区間 | 都道府県知事等（大臣から委任） |
| 二級河川 | 都道府県知事 |
| 準用河川 | 市町村長 |

#### 河川区域内で許可が必要な行為

| 行為 | 対象の土地 |
|---|---|
| 土地の **占用** | 官有地のみ（民有地は不要） |
| **土石等の採取** | 官有地のみ（民有地は不要） |
| **工作物の新築**・改築・除去 | 官有地・民有地を問わず全ての土地 |
| 土地の **掘削**・盛土・切土 | 官有地・民有地を問わず全ての土地 |

#### 河川保全区域

- 河川管理施設から **50m以内** の区域
- 土地の掘削・盛土・堅固な工作物の新築等に許可が必要
- 許可不要: 耕うん、高さ **3m以内** の盛土、深さ **1m以内** の掘削等
- ただし、河川管理施設の敷地から **5m以内** の行為は許可が必要

### 2.6 建築基準法

:::note[試験のポイント]
建設工事の現場事務所等の仮設建築物に対する規制緩和が最頻出。建築確認・完了検査の手続き、用語の定義（建築物・居室・主要構造部等）も押さえておく。
:::

#### 建築確認・完了検査

- 建築の **着工前** に **建築主事** または **指定確認検査機関** の確認を受ける
- 工事完了後 **4日以内** に完了検査を申請

#### 仮設建築物の規制緩和（最頻出）

現場事務所・下小屋・材料置場等の仮設建築物は以下のとおり緩和される。

| 区分 | 適用 |
|---|---|
| 建築確認申請・完了検査 | **不要** |
| 接道義務（2m以上） | **不適用** |
| 容積率・建ぺい率 | **不適用** |
| 用途地域の制限 | **不適用** |
| 構造耐力（安全な構造） | **適用される** |
| 採光・換気 | **適用される** |
| 電気設備の安全 | **適用される** |
| 避雷設備（高さ20m超） | **不適用** |
| 防火地域の屋根の構造 | 延べ面積 **50m&sup2;超** の場合のみ適用 |

#### 主な用語

| 用語 | 注意点 |
|---|---|
| 建築物 | 屋根＋柱、または屋根＋壁を有する土地定着工作物。鉄道線路敷地内の運転保安施設は除外 |
| 居室 | 継続的に使用する部屋。**更衣室は居室ではない** |
| 主要構造部 | 壁、柱、床、はり、屋根、階段。**最下階の床は含まない** |
| 設計図書 | 工事用の図面（現寸図を除く）と仕様書 |

### 2.7 火薬類取締法・港則法

:::note[試験のポイント]
火薬類取締法は貯蔵・運搬・取扱いの実務的な禁止事項（鉄類の持込禁止、土足禁止、18歳未満の取扱い禁止等）が出題される。港則法は特定港における届出先（港長）や許可事項を押さえる。
:::

#### 火薬類取締法

**貯蔵のルール:**
- 火薬類は **火薬庫** に貯蔵する（少量の場合は例外あり）
- 火薬庫の設置・移転は **都道府県知事の許可** が必要
- 火薬庫内には **火薬類以外の物** を貯蔵してはならない
- 火薬庫に入るときは **鉄類** や **懐中電灯以外の灯火** の持込み禁止
- **土足** での出入り禁止
- 無煙火薬・ダイナマイトは温度管理（**最高最低寒暖計** を備える）

**運搬のルール:**
- 陸上運搬は **都道府県公安委員会** に届出、**運搬証明書** を携帯
- 防水性・防火性の **被覆**、**標識** の掲示、**見張人** の配置

**取扱いのルール:**
- **18歳未満** の者は取扱い禁止
- 火薬類の喪失・盗取は **警察官** に届出
- 容器は **木等の電気不良導体** で作り、内面に鉄類を表さない
- 凍結ダイナマイトは **もみほぐす**（火気・高熱源に接近させない）

#### 港則法

**基本事項:**
- **特定港**: 大小船舶の交通が多く、外国船舶が常時出入りする港
- **港長**: 海上保安庁長官が海上保安官の中から任命

**届出・許可が必要な行為:**

| 行為 | 届出先 |
|---|---|
| 特定港への入出港 | **港長** に届出 |
| 特定港内での船舶の修繕・けい船 | **港長** に届出 |
| 港内で工事・作業を行う場合 | **港長の許可** |
| 危険物の荷役 | **港長の許可** |

- 特定港内の停泊は、トン数・積荷の種類により **定められた区域** に停泊
- 汽艇等・いかだは、みだりにけい船浮標や他の船舶にけい留してはならない

### 2.8 騒音規制法・振動規制法

:::note[試験のポイント]
特定建設作業の種類（騒音8種類・振動4種類）、規制基準の数値（騒音85dB・振動75dB）、届出期限（7日前）と届出先（市町村長）が頻出。「2日以上にわたって実施される作業」という定義も重要。
:::

#### 特定建設作業の定義

- 著しい騒音・振動を発生させる作業で、かつ **2日以上** にわたって実施される作業

#### 特定建設作業の種類

| 騒音の規制対象（8種類） | 振動の規制対象（4種類） |
|---|---|
| くい打機・くい抜機等 | くい打機・くい抜機等 |
| びょう打機 | 鋼球による工作物の破壊 |
| さく岩機 | 舗装版破砕機 |
| 空気圧縮機（15kW以上） | ブレーカ（手持式を除く） |
| コンクリートプラント等 | — |
| バックホウ（80kW以上） | — |
| トラクターショベル（70kW以上） | — |
| ブルドーザ（40kW以上） | — |

#### 規制基準

| 項目 | 騒音 | 振動 |
|---|---|---|
| 大きさの制限 | **85dB** を超えないこと | **75dB** を超えないこと |
| 測定場所 | 敷地の **境界線** | 敷地の **境界線** |
| 夜間作業禁止 | 1号区域: 19時〜翌7時 / 2号区域: 22時〜翌6時 | 同左 |
| 1日の作業時間 | 1号区域: **10時間** / 2号区域: **14時間** | 同左 |
| 作業期間 | 連続 **6日間** を超えないこと | 同左 |
| 作業禁止日 | **日曜日**・休日 | 同左 |

#### 届出

- **届出期限**: 作業開始日の **7日前** まで
- **届出先**: **市町村長**
- **届出者**: 元請業者
