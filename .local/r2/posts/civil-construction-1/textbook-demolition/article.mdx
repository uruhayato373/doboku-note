# 解体工事

## 解体工事の種類と特徴

### 解体原理による種類

#### 打撃（ブレーカ）工法

油圧式等のノミ（チゼルともいう）でコンクリート等を打撃し破砕する工法であり、**ハンドブレーカ工法**と**大型ブレーカ工法**がある。

大型ブレーカ工法は、油圧ショベルにブレーカユニットを装着して解体する工法である。

<img src="/posts/civil-construction-1/textbook-demolition/img/fig-6-1.png" alt="図6.1 油圧ブレーカとその構造" loading="lazy" />

#### 圧砕工法

油圧で圧砕アームを開閉し、コンクリート等を圧砕する工法である。昭和50年頃から主流となっており、手持式から大型まで多くの種類がある。

<img src="/posts/civil-construction-1/textbook-demolition/img/fig-6-2.png" alt="図6.2 ベースマシンに搭載した圧砕機" loading="lazy" />

<img src="/posts/civil-construction-1/textbook-demolition/img/fig-6-3.png" alt="図6.3 油圧圧砕機の種類" loading="lazy" />

#### 切断工法

切断工法には、以下の4つの工法がある。

**1) カッタ工法**

ダイアモンド等を埋め込んだブレードにより、コンクリート等を切断する工法である。φ1,000mmを超える大型のものもある。

**2) ワイヤソーイング工法**

ダイアモンドビーズを埋め込んだワイヤソーにより、コンクリート等を切断する工法である。石切り用の装置を改良したものである。

<img src="/posts/civil-construction-1/textbook-demolition/img/fig-6-4.png" alt="図6.4 ワイヤソーイング工法" loading="lazy" />

**3) コアドリル工法**

コンクリート等を削孔（ラインカット）する工法である。長さ10m程度の削孔も可能である。

<img src="/posts/civil-construction-1/textbook-demolition/img/photo-6-1.png" alt="写真6.1 コアドリル" loading="lazy" />

**4) ウォータージェット工法**

超高水圧によりコンクリート等を破砕する工法である。研磨剤を混合することにより鉄筋も切断できるが、特殊な現場でしか使用されない。

#### 静的破砕剤工法

酸化カルシウム（CaO）と水の膨張圧により、コンクリート等を破砕する工法である。無筋コンクリートに比べ鉄筋コンクリートでは効率が良くない。大型基礎や土木構造物本体の解体で利用される。

#### 転倒工法

ワイヤロープを構造物の頂部に掛けて引き倒す工法、または重機のアタッチメントで掛けて引き倒す工法である。事故が多く、安全管理が特に重要である。

### 施工要領による種類

#### 地上解体工法

ロングブーム圧砕機により地上から解体する工法である。ブームおよびアームの長さの合計が12m以上のものは「**特定解体用機械**」として、労働安全衛生法令上の規制を受ける。

<img src="/posts/civil-construction-1/textbook-demolition/img/fig-6-5.png" alt="図6.5 地上解体工法の例" loading="lazy" />

#### 階上解体工法

クレーンで解体用機械を屋上に上げ、上から順に解体する工法である。床版、梁に支保工を設置して施工する。隣接構造物等との離隔距離が小さい都市部で多く採用される。

<img src="/posts/civil-construction-1/textbook-demolition/img/fig-6-6.png" alt="図6.6 階上解体工法の例" loading="lazy" />

## 解体工事の施工

### 一般的な流れ

解体工事は、建設リサイクル法の規定を基本とした流れで行う。

#### 事前調査

解体工事に先立ち、以下の項目について事前調査を行う。

| 表6.1 事前調査の主な項目 |
|:--|

| 調査項目 | 主な調査内容 |
|:--|:--|
| 土木構造物 | 構造種別、規模、階数、築年数、増改築の有無、劣化・損傷状況、有害物質（アスベスト等）の使用状況 |
| 敷地 | 敷地の広さ、地盤状況、地中障害物の有無、埋設物の有無 |
| 道路 | 前面道路の幅員、交通量、通学路の有無、架空線の有無 |
| 近隣 | 隣接構造物の状況、近隣住民の状況、学校・病院等の有無 |
| 関係機関 | 届出・許可の必要性、規制事項の確認 |
| 廃棄物 | 廃棄物の種類・量の推定、処理先の確認 |

#### 施工計画

事前調査の結果に基づき、以下の施工計画を作成する。

| 表6.2 施工計画の種類・内容 |
|:--|

| 計画の種類 | 主な内容 |
|:--|:--|
| 準備作業計画 | 事前措置、近隣対策、届出・許可手続き |
| 仮設計画 | 足場、防音パネル・シート、養生、仮囲い |
| 解体作業計画 | 解体工法の選定、使用機械の選定、作業手順 |
| 工程計画 | 全体工程、各工種の工程、搬出計画 |
| 安全衛生管理計画 | 安全管理体制、安全教育、作業主任者の配置 |
| 環境保全計画 | 騒音・振動対策、粉じん対策、排水処理 |
| 廃棄物処理計画 | 分別解体、廃棄物の搬出・処理方法、再資源化 |
| 終結作業計画 | 整地、仮設物の撤去、完了届出 |

#### 事前措置

解体作業に先立ち、以下の事前措置を行う。

| 表6.3 事前措置の主な項目 |
|:--|

| 項目 | 主な内容 |
|:--|:--|
| 作業場所の確保 | 内部の残存物の撤去、有害物質の除去、電気・ガス・水道等の供給停止の確認 |
| 搬出経路の確保 | 搬出路の設定、交通誘導員の配置、道路使用許可 |
| その他 | 近隣への周知、仮囲いの設置、標識の設置 |

#### 解体作業

**1) 仮設・養生**

解体作業にあたり、以下の仮設・養生を行う。

- **足場** — 作業員の墜落防止および作業床の確保のために設置する
- **防音パネル・シート** — 騒音の低減および飛散防止のために設置する
- **散水設備** — 粉じんの飛散防止のために設置する
- **照明設備** — 作業場所の照度確保のために設置する
- **換気設備** — 密閉空間での作業時に設置する

**2) 橋脚等の土木構造物の解体**

**① 鉄筋コンクリート造構造物等の解体**

機械作業工法と手作業工法の併用により解体する。圧砕機、大型ブレーカ等の機械作業工法を主体とし、機械で施工できない箇所はハンドブレーカ等の手作業工法で補完する。

**② 鉄骨造構造物等の解体**

鉄骨切断機で切断して解体する。

**③ 鉄骨鉄筋コンクリート造構造物等の解体**

上記①と②の工法を組み合わせて解体する。

**3) 基礎・基礎杭の解体**

基礎の解体は、圧砕機や大型ブレーカ等で行う。基礎杭の解体は、引抜き工法や切断工法により行う。

**4) 整地**

解体作業完了後、地盤面を整地する。

### 構造物解体（取壊し）工法における必要な措置

#### 圧砕工法、大型ブレーカ等

- 転倒防止のため、外壁等の自立する部分の高さは、その部分の厚さの5倍以下とする
- 解体物の飛来落下に備え、作業員に保護帽、保護めがね等の保護具を着用させる
- 粉じんの飛散防止のため、散水を行う
- 騒音・振動の防止対策を講じる
- 解体物の落下範囲に作業員を立ち入らせない

#### 転倒工法

- 転倒方向に十分な空間を確保する
- ワイヤロープの取付け位置、引く方向等を事前に検討する
- 転倒時の影響範囲内に作業員を立ち入らせない
- 転倒方向の地盤が転倒の衝撃に耐えられることを確認する

#### カッタ工法

- 切断箇所の鉄筋等の配置を事前に確認する
- ブレードの回転方向に作業員を配置しない
- 冷却水の飛散防止措置を講じる

#### ワイヤソーイング工法

- ワイヤソーの張力を適切に管理する
- ワイヤソーの回転範囲内に作業員を立ち入らせない
- ワイヤソーの切断に備え、防護措置を講じる

#### ウォータージェット工法

- 超高水圧による危険を防止するため、作業範囲に作業員を立ち入らせない
- ノズルの取扱いに注意し、誤噴射を防止する
- 排水の処理対策を講じる

#### 静的破砕剤工法

- 削孔時の粉じん対策を講じる
- 破砕剤充填後の異常膨張による噴出に注意する
- 破砕剤の水和熱による火傷に注意する

### 構造物解体（取壊し）作業における安全確認事項

|:--|

| 作業工種 | 作業手順 | 安全確認事項 |
|:--|:--|:--|
| 作業前 | 作業計画の確認 | 当日の作業範囲、作業手順を全作業員に周知する |
| | 機械の点検 | 圧砕機・ブレーカの油圧系統、アタッチメントの取付け状態を点検する |
| | 作業区域の確認 | 立入禁止区域を設定し、標識・バリケードを設置する |
| 作業中 | 圧砕・打撃作業 | 外壁等の自立する部分の高さが厚さの5倍以下であることを確認する |
| | | 解体物の飛来落下範囲に作業員がいないことを確認する |
| | | 散水による粉じん飛散防止を行う |
| | 解体物の搬出 | 搬出経路の安全を確認する |
| 作業後 | 作業箇所の確認 | 不安定な構造物が残っていないか確認する |
| | 機械の格納 | アタッチメントを接地し、機械を安定した状態にする |
