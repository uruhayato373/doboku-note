2級土木 第2次検定の必須問題である施工経験記述について、出題傾向・出題形式の見直し・過去の問題例・記述上の留意点・管理別のヒント文章案までを一通り整理する。まずは何が問われ、どの観点で書くのかという全体像から押さえていく。

## 出題傾向

第2次検定の問題1は「施工経験記述」であり、受検者自身が担当した土木工事の現場における施工管理の経験を記述する必須問題である。配点が大きく合否を分けやすい一方、自分の経験をその場で文章化する必要があるため、事前準備の有無が結果に直結する。

施工管理のテーマは「安全管理」「品質管理」「工程管理」「環境対策」から年度ごとに選ばれる。近年の2級第2次検定では安全・品質・工程の3管理が中心であり、この3つを書けるよう準備しておけば、ほとんどの出題パターンに対応できる。

### 年度別の出題テーマ

直近5年の問題1で問われた施工管理項目と、その出題形式は次のとおりである。

| 年度 | 設問1 | 設問2 | 出題形式 |
|---|---|---|---|
| 令和7年度 | 安全管理 | 工程管理 | 2テーマ必答（各2項目） |
| 令和6年度 | 品質管理 | 工程管理 | 2テーマ必答（各2項目） |
| 令和5年度 | 安全管理 または 工程管理 | （選択した1テーマ） | 1テーマ選択（3項目） |
| 令和4年度 | 品質管理 または 工程管理 | （選択した1テーマ） | 1テーマ選択（3項目） |
| 令和3年度 | 安全管理 または 品質管理 | （選択した1テーマ） | 1テーマ選択（3項目） |

令和5年度までは「2つの管理項目から1つを選んで記述する」形式が続いたが、令和6年度から「設問1と設問2で異なる管理項目が固定で与えられ、両方を必答する」形式へと変わっている。準備の段階では、いずれの形式にも対応できるよう **安全・品質・工程の3管理すべて** を書けるようにしておくことが重要である。

### 出題形式の見直し（令和6年度〜）

<Callout type="warn" title="令和6年度から形式が変わっている">
令和5年度以前と令和6年度以降では、設問の構成が次のように異なる。どちらの形式で出題されても対応できるよう、両方の型を理解しておく。

**令和5年度以前（1テーマ選択・3項目）**

- 2つの管理項目から得意な1つを選んで記述する。
- 設問2は次の3項目で構成される。
  - (1) 特に留意した**技術的課題**
  - (2) 技術的課題を解決するために**検討した項目と検討理由及び検討内容**
  - (3) 上記検討の結果、現場で実施した**対応処置とその評価**

**令和6年度以降（2テーマ必答・各2項目）**

- 設問1・設問2で異なる管理項目（例：設問1=安全管理、設問2=工程管理）が固定で与えられ、両方を必答する。
- 各設問は次の2項目で構成される。
  - (1) 具体的な**現場状況**と特に留意した技術的課題
  - (2) (1) の課題を解決するために**検討した項目とその対応処置**（設問2では「留意事項」と「講じた対策とその理由」）

これは、第2次検定で「自身の経験に基づく解答」に加えて「幅広い視点からの経験」を確認する方向への見直しによるものである。出題テーマを絞り込みすぎず、安全・品質・工程を横断的に準備しておくとよい。
</Callout>

## 過去の問題例（令和7年度）

令和7年度の問題1は次の構成であった。設問1で安全管理、設問2で工程管理が固定で与えられ、両方を必答する形式である。問題文は試験対策の目的で引用する。

> **問題1**　あなたが経験した土木工事を1つ選び、工事概要を具体的に記述したうえで、次の〔設問1〕、〔設問2〕に答えなさい。
>
> なお、あなたが経験した工事でないことが判明した場合は、失格となります。

**〔工事概要〕**

<div className="list-plain">

- (1) 工事名
- (2) 工事現場における施工管理上のあなたの立場
- (3) 工事の内容
  - ① 発注者名　② 工事場所　③ 工期　④ 主な工種　⑤ 施工量

</div>

**〔設問1〕**（安全管理）

<div className="list-plain">

- (1) 具体的な現場状況と特に留意した安全管理上の技術的課題
- (2) (1) で記述した技術的課題を解決するために検討した項目とその対応処置

</div>

**〔設問2〕**（工程管理）

<div className="list-plain">

- (1) 施工条件や現場周辺の状況の観点から、工程管理上、留意した事項（工事着手前・工事中のいずれでも可）
- (2) (1) で記述した留意事項に対して講じた対策とその理由

</div>

各年度の問題文と解答の組み立て方は、年度別の過去問ページで確認できる。

## 施工経験記述の対象となる土木工事

施工経験記述は、受検者自身が経験した土木工事の現場における施工管理について記述するものである。どの工事を題材にするか迷う場合は、まず実務経験として認められる工事種別かどうかを確認する。

### 実務経験として認められる工事種別・内容

| 工事種別 | 主な工事内容 |
|---|---|
| 河川工事 | 築堤・護岸工事、根固め工事、水門・樋門（樋管）工事、河川改修工事、浚渫工事 |
| 海岸工事 | 海岸堤防工事、突堤・離岸堤工事、消波工、高潮・侵食対策工事 |
| 砂防工事 | 砂防ダム工事、流路工事、地すべり・急傾斜地崩壊防止工事 |
| ダム工事 | コンクリートダム・フィルダムの本体工事 |
| 道路工事 | 道路改良・築造工事、舗装工事、側溝・道路排水工事、歩道設置工事 |
| 橋梁工事 | 橋梁上部工事、橋梁下部工事（橋台・橋脚）、PC工事 |
| トンネル工事 | 開削トンネル工事、シールド工事、推進工事、山岳トンネル（NATM） |
| 土工事・造成工事 | 掘削・盛土工事、地盤改良工事、宅地造成工事、造成排水工事 |
| 基礎・仮設工事 | 杭打ち（基礎）工事、矢板・締切工事、仮設工事、仮橋・工事用道路 |
| 上下水道工事 | 取水・浄水・送配水施設工事、管渠工事、ポンプ場・処理場工事 |
| 港湾・空港工事 | 港湾工事、埋立・浚渫工事、空港工事 |
| 鉄道・地下構造物工事 | 線路（軌道）工事、共同溝・電線共同溝工事、地下横断歩道工事 |
| 鋼構造物・鉄筋工事 | 鋼橋・水門等の製作据付、鉄筋加工組立・継手工事 |
| 農業土木・森林土木工事 | 農業用水路・頭首工・ため池工事、治山・林道工事 |

工事種別の判断に迷う場合は、受検年度の「受検の手引」に記載された実務経験の区分を確認する。

### 実務経験として認められない工事・業務

次のような工事・業務は土木施工管理の実務経験として認められないため、題材に選んではならない。

| 区分 | 認められない内容（例） |
|---|---|
| 建築工事 | ビル・マンションの躯体・仕上・基礎工事、建築設備工事 |
| 個人住宅工事 | 宅地内の各種工事、住宅本体工事 |
| 設備・浄化槽工事 | 給排水・空調などの建築設備工事、敷地内浄化槽の配管工事 |
| 外構・造園工事 | フェンス・門扉等の設置、植栽・修景・遊具設置工事（小規模） |
| 解体工事 | 建築物・建築設備の解体工事 |
| 製作・据付 | プレキャスト製品・鋼構造物の工場製作、機械器具の据付 |
| 調査・設計・事務 | 地質調査・測量・環境調査、設計業務、積算、営業・事務、教育・研究 |

<Callout type="tip">
題材に選ぶ工事は、自社（受注者）が請け負った土木工事に限る。下請けで参加した工事は、自社が担当した工種・工期の範囲で記述する。土木工事以外（建築・管・電気工事など）の工種を書くと不合格となるため注意する。
</Callout>

### 施工管理上の立場

工事現場における立場は、会社内の役職ではなく **現場での立場** を記入する。2級土木施工管理技士で記述する立場としては、次のものが該当する。

| 立場 | 説明 |
|---|---|
| 現場代理人 | 受注者を代理して現場を統括する立場 |
| 主任技術者 | 建設業法に基づき現場の技術上の管理をつかさどる立場 |
| 現場監督・工事主任 | 受注者側で現場の施工管理を担当する立場 |
| 監督員（発注者側） | 発注機関に所属し工事を監督する立場 |

「作業員」「職人」は施工管理の立場としては不適切と判断されるため記入しない。

## 記述上の留意事項

### 記述全般

採点は人が行うため、内容が優れていても読みづらい字や趣旨の外れた記述では評価されない。次の点を守る。

1. 試験問題の指示どおりの筆記具（HBなど）で、丁寧に記述する。乱雑な字や大きさの揃わない字は減点の対象になりやすい。
2. 解答欄の8割以上を、適切な分量で埋める。空欄が多い、はみ出す、行間を空けて行数を稼ぐ、といった記述は減点される。
3. 文末は「です・ます」調ではなく「である」「であった」で統一する。
4. できるだけ専門用語を正しく使い、施工管理の経験があることが伝わるようにする。専門用語の誤字には特に注意する。
5. 「何を」「どのように」をセットで、具体的に記述する。結果だけを書くのではなく、数値・工法・材料・管理方法を添える。

漢字や数値が思い出せない場合は、ひらがなで書く、言い回しを変える、「所定の値で管理した」などの表現に置き換えて対応する。

<Callout type="note" title="自分の経験記述、合格水準に届いているか（PR）">
第2次検定の経験記述は配点が大きく、合否を分けやすい。一方、独学では「自分の答案が採点者に伝わるか」を客観的に確かめる手段がない。誤字・論理の飛び・具体性の不足は、書いた本人ほど気づきにくい。
</Callout>

### 工事名

工事の対象（河川名・路線名・施設名）、場所（地区・地先名）、種類（護岸・舗装・改良など）がわかるように具体的に記述する。原則として契約書や工事看板のとおりに記入し、長い場合は概要や略称にしてもよい。「道路工事」「河川工事」だけでは不十分である。

| 不適当な例 | 適当な例 |
|---|---|
| 道路工事 | 市道〇〇号線 道路改良舗装工事 |
| 河川工事 | 〇〇川 河川改修護岸工事（〇〇地区） |
| 下水道工事 | 〇〇雨水幹線 管渠築造工事 |

### 発注者名

工事を受注した相手方を発注者として記入する。元請けの場合は工事の発注機関を、下請けの場合は直上の注文者となった会社名を記入する。

1. 国土交通省や都道府県だけでなく、発注した部門・事務所まで記入する。
2. 下請けの場合は個人名ではなく会社名を記入する。

| 不適当な例 | 適当な例 |
|---|---|
| 国土交通省 | 国土交通省〇〇地方整備局〇〇国道（河川）事務所 |
| 〇〇県 | 〇〇県〇〇土木事務所 |
| 個人名 | 〇〇建設（株） |

### 工事場所

土木工事が行われた場所を、都道府県名・市郡名・町村名までなるべく詳しく記入する。道路工事は交差点間やキロポスト、鉄道工事は駅間など、場所が特定できるように書く。記入がないと減点の対象になる。

| 不適当な例 | 適当な例 |
|---|---|
| 〇〇県〇〇市 | 〇〇県〇〇市〇〇町〇丁目地内 |
| 〇〇県〇〇郡 | 〇〇県〇〇郡〇〇町〇〇地先 |

工事場所からは地域特有の自然環境や市街環境が読み取られる。記述本文の現場状況と整合させる。

### 工期

自社が請け負った工期を記入する。下請け工事の場合は下請け部分の工期を書く。和暦でもよい。

1. 工期は原則として1か月以上の工事を取り上げる。準備期間（資機材・労務の調達）から完成（竣工）までを含める。
2. 現在施工中の工事は避ける。
3. 年号・年月日を正確に記入する。
4. 施工量および記述本文の季節・時期と矛盾しないようにする。

| 不適当な例 | 適当な例 |
|---|---|
| 6月〜9月 | 令和5年6月1日〜令和5年9月29日 |

### 主な工種

工事内容がイメージできる主要な工種を、施工順に記入する。下請けの場合は自社が請け負った工種を書く。記述本文で扱う工種は、ここに必ず挙げておく。

| 不適当な例 | 適当な例 |
|---|---|
| 道路工 | 道路土工、排水構造物工、アスファルト舗装工 |
| 護岸工 | 護岸工（大型ブロック張工）、根固め工 |

### 施工量

「主な工種」に対応するように、構造物の規模、材料の種類、施工数量（面積・体積・本数・延長など）を具体的に記入する。単位を忘れず、工期と矛盾しない数量にする。

| 工種の例 | 施工量の記述例 |
|---|---|
| 盛土・路盤 | 盛土量〇〇〇m<sup>3</sup>、下層路盤 t=〇〇cm |
| コンクリート工 | コンクリート〇〇〇m<sup>3</sup>（24N/mm<sup>2</sup>）、鉄筋〇〇t |
| 護岸工 | 護岸ブロック〇〇〇m<sup>2</sup>、延長 L=〇〇〇m |
| 管渠工 | 管渠布設 φ〇〇〇mm、延長〇〇m、マンホール〇基 |

## 設問への答え方

設問は年度の形式により2〜3項目に分かれるが、書くべき要素は共通して「**現場状況 → 技術的課題 → 検討項目（理由・内容）→ 対応処置 → 評価**」の流れである。この5要素を一貫させて書き切ることが最優先となる。

### (1) 現場状況と特に留意した技術的課題

最初の2〜3行で工事の施工箇所と施工内容を簡潔にまとめ、メインの施工数量も添える。続いて、技術的課題の原因となる現場特有の条件を示し、そこから生じる課題を明記する。

- 課題の原因となる現場条件の例
  - 現場条件：軟弱な粘性土地盤、谷状地形で水が溜まりやすい、湧水が多い
  - 気象条件：梅雨・台風の多い時期、冬季の平均気温が低い、夏季の高温
  - 作業条件：施工ヤードが狭い、交通量の多い道路に近接、大型機械の搬入が困難

ここでは検討内容や実施したことは書かず、「何が原因で、どのような課題が生じたか」までを書く。課題は1つに絞ると、後段が書きやすい。

### (2) 検討した項目と検討理由及び検討内容

課題を解決するために事前に何を検討したかを2〜3項目挙げ、それぞれの検討理由と検討内容をセットで書く。実施したこと（結果）はここでは書かない。項目分けの観点は次のとおり。

- 品質管理：計画、材料、施工、養生、検査、作業員への周知
- 工程管理：材料・機械、工程表、作業の効率化、気温対策、創意工夫
- 安全管理：点検・確認、安全措置、作業員教育、安全施工サイクル

### (3) 対応処置とその評価

検討の結果、現場で実施した対応処置を、数値・工法・管理方法を入れて具体的に記述する。最後の1〜2行で、課題が解決できたことを端的に評価して締めくくる。

- 品質管理：所定の品質（規格値）を確保できた
- 工程管理：工期内に工事を完了できた／〇〇日の遅れを挽回できた
- 安全管理：無事故・無災害で工事を完了できた

<Callout type="note" title="2級の記述レベル">
2級土木施工管理技士では、主任技術者・現場代理人レベルの現場管理が書ければ十分である。特殊な工事や高度な工法を書いても加点されるわけではない。適切に施工管理が行われていることが採点者に伝わるよう、「私は〇〇の観点から〇〇を検討し、〇〇を講じた。その結果〇〇が達成できた」と、1人称・能動態でシンプルに書く。
</Callout>

## 減点される文章の共通点

次のような答案は、内容以前の問題で減点・不合格となりやすい。

- 字が乱雑で読めない、字の大きさが揃わずはみ出している。
- 解答欄の空欄が多い（8割以上を目標に埋める）。
- 行数を稼ぐために、文頭・文末・行間にスペースや空行を入れている。
- 改行のタイミングが不自然（行末を空けて改行している）。
- 指定されたテーマから外れた内容に文字数を割いている。
- 土木工事以外の工種を書いている、工事概要と本文の内容が矛盾している。
- 何を伝えたいのかわからない。採点者は記述された文章だけで判断するため、現場がイメージできるよう端的に書く。

## 出題項目に応じたヒント文章案

実際の答案は自分が経験した工事に即して書く必要があるが、課題と対応処置の組み立て方を理解するためのヒントを管理項目別に示す。次の表は典型的な現場条件・課題・対応の対応関係であり、そのまま書き写すと多数の受検者と同じ内容になり不合格の原因となるため、必ず自分の経験に置き換える。

### 安全管理

| 現場状況・課題 | 検討・対応処置のヒント |
|---|---|
| 高所作業での墜落・転落 | 足場の設置基準を遵守し、手すり・中さん・幅木・安全ネットを設置。開口部付近では要求性能墜落制止用器具（フルハーネス）を使用させ、毎日点検する。 |
| 重機と作業員の接触 | 作業区域と歩行・一般車両の区域を柵・カラーコーンで明確に区分。誘導員を配置し、上下作業・接触のおそれのある同時作業を禁止する。 |
| 掘削法面・土留めの崩壊 | 地山の状態を観察し、法面勾配の見直しや土留め支保工を設置。土留めの変位を計測し、管理基準を定めて掘削する。 |
| 第三者災害（道路工事） | 道路標識・保安灯・防護柵を設置し、通行者の動線を確保。KY活動と誘導員配置で第三者の安全を確保する（誘導員の配置のみの記述は不可）。 |
| 夏季の熱中症 | 日陰の休憩所・テントを設置し、水分・塩分を補給。WBGT値を測定し、連続作業時間を管理して安全衛生教育を行う。 |

<Callout type="warn">
安全管理を選ぶ場合、「交通誘導員の配置のみ」に関する記述は除外指示が出る年度がある。誘導員配置を扱うときは、必ずバリケード・標識・KY活動・上下作業禁止などの対策と組み合わせて書く。
</Callout>

### 品質管理

| 現場状況・課題 | 検討・対応処置のヒント |
|---|---|
| 盛土・路床の締固め不足 | 1層の巻出し厚を木製枠などで明示し、所定の仕上がり厚を遵守。RI計器や砂置換法で各層の締固め度を測定し、規格値を確認しながら施工する。 |
| 雨水による支持力低下 | 仕上がり面に排水勾配を設け、仮排水路・土のうで雨水の浸透を防止し、トラフィカビリティを確保する。 |
| 暑中コンクリートのコールドジョイント | 練混ぜ水の冷却・遅延型減水剤の使用、打重ね時間間隔の管理、上面のシート養生で温度上昇と乾燥を抑える。 |
| 寒中コンクリートの初期凍害 | 配合の確認、運搬中の保温、打設後の保温養生で所定の初期強度を確保する。 |
| 舗装の温度・平坦性管理 | アスファルト混合物の温度を運搬・敷均し・転圧の各段階で管理し、所定の締固め度と平坦性を確保する。 |

### 工程管理

| 現場状況・課題 | 検討・対応処置のヒント |
|---|---|
| 梅雨・台風による作業の遅れ | 休工日を見込んだネットワーク工程表を作成し、進捗を確認しながら遅延工程をフォローアップする。 |
| 関係機関協議・用地による着手遅延 | 先行して手続きに着手し、施工順序を入れ替えて着手可能な工種から進める。 |
| 地下埋設物の発見・設計変更 | 代替工法を速やかに比較検討し、迂回工法・夜間施工への切替えで影響を最小化する。 |
| 交通規制内での舗装復旧 | 規制時間内に完了するよう作業手順と機械配置を最適化し、待ち時間のない人員・機械を確保する。 |
| 工期短縮の要請 | 作業班の増班・機械の増強・並行作業により1日当たりの施工量を増やし、クリティカルパスを重点管理する。 |

### 環境対策

環境対策が出題された場合は、現場で発生する騒音・振動、排水（水質汚濁）、粉じん、産業廃棄物への対応を、立地（市街地か自然環境か）に応じて記述する。

- 騒音・振動：低騒音・低振動型建設機械の使用、防音シート・仮囲いの設置、空ぶかし・急発進の防止。
- 粉じん：散水、防じんネット・仮囲いの設置、種子吹付けによる飛散防止。
- 水質：濁水処理（沈砂池・凝集処理）、汚濁防止膜の設置、公共用水域への排水基準の遵守。
- 産業廃棄物：分別解体と現場内分別、マニフェストによる適正処理の確認、再資源化の促進。

## 令和6年度以降の新形式・新項目への備え

第2次検定の見直しにより、自身の経験に加えて「現場状況を指示しての記述」や「幅広い視点からの記述」が求められる場面が増えている。次のような出題にも対応できるよう、準備した記述を応用できるようにしておく。

- **条件提示型**：「平地／山間部」「夏季／冬季／雨季」など、出題者から現場・施工条件が与えられ、その条件下での施工を記述する。
- **複数管理の必答**：設問1・設問2で異なる管理項目（例：安全＋工程）が固定で与えられ、両方を記述する（令和6・7年度の形式）。
- **新項目の記述**：環境対策（騒音・振動・粉じん）、出来形管理、請負金額、工事に必要な届出書類（届出先）など。
- **日常業務の記述**：ヒヤリハットの事例とその後の改善、朝礼で意識する安全事項、作業日誌の記載項目、材料受入時の留意事項、品質管理写真の撮影上の留意事項など。

準備の基本は変わらない。安全・品質・工程の3管理について、自分が経験した工事をもとに「現場状況 → 技術的課題 → 検討 → 対応処置 → 評価」の記述を1セットずつ用意し、条件が変わっても課題と対応を入れ替えられるよう練習しておくことが、最も確実な対策となる。

</Callout>

## 経験記述は完成答案を雛形にするのが最短

「どう書けばいいか分からない」状態を最短で脱するには、答案の型と完成例を手に入れ、自分の現場の工種・テーマに置き換えて書き上げるのが近道である。

<Callout type="tip" title="フル完成答案は note 有料マガジンで">
本ページは経験記述の「書く観点」を示すものです。3 管理（安全・品質・工程）の **複数工種のフル完成答案**、年度別の過去問模範答案、自分の現場への置換ガイド・採点者視点は note 有料マガジンにまとめています。自分の現場に最も近い工種をそのまま雛形として使えます。
</Callout>
