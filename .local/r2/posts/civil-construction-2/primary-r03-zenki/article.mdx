## 問題 No.1

「土工作業の種類」と「使用機械」に関する次の組合せのうち、**適当でないもの**はどれか。

| 土工作業の種類 | 使用機械 |
|---|---|
| (1) 掘削・積込み | バックホウ |
| (2) 溝掘り | ランマ |
| (3) 敷均し・整地 | ブルドーザ |
| (4) 締固め | ロードローラ |

<details>
<summary>解答・解説</summary>

**正解: (2)**

1. バックホウは機械位置より低い場所の掘削や積込みに適する ✅

2. **ランマは小規模な締固め用の機械で、溝掘りには適さない。溝掘りはバックホウ等を用いる ❌**

3. ブルドーザは土砂の敷均し・整地・押土に適する ✅

4. ロードローラは路盤・路床の締固めに用いられる ✅

</details>

## 問題 No.2

土質試験における「試験名」とその「試験結果の利用」に関する次の組合せのうち、**適当でないもの**はどれか。

| 試験名 | 試験結果の利用 |
|---|---|
| (1) 砂置換法による土の密度試験 | 土の締固めの管理 |
| (2) 土の一軸圧縮試験 | 支持力の推定 |
| (3) ボーリング孔を利用した透水試験 | 地盤改良工法の設計 |
| (4) ポータブルコーン貫入試験 | 土の粒度の判定 |

<details>
<summary>解答・解説</summary>

**正解: (4)**

1. 砂置換法は現場の土の密度を測り、締固め管理に用いる ✅

2. 一軸圧縮試験は粘性土の一軸圧縮強さから支持力を推定する ✅

3. ボーリング孔利用の現場透水試験は透水係数を求め、地盤改良の設計に用いる ✅

4. **ポータブルコーン貫入試験はコーン指数qcを求め、建設機械のトラフィカビリティ判定に用いる。粒度の判定は粒度試験で行う ❌**

</details>

## 問題 No.3

盛土の施工に関する次の記述のうち、**適当でないもの**はどれか。

1. 盛土の締固めの目的は、土の空気間隙を少なくすることにより、土を安定した状態にすることである。

2. 盛土材料の敷均し厚さは、盛土材料の粒度、土質、要求される締固め度等の条件に左右される。

3. 盛土材料の含水比が施工含水比の範囲内にないときには、空気量の調節が必要となる。

4. 盛土の締固めの効果や特性は、土の種類、含水状態及び施工方法によって大きく変化する。

<details>
<summary>解答・解説</summary>

**正解: (3)**

1. 締固めにより空気間隙を減らし土を安定させるのは正しい ✅

2. 敷均し厚さは粒度・土質・要求締固め度で決まる ✅

3. **含水比が施工含水比の範囲外のときは「含水量の調節（曝気乾燥や散水）」を行うのが原則で、空気量の調節は誤り ❌**

4. 締固め効果は土質・含水状態・施工方法で変化する ✅

</details>

## 問題 No.4

軟弱地盤における次の改良工法のうち、締固め工法に**該当するもの**はどれか。

1. 押え盛土工法

2. バーチカルドレーン工法

3. サンドコンパクションパイル工法

4. 石灰パイル工法

<details>
<summary>解答・解説</summary>

**正解: (3)**

1. 押え盛土工法はすべり抵抗を増す荷重バランス工法で、締固め工法ではない ❌

2. バーチカルドレーン工法は排水促進による圧密促進工法である ❌

3. サンドコンパクションパイル工法は砂杭を打設して締め固める締固め工法である ✅

4. 石灰パイル工法は固結（脱水・固化）工法である ❌

</details>

## 問題 No.5

コンクリートで使用される骨材の性質に関する次の記述のうち、**適当でないもの**はどれか。

1. 骨材の品質は、コンクリートの性質に大きく影響する。

2. 吸水率の大きい骨材を用いたコンクリートは、耐凍害性が向上する。

3. 骨材に有機不純物が多く混入していると、凝結や強度等に悪影響を及ぼす。

4. 骨材の粗粒率が大きいほど、粒度が粗い。

<details>
<summary>解答・解説</summary>

**正解: (2)**

1. 骨材品質はコンクリート性質に大きく影響する ✅

2. **吸水率の大きい骨材は内部の水分凍結により耐凍害性が「低下」する。向上は誤り ❌**

3. 有機不純物は凝結遅延・強度低下を招く ✅

4. 粗粒率が大きいほど粒度は粗い ✅

</details>

## 問題 No.6

コンクリートの施工に関する次の記述のうち、**適当なもの**はどれか。

1. コンクリートを練り混ぜてから打ち終わるまでの時間は、外気温が25℃を超えるときは2時間以内を標準とする。

2. 現場内でコンクリートを運搬する場合、バケットをクレーンで運搬する方法は、コンクリートの材料分離を少なくできる方法である。

3. コンクリートを打ち重ねる場合は、棒状バイブレータ（内部振動機）を下層コンクリート中に10cm程度挿入する。

4. 養生では、散水、湛水、湿布で覆う等して、コンクリートを一定期間湿潤状態に保つことが重要である。

<details>
<summary>解答・解説</summary>

**正解: (1)**

1. **外気温が25℃を超えるときは「1.5時間以内」を標準とする。2時間以内は誤り ❌**

2. バケットをクレーンで運搬する方法は材料分離が起こりにくく、適切である ✅

3. 打重ねでは棒状バイブレータを下層コンクリート中に10cm程度挿入し一体化する ✅

4. 養生はコンクリートを一定期間湿潤状態に保つことが重要で正しい ✅

</details>

## 問題 No.7

フレッシュコンクリートに関する次の記述のうち、**適当でないもの**はどれか。

1. コンシステンシーとは、コンクリートの仕上げ等の作業のしやすさである。

2. スランプとは、コンクリートの軟らかさの程度を示す指標である。

3. 材料分離抵抗性は、コンクリート中の材料が分離することに対する抵抗性である。

4. ブリーディングとは、練混ぜ水の一部が遊離してコンクリート表面に上昇する現象である。

<details>
<summary>解答・解説</summary>

**正解: (1)**

1. **コンシステンシーは変形・流動に対する抵抗性（軟らかさの程度）であり、「作業のしやすさ」はワーカビリティーの定義で誤り ❌**

2. スランプは軟らかさの程度を示す指標で正しい ✅

3. 材料分離抵抗性の説明は正しい ✅

4. ブリーディングの説明は正しい ✅

</details>

## 問題 No.8

型枠の施工に関する次の記述のうち、**適当なもの**はどれか。

1. 型枠内面には、セパレータを塗布しておく。

2. コンクリートの側圧は、コンクリート条件、施工条件によらず一定である。

3. 型枠の締付け金物は、型枠を取り外した後、コンクリート表面に残してはならない。

4. 型枠は、取り外しやすい場所から外していくのがよい。

<details>
<summary>解答・解説</summary>

**正解: (3)**

1. **型枠内面に塗布するのは「はく離剤」で、セパレータは型枠間隔を保持する金具。誤り ❌**

2. **側圧はコンクリート条件・施工条件（打込み速度・温度等）で変化し一定ではない ❌**

3. 締付け金物は取り外した後、コンクリート表面に残さず除去・処理するのが正しい ✅

4. **型枠の取外しは荷重を受けない部分（梁側面・柱・壁等）から先に外すのが原則で、取り外しやすい場所からではない ❌**

</details>

## 問題 No.9

既製杭の打撃工法に用いる杭打ち機械に関する次の記述のうち、**適当でないもの**はどれか。

1. ドロップハンマは、ハンマの重心が低く、杭軸と直角にあたるものでなければならない。

2. ドロップハンマは、ハンマの落下高さを変えることで、同じ打撃力を得ることができる。

3. 油圧ハンマは、ラムの落下高さを任意に調整できることから、杭打ち時の騒音を低くすることができる。

4. 油圧ハンマは、構造自体の特徴から油煙の飛散が非常に多い。

<details>
<summary>解答・解説</summary>

**正解: (4)**

1. ドロップハンマは杭軸と直角にあたる構造が必要である ✅

2. 落下高さの調整で打撃力を変えられる ✅

3. 油圧ハンマは落下高さを調整でき、低騒音施工が可能である ✅

4. **油圧ハンマは油煙の飛散が「少なく」、騒音・振動も小さい低公害型機械。飛散が非常に多いは誤り ❌**

</details>

## 問題 No.11

土留め壁の「種類」と「特徴」に関する次の組合せのうち、**適当なもの**はどれか。

| 種類 | 特徴 |
|---|---|
| (1) 連続地中壁 | あらゆる地盤に適用でき、剛性に比べ経済的である |
| (2) 鋼矢板 | 止水性がよく、地下水位が高い地盤に適する |
| (3) 柱列杭 | 剛性が小さいため、深い掘削に適する |
| (4) 親杭・横矢板 | 地下水のある地盤に適しているが、施工は比較的簡単である |

<details>
<summary>解答・解説</summary>

**正解: (2)**

1. **連続地中壁は剛性・止水性に優れるが「経済的」ではなく高コスト ❌**

2. 鋼矢板は止水性がよく、地下水位の高い地盤に適する ✅

3. **柱列杭は剛性が大きく深い掘削に適する。剛性が小さいは誤り ❌**

4. **親杭・横矢板は止水性がなく地下水のある地盤には不向きで、地下水位の低い地盤に適する ❌**

</details>

## 問題 No.12

鋼材に関する次の記述のうち、**適当でないもの**はどれか。

1. 鋼材は、応力度が弾性限界に達するまでは弾性を示すが、それを超えると塑性を示す。

2. PC鋼材は、鉄筋コンクリート用棒鋼に比べて高い強さをもっているが、伸びは小さい。

3. 炭素鋼は、炭素含有量が少ないほど延性や展性は低下するが、硬さや強さは向上する。

4. 継ぎ目なし鋼管は、小・中径のものが多く、高温高圧用配管等に用いられている。

<details>
<summary>解答・解説</summary>

**正解: (3)**

1. 弾性限界までは弾性、超えると塑性を示すのは正しい ✅

2. PC鋼材は高強度だが伸びが小さい ✅

3. **炭素含有量が少ないほど延性・展性は「高く」、硬さ・強さは低下する。記述が逆で誤り ❌**

4. 継ぎ目なし鋼管は高温高圧用配管に用いられる ✅

</details>

鋼道路橋に用いる高力ボルトに関する次の記述のうち、**適当でないもの**はどれか。

## 問題 No.18

地すべり防止工に関する次の記述のうち、**適当でないもの**はどれか。

1. 抑制工は、地下水状態等の自然条件を変化させ、地すべり運動を停止・緩和する工法である。

2. 水路工は、地表の水を水路に集め、速やかに地すべりの地域外に排除する工法である。

3. 排土工は、地すべり脚部の不安定土塊を排除し、地すべりの滑動力を減少させる工法である。

4. 抑止工は、杭等の構造物によって、地すべり運動の一部又は全部を停止させる工法である。

<details>
<summary>解答・解説</summary>

**正解: (3)**
