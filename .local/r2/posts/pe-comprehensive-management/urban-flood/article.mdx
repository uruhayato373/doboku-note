# 都市型水害

## 都市型水害とは

都市型水害とは、都市化の進展に伴い発生する特有の水害の総称である。

従来の河川氾濫（外水氾濫）に加え、排水能力を超える降雨による内水氾濫や、地下街・地下鉄への浸水など、都市特有の被害形態が問題となっている。

近年の気候変動による短時間集中豪雨の増加が、都市型水害のリスクをさらに高めている。

### 原因

都市型水害の発生には以下の要因が複合的に作用している。

| 要因 | メカニズム |
|---|---|
| **不浸透面の増大** | 舗装・建築物により雨水浸透が減少し、流出量が急増 |
| **流出時間の短縮** | 下水道・側溝による集水で洪水到達時間が短縮 |
| **遊水機能の喪失** | 水田・ため池等の開発で一時貯留機能が消失 |
| **下水道能力の限界** | 計画降雨強度（概ね50mm/h）を超える豪雨の頻発 |
| **地下空間の拡大** | 地下街・地下鉄・地下駐車場への浸水リスク増大 |
| **気候変動** | 短時間集中豪雨（ゲリラ豪雨）の頻度・強度の増加 |

### 被害特性

都市型水害は従来の河川氾濫と異なる以下の特性を持つ。

| 特性 | 内容 |
|---|---|
| **内水氾濫** | 下水道・水路の排水能力超過による市街地浸水 |
| **地下空間浸水** | 地下街・地下鉄では避難が困難で人命リスクが高い |
| **急激な水位上昇** | 流出時間の短縮により避難時間が確保できない |
| **広域同時多発** | 面的な市街地浸水が複数箇所で同時に発生 |
| **被害の集中** | 資産が集中する都市部で経済的損失が甚大 |

### 対策

都市型水害対策は、流域・下水道・河川・減災の4分類に体系化される。

- **流域対策 — 雨水貯留浸透施設**: 校庭・公園等の貯留、浸透ます・浸透トレンチ
- **流域対策 — 透水性舗装**: 舗装面からの雨水浸透を促進
- **下水道対策 — 雨水幹線・貯留管**: 大規模地下貯留施設の整備
- **下水道対策 — ポンプ場の増強**: 排水ポンプの能力増強
- **河川対策 — 調節池**: 河川沿いに洪水調節機能を付加
- **減災対策 — 内水ハザードマップ**: 浸水想定区域と避難情報の周知
- **減災対策 — 地下空間の止水対策**: 止水板、防水扉の設置
- **減災対策 — リアルタイム情報提供**: 水位情報・降雨レーダーの活用

## 総合技術監理における位置づけ

総合技術監理キーワード集では[**6.2 地域環境問題**](/docs/pe-comprehensive-management-keyword-2026#62-地域環境問題)に位置づけられる。

都市型水害対策は安全管理（人命保護、施設の安全確保）と社会環境管理（都市計画と流域管理の統合）の接点に位置する。グリーンインフラやEco-DRRの考え方を取り入れた雨水浸透・貯留施設の整備は、防災と環境保全の両立を図るものであり、経済性管理の視点からライフサイクルコスト評価も求められる。

## 参考資料

### 公的資料

- **国土交通省 水管理・国土保全局「都市の水害対策」** — 内水浸水想定区域図の作成・公表、流域治水の方向性、雨水幹線・貯留施設整備の施策概要を網羅する。[国土交通省 水管理・国土保全局 HP](https://www.mlit.go.jp/mizukokudo/)
- **内閣府防災「水害対応タイムライン策定ガイド」** — 避難勧告・指示の発令タイミングと住民避難の時系列を示した実務ガイド。都市型水害での地下空間避難誘導計画立案に直結する。[内閣府防災 HP](https://www.bousai.go.jp/)
- **気象庁「キキクル（危険度分布）」** — 短時間強雨リスクのリアルタイム分布情報。都市型水害の早期警戒に活用され、自治体の避難行動と連動する。[気象庁 HP](https://www.jma.go.jp/bosai/risk/)

### 民間・学術資料

- **建設技術研究所「都市型水害と流域治水の実務解説」** — 雨水幹線・貯留管・グリーンインフラの計画設計手法を解説した実務資料。技術士建設部門の業務と直結する施設計画の参考となる。[建設技術研究所 HP](https://www.ctie.co.jp/)
- **東京海上日動「水害リスクと事業継続計画（BCP）策定ガイド」** — 水害による操業停止・サプライチェーン断絶リスクを定量評価し、BCP策定に活用する手法を解説。経済性管理の視点でライフサイクルコスト評価を行う際に参照価値が高い。[東京海上日動 HP](https://www.tokiomarine-nichido.co.jp/)
