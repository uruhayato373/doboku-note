# 高年齢者雇用安定法

## 高年齢者雇用安定法とは

**高年齢者雇用安定法**（正式名称：高年齢者等の雇用の安定等に関する法律、昭和46年法律第68号）は、高年齢者の安定した雇用の確保と再就職の促進を図る法律である。

少子高齢化の進展と年金支給開始年齢の引上げに対応し、高年齢者が意欲と能力に応じて働き続けられる環境整備を目的としている。

## 法律の概要

| 項目 | 内容 |
|---|---|
| **正式名称** | 高年齢者等の雇用の安定等に関する法律（昭和46年法律第68号） |
| **目的** | 高年齢者の安定した雇用の確保、再就職の促進、就業の機会の確保 |
| **適用範囲** | 常時雇用する労働者を有するすべての事業主 |
| **所管** | 厚生労働省 |
| **定義** | 高年齢者＝55歳以上の者 |

## 65歳までの雇用確保措置（義務）

事業主は、定年を65歳未満に定めている場合、以下のいずれかの措置を講じなければならない（第9条）。

| 措置 | 内容 |
|---|---|
| **① 定年の引上げ** | 定年年齢を65歳以上に引き上げる |
| **② 継続雇用制度の導入** | 65歳まで希望者全員を対象とする再雇用制度等の導入 |
| **③ 定年の廃止** | 定年制そのものを廃止する |

### 企業の対応状況（2024年）

| 措置 | 割合 |
|---|---|
| **定年の引上げ** | 約26% |
| **継続雇用制度** | 約69% |
| **定年の廃止** | 約4% |

## 70歳までの就業確保措置（努力義務）

2021年4月の改正により、65歳から70歳までの就業機会を確保するための措置が努力義務として追加された（第10条の2）。

| 措置 | 内容 | 雇用 / 非雇用 |
|---|---|---|
| **① 定年の引上げ** | 定年年齢を70歳以上に引き上げる | 雇用 |
| **② 継続雇用制度の導入** | 70歳まで継続雇用する制度（グループ会社・他社への再雇用含む） | 雇用 |
| **③ 定年の廃止** | 定年制を廃止する | 雇用 |
| **④ 業務委託契約** | 70歳まで継続的に業務委託契約を締結する制度（創業支援等措置） | 非雇用 |
| **⑤ 社会貢献活動への従事** | 70歳まで社会貢献事業に従事できる制度（創業支援等措置） | 非雇用 |

## 高年齢者雇用状況等報告

| 項目 | 内容 |
|---|---|
| **報告義務** | 常時雇用する労働者が21人以上の事業主は毎年6月1日時点の状況を報告 |
| **報告内容** | 定年・継続雇用制度の状況、高年齢者の雇用状況 |
| **報告先** | ハローワーク |

## その他の施策

| 施策 | 内容 |
|---|---|
| **高年齢者雇用確保措置の指導・助言** | 未実施の事業主に対し労働局が指導・助言、勧告、企業名公表 |
| **シルバー人材センター** | 高年齢者に臨時的・短期的な就業機会を提供する公益法人 |
| **高年齢者雇用安定助成金** | 65歳超への定年引上げ等を実施した事業主に助成 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では[**3.2 労働関係法と労務管理**](/docs/pe-comprehensive-management-keyword-2026#32-労働関係法と労務管理)に位置づけられる。

高年齢者雇用安定法は、少子高齢社会における労働力確保と人的資源の有効活用に関する法律である。

総合技術監理の観点では、建設業における熟練技能者の知識・経験の継承、高年齢労働者の安全管理（労働災害リスクの増加）、人件費への影響（経済性管理）が重要なテーマとなる。
