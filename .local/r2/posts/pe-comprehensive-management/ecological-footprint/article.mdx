# エコロジカル・フットプリント

## エコロジカル・フットプリントとは

エコロジカル・フットプリント（Ecological Footprint: EF）は、人間の活動が自然環境に与える負荷を「土地面積」に換算して定量的に示す指標である。

1990年代にカナダのブリティッシュコロンビア大学のマティス・ワケナゲルとウィリアム・リースによって提唱された。

人間が消費する資源の生産と廃棄物の吸収に必要な生態学的に生産力のある土地・水域面積を「グローバルヘクタール（gha）」の単位で表し、地球の生物生産力（バイオキャパシティ）と比較することで、持続可能性を評価する。

## 歴史・背景

エコロジカル・フットプリントの概念は、1990年代初頭にカナダのブリティッシュコロンビア大学のウィリアム・リース教授とその学生だったマティス・ワケナゲルによって開発された。

リースは1980年代後半から、人間が地球の生態系に与える負荷を定量化する方法を模索していた。当初は「収奪された環境収容力（Appropriated Carrying Capacity）」という概念として考案されたが、この名称が難解であったため、人間活動が地球に刻む「足跡（フットプリント）」という比喩を用いた現在の名称に改められた。1992年のリースの論文が「エコロジカル・フットプリント」という用語の初出とされる。

この指標が生まれた背景には、1972年のローマクラブ報告書「成長の限界」が提起した資源枯渇・環境破壊への警告があった。しかし、「成長の限界」は定性的・シナリオ的な分析にとどまっており、現実の消費行動がどの程度の生態系負荷を生じているかを土地面積という具体的な数値で示すツールは存在しなかった。エコロジカル・フットプリントは、この問いに応える形で開発された。

1996年にワケナゲルとリースが著書でこの概念を広く発表すると、国際的な環境政策の場で急速に普及した。2003年にはワケナゲルを中心として「グローバル・フットプリント・ネットワーク（GFN）」が設立され、各国・地域のデータを集約したデータベースが整備された。現在ではGFNが毎年「ナショナル・フットプリント・アカウント」を更新し、各国のEFと地球全体のバイオキャパシティを比較する標準的な指標として広く参照されている。

日本でも環境省が平成30年版環境白書でEFを取り上げ、国際比較の観点から日本の生態系への依存度が高いことを示している。建設部門でも、大規模インフラの整備が土地改変・資材消費を通じてEFを増大させることから、環境配慮設計の評価指標として参照されている。

### 計算の構成要素

| 構成要素 | 内容 |
|---|---|
| **耕作地** | 食料・繊維の生産に使われる農地 |
| **牧草地** | 畜産物の生産に使われる土地 |
| **森林地** | 木材・紙の生産に使われる森林 |
| **漁場** | 水産物の採取に使われる水域 |
| **市街地** | 建物・インフラに占有される土地 |
| **カーボン・フットプリント** | CO2排出を吸収するために必要な森林面積（最大の構成要素） |

### 地球何個分

エコロジカル・フットプリントが地球のバイオキャパシティを超えると「エコロジカル・オーバーシュート」となる。

| 指標 | 値（2024年時点） |
|---|---|
| **世界平均EF** | 約2.8 gha/人 |
| **地球のバイオキャパシティ** | 約1.6 gha/人 |
| **地球何個分** | 約1.7個分（人類全体で地球1.7個分の資源を消費） |
| **オーバーシュート開始年** | 1970年代前半 |

### 主要国の比較

| 国 | EF（gha/人） | 地球何個分 |
|---|---|---|
| **アメリカ** | 約8.0 | 約5.0 |
| **オーストラリア** | 約6.6 | 約4.1 |
| **日本** | 約4.7 | 約2.9 |
| **中国** | 約3.7 | 約2.3 |
| **インド** | 約1.2 | 約0.7 |

### アース・オーバーシュート・デー

その年の人類のエコロジカル・フットプリントが地球のバイオキャパシティと等しくなる日を「アース・オーバーシュート・デー」と呼ぶ。

この日以降は、地球が1年間で再生できる以上の資源を消費していることを意味する。

2024年のオーバーシュート・デーは8月1日であり、年々早まる傾向にある。
