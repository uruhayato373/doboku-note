# ステーク・ホルダー

## ステークホルダーとは

**ステークホルダー（Stakeholder：利害関係者）** とは、組織やプロジェクトの活動によって影響を受ける、または影響を与えることができる個人・グループ・組織のことである。Freemanにより1984年に体系化された概念で、株主（ストックホルダー）だけでなく、従業員・顧客・地域住民・行政機関等を含む。

## 公共事業の主なステークホルダー

| ステークホルダー | 関心事 |
|---|---|
| **発注者（行政機関）** | 事業目的の達成、予算・工期の遵守 |
| **受注者（建設会社）** | 利益の確保、品質・安全の実現 |
| **地域住民** | 生活環境への影響、利便性の向上 |
| **利用者** | 施設の機能・安全性・利便性 |
| **関係行政機関** | 法令遵守、許認可条件の履行 |
| **環境団体** | 自然環境・生態系への影響 |
| **金融機関・投資家** | 事業の採算性・リスク |
| **下請業者** | 受注・利益の確保、安全な労働環境 |

## ステークホルダー分析

### 権力／関心マトリクス

| | 関心度：高 | 関心度：低 |
|---|---|---|
| **権力：高** | 密接に管理（Key Player） | 満足させ続ける |
| **権力：低** | 情報を提供し続ける | 最小限の対応 |

## ステークホルダー・エンゲージメント

| レベル | 内容 |
|---|---|
| **不認知** | プロジェクトの存在を知らない |
| **抵抗** | プロジェクトに反対している |
| **中立** | 賛成でも反対でもない |
| **支持** | プロジェクトを支持している |
| **主導** | 積極的にプロジェクトを推進 |

## マネジメントの手順

| ステップ | 内容 |
|---|---|
| **1. 特定** | すべてのステークホルダーを洗い出す |
| **2. 分析** | 権力・関心・態度・影響度を評価 |
| **3. 計画** | 各ステークホルダーへの対応戦略を策定 |
| **4. 実行** | コミュニケーション計画に基づく関与 |
| **5. 監視** | ステークホルダーの態度変化を継続的に監視 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**4.2 コミュニケーションと合意形成**」に位置づけられる。

ステークホルダー管理はコミュニケーション計画・住民参加・社会的受容（PA）・パブリックリレーションズの前提であり、すべての合意形成活動の出発点となる。
