# 職務給

## 職務給とは

職務給とは、従業員が担当する職務（仕事）の内容・難易度・責任の大きさに基づいて賃金を決定する賃金制度である。

「同一職務・同一賃金」の原則に基づき、誰がその職務を担当するかにかかわらず、職務そのものの価値によって賃金が決まる点が最大の特徴である。

欧米企業では職務給が主流であり、日本では近年のジョブ型雇用の広がりとともに導入が進んでいる。

### 職務給の導入プロセス

| ステップ | 内容 |
|---|---|
| **職務分析** | 各職務の内容、必要な知識・技能、責任、作業条件等を体系的に調査・記述 |
| **職務記述書の作成** | 職務分析の結果を文書化（職務名、目的、主要な責務、必要資格等） |
| **職務評価** | 各職務の相対的な価値を評価（序列法、分類法、点数法、要素比較法等） |
| **職務等級の設定** | 職務評価の結果に基づき職務を等級に格付け |
| **賃金レンジの設定** | 各等級に対応する賃金の範囲（最低額〜最高額）を設定 |

### 職務評価の方法

| 方法 | 概要 | 特徴 |
|---|---|---|
| **序列法** | 職務全体を比較して順位づけ | 簡便だが大規模組織には不向き |
| **分類法** | あらかじめ等級基準を定め、各職務を当てはめる | 公務員制度で広く採用 |
| **点数法** | 評価要素ごとに点数を付与し合計で評価 | 客観的だが導入コストが高い |
| **要素比較法** | 評価要素ごとに基準職務と比較して賃率を決定 | 精緻だが複雑 |

### メリット・デメリット

| 項目 | 内容 |
|---|---|
| **メリット** | 賃金の公正性・透明性が高い、同一労働同一賃金に適合、人件費の予測が容易、中途採用者の処遇が明確 |
| **デメリット** | 職務分析・評価のコストが大きい、職務変更時の柔軟性に欠ける、職務の固定化が起こりやすい、チームワークが阻害されるリスク |

### 職能給との比較

| 比較項目 | 職務給 | 職能給 |
|---|---|---|
| **基準** | 職務（仕事）の価値 | 人（職務遂行能力） |
| **賃金決定** | 担当する職務で決定 | 保有する能力で決定 |
| **異動時** | 職務変更で賃金が変動 | 能力は下がらないため賃金維持 |
| **年功的運用** | なりにくい | なりやすい |
| **普及** | 欧米で主流 | 日本で広く普及 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では[**3.2 労働関係法と労務管理**](/docs/pe-comprehensive-management-keyword-2026#32-労働関係法と労務管理)に位置づけられる。

職務給は個別賃金管理の中核的な賃金決定方式の一つであり、職能給、成果主義賃金、年功賃金と対比して理解する必要がある。

ジョブ型雇用への移行や同一労働同一賃金の実現といった近年の人事制度改革の文脈で出題される可能性が高いテーマである。
