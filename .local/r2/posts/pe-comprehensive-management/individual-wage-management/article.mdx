# 個別賃金管理

## 個別賃金管理とは

個別賃金管理とは、個々の従業員に支払う賃金の水準・構成・昇給を管理する手法である。

総額賃金管理が企業全体の人件費総額を管理するマクロ的視点であるのに対し、個別賃金管理は従業員一人ひとりの賃金をミクロ的視点から管理する。

個別賃金管理の目的は、従業員の能力・職務・成果に応じた公正な賃金を実現し、モチベーションと生産性の向上を図ることにある。

### 賃金体系の構成

| 区分 | 内容 |
|---|---|
| **基本給** | 賃金の根幹部分。年齢給、勤続給、職能給、職務給、役割給等で構成 |
| **諸手当** | 役職手当、家族手当、住宅手当、通勤手当、資格手当等 |
| **賞与** | 夏季・冬季の一時金。業績連動型と固定型がある |
| **退職金** | 退職時に支給。基本給連動型、ポイント制、確定拠出年金型等 |

### 基本給の決定方式

| 方式 | 基準 | 特徴 |
|---|---|---|
| **年齢給** | 年齢 | 生活保障の性格が強い、年功的 |
| **勤続給** | 勤続年数 | 長期勤続を評価、企業への忠誠心を促進 |
| **職能給** | 職務遂行能力 | 能力の蓄積を評価、日本企業で広く普及 |
| **職務給** | 職務の価値 | 職務分析に基づく、同一職務同一賃金 |
| **役割給** | 役割の大きさ | 期待される役割で決定、成果との連動がしやすい |
| **成果給** | 業績・成果 | 結果に応じた処遇、変動部分が大きい |

### 賃金カーブ

賃金カーブとは、横軸に年齢（または勤続年数）、縦軸に賃金水準をとったグラフのことである。

| 類型 | 特徴 |
|---|---|
| **年功型** | 年齢とともに賃金が上昇し続ける。勾配が急 |
| **能力重視型** | 若年期は上昇するが、中高年期は能力差で賃金が分散 |
| **成果重視型** | 年齢による上昇は小さく、成果により大きく変動 |
| **フラット型** | 年齢による上昇がほとんどなく、職務や成果で決定 |

### 個別賃金管理の主要課題

| 課題 | 内容 |
|---|---|
| **内部公平性** | 社内の他の従業員と比較して公正な賃金水準であるか |
| **外部競争性** | 同業他社・労働市場と比較して競争力のある賃金水準であるか |
| **個人貢献度の反映** | 能力・成果に応じた処遇が実現できているか |
| **生活保障** | 従業員の生活を安定的に支える水準であるか |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**3.2 労働関係法と労務管理**」に位置づけられる。

個別賃金管理は従業員のモチベーション管理と人材確保・定着に直結するテーマであり、職能給、職務給、成果主義賃金、年功賃金といった関連キーワードと一体的に理解する必要がある。

総額賃金管理との関係では、企業全体の支払能力（マクロ）の制約のもとで個別の賃金配分（ミクロ）をいかに最適化するかが問われる。
