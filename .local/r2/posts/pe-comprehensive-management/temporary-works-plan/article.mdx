# 仮設計画

## 仮設計画とは

**仮設計画** とは、本体構造物の施工に必要な仮設構造物（足場・支保工・土留め・仮設道路等）の設計・配置・施工手順・安全対策を定める計画のことである。工事の安全性と効率性を左右する重要な計画である。

## 指定仮設と任意仮設

| 区分 | 内容 | 設計変更 |
|---|---|---|
| **指定仮設** | 発注者が仕様・構造を指定 | 変更可能（設計変更対象） |
| **任意仮設** | 施工者が自由に計画・設計 | 原則変更不可（施工者責任） |

## 主な仮設構造物

| 種類 | 内容 |
|---|---|
| **足場** | 枠組足場・単管足場・くさび緊結式足場 |
| **型枠支保工** | パイプサポート・枠組支保工・鋼製支柱 |
| **土留め** | 鋼矢板・親杭横矢板・SMW壁・地中連続壁 |
| **仮設道路** | 工事車両の搬入出路・仮設橋 |
| **仮設排水** | 釜場排水・ウェルポイント・ディープウェル |
| **仮囲い** | 工事区域の安全囲い・防音壁 |

## 仮設計画の策定手順

| ステップ | 内容 |
|---|---|
| **1. 現地条件の把握** | 地形・地質・地下水位・近隣環境の調査 |
| **2. 施工方法の決定** | 本体工事の工法に応じた仮設の選定 |
| **3. 構造計算** | 仮設構造物の安定計算・強度計算 |
| **4. 配置計画** | 仮設備・仮設構造物のレイアウト |
| **5. 安全対策** | 墜落防止・倒壊防止・第三者災害防止 |
| **6. 環境対策** | 騒音・振動・濁水・地盤沈下対策 |

## 仮設構造物の設計上の留意点

| 留意点 | 内容 |
|---|---|
| **安全率** | 仮設は本体構造に比べ使用期間が短いが、安全性は確保 |
| **作用荷重** | 施工荷重・風荷重・地震荷重の考慮 |
| **地盤条件** | 支持力・変形・地下水の影響 |
| **転用・再利用** | 仮設材の経済的な転用計画 |
| **解体計画** | 安全な撤去手順の事前計画 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**2.1 事業企画と計画**」に位置づけられる。

仮設計画は安全管理と経済性管理の接点であり、工事計画・工法計画・安全衛生計画と一体的に策定する。任意仮設では施工者の技術力と判断力が問われる。
