## 緊急時情報システム・サービスとは

**緊急時情報システム・サービス** とは、災害・事故等の緊急事態において、迅速かつ確実に情報を収集・伝達するために整備されたシステムおよびサービスの総称である。国・地方自治体・通信事業者が協力して運用する。

## 緊急時情報の 3 つのサービス分類

教材『情報管理』では、緊急時に提供される情報サービスを目的別に **3 つの分類**で整理している。後述の個別システム（J-ALERT 等）はこの 3 分類の組合せで運用される。

- **緊急速報サービス**: エリア内の契約者全員に情報を伝達するサービス — 例: エリアメール、緊急速報メール、J-ALERT
- **安否確認サービス**: 従業員等の安否状況の登録を依頼し、集計結果を組織の管理者に通知するサービス — 例: 企業向け安否確認システム、家族間安否確認アプリ
- **被害予測システム**: 過去の同種災害データと照らして被害推計を行い、迅速な救出・救援対応につなげるシステム — 例: 国の被害推計システム、自治体の災害被害想定システム

「情報を **届ける**（緊急速報）」「**集める**（安否確認）」「**予測して対応につなげる**（被害予測）」の 3 機能の連携が、緊急時情報管理の全体像を構成する。

## 主な緊急時情報システム

各システムの運用主体と機能は以下のとおりである。

- **J-ALERT（全国瞬時警報）**: 消防庁 — 弾道ミサイル・津波・緊急地震速報等を自動伝達
- **L-ALERT（災害情報共有）**: 総務省 — 自治体の避難情報等を多様なメディアに一斉配信
- **緊急地震速報**: 気象庁 — P波検知で主要動到達前に地震情報を発信
- **津波警報・注意報**: 気象庁 — 津波の予想高さ・到達時刻を発表
- **防災行政無線**: 市町村 — 同報系無線で住民に直接伝達
- **エリアメール・緊急速報メール**: 通信事業者 — 特定エリアの携帯端末に一斉配信

## 歴史・背景

日本における緊急時情報伝達体制は、大規模災害のたびに課題が顕在化し、制度的整備が重ねられてきた歴史を持つ。

防災行政無線（同報系）は1950年代から整備が始まり、1961年の**災害対策基本法**制定を機に市町村レベルでの普及が加速した。しかし音声による一方向伝達は聞き取り困難・情報量の制約という問題を抱え、後続システムの必要性が示されていた。

転機となったのは1995年の**阪神・淡路大震災**である。通信インフラの集中的な被災と情報伝達の遅れが多数の二次被害を招いたことを教訓に、国は「情報の多重化・冗長化」を防災政策の柱とした。これを受けて2004年に**J-ALERT**（全国瞬時警報システム）の開発が開始され、2007年2月より運用が始まった。衛星回線と地上回線の二重化により、人手を介さず数秒以内に住民端末へ情報が届く仕組みが実現された。

並行して、2007年の**新潟県中越沖地震**や2011年の**東日本大震災**を経て、携帯電話網を活用したエリアメール（NTTドコモ、2007年）・緊急速報メール（KDDI/ソフトバンク、2010年〜）が普及した。また避難情報の一元配信を目的とした**L-ALERT**（災害情報共有システム）が2011年6月に運用を開始し、2019年4月に全都道府県での利用が完了した。

こうした多層的な整備の結果、現在では弾道ミサイル情報から局地的な豪雨警戒情報まで、複数の伝達手段が相互補完する体制が確立されている。

## 情報伝達の多重化

| 手段 | 特徴 |
|---|---|
| **防災行政無線** | 屋外スピーカーで広域に伝達（聞こえにくい場合あり） |
| **携帯電話（エリアメール）** | 個人端末に直接到達（通信輻輳の影響あり） |
| **テレビ・ラジオ** | 広範囲に伝達（停電時はラジオが有効） |
| **インターネット** | 詳細情報の提供（通信障害リスク） |
| **サイレン・半鐘** | 原始的だが確実（電源不要） |
| **SNS** | 即時拡散（デマのリスク） |

## 建設現場での緊急情報システム

| システム | 内容 |
|---|---|
| **現場内緊急連絡網** | 電話・無線・サイレンによる連絡体制 |
| **安否確認システム** | 作業員の安否を一斉確認するシステム |
| **気象情報サービス** | 工事現場向けのリアルタイム気象情報 |
| **河川水位情報** | 国土交通省「川の防災情報」等のリアルタイムデータ |
| **CCTV監視** | 現場・周辺の映像によるリアルタイム状況把握 |

## 課題と対策

| 課題 | 対策 |
|---|---|
| **情報伝達の空白** | 多重化（複数手段の併用） |
| **通信途絶** | 衛星通信・MCA無線等のバックアップ回線 |
| **情報の信頼性** | 公式情報源の明確化、デマ対策 |
| **要配慮者への伝達** | 多言語・視覚・聴覚障害者対応 |

## 総合技術監理における位置づけ


総合技術監理キーワード集では[**4.2 コミュニケーション**](/docs/pe-comprehensive-management-keyword-2026#42-コミュニケーション)に位置づけられる。

緊急時情報システムは情報管理と安全管理の接点であり、緊急時の情報処理・BCP・危機管理と連動する。平時からのシステム整備と運用訓練が不可欠である。
