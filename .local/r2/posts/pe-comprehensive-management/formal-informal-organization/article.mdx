## 公式組織と非公式組織とは

組織は**公式組織（フォーマル組織）** と**非公式組織（インフォーマル組織）** の2つの側面を持つ。2つの区分はそれぞれ定義と特徴が異なる。

- **公式組織**: 組織図・規程等で公式に定められた組織構造 — 権限・責任が明確、目標達成のための合理的設計
- **非公式組織**: 人間関係・共通関心等から自然発生的に形成される集団 — 情緒的結合、暗黙のルール、組織図に表れない

## 理論的背景

公式組織・非公式組織の概念を形成した主要な理論と提唱者は以下の通りである。

- **組織の3要素**: バーナード（1938） — 共通目的・貢献意欲・コミュニケーションが組織成立の条件
- **ホーソン実験**: メイヨー・レスリスバーガー（1927〜32） — 非公式組織が生産性に大きく影響することを発見
- **官僚制組織論**: ウェーバー — 公式組織の合理的設計（規則・階層・文書主義）

## 非公式組織の機能

非公式組織は組織に対して正の機能と負の機能の両面をもたらす。それぞれの機能を整理すると以下の通りである。

| 機能 | 内容 |
|---|---|
| **正の機能** | |
| 情報伝達の補完 | 公式ルートでは伝わらない情報の共有 |
| 帰属意識の醸成 | メンバー間の連帯感・モチベーション向上 |
| 相互扶助 | 困りごとの助け合い、暗黙知の伝達 |
| **負の機能** | |
| 排他性 | 内集団と外集団の対立、いじめ・派閥 |
| 変革への抵抗 | 既存の慣行を守ろうとする保守性 |
| 非公式規範の圧力 | 集団規範への同調圧力（能率制限） |

## 建設現場での具体例

建設現場では公式組織と非公式組織が場面ごとに異なる形で機能する。各場面における両者の役割は以下の通りである。

- **指揮命令**: 公式組織 — 現場代理人→工事主任→職長→作業員 / 非公式組織 — ベテラン職人を中心とした技能伝承
- **安全管理**: 公式組織 — 安全衛生協議会、安全パトロール / 非公式組織 — 職人同士の声かけ、危険の口伝え
- **情報共有**: 公式組織 — 朝礼、工程会議、安全掲示板 / 非公式組織 — 昼食時の雑談、休憩所での情報交換
- **問題解決**: 公式組織 — クレーム処理手順、設計変更手続き / 非公式組織 — 経験者への相談、他現場の知恵の活用

## 公式組織・非公式組織概念の歴史的背景

公式組織・非公式組織の二分論が確立するには、20世紀前半の組織論の転換が必要だった。

19世紀末から20世紀初頭の科学的管理法（テイラー）は、作業効率を物理的・技術的条件で説明しようとした。人間を「合理的経済人」として捉え、賃金と条件が整えば生産性は向上するという前提に立っていた。

この前提を覆したのがホーソン実験（1927〜1932年）である。ウェスタン・エレクトリック社での一連の実験は、照明や休憩時間などの物的条件と生産性の間に明確な相関を見出せず、むしろ実験参加者が「観察されている」という意識や、職場での仲間意識が生産性に影響することを示した。この発見はメイヨーとレスリスバーガーによって「人間関係論」として体系化された。

バーナード（1938年）は組織の公式・非公式の二元論を理論化した。バーナードは非公式組織を「意識された共通目的を持たない接触や相互作用」と定義し、公式組織はその上に成立すると論じた。この視点は、組織管理において規程や権限関係だけでなく、自然発生的な人間関係の網の目を設計の対象として捉える必要性を示した。
