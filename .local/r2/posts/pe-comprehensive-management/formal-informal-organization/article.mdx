# 公式組織・非公式組織

## 公式組織と非公式組織とは

組織は**公式組織（フォーマル組織）** と**非公式組織（インフォーマル組織）** の2つの側面を持つ。

| 区分 | 定義 | 特徴 |
|---|---|---|
| **公式組織** | 組織図・規程等で公式に定められた組織構造 | 権限・責任が明確、目標達成のための合理的設計 |
| **非公式組織** | 人間関係・共通関心等から自然発生的に形成される集団 | 情緒的結合、暗黙のルール、組織図に表れない |

## 理論的背景

| 理論 | 提唱者 | 内容 |
|---|---|---|
| **組織の3要素** | バーナード（1938） | 共通目的・貢献意欲・コミュニケーションが組織成立の条件 |
| **ホーソン実験** | メイヨー・レスリスバーガー（1927〜32） | 非公式組織が生産性に大きく影響することを発見 |
| **官僚制組織論** | ウェーバー | 公式組織の合理的設計（規則・階層・文書主義） |

## 非公式組織の機能

| 機能 | 内容 |
|---|---|
| **正の機能** | |
| 情報伝達の補完 | 公式ルートでは伝わらない情報の共有 |
| 帰属意識の醸成 | メンバー間の連帯感・モチベーション向上 |
| 相互扶助 | 困りごとの助け合い、暗黙知の伝達 |
| **負の機能** | |
| 排他性 | 内集団と外集団の対立、いじめ・派閥 |
| 変革への抵抗 | 既存の慣行を守ろうとする保守性 |
| 非公式規範の圧力 | 集団規範への同調圧力（能率制限） |

## 建設現場での具体例

| 場面 | 公式組織 | 非公式組織 |
|---|---|---|
| **指揮命令** | 現場代理人→工事主任→職長→作業員 | ベテラン職人を中心とした技能伝承 |
| **安全管理** | 安全衛生協議会、安全パトロール | 職人同士の声かけ、危険の口伝え |
| **情報共有** | 朝礼、工程会議、安全掲示板 | 昼食時の雑談、休憩所での情報交換 |
| **問題解決** | クレーム処理手順、設計変更手続き | 経験者への相談、他現場の知恵の活用 |
