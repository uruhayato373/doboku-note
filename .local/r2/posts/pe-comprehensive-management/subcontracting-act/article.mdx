# 下請法

## 下請法とは

**下請法** とは、親事業者による下請事業者に対する優越的地位の濫用を規制し、下請取引の公正化と下請事業者の利益保護を図る法律である。

独占禁止法の補完法として1956年に制定され、公正取引委員会と中小企業庁が共同で運用する。

親事業者が下請事業者に対して不当な代金減額や支払遅延などを行うことを禁止し、取引条件の書面交付や代金の支払期日遵守を義務づけている。

### 適用要件（資本金区分）

下請法の適用は、親事業者と下請事業者の**資本金の額**および**取引の内容**によって決まる。

| 取引内容 | 親事業者 | 下請事業者 |
|---|---|---|
| **製造委託・修理委託** | 資本金3億円超 | 資本金3億円以下 |
| 同上 | 資本金1千万円超3億円以下 | 資本金1千万円以下 |
| **情報成果物作成委託・役務提供委託** | 資本金5千万円超 | 資本金5千万円以下 |
| 同上 | 資本金1千万円超5千万円以下 | 資本金1千万円以下 |

なお、**建設工事の請負**は下請法の対象外であり、建設業法が適用される。

ただし、建設業者が行う資材の製造委託や設計業務の委託などは下請法の対象となりうる。

### 親事業者の4つの義務

| 義務 | 内容 |
|---|---|
| **書面の交付義務** | 発注に際して、下請事業者の給付内容・下請代金の額・支払期日等を記載した書面を直ちに交付する |
| **書類の作成・保存義務** | 下請取引に関する書類を作成し、2年間保存する |
| **支払期日を定める義務** | 下請代金の支払期日を、給付を受領した日から起算して60日以内のできる限り短い期間内に定める |
| **遅延利息の支払義務** | 支払期日までに下請代金を支払わなかったときは、受領日から起算して60日を経過した日から遅延利息（年率14.6%）を支払う |

### 11の禁止行為

| 分類 | 禁止行為 | 概要 |
|---|---|---|
| **代金関連** | 下請代金の減額 | 正当な理由なく下請代金を減額すること |
| 同上 | 下請代金の支払遅延 | 支払期日を過ぎても下請代金を支払わないこと |
| 同上 | 割引困難な手形の交付 | 一般の金融機関で割引を受けることが困難な手形を交付すること |
| **受領関連** | 受領拒否 | 下請事業者に責任がないのに給付の受領を拒むこと |
| 同上 | 返品 | 下請事業者に責任がないのに給付を受領した後に返品すること |
| **購入・利用強制** | 購入・利用強制 | 正当な理由なく指定する物品等を強制的に購入させること |
| **その他** | 報復措置 | 公正取引委員会等に申告したことを理由に不利益な取扱いをすること |
| 同上 | 有償支給原材料等の対価の早期決済 | 有償支給した原材料等の対価を下請代金の支払期日前に相殺・支払わせること |
| 同上 | 不当な経済上の利益の提供要請 | 下請事業者に対し金銭・役務等の経済上の利益を不当に提供させること |
| 同上 | 不当な給付内容の変更・やり直し | 下請事業者に責任がないのに給付内容の変更・やり直しを行わせ、費用を負担しないこと |
| 同上 | 買いたたき | 通常支払われる対価に比べて著しく低い下請代金を不当に定めること |

## 総合技術監理における位置づけ

総合技術監理キーワード集では[**4.3 知的財産権と情報の保護と活用**](/docs/pe-comprehensive-management-keyword-2026#43-知的財産権と情報の保護と活用)に位置づけられる。

下請法は経済性管理における調達・外注管理と密接に関連する。

親事業者として下請事業者に業務を委託する場合、下請法の義務を遵守した契約管理・支払管理体制の整備が求められる。

また、独占禁止法・建設業法との適用区分を正しく理解し、取引類型に応じた法令遵守（コンプライアンス）を実践することが、総合技術監理における社会環境管理の観点からも重要である。
