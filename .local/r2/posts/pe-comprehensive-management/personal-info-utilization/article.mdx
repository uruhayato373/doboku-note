# 個人情報の活用・流通

## 個人情報の活用・流通とは

**個人情報の活用・流通**とは、個人の権利利益を保護しながらパーソナルデータを社会的に有効活用するための制度・基盤の総称である。

Society 5.0の実現に向けて、個人に関するデータの安全かつ円滑な流通を促進するため、情報銀行・PDS（パーソナルデータストア）・データ取引市場などの仕組みが整備されつつある。

政府は「官民データ活用推進基本法」（2016年）を制定し、データの利活用を国の基本施策として位置づけている。

## パーソナルデータ流通の3つの仕組み

- **情報銀行（情報利用信用銀行）**
  - 定義: 個人からデータの管理・提供を委任され、本人の同意に基づいて第三者に提供する事業者
  - 特徴: 本人に代わり提供先を判断。認定制度あり（総務省・経産省）
- **PDS（パーソナルデータストア）**
  - 定義: 個人が自分のデータを蓄積・管理し、提供先を自ら選択するシステム
  - 特徴: 個人が主体的にデータを管理。分散型の仕組み
- **データ取引市場**
  - 定義: データの売り手と買い手をマッチングするプラットフォーム
  - 特徴: 匿名加工情報・統計データ等を取引。透明性の確保が課題

## 法制度と政策

| 法令・政策 | 内容 |
|---|---|
| **官民データ活用推進基本法（2016年）** | データ活用を国の基本施策に位置づけ。官民データ活用推進計画の策定義務 |
| **個人情報保護法（匿名加工情報）** | 匿名加工情報の制度化によりビッグデータ活用の法的基盤を整備 |
| **個人情報保護法（仮名加工情報）** | 2020年改正で仮名加工情報を新設し社内分析を促進 |
| **データ戦略（デジタル庁）** | ベースレジストリ整備、データ連携基盤の構築 |
| **DFFT（信頼性のある自由なデータ流通）** | 日本提唱の国際的データ流通枠組み（2019年G20大阪） |

## 事業者の義務（個人情報の流通に関するもの）

| 義務 | 内容 |
|---|---|
| **利用目的の特定・通知** | データの収集時に利用目的を明確にし本人に通知 |
| **本人同意の取得** | 第三者提供時は原則として本人の同意が必要 |
| **トレーサビリティの確保** | 第三者提供時の記録作成・保存義務（提供元・提供先双方） |
| **越境移転の制限** | 外国にある第三者への提供には本人同意＋移転先の体制確認が必要 |

## 違反時の制裁

| 制裁 | 内容 |
|---|---|
| **勧告・命令** | 個人情報保護委員会による是正勧告、命令 |
| **刑事罰** | 命令違反は1年以下の懲役または100万円以下の罰金 |
| **法人重科** | 法人に対しては1億円以下の罰金 |
| **民事責任** | 不適切な流通による損害賠償 |

## 建設・インフラ分野での活用事例

- **都市計画**
  - データ種別: 携帯電話位置情報（匿名加工）
  - 活用内容: 人流分析による都市計画・交通計画の策定
- **防災**
  - データ種別: 避難行動データ
  - 活用内容: 避難シミュレーション・避難計画の改善
- **インフラ維持管理**
  - データ種別: 利用者フィードバック
  - 活用内容: 施設の利用実態把握・改修計画への反映
- **スマートシティ**
  - データ種別: 多種データの統合活用
  - 活用内容: エネルギー最適化・交通制御・生活サービス向上
