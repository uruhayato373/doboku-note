# 同一労働同一賃金

## 同一労働同一賃金とは

同一労働同一賃金とは、同一の企業内において、正規雇用労働者と非正規雇用労働者（パートタイム労働者、有期雇用労働者、派遣労働者）の間の不合理な待遇差を解消することを目的とする原則である。

2018年の働き方改革関連法により、パートタイム・有期雇用労働法および労働者派遣法が改正され、法的に規定された。

大企業は2020年4月から、中小企業は2021年4月から適用されている。

### 均等待遇と均衡待遇

| 概念 | 内容 | 根拠条文 |
|---|---|---|
| **均等待遇** | 職務内容（業務の内容＋責任の程度）と職務内容・配置の変更の範囲が同じ場合、差別的取扱いを禁止 | パートタイム・有期雇用労働法9条 |
| **均衡待遇** | 職務内容、職務内容・配置の変更の範囲、その他の事情を考慮して不合理な待遇差を禁止 | 同法8条 |

### 待遇差の判断要素

不合理な待遇差かどうかは、以下の3要素を考慮して個々の待遇ごとに判断される。

| 判断要素 | 内容 |
|---|---|
| **職務の内容** | 業務の内容および当該業務に伴う責任の程度 |
| **職務内容・配置の変更の範囲** | 転勤の有無・範囲、職務内容の変更の有無・範囲 |
| **その他の事情** | 合理的な労使の慣行、成果、能力、経験、労使交渉の経緯等 |

### 待遇ごとの主な判断基準（ガイドライン）

| 待遇項目 | 基本的考え方 |
|---|---|
| **基本給** | 能力・経験、業績・成果、勤続年数に応じた部分について同一の支給を求める |
| **賞与** | 会社の業績等への貢献に応じて支給する場合、同一の貢献には同一の支給 |
| **各種手当** | 通勤手当、出張手当、食事手当等は同一の支給。役職手当は同一の役職には同一の支給 |
| **福利厚生** | 食堂・休憩室・更衣室の利用、慶弔休暇、健康診断等は同一の利用・付与 |
| **教育訓練** | 職務に必要な教育訓練は同一の実施 |

### 事業主の義務

| 義務 | 内容 |
|---|---|
| **待遇差の説明義務** | 非正規雇用労働者から求められた場合、正規との待遇差の内容・理由を説明する義務 |
| **行政ADR（裁判外紛争解決手続）** | 都道府県労働局で無料・非公開の紛争解決援助を利用可能 |
| **待遇の見直し** | 不合理な待遇差が認められる場合は是正措置が必要 |

### 主要判例

| 判例 | 争点・判旨 |
|---|---|
| **ハマキョウレックス事件（2018年最高裁）** | 各種手当の不支給が不合理と判断。手当ごとの個別判断の枠組みを確立 |
| **長澤運輸事件（2018年最高裁）** | 定年後再雇用者の賃金減額について、一部手当の不支給は不合理と判断 |
| **大阪医科薬科大学事件（2020年最高裁）** | アルバイト職員への賞与不支給は不合理とまではいえないと判断 |
| **メトロコマース事件（2020年最高裁）** | 契約社員への退職金不支給は不合理とまではいえないと判断 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では[**3.2 労働関係法と労務管理**](/docs/pe-comprehensive-management-keyword-2026#32-労働関係法と労務管理)に位置づけられる。

同一労働同一賃金は個別賃金管理、職務給、成果主義賃金と密接に関連するテーマであり、雇用形態にかかわらない公正な処遇の実現を求めるものである。

建設業では技能労働者の処遇改善が担い手確保の鍵であり、正規・非正規間、元請・下請間の待遇差の適正化が業界全体の課題となっている。
