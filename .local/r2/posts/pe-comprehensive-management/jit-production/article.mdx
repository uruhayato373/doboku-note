# JIT生産方式

## JIT生産方式とは

JIT生産方式（Just In Time Production）とは、**必要なものを、必要な時に、必要な量だけ生産・供給する方式**である。

トヨタ生産方式（TPS）の柱の一つであり、ムダの徹底排除を基本理念とする。

## 7つのムダ

| ムダ | 内容 |
|---|---|
| **作りすぎのムダ** | 必要以上に生産する（最大のムダ） |
| **手待ちのムダ** | 作業者が待機している |
| **運搬のムダ** | 不要な移動・搬送 |
| **加工のムダ** | 不必要な加工工程 |
| **在庫のムダ** | 過剰な仕掛品・完成品の保管 |
| **動作のムダ** | 不要な動作・手順 |
| **不良のムダ** | 不良品の発生・手直し |

## JITの前提条件

- **プル型生産**（後工程引取り）の採用
- **平準化生産**（品種・量の均一化）
- **段取替え時間の短縮**（小ロット生産の実現）
