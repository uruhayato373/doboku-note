# 勤務地限定社員制度

## 勤務地限定社員制度とは

**勤務地限定社員制度**とは、勤務地を一定の地域に限定する正社員区分を設ける制度である。転勤を伴う「無限定正社員」と、非正規雇用の中間に位置する**多様な正社員（限定正社員）** の1類型として注目されている。

## 限定正社員の3類型

| 類型 | 限定内容 | 例 |
|---|---|---|
| **勤務地限定** | 転勤の範囲を限定 | エリア限定（関東のみ）、拠点限定（本社のみ） |
| **職務限定** | 担当する職務を限定 | 経理専門職、ITエンジニア |
| **勤務時間限定** | 労働時間を限定 | 短時間正社員（育児・介護対応） |

## 無限定正社員との比較

| 項目 | 無限定正社員 | 勤務地限定社員 |
|---|---|---|
| **転勤** | 全国転勤あり | なし・限定的 |
| **賃金** | 高い（転勤手当等含む） | 相対的に低い（8〜9割程度） |
| **昇進** | 管理職・幹部候補 | 上限あり（制度による） |
| **雇用安定性** | 高い | 事業所閉鎖時に解雇リスク |
| **転換制度** | ー | 無限定への転換制度を設ける企業も |

## 導入の背景

| 背景 | 内容 |
|---|---|
| **ワークライフバランス** | 育児・介護との両立で転勤が困難な人材の確保 |
| **地域人材の確保** | 地方での人材定着、UIJターン促進 |
| **同一労働同一賃金** | 正規・非正規の格差是正、合理的な処遇差の設計 |
| **多様な働き方** | 画一的な雇用区分から多様な正社員区分への移行 |

## 建設業での活用

| 場面 | 内容 |
|---|---|
| **地方建設会社** | 地域密着の施工管理者を勤務地限定で採用 |
| **大手ゼネコン** | エリア総合職として地域限定の技術者を確保 |
| **本支店事務** | 事務系人材を勤務地限定で安定確保 |
| **技能者確保** | 地元の技能者を正社員として処遇改善 |
