# データガバナンス

## データガバナンスとは

**データガバナンス**とは、組織が保有するデータの品質・セキュリティ・プライバシー・利活用に関する方針・プロセス・体制を整備し、データを適切に管理・統制する仕組みである。

データが経営資源として重要性を増す中、データの信頼性確保とリスク管理を両立させるための組織的な取組みである。

データガバナンスが不十分な場合、データの品質低下、セキュリティ侵害、法令違反、意思決定の誤りなど、組織に深刻な影響を及ぼす。

### データガバナンスの主要領域

| 領域 | 内容 | 関連規格・法令 |
|---|---|---|
| **データ品質管理** | 正確性・完全性・一貫性・適時性の確保 | ISO 8000（データ品質） |
| **データセキュリティ** | アクセス制御・暗号化・漏洩防止 | ISO/IEC 27001（ISMS） |
| **データプライバシー** | 個人情報の適切な取扱い | 個人情報保護法、GDPR |
| **データアーキテクチャ** | データの構造・フロー・保管の設計 | DMBOK（Data Management Body of Knowledge） |
| **メタデータ管理** | データの定義・分類・辞書の整備 | データカタログ |
| **データライフサイクル** | 生成から廃棄までの管理 | 文書管理規程 |

### データガバナンスの組織体制

| 役割 | 英語 | 責務 |
|---|---|---|
| **最高データ責任者** | CDO（Chief Data Officer） | データ戦略の統括、経営層への報告 |
| **データオーナー** | Data Owner | データの所有権と利用許可の管理 |
| **データスチュワード** | Data Steward | データ品質の維持、日常的な管理運用 |
| **データ利用者** | Data Consumer | ルールに基づくデータの利用 |

### データガバナンスと情報セキュリティポリシー

データガバナンスは情報セキュリティポリシーの上位概念として、データ全体の統制を担う。

| 観点 | データガバナンス | 情報セキュリティポリシー |
|---|---|---|
| **範囲** | データの品質・利活用・セキュリティ全般 | 情報セキュリティに特化 |
| **目的** | データの価値最大化とリスク最小化 | 情報資産の保護 |
| **対象** | 構造化・非構造化データ全般 | 情報資産全般 |

### データガバナンスの成熟度モデル

| レベル | 状態 | 特徴 |
|---|---|---|
| レベル1 | 初期 | データ管理が属人的、ルールなし |
| レベル2 | 反復可能 | 部門ごとにルールが存在 |
| レベル3 | 定義済み | 全社的なポリシー・手順が文書化 |
| レベル4 | 管理 | メトリクスによるデータ品質の定量管理 |
| レベル5 | 最適化 | 継続的改善プロセスが機能 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**4.5 情報セキュリティ**」に位置づけられる。

データガバナンスは5つの管理分野すべてに関連する横断的な概念である。

経済性管理（データに基づく意思決定の信頼性）、人的資源管理（データリテラシー教育）、安全管理（センサーデータの品質管理）、社会環境管理（環境データの信頼性・公開性）と密接に関連する。
