# 循環型社会形成推進基本法

## 循環型社会形成推進基本法とは

**循環型社会形成推進基本法**（2000年制定）は、大量生産・大量消費・大量廃棄型の社会を転換し、循環型社会の形成を推進するための基本的枠組みを定めた法律である。

天然資源の消費を抑制し、環境への負荷をできる限り低減する社会の実現を目的としている。

本法は個別リサイクル法の上位法として機能し、3R（Reduce・Reuse・Recycle）の優先順位を法的に明確化した点に最大の特徴がある。

### 3Rの優先順位

本法は廃棄物等の処理における優先順位を以下のとおり法定している。

- **1位 リデュース（Reduce：発生抑制）**: 廃棄物の発生そのものを抑える — 製品の長寿命化、簡易包装
- **2位 リユース（Reuse：再使用）**: 使用済み製品をそのまま再使用 — リターナブルびん、中古品流通
- **3位 リサイクル（Recycle：再生利用）**: 原材料として再生利用 — 古紙→再生紙、PET→繊維
- **4位 熱回収（サーマルリサイクル）**: 焼却時の熱エネルギーを回収 — ごみ発電、セメント原燃料化
- **5位 適正処分**: 最終手段としての埋立処分等 — 管理型最終処分場

### 循環型社会の法体系

循環型社会に関連する法体系は、最上位の基本法から個別リサイクル法まで階層構造をなしている。

- **基本的枠組み法 — 環境基本法**: 環境政策の最上位法
- **循環の基本法 — 循環型社会形成推進基本法（2000年）**: 3Rの優先順位、循環資源の定義
- **廃棄物の適正処理 — 廃棄物処理法（1970年改正）**: 廃棄物の分類・処理基準・マニフェスト
- **資源の有効利用 — 資源有効利用促進法（2000年改正）**: 事業者の3R取組促進（指定省資源化製品等）
- **個別リサイクル法 — 容器包装リサイクル法（1995年）**: ガラスびん・PETボトル・プラスチック製容器包装等
- **個別リサイクル法 — 家電リサイクル法（1998年）**: テレビ・冷蔵庫・洗濯機・エアコンの4品目
- **個別リサイクル法 — 建設リサイクル法（2000年）**: コンクリート・アスファルト・木材の分別解体・再資源化
- **個別リサイクル法 — 食品リサイクル法（2000年）**: 食品廃棄物の発生抑制・再生利用（飼料・肥料化）
- **個別リサイクル法 — 自動車リサイクル法（2002年）**: フロン・エアバッグ・シュレッダーダストの処理
- **個別リサイクル法 — 小型家電リサイクル法（2012年）**: 使用済み小型電子機器等の再資源化
- **個別リサイクル法 — プラスチック資源循環促進法（2021年）**: プラスチック製品の設計から廃棄まで一貫した資源循環

### 都市鉱山

**都市鉱山** とは、使用済みの電子機器や家電製品に含まれるレアメタル・貴金属等の有用資源を、鉱山に見立てて回収・再利用する概念である。

| 項目 | 内容 |
|---|---|
| **背景** | 天然資源の枯渇リスクと資源価格の高騰 |
| **対象資源** | 金・銀・銅・白金・パラジウム・レアアース等 |
| **日本の埋蔵量** | 金は世界の埋蔵量の約16%、銀は約22%が都市鉱山に存在するとの試算 |
| **回収の課題** | 製品中の含有量が微量で分離・精錬コストが高い |
| **関連法制度** | 小型家電リサイクル法（2012年）が都市鉱山活用の法的基盤 |
| **東京オリンピック** | 2020年東京大会のメダルを使用済み小型家電から製造（都市鉱山メダルプロジェクト） |

### 建設リサイクル法の詳細

建設分野に特に関連する建設リサイクル法の要点を整理する。

| 項目 | 内容 |
|---|---|
| **正式名称** | 建設工事に係る資材の再資源化等に関する法律 |
| **対象工事** | 床面積80m2以上の解体工事、500m2以上の新築等工事 |
| **特定建設資材** | コンクリート、コンクリート及び鉄からなる建設資材、木材、アスファルト・コンクリート |
| **義務** | 分別解体と再資源化（特定建設資材廃棄物） |
| **届出** | 工事着手の7日前までに都道府県知事に届出 |
| **再資源化率** | コンクリート約99%、アスファルト約99%、建設発生木材約96%（2018年度） |

## 制度の成立と主な改正の経緯

**2000年以前：大量廃棄型社会の問題化**

高度経済成長期以降の日本は大量生産・大量消費・大量廃棄のサイクルを繰り返し、廃棄物の最終処分場の逼迫が深刻な社会問題となっていた。1990年代後半には廃棄物処理施設への不法投棄事件が相次いだほか、天然資源の枯渇リスクが国際的に意識されるようになった。

**2000年（循環型社会元年）**

廃棄物処理行政から循環型社会の形成へという政策転換を図るため、循環型社会形成推進基本法が2000年に制定された。同年には廃棄物処理法の抜本改正、資源有効利用促進法の改正、建設リサイクル法・食品リサイクル法の制定も行われ、2000年は「循環型社会元年」と呼ばれる。

**2003年（循環型社会形成推進基本計画）**

本法に基づく第一次循環型社会形成推進基本計画が閣議決定され、資源生産性・循環利用率・最終処分量の数値目標が初めて法的な位置づけを得た。以後おおむね5年ごとに改定されている。

**2012年（小型家電リサイクル法の制定）**

都市鉱山に含まれるレアメタル等の有用資源を回収・再生利用することを目的に、使用済み小型電子機器等の再資源化の促進に関する法律（小型家電リサイクル法）が制定された。

**2021年（プラスチック資源循環促進法の制定）**

海洋プラスチック汚染問題の深刻化を受け、プラスチックの設計・製造・販売・回収・再資源化の各段階を一貫して規律するプラスチック資源循環促進法が制定された。循環型社会の枠組みがより広範な資源カテゴリに拡大された改正として位置づけられる。

## 総合技術監理における位置づけ

総合技術監理キーワード集では[**6.2 地域環境問題**](/docs/pe-comprehensive-management-keyword-2026#62-地域環境問題)に位置づけられる。

循環型社会の法体系は社会環境管理の制度的基盤であり、建設リサイクル法は建設事業に直接適用される。

経済性管理（廃棄物処理コスト・再資源化コスト）、安全管理（有害物質の適正処理）との複合的な判断が、建設プロジェクトのマネジメントにおいて不可欠である。
