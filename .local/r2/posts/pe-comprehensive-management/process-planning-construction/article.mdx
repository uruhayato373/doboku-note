# 工程計画

## 工程計画とは

**工程計画** とは、工事の各作業の順序・期間・相互関係を定め、全体工期内に完成させるためのスケジュールを策定する計画のことである。工程管理の基盤であり、資源配分・コスト管理の前提となる。

## 工程表の種類

| 種類 | 特徴 | 用途 |
|---|---|---|
| **バーチャート（ガントチャート）** | 横棒で作業期間を表示 | 全体把握・報告用（簡明） |
| **ネットワーク工程表** | 作業間の依存関係を矢印で表現 | クリティカルパスの特定 |
| **マイルストーンチャート** | 主要節目を時間軸上に表示 | 進捗管理・意思決定ポイント |
| **出来高曲線（Sカーブ）** | 累積出来高を時間で表示 | 進捗率の監視 |
| **工程山積み図** | 資源使用量の時間推移 | 資源の平準化 |

## ネットワーク工程表（CPM/PERT）

| 項目 | 内容 |
|---|---|
| **クリティカルパス（CP）** | 全体工期を決定する最長経路（余裕なし） |
| **最早開始時刻（ES）** | 最も早く作業を開始できる時刻 |
| **最遅完了時刻（LF）** | 工期を遅延させない最も遅い完了時刻 |
| **トータルフロート（TF）** | クリティカルパスに影響しない余裕日数 |
| **フリーフロート（FF）** | 後続作業に影響しない余裕日数 |

## 工程計画策定の手順

| ステップ | 内容 |
|---|---|
| **1. 作業の洗い出し** | WBSに基づく作業項目の分解 |
| **2. 作業順序の決定** | 先行・後続関係（FS/FF/SS/SF）の設定 |
| **3. 所要日数の見積り** | 各作業の必要日数を算出 |
| **4. 資源の割当て** | 人員・機械・資材の配分 |
| **5. 工程表の作成** | ネットワーク図・バーチャートの作成 |
| **6. 工期の短縮** | クリティカルパスの短縮検討（クラッシング・ファストトラッキング） |

## 工期短縮手法

| 手法 | 内容 | 留意点 |
|---|---|---|
| **クラッシング** | 資源追加で作業期間を圧縮 | コスト増加 |
| **ファストトラッキング** | 作業を並行化（CE的手法） | リスク増大 |
| **作業方法の変更** | より効率的な工法への変更 | 品質への影響確認 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**2.1 事業企画と計画**」に位置づけられる。

工程計画は工程管理の基盤であり、経済性管理（コスト最適化）・人的資源管理（要員配置）・安全管理（作業の輻輳回避）と密接に関連する。工事計画の中核として5つの管理の統合に寄与する。
