# パブリック・リレーションズ（PR）

## パブリック・リレーションズとは

**パブリック・リレーションズ**（PR：Public Relations）とは、組織と公衆（ステークホルダー）との間に相互理解と良好な関係を構築・維持するための戦略的なコミュニケーション活動のことである。一方的な宣伝（プロパガンダ）とは異なり、双方向のコミュニケーションを重視する。

## PRの基本活動

PR活動は多様な公衆（ステークホルダー）それぞれとの関係構築を目的とし、場面に応じた手段を組み合わせて実施される。

| 活動 | 内容 |
|---|---|
| **広報（パブリシティ）** | メディアを通じた情報発信（プレスリリース、記者会見） |
| **広聴** | 社会の声・世論を収集・分析 |
| **メディアリレーションズ** | マスメディアとの良好な関係構築 |
| **コミュニティリレーションズ** | 地域社会との関係構築 |
| **インターナルコミュニケーション** | 組織内の情報共有・意識統一 |
| **危機広報（クライシスコミュニケーション）** | 事故・不祥事時の情報発信・対応 |

## PRと広告の違い

PRと広告は「誰が情報をコントロールするか」という点で根本的に異なる。各項目を PR（広報）と広告で比較すると以下のとおりである。

- **費用**: PR（広報）= メディア掲載は無料（取材対応） — 広告 = 有料（媒体費）
- **信頼性**: PR（広報）= 第三者（メディア）の視点で報道 — 広告 = 自社の意図で制作
- **コントロール**: PR（広報）= 報道内容は制御できない — 広告 = 内容を完全にコントロール
- **持続性**: PR（広報）= 信頼の蓄積で長期的効果 — 広告 = 掲載期間で効果が限定

## 危機広報のポイント

事故・不祥事が発生した際、組織への信頼を守るために以下の5原則に従って情報発信を行う。

| ポイント | 内容 |
|---|---|
| **迅速性** | 事案発生後、速やかに第一報を発信 |
| **正確性** | 確認できた事実のみを発信、推測を避ける |
| **一貫性** | スポークスパーソンの一元化、情報の矛盾回避 |
| **誠実性** | 事実を隠さず、被害者・住民に寄り添う姿勢 |
| **継続性** | 状況の進展に応じた続報の発信 |

## 公共事業でのPR活動

公共事業では社会的受容（PA）の確保が不可欠であり、工事着手前から完成後まで継続的なPR活動を展開する。

| 活動 | 内容 |
|---|---|
| **事業広報** | 事業の目的・効果を住民・国民に発信 |
| **工事広報** | 工事の内容・期間・影響を近隣住民に周知 |
| **完成披露** | 竣工式・施設見学会の開催 |
| **報道対応** | 記者発表・現場公開・取材対応 |
