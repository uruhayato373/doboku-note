# 高度プロフェッショナル制度

## 高度プロフェッショナル制度とは

高度プロフェッショナル制度とは、高度の専門的知識を有し一定の年収要件を満たす労働者を対象に、労働基準法に定める労働時間・休憩・休日・深夜割増賃金に関する規定を適用しない制度である。

2019年4月に働き方改革関連法の施行に伴い、**労働基準法第41条の2**として新設された。

成果で評価される働き方を選択できる制度として導入されたが、長時間労働を助長する懸念もあり、厳格な健康確保措置が義務づけられている。

## 適用要件

| 要件 | 内容 |
|---|---|
| **対象業務** | 高度の専門的知識等を必要とし、従事した時間と成果の関連性が高くない業務 |
| **年収要件** | 基準年間平均給与額の3倍を相当程度上回る水準（1,075万円以上） |
| **本人同意** | 書面による本人の同意が必要（同意の撤回も可能） |
| **労使委員会の決議** | 委員の4/5以上の多数による決議が必要 |
| **届出** | 労働基準監督署への届出が必要 |

## 対象業務

| 業務 | 具体例 |
|---|---|
| **金融商品の開発** | デリバティブ商品の開発、ストラクチャードファイナンスの組成 |
| **金融商品のディーリング** | 有価証券等の売買・運用 |
| **アナリスト** | 企業・市場の調査・分析 |
| **コンサルタント** | 事業・業務の企画運営に関する助言 |
| **研究開発** | 新たな技術・商品・役務の研究開発 |

## 適用除外される規定

| 適用除外される規定 | 内容 |
|---|---|
| **労働時間** | 1日8時間・週40時間の制限なし |
| **休憩** | 休憩時間の付与義務なし |
| **休日** | 週1日・4週4日の法定休日規制なし |
| **深夜割増賃金** | 深夜労働の割増賃金なし |
| **時間外割増賃金** | 時間外労働の割増賃金なし |

## 健康確保措置

| 措置 | 内容 |
|---|---|
| **年間104日以上の休日確保** | 4週間を通じ4日以上の休日を必ず付与（義務） |
| **健康管理時間の把握** | 事業場内外の在所時間＋事業場外の労働時間を把握 |
| **選択的措置（いずれか1つ）** | 勤務間インターバル＋深夜業回数制限、健康管理時間の上限設定、連続2週間の休日、臨時の健康診断 |
| **医師の面接指導** | 健康管理時間が一定基準を超えた場合に義務的に実施 |

## 導入状況と課題

| 課題 | 内容 |
|---|---|
| **導入企業の少なさ** | 厳格な要件により適用労働者は限定的 |
| **長時間労働リスク** | 労働時間規制の適用除外により過重労働のおそれ |
| **成果評価の困難** | 成果と報酬の適切な連動が前提だが評価基準の確立が難しい |
| **同意の自由** | 実質的に自由な同意が確保されるかという懸念 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**3.2 労働関係法と労務管理**」に位置づけられる。

高度プロフェッショナル制度は、高度人材の自律的で創造的な働き方を実現する制度（人的資源管理）である一方、労働時間規制の適用除外により健康リスクが増大する可能性がある（安全管理）。

総合技術監理者には、制度の適用可否の判断と健康確保措置の確実な実施、そして成果評価制度との連動による適正な運用が求められる。
