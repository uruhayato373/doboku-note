# 水俣条約

## 水俣条約とは

水銀に関する水俣条約（Minamata Convention on Mercury）は、水銀及び水銀化合物の人為的な排出・放出から人の健康及び環境を保護することを目的とする国際条約である。

2013年10月に熊本市・水俣市で開催された外交会議で採択され、2017年8月に発効した。

条約名に「水俣」を冠するのは、日本の水俣病の教訓を世界と共有し、水銀汚染を二度と繰り返さないという国際社会の決意を示すものである。

### 水銀の特性とリスク

- **物理的特性**: 常温で液体の唯一の金属、蒸発しやすい
- **毒性**: 中枢神経障害、腎臓障害、胎児への発達毒性
- **環境動態**: メチル水銀への変換→食物連鎖で生物濃縮（特に大型魚類）
- **代表的被害**: 水俣病（1956年公式確認）、新潟水俣病（1965年）

### 条約の規制内容

| 規制分野 | 内容 |
|---|---|
| **水銀の供給** | 新規水銀鉱山の開設禁止、既存鉱山の15年以内の閉鎖 |
| **水銀添加製品** | 電池、スイッチ・リレー、蛍光灯、体温計、血圧計等の製造・輸出入を2020年以降禁止 |
| **製造プロセス** | クロルアルカリ工業での水銀使用を2025年までに廃止 |
| **小規模金採掘（ASGM）** | 水銀使用の削減・廃絶に向けた国家行動計画の策定 |
| **大気排出** | 石炭火力発電所、廃棄物焼却施設等からの排出にBAT/BEPを適用 |
| **水・土壌への放出** | 放出源の特定と放出削減措置 |
| **水銀廃棄物** | バーゼル条約と整合した環境上適正な管理 |
| **汚染サイト** | 汚染サイトの特定・評価・リスク低減 |

### 日本の対応

| 対応 | 内容 |
|---|---|
| **条約批准** | 2016年2月に締結（条約採択国として率先して対応） |
| **水銀汚染防止法** | 2015年制定、水銀の採掘禁止・特定水銀使用製品の製造禁止等 |
| **大気汚染防止法改正** | 水銀排出施設からの排出規制（排出基準の設定） |
| **廃棄物処理法改正** | 水銀廃棄物の適正処理に関する規定を整備 |
| **水銀使用製品の回収** | 蛍光灯、体温計、血圧計等の回収・適正処理を推進 |

### 水銀汚染防止法の概要

水銀汚染防止法は2015年に水俣条約の国内担保法として制定され、水銀の採掘・製品・貯蔵・再生資源を一体的に規制している。

- **目的**: 水俣条約の的確かつ円滑な実施を確保
- **水銀等の採掘禁止**: 国内での水銀鉱山の新規開設・既存鉱山での採掘を禁止
- **特定水銀使用製品**: 水銀体温計、水銀血圧計等の製造を禁止
- **水銀等の貯蔵**: 環境上適正な方法での貯蔵を義務化
- **水銀含有再生資源**: 管理基準の遵守を義務化
