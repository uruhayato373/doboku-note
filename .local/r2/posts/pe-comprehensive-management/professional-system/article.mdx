## 定義

専門職制度とは、管理職（マネジメント）コースとは別に、高度な専門知識・技術を持つ人材を適切に処遇し、長期にわたって組織に貢献させるために設計された人事制度である。キャリア・プラットフォームの解消や企業内の専門的知識の需要増への対応等が背景となっており、労働者が専門性を軸にしたキャリア目標を持つことが可能になる。

## 過去問での出題

  - [[R07_択一式]]

## 導入時期と背景

| 項目 | 内容 |
|---|---|
| 導入時期 | 1970～80年代（高度経済成長後） |
| 背景 | 「管理職になれない優秀な技術者・専門家をどう処遇するか」という課題 |
| **誤解** | **1990年代後半は誤り** — この時期は人事評価制度の多様化、成果主義の時代 |

## 評価検討項目

専門職制度においては、以下の項目が評価される：
- 特定分野における専門知識や技術の保有状況
- 業務経験
- 企業業績への貢献度
- 職務適合性の格付け

## 評価項目と運用

| 項目          | 説明                 |
| ----------- | ------------------ |
| 実績達成度       | 職務や格付けに対応した実績      |
| 知識・技術・経験の蓄積 | 専門分野での深掘り          |
| 能力・意欲       | 継続的な自己開発           |
| 評価手法        | 目標管理制度（MBO）をベースに実施 |

## 報酬設計

- 高度な専門職の育成を目的とする場合が多い
- 外部労働市場からの調達を視野に入れることもある
- 競合他社や他業界の水準を意識した設計になることが多い
