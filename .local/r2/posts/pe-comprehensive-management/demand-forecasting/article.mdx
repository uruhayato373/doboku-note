# 需要予測

## 需要予測とは

需要予測とは、**過去のデータや市場情報に基づき、将来の製品・サービスの需要量を推定する活動**である。

生産計画・在庫管理・設備投資計画等の意思決定の基盤となる。

## 主な予測手法

| 分類 | 手法 | 特徴 |
|---|---|---|
| **時系列分析** | 移動平均法 | 直近N期の平均値で予測。平滑化効果 |
|  | 指数平滑法 | 直近データに大きな重みを付ける |
|  | 傾向変動分析 | トレンドを回帰分析で把握する |
| **因果関係分析** | 回帰分析 | 説明変数から需要を推定する |
| **定性的手法** | デルファイ法 | 専門家の意見を収斂させる |
|  | 市場調査法 | アンケート・ヒアリングで把握する |

## 移動平均法と指数平滑法の比較

- **移動平均法**：過去N期のデータを等しい重みで平均化する。Nが大きいほど平滑化効果が高い
- **指数平滑法**：平滑化定数α（0＜α＜1）を用いて直近データほど重く加重する。αが大きいほど直近変動に敏感に反応する

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**2.1 事業企画・計画**」に位置づけられている。

需要予測は[市場調査](/docs/pe-comprehensive-management-market-research)と合わせて事業企画の出発点であり、[サプライチェーンマネジメント](/docs/pe-comprehensive-management-supply-chain-management)における生産計画・在庫管理の基盤となる。[予算計画](/docs/pe-comprehensive-management-budget-planning)の策定にも不可欠な情報を提供する。
