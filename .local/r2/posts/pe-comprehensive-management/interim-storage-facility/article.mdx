# 中間貯蔵施設

## 中間貯蔵施設とは

中間貯蔵施設とは、福島第一原子力発電所事故に伴う除染等で発生した除去土壌や汚染廃棄物を安全に集約・貯蔵する施設である。

福島県内の大熊町・双葉町に設置され、2015年3月から除去土壌等の搬入が開始された。

中間貯蔵開始後30年以内（2045年3月まで）に福島県外で最終処分を完了することが法律で定められている。

### 法的根拠

根拠法は**中間貯蔵・環境安全事業株式会社法**（JESCO法）であり、関連法として放射性物質汚染対処特別措置法が定められている。

JESCO法附則第2条により、中間貯蔵開始後30年以内に県外最終処分を完了する義務が国に課せられている。事業の実施主体は環境省（事業運営はJESCO）であり、費用は国のエネルギー対策特別会計から支出され、東京電力に一部求償される。

### 施設の構成と機能

中間貯蔵施設は受入から貯蔵・減容化まで一体的に機能する複数施設で構成される。

| 施設 | 機能 |
|---|---|
| **受入・分別施設** | 搬入された除去土壌等を受け入れ、異物を除去・分別 |
| **土壌貯蔵施設** | 除去土壌を安全に貯蔵（遮水シート等で地下水汚染を防止） |
| **廃棄物貯蔵施設** | 汚染廃棄物（10万Bq/kg以下）を貯蔵 |
| **減容化施設** | 可燃物の焼却による減容化、土壌の分級処理 |

### 搬入の現状

施設は福島県大熊町・双葉町の帰還困難区域内（約16km²）に立地し、2015年3月から搬入が開始された。

搬入対象は除染特別地域・汚染状況重点調査地域の除去土壌等であり、福島県内各地の仮置場からの輸送が順次推進された。用地取得にあたっては地権者約2,400人との交渉が課題となった。

### 県外最終処分に向けた課題

県外最終処分の実現には、技術・社会・法的側面にまたがる多面的な課題がある。

| 課題 | 内容 |
|---|---|
| **処分先の確保** | 県外最終処分の具体的な処分先・方法が未定 |
| **減容・再生利用** | 除去土壌の減容化技術の開発と再生利用の実証が必要 |
| **社会的受容** | 受入先自治体の住民理解の獲得が困難 |
| **技術的課題** | 放射性セシウムの分離技術、安全な輸送方法の確立 |
| **期限の厳守** | 2045年3月までの完了は法定義務であり遅延は許されない |

## 総合技術監理における位置づけ


総合技術監理キーワード集では[**6.2 地域環境問題**](/docs/pe-comprehensive-management-keyword-2026#62-地域環境問題)に位置づけられる。

中間貯蔵施設は社会環境管理（汚染土壌の適正管理と環境修復）と安全管理（放射線防護、施設の安全性確保）の両面に深く関わる。経済性管理（巨額の事業費管理と世代間公平）、情報管理（地権者・住民へのリスクコミュニケーション）、人的資源管理（作業員の被ばく管理）を含め、5管理分野を横断する典型的な総合技術監理の課題である。

中間貯蔵施設の運営では、地権者・住民・行政間の[コミュニケーション・コントロール](/docs/pe-comprehensive-management-communication-control)と放射線・工事に関わる[リスク](/docs/pe-comprehensive-management-risk)管理が不可欠である。
