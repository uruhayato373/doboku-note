# 再雇用制度

## 再雇用制度とは

再雇用制度とは、定年に達した労働者を一旦退職させた後、新たな雇用契約を締結して引き続き雇用する制度である。

高年齢者雇用安定法（高年齢者等の雇用の安定等に関する法律）に基づく継続雇用制度の代表的な形態であり、多くの企業で導入されている。

少子高齢化による労働力人口の減少と年金支給開始年齢の引上げを背景に、高年齢者の就業機会確保が社会的課題となっている。

## 高年齢者雇用安定法の3つの措置

事業主は65歳までの雇用確保のため、以下のいずれかの措置を講じる義務がある（義務規定）。

| 措置 | 内容 | 導入割合 |
|---|---|---|
| **定年の引上げ** | 定年年齢を65歳以上に引き上げる | 約26% |
| **継続雇用制度の導入** | 定年後も引き続き雇用する制度（再雇用制度等） | 約70% |
| **定年の廃止** | 定年制そのものを廃止する | 約4% |

## 70歳までの就業確保措置（努力義務）

2021年4月施行の改正法により、65歳から70歳までの就業機会確保が努力義務となった。

| 措置 | 内容 |
|---|---|
| **定年の引上げ** | 70歳以上への定年引上げ |
| **定年の廃止** | 定年制の廃止 |
| **継続雇用制度** | 70歳までの継続雇用（グループ企業・他企業含む） |
| **業務委託契約** | 70歳まで継続的に業務委託契約を締結する制度（創業支援等措置） |
| **社会貢献事業** | 70歳まで事業主が実施する社会貢献事業に従事できる制度 |

## 再雇用制度の運用

| 項目 | 内容 |
|---|---|
| **雇用形態** | 嘱託社員・契約社員等の有期雇用が一般的 |
| **契約期間** | 1年ごとの更新が多い（65歳まで） |
| **対象者** | 希望者全員（2013年改正で経過措置を経て全員対象に） |
| **労働条件** | 定年前と異なる条件（賃金・勤務時間・業務内容等）を設定可能 |
| **賃金水準** | 定年前の60〜80%程度が一般的 |

## 課題と留意点

| 課題 | 内容 |
|---|---|
| **モチベーション維持** | 賃金低下や役職変更による意欲低下 |
| **処遇の合理性** | 同一労働同一賃金の原則との整合性（パートタイム・有期雇用労働法） |
| **技術・技能の伝承** | 高年齢者の知識・経験を若手に伝承する仕組みづくり |
| **健康管理** | 加齢に伴う体力・健康面への配慮 |
| **役割の明確化** | 再雇用後の職務内容・期待役割を明確にする |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**3.2 労働関係法と労務管理**」に位置づけられる。

再雇用制度は高年齢者の知識・経験の活用（人的資源管理）と、人件費の適正管理（経済性管理）のバランスが問われるテーマである。

建設業をはじめとする技術系分野では、熟練技術者の技能伝承が喫緊の課題であり、再雇用者の役割設計と処遇の適正化が総合技術監理者に求められる。
