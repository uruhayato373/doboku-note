# 評価誤差

## 評価誤差とは

評価誤差とは、**人事評価において考課者の心理的傾向により生じる系統的な偏り**である。適正な評価を阻害する要因となる。

## 主な評価誤差

| 評価誤差 | 内容 |
|---|---|
| **ハロー効果** | ある特性の印象に引きずられ、他の評価項目まで同様に評価してしまう |
| **寛大化傾向** | 全体的に甘い評価をつける傾向 |
| **厳格化傾向** | 全体的に厳しい評価をつける傾向 |
| **中心化傾向** | 評価が中央値に集中し、差がつかない傾向 |
| **論理的誤差** | 関連がありそうな評価項目を論理的に同じ評価にしてしまう |
| **対比誤差** | 考課者自身の能力を基準にして評価してしまう |
| **近接誤差** | 評価期間の直近の出来事に影響されやすい傾向 |

## 評価誤差の防止策

- **考課者訓練**: 評価誤差の類型と防止法を体系的に学習する
- **評価基準の明確化**: 行動レベルで具体的な基準を設定する
- **多面評価の導入**: 複数の評価者による偏り軽減
- **評価調整会議**: 考課者間の評価水準を擦り合わせる

## 総合技術監理における位置づけ


> 📘 **[人的資源管理 学習ガイド](/docs/pe-comprehensive-management-human-resource-management-pillar)** — 4 サブカテゴリの体系・頻出論点・学習導線

総合技術監理キーワード集では[**3.4 人材開発**](/docs/pe-comprehensive-management-keyword-2026#34-人材開発)に位置づけられている。

評価誤差は[人事考課の三原則](/docs/pe-comprehensive-management-appraisal-three-principles)の客観の原則に反する事象であり、[バイアス](/docs/pe-comprehensive-management-evaluation-bias)の一類型として人事評価の信頼性に直結する課題である。

過去問 **[R02 Ⅰ-1-16](/docs/pe-comprehensive-management-r02-primary#1-16)** では「ハロー効果 = 個人的な親しみを感じることで生じる評価誤差」という誤答が出題された。**ハロー効果は「ある一点の優秀さが他の評価項目にも波及する」認知バイアス**であり、個人的親しみによる誤差（= 親近効果・個人的接触誤差）とは区別される点が誤答識別の核心。
