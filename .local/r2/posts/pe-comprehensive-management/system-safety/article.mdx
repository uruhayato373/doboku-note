# システム安全

## システム安全とは

**システム安全（System Safety）** とは、システムのライフサイクル全体（企画・設計・製造・運用・廃棄）を通じて、ハザードを体系的に特定・評価・管理し、リスクを受容可能な水準に維持する工学的アプローチのことである。1960年代に米国国防総省（DoD）のミサイル・航空宇宙分野で確立された。

## 基本原則

| 原則 | 内容 |
|---|---|
| **システム的アプローチ** | 要素間の相互作用を含むシステム全体でリスクを評価 |
| **ライフサイクル管理** | 企画〜廃棄の全段階で安全を管理 |
| **設計段階での対処** | 上流段階でのハザード除去・低減が最も効果的かつ経済的 |
| **残留リスクの管理** | 除去できないリスクは運用段階で管理 |
| **文書化と追跡** | ハザードの特定から対策完了までをトレース |

## システム安全の手法

| 手法 | 概要 |
|---|---|
| **PHA（予備ハザード分析）** | 設計初期段階でのハザード概括的評価 |
| **FMEA（故障モード影響分析）** | 構成要素の故障モードとシステムへの影響分析 |
| **FTA（故障の木解析）** | トップ事象から原因を論理的にたどる演繹的手法 |
| **ETA（事象の木解析）** | 起因事象から結末をたどる帰納的手法 |
| **HAZOP** | プロセスのずれ（逸脱）を体系的に分析 |

## MIL-STD-882（米国軍用規格）

| 項目 | 内容 |
|---|---|
| **概要** | システム安全の国際的な基本規格 |
| **リスクマトリクス** | 発生確率×深刻度でリスクを4段階に分類 |
| **深刻度** | 壊滅的（Ⅰ）・重大（Ⅱ）・限界（Ⅲ）・無視可能（Ⅳ） |
| **発生確率** | 頻繁・起こりそう・時々・まれ・起こりそうにない |
