# モンテカルロシミュレーション

## モンテカルロシミュレーションとは

モンテカルロシミュレーション（Monte Carlo Simulation）とは、**乱数を用いた確率的試行を反復**することで結果の統計的分布を導く手法である。

解析的に解くことが困難な問題や、不確実性を含む問題に対して、大量の試行（サンプリング）によって近似解を得る。乱数の使用が本質的な特徴であり、確定的な手法とは根本的に異なるアプローチである。

## 実施手順

モンテカルロシミュレーションは以下の5ステップで実施する。各ステップの精度がシミュレーション全体の信頼性に影響する。

| ステップ | 内容 |
|---|---|
| **1. モデルの構築** | 分析対象のシステムを数学モデルで表現する |
| **2. 確率分布の設定** | 不確実な入力変数の確率分布（正規分布・一様分布・三角分布等）を設定する |
| **3. 乱数による試行** | 設定した確率分布から乱数を発生させ、モデルに代入して結果を計算する |
| **4. 多数回の反復** | 上記試行を数千〜数万回繰り返す（大数の法則により試行回数が多いほど精度が向上） |
| **5. 統計分析** | 得られた結果の分布・平均・分散・信頼区間等を分析する |

## 確定的手法との比較

確率的手法であるモンテカルロシミュレーションと、線形計画法に代表される確定的手法の主な違いを以下に整理する。

| 項目 | モンテカルロシミュレーション | 線形計画法等の確定的手法 |
|---|---|---|
| **入力値** | 確率分布（不確実性を反映） | 確定値（既知の定数） |
| **乱数の使用** | 必須 | 不使用 |
| **結果** | 確率分布（リスクの幅を提示） | 単一の最適解 |
| **適用場面** | 不確実性が大きい問題 | 制約条件が明確な最適化問題 |

## 適用分野

不確実性を含む問題であれば広く適用できる。総合技術監理の文脈では特に次の分野での利用が重要となる。

| 分野 | 適用例 |
|---|---|
| **プロジェクト管理** | 工期のばらつきを考慮した完了確率の推定（PERT との併用） |
| **リスク分析** | コスト超過確率の算出、需要変動の影響評価 |
| **投資評価** | NPVの確率分布、投資のリスク・リターン分析 |
| **信頼性工学** | システム故障確率の推定 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では[**2.7 計画・管理の数理的手法**](/docs/pe-comprehensive-management-keyword-2026#27-計画・管理の数理的手法)に位置づけられている。

モンテカルロシミュレーションは[線形計画法](/docs/pe-comprehensive-management-linear-programming)（確定的手法）や[ゲーム理論](/docs/pe-comprehensive-management-game-theory)（戦略的分析）とともに、数理的手法の代表例として出題される。不確実性下での意思決定を支援する手法として、[デルファイ法](/docs/pe-comprehensive-management-delphi-method)（専門家の主観的判断）とも対比される。

## 発展の背景と建設分野での応用

モンテカルロ法は第二次世界大戦中の核兵器開発プロジェクト（マンハッタン計画）において、中性子拡散のシミュレーションを目的としてスタニスワフ・ウラムとジョン・フォン・ノイマンが考案した手法である。名称はモナコのカジノで有名なモンテカルロ地区に由来し、「乱数を使う」という本質的特徴を端的に表している。

デジタルコンピュータの普及とともに計算コストが大幅に低下し、1990年代以降は金融・保険分野を中心に実務利用が急拡大した。日本では内閣府が策定する社会インフラの維持管理計画にも確率的手法が導入され始め、建設分野での適用が広がっている。

建設部門での具体的な活用として、大規模道路・ダム・橋梁などのインフラ整備プロジェクトにおける工期リスク評価がある。各工種の作業日数にばらつき（確率分布）を設定し、悪天候・用地取得遅延・資機材調達の不確実性を組み込んで数万回のシミュレーションを実施することで、工期超過確率とコスト超過額の分布を定量化できる。これにより、「工期を3か月延長すれば超過確率が45%から12%に低下する」といった数値根拠に基づく意思決定が可能になる。

総合技術監理の観点では、確率的リスク評価の結果を**5つの管理（経済・安全・品質・情報・人的）**に対応する指標として整理し、統合的な意思決定に活用することが重要である。不確実性を「幅」として可視化する本手法は、最悪シナリオの回避策と機会シナリオへの対応を同時に設計するうえで有効な思考ツールとなる。
