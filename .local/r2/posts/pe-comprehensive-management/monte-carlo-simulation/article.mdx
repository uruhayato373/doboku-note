# モンテカルロシミュレーション

## モンテカルロシミュレーションとは

モンテカルロシミュレーション（Monte Carlo Simulation）とは、**乱数を用いて確率的なモデルを多数回シミュレーションし、結果の統計的な分布を得る手法**である。

解析的に解くことが困難な問題や、不確実性を含む問題に対して、大量の試行（サンプリング）によって近似解を得るアプローチである。

## 実施手順

| ステップ | 内容 |
|---|---|
| **1. モデルの構築** | 分析対象のシステムを数学モデルで表現する |
| **2. 入力変数の確率分布設定** | 不確実な入力変数の確率分布（正規分布、一様分布等）を設定する |
| **3. 乱数による試行** | 設定した確率分布から乱数を発生させ、モデルに代入して結果を計算する |
| **4. 多数回の反復** | 上記試行を数千〜数万回繰り返す |
| **5. 統計分析** | 得られた結果の分布・平均・分散・信頼区間等を分析する |

## 適用分野

| 分野 | 適用例 |
|---|---|
| **プロジェクト管理** | 工期のばらつきを考慮した完了確率の推定 |
| **リスク分析** | コスト超過確率、需要変動の影響評価 |
| **投資評価** | NPVの確率分布、投資のリスク・リターン分析 |
| **信頼性工学** | システム故障確率の推定 |
