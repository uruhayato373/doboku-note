# モンテカルロシミュレーション

## モンテカルロシミュレーションとは

モンテカルロシミュレーション（Monte Carlo Simulation）とは、**乱数を用いて確率的なモデルを多数回シミュレーションし、結果の統計的な分布を得る手法**である。

解析的に解くことが困難な問題や、不確実性を含む問題に対して、大量の試行（サンプリング）によって近似解を得る。乱数の使用が本質的な特徴であり、確定的な手法とは根本的に異なるアプローチである。

## 実施手順

| ステップ | 内容 |
|---|---|
| **1. モデルの構築** | 分析対象のシステムを数学モデルで表現する |
| **2. 確率分布の設定** | 不確実な入力変数の確率分布（正規分布・一様分布・三角分布等）を設定する |
| **3. 乱数による試行** | 設定した確率分布から乱数を発生させ、モデルに代入して結果を計算する |
| **4. 多数回の反復** | 上記試行を数千〜数万回繰り返す（大数の法則により試行回数が多いほど精度が向上） |
| **5. 統計分析** | 得られた結果の分布・平均・分散・信頼区間等を分析する |

## 確定的手法との比較

| 項目 | モンテカルロシミュレーション | 線形計画法等の確定的手法 |
|---|---|---|
| **入力値** | 確率分布（不確実性を反映） | 確定値（既知の定数） |
| **乱数の使用** | 必須 | 不使用 |
| **結果** | 確率分布（リスクの幅を提示） | 単一の最適解 |
| **適用場面** | 不確実性が大きい問題 | 制約条件が明確な最適化問題 |

## 適用分野

| 分野 | 適用例 |
|---|---|
| **プロジェクト管理** | 工期のばらつきを考慮した完了確率の推定（PERT との併用） |
| **リスク分析** | コスト超過確率の算出、需要変動の影響評価 |
| **投資評価** | NPVの確率分布、投資のリスク・リターン分析 |
| **信頼性工学** | システム故障確率の推定 |
