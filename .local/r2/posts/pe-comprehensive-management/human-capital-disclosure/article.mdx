## 人的資本の情報公開とは

人的資本の情報公開（人的資本開示）とは、企業が保有する人材の価値や人材に対する投資・取組の状況を、ステークホルダーに対して開示することをいう。

従来、人材に関する支出は「コスト」として捉えられてきたが、人的資本経営の考え方のもとで「投資」として位置づけ直し、その成果を可視化する動きが国際的に広がっている。

日本では2023年3月期決算以降、有価証券報告書における人的資本情報の開示が義務化された。

## 開示の枠組み

人的資本情報の開示は国際規格・国内指針・法規制の3層で支えられている。主な枠組みを以下に整理する。

| 枠組み | 概要 |
|---|---|
| **ISO 30414** | 人的資本に関する情報開示のための国際ガイドライン（2018年発行） |
| **人的資本可視化指針** | 内閣官房が2022年に策定した日本国内向けの指針 |
| **有価証券報告書** | 2023年3月期から「人的資本、多様性」に関する記載が義務化 |
| **コーポレートガバナンス・コード** | 人的資本への投資について取締役会の監督を求める |

## ISO 30414の開示領域

ISO 30414は11の開示領域に58指標を定義しており、企業規模に関わらず開示が推奨される指標と大企業向け指標を区分している。各領域と代表的な指標を以下に示す。

| 開示領域 | 主な指標例 |
|---|---|
| **コンプライアンスと倫理** | 苦情件数、懲戒処分件数 |
| **コスト** | 総人件費、採用コスト、離職コスト |
| **ダイバーシティ** | 年齢・性別・障害者の構成比、管理職の多様性 |
| **リーダーシップ** | リーダーシップに対する信頼度 |
| **組織文化** | 従業員エンゲージメント、従業員満足度 |
| **健康・安全・ウェルビーイング** | 労働災害件数、労働災害による損失日数 |
| **生産性** | 1人あたり売上高、1人あたり利益 |
| **採用・異動・離職** | 採用数、内部異動率、離職率 |
| **スキルと能力** | 研修費用、研修時間、資格取得者数 |
| **後継者計画** | 内部昇格率、後継者候補の充足率 |
| **労働力の利用可能性** | 従業員数、非正規比率、欠勤率 |

## 有価証券報告書での義務的開示項目

2023年3月期以降、上場企業等は有価証券報告書の「サステナビリティに関する考え方及び取組」において以下を開示する。

| 項目 | 開示内容 |
|---|---|
| **人材育成方針** | 人材の育成に関する方針（戦略の一部として記載） |
| **社内環境整備方針** | 働きやすい職場環境の整備に関する方針 |
| **女性管理職比率** | 管理職に占める女性の割合 |
| **男性育休取得率** | 男性労働者の育児休業取得率 |
| **男女間賃金格差** | 男性の賃金に対する女性の賃金の割合 |

## 人的資本経営との関係

人的資本の情報公開は単なる規制対応ではなく、人的資本経営の実践と一体で推進されるものである。関連する概念と日本の主要指針を以下に整理する。

| 概念 | 内容 |
|---|---|
| **人的資本経営** | 人材を「資本」と捉え、その価値を最大限に引き出す経営 |
| **伊藤レポート2.0** | 経済産業省の人材版伊藤レポート（2022年）、人的資本経営の実践指針 |
| **3つの視点・5つの共通要素** | 経営戦略と人材戦略の連動、As is - To beギャップの定量把握等 |

## 開示における課題

義務化が先行した一方、実効性の確保には複数の課題が残る。主な課題を以下に示す。

| 課題 | 内容 |
|---|---|
| **指標の標準化** | 企業間比較が可能な共通指標の確立 |
| **定量化の困難** | 人材の質やエンゲージメントの数値化 |
| **形式的開示** | ポジティブ情報に偏り、実態を反映しない開示のリスク |
| **開示コスト** | データ収集・分析・報告の実務負担 |
| **経営との連動** | 開示が経営改善に実質的につながる仕組みづくり |

## 制度化の背景と経緯

人的資本開示が国際的に注目されるようになった契機の一つは、2016年に米国SECが開示規制を見直した動きである。それまでの財務情報中心の開示に対し、投資家が「企業の本質的な価値を人材から評価したい」という要請を強め、ESG投資の拡大とともに非財務情報への関心が急速に高まった。

ISOは2018年にISO 30414を発行し、人的資本情報の国際標準を初めて体系化した。日本でも2020年代に入り、「人材版伊藤レポート」（2020年）が人的資本経営の実践を促し、2022年に内閣官房が人的資本可視化指針を策定した。

2023年には金融庁が有価証券報告書での人的資本情報開示を義務化し、日本の上場企業に法的拘束力のある開示が求められるようになった。2026年3月には可視化指針が改訂され、経営戦略と人材戦略の連動をより明示的に求める方向に進化している。

建設分野においても、「技術者の確保・育成」「ダイバーシティの推進」「安全衛生」が投資家・発注者双方から注目されており、建設部門の技術者にとっても無視できないテーマとなっている。

## 総合技術監理における位置づけ


総合技術監理キーワード集では[**3.2 労働関係法と労務管理**](/docs/pe-comprehensive-management-keyword-2026#32-労働関係法と労務管理)に位置づけられる。

人的資本の情報公開は人的資源管理（人材育成・ダイバーシティ・エンゲージメント）の成果を可視化し、経営戦略（経済性管理）と連動させるテーマである。

情報管理（開示情報の正確性・適時性）や社会環境管理（ステークホルダーへの説明責任・ESG対応）とも密接に関連しており、総合技術監理者には複数の管理分野を統合した人的資本戦略の推進が求められる。
