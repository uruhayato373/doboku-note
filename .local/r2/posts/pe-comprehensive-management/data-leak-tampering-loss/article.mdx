# 情報漏洩・改ざん・消失

## 概要

**情報漏洩・改ざん・消失**は、情報セキュリティにおける3大脅威であり、それぞれCIAの機密性・完全性・可用性を直接侵害するものである。

| 脅威 | 侵害される要素 | 定義 |
|---|---|---|
| **情報漏洩** | 機密性（C） | 許可されていない者に情報が渡ること |
| **改ざん** | 完全性（I） | 情報が不正に書き換えられること |
| **消失** | 可用性（A） | 情報が失われ、アクセスできなくなること |

これらの脅威は単独で発生するだけでなく、複合的に発生する場合も多い。

たとえば、ランサムウェア攻撃ではデータの暗号化（消失）と情報の窃取（漏洩）が同時に行われるケースが増加している。

## 情報漏洩の手口・原因

### 外部要因

| 手口 | 内容 |
|---|---|
| **標的型攻撃** | 特定組織を狙ったマルウェア・フィッシングメール |
| **不正アクセス** | 脆弱性の悪用やパスワードクラックによる侵入 |
| **サプライチェーン攻撃** | 取引先・委託先を経由した情報窃取 |
| **ソーシャルエンジニアリング** | 人間の心理的弱点を突いた情報詐取 |

### 内部要因

| 原因 | 内容 |
|---|---|
| **誤操作** | メール誤送信、ファイルの公開設定ミス |
| **内部不正** | 退職者・不満社員による意図的な持ち出し |
| **管理不備** | アクセス権限の設定漏れ、退職者IDの未削除 |
| **紛失・盗難** | ノートPC・USBメモリ・書類の物理的紛失 |

### 被害事例

- 個人情報の大量流出による損害賠償（1件あたり数千円〜数万円の賠償金）
- 企業の信用失墜、株価下落
- 行政処分（個人情報保護委員会からの勧告・命令）

## 改ざんの手口・原因

| 手口 | 内容 |
|---|---|
| **Webサイト改ざん** | CMSの脆弱性を突いた表示内容の不正書き換え |
| **SQLインジェクション** | データベースへの不正なSQL文の注入 |
| **中間者攻撃（MITM）** | 通信経路上でのデータの傍受・改変 |
| **DNSキャッシュポイズニング** | DNS応答の改ざんによる偽サイトへの誘導 |
| **内部不正** | 権限を持つ者による意図的なデータ書き換え |

### 被害事例

- 政府機関のWebサイト改ざんによる信頼性の毀損
- 会計データの改ざんによる不正会計
- 制御系システムのデータ改ざんによる安全上の事故

## 消失の手口・原因

| 原因 | 内容 |
|---|---|
| **ランサムウェア** | データを暗号化して身代金を要求 |
| **ハードウェア障害** | ディスク故障、電源障害 |
| **自然災害** | 地震・水害・火災によるデータセンター損壊 |
| **人為的ミス** | 誤削除、バックアップ手順の不備 |
| **サイバー攻撃** | ワイパー型マルウェアによるデータ破壊 |

### 被害事例

- ランサムウェア被害による業務停止（数日〜数週間）
- バックアップ不備による復旧不能
- 災害時のデータセンター損壊による情報消失

## 対策の体系

| 分類 | 対策 | 対象脅威 |
|---|---|---|
| **技術的対策** | 暗号化（保存時・通信時） | 漏洩 |
| **技術的対策** | ハッシュ関数・デジタル署名 | 改ざん |
| **技術的対策** | バックアップ・冗長化・DR | 消失 |
| **技術的対策** | ファイアウォール・IDS/IPS | 漏洩・改ざん |
| **技術的対策** | ウイルス対策・EDR | 漏洩・改ざん・消失 |
| **組織的対策** | 情報セキュリティポリシーの策定 | 全般 |
| **組織的対策** | セキュリティ教育・訓練 | 全般 |
| **組織的対策** | インシデント対応計画（IRP） | 全般 |
| **物理的対策** | 入退室管理・施錠管理 | 漏洩・消失 |
| **物理的対策** | 耐震・防火・防水対策 | 消失 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**4.5 情報セキュリティ**」に位置づけられる。

情報漏洩・改ざん・消失は情報管理の中核的リスクであり、経済性管理（損害賠償・事業継続コスト）、人的資源管理（セキュリティ教育・内部不正対策）、安全管理（制御系システムの保護）、社会環境管理（環境データの信頼性）と5つの管理分野すべてに関連する。
