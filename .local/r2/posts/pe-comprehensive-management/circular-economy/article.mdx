# サーキュラーエコノミー（循環経済）

## サーキュラーエコノミーとは

**サーキュラーエコノミー（Circular Economy：循環経済）** とは、製品・素材・資源の価値を可能な限り長く保持し、廃棄物の発生を最小化する経済モデルである。

従来の「採取→製造→使用→廃棄」という一方通行型の経済（線形経済）に代わり、製品設計段階から再利用・修理・再製造・リサイクルを前提とした仕組みを構築する。

エレン・マッカーサー財団が提唱した概念が国際的に普及し、EUが政策の柱として採用したことで、世界的な経済モデルの転換が加速している。

### 線形経済との対比

| 比較項目 | 線形経済（リニアエコノミー） | 循環経済（サーキュラーエコノミー） |
|---|---|---|
| **資源の流れ** | 採取→製造→使用→廃棄（一方通行） | 循環利用（ループ型） |
| **設計思想** | 計画的陳腐化（買い替え促進） | 長寿命化・修理容易性・再製造 |
| **廃棄物の扱い** | 処理・埋立が前提 | 廃棄物そのものを出さない設計 |
| **価値創出** | 大量生産・大量消費 | サービス化（所有から利用へ） |
| **経済成長** | 資源消費量に比例 | 資源消費とGDP成長のデカップリング |
| **環境負荷** | 外部不経済として発生 | 設計段階で内部化 |

### サーキュラーエコノミーの3原則（エレン・マッカーサー財団）

| 原則 | 内容 | 具体例 |
|---|---|---|
| **廃棄物と汚染を生み出さない設計** | 製品設計段階で廃棄を前提としない | モジュラー設計、有害物質の排除 |
| **製品と素材を使い続ける** | 修理・再利用・再製造・リサイクルで価値を維持 | リマニュファクチャリング、シェアリング |
| **自然システムを再生する** | 生物由来資源を自然に還し、生態系を回復 | コンポスト、再生農業 |

### EU循環経済行動計画

EUは2015年に第1次循環経済行動計画を、2020年に第2次計画（新循環経済行動計画）を採択した。

| 項目 | 第1次（2015年） | 第2次（2020年） |
|---|---|---|
| **位置づけ** | 循環経済パッケージの一部 | 欧州グリーンディールの柱 |
| **重点分野** | 廃棄物管理の改善 | 製品設計段階からの循環性確保 |
| **主な施策** | リサイクル率目標の引き上げ | エコデザイン規則、デジタル製品パスポート |
| **プラスチック** | プラスチック戦略の策定 | 使い捨てプラスチック指令の施行 |
| **食品廃棄** | 食品廃棄物の削減目標 | ファームtoフォーク戦略と連携 |
| **繊維** | 繊維廃棄物の課題提起 | EU繊維戦略の策定 |

### 日本における循環経済の取組

| 取組 | 内容 |
|---|---|
| **循環経済ビジョン2020** | 経済産業省が策定。線形経済から循環経済への転換方針 |
| **プラスチック資源循環促進法（2022年施行）** | 製品設計から廃棄物処理まで一貫した資源循環を推進 |
| **成長志向型の資源自律経済戦略（2023年）** | 経済安全保障の観点から資源循環を経済成長に接続 |
| **GXリーグ** | カーボンニュートラルと資源循環を一体推進する産業界の枠組み |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**6.2 地域環境問題**」に位置づけられる。

サーキュラーエコノミーは社会環境管理の中核概念であると同時に、経済性管理（資源調達コスト低減・新規ビジネスモデル創出）や安全管理（有害物質の排除設計）とも深く関連する。

製品のライフサイクル全体を見通した設計・調達・運用・廃棄の最適化は、総合技術監理が求めるトレードオフ管理そのものである。
