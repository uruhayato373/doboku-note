# 環境基本計画

## 環境基本計画とは

環境基本計画とは、[**環境基本法第15条**](https://laws.e-gov.go.jp/law/405AC0000000091#Mp-At_15)に基づき、政府が定める環境の保全に関する基本的な計画である。

環境の保全に関する総合的かつ長期的な施策の大綱を定め、国の環境政策の方向性を示す最上位の計画として位置づけられる。

中央環境審議会の意見を聴いて閣議決定により策定され、おおむね6年ごとに見直しが行われてきた。

## 歴代の環境基本計画

| 世代 | 策定年 | テーマ・特徴 |
|---|---|---|
| **第一次** | 1994年（平成6年） | 環境基本法制定後の最初の計画。「循環」「共生」「参加」「国際的取組」の4つの長期目標 |
| **第二次** | 2000年（平成12年） | 「環境の世紀への道しるべ」。戦略的プログラムによる計画的取組 |
| **第三次** | 2006年（平成18年） | 「環境から拓く 新たなゆたかさへの道」。環境・経済・社会の統合的向上 |
| **第四次** | 2012年（平成24年） | 東日本大震災を踏まえた「安全」の確保。グリーン経済への移行 |
| **第五次** | 2018年（平成30年） | SDGsの考え方を活用。地域循環共生圏の創造 |
| **第六次** | 2024年（令和6年） | **ウェルビーイング/高い生活の質**を最上位目的に。循環共生型社会の実現 |

## 第六次環境基本計画（2024年5月閣議決定）

### 基本的な考え方

第六次計画は、気候変動・生物多様性の損失・汚染という**地球の3つの危機**に対し、経済社会システムの変革を通じて**循環共生型社会**の実現を目指す。

最大の特徴は、「現在及び将来の国民一人一人の**ウェルビーイング/高い生活の質**」を環境政策の最上位の目的に据えた点にある。

GDPに代表されるフロー（経済的な流れ）だけでなく、自然資本などの**ストック**の維持・回復・充実を図ることを「新たな成長」の基盤と位置づけている。

### 目指す社会像

化石燃料等の地下資源に過度に依存し物質的な豊かさに重きを置いた「**線形・規格大量生産型**」の経済社会システムから、地上資源を基調とし心の豊かさをも重視した「**循環・高付加価値型**」の経済システムへの転換を掲げている。

また、大規模集中型ではなく**自立分散型・水平分散型**の社会経済システムへの移行を推進している。

### 6つの重点戦略

| 分野 | 重点戦略の内容 |
|---|---|
| **経済** | グリーンな経済システムの構築（自然資本への投資拡大、環境価値の市場評価） |
| **国土** | 国土のストック価値向上（自然資本維持、再生可能エネルギー活用） |
| **地域** | 地域づくり（環境課題と経済課題の同時解決、地域金融のESG化） |
| **暮らし** | 安全・安心な暮らし（環境保全、ライフスタイル変革） |
| **科学技術** | 科学技術・イノベーション（グリーンイノベーション、環境スタートアップ支援） |
| **国際** | 国際協調（環境外交、途上国支援） |

### 「勝負の2030年」

第六次計画では、今後の選択と対策が**現在から数千年先まで影響を持つ**とし、2030年までを「勝負の期間」と位置づけている。

環境・経済・社会のすべてにおいて重要な転換期であるとの認識に基づき、施策の統合とシナジーによる加速的な取組を求めている。

## 総合技術監理における位置づけ

総合技術監理キーワード集では、環境基本計画は**6.3 環境保全の基本原則**（社会環境管理）に位置づけられている。

環境基本法のもとで定められる上位計画として、[環境基準](/docs/pe-comprehensive-management-environmental-standards)や[環境影響評価](/docs/pe-comprehensive-management-environmental-impact-assessment)、[汚染者負担原則（PPP）](/docs/pe-comprehensive-management-polluter-pays-principle)などの各種制度・原則の方向性を規定する存在である。
