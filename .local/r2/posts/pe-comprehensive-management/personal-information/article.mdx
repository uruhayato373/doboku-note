# 個人情報

## 個人情報とは

**個人情報**とは、生存する個人に関する情報であって、当該情報に含まれる氏名・生年月日その他の記述等により特定の個人を識別することができるもの、または**個人識別符号**が含まれるものをいう（個人情報保護法第2条第1項）。

個人情報保護法は、個人情報の有用性に配慮しつつ、個人の権利利益を保護することを目的としている。

2015年改正および2020年改正により、個人識別符号の明確化、要配慮個人情報の新設、仮名加工情報の創設など定義が大幅に拡充された。

## 法的定義と分類

### 個人情報の分類体系

| 用語 | 定義 | 例 |
|---|---|---|
| **個人情報** | 特定の個人を識別できる情報 | 氏名、顔写真、氏名付きメールアドレス |
| **個人識別符号** | それ単体で個人を識別できる符号 | 指紋データ、顔認証データ、マイナンバー、旅券番号 |
| **要配慮個人情報** | 不当な差別・偏見が生じうるセンシティブ情報 | 人種、信条、病歴、犯罪歴、障害 |
| **個人データ** | 個人情報データベース等を構成する個人情報 | データベース化された顧客情報 |
| **保有個人データ** | 事業者が開示等の権限を有する個人データ | 自社管理の従業員情報・顧客情報 |

### 個人情報とその他の情報の関係

```
個人情報（最も広い概念）
  └─ 個人データ（データベース化されたもの）
       └─ 保有個人データ（開示等の権限を有するもの）
```

## 事業者の義務

個人情報保護法は、個人情報取扱事業者に対して以下の義務を課している。

| 義務 | 内容 | 条文 |
|---|---|---|
| **利用目的の特定** | できる限り具体的に利用目的を特定 | 第17条 |
| **利用目的による制限** | 特定した目的の範囲内で利用 | 第18条 |
| **適正な取得** | 偽りその他不正の手段による取得の禁止 | 第20条 |
| **取得時の利用目的通知** | 取得時に利用目的を本人に通知・公表 | 第21条 |
| **正確性の確保** | 利用目的の範囲内で正確・最新に保つ | 第22条 |
| **安全管理措置** | 漏洩・滅失・毀損防止の措置 | 第23条 |
| **第三者提供の制限** | 本人同意なしの第三者提供を原則禁止 | 第27条 |

### 要配慮個人情報の取扱い

要配慮個人情報については、通常の個人情報よりも厳格な取扱いが求められる。

| 項目 | 通常の個人情報 | 要配慮個人情報 |
|---|---|---|
| **取得** | 利用目的の通知・公表 | **あらかじめ本人の同意が必要** |
| **オプトアウトによる第三者提供** | 可能 | **不可** |
| **漏洩時の報告義務** | 1,000件超等の場合 | **1件でも報告義務** |

## 違反時の制裁

| 制裁 | 内容 |
|---|---|
| **勧告・命令** | 個人情報保護委員会による是正勧告、命令 |
| **刑事罰（命令違反）** | 命令違反は1年以下の懲役または100万円以下の罰金 |
| **刑事罰（不正提供）** | 個人情報データベース等の不正提供は1年以下の懲役または50万円以下の罰金 |
| **法人重科** | 法人に対しては1億円以下の罰金（2020年改正） |
| **民事責任** | 損害賠償請求（不法行為） |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**4.3 知的財産権と情報の保護と活用**」に位置づけられる。

個人情報の保護は情報管理の中核的課題であり、建設プロジェクトにおいても労働者の健康情報（要配慮個人情報）、住民情報、監視カメラ映像など多くの個人情報を取り扱う。安全管理・人的資源管理との連携が不可欠である。
