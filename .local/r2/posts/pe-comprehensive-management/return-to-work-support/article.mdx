## 職場復帰支援とは

職場復帰支援とは、メンタルヘルス不調等により休業した労働者が円滑に職場復帰し、就労を継続できるよう組織的に支援する取組をいう。

厚生労働省は「心の健康問題により休業した労働者の職場復帰支援の手引き」を策定し、事業者が取り組むべき職場復帰支援の標準的な5つのステップを示している。

メンタルヘルス不調による休業者の増加を背景に、復職後の再休職防止を含めた体系的な支援体制の構築が求められている。

## 職場復帰支援の5つのステップ

- **第1ステップ：病気休業開始及び休業中のケア** — 休業開始時の手続・情報提供、休業中の連絡体制の整備
- **第2ステップ：主治医による職場復帰可能の判断** — 主治医による復職診断書の提出
- 第3ステップ：職場復帰の可否の判断及び職場復帰支援プランの作成 — 産業医の意見聴取、復帰プランの策定
- **第4ステップ：最終的な職場復帰の決定** — 事業者による最終判断、就業上の配慮の決定
- **第5ステップ：職場復帰後のフォローアップ** — 症状の再燃・再発の確認、プランの見直し

## 職場復帰支援プランの主な項目

| 項目 | 内容 |
|---|---|
| **復帰日** | 主治医・産業医の意見を踏まえて決定 |
| **就業上の配慮** | 短時間勤務、残業制限、業務内容の変更、配置転換等 |
| **段階的復帰** | 試し出勤制度、リハビリ出勤、勤務時間の段階的延長 |
| **フォローアップ計画** | 定期面談の頻度、状態確認の方法 |
| **関係者の役割** | 管理監督者・産業保健スタッフ・人事の役割分担 |

## 関係者の役割

| 関係者 | 主な役割 |
|---|---|
| **管理監督者** | 日常的な状態観察、業務調整、相談対応 |
| **産業医** | 医学的判断、就業上の意見、主治医との連携 |
| **人事労務担当** | 制度運用、勤務条件の調整、復帰プランの管理 |
| **産業保健スタッフ** | カウンセリング、復帰プログラムの実施支援 |
| **主治医** | 診断書の発行、治療方針の提示 |

## 運用上の留意点

| 留意点 | 内容 |
|---|---|
| **プライバシー保護** | 健康情報の取扱いルールを明確化し、関係者以外に漏洩しない |
| **主治医との連携** | 職場の業務内容・負荷を主治医に正確に伝える |
| **試し出勤** | 法的位置づけ（労災適用の有無等）を事前に整理 |
| **再休職防止** | フォローアップ期間を十分に確保（数か月〜1年） |
| **不利益取扱いの禁止** | 復職者への不当な降格・配置転換等を行わない |

## 総合技術監理における位置づけ


総合技術監理キーワード集では[**3.2 労働関係法と労務管理**](/docs/pe-comprehensive-management-keyword-2026#32-労働関係法と労務管理)に位置づけられる。

職場復帰支援はメンタルヘルスケアと一体的に取り組むべきテーマであり、人的資源管理と安全管理の双方にまたがる。

休業者の増加は組織の人員不足（人的資源管理）や生産性低下（経済性管理）をもたらすため、予防から復帰支援まで一貫した対策が総合技術監理者に求められる。
