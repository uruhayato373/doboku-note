## 原子力災害対策特別措置法とは

原子力災害対策特別措置法（原災法）は、原子力災害の特殊性に鑑み、原子力災害の予防、応急対策、事後対策について特別の措置を定めた法律である。

1999年のJCO臨界事故を契機に制定され、災害対策基本法の特別法として位置づけられる。

2012年には福島第一原子力発電所事故の教訓を踏まえ大幅に改正され、原子力規制委員会の設置や原子力災害対策指針の策定が規定された。

原災法が災害対策基本法の特別法として設けられた背景には、地震・水害等の一般災害と原子力災害の性質の違いがある。放射性物質による被害は五感で直接感知できず、影響が広域かつ長期に及ぶうえ、専門的な知見に基づく迅速な判断が避難区域の設定や防護措置の選択に不可欠になる。そのため一般的な防災体制を定める災害対策基本法だけでは対応しきれない部分を、原災法が予防・応急対策・事後対策の三段階にわたって補完する構造になっている。

### 法的根拠と関連法令

| 法令 | 役割 |
|---|---|
| **原子力災害対策特別措置法** | 原子力災害の予防・応急対策・事後対策の特別措置 |
| **災害対策基本法** | 一般的な防災体制の基本法（原災法はその特別法） |
| **原子力基本法** | 原子力の平和利用と安全確保の基本方針 |
| **原子力規制委員会設置法** | 独立した規制機関の設置（2012年） |
| **原子力災害対策指針** | 防護措置の判断基準（原子力規制委員会が策定） |

原子力基本法が原子力利用の平和目的と安全確保の基本方針を定め、原子力規制委員会設置法がその安全規制を担う独立機関を設けたのに対し、原災法は事故が実際に起きた際の対応手順に特化した法律である。この役割分担により、平時の安全規制と緊急時の応急対策が別々の法体系で整理され、原子力災害対策指針が両者をつなぐ具体的な判断基準として機能している。

### 制度の仕組み

原子力災害への対応は時系列に沿った一連のプロセスとして組み立てられている。まず原子力事業者が防災業務計画に基づき平常時から防災訓練を実施し、施設で異常が発生すると通報基準（EAL：Emergency Action Level）に基づいて原子力規制委員会へ通報する。これを受けて内閣総理大臣が原子力緊急事態宣言を発出し（法第15条）、自らを本部長とする原子力災害対策本部を設置して国の対応を一元的に指揮する体制に移行する。この段階で住民避難や屋内退避の指示、安定ヨウ素剤の配布といった緊急事態応急対策が実施され、事態が収束すると内閣総理大臣が原子力緊急事態解除宣言を行い、以後は除染や健康調査、被災地域の復興といった事後対策の段階に移る。

| 段階 | 内容 |
|---|---|
| **原子力災害の予防** | 原子力事業者の防災業務計画の策定、防災訓練の実施 |
| **緊急事態の発生** | 事業者が通報基準（EAL）に基づき原子力規制委員会に通報 |
| **原子力緊急事態宣言** | 内閣総理大臣が宣言を発出（法第15条） |
| **原子力災害対策本部** | 内閣総理大臣を本部長とする政府対策本部を設置 |
| **緊急事態応急対策** | 住民避難・屋内退避の指示、安定ヨウ素剤の配布 |
| **原子力緊急事態解除宣言** | 事態の収束後、内閣総理大臣が解除宣言 |
| **事後対策** | 除染、健康調査、被災地域の復興 |

ここで重要なのは、緊急事態を宣言する権限が原子力規制委員会ではなく内閣総理大臣に置かれている点である。原子力規制委員会は通報の受理や技術的な助言、原子力災害対策指針の策定を担う専門機関だが、住民避難という国民の権利に直結する措置を発動する政治的責任は、政府対策本部を統括する内閣総理大臣が負う仕組みになっている。この権限分担は試験でも問われる論点であり、混同しないよう整理しておく必要がある。

### 防護措置の判断基準

原子力災害対策指針（原子力規制委員会策定）が、区域と線量に基づく段階的な防護措置の基準を定めている。

- **PAZ（予防的防護措置準備区域）**: 原則5km圏内。放射性物質放出前でも即時避難を実施する
- **UPZ（緊急防護措置準備区域）**: 概ね30km圏内。屋内退避を基本とし、OIL基準に応じて段階的に避難へ移行する
- **OIL1（500μSv/h）**: 数時間以内に避難
- **OIL2（20μSv/h）**: 1週間以内に一時移転
- **OIL4**: 飲食物中の放射性物質濃度基準を超えた場合に摂取制限

PAZとUPZという二段階の区域設定は、放射性物質の放出前後で防護措置の考え方を切り替える発想に基づいている。PAZでは放出を待たずに予防的に避難させることで被ばくそのものを回避し、UPZでは放出後の実測線量（OIL）に応じて屋内退避から避難・一時移転へと段階的に対応を強めることで、過剰避難による社会的負担を抑えつつ必要な防護を確保する設計になっている。

### 現状・課題

原災法に基づく制度が整備された一方で、実際の運用面では複数の課題が残されている。とりわけ広域避難計画は、UPZ圏内に居住する多数の住民を限られた道路網で同時に避難させる想定であるため、平常時のシミュレーションでも交通渋滞が避けがたく、高齢者や要介護者など要配慮者の移動手段確保が計画の実効性を左右する。さらに地震・津波と原子力災害が同時に発生する複合災害では、避難路自体が損壊し通信網も途絶する可能性があり、単独の原子力災害を前提とした対策だけでは不十分になる。安定ヨウ素剤についても、事前配布体制の整備は進みつつあるが、緊急時に住民が服用のタイミングを自己判断できるだけの周知が行き届いているとは言い難く、平時からの訓練参加率の向上と合わせて住民理解を深めていくことが継続的な課題になっている。

| 課題 | 内容 |
|---|---|
| **広域避難計画** | 30km圏内の全住民避難は交通渋滞・要配慮者対応で困難 |
| **複合災害** | 地震・津波と原子力災害の同時発生への対応 |
| **安定ヨウ素剤** | 事前配布体制の整備と服用判断の周知 |
| **住民理解** | 原子力防災への理解促進と訓練参加率の向上 |

## 総合技術監理における位置づけ


総合技術監理キーワード集では[**6.2 地域環境問題**](/docs/pe-comprehensive-management-keyword-2026#62-地域環境問題)に位置づけられる。

原子力災害対策は5管理のトレードオフが特に色濃く表れる領域である。安全管理の観点では住民の被ばくリスクを最小化するために迅速な避難が最優先されるが、これは社会環境管理の観点、すなわち避難区域の設定が地域社会の生活基盤や経済活動に与える影響と常にせめぎ合う。PAZでの即時避難のように安全側に振り切った判断は住民の生活再建コストを増大させ、逆に避難範囲を絞り込みすぎれば被ばくリスクが残る。両者のバランスをどこに置くかは、原子力災害対策指針という技術的基準だけでなく、監理的な判断が求められる部分である。

人的資源管理と経済性管理の間にも同様のトレードオフがある。要配慮者の避難支援体制を手厚く構築しようとすれば、福祉車両の確保や支援人員の配置、平時からの個別避難計画の策定など継続的なコストが発生する一方、防災投資の規模を抑えれば緊急時の避難完了までに要する時間が長引き、結果的に安全管理上のリスクが増す。さらに情報管理の面では、緊急事態の通報から住民への避難指示までの情報伝達を迅速化するほど誤報や混乱のリスクも高まるため、正確性と速報性のトレードオフを常に意識した体制設計が必要になる。福島事故後は、こうした複合的なトレードオフを住民に説明し納得を得るリスクコミュニケーションと合意形成が、監理上の重要な課題として位置づけられている。

## 試験での問われ方

原災法は、危機管理に関する複数の法律を横断して比較させる設問の中で取り上げられることが多い。令和元年度択一式のⅠ-1-26では、災害対策基本法・国民保護法・原災法など危機管理関連法における避難措置の主体を問う設問が出題され、選択肢の一つに「原子力規制委員会が原子力緊急事態を宣言し、市町村長及び都道府県知事に避難の勧告・指示を行うべき措置を指示する」という記述が示された。これは誤りの選択肢であり、実際には内閣総理大臣が原子力緊急事態を宣言し、政府対策本部を通じて避難指示等を統括する権限を持つ。原子力規制委員会は通報の受理や技術的基準の策定を担う立場であって、緊急事態宣言そのものを行う主体ではない点が、この設問の核心である。

このように、原災法は単独のキーワードとして問われるだけでなく、災害対策基本法や国民保護法といった関連法令と組み合わせて、避難や緊急事態対応における権限の所在を正確に区別できているかを試す形で出題される傾向がある。
