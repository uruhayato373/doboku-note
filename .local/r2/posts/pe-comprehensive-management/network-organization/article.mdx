# ネットワーク組織

## ネットワーク組織とは

ネットワーク組織（network organization）とは、**自組織の中核機能に特化**し、その他の機能を外部の企業・専門家とのネットワークで補完する組織形態である。

従来の組織が内部に多くの機能を抱え込むのに対し、ネットワーク組織は設計・製造・販売・物流などの機能を外部パートナーに委託し、契約関係や信頼関係で結ばれたネットワークとして事業を遂行する。

情報通信技術の発達と経営環境のグローバル化を背景に、1990年代以降急速に広まった。

### 組織構造の特徴

| 項目 | 内容 |
|---|---|
| **中核組織（ハブ）** | 戦略立案・ブランド管理・ネットワーク調整などコア機能を担う |
| **外部パートナー** | 製造・物流・IT・設計など専門機能を提供する独立した組織 |
| **結合メカニズム** | 契約関係・信頼関係・情報システムによる連携 |
| **境界** | 組織の境界が曖昧で、柔軟に組み替えられる |

### ネットワーク組織の形態

| 形態 | 特徴 | 例 |
|---|---|---|
| **安定型ネットワーク** | 長期的な取引関係に基づく固定的な構成 | 自動車メーカーと系列サプライヤー |
| **動的ネットワーク** | プロジェクトごとにパートナーを組み替える | 映画制作、建設プロジェクト |
| **内部ネットワーク** | 社内の部門間を市場原理で結びつける | 社内カンパニー間の内部取引 |

### メリットとデメリット

| 区分 | 内容 |
|---|---|
| **メリット** | |
| 柔軟性の高さ | 市場変化に応じてパートナーを入れ替えられる |
| コア・コンピタンスへの集中 | 非中核機能を外部化し、強みに資源を集中できる |
| コスト効率 | 固定費を変動費化し、規模の経済を外部から享受できる |
| 専門性の活用 | 各分野で最高水準の専門企業の能力を活用できる |
| **デメリット** | |
| 統制の困難さ | 外部パートナーへの直接的な指揮命令ができない |
| 情報漏洩リスク | 技術・ノウハウが外部に流出する可能性がある |
| 品質管理の難しさ | 外部委託先の品質を一定に保つことが困難 |
| 依存リスク | 特定パートナーへの依存が高まると交渉力を失う |

### 適する環境

| 条件 | 理由 |
|---|---|
| **急速に変化する市場** | 固定的な組織では対応が間に合わない |
| **専門分化が進んだ業界** | 自社ですべてを賄うより外部活用が効率的 |
| **プロジェクトベースの事業** | 案件ごとに最適なチームを編成する必要がある |
| **情報通信基盤が整備済み** | パートナー間の調整にITが不可欠 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**3.1 人の行動と組織**」に位置づけられる。

建設業はゼネコンを中核とし、専門工事会社・設計事務所・資材メーカーがネットワークを形成する典型的なネットワーク組織である。

安全管理では元請・下請間の責任範囲の明確化、経済性管理では外部委託の費用対効果、情報管理では組織間の情報共有と機密管理が重要な論点となる。
