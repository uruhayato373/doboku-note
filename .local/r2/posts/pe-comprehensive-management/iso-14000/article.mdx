# ISO 14000シリーズ

## ISO 14000シリーズとは

ISO 14000シリーズとは、ISO（国際標準化機構）が策定した**環境マネジメント**に関する国際規格群の総称である。

1992年の地球サミット（国連環境開発会議）前後から、事業者の環境マネジメントへの関心が世界的に高まり、1993年からISOが規格の検討を開始した。

中心となるのは**ISO 14001**（環境マネジメントシステムの要求事項）であり、そのほか環境監査、環境パフォーマンス評価、環境ラベル、ライフサイクルアセスメント（LCA）など、環境管理の各側面をカバーする複数の規格で構成される。

## 環境マネジメントシステム（EMS）の仕組み

環境マネジメントシステム（EMS: Environmental Management System）とは、組織が自主的に環境保全に取り組むための**方針・目標の設定と、その達成に向けた体制・手続きの仕組み**である。

ISO 14001では、**PDCAサイクル**に基づいて環境マネジメントのレベルを継続的に改善していく。

| フェーズ | 活動内容 |
|---|---|
| **Plan（計画）** | 環境方針の策定、環境側面の特定、目標・実施計画の設定 |
| **Do（実施）** | 体制・役割の整備、教育訓練、運用管理の実施 |
| **Check（点検）** | 監視・測定、順守評価、内部監査の実施 |
| **Act（見直し）** | マネジメントレビュー、是正処置、継続的改善 |

### 2015年改訂の主な変更点

ISO 14001は1996年に制定され、2004年・2015年に改訂された。

2015年改訂では以下の変更が行われた。

- **リーダーシップの強化**: トップマネジメントの関与と説明責任を明確化
- **リスクに基づく考え方**: リスクと機会を特定し、計画に反映する要求を追加
- **ライフサイクルの視点**: 自組織の活動だけでなく、製品・サービスのライフサイクル全体を考慮
- **外部・内部の課題**: 組織を取り巻く状況（利害関係者のニーズ等）の理解を要求

## 主要規格の構成

| 規格番号 | 名称 | 内容 |
|---|---|---|
| **ISO 14001** | 環境マネジメントシステム — 要求事項 | EMSの認証基準となる中核規格 |
| ISO 14004 | 環境マネジメントシステム — 一般指針 | ISO 14001の実施を支援するガイダンス |
| ISO 14010系 | 環境監査 | 環境監査の原則・手順（現在はISO 19011に統合） |
| ISO 14020系 | 環境ラベル | タイプI〜IIIの環境ラベル・宣言の枠組み |
| ISO 14040系 | ライフサイクルアセスメント（LCA） | 製品の環境負荷を評価する手法 |
| ISO 14064系 | 温室効果ガス | GHG排出量の定量化・報告・検証 |

## 認証制度

ISO 14001の認証は、**JAB（公益財団法人日本適合性認定協会）**が認定した第三者認証機関による審査で取得する。

組織はISO 14001への適合について、以下の2つの方法を選択できる。

- **自己宣言**: 組織自らが適合を宣言する方法
- **第三者認証**: 認定された認証機関による審査を受けて登録する方法

認証取得後も、定期的なサーベイランス審査（維持審査）と更新審査が行われ、継続的な適合が確認される。

### エコアクション21との違い

| 観点 | ISO 14001 | エコアクション21 |
|---|---|---|
| 策定主体 | ISO（国際標準化機構） | 環境省（日本独自） |
| 対象 | あらゆる規模・業種の組織 | 主に中小事業者 |
| 要求水準 | 高い（詳細な文書化・手順） | 簡易（取り組みやすさを重視） |
| 認証費用 | 比較的高額 | 比較的低額 |
| 国際的通用性 | 国際規格として世界で通用 | 日本国内のみ |

## 総合技術監理における位置づけ

総合技術監理キーワード集では、ISO 14000シリーズは**6.4 組織の社会的責任と環境管理活動**（社会環境管理）に位置づけられている。

企業等が経営の中で自主的に環境保全に取り組むための仕組みとして、[エコアクション21](/docs/pe-comprehensive-management-eco-action-21)や[環境会計](/docs/pe-comprehensive-management-environmental-accounting)、[環境コミュニケーション](/docs/pe-comprehensive-management-environmental-communication)などの関連キーワードと合わせて出題される。
