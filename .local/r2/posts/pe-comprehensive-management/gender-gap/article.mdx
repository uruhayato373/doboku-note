# ジェンダーギャップ

## ジェンダーギャップとは

**ジェンダーギャップ（Gender Gap）** とは、性別に起因する社会的・経済的・政治的な格差のことである。世界経済フォーラム（WEF）が毎年公表する**ジェンダーギャップ指数（GGI）** が国際比較の代表的指標として用いられる。

## ジェンダーギャップ指数（GGI）の構成

| 分野 | 指標例 | 日本の順位傾向 |
|---|---|---|
| **経済参画** | 労働参加率、賃金格差、管理職比率 | 低い |
| **教育達成** | 識字率、就学率 | 高い |
| **健康と生存** | 出生時性比、健康寿命 | 高い |
| **政治参画** | 国会議員比率、閣僚比率 | 非常に低い |

※日本は2024年で146か国中118位。経済・政治分野の格差が大きい。

## 日本における主な課題

| 課題 | 内容 |
|---|---|
| **賃金格差** | 男性を100とした場合、女性は約75（正規雇用） |
| **管理職比率** | 女性管理職比率は約12%（先進国で最低水準） |
| **M字カーブ** | 出産・育児期に女性の就業率が低下する日本特有の現象 |
| **無償労働の偏り** | 家事・育児の負担が女性に集中 |
| **非正規雇用比率** | 女性の非正規雇用比率は約54%（男性は約22%） |

## 建設業におけるジェンダーギャップ

| 項目 | 現状 |
|---|---|
| **女性技術者比率** | 約6%（全産業平均より低い） |
| **女性技能者比率** | 約2%（極めて低い） |
| **「もっと女性が活躍できる建設業」行動計画** | 国交省（2014年〜）による女性活躍推進 |
| **けんせつ小町** | 日建連の女性活躍推進ブランド |
| **環境整備** | 女性用トイレ・更衣室の現場設置義務化 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**3.3 人的資源の活用**」に位置づけられる。

ジェンダーギャップの解消はダイバーシティ経営・ポジティブアクション・LGBTQ対応と並ぶ人的資源管理の重要テーマであり、女性活躍推進法・均等法等の法制度と連動して取り組む必要がある。
