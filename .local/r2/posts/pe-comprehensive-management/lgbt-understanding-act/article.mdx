# LGBT理解増進法

## LGBT理解増進法とは

LGBT理解増進法（正式名称：性的指向及びジェンダーアイデンティティの多様性に関する国民の理解の増進に関する法律）は、性的指向およびジェンダーアイデンティティの多様性に関する国民の理解を増進することを目的として2023年6月に施行された法律である。

性的マイノリティに対する差別を禁止する「差別禁止法」ではなく、理解を広げるための「理解増進法」として位置づけられている。

国、地方公共団体、事業主、学校に対して、理解増進のための施策の実施や環境整備について努力義務を課している。

### 基本的な用語の定義

| 用語 | 定義 |
|---|---|
| **性的指向** | 恋愛感情又は性的感情の対象となる性別についての指向 |
| **ジェンダーアイデンティティ** | 自己の属する性別についての認識に関するその同一性の有無又は程度に係る意識 |
| **LGBT** | レズビアン（L）、ゲイ（G）、バイセクシュアル（B）、トランスジェンダー（T）の総称 |
| **SOGI** | 性的指向（Sexual Orientation）とジェンダーアイデンティティ（Gender Identity）の頭文字 |

### 主要規定

| 対象 | 努力義務の内容 |
|---|---|
| **国** | 基本計画の策定、知識の普及啓発、相談体制の整備、調査研究の推進 |
| **地方公共団体** | 地域の実情に応じた施策の実施 |
| **事業主** | 性的指向・ジェンダーアイデンティティの多様性に関する労働者の理解増進、普及啓発、就業環境の整備 |
| **学校** | 教育・啓発、教育環境の整備、相談機会の確保 |

### 職場における対応

| 取組 | 内容 |
|---|---|
| **方針の策定** | 差別やハラスメントを許さない方針を明文化し周知 |
| **相談体制** | 性的指向・ジェンダーアイデンティティに関する相談窓口の設置 |
| **アウティング防止** | 本人の同意なく性的指向等を暴露する行為（アウティング）の防止 |
| **制度整備** | 同性パートナーへの福利厚生適用、通称名使用の許可等 |
| **研修** | 管理職・全従業員向けの理解増進研修の実施 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**3.2 労働関係法と労務管理**」に位置づけられる。

LGBT理解増進法はダイバーシティ・インクルージョンの推進に関わる法律であり、人的資源管理における多様な人材の活用と職場環境の整備に直結する。

SOGIハラスメントはパワハラ防止指針にも位置づけられており、労働施策総合推進法（パワハラ防止法）との関連も重要である。
