# 障害者雇用促進法

## 障害者雇用促進法とは

**障害者雇用促進法**（正式名称：障害者の雇用の促進等に関する法律、昭和35年法律第123号）は、障害者の雇用義務等に基づく雇用の促進と、職業リハビリテーションを通じた障害者の職業的自立を図る法律である。

事業主に対し一定割合以上の障害者雇用を義務付ける法定雇用率制度と、その実効性を担保する障害者雇用納付金制度を柱としている。

## 法律の概要

| 項目 | 内容 |
|---|---|
| **正式名称** | 障害者の雇用の促進等に関する法律（昭和35年法律第123号） |
| **目的** | 障害者の雇用の促進、職業の安定 |
| **対象障害者** | 身体障害者、知的障害者、精神障害者（精神障害者保健福祉手帳所持者） |
| **所管** | 厚生労働省 |
| **主要機関** | （独）高齢・障害・求職者雇用支援機構 |

## 法定雇用率制度

| 区分 | 法定雇用率（2024年4月〜） | 法定雇用率（2026年7月〜） |
|---|---|---|
| **民間企業** | 2.5% | 2.7% |
| **国・地方公共団体** | 2.8% | 3.0% |
| **都道府県等の教育委員会** | 2.7% | 2.9% |

### 対象事業主

| 項目 | 内容 |
|---|---|
| **対象** | 常時雇用する労働者が40人以上（2024年4月〜）の事業主 |
| **報告義務** | 毎年6月1日時点の障害者雇用状況を報告 |
| **雇入れ計画** | 雇用率未達成の事業主に対し、厚生労働大臣が計画作成命令 |
| **企業名公表** | 正当な理由なく計画に従わない場合、企業名を公表 |

### カウント方法

| 障害の程度 | 常用雇用（週30時間以上） | 短時間労働（週20〜30時間） |
|---|---|---|
| **重度身体障害者・重度知的障害者** | 2人分 | 1人分 |
| **身体障害者・知的障害者** | 1人分 | 0.5人分 |
| **精神障害者** | 1人分 | 1人分（当分の間の特例） |

## 障害者雇用納付金制度

| 項目 | 内容 |
|---|---|
| **納付金** | 法定雇用率未達成の事業主から不足1人につき月額5万円を徴収 |
| **調整金** | 法定雇用率を超えて障害者を雇用する事業主に超過1人につき月額2万9千円を支給 |
| **報奨金** | 常時雇用100人以下の事業主で一定数超の障害者を雇用する場合に支給 |
| **対象** | 常時雇用する労働者が100人超の事業主（納付金の対象） |

## 合理的配慮の提供義務

| 項目 | 内容 |
|---|---|
| **義務** | 障害者が職場で支障なく働けるよう、必要な措置を講じること |
| **具体例** | 車椅子用の机の設置、手話通訳の配置、勤務時間の調整、業務内容の調整 |
| **過重な負担** | 事業主に過重な負担を及ぼす場合は免除（事業規模・費用等を考慮） |
| **差別の禁止** | 募集・採用、賃金、配置、昇進等における障害を理由とする差別の禁止 |

## 職業リハビリテーション

| 施設・制度 | 内容 |
|---|---|
| **地域障害者職業センター** | 職業評価、職業指導、職業準備訓練の実施 |
| **障害者就業・生活支援センター** | 就業面と生活面の一体的な支援 |
| **ジョブコーチ（職場適応援助者）** | 障害者の職場適応を支援する専門家を派遣 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**3.2 労働関係法と労務管理**」に位置づけられる。

障害者雇用促進法は、ダイバーシティ推進・社会的包摂の観点から人的資源管理の重要テーマである。

総合技術監理の観点では、法定雇用率の達成義務と企業名公表のリスク（社会環境管理）、合理的配慮の提供に伴うコスト（経済性管理）、職場環境の整備（安全管理）など、複数の管理分野にまたがるテーマとなる。
