# 根本原因分析（RCA）

## RCAとは

RCA（Root Cause Analysis：根本原因分析）とは、**事故・トラブルの表面的な原因ではなく、根本的な原因（Root Cause）を特定し、再発防止策を立案するための体系的な分析手法**である。

「なぜ起きたか」を繰り返し掘り下げることで、直接原因の背後にある組織的・システム的な要因にまで到達することを目指す。

## 主要な手法

| 手法 | 内容 |
|---|---|
| **なぜなぜ分析（5 Whys）** | 「なぜ？」を繰り返し（通常5回程度）問い、根本原因に到達する |
| **特性要因図（フィッシュボーン図）** | 結果（特性）に影響する要因を魚の骨状に整理する |
| **FTA** | [FTA](/docs/pe-comprehensive-management-fta)を用いてトップダウンで原因を展開する |
| **VTA法** | [VTA法](/docs/pe-comprehensive-management-vta-method)を用いて時系列の逸脱を特定する |

## 分析の手順

| ステップ | 内容 |
|---|---|
| **1. 問題の定義** | 分析対象とする事故・トラブルを明確に定義する |
| **2. データ収集** | 事実関係・時系列・関係者の証言等を収集する |
| **3. 原因の分析** | 上記手法を用いて直接原因→間接原因→根本原因を特定する |
| **4. 対策の立案** | 根本原因に対する是正策・予防策を立案する |
| **5. 対策の実施・検証** | 対策を実施し、効果を検証する |

## 根本原因の階層

| 階層 | 内容 | 例 |
|---|---|---|
| **直接原因** | 事故を直接引き起こした事象 | 作業員の操作ミス |
| **間接原因** | 直接原因を誘発した要因 | 手順書の不備、訓練不足 |
| **根本原因** | 間接原因の背景にある組織的要因 | 安全管理体制の不備、安全文化の欠如 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**5.6 システム安全工学手法**」に位置づけられている。

RCAは[VTA法](/docs/pe-comprehensive-management-vta-method)や[トライポッド理論](/docs/pe-comprehensive-management-tripod-theory)とともに事故の事後分析に活用される。単なる直接原因の除去ではなく、組織的な根本原因への対策を講じることが総合技術監理者に求められる。
