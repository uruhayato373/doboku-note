# 情報公開法

## 情報公開法とは

**情報公開法**（正式名称：行政機関の保有する情報の公開に関する法律、平成11年法律第42号）とは、行政機関が保有する行政文書について、何人にも開示請求権を認め、行政の透明性と説明責任（アカウンタビリティ）を確保するための法律である。2001年4月施行。

## 法律の構成

| 条項 | 内容 |
|---|---|
| **第1条（目的）** | 国民主権の理念に基づき政府の説明責任を全うする |
| **第3条（開示請求権）** | 何人も行政文書の開示を請求できる |
| **第5条（不開示情報）** | 不開示とすべき情報の6類型を限定列挙 |
| **第6条（部分開示）** | 不開示部分を除いた部分を開示 |
| **第7条（裁量的開示）** | 公益上特に必要なら不開示情報も開示可能 |
| **第9条（開示決定等の期限）** | 原則30日以内に開示決定 |

## 対象機関と行政文書

| 項目 | 内容 |
|---|---|
| **対象機関** | 国の行政機関（内閣府・各省庁等） |
| **行政文書** | 職員が職務上作成・取得した文書で、組織的に用いるもの |
| **独立行政法人** | 独立行政法人等情報公開法（別法）で対応 |
| **地方公共団体** | 各自治体の情報公開条例で対応 |

## 不開示情報の6類型

| 類型 | 概要 |
|---|---|
| **1. 個人情報** | 特定の個人を識別できる情報 |
| **2. 法人情報** | 法人の正当な利益を害するおそれ |
| **3. 国の安全等** | 国の安全・外交上の利益を害するおそれ |
| **4. 公共の安全** | 犯罪予防等に支障を及ぼすおそれ |
| **5. 審議検討情報** | 率直な意見交換等を不当に損なうおそれ |
| **6. 事務事業情報** | 事務事業の適正な遂行に支障を及ぼすおそれ |

## 救済制度

| 制度 | 内容 |
|---|---|
| **審査請求** | 不開示決定等に対する行政機関の長への不服申立て |
| **情報公開・個人情報保護審査会** | 審査請求を受けた第三者機関（内閣府） |
| **行政事件訴訟** | 裁判所への取消訴訟 |
