# POPs条約

## POPs条約とは

POPs条約（ストックホルム条約）は、残留性有機汚染物質（Persistent Organic Pollutants: POPs）の製造・使用の禁止又は制限、非意図的生成物質の排出削減、及びPOPs含有廃棄物の適正管理を定めた国際条約である。

2001年に採択され、2004年に発効した。

POPsは環境中で分解されにくく、生物濃縮により食物連鎖の上位に蓄積し、長距離輸送によって発生源から遠く離れた地域の環境や人体に深刻な影響を及ぼすことが特徴である。

### POPsの4つの特性

POPsは以下の 4 つの特性により、地球規模で長期に環境影響を及ぼす。

| 特性 | 内容 |
|---|---|
| **残留性（Persistence）** | 環境中で容易に分解されず、長期間残留する |
| **生物蓄積性（Bioaccumulation）** | 脂肪組織に蓄積し、食物連鎖を通じて濃縮される |
| **長距離移動性（Long-range Transport）** | 大気・海流により地球規模で移動する |
| **有害性（Toxicity）** | 人の健康や生態系に悪影響を及ぼす |

### 条約の規制内容

条約は附属書 A／B／C の 3 区分で対象物質を分類し、規制内容を定めている。

| 附属書 | 規制内容 | 対象物質例 |
|---|---|---|
| **附属書A（廃絶）** | 製造・使用・輸出入の廃絶 | PCB、DDT、アルドリン他 |
| **附属書B（制限）** | 特定用途のみ使用許可 | DDT（マラリア対策）、PFOS |
| **附属書C（非意図的生成の削減）** | 排出の削減・廃絶 | ダイオキシン類、フラン類 |

附属書 A の主要対象物質には、上記の他にクロルデン・ディルドリン・エンドリン・ヘプタクロル等の有機塩素系農薬が含まれる。DDT は附属書 A に分類されつつ、マラリア媒介蚊の防除目的に限り附属書 B での使用が許容される（人道的例外）。

### 対象物質の拡大

条約採択時は12物質（ダーティ・ダズン）であったが、締約国会議（COP）での検討を経て対象物質は継続的に追加されている。

| 時期 | 追加物質例 |
|---|---|
| **COP4（2009年）** | PFOS及びその塩、リンデン等9物質 |
| **COP5（2011年）** | エンドスルファン |
| **COP7（2015年）** | ヘキサクロロブタジエン等3物質 |
| **COP9（2019年）** | ジコホル、PFOA及びその塩 |
| **COP11（2023年）** | メトキシクロル、デクロランプラス、UV-328 |

### 日本の対応

日本は条約批准に合わせ、複数の法令と国家実施計画で国内対応を整備している。

| 対応 | 内容 |
|---|---|
| **条約批准** | 2002年に締結（発効は2004年） |
| **国内法整備** | 化審法でPOPs該当物質を第一種特定化学物質に指定し製造・輸入を禁止 |
| **ダイオキシン対策** | ダイオキシン類対策特別措置法（1999年制定）で排出削減 |
| **PCB廃棄物処理** | PCB特別措置法（2001年制定）に基づく計画的処理（処理期限：高濃度2026年度末） |
| **国家実施計画** | POPs条約に基づく国内実施計画を策定・更新 |

## 総合技術監理における位置づけ


総合技術監理キーワード集では[**6.2 地域環境問題**](/docs/pe-comprehensive-management-keyword-2026#62-地域環境問題)に位置づけられる。

POPs条約は国際条約と国内法制度（[化審法](/docs/pe-comprehensive-management-chemical-substances-review-act)・ダイオキシン法・[化管法／PRTR法](/docs/pe-comprehensive-management-prtr-act)・PCB特措法）の連動が問われるテーマであり、建設分野ではPCB含有機器の処理やダイオキシン対策が実務上の重要課題となる。経済性管理（処理費用）と社会環境管理（適正処理）の両立が求められる。
