# テクニカルスキルとノンテクニカルスキル

## 定義

**テクニカルスキル**（Technical Skills）とは、専門的な知識・技術・技能であり、業務遂行に直接必要な能力である。**ノンテクニカルスキル**（Non-Technical Skills）とは、人間と人間の関係性を重視した認知的・社会的なスキルであり、安全な業務遂行を支える能力である。

安全管理においては、両者をバランスよく向上させていくことが望ましい。

## ノンテクニカルスキルの構成要素

| カテゴリ | スキル | 内容 |
|---|---|---|
| **認知的スキル** | 状況認識 | 周囲の状況を正確に把握する |
| | 意思決定 | 適切な判断を行う |
| **社会的スキル** | コミュニケーション | 情報を正確に伝達・共有する |
| | チームワーク | チームとして協力して作業する |
| | リーダーシップ | チームを安全に導く |
| **個人資質** | ストレス管理 | 緊急時に冷静さを保つ |
| | 疲労管理 | 疲労による能力低下を管理する |

## テクニカルスキルとの関係

テクニカルスキルがいくら高くても、ノンテクニカルスキルが不足していると安全が確保できない。航空・医療・原子力等の高リスク産業で特に重視される。
