# 過程決定計画図（PDPC法）

## PDPC法とは

PDPC法（Process Decision Program Chart：過程決定計画図）とは、**事態の進展とともに起こりうる問題を事前に予測し、それに対する対策をあらかじめ計画しておく手法**である。

新QC七つ道具の1つであり、不確実性の高い計画やプロジェクトにおいて、想定外の事態に備えるために用いられる。

## 作成手順

| ステップ | 内容 |
|---|---|
| **1. 目標の設定** | 達成すべき目標を明確にする |
| **2. 理想ルートの作成** | 目標に至る理想的な手順（正常ルート）を記述する |
| **3. 問題点の予測** | 各ステップで起こりうる問題・障害を予測する |
| **4. 対策の立案** | 各問題点に対する代替手段・対策を検討する |
| **5. 図の作成** | 正常ルートと代替ルートを矢印で接続した図を作成する |

## 特徴

| 特徴 | 内容 |
|---|---|
| **事前予防型** | 問題が発生する前に対策を準備する |
| **視覚的** | 正常ルートと異常時の代替ルートを図で表現できる |
| **柔軟性** | 計画の進展に応じて図を更新・追加できる |

## 新QC七つ道具における位置づけ

| 道具 | 用途 |
|---|---|
| 親和図法 | 混沌とした情報の整理 |
| 連関図法 | 複雑な因果関係の解明 |
| 系統図法 | 目的と手段の体系的展開 |
| マトリックス図法 | 多元的な関係の整理 |
| **PDPC法** | **不測の事態への事前対応計画** |
| アローダイアグラム法 | 工程管理・日程計画 |
| マトリックスデータ解析法 | 多変量データの分析 |
