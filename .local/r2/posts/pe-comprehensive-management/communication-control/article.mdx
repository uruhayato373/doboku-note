# コミュニケーション・コントロール

## コミュニケーション・コントロールとは

**コミュニケーション・コントロール** とは、組織やプロジェクトにおけるコミュニケーション活動が、計画どおりに実施されているかを監視・管理し、必要に応じて是正措置を講じるプロセスのことである。コミュニケーション計画のPDCAサイクルにおけるC（Check）とA（Act）に相当する。

## コントロールの対象

| 対象 | 内容 |
|---|---|
| **情報の正確性** | 伝達される情報の内容が正確か |
| **適時性** | 必要なタイミングで情報が届いているか |
| **到達性** | 対象者に確実に情報が届いているか |
| **理解度** | 受信者が情報を正しく理解しているか |
| **双方向性** | フィードバックが適切に機能しているか |

## コントロールのプロセス

| ステップ | 内容 |
|---|---|
| **1. 基準の設定** | コミュニケーション計画の目標・基準を明確化 |
| **2. 実績の測定** | 情報伝達の実績（頻度・到達率・理解度）を測定 |
| **3. 差異の分析** | 計画と実績の差異を分析 |
| **4. 是正措置** | 差異の原因に対する改善策を実施 |
| **5. 計画の更新** | 必要に応じてコミュニケーション計画を修正 |

## コントロール手法

| 手法 | 内容 |
|---|---|
| **コミュニケーション監査** | 情報伝達の有効性を体系的に評価 |
| **フィードバック収集** | アンケート・ヒアリングによる理解度の確認 |
| **情報到達確認** | 既読確認・受領確認の仕組み |
| **会議体の評価** | 会議の有効性（時間・参加者・成果）の評価 |
| **情報品質レビュー** | 報告書・通知文書の品質確認 |

## 建設プロジェクトでの適用

| 場面 | コントロール内容 |
|---|---|
| **工事連絡** | 指示・連絡事項の伝達漏れ防止 |
| **安全情報** | 安全指示の全作業員への周知確認 |
| **設計変更** | 変更情報の関係者への確実な伝達 |
| **住民対応** | 苦情・問合せへの対応状況の追跡 |
