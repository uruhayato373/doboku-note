# 継続雇用制度

## 継続雇用制度とは

**継続雇用制度**とは、定年に達した従業員を引き続き雇用する制度の総称である。高年齢者雇用安定法に基づき、企業は65歳までの雇用確保措置として、①定年引上げ、②継続雇用制度の導入、③定年廃止のいずれかを講じる義務がある。

## 継続雇用制度の種類

継続雇用制度には2種類がある。

- **再雇用制度**: 定年退職後に新たな労働契約で再雇用 — 雇用関係は一旦終了し再締結
- **勤務延長制度**: 定年到達後も退職させず雇用を延長 — 雇用関係は継続

## 法的枠組み

| 法令・年次 | 内容 |
|---|---|
| **高年齢者雇用安定法（2004年改正）** | 65歳までの雇用確保措置の義務化 |
| **同法（2012年改正）** | 希望者全員の継続雇用義務（経過措置あり） |
| **同法（2021年改正）** | 70歳までの就業確保措置の努力義務 |

## 70歳までの就業確保措置（努力義務）

| 措置 | 内容 |
|---|---|
| **① 定年引上げ** | 70歳まで定年を引き上げ |
| **② 継続雇用制度** | 70歳まで継続雇用（グループ会社含む） |
| **③ 定年廃止** | 定年制度を廃止 |
| **④ 業務委託契約** | 70歳まで継続的に業務委託（創業支援等措置） |
| **⑤ 社会貢献事業** | 70歳まで社会貢献事業に従事（創業支援等措置） |

## 建設部門における課題と対応

| 課題 | 対応策 |
|---|---|
| **体力的負荷** | 軽作業・管理業務への配置転換 |
| **技能伝承** | ベテラン技術者による若手指導・OJTの仕組み化 |
| **安全管理** | 高齢者の労働災害リスク増大への対策（転倒・墜落防止） |
| **処遇設計** | 再雇用時の賃金・役職の適正設計（モチベーション維持） |

## 制度の成立と変遷

高年齢者雇用安定法は1971年（昭和46年）に制定された。当初は高齢者の職業の安定を図ることを目的としており、定年延長の努力義務規定が中心であった。

その後、少子高齢化の加速と年金支給開始年齢の引き上げを背景に、段階的に義務化の範囲が拡大された。2004年（平成16年）改正では65歳までの雇用確保措置が義務化され、2006年に全面施行された。2012年（平成24年）改正では、それまで労使協定により選定基準を設けることが認められていた仕組みを見直し、希望者全員を対象とする継続雇用が義務化された。

2021年（令和3年）改正は、公的年金の受給開始年齢の柔軟化（65〜75歳選択制）と歩調を合わせ、70歳までの就業機会確保を努力義務として新設した。業務委託や社会貢献事業への従事も「創業支援等措置」として認められ、雇用の枠を超えた就業確保の概念が制度に組み込まれた。

建設部門では、団塊世代の大量退職に伴う技能労働者不足が深刻化した2010年代以降、継続雇用制度を活用したベテラン技術者の確保が現場における重要課題となっている。国土交通省は公共工事の設計労務単価において年齢層別の単価設定を行っており、高齢技術者の処遇改善を後押しする施策が進められている。
