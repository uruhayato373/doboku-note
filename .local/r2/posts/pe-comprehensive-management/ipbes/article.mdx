# IPBES（生物多様性及び生態系サービスに関する政府間科学-政策プラットフォーム）

## IPBESとは

**IPBES**（Intergovernmental Science-Policy Platform on Biodiversity and Ecosystem Services）とは、生物多様性と生態系サービスに関する科学的知見を集約・評価し、政策立案者に提供する政府間組織である。

2012年に設立され、本部はドイツ・ボンに置かれている。

気候変動分野におけるIPCCと同様の役割を生物多様性分野で果たすことから、「**生物多様性版IPCC**」とも呼ばれる。

### IPCCとIPBESの対比

| 項目 | IPCC | IPBES |
|---|---|---|
| **対象分野** | 気候変動 | 生物多様性・生態系サービス |
| **設立年** | 1988年 | 2012年 |
| **設立母体** | WMO・UNEP | UNEP主導 |
| **本部** | ジュネーブ（スイス） | ボン（ドイツ） |
| **主な成果物** | 評価報告書（AR1〜AR6） | 地球規模評価報告書、テーマ別評価報告書 |
| **役割** | 気候変動に関する科学的知見の評価・統合 | 生物多様性・生態系サービスに関する科学的知見の評価・統合 |

### IPBESの4つの機能

| 機能 | 内容 |
|---|---|
| **評価（Assessment）** | 生物多様性・生態系サービスの現状と将来予測を科学的に評価 |
| **政策支援ツール（Policy Support Tools）** | 政策立案者向けのツール・方法論の開発 |
| **能力構築（Capacity Building）** | 途上国の科学者・政策立案者の能力向上 |
| **知識生成（Knowledge Generation）** | 研究課題の特定と知識基盤の強化 |

### 主要な評価報告書

| 報告書 | 公表年 | 主な知見 |
|---|---|---|
| **花粉媒介者・食料生産評価** | 2016年 | ミツバチ等の花粉媒介者の減少が食料生産に深刻な影響。世界の作物の75%以上が動物による花粉媒介に依存 |
| **土地劣化・再生評価** | 2018年 | 世界の陸地面積の75%以上が既に劣化。2050年までに95%に達する可能性 |
| **地球規模評価報告書** | 2019年 | 約100万種が絶滅の危機。自然の劣化速度は人類史上かつてない水準。5つの直接的要因を特定 |
| **自然の多様な価値の評価** | 2022年 | 自然の価値を市場価値だけでなく多様な観点から評価する必要性を提示 |

### 生物多様性喪失の5つの直接的要因

IPBES地球規模評価報告書（2019年）で特定された要因である。

| 順位 | 要因 | 内容 |
|---|---|---|
| **1** | **土地・海域利用の変化** | 農地開発、都市化、森林伐採、埋立て等 |
| **2** | **生物の直接的な搾取** | 乱獲、密猟、過剰伐採等 |
| **3** | **気候変動** | 気温上昇、海面上昇、異常気象の頻発 |
| **4** | **汚染** | 農薬、プラスチック、窒素・リンの過剰投入 |
| **5** | **外来種の侵入** | 在来種の生息地・食物連鎖のかく乱 |
