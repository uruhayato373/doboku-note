# フォーラム標準

## フォーラム標準とは

**フォーラム標準（forum standard）** とは、特定の技術分野に関心を持つ複数の企業・団体が自主的に集まり（フォーラム、コンソーシアム）、協議・合意によって策定する標準である。

公的標準化機関を介さず、市場のニーズに即した迅速な標準策定が可能であり、情報通信分野を中心に広く普及している。

デジュール標準の策定に数年を要する一方、フォーラム標準は参加者間の合意で比較的短期間（1〜3年程度）に策定できる機動性が強みである。

### 策定主体の例

| フォーラム/コンソーシアム | 策定した標準 | 分野 |
|---|---|---|
| **IEEE（Institute of Electrical and Electronics Engineers）** | IEEE 802.11（Wi-Fi）、IEEE 802.3（Ethernet） | 通信・ネットワーク |
| **W3C（World Wide Web Consortium）** | HTML、CSS、XML | Web技術 |
| **Bluetooth SIG** | Bluetooth | 近距離無線通信 |
| **USB-IF（USB Implementers Forum）** | USB規格 | インターフェース |
| **OASIS** | SAML、ebXML | セキュリティ・電子商取引 |
| **3GPP（3rd Generation Partnership Project）** | LTE、5G NR | 移動体通信 |

### 策定プロセス

フォーラム標準の策定プロセスは組織ごとに異なるが、一般的に以下の流れをとる。

| 段階 | 内容 |
|---|---|
| **参加者の募集** | 技術分野に関心を持つ企業・団体が参加を表明し、メンバーシップ契約を締結する |
| **技術仕様の提案** | 参加企業が技術仕様のドラフトを提案する |
| **技術委員会での審議** | ワーキンググループ・技術委員会で仕様の検討・修正を行う |
| **知的財産権の処理** | 必須特許の開示とFRAND条件でのライセンス宣言を行う |
| **投票・承認** | 参加メンバーの投票により仕様を承認する |
| **公開・普及** | 仕様書を公開し、認証プログラム等を通じて普及を図る |

### 3種類の標準の比較

| 比較項目 | デジュール標準 | フォーラム標準 | デファクト標準 |
|---|---|---|---|
| **策定主体** | 公的標準化機関（ISO、IEC等） | 関心企業・団体のコンソーシアム | 市場競争の結果（特定主体なし） |
| **参加資格** | 各国の標準化機関を通じて参加 | フォーラム加入企業・団体 | なし（市場参加者全体） |
| **策定期間** | 長い（3〜5年） | 中程度（1〜3年） | 短い（市場動向次第） |
| **技術の先進性** | 合意重視で保守的になりやすい | 先端技術を迅速に反映しやすい | 最も先進的（市場で淘汰） |
| **透明性** | 高い（公式手続き） | 中程度（メンバーに限定） | 低い |
| **相互運用性** | 高い | 高い（認証制度が充実） | 低い（互換性が保証されない） |
| **具体例** | ISO 9001、JIS | Wi-Fi、USB、Bluetooth | Windows、Google検索 |

### フォーラム標準の特徴

| 利点 | 課題 |
|---|---|
| 市場ニーズに即した迅速な策定が可能 | 参加企業の利害が標準内容に偏りを生む可能性がある |
| 先端技術を早期に標準化できる | 非参加企業にとっては標準策定への影響力が限定される |
| 認証プログラムにより相互運用性が担保される | 複数のフォーラムが競合する場合、標準が乱立するリスクがある |
| デジュール標準への移行が可能（例：Wi-Fi→ISO/IEC標準） | 知的財産権の処理（FRAND条件）が複雑になることがある |

### デジュール標準との関係

フォーラム標準がデジュール標準に移行するケースも多い。

たとえば、IEEE 802.11（Wi-Fi）はISO/IEC 8802-11としてISO規格にも採択されている。

このように、フォーラムで迅速に策定した仕様を後から公的標準化機関に提出し、デジュール標準化する「ファスト・トラック」手続きも活用されている。

## 総合技術監理における位置づけ

総合技術監理キーワード集では[**4.3 知的財産権と情報の保護と活用**](/docs/pe-comprehensive-management-keyword-2026#43-知的財産権と情報の保護と活用)に位置づけられる。

フォーラム標準への参画は、情報管理における技術動向の把握と自社技術の標準反映という戦略的意義を持つ。

参加に伴うメンバーシップ費用・人材派遣コストは経済性管理の投資判断であり、フォーラムへの参加・不参加は事業戦略と一体的に決定する必要がある。
