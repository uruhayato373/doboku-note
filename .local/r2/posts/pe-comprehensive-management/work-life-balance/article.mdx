# ワーク・ライフ・バランス

## ワーク・ライフ・バランスとは

ワーク・ライフ・バランス（仕事と生活の調和）とは、働く人が仕事上の責任を果たしながら、家庭生活・地域活動・自己啓発など仕事以外の生活も充実させることができる状態をいう。

2007年に「仕事と生活の調和（ワーク・ライフ・バランス）憲章」および「仕事と生活の調和推進のための行動指針」が策定され、官民一体の取組が進められている。

少子高齢化による労働力人口の減少、共働き世帯の増加、長時間労働の弊害などを背景に、その重要性が高まっている。

## 憲章が目指す3つの社会

2007 年策定のワーク・ライフ・バランス憲章は、以下の 3 つの社会の実現を目指す。

| 目指す社会 | 内容 |
|---|---|
| **就労による経済的自立が可能な社会** | 若者が経済的に自立でき、結婚・子育てに前向きになれる |
| **健康で豊かな生活のための時間が確保できる社会** | 労働時間の短縮、年次有給休暇の取得促進 |
| **多様な働き方・生き方が選択できる社会** | 性別・年齢にかかわらず多様な働き方を選択できる |

## 主な関連制度・施策

WLB の実現を支える主要な制度・施策は以下のとおり。

| 制度・施策 | 内容 |
|---|---|
| **育児休業制度** | 子が原則1歳（最長2歳）まで取得可能（育児・介護休業法） |
| **介護休業制度** | 対象家族1人につき通算93日まで取得可能 |
| **短時間勤務制度** | 3歳未満の子を養育する労働者に短時間勤務を義務化 |
| **フレックスタイム制** | 始業・終業時刻を労働者が決定 |
| **テレワーク** | 場所にとらわれない柔軟な働き方 |
| **年次有給休暇の時季指定** | 年5日の確実な取得（2019年4月〜義務化） |
| **時間外労働の上限規制** | 原則月45時間・年360時間（2019年4月〜） |

## 企業における取組

企業が実施する代表的な WLB 推進取組は以下のとおり。

| 取組 | 具体例 |
|---|---|
| **長時間労働の是正** | ノー残業デー、勤務間インターバル制度の導入 |
| **柔軟な働き方** | テレワーク、フレックスタイム、時差出勤 |
| **休暇取得促進** | 計画年休、リフレッシュ休暇、男性育休取得推進 |
| **両立支援** | 事業所内保育、復職支援プログラム |
| **意識改革** | 管理職研修、ダイバーシティ推進 |

<Callout type="warn">
R04 Ⅰ-1-11 の正答核心：厚生労働省「テレワークガイドライン」では、**全ての労働時間制度（通常・変形・フレックス・事業場外みなし・裁量労働制）でテレワーク利用が可能**とされている。「みなし労働時間制や裁量労働制ではテレワークができない」とする誤答肢に注意。

ただし、裁量労働制・みなし労働時間制と組み合わせても**労働時間把握義務は引き続き課される**（客観的記録が原則）。
</Callout>

## 総合技術監理における位置づけ

総合技術監理キーワード集では[**3.2 労働関係法と労務管理**](/docs/pe-comprehensive-management-keyword-2026#32-労働関係法と労務管理)に位置づけられる。

ワーク・ライフ・バランスは人的資源管理の中核テーマであり、[労働基準法](/docs/pe-comprehensive-management-labor-standards-act)による労働時間管理・[フレックスタイム制](/docs/pe-comprehensive-management-flextime-system)・[裁量労働制](/docs/pe-comprehensive-management-discretionary-work-system)等の柔軟な働き方と密接に関連する。

長時間労働の是正は安全管理（労働災害・メンタルヘルス防止）にも寄与し、生産性向上は経済性管理の観点からも重要である。総合技術監理者には、組織の生産性を維持しながら従業員の生活の質を高める制度設計が求められる。
