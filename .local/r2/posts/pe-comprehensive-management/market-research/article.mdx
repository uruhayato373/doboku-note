# 市場調査

## 市場調査とは

市場調査（マーケティングリサーチ）とは、**製品・サービスの市場動向、顧客ニーズ、競合状況等に関する情報を体系的に収集・分析し、意思決定の基盤を提供する活動**である。

事業企画・新製品開発・販売戦略等の策定において不可欠なプロセスである。

## 調査手法の分類

| 分類 | 手法 | 特徴 |
|---|---|---|
| **定量調査** | アンケート調査 | 大量データの統計的分析が可能 |
|  | パネル調査 | 同一対象を継続的に追跡調査 |
| **定性調査** | インタビュー調査 | 深層心理やニーズの探索に有効 |
|  | グループインタビュー | 複数人の相互作用から示唆を得る |
| **二次データ分析** | 統計資料・報告書 | 既存データを活用し低コスト |

## 調査プロセス

1. **調査目的の明確化**：意思決定に必要な情報を特定する
2. **調査設計**：対象・手法・サンプルサイズを決定する
3. **データ収集**：調査を実施しデータを取得する
4. **分析・報告**：分析結果を意思決定者に報告する
