# 労災保険制度

## 労災保険制度とは

労災保険制度（労働者災害補償保険制度）とは、業務上の事由または通勤による労働者の負傷・疾病・障害・死亡に対して、必要な保険給付を行う制度である。

労働者災害補償保険法に基づき、政府が管掌する強制保険制度として運営されている。

使用者の無過失責任に基づく労働基準法上の災害補償義務を担保する仕組みであり、労働者の迅速かつ公正な保護を目的とする。

## 適用範囲

| 項目 | 内容 |
|---|---|
| **適用事業** | 労働者を使用するすべての事業（原則として強制適用） |
| **適用労働者** | 正社員・パート・アルバイト・日雇い等すべての労働者 |
| **特別加入** | 中小事業主、一人親方、海外派遣者等が任意加入可能 |
| **適用除外** | 国家公務員・地方公務員（別制度）、船員の一部 |

## 保険給付の対象

| 災害の種類 | 定義 |
|---|---|
| **業務災害** | 業務上の事由による負傷・疾病・障害・死亡 |
| **通勤災害** | 通勤による負傷・疾病・障害・死亡 |
| **複数事業労働者災害** | 複数の事業の業務を要因とする傷病等（2020年新設） |

## 主な保険給付

| 給付の種類 | 内容 |
|---|---|
| **療養（補償）等給付** | 治療費の全額支給（労災指定病院では自己負担なし） |
| **休業（補償）等給付** | 休業4日目から給付基礎日額の60%を支給 |
| **休業特別支給金** | 給付基礎日額の20%を上乗せ（合計80%） |
| **障害（補償）等給付** | 障害等級に応じた年金または一時金 |
| **遺族（補償）等給付** | 遺族に対する年金または一時金 |
| **葬祭料等** | 葬祭に要する費用 |
| **傷病（補償）等年金** | 療養開始後1年6か月経過しても治癒しない場合の年金 |
| **介護（補償）等給付** | 一定の障害により常時または随時介護を要する場合 |

## 保険料

| 項目 | 内容 |
|---|---|
| **負担者** | 事業主が全額負担（労働者負担なし） |
| **保険料率** | 業種ごとに異なる（2.5/1000〜88/1000） |
| **メリット制** | 一定規模以上の事業場で、災害発生率に応じて保険料率を増減（±40%） |
| **算定基礎** | 全労働者の賃金総額 × 保険料率 |

## 業務災害の認定基準

| 要件 | 内容 |
|---|---|
| **業務遂行性** | 労働者が事業主の支配下にある状態で発生したこと |
| **業務起因性** | 業務と傷病等との間に相当因果関係があること |

### 精神障害の労災認定基準

| 要件 | 内容 |
|---|---|
| **対象疾病** | ICD-10のF2〜F4に分類される精神障害 |
| **業務による心理的負荷** | 「強」と評価される出来事があること |
| **業務以外の心理的負荷・個体的要因** | 業務以外の要因で発病したとは認められないこと |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**3.2 労働関係法と労務管理**」に位置づけられる。

労災保険制度は安全管理（労働災害の防止・補償）と人的資源管理（労働者の保護・福利厚生）の接点に位置する。

メリット制により災害防止への経済的インセンティブが働くため、経済性管理の観点からも労働災害の予防が合理的であり、総合技術監理者には安全投資の費用対効果の評価が求められる。
