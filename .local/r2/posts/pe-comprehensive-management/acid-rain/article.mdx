# 酸性雨

## 酸性雨とは

酸性雨（Acid Rain）とは、大気中の硫黄酸化物（SOx）や窒素酸化物（NOx）が雨水に溶け込み、pH5.6以下となった降水の総称である。

狭義には雨のみを指すが、広義には霧・雪・乾性沈着（ガス・粒子の直接沈着）を含む「酸性沈着（Acid Deposition）」として扱われる。

1960年代にスカンジナビア諸国で湖沼の酸性化と魚類の大量死が報告されたことを契機に、国際的な環境問題として認識された。

### 発生メカニズム

| 段階 | 内容 |
|---|---|
| **1. 排出** | 化石燃料の燃焼（火力発電・自動車・工場）によりSOx・NOxが大気中に排出 |
| **2. 変換** | 大気中で化学反応により硫酸（H2SO4）・硝酸（HNO3）に変換 |
| **3. 輸送** | 風により発生源から数百〜数千km離れた地域に輸送（越境汚染） |
| **4. 沈着** | 湿性沈着（酸性雨・霧・雪）または乾性沈着（ガス・粒子）として地表に到達 |

### 酸性雨の基準

| 指標 | 値 | 説明 |
|---|---|---|
| **清浄な雨のpH** | 5.6 | 大気中のCO2が溶解した場合の理論値 |
| **酸性雨の基準** | pH5.6以下 | SOx・NOx等の影響でこれより低い |
| **日本の雨のpH** | 4.5〜5.0程度 | 欧米と同程度の酸性度 |

### 酸性雨による被害

| 分野 | 被害内容 |
|---|---|
| **森林** | 土壌の酸性化による樹木の衰退・枯死（ドイツ・シュヴァルツヴァルトの森林被害等） |
| **湖沼** | 水質の酸性化による魚類・水生生物の減少・死滅 |
| **土壌** | 土壌中のカルシウム・マグネシウムの溶脱、アルミニウムイオンの溶出 |
| **建造物** | 大理石・石灰岩の溶解、金属の腐食（歴史的建造物・文化財への被害） |
| **健康** | 直接的影響は限定的だが、微小粒子状物質（PM2.5）による間接的影響 |

### 国際的な対策

| 条約・枠組み | 年 | 内容 |
|---|---|---|
| **長距離越境大気汚染条約（CLRTAP）** | 1979年 | 欧州経済委員会（UNECE）で採択、越境大気汚染防止の枠組み |
| **ヘルシンキ議定書** | 1985年 | SOx排出の30%削減（1980年比） |
| **ソフィア議定書** | 1988年 | NOx排出の凍結（1987年水準） |
| **ヨーテボリ議定書** | 1999年 | SOx・NOx・VOC・NH3の総合的規制 |
| **EANET** | 2001年 | 東アジア酸性雨モニタリングネットワーク（日本が主導、13か国参加） |

### 日本の対策

| 対策 | 内容 |
|---|---|
| **大気汚染防止法** | SOx・NOxの排出基準、総量規制 |
| **排煙脱硫・脱硝装置** | 火力発電所等への設置義務（日本は世界最高水準の技術） |
| **自動車排ガス規制** | NOx・PM法による排出削減 |
| **モニタリング** | 環境省が全国約100地点で降水のpH・イオン成分を監視 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**6.1 地球的規模の環境問題**」に位置づけられる。

酸性雨は、オゾン層破壊や気候変動と並ぶ地球規模の大気環境問題であり、越境汚染の管理と国際協力のあり方、排煙処理技術の経済性管理、モニタリング体制の情報管理といった複数の管理分野にまたがるテーマである。
