# 開示基準

## 開示基準とは

**開示基準** とは、行政機関が保有する情報の開示・不開示を判断する際の基準のことである。情報公開法において、原則開示を基本としつつ、不開示とすべき情報の類型（不開示情報）が限定列挙されている。

## 原則開示の考え方

| 原則 | 内容 |
|---|---|
| **原則開示** | 行政文書は請求があれば原則として開示する |
| **不開示の限定** | 不開示とできるのは法定の不開示情報に該当する場合のみ |
| **部分開示** | 不開示部分を除いた部分は開示する（容易に区分できる場合） |
| **裁量的開示** | 不開示情報であっても公益上特に必要な場合は開示可能 |

## 不開示情報の判断基準

| 不開示情報 | 判断基準 |
|---|---|
| **個人情報** | 特定の個人が識別されるか、または識別され得るか |
| **法人情報** | 法人の権利・競争上の地位等を害するおそれがあるか |
| **国の安全等** | 国の安全・外交上の利益を害するおそれがあるか |
| **公共の安全** | 公共の安全と秩序の維持に支障を及ぼすおそれがあるか |
| **審議検討情報** | 率直な意見交換・意思決定の中立性が不当に損なわれるか |
| **事務事業情報** | 事務事業の適正な遂行に支障を及ぼすおそれがあるか |

## 部分開示と裁量的開示

| 種類 | 内容 | 根拠 |
|---|---|---|
| **部分開示** | 不開示情報を除いた残りを開示 | 情報公開法第6条 |
| **裁量的開示** | 公益上必要なら不開示情報も開示可 | 情報公開法第7条 |
| **存否応答拒否** | 文書の存否自体を明らかにしない | 情報公開法第8条 |

## 建設事業における開示判断

| 情報 | 開示判断の考え方 |
|---|---|
| **入札・契約情報** | 原則開示（透明性の確保） |
| **設計図書** | 原則開示（安全保障上の懸念がある場合は不開示） |
| **積算内訳** | 予定価格の事後公表が一般的 |
| **環境データ** | 原則開示（環境影響評価法との整合） |
| **個人の技術者情報** | 個人情報に該当する部分は不開示 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**4.2 コミュニケーションと合意形成**」に位置づけられる。

開示基準は情報公開法の運用基準であり、技術者は公共事業の透明性確保と、個人情報・法人情報等の保護のバランスを理解する必要がある。情報開示・開示請求・知る権利と一体で把握する。
