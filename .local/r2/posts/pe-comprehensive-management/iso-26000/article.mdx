# ISO 26000

## ISO 26000とは

ISO 26000とは、**組織の社会的責任（SR）に関する国際ガイダンス規格**である。2010年にISOが発行し、あらゆる種類・規模の組織を対象とする。**認証規格ではなく**、第三者認証の対象とならないガイダンス文書である点が特徴である。

## 7つの中核主題

| 中核主題 | 内容 |
|---|---|
| **組織統治** | 意思決定の透明性・説明責任の確保 |
| **人権** | デューディリジェンス・差別撤廃・脆弱な立場の人々への配慮 |
| **労働慣行** | 安全衛生・労使対話・職場での人材育成 |
| **環境** | 汚染の予防・持続可能な資源利用・気候変動への対応 |
| **公正な事業慣行** | 汚職防止・公正な競争・サプライチェーンでのSR推進 |
| **消費者課題** | 製品安全・情報提供・持続可能な消費の促進 |
| **コミュニティへの参画** | 地域社会への投資・雇用創出・技術移転 |

## ISO 14001との違い

| 項目 | ISO 26000 | ISO 14001 |
|---|---|---|
| **対象** | 社会的責任全般 | 環境マネジメント |
| **性質** | ガイダンス（認証なし） | 要求事項（認証あり） |
| **範囲** | 7つの中核主題 | 環境側面に限定 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では[**6.4 組織の社会的責任と環境管理活動**](/docs/pe-comprehensive-management-keyword-2026#64-組織の社会的責任と環境管理活動)に位置づけられている。

ISO 26000は[CSR](/docs/pe-comprehensive-management-csr)を体系化した国際規格であり、[ISO 14000シリーズ](/docs/pe-comprehensive-management-iso-14000)の環境マネジメントを包含するより広い枠組みである。
