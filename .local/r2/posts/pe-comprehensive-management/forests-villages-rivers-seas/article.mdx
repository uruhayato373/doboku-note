# 森里川海プロジェクト

## 森里川海プロジェクトとは

森里川海プロジェクト（正式名称：「つなげよう、支えよう森里川海」プロジェクト）は、森・里・川・海のつながりを保全・再生し、その恵み（生態系サービス）を将来にわたって享受できる自然共生社会の実現を目指す環境省の取組である。

2014年に環境省が立ち上げ、2016年に「森里川海をつなぎ、支えていくために（提言）」が取りまとめられた。

本プロジェクトは、森から海に至る自然の連環（つながり）が人間活動によって分断・劣化されてきたことへの危機感を出発点とし、「つなげる」「支える」をキーワードに地域の取組を推進している。

### 背景：自然のつながりの分断

| 場所 | 劣化・分断の状況 |
|---|---|
| **森** | 林業の衰退による管理放棄、森林の荒廃、土砂災害リスクの増加 |
| **里** | 耕作放棄地の増加、里山の管理放棄、生物の生息地の縮小 |
| **川** | ダム・堰等による連続性の分断、水質汚濁、氾濫原の消失 |
| **海** | 干潟・藻場の消失、漂着ごみ、栄養塩バランスの変化 |

### プロジェクトの5つのアプローチ

| アプローチ | 内容 |
|---|---|
| **1. 森里川海を知る** | 地域の自然資本の現状把握、マッピング |
| **2. 森里川海をつなぐ** | 分断された生態系のつながりを物理的・制度的に再生 |
| **3. 森里川海を支える** | 地域の担い手育成、経済的仕組みの構築 |
| **4. 森里川海に親しむ** | 体験・教育を通じた自然との関わりの再構築 |
| **5. 森里川海を活かす** | 生態系サービスを活用した地域づくり、グリーンインフラの推進 |

### 関連する政策・概念

| 政策・概念 | 関係 |
|---|---|
| **自然共生サイト（OECM）** | 保護区以外で生物多様性の保全に貢献する区域の認定制度。30by30目標の達成手段 |
| **グリーンインフラ** | 自然環境が有する多様な機能をインフラ整備や土地利用に活用する考え方 |
| **Eco-DRR** | 生態系を活用した防災・減災。湿地による洪水調節、森林による土砂災害防止等 |
| **生物多様性地域戦略** | 生物多様性基本法に基づき地方公共団体が策定する地域の生物多様性保全計画 |
