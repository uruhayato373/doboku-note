# 生成AI

## 生成AIとは

生成AI（Generative AI）とは、大量のデータから学習したパターンに基づき、テキスト・画像・音声・動画・プログラムコード等の新しいコンテンツを自動的に生成する人工知能技術の総称である。

2022年末のChatGPT公開を契機に社会的注目が急速に高まり、産業界・行政・教育など幅広い分野で活用が進んでいる。

従来のAIが「認識・分類・予測」を主な機能としていたのに対し、生成AIは「創造・生成」を行う点で質的に異なる。

### 生成AIの主要技術

技術領域ごとに、代表的なモデル・手法と生成できるコンテンツの種類を整理する。

- **大規模言語モデル（LLM）**
  - 代表モデル: GPT-4、Gemini、Claude
  - 生成対象: テキスト、対話、要約、翻訳
- **画像生成**
  - 代表モデル: Stable Diffusion、DALL-E、Midjourney
  - 生成対象: 画像、イラスト
- **音声生成**
  - 代表モデル: WaveNet、VALL-E
  - 生成対象: 音声合成、音声変換
- **動画生成**
  - 代表モデル: Sora、Runway
  - 生成対象: 動画コンテンツ
- **コード生成**
  - 代表モデル: GitHub Copilot、Cursor
  - 生成対象: プログラムコード
- **マルチモーダル**
  - 代表モデル: GPT-4o、Gemini
  - 生成対象: テキスト＋画像＋音声の統合処理

### 大規模言語モデル（LLM）

大規模言語モデル（Large Language Model; LLM）は、生成AIの中核をなす技術である。

**Transformerアーキテクチャ**に基づき、インターネット上の膨大なテキストデータで事前学習（Pre-training）を行った後、特定タスクに適応させるファインチューニングやプロンプトエンジニアリングにより多様な用途に対応する。

LLMの主要な特徴は以下のとおりである。

| 特徴 | 説明 |
|---|---|
| **文脈理解** | 長文の文脈を把握し、適切な応答を生成 |
| **Few-shot学習** | 少数の例示のみで新しいタスクに対応 |
| **創発的能力** | 明示的に学習していないタスクを遂行する能力がモデル規模の拡大に伴い出現 |
| **ハルシネーション** | 事実に基づかない情報をもっともらしく生成するリスク |

### 生成AIのリスクと課題

生成AIの社会実装には以下のリスクへの対処が必要である。

| リスク領域 | 具体的課題 |
|---|---|
| **正確性** | ハルシネーション（幻覚）による誤情報の生成 |
| **著作権** | 学習データの著作権問題、生成物の権利帰属 |
| **プライバシー** | 個人情報の意図しない生成・漏洩 |
| **バイアス** | 学習データに起因する偏見の再生産・増幅 |
| **セキュリティ** | プロンプトインジェクション、悪意ある利用 |
| **雇用への影響** | 定型業務の自動化に伴う職種構造の変化 |
| **説明可能性** | 生成根拠の不透明さ（ブラックボックス問題） |

### AI利活用ガイドラインとAI規制

政府は2019年にAI社会原則、AIネットワーク社会推進会議は「AI利活用ガイドライン」を策定している。

<Callout type="warn" title="R04 Ⅰ-1-29 の核心: AI 利活用ガイドラインは事前予防が基本姿勢">
ガイドラインの基本姿勢は **AI の精度低下や権利侵害に対する事前の予防的措置** であり、事後対応を求めるだけのものではない。過去問 [R04 Ⅰ-1-29](/docs/pe-comprehensive-management-r04-primary#1-29) では「判断の精度が事後的に損なわれる場合、それに伴う権利侵害発生も後速やかに定めることが期待される」という事後対応偏重の誤答が出題された。開発者・利用者双方に留意事項が設定されている点、ネットワーク化によるリスク増幅の懸念、機械学習のバイアス問題も論点。
</Callout>

ガイドラインが定める10の原則は以下のとおりである。

1. 適正利用の原則
2. 適正学習の原則
3. 連携の原則
4. 安全の原則
5. セキュリティの原則
6. プライバシーの原則
7. 尊厳・自律の原則
8. 公平性の原則
9. 透明性の原則
10. アカウンタビリティの原則

EUのAI規制法（AI Act）は、リスクベースアプローチによりAIシステムを4段階のリスクレベルに分類し、高リスクAIに対して適合性評価を義務づけている。

## 総合技術監理における位置づけ

総合技術監理キーワード集では[**4.1 情報分析と情報活用**](/docs/pe-comprehensive-management-keyword-2026#41-情報分析と情報活用)に位置づけられる。

生成AIは[機械学習](/docs/pe-comprehensive-management-machine-learning)、特にディープラーニング（Transformerアーキテクチャ）の発展により実現された技術である。

[IoT](/docs/pe-comprehensive-management-iot)によるデータ収集基盤や[デジタルツイン・CPS](/docs/pe-comprehensive-management-digital-twin-cps)との連携により、建設・インフラ分野でも設計支援、点検記録の自動生成、安全管理への応用が期待されている。

また、AI利活用ガイドラインに基づく倫理的配慮は、[ELSI](/docs/pe-comprehensive-management-elsi)の観点からも重要である。
