# ヒートアイランド現象

## ヒートアイランド現象とは

ヒートアイランド現象とは、都市部の気温が周辺の郊外地域に比べて高くなる現象である。

等温線を描くと都市部が島のように高温域となることから「熱の島」と名づけられた。

東京では過去100年間で約3.3℃の気温上昇が観測されており、このうち約2℃はヒートアイランド現象によるものとされる。

### 原因

| 要因 | メカニズム |
|---|---|
| **人工排熱の増加** | 自動車、空調機器、工場からの排熱が都市の大気を加熱 |
| **地表面被覆の人工化** | アスファルト・コンクリートが日射を蓄熱し夜間も放熱を継続 |
| **緑地・水面の減少** | 蒸発散による冷却効果の喪失 |
| **都市形態の変化** | 高層建築物による風通しの悪化、天空率の低下で放射冷却を阻害 |

### 影響

| 分野 | 影響内容 |
|---|---|
| **健康** | 熱中症の増加、睡眠障害（熱帯夜の増加） |
| **エネルギー** | 冷房需要の増大による電力消費量の増加 |
| **気象** | 局地的集中豪雨（ゲリラ豪雨）の誘発、風系の変化 |
| **生態系** | 都市の動植物への影響、外来生物の定着促進 |
| **大気環境** | 光化学オキシダントの生成促進 |

### 対策

| 対策分類 | 具体的施策 |
|---|---|
| **人工排熱の低減** | 省エネ機器の導入、交通量削減、地域冷暖房の導入 |
| **地表面被覆の改善** | 保水性舗装、遮熱性舗装、屋上緑化・壁面緑化 |
| **緑地・水面の確保** | 都市公園の整備、親水空間の創出、雨水浸透施設 |
| **都市形態の改善** | 風の道の確保、建築物の配置・形状の工夫 |
| **ライフスタイル** | クールビズ、打ち水、緑のカーテン |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**6.2 地域環境問題**」に位置づけられる。

ヒートアイランド対策は社会環境管理（緑地保全、大気環境改善）のみならず、安全管理（熱中症リスク）、経済性管理（エネルギーコスト）、人的資源管理（労働者の熱中症対策）に横断的に関わるテーマである。グリーンインフラやEco-DRRとの連携も重要となる。
