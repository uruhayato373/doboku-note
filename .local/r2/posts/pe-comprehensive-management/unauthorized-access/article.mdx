# 不正アクセス

## 概要

**不正アクセス**とは、正当な権限を持たない者がコンピュータやネットワークに侵入し、情報の閲覧・取得・改変・破壊等を行う行為である。

不正アクセス行為の禁止等に関する法律（不正アクセス禁止法、2000年施行）により、不正アクセス行為および助長行為は刑事罰の対象となる。

近年はサイバー攻撃の高度化・巧妙化に伴い、不正アクセスの被害件数は増加傾向にあり、組織的な対策が求められている。

## 不正アクセス禁止法の概要

| 項目 | 内容 |
|---|---|
| **正式名称** | 不正アクセス行為の禁止等に関する法律（平成11年法律第128号） |
| **施行** | 2000年2月（2012年改正で罰則強化） |
| **目的** | 電気通信回線を通じた不正アクセスの防止、電気通信の秩序維持 |
| **対象行為** | 不正アクセス行為、不正アクセスの助長行為、他人の識別符号の不正取得・保管・提供 |
| **罰則** | 不正アクセス行為：3年以下の懲役又は100万円以下の罰金 |
| **管轄** | 都道府県公安委員会（不正アクセスの届出先は警察） |

### 不正アクセス行為の類型

| 類型 | 内容 |
|---|---|
| **なりすまし行為** | 他人のID・パスワードを不正に使用してログイン |
| **セキュリティホール攻撃** | プログラムの脆弱性を悪用して認証を回避 |
| **識別符号の不正取得** | フィッシング等でID・パスワードを詐取 |
| **識別符号の不正保管** | 不正に取得した認証情報を保管 |
| **助長行為** | 他人のID・パスワードを第三者に提供 |

## 主な手口

| 手口 | 内容 | 対策 |
|---|---|---|
| **パスワードリスト攻撃** | 漏洩した認証情報リストで他サービスに試行 | パスワード使い回しの禁止、多要素認証 |
| **ブルートフォース攻撃** | 総当たりでパスワードを試行 | アカウントロック、長く複雑なパスワード |
| **辞書攻撃** | よく使われるパスワードで試行 | 推測困難なパスワードの設定 |
| **フィッシング** | 偽サイトで認証情報を窃取 | セキュリティ教育、URLの確認 |
| **脆弱性の悪用** | OSやアプリの脆弱性から侵入 | パッチ適用、脆弱性診断 |
| **SQLインジェクション** | Webアプリの入力値処理の不備を悪用 | 入力値検証、WAF |
| **ソーシャルエンジニアリング** | 人間の心理を突いて認証情報を詐取 | セキュリティ教育、本人確認手順の厳格化 |

## 被害事例

- ECサイトへのパスワードリスト攻撃による個人情報・クレジットカード情報の流出
- 企業VPNの脆弱性を悪用したランサムウェア感染
- 行政機関のシステムへの不正侵入による情報漏洩
- 内部関係者による権限外アクセスでの機密情報持ち出し

## 対策の体系

| 分類 | 対策 | 内容 |
|---|---|---|
| **認証強化** | 多要素認証（MFA） | 知識・所持・生体の2要素以上を組み合わせ |
| **認証強化** | パスワードポリシー | 最小文字数、複雑性要件、定期変更の見直し |
| **アクセス制御** | 最小権限の原則 | 業務に必要な最小限の権限のみ付与 |
| **アクセス制御** | ネットワーク分離 | セグメント化・ゼロトラストアーキテクチャ |
| **検知** | IDS/IPS | 不正アクセスの検知・遮断 |
| **検知** | ログ監視・SIEM | アクセスログの分析・異常検知 |
| **脆弱性管理** | パッチ管理 | OSやアプリケーションの最新化 |
| **脆弱性管理** | 脆弱性診断・ペネトレーションテスト | 定期的なセキュリティ検査 |
| **教育** | セキュリティ教育 | フィッシング対策、パスワード管理の啓発 |
| **法的対応** | 不正アクセス禁止法 | 被害発生時の警察への届出 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**4.5 情報セキュリティ**」に位置づけられる。

不正アクセスは機密性・完全性・可用性のすべてを侵害し得る脅威であり、経済性管理（被害コスト・法的責任）、人的資源管理（セキュリティ教育・ID管理）、安全管理（制御系システムの防護）と密接に関連する。

不正アクセス禁止法は個人情報保護法・サイバーセキュリティ基本法と並ぶ情報セキュリティの法的基盤である。
