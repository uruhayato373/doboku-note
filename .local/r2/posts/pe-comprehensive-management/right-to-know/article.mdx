# 知る権利

## 知る権利とは

**知る権利（Right to Know）** とは、国民が行政機関や企業が保有する情報にアクセスし、公的な意思決定の過程や結果を知ることができる権利のことである。民主主義社会の基盤であり、行政の透明性と説明責任（アカウンタビリティ）を支える。

## 法的根拠

| 根拠 | 内容 |
|---|---|
| **[**日本国憲法第21条**](https://laws.e-gov.go.jp/law/321CONSTITUTION#Mp-At_21)** | 表現の自由から派生する権利として解釈（明文規定なし） |
| **情報公開法** | 知る権利を具体化する制度（行政文書の開示請求権） |
| **地方自治体の情報公開条例** | 各自治体で独自に制定（国に先行する条例も多い） |
| **世界人権宣言第19条** | 情報を求め、受け、伝える自由 |

## 知る権利の内容

| 内容 | 説明 |
|---|---|
| **情報収集の自由** | 自ら情報を収集する自由 |
| **情報受領の自由** | 情報を受け取る自由（検閲の禁止） |
| **情報開示請求権** | 行政機関に対して情報の開示を請求する権利 |
| **取材の自由** | 報道機関の取材活動の自由（報道の自由の一側面） |

## 知る権利の限界

| 限界 | 内容 |
|---|---|
| **プライバシーとの調整** | 個人情報保護との両立 |
| **国家安全保障** | 防衛・外交上の機密情報の保護 |
| **企業秘密** | 営業秘密・知的財産の保護 |
| **公正な裁判** | 裁判の公正性確保のための情報制限 |

## 公共事業における知る権利

| 場面 | 内容 |
|---|---|
| **事業計画の公開** | 公共事業の計画内容・費用対効果の公開 |
| **入札・契約情報** | 入札結果・契約内容の公表 |
| **環境情報** | 環境モニタリングデータ・環境影響評価の公開 |
| **安全情報** | リスク情報・事故報告の開示 |
| **政策評価** | 事業評価結果の公表 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では[**4.2 コミュニケーション**](/docs/pe-comprehensive-management-keyword-2026#42-コミュニケーション)に位置づけられる。

知る権利は情報公開法・情報開示・開示請求・開示基準の上位概念であり、公共事業における透明性確保と民主的統制の理論的基盤となる。
