# クラスター分析

## クラスター分析とは

クラスター分析（cluster analysis）とは、複数のデータを類似性に基づいてグループ（クラスター）に分類する多変量解析手法である。

事前にグループの定義を与えず、データの特徴のみからグループ構造を発見する「教師なし学習」の代表的手法である。

顧客セグメンテーション、文書分類、画像認識、異常検知など、幅広い分野で活用されている。

### 階層的クラスター分析と非階層的クラスター分析

クラスター分析は大きく2つの手法に分類される。

| 特性 | 階層的クラスター分析 | 非階層的クラスター分析 |
|---|---|---|
| **代表手法** | ウォード法、最短距離法、最長距離法、群平均法 | **k-means法**、k-medoids法 |
| **クラスター数** | 事前指定不要（デンドログラムで決定） | 事前にk個を指定 |
| **可視化** | デンドログラム（樹形図） | 散布図等 |
| **計算量** | 大（$O(n^2)$以上） | 比較的小（$O(nk)$） |
| **適するデータ量** | 小〜中規模（数千件程度） | 大規模（数万件以上） |
| **特徴** | 階層構造を把握できる | 高速で大規模データに対応 |

### k-means法のアルゴリズム

非階層的クラスター分析の代表であるk-means法は、以下のステップを繰り返す。

1. k個の初期クラスター中心（セントロイド）をランダムに配置する
2. 各データ点を最も近いセントロイドのクラスターに割り当てる
3. 各クラスターのセントロイドを再計算する（クラスター内データの平均値）
4. 割り当てが変化しなくなるまで2〜3を繰り返す

k-means法は計算が高速で大規模データに適するが、初期値依存性がある点や、球状のクラスターを仮定する点に注意が必要である。

### 距離の測定方法

クラスター分析ではデータ間の「距離」の定義が分析結果を左右する。

| 距離尺度 | 特徴 |
|---|---|
| **ユークリッド距離** | 最も一般的。直線距離 |
| **マンハッタン距離** | 各軸方向の差の絶対値の和 |
| **マハラノビス距離** | 変数間の相関を考慮した距離 |
| **コサイン類似度** | ベクトルの向きの類似性（テキスト分析で頻用） |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**4.1 情報分析と情報活用**」に位置づけられる。

クラスター分析は[データマイニング](/docs/pe-comprehensive-management-data-mining)の主要手法の一つであり、[機械学習](/docs/pe-comprehensive-management-machine-learning)における教師なし学習の代表的アルゴリズムでもある。

分析結果の解釈には[データ可視化](/docs/pe-comprehensive-management-data-visualization)が不可欠であり、デンドログラムや散布図を通じてクラスター構造を把握する。
