# 公害防止管理者

## 公害防止管理者とは

公害防止管理者とは、**「特定工場における公害防止組織の整備に関する法律」に基づき、特定工場に選任が義務づけられた公害防止の技術的管理者**である。

## 公害防止組織の構成

| 役職 | 役割 |
|---|---|
| **公害防止統括者** | 工場の公害防止に関する業務を統括（工場長等） |
| **公害防止主任管理者** | 大規模工場で統括者を補佐（大気+水質の両方を扱う場合） |
| **公害防止管理者** | 公害防止施設の運転・維持管理等の技術的業務を担当 |
| **代理者** | 上記不在時の代行者（それぞれに選任が必要） |

## 資格区分

| 区分 | 対象 |
|---|---|
| **大気関係** | ばい煙発生施設（第1種〜第4種） |
| **水質関係** | 排出水を排出する施設（第1種〜第4種） |
| **騒音・振動関係** | 騒音・振動発生施設 |
| **粉じん関係** | 一般粉じん・特定粉じん発生施設 |
| **ダイオキシン類関係** | ダイオキシン類発生施設 |

## 選任義務

特定工場（製造業・電気供給業・ガス供給業・熱供給業で一定規模以上）は、公害防止管理者の選任が法的に義務づけられている。資格は国家試験の合格または認定講習の修了により取得する。

## 総合技術監理における位置づけ

総合技術監理キーワード集では[**6.4 組織の社会的責任と環境管理活動**](/docs/pe-comprehensive-management-keyword-2026#64-組織の社会的責任と環境管理活動)に位置づけられている。

公害防止管理者は[ISO 14000シリーズ](/docs/pe-comprehensive-management-iso-14000)の自主的な環境管理とは異なり、法に基づく強制的な公害防止体制であり、[環境基準](/docs/pe-comprehensive-management-environmental-standards)の遵守を現場で担保する役割を果たす。
