# 化審法

## 化審法とは

化審法は、新規化学物質の製造又は輸入に際して事前に審査を行い、その性状等に応じて必要な規制を行うことにより、人の健康及び生活環境動植物への被害を防止することを目的とする法律である。

1973年にPCB汚染問題を契機として世界に先駆けて制定された化学物質の事前審査制度であり、日本の化学物質管理の根幹をなす法律である。

2009年の大改正で既存化学物質を含むすべての化学物質を対象とする包括的な管理体系に移行し、国際的な化学物質管理の動向（REACHやSAICM等）との整合が図られた。

### 規制の基本的な枠組み

| 段階 | 内容 |
|---|---|
| **事前審査** | 新規化学物質の製造・輸入前に安全性を審査 |
| **物質分類** | 審査結果に基づき規制区分を決定 |
| **製造・輸入の規制** | 区分に応じた許可・届出・禁止等の措置 |
| **既存化学物質のスクリーニング** | 製造・輸入量の届出に基づくリスク評価 |

### 化学物質の分類と規制

| 分類 | 性状 | 主な規制内容 | 物質例 |
|---|---|---|---|
| **第一種特定化学物質** | 難分解性、高蓄積性、長期毒性又は高次捕食動物への毒性 | 製造・輸入の原則禁止 | PCB、DDT、アルドリン等 |
| **第二種特定化学物質** | 長期毒性又は生態毒性（蓄積性は低い） | 製造・輸入の予定数量の届出、表示義務 | トリクロロエチレン等 |
| **監視化学物質** | 難分解性、高蓄積性だが毒性未確認 | 製造・輸入の届出、有害性調査指示 | |
| **優先評価化学物質** | リスクが十分に低いとは言えない物質 | 製造・輸入数量の届出、有害性情報の報告 | 約200物質 |
| **一般化学物質** | 上記以外 | 製造・輸入数量の届出（年間1トン以上） | |

### 新規化学物質の審査制度

| 制度 | 対象 | 手続き |
|---|---|---|
| **通常新規** | 年間1トン超の新規化学物質 | 製造・輸入前に届出し、審査を受ける |
| **少量新規** | 全国の製造・輸入量の合計が年間1トン以下 | 事前確認のみ（申出制度） |
| **低生産量新規** | 全国合計が年間10トン以下 | 簡易審査（分解性・蓄積性を審査） |
| **中間物等** | 閉鎖系での使用等、環境放出が見込まれないもの | 用途等の確認のみ |

### 2009年改正の主要ポイント

| 改正内容 | 詳細 |
|---|---|
| **既存化学物質の届出義務化** | 年間1トン以上の既存化学物質についても製造・輸入数量の届出を義務化 |
| **優先評価化学物質の創設** | リスクベースでスクリーニングし、優先的にリスク評価を行う仕組みを導入 |
| **リスク評価の導入** | ハザード（有害性）のみでなく、曝露量も考慮したリスク評価に転換 |
| **生態毒性の考慮** | 動植物への影響も評価対象に追加（生活環境動植物の保護） |

### 罰則

| 違反内容 | 罰則 |
|---|---|
| **第一種特定化学物質の無許可製造・輸入** | 3年以下の懲役 又は 100万円以下の罰金 |
| **新規化学物質の無届出製造・輸入** | 1年以下の懲役 又は 50万円以下の罰金 |
| **届出数量の虚偽報告** | 50万円以下の罰金 |
| **表示義務違反** | 50万円以下の罰金 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**6.2 地域環境問題**」に位置づけられる。

化審法は化学物質のライフサイクル管理の根幹であり、新製品開発における安全性評価（安全管理）、審査・届出のコスト（経済性管理）、サプライチェーン全体の情報管理（情報管理）が複合的に関わるテーマである。POPs条約やGFCとの国際的な連動も重要な視点となる。
