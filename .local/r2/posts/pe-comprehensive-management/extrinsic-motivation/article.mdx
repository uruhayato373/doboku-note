# 外発的動機付け

## 外発的動機付けとは

**外発的動機付け（Extrinsic Motivation）** とは、報酬・罰・評価・昇進など、行動の外部にある要因によって行動が促される動機付けの形態である。

行動そのものの楽しさや意義からではなく、行動の結果として得られる外的な成果を目的として行動する状態を指す。

エドワード・デシとリチャード・ライアンの自己決定理論（Self-Determination Theory）では、外発的動機付けを自律性の程度に応じて4段階に分類し、単純な「外発 vs 内発」の二項対立を超えた理解を提唱した。

### 自己決定理論における動機付けの連続体

デシとライアンは、動機付けを「無動機」から「内発的動機付け」までの連続体として整理した。

| 動機付けの種類 | 調整の型 | 自律性 | 具体例 |
|---|---|---|---|
| **無動機** | なし | なし | やる意味を見出せず行動しない |
| **外的調整** | 外的 | 最も低い | 叱られるのが嫌だから仕事をする |
| **取り入れ的調整** | やや外的 | 低い | 周囲に認められたいから勉強する |
| **同一化的調整** | やや内的 | 高い | 資格取得が自分の成長に重要だと認識して学ぶ |
| **統合的調整** | 内的 | 最も高い | 技術者としての価値観と一致するから安全管理に取り組む |
| **内発的動機付け** | 内発的 | 完全に自律的 | 技術そのものが面白いから研究する |

外発的動機付けは「外的調整」から「統合的調整」までの4段階を含み、自律性が高まるほど内発的動機付けに近い質の行動が生まれる。

### 外発的動機付けの主な手段

| 手段 | 分類 | 具体例 |
|---|---|---|
| **金銭的報酬** | 正の強化 | 賞与、昇給、インセンティブ報酬 |
| **昇進・昇格** | 正の強化 | 役職への登用、等級の引き上げ |
| **表彰・承認** | 正の強化 | 社内表彰制度、上司からの称賛 |
| **罰・ペナルティ** | 負の強化・罰 | 減給、降格、懲戒処分 |
| **締切・ノルマ** | 外的圧力 | 納期設定、数値目標 |
| **評価・フィードバック** | 情報的・統制的 | 人事考課、360度評価 |

### 実務での適用

| 場面 | 外発的動機付けの活用 | 留意点 |
|---|---|---|
| **安全管理** | 無災害記録達成時の報奨 | 報告抑制（労災隠し）のリスク |
| **品質管理** | 品質目標達成時のチーム表彰 | 検査データの改ざんリスク |
| **工程管理** | 工期短縮に対するボーナス | 安全・品質の犠牲リスク |
| **資格取得支援** | 合格時の報奨金・昇格 | 同一化的調整への移行を促す好例 |

### 外発的動機付けの限界

| 限界 | 内容 |
|---|---|
| **アンダーマイニング効果** | 外的報酬の付与により、もともとあった内発的動機が低下する |
| **報酬への依存** | 報酬がなくなると行動が停止する（報酬依存） |
| **認知評価の変質** | 「楽しいからやる」が「報酬のためにやる」に変わる |
| **創造性の低下** | 外的統制が強いほど、創造的な問題解決が阻害される |
| **短期的効果** | 即効性はあるが、長期的な行動変容には限界がある |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**3.1 人の行動と組織**」に位置づけられる。

外発的動機付けは人的資源管理の報酬制度・評価制度の基盤であると同時に、安全管理における安全行動の促進や、経済性管理における生産性向上施策とも直結する。

総合技術監理技術者は、外発的動機付けの即効性を活用しつつ、内発的動機付けとの最適な組み合わせを設計し、副作用を最小化するトレードオフ管理が求められる。
