# 言語／非言語コミュニケーション

## 言語コミュニケーションと非言語コミュニケーション

コミュニケーションは**言語的要素**と**非言語的要素**の2つで構成される。

| 種類 | 定義 | 手段 |
|---|---|---|
| **言語コミュニケーション** | 言葉（話し言葉・書き言葉）を用いた伝達 | 会話、文書、メール、チャット |
| **非言語コミュニケーション** | 言葉以外の手段による伝達 | 表情、声のトーン、姿勢、ジェスチャー |

## メラビアンの法則（7-38-55ルール）

感情や態度が矛盾するメッセージを受け取った場合、受け手は以下の比率で影響を受ける：

| 要素 | 影響度 | 内容 |
|---|---|---|
| **言語情報（Verbal）** | **7%** | 話の内容・言葉そのもの |
| **聴覚情報（Vocal）** | **38%** | 声のトーン・速さ・大きさ |
| **視覚情報（Visual）** | **55%** | 表情・姿勢・ジェスチャー |

※矛盾したメッセージの場合の法則であり、常に言葉が7%しか伝わらないという意味ではない。

## 非言語コミュニケーションの要素

| 要素 | 内容 |
|---|---|
| **表情** | 喜怒哀楽・関心・困惑等の感情表現 |
| **アイコンタクト** | 視線の合わせ方・注視時間 |
| **ジェスチャー** | 手振り・身振り・うなずき |
| **姿勢** | 前傾（関心）・腕組み（防御）等 |
| **パーソナルスペース** | 対人距離（親密：〜45cm、社会的：1.2〜3.6m） |
| **接触行動** | 握手・肩たたき等の身体接触 |
| **声の特性（パラ言語）** | 声の大きさ・速さ・抑揚・間 |
| **外見・服装** | 第一印象・信頼性の形成 |

## 建設現場での留意点

| 場面 | ポイント |
|---|---|
| **現場指示** | 騒音環境→大きな声・明確なジェスチャー・合図 |
| **安全教育** | 表情・姿勢で真剣さを伝える、一方通行にしない |
| **住民対応** | 誠意ある態度（視線・姿勢）、言語と非言語の一致 |
| **多文化環境** | 外国人労働者との文化差への配慮（ジェスチャーの意味が異なる） |

## 効果的なコミュニケーションのポイント

| ポイント | 内容 |
|---|---|
| **言語と非言語の一致** | 矛盾すると受け手は非言語を優先して解釈 |
| **アクティブリスニング** | うなずき・アイコンタクトで傾聴を示す |
| **文化的差異の認識** | 非言語の意味は文化によって異なる |
| **書面の併用** | 重要事項は言語（文書）で明確化 |
