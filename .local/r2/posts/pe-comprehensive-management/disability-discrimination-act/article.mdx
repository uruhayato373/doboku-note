# 障害者差別解消法

## 障害者差別解消法とは

**障害者差別解消法**（正式名称：障害を理由とする差別の解消の推進に関する法律、平成25年法律第65号）は、障害を理由とする差別の解消を推進し、すべての国民が障害の有無によって分け隔てられることなく共生する社会の実現を目指す法律である。

障害者権利条約（2006年国連採択、2014年日本批准）の理念を国内法化したものとして2016年に施行された。

## 法律の概要

| 項目 | 内容 |
|---|---|
| **正式名称** | 障害を理由とする差別の解消の推進に関する法律（平成25年法律第65号） |
| **目的** | 障害を理由とする差別の解消の推進、共生社会の実現 |
| **適用範囲** | 行政機関等およびすべての事業者 |
| **所管** | 内閣府 |
| **施行** | 2016年4月 |
| **改正** | 2024年4月改正法施行（事業者の合理的配慮提供を義務化） |

## 障害者差別解消法と障害者雇用促進法の違い

| 項目 | 障害者差別解消法 | 障害者雇用促進法 |
|---|---|---|
| **対象場面** | 日常生活・社会生活全般 | 雇用分野 |
| **対象主体** | 行政機関等・事業者 | 事業主 |
| **所管** | 内閣府 | 厚生労働省 |
| **雇用分野の適用** | 適用除外（雇用促進法が適用） | 適用あり |

## 不当な差別的取扱いの禁止

| 対象 | 内容 |
|---|---|
| **行政機関等** | 障害を理由とする不当な差別的取扱いの禁止（法的義務） |
| **事業者** | 障害を理由とする不当な差別的取扱いの禁止（法的義務） |
| **具体例** | 障害を理由としたサービス提供の拒否、条件の付加、場所・時間の制限 |

### 不当な差別的取扱いの具体例

| 場面 | 不当な差別的取扱いの例 |
|---|---|
| **商品・サービス** | 車椅子利用を理由に入店を拒否 |
| **教育** | 障害を理由に入学・受験を拒否 |
| **交通** | 介助者がいないことを理由に乗車を拒否 |
| **住宅** | 障害を理由に賃貸住宅への入居を拒否 |

## 合理的配慮の提供

| 対象 | 義務の程度（2024年4月改正後） |
|---|---|
| **行政機関等** | 法的義務 |
| **事業者** | 法的義務（改正前は努力義務） |

### 合理的配慮の具体例

| 場面 | 合理的配慮の例 |
|---|---|
| **情報提供** | 文書の読み上げ、わかりやすい説明、筆談 |
| **物理的環境** | 段差へのスロープ設置、広い席への案内 |
| **手続き** | 代筆・代読の対応、手話通訳の配置 |
| **ルール変更** | 順番の変更、休憩時間の調整 |

### 合理的配慮の限界（過重な負担）

事業者に過重な負担がある場合は、合理的配慮の提供義務が免除される。

| 判断要素 | 内容 |
|---|---|
| **事業への影響** | 事業活動に著しい支障が生じるか |
| **費用・負担の程度** | 実現に要する費用・負担の程度 |
| **事業規模** | 事業の規模、財務状況 |
| **公的支援の有無** | 公的な補助金等の有無 |

## 紛争解決・監督

| 手段 | 内容 |
|---|---|
| **相談窓口** | 各行政機関・地方公共団体に設置 |
| **主務大臣の権限** | 事業者に対する報告の徴収、助言・指導・勧告 |
| **罰則** | 報告の不提出・虚偽報告に対し20万円以下の過料 |
| **障害者差別解消支援地域協議会** | 地方公共団体が組織、関係機関の連携・情報共有 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**3.2 労働関係法と労務管理**」に位置づけられる。

障害者差別解消法は、障害者雇用促進法とともに障害者の社会参加を促進する法律であり、社会環境管理（社会的包摂・ダイバーシティ）と人的資源管理の両面に関わる。

総合技術監理の観点では、合理的配慮の提供に伴う施設改修・設備投資（経済性管理）と、バリアフリー化による利用者の安全確保（安全管理）のバランスが重要なテーマとなる。
