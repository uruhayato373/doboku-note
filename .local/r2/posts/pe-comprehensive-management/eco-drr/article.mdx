# Eco-DRR（生態系を活用した防災・減災）

## Eco-DRRとは

Eco-DRR（Ecosystem-based Disaster Risk Reduction）とは、生態系の持つ多様な機能を活用して災害リスクの軽減を図る取り組みである。

2015年の仙台防災枠組において、生態系の保全と回復が防災・減災に寄与することが国際的に認められた。

従来のコンクリート構造物（グレーインフラ）のみに依存する防災から、自然の力を活用した多機能型の防災・減災へと転換する考え方である。

### 生態系が持つ防災・減災機能

| 生態系 | 防災・減災機能 |
|---|---|
| **森林** | 土砂災害の防止、洪水緩和（保水機能）、土壌浸食の防止 |
| **湿地・氾濫原** | 洪水の一時貯留、水質浄化、地下水涵養 |
| **サンゴ礁** | 波浪の減衰、海岸侵食の防止 |
| **マングローブ** | 津波・高潮の減衰、海岸線の安定化 |
| **砂丘・砂浜** | 高潮・波浪の緩衝、海岸侵食の防止 |
| **都市緑地** | 雨水浸透・貯留、ヒートアイランド緩和 |

### NbS（自然を活用した解決策）との関係

| 概念 | 範囲 | 特徴 |
|---|---|---|
| **NbS（Nature-based Solutions）** | 社会課題全般（防災・気候変動・生物多様性等） | IUCN提唱の上位概念 |
| **Eco-DRR** | 防災・減災に特化 | NbSの一部、仙台防災枠組で推進 |
| **EbA（生態系を活用した適応策）** | 気候変動適応に特化 | NbSの一部、気候変動枠組で推進 |
| **グリーンインフラ** | インフラ整備における自然活用 | NbSを社会資本整備に実装する手法 |

### グレーインフラとの比較

| 項目 | グレーインフラ | Eco-DRR（グリーンインフラ） |
|---|---|---|
| **構造** | コンクリート・鋼材等の人工構造物 | 自然生態系の保全・再生 |
| **防災効果** | 設計外力までは確実に機能 | 想定外力に対しても段階的に機能 |
| **多機能性** | 単一機能に特化 | 防災＋生物多様性＋レクリエーション等 |
| **維持管理** | 定期的な補修が必要 | 自律的な回復力を持つが管理も必要 |
| **コスト** | 初期コスト・維持管理コストが高い | 長期的にコスト効率が高い場合が多い |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**6.2 地域環境問題**」に位置づけられる。

Eco-DRRは社会環境管理（生態系保全・自然環境の活用）と安全管理（防災・減災）を統合する概念であり、両分野のトレードオフを最小化するアプローチとして注目される。経済性管理の観点からはライフサイクルコストの評価、人的資源管理の観点からは生態系管理の専門人材確保も課題となる。
