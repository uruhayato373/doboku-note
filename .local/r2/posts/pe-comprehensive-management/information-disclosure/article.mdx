# 情報開示

## 情報開示とは

**情報開示（Information Disclosure）** とは、行政機関や企業が保有する情報を、国民・株主・利害関係者等に対して公開することである。行政の透明性と説明責任（アカウンタビリティ）を確保するとともに、適切な意思決定と社会的信頼の基盤となる。

## 情報開示の種類

| 種類 | 内容 | 例 |
|---|---|---|
| **能動的開示** | 機関が自主的に情報を公開 | ホームページ掲載、広報誌、記者発表 |
| **受動的開示** | 請求に応じて情報を公開 | 情報公開法に基づく開示請求への対応 |
| **義務的開示** | 法令で公開が義務づけられた情報 | 予算・決算・入札結果・環境データ |
| **任意的開示** | 法的義務はないが自主的に公開 | CSR報告書・統合報告書 |

## 行政における情報開示

| 分野 | 開示内容 |
|---|---|
| **財政** | 予算書・決算書・財務書類 |
| **公共事業** | 事業計画・環境影響評価書・入札結果・完成図書 |
| **安全** | 事故報告書・災害統計・リスク評価結果 |
| **環境** | 環境モニタリングデータ・PRTR排出量 |
| **政策評価** | 事前評価書・事後評価書・政策レビュー |

## 企業における情報開示

| 種類 | 内容 |
|---|---|
| **財務情報開示** | 有価証券報告書・決算短信 |
| **IR（投資家向け広報）** | 経営戦略・業績見通し・リスク情報 |
| **ESG開示** | 環境・社会・ガバナンスに関する情報 |
| **TCFD開示** | 気候関連の財務情報開示 |
| **安全報告書** | 重大事故リスク施設の安全対策情報 |

## 情報開示の意義と課題

| 意義 | 課題 |
|---|---|
| 行政・企業の透明性向上 | 開示コスト（作成・審査の負担） |
| 国民・投資家の信頼確保 | 機密情報・個人情報の保護との両立 |
| 適切な意思決定の支援 | 情報の過多による理解困難 |
| 不正の抑止・ガバナンス強化 | 開示情報の正確性の担保 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**4.2 コミュニケーションと合意形成**」に位置づけられる。

情報開示は情報管理の根幹であり、知る権利・情報公開法・開示請求・開示基準と一体の制度体系を構成する。公共事業の社会的受容性確保とステークホルダーとの信頼構築の基盤となる。
