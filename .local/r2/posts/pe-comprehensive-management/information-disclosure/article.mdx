# 情報開示

## 情報開示とは

**情報開示（Information Disclosure）** とは、行政機関や企業が保有する情報を、国民・株主・利害関係者等に対して公開することである。行政の透明性と説明責任（アカウンタビリティ）を確保するとともに、適切な意思決定と社会的信頼の基盤となる。

## 情報開示の種類

情報開示は、開示の契機と根拠によって以下の4種類に分類される。

- **能動的開示**: 機関が自主的に情報を公開 — ホームページ掲載、広報誌、記者発表
- **受動的開示**: 請求に応じて情報を公開 — 情報公開法に基づく開示請求への対応
- **義務的開示**: 法令で公開が義務づけられた情報 — 予算・決算・入札結果・環境データ
- **任意的開示**: 法的義務はないが自主的に公開 — CSR報告書・統合報告書

### 上場企業における法定開示と適時開示

上場企業の情報開示は次の 2 系統に大別される（試験頻出の区別）。

| 種別 | 根拠 |
|---|---|
| **法定開示** | 金融商品取引法 |
| **適時開示** | 証券取引所の規則 |

代表例: 法定開示は **有価証券報告書・四半期報告書・臨時報告書**。適時開示は **業績予想の修正・新株式の発行・工場火災・大株主の異動** 等。

法定開示は正確性・詳細性を重視し、適時開示は速報性を重視する。

<Callout type="warn" title="引っかけ: 有価証券報告書は法定開示（適時開示ではない）">
**有価証券報告書の提出** は金融商品取引法に基づく **法定開示** であり、証券取引所規則による **適時開示** の対象ではない。適時開示の対象は「決定事実・発生事実・決算情報」の 3 カテゴリ（新株式発行・業績予想修正・工場火災・大株主異動等）。過去問 [R04 Ⅰ-1-20](/docs/pe-comprehensive-management-r04-primary#1-20) で有価証券報告書の提出を適時開示として挙げた誤答が出題された。
</Callout>

## 行政における情報開示

行政機関が情報公開法（平成11年法律第42号）に基づいて開示する情報は、分野ごとに以下のとおり体系化されている。

| 分野 | 開示内容 |
|---|---|
| **財政** | 予算書・決算書・財務書類 |
| **公共事業** | 事業計画・環境影響評価書・入札結果・完成図書 |
| **安全** | 事故報告書・災害統計・リスク評価結果 |
| **環境** | 環境モニタリングデータ・PRTR排出量 |
| **政策評価** | 事前評価書・事後評価書・政策レビュー |

## 企業における情報開示

企業の情報開示は、株主・投資家・地域社会に対する説明責任の観点から、法定開示と自主開示の両面で求められる。

| 種類 | 内容 |
|---|---|
| **財務情報開示** | 有価証券報告書・決算短信 |
| **IR（投資家向け広報）** | 経営戦略・業績見通し・リスク情報 |
| **ESG開示** | 環境・社会・ガバナンスに関する情報 |
| **TCFD開示** | 気候関連の財務情報開示 |
| **安全報告書** | 重大事故リスク施設の安全対策情報 |

## 情報開示の意義と課題

情報開示の推進には透明性向上という大きな意義がある一方、実務上の課題も存在する。

| 意義 | 課題 |
|---|---|
| 行政・企業の透明性向上 | 開示コスト（作成・審査の負担） |
| 国民・投資家の信頼確保 | 機密情報・個人情報の保護との両立 |
| 適切な意思決定の支援 | 情報の過多による理解困難 |
| 不正の抑止・ガバナンス強化 | 開示情報の正確性の担保 |
