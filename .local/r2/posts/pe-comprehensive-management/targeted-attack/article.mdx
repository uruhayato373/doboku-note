# 標的型攻撃

## 概要

**標的型攻撃**とは、特定の組織や個人を狙って行われる高度なサイバー攻撃である。

不特定多数を対象とするばらまき型攻撃とは異なり、事前に標的の情報を収集し、その組織の業務内容や人間関係を把握したうえで、巧妙に偽装した手口で侵入する。

特に長期間にわたり潜伏して情報を窃取する攻撃は**APT攻撃（Advanced Persistent Threat：高度持続的脅威）** と呼ばれ、国家機関や重要インフラ事業者が主な標的となる。

## 手口・種類

### 標的型攻撃の主な手法

| 手法 | 内容 |
|---|---|
| **標的型メール** | 業務関連を装ったメールに不正な添付ファイルやURLを含ませ、マルウェアに感染させる |
| **水飲み場攻撃** | 標的がよく閲覧するWebサイトを改ざんし、アクセスした際にマルウェアを仕込む |
| **サプライチェーン攻撃** | 標的の取引先・委託先を先に侵害し、その信頼関係を利用して標的に侵入する |
| **ゼロデイ攻撃** | 未公表の脆弱性を突いて侵入する（パッチが存在しないため防御が困難） |

### 攻撃の段階（キルチェーン）

サイバーキルチェーン（Lockheed Martin社提唱）に基づく標的型攻撃の典型的な進行段階を示す。

| 段階 | 内容 |
|---|---|
| **1. 偵察** | 標的組織の公開情報、SNS、人事情報等を収集 |
| **2. 武器化** | 収集した情報をもとにマルウェアや攻撃ツールを準備 |
| **3. 配送** | 標的型メール・水飲み場攻撃等で標的に攻撃コードを送達 |
| **4. 攻撃** | 脆弱性の悪用やマルウェアの実行により標的端末に侵入 |
| **5. インストール** | バックドア（遠隔操作用の裏口）を設置し、持続的なアクセスを確保 |
| **6. 遠隔操作（C2）** | C2サーバ（Command and Control）を通じて侵入端末を遠隔制御 |
| **7. 目的実行** | 機密情報の窃取、システム破壊、他システムへの横展開（ラテラルムーブメント） |

### 標的型メールの特徴

| 特徴 | 内容 |
|---|---|
| **差出人の偽装** | 実在する取引先や同僚のメールアドレスを詐称 |
| **業務に関連した件名** | 「請求書」「議事録」「人事異動」など業務上開封しやすい件名 |
| **不正な添付ファイル** | マクロ付きOffice文書、PDF、実行ファイル |
| **不正なURL** | 正規サイトに酷似した偽サイトへの誘導リンク |

## 被害例

年金機構への標的型攻撃（2015年）では、職員がメールの添付ファイルを開封したことにより約125万件の個人情報が流出した。

防衛関連企業や先端技術を持つ製造業への標的型攻撃により、軍事技術・知的財産の窃取が国際的に問題となっている。

サプライチェーン攻撃では、ネットワーク管理ソフトウェアの更新機能を悪用し、数千の組織に同時にマルウェアを配布した事例（SolarWinds事件、2020年）がある。

## 対策

| 対策区分 | 具体的な対策 |
|---|---|
| **入口対策** | メールフィルタリング、サンドボックスによる添付ファイル検査、URLフィルタリング |
| **内部対策** | ネットワークセグメンテーション、EDRによる不審挙動の検知、特権アカウント管理 |
| **出口対策** | 外部通信の監視（C2サーバとの通信検知）、プロキシログの分析 |
| **教育・訓練** | 標的型メール訓練（擬似攻撃メールの送信による対応力向上）、報告体制の整備 |
| **インシデント対応** | CSIRT（Computer Security Incident Response Team）の設置、対応手順の整備 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では[**4.5 情報セキュリティ**](/docs/pe-comprehensive-management-keyword-2026#45-情報セキュリティ)に位置づけられる。

標的型攻撃への対応は情報管理だけでなく、人的資源管理（セキュリティ教育・組織体制）、経済性管理（被害コスト・対策投資の最適化）、社会環境管理（個人情報保護・社会的信頼）にまたがる総合的なリスクマネジメントが必要となる。

CSIRT設置やサイバーキルチェーンに基づく多層防御の設計は、総合技術監理の視点から組織横断的に推進すべき課題である。
