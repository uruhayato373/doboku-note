# 男女共同参画社会基本法

## 男女共同参画社会基本法とは

**男女共同参画社会基本法**（平成11年法律第78号）は、男女共同参画社会の形成に関する基本理念と、国・地方公共団体・国民の責務を定めた法律である。

男女が対等な構成員として社会のあらゆる分野における活動に参画し、ともに責任を担う社会の実現を目指す基本法として1999年に制定された。

## 法律の概要

| 項目 | 内容 |
|---|---|
| **正式名称** | 男女共同参画社会基本法（平成11年法律第78号） |
| **目的** | 男女共同参画社会の形成の促進 |
| **性格** | 基本法（理念と施策の基本方針を定める法律） |
| **適用範囲** | 国・地方公共団体・国民のすべて |
| **所管** | 内閣府（男女共同参画局） |
| **施行** | 1999年6月 |

## 5つの基本理念

| 基本理念 | 内容 |
|---|---|
| **① 男女の人権の尊重** | 男女の個人としての尊厳、性別による差別的取扱いの排除 |
| **② 社会における制度又は慣行についての配慮** | 性別による固定的な役割分担意識に基づく制度・慣行の見直し |
| **③ 政策等の立案及び決定への共同参画** | 国・地方公共団体の政策決定過程への男女共同参画 |
| **④ 家庭生活における活動と他の活動の両立** | 家庭生活と社会活動の両立（ワーク・ライフ・バランス） |
| **⑤ 国際的協調** | 国際社会の取組みと協調した男女共同参画の推進 |

## 責務

| 主体 | 責務 |
|---|---|
| **国** | 男女共同参画社会の形成の促進に関する施策の策定・実施 |
| **地方公共団体** | 国の施策に準じた施策、地域の特性に応じた施策の策定・実施 |
| **国民** | 男女共同参画社会の形成に寄与するよう努める |

## 男女共同参画基本計画

| 項目 | 内容 |
|---|---|
| **策定** | 政府が策定義務（都道府県も策定義務、市町村は努力義務） |
| **現行計画** | 第5次男女共同参画基本計画（2020年12月閣議決定） |
| **計画期間** | おおむね5年 |
| **主要目標** | 2020年代の可能な限り早期に指導的地位の女性割合30%達成 |

### 第5次基本計画の重点分野

| 分野 | 内容 |
|---|---|
| **あらゆる分野における女性の参画拡大** | 政治・行政・経済・科学技術等 |
| **安全・安心な暮らしの実現** | 女性に対する暴力の根絶、困難を抱える女性への支援 |
| **男女共同参画社会の基盤整備** | 男女平等教育、メディアにおける表現の適正化 |

## 推進体制

| 機関 | 役割 |
|---|---|
| **男女共同参画会議** | 内閣府に設置、基本計画案の作成、施策の実施状況の監視 |
| **男女共同参画局** | 内閣府の事務局、施策の総合調整 |
| **都道府県男女共同参画センター** | 地域の拠点、相談・研修・情報提供 |

## 関連法律

| 法律 | 内容 |
|---|---|
| **男女雇用機会均等法** | 雇用分野における性別差別の禁止 |
| **女性活躍推進法** | 女性の職業生活における活躍を推進（一般事業主行動計画の策定義務） |
| **育児・介護休業法** | 育児休業・介護休業制度の整備 |
| **配偶者暴力防止法（DV防止法）** | 配偶者からの暴力の防止と被害者の保護 |
| **政治分野における男女共同参画推進法** | 政党等の自主的な取組みの促進 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**3.2 労働関係法と労務管理**」に位置づけられる。

男女共同参画社会基本法は、男女雇用機会均等法・女性活躍推進法等の個別法の上位に位置する基本法であり、ジェンダー平等推進の理念的基盤となる。

総合技術監理の観点では、建設業における女性技術者の参画拡大、ワーク・ライフ・バランスの実現、固定的な役割分担意識の見直しが、人的資源管理と社会環境管理の両面から求められるテーマとなる。
