# 典型７公害

## 典型７公害とは

**典型７公害** とは、環境基本法第2条第3項に規定される7種類の公害をいう。

大気の汚染、水質の汚濁、土壌の汚染、騒音、振動、地盤の沈下、悪臭の7つであり、事業活動その他の人の活動に伴って生ずる相当範囲にわたる環境上の支障と定義される。

旧公害対策基本法（1967年）で定められた分類を環境基本法（1993年）が引き継いだものであり、公害苦情処理や規制法体系の基礎となっている。

### 典型７公害の分類と規制法

| 公害の種類 | 主な発生源 | 主な規制法 | 環境基準の有無 |
|---|---|---|---|
| **大気汚染** | 工場ばい煙、自動車排ガス、VOC | 大気汚染防止法 | あり |
| **水質汚濁** | 工場排水、生活排水、農業排水 | 水質汚濁防止法 | あり |
| **土壌汚染** | 有害物質の漏洩・不法投棄、鉱山廃水 | 土壌汚染対策法 | あり |
| **騒音** | 工場、建設作業、自動車、航空機 | 騒音規制法 | あり |
| **振動** | 工場、建設作業、道路交通 | 振動規制法 | なし（要請限度） |
| **地盤沈下** | 地下水の過剰揚水 | 工業用水法、ビル用水法 | なし（監視基準） |
| **悪臭** | 工場、畜産施設、ごみ処理場 | 悪臭防止法 | なし（規制基準） |

### 公害苦情件数の推移

公害苦情は毎年約6～7万件が全国で処理されている。

| 公害の種類 | 苦情件数の傾向 | 備考 |
|---|---|---|
| **騒音** | 最多（約35%） | 建設作業・生活騒音が中心 |
| **大気汚染** | 第2位（約20%） | 野焼き・ばい煙への苦情 |
| **悪臭** | 第3位（約15%） | 畜産・飲食店からの苦情 |
| **水質汚濁** | 第4位（約12%） | 生活排水・不法投棄 |
| **振動** | 少数 | 建設作業・道路交通 |
| **土壌汚染** | 少数 | 有害物質の漏洩発覚時に増加 |
| **地盤沈下** | 最少 | 地下水揚水規制の効果で減少傾向 |

### 大気汚染に関する規制

| 項目 | 内容 |
|---|---|
| **大気汚染防止法（1968年）** | ばい煙・粉じん・有害大気汚染物質・VOCの排出規制 |
| **規制対象物質** | SOx、NOx、ばいじん、水銀、石綿、ベンゼン、VOC等 |
| **環境基準** | SO2、NO2、CO、光化学オキシダント、SPM、PM2.5 |
| **PM2.5** | 粒径2.5μm以下の微小粒子状物質。2009年に環境基準設定 |
| **自動車NOx・PM法** | 大都市圏における自動車排出ガス対策の特別措置 |

### 水質汚濁に関する規制

| 項目 | 内容 |
|---|---|
| **水質汚濁防止法（1970年）** | 公共用水域・地下水の水質保全。排水基準の設定 |
| **排水基準** | 一律排水基準（全国一律）と上乗せ排水基準（都道府県条例） |
| **環境基準** | 人の健康の保護に関する基準（カドミウム、鉛等27項目）と生活環境の保全に関する基準（BOD、COD等） |
| **総量規制** | 東京湾・伊勢湾・瀬戸内海のCOD・窒素・りんの総量規制 |
| **地下水汚染** | 有害物質の地下浸透を禁止。汚染が判明した場合は浄化措置を命令 |

### 土壌汚染に関する規制

| 項目 | 内容 |
|---|---|
| **土壌汚染対策法（2002年）** | 土壌汚染の調査・対策に関する法律 |
| **調査契機** | 有害物質使用特定施設の廃止時、一定規模以上の土地の形質変更時 |
| **区域指定** | 要措置区域（汚染除去等の措置が必要）と形質変更時要届出区域 |
| **対策手法** | 掘削除去、原位置封じ込め、不溶化、土壌洗浄等 |
| **特定有害物質** | 第一種（VOC等）、第二種（重金属等）、第三種（農薬等）に分類 |

### 建設事業との関連

| 公害の種類 | 建設事業との主な関連 |
|---|---|
| **騒音・振動** | 杭打ち、掘削、ブレーカー作業等が規制対象。特定建設作業の届出義務 |
| **大気汚染** | アスベスト含有建材の除去時の飛散防止対策 |
| **水質汚濁** | 建設工事に伴う濁水処理、セメント・油の流出防止 |
| **土壌汚染** | 土地の形質変更時の調査義務。汚染土壌の搬出規制 |
| **粉じん** | 解体工事・土工事における粉じんの飛散防止 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**6.2 地域環境問題**」に位置づけられる。

典型7公害は社会環境管理の規制体系の根幹であり、建設事業においては騒音・振動・大気汚染・水質汚濁・土壌汚染の5つが日常的に管理対象となる。

安全管理（労働者・住民の健康保護）や経済性管理（公害防止コスト）とのトレードオフを総合的に判断する力が求められる。
