# ダイオキシン類対策特別措置法

## ダイオキシン類対策特別措置法とは

ダイオキシン類対策特別措置法は、ダイオキシン類による環境汚染の防止及びその除去等を図り、国民の健康の保護を図ることを目的とする法律である。

1999年に制定され、ダイオキシン類に関する環境基準及び排出基準を定めるとともに、汚染状況の調査・措置を規定している。

1990年代に廃棄物焼却施設からの高濃度ダイオキシン排出が社会問題化したことを受け、従来の大気汚染防止法や廃棄物処理法では対応が不十分な部分を補完する特別法として制定された。

### ダイオキシン類の定義と毒性

本法で規制対象となるダイオキシン類の範囲と毒性評価の仕組みは以下のとおりである。

- **ダイオキシン類**: ポリ塩化ジベンゾ-パラ-ジオキシン（PCDD）、ポリ塩化ジベンゾフラン（PCDF）、コプラナーPCB
- **毒性等価係数（TEF）**: 異性体ごとの毒性の強さを2,3,7,8-TCDDを1として換算
- **毒性等量（TEQ）**: 各異性体の濃度にTEFを乗じた値の合計で毒性を評価
- **主な健康影響**: 発がん性、免疫毒性、生殖毒性、内分泌かく乱作用
- **発生源**: 廃棄物の焼却、金属精錬、紙パルプ製造、自然発生（山火事等）

### 耐容一日摂取量（TDI）

耐容一日摂取量（TDI）とは、人が生涯にわたって摂取し続けても健康に影響を及ぼさない1日あたりの摂取量である。

- **日本の基準**: 4 pg-TEQ/kg体重/日
- **WHOの評価**: 1〜4 pg-TEQ/kg体重/月（2001年再評価）
- **摂取経路**: 食物からの摂取が約9割（特に魚介類）

### 環境基準

本法に基づき、以下の4媒体についてダイオキシン類の環境基準が定められている。

| 媒体 | 環境基準 |
|---|---|
| **大気** | 0.6 pg-TEQ/m3 以下（年平均値） |
| **水質** | 1 pg-TEQ/L 以下（年平均値） |
| **底質** | 150 pg-TEQ/g 以下 |
| **土壌** | 1,000 pg-TEQ/g 以下 |

### 規制対象施設と排出基準

特定施設の種類と処理能力に応じて、大気への排出基準が段階的に設定されている。

| 施設区分 | 排出基準（大気） | 備考 |
|---|---|---|
| **廃棄物焼却炉（新設・4t/h以上）** | 0.1 ng-TEQ/m3N | 最も厳しい基準 |
| **廃棄物焼却炉（新設・2〜4t/h）** | 1 ng-TEQ/m3N | |
| **廃棄物焼却炉（新設・2t/h未満）** | 5 ng-TEQ/m3N | |
| **製鋼用電気炉** | 0.5 ng-TEQ/m3N | |
| **焼結鉱製造施設** | 0.1 ng-TEQ/m3N | |

排水についても水質排出基準（10 pg-TEQ/L）が設定されている。

### 主要な規制内容

本法では、特定施設の届出から汚染土壌の処理まで、一貫した規制の枠組みが定められている。

- **特定施設の届出**: ダイオキシン類を発生させる施設は都道府県知事への届出が必要
- **排出基準の遵守**: 大気排出基準・水質排出基準の遵守義務
- **自主測定**: 特定施設設置者は排出ガス・排出水のダイオキシン類濃度を年1回以上測定
- **汚染状況調査**: 国・地方公共団体が大気・水質・底質・土壌のダイオキシン類濃度を常時監視
- **対策地域の指定**: 環境基準を超過した地域を対策地域に指定し、対策計画を策定
- **汚染土壌処理**: 対策地域内の汚染土壌について除去等の措置を実施

### 罰則

違反の種類に応じて、以下の罰則が定められている。

| 違反内容 | 罰則 |
|---|---|
| **排出基準違反（直罰）** | 6月以下の懲役 又は 50万円以下の罰金 |
| **改善命令違反** | 1年以下の懲役 又は 100万円以下の罰金 |
| **届出義務違反** | 3月以下の懲役 又は 20万円以下の罰金 |
| **測定義務違反** | 30万円以下の罰金 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では[**6.2 地域環境問題**](/docs/pe-comprehensive-management-keyword-2026#62-地域環境問題)に位置づけられる。
