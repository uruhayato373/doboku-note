# 労働安全衛生法

## 労働安全衛生法とは

**労働安全衛生法**（昭和47年法律第57号）は、職場における労働者の安全と健康を確保するとともに、快適な職場環境の形成を促進することを目的とする法律である。

1972年に労働基準法から独立して制定された。労働災害の防止のための危害防止基準の確立、責任体制の明確化、自主的活動の促進を基本方針としている。

## 法律の概要

| 項目 | 内容 |
|---|---|
| **正式名称** | 労働安全衛生法（昭和47年法律第57号） |
| **目的** | 労働災害の防止、労働者の安全と健康の確保、快適な職場環境の形成 |
| **適用範囲** | 労働者を使用するすべての事業場 |
| **所管** | 厚生労働省 |
| **監督機関** | 労働基準監督署、都道府県労働局 |
| **罰則** | 最高で3年以下の懲役または300万円以下の罰金（法人重課あり） |

## 安全衛生管理体制

### 事業場規模別の管理体制

| 管理者等 | 選任基準 | 役割 |
|---|---|---|
| **総括安全衛生管理者** | 常時100人以上（建設業・製造業等）、300人以上（その他） | 安全管理者・衛生管理者の指揮、安全衛生に関する業務の統括管理 |
| **安全管理者** | 常時50人以上（一定業種） | 安全に係る技術的事項の管理 |
| **衛生管理者** | 常時50人以上（全業種） | 衛生に係る技術的事項の管理 |
| **安全衛生推進者** | 常時10〜49人 | 安全衛生に係る業務の担当 |
| **産業医** | 常時50人以上 | 労働者の健康管理、作業環境管理に関する医学的助言 |

### 建設業の特定元方事業者の体制

| 管理者等 | 選任基準 | 役割 |
|---|---|---|
| **統括安全衛生責任者** | ずい道・橋梁建設等：常時30人以上、その他：常時50人以上 | 元方事業者が選任、現場全体の安全衛生を統括 |
| **元方安全衛生管理者** | 統括安全衛生責任者の選任事業場 | 統括安全衛生責任者を技術的に補佐 |
| **店社安全衛生管理者** | 統括安全衛生責任者の選任が不要な規模の現場 | 毎月1回以上の現場巡視 |
| **安全衛生責任者** | 関係請負人が選任 | 統括安全衛生責任者との連絡調整 |

### 委員会

| 委員会 | 設置基準 | 構成 |
|---|---|---|
| **安全委員会** | 常時50人以上（一定業種） | 総括安全衛生管理者等、安全管理者、労働者の代表 |
| **衛生委員会** | 常時50人以上（全業種） | 総括安全衛生管理者等、衛生管理者、産業医、労働者の代表 |
| **安全衛生委員会** | 両方の設置義務がある場合に統合可能 | 上記の委員を合わせた構成 |

## 危険防止措置

| 措置 | 内容 |
|---|---|
| **事業者の講ずべき措置** | 機械・爆発物・電気等による危険の防止、墜落・崩壊等による危険の防止 |
| **作業主任者の選任** | 危険・有害作業について資格を有する者を選任（足場の組立て、土止め支保工等） |
| **特定機械等の検査** | ボイラー、クレーン、エレベーター等の製造許可・検査 |
| **化学物質のリスクアセスメント** | 一定の危険有害化学物質を取り扱う場合にリスクアセスメントを実施（2016年義務化） |

## 安全衛生教育

| 種類 | 対象 | 内容 |
|---|---|---|
| **雇入れ時教育** | 新規雇入れの労働者全員 | 機械等の取扱い、作業手順、安全装置 |
| **作業内容変更時教育** | 作業内容を変更した労働者 | 変更後の作業に関する安全衛生事項 |
| **特別教育** | 危険・有害業務に従事する労働者 | アーク溶接、高所作業車、酸素欠乏危険作業等 |
| **職長教育** | 新たに職長になった者（建設業等） | 作業方法の決定、労働者の配置、指導・監督 |

## 健康管理

| 項目 | 内容 |
|---|---|
| **一般健康診断** | 雇入れ時、定期（1年以内ごとに1回） |
| **特殊健康診断** | 有害業務従事者に対する特別な項目の健診 |
| **ストレスチェック** | 常時50人以上の事業場で年1回実施義務（2015年〜） |
| **長時間労働者への医師面接** | 月80時間超の時間外労働者に対し、申出により医師面接指導 |
| **作業環境測定** | 有害業務を行う作業場で定期的に実施 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**3.2 労働関係法と労務管理**」に位置づけられる。

労働安全衛生法は人的資源管理と安全管理の交差領域に位置する重要法規である。

総合技術監理の観点では、建設業における元方事業者の安全衛生管理体制、リスクアセスメントの実施、安全衛生教育の充実が、労働災害の防止と工程管理の効率化の両立に不可欠なテーマとなる。
