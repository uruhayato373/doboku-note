# データ可視化

## データ可視化とは

データ可視化（data visualization）とは、数値データや分析結果をグラフ・チャート・ダッシュボード・地図等の視覚的表現に変換し、データに内在するパターンや傾向の理解・伝達を促進する技術である。

人間の視覚認知能力を活用することで、大量のデータから直感的に洞察を得ることが可能になる。

ビッグデータ時代においては、データ量の爆発的増加に伴い、効果的な可視化の重要性が一層高まっている。

### 可視化手法の分類

目的とデータの種類に応じて、適切な可視化手法を選択する必要がある。

| 可視化の目的 | 代表的手法 | 適するデータ |
|---|---|---|
| **比較** | 棒グラフ、レーダーチャート | カテゴリ別の数値比較 |
| **推移・変化** | 折れ線グラフ、面グラフ | 時系列データ |
| **構成比** | 円グラフ、積み上げ棒グラフ、ツリーマップ | 全体に占める割合 |
| **分布** | ヒストグラム、箱ひげ図、バイオリンプロット | データの散らばり |
| **相関** | 散布図、バブルチャート、ヒートマップ | 2変数以上の関係性 |
| **地理空間** | コロプレスマップ、ドットマップ | 位置情報を含むデータ |
| **ネットワーク** | ノード・リンク図、弦図 | 関係性・つながり |
| **階層構造** | デンドログラム、サンバースト図 | 階層的分類データ |

### インフォグラフィックスとダッシュボード

**インフォグラフィックス**は、情報やデータをイラスト・図表・テキストを組み合わせて視覚的にわかりやすく表現する手法である。

報告書やプレゼンテーションにおいて、複雑な情報を直感的に伝達するために活用される。

**ダッシュボード**は、複数の可視化要素を一つの画面に統合し、KPI（重要業績指標）や業務状況をリアルタイムでモニタリングする仕組みである。

BIツール（Business Intelligence）と連携することで、インタラクティブなデータ探索が可能になる。

### 可視化における注意点

データ可視化には、誤解を招くリスクも存在する。

- 軸のスケール操作（ゼロ基点の省略、対数スケールの不適切な使用）
- 3Dグラフによる遠近法の錯覚
- 色覚多様性への未対応（色弱者が区別困難な配色）
- 因果関係と相関関係の混同を助長する表現

正確かつ誠実なデータ表現は、技術者倫理の観点からも重要である。
