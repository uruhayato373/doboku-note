# RoHS規制・WEEE規制

## RoHS規制・WEEE規制とは

RoHS指令（Restriction of Hazardous Substances Directive）は、電気電子機器に含まれる特定有害物質の使用を制限するEU指令であり、2006年7月に施行された。

WEEE指令（Waste Electrical and Electronic Equipment Directive）は、電気電子機器廃棄物の回収・リサイクルを義務づけるEU指令であり、2003年2月に施行された。

両指令はセットで運用され、電気電子機器のライフサイクル全体を通じた有害物質管理と資源循環を実現する枠組みとなっている。

### RoHS指令の規制内容

| 項目 | 内容 |
|---|---|
| **正式名称** | Directive 2011/65/EU（RoHS2、2013年施行で改正） |
| **目的** | 電気電子機器中の有害物質を制限し、人の健康と環境を保護 |
| **対象** | EU域内で上市されるすべての電気電子機器（11カテゴリ） |
| **規制方式** | 均質素材中の最大許容濃度を設定 |

### RoHS規制対象物質（10物質）

| 物質 | 最大許容濃度 | 追加時期 |
|---|---|---|
| **鉛（Pb）** | 0.1重量% | 当初6物質（2006年） |
| **水銀（Hg）** | 0.1重量% | 同上 |
| **カドミウム（Cd）** | 0.01重量% | 同上 |
| **六価クロム（Cr6+）** | 0.1重量% | 同上 |
| **PBB（ポリ臭化ビフェニル）** | 0.1重量% | 同上 |
| **PBDE（ポリ臭化ジフェニルエーテル）** | 0.1重量% | 同上 |
| **DEHP（フタル酸ジ-2-エチルヘキシル）** | 0.1重量% | 追加4物質（2019年） |
| **BBP（フタル酸ブチルベンジル）** | 0.1重量% | 同上 |
| **DBP（フタル酸ジブチル）** | 0.1重量% | 同上 |
| **DIBP（フタル酸ジイソブチル）** | 0.1重量% | 同上 |

### RoHS対象製品カテゴリ（11カテゴリ）

| カテゴリ | 例 |
|---|---|
| **1. 大型家庭用電気製品** | 冷蔵庫、洗濯機、エアコン |
| **2. 小型家庭用電気製品** | 掃除機、アイロン、時計 |
| **3. IT・通信機器** | PC、プリンタ、携帯電話 |
| **4. 民生用電子機器** | テレビ、オーディオ機器 |
| **5. 照明器具** | 蛍光灯、LED照明 |
| **6. 電動工具** | ドリル、のこぎり |
| **7. 玩具・レジャー・スポーツ用品** | 電子玩具、ゲーム機 |
| **8. 医療機器** | 放射線治療装置、人工透析装置 |
| **9. 監視・制御機器** | 煙感知器、計測機器 |
| **10. 自動販売機** | 飲料・食品自動販売機 |
| **11. その他の電気電子機器** | 上記に含まれないもの |

### WEEE指令の規制内容

| 項目 | 内容 |
|---|---|
| **正式名称** | Directive 2012/19/EU（WEEE2、2014年施行で改正） |
| **目的** | 電気電子機器廃棄物の発生抑制、再使用・リサイクルの促進 |
| **回収目標** | 過去3年間の平均上市量の65%又は発生廃棄物量の85% |
| **再資源化率** | カテゴリに応じて75〜85% |
| **生産者責任** | 拡大生産者責任（EPR）に基づき、製造者が回収・リサイクル費用を負担 |
| **マーキング** | 車輪付きゴミ箱にバツ印のマーク（分別回収の表示義務） |

### RoHSとWEEEの関係

| 項目 | RoHS指令 | WEEE指令 |
|---|---|---|
| **規制段階** | 製品の設計・製造段階 | 製品の廃棄・リサイクル段階 |
| **アプローチ** | 有害物質の使用制限（入口規制） | 廃棄物の回収・再資源化（出口規制） |
| **対象** | 均質素材中の有害物質濃度 | 廃電気電子機器の回収率・再資源化率 |
| **補完関係** | RoHSで有害物質を減らし、WEEEでリサイクルしやすくする |

### 日本の対応

| 対応 | 内容 |
|---|---|
| **J-Moss** | 日本版RoHSに相当するJIS C 0950（電気電子機器の特定化学物質の含有表示） |
| **家電リサイクル法** | 特定家庭用機器のリサイクルを義務化（WEEEに類似） |
| **小型家電リサイクル法** | 小型電子機器の回収・再資源化（2013年施行） |
| **輸出企業の対応** | EU向け製品はRoHS適合を確認、CEマーキング取得が必要 |
| **グリーン調達** | サプライチェーン全体での有害物質管理（chemSHERPA等） |

## 総合技術監理における位置づけ

総合技術監理キーワード集では[**6.2 地域環境問題**](/docs/pe-comprehensive-management-keyword-2026#62-地域環境問題)に位置づけられる。

RoHS・WEEE規制はEUの環境規制であるが、グローバルに事業展開する日本企業のサプライチェーン管理に直接影響する。経済性管理（代替材料への転換コスト）、情報管理（含有化学物質の把握・伝達）、社会環境管理（有害物質削減・資源循環）の統合的なマネジメントが必要となる。
