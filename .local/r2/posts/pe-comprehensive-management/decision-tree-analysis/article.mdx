# デシジョンツリー分析

## デシジョンツリー分析とは

デシジョンツリー分析（Decision Tree Analysis）とは、**意思決定の選択肢とその結果を樹形図（ツリー）で表し、各選択肢の期待値を比較して最適な意思決定を行うための手法**である。

不確実性を含む意思決定問題において、リスクと期待される効果を定量的に評価するために用いられる。

## 構成要素

| 要素 | 記号 | 内容 |
|---|---|---|
| **決定ノード** | □（四角） | 意思決定者が選択を行う分岐点 |
| **確率ノード** | ○（丸） | 不確実な事象の発生確率による分岐点 |
| **結果ノード** | △（三角） | 各経路の最終的な結果（利益・損失等） |

## 分析の手順

| ステップ | 内容 |
|---|---|
| **1. ツリーの構築** | 決定ノードと確率ノードを用いてツリーを描く |
| **2. 確率の設定** | 各確率ノードの分岐に発生確率を割り当てる |
| **3. 結果の評価** | 各末端の結果（期待利益・損失）を評価する |
| **4. 期待値の計算** | 各分岐の確率×結果を積算し、期待値を算出する |
| **5. 最適選択の決定** | 期待値が最も高い（またはリスクが最も低い）選択肢を選ぶ |

## ETAとの比較

| 項目 | デシジョンツリー | ETA |
|---|---|---|
| **目的** | 最適な意思決定の選択 | 事故シナリオの展開と確率評価 |
| **分岐の性質** | 意思決定と不確実事象 | 安全機能の成功・失敗 |
| **適用分野** | 経営判断・投資判断 | 安全工学・リスク分析 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では[**5.6 システム安全工学手法**](/docs/pe-comprehensive-management-keyword-2026#56-システム安全工学手法)に位置づけられている。

デシジョンツリー分析は、安全対策の選択肢を比較検討する際の意思決定ツールとして活用される。[ETA](/docs/pe-comprehensive-management-eta)と形式は類似するが、安全分析ではなく意思決定支援に重点がある点で区別される。
