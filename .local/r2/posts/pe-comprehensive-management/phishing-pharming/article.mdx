# フィッシング詐欺・ファーミング詐欺

## 概要

**フィッシング詐欺（Phishing）** とは、実在する組織（銀行、ECサイト、行政機関等）を装った偽のメールやWebサイトを用いて、利用者のID・パスワード・クレジットカード情報等を騙し取る詐欺行為である。

**ファーミング詐欺（Pharming）** とは、DNSの設定を改ざんすることにより、利用者が正しいURLを入力しても偽のWebサイトに誘導される攻撃手法である。

フィッシングが利用者を「騙して」偽サイトに誘導するのに対し、ファーミングはDNSの仕組みを「改ざんして」自動的に偽サイトへ転送する点が異なる。

## 手口・種類

### フィッシング詐欺の種類

| 種類 | 手口 |
|---|---|
| **メールフィッシング** | 銀行やECサイトを装った偽メールで偽サイトに誘導し、認証情報を入力させる |
| **スピアフィッシング** | 特定の個人・組織を標的にした精巧なフィッシング（標的型攻撃の入り口） |
| **スミッシング（SMS Phishing）** | SMSを利用した偽メッセージで偽サイトに誘導する |
| **ビッシング（Voice Phishing）** | 電話を利用して銀行等を装い、口頭で認証情報を聞き出す |
| **クローンフィッシング** | 正規のメールを複製し、リンクや添付ファイルだけ不正なものに差し替える |

### ファーミング詐欺の手法

| 手法 | 内容 |
|---|---|
| **DNSキャッシュポイズニング** | DNSサーバのキャッシュに偽の情報を注入し、正規URLへのアクセスを偽サイトに転送 |
| **hostsファイルの改ざん** | マルウェアによりPC内のhostsファイルを書き換え、名前解決を偽装する |
| **不正なDHCPサーバ** | ネットワーク内に偽のDHCPサーバを設置し、偽DNSサーバを参照させる |

### フィッシングとファーミングの比較

- **誘導方法**
  - フィッシング: 偽メール・SMSで利用者を騙して偽サイトに誘導
  - ファーミング: DNS改ざんにより正規URL入力でも自動転送
- **利用者の行動**
  - フィッシング: 偽リンクをクリックして偽サイトへ遷移
  - ファーミング: 正しいURLを入力しても偽サイトへ転送される
- **検知の難易度**
  - フィッシング: 注意すれば偽メールに気づける
  - ファーミング: URLが正規のまま表示されるため利用者が気づきにくい
- **攻撃対象**
  - フィッシング: 個人単位
  - ファーミング: ネットワーク・DNS単位で広範囲

## 被害例

金融機関を装ったフィッシングメールによるインターネットバンキングの不正送金被害は年間数十億円規模に達している。

宅配業者を装ったスミッシングでは、不在通知を偽装したSMSから偽サイトに誘導し、マルウェアのインストールや個人情報の窃取が行われている。

DNSキャッシュポイズニングにより、正規のURLを入力した多数の利用者が一斉に偽サイトに誘導され、大規模な情報漏洩に至った事例がある。

## 対策

| 対策区分 | 具体的な対策 |
|---|---|
| **利用者教育** | 不審なメール・SMSのリンクを安易にクリックしない、URLの確認習慣 |
| **技術的対策（フィッシング）** | メールフィルタリング、SPF/DKIM/DMARCによる送信元認証、Webフィルタリング |
| **技術的対策（ファーミング）** | DNSSEC（DNS Security Extensions）の導入、SSL/TLS証明書の確認 |
| **認証強化** | 多要素認証（MFA）の導入により、ID・パスワードが窃取されても不正ログインを防止 |
| **ブラウザ機能** | フィッシングサイト警告機能、EV証明書による正規サイトの識別 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では[**4.5 情報セキュリティ**](/docs/pe-comprehensive-management-keyword-2026#45-情報セキュリティ)に位置づけられる。

フィッシング・ファーミング詐欺は、個人情報保護（社会環境管理）、金銭被害の防止（経済性管理）、利用者教育（人的資源管理）と関連する。

技術的対策（多要素認証・DNSSEC）と利用者のリテラシー向上を組み合わせた対策が、総合技術監理の視点では重要となる。
