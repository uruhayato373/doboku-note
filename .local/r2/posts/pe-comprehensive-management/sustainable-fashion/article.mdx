# サステナブルファッション

## サステナブルファッションとは

**サステナブルファッション** とは、衣服の生産・流通・着用・廃棄の全ライフサイクルにおいて、環境負荷の低減と社会的公正の実現を目指す取組の総称である。

ファッション産業は世界の温室効果ガス排出量の約8～10%を占め、水質汚染の20%がファッション産業に起因するとされる。

ファストファッションの台頭により衣服の生産量が過去20年間で約2倍に増加する一方、1着あたりの着用回数は約36%減少しており、大量生産・大量廃棄の構造が顕在化している。

### ファッション産業の環境負荷

| 環境負荷 | 内容 |
|---|---|
| **温室効果ガス排出** | 世界全体の約8～10%（約12億トンCO2/年）。航空業と海運業の合計を上回る |
| **水消費** | Tシャツ1枚に約2,700リットル、ジーンズ1本に約7,500リットルの水を使用 |
| **水質汚染** | 染色工程での化学物質排出が世界の水質汚染の約20%を占める |
| **マイクロファイバー** | 合成繊維の洗濯時に海洋に流出するマイクロプラスチックの主要発生源 |
| **廃棄量** | 世界で毎秒トラック1台分の繊維廃棄物が埋立・焼却されている |
| **土地利用** | 綿花栽培に大量の農薬・水を使用。農地の約2.4%を占有 |

### 繊維廃棄物の現状

| 項目 | 内容 |
|---|---|
| **世界の繊維生産量** | 年間約1億トン（2020年時点）。2030年には1.4億トンに増加見込み |
| **リサイクル率** | 繊維廃棄物のリサイクル率は約12%にとどまる |
| **日本の衣類廃棄量** | 年間約48万トン（環境省、2020年推計）。そのうち約65%が焼却・埋立 |
| **日本の1人あたり** | 年間約18枚を購入し、約12枚を手放す（うちリユース・リサイクルは約35%） |
| **課題** | 混紡素材のリサイクル困難性、回収インフラの不足、消費者意識の変革 |

### サステナブルファッションの主なアプローチ

サステナブルファッションには以下の6つの主要アプローチがある。

- **スローファッション**: 高品質で長持ちする衣服を少量生産・購入 — パタゴニア、エシカルブランド
- **サーキュラーファッション**: 衣服の循環利用（リペア・リメイク・リサイクル） — 古着販売、修理サービス、繊維to繊維リサイクル
- **エシカルファッション**: 労働者の権利保護、フェアトレード — ラナプラザ事故後のサプライチェーン透明化
- **素材イノベーション**: 環境負荷の低い素材の開発 — オーガニックコットン、再生ポリエステル、植物由来繊維
- **デジタルファッション**: バーチャル試着やNFTファッションで物理的生産を削減 — メタバースでの仮想衣装
- **シェアリング**: 衣服のレンタル・サブスクリプション — ファッションレンタルサービス

### 国際的な動向

| 動向 | 内容 |
|---|---|
| **ファッション産業気候行動憲章（2018年）** | COP24で採択。2030年までにGHG排出量30%削減、2050年ネットゼロ目標 |
| **EU繊維戦略（2022年）** | 2030年までにEU市場の繊維製品を長寿命・リサイクル可能にする目標 |
| **EU エコデザイン規則（2024年）** | 繊維製品にデジタル製品パスポートの導入を義務化 |
| **フランス廃棄禁止法（2020年）** | 売れ残り衣服の廃棄を禁止（寄付またはリサイクルを義務化） |
| **ラナプラザ崩落事故（2013年）** | バングラデシュの縫製工場崩壊で1,100人以上が死亡。サプライチェーンの人権問題が顕在化 |
