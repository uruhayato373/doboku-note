# 総合技術監理部門 記述式試験の解答戦略

<Callout type="tip" title="この記事の目的">
総合技術監理部門の記述式試験（論文）を、**5つのステップ**に分解して解答する方法を解説します。3時間30分（210分）という限られた時間の中で、的確な論文を完成させるための工程管理を身につけましょう。
</Callout>

## 1. 記述式試験の解答工程5ステップ

記述式試験は問題文が長文であり、約3,000字程度で論文を記述する必要があります。いきなり書き始めるのではなく、以下の5ステップで工程管理しながら取り組みます。

<img src="/posts/pe-comprehensive-management/essay-exam-strategy/img/figure-4-01.svg" alt="図表4.1 記述式試験の解答工程5ステップ" />

| ステップ | 内容 | 目安時間 |
|---|---|---|
| Step 1 | 前文の分析 | 試験開始後 60分 |
| Step 2 | 論文骨子の構成 | 10分 |
| Step 3 | 準備題材の活用と骨子の肉付け | ― （Step 2と並行） |
| Step 4 | 論文評価基準の確認 | 25分 |
| Step 5 | いざ執筆！ | 残り約115分 |

まず問題文を分析（Step 1）してから論文骨子を作成（Step 2・3）し、論文評価基準をクリアしているか自己確認（Step 4）したうえで、執筆に入ります。

## 2. Step 1：前文の分析

問題文は**前文**と**設問（1）、（2）、（3）……**に分かれます。前文が長文であっても、正確に分析することが的確な解答の前提です。

### 前文から抽出すべき4つの要素

前文から、以下の4つの要素を抽出します。

<img src="/posts/pe-comprehensive-management/essay-exam-strategy/img/figure-4-02.svg" alt="図表4.2 前文の分析事項" />

#### 1）テーマの抽出

問題文の中から、**中心となるキーワード（テーマ）**を特定します。テーマは問題文の冒頭や設定条件の中に明示されていることが多いです。

<details>
<summary>サンプル：平成30年度のテーマ抽出（図表4.3）</summary>

<img src="/posts/pe-comprehensive-management/essay-exam-strategy/img/figure-4-03.svg" alt="図表4.3 テーマの抽出（平成30年度）" />

前文に「長時間労働の抑制」「労働生産性の向上」「女性や高齢者の労働参加の促進」「多様な働き方への対応」「働き方改革実行計画」等のキーワードが提示されており、テーマは**「働き方改革」**と特定できます。

</details>

#### 2）設定条件の抽出

テーマに関連した**背景情報や前提条件**を整理します。政策の背景、社会情勢の変化、具体的な事象など、論文で前提とすべき情報を漏れなく抽出します。

<details>
<summary>サンプル：平成30年度の設定条件（図表4.4・4.5）</summary>

<img src="/posts/pe-comprehensive-management/essay-exam-strategy/img/figure-4-04.svg" alt="図表4.4 設定条件の抽出①（背景）" />

<img src="/posts/pe-comprehensive-management/essay-exam-strategy/img/figure-4-05.svg" alt="図表4.5 設定条件の抽出②（具体的事象）" />

- 政策的背景：働き方改革実行計画（平成29年3月決定）
- 社会的背景：就業者数の減少、年平均労働時間の長さ、パートタイム労働者の賃金水準の低さ
- 具体的事象：
  - 建設現場や工場における危険作業の機械化による安全性の向上
  - コンピュータの発達による設計作業や事務作業の効率化
  - 交通網の発達に伴う地域間の協働や交流の活性化
  - 情報通信技術の普及に伴う働く場所の多様化
  - 社会環境意識の高まりに伴う従来型雇用制度の見直し

</details>

#### 3）要求事項の抽出

前文中に示された、**解答に求められる事項**を整理します。総監部門では、必ず「業務全体を俯瞰し、5つの管理の観点から」という要求が含まれます。

<details>
<summary>サンプル：平成30年度の要求事項と総監の視点（図表4.6・4.7）</summary>

<img src="/posts/pe-comprehensive-management/essay-exam-strategy/img/figure-4-06.svg" alt="図表4.6 要求事項の抽出" />

<img src="/posts/pe-comprehensive-management/essay-exam-strategy/img/figure-4-07.svg" alt="図表4.7 総監の視点" />

</details>

| 要求事項 | 内容 |
|---------|------|
| 立場 | 総合技術監理の技術者として |
| 対象 | これまでに経験した事業・プロジェクト等 |
| 視点 | 経済性管理・人的資源管理・情報管理・安全管理・社会環境管理の5つの管理 |
| 行為 | 総合的な分析・評価、最適な企画・計画・実施・対応等 |

#### 4）評価項目の抽出

論文の採点において重視される**評価の観点**を把握します。これは Step 4（論文評価基準の確認）で再度使用します。

<details>
<summary>サンプル：平成30年度の評価項目（図表4.8）</summary>

<img src="/posts/pe-comprehensive-management/essay-exam-strategy/img/figure-4-08.svg" alt="図表4.8 評価項目の抽出" />

</details>

| 評価項目 | 着眼点 |
|---------|--------|
| **考察における視点の広さ** | 5つの管理の観点が含まれているか、トレードオフへの言及があるか |
| **記述の明確さ** | 用語が正確か、具体的に書かれているか |
| **論理的なつながり** | 前後の文脈が論理的に整合しているか、話が飛んでいないか |
| **論文全体のまとまり** | 設問(1)→(2)→(3)を通じた一貫性があるか |

## 3. Step 2：論文骨子の構成

前文の分析結果をもとに、**設問ごとの論文骨子**を作成します。骨子とは、各設問に「何を、どの順番で書くか」を箇条書きで整理したものです。

### 骨子作成のポイント

- 各設問の**問いに正面から答える**項目を立てる
- 設問間の**流れ（過去→現在→将来）**を意識する
- **5つの管理の視点**が全体を通じて網羅されるよう配分する
- トレードオフへの言及箇所を予め決めておく

<details>
<summary>サンプル：平成30年度「働き方改革」の論文骨子（図表4.9〜4.11）</summary>

<img src="/posts/pe-comprehensive-management/essay-exam-strategy/img/figure-4-09.svg" alt="図表4.9〜4.11 論文骨子の作成（設問1〜3）" />

**設問(1)** ― 事業・プロジェクトの概要
1. 名称及び目的
2. 創出している成果物
3. 事例の内容
   - (a) 過去と比較して働き方が変化した事象
   - (b) その変化の内容
   - (c) 働き方への影響

**設問(2)** ― 現在の課題
1. 働き方改革に関係する現在の課題
   - 課題1：背景・具体的な影響
   - 課題2：背景・具体的な影響

**設問(3)** ― 解決のための方策
1. 課題1について
   - (a) 具体的な技術や方策
   - (b) 実現のための障害
   - (c) 実現した場合の効果
   - (d) 付随して生じる留意すべき影響（トレードオフ）
2. 課題2について ― 同構成

</details>

<Callout type="note" title="論文の典型的な流れ">
多くの記述式試験では、設問が以下の時間軸で構成されています。

- **設問(1)**：過去〜現在の経験・事例の記述
- **設問(2)**：現在の課題の分析
- **設問(3)**：将来に向けた方策・提案

この「過去→現在→将来」の流れを意識して骨子を構成すると、論文全体にストーリー性が生まれます。
</Callout>

## 4. Step 3：準備題材の活用と骨子の肉付け

### 業務経歴からの題材活用

論文骨子に肉付けする**具体的な題材**は、出願時に作成した業務経歴から準備します。記述式試験は3時間30分で論文を構成する必要があるため、事前の題材準備が不可欠です。

<img src="/posts/pe-comprehensive-management/essay-exam-strategy/img/figure-4-12.svg" alt="図表4.12 業務経歴から準備した題材の活用" />

<Callout type="tip" title="出願ガイドとの連携">
出願段階で作成した業務経歴（5つの業務）と業務内容の詳細が、ここでの題材のベースになります。出願時に5つの管理の視点・トレードオフ・成果を整理しておくと、記述式試験での題材準備がスムーズです。
</Callout>

業務経歴から以下の要素を題材として整理しておきます。

| 業務 | 成果 | 課題 | 解決策 | トレードオフ |
|-----|------|------|--------|-----------|
| 業務1 | | | | |
| 業務2 | | | | |
| 業務3 | | | | |
| 業務4 | | | | |
| 業務5 | | | | |

### 論文題材の選定（スクリーニング）

準備した題材の中から、**テーマや要求事項に合致するもの**を選定します。すべての業務経歴がテーマに合うとは限りません。テーマとの関連性が高い業務を選び、骨子の各項目に当てはめていきます。

<img src="/posts/pe-comprehensive-management/essay-exam-strategy/img/figure-4-13.svg" alt="図表4.13 論文題材の選定（スクリーニング）" />

### 論文全体のまとまりと流れ

題材を骨子に当てはめた後、**論文全体のストーリー性**を確認します。

<img src="/posts/pe-comprehensive-management/essay-exam-strategy/img/figure-4-14.svg" alt="図表4.14 設問に対する論文の流れ" />

- テーマを中心とした流れがスムーズにつながるか
- 設問(1)→(2)→(3)の間に論理的な飛躍がないか
- 前後の文脈が一貫しているか

## 5. Step 4：論文評価基準の確認

執筆に入る前に、作成した論文骨子が**評価基準をクリアしているか**をセルフチェックします。

<img src="/posts/pe-comprehensive-management/essay-exam-strategy/img/figure-4-25.svg" alt="図表4.25 論文評価基準の確認（チェックリスト）" />

<CustomUnorderedList
  title="論文評価基準チェックリスト"
  style="checklist"
  items={[
    "テーマに対する要求事項（問い）に正面から答えているか",
    "具体的な方策やその影響が述べられているか",
    "5つの管理（経済性・人的資源・情報・安全・社会環境）の観点が含まれているか",
    "管理間のトレードオフへの対応が述べられているか",
    "骨子の内容と設問の要求が合致しているか",
    "内容が論理的につながっているか（話が飛んでいないか）",
    "論文全体としてまとまりがあるか（過去→現在→将来の流れ）"
  ]}
/>

<Callout type="caution" title="Step 4を省略しない">
時間に追われて Step 4 を省略し、すぐに執筆に入ってしまうと、設問の要求を満たしていない論文を書き上げてしまうリスクがあります。25分程度をかけて確実に確認しましょう。
</Callout>

## 6. Step 5：いざ執筆！

### 執筆の手順と時間配分

3時間30分（210分）の試験時間を、以下のように配分します。

<img src="/posts/pe-comprehensive-management/essay-exam-strategy/img/figure-4-26.svg" alt="図表4.26〜4.28 執筆手順・時間配分・タイムテーブル" />

執筆速度に応じて Step 1〜4 に使える時間が変わります。

| 執筆速度 | 解答用紙1枚あたり | 4枚の執筆時間 | Step 1〜4に使える時間 |
|---------|-----------------|-------------|---------------------|
| ゆっくり | 30分 | 120分 | 約75分 |
| 標準 | 25分 | 100分 | 約95分 |
| 速い | 20分 | 80分 | 約115分 |

<Callout type="note" title="自分の執筆速度を把握しておく">
事前に解答用紙1枚を書くのにどれくらいかかるか計測しておきましょう。標準的には1枚25分程度です。
</Callout>

### 試験本番のタイムテーブル例

標準的な執筆速度（1枚25分）の場合のタイムテーブルです。

| 開始時刻 | 所要時間 | 内容 |
|---------|---------|------|
| 13:30 | 60分 | **Step 1** 前文の分析 |
| 14:30 | 10分 | **Step 2・3** 論文骨子の構成と肉付け |
| 14:40 | 25分 | **Step 4** 論文評価基準の確認 |
| 15:05 | 25分 | **Step 5** 解答用紙1枚目の執筆 |
| 15:30 | 25分 | 解答用紙2枚目の執筆 |
| 15:55 | 25分 | 解答用紙3枚目の執筆 |
| 16:20 | 25分 | 解答用紙4枚目の執筆 |
| 16:45 | 15分 | 見直し |

<Callout type="note" title="出題の傾向">
テーマは「社会的に注目されている課題」から出題される傾向にあります。いずれのテーマでも、**5つの管理の視点**と**トレードオフへの対応**が求められる点は共通です。
</Callout>

## 8. まとめ

<Callout type="info" title="記述式試験 5ステップのポイント">
記述式試験は「書く力」だけでなく「工程管理の力」が問われます。

- **Step 1（前文の分析）**：テーマ・設定条件・要求事項・評価項目を正確に抽出
- **Step 2（論文骨子の構成）**：設問ごとに「何を書くか」を箇条書きで整理
- **Step 3（準備題材の活用）**：業務経歴から題材を選定し骨子に肉付け
- **Step 4（評価基準の確認）**：セルフチェックで要求事項の見落としを防止
- **Step 5（執筆）**：時間配分に沿って一気に書き上げる

出願時の業務経歴準備と記述式試験の題材準備は直結しています。出願段階から記述式試験を見据えた準備を行いましょう。
</Callout>
