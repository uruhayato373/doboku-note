# ドーナツ経済

## ドーナツ経済学とは

**ドーナツ経済学**（Doughnut Economics）とは、英国の経済学者ケイト・ラワース（Kate Raworth）が2012年に提唱した経済モデルである。

GDP成長を目的とする従来の経済学に代わり、「人類が安全かつ公正に活動できる空間」を視覚的に示すフレームワークとして注目されている。

ドーナツ型の図の内側の輪（社会的な土台）と外側の輪（環境の上限）の間の環状領域が、人類にとって「安全で公正な空間」であると定義する。

### ドーナツモデルの構造

ドーナツ経済学の中核となる概念は以下の3層構造で理解できる。

| 要素 | 内容 |
|---|---|
| **社会的な土台（Social Foundation）** | すべての人が満たされるべき最低限の生活水準。食料、健康、教育、所得、政治的発言力、社会的公正、ジェンダー平等など12の要素で構成 |
| **環境の上限（Ecological Ceiling）** | 地球が許容できる環境負荷の限界。プラネタリー・バウンダリー（地球の限界）の9つの指標に対応。気候変動、生物多様性の喪失、土地利用変化、窒素・リン循環など |
| **安全で公正な空間** | 社会的な土台と環境の上限の間の環状領域。この空間内に経済活動を収めることが目標 |
| **ショートフォール（不足）** | 社会的な土台を下回る状態。貧困、教育機会の欠如、健康格差など |
| **オーバーシュート（超過）** | 環境の上限を超えた状態。温暖化、オゾン層破壊、生物種の絶滅など |

### プラネタリー・バウンダリーとの関連

ドーナツモデルの環境の上限は、ストックホルム・レジリエンス・センターのヨハン・ロックストロームらが2009年に提唱した「**プラネタリー・バウンダリー**（地球の限界）」に基づいている。

| 指標 | 現状 |
|---|---|
| **気候変動** | 超過（CO2濃度が安全な範囲を超過） |
| **生物多様性の喪失** | 大幅超過（絶滅速度が安全な範囲を大幅に超過） |
| **窒素・リン循環** | 超過（農業由来の窒素・リンが水圏に過剰流入） |
| **土地利用変化** | 超過（森林破壊等による土地利用の変化） |
| **淡水利用** | 超過（一部地域で過剰取水） |
| **海洋酸性化** | 安全範囲内（ただし悪化傾向） |
| **オゾン層破壊** | 安全範囲内（モントリオール議定書の成果） |
| **大気エアロゾル** | 地域的に超過 |
| **新規化学物質** | 超過（プラスチック・化学物質汚染の拡大） |

### 従来の経済学との違い

ドーナツ経済学は、GDP成長を絶対視する従来の経済学と以下の点で本質的に異なる。

- **目標**: 従来の経済学はGDP成長の最大化 — ドーナツ経済学は社会的土台と環境上限の間に収まること
- **成長観**: 従来の経済学は無限の成長を前提 — ドーナツ経済学は「成長に依存しない繁栄」を志向
- **環境**: 従来の経済学は外部性として扱う — ドーナツ経済学は経済活動の絶対的な制約条件
- **分配**: 従来の経済学は成長の結果として波及（トリクルダウン） — ドーナツ経済学は最初から分配を設計に組み込む
- **指標**: 従来の経済学はGDP — ドーナツ経済学は社会的土台12要素＋環境上限9要素
