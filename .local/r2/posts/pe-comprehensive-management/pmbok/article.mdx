# PMBOK

## PMBOKとは

PMBOK（Project Management Body of Knowledge）とは、**PMI（米国プロジェクトマネジメント協会）が策定したプロジェクトマネジメントの知識体系ガイド**である。

プロジェクトの立上げから終結までを体系的に整理し、知識エリアとプロセス群で構成される。

## 10の知識エリア（第6版）

| 知識エリア | 主な内容 |
|---|---|
| **統合管理** | プロジェクト全体の調整・変更管理 |
| **スコープ管理** | WBS（作業分解構造）による範囲定義 |
| **スケジュール管理** | CPM（クリティカルパス法）による工程管理 |
| **コスト管理** | EVM（アーンドバリューマネジメント）等 |
| **品質管理** | 品質計画・品質保証・品質管理 |
| **資源管理** | 人的資源・物的資源の管理 |
| **コミュニケーション管理** | 情報の生成・配布・保管 |
| **リスク管理** | リスクの特定・分析・対応 |
| **調達管理** | 外部からの調達・契約管理 |
| **ステークホルダー管理** | 利害関係者の特定・関与管理 |

## 5つのプロセス群

**立上げ→計画→実行→監視・コントロール→終結**の5プロセス群で構成される。

## 総合技術監理における位置づけ

総合技術監理キーワード集では[**2.1 事業企画**](/docs/pe-comprehensive-management-keyword-2026#21-事業企画)に位置づけられている。

PMBOKは総合技術監理の5つの管理（経済性・人的資源・情報・安全・社会環境）を横断するプロジェクトマネジメントの枠組みである。[PDCAサイクル](/docs/pe-comprehensive-management-pdca-cycle)の考え方と整合し、[リスク評価](/docs/pe-comprehensive-management-risk-assessment)もリスク管理知識エリアに含まれる。
