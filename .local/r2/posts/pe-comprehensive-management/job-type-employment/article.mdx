# ジョブ型（職務主義）

## ジョブ型雇用とは

**ジョブ型雇用（職務主義）** とは、職務記述書（ジョブディスクリプション）に明記された特定の職務に対して人を採用・配置する雇用形態である。欧米で主流の雇用システムであり、「仕事に人をつける」考え方に基づく。

## メンバーシップ型との比較

過去問 **[R04 Ⅰ-1-15](/docs/pe-comprehensive-management-r04-primary#1-15)** では「メンバーシップ型はジョブ型に比べビジネスモデルの変革や事業の変化が激しい場合で対応が容易」という誤答が出題された。**変化対応力はジョブ型の方が高く**、メンバーシップ型は内部育成・長期雇用で柔軟配置が可能な反面、急激な変革には対応が遅い点が試験で問われる。

| 項目 | ジョブ型（職務主義） | メンバーシップ型（属人主義） |
|---|---|---|
| **採用** | 職務を特定して採用（中途中心） | 一括採用後に配置（新卒中心） |
| **職務範囲** | 職務記述書で限定 | 包括的（異動・配転あり） |
| **異動** | 本人同意が原則 | 会社主導の人事異動 |
| **賃金** | 職務の価値に基づく（職務給） | 人の能力・年功に基づく |
| **育成** | 自律的キャリア開発 | 会社主導のローテーション・OJT |
| **雇用保障** | 職務消滅で解雇の可能性 | 高い雇用安定性 |
| **評価** | 職務の成果（アウトプット） | 能力・態度・プロセスも含む |

## 日本企業の導入動向

| 背景 | 内容 |
|---|---|
| **専門人材の確保** | DX・AI等の高度専門人材を市場価値に見合う処遇で採用 |
| **同一労働同一賃金** | 2020年施行の法改正がジョブ型への移行を後押し |
| **テレワークの普及** | コロナ禍で成果ベースの管理が求められるように |
| **グローバル対応** | 海外拠点との人事制度統合の必要性 |

## 導入時の課題

| 課題 | 内容 |
|---|---|
| **職務記述書の整備** | 全職務の分析・定義に多大な労力が必要 |
| **柔軟性の低下** | 職務外業務への対応が困難 |
| **育成機会の制限** | ローテーションによる幅広い経験が減少 |
| **日本的雇用慣行との摩擦** | 年功序列・終身雇用との両立が困難 |

## 図解

択一過去問の解説に掲載されていた図表。同キーワードの理解を補助する。

**表: ジョブ型雇用とメンバーシップ型雇用の比較**

| 概要 | ジョブ型雇用 | メンバーシップ型雇用 |
|---|---|---|
| 仕事の範囲 | 職務を明細化し（ジョブディスクリプション）、限定的・専門的 | 職務を規定せず、幅広く人材を採用・育成する（日本企業に多い） |
| 人材流動性 | 高い | 低い |
| 採用・配属 | 職務記述書（ジョブディスクリプション）に基づき適合人材を選ぶ人材を採用 | 配属組織のミッション等により決定、総合的 |
