# 技術士二次試験 総合技術監理部門 令和5年度 記述式

## 必須科目

**I-2** 次の問題について解答せよ。（指示された答案用紙の枚数にまとめること。）

近年，新型コロナウイルス感染症の流行，国際的な政情不安等，社会の様々なリスク要因が増加しつつある。またICTの急速な進展の成果等が利用可能となる反面，深刻な少子高齢化や労働力不足の加速化等，我が国の経済社会は大きく変化しつつある。不安定な時代にあって，組織を様々な視点から分析し，組織の持続的発展等に向けた戦略を適切に立案することは，総合技術監理部門の技術士など組織を総合的に俯瞰すべき者にとり，益々重要となってくるといえよう。

そこでここでは，SWOT分析の考えをベースにした組織分析，組織の戦略立案を行いたい。

SWOT分析は主に，経営・マーケティング分析で用いられてきた手法であるが，近年は行政機関でもこの手法を施策づくりに活用するなどの例が出てきている。組織の目的はその性質によって様々であり，例えば民間企業では「利益の最大化」などが考えられ，行政機関等では「公益の最大化」などが考えられる。その目的達成のための戦略立案に，SWOT分析が活用できるであろう。以下，この論文において実施するSWOT分析の手法について説明する（図1を参考にされたい）。

まずSWOT分析では，内部環境としての「強み（Strength）」と「弱み（Weakness）」，外部環境としての「機会（Opportunity）」と「脅威（Threat）」の4つの要因に着目し，それぞれに含まれる項目を特定する。本論文では，「内部環境（S：強み，W：弱み）」は組織の活動や努力によって変えうるものとし，例えば人材・設備・技術・ノウハウ等の組織の様々な経営資源や組織文化等の無形資源が考えられる。また「外部環境（O：機会，T：脅威）」は，取り上げた組織の活動や努力とは無関係又は変更が困難なものとし，例えばICTの進展等の技術的要因，景気動向等の経済的要因，法令・規制の変更等の政治的要因，人口動態やライフスタイルの変化等の社会的要因，顧客や市場の変化，競合他社の動向，などが考えられる。

S，W，O，Tそれぞれに含まれる主な項目を特定した次の段階として，各項目を掛け合わせるクロス分析により，様々な戦略を立案することが一般的に行われる。クロス分析のパターンとしては，以下の4つのパターンがあり，それぞれにおいて考えられる典型的な戦略の例を合わせて示す。

パターンA：（S：強み×O：機会）組織の強みがある領域に機会が生じたパターンであり，例えば活動の拡大や新規の活動への進出等の戦略が考えられる。

パターンB：（W：弱み×O：機会）組織の弱みがある領域に機会が生じたパターンであり，機会を活かせるようにするために，例えば外部からの補強や他組織との提携，経営資源の段階的な改善等の戦略が考えられる。

パターンC：（S：強み×T：脅威）組織の強みがある領域に脅威が生じたパターンであり，例えば製品・サービスの付加価値向上による差別化等の戦略が考えられる。

パターンD：（W：弱み×T：脅威）組織の弱みがある領域に脅威が生じたパターンであり，脅威を回避するために，例えば活動の縮小や撤退等の戦略が考えられる。

**図1　SWOTの4つの要因，4つのクロス分析のパターン及び戦略の例**

|  | 強み（S） | 弱み（W） |
|---|---|---|
|  | 項目S1，項目S2 | 項目W1，項目W2 |
| **機会（O）**　項目O1，項目O2 | パターンA：（強み×機会）拡大戦略，進出戦略など | パターンB：（弱み×機会）改善戦略，補強戦略，提携戦略など |
| **脅威（T）**　項目T1，項目T2 | パターンC：（強み×脅威）差別化戦略など | パターンD：（弱み×脅威）撤退戦略，縮小戦略など |

図2はある組織において，S，W，O，Tに含まれる項目から戦略のベースとなる項目の組合せを選定した例である。

**図2　SWOT分析の項目の組合せを選定した例**

|  | 強み（S） | 弱み（W） |
|---|---|---|
|  | S1：（例）知名度が高い | W1：（例）販売コストが高い |
|  | S2：（例）従業員の技術力が高い | W2：（例）人材確保が困難 |
| **機会（O）** |  |  |
| O1：（例）地域の急激な発展 | パターンA：（強み×機会）例：S2×O1をベースにした戦略 | パターンB：（弱み×機会）例：W2×O2をベースにした戦略 |
| O2：（例）特定分野のニーズの増大 |  |  |
| **脅威（T）** |  |  |
| T1：（例）競合他社の出現 | パターンC：（強み×脅威）例：S1×T1をベースにした戦略 | パターンD：（弱み×脅威）例：W1・W2×T1をベースにした戦略 |
| T2：（例）特定素材の価格高騰 |  |  |

以上を踏まえ，総合技術監理の視点に留意しつつ，以下の（1）〜（3）の問いに答えよ。

なお総合技術監理の視点とは，「業務全体を俯瞰し，経済性管理，安全管理，人的資源管理，情報管理，社会環境管理に関する総合的な分析，評価に基づいて，最適な企画，計画，実施，対応等を行う。」立場からの視点をいう。なお，書かれた論文を評価する際，考察における視点の広さ，記述の明確さと論理的なつながり，そして論文全体のまとまりを特に重視する。

## （1）組織の概要

本論文においてあなたが取り上げる組織について，以下の問いに答えよ。

ここでの「組織」は，継続的に事業やプロジェクトを実施する機能を有する「組織」のことであり，組織が取り扱う事業やプロジェクトそのものではないことに留意されたい。また取り上げる組織としては，組織体全体でもよいし，その一部を構成する「事業部」，「地方組織」などの単位で自由に設定してもよい。

（問い（1）については，答案用紙1枚以内にまとめよ。）

1. 取り上げる組織の概要及び組織の役割を記せ。
2. この組織における経営資源（人材・設備・技術・ノウハウ等），及びアウトプット（この組織が創出する製品・構造物・サービス・技術・政策等）を記せ。
3. この組織の主要な業務プロセス（経営資源によりアウトプットを創出する過程の代表例）を記せ。

## （2）SWOT分析の項目

取り上げた組織に関する，S：強み，W：弱み，O：機会，T：脅威の4つの要因について，「それぞれ2項目ずつ」を挙げ，各項目の具体的内容を記せ（合計8項目を記載すること）。

（問い（2）については，答案用紙を替えたうえで，答案用紙1枚以内にまとめよ。）

S1：（強みの1つめの記載）

S2：（強みの2つめの記載）

W1：（弱みの1つめの記載）

・・・

以下同様に，SWOTの順で記載すること。

## （3）戦略の立案

近い将来（概ね今後5年以内）の実現を図ることを目標とし，「組織が何をすべきか（What），そのためにどう具体的に行動するか（How）」を主体とした「戦略」を立案したい。

ここでは，パターンA，B，C，Dから異なる3つのパターン（例えば，A，B及びD）を選択し，選んだ3つのパターンそれぞれについて，項目の組合せを選び，それらをベースとした戦略を考える（計3つの戦略を立案する）。項目の組合せを選ぶに当たり，S，W，O，Tのそれぞれについて問い（2）で記した2つの項目から1項目のみを組合せに用いてもよいし，2項目の両方を用いてもよい。

上記に留意し，以下の問いに答えよ。

（問い（3）については，3つの戦略それぞれについて，答案用紙を替えたうえで，1枚以内にまとめよ。）

1. 戦略のベースとなる項目の組合せ及び戦略が目指す目標を簡潔に記せ。（なお項目の組合せについては，例えば「S1」と「O2」の組合せを選んだ場合，（S1×O2）と記し，「W1及びW2」と「T1」の組合せの場合は（W1・W2×T1）のように記す。続いて戦略が目指す目標を記す。）
2. この目標を達成するための，戦略の具体的な方策（組織が何をすべきか，どう行動するか）について記せ。
3. この戦略を今後5年以内に実現するに当たり直面する障害とその克服策を，総合技術監理の視点から記せ。（異なる総合技術監理分野のトレードオフに留意すること。）

## 模範論文例

### 問い（1）への解答：組織の概要

<details>
<summary>模範解答を見る（答案1枚目）</summary>

**① 組織概要及び役割**

取り上げる組織は、都市部の鋼道路橋の新設及び維持管理を行う組織である。役割は、鋼道路橋の新設及び維持管理の設計・製作・施工を行うことである。組織の役割は、適切な維持管理による交通流の円滑化、長寿命化により国民経済の健全な発展と国民生活の向上である。

**② 経営資源及びアウトプット**

1) **経営資源**: 鋼道路橋の設計・製作・施工・維持管理技術及び技術者、鋼材の切断や組立てを行う製作工場、維持管理業務の点検を行う3Dレーザースキャナ等である。
2) **アウトプット**: 鋼道路橋の設計図書、ブロック割りした工場製作物、施工計画書、点検・診断結果、損傷箇所の補強構造の設置等である。また、交通流の円滑化によるCO2の排出抑制、長寿命化による建設廃棄物の発生抑制等のサービスも提供している。

**③ 業務プロセス**

発注者より鋼道路橋の新設及び維持管理を受注し、経営資源からアウトプットを創出する。新設では設計したものをもとに工場でブロック割を製作し、現地で組み立てる。維持管理業務では、点検・診断から損傷箇所への補強構造を設計し、現地で設置する。

</details>

### 問い（2）への解答：SWOT分析の項目

<details>
<summary>模範解答を見る（答案2枚目）</summary>

以下に取り上げた組織の4つの要因について、それぞれ2項目ずつ挙げる。

- **強みS1**: 新設及び維持管理の設計・製作・施工まで全て1つの組織で完結可能である。
- **強みS2**: き裂等の損傷部に補強構造設置の際、交通流の円滑化のため、供用しながら施工可能など高難度工事に対応可能である。
- **機会O1**: 鋼道路橋の過酷な使用状況に加え、建設後40年以上経過していることからインフラ老朽化が加速し、「地域の守り手」としての需要が増大している。
- **機会O2**: ICT技術の急速な進展に伴い、ICT技術を活用した生産性向上が期待されている。
- **弱みW1**: 建設産業の危険・汚い・きついというイメージやその他若者の就職に対する嗜好の変化等により担い手が不足している。
- **弱みW2**: 組織の年齢構成は、55才以上が1/3を占め今後10年以内に退職することが想定され、若年就業者は1割程度であることから技術の継承が困難となっている。
- **脅威T1**: 少子高齢化の進展に伴い、若年就業者の確保が困難となっている。
- **脅威T2**: 今後新たなウイルスの感染拡大はいつ発生してもおかしくなく、出勤が困難となったり、業務の実施が困難となる可能性が考えられる。

</details>

### 問い（3）への解答：戦略の立案

<details>
<summary>模範解答を見る（答案3枚目：O1・O2 × W1 — i-bridgeの推進）</summary>

**① 組合せ：O1・O2 × W1**

**目標**: インフラ老朽化の加速で需要が増大しているが、担い手が不足しているため、急速に発達しているICT技術で担い手不足を補い生産性を向上させることが目標である。

**② 方策**

目標を達成するための方策は、i-bridgeを推進することである。具体的には、鋼道路橋の生産プロセスである設計・製作・施工・維持管理においてICT技術等を活用し、生産性を向上させることである。設計では、3次元CADを使用し、部材同士の干渉確認を実施し、製作では、現場でブロック割した製作物を組立てるが、手戻りを防ぐため、工場で仮組を行うが工場製作の1/5を占めることからシミュレーション仮組立を実施する等している。

**③ 障害と克服策**

1) **経済性管理**: ICT機器の購入や生産システムの開発には多額の初期投資と開発期間がかかるリスクがある。そのため、中長期的な視点で収益をプラス方向へ改善していく人材育成が必要である。
2) **人的資源管理**: ICT機器の扱いには、従来の土木技術とは異なる技術が必要なため、習得するのに却って長時間労働となるリスクがある。そのため、ダイバーシティを推進し、ICT技術等に精通した多様な人材を採用する。

</details>

<details>
<summary>模範解答を見る（答案4枚目：T1 × W2 — 働き方改革・ナレッジマネジメント）</summary>

**① 組合せ：T1 × W2**

**目標**: 組織の年齢構成が、55才以上が1/3を占め、若年就業者が1割程度である中で、いかに技術を継承していくかが目標である。また、少子高齢化が進行する中でいかに若年者の就業を支援するかが目標である。

**② 方策**

目標を達成するための方策は、働き方改革の推進である。働き方改革により長時間労働の正、週休2日制の導入等により若年者の就業を支援していく。また、技術を継承していくための方策はナレッジマネジメントの推進である。具体的には熟練技術者の持つ経験やノウハウといった暗黙知を形式知に変換し、経験が浅い若手技術者でも分かり易く、いつでも学べるeラーニング等の整備を行う。

**③ 障害と克服策**

1) **情報管理**: 熟練技術者の持つ暗黙知を形式知に変換するには、熟練技術者の作業状況をAIで分析し、ICT技術と融合させ経験が浅い技術者の教育訓練に活用する必要がある。
2) **経済性管理**: 一方で、開発には多額の初期投資と開発期間がかかるリスクがあるため、中長期的な展望で収益がプラスとなるように計画を立て実施していく。

</details>

<details>
<summary>模範解答を見る（答案5枚目：T2 × W1 — テレワークの推進）</summary>

**① 組合せ：T2 × W1**

**目標**: コロナ感染症により出勤困難で担い手が不足する中で、業務を継続していくことが目標である。

**② 方策**

目標を達成するための方策は、テレワークの推進である。テレワークでは、自宅やサテライトオフィスなど就業場所を選ばず就業することが可能となり多様な人材を担い手として確保することが可能となる。

**③ 障害と克服策**

1) **安全管理**: コロナ感染症が流行する中で、無理に出勤する必要がなくなり安全性が確保される。一方で、勤務時間の把握が困難となるため、働き過ぎによる過重労働のリスクがある。管理職による労働時間の確認方法の構築や健康管理への配慮が必要である。
2) **情報管理**: PCやネット環境があれば自宅など就業場所を選ばず就業可能であるが、PC持ち出し時に電車内へ置き忘れや盗難被害にあった場合、業務情報が流出するリスクが高くなる。また、ウイルス感染による情報流出リスクもある。対策としては、情報管理マニュアルを整備し、教育訓練を実施しリスクを低減していく必要がある。また使用パソコンについては最新のウイルス対策ソフトをインストールする。

</details>
