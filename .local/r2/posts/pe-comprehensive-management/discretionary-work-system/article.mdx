# 裁量労働制

## 裁量労働制とは

裁量労働制とは、業務の性質上その遂行方法を大幅に労働者の裁量に委ねる必要がある業務について、実際の労働時間にかかわらず労使協定や労使委員会の決議で定めた時間を労働したとみなす制度である。

労働基準法に基づく「みなし労働時間制」の一種であり、専門業務型と企画業務型の2種類がある。

2024年4月の改正により、専門業務型では本人同意の取得と同意撤回手続の整備が新たに義務化された。

## 2つの類型

| 項目 | 専門業務型裁量労働制 | 企画業務型裁量労働制 |
|---|---|---|
| **根拠条文** | **労基法第38条の3** | 労基法第38条の4 |
| **対象業務** | 法令で定める20業務（研究開発、デザイン、SE等） | 事業運営の企画・立案・調査・分析業務 |
| **対象事業場** | 制限なし | 本社・本店等の事業運営に関する企画業務がある事業場 |
| **導入手続** | 労使協定の締結＋届出 | 労使委員会の設置＋委員の4/5以上の決議＋届出 |
| **本人同意** | 必要（2024年4月〜） | 必要 |
| **同意撤回** | 手続整備が必要（2024年4月〜） | 手続整備が必要 |

## 専門業務型の対象業務（主な例）

| 分野 | 対象業務の例 |
|---|---|
| **研究・開発** | 新商品・新技術の研究開発 |
| **情報処理** | 情報処理システムの分析・設計 |
| **デザイン** | 衣服・室内装飾等のデザイン考案 |
| **メディア** | 放送番組・映画のプロデューサー・ディレクター |
| **士業** | 弁護士、公認会計士、税理士、弁理士等 |
| **コンサルティング** | 経営コンサルタント |

## 導入要件の比較

| 要件 | 専門業務型 | 企画業務型 |
|---|---|---|
| **労使協定/決議** | 労使協定 | 労使委員会の4/5以上の決議 |
| **届出** | 労働基準監督署に届出 | 労働基準監督署に届出 |
| **みなし労働時間** | 協定で定める | 決議で定める |
| **健康・福祉確保措置** | 協定に定める | 決議に定める |
| **苦情処理** | 協定に定める | 決議に定める |
| **有効期間** | 協定に定める | 3年以内が望ましい |
| **定期報告** | 不要（2024年改正で廃止） | 6か月以内ごとに1回 |

## 運用上の留意点

| 留意点 | 内容 |
|---|---|
| **みなし時間の設定** | 実態とかけ離れた短時間設定は違法となりうる |
| **深夜・休日労働** | みなし制の適用外であり、実労働時間に基づく割増賃金が必要 |
| **健康管理** | 労働時間の状況把握と健康確保措置が義務 |
| **対象業務の限定** | 対象外の業務に適用すると制度自体が無効 |
| **本人同意の撤回** | 撤回した場合の配置転換等の不利益取扱いは禁止 |

## 制度成立の経緯

裁量労働制は、1985年（昭和60年）の労働基準法研究会最終報告を契機に立案された。同報告は、技術革新と経済のサービス化・情報化の進展を踏まえ、「業務遂行の方法や時間配分を労働者に委ねる必要がある業務については、実労働時間によるのではなくみなし時間制を認めるべき」と提言した。

これを受けて1987年（昭和62年）の労働基準法改正において**専門業務型裁量労働制**（労基法第38条の3）が新設され、翌1988年（昭和63年）4月に施行された。当初の対象業務は研究開発、情報処理システムの分析・設計など数業種に限定されていた。

1998年（平成10年）の法改正では、経済の高度化・複雑化に伴う本社機能の重要性の高まりを背景に、事業の企画・立案・調査・分析業務を対象とする**企画業務型裁量労働制**（労基法第38条の4）が追加され、2000年（平成12年）4月に施行された。企画業務型は労使委員会の4/5以上の決議という厳格な手続きを必要とし、現場裁量より経営判断に近い職務を対象とする点が専門業務型との大きな違いである。

その後も対象業務の範囲は段階的に拡大し、2024年（令和6年）4月の改正では、働き方改革の観点から専門業務型に本人同意の取得と同意撤回手続の整備が義務化された。制度の重心が「事業主の管理コスト削減」から「労働者の自律的な働き方の支援」へと移行しつつある現在の方向性を示している。

## 総合技術監理における位置づけ

総合技術監理キーワード集では[**3.2 労働関係法と労務管理**](/docs/pe-comprehensive-management-keyword-2026#32-労働関係法と労務管理)に位置づけられる。

裁量労働制は高度な専門性を持つ人材の自律的な働き方を支援する制度であり、人的資源管理における人材活用の重要な選択肢である。

一方で、みなし時間と実労働時間の乖離による健康リスク（安全管理）、対象業務の適正な限定（社会環境管理・コンプライアンス）など、複数の管理分野にまたがる課題への対応が求められる。
