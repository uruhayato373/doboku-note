# WEBサービス

## WEBサービスとは

WEBサービスとは、インターネット上の標準プロトコル（HTTP等）を利用して、異なるシステム間でデータや機能を相互にやり取りする仕組みの総称である。

SOA（サービス指向アーキテクチャ）の考え方に基づき、個々の機能をサービスとして公開し、ネットワーク経由で呼び出すことで、システム間連携の柔軟性と再利用性を高める。

WEBサービスは企業の業務システム統合、公共データの公開（オープンデータ）、モバイルアプリケーションのバックエンドなど、幅広い領域で活用されている。

### SOAP と REST の比較

WEBサービスの実装方式として、SOAPとRESTが代表的である。

| 項目 | SOAP | REST |
|---|---|---|
| **プロトコル** | 独自のSOAPプロトコル（XML） | HTTPメソッド（GET, POST, PUT, DELETE） |
| **データ形式** | XML | JSON（XML も可） |
| **記述の複雑さ** | WSDLによる厳密な定義が必要 | シンプルなURL設計で記述容易 |
| **トランザクション** | WS-Transactionで対応 | 標準的な仕組みなし |
| **セキュリティ** | WS-Securityで標準化 | HTTPS + OAuthなど |
| **適用場面** | 金融・医療など厳密性が求められる分野 | Web・モバイルアプリケーション全般 |
| **現在の主流度** | レガシーシステムで残存 | 新規開発の主流 |

### API エコノミーとマイクロサービス

APIを外部に公開し、他社サービスと連携することで新たな価値を創出する仕組みを **APIエコノミー** と呼ぶ。

**マイクロサービスアーキテクチャ** は、大規模なシステムを独立した小さなサービスの集合体として構築する設計手法であり、各サービスはRESTful APIやメッセージキューを通じて疎結合に連携する。

これにより、サービスごとの独立した開発・デプロイ・スケーリングが可能となり、システム全体の変更柔軟性が向上する。

### WEBサービスの関連技術

| 技術 | 概要 |
|---|---|
| **XML / JSON** | データ記述・交換フォーマット |
| **WSDL** | WEBサービスのインタフェース記述言語（SOAP用） |
| **UDDI** | WEBサービスの登録・検索ディレクトリ |
| **OAuth 2.0** | API利用時の認可プロトコル |
| **OpenAPI (Swagger)** | RESTful APIの仕様記述標準 |
| **GraphQL** | Facebook が開発したクエリ言語（RESTの代替） |
| **gRPC** | Google が開発した高速RPC フレームワーク |
