# ビジネスインテリジェンス（BI）

## BIとは

ビジネスインテリジェンス（Business Intelligence: BI）とは、企業が蓄積する大量のデータを収集・統合・分析し、経営上の意思決定を支援する手法・技術・ツールの総称である。

BIは単なるデータ分析ツールではなく、データウェアハウス（DWH）への蓄積からレポーティング・ダッシュボードによる可視化まで、一連のプロセスを包含する概念である。

意思決定支援システム（DSS）の発展形として位置づけられ、現在ではセルフサービスBIとして現場の担当者が自らデータ分析を行う形態が主流となっている。

### BIの主要機能と構成要素

| 構成要素 | 役割 | 具体例 |
|---|---|---|
| ETL | データの抽出・変換・ロード | Talend, Informatica |
| データウェアハウス（DWH） | 分析用データの統合蓄積基盤 | Snowflake, BigQuery, Redshift |
| OLAP | 多次元分析（スライス・ダイス・ドリルダウン） | SSAS, Mondrian |
| レポーティング | 定型帳票・定期レポートの自動生成 | Crystal Reports, SSRS |
| ダッシュボード | KPIの可視化・リアルタイム監視 | Tableau, Power BI, Looker |
| データマイニング | パターン発見・予測分析 | R, Python, SAS |

### OLAP分析の操作

OLAP（Online Analytical Processing）はBIの中核的な分析手法であり、多次元データベースを用いた以下の操作が特徴である。

| 操作 | 内容 |
|---|---|
| スライス | 多次元データの特定の断面を切り出す |
| ダイス | 複数の次元を組み合わせたサブキューブを抽出する |
| ドリルダウン | 集計データからより詳細なレベルへ掘り下げる |
| ドリルアップ | 詳細データからより上位の集計レベルへ集約する |
| ピボット | 分析軸を入れ替えてデータを別の角度から観察する |

### BIとデータ分析の発展段階

| 段階 | 分析の問い | 代表的手法 |
|---|---|---|
| 記述的分析 | 何が起きたか | レポーティング、ダッシュボード |
| 診断的分析 | なぜ起きたか | OLAP、ドリルダウン分析 |
| 予測的分析 | 何が起きるか | 機械学習、統計モデル |
| 処方的分析 | どうすべきか | 最適化アルゴリズム、シミュレーション |
