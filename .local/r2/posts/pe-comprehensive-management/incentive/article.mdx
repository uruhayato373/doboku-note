# インセンティブ

## インセンティブとは

**インセンティブ（Incentive）** とは、個人や集団の行動を特定の方向へ誘導するための誘因・刺激のことである。

経済学では「合理的な行為者が報酬や罰に応じて行動を選択する」という前提に基づき、組織管理では従業員の動機付けと成果向上のための制度設計として活用される。

チェスター・バーナードは組織均衡理論において、組織が存続するためにはメンバーへの「誘因（インセンティブ）」がメンバーの「貢献」を上回る必要があると論じた。

### インセンティブの分類

| 分類基準 | 種類 | 内容 | 具体例 |
|---|---|---|---|
| **金銭的・非金銭的** | 金銭的インセンティブ | 報酬・手当・賞与など経済的対価 | 成果給、業績ボーナス、ストックオプション |
|  | 非金銭的インセンティブ | 承認・成長機会・職場環境など | 表彰、昇進機会、裁量権の付与、福利厚生 |
| **正・負** | 正のインセンティブ | 望ましい行動への報酬 | 目標達成時のボーナス、資格取得支援 |
|  | 負のインセンティブ | 望ましくない行動への罰・不利益 | 減給、降格、ペナルティ |
| **個人・集団** | 個人インセンティブ | 個人の成果に連動 | 個人業績給、営業歩合 |
|  | 集団インセンティブ | チームや組織の成果に連動 | 部門業績賞与、利益配分制度 |

### バーナードの誘因理論

バーナードは組織が提供する誘因を以下の4つに分類した。

| 誘因の種類 | 内容 |
|---|---|
| **物質的誘因** | 金銭、物品など経済的な報酬 |
| **個人的で非物質的な機会** | 威信、権力、地位など個人的な満足 |
| **好ましい物的条件** | 快適な職場環境、労働条件 |
| **理想の恩恵** | 組織の使命・理念への共感、社会貢献の実感 |

### インセンティブ制度の設計原則

| 設計原則 | 内容 |
|---|---|
| **明確性** | 何をすれば報酬が得られるかが具体的に示されていること |
| **公平性** | 貢献に見合った報酬配分がなされること |
| **即時性** | 行動と報酬の時間的距離が短いこと |
| **個別適合性** | メンバーの価値観やニーズに合った誘因であること |
| **持続可能性** | 組織の財務的・運営的に継続可能な設計であること |

### インセンティブの副作用

| 副作用 | 内容 |
|---|---|
| **アンダーマイニング効果** | 外的報酬が内発的動機を低下させる現象 |
| **短期志向の助長** | 成果指標に直結する行動のみに注力し、長期的な価値創造が軽視される |
| **モラルハザード** | 成果の捏造やフリーライダーの発生 |
| **過度な競争** | 個人インセンティブがチーム協力を阻害する |
| **指標のゆがみ** | 測定しやすい指標のみが追求され、測定困難な重要業務が無視される |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**3.1 人の行動と組織**」に位置づけられる。

インセンティブ設計は人的資源管理の中核であると同時に、経済性管理（報酬コストと生産性のバランス）や安全管理（安全行動への正のインセンティブ）とも密接に関連する。

総合技術監理技術者は、金銭的報酬だけでなく非金銭的な誘因も含めた総合的なインセンティブ設計を行い、副作用（アンダーマイニング効果、短期志向など）にも配慮する視点が求められる。
