# メンタルヘルスケア

## メンタルヘルスケアとは

メンタルヘルスケアとは、労働者の心の健康の保持増進を目的とした組織的な取組をいう。

厚生労働省は「労働者の心の健康の保持増進のための指針」（メンタルヘルス指針、2006年策定）において、事業者が継続的かつ計画的に実施すべきメンタルヘルスケアの基本的な枠組みを示している。

精神障害に関する労災請求件数は増加傾向にあり、職場におけるメンタルヘルス対策の重要性が年々高まっている。

## 4つのケア

| ケア | 実施主体 | 内容 |
|---|---|---|
| **セルフケア** | 労働者本人 | ストレスへの気づき、ストレスへの対処、自発的な相談 |
| **ラインによるケア** | 管理監督者 | 職場環境の改善、部下の相談対応、異変への気づきと対応 |
| **事業場内産業保健スタッフ等によるケア** | 産業医・衛生管理者・保健師等 | 心の健康づくり計画の策定、個人への相談対応、管理監督者への支援 |
| **事業場外資源によるケア** | 外部EAP・医療機関等 | 専門的カウンセリング、復職支援プログラム、情報提供 |

## 予防段階

| 段階 | 名称 | 内容 |
|---|---|---|
| **一次予防** | 未然防止・健康増進 | ストレスチェック、職場環境改善、教育研修 |
| **二次予防** | 早期発見・早期対応 | 相談体制の整備、管理監督者による気づき |
| **三次予防** | 治療・復帰支援 | 職場復帰支援プログラム、再発防止 |

## ストレスチェック制度

2015年12月に義務化されたストレスチェック制度は、メンタルヘルス不調の一次予防を目的とする。

| 項目 | 内容 |
|---|---|
| **根拠法令** | **労働安全衛生法第66条の10** |
| **対象事業場** | 常時50人以上の労働者を使用する事業場（50人未満は努力義務） |
| **実施頻度** | 1年以内ごとに1回 |
| **実施者** | 医師、保健師等 |
| **調査項目** | 仕事のストレス要因、心身のストレス反応、周囲のサポート |
| **高ストレス者** | 医師による面接指導を実施（本人の申出が必要） |
| **集団分析** | 職場ごとの集団的分析と職場環境改善への活用（努力義務） |

## 事業者が策定すべき計画

| 計画項目 | 内容 |
|---|---|
| **心の健康づくり計画** | 事業場の方針、目標、体制、具体的な取組内容 |
| **衛生委員会での調査審議** | メンタルヘルス対策の計画・実施状況を審議 |
| **教育研修** | 管理監督者向け研修、労働者向けセルフケア研修 |
| **相談体制** | 社内相談窓口、外部EAP（従業員支援プログラム）の整備 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では[**3.2 労働関係法と労務管理**](/docs/pe-comprehensive-management-keyword-2026#32-労働関係法と労務管理)に位置づけられる。

メンタルヘルスケアは人的資源管理（人材の確保・定着）と安全管理（労働者の健康確保・労災防止）の双方に深く関わるテーマである。

長時間労働の是正（経済性管理とのトレードオフ）、ハラスメント防止（社会環境管理）、職場復帰支援プログラムの運用など、総合技術監理者には複数の管理分野を統合した対策の推進が求められる。
