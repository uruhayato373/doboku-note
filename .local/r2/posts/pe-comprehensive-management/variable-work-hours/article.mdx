# 変形労働時間制度

## 変形労働時間制度とは

変形労働時間制度とは、一定の期間を平均して1週間あたりの労働時間が法定労働時間（40時間）を超えない範囲で、特定の日や週に法定労働時間を超えて労働させることができる制度である。

業務の繁閑に応じた労働時間の配分を可能にし、総労働時間を増やすことなく効率的な働き方を実現する仕組みとして、労働基準法に規定されている。

建設業や製造業など季節的・時期的に業務量が変動する業種で広く活用されている。

## 変形労働時間制度の種類

| 制度 | 根拠条文 | 変形期間 | 導入要件 | 主な適用業種 |
|---|---|---|---|---|
| **1か月単位** | **労基法第32条の2** | 1か月以内 | 労使協定または就業規則 | 交替制勤務、病院、警備等 |
| **1年単位** | 労基法第32条の4 | 1か月超1年以内 | 労使協定＋届出 | 建設業、製造業、小売業等 |
| **1週間単位** | 労基法第32条の5 | 1週間 | 労使協定＋届出 | 小規模小売業・旅館・料理店（30人未満） |

## 1か月単位の変形労働時間制

| 項目 | 内容 |
|---|---|
| **変形期間** | 1か月以内 |
| **導入手続** | 労使協定または就業規則への規定 |
| **労働時間の上限** | 変形期間を平均して週40時間以内 |
| **シフト** | 各日・各週の労働時間をあらかじめ特定 |
| **時間外労働** | あらかじめ定めた時間を超えた部分が時間外 |

## 1年単位の変形労働時間制

| 項目 | 内容 |
|---|---|
| **変形期間** | 1か月超1年以内 |
| **導入手続** | 労使協定の締結＋労働基準監督署への届出 |
| **1日の労働時間上限** | 10時間 |
| **1週の労働時間上限** | 52時間 |
| **連続労働日数** | 原則6日以内（特定期間は12日以内） |
| **対象労働者** | 対象期間中の途中採用者・退職者は実労働期間で精算 |

## 1週間単位の非定型的変形労働時間制

| 項目 | 内容 |
|---|---|
| **対象事業場** | 常時30人未満の小売業・旅館・料理飲食店 |
| **1日の労働時間上限** | 10時間 |
| **シフト通知** | 少なくとも1週間前に書面で各日の労働時間を通知 |

## 導入時の共通留意点

| 留意点 | 内容 |
|---|---|
| **事前特定の原則** | 各日・各週の労働時間をあらかじめ具体的に定める |
| **割増賃金** | 所定時間を超える部分には時間外割増賃金が必要 |
| **適用除外** | 18歳未満の年少者には原則適用不可 |
| **育児・介護配慮** | 育児・介護を行う者への配慮が求められる |
| **健康確保** | 長時間の所定労働日が続かないよう配慮 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では[**3.2 労働関係法と労務管理**](/docs/pe-comprehensive-management-keyword-2026#32-労働関係法と労務管理)に位置づけられる。

変形労働時間制度は業務の繁閑に合わせた効率的な人員配置（経済性管理）と、労働者の健康確保・過重労働防止（安全管理）のバランスが求められる制度である。

建設プロジェクトでは工期と作業量の変動が大きいため、1年単位の変形労働時間制の適切な運用が総合技術監理者にとって重要な実務課題となる。
