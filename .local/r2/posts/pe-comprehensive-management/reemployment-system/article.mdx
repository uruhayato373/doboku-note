# 再雇用制度

## 再雇用制度とは

**再雇用制度**とは、定年に達した従業員を一旦退職させた上で、新たな労働条件で再び雇用する制度である。高年齢者雇用安定法に基づく継続雇用制度の最も一般的な形態であり、約8割の企業が採用している。

## 勤務延長制度との比較

| 項目 | 再雇用制度 | 勤務延長制度 |
|---|---|---|
| **雇用関係** | 一旦終了→再締結 | 継続（退職なし） |
| **労働条件** | 新条件で再契約（変更が容易） | 原則従前の条件を維持 |
| **退職金** | 定年時に支給 | 延長終了時に支給 |
| **採用比率** | 約80%の企業が採用 | 約10%の企業が採用 |
| **契約形態** | 有期契約（1年更新が多い） | 正社員のまま |

## 再雇用の労働条件

| 項目 | 一般的な設計 |
|---|---|
| **賃金** | 定年時の50〜70%程度（企業による） |
| **役職** | 管理職から外れ、専門職・嘱託等 |
| **勤務形態** | フルタイムまたは短時間勤務 |
| **契約期間** | 1年更新の有期契約（65歳まで） |
| **業務内容** | 従前の経験を活かした業務 |

## 同一労働同一賃金との関係

最高裁判例（長澤運輸事件・2018年）では、定年後再雇用者の賃金引下げについて「不合理な待遇差」に当たるかが争点となった。基本給・賞与の一定の減額は許容されるが、精勤手当の不支給は不合理と判断された。

## 建設業における再雇用

| 観点 | 内容 |
|---|---|
| **技能伝承** | ベテラン技術者による若手への技術指導が最大の目的 |
| **人材不足対応** | 深刻な人手不足の中、熟練者の戦力維持 |
| **安全配慮** | 高齢者の体力低下に応じた業務配置と安全対策 |
| **資格活用** | 監理技術者・主任技術者の資格保有者の活用 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**3.3 人的資源の活用**」に位置づけられる。

再雇用制度は継続雇用制度の中核であり、高齢者の人的資源活用・技能伝承・セカンドキャリアと密接に関連する。
