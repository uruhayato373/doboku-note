# 設備総合効率

## 設備総合効率（OEE）とは

設備総合効率（OEE: Overall Equipment Effectiveness）とは、設備がどれだけ有効に活用されているかを総合的に評価する指標である。

OEEはTPM（Total Productive Maintenance：全員参加の生産保全）活動において中核的な管理指標として広く用いられている。

OEEを構成する3つの要素は、時間稼働率・性能稼働率・良品率であり、これらの積で算出される。

### 計算式

$$OEE = \text{時間稼働率} \times \text{性能稼働率} \times \text{良品率}$$

各要素の定義は以下のとおりである。

| 要素 | 計算式 | 意味 |
|---|---|---|
| 時間稼働率 | $\frac{\text{稼働時間}}{\text{負荷時間}}$ | 設備が停止せずに動いていた時間の割合 |
| 性能稼働率 | $\frac{\text{基準サイクルタイム} \times \text{加工数量}}{\text{稼働時間}}$ | 設備が本来の能力で動いていた割合 |
| 良品率 | $\frac{\text{加工数量} - \text{不適合品数}}{\text{加工数量}}$ | 生産した製品のうち良品の割合 |

ここで負荷時間は、1日の操業時間から計画停止時間を差し引いた時間である。

稼働時間は、負荷時間から停止ロス（故障・段取・調整等）を差し引いた時間である。

### 計算例

ある設備の1日の稼働データが以下のとおりであるとする。

| 項目 | 値 | 備考 |
|---|---|---|
| 操業時間 | 480分 | 1日の総時間 |
| 計画停止時間 | 20分 | 朝礼・定期点検等、最初から稼働に含めない時間 |
| 停止ロス | 40分 | 故障・段取・調整による停止 |
| 基準サイクルタイム | 0.5分/個 | |
| 加工数量 | 700個 | |
| 不適合品数 | 14個 | |

1. 負荷時間 = 480 − 20（計画停止）= **460分**
2. 稼働時間 = 460 − 40（故障・段取）= **420分**
3. 時間稼働率 = 420 / 460 = **91.3%**
4. 性能稼働率 = 0.5 × 700 / 420 = **83.3%**
5. 良品率 = (700 − 14) / 700 = **98.0%**

$$OEE = 0.913 \times 0.833 \times 0.980 = 0.745 \quad (74.5\%)$$

### 7大ロスとOEEの関係

OEEの向上は、設備に関する7大ロスの削減によって達成される。

| 分類 | ロスの種類 | 影響する要素 |
|---|---|---|
| 停止ロス | 故障ロス | 時間稼働率 |
| 停止ロス | 段取・調整ロス | 時間稼働率 |
| 速度ロス | 空転・チョコ停ロス | 性能稼働率 |
| 速度ロス | 速度低下ロス | 性能稼働率 |
| 不良ロス | 不良・手直しロス | 良品率 |
| 不良ロス | 立上りロス | 良品率 |
| 停止ロス | 刃具交換ロス | 時間稼働率 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**2.6 設備管理**」に位置づけられる。

設備総合効率は、設備の信頼性（MTBF）・保全性（MTTR）が時間稼働率に、設備の状態管理が性能稼働率に、品質管理が良品率にそれぞれ反映される統合指標である。

設備管理の成果を定量的に示すKPIとして、設備投資の効果検証や保全方式の妥当性評価に広く活用される。
