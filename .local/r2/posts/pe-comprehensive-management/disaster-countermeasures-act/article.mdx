# 災害対策基本法

## 災害対策基本法とは

災害対策基本法とは、**昭和36年（1961年）に制定された、日本の防災・災害対応の基本をなす法律**である。

伊勢湾台風（1959年）による甚大な被害を教訓に、国・都道府県・市町村・住民それぞれの責務と役割を明確にし、**総合的・計画的な防災行政の推進**を図ることを目的とする。

## 防災体制と計画の体系

### 防災基本計画

中央防災会議が作成する**国レベルの防災の基本計画**である。各省庁・指定公共機関（ライフライン事業者等）が作成する防災業務計画の上位計画として位置づけられる。

### 地域防災計画

都道府県・市町村の防災会議がそれぞれ作成する計画である。地域の実情に応じた災害予防・応急対策・復旧・復興の方針を定める。

| 計画 | 作成主体 |
|---|---|
| 防災基本計画 | 中央防災会議 |
| 都道府県地域防災計画 | 都道府県防災会議 |
| 市町村地域防災計画 | 市町村防災会議 |
| 防災業務計画 | 各省庁・指定公共機関 |

## 各主体の責務

災害対策基本法は、防災における各主体の責務を明確に規定している。

| 主体 | 責務 |
|---|---|
| 国 | 防災基本計画の作成、総合的・長期的な防災施策の実施 |
| 都道府県 | 市町村の実施する防災活動の援助・調整 |
| 市町村 | 基礎的地方公共団体として地域防災の実施主体 |
| 指定公共機関 | ライフライン等の被災時における継続・復旧義務 |
| 住民 | 自らの生命・財産を守るための措置と防災活動への協力 |

## 避難情報の体系（警戒レベル）

2021年の法改正により、避難情報が整理され**5段階の警戒レベル**と対応づけられた。

| 警戒レベル | 避難情報 | 対象・タイミング |
|---|---|---|
| レベル1 | 早期注意情報 | 危険の認識・確認段階 |
| レベル2 | 洪水注意報等 | ハザードマップ等で事前確認 |
| レベル3 | **高齢者等避難** | 避難に時間を要する高齢者・障がい者等が避難開始 |
| レベル4 | **避難指示** | 危険な場所にいる全員が避難（立退き避難） |
| レベル5 | **緊急安全確保** | 災害が発生・切迫し、立退き避難が困難な場合の緊急措置 |

## 南海トラフ地震臨時情報

南海トラフ地震臨時情報は、気象庁が南海トラフの想定震源域で一定規模以上の地震発生やプレート境界面の異常なずれを観測した際に発表する情報である。

| 情報の種類 | 発表の契機 |
|---|---|
| 調査中 | 観測・評価着手を開始した時点で発表 |
| **巨大地震注意** | 大規模地震の発生可能性が相対的に高まったと評価された場合 |
| **巨大地震警戒** | さらに高い可能性（M8.0以上の地震発生後等）と評価された場合 |

### 最も警戒する期間

**巨大地震警戒**が発表された場合、**最も警戒する期間は地震発生後1週間を基本**とする。1週間経過後も注意は継続するが、最大警戒レベルは段階的に解除される。

突発的な大規模地震が警戒情報なしに発生する可能性もあるため、**地震対策は基本的に突発地震への備えとして平時から実施する**ことが前提となっている。

## 総合技術監理における位置づけ

総合技術監理キーワード集では、災害対策基本法は「**5.5 危機管理**」に位置づけられている。

総合技術監理者として、組織・プロジェクトの危機管理計画を立案する際には、災害対策基本法に基づく防災体制（国・都道府県・市町村との役割分担）を理解した上で、事業継続計画（BCP）と地域防災計画との整合を図ることが求められる。
