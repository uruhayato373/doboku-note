# 名古屋議定書

## 名古屋議定書とは

**名古屋議定書**（Nagoya Protocol on Access and Benefit-sharing）とは、遺伝資源の取得の機会（Access）とその利用から生じる利益の公正かつ衡平な配分（Benefit-Sharing）に関する国際的なルールを定めた議定書である。

2010年10月、愛知県名古屋市で開催された生物多様性条約第10回締約国会議（COP10）で採択され、2014年に発効した。

生物多様性条約の3つの目的のうち「遺伝資源の利用から生じる利益の公正かつ衡平な配分（ABS）」を具体化するための法的枠組みである。

### 生物多様性条約（CBD）の3つの目的

| 目的 | 内容 |
|---|---|
| **1. 生物多様性の保全** | 生態系、種、遺伝子の3つのレベルでの多様性の保全 |
| **2. 持続可能な利用** | 生物多様性の構成要素の持続可能な利用 |
| **3. ABS（利益配分）** | 遺伝資源の利用から生じる利益の公正かつ衡平な配分 ← **名古屋議定書が具体化** |

### 名古屋議定書の主要規定

| 項目 | 内容 |
|---|---|
| **事前の情報に基づく同意（PIC）** | 遺伝資源の取得には、提供国の事前同意が必要 |
| **相互に合意する条件（MAT）** | 利益配分の条件について、提供者と利用者が相互に合意 |
| **利益配分の対象** | 金銭的利益（ロイヤルティ等）および非金銭的利益（技術移転、共同研究等） |
| **遵守の確保** | 各国はABSに関する法令を整備し、国内連絡窓口・監視制度を設置 |
| **伝統的知識** | 先住民・地域社会が保有する遺伝資源に関連する伝統的知識もABSの対象 |

### ABSの具体例

| 分野 | 事例 |
|---|---|
| **医薬品開発** | 途上国の植物から有効成分を発見し新薬を開発 → 提供国にロイヤルティを支払い |
| **農業** | 野生種の遺伝資源を品種改良に利用 → 種子バンクへのアクセスと技術移転 |
| **化粧品** | 伝統的に利用されてきた植物由来成分の商品化 → 地域社会への利益還元 |
| **バイオテクノロジー** | 微生物の遺伝資源を利用した酵素・素材開発 → 共同研究の実施 |

### 日本の対応

日本は2017年に名古屋議定書を締結した。

国内措置として「遺伝資源の取得の機会及びその利用から生じる利益の公正かつ衡平な配分に関する指針」（ABS指針）を策定し、日本の利用者が外国の遺伝資源を取得する際の手続きを規定している。
