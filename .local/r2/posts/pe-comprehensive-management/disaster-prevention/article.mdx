# 防災

## 防災とは

**防災**とは、災害を未然に防止し、災害が発生した場合における被害の拡大を防ぎ、および災害の復旧を図ることをいう（災害対策基本法第2条）。近年は「防災」に加えて「減災」「縮災」の概念も重視されている。

## 防災・減災・縮災

| 概念 | 内容 |
|---|---|
| **防災** | 災害の発生そのものを防ぐ（堤防、耐震化等） |
| **減災** | 災害は起こりうる前提で被害を最小化する（避難計画、BCP等） |
| **縮災** | 被災後の回復力を高めて被害期間を縮小する（レジリエンス） |

## 災害対策基本法と防災体制

| 項目 | 内容 |
|---|---|
| **災害対策基本法（1961年）** | 日本の防災法制の根幹（伊勢湾台風を契機に制定） |
| **中央防災会議** | 内閣総理大臣を会長とする防災に関する最高意思決定機関 |
| **防災基本計画** | 国の防災の基本方針（中央防災会議が策定） |
| **地域防災計画** | 都道府県・市町村が策定する地域の防災計画 |
| **地区防災計画** | 住民・事業者が自発的に策定する計画（2013年追加） |

## 自助・共助・公助

| 区分 | 内容 | 例 |
|---|---|---|
| **自助** | 自分の命は自分で守る | 備蓄、耐震化、避難行動 |
| **共助** | 地域・コミュニティで助け合う | 自主防災組織、避難支援 |
| **公助** | 行政による防災対策 | インフラ整備、救助・救援 |

## 建設業と防災

| 役割 | 内容 |
|---|---|
| **インフラ整備** | 堤防・ダム・砂防施設等の防災インフラの建設 |
| **耐震化** | 建築物・橋梁・トンネル等の耐震補強 |
| **応急復旧** | 災害時の道路啓開、仮設構造物の設置 |
| **災害協定** | 自治体との災害応急対策に関する協定締結 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**5.1 安全の概念**」に位置づけられる。

防災はレジリエンス・オールハザードアプローチ・BCP・危機管理と連動する安全管理の基盤概念であり、建設業はインフラ整備・応急復旧を通じて防災の中核的役割を担う。
