# パスワード強化

## 定義

**パスワード強化**とは、情報システムへの不正アクセスを防止するために、パスワードの設定・管理・運用に関するセキュリティレベルを向上させる取り組みの総称である。

パスワードは最も基本的な認証手段であるが、「使い回し」「単純な文字列」「漏洩後の放置」など不適切な管理が情報漏洩の主要因となっている。

近年はパスワードだけに依存しない**多要素認証（MFA）** や、パスワード自体を不要とする**パスワードレス認証**への移行が推進されている。

## 仕組み

### パスワード攻撃の手法

| 攻撃手法 | 内容 |
|---|---|
| **ブルートフォース攻撃（総当たり攻撃）** | すべての文字の組み合わせを順に試行する |
| **辞書攻撃** | 一般的な単語やよく使われるパスワードのリストを用いて試行する |
| **パスワードリスト攻撃** | 他のサービスから流出したID・パスワードの組み合わせを使い回して試行する |
| **レインボーテーブル攻撃** | ハッシュ値とパスワードの対応表を用いて逆引きする |
| **クレデンシャルスタッフィング** | 大量の流出認証情報を自動化ツールで複数サービスに試行する |
| **キーロガー** | キーボード入力を記録してパスワードを窃取する |

### パスワードの強度に影響する要素

| 要素 | 内容 |
|---|---|
| **文字数** | 長いほど総当たりに要する時間が指数関数的に増加する |
| **文字種** | 英大文字・小文字・数字・記号を組み合わせることで組み合わせ数が増大 |
| **推測困難性** | 辞書に載っている単語、名前、誕生日等を避ける |
| **一意性** | サービスごとに異なるパスワードを使用する |

## 種類・比較

### 認証方式の分類

| 認証要素 | 分類 | 具体例 |
|---|---|---|
| **知識情報（Something You Know）** | 第1要素 | パスワード、PIN、秘密の質問 |
| **所持情報（Something You Have）** | 第2要素 | ICカード、ワンタイムパスワード（OTP）トークン、スマートフォン |
| **生体情報（Something You Are）** | 第3要素 | 指紋、顔認証、虹彩認証、静脈認証 |

**多要素認証（MFA：Multi-Factor Authentication）** は、上記の異なる種類の要素を2つ以上組み合わせて認証する方式である。

**二段階認証**と混同されやすいが、二段階認証は同一種類の要素を2回使う場合も含む点が異なる。

### パスワードポリシーの推奨事項

| 項目 | 従来の推奨 | 現在の推奨（NIST SP 800-63B等） |
|---|---|---|
| **最小文字数** | 8文字以上 | 8文字以上（できれば15文字以上のパスフレーズ） |
| **文字種の強制** | 英大小文字・数字・記号を必須 | 強制は推奨しない（ユーザビリティを考慮） |
| **定期変更** | 90日ごとの強制変更 | 漏洩が判明した場合のみ変更（定期変更は推奨しない） |
| **パスワード履歴** | 過去N回分の再利用禁止 | 漏洩パスワードリストとの照合を推奨 |
| **パスフレーズ** | ― | 長い文章（例：「TodayIsABeautifulDay2026!」）を推奨 |

### パスワードマネージャー

**パスワードマネージャー**は、複数サービスのパスワードを暗号化して一元管理するツールである。

| メリット | 内容 |
|---|---|
| **一意性の確保** | サービスごとに異なる強力なパスワードを自動生成・記憶 |
| **利便性** | マスターパスワード1つで全サービスにアクセス可能 |
| **漏洩検知** | 流出パスワードデータベースとの自動照合による通知 |

| リスク | 内容 |
|---|---|
| **マスターパスワードの漏洩** | 全パスワードが一度に危険にさらされる |
| **サービス自体の侵害** | パスワードマネージャー提供企業への攻撃 |

## 導入時の留意点

| 留意点 | 内容 |
|---|---|
| **多要素認証の導入** | パスワード単体ではなくMFAの導入を最優先事項とする |
| **パスワードポリシーの見直し** | 定期変更の強制は見直し、長く推測困難なパスフレーズの使用を推奨 |
| **パスワードマネージャーの活用** | 組織的な導入により、パスワードの使い回し防止と管理負荷の軽減を図る |
| **パスワードレス認証の検討** | FIDO2/WebAuthn等のパスワードレス認証技術への段階的な移行を検討 |
| **教育と周知** | パスワードリスト攻撃の危険性、使い回し禁止の徹底を継続的に教育 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**4.5 情報セキュリティ**」に位置づけられる。

パスワード管理は情報管理（アクセス制御）の基本であると同時に、人的資源管理（利用者教育・ユーザビリティ）との両立が求められる。

セキュリティ強度と利用者の利便性のトレードオフをどう管理するかが、総合技術監理の視点では重要な課題となる。
