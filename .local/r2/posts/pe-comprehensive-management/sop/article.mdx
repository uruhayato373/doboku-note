# 標準作業手順書（SOP）

## SOPとは

標準作業手順書（SOP: Standard Operating Procedure）とは、**作業の手順を標準化し、誰が行っても同じ品質と安全性で作業を実施できるようにするための文書**である。

作業の各ステップ、使用する工具・材料、安全上の注意事項、異常時の対応等を具体的に記述する。

## SOPの主な記載項目

| 項目 | 内容 |
|---|---|
| **目的・適用範囲** | 作業の目的と適用する範囲 |
| **必要な資格・教育** | 作業に必要な資格や教育訓練 |
| **使用機器・材料** | 使用する機器・工具・材料のリスト |
| **作業手順** | 各ステップの具体的な手順と順序 |
| **安全上の注意事項** | 危険箇所・保護具・禁止事項 |
| **異常時の対応** | 異常発生時の対処手順 |

## 安全管理における役割

- **作業の標準化**：個人の経験や勘に依存しない安全な作業を実現する
- **教育訓練の教材**：新人教育や作業内容変更時の教育に活用する
- **事故分析の基準**：事故発生時に、SOP通りに作業が行われたかを検証する
