# 隔離安全・停止安全

## 隔離安全・停止安全とは

**隔離安全**とは、人と危険源を物理的に隔離（分離）することにより安全を確保する考え方である。**停止安全**とは、人が危険区域に入る際に機械を停止させることで安全を確保する考え方である。

いずれも「人と機械の共存領域をなくす」ことで安全を実現するSafety 1.0の基本的な安全思想である。

## 具体例

| 方式 | 具体例 |
|---|---|
| **隔離安全** | 安全柵で機械を囲い、作業者の接近を防止する |
| | 防護カバーにより回転部への接触を防止する |
| **停止安全** | 安全扉を開けると機械が自動停止する |
| | [インターロック](/docs/pe-comprehensive-management-interlock)により安全柵内への立入時に機械を停止する |

## 本質安全との関係

隔離安全・停止安全は、[本質安全](/docs/pe-comprehensive-management-inherent-safety)設計（危険源の除去）が困難な場合に採用される安全方策である。危険源そのものは残存するが、人と危険源の接触を物理的に排除する。

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**5.4 未然防止活動**」に位置づけられている。

隔離安全・停止安全は[本質安全](/docs/pe-comprehensive-management-inherent-safety)に次ぐ安全方策であり、[インターロック](/docs/pe-comprehensive-management-interlock)・[非常停止装置](/docs/pe-comprehensive-management-emergency-stop-device)等の安全機構によって実現される。[機能安全](/docs/pe-comprehensive-management-functional-safety)の枠組みでも重要な概念である。
