# 教育訓練技法

## 教育訓練技法とは

教育訓練技法とは、**研修や訓練において効果的な学習を実現するための指導・学習方法の総称**である。

## 主な技法

| 技法 | 内容 |
|---|---|
| **ブレインストーミング** | 自由にアイデアを出し合い、批判なしで発想を広げる |
| **ケーススタディ** | 実際の事例を題材に分析・討議を行う |
| **インバスケット** | 未処理案件を制限時間内に優先順位をつけて処理する |
| **ロールプレイング** | 特定の役割を演じ、対応力を実践的に身につける |
| **グループディスカッション** | グループで課題を議論し結論をまとめる |
| **ケースメソッド** | 事例を多角的に分析し意思決定力を養う |
| **アクションラーニング** | 実際の課題解決と学習を同時に進める |

## 技法の分類

| 分類 | 技法例 | 特徴 |
|---|---|---|
| **知識習得型** | 講義法、eラーニング | 体系的な知識の伝達に適する |
| **参加体験型** | ロールプレイング、インバスケット | 実践的なスキル習得に適する |
| **討議型** | ケーススタディ、ブレインストーミング | 思考力・判断力の向上に適する |
