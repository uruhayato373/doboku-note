# 昆明・モントリオール生物多様性枠組

## 昆明・モントリオール生物多様性枠組とは

**昆明・モントリオール生物多様性枠組**（Kunming-Montreal Global Biodiversity Framework: GBF）とは、2022年12月にカナダ・モントリオールで開催された生物多様性条約COP15において採択された、2030年までの新たな国際目標である。

前身の「愛知目標」（2010年COP10で採択、2020年が目標年）の多くが未達成に終わったことを踏まえ、より実効性のある枠組みとして策定された。

4つのゴール（2050年ビジョン）と23のターゲット（2030年ミッション）で構成される。

### 4つのゴール（2050年ビジョン）

2050年の長期ビジョンとして、以下の4つのゴールが設定されている。各ゴールは生態系保全・持続可能な利用・利益配分・資金確保の4軸を担う。

| ゴール | 内容 |
|---|---|
| **ゴールA** | 生態系の健全性・連結性・レジリエンスの維持・強化・回復。2050年までに自然生態系の面積を大幅に増加 |
| **ゴールB** | 生物多様性の持続可能な利用と管理。遺伝的多様性の維持 |
| **ゴールC** | 遺伝資源の利用から生じる利益の公正かつ衡平な配分（ABS） |
| **ゴールD** | 実施手段（資金、能力構築、技術移転等）の確保。先進国から途上国への資金フローを2030年までに年間200億ドル、2025年までに年間300億ドルに増加 |

### 主要な23ターゲット（2030年ミッション）からの抜粋

2030年までに達成すべき23のターゲットから、総監試験で特に重要な7項目を示す。土地・海洋保全・資金・開示義務が頻出論点となる。

| ターゲット | 内容 |
|---|---|
| **ターゲット1** | すべての地域が参加型の空間計画プロセスの下に置かれること |
| **ターゲット2** | 劣化した生態系の30%以上を効果的に回復すること |
| **ターゲット3（30by30）** | 陸と海のそれぞれ30%以上を保護地域等により保全すること |
| **ターゲット7** | 農薬等による環境へのリスクを半減、有害な化学物質の放出を削減 |
| **ターゲット8** | 気候変動の生物多様性への影響を最小化（自然を活用した解決策を含む） |
| **ターゲット15** | 大企業・金融機関に生物多様性に関するリスク・影響の開示を義務付け |
| **ターゲット18** | 生物多様性に有害な補助金を2030年までに年間5,000億ドル削減 |
| **ターゲット19** | すべての資金源からの資金動員を2030年までに年間2,000億ドルに増加 |

### 30by30（サーティ・バイ・サーティ）

**30by30**はGBFのターゲット3に掲げられた目標であり、2030年までに陸と海のそれぞれ30%以上を保護地域や**OECM**（Other Effective area-based Conservation Measures: 保護地域以外で生物多様性保全に貢献する区域）により保全することを目指す。

日本では「30by30ロードマップ」（2022年4月）を策定し、国立公園等の既存保護地域に加え、企業の森林・里山・社寺林等をOECM（自然共生サイト）として認定する仕組みを構築している。

## 総合技術監理における位置づけ


総合技術監理キーワード集では[**6.1 地球的規模の環境問題**](/docs/pe-comprehensive-management-keyword-2026#61-地球的規模の環境問題)に位置づけられる。

GBFは生物多様性条約・名古屋議定書・IPBES評価報告書・ネイチャーポジティブ等の生物多様性関連キーワードの上位概念であり、気候変動対策（パリ協定）と並ぶ国際環境目標として位置づけられる。
