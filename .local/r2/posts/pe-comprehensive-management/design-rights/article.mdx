# 意匠権（意匠法）

## 意匠権とは

**意匠権** とは、**物品、建築物又は画像のデザイン**（視覚を通じて美感を起こさせるもの）を独占的に実施できる権利である。

意匠法（昭和34年法律第125号）に基づき、特許庁への出願・実体審査・登録を経て権利が発生する。

存続期間は**出願の日から25年**であり、2020年の法改正により従前の「登録の日から20年」から大幅に延長された。

### 意匠法の保護対象

2020年の意匠法改正により、保護対象が大幅に拡大された。

| 保護対象 | 内容 | 例 |
|---|---|---|
| **物品の意匠** | 物品の形状・模様・色彩又はこれらの結合 | 自動車、家具、容器のデザイン |
| **建築物の意匠** | 建築物の形状等（2020年改正で追加） | 商業施設の外観、住宅のデザイン |
| **画像の意匠** | 機器に表示される画像（2020年改正で拡充） | GUI（グラフィカルユーザーインターフェース）、アイコン |
| **部分意匠** | 物品等の部分のデザイン | スマートフォンの背面カメラ部分のデザイン |
| **組物の意匠** | 一組の物品全体のデザイン | 一組の食器セット |

### 登録要件

| 要件 | 内容 |
|---|---|
| **工業上の利用可能性** | 工業的に量産できるものであること |
| **新規性** | 出願前に公知でないこと |
| **創作非容易性** | 当業者が容易に創作できたものでないこと（特許法の「進歩性」に相当） |
| **先願であること** | 同一・類似の意匠は最先の出願のみが登録される |
| **不登録事由に該当しないこと** | 公序良俗に反するデザイン、他人の業務と混同を生ずるもの等でないこと |

### 出願・登録の手続

| 段階 | 内容 |
|---|---|
| **出願** | 願書と図面（6面図等）を特許庁に提出する |
| **方式審査** | 書類の形式要件を審査する |
| **実体審査** | 新規性・創作非容易性等の登録要件を審査する |
| **登録査定** | 登録要件を満たすと判断された場合に発行される |
| **設定登録** | 登録料の納付により意匠権が発生する |
| **意匠公報** | 登録内容が公報に掲載される（秘密意匠の場合を除く） |

### 関連意匠制度

**関連意匠制度** は、基本となる意匠（本意匠）に類似するバリエーションデザインを保護する制度である。

| 項目 | 内容 |
|---|---|
| **目的** | 一つのデザインコンセプトから生まれるバリエーションを一体的に保護する |
| **出願期間** | 本意匠の出願日から10年以内に出願可能（2020年改正で延長） |
| **類似の範囲** | 本意匠に類似する意匠のみ登録可能 |
| **存続期間** | 基礎意匠の出願日から25年 |
| **意義** | デザイン戦略の幅を広げ、模倣品対策の実効性を高める |

### 秘密意匠制度

出願人の請求により、登録後最長3年間、意匠の内容を秘密にできる制度である。

新製品の発売前にデザインが競合他社に知られることを防ぐ目的で利用される。

### 侵害時の救済

| 救済手段 | 内容 |
|---|---|
| **差止請求（37条）** | 侵害行為の停止・予防、侵害品の廃棄を請求できる |
| **損害賠償請求** | 意匠法に損害額の推定規定があり、立証負担が軽減される |
| **信用回復措置（41条で準用）** | 業務上の信用を回復するための措置を請求できる |
| **刑事罰** | 意匠権侵害は10年以下の懲役または1000万円以下の罰金 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では[**4.3 知的財産権と情報の保護と活用**](/docs/pe-comprehensive-management-keyword-2026#43-知的財産権と情報の保護と活用)に位置づけられる。

意匠権は製品やサービスのデザインを法的に保護し、ブランド価値の向上と模倣品排除に寄与する。

建設分野では、2020年改正により建築物のデザインが意匠登録の対象となったことで、商業施設や公共建築物の外観デザインの保護が可能となり、建設プロジェクトの経済性管理における知的財産戦略の選択肢が広がった。
