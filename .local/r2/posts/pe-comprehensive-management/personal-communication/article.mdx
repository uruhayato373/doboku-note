# パーソナル・コミュニケーション

## パーソナル・コミュニケーションとは

**パーソナル・コミュニケーション（Personal Communication）** とは、個人対個人または少人数間で行われる直接的なコミュニケーション形態のことである。対面での会話、電話、手紙、メール等を含み、マス・コミュニケーション（不特定多数への大量伝達）と対比される。

## マス・コミュニケーションとの比較

| 項目 | パーソナル・コミュニケーション | マス・コミュニケーション |
|---|---|---|
| **対象** | 特定の個人・少数 | 不特定多数 |
| **方向性** | 双方向 | 一方向が基本 |
| **フィードバック** | 即座に可能 | 遅延・困難 |
| **内容の調整** | 相手に応じて柔軟に変更 | 画一的 |
| **非言語情報** | 豊富（表情・声のトーン） | 限定的 |
| **信頼構築** | 容易 | 困難 |
| **到達範囲** | 限定的 | 広範 |

## コミュニケーションの要素

| 要素 | 内容 |
|---|---|
| **送り手（発信者）** | メッセージを発する者 |
| **メッセージ** | 伝達される情報・意図 |
| **チャネル** | 伝達の媒体（対面・電話・メール等） |
| **受け手（受信者）** | メッセージを受ける者 |
| **フィードバック** | 受け手から送り手への応答 |
| **ノイズ** | 伝達を阻害する要因（物理的・心理的） |

## 効果的なパーソナル・コミュニケーション

| 要素 | 内容 |
|---|---|
| **アクティブリスニング** | 傾聴・共感・要約による積極的な聴き方 |
| **アサーション** | 自他を尊重した自己表現 |
| **オープンクエスチョン** | 相手の考えを引き出す開かれた質問 |
| **パラフレーズ** | 相手の発言を自分の言葉で言い換え確認 |
| **非言語メッセージの活用** | 表情・姿勢・アイコンタクトの意識的活用 |

## コミュニケーション技法 7 種

総合技術監理キーワード集では、コミュニケーション技法として 7 つの代表手法が示されている。場面と目的に応じた使い分けが重要であり、特に**プッシュ型／プル型**の対比は情報の流れの方向性を示す基本概念として頻出である。

| 技法 | 概要 | 主な活用場面 |
|---|---|---|
| **ファシリテーション** | 議論の舵取り。発言しやすい環境を整え、結論に向けて収束させる | 会議運営、ワークショップ |
| **コーチング** | 対話により相手の自己実現や目標達成を促す。質問で気づきを引き出す | 部下指導、人材育成 |
| **カウンセリング** | 傾聴・共感・要約・矛盾点の指摘により相手の意識変容を試みる | 心理的支援、行動変容 |
| **ネゴシエーション** | 意見・方向性の相違を議論で調整。Win-Win の関係構築が理想 | 利害調整、契約交渉 |
| **合意形成** | ステークホルダーの意見一致を図る | 公共事業、住民合意 |
| **プッシュ型** | 送信者が特定の相手に情報を発信（読まれるかは受信者次第） | 電子メール、手紙 |
| **プル型** | 受信者が必要な時に情報にアクセスする | ポータル、イントラネット、e ラーニング |

### プッシュ型／プル型の対比

両者は **情報の流れにおける主導権（イニシアチブ）の所在** で区別される。プッシュ型は送信者が能動的に情報を送り出すが、受信者が読むとは限らない。プル型は受信者が能動的に情報源にアクセスするため、必要な時に必要な情報を取得できるが、受信者がアクセスしなければ情報は届かない。

組織のコミュニケーション戦略では両者を併用するのが一般的である。緊急性の高い情報や全員が確実に把握すべき内容はプッシュ型（メール・全社告知）、参照が必要な時に必要な人がアクセスする情報はプル型（ナレッジベース・ポータル）が適している。

## 建設現場での活用

| 場面 | ポイント |
|---|---|
| **現場指示** | 口頭指示は復唱確認、重要事項は書面併用 |
| **安全教育（TBM）** | 少人数での対面ミーティングで危険予知 |
| **住民対応** | 個別の苦情対応では対面でのコミュニケーションが有効 |
| **部下指導** | コーチング・メンタリングによる育成 |
