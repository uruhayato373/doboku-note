# パーソナル・コミュニケーション

## パーソナル・コミュニケーションとは

**パーソナル・コミュニケーション（Personal Communication）** とは、個人対個人または少人数間で行われる直接的なコミュニケーション形態のことである。対面での会話、電話、手紙、メール等を含み、マス・コミュニケーション（不特定多数への大量伝達）と対比される。

## マス・コミュニケーションとの比較

| 項目 | パーソナル・コミュニケーション | マス・コミュニケーション |
|---|---|---|
| **対象** | 特定の個人・少数 | 不特定多数 |
| **方向性** | 双方向 | 一方向が基本 |
| **フィードバック** | 即座に可能 | 遅延・困難 |
| **内容の調整** | 相手に応じて柔軟に変更 | 画一的 |
| **非言語情報** | 豊富（表情・声のトーン） | 限定的 |
| **信頼構築** | 容易 | 困難 |
| **到達範囲** | 限定的 | 広範 |

## コミュニケーションの要素

| 要素 | 内容 |
|---|---|
| **送り手（発信者）** | メッセージを発する者 |
| **メッセージ** | 伝達される情報・意図 |
| **チャネル** | 伝達の媒体（対面・電話・メール等） |
| **受け手（受信者）** | メッセージを受ける者 |
| **フィードバック** | 受け手から送り手への応答 |
| **ノイズ** | 伝達を阻害する要因（物理的・心理的） |

## 効果的なパーソナル・コミュニケーション

| 要素 | 内容 |
|---|---|
| **アクティブリスニング** | 傾聴・共感・要約による積極的な聴き方 |
| **アサーション** | 自他を尊重した自己表現 |
| **オープンクエスチョン** | 相手の考えを引き出す開かれた質問 |
| **パラフレーズ** | 相手の発言を自分の言葉で言い換え確認 |
| **非言語メッセージの活用** | 表情・姿勢・アイコンタクトの意識的活用 |

## 建設現場での活用

| 場面 | ポイント |
|---|---|
| **現場指示** | 口頭指示は復唱確認、重要事項は書面併用 |
| **安全教育（TBM）** | 少人数での対面ミーティングで危険予知 |
| **住民対応** | 個別の苦情対応では対面でのコミュニケーションが有効 |
| **部下指導** | コーチング・メンタリングによる育成 |
