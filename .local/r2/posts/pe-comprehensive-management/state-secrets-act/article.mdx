# 特定秘密保護法

## 特定秘密保護法とは

**特定秘密保護法**（特定秘密の保護に関する法律、平成25年法律第108号）とは、国の安全保障に関する情報のうち特に秘匿が必要な情報を「**特定秘密**」に指定し、その漏洩を防止するための法律である。

2013年12月に公布され、2014年12月に施行された。

漏洩した場合の最高刑は**懲役10年**であり、従来の国家公務員法（懲役1年以下）や自衛隊法（懲役5年以下）よりも厳しい罰則が設けられている。

### 特定秘密の4分野

特定秘密として指定できる情報は、以下の4分野に限定されている。

| 分野 | 内容 | 具体例 |
|---|---|---|
| **防衛** | 自衛隊の運用、防衛力の整備に関する情報 | 防衛計画、装備品の性能、自衛隊の作戦情報 |
| **外交** | 外国政府との交渉、国際約束に関する情報 | 条約交渉の内容、外国政府から提供された機密情報 |
| **特定有害活動の防止** | スパイ活動等の防止に関する情報 | スパイ活動の捜査情報、防諜に関する情報 |
| **テロリズムの防止** | テロ行為の防止に関する情報 | テロ関連の捜査・警備情報 |

### 特定秘密の指定要件

| 要件 | 内容 |
|---|---|
| **指定権者** | 行政機関の長（大臣等）が指定する |
| **対象情報** | 4分野に該当する情報であること |
| **非公知性** | 公になっていない情報であること |
| **秘匿の必要性** | 漏洩が国の安全保障に著しい支障を与えるおそれがあること |
| **指定期間** | 原則5年以内（通算30年まで延長可能。60年を超える延長は限定的な例外を除き不可） |

### 適性評価制度（セキュリティ・クリアランス）

特定秘密を取り扱う者に対して、情報漏洩のリスクを評価する制度である。

| 項目 | 内容 |
|---|---|
| **対象者** | 特定秘密を取り扱う行政機関の職員、契約事業者の従業員 |
| **調査事項** | 犯罪・懲戒の経歴、情報の取扱いに関する非違歴、薬物使用、精神疾患、飲酒の節度、経済的状況等 |
| **実施者** | 行政機関の長 |
| **同意** | 本人の同意を得て実施する |
| **結果** | 適性が認められない場合、特定秘密の取扱いを認めない |

### 罰則

| 行為 | 罰則 |
|---|---|
| **特定秘密の漏洩（公務員等）** | 10年以下の懲役（又は情状により1000万円以下の罰金を併科） |
| **特定秘密の取得（外部者）** | 不正な手段（欺き・暴行・脅迫等）による取得は10年以下の懲役 |
| **共謀・教唆・煽動** | 5年以下の懲役 |
| **過失による漏洩** | 2年以下の禁錮又は50万円以下の罰金 |

### 情報公開との関係

| 論点 | 内容 |
|---|---|
| **知る権利との緊張関係** | 国民の知る権利・報道の自由と、安全保障上の秘匿の必要性のバランスが議論されている |
| **運用基準** | 法律の運用基準において、報道機関の取材活動は「出版又は報道の業務に従事する者の取材行為」として正当業務行為に該当する旨が明記されている |
| **国会への報告** | 特定秘密の指定・解除の状況は、毎年国会に報告される |
| **独立公文書管理監** | 内閣府に設置され、特定秘密の指定・解除の適正性を検証・監察する |
| **情報監視審査会** | 衆参両院に設置され、特定秘密の指定等の運用を常時監視する |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**4.3 知的財産権と情報の保護と活用**」に位置づけられる。

特定秘密保護法は、国家安全保障に関する情報の保護と、国民の知る権利・情報公開との間のバランスという、情報管理における根本的な課題を体現する法律である。

安全管理の観点からは、防衛・テロ防止分野の情報保護が国家のリスクマネジメントに直結し、人的資源管理の観点からは、適性評価制度による従業員のセキュリティ・クリアランスの運用が、防衛関連事業に携わる組織の実務課題となる。
