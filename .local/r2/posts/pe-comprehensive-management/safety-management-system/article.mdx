# 安全マネジメントシステム

## 安全マネジメントシステムとは

**安全マネジメントシステム（SMS：Safety Management System）** とは、組織の安全に関する方針・目標・計画・実施・評価・改善をPDCAサイクルで体系的に管理する仕組みである。ISO 45001（労働安全衛生）やICAO（航空）のSMS等、分野ごとに規格・基準が存在する。

## 主な安全マネジメントシステム規格

| 規格・制度 | 分野 | 内容 |
|---|---|---|
| **ISO 45001** | 労働安全衛生 | OHSAS 18001を承継した国際規格（2018年） |
| **OSHMS指針** | 労働安全衛生 | 厚生労働省の労働安全衛生マネジメントシステム指針 |
| **運輸安全マネジメント** | 運輸 | 国交省の運輸事業者向けSMS（2006年〜） |
| **ICAO SMS** | 航空 | 国際民間航空機関の安全管理システム |
| **ISMコード** | 海事 | 船舶の安全運航管理の国際基準 |

## ISO 45001の構造

| 要素 | 内容 |
|---|---|
| **組織の状況** | 内外の課題、利害関係者のニーズ |
| **リーダーシップ** | トップマネジメントの責任・安全方針 |
| **計画** | リスクアセスメント、目標設定 |
| **支援** | 資源、力量、認識、コミュニケーション |
| **運用** | 運用計画、変更管理、緊急事態対応 |
| **パフォーマンス評価** | 監視・測定、内部監査、マネジメントレビュー |
| **改善** | インシデント対応、是正処置、継続的改善 |

## 従来の安全管理との違い

| 項目 | 従来の安全管理 | SMS |
|---|---|---|
| **アプローチ** | 規制遵守型（法令に従う） | 自律型（組織が主体的に管理） |
| **範囲** | 個別対策の積み上げ | 体系的・組織横断的な管理 |
| **改善** | 事故後の再発防止 | PDCAによる継続的改善 |
| **経営者の関与** | 限定的 | トップマネジメントのリーダーシップ必須 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**5.1 安全の概念**」に位置づけられる。

安全マネジメントシステムは安全文化・安全目標・リスクアセスメント・安全教育等を統合的に運用する枠組みであり、安全管理の中核をなす概念である。
