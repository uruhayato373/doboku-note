# リスク

## リスクとは

リスク（Risk）とは、**目的に対する不確かさの影響**である（JIS Q 31000:2019）。

従来は「好ましくない事象の発生確率とその結果の組合せ」と定義されることが多かったが、ISO 31000では好ましい影響（機会）も含む広義の定義が採用されている。安全管理の文脈では、リスクレベルは以下の式で表される。

$$\text{リスクレベル} = \text{起こりやすさ} \times \text{影響の大きさ}$$

## リスクの構成要素

| 構成要素 | 内容 |
|---|---|
| **<RelatedKeywords items={[{ label: "ハザード", slug: "hazard" }]} />** | リスクの源となる潜在的な危険要因 |
| **<RelatedKeywords items={[{ label: "起こりやすさ", slug: "likelihood" }]} />** | 事象が発生する確率・頻度 |
| **<RelatedKeywords items={[{ label: "影響", slug: "impact" }]} />** | 事象が発生した場合の結果の大きさ |

## リスクの分類

| 分類基準 | 種類 | 内容 |
|---|---|---|
| **性質** | 純粋リスク | 損失のみが生じるリスク（事故・災害等） |
| | 投機的リスク | 損失と利益の両方が生じ得るリスク（投資等） |
| **対象** | 安全リスク | 人命・健康への影響 |
| | 経済リスク | 財務・経済的損失 |
| | 社会的リスク | 環境・社会への影響 |
