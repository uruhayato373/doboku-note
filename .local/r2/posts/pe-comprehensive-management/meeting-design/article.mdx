## 会議設計とは

**会議設計** とは、会議の目的を達成するために、参加者・議題・進行方法・時間配分・成果物を事前に計画し、効率的な会議運営を実現する活動のことである。不適切な会議は時間と人的資源の浪費の主要因となる。

## 会議の種類と目的

| 種類 | 目的 | 運営のポイント |
|---|---|---|
| **情報共有会議** | 報告・連絡・周知 | 一方向伝達中心、質疑応答を効率的に |
| **意思決定会議** | 方針・判断事項の決定 | 決裁権者の出席、代替案の事前準備 |
| **問題解決会議** | 課題の分析・解決策の検討 | ブレーンストーミング、ファシリテーション |
| **アイデア創出会議** | 新しいアイデアの発想 | 自由な発言環境、批判禁止 |
| **調整会議** | 関係者間の利害調整 | 各者の立場の理解、妥協点の探索 |

## 効率的な会議設計の要素

| 要素 | 内容 |
|---|---|
| **目的の明確化** | 会議で達成すべきゴールを事前に定義 |
| **参加者の選定** | 必要最小限の適切なメンバー |
| **アジェンダ** | 議題・時間配分・担当者の事前配布 |
| **資料の事前配布** | 会議中の説明時間を削減 |
| **時間管理** | 開始・終了時刻の厳守、各議題の時間枠 |
| **ファシリテーション** | 議論の促進・整理・合意形成の支援 |
| **議事録** | 決定事項・アクションアイテム・担当者・期限の記録 |

## ファシリテーションの技法

| 技法 | 内容 |
|---|---|
| **場の設定** | 目的・ルール・タイムラインの共有 |
| **発散** | アイデアを広く引き出す（ブレスト、KJ法） |
| **収束** | アイデアを整理・絞り込む（投票、マトリクス） |
| **合意形成** | 参加者の納得を得て結論を導く |

## 建設プロジェクトの主要会議

| 会議 | 頻度 | 内容 |
|---|---|---|
| **定例工程会議** | 週次 | 工程の進捗確認・調整 |
| **安全衛生協議会** | 月次 | 安全管理の協議（特定元方事業者） |
| **設計協議** | 随時 | 設計変更・技術的課題の協議 |
| **住民説明会** | 随時 | 工事概要・影響の説明・質疑応答 |

## 総合技術監理における位置づけ


総合技術監理キーワード集では[**4.2 コミュニケーション**](/docs/pe-comprehensive-management-keyword-2026#42-コミュニケーション)に位置づけられる。

会議設計はコミュニケーション計画の実行手段であり、人的資源管理（時間の有効活用）と情報管理（意思決定の記録）に直結する。オンライン会議と組み合わせた効率的な運営が求められる。
