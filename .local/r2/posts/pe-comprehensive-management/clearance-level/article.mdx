# クリアランスレベル

## クリアランスレベルとは

クリアランスレベルとは、放射性廃棄物に含まれる放射性物質の放射能濃度が十分に低く、人の健康への影響が無視できるレベルとして定められた基準値である。

この基準値以下の廃棄物は放射性廃棄物としての規制から除外（クリアランス）され、一般の廃棄物と同様に再利用または処分が可能となる。

IAEAが国際的な基準値を策定しており、日本では2005年の核原料物質、核燃料物質及び原子炉の規制に関する法律（炉規法）の改正により制度化された。

### 法的根拠と制度の仕組み

| 項目 | 内容 |
|---|---|
| **根拠法** | 核原料物質、核燃料物質及び原子炉の規制に関する法律（炉規法） |
| **制度開始** | 2005年（炉規法改正による制度化） |
| **基準設定** | 原子力規制委員会が核種ごとに放射能濃度基準を設定 |
| **判断基準** | 年間10μSv以下（自然放射線の約1/100） |
| **確認手続** | 原子力規制委員会による「確認」を受けてクリアランス認定 |
| **国際基準** | IAEA安全指針RS-G-1.7に基づく |

### クリアランス制度の流れ

| 段階 | 内容 |
|---|---|
| **1. 認可申請** | 事業者がクリアランスに関する測定・評価方法の認可を申請 |
| **2. 測定・評価** | 認可された方法で放射能濃度を測定・評価 |
| **3. 確認申請** | 基準値以下であることを原子力規制委員会に確認申請 |
| **4. 確認** | 原子力規制委員会が確認し、規制対象から除外 |
| **5. 再利用・処分** | 一般の廃棄物として再利用（金属スクラップ等）または処分 |

### 主要核種のクリアランスレベル

| 核種 | クリアランスレベル（Bq/g） | 主な発生源 |
|---|---|---|
| **コバルト60（Co-60）** | 0.1 | 原子炉構造材の放射化 |
| **セシウム137（Cs-137）** | 0.1 | 核分裂生成物 |
| **セシウム134（Cs-134）** | 0.1 | 核分裂生成物 |
| **トリチウム（H-3）** | 100 | 原子炉冷却水 |
| **炭素14（C-14）** | 1 | 原子炉構造材の放射化 |

### 現状・課題

| 課題 | 内容 |
|---|---|
| **廃炉の本格化** | 原発廃炉に伴い大量のクリアランス対象物が発生見込み |
| **社会的受容** | クリアランス物の再利用先確保に住民理解が必要 |
| **トレーサビリティ** | クリアランス後の追跡管理の必要性に関する議論 |
| **認定実績** | 東海発電所等で実績があるが、今後の大量処理への対応が課題 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**6.2 地域環境問題**」に位置づけられる。

クリアランス制度は安全管理（放射線防護基準の合理的設定）と社会環境管理（廃棄物の減量化・資源循環）の接点に位置する。経済性管理（廃炉コストの削減、資源の有効利用）の観点からも重要であり、制度の信頼性を支える情報管理（測定データの透明性、リスクコミュニケーション）が不可欠である。
