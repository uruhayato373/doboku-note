# 社会的受容（PA）

## 社会的受容（PA）とは

**社会的受容（PA：Public Acceptance）** とは、技術やインフラ、施策等に対して社会（住民・市民）がそれを受け入れることである。公共事業では、事業の必要性・安全性・環境への影響等について地域住民や社会全体の理解と合意を得ることを指す。

## PAの3つのレベル

| レベル | 内容 | 例 |
|---|---|---|
| **社会的受容** | 社会全体としての受容 | 再生可能エネルギー政策への国民的支持 |
| **地域的受容** | 立地地域での受容 | 風力発電所の建設への地域住民の合意 |
| **市場的受容** | 消費者・利用者としての受容 | 電気自動車の購買・利用 |

## PAを阻害する要因

| 要因 | 内容 |
|---|---|
| **NIMBY（ニンビー）** | 必要性は認めるが自分の近隣には反対（Not In My Back Yard） |
| **リスク認知の乖離** | 専門家と市民のリスク認識の差 |
| **情報の非対称性** | 事業者と住民の情報量の格差 |
| **不信感** | 事業者・行政への過去の不信 |
| **分配の不公平感** | 便益は広域、迷惑は地域に集中 |

## PA促進の手法

| 手法 | 内容 |
|---|---|
| **リスクコミュニケーション** | リスク情報の双方向の対話 |
| **パブリックインボルブメント** | 計画段階からの住民参加 |
| **情報開示** | 事業情報の積極的かつ分かりやすい公開 |
| **便益の地元還元** | 地域振興策・補償措置 |
| **第三者機関の活用** | 中立的な専門家委員会による評価 |
| **段階的合意形成** | 段階ごとに合意を積み重ねるプロセス |

## 公共事業におけるPAの課題

| 課題 | 対応策 |
|---|---|
| **長期的な信頼構築** | 継続的なコミュニケーションと実績の積み重ね |
| **多様なステークホルダー** | 利害関係者の網羅的な特定と対話 |
| **科学的不確実性** | 不確実性を率直に説明し対話する姿勢 |
| **世代間の課題** | 将来世代への影響も含めた議論 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**4.2 コミュニケーションと合意形成**」に位置づけられる。

社会的受容は公共事業の成否を左右する重要概念であり、住民参加・ステークホルダー管理・パブリックリレーションズ・情報開示のすべてがPA確保に向けた手段である。
