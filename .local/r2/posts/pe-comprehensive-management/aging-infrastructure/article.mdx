# インフラ老朽化対策

## インフラ老朽化の現状

日本の社会インフラの多くは高度経済成長期（1960〜70年代）に集中的に整備され、建設後50年以上が経過する施設が急増している。

| 施設 | 建設後50年超の割合（2033年） |
|---|---|
| **道路橋** | 約63% |
| **トンネル** | 約42% |
| **河川管理施設（水門等）** | 約62% |
| **下水道管きょ** | 約21% |
| **港湾岸壁** | 約58% |

## インフラ長寿命化基本計画

| 項目 | 内容 |
|---|---|
| **策定** | 2013年、インフラ老朽化対策の推進に関する関係省庁連絡会議 |
| **基本方針** | 事後保全から予防保全への転換 |
| **行動計画** | 各省庁・地方公共団体が個別施設計画を策定 |
| **目標** | メンテナンスサイクルの構築（点検→診断→措置→記録） |

## 事後保全と予防保全

| 項目 | 事後保全 | 予防保全 |
|---|---|---|
| **タイミング** | 壊れてから修繕 | 壊れる前に計画的に修繕 |
| **コスト** | 長期的に高い（大規模修繕・架替え） | 長期的に低い（小規模修繕の積み重ね） |
| **安全性** | 突然の機能喪失リスク | 機能を維持しながら管理 |
| **試算** | 30年間で約280兆円（国交省推計） | 30年間で約190兆円 |

## 主要施策

| 施策 | 内容 |
|---|---|
| **法定点検の義務化** | 橋梁・トンネル：5年に1回の近接目視点検（2014年〜） |
| **新技術の活用** | ドローン、AI画像解析、センサーモニタリング |
| **アセットマネジメント** | ライフサイクルコストを考慮した最適な維持管理計画 |
| **集約・撤去** | 利用度の低い施設の統廃合・撤去 |
| **人材育成** | メンテナンス技術者の確保・育成 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**5.1 安全の概念**」に位置づけられる。

インフラ老朽化対策はレジリエンス・安全投資・スマート保安と密接に関連し、公衆安全の確保と経済性管理のトレードオフが問われる重要テーマである。
