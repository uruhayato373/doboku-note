# ロジスティック回帰

## ロジスティック回帰とは

ロジスティック回帰（Logistic Regression）とは、目的変数が二値（0または1）のとき、あるカテゴリに属する確率を説明変数の線形結合で予測する統計手法である。

名前に「回帰」と付くが、実質的には分類問題に用いる手法である。

土木分野では、構造物の損傷有無の判別、事故発生の有無と要因の関係分析、入札の成功・失敗の予測などに適用される。

### 数理モデル

ロジスティック回帰では、事象が発生する確率 $p$ を以下のロジスティック関数（シグモイド関数）でモデル化する。

$$
p = \frac{1}{1 + e^{-(\beta_0 + \beta_1 x_1 + \cdots + \beta_p x_p)}}
$$

線形回帰との本質的な違いは、目的変数が確率（0から1の範囲）に制約される点である。

これを変形すると、オッズの対数（ロジット）が説明変数の線形結合で表される。

$$
\ln\left(\frac{p}{1-p}\right) = \beta_0 + \beta_1 x_1 + \cdots + \beta_p x_p
$$

$p/(1-p)$ をオッズ（事象が起こる確率と起こらない確率の比）という。

### 線形回帰との比較

| 項目 | 線形回帰 | ロジスティック回帰 |
|---|---|---|
| 目的変数 | 連続量（売上、強度など） | 二値（有/無、合格/不合格） |
| 出力 | 予測値（実数全体） | 確率（0〜1） |
| 関数形 | $y = \beta_0 + \beta_1 x$ | $p = 1/(1 + e^{-z})$ |
| 推定法 | 最小二乗法（OLS） | 最尤推定法（MLE） |
| 評価指標 | 決定係数 $R^2$ | 正解率・AUC・適合率・再現率 |

### 最尤推定法

ロジスティック回帰の係数は最尤推定法（Maximum Likelihood Estimation, MLE）で求める。

最小二乗法が残差の二乗和を最小化するのに対し、最尤推定法は観測データが得られる尤度（もっともらしさ）を最大化する方法である。

対数尤度関数を偏微分し、反復計算（ニュートン法など）で解を求める。

### モデルの評価

ロジスティック回帰モデルの予測性能は、混同行列から算出される指標で評価する。

| 指標 | 定義 |
|---|---|
| 正解率（Accuracy） | 全予測のうち正しかった割合 |
| 適合率（Precision） | 陽性と予測したもののうち実際に陽性だった割合 |
| 再現率（Recall） | 実際の陽性のうち正しく陽性と予測できた割合 |
| F値 | 適合率と再現率の調和平均 |
| AUC | ROC曲線の下の面積。1に近いほど識別力が高い |
