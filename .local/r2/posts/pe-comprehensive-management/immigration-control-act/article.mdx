# 出入国管理及び難民認定法

## 出入国管理及び難民認定法とは

出入国管理及び難民認定法（入管法）は、日本に入国・在留するすべての外国人の出入国管理と在留資格の付与、難民の認定手続等を定めた法律である。

外国人が日本で就労するためには、就労が認められる在留資格を取得する必要がある。

人手不足が深刻化する中、2018年の改正で新たな在留資格「特定技能」が創設され、外国人材の受入れが拡大された。

### 主な就労系在留資格

| 在留資格 | 対象 | 在留期間 |
|---|---|---|
| **技術・人文知識・国際業務** | エンジニア、通訳、デザイナー等 | 5年、3年、1年又は3月 |
| **高度専門職** | ポイント制で高度人材と認定された者 | 1号：5年、2号：無期限 |
| **技能実習** | 技能実習計画に基づき技能を修得する者 | 1号：1年、2号：2年、3号：2年（計最長5年） |
| **特定技能** | 人手不足分野で相当程度の知識・経験を有する者 | 1号：通算5年、2号：更新上限なし |
| **特定活動** | 法務大臣が個別に指定する活動 | 指定による |

### 技能実習制度

| 項目 | 内容 |
|---|---|
| **目的** | 開発途上国への技能・技術・知識の移転（国際貢献） |
| **対象職種** | 90職種165作業（建設関係22職種33作業を含む） |
| **実習期間** | 最長5年（1号1年→2号2年→3号2年） |
| **監理団体** | 実習実施者を監理する非営利法人 |
| **課題** | 労働環境問題、失踪、人権侵害の指摘 |
| **制度見直し** | 2024年に育成就労制度への移行が決定（2027年施行予定） |

### 特定技能制度

| 項目 | 特定技能1号 | 特定技能2号 |
|---|---|---|
| **技能水準** | 相当程度の知識又は経験 | 熟練した技能 |
| **在留期間** | 通算5年 | 上限なし（更新可） |
| **家族帯同** | 不可 | 可（配偶者・子） |
| **対象分野** | 16分野（建設、介護、外食等） | 11分野（介護を除く） |
| **試験** | 技能試験＋日本語試験 | 技能試験（より高度） |
| **転職** | 同一分野内で可能 | 同一分野内で可能 |

### 建設分野における外国人材

建設分野は特定技能の対象分野であり、技能実習からの移行も多い。

| 区分 | 特徴 |
|---|---|
| **特定技能1号（建設）** | 土木、建築、ライフライン・設備の3区分、国土交通大臣の計画認定が必要 |
| **建設キャリアアップシステム** | 外国人技能者の登録が義務、技能と経験を客観的に評価 |
| **受入れ上限** | 常勤職員の総数を超えないこと |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**3.2 労働関係法と労務管理**」に位置づけられる。

外国人材の活用は人的資源管理における人材確保の重要な手段であり、特に建設業では深刻な担い手不足への対応として不可欠なテーマとなっている。

安全管理（労働災害防止のための安全教育）、社会環境管理（多文化共生）、経済性管理（人件費と生産性）の各管理分野と横断的に関わる。
