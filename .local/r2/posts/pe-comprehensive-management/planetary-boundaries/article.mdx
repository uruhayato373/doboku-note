# プラネタリー・バウンダリー（地球の限界）

## プラネタリー・バウンダリーとは

プラネタリー・バウンダリー（Planetary Boundaries）は、2009年にスウェーデンのストックホルム・レジリエンス・センターのヨハン・ロックストロームらが提唱した、地球システムの安定性を維持するための「安全な活動空間（Safe Operating Space）」を定義する概念的枠組みである。

人類が地球上で安全に活動できる限界を9つの領域で定量化し、各領域の境界値を超えると不可逆的で急激な環境変化が生じるリスクがあることを示している。

2023年の最新評価では、9領域中6領域で既に境界値を超えており、地球システムの安定性が脅かされていることが明らかとなった。

### 9つの領域と現状（2023年評価）

| 領域 | 境界値の指標 | 現状 |
|---|---|---|
| **① 気候変動** | 大気中CO2濃度 350ppm / 放射強制力 +1.0W/m2 | 超過（CO2 約420ppm） |
| **② 生物圏の一体性（生物多様性）** | 種の絶滅速度、生態系機能の多様性 | 大幅に超過（最も深刻） |
| **③ 土地利用変化** | 森林面積の割合（原生林の75%を維持） | 超過 |
| **④ 淡水利用** | 河川流量、土壌水分（グリーンウォーター） | 超過 |
| **⑤ 生物地球化学的循環（窒素・リン）** | 窒素の固定量、リンの海洋流入量 | 大幅に超過 |
| **⑥ 新規化学物質（新規実体）** | プラスチック、化学物質の環境放出量 | 超過 |
| **⑦ 成層圏オゾン層の破壊** | オゾン全量（ドブソン単位） | 境界内（改善中） |
| **⑧ 大気エアロゾルの負荷** | エアロゾル光学的厚さ | 評価中（一部地域で超過） |
| **⑨ 海洋酸性化** | 海水中のアラゴナイト飽和度 | 境界内（悪化傾向） |

### 領域の状態分類

| 状態 | 意味 | 該当領域（2023年） |
|---|---|---|
| **安全な活動空間内** | 境界値を超えていない | ⑦成層圏オゾン、⑨海洋酸性化 |
| **不確実性の領域** | 境界値付近、リスク増大中 | ⑧大気エアロゾル |
| **高リスク領域** | 境界値を超過 | ①気候変動、③土地利用、④淡水、⑥新規化学物質 |
| **超高リスク領域** | 境界値を大幅に超過 | ②生物多様性、⑤窒素・リン循環 |

### ドーナツ経済学との関連

イギリスの経済学者ケイト・ラワースは、プラネタリー・バウンダリー（環境の上限）と「社会的な土台」（人々の基本的ニーズの下限）を組み合わせた「ドーナツ経済学」を提唱した。

| 概念 | 内容 |
|---|---|
| **外側の輪（環境の上限）** | プラネタリー・バウンダリーの9領域 |
| **内側の輪（社会的な土台）** | 健康、教育、収入、政治的発言力など12の基本ニーズ |
| **ドーナツの中（安全で公正な空間）** | 環境の上限を超えず、社会的な土台を満たす持続可能な空間 |
