# 環境と開発に関するリオ宣言

## リオ宣言とは

環境と開発に関するリオ宣言（Rio Declaration on Environment and Development）は、1992年の地球サミット（UNCED）で採択された、持続可能な開発に関する27の原則を定めた国際宣言である。

1972年の人間環境宣言（ストックホルム宣言）を再確認・発展させたものであり、環境と開発を統合的に捉える理念を示している。

法的拘束力はないが、以後の国際環境条約や各国の環境法制に大きな影響を与えた指導原則である。

### リオ宣言の重要原則

| 原則 | 名称・概念 | 内容 |
|---|---|---|
| **第3原則** | 世代間公平 | 開発の権利は、現在および将来世代の環境上のニーズを公平に満たすよう行使 |
| **第4原則** | 環境と開発の統合 | 持続可能な開発を達成するため、環境保護は開発過程の不可分の部分を構成する |
| **第7原則** | 共通だが差異ある責任 | 地球環境の悪化への各国の寄与度に応じ、先進国はより大きな責任を負う |
| **第10原則** | 市民参加・情報公開 | 環境問題は関係市民の参加により最も適切に扱われる（後のオーフス条約に影響） |
| **第13原則** | 汚染者負担原則（PPP） | 汚染者が汚染の費用を負担すべき |
| **第15原則** | 予防原則 | 深刻な損害のおそれがある場合、科学的確実性が十分でないことを理由に対策を延期してはならない |
| **第16原則** | 外部費用の内部化 | 環境コストの内部化と経済的手段の使用を促進すべき |

### ストックホルム宣言との比較

| 項目 | ストックホルム宣言（1972年） | リオ宣言（1992年） |
|---|---|---|
| **原則数** | 26原則 | 27原則 |
| **焦点** | 環境保護が中心 | 環境と開発の統合 |
| **途上国の位置づけ** | 開発の権利に言及 | 共通だが差異ある責任を明記 |
| **予防原則** | 明示なし | 第15原則で明記 |
| **市民参加** | 限定的な言及 | 第10原則で情報公開・参加を明記 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では[**6.1 地球的規模の環境問題**](/docs/pe-comprehensive-management-keyword-2026#61-地球的規模の環境問題)に位置づけられる。

リオ宣言の諸原則は、アジェンダ21の理論的基盤であり、気候変動枠組条約における「共通だが差異ある責任」や、日本の環境基本法における予防的取組・汚染者負担原則に直接反映されているため、環境管理分野の出題で繰り返し問われる重要テーマである。
