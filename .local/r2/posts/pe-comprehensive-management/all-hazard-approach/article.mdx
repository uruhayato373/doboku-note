# オールハザードアプローチ

## オールハザードアプローチとは

**オールハザードアプローチ（All-Hazards Approach）** とは、自然災害・事故・テロ・感染症等のあらゆる種類のハザード（危険事象）に対して、共通の危機管理体制・手順で対応する考え方である。米国FEMA（連邦緊急事態管理庁）が推進し、国際的に普及した。

## ハザード別アプローチとの比較

| 項目 | オールハザードアプローチ | ハザード別アプローチ |
|---|---|---|
| **対応体制** | 共通の指揮系統・手順 | ハザードごとに個別の体制 |
| **対象** | すべてのハザードを包括 | 地震、水害、火災等を個別に対応 |
| **利点** | 想定外の事象にも対応可能 | 専門性の高い対応が可能 |
| **欠点** | 個別ハザードの専門性が薄れるリスク | 複合災害への対応が困難 |

## 主な適用フレームワーク

| フレームワーク | 内容 |
|---|---|
| **ICS（事故指揮システム）** | 米国発の標準的な現場指揮体制（ハザード共通） |
| **NIMS** | 米国の国家事故管理システム（ICSを含む包括体制） |
| **仙台防災枠組（2015〜2030）** | 国連のオールハザード型防災戦略 |
| **国土強靱化基本計画** | 日本版のオールハザードアプローチ（あらゆるリスクを想定） |

## 対象となるハザード

| カテゴリ | 例 |
|---|---|
| **自然災害** | 地震、津波、風水害、火山噴火 |
| **技術的災害** | 産業事故、化学物質漏洩、原子力事故 |
| **人為的脅威** | テロ、サイバー攻撃、武力攻撃 |
| **健康危機** | 感染症パンデミック、食中毒 |
| **複合災害（Natech）** | 自然災害に起因する技術的災害 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**5.1 安全の概念**」に位置づけられる。

オールハザードアプローチはレジリエンス・危機管理・BCP・ICS等と連動する安全管理の包括的概念であり、防災とセキュリティを統合的に捉える基盤となる。
