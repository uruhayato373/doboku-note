# 労働基準法

## 労働基準法とは

**労働基準法**（昭和22年法律第49号）は、労働条件の最低基準を定める法律である。

[**日本国憲法第27条第2項**](https://laws.e-gov.go.jp/law/321CONSTITUTION#Mp-At_27)「賃金、就業時間、休息その他の勤労条件に関する基準は、法律でこれを定める」を受けて1947年に制定された。労働者を使用するすべての事業に適用され（一部適用除外あり）、厚生労働省が所管し、労働基準監督署が監督を行う。

使用者が労働者に対して守るべき最低基準を定めており、この基準に達しない労働条件は無効となり、法定基準が適用される（第13条）。

## 主要規定

労働基準法の規定は、労働契約・労働時間・休暇・災害補償など多岐にわたる。以下では試験で問われやすい5つの分野を整理する。

### 労働契約と就業規則

労働契約の締結から終了まで、使用者が遵守すべき基本ルールを定めている。

| 項目 | 内容 |
|---|---|
| **労働条件の明示** | 賃金・労働時間等の条件を書面で明示（第15条） |
| **解雇予告** | 30日前の予告または30日分の平均賃金の支払い（第20条） |
| **就業規則の作成** | 常時10人以上の労働者を使用する事業場で作成・届出義務（第89条） |
| **就業規則の記載事項** | 始業・終業時刻、休日、賃金、退職に関する事項（絶対的必要記載事項） |

### 法定労働時間と休日

労働時間・休憩・休日に関する法定基準は以下のとおりである。

| 項目 | 基準 |
|---|---|
| **法定労働時間** | 1日8時間、1週40時間（第32条） |
| **休憩** | 6時間超：45分以上、8時間超：1時間以上（第34条） |
| **休日** | 毎週少なくとも1回、または4週に4回以上（第35条） |
| **変形労働時間制** | 1か月単位・1年単位・1週間単位・フレックスタイム制（第32条の2〜5） |

### 三六協定（時間外・休日労働）

法定労働時間を超えて労働させる場合、使用者は労働者の過半数代表との書面による協定（三六協定）を締結し、労働基準監督署に届け出なければならない（第36条）。

| 項目 | 内容 |
|---|---|
| **上限規制（原則）** | 月45時間・年360時間 |
| **特別条項付き上限** | 年720時間、単月100時間未満（休日労働含む）、2〜6か月平均80時間以内 |
| **適用猶予** | 建設事業・自動車運転業務・医師等は2024年4月から適用 |
| **罰則** | 上限規制違反：6か月以下の懲役または30万円以下の罰金 |

### 年次有給休暇

一定の要件を満たした労働者に有給の休暇を付与する制度である。

| 項目 | 内容 |
|---|---|
| **付与要件** | 6か月継続勤務し、全労働日の8割以上出勤 |
| **付与日数** | 6か月経過：10日、以後1年ごとに加算（最大20日） |
| **時季指定義務** | 年10日以上付与の労働者に年5日の取得を使用者が時季指定（2019年4月〜） |
| **時効** | 2年（未消化分は翌年に繰越可能） |

### 災害補償

業務上の負傷・疾病・障害・死亡について、使用者に補償責任を課している（第75〜88条）。

| 種類 | 内容 |
|---|---|
| **療養補償** | 必要な療養または療養費の負担 |
| **休業補償** | 平均賃金の60%を支給 |
| **障害補償** | 障害の程度に応じた平均賃金の補償 |
| **遺族補償** | 平均賃金の1,000日分 |
| **葬祭料** | 平均賃金の60日分 |

実務上は労災保険法に基づく保険給付により使用者の補償責任が免除される。

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**3.2 労働関係法と労務管理**」に位置づけられる。

労働基準法は労働関係法の基本法であり、[労働安全衛生法](/docs/pe-comprehensive-management-occupational-safety-act-osh)（安全管理）・最低賃金法（経済性管理）・労働契約法（人的資源管理）など他の労働関係法と密接に関連する。

総合技術監理の観点では、法定労働時間の遵守と工期・コストのトレードオフ、三六協定の上限規制が建設現場の工程管理に与える影響が重要なテーマとなる。
