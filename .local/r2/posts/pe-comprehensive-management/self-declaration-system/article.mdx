# 自己申告制度

## 自己申告制度とは

**自己申告制度**とは、従業員が自らのキャリア希望・異動希望・業務適性・能力開発ニーズ等を会社に申告する制度である。会社主導の人事異動の中に従業員の意向を反映させる仕組みであり、日本企業で広く導入されている。

## 申告の主な内容

| 項目 | 内容 |
|---|---|
| **キャリアビジョン** | 将来の目標・希望するキャリアパス |
| **異動希望** | 希望部署・希望地域・異動可否 |
| **現職の満足度** | 現在の業務・上司・職場環境の満足度 |
| **能力・適性** | 自己評価する能力・保有資格・特技 |
| **能力開発希望** | 受けたい研修・取得したい資格 |
| **家庭事情** | 介護・育児等の異動制約事情 |

## 社内公募制との比較

| 項目 | 自己申告制度 | 社内公募制 |
|---|---|---|
| **起点** | 個人（希望の申告） | 組織（ポストの公開） |
| **対象** | 全従業員（定期的） | 応募者のみ |
| **選考** | なし（参考情報） | あり |
| **異動の確実性** | 保証されない | 合格すれば確実 |
| **活用方法** | 人事異動の参考材料 | 特定ポストへのマッチング |

## 運用のポイント

| ポイント | 内容 |
|---|---|
| **秘密保持** | 申告内容が現部門上司に筒抜けにならない仕組み |
| **フィードバック** | 申告に対する何らかの応答がないと形骸化 |
| **面談との組合せ** | 申告書だけでなく上司・人事との面談で補完 |
| **活用の明示** | 申告内容がどう活用されるかの説明 |
