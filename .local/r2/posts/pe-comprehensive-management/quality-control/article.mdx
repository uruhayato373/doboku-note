# 品質管理

## 品質管理とは

品質管理（QC: Quality Control）とは、品質要求事項を満たすことに焦点を合わせた**品質マネジメント**の一部である。

工程（プロセス）を管理することで製品・サービスの品質を確保する活動を指す。

## QC七つ道具

QCの現場で広く使われる代表的な分析・可視化ツールが以下の7種類である。それぞれの目的を理解して使い分けることが品質改善活動の基本となる。

| 道具 | 用途 |
|---|---|
| **パレート図** | 不良項目を重要度順に整理する |
| **特性要因図** | 原因と結果の関係を体系的に整理する |
| **ヒストグラム** | データのばらつき・分布を可視化する |
| **管理図** | 工程の安定性を時系列で監視する |
| **散布図** | 2変数間の相関関係を把握する |
| **チェックシート** | データを分類・整理して収集する |
| **層別** | データを要因別に分類して分析する |

## TQC（全社的品質管理）とTQM

- **TQC**：全社的品質管理。品質管理を全部門で推進する
- **TQM**：総合的品質マネジメント。品質を経営の中核に据える発展形

## 品質管理の歴史的背景

現代の品質管理の原型は、1940年代に米国のW・エドワーズ・デミングと水準の統計的プロセス制御（SPC）にさかのぼる。戦後、デミングは日本科学技術連盟（JUSE）の招聘で来日し、統計的品質管理の手法を日本の製造業に伝えた。この流れを受けて1951年にデミング賞が創設され、日本全土でQC活動が急速に普及した。

1960年代には現場サークル活動（QCサークル）が製造現場に広がり、品質管理を全部門で実践する**TQC（全社的品質管理）**へ発展した。1990年代以降は経営戦略との統合を重視した**TQM（総合的品質マネジメント）**が主流となり、ISO 9001:1987（JIS Q 9001）の制定により国際標準化が進んだ。

建設分野では、1990年代後半から公共工事にISO 9001認証が広まり、施工管理基準との整合が図られた。2017年の品質確保促進法改正では、発注者・受注者双方が品質確保に責任を持つ枠組みが強化されている。

## 総合技術監理における位置づけ

総合技術監理キーワード集では[**2.2 品質の管理**](/docs/pe-comprehensive-management-keyword-2026#22-品質の管理)に位置づけられている。

品質管理は[工程能力指数（Cp・Cpk）](/docs/pe-comprehensive-management-process-capability-index)や[管理限界](/docs/pe-comprehensive-management-control-limits)などの統計的手法を用いて実施される。[品質保証](/docs/pe-comprehensive-management-quality-assurance)が「信頼感を与える活動」であるのに対し、品質管理は「要求事項を満たす活動」である。

5つの管理軸との関連では、品質管理は経済性管理・情報管理と密接に結びつく。[コスト管理](/docs/pe-comprehensive-management-cost-management)の観点では、品質不良による手戻り・手直しコストの削減が直接コスト低減につながる（品質コスト）。[情報管理](/docs/pe-comprehensive-management-information-management)の観点では、QC七つ道具で収集・分析したデータの記録・共有が工程改善の知識ベースとなる。
