# SATOYAMAイニシアティブ

## SATOYAMAイニシアティブとは

**SATOYAMAイニシアティブ**（Satoyama Initiative）とは、里山・里海のような人間活動と自然が長期にわたり相互作用してきた**二次的自然環境**（SEPLS: Socio-Ecological Production Landscapes and Seascapes）の持続可能な利用と管理を推進する国際的取組みである。

2010年、生物多様性条約COP10（名古屋）において日本が主導して提唱した。

原生的な自然の保護だけでなく、人間が適度に管理することで維持されてきた自然環境の価値を国際的に認知させた点で意義がある。

### 二次的自然環境（SEPLS）の特徴

| 特徴 | 内容 |
|---|---|
| **人間活動との共存** | 農林業等の人間活動により維持されてきた自然環境。管理を放棄すると生物多様性が低下 |
| **高い生物多様性** | 多様なハビタット（水田、畦畔、ため池、雑木林等）が多様な生物種を支える |
| **文化的価値** | 地域の伝統知識・文化と密接に結びついた景観 |
| **日本の里山・里海が原型** | 農村の雑木林、水田、ため池、沿岸の藻場・干潟など |

### 3つの行動指針

SATOYAMAイニシアティブは以下の3つのアプローチを柱としている。

| 指針 | 内容 |
|---|---|
| **1. 生態系サービスの多様な利用の確保** | 多種多様な生態系サービスを持続可能な形で利用。1つの生態系から複数の便益を引き出す「多面的利用」を推進 |
| **2. 自然資源の循環利用の促進** | 地域の自然資源を循環的に利用し、外部依存を低減。バイオマス利用、堆肥化、水の循環利用等 |
| **3. 地域の伝統的知識の活用とステークホルダーの参画** | 地域コミュニティが保有する伝統知識を活用し、多様な主体の参画による協働管理を実現 |

### IPSI（国際パートナーシップ）

**IPSI**（International Partnership for the Satoyama Initiative）は、SATOYAMAイニシアティブを推進する国際的なパートナーシップである。

| 項目 | 内容 |
|---|---|
| **設立** | 2010年（COP10で発足） |
| **事務局** | 国連大学サステイナビリティ高等研究所（UNU-IAS） |
| **参加主体** | 政府機関、NGO、研究機関、民間企業、先住民団体など300以上の組織 |
| **活動** | 事例収集・知見共有、政策提言、能力構築、共同研究プロジェクト |

### 日本における里山・里海の課題

| 課題 | 内容 |
|---|---|
| **管理放棄** | 過疎化・高齢化により里山の管理が行われなくなり、竹林や低木林に変化。生物多様性が低下 |
| **耕作放棄** | 水田の放棄により湿地性生物のハビタットが消失 |
| **外来種の侵入** | 管理の低下した里山・ため池に外来種が定着 |
| **獣害の増加** | 里山の荒廃により野生動物と人間の緩衝地帯が機能しなくなり、農作物被害が増加 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では[**6.1 地球的規模の環境問題**](/docs/pe-comprehensive-management-keyword-2026#61-地球的規模の環境問題)に位置づけられる。

SATOYAMAイニシアティブは生物多様性条約やGBFの30by30目標と連携し、OECM（保護地域以外の保全区域）の拡大にも貢献する取組みとして位置づけられている。
