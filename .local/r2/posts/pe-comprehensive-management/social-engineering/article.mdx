# ソーシャルエンジニアリング

## 概要

**ソーシャルエンジニアリング**とは、技術的な手段を用いずに、人間の心理的な弱点（信頼・恐怖・権威への服従・好奇心等）を巧みに利用して、機密情報やシステムへのアクセス権限を不正に取得する手法の総称である。

情報セキュリティにおいては、いかに堅牢な技術的対策を施しても、「人間」という最も脆弱な要素を突かれることで防御が無力化される危険性がある。

ソーシャルエンジニアリングは単独で用いられるだけでなく、標的型攻撃やフィッシング詐欺の初期段階として組み合わせて使用されることが多い。

## 手口・種類

### 主な手法

| 手法 | 内容 |
|---|---|
| **なりすまし（プリテキスティング）** | IT部門の担当者や取引先を装い、電話やメールでパスワードや機密情報を聞き出す |
| **ショルダーハッキング** | 背後からパスワード入力やPC画面を覗き見る |
| **トラッシング（ダンプスターダイビング）** | ゴミ箱から廃棄された書類・記録媒体を漁り、情報を収集する |
| **テールゲーティング（共連れ）** | 正規の入館者の後ろについて入退室管理を突破する |
| **ベイティング** | マルウェア入りのUSBメモリを駐車場やロビーに放置し、拾った人に接続させる |
| **クイドプロクォー** | 「IT部門ですが、問題解決のためにパスワードを教えてください」等の見返り型手口 |
| **ウォータリングホール（水飲み場型）** | 標的がよく利用するWebサイトにマルウェアを仕込む（技術手法との複合） |

### 悪用される心理的要因

| 心理的要因 | 内容 | 悪用例 |
|---|---|---|
| **権威への服従** | 上司や権威者の指示に従いやすい | 「社長からの緊急指示」と称するビジネスメール詐欺（BEC） |
| **信頼** | 同僚や取引先を信用する | 取引先を装ったなりすましメール |
| **恐怖・緊急性** | 「すぐに対応しないと大変なことになる」という焦り | 「アカウントが凍結されます」という偽通知 |
| **好奇心** | 興味を引く情報に手を出してしまう | 「給与一覧表」と書かれた不審なファイル |
| **返報性** | 何かをしてもらうとお返ししたくなる | 親切なふりをして情報提供を求める |

## 被害例

企業のCEOや経営幹部を装ったビジネスメール詐欺（BEC）により、数億円規模の送金被害が世界的に多発している。

IT部門を装った電話でパスワードをリセットさせ、システムに不正アクセスした事例がある。

廃棄文書から個人情報や取引先情報を収集し、より精巧ななりすまし攻撃に利用された事例がある。

## 対策

| 対策区分 | 具体的な対策 |
|---|---|
| **セキュリティ教育** | ソーシャルエンジニアリングの手口と事例の周知、定期的な訓練 |
| **本人確認の徹底** | 電話・メールによる情報提供依頼に対するコールバック確認、対面確認 |
| **物理的対策** | 入退室管理の厳格化（共連れ防止）、クリアデスクポリシー、シュレッダーの設置 |
| **情報分類と管理** | 機密レベルに応じた情報の取扱いルール、Need-to-Know原則の徹底 |
| **組織的対策** | インシデント報告体制の整備、不審な依頼を断りやすい組織文化の醸成 |
| **技術的補完** | メール認証（SPF/DKIM/DMARC）、USB使用制限、プライバシーフィルターの活用 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**4.5 情報セキュリティ**」に位置づけられる。

ソーシャルエンジニアリングは人的資源管理（教育訓練・組織行動論）と情報管理（セキュリティ対策）の交差領域に位置する。

技術的対策だけでは防げない人的脆弱性への対応として、組織文化や教育体制を含めた総合的なセキュリティマネジメントが、総合技術監理の視点では不可欠となる。
