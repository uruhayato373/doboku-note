# PERT/CPM

## PERT/CPMとは

- **PERT**（Program Evaluation and Review Technique）：作業時間に確率的変動を考慮したネットワーク手法
- **CPM**（Critical Path Method）：各作業の所要時間を確定値として扱い、クリティカルパスを特定する手法

いずれも**ネットワーク工程表**（アロー・ダイアグラムまたはプレシデンス・ダイアグラム）を用いて工程を管理する。

## クリティカルパス

クリティカルパスとは、**ネットワーク工程表において最も所要時間が長い経路**であり、プロジェクト全体の工期を決定する。

- クリティカルパス上の作業が遅延すると全体工期が延びる
- **トータルフロート（余裕時間）がゼロ**の作業で構成される
- 工期短縮にはクリティカルパス上の作業を優先的に改善する

## PERTとCPMの違い

| 項目 | PERT | CPM |
|---|---|---|
| **作業時間** | 確率的（3点見積り） | 確定的（1点見積り） |
| **適用場面** | 不確実性の高いプロジェクト | 実績データのあるプロジェクト |
| **重視する点** | 時間の不確実性 | コストと時間のトレードオフ |

## PERTの3点見積り

PERTでは、各作業の所要時間を**3点見積り**で設定し、期待時間を確率的に求める。

- **楽観時間（O）**：最も楽観的な場合の所要時間
- **最頻時間（M）**：最も可能性が高い場合の所要時間
- **悲観時間（P）**：最も悲観的な場合の所要時間

期待時間（$t_e$）の計算式：

$$t_e = \frac{O + 4M + P}{6}$$

## CPMの4つの管理時刻とフロート

CPMでは、各作業について以下の4つの時刻を管理する。

| 時刻 | 略称 | 意味 |
|---|---|---|
| **最早開始時刻** | EST | 最も早く作業を開始できる時刻 |
| **最早終了時刻** | EFT | 最も早く作業を終了できる時刻 |
| **最遅開始時刻** | LST | 全体工期を遅延させずに最も遅く開始できる時刻 |
| **最遅終了時刻** | LFT | 全体工期を遅延させずに最も遅く終了できる時刻 |

**フロート（余裕時間）** ＝ LST − EST ＝ LFT − EFT

フロートがゼロの作業がクリティカルパス上の作業であり、1日でも遅れるとプロジェクト全体の遅延につながる。

### ネットワーク図のサンプル

| 作業 | 所要期間（日） | 先行作業 |
|------|-------------|--------|
| A | 2 | なし |
| B | 5 | なし |
| C | 7 | A, B |
| D | 4 | A, B |
| E | 1 | なし |
| F | 9 | C |

この場合、クリティカルパスは B → C → F（5 + 7 + 9 = 21日）となる。
