# グリーンインフラ

## グリーンインフラとは

グリーンインフラ（Green Infrastructure）とは、自然環境が有する多様な機能を社会資本整備や土地利用等に活用し、持続可能で魅力あるまちづくりや地域づくりを進める取り組みである。

2015年に閣議決定された国土形成計画および第4次社会資本整備重点計画において、グリーンインフラの取り組みを推進することが明記された。

2019年にはグリーンインフラ官民連携プラットフォームが設立され、産学官民の連携による推進体制が整備されている。

### 自然環境の多機能性

グリーンインフラが発揮する機能は防災から経済効果まで多岐にわたる。主な機能分類と活用例を以下に示す。

- **防災・減災**: 雨水貯留・浸透、洪水緩和 — 雨庭、透水性舗装、遊水池
- **環境保全**: 生物多様性の確保、水質浄化 — ビオトープ、人工湿地
- **気候変動緩和・適応**: CO2吸収、ヒートアイランド緩和 — 街路樹、屋上緑化、壁面緑化
- **景観・アメニティ**: 良好な景観形成、レクリエーション — 都市公園、親水空間
- **健康・福祉**: 精神的健康の向上、運動促進 — 緑道、コミュニティガーデン
- **経済効果**: 不動産価値の向上、観光資源 — 緑豊かなまちなみ形成

### グレーインフラとの関係

グレーインフラ（コンクリート・鋼材等の人工構造物）とグリーンインフラには、機能面・コスト面で対照的な特性がある。両者の違いとハイブリッドの特性を以下に整理する。

- **構成**
  - グレーインフラ: 人工構造物
  - グリーンインフラ: 自然環境
  - ハイブリッド: 両者の組み合わせ
- **機能**
  - グレーインフラ: 単機能
  - グリーンインフラ: 多機能
  - ハイブリッド: 多機能＋確実性
- **初期コスト**
  - グレーインフラ: 高い
  - グリーンインフラ: 比較的低い
  - ハイブリッド: 中程度
- **維持管理**
  - グレーインフラ: 劣化・更新が必要
  - グリーンインフラ: 自律的回復力あり
  - ハイブリッド: 両方の管理が必要
- **効果発現**
  - グレーインフラ: 即時的
  - グリーンインフラ: 時間がかかる場合あり
  - ハイブリッド: 段階的に発現

### 主な施策

国土交通省を中心に、グリーンインフラの社会実装を支援する以下の施策が展開されている。

| 施策 | 内容 |
|---|---|
| **グリーンインフラ活用型都市構築支援事業** | 国交省による財政的支援制度 |
| **官民連携プラットフォーム** | 産学官民の情報共有・連携体制（2019年〜） |
| **グリーンインフラ技術集** | 国交省が技術的知見を集約した手引き |
| **流域治水との連携** | 流域のあらゆる関係者が協働する治水対策にグリーンインフラを組み込み |
| **カーボンニュートラルとの連携** | 都市緑化によるCO2吸収源の確保 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では[**6.2 地域環境問題**](/docs/pe-comprehensive-management-keyword-2026#62-地域環境問題)に位置づけられる。

グリーンインフラは社会環境管理の中核的概念であり、安全管理（[Eco-DRR](/docs/pe-comprehensive-management-eco-drr)による防災・減災）、経済性管理（ライフサイクルコスト、不動産価値向上）、人的資源管理（健康増進、ウェルビーイング）の各分野と横断的に関連する。総合技術監理の観点からは、多機能性を定量的に評価し、グレーインフラとの最適な組み合わせを判断する能力が求められる。

## 歴史と背景

グリーンインフラの概念は1990年代後半に米国で体系化され、欧州を中心に国際的な広がりをみせた。

米国では、都市部の合流式下水道対策として雨水管理に自然機能を活用する試みが先行した。2010年頃には環境保護庁（EPA）が雨水管理のためのグリーンインフラ計画を策定し、技術的知見の蓄積が進んだ。欧州では2013年に欧州委員会がグリーンインフラ戦略を採択し、生物多様性保全と生態系サービスの維持を政策の柱に位置づけた。

日本への本格導入は2013年頃から始まり、2014年には産学連携によるグリーンインフラ研究会が設立された。2015年の国土形成計画への明記を機に政策上の位置づけが確立し、2019年の官民連携プラットフォーム設立、2023年の「グリーンインフラ推進戦略2023」策定へと展開が続いている。

気候変動適応・防災・生物多様性保全という複数の政策課題に横断的に対応できる点が、各国で重視される共通の背景である。
