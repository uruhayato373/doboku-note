# ウェルビーイング

## ウェルビーイングとは

**ウェルビーイング（Well-being）** とは、身体的・精神的・社会的に良好な状態にあることを意味する包括的な概念である。

WHO（世界保健機関）憲章（1946年）では、「健康とは、病気でないとか、弱っていないということではなく、肉体的にも、精神的にも、そして社会的にも、すべてが満たされた状態にあること」と定義しており、これがウェルビーイングの原点とされる。

近年、企業経営においてもウェルビーイングが注目され、従業員の幸福が生産性・創造性・定着率の向上に寄与するという実証研究が蓄積されている。

### ウェルビーイングの2つのアプローチ

- **ヘドニック（快楽主義的）**（ベンサム、カーネマン）: 快楽の最大化と苦痛の最小化 — 測定の焦点: 主観的幸福感、ポジティブ感情、生活満足度
- **ユーダイモニック（自己実現的）**（アリストテレス、リフ）: 人間としての潜在能力の実現、意味ある生 — 測定の焦点: 人生の意味、自律性、成長、社会への貢献

現代のウェルビーイング研究は、両アプローチを統合した多次元的な捉え方が主流である。

### 主要なウェルビーイング理論・モデル

- **PERMAモデル**（セリグマン）: Positive Emotion（快感情）、Engagement（没入）、Relationships（関係性）、Meaning（意味）、Accomplishment（達成）
- **心理的ウェルビーイングの6次元**（リフ）: 自己受容、人生の目的、環境統制、人格的成長、自律性、積極的対人関係
- **主観的ウェルビーイング**（ディーナー）: 生活満足度、ポジティブ感情、ネガティブ感情（の少なさ）
- **ギャラップの5要素**（ギャラップ社）: キャリア、ソーシャル、ファイナンシャル、フィジカル、コミュニティ

### 組織におけるウェルビーイング経営

| 施策領域 | 具体例 |
|---|---|
| **身体的ウェルビーイング** | 健康経営の推進、運動習慣の支援、長時間労働の是正 |
| **精神的ウェルビーイング** | メンタルヘルス対策、ストレスチェック、EAP（従業員支援プログラム） |
| **社会的ウェルビーイング** | 職場の人間関係改善、心理的安全性の確保、ダイバーシティの推進 |
| **キャリア・ウェルビーイング** | キャリア自律の支援、成長機会の提供、意味ある仕事の割当 |
| **経済的ウェルビーイング** | 適正な報酬、福利厚生の充実、ファイナンシャル・リテラシー教育 |

### ウェルビーイングと組織成果の関係

| 成果指標 | ウェルビーイングとの関連 |
|---|---|
| **生産性** | ウェルビーイングの高い従業員は生産性が12〜31%高い（オックスフォード大学等の研究） |
| **離職率** | 低下する（組織への愛着・情緒的コミットメントが高まる） |
| **創造性** | ポジティブ感情が拡張形成理論（フレデリクソン）により創造性を促進 |
| **欠勤率** | 低下する（身体的・精神的健康が改善） |
| **安全行動** | 向上する（注意力・判断力が良好な状態で維持される） |

### 日本における政策動向

| 政策・取組 | 内容 |
|---|---|
| **健康経営優良法人認定制度** | 経済産業省が従業員の健康管理を経営的視点で実践する法人を認定 |
| **骨太の方針（2021年）** | 政府がウェルビーイングに関するKPIの設定を明記 |
| **Well-being指標** | 内閣府がGDP以外の社会の豊かさを測る指標群を整備 |
| **働き方改革関連法** | 長時間労働の是正、多様な働き方の実現を法制度で推進 |

### 限界と留意点

| 限界 | 内容 |
|---|---|
| **測定の主観性** | ウェルビーイングは主観的な要素が大きく、客観的測定が難しい |
| **文化的差異** | 幸福の定義や重視する次元は文化によって異なる |
| **因果関係の不明確さ** | ウェルビーイングが成果を生むのか、成果がウェルビーイングを生むのかの方向性は複雑 |
| **形式化のリスク** | ウェルビーイング施策が従業員の実感と乖離した「見せかけ」になりうる |

## 総合技術監理における位置づけ

総合技術監理キーワード集では[**3.1 人の行動と組織**](/docs/pe-comprehensive-management-keyword-2026#31-人の行動と組織)に位置づけられる。

ウェルビーイングは人的資源管理の目標概念であると同時に、安全管理（心身の健康が安全行動の前提）、経済性管理（生産性・創造性への影響）、社会環境管理（持続可能な社会の実現）とも横断的に関連する。

総合技術監理技術者は、ウェルビーイングを単なる福利厚生ではなく組織パフォーマンスの基盤として位置づけ、5つの管理分野を統合する視点で施策を設計することが求められる。
