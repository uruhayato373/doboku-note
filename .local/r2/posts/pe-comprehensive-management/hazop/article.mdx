# HAZOP

## HAZOPとは

HAZOP（Hazard and Operability Study：危険・運転性検討）とは、**プロセスの設計意図からの逸脱を体系的に検討し、ハザードや運転上の問題を特定する手法**である。

1960年代に英国ICI社で化学プラントの安全分析手法として開発された。**ガイドワード**を用いてプロセスパラメータの逸脱を網羅的に検討する点が特徴である。

## ガイドワード

| ガイドワード | 意味 | 逸脱の例（流量に対して） |
|---|---|---|
| **No / Not** | 設計意図の完全な否定 | 流れない |
| **More** | 量的な増加 | 流量が多すぎる |
| **Less** | 量的な減少 | 流量が少なすぎる |
| **As Well As** | 質的な増加（異物混入等） | 想定外の物質が混入 |
| **Part Of** | 質的な減少（成分の一部欠落） | 一部の成分が欠落 |
| **Reverse** | 逆方向 | 逆流する |
| **Other Than** | 設計意図と全く異なる | 別の物質が流れる |

## 実施手順

| ステップ | 内容 |
|---|---|
| **1. ノードの設定** | プロセスを分析単位（ノード）に分割する |
| **2. 設計意図の確認** | 各ノードの正常な運転条件を明確にする |
| **3. 逸脱の検討** | ガイドワードをプロセスパラメータに適用して逸脱を導出する |
| **4. 原因と結果の特定** | 各逸脱の原因と、それによる影響を評価する |
| **5. 対策の検討** | 既存の安全対策の妥当性を評価し、追加対策を検討する |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**5.6 システム安全工学手法**」に位置づけられている。

HAZOPは[FMEA](/docs/pe-comprehensive-management-fmea)と並ぶ代表的なハザード分析手法である。[PHA](/docs/pe-comprehensive-management-pha)が概略的なハザード評価であるのに対し、HAZOPはより詳細なプロセス分析に用いられる。
