# 営業支援（SFA）システム

## SFAシステムとは

SFA（Sales Force Automation: 営業支援システム）とは、営業活動のプロセスを可視化・標準化し、営業担当者の生産性向上と組織的な営業力強化を実現する情報システムである。

営業活動は属人的になりやすく、担当者の異動・退職により顧客情報や商談状況が失われるリスクがある。

SFAはこうした営業の「見えない活動」をデータ化し、組織全体で共有可能にすることで、営業の属人化を解消する。

### 主な機能

| 機能分類 | 主な機能 | 内容 |
|---|---|---|
| **商談管理** | 案件登録・進捗管理 | 商談のステージ（初回訪問→提案→見積→受注）を可視化 |
| **活動管理** | 訪問・電話・メールの記録 | 営業活動量の把握と分析 |
| **パイプライン管理** | 売上予測・案件一覧 | 受注見込みの精度向上 |
| **日報・週報** | 活動報告の入力・共有 | マネージャーのコーチング支援 |
| **名刺管理** | 名刺情報のデジタル化 | 顧客接点情報の組織共有 |
| **モバイル対応** | スマートフォンからの入力 | 外出先でのリアルタイム情報更新 |

### SFAとCRMの違い

SFAとCRMは密接に関連するが、カバーする範囲と主な利用者が異なる。

| 比較項目 | SFA | CRM |
|---|---|---|
| **目的** | 営業プロセスの効率化 | 顧客関係の長期的管理 |
| **主な利用者** | 営業担当者・営業マネージャー | マーケティング・営業・サービス部門全体 |
| **管理対象** | 商談・活動・売上予測 | 顧客情報・接触履歴・サービス履歴 |
| **カバー範囲** | 営業プロセス（リード→受注） | 顧客ライフサイクル全体 |
| **関係性** | CRMの一部として位置づけられることが多い | SFA機能を内包する上位概念 |

実際の製品では、SFA機能を備えたCRMパッケージとして一体提供されるケースが多い。

### 導入効果と他システムとの連携

| 観点 | 導入効果 |
|---|---|
| **営業の可視化** | 商談ステージ・活動量・受注率の定量把握 |
| **属人化の排除** | 担当引継ぎ時の情報ロス防止 |
| **売上予測精度** | パイプラインに基づく客観的な予測 |
| **マネジメント強化** | データに基づく指導・戦略立案 |
| **営業生産性** | 事務作業の削減、提案活動への集中 |

| 連携先システム | 連携データ | 連携の効果 |
|---|---|---|
| **CRMシステム** | 顧客情報・接触履歴 | 顧客理解に基づく営業活動 |
| **販売管理システム** | 受注・売上実績 | 商談と実績の突合 |
| **マーケティングオートメーション** | リード情報 | 見込客の営業チームへの引き渡し |
| **グループウェア** | スケジュール・メール | 営業活動の効率化 |

## 総合技術監理における位置づけ

総合技術監理キーワード集では「**4.4 情報通信技術動向**」に位置づけられる。

SFAはCRMの一機能として営業プロセスを支援し、販売管理システムやERPと連携することで、経済性管理（2章）における売上管理の精度向上と人的資源管理（3章）における営業人材の生産性向上に寄与する。
