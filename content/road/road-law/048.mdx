# 第48条（道路保全立体区域内の制限）

> **第四十八条** 道路保全立体区域内にある土地、竹木又は建築物その他の工作物の所有者又は占有者は、その土地、竹木又は建築物その他の工作物が道路の構造に損害を及ぼし、又は交通に危険を及ぼすおそれがあると認められる場合においては、その損害又は危険を防止するための施設を設け、その他その損害又は危険を防止するため必要な措置を講じなければならない。
>
> **3** 第一項に規定する所有者又は占有者は、高架の道路の橋脚の周囲又は地盤面下の道路の上下における土石の採取その他の道路保全立体区域における行為であって、道路の構造に損害を及ぼし、又は交通に危険を及ぼすおそれがあると認められるものを行ってはならない。

## 一 趣旨

本条は、道路保全立体区域においては、土地の所有者等は、沿道区域におけるものと同様の損害予防義務等のほかに、一定の行為制限を受けるものとする規定である。

## 二 第一項と第三項の違い

第一項は、道路保全立体区域内に土地等が存すること自体により生じる道路の支障を防止するための規定であり、不作為によって生じる損害や危険を防止するために土地の所有者等に行為義務を課すものである。第三項は、道路保全立体区域内において行われる行為によって生じる道路の支障を防止するための規定であり、作為によって生じる損害や危険を防止するために不作為義務等を課すものである。

## 三 具体的な禁止行為

- 高架の道路の橋脚の周囲又は地盤下の道路の上下における土石の採取
- 高架下等における爆発物等の不正使用
- 高架下で行われる大規模な火入れ、焚き火その他これらに類する行為
- 地盤下で行われる一定以上の重量を有する物件の設置
- 高架下における煙、ガスの排出

# 第48条の2（自動車専用道路の指定）

> **第四十八条の二** 道路管理者は、交通が著しくふくそうして道路における車両の能率的な運行に支障のある市街地及びその周辺の地域において、交通の円滑を図るために必要があると認めるときは、まだ供用の開始がない道路について、自動車のみの一般交通の用に供する道路を指定することができる。

## 一 趣旨

道路は、本来広く一般交通の用に供されるべきものであるが、交通の状況によっては、自動車、自転車、歩行者等が混合して通行した場合に車両の能率的な運行に支障が生ずることが想定される。本条は、特定の道路について、自動車のみの一般交通の用に供することができる旨を定めている。

## 二 指定要件

### (1) 第一項自動車専用道路

- 交通が著しくふくそうして車両の能率的な運行に支障のある市街地及びその周辺の地域であること
- まだ供用の開始がない道路であること

### (2) 第二項自動車専用道路

- 交通が著しくふくそうし、又はふくそうすることが見込まれること
- 通常他に道路の通行の方法があって、自動車以外の方法による通行に支障のないこと

## 三 指定の公示

自動車専用道路の指定が行われると、立入制限等の行為制限及び罰則等が生ずるため、公示は指定の効力発生要件である。

# 第48条の3（道路等との交差の方式）

> **第四十八条の三** 道路管理者は、自動車専用道路を道路等と交差させようとする場合においては、当該交差の方式は、立体交差としなければならない。

自動車専用道路を他の道路等と交差させる場合の交差方式を定めた規定であり、原則として立体交差としなければならない。ただし、交通量が少ない場合、地形上やむを得ない場合等は立体交差としなくてもよい。

# 第48条の4（自動車専用道路との連結の制限）

> **第四十八条の四** 次に掲げる施設以外の施設は、自動車専用道路と連結させてはならない。

連結許可対象施設は、道路等、休憩所・給油所等の利便施設、これらの施設と自動車専用道路とを連絡する通路等である。

# 第48条の5（連結許可等）

自動車専用道路と連結させる施設については、道路管理者の許可を受けなければならない。連結の許可に当たっては、自動車専用道路の構造の保全と安全かつ円滑な交通の確保のため必要な条件を付することができる。

# 第48条の7（連結料の徴収）

道路管理者は、連結許可を受けた施設の連結に係る連結料を徴収することができる。

# 第48条の9（連結許可の取消し等）

道路管理者は、連結許可を受けた者が許可の条件に違反した場合等には、連結の許可を取り消すことができる。

# 第48条の11（出入の制限等）

自動車専用道路は、自動車のみの一般交通の用に供する道路であるから、道路管理者は、入口その他必要な場所に通行の禁止又は制限の対象を明らかにした道路標識を設けなければならない。

# 第48条の12（違反行為に対する措置）

道路管理者は、自動車専用道路に関する禁止行為に違反した者に対し、行為の中止その他必要な措置を命ずることができる。

# 第48条の13（自転車専用道路等の指定）

> **第四十八条の十三** 道路管理者は、自転車又は歩行者の安全かつ円滑な通行を確保するため特に必要があると認めるときは、まだ供用の開始がない道路又は道路の部分について、自転車専用道路、自転車歩行者専用道路又は歩行者専用道路を指定することができる。

# 第48条の14（道路等との交差等）

自転車専用道路等を道路等と交差させようとする場合には、立体交差とするよう努めなければならない。

# 第48条の15（通行の制限等）

自転車専用道路等における通行の制限について定めたものである。

# 第48条の16（違反行為に対する措置）

自転車専用道路等に関する違反行為に対する措置命令について定めたものである。

# 第48条の17（利便施設協定の締結等）

> **第四十八条の十七** 道路管理者は、道路の通行者又は利用者の利便の増進に資する施設等について、当該施設等を設けようとする者と協定を締結することができる。

道路管理者は、道路の区域内の地上に通行者等の利便の増進に資する施設を設け、又は管理する者と、当該施設の設置・管理に関する事項を定めた利便施設協定を締結することができる。

# 第48条の18（利便施設協定の縦覧等）

利便施設協定を締結しようとするときは、その旨を公告し、協定の案を縦覧に供しなければならない。

# 第48条の19（利便施設協定の効力）

公示のあった利便施設協定は、その公示のあった後において協定施設の管理者となった者に対しても効力がある。

# 第48条の20（道路協力団体の指定）

道路管理者は、道路の管理に関する活動を適正かつ確実に行うことができると認められる法人その他の団体を、道路協力団体として指定することができる。

# 第48条の21（道路協力団体の業務）

道路協力団体は、道路の管理に関する情報又は資料の収集及び提供、道路管理者に対する技術的な助言等の業務を行う。

# 第48条の23（情報の提供等）

道路管理者は、道路協力団体に対し、その業務の実施に関し必要な情報の提供又は指導若しくは助言をすることができる。

# 第48条の24（道路協力団体に対する道路管理者の承認等の特例）

道路協力団体がその業務として行う道路の占用等について、手続の特例を定めたものである。

# 第48条の25（踏切道の改良への協力）

踏切道の改良について、鉄道事業者その他の関係者の協力義務を定めたものである。踏切道の安全確保のための注意看板の設置、迂回路の案内等の情報提供、啓発活動等が想定されている。
