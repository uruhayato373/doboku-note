# B-12 監督処分と実態調査 — 立入検査・指示・営業停止を避ける社内の備え（骨子）

## 読者と場面
- 国土交通省や都道府県から下請取引等実態調査の調査票が届いた、立入検査や建設Gメンの調査の連絡が来た、指導票や勧告を受けた、元請から法令遵守の確認を求められた。そのとき「何を聞かれ、どの根拠で処分が決まり、日頃何を整えておけばよいか」で迷う、建設会社の経営者・管理部門・現場の責任者。
- 調査や検査を避ける話ではなく、聞かれる項目と処分の決まり方を知って、社内の帳簿・契約書類・届出・是正の記録をそろえる話として書く。
- 数字は国土交通省の令和7年度の活動結果と調査結果、処分の基準は令和8年10月1日の最終改正から引く。個別の事案の対応は弁護士や許可行政庁への相談を前提にする。
- この章が扱わないこと: 元請が守る取引ルールの中身（B-07）、作業員への指示と偽装請負（B-08）、経審の虚偽申請の処分の詳細（B-05）、許可の要件と届出の期限（B-03・B-04）、審査会による紛争の解決（B-11）。

## 論点
- 監督の入口は、調査・通報・立入検査の三つ
  - 根拠: mlit-compliance-headquarters-activity-2026-05 国土交通省 令和7年度「建設業法令遵守推進本部」の活動結果及び令和8年度の活動方針（令和8年5月・不動産・建設経済局建設業課）本文1〜2（疑義情報の収集、報告徴収及び立入検査）
  - 根拠: construction-business-act#第30条 不正事実の申告（利害関係人が許可行政庁へ申告できる）
- 報告と立入検査には応じる義務があり、拒むと罰則
  - 根拠: construction-business-act#第31条 報告徴収及び立入検査（第1項 大臣は建設業を営む全ての者、知事は区域内の者へ。第2項 身分証明書の携帯・提示、犯罪捜査のための権限ではない）
  - 根拠: construction-business-act#第52条 報告をせず・虚偽の報告・検査の拒み妨げ忌避は100万円以下の罰金（第5号・第6号）
  - 根拠: construction-business-act#第53条 法人の代表者・従業者の違反行為は法人にも罰金刑
  - 本: construction-business-act-tips-3rd/u0533
- 実態調査は毎年あり、近年は3万者に出る
  - 根拠: mlit-subcontract-survey-request-2026 国土交通省 令和8年度下請取引等実態調査への回答のお願い（国土交通大臣と中小企業庁長官が毎年実施。無作為抽出30,000業者、回答期限 令和8年8月25日、対象期間 令和7年7月1日〜令和8年6月30日、法第31条第1項・第42条の2第1項に基づく）
  - 根拠: mlit-subcontract-survey-results-2025 国土交通省 令和7年度下請取引等実態調査の結果概要（30,000業者に実施、回収19,964者・回収率66.5%、集計17,756者、指導票を送付した元請負人17,207業者）
  - 根拠: construction-business-act#第40条の4 国土交通大臣による調査等（請負契約の締結状況などを調査し、結果を公表する）
  - 本: construction-business-act-tips-3rd/u0548
- 適正回答率が低いのは、見積提示と契約条項
  - 根拠: mlit-subcontract-survey-results-2025 令和7年度下請取引等実態調査の結果概要 1-(2)（高い: 支払期間98.7％・決定方法96.0％・支払手段92.9％。低い: 契約締結方法62.7％・施工体制台帳の添付書類48.7％・契約条項33.7％・見積提示内容17.9％）
  - 本: construction-business-act-tips-3rd/u0554
- 契約書は15項目、見積条件は14項目をそろえる
  - 根拠: construction-business-act#第19条 契約書の記載事項（第1項 各号15事項、書面を相互に交付）
  - 根拠: construction-business-act#第20条 見積り等（第3項 注文者は第19条第1項各号のうち第2号を除く事項を、見積りの前に具体的に提示。第1項 材料費等記載見積書）
  - 根拠: mlit-construction-business-act-compliance-guideline-12 国土交通省 建設業法令遵守ガイドライン（第12版・令和8年1月最終改訂）pp.2-4（見積条件の提示、工事内容として最低限明示する8事項）
  - 根拠: mlit-subcontract-survey-results-2025 令和7年度下請取引等実態調査の結果概要（※6 契約書に定めるべき15項目の全て、※7 見積条件の提示すべき14項目の全て）
- 調査は見積り・契約・工期・転嫁・支払いを見る
  - 根拠: mlit-compliance-headquarters-activity-2026-05 令和8年度の活動方針 別紙③（1）〜（5）（労務費と請負代金、契約書面と契約変更の条項、工期の設定、価格転嫁の協議、支払い・手形・振込手数料）
  - 根拠: mlit-subcontract-survey-results-2025 令和7年度下請取引等実態調査の結果概要 2（労務費の内訳明示の見積書、価格変更の協議、工期の見積書、現場閉所）
- 疑義情報から建設Gメンの調査へ、立入検査へ進む
  - 根拠: mlit-compliance-headquarters-activity-2026-05 令和7年度の活動結果（法令違反疑義情報3,558件、うち駆け込みホットライン1,946件、実態調査の情報を基に違反疑義として抽出612件、立入検査等1,152業者・1,318件）と令和8年度の方針 2（通報で疑われる業者、営業所の実態や技術者の配置に疑義のある業者、過去に指導監督を受けた業者を中心に機動的に実施）
  - 根拠: construction-business-act#第40条の4 国土交通大臣による調査等
  - 本: construction-business-act-tips-3rd/u0533
- 通報した下請への不利益な取扱いは禁じられている
  - 根拠: construction-business-act#第24条の5 不利益取扱いの禁止（通報を理由とした取引の停止などを禁じる）
  - 根拠: mlit-compliance-headquarters-activity-2026-05 令和8年度の活動方針 1（通報者の秘密保持、その後の取引状況の適時フォロー）
- 処分は指示、営業停止、許可取消の順に重くなる
  - 根拠: construction-business-act#第28条 指示及び営業の停止（第1項 指示、第3項 1年以内の営業の全部又は一部の停止、指示に従わないときも停止を命じられる）
  - 根拠: construction-business-act#第29条 許可の取消し（第1項第8号 情状特に重い場合、営業停止処分違反）
  - 根拠: mlit-supervisory-disposition-criteria-2026-10 国土交通省 建設業者の不正行為等に対する監督処分の基準（最終改正 令和8年10月1日国不建第95号）二3(3)・三1（処分に至らない場合は勧告等を機動的に行う）
- 故意・重過失は原則営業停止、他は原則指示
  - 根拠: mlit-supervisory-disposition-criteria-2026-10 監督処分の基準（令和8年10月1日国不建第95号）三1(1)（法第28条第1項各号に当たる不正行為は故意・重過失なら原則営業停止、その他は原則指示）・三1(2)（第11条・第19条・第40条・第40条の3違反などは指示）
- 営業停止中は、新規契約と入札・見積りができない
  - 根拠: mlit-supervisory-disposition-criteria-2026-10 監督処分の基準 二6・別表（できない: 新たな請負契約の締結と関連する入札・見積り・交渉。できる: 許可・経審・入札参加資格の申請、既契約の施工、瑕疵の修繕、請負代金の請求・受領、災害時の緊急工事）
  - 根拠: construction-business-act#第29条の3 処分前に結んだ請負契約の工事は施工できる（2週間以内に注文者へ通知、注文者は30日以内に解除できる）
  - 根拠: construction-business-act#第29条の4 営業の禁止（営業停止を命じるとき、役員等にも同じ期間の新たな営業の開始を禁じる）
- 停止の日数には、事由ごとの目安がある
  - 根拠: mlit-supervisory-disposition-criteria-2026-10 監督処分の基準 三2（主任技術者等の不設置は15日以上、不正取得の資格者を置いたときは30日以上、一括下請負は15日以上、無許可業者との下請契約と施工体制台帳等の不作成は7日以上、談合・贈賄などは事由に応じ30日〜1年）
  - 根拠: mlit-compliance-headquarters-activity-2026-05 令和7年度の活動結果 ④（許可取消1業者、営業停止14業者、指示4業者、勧告・文書指導等768業者と主な事由）
  - 本: construction-business-act-tips-3rd/u0533
- 処分は公表され、経審の法令遵守の項目に響く
  - 根拠: construction-business-act#第29条の5 監督処分の公告、建設業者監督処分簿を公衆の閲覧に供する
  - 根拠: mlit-supervisory-disposition-criteria-2026-10 監督処分の基準 四③（処分の内容は速やかに公表する）
  - 根拠: cbr-keishin-handbook-2026-07 中部地方整備局 経営規模等評価申請・総合評定値請求の手引き（令和8年7月1日）項番56・57（法第28条に基づく営業停止処分・指示処分の有無を、審査基準日直前1年間について記入。行政指導（勧告等）と指名停止は該当しない）
  - 根拠: mlit-negative-info-site 国土交通省 ネガティブ情報等検索サイト 本サイトについて（過去の処分歴を行政が公開する趣旨）
- 帳簿・契約書類・決算の届出を期限どおりにそろえる
  - 根拠: construction-business-act#第40条の3 帳簿の備付け等（営業所ごとに帳簿を備え、帳簿と営業に関する図書を保存する）
  - 根拠: construction-business-act-rule#第26条 建設業法施行規則第26条（帳簿の記載事項、契約書面・施工体制台帳・材料費等記載見積書などの添付と保存。令和8年7月1日施行版）
  - 根拠: construction-business-act#第11条 変更等の届出（第2項 毎事業年度経過後4か月以内に決算関係の書類を提出）
  - 根拠: construction-business-act#第50条 届出書類を出さない・虚偽の記載で出す行為は6月以下の拘禁刑又は100万円以下の罰金
- 指導票や指示を受けたら、是正して記録を残す
  - 根拠: mlit-subcontract-survey-results-2025 令和7年度下請取引等実態調査の結果概要 1-(1)（指導が必要と認められた元請負人に指導票を送付し、是正措置を求める）
  - 根拠: mlit-supervisory-disposition-criteria-2026-10 監督処分の基準 二3(4)（指示処分後は従っているかを点検・調査する）・二5(2)（指示の内容を実行しない、または3年以内に指示に違反して類似の行為をしたときは営業停止）
  - 根拠: construction-business-act#第28条 第3項（指示に従わないとき営業停止を命じられる）

## 既存記事との分担
- content/site/civil-practice/subcontract-fair-dealing/article.mdx: 元請が守る書面の形・一括下請負・意見聴取・資材の指定・やり直し費用・引渡しの決まりが、令和8年1月の建設業法令遵守ガイドライン（第12版）を土台に書いてある。実態調査・建設Gメン・立入検査・監督処分の節は無い → 取引ルールの中身は再掲せず、リンクで済ませる。この章は、そのルールを「誰がどう調べ、守れていないと何が起きるか」の側から書く。
- content/site/civil-practice/subcontract-instruction-boundary/article.mdx: 作業員への指示と偽装請負の線引き → 取り上げない。調査項目として触れるときはリンクで済ませる。
- content/site/civil-practice/keishin-bidder-qualification/article.mdx の「虚偽申請は、罰則と営業停止の対象になる」の節（183行目〜）: 経審の虚偽申請の罰則（法第50条）と営業停止30日以上・45日以上 → 再掲しない。この章は、処分の段階と原則、営業停止中の制限、処分が経審の法令遵守の項目に響くことを書く。
- content/site/civil-practice/foreign-workers-site-check/article.mdx（208行目・279行目）: 特定技能の受入れ条件に、申請日前5年以内に監督処分（一部を除く）を受けていないことが入っている → 処分が波及する先の一つとして、リンクで示す。条件の中身は書かない。
- B-03・B-04（許可の要件と手続き）が、要件を欠いたときの届出の期限や更新・変更を扱う。この章は、届出を怠った側の処分と罰則を、基準の一行ずつで示す。
- B-11（紛争審査会）は、民事の争いを解く手続で、行政の指導監督とは別。審査会に申請しても許可や入札で不利にならないことは、B-11に任せる。
- この章だけが扱うこと: 監督の入口（調査・通報・立入検査）の見取り図、調査票が聞く項目と適正回答率の低い項目、処分の段階と原則、営業停止中にできること・できないこと、処分の公表と経審への響き、社内の備え（帳簿・契約書類・決算の届出・是正の記録）。
- 書かないこと: 刑事手続と弁護、談合・独占禁止法の詳細、他法令違反（労働安全衛生法など）の細目、各整備局・都道府県の窓口の一覧、発注者ごとの指名停止の基準。

## 図・写真の候補
- 図: 端緒から処分までの流れ（自作の SVG）。端緒（実態調査・駆け込みホットライン・建設Gメン）→ 報告徴収・立入検査 → 指導票／勧告・文書指導 → 指示 → 営業停止 → 許可取消を段階で並べ、各段階の根拠（条または基準）と令和7年度の件数（勧告・文書指導等768業者、指示4、営業停止14、許可取消1）を添える。軸は段階と件数。出典の注記（1社が複数の事由に当たることがある）を図に書く。件数の対象が大臣許可業者か全体かは、資料の注記で確かめてから書く。
- 図: 令和7年度下請取引等実態調査の適正回答率（自作の SVG）。高い3項目と低い4項目を横棒で並べ、低い項目に「契約書15項目・見積条件14項目」の注を付ける。出典は国土交通省の結果概要で、令和5年度の本の表（p0440）は構図の参考にとどめる。
- 図: 営業停止中にできること・できないこと（自作の SVG）。基準の別表を、新規の契約・入札・見積りと、既契約の施工・請求・受領・申請に分けた2列の表にする。
- 写真は使わない（制度と社内書類の話で、写真が判断の助けにならない）。
