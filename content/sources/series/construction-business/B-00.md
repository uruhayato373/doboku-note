# B-00 建設業の経営と法務の全体像 — 許可・経審・下請・担い手・紛争のつながり（骨子）

## 読者と場面
- 建設会社の経営者・管理部門・現場の責任者で、許可、経審と入札、下請との取引、現場の人、行政の監督と争いが「別々の制度」に見え、いま自社はどこから確かめればよいかで迷う人。経営を引き継いだ、許可の更新が近い、公共工事に出たい、元請から法令遵守を求められた、行政から調査票が来た、といった場面で最初に開く。
- 建設業法の目的（第1条）と章立てを背骨にして、シリーズの各章を会社の動く順（許可→経審と入札→下請と現場の人→紛争と監督→これから）に案内する入口の章。個々の要件・数値・手続は各章に任せ、ここには書かない。
- 数字や期限は書かない。書くのは「この制度は何のためにあり、前後のどの制度とつながり、詳しくはどの章か」までにする。
- この章が扱わないこと: 許可の要件・手続の細目（B-03・B-04）、経審の点数の計算（B-05・B-06）、取引ルールの中身（B-07・B-08）、制度ごとの最新の数値。

## 論点
- 建設業法は、適正な施工と発注者の保護が目的
  - 根拠: construction-business-act#第1条 目的（建設業を営む者の資質の向上と請負契約の適正化により、適正な施工の確保、発注者の保護、建設業の健全な発達、公共の福祉の増進を図る）
  - 本: construction-business-act-tips-3rd/u0054
- 法律の章立てを、会社の動く順に読み替える
  - 根拠: construction-business-act 章立て（第2章 建設業の許可、第3章 建設工事の請負契約、第3章の2 請負契約に関する紛争の処理、第4章 施工技術の確保、第4章の2 経営に関する事項の審査等、第5章 監督。e-Gov 法令検索 令和7年12月12日施行版の目次）
- 請け負う営業には、まず許可がいる
  - 根拠: construction-business-act#第3条 建設業の許可（軽微な建設工事のみを請け負う場合は例外）
  - 根拠: mlit-construction-license-about 国土交通省 建設業の許可とは（公共工事・民間工事を問わず必要。軽微な建設工事の金額の目安）
- 許可は営業所の置き方と下請金額で区分される
  - 根拠: construction-business-act#第3条 建設業の許可（第1項 大臣許可と知事許可、一般建設業と特定建設業。第2項 業種ごとに与える）
  - 根拠: mlit-construction-license-about 国土交通省 建設業の許可とは（大臣・知事の別は営業所の所在地で決まり、施工できる区域に制限は無い。一般・特定は下請契約の総額で決まる。29業種）
- 許可は取る日だけでなく、保つ間も満たす
  - 根拠: construction-business-act#第7条 許可の基準
  - 根拠: construction-business-act#第29条 許可の取消し（第1項第1号 基準を満たさなくなった場合）
- 許可は5年ごとに更新し、変更は届け出る
  - 根拠: construction-business-act#第3条 第3項（許可の有効期間は5年）
  - 根拠: construction-business-act#第11条 変更等の届出
  - 根拠: construction-business-act#第12条 廃業等の届出
- 公共工事を直接請け負うなら、経審を受ける
  - 根拠: construction-business-act#第27条の23 経営事項審査（公共性のある施設・工作物の工事を発注者から直接請け負おうとする建設業者は、経営状況と経営規模・技術力などの客観的事項の審査を受ける）
  - 根拠: mlit-keishin-about 国土交通省 経営事項審査及び総合評定値の請求について
- 経審の点数は、発注者の点と合わさり等級になる
  - 根拠: mlit-keishin-about 国土交通省 経営事項審査とは（発注機関が欠格要件を確かめ、客観的事項と主観的事項の審査結果を点数化して順位付け・格付けする。経営事項審査は客観的事項の審査）
- 契約は対等な立場で、書面で結ぶ
  - 根拠: construction-business-act#第18条 建設工事の請負契約の原則
  - 根拠: construction-business-act#第19条 契約書の記載事項
- 元請は下請の意見を聞き、代金と引渡しを守る
  - 根拠: construction-business-act#第24条の2 下請負人の意見の聴取
  - 根拠: construction-business-act#第24条の3 下請代金の支払
  - 根拠: construction-business-act#第24条の4 検査及び引渡し
- 丸投げ禁止と作業員への指示の線は、別に確かめる
  - 根拠: construction-business-act#第22条 一括下請負の禁止
  - 根拠: mlit-construction-business-act-compliance-guideline-12 国土交通省 建設業法令遵守ガイドライン（第12版・令和8年1月最終改訂）
- 現場には資格のある技術者を置く
  - 根拠: construction-business-act#第26条 主任技術者及び監理技術者の設置等
- 担い手の育成と処遇は、建設業者の努力義務
  - 根拠: construction-business-act#第25条の27 施工技術の確保に関する建設業者等の責務（担い手の育成・確保、公正な評価に基づく適切な処遇の確保に努める）
  - 根拠: mlit-ccus-portal 国土交通省 建設キャリアアップシステムポータル（技能者の資格や就業履歴を登録・蓄積し、能力評価につなげる仕組み）
- 争いは審査会で解き、行政の監督は別に動く
  - 根拠: construction-business-act#第25条 建設工事紛争審査会の設置（請負契約に関する紛争のあっせん・調停・仲裁）
  - 根拠: construction-business-act#第28条 指示及び営業の停止
  - 根拠: construction-business-act#第31条 報告徴収及び立入検査
  - 根拠: mlit-construction-dispute-scope 建設工事紛争審査会の取り扱う事件（行政上の指導監督を行う機関ではない）
- 生成AIは、これらのルールの上で試す
  - 根拠: ai-promotion-act#第7条 人工知能関連技術の研究開発及び活用の推進に関する法律 第7条（活用事業者の責務。令和7年6月4日公布・同日施行、全面施行は同年9月1日）
  - 根拠: ai-business-guideline 第1.2版（総務省・経済産業省、令和8年3月31日）第5部（AI利用者に関する事項。pp.40-41）

## 既存記事との分担
- 各論点は、案内する章への入口の一文に留める。章の本文は書き写さず、リンクと範囲の説明で済ませる。下の対応を、記事の最初の「読む順」の表に使う。
- 入口: content/site/civil-practice/construction-industry-structure/article.mdx（B-01）が、発注者・元請・下請・専門工事業・JV・建設コンサルタントの関係を契約の線と責任の線で整理している → この章は関係者の説明をせず、「まず関係者の地図を見たい人はB-01」と案内する。
- 許可を取り、保つ: content/site/civil-practice/license-scope-judgment/article.mdx（B-02）が、許可が要る工事かの判断（建設工事か、軽微な工事か、業種、附帯工事、許可区分）を扱う → 判断の中身は書かない。B-03（許可の要件）、B-04（許可の手続き）は台帳の題どおり、要件の確認と更新・変更・承継・廃業・電子申請を扱う。この章は3本の順と使い分けだけを示す。
- 経審と入札: content/site/civil-practice/keishin-bidder-qualification/article.mdx（B-05）が点数が等級に変わり入札に出られる工事が決まるまでを扱い、B-06（経審の結果を読み、受け直す）が結果通知書・再審査・合併や承継のときの審査を扱う。公共工事の入札方式は content/site/civil-practice/public-works-bidding-methods/article.mdx が扱う → 点数や方式の中身は書かない。
- 下請と現場の人: content/site/civil-practice/subcontract-fair-dealing/article.mdx（B-07）、subcontract-instruction-boundary/article.mdx（B-08）、ccus-kentaikyo-site/article.mdx（B-09）、foreign-workers-site-check/article.mdx（B-10）が、それぞれ取引ルール、作業員への指示と偽装請負、CCUSと建退共、外国人材の受入れ前の確認を扱う → 中身は書かない。現場に置く技術者は content/site/civil-construction-1/guide-engineer-assignment/article.mdx にあり、リンクで案内する。
- 紛争と監督: B-11（content/site/civil-practice/construction-dispute-resolution/article.mdx）が審査会の手続を、B-12（supervision-compliance-surveys/article.mdx）が実態調査・立入検査・監督処分を扱う。設計変更の協議の進め方は content/site/civil-practice/cost-and-design-change/article.mdx → ここでは「争いと行政の監督は別の制度」と示すだけにする。
- これから: B-13（generative-ai-adoption/article.mdx）が会社としての生成AI導入を扱う。工事書類ごとの検証は content/site/civil-practice/ai-document-verification/article.mdx → 案内だけにする。
- この章だけが扱うこと: 建設業法の目的と章立てから見たシリーズの地図、会社の動く順（許可→経審と入札→下請と現場の人→紛争と監督→これから）、場面別の入口（許可の更新が近い・公共工事に出たい・下請に出す・争いになった・調査票が来た・AIを使いたい）、各章の範囲の境目。
- 書かないこと: 要件・数値・期限・手数料などの個別の制度の細目、試験の話、特定の事業者や製品の紹介、最新の統計値。
