# G-04 公開されている地理空間データの使い方 — 地理院地図・国土数値情報・3D都市モデル・ハザードマップ（骨子）

## 読者と場面
- 自治体の計画担当、コンサルの設計者、施工会社の現場計画担当が、無償で公開されている地図・標高・災害リスク・3D モデルのデータを業務に使おうとして、「どれを選ぶか」「使ってよいか」「どこまで信じてよいか」で迷う場面。
- 報告書や資料に載せるとき、出典の書き方と、測量法に基づく申請が要るかどうかを確かめたい。
- この章は公開データの種類・形式・更新・利用条件・限界を書く。GIS で重ねるときの座標・属性・面積の検算は G-03、座標系の定義は G-01、自治体の庁内 GIS と台帳の整備は G-05、点群の計測は G-06 に任せる。

## 論点
- 国の持つ地理空間情報は、原則無償で公開される
  - 根拠: geospatial-information-act#第18条 地理空間情報活用推進基本法（平成19年法律第63号）第18条第2項（国は保有する基盤地図情報等を原則としてインターネットで無償提供）
  - 本: civil-technology-basics/u0292
- 基盤地図情報は、位置の基準となる10項目
  - 根拠: geospatial-information-act#第2条 同法第2条第3項（基盤地図情報の定義）
  - 根拠: gsi-foundation-map-faq 基盤地図情報FAQ（国土地理院）Q.3-1（基本項目は測量の基準点、海岸線、行政区画の境界線、道路縁、軌道の中心線、標高点、水涯線、建築物の外周線、町・字の境界線、街区の境界線の10項目）
- 基盤地図情報は経緯度で、年4回更新される
  - 根拠: gsi-foundation-map-faq 同 Q.2-4（世界測地系の経緯度、小数点以下9桁。有効精度は整備方法で異なる）・Q.3-4（基本項目は1月・4月・7月・10月に更新）・Q.2-2（JPGIS（GML）に基づく XML 形式）
- 標高は、数値標高モデルの種別で間隔が違う
  - 根拠: gsi-foundation-map-faq 同 Q.4-1・Q.4-2（DEM1A、DEM5A、DEM5B、DEM5C、DEM10A、DEM10B の6種。メッシュ間隔は1m・5m・10m相当）
  - 根拠: gsi-tile-list 地理院タイル一覧（標高タイルの DEM 種別ごとのズームレベル。2026-10-16 に確認）
- 地理院タイルは、種類ごとに利用条件が違う
  - 根拠: gsi-tile-list 同（基本測量成果のタイル、出典明示のみで使えるタイル、他機関の条件が付くタイルの3区分。標準地図・淡色地図の日本域はズームレベル5〜18の基本測量成果）
  - 本: civil-technology-basics/u0292
- 国土数値情報は、データごとに版と条件が違う
  - 根拠: ksj-terms 国土数値情報ダウンロードサイト 利用約款（令和8年3月23日施行。データごとに CC BY 4.0・旧約款準拠の商用可／非商用などが分かれる）
  - 根拠: ksj-download-site 国土数値情報ダウンロードサイト（データ識別子の年が版を示す。Shapefile・GeoJSON・XML。2026-10-16 に確認）
- 災害の図は、ポータルで探して作成機関で確かめる
  - 根拠: gsi-disaportal ハザードマップポータルサイト（重ねるハザードマップは地図に重ねて表示、わがまちハザードマップは市町村が作成した図へのリンク。内容の解釈は作成機関へ。2026-10-16 に確認）
  - 根拠: gsi-disaportal-opendata 同 オープンデータ（地理院タイル仕様に準じた PNG のラスタータイル。都道府県管理河川は許諾を得た都道府県分のみで地域に偏りがある）
  - 本: civil-technology-basics/u0276
- 洪水の想定区域は、想定最大規模の降雨で指定される
  - 根拠: flood-control-act#第14条 洪水浸水想定区域（想定最大規模降雨により河川が氾濫した場合に浸水が想定される区域を、国土交通大臣・都道府県知事が指定して公表）
  - 根拠: flood-control-act#第15条 浸水想定区域における円滑かつ迅速な避難の確保（市町村地域防災計画への記載と、市町村長による印刷物の配布などの周知）
  - 根拠: mlit-flood-hazard-map-guide 水害ハザードマップ作成の手引き（国土交通省 水管理・国土保全局）
- 土砂災害は、警戒区域と特別警戒区域で意味が違う
  - 根拠: sediment-disaster-act#第7条 土砂災害警戒区域（警戒避難体制を特に整備すべき区域）
  - 根拠: sediment-disaster-act#第9条 土砂災害特別警戒区域（一定の開発行為の制限と建築物の構造の規制をすべき区域）
- 想定区域の図には、位置と想定の限界がある
  - 根拠: ksj-flood-inundation-a31a 国土数値情報「洪水浸水想定区域（河川単位）」（位置精度は約25m。支川の氾濫・想定を超える降雨・高潮・内水は含まれない。2026-10-16 に確認）
  - 根拠: gsi-disaportal-opendata 同（内水浸水想定は河川氾濫や高潮の浸水を考慮せず、浸水深0〜0.1mの範囲は表示されない）
- PLATEAU は、建物を LOD で段階的に表す
  - 根拠: mlit-plateau-libraries 国土交通省 PLATEAU 技術資料・ドキュメント（3D都市モデル標準製品仕様書 第5.1版・3D都市モデル整備のための測量マニュアル 第4.1版、いずれも2026年3月31日掲載。LOD1は建物図形に高さを与えた箱型、LOD2は屋根形状を表現。書く前に標準製品仕様書の本文で確かめる）
  - 根拠: mlit-plateau-open-data 同 オープンデータ（令和8年5月11日時点で306都市。G空間情報センターのポータルから入手）
- PLATEAU は出典を書き、測量法の制約を確かめる
  - 根拠: mlit-plateau-site-policy PLATEAU サイトポリシー（公共データ利用規約 第1.0版（PDL1.0）で利用でき CC BY 4.0 と互換。出典を書き、加工したら別に明記。測量法に基づく測量成果は個別の法令による制約がある）
  - 根拠: plateau-portal-gspatial-center PLATEAU オープンデータポータル（商用利用を含め無償。都市ごとの公開年、属性一覧は令和8年3月31日時点）
- 道路の基盤地図は、閲覧と提供で条件が分かれる
  - 根拠: mlit-press-2024-05-road-base-map-database 全国道路基盤地図等データベースの公開開始（令和6年5月31日。直轄国道等が対象。閲覧は無料、研究機関・民間企業へのデータ提供は有償）
- 申請が要るかは、使い方で決まる
  - 根拠: gsi-survey-result-use-procedure 国土地理院「測量成果の利用手続」（基本測量成果の複製は測量法第29条、使用は第30条。基本測量成果でないものは出典の明示のみ）
  - 根拠: survey-act#第29条 測量成果の複製（基本測量成果の複製の承認）
  - 根拠: survey-act#第30条 測量成果の使用（基本測量成果を使用した基本測量以外の測量の承認）
- 出典は書き方を決め、加工したら明記する
  - 根拠: gsi-content-terms 国土地理院コンテンツ利用規約（「出典：国土地理院ウェブサイト（ページの URL）」の形。加工した場合は別に明記し、国土地理院が作成したかのように見せない。令和7年11月20日改正）
  - 根拠: gsi-tile-list 同（Web での表示は「国土地理院」または「地理院タイル」と書いてタイル一覧へリンク）

## 既存記事との分担
- `content/site/civil-practice/gis-layer-validation/article.mdx`: 「業務の問いごとに、重ねるデータを選ぶ」の節で、台帳・ハザードマップポータル・国土数値情報・基盤地図情報を問いごとに紹介し、基盤地図情報の測量法上の扱い（FAQ の Q.1-7）と地理院地図の利用規約にも触れている → 問いからデータを選ぶ話、重ねる前の座標・属性・面積の検算はリンクで済ませる。この章は、各データそのものの中身・形式・更新・利用条件・限界を書く。
- `content/site/civil-practice/gnss-positioning-basics/article.mdx`: ジオイド・モデルが測量成果で、利用に測量法の手続が必要な場合があることを触れている → リンクで済ませる。この章はジオイド・モデルの配布には立ち入らない。
- `content/site/civil-practice/regional-disaster-plan-flood-fighting/article.mdx`、`sediment-disaster-erosion-control/article.mdx`、`flood-season-river-work/article.mdx`: 洪水・土砂災害の計画と出水期の施工判断 → リンクで済ませる。この章は、想定区域の図とデータの読み方の限界だけを書き、防災計画の中身は書かない。
- `content/site/civil-practice/road-boundary-and-road-ledger/article.mdx`: 道路台帳の調書・図面の組成、境界の確認 → リンクで済ませる。この章は全国道路基盤地図の公開条件の1論点だけ。
- G-05（自治体の GIS）が庁内の統合型・公開型 GIS と台帳のデジタル化を扱う。この章は国や公的機関が出すデータの使い方まで。
- この章だけが扱うこと: 基盤地図情報・地理院タイル・国土数値情報・ハザードマップポータル・PLATEAU・全国道路基盤地図の違い、データ別の更新と利用条件、測量法に基づく申請の判断、出典の書き方、想定区域図の限界。
- 書かないこと: 各データの全件一覧、ダウンロードの操作手順の画面説明、QGIS での取り込み操作（G-03）、PLATEAU の CityGML の構造の細目。

## 図・写真の候補
- 図: 「知りたいこと」から公開データを選ぶ図（どこが危ない → ハザードマップポータル・国土数値情報、地形の高低 → 基盤地図情報の標高、建物の形と高さ → PLATEAU、道路の位置 → 基盤地図情報・全国道路基盤地図）。縦に問い、横に「データ名・出す機関・更新」を置く2軸の図（自作の SVG）。構図の参考: `civil-technology-basics` p0275（地理情報）
- 図: 利用手続の判断フロー（その地図は基本測量成果か → 複製・使用の申請（第29条・第30条）／出典の明示のみ → 地図の利用手続ナビで確かめる）（自作の SVG）
- 図: PLATEAU の LOD1（箱型）と LOD2（屋根形状）を同じ建物で比べる概念図（自作の SVG。高さの与え方と屋根の表現の違いを示す）
- 写真は使わない（データの画面は他機関の画面の複製になるうえ、判断の助けにならない）。
