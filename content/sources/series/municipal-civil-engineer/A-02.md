# A-02 社会資本の全体像 — 種類・整備の歩み・投資の推移と維持更新の時代（骨子）

## 読者と場面
- 市町村の土木部署に配属され、道路・橋・河川・下水道などを預かることになったが、自分の仕事が社会資本の全体のどこにあたり、なぜ今「維持と更新」が中心なのかを知りたい人。
- 係の会議や議会の質疑で、「施設が古くなっている」「投資が減っている」と言われたとき、どの資料の何の数字を根拠に話せばよいかで迷う。
- 数字は白書や国土交通省の公表値から引く。この章は、種類と歩みの見取り図、投資の見方、維持更新が中心になった背景を書き、個別の制度は後ろの章に任せる。
- 道路・河川の管理の仕組みは A-06 以降、予算と財源は A-05、計画の体系と事業評価は A-20、点検の細目は A-11・A-16 に任せる。

## 論点
- 社会資本整備事業は、道路・鉄道・空港・港湾などの総称
  - 根拠: infrastructure-priority-plan-act#第2条 社会資本整備事業の定義
- 国は計画で重点を決め、地方公共団体の自主性を尊重する
  - 根拠: infrastructure-priority-plan-act#第3条 基本理念（第2項 地方公共団体の自主性と国の責務の役割分担）
  - 根拠: infrastructure-priority-plan-act#第4条 重点計画（閣議決定、重点目標、事業の概要）
- 重点計画は更新される。現在は第6次計画の期間に入った
  - 根拠: mlit-white-paper 令和8年版 第II部第1章第5節 社会資本整備の推進（令和8年1月閣議決定の第6次計画。計画期間は令和12年度まで、4つの重点目標。pp.139-141）
  - 根拠: https://www.mlit.go.jp/report/press/sogo12_hh_000496.html 国土交通省 報道発表 令和8年1月16日「第6次社会資本整備重点計画・第3次交通政策基本計画を閣議決定」（令和12年度までの計画期間）
- 施設ごとに、管理する主体が国・都道府県・市町村に分かれている
  - 根拠: road-act#第13条 国道の維持・修繕その他の管理（指定区間は国、それ以外は都道府県）
  - 根拠: road-act#第16条 市町村道の管理は市町村
  - 根拠: river-act#第9条 一級河川の管理は国土交通大臣（指定区間の事務は都道府県知事）
  - 根拠: river-act#第10条 二級河川の管理は都道府県知事
- 整備の歩みは、新設の時代から維持更新の時代へ移った
  - 根拠: mlit-white-paper 令和8年版 第II部第1章第4節 社会資本の老朽化対策等（平成25年11月のインフラ長寿命化基本計画、平成25年を「社会資本メンテナンス元年」と位置づけ。pp.137-138）
- 高度経済成長期に集中して整備した施設が、同じころに古くなる
  - 根拠: https://www.mlit.go.jp/sogoseisaku/maintenance/_pdf/50year_percentage.pdf 国土交通省「建設後50年以上経過する社会資本の割合」（道路橋・トンネル・河川管理施設・水道管路・下水道管渠・港湾施設の2025年3月・2030年3月・2040年3月の見通し）
- 古さの数字は、施設の種類と建設年度不明の扱いで変わる
  - 根拠: https://www.mlit.go.jp/sogoseisaku/maintenance/_pdf/50year_percentage.pdf 同資料の注（建設後50年は便宜上の整理。建設年度不明を除いた施設と含めた施設がある）
- 維持更新は、道路法・河川法が管理者に課す義務になっている
  - 根拠: road-act#第42条 道路の維持・修繕と、点検に関する基準
  - 根拠: river-act#第15条の2 河川管理施設等の維持・修繕と、点検に関する基準
- 事後保全から予防保全へ移すと、今後の費用を抑えられる見通し
  - 根拠: mlit-white-paper 令和8年版 第II部第1章第4節 社会資本の老朽化対策等（平成30年の推計で今後30年間の累計で約3割縮減できる見込み、令和3年6月の行動計画の改定。p.138）
- 自治体の投資は、決算の普通建設事業費で見る
  - 根拠: chihou-zaisei-white-paper 令和8年版 第19表 普通建設事業費の推移（令和6年度決算で15兆8,231億円、平成26年度からの推移）
- 投資は、補助事業と単独事業に分けて見る
  - 根拠: chihou-zaisei-white-paper 令和8年版 第19表（補助事業費・単独事業費・国直轄事業負担金の内訳）
- 市町村は、投資の6割ほどが更新整備にあたる
  - 根拠: chihou-zaisei-white-paper 令和8年版 普通建設事業費のうち更新整備に要した経費（市町村で5兆1,854億円、割合61.1％。都道府県は43.6％）
- 建設全体の投資の長い推移は、国の統計表で見る
  - 根拠: https://www.mlit.go.jp/statistics/content/002013722.pdf 国土交通省 国土交通白書 令和8年版 関連データ集「建設投資、許可業者数及び就業者数の推移」
- 人口減少のもとで、集約・再編による適正化も選択肢
  - 根拠: mlit-white-paper 令和7年版 第II章第5節 インフラメンテナンス（集約・再編等によるインフラストック適正化）
- 一つの自治体で抱えきれない管理を、群でまとめる考え方
  - 根拠: mlit-white-paper 令和7年版 第II章第5節 地域インフラ群再生戦略マネジメント（群マネ、令和5年度に選定したモデル地域11件40地方公共団体）
  - 根拠: mlit-white-paper 令和8年版 第II部第1章第4節（令和7年10月に「群マネの手引き Ver.1」を公表し全国展開へ。pp.138-139）
  - 根拠: https://www.mlit.go.jp/sogoseisaku/maintenance/03activity/03_02_07.html 国土交通省「群マネモデル地域」（11件40地方公共団体を選定）
  - 根拠: https://www.mlit.go.jp/sogoseisaku/maintenance/03activity/03_02_06.html 国土交通省「地域インフラ群再生戦略マネジメント」
- 防災の投資は、国土強靱化の計画と地域計画で別枠に組まれている
  - 根拠: national-resilience-basic-act#第11条の2 国土強靱化実施中期計画
  - 根拠: national-resilience-basic-act#第13条 都道府県・市町村の国土強靱化地域計画

## 既存記事との分担
- content/site/civil-practice/preventive-maintenance-diagnosis/article.mdx: 予防保全への転換、法定点検の基準、健全性の区分、アセットマネジメント → 点検と診断の中身はリンクで済ませる。この章は「なぜ維持更新が中心になったか」の背景と、自治体の投資の見方だけを書く。
- content/site/pe-construction/shakai-shihon-ronbun-keyword/article.mdx、infra-roukyuuka-iji/article.mdx、kokudo-keisei-chiiki/article.mdx: 技術士の論述向けに、社会資本整備、老朽化と維持管理、国土形成計画の論点を整理 → 試験の論述の書き方はリンクで済ませる。この章は自治体の担当の目線で書く。
- A-05（予算と財源）が補助金・交付金・地方債を、A-20（計画の体系と事業評価）が国土形成計画・社会資本整備重点計画の体系を扱う。この章は計画の名前と更新の事実を示すところまでにする。
- この章だけが扱うこと: 社会資本の種類と管理主体の見取り図、整備から維持更新へ移った流れ、自治体の投資を決算の統計で見る読み方、数字を引くときの出典の選び方。
- 書かないこと: 国の予算額の推移を自分で集計して作る図（出典の表を引く）、将来の投資額の独自推計。

## 一次資料で確かめてから書く数値・規格
- 建設後50年以上経過する割合の各施設の値。国土交通省の資料の図は、道路橋（橋長2m以上、約73万橋）・トンネル（約1万2千本）・河川管理施設（約2万8千施設）・水道管路（約75万km）・下水道管渠（約50万km）・港湾施設（約2万5千施設）の2025年3月・2030年3月・2040年3月を示す。文字として取り出せなかった割合は、公開前に資料の図を目で確かめ、版（掲載日）を記す。
- 地方財政白書（令和8年版）の普通建設事業費の値（令和6年度 15兆8,231億円、補助事業費 7兆4,796億円、単独事業費 7兆5,522億円、国直轄事業負担金 7,914億円、更新整備の割合 都道府県 43.6％・市町村 61.1％）と頁（第19表は p.50）。総務省の公開版で確かめる。
- 国土交通白書は令和8年版が公開済み（第II部第1章第4節 p.137〜139、第5節 p.139〜141 で確認）。集約・再編と群マネのモデル地域11件40団体は令和7年版（第II章第5節 pp.142〜144）の記述で、令和8年版の同じ節では見つからなかったため、書く前に令和8年版の該当箇所か別の最新資料で確かめる。
- 第6次社会資本整備重点計画の計画期間（報道発表は令和12年度まで）と重点目標。計画本文を開いて確かめる。
- 国土強靱化実施中期計画の計画期間（令和7年6月閣議決定、令和8〜12年度の5年間。国土交通白書令和8年版 p.140 で確認）と事業規模（未確認）。内閣官房の公表で確かめる。

- 図: 「整備の時代 → 維持更新の時代」の流れ（昭和の整備 → 老朽化 → 平成25年のメンテナンス元年 → 予防保全 → 群マネ）を示す年表（自作の SVG）。
