# A-22 地元説明会と合意形成（骨子）

## 読者と場面
- 市町村の土木担当で、道路や河川、公園の事業について、地元や関係者に説明する場を初めて組む人。説明会の上司や議員への報告も含め、「何を、いつ、誰に、どの形で伝え、意見をどう扱うか」で迷う。
- 一般論として書く。公開の指針（国土交通省のガイドライン）と法令の手続から、場の設計と判断の順を示す。特定の地区・団体・個人・案件の経験談は書かない。
- 要望の受付と事業化は A-21、用地の個別の交渉と補償は A-23、環境アセスメントの手続は A-25、住民・議会への説明資料の作り方は A-40 に任せる。この章は、説明会と合意形成の枠組みだけを扱う。

## 論点
- 住民参画は計画の手続の正当性を支える
  - 根拠: https://www.mlit.go.jp/tec/kanri/pdf/koukyou_guidegaiyou.pdf 国土交通省「公共事業の構想段階における計画策定プロセスガイドライン（解説）」（平成 21 年 3 月）第 1 の（1）（透明性・客観性・合理性・公正性）
- 参画の進め方は早い段階で公表する
  - 根拠: https://www.mlit.go.jp/tec/kanri/pdf/koukyou_guidegaiyou.pdf 同ガイドライン（解説）第 3 の冒頭（早期の公表・積極的な情報提供・機会と期間の確保・真摯な対応）
- 誰が関係者かを事業ごとに把握し直す
  - 根拠: https://www.mlit.go.jp/tec/kanri/pdf/koukyou_guidegaiyou.pdf 同 第 3 の（1）住民・関係者等の対象範囲の把握
- 目的と相手に合わせて場の形を選ぶ
  - 根拠: https://www.mlit.go.jp/tec/kanri/pdf/koukyou_guidegaiyou.pdf 同 第 3 の（2）コミュニケーション手法の選択（目的・対象者・手法の特性・予算と時間）
- 構想の段階では複数案を示して意見を聞く
  - 根拠: https://www.mlit.go.jp/tec/kanri/pdf/koukyou_guidegaiyou.pdf 同 第 2 の（3）複数案の設定、（5）複数案の比較評価
- 段階ごとに情報提供・意見把握・対応の公表を回す
  - 根拠: https://www.mlit.go.jp/tec/kanri/pdf/koukyou_guidegaiyou.pdf 同 第 3 の（3）段階に応じた双方向コミュニケーションの実施
- 法が定める説明・縦覧の手続を落とさない（都市計画）
  - 根拠: city-planning-act#第16条 公聴会の開催等住民の意見を反映させる措置
  - 根拠: city-planning-act#第17条 都市計画の案の縦覧と意見書の提出
- 法が定める住民の意見の手続（河川整備計画）
  - 根拠: river-act#第16条の2 河川整備計画の案について必要があるときの公聴会等関係住民の意見を反映させる措置（第 4 項）
- 収用を伴う事業は認定の前に説明会が要る
  - 根拠: land-expropriation-act#第15条の14 事業の説明（起業者は事業の認定を受けようとするときに説明会などで利害関係者へ説明する）
  - 根拠: land-expropriation-act#第23条 事業の認定における公聴会
- 利害関係者は事業の認定について意見書を出せる
  - 根拠: land-expropriation-act#第25条 利害関係人の意見書の提出
- 環境アセスメントの説明会は法の様式で開く
  - 根拠: environmental-impact-assessment-act#第7条の2 方法書についての説明会の開催等
  - 根拠: environmental-impact-assessment-act#第17条 準備書についての説明会の開催等
- 日時と場所は参加できる人の範囲で決める
  - 根拠: https://www.mlit.go.jp/tec/kanri/pdf/koukyou_guidegaiyou.pdf 同 第 3 の解説（参加しやすい場所・夜間や休日の時間帯・意見を整理する期間の確保）
- 資料は案の特徴と判断の根拠を分けて示す
  - 根拠: https://www.mlit.go.jp/tec/kanri/pdf/koukyou_guidegaiyou.pdf 同 第 4 の（4）検討結果の公表
- 出た意見は整理して、採否の理由まで返す
  - 根拠: https://www.mlit.go.jp/tec/kanri/pdf/koukyou_guidegaiyou.pdf 同 第 3 の解説④（意見を全て受け入れるのではなく採用しない理由を丁寧に説明する）
- 対立が強いときは第三者の場と共通のルールを使う
  - 根拠: https://www.mlit.go.jp/tec/kanri/pdf/koukyou_guidegaiyou.pdf 同 第 3 の（4）留意事項（委員会等の設置・ルール作り）、第 5 委員会等
- 出席者名簿と意見票は個人情報として扱う
  - 根拠: personal-information-protection-act#第62条 本人から書面で個人情報を取得するときの利用目的の明示
  - 根拠: personal-information-protection-act#第66条 保有個人情報の安全管理措置
- 用地や補償の個別の話は説明会と分ける
  - 根拠: https://www.mlit.go.jp/common/001208294.pdf 国土交通省「用地取得のあらまし」用地取得の流れ（事業計画の説明と、補償説明・用地交渉の段階が別）
  - 根拠: https://www.mlit.go.jp/common/001208297.pdf 同 補償の説明等（用地補償説明会と個別の用地交渉）

- この章だけが扱うこと: 構想段階から工事前までの説明の目的の違い、場の設計（範囲・手法・日時）、意見の整理と回答、法定の手続との関係、名簿などの個人情報、対立が強いときの進め方。体験談は書かない。

## 一次資料で確かめてから書く数値
- 土地収用法第 15 条の 14 が定める「国土交通省令で定める説明会」の開催の要件は、同法の施行規則の該当条（開催の周知の方法など）で確かめる。
- 都市計画の案の縦覧期間（2 週間）と意見書の提出期間は、都市計画法第 17 条の本文で確かめる。
- 国土交通省のガイドラインの適用事業（国等が実施する事業）と、地方公共団体への通知の扱いは、ガイドライン本文の「適用事業」と通知で確かめ、市町村の事業には「参考にする」と書く。

## 図・写真の候補
- 図: 構想 → 計画 → 事業認定・予算 → 用地 → 工事前、の段階ごとに説明の目的（情報提供・意見把握・補償の個別説明・工事の周知）と法定の手続を並べた表（2 軸）。
- 図: 説明会の準備から回答までの流れ（範囲の把握 → 手法の選択 → 開催と記録 → 意見の整理 → 採否の理由の回答と公表）の流れ図（自作の SVG）。
