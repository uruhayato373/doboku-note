# A-47 気象情報の読み方 — 警報と注意報、解析雨量、気象衛星、アメダス（骨子）

## 読者と場面
- 市町村の土木担当（技術職）。大雨や台風の前後に、気象庁の警報・キキクル・雨量の画面を見て、道路の通行止め、河川の巡視、水防の体制、避難情報を出す部署への情報の渡し方を決める人。
- 迷う場面は三つ。令和8年5月から警報の名前が変わり、何がどの段階か分からなくなったとき、市内に観測所がなく、アメダスの数字が自分の地区の雨を表しているか判断できないとき、「警報が出たから避難指示を出す」のか、警報と避難情報の関係で迷うとき。
- 現場の作業の中止と再開の判断は、既存の記事に任せる。この章は、自治体が情報の仕組みと限界を知って読む側に絞る。水防の体制と避難情報は A-38、土砂災害の警戒区域は A-39、河川の操作は A-16、下水道の雨水対策は A-36 に任せる。

## 論点
- 警報を出せるのは、気象庁だけ
  - 根拠: meteorological-service-act#第2条 気象業務法 第2条 第7項（警報は、重大な災害の起こるおそれのある旨を警告して行う予報）・第13条 第1項・第23条（気象庁以外の者は警報をしてはならない。政令で定める場合を除く）
- 特別警報の基準は、市町村長の意見を聴いて定める
  - 根拠: meteorological-service-act#第13条の2 気象業務法 第13条の2 第1項・第2項・第3項（特に異常で重大な災害のおそれが著しく大きい場合。基準を定めるときは都道府県知事の意見を聴き、知事は市町村長の意見を聴く。基準は公表）
- 警報は県を通じて市町村長に届き、住民へ周知する
  - 根拠: meteorological-service-act#第15条 気象業務法 第15条 第1項〜第3項（警報事項を都道府県などへ通知し、市町村長へ通知するよう努め、市町村長は公衆に周知させるよう努める）
  - 根拠: meteorological-service-act#第15条の2 気象業務法 第15条の2 第2項・第4項（特別警報は、都道府県が市町村長へ通知しなければならず、市町村長は周知の措置をとらなければならない）
- 警報・注意報は、市町村ごとの区域で出る
  - 根拠: jma-warning-areas 気象庁「気象警報・注意報や天気予報の発表区域」（警報・注意報は二次細分区域ごと。原則は市町村で、一部の市町村は分割。天気予報は一次細分区域ごと。市町村等をまとめた地域は概観のための区域）
  - 根拠: jma-warning-area-change-notice-2025-12 気象庁 配信資料に関するお知らせ 令和7年12月22日（横浜市・相模原市・長野市・伊那市・富山市・津市・松阪市・八代市の区域を令和8年5月下旬頃に分割する予定）
  - 本: weather-disaster-basics/u0149
- 令和8年5月29日から、情報の名前にレベルの数字が付く
  - 根拠: jma-press-2026-04-14-new-disaster-info 気象庁・国土交通省 報道発表 令和8年4月14日「5月29日（金）から、新たな防災気象情報の運用を開始します」
  - 根拠: jma-press-2026-04-14-enforcement-order 気象庁 報道発表 令和8年4月14日（「気象業務法及び水防法の一部を改正する法律」令和7年法律第86号、令和7年12月12日公布、施行は令和8年5月29日。気象業務法施行令に「洪水特別警報」を新設）
- 注意報はレベル2、警報は3、危険警報は4、特別警報は5
  - 根拠: jma-disaster-weather-info-improvement-2026-04 気象庁・国土交通省「防災気象情報の改善について」令和7年12月（令和8年4月更新）スライド4（河川氾濫・大雨・土砂災害・高潮の4つの現象を、警戒レベル2〜5に対応する「注意報・警報・危険警報・特別警報」で整理。レベル1は早期注意情報。危険警報は新設）
  - 根拠: jma-new-disaster-weather-info-2026 気象庁「新たな防災気象情報について（令和8年〜）」
- 洪水警報は廃止され、川の氾濫は河川ごとの情報になる
  - 根拠: jma-disaster-weather-info-improvement-2026-04 防災気象情報の改善について スライド5・14（市町村ごとの洪水警報・注意報は発表せず、大雨の情報に一体化。氾濫の情報は洪水予報河川のみ、河川ごとに発表。洪水予報河川は約400河川）
  - 根拠: flood-control-act#第10条 国の機関が行う洪水予報等（国土交通大臣と気象庁長官が共同して指定河川の洪水予報を行う）
  - 根拠: flood-control-act#第11条 都道府県知事が気象庁長官と共同して行う洪水予報
  - 根拠: flood-control-act#第13条 水位情報の通知及び周知（水位周知河川は河川事務所などの水位情報を従来どおり運用）
- レベル3土砂災害警報は、危険警報の直前の合図
  - 根拠: jma-press-2026-04-30-issuance-criteria 気象庁 報道発表 令和8年4月30日「新たな防災気象情報の発表基準等を公表します」（レベル3土砂災害警報は、レベル4土砂災害危険警報の基準に到達すると予想される場合にのみ発表。土砂災害の基準は土壌雨量指数と60分雨量の組み合わせに統一）
  - 根拠: jma-disaster-weather-info-improvement-2026-04 防災気象情報の改善について スライド6（レベル4相当に至らないレベル3相当情報の発表回数を大幅に減らせる。令和5年6〜9月のデータでの現行方式と新方式の比較図）
- 警戒レベル相当情報は、避難情報そのものではない
  - 根拠: cao-evacuation-information-guideline-2026 内閣府（防災担当）「避難情報に関するガイドライン」令和8年3月 3.3（印字 p.38。警戒レベル相当情報は警戒レベルそのものではなく、市町村が避難情報を発令するにあたって参考となる情報。情報名にレベルの数字が付いても位置づけは変わらない）
  - 根拠: disaster-countermeasures-basic-act#第60条 市町村長の避難の指示等
- 早期注意情報と時系列情報で、前もって体制を決める
  - 根拠: jma-disaster-weather-info-improvement-2026-04 防災気象情報の改善について スライド9・10（早期注意情報は5日先までの警報級の可能性、時系列情報は明日までの警報等の見通しで、毎日4回発表。心構えと事前の体制確保の検討に使う）
- キキクルは、市内で危ない場所を絞る
  - 根拠: jma-disaster-weather-info-improvement-2026-04 防災気象情報の改善について スライド11（大雨キキクルは大河川以外の河川の氾濫と浸水の危険度を重ねて表示。土砂キキクルは、赤の判定が狭く、黄から紫になる場合が多い）
  - 根拠: jma-doshakikikuru 気象庁「土砂キキクル」
- 気象防災速報は、府県単位の速報
  - 根拠: jma-disaster-weather-info-improvement-2026-04 防災気象情報の改善について スライド12（記録的短時間大雨・線状降水帯・竜巻注意などを、府県単位で速報。気象解説情報は全国・地方・府県単位で適宜発表）
- 雨の実況は、アメダスの点と解析雨量の面で読む
  - 根拠: jma-amedas 気象庁「アメダス」（降水量の観測所は約1,300か所で約17km間隔、風・気温・湿度も測るのは約840か所で約21km間隔）
  - 根拠: jma-spec-11601-analyzed-precipitation 気象庁予報部 配信資料に関する仕様 No.11601「解析雨量・速報版解析雨量」令和2年3月31日（気象庁・国土交通省のレーダーと、気象庁・国土交通省・地方自治体の雨量計を組み合わせ、1時間降水量を1km四方で解析。解析雨量は30分ごと、速報版は10分ごと）
  - 本: weather-disaster-basics/u0065
  - 本: weather-disaster-basics/u0067
- ひまわりと推計気象分布は、雲と天気の広がりを面で見る
  - 根拠: jma-satellite-image-guide 気象庁「衛星画像の見方」（可視画像は昼間のみ。赤外画像は昼夜とも使えるが、白い雲が雨を降らせるとは限らない。水蒸気画像は上・中層の水蒸気。雲頂強調画像は降水強度ではない）
  - 根拠: jma-msc-himawari-observation 気象衛星センター「観測の概要」（全球は10分ごと、日本域は約2.5分ごと）
  - 根拠: jma-estimated-weather-distribution 気象庁「推計気象分布」（天気・気温・日照時間を約1kmメッシュで1時間ごとに推計。観測値とは一致しないことがある）
  - 本: weather-disaster-basics/u0056
  - 本: weather-disaster-basics/u0057
  - 本: weather-disaster-basics/u0061
- 氾濫の切迫は、管理者の通報でレベル5につながる
  - 根拠: flood-control-act#第24条の2 氾濫等の通報（河川・下水道・海岸の管理者は、氾濫による著しい危険が切迫していれば直ちに都道府県知事などへ通報。知事は水防管理者・量水標管理者・気象庁長官へ通知）
  - 根拠: jma-disaster-weather-info-improvement-2026-04 防災気象情報の改善について スライド13（通報を受けた知事の通知が、特別警報の発表の判断要素になる）

## 既存記事との分担
- content/site/civil-practice/rainfall-work-suspension/article.mdx: 現場での作業中止・再開の基準、キキクルの色と指数の読み方、降水ナウキャスト・降水短時間予報、アメダス観測所の間隔を現場の言葉に直した説明 → リンクで済ませる。この章は、自治体が情報を発表する仕組み（法律の伝達ルート、区域、名称の体系）と、情報の限界（観測の網目、衛星と推計の注意点）を書く。
- content/site/civil-practice/typhoon-forecast-work-planning/article.mdx: 台風の予報円・暴風域・高潮・高波と、撤収の逆算 → リンクで済ませる。この章は台風の進路の読み方を扱わない。
- content/site/civil-practice/regional-disaster-plan-flood-fighting/article.mdx（A-38）: 地域防災計画、水防警報、避難指示の発令、管理者の通報、ハザードマップ → リンクで済ませる。この章は、避難情報の発令基準そのものを書かず、「警戒レベル相当情報は避難情報ではない」という位置づけだけを示す。
- content/site/civil-practice/sediment-disaster-erosion-control/article.mdx（A-39）: 土砂災害の警戒区域と警戒情報の運用 → リンクで済ませる。
- content/site/civil-practice/river-facility-inspection-operation/article.mdx（A-16）: 出水中の巡視と樋門・水門の操作 → リンクで済ませる。
- content/site/civil-practice/owner-safety-responsibility/article.mdx（A-30）: 発注者の安全責任と異常気象時の作業中止の指示 → リンクで済ませる。
- この章だけが扱うこと: 気象業務法が定める警報の主体と伝達、警報・注意報の発表区域、令和8年5月29日の新しい名称の体系、警戒レベル相当情報と避難情報の関係、早期注意情報から気象防災速報までの使い分け、アメダス・解析雨量・ひまわり・推計気象分布の仕組みと限界。
- 書かないこと: 気象庁の予測手法（数値予報の中身）、地震・津波・火山の情報、民間の気象サービスの比較、個別の災害の検証。

## 一次資料で確かめてから書く数値・規格
- 新しい防災気象情報の名称・基準・区域は、気象庁の特設ページ（令和8年〜）と、発表基準の一覧（https://www.jma.go.jp/jma/kishou/know/kijun_new/index.html）の最新版で確かめる。令和8年4月30日の報道発表と「防災気象情報の改善について」令和8年4月更新版を確認した。
- 「洪水特別警報」（気象業務法施行令第5条の名称）と「氾濫特別警報」（防災気象情報の整理での名称）は、どちらも国土交通省・気象庁の資料に出る。記事では同じ情報を指すことを確かめ、どちらの語を主にするかを決める。
- 気象警報等の発表区域の分割（8市）は、令和7年12月22日の技術情報で予定として確認した。実際に令和8年5月下旬に実施されたか、現在の区域を気象庁の発表区域のページで確かめる。
- 解析雨量の仕様（1km・30分ごと・速報版10分ごと）は令和2年3月の資料。最新の配信資料に関する仕様で、メッシュと更新間隔が変わっていないか確かめる。
- アメダスの観測所の数（降水約1,300か所・風など約840か所）は気象庁のページの記載。書く時点の最新の数を確かめる。
- ひまわりの運用中の衛星（ひまわり9号が観測、8号が待機とされるが、気象衛星センターの観測の概要のページには明記がなかった）と、次期衛星の計画は、書く前に気象庁の衛星のページで確かめる。
- 推計気象分布の更新間隔（1時間ごと）と天気分布予報（5kmメッシュ、毎日5時・11時・17時）は、気象庁のページの記載。変更されていないか確かめる。
- 避難情報に関するガイドラインは令和8年3月版を確認した。津波の避難情報の通知（令和8年7月21日）は A-38 の確認に合わせる。
