# A-56 橋の定期点検と健全性の判定 — 5年に1回の点検結果から補修設計へ（骨子）

## 読者と場面
- 橋の定期点検を委託し、報告書が届いた市町村の道路担当。判定区分の読み方や、点検のときに発注者が決めておくこと、結果が出たあとに何を先にするのかが分からない人。
- 点検の頻度・区分・計画の事務は既存記事が整理している。この章は、点検の現場で発注者が決めること（初回点検、落下物の予防、記録）と、国の要領の適用範囲の読み分けを補う。
- 扱わないこと: 長寿命化修繕計画と補助の申請（road-inspection-longevity-plan）、コンクリートの劣化診断（preventive-maintenance-diagnosis）、補修工法の選び方（concrete-repair-leakage）。補修設計の進め方と主な補修工法は、国の公開資料を確かめられなかったため、この章の論点には入れていない。

## 論点
- 点検は法令の義務で、5年に1回、近接目視が基本
  - 根拠: road-act-rules#第4条の5の6 道路法施行規則 第4条の5の6第一号
- 診断の結果と措置は、橋の供用中は保存する
  - 根拠: road-act-rules#第4条の5の6 道路法施行規則 第4条の5の6第二号・第三号
- 自治体が使うのは技術的助言の点検要領
  - 根拠: mlit-bridge-periodic-inspection-guideline-2024 道路橋定期点検要領（技術的助言）令和6年3月
- 国の橋梁定期点検要領は、国の管理橋に適用
  - 根拠: mlit-bridge-periodic-inspection-guideline-national-2024 国土交通省 道路局 橋梁定期点検要領（令和6年7月）第1章 1（適用の範囲）
- 初回点検は、供用開始後 2 年以内に行う
  - 根拠: mlit-bridge-periodic-inspection-guideline-national-2024 同要領 第1章 3（定期点検の頻度）
- 完成時の点検と工事記録を、初回点検へ引き継ぐ
  - 根拠: mlit-bridge-periodic-inspection-guideline-national-2024 同要領 第1章 3 解説（工事記録の保管と、完成時の点検）
- 状況に応じて、5年より短い間隔にしてよい
  - 根拠: mlit-bridge-periodic-inspection-guideline-national-2024 同要領 第1章 3 解説
- 点検の時期は、水位が低く見える時期を選ぶ
  - 根拠: mlit-bridge-periodic-inspection-guideline-national-2024 同要領 第1章 3 解説（渇水期など確実に確認できる時期）
- 計画の段階で、他の管理者との協議と安全対策を決める
  - 根拠: mlit-bridge-periodic-inspection-guideline-national-2024 同要領 第1章 4 解説（管理者協議・安全対策）
- 健全性の診断は、Ⅰ〜Ⅳの 4 区分で決める
  - 根拠: mlit-bridge-periodic-inspection-guideline-national-2024 同要領 第1章 5.1 表-5.1.1
- 区分ごとに、次回点検までの措置の考え方が違う
  - 根拠: mlit-bridge-periodic-inspection-guideline-national-2024 同要領 第1章 5.1 (2)
- 区分のほかに、緊急・維持工事・詳細調査の印を付ける
  - 根拠: mlit-bridge-periodic-inspection-guideline-national-2024 同要領 第1章 5.2〜5.4（E・M・S1・S2）
- 区分Ⅳの例は、落橋のおそれがあるとき
  - 根拠: mlit-bridge-periodic-inspection-guideline-national-2024 同要領 第1章 5.1 (2) 解説
- 桁下の利用状況で、落下物の予防の範囲を決める
  - 根拠: mlit-bridge-periodic-inspection-guideline-national-2024 同要領 第3章 2（措置の対象）
- うき・剥離は、打音検査で見つけて叩き落とす
  - 根拠: mlit-bridge-periodic-inspection-guideline-national-2024 同要領 第3章 4.2（措置の手順及び方法）
- 叩き落とすと安全が損なわれるときは別の方法
  - 根拠: mlit-bridge-periodic-inspection-guideline-national-2024 同要領 第3章 4.2 解説（PC 桁など）
- 落下箇所には、鉄筋の防錆処置と記録を残す
  - 根拠: mlit-bridge-periodic-inspection-guideline-national-2024 同要領 第3章 4.2 解説
- 点検結果は、国が道路メンテナンス年報で公表する
  - 根拠: mlit-road-maintenance-annual-report-2025 国土交通省 道路局 橋梁等の2025年度点検結果（道路メンテナンス年報・令和8年8月26日）
- 区分Ⅲ・Ⅳは、次の点検までに措置するべきとされる
  - 根拠: mlit-road-maintenance-annual-report-2025 同報道資料（区分Ⅲ・Ⅳの措置の着手率を含む）
