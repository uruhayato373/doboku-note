# A-38 地域防災計画と水防 — 市町村の土木担当が受け持つこと（骨子）

## 読者と場面
- 市町村の道路・河川・下水の担当になり、地域防災計画や水防計画の中で「土木部局の事務」が何と書かれているかを知らないまま、出水期や台風を迎える人。
- 水防団や消防との分担、河川管理者（国・都道府県）への連絡、避難指示を出す市長・町長への情報の渡し方、災害時に頼る建設業者との約束が、どの法律に基づくのかで迷う。
- 樋門・水門の操作と点検は A-16、流域治水は A-17、被災後の復旧は A-37、土砂災害の警戒区域は A-39 に任せる。この章は、平時の備えと発災時の判断で、土木担当が計画のどこを受け持つかを書く。

## 論点
- 防災の第一の責任は、市町村にある
  - 根拠: disaster-countermeasures-basic-act#第5条 市町村の責務（計画の作成と実施、消防機関・水防団などの組織の整備）
  - 根拠: flood-control-act#第3条 市町村の水防責任
- 地域防災計画は、防災会議が毎年見直す
  - 根拠: disaster-countermeasures-basic-act#第16条 市町村防災会議
  - 根拠: disaster-countermeasures-basic-act#第42条 第1項 市町村地域防災計画の作成と毎年の検討・修正
  - 根拠: cao-disaster-basic-plan 内閣府「防災基本計画」（災害対策基本法第34条に基づき中央防災会議が作成。令和8年7月14日修正）
  - 本: weather-disaster-basics/u0033
- 計画に書かれた土木部局の事務を確かめる
  - 根拠: disaster-countermeasures-basic-act#第42条 第2項 事務の大綱、災害予防・応急対策・復旧の別の計画、労務・資材などの整備
- 本部が立ったときの分担を、あらかじめ決めておく
  - 根拠: disaster-countermeasures-basic-act#第23条の2 市町村災害対策本部（地域防災計画の定めるところにより市町村長が設置）
- 災害予防は、点検・備蓄・訓練を平時に組む
  - 根拠: disaster-countermeasures-basic-act#第46条 災害予防の事項
  - 根拠: disaster-countermeasures-basic-act#第48条 防災訓練
  - 根拠: disaster-countermeasures-basic-act#第49条 物資・資材の備蓄と、防災施設・設備の点検
- 水防は、市町村長が管理者として責任を持つ
  - 根拠: flood-control-act#第2条 水防管理団体と水防管理者（市町村長）の定義
  - 根拠: flood-control-act#第5条 水防団
  - 根拠: flood-control-act#第41条 水防管理団体の費用負担
- 都道府県の水防計画に、指定管理団体の水防計画をそろえる
  - 根拠: flood-control-act#第7条 都道府県の水防計画（河川管理者・下水道管理者の協力事項は同意を得て記載）
  - 根拠: flood-control-act#第33条 指定管理団体の水防計画
  - 根拠: flood-control-act#第32条の2 水防訓練
- 重要水防箇所を、出水期前に河川管理者と確かめる
  - 根拠: flood-control-act#第9条 河川等の巡視と、危険箇所の管理者への連絡
  - 根拠: ktr-tone-upper-important-flood-fighting-spots 国土交通省利根川上流河川事務所「重要水防箇所って何？」（出水期前の合同巡視、重要度 A・B の区分。国の事務所の例）
- 洪水の情報と水防警報の受け方を決める
  - 根拠: flood-control-act#第10条 国の機関が行う洪水予報
  - 根拠: flood-control-act#第13条 水位情報の通知及び周知
  - 根拠: flood-control-act#第16条 水防警報
  - 根拠: flood-control-act#第17条 水防警報などを受けた水防団・消防機関の出動準備
- 洪水浸水想定区域を、避難経路の計画に反映する
  - 根拠: flood-control-act#第14条 洪水浸水想定区域
  - 根拠: flood-control-act#第15条 第1項 市町村地域防災計画に定める事項（情報の伝達方法、避難場所・避難経路、要配慮者利用施設）
- 小さな川の浸水実績も把握して、住民に知らせる
  - 根拠: flood-control-act#第15条の11 洪水予報河川等以外の河川での浸水実績・水災の危険の周知
- ハザードマップは、避難の判断につながる形で作る
  - 根拠: flood-control-act#第15条 第3項 浸水想定区域の事項を住民等に周知する印刷物の配布
  - 根拠: mlit-flood-hazard-map-guide 国土交通省水管理・国土保全局「水害ハザードマップ作成の手引き」平成28年4月（令和3年12月一部改定）
- 避難指示は市町村長が出し、河川管理者の助言を使う
  - 根拠: disaster-countermeasures-basic-act#第60条 市町村長の避難の指示等
  - 根拠: disaster-countermeasures-basic-act#第61条の2 指定行政機関の長・都道府県知事への助言の求め
  - 根拠: cao-evacuation-information-guideline-2026 内閣府（防災担当）「避難情報に関するガイドライン」令和8年3月改定（令和8年5月下旬の新しい防災気象情報の運用開始に合わせた改定）4.1 避難情報の発令基準等の設定手順（p.54）・4.8 避難情報の発令時における助言（p.117）
- 管理する施設の危険が迫れば、直ちに通報する
  - 根拠: flood-control-act#第24条の2 河川管理者・下水道管理者・海岸管理者の氾濫等の通報
  - 根拠: flood-control-act#第25条 堤防などが決壊したときの通報
- 緊急の土地・資材の使用と、損失の補償を知っておく
  - 根拠: flood-control-act#第28条 水防の公用負担（時価による損失補償）
  - 根拠: disaster-countermeasures-basic-act#第64条 応急公用負担
- 道路の車両移動と啓開を、管理者の権限として押さえる
  - 根拠: disaster-countermeasures-basic-act#第76条の6 災害時における車両の移動等
- 災害協定で、建設業者の応急対策を事前に決めておく
  - 根拠: disaster-countermeasures-basic-act#第46条 第1項第5号 民間の団体の協力の確保のためにあらかじめ講ずべき措置
  - 根拠: disaster-countermeasures-basic-act#第49条の2 相互応援に関する協定
  - 根拠: public-works-quality-act#第7条 第5項 災害応急対策工事等の実施に関する協定の締結
  - 根拠: mlit-ordering-operation-guideline-2025 関係省庁「発注関係事務の運用に関する指針」令和7年2月3日改正 Ⅲ 1－1（災害協定の締結状況を踏まえた契約の相手方の選定）
- 協議会で、河川管理者や気象台と顔を合わせる
  - 根拠: flood-control-act#第15条の10 都道府県大規模氾濫減災協議会（市町村長・水防管理者・河川管理者・気象台長などで構成）

## 一次資料で確かめてから書く数値・規格
- 避難情報の警戒レベル（3 高齢者等避難、4 避難指示、5 緊急安全確保）の区分は、内閣府「避難情報に関するガイドライン」令和8年3月改定版で確認済み（令和3年5月改定・令和4年9月更新版から、警戒レベル相当情報の名称が新しい防災気象情報に変わった）。津波の避難情報は令和8年7月21日の通知も確かめる。
- 防災基本計画の最新の修正（内閣府の公開ページで令和8年7月14日修正と確認）の風水害対策編の記述。
- 水防法の水防警報の指定河川の範囲、洪水予報の種類（第10条・第11条）、水位周知河川の指定（第13条）の最新の条文。令和以降の改正の施行日。
- 水防計画に定める水防団の定員の基準（都道府県の条例）と、水防管理団体の数（国土交通省の統計）。
- 重要水防箇所の評定基準（国土交通省の通達・各地方整備局の公開資料）の現行版と、都道府県での設定の例。
- 市町村地域防災計画の実例で、土木部局の事務分掌がどう書かれているか。例として 1〜2 市の公開版を版つきで確かめる（全国共通の書き方としては書かない）。

## 図・写真の候補
- 図: 平時（点検・訓練・協定）→ 出水期前（重要水防箇所の合同巡視）→ 警戒（洪水予報・水防警報・出動準備）→ 発災（避難指示・通報・公用負担）の時系列に、水防管理者（市町村長）・河川管理者・市町村長・土木担当の役割を帯で分けた図（自作の SVG）。
- 図: 国・都道府県・市町村の計画の関係（防災基本計画 → 都道府県地域防災計画・水防計画 → 市町村地域防災計画・水防計画）の入れ子図。
- 写真は使わない（法令と計画の話）。
