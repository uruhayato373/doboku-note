# A-37 災害復旧事業と災害査定 — 被災から国庫負担の決定、成功認定まで（骨子）

## 読者と場面
- 市町村の道路・河川の担当として、豪雨や地震で被災した市道・準用河川・橋・護岸などの復旧を任された人。被災直後に何を記録し、どの順で国庫負担の手続に載せるか、査定ではどこを見られるかで迷う。
- 「災害査定を待たずに工事してよいのか」「小さな被災は対象になるのか」「元通りに直せない場合は」といった判断を、法律・政令・国の公開資料から順に確かめたい。
- 被災前の点検と水防は A-16・A-38、土砂災害は A-39、会計検査は A-31 に任せる。この章は、被災後の復旧事業を国の負担で進める手続に絞る。

## 論点
- 被災したら、応急工事と被災状況の写真を先に残す
  - 根拠: https://www.mlit.go.jp/river/bousai/hukkyu/pdf/00-index-saigaihukkyu-gaiyo.pdf 国土交通省水管理・国土保全局「災害復旧事業（補助）の概要」（査定前の着工、写真が被災の事実を示す唯一の手段になること、応急的な仮工事も国庫負担の対象）
  - 根拠: disaster-restoration-subsidy-act-order#第4条 公共土木施設災害復旧事業費国庫負担法施行令第4条 第2項 応急工事費・仮設工事費を事業費に含める
- 国庫負担の対象かは、災害と施設の要件で決まる
  - 根拠: disaster-restoration-subsidy-act#第2条 災害（異常な天然現象による災害）と災害復旧事業の定義
  - 根拠: disaster-restoration-subsidy-act#第3条 国が費用の一部を負担する施設
  - 根拠: disaster-restoration-subsidy-act-order#第1条 同法施行令第1条 政令で定める公共土木施設
- 対象外になる箇所を先に見分ける
  - 根拠: disaster-restoration-subsidy-act#第6条 適用除外（市町村は一箇所の工事費が一定額に満たないもの、維持工事、設計の不備・維持管理の怠りによるもの、災害復旧事業以外の工事の施行中に生じたもの、など）
- 被災箇所は、連続の間隔で一箇所の工事にまとめる
  - 根拠: disaster-restoration-subsidy-act#第6条 第2項 災害にかかった箇所が百メートル以内の間隔で連続するものを一箇所の工事とみなす
  - 根拠: https://www.mlit.go.jp/toshi/content/001402749.pdf 国土交通省「大規模災害時における公共土木施設災害復旧事業査定方針」解説 令和4年6月改定 第八（一箇所工事の取扱い）
- 復旧は原形が原則、できなければ従前の効用を復旧する
  - 根拠: disaster-restoration-subsidy-act#第2条 第2項・第3項 原形復旧と、原形に復旧することが著しく困難又は不適当な場合の代わりの施設
  - 根拠: https://www.mlit.go.jp/river/bousai/hukkyu/pdf/00-index-saigaihukkyu-gaiyo.pdf 同上（原形復旧とは従前の効用を復旧するもの）
- 再度災害を防ぐ改良は、別の事業の枠で組む
  - 根拠: https://www.mlit.go.jp/river/bousai/hukkyu/pdf/00-index-saigaihukkyu-gaiyo.pdf 同上（改良復旧事業：河川等災害関連事業、河川等災害復旧助成事業）
  - 根拠: severe-disaster-act#第3条 激甚災害に対処するための特別の財政援助等に関する法律第3条 第1項第2号 再度災害の防止のために合併して行う新設・改良
- 被害は災害報告で、都道府県を通じて国へ伝える
  - 根拠: disaster-restoration-subsidy-act-order#第5条 公共土木施設災害復旧事業費国庫負担法施行令第5条 災害報告（市町村長から都道府県知事へ、知事が取りまとめて主務大臣へ）
  - 根拠: https://www.mlit.go.jp/river/bousai/hukkyu/pdf/00-index-nagare.pdf 国土交通省「災害復旧事業の主な流れ」（災害終息後の概算被害額の報告、訂正報告の期限）
- 国庫負担の申請には、設計書と目論見書を添える
  - 根拠: disaster-restoration-subsidy-act-order#第6条 同施行令第6条 第1項・第2項 目論見書・設計書の添付と、設計単価・歩掛の同意
- 市町村の書類は、都道府県を経由して出す
  - 根拠: disaster-restoration-subsidy-act-order#第6条 同施行令第6条 第3項
  - 根拠: disaster-restoration-subsidy-act#第13条 市町村の災害復旧事業費に関する事務を都道府県知事が行う
  - 根拠: disaster-restoration-subsidy-act-order#第12条 同施行令第12条 都道府県知事の事務
- 査定は、机上と実地に分かれて受ける
  - 根拠: https://www.mlit.go.jp/toshi/content/001402749.pdf 査定方針解説 令和4年6月 2.（机上査定上限額、採択保留金額の原則と、査定の法令・要綱・査定方針の体系）
  - 根拠: disaster-restoration-subsidy-act#第7条 災害復旧事業費の決定（地方公共団体の提出する資料、実地調査の結果等を勘案）
  - 根拠: https://www.mlit.go.jp/river/bousai/hukkyu/pdf/00-index-nagare.pdf 同上（災害査定の時期の目安）
- 大規模災害では、査定の手続が簡素になる
  - 根拠: https://www.mlit.go.jp/toshi/content/001402749.pdf 同上 第二〜第九（対象とする大規模災害、机上査定限度額・採択保留金額の引上げ、設計図書の簡素化）
- 査定で決まった設計を変えるときは、協議を要する
  - 根拠: disaster-restoration-subsidy-act-order#第7条 同施行令第7条 設計の変更（軽微な変更を除き、主務大臣の同意を条件とする）
  - 根拠: disaster-restoration-subsidy-act#第8条 国庫負担金の交付方法
- 工事の発注は、緊急度で随意契約か指名競争かを選ぶ
  - 根拠: public-works-quality-act#第7条 第1項第4号 災害時の随意契約・指名競争入札の活用
  - 根拠: local-autonomy-act-order#第167条の2 地方自治法施行令第167条の2 第1項第5号 緊急の必要により競争入札に付することができないとき
  - 根拠: https://www.mlit.go.jp/tec/content/001860706.pdf 関係省庁「発注関係事務の運用に関する指針」令和7年2月3日改正 Ⅲ 1－1（災害時における入札契約方式の選定）
- 職員が足りなければ、民間の力で査定の準備と発注を補う
  - 根拠: https://www.mlit.go.jp/tec/content/001860706.pdf 運用指針 Ⅲ 1－2（5）早期の災害復旧・復興に向けた取組（災害査定申請書の作成、発注、監督での事業促進 PPP・CM 方式の活用）
  - 根拠: public-works-quality-act#第22条 発注関係事務を適切に実施できる者の活用
- 国の負担率と地方債で、市町村の負担の姿を見積る
  - 根拠: disaster-restoration-subsidy-act#第4条 国庫負担率（標準税収入に応じた段階的な率）
  - 根拠: local-finance-act#第5条 第1項第4号 災害復旧事業費を地方債の財源とできる場合
  - 根拠: severe-disaster-act#第2条 激甚災害に対処するための特別の財政援助等に関する法律第2条 激甚災害の指定
- 完成したら、精算して成功認定を受ける
  - 根拠: disaster-restoration-subsidy-act#第10条 災害復旧事業費の精算と成功認定
  - 根拠: disaster-restoration-subsidy-act-order#第11条 同施行令第11条 成功認定の申請
  - 根拠: disaster-restoration-subsidy-act#第12条 剰余金の返還
- 目的外の使用や工事を施行しない部分は、返還を求められる
  - 根拠: disaster-restoration-subsidy-act#第9条 主務大臣の検査・報告の徴収と指示
  - 根拠: disaster-restoration-subsidy-act#第11条 負担金の還付

## 一次資料で確かめてから書く数値・規格
- 公共土木施設災害復旧事業費国庫負担法第6条の「市町村の一箇所の工事費六十万円未満」は適用除外（条文で確認済み）。現行の金額と、小規模施設の扱い（主務大臣が定める小規模な施設）を、公共土木施設災害復旧事業費国庫負担法施行規則と事務取扱要綱で確かめる。
- 机上査定の上限（原則 1,000 万円）と採択保留金額（原則 4 億円）は、国土交通省「大規模災害時における公共土木施設災害復旧事業査定方針」解説（令和4年6月）で確認済み。通常時の査定方針（昭和32年建河発第351号）の現行の値と、近年の改定を確かめる。
- 災害報告の期限（災害終息後 10 日以内に概算被害額、訂正は 1 か月以内）と、査定の時期の目安（被災後 2 か月以内）は、国土交通省「災害復旧事業の主な流れ」で確認済み。法令に書かれた期限ではない。
- 国庫負担率の段階（標準税収入の二分の一まで三分の二、二倍までは四分の三、超える部分は四分の四）の現行の条文と、激甚災害のかさ上げ率（激甚法第4条）。
- 事務費の算定率（施行令第4条第3項）の現行の数値。
- 公共土木施設の対象（施行令第1条）に、市町村が管理する施設のどこまでが入るか。
- 「異常な天然現象」の目安（降雨量や風速などの基準）。査定方針の現行の基準を確かめる。
- 災害復旧事業債の充当率と交付税措置。総務省の資料を版つきで確かめる（A-05 と重複させない）。

## 図・写真の候補
- 図: 災害発生 → 応急工事・写真 → 災害報告 → 測量・設計 → 国庫負担申請 → 災害査定 → 事業費の決定 → 発注・施工 → 精算 → 成功認定、の流れ図に、市町村・都道府県・国の担当を帯で分けたもの（自作の SVG）。国土交通省の流れ図を写さず、手続の順を自分で描く。
- 図: 原形復旧・効用の復旧（橋に替える等）・改良復旧の三つの違いを、河川の断面で示す概念図。
- 写真は使わない（被災の実物は実在の事例と結びつきやすい。必要なら AI 生成画像の監査を通す）。
