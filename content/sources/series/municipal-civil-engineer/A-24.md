# A-24 埋蔵文化財 — 包蔵地の照会と工事前の調査（骨子）

## 読者と場面
- 市町村の道路・河川・公園・区画整理などの事業担当になり、計画した場所が遺跡の地図に重なっていると言われた人。
- 教育委員会へ何をいつ出し、試掘や本発掘の費用と期間をどう予算と工程に織り込むかで迷う。
- 民間の開発の届出（法 93 条）と自治体自らの事業の通知（法 94 条）の違いも、ここで押さえる。
- 用地の取得と補償は A-23、事業化の段取りは A-21 に任せる。

## 論点
- 計画の早い段階で、予定地を教育委員会へ照会する
  - 根拠: https://www.bunka.go.jp/seisaku/bunkazai/shokai/pdf/hokoku_03.pdf 文化庁次長通知「埋蔵文化財の保護と発掘調査の円滑化等について」平成10年9月29日 庁保記第75号 3（開発事業との調整）
  - 根拠: https://www.bunka.go.jp/seisaku/bunkazai/shokai/pdf/93600501_01.pdf 文化庁「道路事業に伴う発掘調査の位置づけと発掘調査費用について（報告）」令和3年11月30日 2（2）公共事業の連絡調整
- 周知の包蔵地かどうかは、遺跡地図や台帳で確かめる
  - 根拠: cultural-properties-act#第95条 周知の埋蔵文化財包蔵地の周知
  - 根拠: https://www.bunka.go.jp/seisaku/bunkazai/shokai/pdf/hokoku_03.pdf 平成10年通知 4（包蔵地の把握と周知）
- 自治体の事業は届出でなく通知で、民間は届出になる
  - 根拠: cultural-properties-act#第93条 民間の土木工事等のための発掘の届出（六十日前）
  - 根拠: cultural-properties-act#第94条 国の機関・地方公共団体が行う発掘の通知
- 通知は事業計画をつくる段階で、あらかじめ出す
  - 根拠: cultural-properties-act#第94条 事業計画の策定に当たりあらかじめ通知
- 通知の受け手は教育委員会で、協議を求められることもある
  - 根拠: cultural-properties-act#第184条 通知の受理を都道府県・市の教育委員会が行える
  - 根拠: cultural-properties-act#第94条 協議を求める通知と協議の義務
- 範囲と深さは、試掘・確認調査で先に押さえる
  - 根拠: https://www.bunka.go.jp/seisaku/bunkazai/shokai/pdf/hokoku_03.pdf 平成10年通知 5（試掘・確認調査）
- 大きな事業は、包蔵地の外でも事前に試掘する
  - 根拠: https://www.bunka.go.jp/seisaku/bunkazai/shokai/pdf/93958001_02.pdf 文化審議会文化財分科会「これからの埋蔵文化財保護の在り方について（第一次報告書）」令和4年7月22日
- まず現状保存できないか、計画で避けられないかを考える
  - 根拠: https://www.bunka.go.jp/seisaku/bunkazai/shokai/pdf/hokoku_03.pdf 平成10年通知 1・6・7（1）現状保存の考え方
  - 根拠: https://www.bunka.go.jp/seisaku/bunkazai/shokai/pdf/93600501_01.pdf 令和3年報告 2（2）現状保存と記録保存
- 盛土で残すなら、事前の調査と記録を条件にする
  - 根拠: https://www.bunka.go.jp/seisaku/bunkazai/shokai/pdf/hokoku_03.pdf 平成10年通知 6（3）盛土等とその留意事項
- 本発掘は、範囲・期間・経費の提示を受けて協議する
  - 根拠: https://www.bunka.go.jp/seisaku/bunkazai/shokai/pdf/hokoku_03.pdf 平成10年通知 3（2）・6（2）
- 調査費は事業者として、事業費に見込む
  - 根拠: https://www.bunka.go.jp/seisaku/bunkazai/shokai/pdf/hokoku_03.pdf 平成10年通知 7（1）・（2）経費負担の理念と範囲
  - 根拠: https://www.bunka.go.jp/seisaku/bunkazai/shokai/pdf/93600501_01.pdf 令和3年報告 はじめに（公共工事の発掘調査費は事業者側の予算措置）
- 調査費の積算は、標準に沿った説明を受けて確かめる
  - 根拠: https://www.bunka.go.jp/seisaku/bunkazai/shokai/pdf/hokoku_04.pdf 文化庁調査研究委員会「埋蔵文化財の本発掘調査に関する積算標準について（報告）」平成12年9月28日
  - 根拠: https://www.bunka.go.jp/seisaku/bunkazai/shokai/pdf/94353501_01.pdf 文化庁調査研究委員会「埋蔵文化財発掘調査の設計の透明化と業務の発注に関するガイドライン」令和8年3月31日 Ⅱ・Ⅲ
- 調査を委託するなら、契約として設計・監督・検査する
  - 根拠: https://www.bunka.go.jp/seisaku/bunkazai/shokai/pdf/94353501_01.pdf 令和8年3月31日ガイドライン Ⅱ（発注の基本事項）・Ⅴ（監理、監督・検査）
- 工区を分け、調査と工事を並行させて工期を縮める
  - 根拠: https://www.bunka.go.jp/seisaku/bunkazai/shokai/pdf/hokoku_03.pdf 平成10年通知 3（3）発掘調査の円滑・迅速化
  - 根拠: https://www.bunka.go.jp/seisaku/bunkazai/shokai/pdf/94353501_01.pdf 令和8年3月31日ガイドライン コラム（事業者負担軽減への取組）
- 調査で工事が止まるときの、一時中止と工期の見直し
  - 根拠: standard-contract-terms#第20条 発注者の都合による工事の一時中止（約款の条文は採用する版で確かめる）
- 工事中に遺跡を見つけたら、現状を変えず通知する
  - 根拠: cultural-properties-act#第97条 国の機関等が遺跡を発見したときの通知
  - 根拠: cultural-properties-act#第96条 土地の所有者等の発見の届出と停止命令（民間の場合との比較）

## 一次資料で確かめてから書く数値・規格
- 周知の埋蔵文化財包蔵地の全国の数（令和4年7月の報告書は「47万か所以上」と書く。脚注の出典年と頁を確かめる）。
- 民間の届出は工事の 60 日前（法 93 条）、遺跡発見時の停止命令は 3 か月以内で、延長しても通算 6 か月まで（法 96 条）。条文は確認済みだが、記事にする時点の最新の版でもう一度見る。
- 各県の「発掘調査の基準」「照会の様式」「通知の様式」は県・市ごとに違う。例として使う県市の資料は、公開ページを開いて版と頁を確かめてから使う（宮城県「埋蔵文化財発掘調査標準」平成31年4月は、国の次長通知 16庁財第312号（平成16年12月20日）に基づく県の例として開いて確認した）。
- 試掘の依頼から結果が出るまでの目安の期間（市の手引きに「着工の 3 か月前」と書く例を見たが、資料名・版を確かめていない）。

## 図・写真の候補
- 図: 計画 → 照会 → 周知の包蔵地か → 通知（協議）→ 試掘・確認調査 → 現状保存か記録保存か → 本発掘 → 工事の流れ図（自作の SVG。通知の根拠条文を節目に付ける）。
- 図: 民間（届出・60 日前）と自治体の事業（通知・事業計画の策定時）の違いの 2 列の対比（表にすると 2 軸になる）。
- 写真: 試掘のトレンチ（掘って遺構面を確かめる様子）。AI 写真にする場合は実物どおりかを監査する。
