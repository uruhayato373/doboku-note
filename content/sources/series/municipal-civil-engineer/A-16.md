# A-16 河川管理施設の点検と操作 — 堤防・樋門・水門（骨子）

## 読者と場面
- 市町村の河川担当になり、準用河川や、管理を受け持つ樋門・水門・陸閘・排水機場を引き継いだ人。または、都道府県が管理する川の樋門の操作を地域に委託される側の人。
- 出水期前に何をいつまでに点検するか、結果をどう評価して補修の順を決めるか、洪水のとき誰がどの水位で操作し、いつ退避するかで迷う。
- 堤防がなぜ壊れるか、どう補強するかは既存記事に任せる。この章は「管理者としての点検の義務と段取り」と「操作の決まりと操作員の安全」を扱う。

## 論点
- 施設の維持と修繕は管理者の義務
  - 根拠: river-act#第15条の2 河川管理施設・許可工作物の維持又は修繕と、点検に関する基準を含む技術的基準
  - 根拠: river-act-order#第9条の3 維持又は修繕に関する技術的基準等
- 巡視・点検・措置は別の仕事として組む
  - 根拠: river-act-order#第9条の3 第1項 第1号（巡視）・第2号（点検）・第4号（異状を把握したときの措置）
  - 根拠: small-river-inspection-guideline#I-4.1 令和6年3月版（https://www.mlit.go.jp/river/shishin_guideline/kasen/pdf/02_chusyou_tenkenyoukou.pdf）（巡視の機会を活用した点検＝巡視中に異常を見つけたら変状箇所へ移動して詳細を確認する方法。点検そのものは巡視と別に計画する）
- 年1回以上の点検が要る施設を台帳から特定する
  - 根拠: river-act-order#第9条の3 第1項 第3号 ダム・堤防などは1年に1回以上の適切な頻度
  - 根拠: river-act-rules#第7条の2 河川法施行規則第7条の2 第1項 年1回以上の点検が要る施設（堤内地盤高が計画高水位より高い区間の盛土による堤防を除く堤防、その堤防が存する区間の可動堰・水門・樋門など）
  - 根拠: small-river-inspection-guideline#I-2 令和6年3月版 適用範囲（規則第7条の2の堤防等を、出水期前等の適切な時期に1年に1回以上点検する）
- 準用河川にも同じ点検の義務が及ぶ
  - 根拠: river-act#第100条 準用河川への準用
  - 根拠: river-act-order#第57条の4 政令の準用河川への準用（第9条の3を除外していない）
  - 根拠: river-act-rules#第38条の4 河川法施行規則第38条の4 省令の準用河川への準用（第7条の2を含む）
- 点検は出水期前と台風期に、出水の後にも行う
  - 根拠: small-river-inspection-guideline#I-2 令和6年3月版 適用範囲（出水期前等の適切な時期に1年に1回以上）
  - 根拠: https://www.mlit.go.jp/river/shishin_guideline/kasen/pdf/01_teibou_tenkenhyouka_youryou_r503.pdf 国土交通省「堤防等河川管理施設及び河道の点検・評価要領」令和5年3月 I-3.2 点検の実施時期（出水期前・台風期・出水後。直轄向けの例）
- 点検の頻度と方法は川の区間を4つに分けて決める
  - 根拠: small-river-inspection-guideline#I-3.2 令和6年3月版 河川の区間区分・II-2 表2.1（堤防が存する区間は1年に1回を基本、堤防が存しない掘込み区間は1年に1回が望ましい。有堤区間（一般）と掘込み区間は巡視の機会を活用した点検も可）
- 点検は2人以上で歩き、写真と定点で記録する
  - 根拠: small-river-inspection-guideline#I-4.1 令和6年3月版 点検方法・4.2 点検の体制（目視点検は班2人以上、変状は写真に撮り次回も同じ位置・方向で撮れるよう現地にマーキング、水防団・自治体と連携）
- 樋門・水門は函体と周辺の堤防を一組で見る
  - 根拠: small-river-inspection-guideline#III-1 令和6年3月版 点検・評価の対象（樋門・水門の周辺の堤防は堤防の一般区間と区分して点検する。範囲は概ね取付護岸の施工範囲）
  - 根拠: https://www.mlit.go.jp/river/shishin_guideline/kasen/pdf/01_teibou_tenkenhyouka_youryou_r503.pdf 同上 別紙 点検結果記録様式（樋門・樋管、水門、堰ごとの様式1〜3）
- 変状は3〜4区分で評価して、措置の要否を決める
  - 根拠: https://www.mlit.go.jp/river/shishin_guideline/kasen/pdf/01_teibou_tenkenhyouka_youryou_r503.pdf 同上 I-4.1 評価の手順（異常なし・要監視段階・予防保全段階・措置段階の4区分、一次評価と二次評価）
  - 根拠: small-river-inspection-guideline#II-3 令和6年3月版 表2.2（中小河川版は異状なし・監視段階・措置段階の3区分を基本とする）
- ゲートやポンプなどの機械設備は別の基準で点検する
  - 根拠: small-river-inspection-guideline#I-2 令和6年3月版 適用範囲（堰・水門・樋門の機械設備と電気通信施設は対象外で、別に定められた規程・マニュアルによる）
- 許可工作物は設置者が点検し、管理者は合同で確かめる
  - 根拠: river-act#第15条の2 第1項 許可工作物の管理者も維持・修繕の主体
  - 根拠: https://www.mlit.go.jp/river/shishin_guideline/kasen/pdf/01_teibou_tenkenhyouka_youryou_r503.pdf 同上 I-2 適用範囲（許可工作物は設置者の点検が基本、必要に応じ河川管理者と合同点検）
- 点検の記録は次の点検まで保存する
  - 根拠: river-act-rules#第7条の2 河川法施行規則第7条の2 第2項 記録する事項（年月日・点検者の氏名・結果、可動部の作動状況）と保存期間
  - 根拠: small-river-inspection-guideline#I-6 令和6年3月版 点検・評価結果の記録と活用（年月日・点検者の氏名・結果を記録し、総合的な評価は別紙様式で電子保存が望ましい）
- 操作規則を定める施設は法令で決まっている
  - 根拠: river-act#第14条 第1項 河川管理施設の操作規則
  - 根拠: river-act-order#第8条 操作規則を定めなければならない河川管理施設（洪水の調節・流水の分流・内水の排除・逆流の防止など）
- 操作規則には水位・方法・点検整備・観測・措置を書く
  - 根拠: river-act-order#第9条 河川管理施設の操作規則に定める事項
- 操作員が退避する水位を先に決めておく
  - 根拠: https://www.mlit.go.jp/river/shishin_guideline/kasen/pdf/himon_sousa_guideline.pdf 国土交通省水管理・国土保全局「樋門等の操作規則・操作要領作成における操作員退避検討に当たってのガイドライン」令和元年6月21日事務連絡
- 操作を地域に委ねるなら委託契約に安全と被災時の対応を書く
  - 根拠: river-act#第99条 地方公共団体等への委託
  - 根拠: https://www.mlit.go.jp/river/shishin_guideline/kasen/pdf/sisetsusousa_itaku.pdf 国土交通省水管理・国土保全局河川環境課長「河川管理施設の操作の委託について」平成24年3月9日国水環第106号
- 陸閘は閉め切れなくても避難を優先する決まりにする
  - 根拠: https://www.soumu.go.jp/main_content/000891170.pdf 総務省「河川の陸閘の管理・運用に関する調査の結果に基づく勧告（概要）」令和5年7月7日
- 出水中の巡視は水防管理者が行い、管理者へ連絡する
  - 根拠: flood-control-act#第9条 河川等の巡視（水防上危険な箇所を河川管理者に連絡して措置を求める）
  - 根拠: flood-control-act#第3条 市町村の水防責任

## 一次資料で確かめてから書く数値
- 国土交通省の点検・評価要領の版: 中小河川版は令和6年3月（国水環保第5号）、直轄版は令和5年3月、参考資料は平成31年4月。中小河川版の対象は都道府県・政令市が管理する一級・二級河川で、市町村の準用河川には技術的助言として周知されたもの（参考扱い）。書く直前に国土交通省の「河川管理施設の点検・評価要領」のページで、これより新しい版が出ていないか確かめる。
- 河川法施行規則第7条の2が挙げる施設の範囲と、準用河川への読み替え（第38条の4）。書く直前に e-Gov の現行条文で引き直す。
- 操作規則の作成基準（国土交通省水管理・国土保全局の通知）の最新の版。事務連絡が引く「令和元年6月20日国水環第4号」を直接開いて確かめる。
- 総務省の勧告の本文にある調査の数（陸閘 110 基のうち、規定が無かったものの割合など）。概要の数字を使う前に本文で確かめる。

## 図・写真の候補
- 図: 点検（出水期前・台風期・出水後） → 一次評価 → 二次評価 → 措置 → 記録 の年間サイクルの流れ図（自作の SVG）。
- 図: 樋門の断面図に、点検する部位（函体・継手・ゲート・取付護岸・周辺の堤防）を重ねた図（自作の SVG）。
- 写真: 樋門の機側操作盤と操作員（AI 写真にする場合は実物どおりの監査を通す）。
