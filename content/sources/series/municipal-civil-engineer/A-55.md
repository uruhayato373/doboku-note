# A-55 設計業務の監督と成果品の確認 — 業務の流れ、照査、図面と数量の見方（骨子）

## 読者と場面
- 設計コンサルタントに調査・計画・設計を委託し、打合せの席に着き、納品された成果品を受け取る市町村の担当。工事の監督は経験があっても、設計業務では何を見て何を承諾するのかが分からない人。
- 設計の技術（構造計算や水理計算）の中身は書かない。発注者が仕様書で示すもの、打合せで決めるもの、成果品で確かめるものに絞る。
- 扱わないこと: 積算と予定価格（A-60）、工事の設計変更（A-29、cost-and-design-change）、工事の検査（A-28、construction-inspection-types）。

## 論点
- 調査・計画・設計は、成果の使い道で見分ける
  - 根拠: mlit-design-work-common-specification-2026 国土交通省 土木設計業務等共通仕様書（案）令和8年度版 第1203条〜第1206条
- 概略・予備・詳細設計は、出す成果が違う
  - 根拠: mlit-design-work-common-specification-2026 同仕様書 第1206条第2項〜第4項
- 設計条件は受注者が設定し、発注者が承諾する
  - 根拠: mlit-design-work-common-specification-2026 同仕様書 第1209条第1項
- 使う技術基準は特記仕様書と最新版で決まる
  - 根拠: mlit-design-work-common-specification-2026 同仕様書 第1201条
- 業務計画書は、契約後 14 日以内に出させる
  - 根拠: mlit-design-work-common-specification-2026 同仕様書 第1112条
- 打合せは、着手時と業務の区切りで行う
  - 根拠: mlit-design-work-common-specification-2026 同仕様書 第1111条第1項・第2項・第4項
- 調査職員の権限は、指示・承諾・協議に分かれる
  - 根拠: mlit-design-work-common-specification-2026 同仕様書 第1102条（用語の定義）第3項〜第6項
- 照査は受注者の責任で、照査技術者を置く
  - 根拠: mlit-design-work-common-specification-2026 同仕様書 第1108条第2項・第3項
- 設計図・計算書・数量の整合を赤黄チェックで見る
  - 根拠: mlit-design-work-common-specification-2026 同仕様書 第1108条第1項
- 成果品は、概要書・計算書・図面・数量計算書でそろう
  - 根拠: mlit-design-work-common-specification-2026 同仕様書 第1211条
- 数量は、国の数量算出要領の約束で確かめる
  - 根拠: nilim-quantity-calculation-guideline-2026 国土技術政策総合研究所 令和8年度 土木工事数量算出要領 第1編 第1章 1.2・1.3
- 概算工事費は、協議した単価と概略数量で出す
  - 根拠: mlit-design-work-common-specification-2026 同仕様書 第1211条（5）
- 比較案の検討に、新技術の情報も使わせる
  - 根拠: mlit-design-work-common-specification-2026 同仕様書 第1209条第12項
- 条件を変えるときは、指示書で出す
  - 根拠: mlit-design-work-common-specification-2026 同仕様書 第1121条第2項・第1122条
- 検査は、成果物と業務の管理状況の二つを見る
  - 根拠: mlit-design-work-common-specification-2026 同仕様書 第1119条第3項
- 不備は、検査職員が期限を付けて修補させる
  - 根拠: mlit-design-work-common-specification-2026 同仕様書 第1120条
- 成果物は電子納品の要領に沿って受け取る
  - 根拠: mlit-design-work-common-specification-2026 同仕様書 第1117条第4項
- 契約図書は、契約書と設計図書をいう
  - 根拠: mlit-design-work-common-specification-2026 同仕様書 第1102条（用語の定義）第12項・第14項

## 図・写真の候補
- 図: 設計業務の流れ（発注 → 業務計画書 → 打合せ → 照査 → 成果物の提出 → 検査 → 修補）と、各場面で発注者が出すもの・確かめるものを並べた時系列の図（自作の SVG）。
- 図: 概略設計・予備設計・詳細設計が、それぞれ何を出すかを段階で並べた図（自作の SVG）。
- 図: 設計図・設計計算書・数量計算書を結ぶ赤黄チェックの考え方の概念図（自作の SVG）。

## 一次資料で確かめてから書く数値
- 土木設計業務等共通仕様書（案）の版（令和8年度版）と条番号。市町村の仕様書は国の例と違うため、記事では「国の例」と書く。
- 業務計画書の提出期限（契約締結後 14 日）と、担当技術者の人数の上限（8 名）。
- 詳細設計照査要領は、第1108条第2項が引く要領の現行版を本省の原本で確かめる（再掲載のみ確認）。土木設計業務等変更ガイドラインは本文を読んでから使う（本文は未読のため、この章の論点には入れていない）。
