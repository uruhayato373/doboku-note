# A-58 着工前に確かめるほかの法令の手続き — 埋蔵文化財・リサイクル・土壌・保安林・盛土・景観・ドローン（骨子）

## 読者と場面
- 道路・河川・公園の工事を発注する直前の市町村の担当。設計はできたが、「ほかの法律の届出や許可は要らないか」を、何の順で確かめればよいのか分からない人。
- 法令ごとの解説を並べる記事にしない。着工前の確認表として、対象になる規模、手続の名前（届出・許可・通知・協議）、市町村が発注者のときに手続が変わるかを一つずつ示す。
- 扱わないこと: 道路法の占用・承認工事（road-work-approval-vs-road-use-permit）、都市計画法の開発許可（A-33）。埋蔵文化財・景観・環境影響評価は既存記事へ任せる。自治体が発注者のときの特例の有無が条文から読めないものは、「確認が要る」と書く。

## 論点
- 発注者が自治体だと、届出が通知か協議に変わる
  - 根拠: construction-recycling-act#第11条 建設リサイクル法 第11条（国の機関・地方公共団体の通知）
  - 根拠: landscape-act#第16条 景観法 第16条第5項（国・地方公共団体の通知）
  - 根拠: cultural-properties-act#第94条 文化財保護法 第94条（国の機関・地方公共団体等の通知）
- 道路の交差部の改築などは、公安委員会の意見を聴く
  - 根拠: road-act#第95条の2 道路法 第95条の2第1項
- 建設リサイクル法の対象は、工事の規模で決まる
  - 根拠: construction-recycling-act-order#第2条 建設リサイクル法施行令 第2条
- 契約を分けても、同じ者の工事は 1 契約とみなす
  - 根拠: construction-recycling-act-order#第2条 同施行令 第2条（分割して請け負う場合）
- 対象の工事は、着工前に都道府県知事へ通知する
  - 根拠: construction-recycling-act#第11条 建設リサイクル法 第11条
  - 根拠: construction-recycling-act#第10条 建設リサイクル法 第10条第1項（民間の届出は着手の 7 日前まで）
- 受注者は、発注者へ書面で内容を説明する
  - 根拠: construction-recycling-act#第12条 建設リサイクル法 第12条第1項
- 土壌の形質変更は、3,000 平方メートル以上で届出
  - 根拠: soil-contamination-act#第4条 土壌汚染対策法 第4条第1項
  - 根拠: soil-contamination-act-rules 土壌汚染対策法施行規則 第22条
- 土壌汚染対策法の届出に、自治体を除く例外はない
  - 根拠: soil-contamination-act#第4条 土壌汚染対策法 第4条第1項ただし書（例外は三つで、国・自治体の行為は挙がっていない）
- 工事で出る廃棄物は、元請が事業者として扱われる
  - 根拠: waste-management-act#第21条の3 廃棄物処理法 第21条の3第1項
- 産業廃棄物を委託するときは、管理票を交付する
  - 根拠: waste-management-act#第12条の3 廃棄物処理法 第12条の3第1項
- 保安林の伐採や形質変更は、知事の許可が要る
  - 根拠: forest-act 森林法 第34条第1項・第2項
- 林地開発の許可は、国・自治体の事業は適用除外
  - 根拠: forest-act 森林法 第10条の2第1項
  - 根拠: forest-act-order 森林法施行令 第2条の3（道路の新設・改築の規模）
- 盛土・切土の規模は、政令の高さと面積で決まる
  - 根拠: residential-land-fill-regulation-act-order 宅地造成及び特定盛土等規制法施行令 第3条
- 規制区域内の工事は許可。市町村は特例の文言にない
  - 根拠: residential-land-fill-regulation-act 宅地造成及び特定盛土等規制法 第12条第1項・第15条第1項（市町村発注の運用通知は未確認）
- 国立・国定公園の特別地域は、工作物や伐採に許可
  - 根拠: natural-parks-act 自然公園法 第20条第3項
- 自然公園法の国の特例は、国の機関だけを挙げる
  - 根拠: natural-parks-act 自然公園法 第68条第1項
- 景観計画の区域では、自治体の工事も事前に通知
  - 根拠: landscape-act#第16条 景観法 第16条第1項・第5項・第6項
- 周知の埋蔵文化財包蔵地は、計画の段階で通知する
  - 根拠: cultural-properties-act#第94条 文化財保護法 第94条
- 都市計画施設の区域内の建築は、許可が要る
  - 根拠: city-planning-act#第53条 都市計画法 第53条第1項
- 無人航空機は、空域と飛ばし方で許可・承認が要る
  - 根拠: civil-aeronautics-act 航空法 第132条の85・第132条の86

## 図・写真の候補
- 図: 着工前の確認表（法令 → 対象の目安 → 手続の名前 → 提出先 → 自治体が発注者のときの扱い）を、法令の色分けで並べた一覧の図（自作の SVG・表にしない）。
- 図: 「届出」「許可」「通知」「協議」の違い（だれが、いつ、だれに、返事が要るか）を並べた対比図（自作の SVG）。
- 図: 工事の計画から着工までの時間軸に、各法令の届出の期限（30 日前、7 日前、60 日前など）を並べた図（自作の SVG）。

## 一次資料で確かめてから書く数値
- 土壌汚染対策法施行規則の規模（3,000 平方メートル、900 平方メートル）と施行日（令和8年7月1日の版）。国・自治体向けの特例は、条文のうえでは確認できていない。
- 森林法・盛土規制法・航空法・自然公園法で、市町村が発注者のときの運用通知（保安林の作業許可・保安林解除の運用、盛土規制法の協議の扱い）は未確認。公開の通知で確かめてから書く。
- 建設リサイクル法施行令第2条の規模（80 平方メートル・500 平方メートル・1 億円・500 万円）の現行の値。
- 景観法は令和8年11月24日施行の版がある。条の番号は最新の本文で確かめる。
- 文化財保護法第92条・第93条の期限（60 日前）と、第94条の通知の窓口（都道府県の教育委員会）の現行の運用。
- 都市計画道路の区域内の制限は、都市計画法第53条（建築の許可）の範囲で書く。土木の工事そのものの制限は、確かめられなかったため論点に入れていない。希少種（種の保存法）の手続も同様。
