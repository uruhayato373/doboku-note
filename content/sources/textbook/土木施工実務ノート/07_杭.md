# §7 杭（Pile）

## この章の要旨

- 杭は上部構造物の荷重を支持地盤へ伝える部材であり、必要な支持力を備えていなければならない
- 施工中の孔壁崩壊を防ぐには、工法ごとの「何で孔壁を保たせているか」を理解する
- 場所打ち杭のコンクリートは水中コンクリートとして扱う。余盛りの処理まで含めて品質管理である
- 杭施工の要点は **孔壁保護・孔底処理・杭頭部と構造物の連結** の3点に集約される
- 土質データや設計値だけでは、施工段階で支持力が確保される保証にはならない。現物での確認が要る

---

## 7-1 既製杭と場所打ち杭の比較

基礎杭は、工場製造の杭を打ち込む **既製杭** と、現場で杭孔を掘削し鉄筋を建て込んでコンクリートを打つ **場所打ち杭** に大別される。設計図で指定されていても、工法の長短を理解したうえで短所をカバーする手立てを準備しておく。

| | 既製杭 | 場所打ち杭 |
|---|---|---|
| 品質 | 工場製造で杭体品質が保証される | 現場打設のため孔壁・打設管理に品質が左右される |
| 施工速度 | 鉄筋建込みや打設が不要で速い | 掘削→鉄筋→打設と工程が多い |
| 寸法の制約 | 杭径 **約1,000mmまで**／杭長 **約40mまで** | 大口径・大深度に対応（深礎では最大 **10m程度**） |
| 支持層のズレ | 追加材の調達に時間がかかる | 掘削しながら施工管理で柔軟に対応できる |
| 支持層の確認 | 事前ボーリングが頼り。現場での目視採取は難しい | 排出土を採取して事前データと照合できる |
| 排土量 | 少ない | 多い |
| 経済性 | 本数が増えると割高。大規模工事では不利 | 本数が多いほどスケールメリットが出る |
| 環境影響 | 打撃工法は騒音・振動が大きい | 打撃がないぶん小さい |
| その他 | 現場に仮置きスペースが必要。在庫がなければ工場製作待ちで工程に響く | 杭頭処理の手間が多い。天候・気温が打設に影響する |

**なぜ既製杭で工程管理が問題になるか** — 長尺品は在庫が薄い。支持層が想定より深いと分かった時点で追加発注しても、製作と運搬（トレーラー）に日数がかかり、現場が止まる。継杭の場合は溶接品質の管理も加わり、悪天候時は溶接自体ができない。

## 7-2 場所打ち杭① オールケーシング工法（ベノト杭）

孔壁に働く土圧を、**ケーシングチューブという鋼管で物理的に押さえる**工法。孔壁保護の原理が最も分かりやすく、土木工事での実績が多い。

| 項目 | 内容 |
|---|---|
| 杭径 | **1.0〜3.0m程度** |
| 杭長 | **30m程度**まで |
| 孔壁保護 | ケーシングチューブ（機械的な支保） |
| 安定液 | 原則不要 |

### 長所

- ケーシングで孔壁が安定するため、杭体品質を確保しやすい。孔壁管理が比較的容易
- ベントナイトを使わないので、残土は天日乾燥後に再利用できる（産業廃棄物として扱わなくてよい）

### 短所

- 大型機械を使うため、金属音と振動が大きい
- 転石・砂礫層ではケーシング引抜き時に周面摩擦が増し、**引き抜けなくなる**ことがある

### 現場で効く判断

- 引抜き困難が予想される地盤では、揺動型ではなく **全周回転型** の引抜機を選定する
- コンクリート打込み後は速やかにケーシングを引き抜く。時間を置くほど抜けにくくなる
- **鉄筋の共上がりは一度起きると復旧できない。** 所定位置に戻すことはほぼ不可能なので、事前対策がすべて
  - トランシット等でケーシング挿入時の垂直性を確認する
  - 組立時にスペーサーを確実に取り付け、かぶりを確保する
  - ラップ部が動かないよう番線でしっかり固定する
  - 引抜きは慎重かつ垂直に行う

## 7-3 場所打ち杭② アースドリル工法

ドリリングバケットを回転させて先端の土砂を削り取り、バケット内に取り込んで孔外へ排出する。孔壁は **安定液の比重と地下水との比重差** で保たせる。地表部はスタンドパイプ、それより深い部分は安定液が受け持つ。

| 項目 | 内容 |
|---|---|
| 杭径 | **0.8〜3.0m程度** |
| 杭長 | 通常 **30m程度** |
| 孔壁保護 | 安定液（比重 **1.01〜1.10程度**） |
| 施工速度 | 支障物がなければ他工法より速い |

### 長所

- 底部でドリリングバケットを **拡底翼** に交換すれば拡底杭が形成でき、先端支持力を高められる
- オールケーシング工法に比べて騒音・振動が小さい

### 短所

- ベントナイトを使うため建設汚泥（建設副産物）が発生する
- ベントナイトの介在により、**周面摩擦力は計算に算入できない。**
- ドリリングバケットは **約10cm以上の礫層** の掘削が困難。事前に土層・土質を確認しておく

### この工法の生命線は比重管理

比重が **低すぎる** と孔壁を押し返せず崩壊する。比重が **高すぎる** とバケットの撹拌能力が落ち、作業効率が下がる。掘削の進行とともに土砂が混ざって比重は動くので、排出量に見合った常時の比重確認が要る。

## 7-4 場所打ち杭③ リバース工法

孔内に清水を満たし、周囲の地下水位より約 **2m高い水位** を維持することで、内側からの水圧で孔壁を保たせる。切削土砂はポンプで孔内水ごと吸い上げ、分離後に泥水を孔内へ戻して循環させる。この「逆循環」が名称の由来とされる。

| 項目 | 内容 |
|---|---|
| 杭径 | **0.8〜3.0m程度** |
| 杭長 | **75m程度**まで（場所打ち杭では最深クラス） |
| 孔壁保護 | 水頭差 **2m以上** |
| 表層部 | スタンドパイプ／ケーシング |

### 長所

- 機械がコンパクトで、**上空制限のある場所**でも施工できる
- 特殊ビットを使えば岩盤の掘削も可能
- 低振動・低騒音。逆循環方式のため、マッドスクリーンで分離した土砂を再利用できる

### 短所

- 水頭差が確保できないと孔壁が崩壊する
- **直径15cm以上の礫** は先端ビットで掘れない
- 他工法に比べて施工スピードが遅い

### 水頭差が取れないときの手

周辺地下水位が高くて2mの差が作れない場合、**ウェルポイント等で周辺地盤の地下水位を約2m低下させ、相対的に水頭差を確保する**という解決事例がある。孔内水位を上げるだけが手ではない。

## 7-5 場所打ち杭④ 深礎工法

現在使われている場所打ち杭のなかで最も古い技術。**人力掘削＋軽量なライナープレート**の組み合わせで成立するため、施工機械が進入できない急傾斜地や山間部でも施工できる。機械掘削の場合はテレスコクラムシェル等を使う。

| 項目 | 内容 |
|---|---|
| 杭径 | **1.6〜3.5m程度**（近年は **10m程度**を超える大口径深礎も） |
| 杭長 | **50m程度**まで |
| 孔壁保護 | ライナープレート（大口径ではコンクリート吹付け＋ロックボルト） |
| 孔内排水 | **毎分0.2m³** が限界の目安 |

### 長所

- 発破を併用すれば岩盤（支持層）の掘削も可能
- **アンダーピーニング工法**に適用できる。既存構造物の周囲に深礎杭を施工して新たな基礎を作り、沈下状況を修正する工法である
- 支持層を直接目視でき、シュミットハンマー等で強度を確認できる（→7-12）

### 短所

- 人力主体のため施工速度が遅い
- **上下作業になる。** 作業員が孔内にいる状態でクラムシェルによる排土を行うため、バケットからの土砂・破砕岩の落下が常に危険要因となる。ライナープレートへの落下防止ネット設置と、退避場所の確保が必須

### 現場で押さえること

- ライナープレート背面には必ず空隙ができる。エアーモルタル等で充填する。充填用の配管はコンクリート打込み前に孔内へ整えておく
- 表層に近い部分は掘削中の崩壊が起きやすく、山出しが目立たない場合は薬液注入等の対策も検討する
- 発破作業を行う場合、有資格者の配置・火薬の運搬保管・発破方法まで各段階で関係法令を遵守する

## 7-6 既製杭① 打込み杭工法

既製杭工法は **打込み・埋込み・回転** の3つに分類される。打込み杭工法は、油圧ハンマーやドロップハンマーで杭頭を打撃し、所定深さまで打ち込む方式。

| 分類 | 主な工法 |
|---|---|
| ①打込み杭工法 | 打撃工法 |
| ②埋込み杭工法 | 中掘り工法／プレボーリング工法／鋼管ソイルセメント杭工法（→7-7） |
| ③回転杭工法 | 回転圧入（→7-8） |

杭材は **鋼管杭・RC杭・PC/PHC杭**。

### 長所

- 他工法に比べて施工速度が速く、経済的。機械も小型で済む
- 地下水位に影響されない。斜杭の施工もできる
- 最終打撃時の **貫入量とリバウンド量** から、支持層への貫入を施工中に評価できる（→7-12）

### 短所

- 騒音・振動が大きく、近隣構造物への影響が懸念されるため **市街地ではほぼ採用できない。**
- 硬い地盤では垂直精度の確保が難しい

### 天端が壊れても高さ管理を続けるために

杭頭部がハンマーで破壊されると打止め高さの基準を失う。そうなる前提で、**天端から下方（例：100cm下）にマーキングを事前に入れておく**。天端が壊れてもこのマークから高さを追える。

## 7-7 既製杭② 埋込み杭工法

掘削ビット等で土砂をほぐし、根固め液・杭周固定液を注入してソイルセメント状にした孔に既製杭を沈設する。**中掘り工法／プレボーリング工法／鋼管ソイルセメント杭工法** の3種。杭材は鋼管杭・PC杭・PHC杭。

### 長所

- 打撃しないため騒音・振動が小さく、スピーディー
- 孔内に **品質の保証された既製杭** が入る。現在の既製杭工法の主流
- 掘削孔壁と杭体外周の隙間がソイルセメントで充填されるため、水平抵抗や周面摩擦力の向上が期待できる

### 短所

- 中間層に砂礫層や締まった砂層があると、**杭が途中で止まる**懸念がある
- 支持地盤が砂礫層の場合、根固め液の撹拌が不十分だと先端支持力が得られない
- スパイラルオーガの掘削が偏ると孔が傾斜する。ケーシングとオーガを同時回転できるドーナツオーガタイプの掘削機が有効

### 液の比重が両方向に効く

| 液 | 低すぎると | 高すぎると |
|---|---|---|
| 杭周固定液 | 孔壁が崩壊する | 杭体と孔壁の摩擦力が低下する |
| 根固め液 | 逸走して先端支持力が得られない | — |

施工中は常に比重を確認し、根固め液は **天端高さ** で管理する。

## 7-8 既製杭③ 回転杭工法

杭の先端部に溶接した **羽根（先端翼）** を回転させて掘削しながら、杭体を地中に押し込む。杭材は主に鋼管杭。

### 長所

- 羽根により先端面積が増加し、**高い支持力**が期待できる
- 孔壁保護のセメントミルクが不要なため、現場設備がコンパクトで済む
- 周囲への振動・騒音がほとんどない
- 排出土をほとんど出さない（残土が少ない）

### 短所

- 回転に対する反力が必要なため、機械が大型化しやすい
- 中間層に礫があると回転力が不足し、貫入できないことがある
- 転石等の障害物があると回転そのものが成立しない

### 事前と施工中の確認

- ボーリングデータを詳細に分析し、**転石など障害物がないこと**を着手前に確認する
- 施工中は掘削値や **積分電流値** で支持層到達を判断し、1本ごとに記録する（→7-12）

## 7-9 場所打ち杭に関する留意事項① コンクリート工

場所打ち杭のコンクリートは **水中コンクリート** である。孔内水の水面には不純物が浮いており、これを杭体に巻き込ませないことが打設管理のすべて。

### トレミー管の使い方

- トレミー管を用い、管の先端を **打設済みコンクリート中に2m以上挿入した状態**を保ちながら押し上げる
- 挿入長が **2m未満** になると、孔内水と不純物がコンクリート内へ回り込み、杭体に残る
- 余盛りは **計画天端から概ね1m程度**。余盛りが不足すると不純物が杭体側に残る

## 7-10 場所打ち杭に関する留意事項② 杭径

かつて杭支持力データの改ざんによるマンション不等沈下が社会問題化した。杭径は先端支持面積に直結するため、施工者にとって重要な管理項目である。

### 杭径を決めているのはケーシングではない

**杭の直径は、周辺地山と接触する部分の直径で決まる。** ケーシングチューブの外径ではない。

| 部位 | 寸法の考え方 |
|---|---|
| ケーシングチューブ | 公称値の **−30〜−20mm**（公称1,000mmなら実寸 **970〜980mm**） |
| カッティングエッジ | 公称値より外側に **約20mm以上** オーバーカット |
| アースドリル | サイドカッターが同じ役割を果たす |

**なぜオーバーカットするのか** — ケーシングと孔壁が同径だと周面摩擦が大きすぎて、挿入も引抜きもできなくなる。エッジを外側に張り出して孔を一回り大きく削ることで、摩擦を逃がしている。

### 摩耗を放置すると出来形が落ちる

カッティングエッジやサイドカッターは掘削と回転で摩耗する。

- 公称1,000mmの先端支持面積は **0.785m²**
- これが摩耗で **970mm** になると、先端支持面積が **約6%減少** する
- 施工中も定期的に摩耗を点検し、杭径不足が判明したら **取り替える**

## 7-11 場所打ち杭に関する留意事項③ 杭頭部

杭頭処理とは、余盛りコンクリートを杭本体から切り離す作業をいう。杭頭鉄筋は杭と上部構造物を結ぶ部分であり、ここで鉄筋を損傷させると鉄筋圧接等で補修することになる。

### 打止め高さの管理

基準となる地盤から **コンクリート検測レッド**（スケール）を孔内に垂直に降ろし、先端がコンクリート表面に触れた感触で天端位置を読む。この寸法で打止めを管理する。

### 杭頭処理の手順

1. 計画天端の **約10cm上方** をコンクリートカッターで縁切りする
2. セリヤを併用して杭本体と余盛り部を切り離す
3. 縁切りした余盛りコンクリートを吊り上げて撤去する

**打設前の一手** — 杭頭鉄筋に発泡スチロール製の鉄筋カバーを取り付け、余盛りコンクリートと鉄筋が直接接触しないようにしておくと、撤去時の吊り上げが円滑に進む。

### 余盛りコンクリートは何のためにあるか

余盛りは「捨てる部分」ではあるが、2つの役割を持つ。

- 孔内水の不純物を杭体上部から追い出し、杭本体側の品質を確保する
- 撤去作業時のバックホウのバケット当りから杭頭鉄筋を守る

余盛りが少ないまま構造物撤去を行うと、露出した鉄筋が損傷・変形する。

## 7-12 支持力の確認方法

杭の種類によって支持力の確認方法は異なるが、**どの杭でも確認は必須**である。設計値と土質データだけでは、その1本が支持力を持っている証明にならない。

| 確認方法 | 主な適用 | 何を見るか |
|---|---|---|
| 支持層のサンプリング目視 | 場所打ち杭・既製杭 | 杭底掘削時の土質サンプルを事前ボーリングデータと照合。相違がないこと |
| 支持層の直接確認 | 深礎工法 | 杭底まで降りて岩盤をシュミットハンマー等で打撃し、強度を確認 |
| 掘削機械の抵抗値 | プレボーリング・中掘り等 | **積分電流値（電流値）** や回転抵抗（トルク値）の変化 |
| 動的支持力確認 | 打込み杭工法 | 貫入量・打撃回数・**リバウンド量** から1本ごとに評価 |
| 載荷試験 | 全般 | 実荷重に耐えるかを試験で確認 |

深礎工法では支持層だけでなく、**各層の厚さと土質**も併せて確認する。

### 載荷試験の分類

| | 静的載荷試験 | 動的載荷試験 |
|---|---|---|
| 考え方 | 実際の荷重条件で載荷する | 杭頭に動的な荷重を作用させる |
| 信頼性 | 高い | 静的試験より簡便 |
| 設備 | **反力杭や載荷架台が必要**。費用と工期がかかる | 大掛かりな反力体が不要 |
| 種類 | 押込み・水平・引抜き・先端載荷試験 | 急速載荷試験・衝撃載荷試験 |
