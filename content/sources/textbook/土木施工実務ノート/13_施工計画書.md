# §13 施工計画書（Construction Plan）

## この章の要旨

- 全く同一の工事は存在しないのと同様に、施工計画書も完全に同じものは存在しない
- 工事の重要なポイントを取り込み、実現可能な管理方法や対策を記載
- 施工計画書がなければ正確な予算書を作成できない。そもそも工事に着手できない
- 施工計画書は独自性を持つべきである。引用は良いがコピー＆ペーストは禁じ手
- 工事完了後の施工データは宝の山。フィードバックが現場力の向上につながる

---

## 13-1 施工計画書・作成の基本

建設工事では類似の工事は存在しても、**全く同一の工事は存在しない。** したがって、施工計画書も完全に同じものはなく、それぞれの工事に応じて作成する必要がある。

### 作成要領

- 発注者が様式を指定している場合は必ずその様式を使用する。指定がない場合はウェブサイト上に掲載されている様式を参考にする
- 表計算ソフトや工事書類作成ツール、施工管理専用のアプリケーションを活用することで効率的に作成できる
- **ポイントは、現場の状況を正確に反映させること**
- 実現可能な計画を作成するためには、単に現場を確認するだけでなく、実際の施工をシミュレーションし、現場および周辺環境を十分に把握したうえで計画に反映させる
- 施工計画書の記載内容には履行義務が伴うため、**実現不可能な計画は記載しない**

### 記載内容

- 現場の状況を正確に反映した**［工事概要］［現場組織表］**の記載が重要
- 中核となるのは**［計画工程表］**と**［施工管理計画］**である
- これらを確定しなければ住民への説明や予算の作成、労働基準監督署への届出、地下埋設物の協議を開始できない
- 計画工程表は、準備期間・後片付け期間を考慮した現実的な計画とし、形式はバーチャート、ガントチャート、ネットワーク式などの現場規模や複雑さに応じて選択する（→10-5参照）
- 施工管理は、現場調査の結果や工事特有の条件、留意事項を反映させれば有効的な文書となる。**文書の記述のみでは十分ではなく、内容の充実を図る**

### 施工計画書 記載内容・留意事項一覧

| 項目 | 記載内容・留意事項 |
|---|---|
| 工事概要 | 工種の一覧を記載 |
| 計画工程表 | 準備期間・後片付け期間を十分に考慮する（施工計画書の中核） |
| 現場組織表 | 誰がどのような役割を果たすのかを明確に記載 |
| 指定機械・資材 | 仕様書で指定された機械や資材があれば記載 |
| 主要機械 | 使用する機械名、規格、台数 |
| 主要資材 | 工事に関する会社名・メーカー、数量一覧 |
| 施工方針・方法 | 品質・出来形管理、施工方法の詳細・方針、施工フロー（施工計画書の中核） |
| 施工管理計画 | 労災事故や施工トラブル防止計画、安全衛生体制や責任者名を記載 |
| 安全衛生管理 | 緊急時の体制および対応、連絡体制、医療機関の連絡先 |
| 緊急時の対応 | 現場周辺の交通規制や標識等の管理計画、交通誘導員等の配置位置 |
| 交通管理 | 騒音・振動対策、廃棄物の適正処理 |
| 環境対策（副産物の適正処理方法） | 工事現場や現場事務所からの環境整備 |
| 現場作業環境の整備 | 必要に応じて記載 |
| 応急対策 | 建設工事計画書、特定建設業実施届出書 |
| 届出・手続き | 必要に応じて記載 |
| その他 | 必要に応じて記載 |

## 13-2 施工計画書・作成ポイント

建設工事には大小さまざまな課題が存在する。技術・安全・工程・近隣対応など多岐にわたる。**施工計画書は、これらの課題を解決するための重要な文書である。**

### 作成の視点

- **施工計画書の策定はまず現地を視察し、工事全体のイメージを頭の中でシミュレーションしたうえで、課題に対策を整理することから始まる**
- **社内にも理解できるように明瞭でわかりやすい文章で作成する。** 内容や重要事項を協力会社と共有することが求められる
- 施工計画書の作成は目的ではない。**工事内容が多くの関係者に共有されることにある**
- 理解不足や認識の相違が生じると、**作業の効率低下や修正が必要になることや、解釈による個人差が予期せぬトラブルを招くことになる**

### 作成のポイント

- **効率的かつ安全施工のため、図や写真を用いてイメージを具体化する。簡単なイラストでも、直感的にわかりやすいことがポイントである**
- 分かりやすい記述とは、**いつ（When）、どこで（Where）、誰が（Who）、どのように（How）が明確に記述されていることを指す**
- 特に「誰が」が明確でない場合、計画が実行されない可能性が高くなる。また「原則」「・・・を行う」といった抽象的な表現は避ける

### 施工計画書の活用

- 当該工事の重要なポイントは何か、工程の管理は何か、高難度な施工の実施か、あるいは近隣対策の徹底か。これらについて自分なりに考察する
- 考えを 13-1 表1の**［施工方針・方法］**に反映させる
- **最も重要と考える課題を選定し、具体的な問題を特定する**

### 課題への対応

- 現場で選定される問題を特定した課題は、解決に向けて実現可能な計画を作成する
- **費用を投じることが必ず効果につながるわけではない。費用対効果を検討する**
- 社内の経験者や上司に相談し、同意を得られた内容を施工計画書に反映し、協力会社と協議して作業手順書に落とし込む
- 施工中は毎日現地を確認。**立案した対策を関係者と協議しその効果を確認するとともに、必要に応じて修正する**
- 不具合が発生した場合には関係者と協議し、**速やかにその旨を報告し、追加の計画書を作成する**
- 課題解決には**別途、提出する。その際は「別途、提出する」旨を発注者に提出し承認を得る**ことが望ましい

## 13-3 施工計画書・作成時の禁じ手

施工計画書は、工事の特性に応じた**独自性**を備えていることが求められる。示方書に基づいて記述する場合でも、自らの理解をもとに自分の言葉で具体的に感じられないことが多いが、**こうした努力の積み重ねは必ず現場力の向上につながる。**

### 作成時の禁じ手

| 禁じ手 | 内容 |
|---|---|
| **安易な引用・丸写し** | 「コンクリートの打込み時、適切な放水やいなど処理を行わなければならない」といった記述を見かけることがあるが、これはコンクリート標準示方書の引用であり、現場で実際に何を行うのかが不明確である |
| **過去資料の切り貼り** | 施工位置や工法の相違、数量変更などは新たに作成する必要がある。過去の類似工事の施工計画書から部分をコピーして編集するといった、**一貫性を欠いたものになる** |
| **標準仕様の丸写し** | 当該工事は、示方書や仕様書に記載された標準的な施工方法を写すものであり、ただコピーするだけでは有用性が低いものになる（**コピー＆ペーストは禁忌**） |

### 望ましい姿勢

- 施工計画書は、示方書や仕様書を理解したうえで自分の考えを記述したうえで、自分の言葉で近道である
- 画を現場で確実に実行することの記述式では、具体的な対応や処理方法が不明確である。**それだけでは何を指すのかを自ら考え、その内容を明確にし、適切な処理とは具体的に何を指すのかを自ら考え、その内容を記述する**
- これらを繰り返し実践することで、**施工計画書は単なる形式的な文書ではなく、現場を動かす実効的な指針となり、最終的な現場力の強化につながる**

## 13-4 工事完了後のフィードバック

工事が完了した後に残る施工データは、**まさに宝の山**である。工事着手前に苦労して立案した計画が実際にどのように実現されたのか、計画が十分であったのか、不足していたのか、そのデータを見直すことが重要である。**満足できたのかも不足していた点を明確にして、確実にフィードバックすることが、その後の大きな価値につながる。**

### 計画と実際

- **建設目的物は施工過程で気象条件や周囲の環境の影響を受けやすい。苦労して作成した施工計画は、計画書は単なる紙の成果に過ぎなくなってしまう**
- 品質管理を伴って、条件の違いによる品質にばらつきが生じる原因になる
- **作業員の技術レベルによる影響** — 品質管理をむずかしくしているもう一つの要因である。建設現場は労働集約型の作業が主体であり、作業員は製造業の工場作業員と比べて入れ替わりが多い
- そのため、必要な知識や技術レベルは当初にならないように分かりやすい。**このようなばらつきを完全に排除することは難しい。しかし、施工計画書に基づいて作業を進めれば、一定の品質を保持し、安全確保を実現できる**

### フィードバック

| 観点 | 内容 |
|---|---|
| **検証の重要性** | 工事完了時の結果を評価するだけでは不十分である。**苦労して作成した施工計画の妥当性や不足、問題点を検証しなければ、計画書は単なる紙の成果に過ぎなくなってしまう** |
| **現場力の向上** | 課題や解決策を自ら考え実行し、完成後に「何が不足していたのか」を検証することで、**自身の現場力の向上につながる** |
| **成果の共有** | 得られた知見や結果は社内や後輩、協力会社と共有することで次の工事に活かせる。**これらは会社の資産となり、将来の強みとなる** |
| **時間の意識** | 「忙しいからフィードバックするのは無理」という声もあるかもしれない。しかし、**人に平等に与えられた唯一の資源は "時間" である。**「忙しい」と言い訳をしていては、せっかく与えられた時間を無駄にしてしまうことになる |
