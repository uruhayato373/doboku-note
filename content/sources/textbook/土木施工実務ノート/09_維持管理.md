# §9 維持管理（Maintenance）

## この章の要旨

- 2014年に施行された道路法により、近接目視を基本とする全数点検が5年に1度、実施されることになった
- アセットマネジメントに基づく維持管理システムを導入し、性能評価による効率的な更新事業を実施する
- 「補修」と「補強」は類似した言葉だが、その定義と目的の違いを正しく理解しておく必要がある
- 過去の構造物の劣化に関する知識と弱点を学び、新設構造物の施工では長寿命化を目指す
- 更新費用が増加するなか、新設構造物の施工では長寿命化を目標とする

---

## 9-1 事後保全と予防保全

道路法改正以前は、適切に維持管理する情報や計画が存在せず、トラブルが発生した後に対処する**事後保全**方式によって管理されていた。これを、未然に対処する**予防保全**へ転換することが図られている。

| | 事後保全 | 予防保全 |
|---|---|---|
| タイミング | 損傷が発生してから対処 | 損傷が軽微なうちに対処 |
| 対応規模 | 大規模な修繕（床版の打ち替えなど） | 軽微な修繕（ひび割れの補修、塗装の塗り替えなど） |
| 健全性 | 事後保全は健全性が低下しやすい傾向 | 状態を一定の管理水準に保てる |

### 経済性の比較

- 事後保全はその都度の対応が多く、結果として維持管理コストの増大を招きやすい
- **予防保全は事後保全と比較して、トータルコストの約3割の削減が可能**とされている
- ライフサイクルコスト（LCC）の縮減とストック効果の最大化を目的とする

▶ 図参照：事後保全と予防保全のサイクル／トータルコスト比較（原本 p.198-199）

## 9-2 アセットマネジメント（AM）

インフラの維持管理では、撤去なども痛みを伴う判断となる。インフラの性能を維持・向上させ、社会インフラの信頼を回復させることを目的とし、**社会資本を「資産」として捉え、インフラの持続的な活用を図る**。

### AMとは

- 限られた財政の中で計画に基づいて効果的・効率的に社会資本の維持・更新を行う経営手法
- 具体的には、現有の社会資本の状況を調査・把握し、残存余命や将来需要を見極えた計画のもとで、予防的な維持管理や更新事業を実施する
- 新設工事は仕様規定に基づく施工であるのに対し、維持管理は**性能評価に基づく効率的な更新事業**が求められる
- 点検業務では専門技術者や研究者の育成、確保することが難しいため、地方自治体では日常的に把握できる技術者が必要となる

### 手法としての民間活用

| 方式 | 内容 |
|---|---|
| PFI事業 | 建設から運営・維持管理まで民間に委託 |
| PPP事業 | 一定地域内の道路点検・補修を一定期間民間に委託 |

さらに、公共施設の維持管理を市民や企業が支援する**アダプト制度**の活用も有効である。市民や企業が公共的な場所をいわば養子にするような形でボランティア活動を行う仕組み。現場を常に見守り、より効果的な維持管理が可能となる。

### 痛みを伴う政策も必要

- 撤去を伴う場合は、地元住民の理解を得ることが難しい場合がある。**撤去の必要性を丁寧に説明する**ことが重要
- **コンパクトシティ構想** — 住まい・交通・公共サービス・商業施設などの生活拠点をコンパクトに集約し、地域を再編成する
- 少子高齢化が進行するなか、限界集落（地域人口の50%以上が65歳以上の集落）は全国各地に存在する。そのような地方の活性化、道路の維持管理費に投資するための予算には限界がある

## 9-3 建設目的物の品質向上の必要性

我が国の社会インフラは、戦後の高度経済成長期に集中的に整備されたものが多い。これらのインフラは現在かなりの老朽化が進行しており、維持管理にかかる費用は年々増加の一途をたどっている。

### 維持管理費の動向

- 建設投資の総額が横ばいのまま推移していると仮定した場合、**2030年代には維持管理や更新に必要な費用が予算を上回る可能性がある**
- このような背景から、新たな建設事業に従事する技術者には、長寿命化を考慮した施工が求められている

### 新設工事施工者の留意事項

- 現在、新設されたインフラは、供用開始から2年以内に初回の定期点検を実施し、その後は5年ごとに点検が行われる
- **2年以内に初期損傷が発見された場合は、当然、更新にかかる費用が発生してしまう**
- 新たに建設される施設には可能な限り更新費用が発生しないよう、長寿命化を目標とした施工が求められる
- そのためには、**過去の建設物における劣化に関する弱点を学び、その知見を新たな施工に活かすことが重要である**

## 9-4 コンクリートの劣化診断

施工に従事する技術者にとって、コンクリートの劣化診断の技術は必ずしも身近なものではない。しかし今後の新設工事においても、劣化診断に関する知識を身につけておくことが求められる。

### インフラの長寿命化のために

- コンクリート診断とは、コンクリートがどのように施工され、その後どのように劣化したのかを評価する技術である
- 診断技術の核心は、コンクリートの劣化に関する多様な情報を読み取ることにある
- このような情報を正しく解釈することが、**新たに施工するコンクリートの長寿命化につながる**

### 劣化診断方法

- **目視調査**や**打音検査**によって劣化の原因を推定する。ひび割れのパターンや発生箇所から推定
- **シュミットハンマー**を用いた圧縮強度の推定
- **コアの割裂面における変色**をもとにした中性化の診断
- **コンクリート内部の塩分濃度の分析**
- **専門機器による劣化の進行状況の調査**

打音検査はコンクリート点検ハンマーを用いた打撃音により、"浮き"や"剥離"の有無を確認する。

## 9-5 コンクリートのひび割れ管理

コンクリートに発生するひび割れ（クラック）は、構造物の用途に応じて許容される範囲が異なる。ひび割れが進行するかどうかを定期的に記録するため、**クラックゲージ**を用いて幅を測定する。

### ひび割れの測定

- ひび割れの状況を把握し、今後の成長の可能性を予測するためには、定期的な測定が必要である
- ひび割れが進行中に行う補修は、ひび割れの反発が続く可能性があるため、無駄になることもある
- ひび割れの始点と終点の側および中間部の幅を測定する
- 測定には超音波法や弾性波測定法が用いられるが、**まず幅の測定を優先すればよい**
- 測定間隔は1週間から1カ月程度。ひび割れの年齢が若いほど短い間隔で測定する

### ひび割れ幅の影響

**鋼材腐食の観点からのひび割れ幅の影響**（大／中／小の3段階で耐久性を評価）

| ひび割れ幅 ω（mm） | 塩害環境下 | 水掛かりあり | 水掛かりなし |
|---|---|---|---|
| 0.5 < ω | 大 | 大 | 大 |
| 0.4 < ω ≦ 0.5 | 大 | 大 | 中 |
| 0.3 < ω ≦ 0.4 | 大 | 中 | 小 |
| 0.2 < ω ≦ 0.3 | 中 | 小 | 小 |
| ω ≦ 0.2 | 小 | 小 | 小 |

（いずれも20年耐久性を前提とした評価）

**防水性・水密性の観点からのひび割れ幅の部材性能への影響**

| ひび割れ幅 ω（mm） | 常時水圧作用環境下 180未満 | 180以上 | 左記以外 |
|---|---|---|---|
| 0.20 < ω | 大 | 大 | 大 |
| 0.15 < ω ≦ 0.20 | 大 | 大 | 中 |
| 0.05 < ω ≦ 0.15 | 中 | 中 | 小 |
| ω ≦ 0.05 | 小 | 小 | 小 |

**評価の読み方**
- **大** … ひび割れによる性能低下が顕著であり、部材が要求性能を満たしていない
- **中** … ひび割れが性能低下の原因となるが、軽微（簡易）な対策により部材が要求性能を満たす
- **小** … ひび割れが性能低下の原因となっておらず、部材が要求性能を満たしている

## 9-6 劣化要因によるひび割れパターンと補修・補強方法

コンクリートのひび割れは、そのパターンによって特徴が異なるため、**目視観察から劣化要因をある程度推定できる**。

### 主な劣化要因とひび割れパターン

| 劣化要因 | ひび割れパターン | 補修・補強方法 |
|---|---|---|
| **温度ひび割れ** | 部材幅と直角方向に直線状に発生。ほぼ等間隔で規則的 | 表面塗布工法、ひび割れ注入工法、充填工法 |
| **乾燥収縮ひび割れ** | 亀甲状、開口部の周囲では放射状、外壁部や隅角部では斜め方向に発生 | 表面塗布工法、ひび割れ注入工法、充填工法 |
| **沈みひび割れ** | 水平鉄筋に沿って直線状、セパレーター直下に曲線的に発生 | 表面塗布工法、ひび割れ注入工法、充填工法 |
| **プラスチックひび割れ** | 不規則で比較的短い表面ひび割れが発生 | 表面塗布工法、ひび割れ注入工法、充填工法 |
| **初期凍害** | 表面に凍結痕、または全体が崩壊するなどの現象が発生 | 表層部をはつり除去し、セメント系ペースト等で表面被覆補修。内部まで進行している場合は断面修復工法、またはリートをやり直し |
| **凍結融解によるひび割れ** | 不規則な網目状の微細なひび割れが発生。ポップアウトやスケーリングなどの表面劣化を伴うことがある | 表面塗布工法やはつり、充填工法、ひび割れ注入工法、ひび割れ部分やコンクリート表面まで大幅な打ち替え・取り替え工法による補修 |
| **塩害** | 鉄筋に沿った直線状のひび割れ、剥離・剥落、錆汁流出が発生 | 表面被覆工法、表面含浸工法、ひび割れ注入工法、鉄筋防錆工法、断面修復工法、電気化学的補修 |
| **アルカリ骨材反応** | 不規則な亀甲状のひび割れ。ゼラチン状の物質や白色析出物が発生 | 表面被覆工法、ひび割れ注入工法、充填工法、鉄筋に腐食がある場合は補強方法として打ち替え工法 |
| **打ち継ぎ部のひび割れ** | 打ち継ぎ部に沿って直線状に発生 | 表面塗布工法、ひび割れ注入工法、充填工法 |
| **コールドジョイント** | コールドジョイント部に沿って水平状に発生 | コンクリート部材の打ち替え・取り替え |
| **中性化** | 鉄筋に沿って表面に規則的な直線状のひび割れが発生 | コンクリート部材の打ち替え・取り替え、断面修復、電気化学的補修 |
| **気泡・ジャンカ** | 空隙の多くなった構造物の不具合部が発生。豆板をともなう | 表面塗布工法、ひび割れ注入工法、充填工法 |

**中性化についてはフェノールフタレイン反応**を用いると、簡易的に判断することができる。

## 9-7 コンクリートの補修・補強の定義

「補修」と「補強」は類似した言葉だが、その定義と目的の違いを正しく理解しておく必要がある。

| | 補修 | 補強 |
|---|---|---|
| 目的 | **耐久性を回復・向上させる** | **強度を向上させる** |
| 定義 | 構造物や劣化した部材に対して、今後の劣化を抑制するための措置。劣化した構造物の周囲における剥落防止などを目的とした対策 | 構造物の部材の力学的な耐荷性や剛性などに対して、当初の性能を超えて安全性を回復・向上させる対策 |
| 範囲 | さらに、人や物に与える影響を軽減することも含まれる。供用期間中における構造物の安全性を回復させる措置も含まれる | 当初の性能を上回る強度を実現させること。当初の設計値を上回る性能を求めることも含まれる |

▶ 図参照：補修と補強の概念（原本 p.208）

## 9-8 コンクリートの漏水補修は難しい

コンクリート構造物の背面から土砂に接している場合、その漏水補修作業は水の侵入経路となるひび割れが土砂に接している。補修材料を注入し、補修工法は同様に行われる。**止水を目的とするものであるが、使用する補修材料の選定に慎重さが必要である。**

| 工法 | 内容 |
|---|---|
| **注入工法** | 構造物の埋め戻し側から水が漏れ出ている場合、コンクリート背面からの漏水が常に発生している場合は、既にひび割れ部分に水圧を受けてウレタン系の水膨張性樹脂を注入する方法を用いる。水に反応して即座に硬化するウレタン系の材料を用いて対応する |
| **背面注入工法** | 地中構造物に対応する背面注入工法。ひび割れ開口部にはポリマーセメントモルタルやゴム系。コンクリートの背面にある水を埋め戻す前に、コンクリート背面に防水層を設け、背面注入を行うために対象箇所を削り出し、高極スラグ微粒子などを充填する工法である。埋め戻し作業の前に行う必要がある |
| **表面被覆工法** | 水の侵入を防ぐために、ひび割れの開口部を樹脂系の材料を用いて被覆する |

### 難しいコンクリートの漏水補修

- ひび割れを通じて漏水しているコンクリートは、漏水箇所だけの問題ではない。**コンクリート全体が脆弱になっていると考えるべきである**
- そのため、漏水箇所を修理して止水に成功したとしても、次の脆弱部分から新たな漏水が発生する可能性が高い。**いわゆる "いたちごっこ" になることが多い**
- 最も効果的な対策は、**漏水箇所にパイプを埋設して水を抜くこと**である。排水しきれない場合は水中ポンプを使用して排水する方法が有効である

## 9-9 ボックスカルバートの目地からの漏水補修方法

目地からの漏水に対しては止水剤を用いた注入工法が用いられるが、実際の止水は非常に困難である。**目地自体が脆弱な部分であるため、他の脆弱な箇所から新たに漏水が発生する可能性が高い。**

### 止水剤の注入

1. 漏水箇所にコンクリートドリルを用いて注入孔を設け、注入ホースを取り付けて固定し、漏水をホース一本に導いて排水する
2. 周囲からの漏水が停止したことを確認した後、周辺を結晶止水剤でコーキングする
3. 最後に、ホース一本に止水剤（ウレタン系、アクリル系、セメント系など）を注入する
4. 止水剤が固化し、漏水が停止したことを確認した後、ホースまたはバルブとコーキング材を撤去し、表面仕上げを行う

### 導水工法

目地から漏水が発生した場合、止水剤を注入しても完全な止水は困難である（→9-8参照）。

- ボックスカルバート内に排水経路を設けて導水パイプを埋設し、カルバート内の水路へ排水することも有効な対策となる

### 躯体外での排水処理

- 目地からの漏水が予想される場合、**土砂の埋め戻し作業の前に躯体外周辺に透水シートを取り付け、排水処理を行う**
- 使用する透水シートは、土砂の流出を防ぐ機能を持つ製品を選定する
