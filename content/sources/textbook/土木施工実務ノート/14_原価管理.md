# §14 原価管理（Cost）

## この章の要旨

- 現場における原価管理は、単なる原価計算を超えた広範なマネジメント能力が必要
- 工期短縮によるコスト削減は、新たなコストの発生とトレードオフの関係
- 協力会社に対する指し値や値引きの強要は、信頼関係を悪化させる
- 原価管理が難しい理由は、設計変更が頻繁に発生し、原価の確定が遅れること
- 受注者の利益向上の基本は、現場での創意工夫によるコスト削減

---

## 14-1 建設現場の利益の区別

**キーワード：理想は工事原価90%以下／一般管理費3%程度の利益／粗利益5%程度が収益分岐点**

### 請負工事費の構成（一般土木工事）

```
請負工事額 110%
├─ 工事価格 100%
│   ├─ 工事原価 90%
│   │   ├─ 直接工事費 約60%  ← 歩掛（労務単価・材料単価・機械経費）
│   │   └─ 間接工事費 約30%
│   │       ├─ 共通仮設費 約10%   ［直接工事費 × 経費率］＋［積上げによる計上］
│   │       └─ 現場管理費 約20%   ［（直接工事費＋共通仮設費）× 経費率］
│   └─ 一般管理費 約10%
└─ 消費税相当額 10%
```

**費目の定義**

| 費目 | 内容 |
|---|---|
| 一般管理費 | 会社の本支店での必要経費。試験研究費など |
| 直接工事費 | 目的物の施工に直接必要となる費用 |
| 共通仮設費 | 施工するために間接的に必要となる各工事共通の費用 |
| 現場管理費 | その現場を管理するために必要な費用 |

### 審査が考える必要な金額の目安

```
請負工事額 110%
├─ 工事価格 100%
│   ├─ 工事原価 約92%
│   │   ├─ 直接工事費 約67%
│   │   └─ 間接工事費 約25%
│   │       ├─ 共通仮設費 約6%
│   │       └─ 現場管理費 約19%
│   └─ 一般管理費 約8%（利益込み）
└─ 消費税相当額 10%
```

### 受注金額を100%としたときの判定

| 状況 | 意味 |
|---|---|
| 直接工事費が **67%以上** | 工事費を確保できていない赤字工事 |
| 間接工事費が **25%以上** | 共通仮設費・現場管理費のいずれか、あるいは両方が不足している赤字工事 |
| 工事原価が **92%以上** | 直接工事費か間接工事費、またはその両方が確保できていない状況 |
| 工事原価が **100%以上** | 営業利益が見込めず、**企業の存続に直結する問題** |

現場管理費は主に作業所所属職員の給料に相当するため、工事原価が92%を上回ると、**職員数が標準を上回っている可能性がある。**

### 一般管理費の位置づけと収益分岐点

- 一般管理費は本社経費、人件費などを指す。**固定費であるため、これを確保できない工事は営業利益が見込めず赤字となる**
- ここでいう一般管理費には、おおよそ**3%程度の利益**が含まれている
- したがって工事価格の95%（工事原価92% + 利益3%）以上が工事原価となる
- **収益分岐点は、現場の粗利益5%程度（一般管理費相当額）**

## 14-2 コストダウンのための創意工夫

**キーワード：創意工夫・脳内発汗／歩掛り（作業効率）の改善／実行予算と実績の比較**

### （1）着手前（施工計画段階）

- 過去の経験や知識を最大限に活用し、創意工夫を徹底する。**単に従来の方法を踏襲するのではなく、より良い方法を追求することが求められる**
- 任意仮設を複数比較検討し、施工性・安全性・経済性の観点から最も合理的な方法を選定する
- **社内他現場だけでなく、協力会社の意見も広く取り入れる**。理想論に固執せず、実現可能な工夫を重ねることが高い成果をもたらす

### （2）施工段階

- 元請と協力会社の間でコスト・納期・品質などをめぐって利害が対立することもある。しかし、**持続的なパートナーシップを築くためには元請企業の協力なしでは成立しない**
- ここでいう**「生産性向上」とは、いわゆる歩掛りの改善を意味する**
- 1人当たりの1日の作業量を増やすことで完成させる。このため、単価の引き下げが難しい場合、（単価 × 数量 = 歩掛り）で改善する
- コスト縮減は一般的に、常に歩掛りを把握し、**実行予算との実績を早期に比較して定期的に行うことでPDCAサイクルを回す**
（計画 Plan → 実行 Do → 評価 Check → 改善 Action）

### （3）工事完了後の分析

工事完了後には、**実行予算と実績の対比を行い、詳細に分析する。この作業は単なる集計ではない。**

### （4）原価分析結果による次回への反映

- 実行予算と実績の比較により差異が発生した場合、その理由を明確にしなければならない
- 同様に**次回の現場でも繰り返してしまう**。したがって、この改善策の分析結果を次の予算策定と施工計画に反映することができなければならない
- 例えば、土砂運搬費が想定より高騰した原因が、運搬ルートの混雑や待機時間の増加であった場合、次回は「ダンプトラックの台数」を検討する
- また資材費が上昇した場合には、**代替資材の検討や早期発注によるコスト抑制などの戦略的な判断が必要となる**

### （5）技術者にとっての学びと現場力向上

- 差異の分析は、単なる経理的な改善ではない。むしろ、**技術者の成長と現場のコスト管理能力を高める学習プロセスである**
- 例えば、コンクリート打込み手順の標準化を行うと、次回は「事前段取りが "現場のリズム" を作った」と経験した技術者は、**同種の現場でコストを高める判断を蓄積した経験値であり、企業の技術資産となる**
- **結果として、企業が独自の価値を高めることが企業競争力の向上に直結する**

### 理念と実践の一体化

- 持続的な成長と収益の向上は企業力の増加につながる。**理念を根拠に計画を立案し、行動に移して初めて意味を持つ**
- **データを根拠に計画を立て、改善を重ねる。このサイクルこそが、長く高い収益力を支える企業の体質といえる**

## 14-3 コストダウンに関する考察

**キーワード：工期短縮は両刃の剣／値切りや指し値はコスト削減ではない／協力会社と信頼関係を強化**

### （1）工期短縮はリスクを伴う

- 工期短縮は現場管理費や共通仮設費の削減につながる一方で、**その実現には新たなコストの発生というリスクを伴う。いわゆるトレードオフの関係である**
- 例えば「工事の短縮による削減効果」と「それに伴う追加コスト」を総合的に比較・評価し、**経済的な合理性を確保することが重要である**
- 一方でトンネル掘削工事において、工期短縮による削減効果と、短時間機の損料増加との費用比較が必要になる

### （2）協力会社に対する値切り・指し値は禁物

- コストダウンを**「協力会社との契約金額を引き下げる行為」と誤解する担当者は少なくない**
- 値切りや指し値は、実質的に協力会社にコスト削減を一方的に強いるものである。**建設業法に抵触する可能性もある**
- 協力会社が契約金額に不満を抱いた場合、品質および安全性の低下を招く可能性が高く、さらに工事の遅延にもつながりかねない
- 一方で「契約金額の固定化されているのに」との意見も散見される。**元請にも利益がかかわらない**
- **しかし生産性向上による利益は、協力会社のみに帰属し、元請企業には長期的に波及し、協力会社との信頼関係の強化につながる**
- 特に深刻化する建設業の人手不足を背景に、**元請企業は協力会社から選ばれる存在となる必要がある**
- この観点からも、**短期的な値下げ交渉に終始するのではなく、相互利益を追求する関係構築を重視すべきである**

### （3）発注者へのVE提案リスク

- **VE（Value Engineering）提案**は、コスト削減を実現するうえで有効な手法である。しかし、我が国の公共工事においてはその適用が困難となる事例が少なくない
- 背景には、**発注者が常に会計検査を意識しなければならない状況が影響している**
- 例えば、開削工法を推進工法に変更する場合、工事費の減額を伴う事例も報告されている
- 発注者がVE提案を受け入れた結果として、**工事費の減額を余儀なくされる可能性がある**
- **発注者は契約金額を減らさなければ、発注時点における設計の妥当性を会計検査院に対して説明することが困難となる**

## 14-4 原価管理の手順

**キーワード：信頼できる協力会社を選定／毎月の繰り返しによる管理／予算の見直し**

### （1）予算書の作成から発注・契約まで

- 本支店の予算策定部署が作成した入札時の**入札内訳書（案A）**を基礎とし、現場担当者は入札時の施工条件と実際の施工条件との乖離により、**内容により近い内訳書の予算書（案B）**を作成する
- 入札から受注までには、工事に関する情報量は大きく異なる。そのため、入札時の**入札内訳書は「正しいもの」として扱うことが誤る**可能性が高まる
- 予算書の見積もりを誤ることに基づいて、社内発注部署と協議し、信頼できる協力会社を選定して**最終予算を決定する**
- **ここでのポイントは「信頼できる協力会社の選定」であり、"信頼" とは単にコストを下げられることではなく、品質・安全性を総合的に評価した工事である**
- 最終決定した予算書をもとに、協力会社への発注・契約を行う。特別な場合を除き、**協力会社との発注・契約は工事着手前に行うことが、精度の高い原価管理につながる**

### （2）出来高管理・原価管理

- 工事現場は日々変化するため、着工前に作成した予算書だけで完成までの原価を正確に把握できる現場は、ほとんど存在しないといっても過言ではない
- **精度の高い原価管理には、毎月の繰り返しによる管理が欠かせない**
- そのうえで、場合によっては**予算の見直し**も必要となる

### （3）決算

- 建設企業の収益は、各工事現場における最終的な原価予測、すなわち決算に基づく数値に大きく左右される
- したがって、最終原価を正確に見積もるためには**設計変更、労災保険料請負金、その他の費用変動要因を的確に把握し、予測することが不可欠である**
- 設計変更には以下の場合が含まれる
  - 工事の追加および削減
  - 数量の変更
- これらの要素を考慮したうえで、**原価管理を継続的に的確に実施することが、企業の収益確保に直結する**

## 14-5 原価管理のコツ

**キーワード：ルーチンワークとして最終利益予測／コストダウンの工夫／ひとりで悩まない**

### 原価管理はルーチンワーク

- 建設現場における原価管理は、多くの不確定要素が絡み、設計変更も頻繁に発生するため、**予測は困難とされている**
- 毎月のルーチンワークとして最終利益予測を行うことで、**不確定要素は次第に確定要素へと変化し、予測の変動幅は縮小して最終的な利益額に収束していく**
- 例：4月時点では利益率が0〜12.0%と幅があったものの、翌年3月には11.0%に収束する
- **最終的な利益率がほぼ "ゼロ" となることではなく、変動幅が最も小さくなる。収支が報告よりも多い場合は "粉飾決算" と受け取られるおそれがある。正確な収支を認識する**
- 毎月のルーチンワークとして繰り返し原価を予測することで、**発注漏れを防ぎ、予測精度も高まる**
- **原価管理の基本は、コスト上昇の抑制とコストダウンの工夫の決め手となる**

### 予定の利益が守れない場合

- 予算書と実行予算を常に比較し、**守れない項目は早期に是正を図る。必要に応じて本支店の協力を仰ぐ**
- **ひとりで抱え込んで悩んでいても解決には至らない。早期に対応と組織的なサポートが重要である**
