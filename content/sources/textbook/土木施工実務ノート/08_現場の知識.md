# §8 現場の知識（Know-how）

## この章の要旨

- 舗装・道路・河川・砂防など、工種ごとに固有の管理値と時期の制約がある。工種を跨いだ現場では、それぞれの前提を取り違えない
- 土質・地盤改良は「何を改良するのか」を先に決める。深度と目的で工法が決まり、逆順では選べない
- 揚重・打込みなど機械が主役の作業は、定格荷重と作業半径、適用地盤の上限が判断の起点になる
- 品質は記録できて初めて品質になる。仕上がりで隠れる部分ほど、記録の取り方を施工方法そのものに組み込む
- 管理図・写真管理・BCP は、いずれも「異常を早く見つけて戻す」ための仕組み。合否判定の道具と混同しない

## 8-1 舗装工事におけるアスファルトの施工管理

アスファルト舗装の管理は **合材の温度** と **転圧機械の選定** に集約される。合材が冷めてから締め固めても密度は上がらない。

### 層の構成と役割

| 層 | 役割 |
|---|---|
| 表層 | 走行面。荷重の分散と排水機能を担う |
| 基層 | 路盤の不陸を補正し、荷重を表層へ均等に伝える |
| 路盤 | 表層・基層からの荷重をさらに分散して路床へ伝える。上下2層構成が多い |
| 路床 | 舗装の支持地盤。路盤下の約 **1m** の土の層 |
| 路体 | 路床の下の盛土部分 |

### 種類別の厚さの目安

| | 表層＋基層 | 路盤 |
|---|---|---|
| 一般道路 | **15〜20cm程度** | **20cm程度** |
| 簡易舗装（駐車場等） | 表層のみ **3〜4cm程度** | **15cm程度** |
| 歩道 | 表層 **3〜4cm程度** | **10cm程度** |

交通量や地盤条件によってはさらに厚くする。歩道の路盤厚は自転車・車椅子の荷重を考慮した値。

▶ 図：[舗装の層構成と厚さの目安](figures/08-01_舗装の断面構成.svg)

### 転圧機械の使い分け

| 機械 | 用途 | 特徴 |
|---|---|---|
| ロードローラ | 初期転圧 | 三輪構造で地盤を締め固める。自重 **6〜16t程度** |
| タイヤローラ | 二次転圧 | ゴムタイヤ。散水装置付きが多い |

タイヤへの合材付着を防ぐため散水するが、散水過多は温度低下を招く。

### 打ち継ぎ目

継ぎ目は舗装の仕上がりを左右するので、**できる限り少なくなるよう計画する。**

- **横継ぎ目**：1日の施工を終了した位置の継ぎ目。段差が生じないよう所定の高さ・形状に仕上げる
- **縦継ぎ目**：複数車線を分割施工する場合の、道路線形に平行な継ぎ目。ひび割れが生じやすいため **車両走行位置に設けない**（車線境界に合わせる）のが原則。上層の継ぎ目を下層の継ぎ目の直上に重ねない
- **ホットジョイント**：複数の舗装機械で同時施工する場合、継ぎ目部を **5〜10cm程度** 転圧せずに残し、隣接合材を敷いた後に一緒に締め固めて一体化を図る

## 8-2 多様な特殊舗装

アスファルトが主流だが、ヒートアイランド緩和・すべり防止・景観など、目的に応じた工法が開発されている。

| 舗装 | 何を狙うか | 押さえどころ |
|---|---|---|
| コンクリート舗装 | 明るさ・耐久性 | 白色系で照明効率が高くトンネル内に多い。補修頻度が少なくライフサイクルコストが低い |
| 遮熱性舗装 | 温度上昇の抑制 | 遮熱塗料を表面に塗布し赤外線を反射する |
| 保水性舗装 | 温度上昇の抑制 | 開粒度アスファルトの空隙に保水材（セメントミルク系）を注入。水分の気化熱で路面温度を下げる |
| カラー舗装 | 視認性 | 混合物に顔料を加える。一般舗装と同等の耐久性。スクールゾーン等 |
| インターロッキングブロック舗装 | 荷重分散・景観 | ブロック同士が組み合う形状。色・素材が豊富で歩道向き |
| ウッドチップ舗装 | クッション性 | 間伐材・剪定材のチップを再利用。散策路・遊歩道 |
| ゴムチップ弾性舗装 | 安全性 | 歩道用の現場施工型。**スパイク靴で傷む** |
| 樹脂系すべり止め舗装 | 摩擦抵抗 | 樹脂を薄く塗布し耐摩耗骨材を散布。交差点手前など |

遮熱性は「反射して熱を持たせない」、保水性は「水を蒸発させて奪う」。同じ温度対策でも原理が違うので、日射条件や降雨頻度で向き不向きが出る。

## 8-3 舗装工事における路盤の施工管理

路盤は表層を支持し、交通荷重を分散して路床へ伝える層。所定の密度が出るまで転圧できているかが品質のすべて。

| | 厚さ | 材料 |
|---|---|---|
| 下層路盤 | **10〜20cm程度** | クラッシャラン（安価で扱いやすい） |
| 上層路盤 | **5〜20cm程度** | 粒度調整砕石。セメント・石灰による安定処理材を用いることもある |

上層ほど支持力の高い材料を使う。表層に近いほど輪荷重が集中するためである。

### 施工機械

| 工程 | 機械 |
|---|---|
| 粗い敷均し | ブルドーザ |
| 仕上げ敷均し | モーターグレーダ |
| 締固め | ロードローラ **10〜12t級**／タイヤローラ **8〜20t級** |

### プライムコートとタックコート

| | 散布位置 | 役割 |
|---|---|---|
| プライムコート | 路盤を仕上げた直後、路盤とアスファルト層の間 | 路盤と舗装層の接着強化、防水性の向上、雨水浸透の防止 |
| タックコート | アスファルト層間（主に基層と表層の間） | 層間の接着。オーバーレイ（舗装修繕）施工時にも使用し一体性を確保 |

路盤を仕上げたら **速やかに** プライムコートを散布する。放置すると路盤表面が乱れる。

## 8-4 舗装工事における路床の施工管理

路床は舗装構成材と交通荷重を安定的に支持する層。盛土なら仕上がり面から、切土なら掘削面から、**それぞれ約1m下の範囲**がこれに該当する。

### 材料と構築路床

- 使用材料は主に砂・砂利。購入土であれば新材を用いる
- **CBR（路床土支持力比）が3未満** の軟弱地盤は、地下水の変動などで路床が崩れるリスクが高い。均一な支持力を確保するため整備するものを **構築路床** という
- 構築路床の施工は **置換工法・安定処理工法・盛土工法** のうち現場条件に合うものを選定する

### 敷均しと締固め

- モーターグレーダやブルドーザで1層ずつ均一に敷均し、ロードローラ・タイヤローラで転圧する
- 敷均し厚は **1層当たり20cm以下** とし、各層ごとに所定の密度に締め固める

### 品質管理

路床の支持力は **CBR試験** で判定する。盛土路床の場合は、施工に使用する材料を試料として試験を行う。

## 8-5 舗装時の重機によるコンクリート欠損防止策

現場打ち側溝に接する舗装端部を転圧する際、**転圧機械の鉄輪が側溝コンクリートの天端に接触して欠損する**ことがある。

- タンデムローラ・マカダムローラ等で路床・路盤・表層を転圧する際、L型側溝のエプロン部や現場打ち側溝の天端に鉄輪が当たる
- 欠損が生じると外観上も好ましくなく、補修の手間が発生する

### 防ぎ方

型枠設置時に **薄ベニヤをコンクリート天端に貼り付けておく**。ベニヤ板の厚さ分だけ天端が低くなり、鉄輪が直接接触しない。撤去も容易。

## 8-6 舗装工事中の仮排水方法

排水側溝が完成し舗装工事に入った段階では、側溝はまだ排水機能を持っていないことがある。この時点で降雨があると **路床が軟弱化し、路床の交換や地盤改良が必要になる。**

### 舗装中の仮排水

- 集水は **1カ所にまとめて排水する**のが望ましい。可能であれば自然排水で成立するよう計画する。水中ポンプに頼らなくて済むほうがよい
- 側溝の壁面に **仮水抜きパイプ** を埋設し、路盤側からの水を側溝へ逃がす
- パイプと路盤材の間に **吸出し防止材（不織布など）** を挟み、路盤材の流出を防ぐ
- 舗装完了後は、パイプの穴を閉塞するか、特に問題がなければ **排水孔としてそのまま機能させる**

**なぜ後から仮排水を追加するのは難しいか** — 側溝完成後に壁面を貫通させる工事は手戻りになる。舗装工程に入る前の計画段階で埋設しておくかどうかが分かれ目である。

## 8-7 道路の用語

道路は交通機能に加え、環境空間・防災空間としての役割と、地下の電線・水道・電話線などライフラインを収容する役割を持つ。用語を正確に理解しないと、道路管理者や警察との協議で話が噛み合わない。

### 車道・歩道・路側帯・路肩

| 用語 | 定義 |
|---|---|
| 車道 | 自動車・バイク・路面電車が通行する部分。左側通行で車道の端を走ることと定められている |
| 歩道 | 車道と分離して設置され、歩行者が通行する部分 |
| 路側帯 | **歩道が設置されていない**道路（または歩道のない側）の端に設けられた帯状部分。道路標示で区画される |
| 路肩 | 道路の主要構造部を保護し車道の機能を維持するため、車道・歩道・自転車道に接続して設けられる帯状部分（道路構造令 第2条12号） |

**歩道がある場合、同じ場所が道路構造令では「路肩」、道路交通法では「車道」に区分される。** 車道の幅の解釈が変わるため、規制や協議で注意が要る。

### 歩道の3形式

| 形式 | 特徴 |
|---|---|
| マウントアップ型 | 車道より一段高い。交差点や車両進入部で斜路が形成される |
| フラット型 | 車道とほぼ同じ高さ。縁石で分離 |
| セミフラット型 | やや高く設置。今後の主流と目される |

マウントアップ型はバスの乗降に支障を来すため減少しつつある。

▶ 図：[道路横断面の用語と歩道の3形式](figures/08-07_道路横断面の用語.svg)

## 8-8 車両用防護柵の種類と特長

車両用防護柵は、走行中の車両の路外逸脱・転落や対向車線への飛び出しを防ぐとともに、乗員と周囲の第三者への被害を軽減する。

| 種類 | 特徴 |
|---|---|
| ガードレール | 剛性と靭性を備えた波形断面のビームと支柱。一般道路は山1つ、高速道路は山2つの断面を使い分ける |
| ガードパイプ | 複数のパイプ状ビームと支柱。景観に優れるが施工性にやや難 |
| ボックスビーム | 角形パイプのビーム。剛性・靭性が高く、重大事故が懸念される区間に用いる |
| ガードケーブル | 複数のケーブルと支柱で構成。衝突エネルギーを吸収する。間隔保持材が取り付けられることもある |
| コンクリート製防護柵 | 衝突を受けてもほとんど変形しない剛構造。高速道路・立体交差・路外高低差の大きい箇所 |

### 施工時の留意点

| 項目 | 管理値 |
|---|---|
| 停車帯・歩道に設置する場合の車道外側の空間 | **25cm程度** |
| 路面から防護柵上端までの設置高さ | **0.6m以上1.0m以下** |
| 土中打込みタイプの支柱埋込み長 | **1.2〜1.5m程度** |

- 車道に設置する場合は路肩の端部から、歩道では歩車道境界部から立ち上げる。25cmの空間は建築限界の確保のため（→8-7）
- 道路延長の直角方向に支柱位置がずれると、ビームの取付けが困難になる。レーザー機器・水平器・巻尺で精度管理を徹底する
- **土中打込みタイプは打込み不足が過去に問題化した。** 衝突時に本来の機能を果たせなくなる。超音波装置で埋込み長を測定して確認できる
- 設置高さは箇所ごとに仕様が異なるため、事前に図面で確認する

## 8-9 コンクリート二次製品 ヤクモノの割付

**ヤクモノ**とは、標準品以外の長さや形状を持つ部材のこと。標準品で割り切れない端部やコーナー部に使う。どこにどう配置するかは現場技術者の判断力で差が出る。

### 割付のルール

- 目地は **1cm** として計算する
- 使用するヤクモノは **標準長の1/2以上**（標準長60cmなら **30cm以上**）とする
- 1本で対応できない場合、**2本のヤクモノを組み合わせて配置する**
- 集水桝の周辺は埋戻しの影響が大きいため、**端部に短いヤクモノを使用しない**

### 計算例（U字溝 標準長60cm・目地1cm）

集水桝の設置間隔 **13.0m** をU字溝で連結する場合：

- (13.0m − 0.6m) ÷ 0.61m（U字溝60cm＋目地1cm）＝ 約20
- 標準品だけでは端数が出るため、標準U字溝19本 ＋ **ヤクモノ40cm×2本** とする

短い20cm1本で処理するのではなく、40cmを2本に振り分ける。標準長の1/2以上を確保でき、端部の欠けや沈下に強くなる。

## 8-10 自由勾配側溝のインバート／高さ出しは現場で工夫

自由勾配側溝は、側溝上面の勾配とインバート面の勾配が異なることがある。設置後は地表より深く手が届きにくいため、**仕上げ作業そのものより事前準備が勝負**になる。

### 仕上げの工夫

- 幅30cm程度・高さ80cm程度の製品では、作業員が側溝内に入れないため **専用のインバート仕上げコテ** を使用する
- 幅の広い製品では作業員が中に入って通常のコテを使うこともある
- コテに木の棒を取り付けて延長するといった工夫で仕上げることもある

### 墨出しの工夫

- 側溝設置後に勾配が逆方向になることがある。**設置前に製品の設置順序を決定し、勾配に合わせて配置する。**
- インバートの仕上がり高さを示す墨は、**コンクリート打込み中に消えてしまうことが多い**。墨出し位置に貼ったガムテープの下端を目印にすると、打込み中も高さを追える

## 8-11 土質の基礎知識

地盤が硬いか軟弱かは、主として土粒子の大きさと含水量の差による。砂質土は粒子が粗く間隙が大きいため水を保持できず、粘性土は粒子が細かく間隙が狭いので水分を多く保持して軟弱地盤となりやすい。公式を暗記する必要はないが、一覧で手元に置いておくと実務で役に立つ。

### 質量・体積の比で表す量

| 量 | 記号 | 式 | 意味 |
|---|---|---|---|
| 含水比 | w | mw / ms | 土粒子の質量に対する間隙中の水の質量割合 |
| 飽和度 | Sr | Vw / Vv | 間隙体積中の水の体積の割合。空気がなければ **100%** |
| 間隙率 | n | Vv / V | 土の全体積に占める間隙の体積の割合 |
| 間隙比 | e | Vv / Vs | 土粒子の体積に対する間隙の体積の割合 |

### 密度

| 量 | 記号 | 式 | 意味 |
|---|---|---|---|
| 乾燥密度 | ρd | ms / V | 土粒子の質量を全体積で割ったもの（含水比 w＝0 のときの密度） |
| 湿潤密度 | ρt | m / V | 土の質量（固体＋水）を全体積で割ったもの（含水比 w＞0 のときの密度） |

**間隙率と間隙比の違い** — 分母が「全体積」か「土粒子の体積」か。数値の大小を比較するときは、どちらの指標で語られているかを確認する。

## 8-12 出水期制限に注意！河川工事

河川工事の **出水期は原則6〜10月** とされ、この期間は工事の実施が制限される。ただし施工時期の平準化や十分な工期確保による生産性向上・働き方改革の観点から、近年は制限が一部緩和されつつある。

### 出水期は河川ごとに違う

| 河川 | 出水期 |
|---|---|
| 荒川 | 6月1日〜10月31日 |
| 淀川 | 6月16日〜10月15日 |
| 信濃川 | 6月15日〜9月30日 |

各河川管理事務所のホームページ等で **正確な日付を必ず確認する**。

### 緩和工種

出水期でも安全が確保できる工種は制限が緩和されている。平成29年度から国土交通省が施工可能な工種を指定し、**平成30年度からは遮水対策（矢板）工・耐震補強護岸工が新たに追加**された。

指定されている工種の例：準備工、後片付け、河道掘削、天端保護、土砂撤去、根固め工、樹木伐採、流木除去、高水敷道路、法覆工、矢板護岸

### 施工と備え

- 出水期に施工する場合は工事箇所全体を一括で施工せず、**洪水が予測された際に原形復旧が可能な範囲に限定**し、段階的に進める
- 作業員・資機材の退避を含む防災措置をあらかじめ計画しておく
- 近年の気候変動により、**非出水期であっても増水は起こりうる**。特に季節の変わり目、大雨や台風による増水に注意する

## 8-13 地盤改良工法のノウハウ

地盤改良は汎用性が高く、深さと作業スペースで工法が決まる。地中という **不可視部分** を扱うため、施工管理の記録が品質の証明そのものになる。

| 工法 | 対応深度 | 特徴 |
|---|---|---|
| 浅層混合処理 | **1〜2m程度** | バックホウやスタビライザで掘り起こしセメント固化材と撹拌。短期間・低コスト |
| 中層混合処理 | **2〜13m程度** | バックホウ基幹の専用機。比較的狭い現場でも対応可能 |
| 深層混合処理 | ケーシング継足しで **最大50m程度** | 撹拌翼の先端・側面から固化材を吐出しソイルセメントコラムを造成。大型リーダー式マシンのため広い作業スペースが必要 |
| 高圧噴射撹拌（ジェットグラウト） | **最大25m程度** | 機械がコンパクトで狭所向き。単管／二重管／三重管方式 |
| 薬液注入 | 深度によらない | 地盤の強度向上・止水。固結時間と地質で工法を選ぶ |

▶ 図：[地盤改良工法の対応深度と選定の分かれ目](figures/08-13_地盤改良の深度区分.svg)

### 高圧噴射撹拌の方式

| 方式 | 噴射するもの |
|---|---|
| 単管 | 固化材のみ。切削と改良を同時に行う |
| 二重管 | グラウト＋エア |
| 三重管 | 水＋エア＋グラウト。土砂を切削・排出して置き換えるため、確実な改良強度が期待できる |

三重管ほど確実だが、置き換えるぶん **排出スラリーが大量に出る**。処理計画とセットで検討する。

### 施工管理で残すべき記録

- 施工範囲のマーキング、改良深度の確認（不可視部分の管理）
- セメント量・薬液量の計測管理
- 供試体による強度試験
- 必要に応じて **六価クロム溶出試験**、周辺水質の確認

## 8-14 河川の用語

治水は日本の土木の原点であり、信玄堤・太閤堤・利根川東遷事業といった歴史的事業を持つ。1970年代からは堤防に頼るだけでなく、流域全体で貯水能力を高める **総合治水対策** へ移行し、遊水地の整備が進んだ。

| 用語 | 意味 |
|---|---|
| 本川 | 水系の中で流量・流域・河川の長さが最も重要と考えられる河川 |
| 支川 | 本川に合流する河川。上流から見て右側に合流するものを右支川、左側を左支川と呼ぶ |
| 低水路 | 平常時に水が流れている部分 |
| 高水敷 | 低水路の外側で、増水時に水が乗る部分 |
| 川表・川裏 | 堤防を境に水が流れている側が川表、住居や農地の多い側が川裏 |
| 外水・内水 | 堤外地（河道内）の水が外水、堤内地にたまる水が内水 |
| 内水地域 | 雨水が河川に自然排水されにくく、湛水しやすい地域 |
| 河道 | 流水を安全に流下させるための部分 |
| 超過洪水 | 計画高水位を超えてあふれ出す状態 |
| 破堤 | 堤防が破壊されること |
| 河積（河道断面積） | 増水した河川の横断面において洪水の流れる断面積 |

**「堤内地」が住居側であることに注意。** 直感と逆になりやすい。堤防で守られている内側、と覚える。

## 8-15 都市公園は防災拠点 〜工事の留意点〜

都市公園は都市計画に基づいて設置され、全国に **約11万5,000カ所** が整備されている。工事の相手は構造物だけでなく、生物と地域住民である。

### 都市公園の役割

- 植物の蒸散機能によりヒートアイランド現象を緩和し、都市の景観をつくる
- **地域の防災拠点** — 大規模災害時の避難場所・避難路・復興拠点
- 運動施設、野鳥・昆虫・野草の生息地、地域の観光拠点

### 工事の留意点

- 工事中は生物の生息・生育条件を維持する対策を講じる。維持が難しい場合は **一時的に他の場所へ移動させる**ことも検討する
- 設計図や地盤条件だけで判断せず、**発注者・受注者双方で現地を直接確認する**。困難な場合は専門家と協議し、認識のずれを防ぐ。協議資料を作成して残す
- 自然環境の保全を重視した整備では、計画から設計までの経緯を施工担当者・管理者が理解しておく。現場での経験を次回の施工へフィードバックする
- 地域住民の期待が高いため、完成予想図や閉園予定日を掲示するなど、良好な関係づくりに努める

▶ 図参照：防災公園の施設例 — 平常時はベンチで災害時に炊き出しかまどになる設備、便器を取り付けて災害用トイレになるマンホール、テントを張って救護スペースにする広場（原本 p.177 Topics）

## 8-16 砂防工事の役割と工事の留意点

砂防は、山地の荒廃を防ぎ、急峻な渓流から押し出される土砂によって下流の生命と生活が損なわれることを防ぐ事業である。日本の砂防技術は評価が高く、海外に相当する用語がないことから、**1950年代頃から「SABO」がそのまま国際語として使われている。**

### 対策の種類

| 対策 | 主な工種 |
|---|---|
| 土石流対策 | 砂防堰堤、土留め |
| 落石対策 | 落石防護柵、落石防護網 |
| 斜面の安定 | 擁壁工、法枠工、抑止杭 |
| 地すべり対策 | **集水井・地下水排除工**（原因の多くは地下水） |
| 山林保全 | 荒廃地の斜面崩壊防止 |

2014年8月に広島市北部で発生した大規模土砂災害は、土石流が一度発生したときの被害の大きさを示している。

### 施工上の留意点

- 同一流域・河川の **上下流における他事業との調整を事前に行い**、工事間の連絡体制を整備する。施工中の災害・事故を未然に防ぐ
- 基礎岩盤に付着している浮石や砂は除去してからコンクリートを打ち込む
- 施工順序は原則 **上流から下流** へ。ただし人家など保全対象が下流にある場合は、下流から上流へ向かって施工する
- 山腹保全工では斜面の早期安定を図る。緑化にあたっては在来の自然環境を尊重して草木の種を選定し、排水路の位置は小動物・昆虫に配慮した構造とする
- 魚道の施工は、着手前に河道の位置・幅・水深・植生などを写真やメモで十分に記録する。河床材料は一時的に仮置きし、河床環境の復元に再利用する

## 8-17 道路排雪作業の重要性

除雪は道路交通の確保に不可欠であるだけでなく、地域の暮らしを支える社会的意義のある業務である。作業ごとに国土交通省の実施目安が定められている。

| 作業 | 内容 | 実施の目安 |
|---|---|---|
| 新雪除去 | 走行車線の新雪をエッジで削り取る | **5〜10cm程度**の降雪量を目安に、道路交通に支障がある場合 |
| 路面整正 | 圧雪の凹凸やわだちをグレーダで削り平坦に整える | 圧雪状態が放置すると交通確保が困難になるおそれがある場合 |
| 拡幅除雪 | 増大した路肩の雪堤下部を除去し車道幅員を確保する | 必要な車道幅員および堆積雪幅が確保できない場合 |
| 運搬排雪 | 拡幅が難しい市街地・交差点・橋梁・トンネル出入口等で雪を搬出する | 引き続き降雪増加が予想され、交通に支障をきたすおそれがある場合 |
| 歩道除雪 | 小型ローダ除雪車等で歩道の雪を除去する | 歩行者の通行に支障がある場合 |

新雪除去は **圧雪状態になる前に行うのが基本**。車両に踏まれて圧密されると格段に手間が増えるため、多くは前日深夜から早朝にかけて実施される。

### 凍結防止剤散布

| 項目 | 内容 |
|---|---|
| 主成分 | 塩化ナトリウム、塩化カルシウム |
| 原理 | **凝固点降下** により低い温度でも溶ける。既に形成された凍結膜を溶かす効果もある |
| 散布量 | **20g/m²程度** が目安 |
| 効果の限界 | 気温 **−8℃以下** では効果が低い |

- 気温が低すぎる場合や路面に雪が積もっている場合は、すべり止め材（焼砂等）を使用する
- 日陰、橋梁、急カーブ、急な坂など **凍結しやすい箇所に限定して散布**することが多い
- **塩化ナトリウムはコンクリート内部の鉄筋腐食や鋼構造物の腐食を助長する。** 影響が懸念される箇所では、舗装内に電熱線等を埋設するロードヒーティング施設を設置する事例もある

## 8-18 鋼矢板の打込み工法

打込み工法は **地質条件と周辺環境** で決まる。矢板の長さに応じて機械を選定し、必要に応じて補助工法を併用する。

| 工法 | 適用土質 | 振動 | 騒音 | 長所 | 短所 |
|---|---|---|---|---|---|
| 振動工法（バイブロハンマ） | 砂質土・粘性土。砂礫や玉石混じりは不可 | 大 | 大 | 施工速度が速い。**N値50程度**まで対応。最も安価 | 近接構造物への影響が大きい |
| 振動工法（高周波バイブロハンマ） | 同上 | 大（バイブロより小） | 大（バイブロより小） | 振動数を高めて振動・騒音を低減。N値50程度まで対応 | それでも比較的大きい |
| 油圧圧入（サイレントバイブロ） | 砂質土・粘性土。砂礫や玉石混じりは不可 | **発生しない** | **発生しない** | 近接構造物への影響が小さい | 施工速度が遅い。適用N値の上限が低い |
| アースオーガー併用圧入（HAS） | 砂質土・粘性土 | 小 | オーガー回転圧入時に摩擦音 | 施工速度が速く振動が小さい | 杭打機やプラント設備が必要 |
| ロックオーガー併用圧入 | 砂礫、玉石混じり、岩 | 小 | オーガー回転時に大きな摩擦音 | **岩盤の硬質層にも適用可能** | 施工速度が遅く、工費が高い |

油圧圧入は、既に打ち込まれた **4本程度の鋼矢板を反力材として掴み**、油圧ジャッキの伸縮で新たな矢板を圧入する。オーガー併用の2工法は、孔壁をセメントミルクで保護してから矢板を挿入する点が共通する。

### 補助工法：ウォータージェット併用

| 項目 | 内容 |
|---|---|
| 併用先 | バイブロハンマ、サイレントバイブロ |
| 適用土質 | 砂質土・砂礫層・玉石混じり層。**粘性土には適用不可** |
| 効果 | 硬質地盤でも迅速・確実な施工が可能。矢板先端が硬い層に入る際の振動を低減できる |
| 短所 | **多量の水の供給が必要**。市街地では汚水の処理施設が要る。ジェット設備のポンプ音が加わる |

## 8-19 揚重機の種類・定格荷重・作業半径

クレーンは **吊り上げる重量・作業半径・揚程・機動性** の条件から適切な機種を選定する。移動式クレーンはクローラクレーンとホイールクレーンに大別され、ホイールクレーンはさらにトラッククレーン、ラフテレーンクレーン、クレーン装着トラック（ユニック車）に分類される。

| 種類 | 吊り上げ能力 | 機動性 | 特徴 |
|---|---|---|---|
| クローラクレーン | 最大 **1,000t** を超える機種もある | 極めて遅い。走行速度 **1〜3km/h** | 履帯で接地面積が広く、凹凸地でもスムーズ。ジブはトラス構造。大型は組立解体にクレーンが必要 |
| トラッククレーン（ホイールクレーン） | **145t級** | 高速道路の走行も可能。最高速度 **約90km/h** | 走行用とクレーン作業用の運転室が別々 |
| ラフテレーンクレーン | 大半が最大吊り上げ荷重 **100t未満** | 走行速度 **50km/h未満**。高速道路の走行は不可 | 走行もクレーン操作も同じ運転席。四輪駆動・四輪操舵で悪路や軟弱地盤に強い。大型特殊自動車 |
| クレーン装着トラック（ユニック車） | 最大 **4.9t**（一般的には **2.93t**） | 通常のトラックと同様 | 正式名称は搭載型トラッククレーン。ブームは通常4段、5〜7段仕様もある。作業半径 **8〜10m程度** |

「ユニック」は古河ユニック社の製品名に由来する通称。「ラフテレーン」は英語の Rough Terrain Crane に由来する。

### 定格総荷重と定格荷重は違う

- クレーンのカタログの荷重表に示される数値は **定格総荷重**
- 実際に吊れる重量は、定格総荷重から **フックや吊り具の重量を差し引いた値** で、これを **定格荷重** という
- **作業半径は、クレーン旋回中心からフック中心までの水平距離**。アウトリガーやクローラ端部からの距離ではない

この2点を取り違えると、吊れるはずの荷が吊れない、あるいは能力を超えた計画になる。

## 8-20 現場でさくっと計算 H形鋼のたわみ計算

現場で仮設梁のたわみを確認したいとき、**H形鋼に限定すれば電卓で計算できる形に整理できる。** 単位は荷重 P〔N〕、支間長 L〔mm〕で統一する。

### 単位換算

| 量 | 換算 |
|---|---|
| 荷重 P | 1 t ＝ 1,000 kgf ＝ **9,800 N** |
| 支間長 L | 1 m ＝ **1,000 mm** |
| ヤング係数 E | **2.05×10⁵ N/mm²** |
| 断面2次モーメント Ix | 1 cm⁴ ＝ **1×10⁴ mm⁴** |
| 鋼材単位自重 w | 1 kgf/m ＝ 9.8 N/m ＝ 9.8×10⁻³ N/mm |

### 許容たわみの目安

> **δ ＜ L × 1/250**

支間長5mなら **20mm** が上限。この値に収まれば安全側と判断できる。

### H形鋼向けに整理した式

| 条件 | 一般式 | H形鋼用（Ix は cm⁴、L は m、P は t、w は kgf/m） |
|---|---|---|
| 単純梁・中央集中荷重 | δ₁ ＝ PL³/48EI | δ₁ ＝ **99.59 × P × L³ / Ix** |
| 単純梁・等分布荷重（自重） | δ₂ ＝ 5wL⁴/384EI | δ₂ ＝ **0.0622 × w × L⁴ / Ix** |
| 片持ち梁・端部集中荷重 | δ₃ ＝ PL³/3EI | δ₃ ＝ **1,593.50 × P × L³ / Ix** |
| 片持ち梁・等分布荷重 | δ₄ ＝ wL⁴/8EI | δ₄ ＝ **0.598 × w × L⁴ / Ix** |

|---|---|---|---|---|---|---|

| 150×150×7×10 | 1,620 | 31.1 | 8.43 | ○ | 130.13 | ✕ |
| 200×200×8×12 | 4,720 | 49.9 | 3.05 | ○ | 46.14 | ✕ |

## 8-21 防水塗装は色を変えて重ね塗り

水槽の防水工事はウレタン樹脂による防水塗装が一般的で、**下塗り・中塗り・上塗りの3層**で構成されることが多い。全体の塗膜厚は塗膜厚検査で確認できるが、**3層すべてが同一色だと写真記録で各層の識別ができず、重ね塗りの証明が困難になる。**

### 対策：層ごとに色を変える

各層の塗装色を異なるものにすれば、施工状況の写真そのものが重ね塗りの証拠になる。

### 同じ考え方の応用：炭素繊維シートの積層

積層施工でも同様の課題があり、端部の処理で証明できる。

- シート端部に **10mm程度** の白色マーキングを施しておく
- 1〜3層目の端部を **5mmずつ短く** カットして貼り付ける
- 表面に現れる白色マーキングが **5mm** になっていれば、3層施工されたと証明できる

**証明できない品質は、施工していないのと同じ扱いになりかねない。** 見えなくなる部分ほど、記録の取り方を施工方法そのものに組み込んでおく。

## 8-22 管理図の活用方法（X-Rs）

管理図は、品質特性の折れ線データと中心線・管理限界線からなるグラフ。工程内の品質のばらつきを分析し、**管理限界内であっても、読み解くことで異常を察知できる。**

### 活用の目的

- 中心線や管理限界線との相対的な位置関係を確認する
- 客観的な指標を用いることで、**異常の兆候を早期に特定できる**
- 対策を講じて正常な状態に戻す

### 利用上の注意

- X-Rs管理図を現場でJIS規格の生コンクリートにそのまま当てはめるのは適切ではない。JISの枠組みは**「合否判定」（ロット判定＝規格への適合判定）**であり、目的が異なる
- 一方、管理図は**「工程が安定しているか」を統計的に監視するツール**である
- 生コンの現場では、ばらつきが大きいことから、**統計的に「工程能力を掴みにくい」**という現場の特長を生かしきれない
- 実際の現場では土質管理に向いており、例えば**含水比、密度、粒度試験、プレート荷重試験、CBR試験**などが適する
- **同じ材料であれば、工程の自然なばらつきを管理しやすい**

### 管理図の見方

**JIS Z 9020-2**（管理図に関する指針）では、管理限界線（UCL・LCL）間を1σ刻みで6つの領域（ゾーンA／B／C）に分け、**突発的に見られる変動原因に対する異常判定ルールの8つ**を定めている。

| ルール | 内容 |
|---|---|
| **1** | ゾーンAを超えた1つの点（最も明確な異常） |
| **2** | 中心線の片側上のゾーンCの中で、またはそれを超えて一列になった9点（系統的な偏りの発生） |
| **3** | 一列になって上方向に増加、または下方向に減少する6点（傾向の発生） |
| **4** | 一列になって交互に上下する14点（作業シフト・設備稼働など、周期的要因が疑われる） |
| **5** | 中心線の片側のゾーンAの中で、またはそれを超えて一列になった3点のうちの2点（突発的な原因の発生） |
| **6** | 中心線の片側のゾーンBの中で、またはそれを超えて一列になった5点のうちの4点（操作条件の偏り・材料ロット違いなど） |
| **7** | 中心線の上下のゾーンCの中で一列になった15点（変動が自然に小さくなりすぎている。ばらつきの過小報告・計測器の故障など） |
| **8** | 中心線の両側にて一列になった8点（ゾーンCに点がない。自然ではない規則性が疑われる） |

### 2つの誤り

管理図を活用する際は、**よくある2つの誤り**を念頭に置く。

| 誤り | 内容 |
|---|---|
| **あわて者の誤り（見逃さないが過剰）** | 本来は正常であるのに、異常と過剰に判断してしまう |
| **ぼんやり者の誤り（見過ごし）** | 本来は異常であるのに、見逃してしまう |

## 8-23 写真管理のPDCA

工事写真は工事情報を記録すると共に、工事完成後には確認できない不可視部分の施工を証明するものである。**その都度実施することで、撮影忘れや不具合の早期発見が可能となり、結果として業務の省力化につながる。**

### 事前準備

- **工事写真は撮影後に整理するのではなく、施工計画書や数量総括表に基づき、工事箇所や工種を記載した写真管理帳を作成しておく**
- 撮影データは電子写真専用のフォルダーに格納するだけでは、後追いでは抜け落ちや漏れが生じる。**必ず事前に完成させておき、作成が終わった場合はその都度、写真管理も追加・作成する**
- 設計変更が発生した場合には、随時追加する
- 写真管理に使用するアプリケーションは、**単なる写真添付機能だけでなく、撮影忘れや複数写真の確認機能を備えたものが望ましい**

### 国土交通省の工事写真管理基準

- 施工状況を示す手順を示すため、各段階の施工状況をまとめた写真を貼付し、工事の進行を証明する
- 特に施工品質に影響を与える重要な箇所の写真は必ず撮影する
- 安全管理では、各施工段階における安全管理の状況を示す写真を貼付する。具体的には安全設備や標識の設置状況、交通誘導員による交通整理の状況などが含まれる
- 品質管理では、材料検収時に品質・規格を証明する写真を貼付する。安全訓練の実施状況なども含まれる
- 所定の材料を使用し、設計図書に示された材料と同等以上の品質であることを証明する必要がある
- 必要に応じて設計値と実測値を記載し、施工方法に従っている写真を貼付する
- 工事目的物の出来形寸法を計測した写真により、施工の精度と実際を現場写真で示すものである

### 写真の貼付

- 工事進捗に合わせて撮影漏れがないようにするため、前日にどのような写真の確認をするのか**"To doリスト"を作成する**
- 撮影予定と写真は事前に準備し、工事写真帳に貼付する。**撮影不足や写真に応じて翌日に撮影することで、このような写真管理のPDCAを継続的に実施する**
- **前日にペーパーベースで準備し、少なくとも1回の確認を習慣化することで、写真整理に要する時間を大幅に短縮できる**
- 工事板に図面等の資料を貼り付ける時間があれば、日々の行動の中で変化を生む活動になる。**これは鉄筋写真時に黒板を貼り付けて撮影する**

## 8-24 備えよ常に!! 現場版BCPと地域貢献

**BCP（Business Continuity Plan：事業継続計画）** とは、自然災害、感染症の流行、テロ、サイバー攻撃などの予期せぬ緊急事態が発生した際に、被害を最小限に抑えつつ、迅速に事業を再開するための戦略的な計画である。

さらに、災害などに備えることで作業の中断期間を短縮し、早期の事業再開を可能にする。**こうした事前の備えは、被災地域の住民支援に直結する。**

### 建設現場におけるBCP（現場版BCP）

- 建設現場は、地震・風水害・豪雨などの自然災害の影響を最も受けやすい事業形態の一つである
- そのため、現場ごとに緊急時の手順・体制・備品を整備しておくことが**「現場版BCP」**である
- 現場は資機材や重機が揃っており、備蓄品等の保管場所も確保できる。**現場にも役立つことができる。こうした継続的な備えを立てることで、持続的なBCPの実践といえる**

### 資機材の備え

- 水害への備えとして土のう、松杭、木矢板、釘などを常備しておく。**特に土のうは、急な時にすぐ使えるよう、袋詰めではなく土を詰めた状態にしておく**
- 豪雨時の水没に備えて、水中ポンプを専用に使用できる状態にしておく
- 山間部では強風による倒木リスクが高いため、**発電機と燃料を備蓄しておくことで、チェーンソーの使用が可能になる**
- 災害発生時に機材が使用できるよう、**空調設備などの充実、携帯電話の充電など、常に新しいものを確保する**

### 人への備え

- 帰宅困難者用として、毛布、飲料水、インスタント食品、缶詰などを備蓄する
- **食品類は定期的に入れ替えを行い、常に新しいものを確保する**

### ソフト面の備え

- 地域のハザードマップを入手し、避難場所や避難ルートを共有する
- 特に河川工事では、避難時に備えて重機待避場所となる高台などを事前に指定しておく

### 地域貢献としての現場版BCP

- 建設現場におけるBCPは、単に自社のための備えではなく、**地域社会への貢献という側面を持つ**
- **土のうサポートは、近隣住宅の浸水防止に役立つ**
- **チェーンソーは、倒木の除去や避難路の確保に機能する**
- **発電機や照明は、停電時に地域の明かりや電源供給として活用する**
- 現場付近で業務が被災を免れた場合、**そこが地域の一時的な防災拠点として活用されることもある**
- **短期間の工事であっても「地域の一員」としての意識を持ち、地域貢献型の備えを整えることに意義がある**

### 企業評価と企業の価値

- 現場版BCPの目的は、災害からの迅速な復旧と地域の支援である
- 住民からの信頼を高めると同時に、発注者からの企業評価にもつながる
- **派手さではなく、日々の小さな努力の積み重ねこそが価値である**

**「備えよ常に」— 現場は地域の守り手。**

## 8-25 ウィークリースタンス

「ウィークリースタンス」という言葉を耳にする機会が増えている。これは、**発注者と受注者の間で設計や業務の効率化・働き方改革の推進を目的として導入されている**取組みである。

同様の取組みを社内の部下や協力業者と共有し、実践してみてはどうだろうか。

| 名称 | 内容 |
|---|---|
| **マンデー・ノーピリオド** | 月曜日など休日明けを依頼の期限日としない |
| **ウェンズデー・ホーム** | 水曜日など週1回以上は定時帰宅を心掛ける |
| **フライデー・ノーリクエスト** | 金曜日など休日前に依頼しない |
| **ランチタイム・オーバーファイブ・ノーミーティング** | 昼休みや17時以降の打合せをしない |
| **イブニング・ノーリクエスト** | 定時間際・定時後の依頼・打合せをしない |
