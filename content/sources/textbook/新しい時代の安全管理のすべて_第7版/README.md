# 『新しい時代の安全管理のすべて 第7版』— 非公開文字起こし索引

大関親著、中央労働災害防止協会、2020年刊（ISBN 978-4-8059-1935-4）のうち、
原本 p.106–273（第2編「安全管理システム」・第3編「労働安全衛生マネジメントシステム」）を
2026-08-30 に168ページ分を二重OCRし、低一致率・低信頼度だった22ページは原画像との目視再照合まで完了した。

本文、OCR第二読、ページ別照合台帳は public repo では追跡せず、Google Drive の private vault
`doboku-note/文字起こし/新しい時代の安全管理のすべて_第7版/` に保管する。
原本PDF 5ファイルは Google Drive vault `doboku-note/原資料PDF/書籍/新しい時代の安全管理のすべて_第7版/` に保存済み
（private R2 `doboku-note-archive/textbook/` は移行中で撤去予定）。

## 取扱い

- 市販書籍の全文文字起こしは非公開。サイトへ逐語転載しない
- 公開記事は原本の章立て・表現を写さず、厚生労働省、e-Gov、国土交通省等の一次資料で事実を取り直して独自に再構成する
- OCRは macOS Vision と Tesseract の二重読取。168ページすべてに主文字起こしと第二読を持つ
- OCR差分の大きかった22ページは表・図・注記を原画像と再照合し、`reviewRequired: 0`・判読不能0件まで解消した。校正版と照合記録は private vault の `visual-review/` と `ocr-audit.json` に保存する
- スキャンは見開き由来で裏写り・指の写り込みがあるため、この完了状態は「全ページ二重OCR＋機械判定例外の画像照合」であり、全168ページを人間が一字ずつ照合したことを意味しない

全体の保管ルールは [content/sources/textbook/README.md](../README.md) と
[asset-storage-policy.md](../../../../.claude/knowledge/reference/asset-storage-policy.md) を参照。
