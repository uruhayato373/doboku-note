# 総合技術監理キーワード集2026 — 文字起こし索引

『総合技術監理 キーワード集 ２０２６』（文部科学省・日本技術士会）全40ページの全文。
原本PDFは born-digital で埋め込みフォントのテキスト層を持つため、**画像OCRではなく
テキスト層をそのまま取り出している**（`method: pdf-text-layer`）。文字認識誤りは生じない。

## 構造の決め方

版面の幾何で決めており、`pdftotext -layout` の空白数は使わない（同じ字下げ段でも揺れるため）。

- 行頭 x = 128 / 161 / 194 / 227 pt → キーワードの第1〜4階層
- 行頭 x = 144 pt → 散文段落の1字下げ（段落の開始）
- 行末 x が版面幅（760 pt 以上）→ 次行へ折り返した継続行
- 表1（5つの管理技術の範囲）は本文段落の間に割り込むフロートなので、段落の再結合から外して別に組む

## 再生成

```bash
VAULT_BOOK="<vault>/原資料PDF/書籍/ipej-cem-keywords-2026__総合技術監理キーワード集2026" \
  python3 .claude/skills/conversion/pdf-to-mdx/scripts/text-layer/extract_ipej_cem_keywords.py \
  content/sources/books/ipej-cem-keywords-2026__総合技術監理キーワード集2026/ocr
```

原本 `source/001.pdf` だけを入力とし、再実行で bit 一致することを確認済み。

## 検証

- 原本テキスト層 18,456 文字に対し出力 18,458 文字。差はすべて説明済み
  （見出しの全角数字・「．」を半角へ直した 90 文字と、目次章に付けた H1「目次」2 文字）
