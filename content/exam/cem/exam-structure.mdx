# 試験科目・出題範囲

技術士総合技術監理部門は、**必須科目（5つの管理技術）+ 選択科目（1分野）** の2段階試験です。

## 必須科目（7月20日実施）

### 試験構成

| 項目 | 内容 |
|---|---|
| **実施日** | 7月20日（日） |
| **試験時間** | 5.5時間（午前2時間 + 午後3.5時間） |
| **午前：択一式** | 40問（各分野8問×5分野） |
| **午後：論文式** | 1問を600字×5枚以内で作成 |
| **配点** | 各分野100点 × 5 = 500点 |
| **合格基準** | 500点中300点（60%）以上 |

### 5つの管理技術

#### ① 安全管理（40点満点の目安）

**出題範囲:**
- 労働安全衛生管理
- 事業継続計画（BCP）
- リスクマネジメント手法
- 危険予知訓練（KYT）
- 安全文化の構築

**よく出る問題パターン:**
```
□ OSHA・ISO 45001等の国際規格
□ 事故防止・ヒューマンエラー対策
□ 現場の安全衛生計画策定
□ 自然災害・パンデミック対応
```

---

#### ② 社会環境との調和（40点満点の目安）

**出題範囲:**
- 環境規制（大気汚染防止法、水質汚濁防止法等）
- 環境アセスメント
- サステナビリティ・SDGs対応
- 社会コンプライアンス
- 地域社会との関係構築

**よく出る問題パターン:**
```
□ カーボンニュートラル・脱炭素化
□ 騒音・振動・廃棄物管理
□ ISO 14001環境マネジメント
□ 地域貢献・社会責任（CSR）
□ サーキュラーエコノミー推進
```

---

#### ③ 経済性（40点満点の目安）

**出題範囲:**
- コスト管理（VE、VA分析）
- 品質管理（QC、SQC）
- 生産性向上
- 原価企画・見積方法
- 利益計画・収益性分析

**よく出る問題パターン:**
```
□ 工事原価の構成・管理手法
□ 施工の効率化・工期短縮
□ 品質保証・リスク対価
□ 資源・エネルギー効率
□ ROI・利益率計算
```

---

#### ④ 情報管理（40点満点の目安）

**出題範囲:**
- データセキュリティ・情報セキュリティ
- IT戦略・DX（デジタルトランスフォーメーション）
- BIM/CIM等の新技術活用
- サイバーセキュリティ対策
- データ分析・ビッグデータ活用

**よく出る問題パターン:**
```
□ 個人情報保護（GDPR、個保法）
□ クラウド・IoT・AI導入戦略
□ BIM・CIM・ドローン活用
□ 情報システムの構築・選定
□ データ駆動意思決定
```

---

#### ⑤ 人的資源管理（40点満点の目安）

**出題範囲:**
- 組織構造・人員配置
- 人材育成・研修計画
- モチベーション管理
- キャリア開発
- ダイバーシティ・働き方改革

**よく出る問題パターン:**
```
□ 技術者の確保・育成
□ 現場労働者の処遇・働き方改革
□ 女性技術者・多様性推進
□ 高齢技術者の活用
□ 効果的なリーダーシップ
```

---

### 午前：択一式（40問 2時間）

**形式:** マークシート方式

**問題構成:**
- 各分野8問（安全/社会環境/経済性/情報/人的資源）
- 1問1分野3分で解く必要
- 単純な暗記問題は少なく、**実務に基づく判断問題が大半**

**出題レベル:**
```
易しい ← 基礎知識を問う問題 20%
   ↓
標準 ← 実務経験で判断できる問題 60%
   ↓
難しい → 新規制度・最新トレンド 20%
```

---

### 午後：論文式（1問 3.5時間）

**形式:** 手書き論文（600字×5枚以内）

**出題パターン:**
```
【典型例】
「プロジェクト管理において、以下の3つの管理技術の相互関係を説明し、
統合的マネジメント手法を提案せよ。
  1) 安全管理と経済性の両立
  2) 環境配慮と工期短縮の調和
  3) 人的資源活用と品質確保
（600字以内）」
```

**評価ポイント:**
- 複数分野の知識を統合できているか
- 実務的な課題解決ができているか
- 根拠を示し、体系的に論述できているか
- 文字数・フォーマットが正確か

## 選択科目（7月21日実施）

### 試験構成

| 項目 | 内容 |
|---|---|
| **実施日** | 7月21日（月・祝） |
| **試験時間** | 5.5時間 |
| **午前：択一式** | マークシート（20～50問、分野により異なる） |
| **午後：論文式** | 3題中2題選択、各1,200～1,500字 |
| **配点** | 500点（必須と同じ） |
| **合格基準** | 500点中300点（60%）以上 |

### 選択科目の選択肢（20部門）

```
【土木系（推奨）】
- 建設部門 ← 1級土木施工管理技士との親和性高い
- 農業土木部門
- 森林土木部門
- 水道技術部門

【機械系】
- 機械部門
- 金属部門
- 資源工学部門

【電気系】
- 電気電子部門
- 衛星通信部門

【化学・食品系】
- 化学部門
- 繊維部門
- 食品部門

【環境・安全系】
- 環境部門 ← 社会環境との調和が活きやすい
- 原子力・放射線部門

【その他】
- 上下水道部門
- 船舶・海洋部門
- 航空宇宙部門
- 建築部門
```

**選択のコツ:**
```
1. 実務経験が最も活かせる分野を選ぶ
2. 「建設」「機械」など、素材が豊富な分野を選ぶ
3. 予備知識がある分野＜新規に学べる分野の重要性は低い
```

## 合格基準

### 筆記試験

| 試験 | 配点 | 合格基準 |
|---|---|---|
| **必須科目** | 500点 | 300点以上（60%） |
| **選択科目** | 500点 | 300点以上（60%） |
| **両試験総合** | 1,000点 | **全試験で60%以上を得点** |

:::info
両科目とも各々60%以上を得点する必要があります。必須科目は合格したが選択科目が不合格、というケースは落第です。
:::

### 口頭試験

- 筆記試験合格者のみ受験
- **合格基準は非公開**（約90～95%が合格と言われている）
- 筆記試験の内容に基づく確認問題が中心

## 出題の特徴・傾向

### 1. 「最新トレンド」が頻出

```
【2024-2025年の注目キーワード】
- 脱炭素化・カーボンニュートラル
- DX・AI導入
- BIM・CIM活用
- 働き方改革・働き手不足対策
- サーキュラーエコノミー
- サイバーセキュリティ
```

### 2. 単なる知識問題より「判断問題」

```
❌ 「OSHA とは何か」← こんな形で出ない
✅ 「建設プロジェクトで作業員の切断事故が多い場合、
      総合技術管理の視点で対策を述べよ」← こんな形で出る
```

### 3. 複数分野の統合問題

```
【例：論文出題パターン】
「品質コストが急増するプロジェクトに対して、
 経済性と安全管理を両立させた改善案を提案せよ」

→ 単なる「品質」「安全」ではなく、
  「経済性との相互作用」を理解していることが問われる
```
