# 2025年度 合格への学習計画

2025年7月21日（選択科目）の試験日に向けた、**段階的な学習ロードマップ**を提案します。

**前提:** 1級土木施工管理技士取得者、または建設系実務経験3年以上

---

## 全体スケジュール（4月～7月）

```
【2025年】
4月 ┌─ 受験申込 + 学習準備期
   │  ├─ 5分野の基礎キーワード抽出（100個）
   │  └─ 参考書・過去問入手
   │
5月 ┤  学習加速期
   ├─ キーワード学習（50個/週）
   └─ 過去問分析開始
   │
6月 │  論文作成訓練期
   ├─ 実践問題演習
   └─ 答案作成・添削
   │
7月 ├─ 直前対策
   ├─ 7月20日 必須科目試験
   ├─ 7月21日 選択科目試験
   └─ 12月～1月 口頭試験（予定）
```

---

## Phase 1: 準備期（4月上旬）

### 目標: 学習の方向性を決める

**やることリスト:**

| タスク | 内容 | 時間 |
|---|---|---|
| 受験申込 | WEB申込ポータルで手続き完了 | 1時間 |
| 試験要項確認 | 合格基準・出題範囲を100%理解 | 2時間 |
| 選択科目決定 | 20部門から1つ選択（推奨: 建設部門） | 1時間 |
| 学習計画策定 | 勉強スケジュール・時間配分を決定 | 2時間 |
| 参考資料入手 | 過去問、参考書、講座資料の確保 | 2時間 |
| **合計** | | **約8時間** |

### 推奨資料

```
【必須】
□ 日本技術士会 公開資料
  └ 過去3年分の試験問題・正答
□ 通信講座
  └ JES（日本技術サービス）
  └ アガルート
  └ STUDYing

【オプション】
□ 参考書『技術士総合技術監理部門合格ガイド』
□ 関連法規集
  └ 労働安全衛生法、環境基本法等
```

## Phase 2: 基礎習得期（4月下旬～5月）

### 目標: 5分野の重要キーワード200個を習得

**1日の勉強タイムスケジュール（90分推奨）**

```
15分   キーワード学習（動画 or 解説書で新規キーワード5個）
30分   過去問を読む＆考える（不正解分析）
30分   要点まとめ（キーワードカード or Notion に記録）
15分   復習（前日のキーワード確認）
───
90分 /日
```

### 5分野の学習順序

| 優先度 | 分野 | 理由 | 学習期間 |
|---|---|---|---|
| 🔴 **最優先** | **安全管理** | 出題頻度高、実務性高い | 1週間 |
| 🔴 **最優先** | **経済性** | VE・品質管理は1級土木と親和性 | 1週間 |
| 🟠 高 | **人的資源管理** | 組織・人材育成テーマ | 1週間 |
| 🟠 高 | **情報管理** | DX・セキュリティは最新トレンド | 1週間 |
| 🟡 標準 | **社会環境との調和** | 環境法規は暗記ベース | 1週間 |

### 月間学習目標

```
4月下旬～5月末（約5週間）

📚 安全管理
  ├─ 労働安全衛生法の基本
  ├─ リスクマネジメント手法
  ├─ BCP（事業継続計画）
  ├─ KYT（危険予知訓練）
  └─ 過去問3年分分析

📚 経済性
  ├─ VE（バリューエンジニアリング）
  ├─ 原価管理・見積方法
  ├─ 品質コスト論
  ├─ 生産性指標
  └─ 過去問3年分分析

... （人的資源・情報・社会環境も同様）
```

### 学習記録

```
【毎日記録すること】
□ 学習時間（90分以上）
□ 学習分野（5分野いずれか）
□ 習得キーワード数
□ 過去問の正答率
□ 次回への改善点
```

## Phase 3: 加速期（6月上旬～中旬）

### 目標: 300個のキーワード完全習得 + 過去問演習開始

**1日の勉強タイムスケジュール（120分推奨）**

```
20分   キーワード復習（速読）
40分   過去問演習（午前の択一式 40問を本番時間で解く）
40分   解説読み込み＆要点記録
20分   類似問題の応用理解
───
120分 /日
```

### 実施内容

| 週 | タスク | 詳細 |
|---|---|---|
| **6月1週** | 5分野の統合演習 | 各分野の過去問を「まとめて40問」解く |
| **6月2週** | 弱点分野の補強 | 正答率60%未満の分野を集中学習 |
| **6月3週** | 論文問題演習 | 必須科目の論文1問を実際に作成 |
| **6月4週** | 選択科目(建設部門)演習 | 過去問2年分を本番と同じ形式で実施 |

### 過去問活用のコツ

```
❌ 「正答を暗記する」
✅ 「なぜこの選択肢が正解か」を理解する

❌ 「分からない問題はスキップ」
✅ 「分からない問題こそ、解説を深掘りする」

❌ 「本番1か月前に過去問を解く」
✅ 「4月から少量ずつ、3～4回繰り返す」
```

## Phase 4: 論文訓練期（6月下旬～7月初旬）

### 目標: 論文答案の作成に慣れる

**1日の勉強タイムスケジュール（150分推奨）**

```
30分   キーワード速読（復習）
60分   論文作成（時間計測、600字×5枚まで）
40分   添削・推敲（自分でチェック or 他者に見てもらう）
20分   反省・改善点の記録
───
150分 /日
```

### 論文作成のテンプレート

```
【構成案（600字×5枚）】

【1枚目】
├─ 問題認識（この課題の重要性）
└─ 自分の立場・役割の明確化

【2枚目】
└─ 現状の課題分析（複数分野の視点で）

【3枚目】
└─ 改善案の提案（具体的アクション）

【4枚目】
├─ 各改善案の効果
└─ 実現可能性

【5枚目】
├─ 他分野との相乗効果
└─ 期待される成果・結論

【全体】
├─ 論理展開が明確か
├─ 複数分野の知識を統合しているか
├─ 実務的な説得力があるか
└─ 600字以内か
```

### 模擬論文のテーマ例

```
1. 「建設プロジェクトにおいて、安全管理と経済性を両立させるには」
2. 「DX推進の課題と、人的資源管理の観点からの対策」
3. 「カーボンニュートラル達成と工期短縮の調和方法」
4. 「高齢化社会における技術者の確保・育成戦略」
5. 「パンデミック対応を視野に入れた事業継続計画の構築」
```

```

├─ 午前: 必須科目 択一式(40問 × 2時間) + 論文(1問 × 3.5時間)
└─ 翌日: 選択科目(建設部門) 午前+午後(計5.5時間)

├─ 試験会場までのアクセス確認

```

## 合格可能性を高める秘訣

### 1. 「キーワード300個」を完全習得する

```
理想的なキーワード習得順序:
週1周目  100個を「見出し」だけ知る
週2周目   50個を「意味」まで理解
週3周目   30個を「実例」で説明できる
週4週   10個を「論述」に使える
```

### 2. 実務経験を「言語化」する

```
例：1級土木施工管理技士での経験
「品質管理」 → 「経済性」へ昇華

「工事現場でコンクリート品質を管理していた」
       ↓ 総合技術管理の視点で言語化
「限られた予算の中で品質を確保し、
 VEにより原価を削減。その結果、
 社会的信頼を得て受注率が向上した」
```

### 3. 「複数分野の統合」を意識する

```
❌ 「安全管理とは何か」を答える
✅ 「安全と経済性を両立させるマネジメント手法」を説明する

出題者は、単分野の知識ではなく、
複数領域を統合的に考える能力を見ている
```

### 4. 最新動向をキャッチする

```
【購読すべきニュース・雑誌】
□ 建設通信新聞（安全・DX・働き方改革の最新ニュース）
□ 日経xwoman（ダイバーシティ・女性技術者）
□ 環境新聞（脱炭素・サーキュラーエコノミー）
□ IT関連メディア（DX・セキュリティ動向）
```

## よくある落とし穴

| 陥りやすい行動 | 改善策 |
|---|---|
| キーワードの「暗記」に偏る | 理由と背景を理解する |
| 1分野の深掘り（例：安全管理だけを極める） | 5分野をバランスよく学習 |
| 過去問を「1回だけ」解く | 最低3回は繰り返す |
| 実務経験がないからと諦める | 業界ニュースから「疑似経験」を作る |
| 論文の添削をしない | 誰かに見てもらう（講座利用推奨） |

## 最後に

> **「総合技術監理部門は、技術士資格の『統括者』たる資質を問う試験です。」**

単なる知識の多さではなく、複数の管理技術を**バランスよく、統合的に理解し、実務で適用できるか**が評価されます。

本サイトの各分野の解説と過去問分析を活用し、あなたの実務経験を「経営視点」に昇華させることが、合格への最短路です。
