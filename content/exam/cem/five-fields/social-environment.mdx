# 社会環境との調和（Social and Environmental Coordination）

## 概要

プロジェクト・事業が **社会・環境に与える影響を最小化** し、地域社会との良好な関係を構築する管理技術です。

**出題の傾向:**
- 環境法規 45%
- サステナビリティ・SDGs 35%
- 社会コンプライアンス・地域対応 20%

---

## 重要キーワード（35個）

### 環境規制（15個）

```
01. 大気汚染防止法      排ガス・粉塵の規制基準
02. 水質汚濁防止法      工事排水、有害物質の規制
03. 廃棄物処理法        建設廃棄物の分別・処理
04. 特別管理産業廃棄物  アスベスト、PCB等
05. 騒音規制法          工事騒音の許可基準
06. 振動規制法          工事振動の制限時間
07. 土壌汚染対策法      掘削工事での汚染土壌対応
08. フロン回収・破壊法  冷媒処理
09. グリーン購入法      環境配慮製品の優先購入
10. 建設リサイクル法    分別解体の義務化
11. 森林保護法          樹木伐採・森林破壊規制
12. 文化財保護法        遺跡発掘時の届出
13. 労働安全衛生法      作業環境測定（騒音・粉塵）
14. 自動車排出ガス規制  工事用機械の排ガス基準
15. エコマーク/ISO 14001 環境マネジメント認証
```

### サステナビリティ・SDGs（12個）

```
16. カーボンニュートラル     2050年までのCO2排出ゼロ目標
17. 脱炭素化施策            再生可能エネルギー、電動化
18. LCA（ライフサイクル分析） 建設～廃棄までのCO2総量評価
19. サーキュラーエコノミー    資源循環・廃棄物削減
20. 生物多様性保全           レッドリスト対応、生態系復元
21. 水資源管理              雨水活用、節水対策
22. サステナブル建設材料     FSC木材、リサイクル材
23. グリーンビルディング    省エネ建物の設計・認証
24. SDGs 17個目標対応       その他の社会課題
25. ESG投資                環境・社会・ガバナンスで企業評価
26. TCF（気候関連財務情報開示） リスク情報の透明化
27. RE100加入              100%再生可能エネルギー宣言
```

### 社会コンプライアンス・地域対応（8個）

```
28. 環境アセスメント      大規模プロジェクトの事前評価
29. 社会的影響評価（SIA） 地域コミュニティへの影響分析
30. ステークホルダー対話   地域住民・関係者との協議
31. 地域雇用・発注        地元企業の活用による地域貢献
32. 紛争予防              工事に伴う苦情・トラブル対策
33. 人権デューディリジェンス 児童労働・強制労働防止
34. 情報開示・説明責任     工事内容の事前告知
35. 社会貢献活動（CSR）    地域との共生事業
```

## 環境アセスメント（EIA）の流れ

```
【計画段階】 
  ↓
【環境影響調査】
  ├─ 大気汚染、騒音・振動
  ├─ 水質、土壌汚染
  ├─ 動物・植物、生態系
  ├─ 景観、廃棄物
  └─ 人口・地域社会

  ↓
【評価・予測】
  └─ 負の影響を定量化

  ↓
【対策検討】
  └─ 回避・低減・代償措置

  ↓
【環境影響評価書】作成
  
  ↓
【公開・住民意見募集】
  ↓
【最終評価】→ 承認 or 修正
```

## 2030・2050への脱炭素化ロードマップ

```
【2030年目標】
□ CO2排出量 46%削減（2013年比）
□ 建設業界：機械の電動化進行
□ 再生可能エネルギー 36～38%を供給

【2050年目標】
□ カーボンニュートラル（排出ゼロ）
□ 100%再生可能エネルギー達成
□ 水素・燃料電池が主流化

【建設業での対応】
1. 機械の電動化・水素化
2. 建設廃棄物のゼロエミッション
3. サプライチェーンの脱炭素化
4. 建設材料の低炭素化
5. 再生可能エネルギーの導入
```

## 過去問分析

### パターン1: 法的基準の正誤判定

```
【例】
「建設工事の騒音が80dB（昼間）を超える場合、
 騒音規制法に基づき事前届出が必要である」

→ ✅ 正解（多くの自治体で要届出）
```

### パターン2: 社会環境との調和戦略

```
【例】
「山間地でのダム建設プロジェクトにおいて、
 社会環境との調和の観点から、
 どのような対策を講じるべきか述べよ」

→ 回答例：
  1. 環境アセスメント（猛禽類保全、植生保護）
  2. 地域住民との協議（補償・雇用創出）
  3. 水資源管理（下流河川への影響軽減）
  4. 景観保全（ダム貯水池の親水化）
  5. 廃棄物処理（掘削ズリの活用）
```

### パターン3: SDGs・脱炭素化への対応

```
【例】
「建設業界がカーボンニュートラル達成に向けて、
 総合技術管理の視点から実装すべき施策を述べよ」

→ 回答例：
  ・電動・水素重機の導入率50%以上
  ・工事の施工計画段階でのLCA実施
  ・再生可能エネルギー100%活用の目標設定
  ・ゼロエミッション工事の推進
  ・サプライチェーンの脱炭素化推進
```

## 実務での社会環境管理

```
【工事計画段階】
□ 環境アセスメント実施
□ ステークホルダー分析・対話計画
□ 地域への事前説明会開催

【工事実施段階】
□ 環境パトロール（毎週）
□ 騒音・振動・粉塵の測定
□ 工事排水の水質測定
□ 近隣住民からの苦情対応

【工事完了段階】
□ 環境復旧確認
□ 地域への報告会開催
□ 社会貢献活動の実施
```

## 最新トレンド（2024-2025年）

### 1. 脱炭素化の加速

```
□ 機械の電動化：ショベル、ダンプ、クレーン
□ 建設廃棄物のゼロエミッション達成
□ LCAに基づく材料選定
```

### 2. 生物多様性保全

```
□ 希少種保護（猛禽類、カワウソ等）
□ 生態系復元工（ビオトープ）
□ レッドリスト掲載種への対応
```

### 3. 地域共生・スマートシティ

```
□ 雨水活用・節水施設の導入
□ 地元企業・労働者の活用
□ 地域防災拠点としての機能
```

## 出題のポイント

```
✅ 単なる「環境規制対応」ではなく「ビジネス機会」として語る
✅ 脱炭素化＝ コスト削減・企業価値向上と説明
✅ 地域社会との「対立」から「共生」へのシフト
✅ 実務的な測定値・基準値を引用
❌ 「環境破壊は悪」という単純な結論
❌ 経済性とのトレードオフを前提とする
```
