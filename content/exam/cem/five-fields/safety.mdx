# 安全管理（Safety Management）

## 概要

安全管理は、**プロジェクト・組織における人的災害、設備事故、業務中断の予防・最小化**を目的とした管理技術です。

**出題の傾向:**
- 法定知識（労働安全衛生法）40%
- 実務的なリスク対策 50%
- 最新トレンド（パンデミック対応、メンタルヘルス）10%

---

## 重要キーワード（40個）

### 法制度・規格（15個）

```
01. 労働安全衛生法      基本法、罰則規定
02. 労働衛生機関        安全委員会、衛生委員会の必置基準
03. リスクアセスメント   四段階法（危険源の特定→リスク評価→対策→確認）
04. OSHA（米国）        国際標準との比較
05. ISO 45001          労働衛生安全マネジメントシステム
06. PDCA (Plan-Do-Check-Act)
07. 重大インシデント    労災で死傷者3名以上、または重症者
08. 安全衛生教育        新入者教育、再教育の頻度
09. リスクレベル判定    危険度×発生頻度 で優先度付け
10. ハザード vs リスク   違いを理解（ハザード=危険源、リスク=危険性×発生確率）
11. 危険予知訓練（KYT）   4ラウンド法
12. ニアミス報告        未発生の危機を把握
13. 事故報告義務        どんな事故を誰に報告するか
14. 安全衛生委員会      月1回以上の開催
15. 総括安全衛生管理者   大企業の必置人事
```

### 実務的なリスク対策（15個）

```
16. 個人防具（PPE）      装着義務、点検・廃棄管理
17. 機械安全            ガード、インターロック、防止装置
18. 転倒・転落対策       足場、ハーネス、滑り止め
19. 切断・挟まれ事故     工具管理、機械の安全装置
20. 重機操作の安全       オペレーター資格、誘導員配置
21. 掘削工事の安全       土留支保工、酸素欠乏対応
22. 高所作業           はしご・脚立の安全基準
23. 化学物質管理        MSDS（安全データシート）確認
24. 騒音・振動対策       聴覚保護具、マスク、定期検査
25. 暑熱対策           WBGT（湿球黒球温度）、休憩・水分補給
26. 健康診断           定期健康診断、特殊健診（特定有害業務）
27. メンタルヘルス      ストレスチェック、相談体制
28. 過労死・過労運転    長時間労働の管理・監視
29. 労災認定           業務関連性の判断基準
30. ヒューマンエラー対策  標準化・チェックリスト・多重防止
```

### BCP・重大リスク対応（10個）

```
31. 事業継続計画（BCP）   自然災害、パンデミック、テロ対応
32. 復旧優先度の決定      生命安全 > 周辺被害 > 事業継続
33. 代替供給業者の確保    サプライチェーン途絶対策
34. 危機管理本部の設置    意思決定の迅速化
35. 緊急連絡網          各層に周知・定期訓練
36. 情報セキュリティ侵害   個人情報流出、システムダウン
37. テロ・犯罪予防       施設警備、従業員教育
38. 自然災害対策         地震・洪水・台風の事前対応
39. パンデミック対応     在宅勤務体制、感染者隔離
40. 保険・補償制度       災害保険、社会保険
```

## 4ラウンド法（危険予知訓練 KYT）

建設現場で最も重要な安全技法です。試験でもよく出ます。

```
【第1ラウンド】
「現在の状況は？」
→ イラスト・写真から「ありのまま」を描写
　（客観的観察）

【第2ラウンド】
「何が危ないのか？」
→ 危険源・ハザードを洗い出す
　（5-6個列挙）

【第3ラウンド】
「どうなったら大変か？」
→ 最悪シナリオ・重大度を想像
　（死傷の可能性）

【第4ラウンド】
「自分たちはどうするか？」
→ 具体的な行動・対策を決める
　（現場で実行可能なレベル）

【成果】
□ 危険感受性を高める
□ チームの一体感向上
□ 事故予防の実績向上
```

## リスクアセスメントの4段階

```
【段階1】危険源の特定
　例: 掘削工事の足場→転倒の危険源
　
【段階2】リスク評価
　重大度（Severity）: ① 軽傷 ② 重傷 ③ 死傷
　発生頻度（Frequency）: ① 年1回未満 ② 月1回 ③ 週1回
　リスク = 重大度 × 発生頻度
　
【段階3】対策の立案・実施
　優先度（リスクレベル）が高い順に対策
　
【段階4】有効性の確認
　対策後のリスク再評価
　リスク削減が達成されたか
```

## 過去問分析（よく出るパターン）

### パターン1: 法的要件の正誤判定

```
【例】
「労働安全衛生委員会は、安全衛生に関する重要事項を
協議するため、月1回以上開催することが義務付けられている」

→ ✅ 正解
```

### パターン2: リスク対策の優先順位

```
【例】
掘削工事で以下3つの危険源がある：
① 土砂崩落（最悪死傷、年1回程度の発生可能性）
② 重機接触（軽傷～重傷、月1回程度の発生可能性）
③ 転倒・転落（軽傷、週数回の発生可能性）

対策順序は？
→ ① > ② > ③
   （死傷可能性が最重要、発生頻度は二次的）
```

### パターン3: 実務対策の提案

```
【例】
「施工現場でのヒューマンエラーが多発しているとき、
 総合技術管理の視点から対策を述べよ」

→ 回答例：
  ・標準作業手順書（SOP）の整備
  ・チェックリスト化による確認の多重化
  ・朝礼での危険予知訓練（KYT）実施
  ・経験の少ない技能者への教育強化
  ・疲労管理（勤務シフト、休憩時間の最適化）
  
  → 法令対応ではなく、「経営層の判断」を示す
```

## 実務での安全管理

### 現場レベル

```
□ 安全パトロール（毎週）
□ 危険予知訓練 KYT（毎日朝礼）
□ ニアミス報告システム
□ 安全教育・講習（定期的）
□ 個人防具の配給・管理
□ 工事現場の定期点検
```

### 組織レベル

```
□ 安全衛生委員会の運営（月1回）
□ リスクアセスメント実施（年1回以上）
□ 健康診断・ストレスチェック
□ インシデント分析・水平展開
□ 安全衛生目標の設定・進捗管理
□ 事業継続計画（BCP）の策定・訓練
```

### 経営レベル

```
□ 安全衛生戦略の策定
□ 予算配分（安全投資の優先度付け）
□ 取引先・協力業者の安全水準管理
□ 労災発生時の対応体制
□ ISO 45001等の認証取得検討
□ 社会への安全文化発信（CSR）
```

## 最新トレンド（2024-2025年）

### 1. パンデミック対応（新常識化）

```
□ 在宅勤務環境の整備
□ 感染者隔離プロトコル
□ 衛生用品の備蓄
□ テレワーク時の労災判定
```

### 2. メンタルヘルス対策

```
□ ストレスチェック（年1回義務化）
□ 心理カウンセリング体制
□ パワハラ・セクハラ防止
□ 過労死・過労運転の防止
```

### 3. 高齢化対応

```
□ 高齢従業員の配置転換
□ 体力的負荷の軽減（機械化）
□ 経験知の継承（技能伝承）
```

### 4. DX推進に伴う新リスク

```
□ サイバーセキュリティ脅威
□ AI導入時の責任分界点
□ デジタル格差による事故リスク
```

## 出題のポイント

```
✅ 「なぜ安全が重要か」を経営層の視点で説明
✅ 単なる「危険排除」ではなく「リスク最小化」を論ずる
✅ 法定基準だけでなく、業界慣例・最新動向も言及
✅ 実務的な実例を挙げて説明
❌ 「絶対安全」という理想論を言わない
❌ 安全=コスト増 という対立構図を示さない（実は両立可能）
```
