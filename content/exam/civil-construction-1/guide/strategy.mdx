# 出題傾向と得点戦略 — 1級土木施工管理技士 第1次検定

:::tip 合格ライン
第1次検定の合格基準は **全体の60%以上**（96問中58問正解が目安）。選択問題をうまく活用すれば、苦手分野を避けつつ合格ラインに到達できます。
:::

## 1. 試験の構成

### 問題A（61問出題 → 30問選択解答）

| 分野 | 出題数 | 選択数 | 内容 |
|---|:---:|:---:|---|
| **土木一般** | 15問 | 12問 | 土工（5問）+ コンクリート（5問）+ 基礎工（5問） |
| **専門土木** | 34問 | 10問 | 鋼構造・RC・河川・砂防・道路・舗装・港湾・鉄道・上下水道 等 |
| **法規** | 12問 | 8問 | 労安法・建設業法・道路法・河川法・建築基準法 等 |

### 問題B（35問出題 → 全問必須）

| 分野 | 出題数 | 選択数 | 内容 |
|---|:---:|:---:|---|
| **施工管理** | 35問 | **35問（全問必須）** | 施工計画・工程管理・安全管理・品質管理・環境保全 |

### 解答数の合計

| | 出題数 | 解答数 |
|---|:---:|:---:|
| 問題A | 61問 | 30問 |
| 問題B | 35問 | 35問 |
| **合計** | **96問** | **65問** |

65問 × 60% = **39問以上の正解** が合格の目安です。
:::

## 3. 得点戦略

### 3.1 合格までの得点シミュレーション

| 分野 | 解答数 | 目標正解率 | 目標正解数 |
|---|:---:|:---:|:---:|
| 土木一般 | 12問 | 75% | **9問** |
| 専門土木 | 10問 | 70% | **7問** |
| 法規 | 8問 | 75% | **6問** |
| 施工管理（問題B） | 35問 | 60% | **21問** |
| **合計** | **65問** | **66%** | **43問** |

:::tip
上記のシミュレーションでは **43問正解（66%）** となり、合格ライン39問を **4問の余裕** をもってクリアできます。
:::

### 3.2 選択問題の攻め方

#### 土木一般（15問→12問）: 3問捨てられる

- 土工・コンクリート・基礎工はいずれも **毎年同じテーマ** が出るため、過去問の反復で高得点を狙える
- 苦手な分野の3問を飛ばして、得意な12問に集中する
- **推奨**: 全15問に目を通し、自信のある12問を選ぶ

#### 専門土木（34問→10問）: 24問も捨てられる

- **最大のチャンス**。34問中10問だけ選べばよい
- 得意分野を **3〜4分野** に絞り、その中から確実に10問を選ぶ
- 未経験の分野（港湾・鉄道など）は最初から勉強しないという割り切りも有効

**おすすめの選択パターン:**

| パターン | 選択分野 | 対象問題数 | 選択数 |
|---|---|:---:|:---:|
| 建設系 | 鋼構造 + コンクリート構造 + 道路・舗装 + 上下水道 | 約12〜15問 | 10問 |
| 河川系 | 河川 + 砂防 + 道路・舗装 + 鋼構造 | 約10〜14問 | 10問 |
| 都市基盤系 | 道路・舗装 + 上下水道 + 鉄道 + コンクリート構造 | 約10〜14問 | 10問 |

#### 法規（12問→8問）: 4問捨てられる

- **労安法と建設業法で5〜6問** を確保できれば、残りは2〜3問だけ
- 道路法・河川法は条文がシンプルで得点しやすい
- 建築基準法は実務経験がないと難しい → 捨て候補

### 3.3 問題Bの攻略

問題Bは **全35問必須** のため、捨て分野を作れません。

- **安全管理**（8〜10問）が最大の出題数 → 重点的に学習
- **工程管理** のネットワーク工程表は計算問題が出るため、解法パターンを習得する
- **品質管理** の統計手法（ヒストグラム、管理図）は理解すれば確実に得点できる

## 4. 分野別 学習優先度

| 優先度 | 分野 | 理由 |
|---|---|---|
| ★★★ | **土木一般（土工・コンクリート・基礎工）** | 毎年同じテーマ。過去問の反復で確実に得点可能 |
| ★★★ | **施工管理（安全管理）** | 問題B最大の出題数。暗記で対応可能な問題が多い |
| ★★☆ | **施工管理（工程管理・品質管理）** | 計算問題あり。パターンを習得すれば安定 |
| ★★☆ | **法規（労安法・建設業法）** | 出題パターンが固定。条文暗記が有効 |
| ★★☆ | **専門土木（得意分野3〜4つ）** | 自分の実務経験に合う分野を深堀り |
| ★☆☆ | **施工管理（施工計画・環境保全）** | 出題数が少ないが必須。基本事項は押さえる |
| ★☆☆ | **専門土木（苦手分野）** | 34問中10問選択なので、苦手分野は捨ててよい |

:::note 学習の進め方
1. まず **過去問を1年分** 通して解き、自分の得意・苦手を把握する
2. **土木一般 → 施工管理（問題B）→ 法規 → 専門土木** の順に学習する
3. 過去問は **最低3周** 繰り返す（同じ問題が表現を変えて繰り返し出題される）
:::
