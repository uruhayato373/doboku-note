# はじめに

本書は、技術士第二次試験 建設部門「施工計画、施工設備及び積算」の令和7年度分として、必須科目I、選択科目II-1・II-2・III の模範解答を、元公務員（発注者）として工事の発注・監督に携わった経験を持つ技術士（建設部門・総合技術監理部門）の立場からまとめた一冊です。この科目の模範解答を年度ごとに分けたシリーズの1年度分にあたり、この一冊だけで令和7年度の出題を通して確認できます。

収録しているのは次の4本です。

- 必須科目I：I-1（持続可能な建設業の実現）、I-2（経済成長の実現を目的とする社会資本整備）の両問題
- 選択科目II-1：II-1-1〜II-1-4 の全4設問
- 選択科目II-2：II-2-1、II-2-2 の両設問
- 選択科目III：III-1、III-2 の両問題

本番ではそれぞれ1問（設問）を選んで解答しますが、本書は選ばなかった側にも目を通せるよう、出題されたすべてを収めています。各記事には、試験問題の全文、設問ごとの論述方針、フル模範解答、答案を見直すための要点をそろえました。模範解答は令和8年度の改訂コンピテンシーに対応した書き方にしています。

**本書の使い方**

1. まず試験問題の全文を読み、自分ならどう構成するかを数分間考える
2. 「設問構成と論述方針」で、問われている論点と論述の骨子を確認し、自分の構成案と照らし合わせる
3. フル模範解答を読み、論述の順序・専門用語の使い方・字数の配分を確認する
4. 各記事の末尾にある要点で、答案のどこを見直すとよいかを確認する
5. 余裕があれば、骨子だけを見て自分の言葉で答案を書き直す

**対象読者**

- 令和7年度の設問に取り組み、答案の書き方を確かめたい方
- 「苦情内容を複数想定する」形式の利害調整や、PDCA の書き分けに悩んでいる方
- 発注者・現場責任者の視点をどう答案に反映すればよいか掴めていない方

なお、本書に掲載する試験問題は公益社団法人 日本技術士会が公表した過去の試験問題に基づく引用であり、模範解答は独自に作成したオリジナルの論述です。

# 令和7年度の出題傾向

## 必須科目I

I-1 は、令和6年6月の担い手3法（建設業法・公共工事の入札及び契約の適正化の促進に関する法律・公共工事の品質確保の促進に関する法律）の改正を踏まえ、建設業が社会資本の整備等の担い手・地域の守り手として役割を果たし続けるための技術課題を問いました。I-2 は、第5次社会資本整備重点計画の「経済成長の実現」を目的とする社会資本整備の技術課題を問いました。両問題とも、「技術課題」に構造上・制度上・管理上等の課題（I-2 は制度上の課題）が含まれるとの説明があり、「観点を述べてから技術課題を示す」注記が付いています。(1)〜(4) の4問構成は11の選択科目で共通で、答案用紙は3枚です。

## 選択科目II-1（4設問から1問選択・答案用紙1枚）

- II-1-1：落石対策工の基本的な考え方を目的別に述べ、代表的な工種2つの特徴を説明する（土工構造物）
- II-1-2：工事請負契約書における請負代金額変更の規定であるスライド条項全般の概説と、種別2つの内容（契約・積算）
- II-1-3：建設現場の生産性向上の取組「i-Construction2.0」の目指す姿の概説と、取組事項2つの具体的内容（DX）
- II-1-4：コンクリート構造物の耐久性の回復・向上を目的とした主な補修工法の種類の概説と、補修工法を選定する際に考慮すべき事項2つ（コンクリート・維持管理）

## 選択科目II-2（2設問から1問選択・答案用紙2枚）

II-2-1 は、川幅約250mの河川を横断する橋梁の新設工事で、河川内の下部工4基はニューマチックケーソン基礎、上部工は張り出し施工、施工時期は非出水期に限られる場面でした。II-2-2 は、山岳トンネル建設に伴う掘削ずり（礫質土、約50万m3）を、坑口から約10km離れた谷地形（特定盛土等規制区域）の土捨場へ運搬して盛土する場面でした。

小問の形は両設問で共通しています。

1. 仮設形式（II-2-1）または盛土の安定性確保の対策（II-2-2）を2つ挙げて概要を述べ、本工事の特性を踏まえて採用するための条件を述べる
2. 沈設管理（II-2-1）または施工中の盛土の安定性管理（II-2-2）について、PDCAサイクルの計画段階（P）で考慮すべき事項と、検証段階（C）・是正段階（A）の具体的方策を述べる（是正段階の記述に、設問文の条件が付いています）
3. 運搬経路周辺の住民から複数の苦情が寄せられた場面で、苦情内容を複数想定し、地元の理解と工事の推進を両立させる対策案を苦情内容ごとに立案して、利害をどう調整するか説明する（運搬経路は変更できない前提）

(3) が、苦情内容の想定から対策案までを求める個別具体的な形式になっている点が、令和7年度の特徴です。

## 選択科目III（2問題から1問選択・答案用紙3枚）

III-1 は、小規模な市区町村における「地域インフラ群再生戦略マネジメント」の計画策定及び実施について、自分の選択科目に関わる技術課題を問いました。III-2 は、担い手3法の改正を踏まえ、発注者の積算や応札者の入札価格に関わる技術課題を問いました。どちらも「観点を述べてから課題を示す」注記が付き、III-1 の (2) と III-2 の (2) は専門技術用語を交えて示すよう求められています。(3) は、解決策の実行によって生じる波及効果と懸念事項への対応、または新たに浮かび上がる将来的な懸念事項への対策を問う形です。

# 学習ガイド

## 科目ごとに答案の型を決める

**II-1（答案用紙1枚）**
前段で概説、後段で指定された数の工種・取組・考慮事項を、見出しを分けて書きます。II-1-2 のように制度の種別を問う設問は、種別ごとに内容を対比できるように書きます。

**II-2（答案用紙2枚）**
(1) は、2つの案それぞれについて、採用するための条件を工事の特性に結びつけて書きます。(2) の PDCA は、段階ごとに役割を分けます。(3) は、想定する苦情を先に列記し、苦情ごとに対策案と調整方法を対応させます。

**III（答案用紙3枚）**
III-1 は「あなたの選択科目に関わる技術課題」という指定があるため、施工計画、施工設備及び積算の分野の課題として書きます。観点は重ならないよう分け、最重要課題の選定理由を示します。

**必須科目I（答案用紙3枚）**
「技術課題」に制度上などの課題が含まれる旨の説明を、課題の抽出に活かします。

## 時間配分の考え方

答案用紙の枚数は、II-1 が1枚、II-2 が2枚、III が3枚です。この比率を目安に、構成を考える時間（骨子の作成）を各設問の解答時間の2〜3割程度確保すると、書き始めてからの修正を減らせます。試験時間の正確な配分は、日本技術士会が年度ごとに公表する実施要項で確認してください。

## 注意点

- 設問文にある前提（運搬経路は変更できない等）に反する対策を書かないこと
- 苦情内容は具体的に想定し、対策案を内容ごとに分けて書くこと
- 法令・制度の数字や年月日は、日本技術士会や所管官庁の公表資料で正確に確認すること
