# はじめに

本書は、1級土木施工管理技術検定 第2次検定の問題1（施工経験記述）で問われる5つの管理項目、品質管理・安全管理・工程管理・施工計画・環境対策について、それぞれをテーマ別の章に分けて完成答案をまとめた演習書です。令和3〜7年度の過去問を年度別に読む構成とは異なり、本書は管理項目ごとに章を立て、同じテーマの中で工種の異なる複数の完成答案を並べています。自分が苦手な管理項目、あるいはまだ準備できていない管理項目を選んで集中的に演習したい場合に使う本です。

各章は、令和6年度以降の現行形式（2テーマ必答・各2項目）と、令和5年度以前の旧形式（3項目）の両方の書き方に対応しています。本番でどちらの形式が出題されても、あるいは他のテーマと組み合わせて出題されても対応できるよう、章の中で両形式の答案構成を示しています。

著者は、技術士（総合技術監理部門）を持つ元・地方自治体の土木職（発注者）です。1級・2級土木施工管理技士にも自分で合格しており、発注者として施工計画書や工事成績評定の書類を審査してきた立場から、各テーマの完成答案を作成しています。

1級土木施工管理技術検定の施工経験記述は、品質管理・安全管理・工程管理・施工計画・環境対策の5つの管理項目から出題されます。5つのうちどれが出題されても、あるいは令和6年度以降のように2つのテーマが組み合わされて出題されても対応できるよう、まずは1つずつのテーマを確実に仕上げておくことが土台になります。本書はその土台づくりに使う1冊です。

施工経験記述は、受験者自身が経験した工事について記述する問題です。経験していない工事を記述したことが判明した場合は失格となります。本書の完成答案は、そのまま書き写して使うためのものではありません。答案の構成・表現・具体性の水準を確かめ、自分が実際に経験した工事の内容に置き換えて使うための記入例（テンプレート）です。答案中の工事名・数値等は記入例として設定したもので、実在の工事を示すものではありません。

# 本書の使い方

各章は、そのテーマで採点者が見るポイントの整理から始まり、続けて複数の完成答案（工種別）、自分の現場への置換ガイド、減点される典型的なNG答案とその直し方、採点者視点のチェックポイントという順で構成しています。まず「採点者が見るポイント」を読み、そのテーマで何が評価されるのかを把握したうえで、自分の経験に近い工種の完成答案を選んで読むという順序をおすすめします。

自分の現場に置き換える手順は次のとおりです。

1. 各章に収録した複数の完成答案の中から、自分が経験した工事に工種・規模が近いものを1つ選びます。
2. 答案中の工事名・発注者名・工期・数値等（記入例として空欄や仮の値になっている箇所）を、自分の現場の実際の内容に差し替えます。
3. NG答案の例と見比べて、自分の答案が同じ書き方の癖（抽象的な対策、理由の欠落、数値の欠落など）に陥っていないかを確認します。

本番でどのテーマの組合せが出題されても対応できるよう、令和6年度以降の2テーマ必答形式では、準備した管理項目ともう一方の管理項目を組み合わせて書く練習をしておくことをおすすめします。5管理のうちどの組合せが出ても対応したい場合は、同シリーズの「2テーマ組合せ大全」編とあわせて使うと網羅性が高まります。

# 5管理に共通する答案の骨格

品質・安全・工程・施工計画・環境対策の5つの管理項目は、それぞれ着眼点は異なりますが、評価される答案の骨格には共通する型があります。本書の各章末に整理した「採点者が見るポイント」を横断すると、次の4点が共通して求められていることがわかります。

第1に、現場条件から生じる課題を1つに具体的に絞ることです。品質管理であれば規格値・管理基準を脅かす現場条件、安全管理であれば防止すべき災害、環境対策であれば周辺の生活環境・自然環境への影響というように、抽象的な複数の課題を並べるのではなく、その工事に固有の課題を1つに絞り込んで記述することが評価につながります。

第2に、検討した対策に理由や根拠を明記することです。安全管理であれば労働安全衛生法など関係法令・基準、環境対策であれば騒音規制法・水質汚濁防止法・建設リサイクル法などの規制基準、施工計画であれば複数案を比較検討した選定理由というように、「なぜその対策を選んだか」を答案に書くことが求められます。

第3に、対応処置に数値・設備名・試験方法など具体的な情報を入れることです。品質管理の試験方法（載荷試験・RI・スランプ測定等）、安全管理の設備名や有資格者の選任、工程管理の施工量・歩掛・機械の組合せ、環境対策の測定値や監視方法のように、具体的な固有名詞や数値が答案の説得力を左右します。

第4に、答案を客観的な指標や結果で締めくくることです。「所定の品質を確保した」「無事故で完了した」「工期内に完了した」「基準を満たし苦情なく完了した」というように、検討・処置の結果として何が達成されたかを明示して答案を終えることが、いずれのテーマでも共通しています。

各章の「NG答案から合格答案への直し方」は、この4点のどこが欠けると減点されるかを具体的に示す構成にしています。課題を絞らずに複数の懸念を並べただけの答案、対策の理由を書かずに実施内容だけを並べた答案、数値や固有名詞のない抽象的な処置、結果を書かずに終わる答案は、いずれも採点者から見て「何を、なぜ、どう解決したか」が伝わりにくく、評価が下がりやすい書き方です。自分の答案を見直すときは、この4点のどれが欠けていないかを1つずつ確認してください。

# 収録内容

- 第1章　品質管理　完成答案集
  - 場所打ち杭基礎工事、高盛土工事を題材に、規格値・管理基準の明示と試験・測定方法を軸にした完成答案を収録
- 第2章　安全管理　完成答案集
  - シールドトンネル工事、橋梁上部工架設工事、大規模盛土工事を題材に、防止すべき災害を1つに絞った完成答案を収録
- 第3章　工程管理　完成答案集
  - 大規模造成工事、山岳トンネル工事、連続立体交差工事を題材に、遅延要因の予測とクリティカルパス管理を軸にした完成答案を収録
- 第4章　施工計画　完成答案集
  - 既設構造物に近接する施工計画、河川の仮締切、高速道路拡幅を題材に、着手前の事前検討・比較検討を軸にした完成答案を収録
- 第5章　環境対策　完成答案集
  - 市街地工事の騒音振動、河川近接工事の濁水、丘陵地工事の建設発生土を題材に、発生源での具体的対策を軸にした完成答案を収録

各章とも、採点者が見るポイント、工種別の完成答案、自分の現場への置換ガイド、NG答案から合格答案への直し方、採点者視点のチェックポイントという同じ構成で統一しています。年度別の実問題で演習したい場合は同シリーズの「過去問模範答案集」編、5管理を2テーマの組合せで演習したい場合は「2テーマ組合せ大全」編とあわせて使うと、テーマ別・年度別・組合せ別の3方向から施工経験記述を仕上げられます。
