# はじめに

本書は、技術士第二次試験 建設部門 選択科目「電力土木」の令和6年度について、必須科目I、選択科目II-1・II-2・IIIの4区分の模範解答を収録した一冊です。令和3〜8年度を年度ごとに分けた全6巻のシリーズのうち、令和6年度の巻にあたります。

各章の模範解答は、令和8年度に改訂された技術士のコンピテンシー（求められる資質能力）の観点も踏まえて書き直したもので、本文中に「改訂コンピテンシーに対応」と記した箇所があります。

収録するのは、その年に実際に出題された設問のすべてです。必須科目IはI-1・I-2の2問、II-1は4問、II-2は2問、IIIは2問で、合計10問になります。本番では各区分から1問を選んで解答しますが、本書は選ばなかった側の設問も含めて掲載しています。どの設問を選んでも、答案の骨格をたどれるようにするためです。

模範解答は、電力関連の工事との調整に関わった元・地方自治体の土木職（発注者）の視点で書いています。設計図書の安全性照査項目が施設の特性に対応して網羅されているかを確認する立場、施工計画書の品質管理項目を審査する立場、点検・観測データを補修や評価の根拠として活用する立場など、発注者ならではの着眼点を各設問の解答に反映しました。

この「はじめに」を含む出題傾向の整理と学習ガイドは、本書のために新たに書き下ろしたものです。

使い方としては、まず各設問の「論述骨子」で答案の骨格を把握し、次にフル模範解答で文章化の水準を確認し、最後に各設問の末尾に添えた要点で自分の答案を見直す、という順序をおすすめします。答案そのものを覚えるのではなく、論理の組み立て方と着眼点を、自分の実務経験に置き換えて答案を作る練習に使ってください。

# 令和6年度 選択科目「電力土木」の出題傾向

本章は、本書に収録した令和6年度の全10問の問題文を読み込んで整理したものです。一般論や推測ではなく、問題文に書かれた設問の条件に即して書いています。

## 必須科目I

I-1は、第三次国土形成計画の拠点連結型国土を踏まえ、全国的なネットワークの形成と地域内ネットワークの強化を目指す社会資本整備の課題を問う設問です。I-2は、令和6年能登半島地震をはじめとする大規模災害を背景に、発災後の復旧・復興をDXで迅速かつ効率的に進めるための課題を問う設問です。

この年の必須科目Iの特徴は、2問とも「投入できる人員や予算に限りがあることを前提に」課題を抽出する条件が付いていること、そして(1)に「解答の際には必ず観点を述べてから課題を示せ」という注記が付いていることです。I-1の(3)は波及効果と懸念事項への対応策、I-2の(3)は新たに生じうるリスクと対策を問い、(4)は両問とも技術者としての倫理と社会の持続性の観点です。必須科目Iの構成は電力土木以外の選択科目と共通なので、本書では答案の型を確認する位置づけで読んでください。

## 選択科目II-1（専門知識、答案用紙1枚・約600字、4設問中1設問を選択）

| 設問 | 主題 |
|---|---|
| II-1-1 | 原子炉施設の耐震設計（基礎地盤のすべり、基礎の支持力、基礎底面の傾斜のうち1つ以上） |
| II-1-2 | 能登半島地震を踏まえた液状化（メカニズム、地盤側の防止対策、施設側の許容対策） |
| II-1-3 | マスコンクリート（対象施設、温度ひび割れの発生要因、照査概要、複数の対策） |
| II-1-4 | 大規模地震に対するダム耐震性能照査指針（案）（耐震性能、地震動の設定方法、照査方法） |

令和6年度のII-1は、地震と地盤に関わる設問が中心です。II-1-1は基礎地盤の安定性評価、II-1-2は液状化、II-1-4はダムの耐震性能照査と、4問のうち3問が地震・地盤を題材にしています。残るII-1-3はマスコンクリートの温度ひび割れで、施工段階の品質確保を問う設問です。

設問の条件では、II-1-1が審査ガイドに示された3つの評価項目から「1つ以上」を選んで述べる形式であることに注意が必要です。3つすべてを浅く書くのか、1つを深く書くのかを、あらかじめ決めておく必要があります。II-1-2は、液状化を防止する「地盤側」の対策と、液状化を許容する「施設側」の対策という、考え方の異なる2系統の対策をそれぞれ述べる構成です。

## 選択科目II-2（応用能力、答案用紙2枚・約1,200字、2設問中1設問を選択）

- II-2-1：既設水力発電の増電を目的とした、洪水に対処する必要があるダムの降雨・流入量予測に係る運用業務。ダムの与条件（基本諸元、水文条件、水系における役割等）を述べ、検討すべき事項を説明します。
- II-2-2：急傾斜地に近接する、または盛土上に設置された電力土木施設の斜面崩壊。巡視者から崩壊の予兆となる事象の報告を受けた場面を想定し、崩壊のメカニズムと検討事項を述べます。

どちらも、(1)検討事項、(2)業務の手順、(3)関係者の列挙と調整方策、の3小問構成で、令和6年度は(3)で関係者を「列挙」することが明示されています。調整方策だけでなく、誰と調整するのかを先に整理して書く必要があります。II-2-2は(2)で、第一報を受けた直後の応急措置と、恒久対策の立案までの手順を、それぞれ具体的に列挙するよう求めており、時間軸の異なる2つの手順を書き分ける構成になっています。

## 選択科目III（課題遂行能力、答案用紙3枚・約1,800字、2問題中1問題を選択）

- III-1：再生可能エネルギーの主力電源化。我が国の導入状況と2030年度の目標を述べたうえで、水力を除く電源を1つ挙げ、拡大に向けた課題を3つ抽出します。(2)は「電力土木技術者が主体的に対応すべき課題」を選ぶ点が特徴です。
- III-2：デジタル技術を活用した保全業務の省力化とコストダウン。電力土木施設を1つ挙げ、維持管理の現況を踏まえた将来の管理のあるべき姿を述べたうえで、デジタル技術の導入・展開に向けた課題を3つ抽出します。

2問とも、課題、解決策（専門技術用語を交える）、共通して生じうるリスクという3段構成です。III-1は(1)で数値や目標の言及が求められるため、政策動向の整理が前提になります。III-2は課題の抽出の前に「あるべき姿」を述べる構成なので、現況と将来像の差から課題を導く論理の組み立てが問われます。

# 学習ガイド

## 3区分の位置づけと時間配分

必須科目Iは2時間で答案用紙3枚（約1,800字）を書きます。選択科目はII-1・II-2・IIIを合わせて3時間30分（210分）で、答案用紙6枚（約3,600字）を書きます。文字数の比率で単純に配分するとII-1は35分前後、II-2は70分前後、IIIは105分前後ですが、実際には構成を考える時間に文字数以上の比重がかかります。演習の段階で、各区分の構成メモを何分で作れるかを計っておくことをおすすめします。

## 令和6年度の巻の使い方

1. **II-1は地震・地盤の設問を並べて読む**: 基礎地盤の安定性、液状化、ダムの耐震性能と、評価の対象や考え方は違っても、地震動の設定と照査という流れには共通点があります。骨子を並べて比べると、知識の整理が進みます。
2. **II-2は関係者の列挙を先に作る**: ダム運用なら誰と調整するのか、斜面崩壊なら誰と調整するのかを、答案を書く前に書き出します。調整方策は、列挙した関係者ごとに具体的に書きます。
3. **II-2-2は時間軸を分ける**: 応急措置と恒久対策では、目的も手順も異なります。答案の中で2つが混ざらないよう、見出しや段落で分けて書く練習をします。
4. **IIIと必須科目Iは条件文を読み落とさない**: 「人員や予算に限りがある前提」「観点を先に述べる」「主体的に対応すべき課題」といった条件は、答案の評価対象になります。

## 答案作成上の注意点

II-1は答案用紙1枚の制約の中で、施設名・メカニズム・対策・留意点を過不足なく書く訓練が必要です。II-2とIIIは、設問文の小問構成に忠実に答案を組み立てることが最も重要です。

本書の模範解答に共通する発注者の視点（設計図書の安全性照査項目の網羅性確認、施工計画書の品質管理項目の審査、点検・観測データの活用など）は、受験者それぞれの立場（電力事業者・設計者・施工者）に応じて、自分自身の着眼点に置き換えて使ってください。特定の立場が求められているわけではなく、実務に基づく判断根拠を示すことが大切です。
