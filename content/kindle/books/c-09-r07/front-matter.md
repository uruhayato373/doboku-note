# はじめに

本書は、技術士第二次試験 建設部門 選択科目「電力土木」の令和7年度について、必須科目I、選択科目II-1・II-2・IIIの4区分の模範解答を収録した一冊です。令和3〜8年度を年度ごとに分けた全6巻のシリーズのうち、令和7年度の巻にあたります。

各章の模範解答は、令和8年度に改訂された技術士のコンピテンシー（求められる資質能力）の観点も踏まえて書き直したもので、本文中に「改訂コンピテンシーに対応」と記した箇所があります。

収録するのは、その年に実際に出題された設問のすべてです。必須科目IはI-1・I-2の2問、II-1は4問、II-2は2問、IIIは2問で、合計10問になります。本番では各区分から1問を選んで解答しますが、本書は選ばなかった側の設問も含めて掲載しています。どの設問を選んでも、答案の骨格をたどれるようにするためです。

模範解答は、電力関連の工事との調整に関わった元・地方自治体の土木職（発注者）の視点で書いています。設計図書の安全性照査項目が施設の特性に対応して網羅されているかを確認する立場、施工計画書の品質管理項目を審査する立場、点検・観測データを補修や評価の根拠として活用する立場など、発注者ならではの着眼点を各設問の解答に反映しました。

この「はじめに」を含む出題傾向の整理と学習ガイドは、本書のために新たに書き下ろしたものです。

使い方としては、まず各設問の「論述骨子」で答案の骨格を把握し、次にフル模範解答で文章化の水準を確認し、最後に各設問の末尾に添えた要点で自分の答案を見直す、という順序をおすすめします。答案そのものを覚えるのではなく、論理の組み立て方と着眼点を、自分の実務経験に置き換えて答案を作る練習に使ってください。

# 令和7年度 選択科目「電力土木」の出題傾向

本章は、本書に収録した令和7年度の全10問の問題文を読み込んで整理したものです。一般論や推測ではなく、問題文に書かれた設問の条件に即して書いています。

## 必須科目I

I-1は、担い手3法の改正（令和6年6月）や罰則付き時間外労働規制の適用を背景に、持続可能な建設業の実現に向けた技術課題を問う設問です。I-2は、第5次社会資本整備重点計画の3つの目的のうち「経済成長の実現」を取り上げ、国際競争力の強化や地域産業の振興に必要な社会資本整備の技術課題を問う設問です。

この年の必須科目Iは、2問とも「技術課題」という言葉を使い、構造上・制度上・管理上などの課題も含めてよいと明示している点が特徴です。(1)には「観点を述べてから技術課題を示せ」という注記が付き、(3)はI-1が将来的な懸念事項と対策、I-2が波及効果と懸念事項への対応策、(4)は両問とも倫理と社会の持続性の観点です。必須科目Iの構成は電力土木以外の選択科目と共通なので、本書では答案の型を確認する位置づけで読んでください。

## 選択科目II-1（専門知識、答案用紙1枚・約600字、4設問中1設問を選択）

| 設問 | 主題 |
|---|---|
| II-1-1 | 津波防護施設の設計（施設1つ、荷重組合せと荷重の設定、複数の留意点） |
| II-1-2 | 水力発電の有効落差と損失水頭（導水路で発生する損失水頭、低減のための3つ以上の対応策と留意点） |
| II-1-3 | 塩害環境下の鉄筋コンクリート造施設（性能低下のメカニズム、性能照査方法、配合設計上の留意点） |
| II-1-4 | 鋼構造物の腐食対策（環境、腐食の要因と腐食しやすい箇所、防止対策を1つ） |

令和7年度のII-1は、4問とも施設の設計・照査・劣化の技術を具体的に問う設問です。II-1-1は規程類に示された荷重の考え方、II-1-2は水力発電の出力算定の基本量、II-1-3とII-1-4は劣化と腐食を題材にしており、施設や環境を自分で特定したうえで、メカニズムから対策へと論を進める構成が共通しています。

設問の条件では、II-1-3の「鋼材腐食を発生させないことを条件とする」という限定が重要です。性能照査の考え方はこの条件のもとで書く必要があります。II-1-4は対策を「1つ」に絞って概要と留意点を述べる形式で、複数を並べても加点には直結しません。II-1-2は損失水頭の種類を複数述べたうえで、低減策を3つ以上挙げる二段構えです。

## 選択科目II-2（応用能力、答案用紙2枚・約1,200字、2設問中1設問を選択）

- II-2-1：半世紀を超えて供用される高経年施設の耐震性能評価。電力土木施設は鉄筋コンクリート造に限り、技術的な検討事項を3つ以上述べたうえで、高経年施設で不足しうる評価条件を確認する手順を述べます。
- II-2-2：ダム計測の管理期間が第2期または第3期にあるダムで、地震後の臨時点検で計測値の特異値を確認した場面。漏水量の増加を正しく確認・評価する手順と、安全性に懸念が生じた場合の緊急的対応策を述べます。

令和7年度のII-2は、小問の構成が従来の「検討事項、手順、関係者調整」の型から少し変わっています。II-2-1は(2)で「高経年施設で不足する条件」を挙げてから確認手順を書く点が、II-2-2は(1)で計測の項目・目的・方法を問い、(3)で緊急対応策と関係者調整をまとめて問う点が特徴です。設問ごとに(1)〜(3)の中身を読み、型に当てはめすぎないことが大切です。

## 選択科目III（課題遂行能力、答案用紙3枚・約1,800字、2問題中1問題を選択）

- III-1：電源建設プロジェクトの投資額縮減。電力需要の増加が想定される中、電源の新設や既存電源の更新・リパワリングに伴う調査・計画から建設までの投資額縮減に向けて、電力土木技術者が対応すべき技術課題を抽出します。
- III-2：老朽化電力土木施設の維持管理・更新。埼玉県八潮市の道路陥没事故に触れたうえで、公衆安全への影響が懸念される施設を挙げ、「費用」「労働力」以外の観点から技術課題を抽出します。

2問とも、技術課題、解決策（専門技術用語を交える）、すべての解決策を実行しても共通して生じうるリスクという3段構成です。III-2は、老朽化対策で真っ先に挙がりやすい費用と労働力を観点から外している点が特徴で、それ以外の観点を自分で立てる力が問われます。III-1は事業価値を高めるための投資額縮減という、経済性を軸にした題材を技術課題として整理する設問です。

# 学習ガイド

## 3区分の位置づけと時間配分

必須科目Iは2時間で答案用紙3枚（約1,800字）を書きます。選択科目はII-1・II-2・IIIを合わせて3時間30分（210分）で、答案用紙6枚（約3,600字）を書きます。文字数の比率で単純に配分するとII-1は35分前後、II-2は70分前後、IIIは105分前後ですが、実際には構成を考える時間に文字数以上の比重がかかります。演習の段階で、各区分の構成メモを何分で作れるかを計っておくことをおすすめします。

## 令和7年度の巻の使い方

1. **設問の限定条件に印を付ける**: 令和7年度は「鉄筋コンクリート造に限る」「鋼材腐食を発生させないことを条件とする」「費用・労働力以外」など、答え方を限定する条件が多い年度です。骨子を書く前に、各設問の限定条件を書き出してください。
2. **II-1は「特定して述べる」型を練習する**: 施設や環境を自分で特定し、その特性から劣化の要因や対策を導く流れを、骨子の段階で確認します。
3. **II-2は小問の中身を読み替える**: 従来の型とは違う小問の構成を、設問文から正確に読み取る練習をします。ダム計測の設問は、計測項目や管理期間といった前提知識の確認も併せて行います。
4. **IIIは観点の立て方を比べる**: 模範解答の観点の置き方を見て、自分ならどの観点を立てるかを書き出してから、課題の内容を考えます。

## 答案作成上の注意点

II-1は答案用紙1枚の制約の中で、施設名・メカニズム・対策・留意点を過不足なく書く訓練が必要です。II-2とIIIは、設問文の小問構成に忠実に答案を組み立てることが最も重要です。

本書の模範解答に共通する発注者の視点（設計図書の安全性照査項目の網羅性確認、施工計画書の品質管理項目の審査、点検・観測データの活用など）は、受験者それぞれの立場（電力事業者・設計者・施工者）に応じて、自分自身の着眼点に置き換えて使ってください。特定の立場が求められているわけではなく、実務に基づく判断根拠を示すことが大切です。
