# はじめに

本書は、技術士第二次試験 建設部門 選択科目「電力土木」の令和8年度について、必須科目I、選択科目II-1・II-2・IIIの4区分の模範解答を収録した一冊です。令和3〜8年度を年度ごとに分けた全6巻のシリーズのうち、令和8年度の巻にあたります。

収録するのは、その年に実際に出題された設問のすべてです。必須科目IはI-1・I-2の2問、II-1は4問、II-2は2問、IIIは2問で、合計10問になります。本番では各区分から1問を選んで解答しますが、本書は選ばなかった側の設問も含めて掲載しています。どの設問を選んでも、答案の骨格をたどれるようにするためです。

模範解答は、電力土木工事の発注・監督業務に携わった元公務員（発注者）としての実務経験に基づいて執筆しています。設計図書の安全性照査項目が施設の特性に対応して網羅されているかを確認する立場、施工計画書の品質管理項目を審査する立場、点検・観測データを補修や評価の根拠として活用する立場など、発注者ならではの着眼点を各設問の解答に反映しました。令和8年度の試験から改訂されたコンピテンシー（技術士に求められる資質能力）を踏まえ、観測・調査・点検データに基づく判断、規制機関や河川管理者などとの協議、安全・経済・環境の三側面といった視点も、各設問の解答に織り込んでいます。

本書は無料で公開しているウェブ記事の転載ではありません。この「はじめに」を含む出題傾向の整理と学習ガイドは、本書のために新たに書き下ろしたものです。

使い方としては、まず各設問の「論述骨子」で答案の骨格を把握し、次にフル模範解答で文章化の水準を確認し、最後に各設問の末尾に添えた要点で自分の答案を見直す、という順序をおすすめします。答案そのものを覚えるのではなく、論理の組み立て方と着眼点を、自分の実務経験に置き換えて答案を作る練習に使ってください。

# 令和8年度 選択科目「電力土木」の出題傾向

本章は、本書に収録した令和8年度の全10問の問題文を読み込んで整理したものです。一般論や推測ではなく、問題文に書かれた設問の条件に即して書いています。

## 必須科目I

I-1は、令和8年1月に定められた第6次社会資本整備重点計画を背景に、新技術・DXの活用によるインフラの価値向上を問う設問です。I-2は、令和7年6月策定の「国土交通省環境行動計画」と令和8年1月策定の「グリーンインフラ推進戦略2030」を背景に、グリーンインフラを活かして人と自然が共生する社会づくりを進める際の技術課題を問う設問です。

この年の必須科目Iは、(1)の観点に条件が付いている点が特徴です。I-1は「インフラの価値に関する観点」、I-2は「人と自然が共生する社会づくりに関する観点」から課題を抽出するよう指定されており、設問の趣旨に沿った観点の設定が求められます。(3)はI-1が新たに生じうる懸念事項と対応策、I-2が将来的な懸念事項と対策、(4)は両問とも倫理と社会の持続性の観点です。必須科目Iの構成は電力土木以外の選択科目と共通なので、本書では答案の型を確認する位置づけで読んでください。

## 選択科目II-1（専門知識、答案用紙1枚・約600字、4設問中1設問を選択）

| 設問 | 主題 |
|---|---|
| II-1-1 | 原子力発電所の基準津波の策定（検討すべき事項と概要） |
| II-1-2 | 発電用ダムの事前放流とアンサンブル降雨予測（洪水調節機能の確保と発電量の最大化を図る運用方法、課題・留意点） |
| II-1-3 | 鉄筋コンクリート造施設の非破壊検査手法（強度、配筋状態、劣化事象を確認する複数の手法の概要と留意点） |
| II-1-4 | 第7次エネルギー基本計画（2025年2月）（基本的視点と2040年に向けた政策の方向性を、再生可能エネルギー・原子力・火力の電源ごとに） |

令和8年度のII-1は、原子力の津波評価（II-1-1）、流域治水と気象予測を結びつけたダム運用（II-1-2）、維持管理の検査技術（II-1-3）、直近のエネルギー政策（II-1-4）と、規制・運用・点検・政策の4つの切り口に分かれています。II-1-2は、洪水調節と発電量の最大化という、両立が難しい2つの目的を同時に扱い、運用方法に加えて期待される効果と課題・留意点も複数述べる設問です。

設問の条件では、II-1-3が鉄筋コンクリート造の施設を1つ挙げたうえで、コンクリート強度・配筋状態・劣化事象のいずれを確認する手法かを明らかにしながら複数挙げる構成である点に注意が必要です。II-1-4は電源ごとに述べる設問で、再生可能エネルギー・原子力・火力のいずれかが抜けると答案の網羅性を欠きます。

## 選択科目II-2（応用能力、答案用紙2枚・約1,200字、2設問中1設問を選択）

- II-2-1：豪雨後に、施設の基礎地盤（掘削地盤を含む）や周辺斜面で通常時と異なる変位量が計測された場面。初動対応から恒久対策の立案までを担う責任者として、調査・検討事項、手順、社内外関係者との調整方策を述べます。
- II-2-2：河川・流域における総合的な土砂管理を背景に、発電用ダムの貯水池の堆砂問題へ対応する場面。(1)で下流への影響と技術的対策を複数、(2)で最適な対策を選定する手順と留意点、(3)で関係者と調整方策を述べます。

II-2-1は、「初動対応」から「恒久対策の立案」までを一連の流れとして問い、計測された変位量という事実を起点に論を組み立てる設問です。II-2-2は、これまで多くの年度で見られた「検討事項、手順、関係者調整」の型と問い方が異なり、(1)が影響と対策、(2)が対策の選定手順になっています。対策を挙げるだけでなく、複数の対策から最適なものを選ぶ手順まで問われるため、選定の基準を言葉にしておく必要があります。

## 選択科目III（課題遂行能力、答案用紙3枚・約1,800字、2問題中1問題を選択）

- III-1：発電設備のリプレースに伴う電力土木施設の更新。施設を1つ挙げ、リプレースに係る工事内容を概説したうえで、技術課題を3つ以上抽出します。
- III-2：技術継承・人材育成。電力土木施設の維持管理を適切に行うにあたっての課題を3つ以上抽出します。施設の指定はなく、(2)では最重要課題を選んだ理由も添えます。

2問とも、課題、解決策（専門技術用語を交える）、すべての解決策を実行しても共通して生じうるリスクという3段構成です。III-1は、高経年化への対応に加えて、発電効率の向上、脱炭素化、変動電源への対応を目的としたリプレースという前提を踏まえた設問で、工事内容の概説から課題へつなぐ論理が重要です。III-2は、(2)で最重要課題を「その理由とともに」挙げる条件が付いており、選んだ根拠を明示する必要があります。

# 学習ガイド

## 3区分の位置づけと時間配分

必須科目Iは2時間で答案用紙3枚（約1,800字）を書きます。選択科目はII-1・II-2・IIIを合わせて3時間30分（210分）で、答案用紙6枚（約3,600字）を書きます。文字数の比率で単純に配分するとII-1は35分前後、II-2は70分前後、IIIは105分前後ですが、実際には構成を考える時間に文字数以上の比重がかかります。演習の段階で、各区分の構成メモを何分で作れるかを計っておくことをおすすめします。

## 令和8年度の巻の使い方

1. **II-1は項目の抜けを確認する**: 電源ごと、手法ごと、検討事項ごとに複数を挙げる設問が多い年度です。骨子を自分で書き出してから、模範解答と照らして抜けを確認します。
2. **II-2は問い方の変化を読み取る**: II-2-2は手順の対象が「対策を選ぶこと」になっています。設問文の(1)〜(3)が何を求めているかを、答案を書く前に一度整理してください。
3. **IIIは理由まで書く**: III-2は最重要課題を選んだ理由まで問われます。課題を並べたあと、選択の根拠を一文で言えるかを確認します。
4. **必須科目Iは観点の条件を守る**: 観点が指定されているため、指定された観点に沿って課題を立てているかを答案作成後に見直します。

## 答案作成上の注意点

II-1は答案用紙1枚の制約の中で、施設名・メカニズム・対策・留意点を過不足なく書く訓練が必要です。II-2とIIIは、設問文の小問構成に忠実に答案を組み立てることが最も重要です。

本書の模範解答に共通する発注者の視点（設計図書の安全性照査項目の網羅性確認、施工計画書の品質管理項目の審査、点検・観測データの活用など）は、受験者それぞれの立場（電力事業者・設計者・施工者）に応じて、自分自身の着眼点に置き換えて使ってください。特定の立場が求められているわけではなく、実務に基づく判断根拠を示すことが大切です。
