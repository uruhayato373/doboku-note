# はじめに

本書は、技術士第二次試験 建設部門「施工計画、施工設備及び積算」の令和4年度分として、必須科目I、選択科目II-1・II-2・III の模範解答を、元公務員（発注者）として工事の発注・監督に携わった経験を持つ技術士（建設部門・総合技術監理部門）の立場からまとめた一冊です。この科目の模範解答を年度ごとに分けたシリーズの1年度分にあたり、この一冊だけで令和4年度の出題を通して確認できます。

収録しているのは次の4本です。

- 必須科目I：I-1（インフラ分野のDX）、I-2（建設分野のカーボンニュートラル）の両問題
- 選択科目II-1：II-1-1〜II-1-4 の全4設問
- 選択科目II-2：II-2-1、II-2-2 の両設問
- 選択科目III：III-1、III-2 の両問題

本番ではそれぞれ1問（設問）を選んで解答しますが、本書は選ばなかった側にも目を通せるよう、出題されたすべてを収めています。各記事には、試験問題の全文、設問ごとの論述方針、フル模範解答、答案を見直すための要点をそろえました。模範解答は令和8年度の改訂コンピテンシーに対応した書き方にしています。

**本書の使い方**

1. まず試験問題の全文を読み、自分ならどう構成するかを数分間考える
2. 「設問構成と論述方針」で、問われている論点と論述の骨子を確認し、自分の構成案と照らし合わせる
3. フル模範解答を読み、論述の順序・専門用語の使い方・字数の配分を確認する
4. 各記事の末尾にある要点で、答案のどこを見直すとよいかを確認する
5. 余裕があれば、骨子だけを見て自分の言葉で答案を書き直す

**対象読者**

- 令和4年度の設問に取り組み、答案の書き方を確かめたい方
- II-1・II-2・III・必須科目I の答案構成に悩んでいる方
- 発注者・現場責任者の視点をどう答案に反映すればよいか掴めていない方

なお、本書に掲載する試験問題は公益社団法人 日本技術士会が公表した過去の試験問題に基づく引用であり、模範解答は独自に作成したオリジナルの論述です。

# 令和4年度の出題傾向

## 必須科目I

I-1 は、社会資本の効率的な整備、維持管理及び利活用に向けたデジタル・トランスフォーメーション（DX）の推進を問いました。I-2 は、2050年カーボンニュートラルに向けた、建設分野のCO2排出量削減とCO2吸収量増加の取組を問いました。どちらも (1) 多面的な観点から課題を3つ抽出、(2) 最重要課題への複数の解決策、(3) 解決策の実行後の影響への対応、(4) 技術者としての倫理・社会の持続性の観点からの要点・留意点、の4問構成です。(3) は I-1 が「波及効果と専門技術を踏まえた懸念事項への対応策」、I-2 が「新たに生じるリスクとそれへの対応策」と、問い方が異なります。この構成は11の選択科目で共通で、答案用紙は3枚です。

## 選択科目II-1（4設問から1問選択・答案用紙1枚）

- II-1-1：切土のり面保護工を選定するうえでの基本的な考え方と、植物によるのり面保護工・構造物によるのり面保護工から各1つ挙げた工法の概要（土工）
- II-1-2：公共事業の契約方式として最近用いられているECI方式の概説と、実施にあたっての留意点（契約制度）
- II-1-3：労働安全衛生法施行令等の改正（2022年1月完全施行）で、墜落による労働災害の防止に関する規定等が改正された背景と、改正内容（労働安全・法令）
- II-1-4：コンクリートの中性化の劣化機構と、中性化と水の浸透に伴う鉄筋腐食が併せて進展する構造物の維持管理方法（コンクリート・維持管理）

II-1-3 のように、法令改正の背景と内容をセットで問う設問が含まれます。

## 選択科目II-2（2設問から1問選択・答案用紙2枚）

II-2-1 は、地方都市郊外の丘陵地で切土（25万m3）して盛土（20万m3、最大高さ10m）する大規模宅地造成工事で、鉄道に近接する範囲の一部に補強土壁（最大高さ6m、延長約200m）を計画する場面でした。II-2-2 は、地下水位の高い市街地でシールドトンネルの発進立坑を構築中、深さ15mまで掘削した時点でソイルセメント地下連続壁の壁面から異常出水が発生し、地盤の一部が沈下して工事が中断している場面でした。

両設問とも本工事の現場責任者の立場で、次の形で問われています。

- II-2-1：補強土壁部の施工計画で検討すべき事項3つ → 品質低下の原因となる重要なリスクを1つ挙げて、どうマネジメントするか → 最上段の施工中に豪雨で一部の補強土壁に異常な変形が生じたときに発揮すべきリーダーシップ
- II-2-2：異常出水を受けて検討すべき事項3つ → 掘削工事の早期再開に必要な手順とマネジメント → 掘削再開後に発揮すべきリーダーシップ

前提となる状況が与えられたうえで、リスクや事故への対応と、現場責任者としてのリーダーシップが問われる形です。

## 選択科目III（2問題から1問選択・答案用紙3枚）

III-1 は、大規模・広域災害で複数のインフラ施設が甚大な被害を受けたときの応急復旧工事で配慮すべき課題を問いました。III-2 は、調査・測量から設計、施工、検査、維持管理・更新までの建設生産プロセスの課題を問い、ICT・DXの推進による個々の建設現場の生産性向上に関する課題は除くという条件が付きました。どちらも、(2) の解決策は専門技術用語を交えて示すよう求められています。

# 学習ガイド

## 科目ごとに答案の型を決める

**II-1（答案用紙1枚）**
「説明せよ。また、〜を挙げて説明せよ」の形です。II-1-1 のように分類（植物／構造物）を指定する設問は、指定どおりに1つずつ挙げます。法令改正を問う II-1-3 は、背景と内容を分けて書きます。

**II-2（答案用紙2枚）**
令和4年度は、(2) と (3) が起きた事象への対応の問いになっています。(1) で検討事項を3つ挙げたあと、(2) では手順や管理の進め方を順序立てて書き、(3) のリーダーシップでは誰に何をするかを具体的に書きます。

**III（答案用紙3枚）**
III-2 のように除外条件がある設問は、課題の抽出前に条件を確認します。3つの課題は観点を変え、最重要課題を選んだ理由を一文で示します。

**必須科目I（答案用紙3枚）**
(3) の問い方は問題ごとに異なるため、設問文を読み分けます。(4) は書き落としやすいので、字数配分に最初から含めておきます。

## 時間配分の考え方

答案用紙の枚数は、II-1 が1枚、II-2 が2枚、III が3枚です。この比率を目安に、構成を考える時間（骨子の作成）を各設問の解答時間の2〜3割程度確保すると、書き始めてからの修正を減らせます。試験時間の正確な配分は、日本技術士会が年度ごとに公表する実施要項で確認してください。

## 注意点

- 設問の立場（受注者の現場責任者など）を冒頭で確認すること
- 事象が起きた後の対応を問う設問は、起きた事象を踏まえた内容になっているかを見直すこと
- 法令・制度の数字や年月日は、日本技術士会や所管官庁の公表資料で正確に確認すること
