# はじめに

本書は、技術士第一次試験「専門科目（建設部門）」の過去問題を、令和元年度から令和7年度までの7年分・245問すべて収録した一冊です。公式正答番号のある244問は選択肢1つ1つの正誤理由まで解説し、令和7年度Ⅲ-13は正答を断定せず5肢の論点を整理しています。

専門科目（建設部門）は、各年度とも「次の35問題のうち25問題を選択して解答せよ」という形式で出題されます（本書収録の全7年度で共通の指示文）。全問を解く必要はありませんが、どの10問を捨てるかを判断するには、まず全分野をひととおり見渡しておく必要があります。本書はその「見渡し」を過去7年分・245問というボリュームで一気に済ませられるように編集しました。

専門科目の大きな特徴は、計算問題と図表付き問題の比率が高いことです。土の三相モデル、はりの断面力図・断面二次モーメント、河川堤防や矩形ゲートの断面図など、図がなければ成立しない設問が数多く出題されます。本書は原典の図版をすべて画像として収録し、数式はKindle端末で正しく表示される形式で再現しています。「図は省略」「計算過程は割愛」という手抜きはしていません。選択肢が5つある問題では、正答の理由だけでなく誤りの選択肢がなぜ誤りなのかも1つずつ言葉で説明しているため、暗記ではなく理解しながら演習できます。

本書はウェブサイト向けに書いた記事をそのまま転載したものではありません。この「はじめに」を含む出題傾向分析と学習ガイドは本書のために新たに書き下ろし、7年分を横断してはじめて見える出題パターンをまとめています。年度ごとに1問ずつ眺めているだけでは気づきにくい「毎年ほぼ同じ順番・同じ分野配分で出題される」という専門科目の構造を、次章で具体的な数字とともに示します。

# 令和元〜令和7年 専門科目（建設部門）の出題傾向分析

本書収録の7年分・245問を実際に読み込んで集計した結果を示します。数値はすべて本書に収録した過去問そのものから数えたものであり、推測や一般論ではありません。

## 出題順序と分野配分はほぼ固定されている

専門科目（建設部門）は35問構成ですが、7年分を並べて比較すると、**出題される分野の並び順が年度を超えてほぼ一定**であることがわかります。Ⅲ-1からⅢ-35までの通し番号と分野の対応は、7年間を通じて次のように安定しています。

| 通し番号 | 分野 | 1年あたり | 7年計 |
|---|---|---|---|
| Ⅲ-1〜4 | 土質及び基礎 | 4問 | 28問 |
| Ⅲ-5〜9 | 構造力学・鋼構造 | 5問 | 35問 |
| Ⅲ-10〜12 | コンクリート | 3問 | 21問 |
| Ⅲ-13〜16 | 都市及び地方計画 | 4問 | 28問 |
| Ⅲ-17〜20 | 水理学 | 4問 | 28問 |
| Ⅲ-21〜22 | 河川 | 2問 | 14問 |
| Ⅲ-23〜24 | 海岸 | 2問 | 14問 |
| Ⅲ-25 | 港湾・空港 | 1問 | 7問 |
| Ⅲ-26 | 砂防 | 1問 | 7問 |
| Ⅲ-27〜28 | 電力土木 | 2問 | 14問 |
| Ⅲ-29 | 道路 | 1問 | 7問 |
| Ⅲ-30 | 鉄道 | 1問 | 7問 |
| Ⅲ-31 | トンネル | 1問 | 7問 |
| Ⅲ-32 | 施工（土留め・地盤改良等） | 1問 | 7問 |
| Ⅲ-33 | 施工管理（工程管理・積算） | 1問 | 7問 |
| Ⅲ-34〜35 | 建設環境 | 2問 | 14問 |

（合計 35問×7年＝245問。本書の収録数と一致）

この並びは、単なる偶然の一致ではありません。「Ⅲ-1は土の状態量、Ⅲ-13は都市計画法の都市施設、Ⅲ-21は河川堤防、Ⅲ-29は舗装、Ⅲ-34〜35は建設環境」というように、同じ通し番号にほぼ同じ分野が7年連続で置かれています。年度をまたいで「この番号は何の分野か」を覚えてしまえば、初見の年度でも問題を見た瞬間にどの知識を引き出せばよいか見当がつきます。

## 最大のボリュームゾーンは「構造力学・鋼構造」＋「コンクリート」

Ⅲ-5〜Ⅲ-12の8問（構造力学・鋼構造5問＋コンクリート3問）は、35問中もっとも配点の大きいまとまりです。7年間で計56問を占め、全245問の約23%に相当します。特にⅢ-5・Ⅲ-6は、はりの曲げモーメントや断面二次モーメントを求める計算問題が7年連続で出題されており、パターンが読みやすい分野です。

次に大きいのが「土質及び基礎」「都市及び地方計画」「水理学」で、いずれも4問/年・28問/7年と並びます。この3分野と構造力学・鋼構造・コンクリートを合わせた5つの大分野だけで、35問中20問（57%）を占めます。25問選択という制約を踏まえると、この5分野を確実に得点源にできれば選択の自由度が大きく広がります。

## ほぼ同一文言で繰り返される「定番設問」

7年分を並べて読むと、年度が変わってもほぼ一字一句同じ書き出しで出題される設問があることに気づきます。

- **Ⅲ-17「ベルヌーイの定理」**：「非圧縮性完全流体の定常流れでは、流線上で次式のベルヌーイの定理が成立する。」という書き出しが、令和元・2・3・5・7年度（7年中5年）でほぼ同一文言で登場します。令和4・6年度はこの位置が静水圧（矩形ゲート・平板に作用する水圧）の計算問題に置き換わっていますが、いずれも水理学の基礎公式を問う設問である点は共通です。
- **「水中の土砂移動」**：「水中の土砂移動に関する次の記述のうち、最も不適切なものはどれか。」が、令和元・2・3・4・7年度（7年中5年）で同一文言のまま出題されています。令和5・6年度はこの位置が開水路の流れの設問に入れ替わっています。
- **Ⅲ-21「河川堤防」**：「河川堤防に関する次の記述のうち、最も不適切なものはどれか。」は7年間すべての年度で同一文言のまま出題されています。

こうした定番設問は、過去問演習の費用対効果がもっとも高い部分です。本書で7年分の解説を読み比べれば、同じ論点がどの選択肢で問われ、どこが不適切とされたかのバリエーションを把握できます。

## 小分野は「1問だけ」だが数は多い

港湾・空港、砂防、道路、鉄道、トンネル、施工、施工管理の7分野は、いずれも1年に1問しか出題されません（7分野×1問＝7問/年、20%）。港湾・空港は年度によって港湾の防波堤が出たり空港の設問が出たりと中身が入れ替わりますが、通し番号Ⅲ-25という位置は一定です。1問だけの小分野をどこまで拾いに行くかは、後述する学習ガイドで戦略として扱います。

## 年度による小さな変化

固定的な構造の中にも、年度による変化はあります。令和5年度以降はⅢ-18の位置が「河川の流出解析」に置き換わり、令和元〜4年度に多かった管路流れ一般の設問から、河川分野へ寄せた出題に変わっています。分野の大枠は変わりませんが、水理学の中でどのサブテーマが選ばれるかは年度によって揺れがあることも押さえておくと安心です。

# 学習ガイド

## 優先順位の考え方

25問選択という制約がある以上、35問全部を均等に勉強する必要はありません。前章の集計を踏まえ、次の順番で学習の比重を決めることをおすすめします。

1. **構造力学・鋼構造＋コンクリート（Ⅲ-5〜12・8問/年）**：最大のボリュームゾーン。はりの計算問題はパターンが決まっているため、演習量に比例して得点が伸びやすい分野です。
2. **土質及び基礎（Ⅲ-1〜4）／都市及び地方計画（Ⅲ-13〜16）／水理学（Ⅲ-17〜20）**：いずれも4問/年。この3分野と1.を合わせると35問中20問に達し、25問選択の8割を大分野だけでまかなえる計算になります。
3. **河川・海岸・電力土木・建設環境（各2問/年）**：中規模の分野。実務や興味がある分野があれば優先的に固め、残りは選択肢の消去法（最も不適切なものを選ぶ形式が大半）で対応できる基礎知識を優先します。
4. **港湾・空港／砂防／道路／鉄道／トンネル／施工／施工管理（各1問/年）**：1問ずつのため、得意分野があれば拾い、そうでなければ無理に手を広げず25問の枠外（捨てる10問）に回す判断も戦略です。

## 選択のコツ

専門科目は「最も不適切なものはどれか」を選ぶ形式が大半を占め、正しい知識を1つ選ぶ形式より、誤りを見抜く訓練が効きます。本書はすべての選択肢に正誤理由をつけているため、正答の選択肢だけでなく、誤答の選択肢がどこをどう変えれば正しい記述になるかを合わせて読むと、同じ論点が別の言い回しで出題されたときにも対応できます。

計算問題（構造力学・水理学・土質）は、公式を覚えるだけでなく「どの記号が何を表すか」を毎回図と対応させて確認する習慣をつけると、令和6年度のように図の形式が変わっても対応しやすくなります。

## 時間配分の考え方

25問を選ぶ試験である以上、まず全35問にざっと目を通し、得意分野・見覚えのある論点から着手するのが基本です。計算問題は図の読み取りに時間がかかるため、演習段階で「この分野の計算問題は何分で解けるか」を自分で計測しておくと、本番での取捨選択の判断が速くなります。知識問題（文章の正誤判定）は、キーワードから正誤が判断できるものを先に片付け、時間のかかる計算問題に多めの時間を残す配分がおすすめです。
