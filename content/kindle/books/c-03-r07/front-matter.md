# はじめに

本書は、技術士第二次試験 建設部門「都市及び地方計画」選択科目を受験する方に向けて、令和7年度の筆記試験の問題に対する模範解答を収めた1冊です。必須科目I、選択科目II-1、II-2、IIIの4本を収録しており、各科目の全設問（必須科目Iが2問題、II-1が4設問、II-2が2設問、IIIが2問題の計10設問）の模範解答を通して読めます。

本書は、年度ごとに1冊ずつに分けたシリーズの1冊です。一つの年度の問題だけを、必須科目から選択科目まで通して読み、答案を再現する練習に使えます。

著者は地方自治体の土木職として都市計画・まちづくり関連業務の発注・監督に携わった経験を持ちます。本書の選択科目の解答は、コンサルタントとして受注する側ではなく、業務を発注し進行管理する側、すなわち行政（発注者）の立場から答案を組み立てている点が特徴です。制度の説明にとどまらず、「行政の担当責任者として何を調査し、誰と調整し、どう合意形成を図るか」という実務プロセスを答案の骨格に据えています。

本書で扱う4科目の形式は次のとおりです。必須科目Iは2問題から1問題を選び、答案用紙3枚（約1,800字）で解答します。II-1は専門知識を問う科目で、4設問から1問を選び答案用紙1枚（約600字）、II-2は応用能力を問う科目で、2設問から1問を選び答案用紙2枚（約1,200字）、IIIは問題解決能力と課題遂行能力を問う科目で、2問題から1問を選び答案用紙3枚（約1,800字）で解答します。本書は各科目について、その年度に出題された全設問の模範解答を収録しているため、本番でどの設問を選んでも対応できるよう準備できます。

対象読者は、技術士第二次試験 建設部門「都市及び地方計画」を受験する予定の方です。本書は次章の出題傾向で令和7年度の問題の特徴を把握したうえで、設問・論述方針・模範解答を通しで読み、自分の言葉で答案を再現する練習に使うことを想定しています。

なお、本書の模範解答は令和8年度に改訂された技術士コンピテンシー（データ・情報技術の活用、ステークホルダーとの合意形成、社会・経済・環境の三側面での持続可能な成果の追求）を踏まえて記述しています。これは特定年度の予想ではなく、技術士第二次試験に共通して求められる評価軸です。

# 出題傾向（令和7年度）

以下は、本書に収録した令和7年度の全10設問の問題文と論点を読んで整理した内容です。他の年度や今後の出題を予想するものではありません。

**必須科目Iは、持続可能な建設業（I-1）と、経済成長の実現を目的とする社会資本整備（I-2）の2問題**である。I-1は令和6年6月の担い手3法の改正を踏まえ、建設業の構造上・制度上・管理上の課題も含む技術課題を問う。I-2は第5次社会資本整備重点計画の3つの目的のうち「経済成長の実現」を取り上げ、制度上の課題も含めた技術課題を問う。どちらも(1)で観点を先に述べてから技術課題を示す指定があり、この科目は11の選択科目で共通である。

**II-1は、4設問のうち1つが課題・解決策を述べる形式である**。II-1-1は日本海側の半島地域で大規模な地震災害が発生した場合に、持続可能な復興対策のために解決すべき主要な技術課題を3つ挙げ、それぞれの解決策を述べさせる。II-1-2は土地区画整理事業の換地計画で、照応の原則と換地の定め方、市町村（政令指定都市を除く）施行の換地計画の決定手続きを問う。II-1-3はマンション管理計画認定制度の仕組みと、認定基準の内容3つを問う。II-1-4は公募設置管理制度（Park-PFI）の内容と、従来の設置管理許可にはない法令上の特例措置を複数挙げ、事業者にとってのメリットを説明させる。

**II-2は、3D都市モデルの活用と、景観計画の策定である**。II-2-1は、大都市の地方公共団体で、駅前広場と道路空間を対象に都市空間再構築の基本構想を作成する際、関係者との円滑な合意形成のために3D都市モデルを活用する業務である。II-2-2は、旧街道沿いの宿場町としての町並みが残る人口10万人規模の地方都市で、町並みに調和しない形態や色彩の建築物や屋外広告物が増えつつある中、景観計画案を作成する業務を問う。いずれも「調査事項」「手順」「関係者調整」の3問である。

**IIIは、立地適正化計画の新規作成（III-1）と、住宅団地の再生（III-2）**である。III-1は人口30万人規模で人口減少傾向の地方都市が、新たに立地適正化計画を作成してまちづくりに取り組む場面で、技術課題の抽出から、計画作成後に浮かび上がる将来的な懸念事項とその対策までを問う。III-2は、大都市郊外の戸建て住宅地を多く含む住宅団地の再生に向けた技術課題を問う。IIIの(1)では、課題ではなく「技術課題」として、観点を明記して抽出するよう指定されている。

**II-1の3設問は、法令上の仕組みを正確に説明させる**。換地計画（II-1-2）、マンション管理計画認定制度（II-1-3）、公募設置管理制度の特例措置（II-1-4）と、制度の内容を条件や手続まで正確に書けることが答案の核になる。

# 学習ガイド

**出題形式ごとに答案の型を固定する**。II-1は「制度の正確な説明＋具体的な内容」を600字で簡潔にまとめる形式で、法令・制度の名称を正確に書けるかが大切になる。II-2は「調査・検討すべき事項→業務手順（留意点・工夫点）→関係者との調整方策」という3段構成が基本で、この型を先に決めておけば、どの設問が出ても骨格に沿って書き進められる。IIIと必須科目Iは「観点を明記した課題の抽出→最重要課題への複数の解決策→残余リスク・波及効果や懸念事項への対策」が中心で、必須科目Iはこれに倫理・社会の持続性の観点が加わる。

**「技術課題」という言葉を意識して書く**。令和7年度は必須科目Iと選択科目IIIの(1)で、課題を「技術課題」と呼び、観点を明記するよう求めている。技術者として何を技術的に解決するのかが読み取れる書き方にする。

**II-1-1は課題と解決策を対で書く**。II-1-1は技術課題を3つ挙げ、それぞれに解決策を述べる形式で、約600字に3組を収める必要がある。1組あたりの字数を先に割り振り、制度の説明に偏らないようにする。

**関係者調整は「グループ分けして具体的手法を書く」型で対応する**。II-2で求められる関係者調整は、行政内部、権限を持つ関係機関、住民・事業者、専門家といった形で関係者を3〜4グループに分け、それぞれに具体的な調整手法（個別協議・説明会・ワークショップ・サウンディング調査など）を挙げる書き方が整理しやすい。

**行政（発注者）の立場を答案に明示する**。本書の選択科目の模範解答は、行政の担当責任者として調査・発注・監督・合意形成をどう進めるかという視点で一貫している。民間コンサルタントの経験が中心の方も、「発注者は何を確認し、何を審査し、どう説明責任を果たすか」を加えると、行政計画に関わる出題に対応しやすくなる。

**配点と時間配分の目安**。日本技術士会の受験案内と文部科学省の合否決定基準では、必須科目Iが40点（答案用紙3枚）、選択科目II-1が10点（1枚）、II-2が20点（2枚）、IIIが30点（3枚）で、合格基準は必須科目・選択科目ともに60％以上の得点とされています。選択科目の試験時間は合計3時間30分（210分）です。II-1に30分程度、II-2に60分程度、IIIに100分程度を目安とし、残りを見直しに充てる進め方が一つの目安になります。設問選択は冒頭で全設問に目を通し、骨格を確実に書ける設問を選ぶことを優先してください。制度の数字は受験する年度の公表資料でも確かめてください。
