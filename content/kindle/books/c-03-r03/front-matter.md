# はじめに

本書は、技術士第二次試験 建設部門「都市及び地方計画」選択科目を受験する方に向けて、令和3年度の筆記試験の問題に対する模範解答を収めた1冊です。必須科目I、選択科目II-1、II-2、IIIの4本を収録しており、各科目の全設問（必須科目Iが2問題、II-1が4設問、II-2が2設問、IIIが2問題の計10設問）の模範解答を通して読めます。

本書は、年度ごとに1冊ずつに分けたシリーズの1冊です。一つの年度の問題だけを、必須科目から選択科目まで通して読み、答案を再現する練習に使えます。

著者は地方自治体の土木職として都市計画・まちづくり関連業務の発注・監督に携わった経験を持ちます。本書の選択科目の解答は、コンサルタントとして受注する側ではなく、業務を発注し進行管理する側、すなわち行政（発注者）の立場から答案を組み立てている点が特徴です。制度の説明にとどまらず、「行政の担当責任者として何を調査し、誰と調整し、どう合意形成を図るか」という実務プロセスを答案の骨格に据えています。

本書で扱う4科目の形式は次のとおりです。必須科目Iは2問題から1問題を選び、答案用紙3枚（約1,800字）で解答します。II-1は専門知識を問う科目で、4設問から1問を選び答案用紙1枚（約600字）、II-2は応用能力を問う科目で、2設問から1問を選び答案用紙2枚（約1,200字）、IIIは問題解決能力と課題遂行能力を問う科目で、2問題から1問を選び答案用紙3枚（約1,800字）で解答します。本書は各科目について、その年度に出題された全設問の模範解答を収録しているため、本番でどの設問を選んでも対応できるよう準備できます。

対象読者は、技術士第二次試験 建設部門「都市及び地方計画」を受験する予定の方です。本書は次章の出題傾向で令和3年度の問題の特徴を把握したうえで、設問・論述方針・模範解答を通しで読み、自分の言葉で答案を再現する練習に使うことを想定しています。

なお、本書の模範解答は令和8年度に改訂された技術士コンピテンシー（データ・情報技術の活用、ステークホルダーとの合意形成、社会・経済・環境の三側面での持続可能な成果の追求）を踏まえて記述しています。これは特定年度の予想ではなく、技術士第二次試験に共通して求められる評価軸です。

# 出題傾向（令和3年度）

以下は、本書に収録した令和3年度の全10設問の問題文と論点を読んで整理した内容です。他の年度や今後の出題を予想するものではありません。

**必須科目Iは、廃棄物と循環型社会（I-1）、風水害への対応（I-2）の2問題**である。いずれも「課題を3つ抽出する」「最重要課題への複数の解決策」「解決策を実行しても生じうるリスクと対応策」「倫理・社会の持続性の観点からの要件」の4問構成で、都市計画の枠を離れ、建設分野全体の技術者として書くことが求められる。この科目は選択科目と独立しており、11の選択科目で共通である。

**II-1は、制度や手法を2つ並べて説明させる設問が目立つ**。II-1-1は東日本大震災の市街地復興で使われた防災集団移転促進事業と土地区画整理事業について、使われ方と相違点にふれて概要と特徴を問う。II-1-2は都市のスポンジ化に対し、土地の集約・再編の手法と、所有権と利用権を分離して低未利用地を活用する手法を、異なるものを1つずつ挙げて概要・メリット・留意点を説明させる。II-1-3は用途規制を緩和する2つの手法を手続にふれて特徴を述べさせ、II-1-4は都市公園をはじめとする自然的環境の保全・創出施策が生物多様性の保全で果たす役割を、多面的な観点から挙げさせる。

**II-2は、前提条件の細かい業務遂行型の設問である**。II-2-1は、駅前の市道を4車線から2車線に減らし、「居心地が良く歩きたくなるまちなか」に向けて道路空間（沿道含む）の再構築計画案を作る業務で、沿道の買収による拡幅、公園等の整備、土地区画整理事業、市街地再開発事業は前提とせず、車線数減少の検討は終わっているものとされている。II-2-2は、人口30万人の地方都市で、廃校になった教育施設またはその跡地を、市が所有権を保持したまま民間の資金とノウハウを取り入れて活用する構想の事業推進業務である。どちらも「調査・検討すべき事項」「業務手順と留意点・工夫点」「関係者との調整方策」の3問で構成される。

**IIIは、新型コロナウイルス感染症後の都市政策（III-1）と、歴史的資産の観光活用（III-2）**である。III-1は「新しい生活様式」の実践で顕在化した変化・課題を3つの異なる観点から抽出し、最重要のものへの都市政策上の対応策、すべての対応策を実行した場合の波及効果と懸念事項への対策までを問う。III-2は、市が取得した建築物と庭園が一体となった歴史的資産を、都市公園として入園料を徴収し指定管理者制度を導入するほか、民間提案による収益事業も検討するという条件のもとで、課題の抽出から残余リスクまでを問う。

**公民連携に関わる論点が、II-2-2とIII-2の2か所に現れている**。廃校活用では市が所有権を保持したままの民間活用、歴史的資産の観光活用では指定管理者制度と収益事業の導入が前提となっており、公共側がどこまで関与し、民間にどこまで任せるかを整理して書く力が求められる。

# 学習ガイド

**出題形式ごとに答案の型を固定する**。II-1は「制度の正確な説明＋具体的な内容」を600字で簡潔にまとめる形式で、法令・制度の名称を正確に書けるかが大切になる。II-2は「調査・検討すべき事項→業務手順（留意点・工夫点）→関係者との調整方策」という3段構成が基本で、この型を先に決めておけば、どの設問が出ても骨格に沿って書き進められる。IIIと必須科目Iは「観点を明記した課題の抽出→最重要課題への複数の解決策→残余リスク・波及効果や懸念事項への対策」が中心で、必須科目Iはこれに倫理・社会の持続性の観点が加わる。

**設問に付いた前提条件を、答案の冒頭で整理する**。II-2-1のように「前提としないもの」「検討済みのもの」が明示されている設問では、前提を外れた施策を挙げると減点要素になりうる。問題文の前提を一度書き出し、その範囲で調査事項と手順を組み立てる。

**III-1は「観点」を明記して課題を分ける**。コロナ後の変化・課題は、日常生活、経済・社会、デジタル化など観点が重なりやすい。3つの課題が互いに独立した観点になるよう、書き始める前に観点の名前を決めておく。

**関係者調整は「グループ分けして具体的手法を書く」型で対応する**。II-2で求められる関係者調整は、行政内部、権限を持つ関係機関、住民・事業者、専門家といった形で関係者を3〜4グループに分け、それぞれに具体的な調整手法（個別協議・説明会・ワークショップ・サウンディング調査など）を挙げる書き方が整理しやすい。

**行政（発注者）の立場を答案に明示する**。本書の選択科目の模範解答は、行政の担当責任者として調査・発注・監督・合意形成をどう進めるかという視点で一貫している。民間コンサルタントの経験が中心の方も、「発注者は何を確認し、何を審査し、どう説明責任を果たすか」を加えると、行政計画に関わる出題に対応しやすくなる。

**配点と時間配分の目安**。日本技術士会の受験案内と文部科学省の合否決定基準では、必須科目Iが40点（答案用紙3枚）、選択科目II-1が10点（1枚）、II-2が20点（2枚）、IIIが30点（3枚）で、合格基準は必須科目・選択科目ともに60％以上の得点とされています。選択科目の試験時間は合計3時間30分（210分）です。II-1に30分程度、II-2に60分程度、IIIに100分程度を目安とし、残りを見直しに充てる進め方が一つの目安になります。設問選択は冒頭で全設問に目を通し、骨格を確実に書ける設問を選ぶことを優先してください。制度の数字は受験する年度の公表資料でも確かめてください。
