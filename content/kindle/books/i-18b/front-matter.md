# はじめに

本書は、1級土木施工管理技術検定 第2次検定「施工経験記述」の対策書「トンネル・専門工事編」の下巻です。共同溝（プレキャストボックス）、電線共同溝（特殊部）、鉄道近接の土留め・仮設、大規模造成の防災調整池、法面対策（吹付・グラウンドアンカー）、軟弱地盤の地盤改良（薬液注入）という6つの専門工事について、品質管理・工程管理・安全管理・施工計画・環境対策の5管理すべての完成答案を収録しています。あわせて、トンネル工（品質・安全・環境の3管理）と共同溝の接合部（品質管理）に絞った補充答案2本を収録しています。

トンネル本体（山岳工法・覆工・坑口部・開削・水路・支保工・補修）の8つの想定工事は、上巻に収録しています。

対象読者は、1級土木施工管理技術検定 第2次検定を受験予定で、共同溝・電線共同溝などの地下埋設構造物、鉄道近接の仮設、大規模造成、法面、地盤改良のいずれかに近い工事の経験をお持ちの方です。1つの工事概要（記入例）を軸に5管理の答案を並べているため、自分の経験に最も近い想定工事を選べば、5管理の書き方を一式まとめて確認できます。

著者は、技術士（総合技術監理部門）を持つ元・地方自治体の土木職（発注者）です。1級・2級土木施工管理技士にも自分で合格しており、発注者として施工計画書や工事成績評定の書類を審査してきた立場から、読み手に伝わりやすい記述の水準を整理しています。総合技術監理部門で求められる品質・工程・安全・施工計画・環境の5つの管理の視点を、施工経験記述の答案分析にも一貫して用いています。

# 本書の使い方

読む順序は、まず自分の経験工事に最も近い想定工事を1つ選び、その5管理を通しで読むことをおすすめします。次に、後半の「専門工事の5管理で問われやすい点」で、共通する着眼点を確認してください。補充答案は、トンネル工と共同溝接合部の品質管理について、上記の想定工事とは別の題材で答案を確認したい場合に使います。

自分の現場への置き換え手順としては、本文中の`〇〇`をすべて自分が経験した工事の数値・工法名・現場条件に置き換えてください。工事名、発注者名、施工量、管理基準値などは、自分の施工計画書や設計図書の記載に必ず合わせる必要があります。数値を空欄のまま提出することはできません。

現行の出題形式（令和6年度以降）では、2テーマが必答で、それぞれについて2項目ずつ記述する形式になっています。本書が1つの想定工事につき5管理すべての答案をそろえているのは、この形式でどの管理の組合せが出題されても、同じ工事概要のまま答案を組み立てられるようにするためです。各工事の章には、その工事で出やすい管理の組合せ早見表も付けています。

施工経験記述は「自分が経験した工事」を書く設問であり、経験していない工事を書いたことが判明すると失格になり得ます。本書の答案は、そのまま書き写すためのものではありません。構成の組み立て方、技術的課題の絞り込み方、対応処置と評価のつなげ方といった記述の水準を確かめたうえで、自分の現場の事実に置き換えて使うことを前提としています。採点基準は公表されていないため、各章の自己点検ポイントは、筆者が読み手の立場で整理した観点です。

# 専門工事の5管理で問われやすい点

本書の専門工事は、地上からの開削や仮設を伴うものが多く、周辺環境や既設構造物との関係が、5管理の着眼点に共通して現れます。

品質管理では、プレキャストの据付精度と接合部の止水、土留めの変位、吹付厚とアンカー定着力、薬液の注入率と固結強度のように、完成後は見えなくなる項目を、計測・試験の方法と管理値とともに書けているかを確かめます。

工程管理では、占用期間、鉄道の営業線間合い、雨期といった、自分では動かせない外的な制約を、どうサイクルに組み込んだかが中心になります。

安全管理では、開削土留めの崩壊、既設埋設物や営業線への近接、高所での足場作業、注入圧による既設構造物の変状といった、工種ごとの重大災害を、具体的な監視・防護の方法で書き分けているかを確かめます。

施工計画では、土留め工法や法面保護工法、注入工法などの複数案比較と選定理由が、着手前の「事前の検討」として書かれているか、施工中の対応と混同していないかを確認しておきたいところです。

環境対策では、開削や掘削に伴う濁水、建設発生土、騒音・振動、薬液の地下水への影響など、周辺へ及ぼす影響を、どの基準に沿って管理したかが論点になります。

# 収録した6つの想定工事

- 共同溝（プレキャストボックス）：据付精度と接合部の止水を軸にした5管理答案
- 電線共同溝（特殊部）：特殊部の据付精度と占用協議を軸にした5管理答案
- 鉄道近接 土留め・仮設工事：営業線近接での土留め変位管理を軸にした5管理答案
- 大規模造成 流域貯留（防災調整池）：雨期をまたぐ大規模土工のクリティカルパス管理を軸にした5管理答案
- 法面対策（吹付・グラウンドアンカー）：吹付厚とアンカー定着力の確保を軸にした5管理答案
- 軟弱地盤 地盤改良（薬液注入工法）：注入率・固結強度の確認と地下水汚染防止を軸にした5管理答案

# 収録した補充答案

- 補充答案 トンネル工：覆工コンクリートの充填・締固め・養生（品質管理）、坑内作業の有害ガス・肌落ち・避難体制（安全管理）、湧水・濁水の坑外流出防止（環境対策）の3管理に絞った答案
- 補充答案 共同溝：プレキャストボックスの接合部に絞った品質管理の答案

トンネル工の補充答案には、現行形式（令和6年度以降）の答案に加えて、旧形式（令和5年度以前の3項目）への組み替え方も収録しています。

# 工事の系統と書き分け

本書の6工事は、地下に構造物を埋設する開削系（共同溝・電線共同溝・鉄道近接の土留め）、地盤や斜面を扱う系統（法面対策・地盤改良）、大規模な土工と調整池を扱う造成系の3つに分かれます。

開削系は、道路や鉄道に近接した狭い現場での土留めと据付が中心で、占用協議や営業線への配慮が答案の軸になります。法面対策と地盤改良は、完成後に見えなくなる品質を、削孔・注入・緊張の記録や効果確認で示せるかが軸になります。造成系は、土量配分と雨期の工程、出水時の退避が軸になります。

同じ専門工事でも、自分の経験がどの系統に近いかを意識して答案を組み立てることが、具体性を高める近道です。
