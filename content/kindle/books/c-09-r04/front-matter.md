# はじめに

本書は、技術士第二次試験 建設部門 選択科目「電力土木」の令和4年度について、必須科目I、選択科目II-1・II-2・IIIの4区分の模範解答を収録した一冊です。令和3〜8年度を年度ごとに分けた全6巻のシリーズのうち、令和4年度の巻にあたります。

収録するのは、その年に実際に出題された設問のすべてです。必須科目IはI-1・I-2の2問、II-1は4問、II-2は2問、IIIは2問で、合計10問になります。本番では各区分から1問を選んで解答しますが、本書は選ばなかった側の設問も含めて掲載しています。どの設問を選んでも、答案の骨格をたどれるようにするためです。

模範解答は、電力土木工事の発注・監督業務に携わった元公務員（発注者）としての実務経験に基づいて執筆しています。設計図書の安全性照査項目が施設の特性に対応して網羅されているかを確認する立場、施工計画書の品質管理項目を審査する立場、点検・観測データを補修や評価の根拠として活用する立場など、発注者ならではの着眼点を各設問の解答に反映しました。

本書は無料で公開しているウェブ記事の転載ではありません。この「はじめに」を含む出題傾向の整理と学習ガイドは、本書のために新たに書き下ろしたものです。

使い方としては、まず各設問の「論述骨子」で答案の骨格を把握し、次にフル模範解答で文章化の水準を確認し、最後に各設問の末尾に添えた要点で自分の答案を見直す、という順序をおすすめします。答案そのものを覚えるのではなく、論理の組み立て方と着眼点を、自分の実務経験に置き換えて答案を作る練習に使ってください。

# 令和4年度 選択科目「電力土木」の出題傾向

本章は、本書に収録した令和4年度の全10問の問題文を読み込んで整理したものです。一般論や推測ではなく、問題文に書かれた設問の条件に即して書いています。

## 必須科目I

I-1は、社会資本の効率的な整備、維持管理、利活用に向けたデジタル・トランスフォーメーション（DX）の推進を問う設問です。I-2は、2050年カーボンニュートラルの宣言を受け、建設分野でのCO2排出量の削減とCO2吸収量の増加の取組を問う設問です。

どちらも4つの小問で構成され、(1)多面的な観点から3つの課題を抽出して観点を明記、(2)最重要課題への複数の解決策、(3)解決策実行後の対応（I-1は波及効果と懸念事項への対応策、I-2は新たに生じるリスクと対応策）、(4)技術者としての倫理と社会の持続性の観点、の順に答えます。I-1の(3)が「波及効果」を含む点は、設問文の言い回しとして読み落とさないようにしてください。必須科目Iの構成は電力土木以外の選択科目と共通なので、本書では答案の型を確認する位置づけで読んでください。

## 選択科目II-1（専門知識、答案用紙1枚・約600字、4設問中1設問を選択）

| 設問 | 主題 |
|---|---|
| II-1-1 | 流体の模型実験（完全な相似性が成立する3条件と、支配的な2つの相似パラメータ） |
| II-1-2 | 電気設備の耐震性区分I・IIと津波への対応（原子力土木施設とダムを除く） |
| II-1-3 | 土砂生産量が多い流域のダムの堆砂対策（3つの方式に分類し、概要と留意点） |
| II-1-4 | 第六次エネルギー基本計画（概要と、電源ごとの2030年に向けた政策対応） |

令和4年度のII-1は、4問とも「何を知っているか」を直接問う色合いが強い年度です。II-1-1は水理の相似則という工学の基礎、II-1-2とII-1-4は、報告書や計画といった特定の文書の内容を前提にした設問です。II-1-2は平成7年11月と平成24年3月の2つの文書名を挙げ、そこに整理された耐震性区分と津波対応の考え方を答えさせます。II-1-4も計画の概要と電源別のポイントを問うため、文書の内容を把握していることが前提になります。

条件の読み取りも重要です。II-1-2は「原子力土木施設及びダムを除く」と範囲を限定し、「区分I」「区分II」のそれぞれについて対象施設・確保すべき耐震性・津波対応の考え方を述べる構成です。II-1-3は堆砂対策を「3つの方式に分類」してから、それぞれに当てはまる具体策を挙げる二段構えになっています。分類を示さずに対策を羅列すると、設問の要求を満たしません。

## 選択科目II-2（応用能力、答案用紙2枚・約1,200字、2設問中1設問を選択）

- II-2-1：重要な既存電力土木施設の大規模地震への備え。施設名と、損壊した場合の影響を明記し、安全性の評価で検討すべき事項と、地震後の状態に応じた対処方針を説明します。
- II-2-2：再生可能エネルギー拡大を目的とした既存電力土木施設の改造。有効活用する施設と改造の概要を明記し、検討すべき事項を挙げます。

どちらも、(1)検討事項、(2)業務を進める手順（項目ごとに留意点・工夫点）、(3)関係者との調整方策の3小問構成です。II-2-1は(1)の中に、安全性の評価に加えて「地震後の状態に応じた対処方針」まで含まれており、評価で終わらず、評価結果に応じた行動まで書く必要があります。II-2-2は、施設と改造内容を自分で設定する設問です。設定した改造が実現可能で、検討事項が改造内容と対応していることが、答案の説得力を左右します。

## 選択科目III（課題遂行能力、答案用紙3枚・約1,800字、2問題中1問題を選択）

- III-1：気候変動によるインフラ施設への影響を踏まえた、電力土木施設の維持管理。施設名を1つ挙げ、外力の増大が及ぼす影響を踏まえて、観点を明記しながら課題を3つ抽出します。
- III-2：再生可能エネルギー事業における地域社会との合意形成。電源名を1つ挙げて特性を述べ、解決すべき課題を2つ以上抽出します。

III-1は、課題、解決策（専門技術用語を交える）、すべての解決策を実行しても共通して生じうるリスクという構成です。III-2は(3)の問い方が異なり、「すべての解決策を実施したうえで成立した電源」について、地域社会への波及効果と懸念事項への対応策を述べます。リスクを書く設問と、成功した状態を前提に波及効果を書く設問が並んでいるため、(3)で何を問われているかを取り違えないことが重要です。

# 学習ガイド

## 3区分の位置づけと時間配分

必須科目Iは2時間で答案用紙3枚（約1,800字）を書きます。選択科目はII-1・II-2・IIIを合わせて3時間30分（210分）で、答案用紙6枚（約3,600字）を書きます。文字数の比率で単純に配分するとII-1は35分前後、II-2は70分前後、IIIは105分前後ですが、実際には構成を考える時間に文字数以上の比重がかかります。演習の段階で、各区分の構成メモを何分で作れるかを計っておくことをおすすめします。

## 令和4年度の巻の使い方

1. **II-1は文書名を手がかりに知識を確認する**: 令和4年度のII-1は、特定の報告書や計画の内容を前提にした設問が含まれます。骨子を自分で書き出し、模範解答と見比べて、用語や区分の抜けを確認してください。
2. **II-2は評価の先まで書く型を作る**: 「検討事項、手順、関係者調整」の骨格に加えて、II-2-1では地震後の状態に応じた対処方針までを、II-2-2では改造の実現性を、それぞれ答案に含める練習をします。
3. **IIIは(3)の問いを読み分ける**: III-1はリスクと対策、III-2は波及効果と懸念事項への対応です。答案を書く前に(3)の設問文を確認する習慣をつけます。
4. **必須科目Iは観点の明記を忘れない**: 課題を3つ挙げるときは、観点を先に示してから課題の内容を書きます。

## 答案作成上の注意点

II-1は答案用紙1枚の制約の中で、施設名・メカニズム・対策・留意点を過不足なく書く訓練が必要です。II-2とIIIは、設問文の小問構成に忠実に答案を組み立てることが最も重要です。

本書の模範解答に共通する発注者の視点（設計図書の安全性照査項目の網羅性確認、施工計画書の品質管理項目の審査、点検・観測データの活用など）は、受験者それぞれの立場（電力事業者・設計者・施工者）に応じて、自分自身の着眼点に置き換えて使ってください。特定の立場が求められているわけではなく、実務に基づく判断根拠を示すことが大切です。
