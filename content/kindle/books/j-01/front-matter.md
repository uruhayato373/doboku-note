# はじめに

本書は、2級土木施工管理技術検定 第2次検定の問題1（施工経験記述）について、2つの方向から答案を確認できるようにまとめた1冊です。ひとつは、令和3年度から令和7年度までの5年分の試験問題と、その年度の出題形式に沿った模範答案（年度別）。もうひとつは、品質管理・安全管理・工程管理のテーマ別に仕上げた完成答案と、地域の小規模インフラ工事4件の答案です。

2級の施工経験記述は、令和3〜5年度は品質管理・安全管理・工程管理のうち2つのテーマが示され、そのどちらか1つを選んで3項目で答える選択形式でした。令和6年度からは、2つのテーマが両方とも指定され、それぞれ2項目で答える必答形式に変わっています。本書は年度をまたいで5年分を通しで読むことで、この形式の変化と、変化後も変わらない答案の骨格の両方を確認できる構成にしています。そのうえで、テーマ別の完成答案を読むと、どの年度の形式にも組み替えて使えます。

著者は、技術士（総合技術監理部門）を持つ元・地方自治体の土木職（発注者）です。1級・2級土木施工管理技士にも自分で合格しており、発注者として施工計画書や工事成績評定の書類を審査してきた立場から、各答案を作成しています。

対象読者は、2級土木施工管理技士 第2次検定の受験を予定している方、特に実際の過去問題文に沿って答案の書き方を確認したい方、品質・安全・工程のどれが出ても書けるように答案を揃えておきたい方です。

施工経験記述は、受験者自身が経験した工事について記述する問題です。経験していない工事を記述したことが判明した場合は失格となります。本書の答案は、そのまま書き写して使うためのものではありません。答案の構成・表現・具体性の水準を確かめ、自分が実際に経験した工事の内容に置き換えて使うための記入例（テンプレート）です。答案中の工事名・数値等は記入例として設定したもので、実在の工事を示すものではありません。

# 本書の使い方

本書は9章で構成しています。第1〜5章が年度別の過去問模範答案、第6〜8章が品質・安全・工程のテーマ別の完成答案、第9章が小規模地域インフラ4工事の答案です。次の順に読み進めると、形式の把握から答案づくりまでを一続きで確認できます。

1. 次の節「令和3〜7年度の出題の流れ」で、5年間の出題テーマと形式の変化を把握します。
2. 第1〜5章（年度別）から、自分が受験する年度に近い出題形式の章を読みます。旧形式の選択・3項目か、新形式の必答・各2項目かを見分けてください。
3. 第6〜8章（テーマ別）で、品質・安全・工程の答案を現行形式（設問2項目）と旧形式（3項目）の両方で確認します。年度別の章で見た答案の型を、別の工事で書き直した例として読めます。
4. 自分の経験が大規模な工事でない場合は、第9章の小規模工事の答案を参考にします。

自分の現場に置き換える手順は、どの章でも共通です。

1. 収録された工事の中から、自分の経験した工事に工種・規模が近いものを1つ選びます。
2. 答案中の工事名・発注者名・工期・数値等（記入例として空欄や仮の値になっている箇所）を、自分の現場の実際の内容に差し替えます。
3. 「特に留意した技術的課題」が、自分の現場で実際にあった課題と一致するように調整します。経験していない課題をそのまま流用しないことが重要です。

失格や書き漏れを避けるために、次の点に注意してください。

- 答案は自分が経験した工事の内容で記述してください。経験していない工事の記述は失格の対象です。
- 安全管理を選ぶ・扱う場合、交通誘導員の配置のみに関する記述が除外される年度があります。誘導員に触れる場合は、必ず他の対策とあわせて記述してください。
- 令和6年度以降の新形式では、2つの設問で扱う技術的課題を明確に書き分けてください。同じ対策を2つの設問に重ねて書かないことが大切です。

各章の末尾には、読み手の視点での自己点検をまとめています。答案を書き終えたら、該当する章のチェックポイントで見直してください。

# 令和3〜7年度の出題の流れ

以下は、本書に収録した各年度の試験問題文にもとづく出題の流れです。他の年度についての推測は含みません。

令和3年度の問題1は、工夫した安全管理または工夫した品質管理のいずれか1つを選んで答える形式でした。設問2は「特に留意した技術的課題」「技術的課題を解決するために検討した項目と検討理由及び検討内容」「上記検討の結果、現場で実施した対応処置とその評価」の3項目です。

令和4年度は品質管理または工程管理のいずれか1つを選ぶ形式、令和5年度は安全管理または工程管理のいずれか1つを選ぶ形式でした。いずれも設問構成は令和3年度と同じ3項目形式です。このように、令和3〜5年度は年度ごとに示される2つのテーマの組合せが変わりながら、受験者がそのどちらか1つを選んで答える選択形式が続いています。

令和6年度から、問題1の出題形式が変わりました。工事概要を先に一括して記述したうえで、〔設問1〕〔設問2〕の2つのテーマについて、それぞれ「技術的課題」「検討した項目とその対応処置」の2項目で答える必答形式です。令和6年度は設問1が品質管理、設問2が工程管理として出題されました。

令和7年度も同じ必答形式で、設問1が安全管理、設問2が工程管理として出題されました。

このように、令和3〜5年度は2テーマのうち1つを選ぶ選択・3項目形式、令和6年度以降は2テーマを両方答える必答・2項目形式という形式の変化が、本書に収録した5年分の試験問題文から確認できます。1級と異なり、2級の施工経験記述で扱われるテーマは品質管理・安全管理・工程管理の3つが中心です。

# 収録内容

年度別の過去問模範答案（第1〜5章）

- 第1章　令和3年度　過去問模範答案（安全管理／品質管理 選択形式）
  - 宅地造成の土工事、場所打ち杭＋橋台躯体工事、軟弱地盤上の道路盛土工事の3つの想定工事を収録
- 第2章　令和4年度　過去問模範答案（品質管理／工程管理 選択形式）
  - 道路の路盤・舗装工事、上水道の配水管布設工事（開削）、重力式コンクリート擁壁工事の3つの想定工事を収録
- 第3章　令和5年度　過去問模範答案（安全管理／工程管理 選択形式）
  - 農業用水路改修工事、道路法面保護工（吹付枠・グラウンドアンカー）、樋門工（鋼矢板仮締切）の3つの想定工事を収録
- 第4章　令和6年度　過去問模範答案（品質管理＋工程管理 必答形式）
  - プレキャストボックスカルバート据付工事、地盤改良工（深層混合処理工法）、河川の床固め・根固めブロック工の3つの想定工事を収録
- 第5章　令和7年度　過去問模範答案（安全管理＋工程管理 必答形式）
  - 小型重力式擁壁＋舗装工事、電線共同溝（C・C・BOX）工事、緑地・公園造成工事の3つの想定工事を収録

テーマ別の完成答案（第6〜8章）

- 第6章　品質管理 完成答案
  - 河川築堤盛土（含水比・締固め度）、函渠コンクリート（温度ひび割れの抑制）、アスファルト舗装（混合物温度・締固め度・平坦性）の3工事。現行形式と旧形式の両方を収録
- 第7章　安全管理 完成答案
  - 河川護岸（掘削・土留め）、下水道管渠（立坑・酸素欠乏・第三者）、市街地の歩道・交差点改良（交通開放下の第三者・重機安全）の3工事。現行形式と旧形式の両方を収録
- 第8章　工程管理 完成答案
  - 砂防堰堤（出水期を避ける工程）、道路改良（関係機関協議・支障物移設）、供用道路の夜間舗装打替え（規制解除時刻からの逆算）の3工事。現行形式と旧形式の両方を収録

小規模工事の答案（第9章）

- 第9章　小規模地域インフラ4工事（12答案）
  - 上水道の仕切弁・消火栓付き弁室更新、地域バス停の乗降場・上屋基礎更新、小規模排水機場のポンプ基礎・躯体・吐出水路更新、小規模漁港の船揚場・係船環更新の4工事について、品質・安全・工程の答案を収録

年度別の章は、試験問題文の再掲、想定工事ごとの完成答案、自分の現場への置換ガイド、読み手の視点での自己点検という同じ構成です。テーマ別の章は、工事ごとの答案に加えて、置換ガイドと、伝わりにくい答案を直す例、自己点検を収めています。
