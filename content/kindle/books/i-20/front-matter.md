# はじめに

本書は、1級土木施工管理技術検定 第2次検定「施工経験記述」の対策書です。供用中の道路施設・トンネル構造物を対象とした維持更新工事7件（道路法面落石防護網更新、大型道路標識基礎更新、道路トンネル覆工構造補強、道路トンネル換気設備基礎更新、トンネル覆工背面空洞充填、共同溝設備架台更新、供用下函渠インバート更新）の想定工事を収録しています。

各想定工事には、品質管理・工程管理・安全管理・施工計画・環境対策の5管理すべての完成答案を掲載しました。1つの工事概要（記入例）を軸に5管理の答案を並べているため、自分の経験に最も近い想定工事を選べば、5管理の書き方を一式まとめて確認できます。道路附属施設の更新とトンネル・地下構造物の補修という、性質の異なる2系統を1冊にまとめているのも本書の特徴です。

対象読者は、1級土木施工管理技術検定 第2次検定を受験予定で、道路附属施設（法面防護・標識・換気設備等）やトンネル・共同溝・函渠といった道路地下構造物の維持更新工事の経験をお持ちの方です。道路本体の舗装・土工とは異なる、附属施設・地下構造物ならではの答案の組み立て方を確認したい方に向けています。

著者は、技術士（総合技術監理部門）を持つ元・地方自治体の土木職（発注者）です。1級・2級土木施工管理技士にも自分で合格しており、発注者として施工計画書や工事成績評定の書類を審査してきた立場から、評価される記述の水準を整理しています。総合技術監理部門で求められる品質・工程・安全・施工計画・環境の5つの管理の視点を、施工経験記述の答案分析にも一貫して用いています。

# 本書の使い方

読む順序は、まず自分の経験工事に最も近い想定工事を1つ選び、その5管理をまず通しで読むことをおすすめします。次に、本書後半の2つの章で、この工種群に固有の採点の着眼点を確認してください。

自分の現場への置き換え手順としては、本文中の`〇〇`をすべて自分が経験した工事の数値・工法名・規制時間・現場条件に置き換えてください。工事名、発注者名、施工量、閉鎖・規制時間帯、管理基準値などは、自分の施工計画書や設計図書の記載に必ず合わせる必要があります。

現行の出題形式（令和6年度以降）では、1つの管理項目から2テーマが必答となり、それぞれについて2項目ずつ記述する形式になっています。本書が1つの想定工事につき5管理すべての答案をそろえているのは、この形式でどの管理の組み合わせが出題されても、同じ工事概要のまま答案を組み立てられるようにするためです。

施工経験記述は「自分が経験した工事」を書く設問であり、経験していない工事を書いたことが判明すると失格になり得ます。本書の答案は、そのまま書き写すためのものではありません。構成の組み立て方、技術的課題の絞り込み方、対応処置と評価のつなげ方といった記述の水準を確かめたうえで、自分の現場の事実に置き換えて使うことを前提としています。数値・工法・規制時間帯がそのまま自分の工事と一致することはまずないという前提で、必ず読み替えてください。

# 供用中の道路・トンネル施設に共通する制約

本書が収録した7件は、いずれも道路交通や既存の地下構造物の供用を止めずに施工する工事です。この前提が、5管理それぞれの答案の組み立て方に影響します。

工程管理では、夜間通行止めや車線規制といった限られた閉鎖時間の中で、撤去・更新・復旧・交通開放までを完結させる考え方が共通しています。トンネル換気設備の基礎更新や函渠インバートの更新のように、1回の作業で完結できない場合は、区画を区切って複数夜に分けて進める工程の組み方が問われます。

安全管理では、道路施設の場合は供用車線・供用道路上の一般車両や歩行者への被害防止、共同溝・函渠のような閉鎖空間の場合は酸欠・有害ガスの該当性確認や増水時の退避計画が中心になります。函渠やトンネル坑内のように増水・湧水のリスクがある現場では、救出計画まで含めて安全管理に書き込む必要があります。この「該当性確認」という考え方は、閉鎖空間だから一律に酸欠対策を講じるのではなく、酸素欠乏症等防止規則の適用対象になるかどうかを自分で判断したうえで対策を選んでいる、という監理技術者としての判断過程を示す点で重要です。

施工計画では、供用を止められないという制約の中で、既存構造物を傷めずに更新・補強する工法（あと施工アンカー、背面空洞への注入充填等）を選定した根拠を、着手前の事前検討として明確に書くことが評価されます。

# 夜間規制・閉鎖時間という制約が答案に与える影響

道路・トンネルの維持更新工事は、新設工事のように工期全体を自由に計画できるわけではありません。多くの場合、1日あたりに使える作業時間が夜間の数時間に限られており、この制約こそが答案の技術的課題の起点になります。

たとえば大型道路標識基礎更新やトンネル換気設備基礎更新では、限られた夜間時間の中で基礎コンクリートの強度発現を待つ必要があり、早強材料の使用や強度確認のタイミングが工程管理の答案の核心になります。また、道路法面落石防護網更新のように片側交互通行を維持しながら急斜面で高所作業を行う工事では、供用車線と作業帯を明確に分離する物理的対策が安全管理の答案の中心になります。

このように、供用継続という制約を単に「大変だった」と書くのではなく、その制約から生じる具体的な技術的課題（強度発現時間、区画分割、退避基準）として答案に落とし込むことが、評価される記述につながります。

品質管理においても、この制約は無関係ではありません。夜間の限られた時間内で行う計測・確認作業は、通常より短い時間で完了させる必要があり、計測項目を絞り込んだ上で、どの項目を必ず確認するかという優先順位づけが求められます。たとえばトンネル覆工背面空洞充填では、注入圧・注入量に加えて確認削孔による充填状況の把握が、限られた夜間開放時間の中で行われます。こうした「短時間で何を優先して確認したか」という判断も、答案の具体性を高める要素になります。

# 収録内容

- 道路法面落石防護網更新：既設網の撤去からアンカー・ワイヤロープによる新設網の展張まで、供用道路直上の急斜面でのロープ高所作業と片側交互通行を軸にした5管理答案
- 大型道路標識基礎更新：架空線・地下埋設物が輻輳する市街地交差点で、既設基礎の撤去から建柱までを夜間規制内で行う工程を軸にした5管理答案
- 道路トンネル覆工構造補強：漏水のある下地への鋼板・繊維補強材の接着と、夜間閉鎖内での先行止水・材料硬化管理を軸にした5管理答案
- 道路トンネル換気設備基礎更新：ジェットファンの撤去・再設置とあと施工アンカーによる基礎金具の更新を、夜間閉鎖内で完結させる工程を軸にした5管理答案
- トンネル覆工背面空洞充填：電磁波調査による空洞範囲の把握から、確認削孔・注入・変位計測までの一連の品質管理を軸にした5管理答案
- 共同溝設備架台更新：酸欠等の該当性確認と、電力・通信等の企業者立会いのもとで行う設備仮受け・架台更新を軸にした5管理答案
- 供用下函渠インバート更新：増水時の監視体制・退避計画と、仮排水区画内で完結させる底版更新工程を軸にした5管理答案
