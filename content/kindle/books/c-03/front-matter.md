# はじめに

本書は、技術士第二次試験 建設部門「都市及び地方計画」選択科目を受験する方に向けて、令和8年度の筆記試験の問題に対する模範解答を収めた1冊です。必須科目I、選択科目II-1、II-2、IIIの4本を収録しており、各科目の全設問（必須科目Iが2問題、II-1が4設問、II-2が2設問、IIIが2問題の計10設問）の模範解答を通して読めます。令和8年度分は、本試験で実際に出題された設問への模範解答です。

本書は、年度ごとに1冊ずつに分けたシリーズの1冊です。一つの年度の問題だけを、必須科目から選択科目まで通して読み、答案を再現する練習に使えます。

著者は地方自治体の土木職として都市計画・まちづくり関連業務の発注・監督に携わった経験を持ちます。本書の選択科目の解答は、コンサルタントとして受注する側ではなく、業務を発注し進行管理する側、すなわち行政（発注者）の立場から答案を組み立てている点が特徴です。制度の説明にとどまらず、「行政の担当責任者として何を調査し、誰と調整し、どう合意形成を図るか」という実務プロセスを答案の骨格に据えています。

本書で扱う4科目の形式は次のとおりです。必須科目Iは2問題から1問題を選び、答案用紙3枚（約1,800字）で解答します。II-1は専門知識を問う科目で、4設問から1問を選び答案用紙1枚（約600字）、II-2は応用能力を問う科目で、2設問から1問を選び答案用紙2枚（約1,200字）、IIIは問題解決能力と課題遂行能力を問う科目で、2問題から1問を選び答案用紙3枚（約1,800字）で解答します。本書は各科目について、その年度に出題された全設問の模範解答を収録しているため、本番でどの設問を選んでも対応できるよう準備できます。

対象読者は、技術士第二次試験 建設部門「都市及び地方計画」を受験する予定の方です。本書は次章の出題傾向で令和8年度の問題の特徴を把握したうえで、設問・論述方針・模範解答を通しで読み、自分の言葉で答案を再現する練習に使うことを想定しています。

なお、本書の模範解答は令和8年度に改訂された技術士コンピテンシー（データ・情報技術の活用、ステークホルダーとの合意形成、社会・経済・環境の三側面での持続可能な成果の追求）を踏まえて記述しています。これは特定年度の予想ではなく、技術士第二次試験に共通して求められる評価軸です。

# 出題傾向（令和8年度）

以下は、本書に収録した令和8年度の全10設問の問題文と論点を読んで整理した内容です。他の年度や今後の出題を予想するものではありません。

**必須科目Iは、新技術・DXの活用によるインフラの価値向上（I-1）と、グリーンインフラの活用（I-2）の2問題**である。I-1は令和8年1月に定められた第6次社会資本整備重点計画を背景に、観点をインフラの価値に関するものとして技術課題を抽出させる。I-2は令和7年6月に策定された国土交通省環境行動計画と、令和8年1月に策定されたグリーンインフラ推進戦略2030を踏まえ、観点を人と自然が共生する社会づくりに関するものとして技術課題を抽出させる。この科目は11の選択科目で共通である。

**II-1は、二地域居住、都市施設、空家等活用促進区域、緑の基本方針の4設問**である。II-1-1は二地域居住の意義と、促進するうえでの主要な課題3つ、それぞれの解決策を問う。II-1-2は都市計画法に基づく都市施設の説明と、都市施設を都市計画に定める意義を問う。II-1-3は空家等対策の推進に関する特別措置法に基づく空家等活用促進区域が設定されるエリアと、設定する際の手続、考慮すべきことその他の留意事項を3つ問う。II-1-4は都市緑地法に基づく緑の基本方針に位置付けられた緑地の保全及び緑化の推進の意義を、社会的背景を踏まえて2つ挙げさせ、その実現に向けた緑地の質の確保・向上の施策を問う。

**II-2は、市街地再開発事業の事業計画と、事前復興まちづくり計画である**。II-2-1は、乗降客数10万人規模の鉄道駅前で、市街地再開発事業の都市計画決定がなされ、組合施行による事業着手に向けて準備が進む状況から、建設費高騰等の背景を踏まえて事業計画を作成する業務を問う。II-2-2は、南海トラフ地震による津波被害が懸念される地方都市で、被災後の復興まちづくりの事前準備として事前復興まちづくり計画を策定する業務を問う。設問の番号は(1)(2)(3)で、調査・検討事項、業務手順、関係者調整の型は共通である。

**IIIは、立地適正化計画の評価と見直し（III-1）と、歴史的風致形成建造物の古民家活用（III-2）**である。III-1は、5年前に立地適正化計画を作成した地方部の中核都市A市を舞台に、(1)で評価すべき課題を3つ抽出して評価の観点を明記し、それぞれの評価方法を示す点が特徴的である。(2)は見直しによる複数の解決策を専門技術用語を交えて示し、(3)は市民や関係者から提起されうる懸念事項と対策案を問う。III-2は、歴史的風致形成建造物に指定された古民家を所有者が保有したまま内部公開し、観光資源として活用する事業で、地元まちづくり団体が中心となって事業実施方針を検討するという条件が付く。

**生活・住まいの課題と、緑地・防災の制度知識が、II-1とII-2の双方に現れる**。二地域居住、空家等活用促進区域、緑の基本方針、事前復興まちづくり計画と、人口減少や気候変動、災害リスクの背景が共通する。制度の仕組みだけでなく、背景として何を挙げるかを準備しておく。

# 学習ガイド

**出題形式ごとに答案の型を固定する**。II-1は「制度の正確な説明＋具体的な内容」を600字で簡潔にまとめる形式で、法令・制度の名称を正確に書けるかが大切になる。II-2は「調査・検討すべき事項→業務手順（留意点・工夫点）→関係者との調整方策」という3段構成が基本で、この型を先に決めておけば、どの設問が出ても骨格に沿って書き進められる。IIIと必須科目Iは「観点を明記した課題の抽出→最重要課題への複数の解決策→残余リスク・波及効果や懸念事項への対策」が中心で、必須科目Iはこれに倫理・社会の持続性の観点が加わる。

**III-1(1)は、課題の抽出と評価方法を対で書く**。令和8年度のIII-1(1)は、評価すべき課題3つについて、評価の観点と評価方法の両方を求めている。課題を並べるだけで終わらず、どのデータや指標で評価するのかまで書く。

**III-2は、関係者が複数いる前提を答案に反映する**。所有者、市担当部局、地元まちづくり団体が連携する条件が付いている。誰が何を担うのかを、課題の抽出や解決策の中で明示する。

**関係者調整は「グループ分けして具体的手法を書く」型で対応する**。II-2で求められる関係者調整は、行政内部、権限を持つ関係機関、住民・事業者、専門家といった形で関係者を3〜4グループに分け、それぞれに具体的な調整手法（個別協議・説明会・ワークショップ・サウンディング調査など）を挙げる書き方が整理しやすい。

**行政（発注者）の立場を答案に明示する**。本書の選択科目の模範解答は、行政の担当責任者として調査・発注・監督・合意形成をどう進めるかという視点で一貫している。民間コンサルタントの経験が中心の方も、「発注者は何を確認し、何を審査し、どう説明責任を果たすか」を加えると、行政計画に関わる出題に対応しやすくなる。

**配点と時間配分の目安**。日本技術士会の受験案内と文部科学省の合否決定基準では、必須科目Iが40点（答案用紙3枚）、選択科目II-1が10点（1枚）、II-2が20点（2枚）、IIIが30点（3枚）で、合格基準は必須科目・選択科目ともに60％以上の得点とされています。選択科目の試験時間は合計3時間30分（210分）です。II-1に30分程度、II-2に60分程度、IIIに100分程度を目安とし、残りを見直しに充てる進め方が一つの目安になります。設問選択は冒頭で全設問に目を通し、骨格を確実に書ける設問を選ぶことを優先してください。制度の数字は受験する年度の公表資料でも確かめてください。
