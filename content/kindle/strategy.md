# Kindle 出版の方針と手順（KDP）

**更新日**: 2026-11-28（運営者の決定「note と併売・全巻セレクト・1 冊 ¥1,650 以下・可能な限り分冊・合本の廃止」を受けて全面改稿）
**位置付け**: Kindle の企画の正本（判断・巻の構成・公開の期限・制作と提出の手順）。収益化全体は [04_収益化戦略.md](../../docs/strategy/04_収益化戦略.md)。

> [!important] 正本の分担
> - **一覧（書籍 id・ASIN・状態・価格・版・公開の予定・置き換え関係）は台帳だけが持つ**: `config/products.json` の Kindle の `catalog`。人は管理画面の「販売状態 → Kindle」で見る（シリーズと巻の順・収録記事・次の予定・受取の推移）。この文書に一覧を写さない
> - 書き換えは `npm run product -- set kindle-<id> <欄> <値>`、新しい巻は `npm run product -- add <JSON>`
> - ビルド定義は `content/kindle/books/<id>/spec.json`、書き下ろしの前付けは同じフォルダの `front-matter.md`

## 1. 方針（2026-11-28 運営者決定）

1. **note と KDP で同じ教材を併売する。** note と Amazon では買う人が違い、KDP には独自の検索と Kindle Unlimited がある
2. **全巻を KDP セレクトに入れ、日本 70% で売る。** 中身は note と同じだが細部（前付け・構成）が違うので、セレクトの独占の条件には当たらないと運営者が判断した
3. **1 冊 ¥1,650 以下にする**（日本の 70% は税込 ¥250〜¥1,650 かつセレクト登録が条件）。¥1,650 を超えると 35% になり、¥1,980 で受取 ¥630・¥2,980 でも ¥948 と、¥1,650 の ¥1,049 を下回る
4. **可能な限り分冊する。** 年度で並ぶ本は年度ごとに 1 巻にし、同じ年に受ける科目は 1 巻にまとめる。毎年は新しい年度の巻を足すだけで、既刊は直さない
5. **合本は廃止する。** 分冊と中身が重なる合本（A-00・d-00・c-I）は販売停止にする
6. **今回は全巻を出品できる状態（ready）まで作る。** KDP への提出・価格変更・セレクト加入・販売停止は、台帳の `plans`（action と予定日）に沿って、1 冊ずつ運営者の承認を得て行う

> [!warning] 見方の違いと予備の案
> Claude の見方: KDP の規約は読者層の違いを考えない。CTA の除去や前付けの違い程度では、別の本と見なされない可能性がある（判断とリスクは運営者が負う）。
> KDP から規約の通知が来たら: note・サイトと中身が重なる本のセレクトを外し（日本 35%）、35% では価格が高いほど受取が増えるので値上げする（例: 建設部門二次は 1 冊 ¥2,980・受取 ¥948、コンクリートは ¥1,650〜¥1,980）。分冊は 35% では効かないので、そのときは巻をまとめ直す。

## 3. 売上と受取の仕組み

| 月 | 受取 | うち電子書籍 | うち KENP |
|---|---|---|---|
| 2026-08 | ¥6,043 | ¥5,159 | ¥884 |
| 2026-09 | ¥9,988 | ¥7,742 | ¥2,246 |
| 2026-10 | ¥10,555 | ¥7,510 | ¥3,045 |
| 2026-11（11/21 まで・推計） | ¥22,750 | ¥19,256 | ¥3,494 |

- 売上の約 8 割は技術士 建設部門 二次。本ごと・月ごとの値は管理画面（`data/kdp/royalties.json`）で見る。取り直しは運営者が `node scripts/ops/weekly-collect.mjs --only kdp`
- 1 冊の受取: 70%（セレクト）は税抜価格 × 70% − 配信料で、¥980→約 ¥623、¥1,250→約 ¥795、¥1,650→約 ¥1,049。35% は税抜価格 × 35%
- 同じ中身なら 1 冊の受取は note（手数料 約 16%）が Kindle の 2〜3 倍ある。Kindle は Amazon で探す人への入口

|---|---|---|

| 技術士 第二次試験（建設部門・総監） | 7 月 | 2027-05 |
| 1級土木 第1次検定 | 7 月 | 2027-05 |
| 1級・2級土木 第2次検定 | 10 月 | 2027-08 |
| 技術士 第一次試験・RCCM・コンクリート主任技士 | 11 月 | 2027-09 |

- 新規の提出は週 10 冊まで（KDP の作成数の制限。詳細は `kdp-publish` スキル）。約 115 巻で約 12 週
- 販売中の本を巻に置き換えるときは、新規作成でやり直さず既存の ASIN へ原稿を差し替える（同じ本が 2 つできる。2026-07 の e-01 で発生）

## 5. 制作の手順

構成の設計（Generator）・ビルド（決まったスクリプト）・評価（Evaluator）を分ける。エージェントの詳細は [agents-registry.md](../../.claude/knowledge/reference/agents-registry.md)、入口は `/kindle-build <id>`。

| 系列 | ビルダー |
|---|---|
| 1級 第1次検定 論点別（A） | `scripts/build/build-takuitsu-reconstruct.mjs --theme <key>`（spec なし・theme が台帳の `buildTheme`） |
| 総監 択一・技術士一次・第1次検定の年度別・コンクリート（B・D・E・G） | `scripts/build/build-pe1-kindle.mjs --spec <spec.json>` |
| 記述・模範解答（C・I・J・H） | `scripts/build/build-essay-kindle.mjs --spec <spec.json>`（1 記事 1 章） |

1 巻の流れ:
1. spec を作り、台帳に `status: draft` と `plans` つきで行を足す
2. `kindle-book-composer` が書き下ろしの前付け（はじめに・出題傾向・学習ガイド）と KDP の販売文（`config/kdp-memo.json` の `books[id]`）を書き、`npm run gen-kdp-memo`
3. 表紙を作る（`npm run kindle-pop-cover`）
4. ビルド → `epubcheck`（エラー・警告 0）→ `npm run check-kindle-format`（入稿前の必須ゲート。可読性・章の改ページ・解答の改ページ・選択肢の連番）→ `kindle-book-qa`（原稿の完全性・構成・EPUB・KDP の規約・商品性の 5 軸）。FAIL は直して再ビルド
5. Kindle Previewer 3 で目視（目次・改ページ・数式・画像）。GUI なので運営者が行う
6. 合格したら台帳を `status: ready` にする
7. 提出と出版は `/kdp-publish`（`kdp-operator`）。出版後は台帳に ASIN と `versionHistory` を記録する（記録先は台帳だけ）

## 6. つまずきやすい点

- **選択肢の番号が全部「1.」になる**: 原稿の空行入りリストをパーサーが選択肢ごとの `<ol>` に分けると番号がリセットされる。`check-kindle-format` の R4 が止める（D 系で実発生）
- **epubcheck は内容の破損を見ない**: 図の取り違え・番号のリセット・サイト専用部品の漏れは `kindle-book-qa` でしか出ない。複数冊の QA を見比べると系統的なバグが出る
- **拡張子 .svg の JPEG があると KDP が処理に失敗する**（epubcheck は通る）。詳細と原稿差し替え後の確認チェックの外れは memory の `.claude/memory/reference_kdp_price_change_gotchas.md` と `kdp-publish` スキル
- **アーカイブは本棚から隠すだけ**: 販売中の本をアーカイブしても売れ続ける。販売停止は必ず出版停止をしてからアーカイブする。停止した本は本棚で「下書き」と表示されるが、下書きの一括削除の対象にしない
- **版の管理**: EPUB を再アップしたら台帳の `version` を上げ、`versionHistory` に 1 行足す。配布物は `scripts/kindle-dist/<id の小文字>.(epub|jpg)` に置き、`node scripts/storage/asset-offload.mjs --group kindle-dist --include-untracked --commit` で private R2 へ上げる（手元に無ければ `npm run asset-hydrate -- --group kindle-dist`）

## 7. 内容の注意

- **出典**: 技術士は日本技術士会、土木施工管理は全国建設研修センター、コンクリートは日本コンクリート工学会（JCI）。EPUB に出典と免責を入れる。問題があれば KDP から取り下げる
- **g-01 の問題は過去問ではない**: 出題分野に沿って作った演習問題。商品説明と前付けで明示する（g-02 は実際の過去問）
- **RCCM（h-01）は過去問を収録しない**: `spec.creditBody` で出典文を「協会公開テーマを一次出典・全て自作」に上書きする（ビルダーの既定文は偽になる）
- **1級 第1次検定 論点別（A）**: 論点の分類は設問の見出し文（lead）の判定と除外の正規表現で行う。図に頼る設問は自動で除く。元データの解説の補完は `civil-1-exam-questions.json` 側にあり、パーサーを再実行すると上書きされる
- **無料公開と重なる中身**: KDP には Web で無料公開の中身を制限するガイドラインがある。書き下ろしの前付け・論点の再構成・出典の明示で、サイトに無い編集物にする
