# 第3節 行政作用の類型

行政作用の類型には様々なものがありますが、特に**行政行為**が試験対策上は重要です。まず行政行為を重点的に学習しましょう。

---

## 1 行政作用とは何か

行政の作用（権力作用と非権力作用をあわせたもの）を類型化すると、以下のものがあります。

| 種類 | 内容 |
|---|---|
| **行政行為** | 行政庁が法律に基づき、一方的に国民の権利義務を変動させる行為 |
| **行政立法** | 行政機関が法規範を定立する行為 |
| **行政計画** | 行政目標を設定し、その達成手段を総合的に示す行為 |
| **行政契約** | 行政主体が契約の当事者として行う行為 |
| **行政指導** | 行政機関が、相手方の任意の協力を前提として行う指導、勧告等 |
| **行政調査** | 行政機関が行政目的達成のために行う調査 |
| **行政上の強制執行** | 行政上の義務の不履行に対する強制的実現 |
| **行政罰** | 行政上の義務違反に対する制裁 |

---

## 2 行政行為

### （1）行政行為とは何か

**行政行為**とは、行政庁が、法律に基づき、**一方的に**国民の権利義務を具体的に決定する行為をいいます。

行政行為は、国民の権利義務に影響を与えますから、法律による行政の原理（**法律の留保の原則**）により、**法律の根拠が必要**です。

### （2）行政行為の種類

行政行為は、大きく**法律行為的行政行為**と**準法律行為的行政行為**に分けられます。

#### 法律行為的行政行為

法律行為的行政行為とは、行政庁の**意思表示**の内容に基づいて法律効果が生じるものをいいます。

| 種類 | 意味 | 具体例 |
|---|---|---|
| **命令的行為** | | |
| 下命 | 国民に対して一定の作為義務を課す | 違法建築物の除却命令 |
| 禁止 | 国民に対して一定の不作為義務を課す | 営業停止命令 |
| 許可 | 法令による一般的禁止を特定の場合に解除する | 営業許可、建築許可、運転免許 |
| 免除 | 特定の義務を解除する | 就学義務の免除 |
| **形成的行為** | | |
| 特許 | 新たに権利や法律上の地位を設定する | 鉱業権設定、公有水面埋立免許、道路占用許可 |
| 認可 | 第三者の行為を補充してその法律上の効力を完成させる | 農地の権利移転の許可、ガス料金の認可 |
| 代理 | 第三者のなすべき行為を行政機関が代わって行う | 土地収用裁決 |

:::note 許可と特許の違い

**許可**は、もともと国民が有している自由を一般的に禁止した上で、特定の場合に解除するものです（例：運転免許）。

**特許**は、国民がもともと有していない権利や地位を新たに設定するものです（例：鉱業権の設定）。

:::

#### 準法律行為的行政行為

**準法律行為的行政行為**とは、行政庁が一定の判断や認識を表示し、それに対して法律が一定の効果を付与するものをいいます。行政庁の意思表示ではなく、認識したことを表示することにより生じるものです。

| 種類 | 意味 | 具体例 |
|---|---|---|
| **確認** | ある事実や法律関係の存否を確認する行為 | 当選人の決定、発明の特許 |
| **公証** | ある事実や法律関係の存在を公に証明する行為 | 選挙人名簿への登録、不動産登記 |
| **通知** | 特定の者に対して一定の事実を知らせる行為 | 代執行の戒告、納税の督促 |
| **受理** | 他人の行為を有効な行為として受け入れる行為 | 届出の受理 |

#### 準法律行為的行政行為の特徴

準法律行為的行政行為は、確認、公証、通知、受理の4種類に分けられます。

行政行為の種類について整理すると、以下のようになります。

```
行政行為
├── 法律行為的行政行為
│   ├── 命令的行為
│   │   ├── 下命
│   │   ├── 禁止
│   │   ├── 許可
│   │   └── 免除
│   └── 形成的行為
│       ├── 特許
│       ├── 認可
│       └── 代理
└── 準法律行為的行政行為
    ├── 確認
    ├── 公証
    ├── 通知
    └── 受理
```

### （3）行政行為の効力

行政行為は、有効な行政行為として一定の効力をもっています。行政行為の効力には次のものがあります。

| 効力 | 内容 |
|---|---|
| **公定力** | 行政行為は、たとえ違法であっても、正当な権限をもつ機関（裁判所や行政庁）によって取り消されるまでは、一応有効なものとして扱われるという効力 |
| **不可争力** | 行政行為について一定の期間が経過すると、もはやその行政行為の効力を争うことができなくなるという効力（出訴期間の経過） |
| **不可変更力** | 行政行為を行った行政庁自身が、その行政行為を取り消したり変更したりすることができなくなるという効力（裁決・決定について認められる） |
| **自力執行力** | 行政行為の内容を、行政庁自らが強制的に実現できるという効力（すべての行政行為に認められるわけではない） |

:::note 公定力のポイント

公定力があるということは、行政行為が**違法であっても当然に無効ではない**ということです。国民は、取消訴訟等の正式な手続を経なければ、行政行為の効力を否定することができません。

ただし、行政行為に**重大かつ明白な瑕疵**がある場合は、その行政行為は**当然に無効**であり、公定力は働きません。

:::
