# 行政裁量

## （7）行政裁量

### （1）行政裁量とは何か

**行政裁量**とは、行政行為を行うに際して、行政庁に認められる判断の余地（裁量の幅）をいいます。

### 覊束行為と裁量行為

行政行為は、行政庁に裁量が認められるかどうかにより、以下の2種類に分けられます。

| 種類 | 内容 |
|---|---|
| **覊束行為** | 法律の要件に該当すれば、行政庁は一定の行為をしなければならない（裁量なし） |
| **裁量行為** | 法律の要件に該当しても、行政庁に判断の余地が認められている（裁量あり） |

以下では、この規定を例にとって、覊束裁量・効果裁量について考えます。

:::note 要件裁量と効果裁量

**要件裁量**とは、行政行為の要件の認定について行政庁に認められる裁量をいいます。

**効果裁量**とは、行政行為の効果（どのような処分をするか）について行政庁に認められる裁量をいいます。

行政庁は、「認められる」「認めることができる」といった文言がある場合に効果裁量が認められると考えられています。

:::

### 裁量の司法審査

裁量行為であっても、裁量権の行使が合理性を欠く場合には、裁判所による司法審査の対象となります。

:::info 重要判例 -- 行政裁量と司法審査

### 神戸税関事件（最判昭52.12.20）

**事案**: 税関職員に対する懲戒処分（免職処分）が、裁量権の逸脱・濫用にあたるかが争われた。

**判旨**: 懲戒権者は、懲戒事由に該当すると認められる行為の原因、動機、性質、態様、結果、影響等のほか、当該公務員の当該行為の前後における態度、懲戒処分等の処分歴、選択する処分が他の公務員及び社会に与える影響等、諸般の事情を考慮して、懲戒処分をすべきかどうか、また、懲戒処分をする場合にいかなる処分を選択すべきかを、その**裁量により決定することができる**。

:::

### （2）行政裁量の有無の判定

裁量が認められるかどうかの判定にあたっては、以下の要素が考慮されます。

| 考慮要素 | 内容 |
|---|---|
| **法律の文言** | 「できる」「認めることができる」→ 裁量あり、「しなければならない」→ 覊束 |
| **行為の性質** | 専門技術的判断が必要 → 裁量が広い |
| **権利利益の重大性** | 国民の権利利益への影響大 → 裁量は狭い |

### （3）行政裁量の逸脱・濫用

裁量行為について、行政庁の判断が合理性を欠く場合には、**裁量権の逸脱・濫用**として違法となります。

:::info 重要判例 -- 裁量権の逸脱・濫用

### 再入国不許可処分と裁判裁量（最判平4.10.29）

**事案**: 外国人の再入国不許可処分が裁量権の逸脱・濫用にあたるかが問題となった。

**判旨**: 再入国の許否の判断にあたっては、外国人の在留状況、渡航の目的、渡航の必要性、渡航先の国の情勢等を考慮して判断すべきであり、これらの事情を全く考慮せずになされた処分は、**裁量権の逸脱・濫用**として違法となりうる。

:::

### （4）行政裁量に対する司法審査

そこで、実際に行われた行政行為の裁量権の逸脱・濫用について、裁判所はどのような判断基準で審査するのかが問題となります。

#### 裁量審査の手法

| 手法 | 内容 |
|---|---|
| **社会観念審査** | 行政行為が社会通念に照らし著しく妥当性を欠くかどうかを審査 |
| **判断過程審査** | 行政庁の判断過程に合理性があるかどうかを審査（考慮すべき事項を考慮したか、考慮すべきでない事項を考慮しなかったか） |

**判断過程審査**とは、行政庁が行った裁量判断の過程に着目して、その判断過程に合理性があるかどうかを審査する方法です。この判断過程審査を行った判例として、以下があります。

:::info 重要判例 -- 判断過程審査

### 日光太郎杉事件（東京高判昭48.7.13）

**事案**: 日光東照宮付近の杉並木の伐採を伴う道路拡幅事業について、土地収用法に基づく事業認定が争われた。

**判旨**: 事業認定の判断過程において、本件土地の文化的価値を適切に考慮せず、これを過小に評価した点で、**裁量権の行使に違法**がある。

:::

:::info 重要判例 -- 裁量審査

### 群馬県教組事件（最判平4.3.6）

**事案**: 教職員の争議行為に対する懲戒処分について、裁量権の逸脱・濫用が争われた。

**判旨**: 裁量権の行使に基づく処分が社会観念上著しく妥当性を欠き、裁量権を付与した目的を逸脱し、これを濫用したと認められる場合に限り、違法であると判断する。

:::

:::info 重要判例 -- 裁量審査と比較衡量

### 小田急高架訴訟本案判決（最判平18.11.2）

**事案**: 小田急線の高架化に伴う都市計画事業認可の取消しが争われた。

**判旨**: 裁量権の逸脱・濫用の有無は、その基礎とされた重要な事実に誤認があること等により重要な事実の基礎を欠くこととなる場合、又は、事実に対する評価が明らかに合理性を欠くこと、判断の過程において考慮すべき事情を考慮しないこと等によりその内容が社会通念に照らし著しく妥当性を欠くものと認められる場合に限り、裁量権の逸脱又は濫用として違法となる。

:::

:::note 補足

なお、裁判所は、実際の行政行為について裁量・覊束を複数の観点から判断するのであり、下級審と最高裁で判断が分かれることもあります。

:::
