# 仮の救済

仮の救済には、取消訴訟が提起された場合になりうる**執行停止**と、義務付け訴訟又は差止め訴訟の場合になされる**仮の義務付け・仮の差止め**があります。それぞれの要件を整理して覚えましょう。

## 1 執行停止

### （1）執行停止の意義

取消訴訟の提起は、処分の効力、処分の執行又は手続の続行を妨げません（25条1項）。これを**執行不停止の原則**といいます。

つまり、取消訴訟を提起しただけでは、処分の効力は停止せず、処分の内容は引き続き実現されることになります。

しかし、取消訴訟の係属中に処分が執行されると、判決を得ても意味がなくなるおそれがあります。そこで、一定の要件のもとで処分の効力等を停止させる制度が**執行停止**です。

### （2）執行停止の要件

執行停止が認められるためには、以下の要件を充たす必要があります。

1. **取消訴訟が提起されていること**（本案係属要件）
2. **重大な損害を避けるため緊急の必要があること**（25条2項）
3. 執行停止が**公共の福祉に重大な影響を及ぼすおそれがない**こと（25条4項、消極要件）
4. **本案について理由がないとみえない**こと（25条4項、消極要件）

:::note 執行停止の要件
- **積極要件**：重大な損害を避けるため緊急の必要があること
- **消極要件**：公共の福祉に重大な影響を及ぼすおそれがないこと、本案について理由がないとみえないこと
:::

### 【執行停止の要件】

| 要件 | 内容 |
|---|---|
| **本案係属** | 取消訴訟が係属していること |
| **重大な損害・緊急の必要** | 重大な損害を避けるため緊急の必要があること |
| **公共の福祉** | 公共の福祉に重大な影響を及ぼすおそれがないこと |
| **本案の理由** | 本案について理由がないとみえないこと |

### （3）執行停止の手続

執行停止の決定は、**当事者の申立て**により行います。裁判所は職権で執行停止をすることはできません（25条2項）。

ただし、処分の効力の停止は、処分の効力の停止以外の措置（処分の執行の停止又は手続の続行の停止）によって目的を達することができる場合には、することが**できません**（25条3項。**内容の補充性**）。

執行停止の決定が確定した場合には、その理由が消滅し、その他事情が変更したときは、相手方の申立てにより、決定をもって、執行停止の決定を**取り消すことができます**（26条1項）。

### （4）内閣総理大臣の異議

執行停止の決定に対しては、**内閣総理大臣の異議**の制度があります（27条）。

内閣総理大臣は、執行停止の決定がされた後において、**異議を述べること**ができます。異議を述べたときは、裁判所は執行停止の決定を取り消さなければなりません。

また、内閣総理大臣は、執行停止の申立てがあった場合にも、裁判所に対し異議を述べることができ、異議があったときは、裁判所は執行停止をすることが**できません**。

:::caution 重要
内閣総理大臣の異議は、やむことをえない場合を除き、あらかじめ**内閣の了承**を得なければなりません（27条4項）。

なお、内閣総理大臣は、異議を述べたときは、次の常会において**国会にこれを報告**しなければなりません（27条6項）。
:::

### 【行政不服審査法と行政事件訴訟法の執行停止】

| | 行政不服審査法 | 行政事件訴訟法 |
|---|---|---|
| **原則** | 執行不停止 | 執行不停止 |
| **手続** | 職権又は申立て | **申立てのみ** |
| **要件** | 必要があると認めるとき | 重大な損害を避けるため緊急の必要があるとき |
| **処分の効力の停止** | 補充性あり | 補充性あり |
| **内閣総理大臣の異議** | なし | **あり** |

## 2 仮の義務付け・仮の差止め

**仮の義務付け**とは、義務付け訴訟（仮の義務付け）や差止め訴訟（仮の差止め）が提起された場合において、仮に処分をすべき旨又は仮に処分をしてはならない旨を命ずるものです。

### 【仮の救済】

| 類型 | 執行停止 | 仮の義務付け・仮の差止め |
|---|---|---|
| **本案訴訟** | 取消訴訟 | 義務付け訴訟・差止め訴訟 |
| **発動方法** | 申立て | 申立て |
| **要件（積極）** | 重大な損害を避けるため緊急の必要 | **償うことのできない損害**を避けるため緊急の必要 |
| **要件（消極）** | 公共の福祉に重大な影響×、本案理由なしとみえない | 公共の福祉に重大な影響×、本案理由あるとみえる |
| **内閣総理大臣の異議** | あり | なし |

仮の義務付け・仮の差止めの要件は、執行停止と比較して**より厳格**です。「重大な損害」ではなく「**償うことのできない損害**」が要件となり、また「本案について理由がないとみえない」ではなく「**本案について理由があるとみえる**」ことが必要です。

# 教示

教示については、行政不服審査法と合わせて学習しましょう。本章では行政事件訴訟法における教示制度を確認します。両者の違いを整理しておきましょう。

## 1 教示とは何か

教示とは、行政庁が処分をする際に、訴訟による救済方法を処分の相手方に教えることをいいます。

この教示制度は、平成16年の行政事件訴訟法改正によって導入されたものです。

## 2 教示の内容

### （1）取消訴訟

行政庁は、取消訴訟を提起することができる処分をする場合には、処分の相手方に対し、以下の事項を**書面で教示**しなければなりません（46条1項）。

1. 当該処分に係る取消訴訟の**被告とすべき者**
2. 当該処分に係る取消訴訟の**出訴期間**
3. 審査請求前置が定められている場合にあっては、その旨

:::tip ポイント
行政事件訴訟法上、処分の相手方に対する教示は**書面**で行わなければなりません。口頭で処分をする場合であっても、教示義務を負います。

なお、行政不服審査法と異なり、**利害関係人**に対する教示義務の規定はありません。
:::

### （2）形式的当事者訴訟

行政庁は、実質的当事者訴訟を提起することができる処分又は裁決をする場合には、処分又は裁決の相手方に対し、**被告とすべき者**や**出訴期間**を書面で教示しなければなりません（46条2項）。

### 【行政不服審査法と行政事件訴訟法の教示】

| | 行政不服審査法 | 行政事件訴訟法 |
|---|---|---|
| **処分の相手方** | 教示義務あり | 教示義務あり |
| | 口頭で処分をする場合は、教示義務なし | **書面による教示義務あり** |
| **利害関係人** | 教示を求められた場合、教示義務あり | 教示義務**なし** |
| | 書面による教示を求められた場合、書面による教示義務あり | ― |
| **誤った教示などの教示規定** | あり | **なし** |

:::info 過去問チェック
- 当該処分又は裁決の相手方以外の者であっても、教示を求められた場合には、行政庁は教示をする義務がある。 → **×**（18-19-4）
- 処分が口頭でされる場合、行政庁は教示義務を負わない。 → **×**（18-19-5）
:::
