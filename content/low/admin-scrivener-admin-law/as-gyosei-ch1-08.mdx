# 第5節 行政上の強制措置

行政上の強制措置については、まず全体像を把握することが重要です。その後、各制度の具体的な内容を学習しましょう。行政代執行法の条文を中心に学んでいきます。

---

## 1 行政上の強制措置の全体像

行政法を守るために国民が自らの行為によって義務を履行しない場合に、行政機関が強制的にその義務の履行を実現する手段が**行政上の強制措置**です。

行政上の強制措置は、大きく**行政上の強制執行**と**即時強制**に分けられます。

```
行政上の強制措置
├── 行政上の強制執行
│   ├── 代執行
│   ├── 執行罰（強制金）
│   ├── 直接強制
│   └── 強制徴収
└── 即時強制
```

---

## 2 行政上の強制執行

**行政上の強制執行**とは、行政上の義務が履行されない場合に、行政機関が自ら強制的に義務の履行を実現し、または義務が履行された場合と同じ状態を実現する制度です。

行政上の強制執行には、代執行、執行罰、直接強制、強制徴収の4種類があります。

:::info 重要判例 -- 行政上の強制執行

### 宝塚市パチンコ店規制条例事件（最判平14.7.9）

**事案**: 宝塚市が条例でパチンコ店の建築を規制し、条例に違反した建築主に対して建築工事の中止命令を発したが、建築主がこれに従わなかったため、市が建築続行禁止の訴訟を提起した。

**判旨**: 国又は地方公共団体が**専ら行政権の主体として**国民に対して行政上の義務の履行を求める訴訟は、**法律上の争訟に当たらない**（不適法として却下）。行政上の義務の履行確保は、行政代執行法等の行政上の強制執行の手段によるべきであり、司法的執行（民事訴訟）は認められない。

:::

行政上の強制執行には、代執行、執行罰、直接強制、強制徴収の4種類があります。

### （1）代執行（行政代執行法）

#### （1）代執行とは何か

**代執行**とは、法律に基づく行政行為により命じられた**代替的作為義務**（他人が代わって行うことができる義務）を義務者が履行しない場合に、行政庁が自ら義務者のなすべき行為をし、またはこれを第三者にさせ、その費用を義務者から徴収する制度です（行政代執行法2条）。

代執行を行うための要件は、以下のとおりです（2条）。

1. **法律**（法律の委任に基づく命令、規則及び条例を含む）により直接命じられ、又は法律に基づく行政行為により命じられた行為であること
2. **他人が代わってなすことができる行為**（代替的作為義務）であること
3. 義務者がこれを**履行しない**こと
4. **他の手段**によってその履行を確保することが**困難**であること
5. その不履行を放置することが著しく**公益に反する**と認められること

#### （2）代執行の手続

代執行の手続は、以下の順序で行われます。

| 手続 | 内容 |
|---|---|
| **1. 戒告** | 相当の履行期限を定め、その期限までに履行がなされないときは代執行をなすべき旨を**文書で**戒告する（3条1項） |
| **2. 代執行令書の通知** | 代執行をなすべき時期、代執行のために派遣する執行責任者の氏名、代執行に要する費用の概算による見積額を義務者に通知する（3条2項） |
| **3. 代執行の実施** | 執行責任者は、その者が執行責任者たる本人であることを示す**証票を携帯**し、要求があるときはいつでもこれを呈示しなければならない（4条） |
| **4. 費用の徴収** | 代執行に要した費用は、**国税滞納処分の例により**徴収することができる（5条、6条） |

:::note 非常の場合

非常の場合または危険切迫の場合において、代執行の急速な実施について緊急の必要があり、戒告・代執行令書の手続をとる暇がないときは、その手続を経ないで代執行をすることができます（3条3項）。

:::

### （2）執行罰

**執行罰**（間接強制）とは、義務の不履行に対して一定の過料を科すことを通告して、間接的に義務の履行を促す制度です。

執行罰は、義務者が義務を履行するまで**繰り返し科すことができる**点が特徴です。

現行法上、執行罰の制度を採用しているのは、**砂防法**36条のみです。

### （3）直接強制

**直接強制**とは、義務者の身体又は財産に対して直接に実力を行使して、義務が履行された場合と同じ状態を実現する制度です。

直接強制は、国民の権利に対する侵害の程度が大きいため、現行法上、個別の法律で認められている場合に限り行うことができます（一般法はない）。

### （4）行政上の強制徴収

行政上の**強制徴収**とは、国税・地方税の滞納処分のように、金銭債権について行政庁が自ら強制的に徴収する制度です。

これについて最高裁判所は、法律に基づかない金銭の徴収については、民事訴訟によるべきであるとしています。

---

## 3 即時強制

**即時強制**とは、義務の存在を前提とせず、行政機関が直接に国民の身体又は財産に対して実力を行使して、行政上の目的を達成する制度をいいます。

即時強制は、義務の不履行を前提としない点で、行政上の強制執行と異なります。

| | 行政上の強制執行 | 即時強制 |
|---|---|---|
| **前提** | 義務の不履行 | 義務の存在を前提としない |
| **法律の根拠** | 必要 | 必要 |
| **具体例** | 代執行、強制徴収 | 感染症患者の強制入院、酒酔い者の保護 |

なお、即時強制については、個別の法律にその手続を定めている規定は見受けられますが、通則的な規定は存在しません。

---

## 4 行政罰

### （1）行政罰とは何か

**行政罰**とは、行政上の義務違反に対して科せられる制裁のことをいいます。

行政罰は、**行政刑罰**と**秩序罰**の2種類に分けられます。

| 種類 | 内容 | 科す手続 |
|---|---|---|
| **行政刑罰** | 行政法上の義務違反に対して科される刑罰（懲役、罰金、拘留、科料等） | **刑事訴訟法**の手続による（原則として裁判所が科す） |
| **秩序罰（過料）** | 行政法上の義務違反のうち、比較的軽微なものに対して科される金銭的制裁 | **非訟事件手続法**による（裁判所が科す場合）、または地方自治法による（地方公共団体の長が科す場合） |

:::note 行政刑罰と秩序罰の違い

- **行政刑罰**は刑法総則の適用があるが、**秩序罰**には刑法総則の適用がない
- 行政刑罰を科す場合は**刑事訴訟法**の手続によるが、秩序罰を科す場合は**非訟事件手続法**等の手続による
- 同一の義務違反に対して行政刑罰と秩序罰の**両方を科すことはできない**が、行政刑罰と**執行罰**を併科することは可能

:::

### 行政刑罰と秩序罰の比較

| | 行政刑罰 | 秩序罰 |
|---|---|---|
| **対象** | 義務違反のうち重大なもの | 義務違反のうち軽微なもの |
| **種類** | 懲役、禁錮、罰金、拘留、科料 | 過料 |
| **手続** | 刑事訴訟法の定めるところによる | 非訟事件手続法等 |
| **刑法総則の適用** | あり | なし |
| **前科** | つく | つかない |
