# 第2節 行政組織法

ここでは、行政組織に関する専門用語の意味と具体例について学習します。行政組織法では、行政の仕組みや組織について規定されています。

---

## 1 行政主体と行政機関

### （1）行政主体

**行政主体**とは、行政活動を行う権利と義務を有し、自己の名と責任において行政活動を行う法人のことです。

行政主体には以下の種類があります。

| 分類 | 具体例 |
|---|---|
| **国** | 国（中央政府） |
| **地方公共団体** | 都道府県、市町村、特別区 |
| **独立行政法人** | 各種独立行政法人 |
| **特殊法人** | 日本放送協会（NHK）など |
| **認可法人** | 日本銀行など |
| **指定法人** | 指定確認検査機関など |

### （2）行政機関

行政主体は法人という肉体のない概念上の存在であるから、実際に行政主体のために意思を決定し、それを国民に対して表示する機関が必要です。これが**行政機関**です。

行政機関は、行政法学上、次の種類に分けられます。

#### 行政庁

**行政庁**とは、行政主体の法律上の意思を決定し、外部に対してこれを表示する権限をもつ機関です。行政庁は一人の人間の場合（独任制）と合議体の場合（合議制）があります。

| 種類 | 具体例 |
|---|---|
| **独任制** | 各省大臣、都道府県知事、市町村長、税務署長 |
| **合議制** | 公正取引委員会、教育委員会、人事院、公害等調整委員会 |

#### 補助機関と自問機関

**補助機関**とは、行政庁の意思決定を補助する機関です（例：副知事、副大臣、事務次官）。

**諮問機関**とは、行政庁の諮問に応じて意見を述べる機関です。諮問機関の答申は行政庁を法的に拘束しません。

#### 参与機関

**参与機関**とは、行政庁の意思を拘束する議決を行う機関のことです。参与機関の議決は行政庁を法的に拘束します。

**諮問機関との違い**: 諮問機関は行政庁に対して参考意見を述べるだけで拘束力がないのに対し、参与機関の議決は行政庁の意思決定を法的に拘束します。

#### 監査機関

**監査機関**とは、行政機関の事務や会計の処理を検査する機関のことです。

---

## 2 行政機関の権限

### （1）指揮監督権

行政機関相互の関係として、上級行政機関は下級行政機関に対して**指揮監督権**を有しています。

指揮監督権の内容としては、以下のものがあります。

| 種類 | 内容 |
|---|---|
| **監視権** | 下級行政機関の事務処理を監視する権限 |
| **訓令権** | 下級行政機関に対して命令を発する権限（通達はこれに基づく） |
| **取消権・停止権** | 下級行政機関の行為を取り消し、または停止する権限 |
| **裁定権** | 下級行政機関間の紛争を裁定する権限 |

上級行政機関は、指揮監督権に基づき、法律の特別の根拠がなくても下級行政機関の事務処理について指揮監督することができます。

### （2）権限の代行

行政機関の権限は法律によって定められていますが、これを他の行政機関が代わりに行使する場合があります。

#### 権限の委任

**権限の委任**とは、ある行政機関の権限の一部を、他の行政機関に移転することをいいます。

| 項目 | 内容 |
|---|---|
| **権限の移転** | ○（委任した行政機関はその権限を失う） |
| **権限の範囲** | 一部 |
| **法律の根拠** | **必要** |

#### 権限の代理

**権限の代理**とは、ある行政機関の権限の行使を、他の行政機関が代わりに行うことです。代理する機関は、被代理機関の名において権限を行使します。

| 種類 | 内容 |
|---|---|
| **授権代理** | 行政機関自身の意思に基づいて代理権を授与するもの。権限の範囲は一部。法律の根拠は**不要** |
| **法定代理** | 法律の規定によって当然に代理権が発生するもの。権限の範囲は全部。法律の根拠は**必要** |

**権限の委任との違い**: 権限の代理の場合、代理する機関は被代理機関の**名前で**権限を行使するだけであり、権限そのものが移転するわけではありません。

#### 権限の委任と代理の比較

| | 権限の委任 | 授権代理 | 法定代理 |
|---|---|---|---|
| **権限の移転** | ○ | × | × |
| **権限の範囲** | 一部 | 一部 | 全部 |
| **法律の根拠** | 必要 | 不要 | 必要 |

#### （3）専決・代決

**専決**とは、法律によって権限を与えられた行政機関が、補助機関に対してその権限に関する事務の処理を委ねることをいいます。

また、**代決**とは、専決する人が不在の場合に、他の人が臨時にその権限に関する事務を処理することをいいます。これらは行政機関内部の問題であり、外部に対しては権限をもっている本来の行政機関の名で表示されます。

なお、専決・代決がなされても、外部に対しては権限をもっている本来の行政機関が責任を負うことになりますから、法律の根拠は**不要**です。

## 3 国の行政組織

国の行政組織については、**国家行政組織法**という法律が規定しています。

国で行政活動を担うのは**内閣**を頂点とする**行政府**です。

### （1）内閣

内閣は、首長である**内閣総理大臣**と大臣（国務大臣）から構成される合議制の機関です。

内閣の機関の下に置かれる行政機関として、以下のものがあります。

| 種類 | 具体例 |
|---|---|
| **内閣府** | 内閣の重要政策に関する企画立案・総合調整を行う |
| **デジタル庁** | デジタル社会の形成に関する施策を推進する |
| **省** | 各省（総務省、法務省、外務省、財務省、文部科学省など） |

### （2）内閣府と省

内閣府は**内閣**に置かれ（内閣府設置法）、内閣の重要政策に関する内閣の事務を助けることを任務とします。内閣府の長は、**内閣総理大臣**です。

デジタル庁も、**内閣**に置かれています（デジタル庁設置法）。

#### その他の行政機関

内閣府および各省以外にも行政機関としては、**人事院**、会計検査院、宮内庁などがあります。

なお、内閣総理大臣がもらう名称を含めたものを、公式には**外局**といいます。外局には**委員会**と**庁**があります。

| 種類 | 具体例 |
|---|---|
| **国家公安委員会** | 警察庁を管理する |
| **公正取引委員会** | 独占禁止法の運用を行う |
| **個人情報保護委員会** | 個人情報保護法の運用を行う |

### 内閣府の外局（内閣府設置法49条）

| 委員会 | 庁 |
|---|---|
| 国家公安委員会 | 金融庁 |
| 個人情報保護委員会 | 消費者庁 |
| カジノ管理委員会 | こども家庭庁 |

## 4 公務員

### （1）公務員の種類

**公務員**とは、国や地方公共団体の公的な業務に従事する人のことをいいます。

公務員は、**国家公務員**と**地方公務員**に分けられ、さらにそれぞれ**一般職**と**特別職**に分けられます。

| 分類 | 具体例 |
|---|---|
| **特別職の国家公務員** | 内閣総理大臣、国務大臣、裁判官、国会議員、自衛隊員 |
| **一般職の国家公務員** | 各省庁の職員など |
| **特別職の地方公務員** | 知事、市町村長、地方議会議員 |
| **一般職の地方公務員** | 地方公共団体の一般職員 |

### （2）公務員の身分保障

公務員は、法律または人事院規則に定める場合を除き、本人の意思に反して免職されることはありません。

| 種類 | 内容 |
|---|---|
| **懲戒処分** | 免職、停職、減給、戒告の4種類 |
| **分限処分** | 勤務成績不良、心身の故障等の場合に行われる処分（免職、休職、降任、降給） |

#### 懲戒処分の種類

| 処分 | 内容 |
|---|---|
| **免職** | 職員を強制的に退職させる |
| **停職** | 一定期間、職務に従事させない |
| **減給** | 給与を減額する |
| **戒告** | 職員の義務違反の責任を確認し、その将来を戒める |

#### 分限処分の種類

| 処分 | 内容 |
|---|---|
| **免職** | 勤務成績不良等の事由がある場合に、職員を退職させる |
| **休職** | 心身の故障その他の事由がある場合に、一定期間職務に従事させない |
| **降任** | 現在の官職より下位の官職に任命する |
| **降給** | 給与を引き下げる |

### （3）公務員の人事行政

公務員の人事行政に関しては、**人事院**（国家公務員の場合）および**人事委員会**（地方公務員の場合）が重要な役割を果たしています。

### （4）公務員の給与・勤務条件

国家公務員の給与は、法律で定められることとされています（給与法定主義）。

国家公務員は、労働基本権が制約されています。その代償措置として、**人事院**が給与その他の勤務条件の改善について勧告を行うこととされています。

## 5 公物

### （1）公物とは何か

**公物**とは、国や地方公共団体などが行政目的を達成するために所有し、または管理している物のことをいいます。

#### 利用目的による分類

| 種類 | 内容 | 具体例 |
|---|---|---|
| **公共用物** | 直接に公衆の利用に供される物 | 道路、河川、公園、海岸 |
| **公用物** | 行政主体自身の使用に供される物 | 庁舎、官舎、公用車 |

#### 成立原因による分類

| 種類 | 内容 | 具体例 |
|---|---|---|
| **自然公物** | 自然の状態で公の目的に供されるもの | 河川、海岸 |
| **人工公物** | 人工的に作られたもの | 道路、公園、庁舎 |

### （2）公物の成立と消滅

| | 公共用物 | | |
|---|---|---|---|
| | **人工公物** | **自然公物** | **公用物** |
| **成立要件** | 公用開始行為が必要 | 自然の状態で成立 | 公用開始行為が必要 |

### （3）公物の法的性質

公物は、私法の適用を全面的に排除するものではなく、**私法の適用がある**とされています。公物であっても、取得時効の対象となりうることについては、判例は以下のとおりです。

:::info 重要判例 -- 公物と時効取得

### 公物の取得時効（最判昭51.12.24）

**事案**: 公共用財産（水路）が長年の間事実上公の目的に供用されることなく放置されていた場合に、取得時効の対象となるかが問題となった。

**判旨**: 公共用財産が、長年の間事実上公の目的に供用されることなく放置され、公共用財産としての形態、機能を全く喪失し、その物のうえに他人の平穏かつ公然の占有が継続したが、そのため実際上公の目的が害されるようなこともなく、もはやその物を公共用財産として維持すべき理由がなくなった場合には、当該公共用財産については、もはや**公用が廃止されたものとして、取得時効の成立を妨げない**。

:::

### （4）公物の使用

#### （1）使用関係

公物の使用関係には、(1)一般使用、(2)許可使用、(3)特許使用の3種類があります。

| 種類 | 内容 | 具体例 |
|---|---|---|
| **一般使用** | 公物の本来の目的に沿って、自由に使用するもの | 道路の通行、公園の散歩 |
| **許可使用** | 一般使用に一定の制限を加え、許可を受けた者だけが使用できるもの | 道路占用許可 |
| **特許使用** | 公物に特定の権利を設定して使用するもの | 公有水面埋立免許 |

なお、一般使用については、以下のような判例があります。

:::info 重要判例 -- 一般使用と権利

### 道路の通行妨害の禁止を求める権利

日常生活上不可欠な道路を通行することについて、その通行を妨害されないという利益は、**反射的利益にとどまらず、法的保護に値する利益**であるとされています。

:::

#### （2）目的外使用

公物を本来の用途以外の目的で使用することを**目的外使用**といいます。目的外使用の許可を行うかどうかは、管理者の**裁量**に委ねられています。

:::info 重要判例 -- 公物の目的外使用

### 呉市学校施設使用不許可事件（最判平18.2.7）

**事案**: 広島県の公立小中学校等に勤務する教職員によって組織された職員団体が、その主催する広島県教育研究集会の会場として、呉市立中学校の体育館等の学校施設の使用を申し出たところ、呉市教育委員会から使用不許可処分を受けたため、これが違法であると主張して国家賠償請求訴訟を提起した。

**判旨**: 国家賠償請求は認められる。学校施設の目的外使用許可における裁量として、管理者の裁量に委ねられている。すなわち、学校教育上支障がないからといって当然に許可しなければならないものではないが、行政財産である学校施設の目的及び用途と目的外使用の目的・態様等との関係に配慮した**合理的な裁量判断**により、使用許可をしないこともできる。

1. 学校施設の目的外使用許可における裁量判断の原則として、管理者の裁量に委ねられている
2. 裁量判断の原考慮事項として、許可申請に係る使用の日時・場所・目的、使用の必要性の程度、許可することによって生じる支障又は許可を与えない場合の影響等の関係、代替施設確保の容易性、許可をしないことによる申請者側の不利益の内容及び程度等の事情を総合考慮すべきものである
3. 使用拒否処分の違法性として、重視すべきでない考慮要素を重視するなど、考慮した事項に対する評価が明らかに合理性を欠いており、他方、当然考慮すべき事項を十分考慮しておらず、その結果、社会通念に照らし著しく妥当性を欠いたものということができる

:::

<summary><strong>確認テスト</strong></summary>

**問1**: 行政主体のために意思を決定し、それを外部に表示する機関のことである。

→ **行政庁**

**問2**: 行政庁の権限が委任された場合でも、委任した行政庁は権限を失わず、委任を受けた機関は委任した行政庁の名でその権限を行使する。

**問3**: 国家行政組織法は、内閣の統轄の下における行政機関で内閣府以外のものについて規定している。

**問4**: 庁舎や国公立学校の校舎のように官公署の用に供される公物のことを公共用物、道路・河川・公園などのように公衆の用に供される公物のことを公用物という。

---

**解答**:
- **問1**: ○
- **問2**: × 行政庁の権限が委任された場合、委任した行政庁はその権限を失い、委任を受けた機関が自己の名と責任でその権限を行使する。
- **問3**: ○（国家行政組織法1条）
- **問4**: × 公共用物と公用物の意味が反対である。

</details>
