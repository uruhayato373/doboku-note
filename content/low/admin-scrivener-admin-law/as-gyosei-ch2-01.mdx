# 行政手続法

## 第1節 行政手続法総則

### 1 行政手続法とは何か

行政作用によって国民が不利益を受けた場合、行政不服審査法や行政事件訴訟法によって、事後的に国民の権利利益を救済する手段が用意されています。

しかし、事後的な救済だけでなく、行政作用が行われる前の段階、すなわち**事前の手続**を整備することによって、国民の権利利益を保護し、行政運営における公正の確保と透明性の向上を図ることも重要です。

そこで、行政手続法は、**処分**、**行政指導**及び**届出**に関する手続並びに**命令等を定める手続**に関し、共通する事項を定めることによって、行政運営における公正の確保と透明性の向上を図り、もって国民の権利利益の保護に資することを目的として制定されました。

### 2 行政手続法の目的

行政手続法の目的は、次のとおりです。

> 行政手続法は、処分、行政指導及び届出に関する手続並びに命令等を定める手続に関し、共通する事項を定めることによって、行政運営における**公正の確保と透明性**（行政上の意思決定について、その内容及び過程が国民にとって明らかであることをいう。）**の向上**を図り、もって**国民の権利利益の保護に資する**ことを目的とする（1条1項）。

つまり、行政手続法は、

- **行政運営における公正の確保と透明性の向上** を図ること
- **国民の権利利益の保護に資する** こと

の2つを目的としています。

なお、行政手続法は行政手続の一般法ですから、他の法律に特別の定めがある場合は、その定めが優先されます（1条2項）。また、地方公共団体の機関がする処分等については行政手続法の規定を直接適用するのではなく、行政手続法の趣旨にのっとった措置を講ずるよう努めなければならないとされています。

### 3 行政手続法の対象

行政手続法は、行政機関が行う行為に関して以下の4つのカテゴリーについて手続を定めています。

1. **処分**（申請に対する処分・不利益処分）
2. **行政指導**
3. **届出**
4. **命令等を定める手続**（意見公募手続）

行政手続法は、行政機関が行う「契約」については対象としていません。

### 4 適用除外

#### （1）行政手続法の適用になじまない行為の適用除外

行政手続法の対象から除外されます（3条1項）。これを**適用除外**といいます。

適用除外となる主なものは、以下のようなものがあります。

**【行政手続法の適用にならない行為の適用除外】**

| 分類 | 適用除外事項 |
|---|---|
| **国会の議決関連** | 国会の両院もしくは一院又は議会の議決によってされる処分 |
| **裁判所関連** | 裁判所もしくは裁判官の裁判により、又は裁判の執行としてされる処分 |
| **国会・裁判所の機関** | 国会もしくは裁判所又はこれらの機関がする処分及び行政指導 |
| **刑事事件関連** | 刑事事件に関する法令に基づいて検察官、検察事務官又は司法警察職員がする処分及び行政指導 |
| **国税・関税等** | 国税又は地方税の犯則事件に関する法令に基づいて国税庁長官等がする処分及び行政指導、関税法に基づく処分等 |
| **学校・刑務所等** | 学校、講習所、訓練所又は研修所において、教育、講習、訓練又は研修の目的を達成するために、学生等に対してされる処分及び行政指導 |
| **刑務所・留置施設等** | 刑務所、少年院その他の収容施設において収容の目的を達成するためにされる処分及び行政指導 |
| **公務員の身分関連** | 公務員又は公務員であった者に対してその職務又は身分に関してされる処分及び行政指導 |
| **外国人の出入国関連** | 外国人の出入国、難民の認定又は帰化に関する処分及び行政指導 |
| **専ら相手方の利益** | 専ら人の学識技能に関する試験又は検定の結果についての処分 |
| **審査請求関連** | 相反する利害を有する者の間の利害の調整を目的としてされる裁定その他の処分及び行政指導 |

#### （2）地方公共団体の機関の行為の適用除外

地方公共団体の機関がする処分（その根拠となる規定が条例又は規則に置かれているものに限る。）及び行政指導、地方公共団体の機関に対する届出（その根拠となる規定が条例又は規則に置かれているものに限る。）並びに地方公共団体の機関が命令等を定める行為については、行政手続法の規定は**適用されません**（3条3項）。

**【地方公共団体の機関の行為の適用除外（3条3項）】**

| 行為 | 根拠が法律 | 根拠が条例・規則 |
|---|---|---|
| **処分** | 適用あり | **適用除外** |
| **行政指導** | **適用除外** | **適用除外** |
| **届出** | 適用あり | **適用除外** |
| **命令等を定める行為** | **適用除外** | **適用除外** |

つまり、地方公共団体の機関については、**処分**と**届出**について根拠が**法律**に置かれている場合のみ行政手続法が適用され、行政指導と命令等を定める行為については根拠にかかわらず適用除外となります。

ただし、適用除外であっても、地方公共団体は行政手続法の趣旨にのっとり、行政運営における公正の確保と透明性の向上を図るため必要な措置を講ずるよう努めなければなりません（46条）。

#### （3）国の機関等に対する行為の適用除外

国の機関又は地方公共団体もしくはその機関に対する処分（これらの機関又は団体がその**固有の資格**において当該処分の相手方となるものに限る。）及び行政指導並びにこれらの機関又は団体がする届出（これらの機関又は団体がその固有の資格においてすべきこととされているものに限る。）については、行政手続法は適用されません（4条1項）。

**固有の資格**とは、一般私人が立ちえないような立場にある場合をいいます。

**【国の機関等に対する行為の適用除外（4条1項）】**

| 行為 | 一般的な場合 | 固有の資格の場合 |
|---|---|---|
| **処分** | 適用あり | **適用除外** |
| **行政指導** | **適用除外** | **適用除外** |
| **届出** | 適用あり | **適用除外** |

#### （4）特殊法人等に対する処分の適用除外

特殊法人等（法律により直接に設立された法人等）が行う業務に対する処分のうち、行政手続法の適用によりその業務の適正な遂行に支障を及ぼすおそれがあるものについては、適用除外とされています（4条2項・別表）。

## 第2節 申請に対する処分

### 1 申請に対する処分とは何か

**申請**とは、法令に基づき、行政庁の許可、認可、免許その他の自己に対し何らかの利益を付与する処分（**許認可等**）を求める行為であって、当該行為に対して行政庁が諾否の応答をすべきこととされているものをいいます（2条3号）。

つまり、申請とは、
- 法令に基づくものであること
- 許認可等の利益的処分を求めるものであること
- 行政庁が諾否の応答義務を負うものであること

の3つの要件を満たすものです。

行政手続法は、申請を出した場合に、行政庁が迅速・公正に対応することを確保するための規定を設けています。

**【申請に対する処分に関する行政庁の義務】**

| 区分 | 行政庁の義務 |
|---|---|
| **審査基準** | 申請により求められた許認可等をするかどうかを法令の定めに従って判断するために必要とされる基準を定めるよう努める（**努力義務**）。定めた場合は公にしておかなければならない（**法的義務**） |
| **標準処理期間** | 申請がその事務所に到達してから当該申請に対する処分をするまでに通常要すべき標準的な期間を定めるよう努める（**努力義務**）。定めた場合は公にしておかなければならない（**法的義務**） |
| **審査・応答** | 申請が到達したときは、遅滞なく審査を開始しなければならない（**法的義務**） |
| **理由の提示** | 拒否処分をする場合は、理由を示さなければならない（**法的義務**） |

### 2 審査基準

審査基準とは、申請により求められた許認可等をするかどうかをその法令の定めに従って判断するために必要とされる基準をいいます（2条8号ロ）。

行政庁は、審査基準を定めるものとされています（5条1項）。

審査基準の設定は**努力義務**ではなく**法的義務**です。しかし、審査基準の内容については、「できる限り具体的なものとしなければならない」とされています（5条2項）。

また、行政庁は、行政上特別の支障があるときを除き、法令により申請の提出先とされている機関の事務所における備付けその他の適当な方法により審査基準を**公にしておかなければなりません**（5条3項）。

:::tip 重要ポイント
- 審査基準の**設定**：法的義務（定めるものとする）
- 審査基準の**公表**：法的義務（公にしておかなければならない）
- 審査基準の**内容**：できる限り具体的なものとしなければならない
:::

#### 重要判例 -- 個人タクシー免許事件（最判昭46.10.28）

:::info 判例
**事案**：個人タクシーの免許申請について、運輸審議会が審査基準を内部的に設定していたが、申請者に対して十分に告知しなかった事例。

**判旨**：多数の者のうちから少数特定の者を、具体的個別的事実関係に基づき選択して免許の許否を決しようとする行政庁としては、事実の認定につき行政庁の独断を疑うことが客観的にもっともと認められるような不公正な手続をとってはならない。審査基準の内容が微妙、高度の認定を要する場合には、申請人に対し、その主張と証拠の提出の機会を与えなければならない。
:::

### 3 標準処理期間

標準処理期間とは、申請がその事務所に到達してから当該申請に対する処分をするまでに通常要すべき標準的な期間をいいます。

行政庁は、申請の処理について、標準処理期間を定めるよう**努めなければなりません**（6条）。つまり、標準処理期間の設定は**努力義務**です。

定めたときは、公にしておかなければならないとされています（6条後段）。

:::tip 重要ポイント
- 標準処理期間の**設定**：努力義務
- 標準処理期間の**公表**：法的義務（定めた場合に限る）
:::

### 4 申請に対する審査・応答

行政庁は、申請がその事務所に到達したときは、**遅滞なく**当該申請の審査を開始しなければなりません（7条）。

また、申請の形式上の要件に適合しない申請については、速やかに、申請をした者に対し相当の期間を定めて当該申請の補正を求め、又は当該申請により求められた許認可等を拒否しなければなりません（7条後段）。

つまり、申請が到達した場合、行政庁は以下のいずれかの対応をしなければなりません。

1. 遅滞なく審査を開始する
2. 形式上の要件に適合しない場合は、補正を求める又は拒否する

申請書の記載事項に不備がない場合、適正な方法により提出された場合は、到達した時点で審査が開始されたものとみなされます。行政庁の窓口担当者が受理を拒否することは認められません（いわゆる「不受理」の禁止）。

### 5 理由の提示

行政庁は、申請により求められた許認可等を拒否する処分をする場合は、申請者に対し、同時に、当該処分の**理由を示さなければなりません**（8条1項）。

ただし、法令に定められた許認可等の要件又は公にされた審査基準が数量的指標その他の客観的指標により明確に定められている場合であって、当該申請がこれらに適合しないことが申請書の記載又は添付書類その他の申請の内容から明らかであるときは、申請者の求めがあったときにこれを示せば足ります（8条2項）。

理由の提示は、許認可等を拒否する処分と同時にしなければなりません。書面で処分をする場合には、理由も書面で示さなければなりません（8条2項前段参照）。

### 6 その他の規定

#### （1）情報の提供

行政庁は、申請者の求めに応じ、当該申請に係る審査の進行状況及び当該申請に対する処分の時期の見通しを示すよう努めなければなりません（9条1項）。

また、申請をしようとする者又は申請者の求めに応じ、申請書の記載及び添付書類に関する事項その他の申請に必要な情報の提供に努めなければなりません（9条2項）。

#### （2）審査 *（公聴会等の開催義務）*

行政庁は、申請者以外の者の利害を考慮すべきことが当該法令において許認可等の要件とされているものを行う場合には、必要に応じ、公聴会の開催その他の適当な方法により当該申請者以外の者の意見を聴く機会を設けるよう努めなければなりません（10条）。

:::tip 重要ポイント
- 複数の申請者のうち一部についてのみ許認可等をすべき場合であっても、他の申請者に対して不許可処分をするにあたっては**理由の提示**が必要です。
- 行政庁は、標準処理期間を定めた場合は公にしておかなければなりませんが、定めること自体は努力義務です。
:::
