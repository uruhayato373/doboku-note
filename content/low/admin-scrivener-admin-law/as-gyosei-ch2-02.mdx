## 第3節 不利益処分

### 1 不利益処分とは何か

**不利益処分**とは、行政庁が、法令に基づき、特定の者を名あて人として、直接に、これに義務を課し、又はその権利を制限する処分のことです（2条4号）。

ただし、申請により求められた許認可等を拒否する処分（**請求拒否処分**）は、申請者の権利を制限する処分であるにもかかわらず、不利益処分に当たらないとされています（2条4号ロ）。なぜなら、申請拒否処分は、「申請に対する処分」の規定により処理されるからです。

不利益処分には、以下のような行為が含まれます。

- 許認可等の取消し
- 営業停止命令
- 課徴金の納付命令
- 施設の使用禁止命令 等

:::note 具体例イメージ
例えば、都道府県知事が、違反行為のあった飲食店の営業許可を取り消す処分をする場合などです。
:::

:::caution 注意
行政代執行手続（又は代執行手続、代執行令による通知手続）や行政上の強制徴収手続による滞納処分など、事実上の行為に当たるものは不利益処分には含まれません。
:::

不利益処分を行う場合、行政庁は次の手続を踏む必要があります。

1. 事前に処分基準（努力義務）を設定・公表する
2. 意見陳述手続（聴聞又は弁明の機会の付与）を行う
3. 理由を提示する

### 2 処分基準

**処分基準**とは、不利益処分をするかどうか又はどのような不利益処分とするかについてその法令の定めに従って判断するために必要とされる基準をいいます（2条8号ハ）。

行政庁は、処分基準を定め、かつ、これを公にしておくよう**努めなければなりません**（12条1項）。

処分基準の設定・公表はいずれも**努力義務**です。これは、不利益処分の内容が多様であり、一律に基準を定めることが困難な場合があるためです。

処分基準を定めるに当たっては、不利益処分の性質に照らしてできる限り具体的なものとしなければなりません（12条2項）。

:::tip 審査基準と処分基準の比較

| | 審査基準（申請に対する処分） | 処分基準（不利益処分） |
|---|---|---|
| **設定** | 法的義務 | 努力義務 |
| **公表** | 法的義務 | 努力義務 |
| **内容** | できる限り具体的 | できる限り具体的 |
:::

### 3 理由の提示

行政庁は、不利益処分をする場合には、その名あて人に対し、同時に、当該不利益処分の**理由を示さなければなりません**（14条1項本文）。

ただし、当該理由を示さないで処分をすべき差し迫った必要がある場合は、理由の提示を省略することができます。この場合においても、処分後相当の期間内に、理由を示さなければなりません（14条1項ただし書、同条2項）。

理由の提示は、不利益処分を書面でするときは、書面により示さなければなりません（14条3項）。

#### 重要判例 -- 不利益処分と理由の提示の程度（最判平23.6.7）

:::info 判例
**事案**：一級建築士の免許取消処分について、処分の根拠法条のみを示して理由の提示としたことの適法性が争われた事例。

**判旨**：行政手続法14条1項本文が不利益処分をする場合に同時にその理由を名あて人に示さなければならないとしているのは、名あて人に直接に義務を課し又はその権利を制限するという不利益処分の性質に鑑み、行政庁の判断の慎重と合理性を担保してその恣意を抑制するとともに、処分の理由を名あて人に知らせて不服の申立てに便宜を与える趣旨に出たものと解される。処分基準の適用関係が示されなければ、名あて人において、いかなる理由に基づいてどのような処分基準の適用によって当該処分が選択されたのかを知ることができず、理由の提示として十分でないといわなければならない。したがって、処分の根拠法条のみを示すのでは理由の提示として不十分であり、処分基準の**適用関係**を示さなければならない。
:::

### 4 意見陳述手続

不利益処分をする場合、申請者には申請が認められないという不利益が生じます。

重大な不利益が生じる場合には、十分な手続保障が必要であり、不利益の程度が比較的軽微な場合には、簡易な手続で対応することが合理的です。

そこで、行政手続法は、不利益処分の意見陳述手続として、**聴聞**と**弁明の機会の付与**という2つの手続を定めています（13条1項）。

**【意見陳述手続】**

| 手続 | 対象となる不利益処分 |
|---|---|
| **聴聞** | 許認可等の取消し、資格又は地位の剝奪、名あて人の資格又は地位を直接に剝奪する不利益処分、その他行政庁が相当と認める場合 |
| **弁明の機会の付与** | 聴聞の対象以外の不利益処分 |

具体的には、以下のように分けられます（13条1項）。

#### 聴聞の対象（13条1項1号）

- イ：許認可等を取り消す不利益処分をしようとするとき
- ロ：名あて人の資格又は地位を直接にはく奪する不利益処分をしようとするとき
- ハ：名あて人が法人である場合におけるその役員の解任を命ずる不利益処分、名あて人の業務に従事する者の解任を命ずる不利益処分又は名あて人の会員である者の除名を命ずる不利益処分をしようとするとき
- ニ：イからハに掲げる場合のほか、行政庁が相当と認めるとき

#### 弁明の機会の付与の対象（13条1項2号）

上記の聴聞に該当しない不利益処分をしようとするとき。

#### （1）聴聞

聴聞の手続は、大まかに、(1)行政庁による通知→(2)聴聞調査→(3)報告書の作成・提出→(4)不利益処分の決定、という流れで行われます。

##### i）行政庁による通知

行政庁は、聴聞を行うに当たっては、聴聞を行うべき期日までに相当な期間をおいて、不利益処分の名あて人となるべき者に対し、次に掲げる事項を書面により通知しなければなりません（15条1項）。

1. 予定される不利益処分の内容及び根拠となる法令の条項
2. 不利益処分の原因となる事実
3. 聴聞の期日及び場所
4. 聴聞に関する事務を所掌する組織の名称及び所在地

行政庁は、不利益処分の名あて人となるべき者の所在が判明しない場合には、通知すべき事項を行政庁の事務所の掲示板に掲示することによって通知に代えることができます（**公示送達**）。この場合、掲示を始めた日から**2週間**を経過したときに、当該通知が名あて人に到達したものとみなされます（15条3項）。

聴聞の通知を受けた者は、代理人を選任することができます（16条）。

##### ii）聴聞調査・報告書の作成・提出

聴聞は、行政庁が指名する職員その他政令で定める者が**主宰者**として主宰します（19条1項）。

ただし、聴聞の主宰者には、次に該当する者はなることができません（19条2項）。

- 当該聴聞の当事者又は参加人
- 当事者又は参加人の配偶者、4親等内の親族又は同居の親族
- 当事者又は参加人の代理人又は補佐人
- 当事者又は参加人であった者
- 当事者又は参加人の配偶者、4親等内の親族又は同居の親族であった者

**【聴聞参考表の整理】**

| 項目 | 内容 |
|---|---|
| **通知の相手方** | 不利益処分の名あて人となるべき者 |
| **通知の方法** | 書面 |
| **通知事項** | (1)予定される不利益処分の内容・根拠法条、(2)原因事実、(3)聴聞の期日・場所、(4)聴聞所掌組織の名称・所在地 |
| **通知の時期** | 聴聞の期日までに相当な期間をおいて |
| **所在不明の場合** | 公示送達（掲示開始から2週間で到達みなし） |
| **主宰者** | 行政庁が指名する職員その他政令で定める者 |
| **代理人** | 選任可能 |

聴聞の期日における審理は、行政庁が公開することを相当と認めるときを除き、**非公開**とされています（20条6項）。

当事者又は参加人は、聴聞の期日への出頭に代えて、主宰者に対し、聴聞の期日までに陳述書及び証拠書類等を提出することができます（21条1項）。

当事者又は参加人は、聴聞の期日における審理の進行に応じて必要な陳述をすることはできますが、主宰者の許可を得なければ、行政庁の職員に対し質問を発することができません（20条2項）。

当事者又は参加人は、聴聞の通知があった時から聴聞が終結する時までの間、行政庁に対し、当該事案についてした調査の結果に係る調書その他の当該不利益処分の原因となる事実を証する資料の**閲覧**を求めることができます（18条1項）。行政庁は、第三者の利益を害するおそれがあるときその他正当な理由があるときでなければ、その閲覧を拒むことができません（18条1項前段）。

主宰者は、聴聞の審理の経過を記載した**聴聞調書**を作成し、当該調書において、不利益処分の原因となる事実に対する当事者及び参加人の主張に理由があるかどうかについての意見を記載した**報告書**を作成し、行政庁に提出しなければなりません（24条1項・3項）。

##### iii）不利益処分の決定

行政庁は、不利益処分の決定をするときは、聴聞調書の内容及び報告書に記載された主宰者の意見を**十分に参酌して**これをしなければなりません（26条）。「十分に参酌」とは、尊重するという意味であり、拘束されるわけではありません。

聴聞を経てされた不利益処分については、当事者及び参加人は、行政不服審査法による**審査請求をすることができません**（27条2項）。ただし、当該処分の相手方が聴聞に関する手続に瑕疵があることを理由として審査請求をする場合は、この限りではありません。

#### （2）弁明の機会の付与

弁明の機会の付与は、聴聞に該当しない不利益処分をしようとする場合に行われます。

弁明は、行政庁が口頭ですることを認めたときを除き、**書面**の提出によってするものとされています（29条1項）。つまり、弁明の機会の付与は原則として書面審理主義が採られています。

行政庁は、弁明書の提出期限（口頭による弁明の機会の付与を行う場合には、その日時）までに相当な期間をおいて、不利益処分の名あて人となるべき者に対し、次に掲げる事項を書面により通知しなければなりません（30条）。

1. 予定される不利益処分の内容及び根拠となる法令の条項
2. 不利益処分の原因となる事実
3. 弁明書の提出先及び提出期限（口頭による弁明の機会の付与を行う場合には、その旨並びに出頭すべき日時及び場所）

**【弁明の場合の付与の流れ】**

行政庁が名あて人に通知（書面）→ 名あて人が弁明書を提出（原則書面）→ 行政庁が不利益処分の決定

### 聴聞と弁明の比較

| | 聴聞 | 弁明 |
|---|---|---|
| **審理方式** | 原則として口頭（20条） | 原則として書面（29条1項） |
| **参加人の関与** | ○（17条1項） | 規定なし |
| **文書等の閲覧請求権** | ○（18条1項） | 規定なし |

:::tip 重要ポイント
聴聞と弁明の機会の付与の違いを正確に把握しておくことが重要です。聴聞は口頭審理主義、弁明は書面審理主義が原則です。また、参加人の関与や文書等の閲覧請求権が認められるのは聴聞のみです。弁明の機会の付与は聴聞の規定が準用されません。
:::
