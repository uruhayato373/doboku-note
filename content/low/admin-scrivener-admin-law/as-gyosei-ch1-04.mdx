# 行政行為の瑕疵・取消し・撤回・附款

## （4）行政行為の瑕疵

### （1）行政行為の瑕疵とは何か

行政行為の**瑕疵**（かし）とは、行政行為が法律に違反している場合（違法）や、行政行為が妥当性に欠けている場合（不当）をいいます。

行政行為の瑕疵には、次の2種類があります。

| 種類 | 内容 | 効果 |
|---|---|---|
| **取消しうべき瑕疵** | 瑕疵が軽微であり、取消しの手続がなされるまでは有効 | 取消しがなされるまで有効（公定力） |
| **無効の瑕疵** | 瑕疵が**重大かつ明白**であり、当然に無効 | 初めから効力を生じない |

### （2）違法性の承継

**違法性の承継**とは、ある行政行為（先行行為）の違法が、後続の行政行為（後行行為）の取消しの理由となるかという問題です。

原則として、先行行為と後行行為が**別個独立**のものである場合には、違法性の承継は認められません。

ただし、先行行為と後行行為が**連続した一連の手続**を構成し、一定の法律効果を発生させるものである場合には、違法性の承継が認められることがあります。

:::info 重要判例 -- 違法性の承継

### 安全認定と違法性の承継（最判平21.12.17）

**事案**: 建築確認に先行する安全認定の違法を、建築確認の取消訴訟において主張することができるかが問題となった。

**判旨**: 安全認定は、それを受けなければ建築確認を受けることができないという関係にあるが、安全認定自体は建築主に対して建築を可能にするにすぎず、それ自体が建築主以外の者の権利を制限するものではないから、安全認定が取り消されていなくても、建築確認の取消訴訟において安全認定の**違法を主張することができる**（違法性の承継を肯定）。

:::

### （3）瑕疵の治癒・違法行為の転換

#### 瑕疵の治癒

**瑕疵の治癒**とは、行政行為に瑕疵があったが、後にその瑕疵が補われた（要件を満たした）場合に、当該行政行為を有効として扱うことをいいます。

#### 違法行為の転換

**違法行為の転換**とは、ある行政行為が違法であっても、別の行政行為の要件を満たしている場合に、その別の行政行為として有効に扱うことをいいます。

## （5）行政行為の取消しと撤回

### （1）取消し・撤回とは何か

**取消し**とは、行政庁が、瑕疵ある行政行為の効力をその行為がなされた時点にさかのぼって失わせることです。

これに対し、**撤回**とは、行政庁が、適法に成立した行政行為について、その後の事情の変化によりその行為の効力を維持することが不適当でなくなった場合に、その行為の効力を将来に向かって失わせることです。

| | 取消し | 撤回 |
|---|---|---|
| **原因** | 行政行為に瑕疵がある | 後発的な事情変化 |
| **効力** | **遡及**して効力を失う | **将来に向かって**効力を失う |

### （2）法律の根拠の要否

取消しも撤回も瑕疵のない状態を回復させるものであり、国民に有利となるものですから、取消し・撤回をするためには、法律の根拠は**不要**です。

もっとも、**授益的行為**（国民に利益を与える行政行為）の取消し・撤回は、相手方に不利益を及ぼすものであるから、制限されます。

:::info 重要判例 -- 授益的行為の撤回

### 行政行為の撤回と法律の根拠（最判昭63.6.17）

**事案**: 人工透析治療の必要がなくなった場合に、身体障害者福祉法による身体障害者手帳の交付を撤回できるかが問題となった。

**判旨**: 撤回によって被る不利益と、撤回しないことにより公益が受ける不利益を比較衡量して判断する。

:::

### （3）なしうる者

取消しは、原則として、処分をした行政庁またはその上級行政庁が行うことができます。撤回は、処分をした行政庁が行うことができます。

| | 取消し | 撤回 |
|---|---|---|
| **処分庁** | ○ | ○ |
| **上級行政庁** | ○ | × |
| **裁判所** | ○（取消訴訟） | × |

## （6）行政行為の附款

### （1）行政行為の附款とは何か

行政行為の**附款**とは、行政行為の効果を制限するため、行政庁の意思表示として付される制限のことです。

行政行為の附款には、以下の5種類があります。

| 種類 | 内容 | 具体例 |
|---|---|---|
| **条件** | 行政行為の効果の発生・消滅を、将来の不確実な事実にかからしめるもの | 停止条件、解除条件 |
| **期限** | 行政行為の効果の発生・消滅を、将来の確実な事実にかからしめるもの | 許可の有効期限 |
| **負担** | 行政行為の相手方に特別の義務を課すもの | 補助金交付に際しての用途指定 |
| **撤回権の留保** | 一定の事由が生じた場合に行政行為を撤回できる旨の留意をつけるもの | 許可に際しての取消権留保 |
| **法律効果の一部除外** | 行政行為の法律効果の一部を除外するもの | 自動車運転免許のAT限定 |

### （2）附款の限界

行政行為の附款には、以下の制限があります。

- 附款を付すことができるのは、法令に附款を付すことが認められている場合、または行政庁に**裁量**が認められている場合に限られる
- **覊束行為**（行政庁に裁量が認められていない行政行為）には、原則として附款を付すことはできない
- 附款の内容は、行政行為の目的に照らして**合理的**でなければならない
