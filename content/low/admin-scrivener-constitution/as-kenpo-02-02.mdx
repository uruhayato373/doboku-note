# 幸福追求権及び法の下の平等

## 1 幸福追求権

### (1) 幸福追求権とは何か

幸福追求権とは、憲法13条で保障されている「生命・自由・幸福追求に対する国民の権利」のことです。各人が自由に人格を形成・発展させていくうえで必要不可欠な権利を広く保障するものです。

> **憲法13条**
>
> すべて国民は、個人として尊重される。生命、自由及び幸福追求に対する国民の権利については、公共の福祉に反しない限り、立法その他の国政の上で、最大の尊重を必要とする。

#### 【人権の根拠】

幸福追求権は、14条以下の個別の人権規定では保障されない**新しい人権**の根拠となるものです。もっとも、どのような権利でも保障されるわけではありません。

### (2) 新しい人権

最高裁判所の判例は、憲法13条を根拠に実質的な権利保障を認めています（権利性を認めると明示したわけではなく実質的に保障しています）。

:::info[京都府学連事件（最大判昭44.12.24）]

**事案**

京都府学連のデモ行進に際して、警察官がデモ隊の先頭を撮影したことが、肖像権の侵害にあたるかが争われた。

**判旨**

- 個人の私生活上の自由の一つとして、何人も、**その承諾なしに、みだりにその容ぼう・姿態を撮影されない自由**を有する。
- 警察官が、正当な理由もないのに、個人の容ぼう等を撮影することは、憲法13条の趣旨に反し許されない。
:::

### プライバシー権

プライバシー権とは、「私生活をみだりに公開されない権利」のことです。

:::info[前科照会事件（最判昭56.4.14）]

**事案**

弁護士が弁護士法に基づき前科照会をしたところ、市区町村長が前科等のすべてを報告した。

**判旨**

- 前科及び犯罪経歴は、人の名誉・信用に直接かかわる事項であり、前科等のある者もこれを**みだりに公開されないという法律上の保護に値する利益**を有する。
:::

自己情報コントロール権は近年のプライバシー権の発展形態です。

:::info[ノンフィクション「逆転」事件（最判平6.2.8）]

**事案**

ノンフィクション作品の中で「逆転」の著者を実名前科を含め詳細に記述され本人上告した事件。

**判旨**

- ある者の前科等にかかわる事実を公表されない利益は、法的保護に値し、その者の**その後の生活状況にかんがみ、その更生を妨げられない利益**として保護される。
:::

:::info[指紋押捺拒否事件（最判平7.12.15）]

**事案**

在日韓国人が外国人登録法上の指紋押捺を拒否した。

**判旨**

- 何人も、個人の私生活上の自由の一つとして、**みだりに指紋の押なつを強制されない自由**を有する。
- 国家機関が正当な理由もなく指紋の押なつを強制することは、憲法13条の趣旨に反して許されない。
- もっとも、外国人登録法の指紋押捺制度は、その立法目的には十分な合理性があり、必要性も肯定でき、相当であって、憲法13条に違反しない。
:::

:::info[住基ネット訴訟（最判平20.3.6）]

**事案**

住民基本台帳ネットワークシステム（住基ネット）により行政機関が住民の本人確認情報を管理・利用等する行為が、プライバシー権を侵害するかが争われた。

**判旨**

- 憲法13条は、国民の私生活上の自由が公権力の行使に対しても保護されるべきことを規定しているものであり、個人の私生活上の自由の一つとして、何人も、個人に関する情報を**みだりに第三者に開示又は公表されない自由**を有する。
- 住基ネットによる本人確認情報の管理・利用等は、正当な行政目的の範囲内で行われており、また、個人情報の漏えい等の具体的な危険も認められない。したがって、憲法13条に**違反しない**。
:::

:::info[早稲田大学講演会参加者名簿提出事件（最判平15.9.12）]

**事案**

早稲田大学が、中国の国家主席の講演会に参加を申し込んだ学生の氏名・住所等の名簿を、本人の同意なく警察に提出した。

**判旨**

- 学籍番号、氏名、住所及び電話番号は、個人識別等を行うための単純な情報であって、その限りにおいてはプライバシーに係る情報としての秘匿性の程度は高くない。
- しかし、このような個人情報についても、**本人が、自己が欲しない他者にはみだりにこれを開示されたくないと考えることは自然なこと**であり、そのことへの期待は保護されるべきものである。
- したがって、大学が無断で警察に名簿を提出したことは**不法行為**を構成する。
:::

:::info[住基ネット訴訟（最判平20.3.6）]

**判旨（補足）**

- 一定の範囲の他者に対して開示されることが予定されている個人情報については、プライバシーに係る情報として**保護の対象とならない**わけではないが、個人の内面にかかわるような秘匿性の高い情報とはいえない。
:::

### 自己決定権

自己決定権とは、個人の人格にかかわる重要な私的事項について、公権力の干渉なしに自ら決定する権利のことです。

:::info[エホバの証人輸血拒否事件（最判平12.2.29）]

**事案**

エホバの証人の信者が、宗教上の理由から輸血を拒否する意思を明確にしていたにもかかわらず、医師が手術中に輸血を行った。

**判旨**

- 患者が、輸血を受けることは自己の宗教上の信念に反するとして、輸血を伴う医療行為を拒否するとの明確な意思を有している場合、このような意思決定をする権利は、**人格権の一内容として尊重されなければならない**。
:::

## 2 法の下の平等

憲法は、法の下の平等を重要な原則として定めています。

> **憲法14条1項**
>
> すべて国民は、法の下に平等であつて、人種、信条、性別、社会的身分又は門地により、政治的、経済的又は社会的関係において、差別されない。

禁止（14条3項）、栄典の授与（14条3項）といった規定を設けて、平等原則の徹底を図っています。

### (1) 法の下の平等の意味

まず、「法の下」の意味ですが、法を平等に適用するだけでなく、**法の内容自体も平等**でなければならないとされています（法内容平等説）。

つまり、法を適用する場面だけでなく、法を**制定する段階**においても平等が要求されます。

次に、「平等」の意味ですが、**相対的平等**と解されています。つまり、合理的な理由のある差別は許容されますが、合理的な理由のない差別は許されません。

**【法の下の平等】**

| 区分 | 意味 |
|---|---|
| **法適用の平等** | 法を平等に適用すること |
| **法内容の平等** | 法の内容自体も平等でなければならない |
| **相対的平等** | 合理的区別は許容、不合理な差別は禁止 |

### (2) 法の下の平等に反する法律・処分

14条1項は、「人種、信条、性別、社会的身分又は門地」を列挙していますが、これは**例示列挙**であり、これら以外の事由による差別も禁止されます。

#### 信条

「信条」とは、法律上の信仰のみならず、思想上・政治上の主義を含みます（最判昭和11.12.21）。

#### 性別

性別による差別が問題となった判例には、以下のようなものがあります。

:::info[女性の再婚禁止期間（最大判平27.12.16）]

**事案**

民法733条1項が、女性について6か月の再婚禁止期間を定めていたことが、憲法14条1項及び24条2項に違反するかが争われた。

**判旨**

- 100日を超える部分については、民法772条の嫡出推定の重複を避けるための期間を超えるものであり、立法目的との間に合理的関連性を有しておらず、**憲法14条1項及び24条2項に違反する**。
- 100日以内の部分については、父性の推定の重複を回避し、もって父子関係をめぐる紛争の発生を未然に防ぐことにあると解されるから、合理性がある。
:::

#### 社会的身分

「社会的身分」とは、人が社会においてある程度継続的な地位を占めることをいいます。

社会的身分を示すことが差別問題となった判例には、以下のようなものがあります。

:::info[尊属殺重罰規定違憲判決（最大判昭48.4.4）]

**事案**

尊属殺人罪の法定刑が死刑又は無期懲役のみと定められていたことが、普通殺人罪との比較において憲法14条1項に違反するかが争われた。

**判旨**

- 尊属に対する尊重報恩は、社会生活上の基本的道義というべきであり、このような自然的情愛ないし普遍的倫理の維持は、刑法上の保護に値する。
- しかし、尊属殺の法定刑を死刑又は無期懲役のみに限っている点において、その立法目的達成のため必要な限度を遥かに超え、普通殺に関する刑法199条の法定刑に比し著しく不合理な差別的取扱いをするものと認められ、**憲法14条1項に違反する**。
:::

:::info[婚外子国籍確認訴訟（最大判平20.6.4）]

**事案**

日本人の父とフィリピン人の母との間に生まれた非嫡出子が、出生後に父から認知を受けたにもかかわらず、国籍法3条1項が準正（父母の婚姻＋認知）を国籍取得の要件としていたため、日本国籍を取得できなかった。

**判旨**

- 国籍法3条1項が、日本国民である父から出生後認知された子について、父母の婚姻により嫡出子たる身分を取得した場合に限り日本国籍の取得を認めていることは、今日では立法目的との間に合理的関連性を見出しがたい。
- したがって、**憲法14条1項に違反する**。
:::

**【婚外子国籍確認訴訟の結論】**

- 出生後認知 → 準正なし → 日本国籍取得**不可** → **違憲**

:::info[非嫡出子の相続分（最大決平25.9.4）]

**事案**

非嫡出子の法定相続分を嫡出子の2分の1とする民法900条4号ただし書の規定が、憲法14条1項に違反するかが争われた。

**判旨**

- 家族という共同体の中における個人の尊重がより明確に認識されてきたことに伴い、嫡出子と嫡出でない子の区別による不利益も許容できないものとなってきた。
- 遅くとも平成13年7月当時において、民法900条4号ただし書は、**憲法14条1項に違反していた**。
:::

#### 門地

「門地」とは、家柄のことです。

### (3) 議員定数不均衡

議員定数不均衡の問題とは、憲法において、各選挙区の議員定数の配分が、各選挙区の有権者数（人口）に比例していないことにより、選挙権の平等が侵害されているという問題です。つまり、一票の価値の格差の問題です。

#### 衆議院の場合

:::info[衆議院議員定数不均衡訴訟（最大判昭51.4.14）]

**事案**

衆議院議員総選挙において、選挙区間における議員一人当たりの人口の較差が、最大約5対1に達していた。

**判旨**

- 各選挙人の投票の価値の平等もまた、憲法の要求するところである。
- 公正かつ効果的な代表を選出するという目的のために合理的に是認することができない投票価値の不平等は、それだけで選挙を違法ならしめる。
- 較差が示す選挙区間における投票価値の不平等は、公選法の議員定数配分規定の下で投票価値の平等が損なわれていることが明らかであり、その状態は**違憲**である。
:::

なお、公正かつ効果的な代表という5対1の較差について「違憲と判断するために十分に必要な期間」を経過していることが必要です。

:::info[衆議院議員定数不均衡訴訟（最大判昭60.7.17）]

**判旨**

- 是正のための合理的期間を経過した後もなお議員定数配分規定が是正されない場合には、当該規定は違憲と判断される。
:::

:::info[衆議院議員定数不均衡訴訟（最大判平23.3.23）]

**判旨**

- 1人別枠方式（各都道府県にまず1議席を配分し、残りを人口比例で配分する方式）は、選挙区間における投票価値の較差を生じさせる主要な原因となっていた。
- 本件選挙時には、合理性が失われており、本件区割基準及び本件区割りは、憲法の投票価値の平等の要求に反する状態に至っていた（**違憲状態**）。
:::

#### 参議院の場合

:::info[参議院議員定数不均衡訴訟（最大判昭58.4.27）]

**判旨**

- 参議院議員の選挙制度の仕組みについて事実上都道府県代表的な意義ないし機能を有する要素があり、人口比例主義を最も重要かつ基本的な基準とする必然性は、衆議院の場合ほどには強くないが、投票価値の平等は憲法上の要請である。
:::

#### 地方議会の場合

:::info[地方議会と議員定数不均衡（最判昭59.5.17）]

**判旨**

- 地方公共団体の議会の議員の定数配分については、人口比例が最も重要かつ基本的な基準であり、特段の合理的理由がない限り、各選挙区の議員1人当たりの人口に顕著な不均衡を生じさせることは許されない。
:::
