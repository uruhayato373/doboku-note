# 精神的自由権（1）-- 思想・良心の自由、信教の自由

## 1 思想及び良心の自由

内心の自由には、「思想及び良心の自由」（19条）、「信教の自由」（20条）、「学問の自由」（23条）があります。特に、「思想及び良心の自由」は精神的自由の根本に位置づけられます。

> **憲法19条**
>
> 思想及び良心の自由は、これを侵してはならない。

### 【思想及び良心の自由の保障内容】

1. **内心の自由**：国家権力が個人の内心に介入してはならない（内心における思想について不利益を課してはならない）
2. **沈黙の自由**：思想について告白を強制されない
3. **思想を理由とする不利益取扱いの禁止**

:::info[謝罪広告強制事件（最大判昭31.7.4）]

**事案**

民法723条に基づく名誉回復処分として、裁判所が謝罪広告の掲載を命じたことが、思想・良心の自由を侵害するかが争われた。

**判旨**

- 謝罪広告を新聞紙等に掲載すべきことを加害者に命ずることは、加害者の倫理的な意思・良心の自由を侵害するものであり許されない。
- ただし、単に事態の真相を告白し陳謝の意を表明するにとどまる程度のものであれば許される（**合憲**）。
:::

:::info[麹町中学内申書事件（最判昭63.7.15）]

**事案**

公立中学校の生徒が、在学中に学外の政治活動に参加したことなどを内申書に記載されたことについて、思想・良心の自由の侵害を主張した。

**判旨**

- 内申書の記載は、生徒の思想・信条そのものを記載したものではなく、**外部的行為**についての客観的な事実を記載したものにすぎない。
- したがって、思想・良心の自由を侵害するものではない。
:::

:::info[国旗起立斉唱行為の意思（最判平23.5.30）]

**事案**

公立高校の教員が、卒業式の国歌斉唱時に起立・斉唱を命じる校長の職務命令に従わなかった。

**判旨**

- 起立斉唱行為は、一般的、客観的に見て、慣例上の儀礼的な所作としての性質を有するものであり、特定の思想を有することを外部に表明する行為と評価することは困難である。
- もっとも、上記の職務命令は、個人の歴史観ないし世界観に由来する行動と異なる外部的行為を求められることとなり、その限りにおいて、思想及び良心の自由についての**間接的な制約**となる面がある。
- しかし、職務命令の目的及び内容、制約の態様等を総合的に較量すれば、その制約を許容し得る程度の必要性及び合理性が認められ、**憲法19条に違反しない**。
:::

## 2 信教の自由

### (1) 信教の自由

#### 信教の自由の内容

憲法は、信仰の自由を保障しています（20条1項前段）。

> **憲法20条1項**
>
> 信教の自由は、何人に対してもこれを保障する。いかなる宗教団体も、国から特権を受け、又は政治上の権力を行使してはならない。

信教の自由には、以下の内容が含まれます。

**【信教の自由】**

| 区分 | 内容 |
|---|---|
| **信仰の自由** | 宗教を信仰し、又は信仰しない自由 |
| **宗教的行為の自由** | 宗教上の行為、祝典、儀式又は行事を行う自由 |
| **宗教的結社の自由** | 宗教団体を設立し、加入し、又は脱退する自由 |

信教の自由の制約について、宗教的行為の自由は外部的行為であるため、公共の福祉による制約を受けます。

:::info[オウム真理教解散命令事件（最決平8.1.30）]

**事案**

オウム真理教に対する宗教法人法に基づく解散命令が、信教の自由を侵害するかが争われた。

**判旨**

- 宗教法人の解散命令は、宗教法人の**法人格**を失わせるにとどまり、信者の宗教上の行為を禁止したり制限したりするものではない。
- 解散命令による宗教法人の活動の制約は、信教の自由に対する間接的で事実上のものにとどまる。
- もっとも、解散命令の制度は、宗教法人の世俗的側面を対象とし、かつ、専ら世俗的目的によるものであって、宗教団体や信者の精神的・宗教的側面に容かいする意図によるものではない。
:::

#### 宗教法人に関する公の利害にかかわる犯罪事実の摘示の問題

宗教法人に関して、公の利害にかかわる犯罪事実を摘示した場合に、名誉毀損罪が成立するかという問題があります。

:::info[創価学会批判記事事件（最判平9.3.8）]

**事案**

雑誌に宗教法人の批判記事を掲載したことが名誉毀損に当たるかが争われた。

**判旨**

- 宗教法人について、その名誉ないし信用に関する事実について批判的な表現がされた場合であっても、その行為が公共の利害に関する事実に係り、もっぱら公益を図る目的に出た場合に、摘示された事実が真実であると証明されたときは、名誉毀損は成立しない。
:::

### (2) 政教分離原則

憲法は、国の宗教活動を禁止するため**政教分離原則**を規定しています（20条3項）。国家と宗教を分離して、国が特定の宗教を援助したり干渉したりしないようにするものです。

> **憲法20条3項**
>
> 国及びその機関は、宗教教育その他いかなる宗教的活動もしてはならない。

政教分離に関しては、政教分離が問題となった判例は、以下のようなものがあります。

:::info[津地鎮祭事件（最大判昭52.7.13）]

**事案**

三重県津市が、市立体育館の起工式を神式の地鎮祭として行い、その費用を市の公金から支出したことが、政教分離原則に違反するかが争われた。

**判旨**

- 政教分離原則は、国家と宗教との完全な分離を実現することは不可能に近いことから、国家と宗教との関わり合いが、**相当とされる限度を超える**ものと認められる場合に、これを許さないとするものである（**目的効果基準**）。
- 具体的には、当該行為の**目的**が宗教的意義をもち、その**効果**が宗教に対する援助、助長、促進又は圧迫、干渉等になるような行為をいう。
- 本件地鎮祭は、建築着工に際し、工事の無事安全等を願う社会一般の慣習に従った儀礼を行うという世俗的なものであり、その効果も神道を援助・助長するものとはいえず、**憲法20条3項に違反しない**。
:::

:::info[愛媛玉串料事件（最大判平9.4.2）]

**事案**

愛媛県が、靖国神社の春秋の例大祭に際して玉串料等を県の公金から支出したことが、政教分離原則に違反するかが争われた。

**判旨**

- 県が特定の宗教団体に対してのみ、本件のような形で特別のかかわり合いを持つことは、一般人に対して、県が当該特定の宗教団体を特別に支援しており、それらの宗教団体が他の宗教団体とは異なる特別のものであるとの印象を与え、特定の宗教への関心を呼び起こすものといわざるを得ない。
- 本件支出は、その目的が宗教的意義を持つことを否定することはできず、その効果が特定の宗教に対する援助、助長、促進になると認めるべきであり、**憲法20条3項に違反する**。
:::

:::info[空知太神社事件（最大判平22.1.20）]

**事案**

北海道砂川市が、市有地を神社施設の敷地として無償で使用させていることが、政教分離原則に違反するかが争われた。

**判旨**

- 市が市有地を無償で神社施設の敷地として使用させていることは、市と当該神社ないし神道とのかかわり合いが、我が国の社会的、文化的諸条件に照らし、**信教の自由の保障の確保という制度の根本目的との関係で相当とされる限度を超える**ものとして、**憲法89条及び20条1項後段に違反する**。
:::

:::info[孔子廟敷地対価免除訴訟（最大判令3.2.24）]

**事案**

那覇市が、市有地上に建てられた孔子廟の土地使用料を全額免除していたことが、政教分離原則に違反するかが争われた。

**判旨**

- 本件施設の外観等に照らし、一般人の目から見て、特定の宗教に対して特別の便益を提供し、これを援助していると評価されてもやむを得ないものである。
- 本件免除は、市と宗教とのかかわり合いが、我が国の社会的、文化的諸条件に照らし、信教の自由の保障の確保という制度の根本目的との関係で**相当とされる限度を超える**ものとして、**憲法89条に違反する**。
:::
