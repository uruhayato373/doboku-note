# 精神的自由権（2）-- 表現の自由、学問の自由

## 3 表現の自由

### (1) 表現の自由の保障

表現の自由（憲法21条1項）とは、自分の意思や思想を外部に表明する自由のことです。

> **憲法21条1項**
>
> 集会、結社及び言論、出版その他一切の表現の自由は、これを保障する。

この表現の自由を支えるのは、「自己実現の価値」（自分の意思や意見を外部に表明して自己の人格を形成・発展させるという個人的価値）と、「自己統治の価値」（言論活動により国民が政治的意思決定に関与するという民主的・政治的価値）の2つの価値です。

**【表現の自由の価値】**

| 区分 | 内容 |
|---|---|
| **自己実現の価値** | 個人が言論を通じて人格を発展させる |
| **自己統治の価値** | 国民が政治的意思決定に参加する |

### (2) 表現の自由の内容

#### 知る権利

知る権利とは、国民が、自由に情報を受け取る権利のことです。表現の自由の受け手側の権利として位置づけられます。

#### アクセス権

アクセス権とは、マスメディアに対して、自己の意思や意見を発表する場を提供することを求める権利のことです。

:::info[サンケイ新聞事件（最判昭62.4.24）]

**事案**

政党が、新聞の意見広告に反論する文章の掲載を求めたことが、表現の自由の問題として争われた。

**判旨**

- 反論文掲載の請求権を認めることは、新聞の紙面の利用を他に強制することになり、新聞社の**編集の自由**を侵害するおそれがある。
- 反論権の制度について、具体的な成文法がないのに、反論文掲載請求権を認めることはできない。
:::

#### 報道・取材の自由

報道の自由が、憲法21条によって保障されるかが問題となります。

:::info[博多駅事件（最大決昭44.11.26）]

**事案**

博多駅前で警官隊とデモ隊の衝突事件があり、裁判所がテレビ局にフィルムの提出を命じたことが、報道の自由・取材の自由の侵害にあたるかが争われた。

**判旨**

- 報道機関の報道は、民主主義社会において、国民が国政に関与するにつき、重要な判断の資料を提供し、国民の「知る権利」に奉仕するものであるから、思想の表明の自由とならんで、事実の報道の自由は、**表現の自由を規定した憲法21条の保障のもとにある**。
- また、報道のための取材の自由も、憲法21条の精神に照らし、**十分尊重に値する**とされているにすぎない（博多駅事件：最大判昭44.11.26）。
:::

**【取材源秘匿の自由】**

取材の自由に関して、取材源の秘密が保護されるかについては、取材源の秘密は職業の秘密に当たるが、公正な裁判の実現のためには証言拒絶が認められないこともあるとされています。

:::info[外務省秘密電文漏洩事件（最決昭53.5.31）]

**事案**

新聞記者が外務省の女性事務官に対して秘密文書の持出しを唆し取得したことが問題となった。

**判旨**

- 報道機関の取材の自由も、何らの制約をも受けないものではなく、取材の手段・方法が法秩序全体の精神に照らし相当なものとして社会通念上是認されるものである限り、正当な取材活動の範囲内にある。
- 取材の手段・方法が、一般の刑罰法令に触れる行為を伴う場合には、正当な取材活動の範囲を逸脱するものである。
:::

取材の自由に関しては、法廷でのペン等による記録（メモ）の自由についても判例があります。

:::info[レペタ事件（最大判平元.3.8）]

**事案**

アメリカ人の弁護士レペタが、法廷で傍聴しながらメモを取ろうとしたところ、裁判長にメモを禁じられた。

**判旨**

- 法廷において傍聴人がメモを取ることは、その見聞する裁判についての認識と記憶をより正確なものとすることを助けるものであり、**憲法21条1項の精神に照らして尊重に値する**。
- もっとも、メモを取る行為が法廷における公正かつ円滑な訴訟の運営を妨げるおそれがある場合には、裁判長の法廷警察権（裁判所法71条）に基づいてこれを制限することも許される。
- 本件では、メモを取ることの許否は裁判長の合理的な裁量に委ねられており、一律に禁止する措置も直ちに違憲とはいえない。
:::

#### 性表現の自由と名誉毀損的表現

性表現について、わいせつ文書の頒布等を処罰する刑法175条が、表現の自由を保障した21条に反しないかが問題となります。

:::info[チャタレー事件（最大判昭32.3.13）]

**判旨**

- わいせつ文書の頒布等は、性的秩序を乱し、最小限度の道徳を守ることに反するものであり、**公共の福祉に反する**ものとして、表現の自由の保護を受けない。
:::

名誉毀損については、表現の自由との調整が問題となります。

:::info[北方ジャーナル事件（最大判昭61.6.11）]

**事案**

北海道知事選挙の候補者を批判する記事を掲載した雑誌に対して、発行前に裁判所が差止めの仮処分を命じたことが、表現の自由の事前抑制にあたるかが争われた。

**判旨**

- 表現行為に対する事前抑制は、表現の自由を保障し検閲を禁止する憲法21条の趣旨に照らし、厳格かつ明確な要件のもとにおいてのみ許容される。
- 出版物の頒布等の事前差止めは、事前抑制に該当し原則として許されないが、その表現内容が**真実でなく、又はそれが専ら公益を図る目的のものでないことが明白**であって、かつ、被害者が重大にして著しく回復困難な損害を被るおそれがあるときは、例外的に事前差止めが許される。
:::

#### 選挙運動の制限

:::info[第1次家永教科書裁判（最判平5.3.16）]

**判旨**

- 普通教育の場において使用される教科書の検定制度は、一般図書としての発行を何ら妨げるものではなく、発表禁止目的や発表前の審査などの特質がないから、**検閲に当たらない**。
:::

#### 漠然不明確な規制・過度に広汎な規制

:::info[徳島市公安条例事件（最大判昭50.9.10）]

**事案**

徳島市の集団行進及び集団示威運動に関する条例が、「交通秩序を維持すること」という不明確な文言で刑罰を科していることが、憲法31条に違反するかが争われた。

**判旨**

- 通常の判断能力を有する一般人の理解において、具体的場合に当該行為がその適用を受けるものかどうかの判断を可能ならしめるような基準が読みとれるかどうかによって決すべきである。
:::

#### 集会の自由

集会とは、多数人が政治的・経済的・宗教的等の目的をもって一定の場所に集まることです。

集会の自由や集団行動の自由も、憲法21条1項によって保障されます。しかし、他の権利との調整のため、集会の自由は公共の福祉による制約を受けることがあります。

:::info[成田新法事件（最大判平4.7.1）]

**事案**

成田国際空港の安全確保に関する緊急措置法（成田新法）が、空港とその周辺における集会等を規制していることが、憲法21条に違反するかが争われた。

**判旨**

- 規制の対象となる行為が多岐にわたるが、いずれも空港の設置・管理に係る者の生命・身体又は財産を侵害するものであり、空港及びその機能を暴力主義的破壊活動の危険から守るため、このような行為が行われる蓋然性の高い場所を使用することを禁止するものである。
- 本件規制は、**合憲**である。
:::

:::info[泉佐野市民会館事件（最判平7.3.7）]

**事案**

市民会館の使用許可申請に対して、集会が妨害されるおそれがあることを理由に不許可としたことが、集会の自由の侵害にあたるかが争われた。

**判旨**

- 集会の用に供される公共施設の管理者は、正当な理由がない限り、その利用を拒否してはならない。
- 「公の秩序をみだすおそれがある場合」には利用を不許可とすることができるが、その要件については、単に危険な事態を生ずる蓋然性があるというだけでは足りず、**明らかな差し迫った危険の発生が具体的に予見される**ことが必要である。
:::

:::info[東京都公安条例事件（最大判昭35.7.20）]

**事案**

東京都の公安条例が、集団行進等の届出制・許可制を定めていることが、憲法21条に違反するかが争われた。

**判旨**

- 公共の安寧を保持する上から、デモ行進等につき、一般的な許可制を定めることは、憲法の趣旨に反する。
- しかし、公共の秩序を保持し、又は公共の福祉が著しく侵されることを防止するための必要かつ最小限度の措置として許可制を用いることは許される。
- 本件条例は、不許可の場合が厳格に制限されており、実質において届出制と異なるところがないから、**憲法21条に違反しない**。
:::

### (3) 表現の自由の規制

表現の自由を規制する立法について、その合憲性を判断する場合には、表現の自由が制約されることがあります。

表現の自由を規制する方法には、**事前規制**と**事後規制**があります。事前規制は、表現行為がなされる前にこれを抑制するものであり、事後規制よりも表現の自由に対する制約の度合いが大きいため、原則として許されないとされています。

**【事前規制と検閲】**

- **事前規制**：表現行為がなされる前にこれを抑制
- **検閲禁止**：憲法21条2項による絶対的禁止

> **憲法21条2項**
>
> 検閲は、これをしてはならない。通信の秘密は、これを侵してはならない。

:::info[税関検査事件（最大判昭59.12.12）]

**事案**

税関検査により輸入品の中にわいせつなものがないかを検査することが、検閲に当たるかが争われた。

**判旨**

- 憲法21条2項にいう「検閲」とは、行政権が主体となって、思想内容等の表現物を対象とし、その全部又は一部の発表の禁止を目的として、対象とされる一定の表現物につき網羅的一般的に、発表前にその内容を審査した上、不適当と認めるものの発表を禁止することを、その特質として備えるものをいう。
- 税関検査は、**検閲に当たらない**。
:::

:::info[北方ジャーナル事件（最大判昭61.6.11）]

**判旨（検閲該当性について）**

- 裁判所の仮処分による出版物の事前差止めは、「行政権」が主体ではないので、**検閲に当たらない**。
- しかし、事前抑制的なものであり、厳格かつ明確な要件のもとにおいてのみ許容される。
:::

#### 漠然不明確な規制と過度に広汎な規制

表現の自由を規制する法律が、あいまいな基準や広すぎる範囲で規制を行うことは問題があります。

:::info[第1次家永教科書裁判（最判平5.3.16）]

**判旨**

- 教科書検定による審査は、学術的・教育的な観点から教科書の記述の適否を判断するものであり、思想内容の禁止を目的とするものではないから、**検閲に当たらない**。
- 検定不合格処分は、発表そのものを一切禁止するものではなく、一般図書としての発行を何ら妨げるものではない。
:::

#### 商業的表現（営利的表現）の自由

営利広告などの商業的表現にも、表現の自由の保障が及びます。もっとも、その保障の程度は、政治的表現に比べて低いとされています。

:::info[あん摩師等法事件（最大判昭36.2.15）]

**判旨**

- あん摩師、はり師等の広告を制限する法律の規定は、国民の保健衛生上の見地から、虚偽・誇大にわたる広告による被害を防止するために設けられたものであって、公共の福祉のために必要なものであるから、**憲法21条に違反しない**。
:::

#### 象徴的表現

象徴的表現とは、表現的に伝達しようとするメッセージを内に含む行為のことです。「焼き→！」という表現や、行進・ピケッティングなどが象徴的表現に当たります。

:::info[集合住宅でのビラ配布行為の処罰（最判平21.4.7）]

**判旨**

- 意を配達したり新たに配達しようとするメッセージを伝達する手段としてのビラ配布行為の処罰は、それが管理権者の明示の意思に反してなされた場合には住居侵入罪に当たることは免れない。
:::

## 4 学問の自由

### (1) 学問の自由

「知識や真理の探究」に関する自由です。学問の自由は、歴史的に、国家権力による学問への弾圧に対する抵抗として発展してきました。

> **憲法23条**
>
> 学問の自由は、これを保障する。

**【学問の自由の内容】**

| 区分 | 内容 |
|---|---|
| **学問研究の自由** | 真理を探究するための研究の自由 |
| **研究結果発表の自由** | 研究の成果を発表する自由 |
| **教授の自由** | 大学その他の教育機関で研究の成果を教授する自由 |

なお、先端科学技術をめぐる研究についても、国民の生命・安全等の観点から、個別にその妥当性が問題となることがあります。

### (2) 大学の自治

大学の自治とは、大学が学術の中心として、自由に研究・教育を行うために、その内部管理について自主的な運営が認められることをいいます。

教員の人事、施設の管理、学生の管理の3つが大学の自治の主要な内容です。

:::info[ポポロ事件（最大判昭38.5.22）]

**事案**

東大の学生団体「ポポロ劇団」主催の演劇発表会の観客の中に私服警官がいることを学生が発見し、その警察手帳に対して暴行を加えたところ、暴力行為等処罰法違反として起訴された。そこで、私服警察官の潜入が大学の自治に反するのではないかが争われた。

**判旨**

1. 23条の趣旨：学問的研究の自由とその研究結果の発表の自由を含むものであって、一面において、広くすべての国民に対してそれらの自由を保障するとともに、他面において、大学が学術の中心として深く真理を探求することを本質とすることにかんがみて、**特に大学におけるそれらの自由を保障することを趣旨としたものである**。
2. 施設利用権と大学の自治：大学における学生の集会も、大学の公認した学生団体が大学の許可を得て学内の施設を利用して行う場合には、大学の自治の一環として保護される。
3. 学生の集会と大学の自治：学生の集会が真に学問的な研究又はその結果の発表のためのものでなく、実社会の政治的社会的活動に当たる行為をする場合には、大学の有する特別の学問の自由と自治は享有しない。
:::
