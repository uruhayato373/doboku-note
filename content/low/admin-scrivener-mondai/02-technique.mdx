このコーナーでは、問題演習に当たり知っておくべき「革命的! 解答テクニック」を伝授する。このテクニックを駆使することで、短時間でミスなく問題を解き進めることができる。

---

## 5肢択一式問題の解き方

### 1. 問題文に○と×を大きく書く

行政書士試験の問題では、「正しいもの（妥当なもの）はどれか」という問題と、「誤っているもの（妥当でないもの）はどれか」という問題が混在している。何となく問題を解いていると、「誤っているものはどれか」という問題で正しいものを選んでしまうなど、知識はあるのに間違えてしまう事態が生じる。

**対策:** 問題文に「正しいもの（妥当なもの）はどれか」とあれば **○** を、「誤っているもの（妥当でないもの）はどれか」とあれば **×** を大きく書いておく。

### 2. 単純正誤問題 ― 各肢の正誤判断の結果を横に書き、記号が一致したものを選ぶ

行政書士試験で最も多く出題される形式。各肢の正誤判断をし、「正しい（妥当である）」と判断した肢の横には○を、「誤り（妥当でない）」と判断した肢の横には×を書いていく。そして、**問題文の記号と肢の横の記号が一致したものが正解** となる。

**例: 「正しいものはどれか」（○を探す問題）**

| 肢 | 内容 | 正誤 | 結果 |
|:---:|------|:---:|------|
| 1 | 札幌 | × | |
| 2 | 東京 | **○** | ← 一致（正解） |
| 3 | 名古屋 | × | |
| 4 | 京都 | × | |
| 5 | 大阪 | × | |

**例: 「誤っているものはどれか」（×を探す問題）**

| 肢 | 内容 | 正誤 | 結果 |
|:---:|------|:---:|------|
| 1 | 埼玉県 | ○ | |
| 2 | 千葉県 | ○ | |
| 3 | 神奈川県 | ○ | |
| 4 | 静岡県 | **×** | ← 一致（正解） |
| 5 | 群馬県 | ○ | |

> ビジュアルでどれが正解かわかるようにしておくと、ケアレスミスの防止に役立つ。

### 3. 組合せ問題 ― 消去法で解く

「正しいもの（妥当なもの）の組合せはどれか」という形式。各肢の正誤判断をしてその結果を横に書き、**記号が一致しないものを含む組合せを消去** していく（消去法）。

**手順の例:**

1. 肢アが誤り（×）とわかったら → アを含む選択肢「1」「2」を消去
2. 肢イが正しい（○）とわかったら → 記号が一致するので消去しない
3. 肢ウが誤り（×）とわかったら → ウを含む選択肢「3」「5」を消去
4. 残った組合せが正解

> **ポイント:** 組合せ問題ではすべての肢を検討しなくても正解が出せる。消去法を駆使して時間と労力を温存すること。

### 4. 個数問題 ― 記号が一致するものの個数を数える

「誤っているもの（妥当でないもの）はいくつあるか」という形式。各肢の正誤判断をしてその結果を横に書き、**記号が一致するものの個数を数える**。

**例: 「誤っているものはいくつあるか」（×の個数を数える問題）**

| 肢 | 内容 | 正誤 |
|:---:|------|:---:|
| ア | 沖縄県 | × |
| イ | 埼玉県 | ○ |
| ウ | 青森県 | × |
| エ | 神奈川県 | ○ |
| オ | 鹿児島県 | × |

→ ×は3つ → 正解は「3 三つ」

> **注意:** 個数問題はすべての肢の正誤が判断できなければ正解できず、出題形式としては最も厳しい。受験生の正答率も低い。本試験で個数問題が出題された場合は、いったん飛ばしておき、最後に時間が余ったら解くようにするとよい。

### 5. 事例問題 ― 簡単な図を書いて登場人物の関係を把握する

行政書士試験では、A・Bといった人物が登場する事例問題が出題される（特に民法で多い）。簡単な図を書いて登場人物の関係を把握することが重要。

- AとBを逆に考えてしまうと、まったく逆の結論になることがある
- 登記を「甲」、抵当権を「抵」と略しても問題ない
- 最初は時間がかかるが、慣れると図を書いた方が把握がスムーズになり、時間短縮とケアレスミス防止の効果がある

**事例1: 売買**

```
A ──（甲土地を売却・登記移転）──> B
```

**事例2: 貸金債権と抵当権**

```
A ──（100万円の貸金債権）──> B
       └─（Bの建物に抵当権設定）
```

## 多肢選択式問題の解き方

### 1. まずは知識で空欄を埋めてみる

問題文を読んで、**選択肢を見ずに** 自分の知識で空欄を埋める。空欄を埋めた後に選択肢を見て、埋めた語句が選択肢の中にあれば、それが解答となる。選択肢の左横に空欄の記号（ア、イ等）を書いておく。

### 2. 埋まらない空欄は選択肢をグループ分けして推測する

自分の知識で埋まらなかった空欄は、選択肢を見てそこから推測する。その際、**選択肢をグループ分け** しておくと推測しやすくなる。

**例:** 選択肢に「～地方」「～県」「～区」が混在している場合

- ○ → 地方グループ（関東地方、中部地方、近畿地方 ...）
- △ → 県グループ（埼玉県、千葉県、神奈川県 ...）
- □ → 区グループ（新宿区、世田谷区、大田区 ...）

問題文の文脈から空欄にどのグループが入るかを判断すれば、20分の1の確率を5分の1や10分の1まで上げることができる。

## 記述式問題の解き方

### 45マスにおさめた文章を解答用紙に記述する

不要な部分を削って45マスにおさまったら、解答用紙のマスに記述する。その際、**誤字・脱字に十分注意** すること。誤字・脱字は減点の対象となる。
