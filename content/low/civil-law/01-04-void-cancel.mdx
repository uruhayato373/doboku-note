:::tip[学習のPOINT]
意思能力・行為能力を欠き又はなかった場合や、意思表示に瑕疵がある場合は、その法律行為は無効又は取り消しうるものとなります。ここでは、その無効・取消しについて学習します。
:::

## 1 無効

### （1）無効とは何か

**無効**とは、客観的に見て法律行為が法的効力を生じないようにみえるにもかかわらず、何らかの理由によって法的効力が発生しない場合のことです。したがって、外見上は法律行為が存在しているが、実際には法的効力は発生していないことになります。

無効な行為は、追認をしても効力がないのが原則です（119条本文）。もっとも、無効であることを知ってから追認をした場合には、新たな行為をしたものとみなされます（119条ただし書）。

### （2）無効行為の追認

無効な行為は、追認をしても、その効力を生じません（119条本文）。ただし、当事者がその行為の無効であることを知って追認をしたときは、新たな行為をしたものとみなされます（119条ただし書）。

## 2 取消し

### （1）取消しとは何か

**取消し**とは、いったん効力が生じた行為を初めから無効であったものとみなすことをいいます（121条）。

### （2）取消権者

取消権者は、以下の者に限られています。

| 取消権者 | 内容 |
|---|---|
| **制限行為能力者等** | 制限行為能力者又はその代理人、承継人 |
| **瑕疵ある意思表示をした者等** | 瑕疵ある意思表示をした者（錯誤・詐欺・強迫によって意思表示をした者）又はその代理人、承継人 |

取り消すことができる行為は、上記の者しか取り消すことができません（120条）。

### （3）取消しの効果

取り消された行為は、初めから無効であったものとなります（121条）。そして、無効な行為に基づく債務の履行として給付を受けた者は、相手方を原状に復させる義務（これを**原状回復義務**という）を負います。

能力者の保護のため無効となった行為の原状回復が減縮される場合もあります。意思無能力者・制限行為能力者は、その行為によって**現に利益を受けている限度**において、返還の義務を負います（121条の2第3項）。

### （4）取り消しうる行為の追認

取り消すことができる行為は、取消権者が追認したときは、以後、取り消すことができなくなります（122条）。

追認の要件として、取消しの原因となっていた状況が消滅し、かつ、取消権を有することを知った後にしなければ、その効力を生じません（124条1項）。

:::warning[注意]
取り消すことができることを知っていなければ、追認としての効力は生じません。
:::

なお、**取消権の消滅時効**については、追認をすることができる時から**5年間**行使しないとき、又は行為の時から**20年**を経過したときは、その効力は生じません（126条）。

### （5）法定追認

取り消すことができる行為について、取消権を有する者が以下の行為をしたときは、追認をしたものとみなされます（125条）。ただし、異議をとどめたときは、この限りでありません。

| 法定追認が生じる事由 |
|---|
| 1 全部又は一部の履行 |
| 2 履行の請求 |
| 3 更改 |
| 4 担保の供与 |
| 5 取り消すことができる行為によって取得した権利の全部又は一部の譲渡 |
| 6 強制執行 |

### 【無効と取消しのまとめ】

| | **無効** | **取消し** |
|---|---|---|
| **効力** | 行為の時から効力が生じない（119条本文） | いったん有効だが、取消しにより遡及的に効力が生じなかったことになる（121条） |
| **主張権者** | 誰でも主張できる | 取消権者に限定（120条） |
| **主張期間** | 制限なし | 追認をすることができる時から5年間の不行使又は行為の時から20年の経過で消滅する（126条） |
| **追認** | 追認することができる。ただし新たな行為とみなされる（119条ただし書） | 追認すると取り消すことができなくなる（122条） |

:::note[確認テスト]
1. 当事者が無効であることを知って追認をしたときは、新たな行為をしたものと（**みなされる**）。
2. 取り消された行為は、その取消しの時から無効であったものとみなされるか。 → 正しくは（**初めから無効**）であったものとみなされる（121条）。
3. 取り消すことができる行為は、取消権者が追認したときは、以後、取り消すことが（**できない**）。
4. 追認は、取消しの原因となっていた状況が消滅し、かつ、取消権を有することを知った後にしなければ、その効力は（**生じない**）。取消権を有することを知った後でなければならない。
:::
