:::tip[学習のPOINT]
役務提供型契約とは、役務（労働力）の提供を目的とする契約のことです。この役務提供型契約には、①雇用契約、②請負契約、③委任契約、④寄託契約の4種類があります。
:::

## 1 雇用契約

**雇用契約**とは、当事者の一方（被用者）が相手方（使用者）に対して労働に従事することを約束し、相手方がこれに対してその報酬を与えることを約束することによって成立する契約のことです（623条）。

![雇用契約の事例](/content/low/civil-law/img/03-10-employment.png)

雇用契約においては、被用者が使用者に従属して労務を提供する（使用者の指揮命令に従う）ものです。

報酬の支払時期については、その約束を行った後でなければ、報酬を請求することができないとされています（624条1項）。雇用契約においては、報酬の後払いが原則とされています。

## 2 請負契約

### （1）請負契約とは何か

**請負契約**とは、当事者の一方（請負人）が仕事を完成すること（家の建築）を約束し、相手方（注文者）がその仕事の結果に対して報酬を支払うことを約束することによって成立する契約のことです（632条）。

![請負契約の事例](/content/low/civil-law/img/03-10-contract-work.png)

ここで、請負契約の報酬は、仕事の目的物の**引渡し**と**同時**に支払わなければなりません。

### （2）下請負

**下請負**とは、請負人が請け負った仕事の全部又は一部をさらにほかの者に請け負わせることです。

この下請負は、請負人本人の能力と認められた特別な請負の場合を除き、原則として許されます。下請負人は元請負人の**履行補助者**となりますので、下請負人の行為について請負人が責任を負います。

### （3）目的物の所有権の帰属

請負契約の目的物の所有権は、以下のように帰属します。

**【目的物の所有権の帰属】**

| 場合 | 所有権の帰属 |
|---|---|
| 注文者が材料の全部又は主要部分を提供した場合 | 目的物の所有権は原始的に**注文者**に帰属する |
| 請負人が材料の全部又は主要部分を提供した場合 | 目的物の所有権は原始的に**請負人**に帰属し、引渡しにより注文者に移転する。ただし、特約があればそれに従う |

### （4）請負人の担保責任

民法改正により、請負人の担保責任の規定が大幅に削除され、売主の担保責任の規定（562条〜564条）が請負契約にも適用されることになりました（559条）。

### （5）請負契約の解除

#### ① 仕事完成前の注文者の解除権

請負人が仕事を完成しない間は、注文者は、いつでも**損害を賠償**して契約の解除をすることができます（641条）。

#### ② 注文者の破産手続開始決定による解除権

注文者が破産手続開始決定の審判を受けたときは、**請負人又は破産管財人**は、契約の解除をすることができます（642条1項ただし書）。

## 3 委任契約

### （1）委任契約とは何か

**委任契約**とは、当事者の一方（委任者）が法律行為（訴訟）をすることを相手方（受任者）に委託し、相手方がこれを承諾することによって成立する契約のことです（643条）。

![委任契約の構造](/content/low/civil-law/img/03-10-mandate-structure.png)

委任契約においても、請負契約と同様、受任者は委任者から独立しています。

委任契約の報酬については、原則として無償です。ただし、報酬についての特約がある場合は、**委任事務を履行**した後でなければ報酬を請求することができません（648条1項、2項）。

そして、報酬についての特約がある場合、期間によって報酬を定めたときは、雇用契約の規定（624条2項）が準用されます（648条3項）。

:::info[重要判例]
**成果報酬型の委任**

成果に対して報酬を支払うことを約した場合は、成果が引渡しを要するときは、報酬は、その成果の引渡しと同時に支払わなければなりません（648条の2）。
:::

### （2）受任者の義務

#### ① 善管注意義務

受任者は、報酬についての特約があるかどうかにかかわらず、委任の本旨に従い、善良な管理者の注意をもって、委任事務を処理する義務を負います（644条）。

なお、各場面における注意義務についてまとめると、以下の表のようになります。

**【注意義務のまとめ】**

| 場面 | 善管注意義務を負う場合 | 注意義務が軽減されている場合 |
|---|---|---|
| 委任 | 受任者（644条） | |
| 親権 | | 自己のためにするのと同一の注意（827条） |
| 相続の承認 | | 固有財産におけるのと同一の注意（918条、644条） |
| 無償寄託 | | 自己の財産に対するのと同一の注意（659条） |

#### ② 付随的義務

受任者がなすべき事務の内容は場合により具体的ですが、民法では、委任事務の処理に際して適宜なことを要する事柄について以下の規定があります。これを付随的義務といい、以下のようなものが挙げられます。

**【受任者の付随的義務】**

| 義務 | 内容 |
|---|---|
| 報告義務 | 委任者の請求があるときは、いつでも委任事務の処理の状況を報告し、委任が終了した後は、遅滞なくその経過及び結果を報告する（645条） |
| 受取物・果実の引渡義務 | 委任事務を処理するにあたって受け取った金銭その他の物を委任者に引き渡す（646条1項） |
| 金銭消費の責任 | 委任者に引き渡すべき金額又はその利益のために用いるべき金額を自己のために消費したときは、消費した日以後の利息を支払い、なお損害があればその賠償の責任を負う（647条） |

#### ③ 復委任

受任者は、第三者に自己の代わりに事務を処理させることができます。

委任者は任意解除権を有していますから、受任者は、委任者の許諾を得たとき、又はやむを得ない事由があるときでなければ、復受任者を選任することができません（644条の2第1項）。

### （3）委任者の義務

委任者は、受任者に損失を与えないために、以下のような義務を負います。

**【委任者の義務】**

| 義務 | 内容 |
|---|---|
| 費用前払義務 | 委任事務を処理するについて費用を要するときは、受任者の請求により、その前払をする（649条） |
| 費用償還義務 | 受任者が委任事務を処理するのに必要と認められる費用を支出したときは、受任者に対し、その費用及び支出の日以後におけるその利息を償還する（650条1項） |
| 代弁済又は担保提供義務 | 受任者が委任事務を処理するのに必要と認められる債務を負担したときは、委任者に対し、自己に代わってその弁済をすることを請求するか、又は相当の担保を供させることができる（650条2項） |
| 損害賠償義務 | 受任者が委任事務を処理するため自己に過失なく損害を受けたときは、委任者に対し、その賠償を請求することができる（650条3項） |

### （4）委任の終了

#### ① 任意解除

委任は、各当事者がいつでもその解除をすることができます（651条1項）。

ただし、当事者の一方が相手方に**不利な時期**に委任の解除をしたときは、相手方が**委任の解除**から損害を受けるおそれがあるため、当事者の一方は、やむを得ない事由がある場合を除き、相手方の損害を賠償しなければなりません（651条2項1号）。

また、委任者が受任者の利益（もっぱら報酬を得ることによるものを除く）をも目的とする委任を解除したときは、当事者の一方は、やむを得ない事由がある場合を除き、相手方の損害を賠償しなければなりません（651条2項2号）。

#### ② 死亡・破産・後見開始

委任は、以下の事由によって終了します（653条）。

| | 死亡 | 破産手続開始の決定（653条2号） | 後見開始の審判（653条3号） |
|---|---|---|---|
| 委任者 | 終了する | 終了する | - |
| 受任者 | 終了する | 終了する | 終了する |

## 4 寄託契約

### （1）寄託契約とは何か

**寄託契約**とは、当事者の一方（寄託者）がある物（時計）を保管することを相手方（受寄者）に委託し、相手方がこれを承諾することによって成立する契約のことです。

![寄託契約の事例](/content/low/civil-law/img/03-10-deposit.png)

寄託は、委任と同様、原則として**無償**であり、報酬を請求することができません（665条、648条1項）。

### （2）受寄者の注意義務

受寄者は、有償寄託の場合は、**善良な管理者の注意**をもって寄託物を保管しなければなりません（400条）。無償寄託の場合には、**自己の財産に対するのと同一の注意**をもって寄託物を保管する義務を負います（659条）。

**【委任契約と寄託契約における注意義務】**

| | 義務の内容 | 注意義務の程度 |
|---|---|---|
| 委任 | 報酬についての特約があるかどうかにかかわらず善管注意義務を負う | 善管注意義務（644条） |
| 有償寄託 | 善管注意義務を負う | 善管注意義務（400条） |
| 無償寄託 | 自己の財産に対するのと同一の注意義務を負う | 軽減される（659条） |

### （3）委任の規定の準用

寄託については、委任の規定が準用されます（665条）。
