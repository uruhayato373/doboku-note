## 1 実子

### （1）実子の種類

実子とは、婚姻関係にある男女間に生まれた**嫡出子**と、婚姻関係にない男女間に生まれた**非嫡出子**とに分類されます。

### （2）嫡出の推定

妻が婚姻中に懐胎した子は、婚姻の成立の日から200日を経過した後又は婚姻の解消・取消しの日から300日以内に生まれた子は、婚姻中に懐胎したものと推定されます（772条1項・2項）。

**【子の出生日と嫡出の推定】**

| | 婚姻の成立 | 婚姻の解消・取消し |
|---|---|---|
| 期間 | 200日 | 300日 |
| 推定されない嫡出子 | 推定される嫡出子 | |

![子の出生日と嫡出の推定](/content/low/civil-law/img/04-02-legitimacy-presumption.png)

### （3）嫡出の否認

嫡出の推定を受ける場合、**嫡出否認の訴え**によってのみ嫡出であることを否定できます。ただし、**親子関係不存在確認の訴え**によっても父子関係の存否を確認することができます。

**【嫡出否認の訴えと親子関係不存在確認の訴え】**

| | 嫡出否認の訴え | 親子関係不存在確認の訴え |
|---|---|---|
| 提訴権者 | 夫（774条） | 利害関係人 |
| 出訴期間 | 子又は親権を行う母が子の出生を知った時から5年以内（777条） | 制限なし |
| 相手方 | 子又は親権を行う母（775条） | 父又は母 |

実子の種類と嫡出を否定する方法についてまとめると、以下のとおりになります。

**【実子の種類と嫡出否認の方法】**

| 実子の種類 | 嫡出否認の方法 |
|---|---|
| 推定される嫡出子 | 嫡出否認の訴え |
| 推定されない嫡出子 | 親子関係不存在確認の訴え |
| 非嫡出子 | 親子関係不存在確認の訴え |

![実子の種類と嫡出否認の方法](/content/low/civil-law/img/04-02-child-types.png)

### （4）認知

認知とは、非嫡出子について、その父又は母との間に親子関係があることを認める意思表示です。

#### ① 任意認知

父又は母が未成年者又は成年被後見人であるときであっても、**法定代理人の同意を要しない**で、認知をすることができます（780条）。

任意認知は、戸籍法の定めるところにより、**届出**をすることによってすることもできますし（781条1項）、**遺言**によってすることもできます（781条2項）。

ただし、以下の者を認知する場合には、認知の承諾が必要です。

**【認知の承諾】**

| 認知される者 | 承諾の要否 |
|---|---|
| 成年の子 | その子の承諾が必要（782条） |
| 胎児 | 母の承諾が必要（783条1項） |
| 死亡した子 | その直系卑属の承諾が必要（783条2項）。ただし、直系卑属が成年の場合のみ |

任意認知は、**出生の時**にさかのぼってその効力を生じますが、第三者が既に取得した権利を害することはできません（784条）。

#### ② 認知の訴え

子、その直系卑属又はこれらの者の法定代理人は、**認知の訴え**を提起することができます。認知の訴えは、父又は母の生存中であれば、いつでも提起できます。これに対し、父又は母の死亡の日から**3年**を経過したときは、提起することができません（787条本文・ただし書）。

#### ③ 準正

準正とは、婚姻でない子に嫡出子としての地位を与えることです。

例えば、父が認知した子は、その父母の婚姻によって嫡出子の身分を取得します（789条1項）。また、婚姻中に父母が認知した子も、嫡出子の身分を取得します。その場合、嫡出子の身分を取得した子は、婚姻の時から嫡出子の身分を取得します（789条2項）。

## 2 養子

### （1）普通養子縁組

#### ① 縁組の成立・取消し

当事者間に縁組をする意思がない場合や、当事者が縁組の届出をしない場合には、縁組は無効となります（802条）。

以下の縁組の要件に違反した場合、数字にチェック（804条〜808条）が取消しの原因となります。

**【普通養子縁組の要件】**

| 要件 | 条文 |
|---|---|
| 養親となる者が成年者であること | 792条 |
| 養親又は養親の直系尊属でないこと | 793条。ただし、自己の直系尊属又は年長者は養子とすることができない |
| 後見人が被後見人を養子にする場合は家庭裁判所の許可を得ること | 794条 |
| 配偶者のある者が未成年者を養子にするには配偶者とともにすること | 795条本文。ただし、配偶者の嫡出子を養子とする場合、又は配偶者がその意思を表示できない場合を除く |
| 配偶者のある者が縁組をするには配偶者の同意を得ること | 796条 |
| 15歳未満の者を養子とする場合は法定代理人が承諾すること | 797条1項 |
| 未成年者を養子とするには家庭裁判所の許可を得ること | 798条。ただし、自己又は配偶者の直系卑属を養子とする場合を除く |

また、詐欺又は強迫によって縁組をした者は、その縁組の取消しを請求することができます（808条1項、747条1項）。

#### ② 代諾縁組

養子となる者が**15歳未満**であるときは、その法定代理人が、これに代わって、縁組の承諾をすることができます（797条1項）。

もっとも、法定代理人が承諾をするときには、養子となる者の父母でその監護をすべき者であるものが他にあるときは、その同意を得なければなりません（797条2項）。

#### ③ 縁組の効果

養子は、**縁組の日**から、養親の嫡出子の身分を取得します（809条）。

また、養子は、養親の氏を称します（810条本文）。ただし、婚姻によって氏を改めた者については、婚姻の際に定めた氏を称すべき間は、この限りではありません（810条ただし書）。

なお、養子は、養親及びその血族との間において養子縁組の日から血族間におけると同一の親族関係を生じます（727条）。

#### ④ 離縁

縁組の当事者は、その協議で、離縁をすることができます（811条1項）。

養子が15歳未満であるときは、その離縁は、養親と養子の離縁後にその法定代理人となるべき者との協議でこれをします（811条2項）。

また、縁組の当事者の一方は、①悪意の遺棄、②3年以上の生死不明、③その他縁組を継続し難い重大な事由の場合には、離縁の訴えを提起することができます（814条1項）。

### （2）特別養子縁組

普通養子縁組がなされても、養子と実方の親族との間の親族関係は存続しますが、民法は、養子と実方の親族との親族関係が終了する**特別養子縁組**の制度を設けています（817条の2〜817条の11）。

特別養子縁組は、実親による養育が困難な場合等に、家庭裁判所の審判によって成立します。

**【普通養子縁組と特別養子縁組】**

| | 普通養子縁組 | 特別養子縁組 |
|---|---|---|
| 成立要件 | ①養親が成年者であること（792条）②養子が養親の尊属でないこと（793条） | ①養親となる者の請求（817条の2第1項）②配偶者のある者であること（817条の3第1項）③養親の一方が25歳以上であること（817条の4）。ただし他方は20歳に達していれば可 |
| 養親の資格 | 成年（792条） | 配偶者のある者（817条の3第1項）。原則25歳以上（817条の4） |
| 監護の状況 | 不要 | 必要。父母による養子となる者の監護が著しく困難又は不適当であること等の事情がある場合に成立する（817条の7） |
| 養子の試験養育期間 | 不要 | 6ヶ月以上（817条の8） |
| 父母の同意 | 不要 | 必要（817条の6） |
| 実親との関係 | 存続 | 原則、終了（817条の9） |
| 離縁 | 自由にできる | 原則、できない（817条の10） |

:::note[確認テスト]
1. 婚姻の成立の日から200日を経過した後又は婚姻の解消・取消しの日から300日以内に生まれた子は、嫡出子と推定される。
2. 父又は母が未成年者又は成年被後見人である場合、認知をするには法定代理人の同意が必要である。
3. 養子は、縁組の日から養親の嫡出子の身分を取得する。
