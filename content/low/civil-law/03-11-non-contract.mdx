契約以外の債権発生原因には、①事務管理、②不当利得、③不法行為の3つがあり、それぞれの要件が重要なので、要件ごとに重点的に学習しましょう。
:::

## 1 事務管理

### （1）事務管理とは何か

Aの家の屋根が壊れてしまったが、BはAに頼まれてもいないのに、その屋根を修理した。

**事務管理**とは、義務がないにもかかわらず他人のために事務を管理すること（697条1項）です。管理者とは、本人のために事務管理をする者のことをいいます。

![事務管理の事例](https://storage.doboku-note.com/content/low/civil-law/img/03-11-management-affairs.png)

上の事例で、BはAに頼まれたわけでもなく、契約が存在しないにもかかわらず、Aの家の屋根を修理しています。Bの行為は事務管理となり、これにより一定の法律関係が生じます。

契約と同様に債権発生原因となります。

この事務管理制度の趣旨は、社会生活を営む上では相互に助け合うことは望ましいことであるので、他人の事務に干渉した者にも一定の法的保護を与えようというものです。

### （2）要件

#### ① 法律上の義務の不存在

契約があれば事務の管理は契約上の義務となりますし、親権のような法律上の義務がある場合は法律の規定に基づいて他人の事務を管理するのですから、事務管理にはなりません。

#### ② 他人のためにする意思があること

「他人のためにする」とは、**他人のために事務を管理する意思**があることを要します（「他人のためにする意思」とは、管理の効果を本人に帰属させる意思が併存していればよいとされます）。

**他人の事務を自己の事務と誤信した場合**は、法律行為（例：賃借契約の締結）で「他人のためにする意思」がないので事務管理とはなりません。もっとも、事実行為（例：家の修理）であれば、「他人のためにする意思」がなくても、事務管理が成立します。

#### ③ 本人の意思及び利益への適合

管理者は、事務の管理を始めた後、**本人の意思に適合する方法**によって、事務管理をしなければなりません（697条1項）。また、管理者は、本人の意思を知っているとき、又はこれを推知することができるときは、本人の意思に従い、事務管理をしなければなりません（697条2項）。

### （3）効果

#### ① 管理者の義務

管理者は、**善良な管理者の注意**をもって事務管理をする義務を負います。ただし、管理者が本人の身体、名誉又は財産に対する急迫の危険を免れさせるために事務管理をしたとき（**緊急事務管理**）は、悪意又は重大な過失がなければ、これによって生じた損害を賠償する責任を負いません（698条）。

また、管理者は、本人又はその相続人もしくは法定代理人が管理をすることができるに至るまで、事務管理を継続しなければなりません（700条本文）。ただし、事務管理の継続が本人の意思に反し、又は本人に不利であることが明らかであるときは、事務管理をやめなければなりません（700条ただし書）。

管理者は、①遅滞なく本人に事務管理の開始を通知すること、②事務管理が終了した後に経過及び結果を報告すること、③事務管理に際して受け取った金銭その他の物を本人に引き渡すこと等の義務を負います。

#### ② 管理者の権利

管理者が本人のために有益な費用を支出したときは、本人に対し、その償還を請求することができます（702条1項）。

また、管理者が本人のために有益な債務を負担した場合も、本人に対し、自己に代わってその弁済をすることを請求することができます（702条2項、650条2項前段）。

しかし、管理者が本人の意思に反して事務管理をしたときは、本人が現に利益を受けている限度においてのみ償還請求をすることができます（702条3項）。

なお、委任と事務管理の異同についてまとめると、以下の表のようになります。

| | 委任 | 事務管理 |
|---|---|---|
| 契約の有無 | 特約があれば（648条1項） | なし |
| 報酬 | 有償も可能（648条1項） | 請求不可 |
| 善管注意義務 | あり（644条） | あり（697条1項） |
| 代弁済請求権 | あり（650条2項） | あり（702条2項） |
| 費用償還請求権 | あり（650条1項） | あり（702条1項） |
| 費用前払請求 | あり（649条） | なし |
| 損害賠償請求 | あり（650条3項） | なし |
| 報告義務 | あり（645条） | あり（701条） |
| 受取物引渡義務 | あり（646条1項） | あり（701条） |
| 金銭消費の責任 | あり（647条） | あり（701条） |

## 2 不当利得

### （1）不当利得とは何か

Aは、自分の所有する時計をBに対して売却し、この時計を引き渡した。しかし、この時計の売買契約はBの詐欺によるものであったので、Aは、時計の売買契約を取り消した。

**不当利得**とは、法律上の原因なく他人の財産又は労務によって利益を受け、そのために他人に損失を及ぼした者（受益者）に対して、その利益の存する限度においてその返還をさせる制度です（703条、704条）。

![不当利得の事例](https://storage.doboku-note.com/content/low/civil-law/img/03-11-unjust-enrichment.png)

上の事例で、AはBとの間の売買契約を詐欺を理由に取り消しましたから、取消しにより契約は遡及的に無効となります。にもかかわらず、BがAの時計を持っている場合、不当利得を有していることになります。不当利得制度がなければ、Bは何の法律上の原因もなく時計を所持し続けることが可能になってしまいます。

また、AはBに対して、時計の返還を請求することになりますが、これは不当利得に基づく返還請求です。このように、不当利得は、契約と同様に債権発生原因のひとつとなります。

不当利得の趣旨は、ある財産的な移動が、形式的には正当とされる財産価値の移動が実質的に正当でない場合に、公平の理念に従ってこれを調整する点にあります。

### （2）要件

不当利得の成立要件は、以下の4つです。

| 要件 |
|---|
| ① 受益者が他人の財産又は労務によって利益を受けたこと |
| ② 他人に損失が生じたこと |
| ③ 受益と損失の間に因果関係があること |
| ④ 法律上の原因がないこと |

### （3）効果

善意の受益者は、**利益の存する限度**において、これを返還する義務を負います（703条）。

これに対して、悪意の受益者は、その受けた利益に利息を付して返還しなければならず、なお損害があるときは、その賠償の責任を負います（704条）。

不当利得の返還請求が制限される場合（**不当利得の特則**）があります。以下の4つです。

#### ① 非債弁済

債務の弁済として給付をした者は、その給付が債務の存在しないことを知ってした場合（**非債弁済**）において、その給付したものの返還を請求することができません（705条）。

#### ② 期限前の弁済

債務者は、**弁済期**にない債務の弁済として給付したものの返還を請求することができません。ただし、債務者が錯誤によってその給付をしたときは、債権者は、これによって得た利益を返還しなければなりません（706条）。

:::warning[注意]
弁済期前の弁済については返還請求できないが、錯誤による場合は債権者が利得を返還する必要がある点に注意しましょう。
:::

#### ③ 他人の債務の弁済

債務者でない者が錯誤によって債務の弁済をした場合において、債権者が善意で証書を毀滅し、もしくは担保を放棄し、又は時効によってその債権を失ったときは、その弁済をした者は、返還の請求をすることができません（707条1項）。

なお、弁済者から債務者に対する求償権の行使は妨げられません（707条2項）。

#### ④ 不法原因給付

不法な原因のために給付をした者は、その給付したものの返還を請求することができません（708条本文）。これを**不法原因給付**といいます。

この趣旨は、みずから反社会的な行為をした者に対しては、その行為の回復を請求することを許さない点にあります。

ここにいう「**給付**」とは、受益者に終局的な利得を与えるような財産的出捐をいいます。

| 給付の意味 | 具体例 |
|---|---|
| 不動産 | 所有権移転登記をすること |
| 動産 | 物を引き渡すこと（現物を引き渡す） |
| 金銭 | 「弁済として」金銭を支払うこと |

なお、不法な原因が**受益者**についてのみ存したときは、給付したものの返還を請求することができます（708条ただし書）。

## 3 不法行為

### （1）不法行為とは何か

Aは、自家用車を運転中、わき見運転をしていたために通行人Bを傷つけてしまった。これにより、Bは全治1ヶ月の傷害を負い、入院を余儀なくされた。

**不法行為**とは、故意又は過失によって他人の権利又は法律上保護される利益を侵害した行為をいいます。この場合に、被害者は加害者に対し損害賠償を請求することができます。すなわち、不法行為を行った者は、これによって生じた損害を賠償する責任を負います（709条）。

![不法行為の事例](https://storage.doboku-note.com/content/low/civil-law/img/03-11-tort.png)

上の事例では、Aのわき見運転という過失によりBに傷害を負わせたので、Bに対して損害賠償請求をすることができます。Aの行為は不法行為にあたります。したがって、Bは、Aに対し、損害賠償請求をすることができます（なお、自動車損害賠償保障法による特則があります（自賠法3条参照）が、ここでは民法上の不法行為について説明します）。

なお、不法行為は、**一般不法行為**と**特殊不法行為**に分類されます。

| 分類 | 内容 |
|---|---|
| 一般不法行為 | 故意又は過失に基づく一般的な不法行為（709条） |
| 特殊不法行為 | 監督義務者の責任（714条）、使用者責任（715条）、注文者の責任（716条）、工作物責任（717条）、動物占有者の責任（718条）、共同不法行為（719条） |

### （2）一般不法行為

一般不法行為の要件は、以下の6つです。

#### ① 故意又は過失があること

**故意**とは、自分の行為が他人に損害を与えることを認識しながらあえてその行為をする心理状態をいい、**過失**とは、結果の発生を予見すべきであったにもかかわらず不注意でこれを予見しなかったことをいいます。

#### ② 責任能力があること

不法行為の加害者は、自己の行為の責任を弁識する能力（**責任能力**）を有しなければなりません。未成年者は、他人に損害を加えた場合において、自己の行為の責任を弁識するに足りる知能を備えていなかったときは、その行為について賠償の責任を負いません（712条）。精神上の障害により自己の行為の責任を弁識する能力を欠く状態にある間に他人に損害を加えた者も、その行為について賠償の責任を負いません。故意又は過失によって一時的にその状態を招いたときは、この限りではありません（713条）。

#### ③ 権利又は法律上保護される利益を侵害したこと

他人の権利又は法律上保護される利益を侵害することが必要です。

#### ④ 損害が発生すること

**損害**とは、不法行為があった場合となかった場合との利益状態の差を金銭で評価したもののことです（**差額説**）。

#### ⑤ 行為と損害との間に因果関係があること

たとえ加害者に故意・過失があったとしても、これは損害に対する責任を負う根拠になるにすぎません。したがって、損害に対する責任を課すには、加害行為と損害との間に因果関係があることが必要です。不法行為における因果関係は、当該行為から通常生じるであろう損害が賠償の対象となります（**相当因果関係**）。

#### ⑥ 違法性阻却事由がないこと

**違法性阻却事由**とは、行為が一応違法と認められたものについて、正当防衛、緊急避難等の事由が存在するために、違法性が否定されることをいいます。

| | 正当防衛（720条1項） | 緊急避難（720条2項） |
|---|---|---|
| 要件 | 他人の不法行為に対し、自己又は第三者の権利又は法律上保護される利益を防衛するため、やむを得ず加害行為をしたこと | 他人の物から生じた急迫の危険を避けるため、やむを得ずその物を損傷したこと |
| 効果 | 損害賠償の責任を負わない。不法行為者に対して損害賠償をすることができる | 損害賠償の責任を負わない。物の所有者に対して損害賠償をすることができる |

### （3）特殊不法行為

#### ① 監督義務者の責任

![監督義務者の責任](https://storage.doboku-note.com/content/low/civil-law/img/03-11-supervisor-liability.png)

責任無能力者（B）がその責任を負わない場合、その責任無能力者を監督する法定の義務を負う者（**監督義務者**）が、その責任無能力者が第三者に加えた損害を賠償する責任を負います（714条1項本文）。ただし、監督義務者がその義務を怠らなかったとき、又はその義務を怠らなくても損害が生ずべきであったときは、この限りではありません（714条1項ただし書）。

:::info[重要判例]
監督義務者に代わって責任無能力者を監督する者（代理監督者）も、監督義務者と同一の責任を負います（714条2項）。
:::

#### ② 使用者責任

![使用者責任の事例](https://storage.doboku-note.com/content/low/civil-law/img/03-11-employer-liability.png)

ある事業のために他人を使用する者（A）は、被用者（B）がその事業の執行について第三者に加えた損害を賠償する責任を負います（715条1項本文）。これを**使用者責任**といいます。

使用者責任の趣旨は、使用者は被用者の活動によって自己の活動範囲を拡張し、利益を得ているという**報償責任**の考え方に基づいています。つまり、利益を得ている以上、被用者が生じさせた損害についても責任を負うべきという点にあります。

ただし、使用者が**被用者の選任及びその事業の監督**について**相当の注意**をしたとき、又は相当の注意をしても損害が生ずべきであったときは、使用者は責任を負いません（715条1項ただし書）。

また、使用者に代わって事業を監督する者（**代理監督者**）も、使用者と同一の責任を負います（715条2項）。

使用者又は監督者は、被用者に対して**求償権**を行使することができます（715条3項）。

#### ③ 注文者の責任

注文者は、注文又は指図についてその注文者に過失があったときでなければ責任を負いません（716条）。請負人は注文者から独立して仕事を行うものであり、より独立性が強いからです。

#### ④ 工作物責任

![工作物責任の事例](https://storage.doboku-note.com/content/low/civil-law/img/03-11-structure-liability.png)

土地の**工作物**の設置又は保存に瑕疵があることによって他人に損害を生じたときは、その工作物の占有者（B）は、被害者に対して損害賠償請求をすることができます（717条1項本文）。

ただし、占有者が損害の発生を防止するのに必要な注意をしたときは、**所有者**がその損害を賠償しなければなりません（717条1項ただし書）。

この場合、所有者の責任は**無過失責任**です。すなわち、占有者が損害の発生を防止するのに必要な注意をしたことを証明して免責された場合、所有者が損害賠償の責任を負います。所有者は過失がなくても責任を免れることができません。

なお、損害の原因について他にその責任を負う者があるときは、占有者又は所有者は、その者に対して求償権を行使することができます（717条3項）。

:::warning[注意]
工作物の占有者の責任は過失責任（中間責任）ですが、所有者の責任は**無過失責任**である点に注意しましょう。
:::

#### ⑤ 動物占有者の責任

動物の占有者は、その動物が他人に加えた損害を賠償する責任を負います（718条1項本文）。

もっとも、動物の種類・性質に従い**相当の注意**をもってその管理をしたときは、免責されます（718条1項ただし書）。

#### ⑥ 共同不法行為

![共同不法行為の事例](https://storage.doboku-note.com/content/low/civil-law/img/03-11-joint-tort.png)

数人が共同の不法行為によって他人に損害を加えたときは、各自が**連帯して**その損害を賠償する責任を負います（719条1項前段）。これを**共同不法行為**といいます。

共同行為者のうちいずれの者がその損害を加えたかを知ることができないときも、各自（719条1項前段）、**連帯責任**（全額の賠償義務者）を負わされることになります。

また、異なる数人の過失による行為も含まれます。以下の2つの場合です。

| 共同不法行為の類型 | 内容 |
|---|---|
| 狭義の共同不法行為 | 数人が共同の不法行為によって他人に損害を加えた場合（719条1項前段） |
| 教唆・幇助 | 行為者を教唆した者又は幇助した者も共同行為者とみなす（719条2項） |

共同不法行為者間には、**過失の割合**（負担部分）に応じた求償権の行使が認められます。しかし、求償権を行使しても全額の回収ができるとは限らず、被害者の保護にもつけられます。

### （4）不法行為の効果

#### ① 金銭賠償の原則

損害賠償の方法は、**金銭賠償**です。加害者に対して金銭で損害賠償額を支払わせることができます。別段の意思表示がないときは、金銭をもってその額を定めなければなりません（722条1項、417条）。

#### ② 名誉毀損の場合

裁判所は、名誉を毀損された者の請求により、損害賠償に代えて、又は損害賠償とともに、名誉を回復するのに適当な処分を命ずることができます（723条）。

#### ③ 損害賠償請求権者

まず、被害者本人は、損害賠償を請求することができます。

**慰謝料**については、損害賠償の請求権については、既に生まれたものなので、被害者本人が生前に慰謝料請求の意思表示をしていなくても、当然に相続の対象となります（最判昭42.11.1）。

また、被害者の**近親者**（被害者の父母、配偶者及び子）も固有の**慰謝料請求権**を有します（711条）。

| 請求権者 | 根拠 |
|---|---|
| 被害者本人 | 709条 |
| 近親者（父母・配偶者・子） | 711条（固有の慰謝料請求権） |

なお、慰謝料請求権の相続について、判例は**当然相続説**を採用しています（大判大15.2.16、最判昭43.11.15）。すなわち、被害者が生前に慰謝料請求の意思表示をしていなくても、慰謝料請求権は当然に相続の対象となります。

#### ④ 損益相殺

不法行為と同一の原因によって被害者が利益を受けた場合は、賠償額の算定にあたって利益を控除（差し引くこと）ができます。これを**損益相殺**といいます。

| 認められるもの | 認められないもの |
|---|---|
| 死亡者の生活費（最大判昭39.6.24） | 生命保険金（最判昭39.9.25） |
| 遺族年金（最判昭50.10.24） | 香典・見舞金 |
| | 所得税（最判昭45.7.24） |
| | 生活保護の受給権（最判昭46.6.29） |
| | 自損事故保険金（最判平7.1.30） |

#### ⑤ 過失相殺

被害者にも過失があったときは、裁判所は、これを考慮して、損害賠償の額を定めることができます（722条2項）。これを**過失相殺**といいます。

そして、過失相殺の対象となる被害者の過失は、被害者本人と身分上ないし生活関係上一体をなすとみられる関係にある者の過失（**被害者側の過失**）を含みます（最判昭42.6.27）。

| 被害者側の過失 | |
|---|---|
| **当たるもの** | **当たらないもの** |
| 夫と妻（最判昭51.3.25） | 被害者の友人 |
| 被害者の被用者の過失（最判昭4.3.4） | 保育園の保育士 |
| 好意同乗者 | |

また、損害の発生や拡大に寄与した被害者の精神的・肉体的素因（**素因減額**）についても、722条2項の規定が類推適用されます。

| 過失相殺の対象となるもの | 過失相殺の対象とならないもの |
|---|---|
| 被害者の心因的要因（精神的素因）（最判昭63.4.21） | 被害者の身体的特徴（首が長いなど）（最判平8.10.29） |

#### ⑥ 損害賠償請求権の期間制限

不法行為による損害賠償の請求権は、被害者又はその法定代理人が損害及び加害者を知った時から**3年**間行使しないときは、時効によって消滅します。また、不法行為の時から**20年**間行使しないときも、時効によって消滅します（724条）。この期間については以下の表を参考にしてください。

| | 消滅時効（知った時から） | 時効・除斥期間（不法行為時から） |
|---|---|---|
| 損害賠償請求権（一般） | 3年 | 20年 |
| 生命・身体の損害賠償請求権 | 5年 | 20年 |

#### ⑦ 債務不履行責任との違い

債務不履行による損害賠償責任と不法行為による損害賠償責任の違いは、以下の表のとおりです。

| | 債務不履行責任（債権者＝被害者） | 不法行為責任（被害者） |
|---|---|---|
| 規定 | 415条 | 709条 |
| 立証責任 | 債務者が帰責事由の不存在を立証 | 被害者が加害者の故意・過失を立証 |
| 過失相殺 | 裁判所は必ず考慮する（418条） | 裁判所は考慮することが**できる**（722条2項） |
| 消滅時効 | 権利行使可能を知った時から5年、権利行使可能時から10年（166条1項各号）。人の生命・身体の侵害は権利行使可能時から20年（167条） | 損害及び加害者を知った時から3年（人の生命・身体を害する不法行為は5年）、不法行為の時から20年（724条、724条の2） |
| 履行遅滞 | 不法行為時から当然に遅滞（最判昭37.9.4） | 不法行為時から当然に遅滞 |
| 損害賠償の範囲 | 通常損害＋特別損害（416条） | 相当因果関係にある損害（判例） |
