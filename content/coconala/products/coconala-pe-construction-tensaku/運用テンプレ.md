# 技術士 建設部門の論文添削（coconala-pe-construction-tensaku）運用テンプレ

> [!note]
> ココナラ商品 `coconala-pe-construction-tensaku` の受注から評価までの型。価格・受付枠・状態は `config/products.json`（生成物 `src/lib/coconala-services.ts`）、出品文は `config/coconala-listings.json` が真実源（ここに価格を書かない）。
> 2026-11-27 の初受注（R8 必須科目 I-1 の再現論文・talkroom 18661633）で固まった形を書き残したもの。総監の記述式の添削は [総監の運用テンプレ](../coconala-pe-sokan-tensaku/運用テンプレ.md) で、納品物の作り方と自己点検は共通。

## 1. 守ること

- 出品文の約束は「赤入れ添削（題意とのずれ・課題の立て方・解決策の具体性・リスクと対策）」「発注者の立場から見て、読み手に伝わりにくい箇所の指摘」「総評と次に直す順番（3つまで）」「質問への回答1往復」。対象は必須科目I・選択科目II・IIIのうち1問。納期は答案の受領から3日
- 「発注者の立場から見た指摘」は独立した節にせず、赤入れの指摘（誰が・どの施設で行うのかが見えない、箇条書きで考えの筋道が切れる、など）として入れる
- 答案の作成代行はしない。答案に無い事実は〇〇の空欄にし、一般的な内容で埋めた例には「ご自身の施設の事実に置き換えて」と注記する
- 購入者の選択科目の技術的な数値や制度に触れるときは、参考情報として断定せずに書く
- 不合格の原因を聞かれても、見ているのは送られた答案（1問）だけだと明記する（ほかの科目の答案は見ていない）
- 納品文と PDF に URL・note・サイト名を書かない（外部誘導の禁止）。合格を保証しない。試験委員を名乗らない
- 顧客の答案と下書きはリポジトリに置かず `.tmp/coconala/talkrooms/{id}/` に保存する

## 2. 購入直後に送る文

購入者が選択科目と状況を書いてきていれば、それを踏まえる。連絡期限は購入から48時間。

```
〇〇様

ご購入ありがとうございます。建設部門 〇〇の再現論文の添削を担当いたします。
（受験の結果に触れていれば、ねぎらいを一文）

次の2点をこのトークルームでお送りください。届いた時点から3日以内にお返しします。

1. 問題文（選んだ問題の番号も教えてください。お手元にある範囲で結構です）
2. 再現論文（手書きの写真・Word・テキストのどれでも構いません）

再現答案は本番と多少違っていても問題ありません。覚えている範囲で書いていただければ、そこから弱点を探ります。
お預かりした答案は本サービスの添削にのみ使い、第三者に開示しません。
```

## 3. 納品物（PDF）の構成

| 区切り | 中身 |
|---|---|
| 資料の構成 | 区切りの一覧と、どこまでが添削でどこからが助言か |
| 1 総評 | 良い点、点を落としやすい箇所を大きく3つ。見ているのは送られた答案だけだという注記 |
| 1 直す順番 | 3つまで |
| 1 設問ごとの判定 | 設問・求められていること・字数（空白を除く）・判定（A/B/C）・ひとこと |
| 2 赤入れ | 設問ごとに、「」内の引用（原文どおり）→ 指摘 → 直し方の型。最後に「全体の書き方」（誰が・どの施設で、問題の大きさ、箇条書き） |
| 3 組み直しの型 | 判定が最も低い設問の、空欄つきの型と、答案用紙に収まる長さの例（注記つき） |
| 4 過去の出題から見た次回への備え | R1 以降のテーマの表、(3)の問い方の型の表、(1)に付く条件、題材になる国の計画、練習の方法 |

必須科目Iで指摘になりやすい型:
- 課題を「〜の効率化」「〜を図る」と手段の形で書いている（「現状 → なぜ問題か」で書く）
- (3)に、解決策を実行している最中のリスクを書いている（設問の型に合わせて、実行した後に残る懸念・波及効果・将来的な懸念を書く）
- (4)が一般論で、自分の解決策と結びついていない。社会の持続性の留意点が「自己研鑽」にずれる
- 解決策の主語と対象（誰が・どの施設で）が無い

(3)の問い方の型（年度ごとの対応は `content/kindle/books/c-I/front-matter.md` と、サイト収録の問題文 `content/site/pe-construction/r0X-required/` で確かめる）:
- 解決策を実行しても（解決策に共通して）新たに生じうるリスク・懸念
- すべての解決策を実行して生じる波及効果と懸念事項
- 解決策に関連して新たに浮かび上がる将来的な懸念

PDF の作り方・置き場は総監の運用テンプレの「3」と同じ。

## 4. 送信前の自己点検

総監の運用テンプレの「4」と同じ。加えて、過去の出題の表は年度・I-1/I-2 ごとに問題文と照らす（I-1 と I-2 で(3)の型が違う年がある）。

## 5. 納品文の型と納品のあと

総監の運用テンプレの「5」「6」と同じ。納品文には「今回見ているのは〇〇の答案だけ」の一文を入れる。
