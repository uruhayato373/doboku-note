# 技術士 口頭試験 想定質問作成（coconala-pe-oral-qa）運用テンプレ

> [!note]
> ココナラ商品 `coconala-pe-oral-qa` の受注から納品までの型。価格・受付枠・状態は `src/lib/coconala-services.ts`、出品文は `.claude/config/coconala-listings.json` が真実源（ここに価格を書かない）。
> 想定問答の素材は note「総監口頭試験 完全準備システム」（`content/note/技術士総監/口頭試験対策-完全版/article.md`）と「建設部門 口頭試験対策」（`content/note/技術士建設部門/magazines/建設部門-口頭試験対策/article.md`）。納品文に URL・note・サイト名を書かない（外部誘導禁止）。

## 1. 守ること

- **事実は購入者の提出物からだけ取る**。業務・数値・役職・成果を創作しない。足りない箇所は「確認事項」として返す（経験記述の Red Line #2 と同じ）。
- 回答は**骨子**まで。一字一句の台本にしない（本人が自分の言葉で話せる形にする）。
- 試問事項・日程は日本技術士会の公式案内が正。資料の記述と食い違ったら公式に合わせる。
- 合格を保証しない。試験委員を名乗らない。

## 2. 購入直後に送る文（ヒアリングシート）

```
ご購入ありがとうございます。口頭試験の想定質問作成を担当いたします。
次の4点をこのトークルームでお送りください。揃った日から4日以内にお返しします。

1. 受験部門と選択科目（例：建設部門／道路、総合技術監理部門）
2. 受験申込書の「業務内容の詳細」全文（720字以内のもの）
3. 業務経歴の一覧（年月・所属・職名・業務の内容。申込書の記載どおりで構いません）
4. 口頭試験で特に不安な点（任意。例：経歴の説明が長くなる、倫理の質問が苦手 など）

お預かりした内容は本サービスの作成にのみ使い、第三者に開示しません。
経験されていない業務を答えに含めることはできませんので、事実が足りない箇所は確認のご質問としてお返しします。
```

## 3. 納品物の型

```
【想定質問20問と回答の骨子】受験部門：〇〇

■ 経歴説明（3問）
Q1. 業務経歴を2分程度で説明してください。
 骨子：①〇〇（最も長い担当）→②〇〇（業務内容の詳細の業務）→③現在の立場。話す順番と各30秒の目安。
 根拠：業務経歴 〇行目／業務内容の詳細 第〇段落

■ 業務内容の詳細への深掘り（6問）
■ コンピテンシー（建設部門）／5管理の視点（総監）（6問）
■ 技術者倫理・継続研さん（5問）

【確認事項】（提出物からは判断できず、骨子を仮置きした箇所）
・Q〇：〇〇の判断をしたのはご本人か、上司か
```

- 20問の内訳は上の 3／6／6／5 を基本にし、提出物の厚い分野へ寄せてよい。
- 各骨子に**提出物のどこから取ったか**（根拠）を付ける。根拠が無い骨子は確認事項へ回す。

## 4. 記録

- 受注は `.claude/state/coconala/orders-log.json` に追記（`/coconala-order`）。`tensakuMinutes` に作成の所要時間を記録し、2〜3件で週枠（2件）と価格を見直す。
- 提出物・原稿本文は repo に保存しない（privacyNote）。
