# 技術士 総監 記述式の添削（coconala-pe-sokan-tensaku）運用テンプレ

> [!note]
> ココナラ商品 `coconala-pe-sokan-tensaku` の受注から評価までの型。価格・受付枠・状態は `config/products.json`（生成物 `src/lib/coconala-services.ts`）、出品文は `config/coconala-listings.json` が真実源（ここに価格を書かない）。
> 2026-11-26〜27 の初受注（R8 地方創生の再現論文・talkroom 18660481）で固まった形を書き残したもの。土木の添削エージェント（`civil-keiken-tensaku-drafter` / `-qa`）は経験記述専用なので使わない。

## 1. 守ること

- 出品文の約束は「赤入れ添削（題意とのずれ・管理の視点・施策の具体性・トレードオフ）」「施策ごとの字数と中身の判定」「総評と次に直す順番（3つまで）」「質問への回答1往復」。納期は答案の受領から3日
- 答案の作成代行はしない。答案に無い事実は足さず、直し方の型では〇〇の空欄にする。一般的な内容で埋めた例を添えるときは「ご自身の施設・業務の事実に置き換えて」と注記する
- 購入者の選択科目（衛生工学など）が専門外のときは、その分野の技術的な正否は判断しない。制度や数値に触れるときは「公表資料を見た範囲では〜のようです」と推測の言い方にし、断定しない（相手はその分野の専門家）
- 納品文と PDF に URL・note・サイト名を書かない（外部誘導の禁止）。合格を保証しない。試験委員・採点者を名乗らない
- 顧客の答案と下書きはリポジトリに置かず `.tmp/coconala/talkrooms/{id}/` に保存する

## 2. 購入直後に送る文

先に購入者との DM（`https://coconala.com/message`）を確かめる。事前に相談を受けていれば、すでに聞いた内容（受験年度・選択科目・業務）を聞き直さず、その内容を踏まえた文にする。連絡期限は購入から48時間（過ぎると自動キャンセル）。

```
〇〇様

ご購入ありがとうございます。総監の記述式の添削を担当いたします。
次の2点をこのトークルームでお送りください。届いた時点から3日以内にお返しします。

1. 設問文（過去問なら年度、練習用の課題ならその問題文。お手元にある範囲で結構です）
2. ご自身で書いた答案1問分（Word・テキスト・手書きの写真のどれでも構いません）

お預かりした答案は本サービスの添削にのみ使い、第三者に開示しません。
```

## 3. 納品物（PDF）の構成

手書きの答案は、答案用紙1枚ずつを高解像度で切り出して文字起こししてから読む（行数は画像で数える）。

| 区切り | 中身 |
|---|---|
| 資料の構成 | 区切りの一覧と、どこまでが添削でどこからが助言か |
| 1 総評 | 良い点1〜2つ、点を落としやすい箇所を大きく3つ。問題文の「評価で重視する」3点（考察における視点の広さ／記述の明確さと論理的なつながり／論文全体のまとまり）に結びつける |
| 1 直す順番 | 3つまで。最優先から |
| 1 枚ごとの判定 | 枚・設問・行数・判定（A/B/C）・ひとこと |
| 2 赤入れ | 「」内は答案からの引用（原文どおり）→ 指摘 → 直し方の型（〇〇の空欄） |
| 3 組み直しの例 | 判定が最も低い1枚を、答案の事実だけで組み直す。足した部分は太字。600字に収まる長さ |
| 4 その年の問題への対応 | 前年度の問題文と比べて新しく入った条件の表と、1枚ごとの型 |
| 5 来年度に向けて | 過去の出題の「その年だけの条件」の表と、練習の方法（変わらない部分を固める・骨子を作る練習・答案を部品で持つ） |

- 区切りごとに改ページし、ページ番号を付ける。表と指摘の枠はページをまたがせない
- PDF は HTML を書いて Playwright の `page.pdf`（`format: 'A4'`・`displayHeaderFooter` でページ番号）で作る。`scripts/note/magazine-to-pdf.mjs` と同じ Chrome ヘッドレスの描画
- 作った PDF は `.tmp/coconala/talkrooms/{id}/` に置き、運営者の求めがあればダウンロードフォルダにも置く

## 4. 送信前の自己点検

- 「」内の答案の引用を、文字起こしした本文と機械で照合する（言い換えを「」に入れない）
- 問題文からの引用を、問題文の原文と照合する（読点の種類まで）
- 過去の出題の表は、サイト収録の問題文（`content/site/pe-comprehensive-management/r0X-secondary/`）と1問ずつ照らす
- 〇〇の空欄を含む型と例に「ご自身の事実で」の注記がある
- 専門外の分野の制度・数値に断定が残っていない
- ページの境目で見出しと本文が分かれていない
- URL・note・サイト名・合格保証が無い

## 5. 納品文の型

```
〇〇様

お待たせしました。〇〇の添削結果をお返しします。
詳しくは添付のPDF（〇ページ）をご覧ください。

（良い点を1〜2文）点を落としやすいのは次の3点で、この順に直すのがおすすめです。

1. 〇〇
　（一言）
2. 〇〇
　（一言）
3. 〇〇
　（一言）

ほかに、枚ごとの判定（A/B/C）、引用つきの赤入れ〇点、〇〇を載せています。
ご質問への回答1往復が含まれていますので、気になる点があればこのトークルームでお知らせください。

内容をご確認のうえ、問題なければ取引の完了をお願いします。
（締めの一文）
```

送信は運営者が行い、「正式な納品」にチェックを入れて PDF を添付する。

## 6. 納品のあと

- 正式な納品のあとも、購入者が取引の完了を承諾するまではトークルームで質問に答えられる。購入者が何もしなければ約3日で自動承諾になる
- 取引の完了後に質問が来たら、DM（購入者のプロフィールの「メッセージを送る」）で答える
- `data/coconala/orders.json` に、納品日時・納品物（ファイル名・sha256・builtAt）・中身の要約を記録する。購入者への評価は `scripts/coconala/coconala-rate-buyer.mjs`
