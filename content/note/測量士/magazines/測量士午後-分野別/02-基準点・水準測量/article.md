# 基準点測量・水準測量 ｜測量士 午後 記述式 解き方の型と過去5年（令和4〜8年）解説

本記事の運営者は測量士の有資格者（2020年取得）・技術士（建設部門ほか）です。

## こんな人のための記事です

- 午後の選択 No.2（基準点測量・水準測量。令和7年4月施行の測量法改正後の科目名は測地測量で、旧・多角測量／汎地球測位システム測量／水準測量）を選ぶか迷っていて、何が出るかを先に知りたい人
- 水準網の最確値（観測方程式と重みつきの最小二乗）を、途中式まで自分で立てられるようになりたい人

### この分野を選ぶべき人・避けるべき人

選ぶべき人は、次のとおりです。

- 連立方程式を解く、係数を並べるといった計算が苦にならず、最確値を毎年の得点源にしたい人
- 基準点測量の工程や、電子基準点・セミ・ダイナミック補正の用語を暗記で押さえられる人
- 作図問題（セッションや観測図）は最悪落としてよい、と割り切れる人

避けたほうがよい人は、次のとおりです。

- 行列や座標の符号（加える・減じる、元期と今期の向き）でよく取り違える人
- 「なぜその制限が緩むのか」を短い文で書くのが苦手で、理由記述を落としたくない人

## 解き方の型

### 型1: 水準網の最確値（観測方程式と最小二乗）

毎年のように出る、この分野の主役です。仮標高に補正量 X を加えて考えます。

使う式は次のとおりです（Σ は総和、重み p は観測距離の逆数）。

- 観測方程式（1本の路線）: V = （終点の仮標高 + 終点の補正量）−（始点の標高 + 始点の補正量）− 観測高低差
- 既知点の補正量は 0 として扱う。新点の補正量は X_M、X_N のように未知数にする。
- 重み p = 1 / 観測距離（km）。距離 2 km なら 0.5、1 km なら 1、4 km なら 0.25。
- 行列表記: V = A X − L（A は係数行列、L は定数項。L は「観測方程式の定数項の符号を反転したもの」）
- 正規方程式: (A の転置 × P × A) X = A の転置 × P × L
- 最確値 = 仮標高 + 補正量 X

手順は次のとおりです。

1. 矢印（観測方向）を確認する。始点から終点へ向かう向きで、終点 − 始点 の形に統一する。
2. 各路線について、仮標高と既知標高だけを先に計算して定数（差）を出す。
3. 係数行列 A（未知数の前の +1、−1、0）を並べる。既知点だけが端点の路線は、その新点の列だけに 1 が立つ。
4. 重み P を対角行列で並べる（距離の逆数）。
5. 正規方程式の係数（A の転置 × P × A）と右辺（A の転置 × P × L）を計算する。
6. 未知数が2つなら消去法か行列式（クラメルの公式）、3つなら問題で与えられる逆行列を掛けて X を出す。
7. 仮標高に X を足して最確値にする。

つまずきやすい点は次のとおりです。

- 定数項の符号。観測方程式が「X − 0.003」なら、L は +0.003。「X + 0.064」なら L は −0.064。
- 単位を m のまま計算する。補正量は数 mm なので 0.003 のように小数を丸めず持つ。
- 「変動が最も大きい」を問われたら、補正量 X の絶対値が最大の点を選ぶ。

### 型2: GNSS セッション計画と点検（セッション間点検・座標閉合差）

使う考え方は次のとおりです。

- 1 セッションで観測できる点数は、使える GNSS 測量機の台数まで（例: 1級1台＋2級3台なら4点）。
- 平均図の基線は、必ずどれかのセッションの中に入れる。最少のセッション数にするには、台数をきちんと使い切る。
- 隣り合うセッションは共通の点を持たせる（重複基線を作る）。
- 電子基準点のみを既知点とするときの点検は、次の2つを書く。
  1. 電子基準点間を最少の辺数で結んだ路線の閉合差を点検する。
  2. 異なるセッションで重複する基線ベクトルの較差を比較点検する。
- 座標閉合差の計算（令和8年型）: 新点を経由する基線ベクトルを足し、最後の点の観測値を出す。閉合差 = 観測値 − その点の（今期の）座標。X、Y、Z それぞれで出す。
- 地心直交の閉合差（ΔX、ΔY、ΔZ）は、与えられた3×3の式で ΔN（南北）、ΔE（東西）、ΔU（高さ）に変換し、許容範囲と比べる。

手順は次のとおりです。

1. 問題の座標が元期か今期かを確認する。既知点の元期座標に補正量を加えて今期にする（型3参照）。
2. 出発点の今期座標に基線ベクトルを順に足す（X は X、Y は Y、Z は Z）。
3. 観測値 − 終点の今期座標 で ΔX、ΔY、ΔZ を出す。
4. 変換式の各行に (ΔX, ΔY, ΔZ) を掛けて足し、ΔN、ΔE、ΔU を出す。
5. 許容範囲より小さいことを確認して判定する。

つまずきやすい点は次のとおりです。

- 既知点2点の座標は、両方とも補正量を加えてから使う（片方だけ補正しない）。
- 変換式の係数は行ごとに ΔN、ΔE、ΔU に対応する。列と行を取り違えない。

### 型3: セミ・ダイナミック補正の計算（バイリニア補間）

使う式は次のとおりです。

- 格子点4点 G0、G1、G2、G3 の補正量を Z0、Z1、Z2、Z3 とし、正規化した位置 x、y（0 から 1）で
  Z = (1−x)(1−y)Z0 + x(1−y)Z1 + y(1−x)Z2 + xy Z3
- x は X 方向（北向き）、y は Y 方向（東向き）の、格子点間隔に対する位置の割合。
- 今期座標 = 元期座標 + 補正量。したがって 元期座標 = 今期座標 − 補正量。
- 補正量は、元期座標と今期座標で同じとみなして計算する。

手順は次のとおりです。

1. 新点を囲む4つの格子点を選ぶ（図の位置と座標値で決める）。
2. x = (新点の X − 左下の格子点の X) / 格子間隔、y も同様に出す。
3. ΔX と ΔY それぞれについて上の式で補正量 Z を出す。
4. 今期座標から補正量を引いて元期座標にする。
5. 距離を問われたら、元期の座標差から √(ΔX² + ΔY²) を計算する。

つまずきやすい点は次のとおりです。

- 補正量の符号（ΔY が負のことがある）。引くときは符号ごと引く（−0.360 を引くと +0.360）。
- 格子点の補正量が X 方向に変わらない図なら、補間は y だけで済む（令和4年）。逆に Y 方向に変わらないなら x だけ。

### 型4: 地殻変動量と許容範囲、セミ・ダイナミック補正の記述

使う式は次のとおりです。

- 相対位置の変化 = 年間 0.2 ppm（10 km で 2 mm）。距離 L km、年数 n 年なら、変動量 = 2 mm × (L / 10) × n。
- 許容範囲を超えるまでの年数 = 許容範囲 / 1年当たりの変動量（超える最初の年に切り上げる）。

記述の型は次のとおりです。

- 電子基準点のみを既知点にするなら、既知点間の距離が長くなる。すると、元期からの時間経過で地殻変動の影響が出て、周囲の基準点成果との間に不整合が生じるおそれがある。この因果（距離が長い → 時間経過で地殻変動 → 不整合）を語群の語句で並べる。
- 適用外になる例は、電子基準点のみを既知点とする場合以外の測量（新点と既知点が近く、ひずみの影響が小さい）。
- 補正の手順は、元期の既知点座標 → 補正量を加えて今期座標 → 今期座標で網平均 → 新点の今期座標 → 補正量を減じて元期座標（成果）。「加える」「減じる」「今期座標」「元期座標」の並びで出る（令和5年）。

つまずきやすい点は次のとおりです。

- 「加える」と「減じる」の向き。既知点は加える（元期 → 今期）、新点は減じる（今期 → 元期）。

### 型5: 水準測量の計算と管理（標尺補正・重みつき平均・地盤沈下調査）

使う式は次のとおりです。

- 標尺補正後の高低差 = 観測高低差 × (1 + 標尺改正数 + 膨張係数 × (観測時の気温 − 20℃))
- 標尺改正数が +4.0 μm/m なら 4.0 × 10⁻⁶、膨張係数 1.0 × 10⁻⁶/℃ なら気温差ごとに掛ける。
- 2つの路線から同じ点の標高が出るときは、重みつき平均（重み = 1 / 距離）。
  最確値 = (p1 × H1 + p2 × H2) / (p1 + p2)

手順は次のとおりです。

1. 路線ごとに、補正係数 = 標尺改正数 + 膨張係数 × (気温 − 20) を計算する（気温が20℃より低いと負になる）。
2. 観測高低差にその係数を掛け、観測高低差に足して補正後の高低差にする。
3. 既知点から各路線の高低差を足し引きして、再設点の標高を2通り出す。
4. 距離の逆数を重みにして平均する。

記述の型は次のとおりです（1級水準測量・地盤沈下調査）。

- 読取順序は、後視 → 前視 → 前視 → 後視。読定単位は 0.1 mm。
- 不動点は、地盤沈下が起きていない地域の外で、地盤が堅固な場所を選ぶ。
- 使う水準点は、亡失・傾斜・埋没・露出・柱石き損・球分き損がないか、前回観測以降に他機関により移転改埋されていないかを確認する。
- 観測期間を短く、再測は速やかに。理由は、観測中も沈下が進むので、期間が長いと沈下を正確に判断できなくなるため。
- 2班が交差する水準点は、できる限り同一時期に観測する。

### 型6: 工程・成果・点検の語句と記述

基準点測量の工程は次の順です。作業計画（作業方法・機器の決定）→ 選点（土地立入りの手続、既知点の現況調査、新点の設置位置の選定、平均図の作成）→ 測量標の設置（永久標識の設置、点の記、写真撮影）→ 観測（機器の点検及び調整、観測、点検測量）→ 計算（平均計算、精度管理表）→ 品質評価（品質評価表）→ 成果等の整理。

成果の語句を工程とセットで覚えます。

- 平均計画図: 作業計画。平均図: 選点で作成。点の記・建標承諾書: 選点と測量標の設置。
- 精度管理表: 計算。品質評価表: 品質評価。
- 令和7年・令和8年は、語句を選ぶ形から「工程順序の番号」や「番号で語群から選ぶ」形に変わった。同じ語句を使わない条件に注意する。

記述の型は次のとおりです。

- 選点の留意点: 発見が容易な場所、視通が確保できる場所、地盤が堅固な場所（後続作業で使いやすいこと）。
- 平均図の承認理由: 選点後の作業を始める前に、網の形状が作業規程の条件を満たしているか、新点の配点密度が適切かを、測量計画機関に確認してもらうため。
- 多角網の制限（TS）: 既知点の数、単位多角形の辺数、路線の辺数、節点間距離、路線長。
- 観測の誤りと判断される例: 既知点1点以上で方向角の取付がない、路線の夾角が60度以上でない、両既知点を結ぶ直線から両側50度以下に新点が選ばれていない、路線長が1 kmを超える、新点間距離が200 mより大幅に短い。
- 点検路線の選定: 既知点と既知点を結合する、全ての既知点を1つ以上の点検路線で結合する。
- 器械誤差: 水平軸誤差は水平軸と鉛直軸が直交していない。鉛直軸誤差は鉛直軸と鉛直線の方向が一致していない。視準線誤差は視準線と水平軸が直交していない（正反観測で消去）。水平軸誤差も正反観測で消去。目盛盤の目盛誤差は目盛盤の位置を変えて観測して軽減する。

つまずきやすい点は次のとおりです。

- 「例に示す内容は除く」の指定。例と同じ内容を書くと無効になる。
- 字数制限（30字、60字、70字）。語群の語句は全て使い、1文で因果を書く。

### 型7: 作図問題（セッション・観測図）

作図の正解図そのものは載せません。考え方だけを押さえます。

- 使える GNSS 測量機の台数 = 1セッションの点数の上限。
- セッション数を最少にするには、全点を4点ずつに区切り、隣り合うセッションで共通点を持たせる。令和5年・令和7年・令和8年の公式解答例は、いずれもセッション A、B、C の3つでした。
- 電子基準点間の閉合差を確認する点検路線は、最少辺数で電子基準点どうしを結ぶ。
- 破線が識別しにくいと減点されるので、セッションごとの点を囲む線がはっきり分かれるように引く。
- TS の観測図は、視通のない区間を飛ばし、方向角の取付と夾角60度以上を意識して、既知点から既知点へ結合する。

## 過去問の解説（令和4〜8年）

最終値は公式解答例の画像と照合し、一致したものだけを載せています。図の位置を答える作図問題は、その旨を書いて飛ばしています。

### 令和4年

問A-1（工程の語句）: ア 平均計画、イ 選点、ウ 平均、エ 点の記、オ 点検測量、カ 精度管理、キ 基準点網。平均計画を立ててから選点、点の記は所在をまとめた資料、点検測量は結果を確かめる作業、精度管理は精度が規定を満たすかを管理する作業。

問A-2（選点の留意点）: 後続作業で利用しやすく発見が容易な場所に選点する。測量標を保存するため地盤が堅固な位置に選点する。

問A-3（点検測量の目的）: 点検測量の結果が規定された許容範囲内であるかを確認すること。

問A-4（承認が必要な図）: 平均図。選点後の作業を始める前に、網の形状が作業規程の条件を満たしているか、新点の配点密度が適切かを計画機関に確認してもらうため。

問B-1（多角測量の作図）: 作図問題のため扱わない。

問B-2（多角網の形成で考慮する項目）: 1個の多角網における既知点数、路線の辺数、節点間の距離、路線長。

## 本番で点を落とさないチェックリスト

- 観測方程式は「終点 − 始点 の形で、仮標高と既知標高の差を定数にする」。定数項 L は符号を反転してから行列に入れる。
- 重みは距離の逆数（km）。2 km は 0.5、4 km は 0.25。正規方程式は、係数の行と列を取り違えずに写す。
- 元期と今期の向きは「元期 + 補正量 = 今期」。元期を出すときは今期から引く。補正量が負のときは符号ごと引く。
- 電子基準点のみを既知点とする記述は「距離が長い → 元期からの時間経過で地殻変動 → 不整合」の因果で書く。語群は全て使う。
- 「例に示す内容は除く」と字数制限を最初に確認する。GNSS の点検は2つ（最少辺数路線の閉合差、重複基線ベクトルの較差）を必ず書く。
