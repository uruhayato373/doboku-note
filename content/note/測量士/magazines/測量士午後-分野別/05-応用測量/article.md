## 解き方の型

### 型1: 単曲線とクロソイド（緩和曲線）の基本量

使う式は次のとおりです。角度は度からラジアンに直して使います（円周率は問題で3.142と指定されます）。

- 接線長 TL = R × tan(I/2)
- 円曲線の長さ CL = R × I（I はラジアン）
- 外線長 SL = R × (1 / cos(I/2) − 1)
- クロソイドの長さ L = A² / R（A はクロソイドパラメータ P と同じ値として使う）
- 接線角 τ = L / (2R)（ラジアン）
- クロソイド＋円曲線＋クロソイドで折れ曲がる場合の円曲線の中心角 θ = α − 2τ（α は全体の交角）
- 曲率 = 1 / R

手順は次のとおりです。

1. 問題の R、P（または L）、交角を確認する。
2. L = P² / R でクロソイドの長さを出す。
3. τ = L / (2R) で接線角を出す。
4. 円曲線の中心角 θ = 交角 − 2τ を出し、円曲線の長さ = R × θ を出す。
5. 区間の路線長は、クロソイド L、円曲線 R × θ、次のクロソイド L を足していく。

つまずきやすい点は次のとおりです。

- 交角が90度なら π/2 = 1.571 を使う。度のまま掛けると桁が外れる。
- 接線角 τ はクロソイドの端点での接線が、始点の直線となす角である。図の角度記号と混同しない。
- 「小数第何位を四捨五入し、整数で」の指定は、途中を丸めず最後に丸める。

### 型2: 曲率図（曲率と路線長のグラフ）

直線は曲率0、円曲線は曲率 1/R（一定）、クロソイドは路線長に比例して曲率が変わる斜めの直線になります。右回りを正、左回りを負とします。

手順は次のとおりです。

1. 点ごとの路線長を、型1で求めた L と円曲線の長さから累積する。
2. 直線区間は曲率0の水平線、クロソイド区間は0と ±1/R をつなぐ斜線、円曲線区間は ±1/R の水平線を引く。
3. 縦軸に曲率、横軸に路線長を書き、全ての点の名前と数値を記入する。

つまずきやすい点は、曲がる向きが変わる箇所で符号が反転することです。図の曲線が A から進む向きに対して左に曲がるか右に曲がるかを、曲線ごとに確認します。

### 型3: 設計変更（半径を変える・移動量から半径を求める）

交点 IP と始点・終点の直線を動かさず、円曲線の半径だけを変える問いです。

使う式は次のとおりです。

- 外線長 SL = R × (1 / cos(I/2) − 1)
- 接線長 TL = R × tan(I/2)
- 交角と直線の向きは変えない場合、SL と TL はどちらも R に比例する。

手順は次の2通りです。

1. 曲線中点 SP を動かす場合（令和5年）: 変更後の SL' = 変更前の SL ± 移動量 とし、R' = SL' / (1 / cos(I/2) − 1) で半径を出す。SP を円の中心方向に動かすと、IP から SP までの距離は移動量だけ増える。
2. 直線を平行に動かす場合（令和6年）: 片方の接線を平行に d だけ動かし、IP' を元の直線に沿ってずらす。ずらす距離 = d / sin(I)。新しい接線長 T' = 元の T + d / sin(I)。半径 R' = T' / tan(I/2)。

つまずきやすい点は次のとおりです。

- 曲線の路線長が半径に比例して変わる一方、直線部は短くなる。全体の距離の差は、直線の差と円曲線の差の合計で見る。
- 変更後の円曲線の中心角は交角と同じ（クロソイドを含まない単曲線の場合）。

### 型4: 用地測量の杭の本数

数え方の型は次のとおりです。

- 中心杭: 道路中心線上に20 m 間隔で置く。指定された起点（No.8 や No.10）を含める。区間の端の BC（円曲線始点）は役杭であり中心杭ではない。
- 用地幅杭: 中心杭と BC のそれぞれについて、中心線に直角に、用地幅の位置に左右1本ずつ置く。本数 = (中心杭の本数 + BC の1点) × 2
- 用地境界仮杭: 境界線が用地幅の線と交わる点で、境界杭が既にある位置を除いて、境界線1本につき交点1つずつ数える。境界杭が用地幅の内側にある場合、その境界杭から用地幅の線まで伸びる境界線も数える。

手順は次のとおりです。

1. 図のスケールから、指定の中心点（No.10 など）から図の端までの距離を読み、20 m 間隔の中心杭の本数を数える。
2. 用地幅杭は (中心杭 + BC) × 2 で出す。
3. 道路中心線から用地幅（問題の値）だけ離れた線を図に引く。
4. 境界線がその線と交わる点を漏れなく数える。

つまずきやすい点は、用地幅の線より外にある境界杭は仮杭の位置ではないことと、用地幅の内側にある境界杭は仮杭にならないことです。交点だけを数えます。

### 型5: 用地面積（座標法と切り取り）

使う式は次のとおりです。

- 座標法の面積 A = (1/2) × |Σ(Xi × Y(i+1) − X(i+1) × Yi)|

手順は次のとおりです。

1. 用地幅の線（道路中心線から片側の幅だけ離れた線）を座標で表す。
2. 四角形の辺が用地幅の線と交わる点を、線分の比例で求める。
3. 切り取られる部分の頂点を順に並べる。
4. 座標法の式で面積を出す。

つまずきやすい点は、頂点を時計回り・反時計回りのどちらかで順に並べることです。順が乱れると面積が過大になります。

### 型6: 点検測量・境界点間距離・精度管理表

記述の型は決まっています。これを覚えるだけで、毎年1〜3問が取れます。

- 中心線測量・条件点の点検: 隣接する点の距離を測定し、座標差から求めた距離と比較する。
- 条件点・用地幅杭点・境界点の座標の点検: 座標決定に用いた既知点以外の既知点から求めた座標値との較差で確認する。
- 境界点間距離の点検（視通がある場合）: 現地で距離を測り、境界測量の座標から計算した距離と比較する。
- 境界点間距離の点検（視通がない場合）: トータルステーションの対辺測定機能を使い、座標から計算した距離と比較する。
- 横断測量の点検: 点検率で選んだ横断面について、再度横断測量をして重ね合わせるか、中心杭と末端見通杭の距離・標高の測定値を点検値と比べる。

精度管理表の判定（令和8年）では、次の手順で判断します。

1. 座標差から距離 S = √(ΔX² + ΔY²) を出し、これが計算値になる。
2. 較差 = |測定値 − 計算値|。
3. 許容範囲を、区分（平地・山地）と距離で表から引く。距離20 m 未満は固定値（平地10 mm・山地20 mm）、20 m 以上は S / 2,000（平地）または S / 1,000（山地）。
4. 許容範囲は小数第4位以下を切り捨て、小数第3位まで（例: 0.0153 → 0.015）。
5. 較差が許容範囲以内かを確認する。

つまずきやすい点は次のとおりです。

- 距離が20 m を超えるのに10 mm のままで書かれている行を見落とさない。
- 較差を出す向き（大きい値 − 小さい値）を間違えても絶対値なので影響しないが、計算値と測定値の取り違えは避ける。
- 図の線が全部の辺を結んでいるか、表にない辺がないかを見る。

### 型7: 河川測量

- 距離標: 河口または幹川への合流点に設けた起点から、河心に沿って200 m 間隔を標準とし、河心線の接線に直角な両岸の堤防法肩または法面等に選定・設置する。
- 水準基標: 水位標に近接した位置に、5 km から20 km の間隔を標準として設置する。
- 定期縦断測量: 観測の基準点は水準基標とし、水準基標から出発して他の水準基標に結合する。平地は3級、山地は4級水準測量。地形・地物の状況によっては間接水準測量（トータルステーションを用いた単観測昇降式による往復観測）で行える。
- 音響測深機: 音波を水底に向けて発射し、水底からの反射時間で水深を求める。

流積の計算（令和4年 D-4）は次のとおりです。

- 平均水深 = 低水路内の流積 A / 低水路幅
- 平均河床高 h = 計画高水位（H.W.L）− 平均水深
- A の変動量 = 今回 A − 前回 A
- h の変動量 = 今回 h − 前回 h

### 型8: 工程・語句の穴埋め

路線測量は、作業計画→線形決定→（IP の設置）→中心線測量／仮 BM 設置測量→縦断測量／横断測量／詳細測量／用地幅杭設置測量→品質評価→成果等の整理、の順です。

- 線形決定: 路線選定の結果に基づき、地形図上で交点 IP の位置を座標で定め、線形図データファイルを作成する。
- 中心線測量: 主要点と中心点を現地に設置し、線形地形図データファイルを作成する。
- 仮 BM 設置測量: 縦断測量・横断測量に必要な水準点を設置し、標高を定める。
- 縦断測量: 中心杭等の標高を定め、縦断面図データファイルを作成する。
- 横断測量: 中心杭等を基準に、地形の変化点等の距離と地盤高を定め、横断面図データファイルを作成する。
- 詳細測量: 構造物設計に必要な詳細平面図・縦断面図・横断面図のデータを作成する。

用地測量は、作業計画→資料調査→復元測量→境界確認→境界測量→境界点間測量→面積計算→用地実測図データ→用地平面図データ、の順です。

### 型9: 作図問題（測点・杭・観測図）

- 放射法の観測図: 4級基準点から境界点まで視通が取れれば直接観測する。建物などで視通が取れない境界点には、途中に補助基準点または節点を置いて2段階で観測する。建物上に測点は置けず、建物内も視通が取れない。
- 役杭・中心杭・引照点杭: 主要点（BC）に役杭、中心点に中心杭を置く。引照点杭は役杭が亡失・破損・移動しても復元できるよう、施工幅の外側で建物を避けた位置に置く。

## 過去問の解説（令和4〜8年）

最終値は公式解答例の画像と照合し、一致したものだけを載せています。図の位置を答える作図問題は、考え方だけを示し、最終の図は載せていません。

### 令和4年

問A-1（工程の語句）: ア 線形決定、イ 詳細測量、ウ 用地幅杭設置測量。IP の設置から中心線測量が始まるので、その前の工程は線形決定。縦断・横断と並ぶ測量は詳細測量と用地幅杭設置測量。

問A-2（中心線測量の点検）: 隣接する中心点等の点間距離を測定し、座標差から求めた計算距離と比較する。型6のとおり。

問A-3（仮BM設置測量の方法）: 平地は3級水準測量、山地は4級水準測量。

問A-4（縦断測量の語句）: エ 中心杭、オ 中心点、カ 単観測昇降、キ 簡易水準測量。往路は中心杭高・縦断変化点杭の地盤高、復路は中心杭高を測る。位置は中心点からの距離で定める。間接水準測量の許容範囲は簡易水準測量の閉合差を準用する。

問A-5（縦断面図の縮尺）: 横縮尺は線形地形図と同一。縦縮尺は線形地形図の5倍から10倍までを標準とする。

問B-1（接線角 τ）: 与えられたのは R = 200 m、P = 180 m。L = P² / R = 180² / 200 = 32,400 / 200 = 162 m。τ = L / (2R) = 162 / 400 = 0.405。答え 0.405 ラジアン（公式解答例と一致）。

問B-2（路線長）: A〜B は L = 162 m（クロソイド）。B〜C は円曲線で、中心角 = 交角 − 2τ = π/2 − 2 × 0.405 = 1.571 − 0.810 = 0.761。長さ = 200 × 0.761 = 152.2 m。答え A〜B 162 m、B〜C 152 m（公式解答例と一致）。

問C-1（航空レーザ測深の語句）: ア 緑色、イ 反射、ウ 近赤外、エ 透過、オ 屈折。陸上用の近赤外のレーザは水中でほとんど透過せず、緑色は水中を透過しやすい。水面を通過する際に屈折するため補正が必要。

問C-2（波形の選択）: 2 を選ぶ。レーザの減衰が小さく、水底付近の反射強度のピークが明確に出ているため。波形図は問題側にあり、本記事では再現しない。

問C-3（水準点成果の改算）: 国土地理院から提供される水準点用の標高補正パラメータを使用して、既知点の成果を測地成果2011から測地成果2024に改算する。

## 本番で点を落とさないチェックリスト

- 度をラジアンに直し、円周率は問題の指定（3.142）で計算する。関数は巻末の表の値を使う。
- 用地幅杭の本数は、(中心杭 + BC) × 2。BC を数え忘れない。
- 仮杭は、境界線が用地幅の線と交わる点だけを数える。用地幅の内側の境界杭は数えない。
- 点検の記述は、「既知点以外の既知点から求めた座標値との較差」と「対辺測定機能による距離との比較」の2つの型で書く。
- 精度管理表は、距離20 m 未満か以上かで許容範囲の式が変わる。20 m 以上は S / 2,000（平地）または S / 1,000（山地）を、小数第4位以下を切り捨てて確認する。表にない辺がないかも確認する。
