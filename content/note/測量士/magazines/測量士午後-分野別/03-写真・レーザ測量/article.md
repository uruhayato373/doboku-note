## 解き方の型

### 型1: 撮影高度と画面の実長（写真測量の基本）

使う式は次のとおりです。焦点距離 f、撮像面の素子寸法 p、撮影基準面の地上画素寸法 GSD（ground sampling distance）を、単位をそろえて使います。

- 撮影高度（基準面からの高さ）H = f × GSD / p
- 海面（標高0 m）からの撮影高度 = H + 撮影基準面の標高
- 画面の実長 = 画素数 × GSD（長辺方向と短辺方向を別々に出す）

手順は次のとおりです。

1. f、p、GSD を m 単位にそろえる（f = 9.2 cm = 0.092 m、p = 5.6 μm = 5.6 × 10⁻⁶ m、GSD = 20 cm = 0.2 m のように）。
2. H = f × GSD / p を出す。
3. 問題文が「標高0 m からの撮影高度」を聞いているときは、基準面の標高を足す。
4. 画面の長辺・短辺の画素数に GSD を掛けて、地上での画面の実長を出す。

つまずきやすい点は次のとおりです。

- GSD と p の比は単位が同じなら無次元。20 cm と 5.6 μm を混ぜたまま割ると桁が外れる。
- 「撮影基準面の標高は地表面と同じ」と書かれているので、H は地表面からの高さになる。海面からの高度を聞かれたら、必ず基準面の標高を足す。

### 型2: 撮影基線長・コース間隔・コース数・写真枚数・撮影間隔

画面の短辺を撮影基線（進行方向）と平行にする条件が付きます。進行方向には短辺、コース直交方向には長辺が向きます。

使う式は次のとおりです。

- 撮影基線長 B = 短辺の実長 ×（1 − 同一コース内の重複度）
- コース間隔 C = 長辺の実長 ×（1 − 隣接コースとの重複度）
- 撮影間隔（秒）= B / 対地速度（UAV や航空機の速度が与えられたとき）

コース数の手順は次のとおりです。

1. 端のコースが、撮影区域の外側に「画面の大きさの ○% 以上」を含むように置く。端のコースの中心は、区域の境界から（長辺の実長 / 2 − はみ出す量）だけ内側になる。
2. 区域の幅から、両端の内側量を2回引いた長さを出す。
3. その長さをコース間隔 C で割り、小数を切り上げて「間隔の数」とする。
4. コース数 = 間隔の数 + 1。

写真枚数の手順は次のとおりです。

1. コース1本の長さ ÷ B を出し、小数を切り上げる。
2. 1を足す（端点の1枚）。
3. 「各コースの両端は撮影区域外に各1モデル分」とあれば、さらに2を足す。
4. コース1本の枚数 × コース数。

つまずきやすい点は次のとおりです。

- 「最小コース数」「最小写真枚数」は、切り上げで出す。四捨五入しない。
- コースの方向（東西か南北か）で、コース長とコースを並べる幅が入れ替わる。区域の東西・南北の長さのどちらがどちらかを最初に決める。
- 記録容量の問いでは、全枚数 × 1枚の容量を出し、指定どおり切り上げる。

### 型3: 航空レーザの諸元計算（スキャン幅・スキャンレート・パルスレート）

使う式は次のとおりです。スキャン角度 θ は片側の角度（±20 度なら θ = 20 度）です。

- スキャン幅 W = 2 × 対地高度 × tan θ
- 1秒間の測線数 = スキャンレート（往復/秒）× 2（1往復で往路・復路の2測線）
- 進行方向の取得点間距離 = 対地飛行速度 / 1秒間の測線数
- 1測線当たりの計測点数 = パルスレート / 1秒間の測線数
- 直交方向の取得点間距離 = W / 1測線当たりの点数
- 点密度（点/m²）= パルスレート /（W × 対地飛行速度）

逆算の手順（パルスレートを求める問い）は次のとおりです。

1. スキャンレート = 対地飛行速度 /（進行方向の取得点間距離 × 2）（往復/秒）。
2. 1測線の点数 = W / 直交方向の取得点間距離。
3. パルスレート = 1測線の点数 × 1秒間の測線数。

つまずきやすい点は、往復を測線2本と数えるかどうかです。「毎秒90往復」は毎秒180測線。tan の値は巻末の関数表から取ります（tan 20度 = 0.36397、tan 30度 = 0.57735）。

### 型4: 地上レーザスキャナ（入射角・スポット径・水平距離）

「レーザ光と地面がなす角」を入射角として扱います。この角度が小さいほど、スポットは地面に対して細長い楕円になり、スポット長径が大きくなって、位置の精度が落ちます。

記述の定型は次のとおりです。

- 斜面では、低い所に据えて高い方向へ計測すると、入射角が大きくなり、スポット径（長径）が小さくなって、観測精度が向上する。
- 点密度の観点では、高い方向へ計測するとレーザが地面に近い角度で入らず、点密度が大きくなる（令和6年の解答例の表現）。

距離の計算は、次の3型に分けます。

- 平らな地面（令和5年）: 水平距離 D = 器械高 h / tan α（α はレーザ光と地面がなす角）
- 下り気味に当たる上り斜面（令和6年）: 地面が斜度 β で上がる場所に、水平距離 D 先を計測する。地面の高さ = D × tan β。器械から見た点の高さ = D × tan β − h。このとき、レーザが水平から下向きに δ の角度をなすなら、地面となす角 = β + δ
- 上り斜面に、地面より緩い角度で当てる（令和8年）: レーザ光は水平から上向きに（β − α）の角度で出ている。D × tan β = h + D × tan(β − α) から D = h /（tan β − tan(β − α)）

つまずきやすい点は、図の角度がどの線と、どの線のなす角かを読み違えることです。地面の傾斜（水平からの角）と、レーザ光と地面のなす角は別の量です。

### 型5: 標高補間（最近隣法・TIN・距離の重み付け）

格子（グリッド）の代表点は、指定がなければ格子の中心です。

最近隣法の手順は次のとおりです。

1. 格子の範囲から、中心の座標を出す（例: X の範囲 78.300〜78.400 なら中心 78.350）。
2. 中心から各点までの平面距離 √(ΔX² + ΔY²) を計算し、最小の点を選ぶ。
3. その点の標高を格子の値とする。

TIN（不整三角網）の手順は次のとおりです。

1. 図で、格子の中心が入っている三角形を見つけ、3頂点の座標と標高を読む。
2. 1つの頂点を原点に、ほかの2頂点との差 dX、dY、dZ を出す。
3. 平面の式 Z = Z₀ + a × dX + b × dY をおき、2頂点の差から連立方程式で a、b を求める。
4. 中心の座標の差を代入して標高を出す。

距離の重み付け内挿（IDW、令和5年）の手順は次のとおりです。

1. 求点から各点までの平面距離 Sᵢ を計算し、指定の範囲（15 cm 以内など）にある点だけを選ぶ。
2. 重み Wᵢ = 1 / Sᵢ。
3. H′ = Σ(Hᵢ × Wᵢ) / ΣWᵢ。
4. ΔH = H′ − 検証点の標高。

つまずきやすい点は次のとおりです。

- 最近隣法は距離が最小の1点だけを使う。2点の標高を平均しない。
- 範囲の境界ぎりぎりの点（0.170 m と 0.150 m など）を含めるかの判定を、距離を計算してから行う。
- TIN の「どの三角形か」は、問題の図に線が引かれている。自分で三角網を作り直さない。

### 型6: メッシュ標高から面積・水量を出す（浸水シミュレーション）

手順は次のとおりです。

1. 水面標高 = 基準の水面 + 上昇量を出す。
2. 各マス目の標高が水面標高より低いマスに水が入る（水部のマスは既に水面なので数えない）。
3. 水深 = 水面標高 − マスの標高。
4. 浸水面積 = 浸水マス数 × 1マスの面積（格子間隔の二乗）。
5. 水量 = Σ水深 × 1マスの面積。

堤防が決壊する問いでは、決壊した箇所のマスから、隣り合うマス（上下左右）をたどれるマスだけが浸水します。たどれないマスは、低くても浸水しません。

つまずきやすい点は、格子間隔が5 m なら1マスは25 m²であることと、水深を小数第1位まで求める指定を忘れないことです。

### 型7: 単写真の撮影高度と、高い物の高さ（令和8年）

使う式は次のとおりです。

- 写真縮尺 = 写真上の長さ / 実際の長さ（写真上の長さは 画素数 × p）
- 撮影高度 H = f / 縮尺
- 鉛直な高塔の高さ h = 根元からの撮影高度 H ×（先端の像の主点からの長さ − 根元の像の主点からの長さ）/ 先端の像の主点からの長さ

手順は次のとおりです。

1. 建物の屋上の一辺（実長と写真上の画素数）から縮尺を出し、屋上の高度を出す。
2. 建物の高さを足し、地面（根元）からの撮影高度にする。
3. 主点から先端 d までの長さと、根元 c から d までの長さを画素で読み、主点から c までを引き算で出す。
4. 上の式に入れる。

つまずきやすい点は、主点から c までは「8,000 − 650」の引き算であること、そして高度は屋上ではなく地面からの高さを使うことです。

### 型8: 記述の定型（レーザ・UAV・車載・重複度）

毎年出る記述は、次の定型文で書けます。字数制限に合わせて短くします。

- 樹高の推定: ファーストパルスとラストパルスから取得した高さの差分をとる（オリジナルデータとグラウンドデータの高さの差分をとる、でも可）。
- 写真地図で重複度を大きくする利点: 建物や樹木（高層ビル）の倒れ込みにより隠れてしまう部分を、極力減らすことができる。
- レーザが写真測量より有利な理由: 写真に写らない樹木の下の地表面でも、レーザが樹木の隙間を通過して測量できる場合があるため。
- 車載写真レーザの利点: 走行しながらデータを取得するため、TS 測量より現地作業日数を短縮できる。
- 車載写真レーザの留意点: 自車位置姿勢データ取得装置のセルフキャリブレーションが行える待避場所を確保する。
- 照射方向を変える理由: 往路と復路で照射方向を変え、地物の陰となる箇所を減らして観測できるため。
- 傾斜地のコース計画: 傾斜地では対地高度が減少して計測幅が狭くなり、コース間重複度を確保できない場合がある。最も標高の高い地点でも重複度を確保できるよう、コース間隔を狭く計画する。
- 点群の合成（座標変換）: 特徴点の取得精度に応じた重み付けを行う。共通に認識できる特徴点又は特徴線を4つ以上抽出する。
- UAV レーザ・UAV 写真点群の適否: 樹木の下や陰など写真に写らない箇所のデータ作成が困難なので、樹林には写真点群測量を使わない。範囲が狭い場合に有人航空機による航空レーザは経済的でない。

### 型9: 語句穴埋めの押さえどころ

- 航空レーザ: レーザ光、GNSS/IMU 装置、近赤外（陸部）、緑色（水部の測深）。
- 標高データの流れ: 三次元計測データ → オリジナルデータ（点検・調整後）→ フィルタリング → グラウンドデータ → 内挿補間 → グリッドデータ。標準の内挿補間は TIN と最近隣法。
- 車載写真レーザ: 固定局は基線距離 10 km 以内（やむを得なくても 30 km）、電子基準点を用い、観測データ取得間隔は1秒以下。キャリブレーションの有効期間は、固定式1年、着脱式6か月。
- UAV: 撮影機器は自律飛行機能を有する。航空法や小型無人機等飛行禁止法、人口集中地区、150 m 以上の空域は許可・承認の確認が必要。
- 点検・仕様: 精度と点密度を要求仕様書に、点検測量と作業仕様書を成果品に対応させる。

### 型10: 基準点の配点密度（令和8年）

手順は次のとおりです。

1. 地図の縮尺バーから、測量範囲（枠）の縦横の実長を読む。
2. 面積（m²）を出し、10,000 m² で割る。
3. 表の配点密度（地域と地図情報レベルの交点）を掛け、必要な点数を出す。
4. 既設の基準点（正常と確認済み）を引く。

## 過去問の解説（令和4〜8年）

問B-2（建物Aの屋上の撮影高度）: 屋上の一辺は実長100 m、写真上で625画素。写真上の長さ = 625 × 5 μm = 3.125 mm。縮尺 = 0.003125 / 100 = 1 / 32,000。H = f / 縮尺 = 0.08 × 32,000 = 2,560 m。答え 2,560 m（公式解答例と一致）。

問B-3（高塔Bの根元cからの撮影高度）: 建物Aの高さが30 m で、建物A と高塔B は標高が一致する平たんな土地に立っている。屋上まで2,560 m なので、根元（地面）からは 2,560 + 30 = 2,590 m。答え 2,590 m（公式解答例と一致）。

問B-4（高塔Bの高さ）: 主点Pから先端dまでは8,000画素、cからdまでは650画素なので、Pからcまでは 8,000 − 650 = 7,350画素。h = 2,590 × 650 / 8,000 = 210.4 m。答え 210 m（公式解答例と一致）。

問C-1（三次元点群測量の正誤）: a は○。b は×で、正しい内容は「移動取得と同時期に行う」。c は×で、正しい内容は「反射した点データをフィルタリング処理により取り除く」。d、e は○。点検のための移動取得は、オリジナルデータの作成時の移動取得と同時期に行う。水底地形では、濁りや水生植物などの反射点は、標高を0 m に置き換えずに、フィルタリングで取り除く。

問C-2（成果品の語句）: ア 精度、イ 点密度（アとイは入れ替わっても正解）、ウ 要求仕様書、エ 点検測量、オ 作業仕様書。A市（計画機関）は要求仕様書、B社（作業機関）は作業仕様書を作る。

問C-3（標高補間）: 格子（間隔0.5 m）の中心は X = 2,560.25、Y = 3,408.25。(1) 最近隣法は、点5（2,560.45、3,408.35）が距離 0.224 m で最小（点4 は 0.30 m、点8 は 0.316 m）。標高 20.35 m。(2) TIN は、中心を含む三角形は点4、点5、点8。点4（20.05 m）を原点にとる。点5: dX = 0.20、dY = 0.40、dZ = 0.30。点8: dX = −0.30、dY = 0.40、dZ = 0.05。0.20a + 0.40b = 0.30、−0.30a + 0.40b = 0.05。引くと 0.50a = 0.25 で a = 0.5、b = 0.5。中心は dX = 0、dY = 0.30 なので、標高 = 20.05 + 0.5 × 0.30 = 20.20 m。答え (1) 20.35 m、(2) 20.20 m（公式解答例と一致）。
