## 問題IIの出題範囲マップ

問題IIは四肢択一25問で、次の4分野から出題する。①建設コンサルタント登録規程・管理技術者/照査技術者の要件・業務委託契約（8問）は、技術管理者の資格要件や登録の有効期間、標準委託契約約款上の管理技術者・照査技術者の職務範囲を扱う。一次出典は建設コンサルタント登録規程（国土交通省告示）と公共土木設計業務等標準委託契約約款である。②品確法・入札契約方式・成果品の照査（6問）は、令和元年改正品確法による対象拡大と、プロポーザル方式・総合評価落札方式の使い分け、設計業務等共通仕様書に基づく照査を扱う。③技術者倫理（5問）は、信用失墜行為の禁止・秘密保持・公益確保・資質向上という考え方と、建設コンサルタンツ協会倫理綱領を扱う。④建設一般知識（6問）は、令和7年版国土交通白書が取り上げるインフラ老朽化対策、i-Construction 2.0、BIM/CIM原則適用、流域治水、建設分野の脱炭素化、担い手確保を扱う。学習順は、実務に直結する①②を先に固め、③は倫理綱領の原文を確認してから解き、④は白書の要点整理を最後に行うと定着しやすい。


## 問題IV-1の出題範囲マップ

問題IV-1は土木基礎知識の四肢択一で、技術士第一次試験（建設部門）専門科目に近い力学・材料・測量の基礎知識が問われます。学習は計算問題の比重が高い順に、①土質力学→②構造力学→③水理学の力学3分野を先に固め、次に④コンクリート工学→⑤鋼構造の材料2分野、続けて⑥測量・地形→⑦建設材料・地盤調査の実務知識2分野、最後に⑧施工・安全の法令・数値基準を仕上げる順が効率的です。土質力学は間隙比・圧密沈下・土圧の計算、構造力学は反力・曲げモーメント・たわみの公式、水理学はマニング式とベルヌーイの定理が頻出です。コンクリートと鋼構造は劣化・接合・疲労に関する用語の正誤判定が中心で、測量は誤差の性質と許容較差、地盤調査はN値と室内試験の対応、施工・安全は労働安全衛生規則の数値基準を押さえておくと得点が安定します。数値計算問題は途中式を再現できるかどうかで得点が分かれ、用語判定問題は似た概念（ヒービングとボイリング、一軸圧縮試験と三軸圧縮試験等）の取り違えが失点の主因になるため、正答だけでなく誤答肢がどこで事実と異なるかまで確認しながら復習してください。

## 予想問題1｜建設コンサルタント登録規程の技術管理者

建設コンサルタント登録規程に基づく技術管理者の要件に関する記述として、不適当なものはどれか。

1. 建設コンサルタントは、登録部門ごとに専任の技術管理者を置かなければならない。
2. 技術管理者は、登録部門に対応する技術士のほか、国土交通大臣が同等の知識及び技術を有すると認定した者も充てることができる。
3. 技術管理者は、他の登録業者の技術管理者を兼任することで自らの実務経験不足を補うことができる。
4. 技術管理者の要件は登録部門ごとに定められ、部門が異なれば必要な資格・実務経験も異なる。

### 正答・解説

**正答：3**。技術管理者は登録部門ごとに専任配置が原則であり、他の登録業者の技術管理者を兼任して要件を充足させる仕組みではありません。1は専任配置の原則、2は技術士のほか大臣認定者も充てられる点、4は部門ごとに要件が異なる点で、いずれも登録規程の内容として正しい記述です。

## 予想問題2｜登録の有効期間と更新

建設コンサルタント登録の有効期間及び更新に関する記述として、最も適当なものはどれか。

1. 登録の有効期間は3年であり、更新登録申請は有効期間満了後30日以内に行う。
2. 登録の有効期間は5年であり、更新登録申請は有効期間満了の日の90日前から30日前までの間に行う。
3. 登録に有効期間の定めはなく、廃業等の届出があるまで効力を有する。
4. 更新登録申請は、有効期間満了日の1年前までに行わなければならない。

### 正答・解説

**正答：2**。建設コンサルタント登録の有効期間は5年で、営業を継続する場合は有効期間満了の日の90日前から30日前までの間に更新登録申請書を提出し、更新登録を受ける必要があります。1は有効期間と申請時期がともに誤り、3は有効期間の定めがある点で誤り、4は申請期限の起算が誤りです。

## 予想問題3｜管理技術者・照査技術者となり得る資格

建設コンサルタント業務における管理技術者・照査技術者の資格に関する記述として、不適当なものはどれか。

1. RCCMは、一般社団法人建設コンサルタンツ協会が実施する資格であり、設計業務等共通仕様書上、管理技術者・照査技術者等となり得る資格の一つとして位置付けられている。
2. RCCMの専門技術部門と、担当する業務の技術的な内容は対応させる必要がある。
3. RCCMの資格を保有していれば、専門技術部門を問わずあらゆる業務で管理技術者になれる。
4. 技術士も、登録を受けた技術部門に応じて管理技術者・照査技術者の要件を満たし得る。

### 正答・解説

**正答：3**。RCCM・技術士のいずれも、資格の専門技術部門（登録部門）と担当業務の技術的な内容が対応していることが前提であり、業務内容に応じた技術的な判断能力を担保する趣旨から、部門を問わず万能に管理技術者となれるわけではありません。1、2、4はRCCM・技術士の位置付けとして正しい内容です。

## 予想問題4｜標準委託契約約款：管理技術者の職務・権限

公共土木設計業務等標準委託契約約款における管理技術者の職務・権限に関する記述として、最も適当なものはどれか。

1. 管理技術者は、契約に基づく受注者の権利をすべて単独で行使でき、業務委託料の変更に関する判断も管理技術者限りで完結する。
2. 管理技術者は、業務の履行に関し受注者を代表する立場にあり、業務委託料の変更や契約の解除に関する権限を除き、契約に基づく受注者の権利を行使できる。
3. 管理技術者は、発注者との連絡調整のみを担い、契約上の権利を行使する立場にはない。
4. 管理技術者を設置するかどうかは、受注者の任意判断に委ねられている。

### 正答・解説

**正答：2**。管理技術者は業務の履行を統括する受注者側の責任者であり、業務委託料の変更や請求・受領、契約解除といった一部の重要事項を除いて、契約に基づく受注者の権利を行使できます。1は業務委託料の変更が単独で完結する点、3は権利行使の立場を否定する点、4は設置が任意である点で、いずれも誤りです。

## 予想問題5｜標準委託契約約款：照査技術者

公共土木設計業務等標準委託契約約款における照査技術者に関する記述として、不適当なものはどれか。

1. 照査技術者は、設計図書に定めがあるときに受注者が設置し、その氏名等を発注者に通知する。
2. 照査技術者は、成果品の内容について技術的な照査を行う。
3. 照査技術者は、同一業務の管理技術者を兼任することができる。
4. 照査技術者の設置は、成果品の品質を担保するための仕組みの一つである。

### 正答・解説

**正答：3**。照査技術者は、同一業務の管理技術者を兼任することができないとされています。管理を担う立場と成果品を客観的に確認する立場を分離することで、内部でのチェック機能が形骸化することを防ぎ、成果品の品質を担保する仕組みです。1、2、4は照査技術者の設置目的・職務として正しい内容です。

## 予想問題6｜条件変更

公共土木設計業務等標準委託契約約款における条件変更に関する記述として、最も適当なものはどれか。

1. 受注者は、図面・仕様書・現場説明書及び質問回答書の内容が一致しないこと等を発見したときは、その旨を直ちに発注者に通知し、確認を請求しなければならない。
2. 受注者は、条件の相違を発見しても、業務の進行に支障がなければ発注者への通知を省略できる。
3. 条件変更の確認は、業務が完了した後にまとめて行えばよい。
4. 条件変更に関する規定は、設計業務には適用されるが調査業務には適用されない。

### 正答・解説

**正答：1**。受注者は図面・仕様書・現場説明書・質問回答書の不一致等の事実を発見したときは、直ちに発注者へ通知し確認を請求する義務があります。2は通知省略を認めていない点、3は速やかな通知が求められる点、4は業務種別で適用可否が分かれない点で、いずれも誤りです。

## 予想問題7｜契約不適合責任

公共土木設計業務等標準委託契約約款における契約不適合責任に関する記述として、不適当なものはどれか。

1. 成果品の内容が設計図書又は発注者の指示に適合しないときは、受注者は必要な修補を行う。
2. 不適合が発注者の指示その他発注者の責めに帰すべき事由による場合、発注者は必要と認めるときは履行期間又は業務委託料を変更する。
3. 契約不適合責任という整理は、民法改正を踏まえて従来の瑕疵担保責任の考え方を整理し直したものである。
4. 契約不適合の有無にかかわらず、発注者は履行期間や業務委託料を一切変更してはならない。

### 正答・解説

**正答：4**。発注者の責めに帰すべき事由による不適合の場合、発注者が必要と認めれば履行期間又は業務委託料を変更する仕組みがあり、一律に変更を禁じてはいません。1、2は契約不適合責任の基本的な扱い、3は令和2年施行の改正で民法の契約不適合責任の考え方に整理された経緯として、いずれも正しい内容です。

## 予想問題8｜建設コンサルタント登録規程の登録部門

建設コンサルタント登録規程に関する記述として、最も適当なものはどれか。

1. 登録は業務の種類にかかわらず一括して行われ、部門別の登録という概念はない。
2. 登録は部門別に行われ、業務を行おうとする部門ごとに登録を受ける必要がある。
3. 登録を受けた部門であっても、技術管理者が退職すると自動的に他部門の登録に振り替えられる。
4. 登録部門は技術士の技術部門とは全く異なる体系であり、両者の対応関係を考慮する必要は一切ない。

### 正答・解説

**正答：2**。建設コンサルタント登録は業務の専門分野ごとの部門別に行われ、業務を行おうとする部門ごとに登録を受ける必要があります。登録可能な部門は複数あり、必要に応じて追加登録することもできます。1は一括登録とする点、3は自動振替とする点、4は技術士部門との対応関係を実務上考慮する必要がない点で、いずれも誤りです。

## 予想問題9｜品確法の対象拡大（令和元年改正）

公共工事の品質確保の促進に関する法律（品確法）の令和元年改正に関する記述として、最も適当なものはどれか。

1. 改正により、対象は公共工事の施工のみに限定され、調査・設計は対象外とされた。
2. 改正により、測量、地質調査その他の調査（点検及び診断を含む）及び設計が新たに法の対象として位置付けられた。
3. 改正は工事の入札契約方式のみを扱い、調査・設計業務の発注方式には触れていない。
4. 改正は民間発注の建設コンサルタント業務にのみ適用され、公共発注には適用されない。

### 正答・解説

**正答：2**。令和元年改正品確法では、測量、地質調査その他の調査（点検・診断を含む）及び設計が新たに法の対象として位置付けられました。1は対象拡大の趣旨と逆である点、3は調査・設計業務の発注方式にも及ぶ点、4は公共発注を対象とする法律である点で、いずれも誤りです。

## 予想問題10｜品確法における発注者の責務

品確法における発注者の責務に関する記述として、不適当なものはどれか。

1. 発注者は、競争参加者の技術的能力に関する事項を審査するよう努める。
2. 発注者は、業務の性格や地域の実情等に応じて入札契約方式を選択するよう努める。
3. 発注者は、価格が最も低い者を機械的に選定すれば品質確保の責務を果たしたことになる。
4. 発注者は、担い手の中長期的な育成及び確保に配慮するよう努める。

### 正答・解説

**正答：3**。品確法は価格のみによる選定を良しとせず、競争参加者の技術的能力に関する事項の審査や、業務の性格・地域の実情等に応じた入札契約方式の選択などを通じて品質を確保することを発注者の責務としています。1、2、4はいずれも品確法が求める発注者の取組として正しい内容です。

## 予想問題48｜土留め・仮設工の安全性

土留め（山留め）に関する記述のうち、最も適当なものはどれか。

1. ヒービングは、砂質地盤で地下水位が高いときに掘削底面から水と土砂が湧き出す現象である。
2. ボイリングは、軟弱な粘性土地盤で背面土の重量により掘削底面が持ち上がる現象である。
3. 土留め壁の根入れ長さは、掘削深さのみで決定され、地盤条件は考慮しない。
4. 切ばり式土留め支保工は、腹起しを介して切ばりで両側の土留め壁を支持する構造であり、掘削の進行に合わせて段階的に設置する。

### 正答・解説

**正答：4**。切ばり式土留め支保工は腹起しと切ばりで両壁を支持し、掘削の進行に合わせて段階的に設置します。1・2はヒービングとボイリングの説明が入れ替わっており誤り、3は根入れ長さが地盤条件にも左右されるため不適当です。

## 予想問題49｜足場からの墜落防止

足場からの墜落防止に関する労働安全衛生関係法令の規定に関する次の記述のうち、最も不適当なものはどれか。

1. 手すりを設置すれば、作業床の幅や床材間の隙間に関する規定は適用されない。
2. 高さ2m以上の作業床の端や開口部には、原則として囲い・手すり・覆い等を設けなければならない。
3. 足場の組立て・解体・変更の作業には、業務に応じた特別教育や技能講習修了者などの資格要件が定められている。
4. 高さ2m以上の箇所で作業を行う場合、作業床を設けることが困難なときは、要求性能墜落制止用器具の使用等の墜落防止措置を講じる。

### 正答・解説

**正答：1**。手すりの設置は作業床の幅や隙間に関する規定を免除するものではなく、両方を満たす必要があります。2は作業床の端・開口部の措置、3は資格要件、4は代替措置として、いずれも適当な記述です。

## 予想問題50｜明り掘削の掘削面こう配

労働安全衛生関係法令に基づく明り掘削作業における地山の掘削面のこう配等に関する記述のうち、最も適当なものはどれか。

1. 掘削面のこう配は、地山の種類にかかわらず一律の基準値が適用される。
2. 掘削深さが浅い場合は、地山の種類を問わず土止め支保工を省略できる。
3. 掘削面の高さやこう配の基準は、地山の種類（岩盤、その他の地山、砂等）によって異なる値が定められている。
4. 明り掘削作業では、点検者を定めずに作業を継続してよい。

### 正答・解説

**正答：3**。掘削面のこう配基準は岩盤・その他の地山・砂など地山の種類ごとに異なる値が定められています。1は一律基準としている点で誤り、2は地盤条件によらない一律省略が誤り、4は点検者を定めて亀裂・湧水等を確認する必要があるため不適当です。
