# 舗装施工管理技術者 note コンテンツ計画（2026-09-29 策定・DN-0352 の決定）

> 位置づけ: `docs/strategy/06_多資格展開戦略.md` の 2026-09-26 決定（舗装を active）。制作は backlog DN-0353、サイト入口は DN-0355。出題分析の根拠は同ディレクトリ `応用試験-出題分析.md`（R4〜R8・1級 46p／2級 35p）。受験者数は `config/exam-stats.json`（R7 1級 3,216 人・2級 1,398 人）。

## 1. 出題分析の要点

- 応用試験は 1級・2級とも「問1 必須＝経験記述」＋選択（1級 問2〜5 から2問、2級 同3問）。分野は両級・全年度で固定（問2 設計／問3 材料・試験／問4 施工／問5 調査・維持修繕）。
- 1級の経験記述は R4〜R8 で不変: 工程管理・出来形/品質管理・安全管理から選び（複数可）、課題 200 字・対策 300 字・結果 100 字。
- 2級の経験記述は R4・R5 が課題 78 字・対策 218 字、R7・R8 は「解答欄に収まるように」。短い。
- 1級の選択は語句・計算・短文記述の混在。頻出は路床 CBRm の式（R4・R5・R6・R8）、測定機器と維持修繕（毎年）、補修断面の TA 計算（R4〜R7）。2級の選択は選択肢から選ぶ穴埋めが基本。

- 一般試験（択一）は note では作らない。サイトの無料記事（DN-0355）と将来の過去問アプリで扱う。

## 3. Red Line

- 公式は解答を出していない。選択問題の正答は技術基準（舗装設計便覧・舗装施工便覧・舗装調査・試験法便覧）で裏取りしてから載せる。
- 問題文の転載はしない（論点の要約と自作の数値例で解説する）。
- 運営者は 1級舗装（2010 取得）。経験記述の模範答案は架空工事であることを明記し、自分の工事に置き換える手順を付ける。

## 4. 買われる時期

試験は 6 月。買われるのは 5〜6 月なので、1級経験記述を 4 月末までに出し、4〜5 月に X・サイトから送客する。
