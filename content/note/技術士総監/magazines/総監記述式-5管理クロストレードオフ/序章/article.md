## 1. なぜ「5管理クロス・トレードオフ」が記述式の核か

総監技術者に問われるのは、専門技術の深掘りではなく、複数の管理にまたがる要求を総合的に判断・調整する力です。5管理すべてを 100% 満たすことは不可能で、限られた資源の中でどれを優先しどこで妥協するか——その判断こそがトレードオフの処理にほかなりません。

だからこそ、想定しうるトレードオフを**あらかじめ列挙して覚えておく**ことが、未知のお題への最短の備えになります。

## 2. 5管理の「核となる目標」

各管理が同じ局面で何を最大化したいのかを1行で押さえます。この核どうしの対立を見抜くことが、トレードオフを書く出発点になります。

- **経済性管理** — コスト・工期・原価・収益の最適化
- **人的資源管理** — 労働力の確保・育成、労働環境の改善、モラール
- **情報管理** — 情報の機密性・完全性・可用性（CIA）、業務効率化
- **安全管理** — 人命・健康・第三者影響の回避、労働安全
- **社会環境管理** — 環境保全・景観・地域合意・社会受容性

## 3. トレードオフの定義 — 解決策の二極化と混同しない

管理間トレードオフは「**解決策の選択肢の対立**」ではありません。

たとえば「事後保全 vs 一律予防保全」は、経済性×安全を**解決するための手段の二極化**であって、トレードオフそのものではありません。本当のトレードオフは「経済性管理の核（コスト・工期の最適化）」と「安全管理の核（人命・第三者影響の回避）」が**ぶつかる構造**そのものです。

答案では「A管理はXを核、B管理はYを核とし、両者は…の局面で衝突する」と、**核同士の対立を1文で宣言してから**施策に入ります。この区別を誤ると、論点が「手段の選択」に滑り評価が伸びません。各記事では、この対立が現れる局面を複数パターン列挙し、それぞれに解決フレームを当てる形で整理しています。

## 4. 解決フレーム辞書

各セルの「解決策（総監的アプローチ）」は、この辞書から2〜3個を組み合わせて構成します。

- **ALARP原則** — 追加対策の費用が便益と見合わなくなる水準でリスクを止め、残余リスクは受容
- **リスクベース判断**（RBM） — 重要度・劣化度でハザードを序列化し、高リスク箇所に資源を集中
- **定量評価** — F-N曲線・期待損失（PML）・費用便益分析（B/C）で投資判断を客観化
- **LCC**（ライフサイクルコスト） — 予防保全への転換で累計維持管理費を下げる根拠
- **LCA**（ライフサイクルアセスメント） — 設計〜廃棄の全工程で環境負荷とコストを一体評価
- **ミティゲーション階層** — 影響を回避 → 低減 → 代替 → 補償の順で対策設計
- **段階的実施**（PoC） — 小規模試行 → 便益実測 → 展開で初期投資と撤退容易性を確保
- **合意形成・情報開示**（PI） — 設計段階から代替案を費用・環境・景観で透明に比較
- **外部不経済の内部化** — カーボンプライシング・環境税・排出量取引で隠れた費用を顕在化
- **人的資本投資** — 教育・処遇改善を単年度費用でなく3〜5年スパンの投資として評価
- **多能工化・形式知化** — 多工程対応とマニュアル化で生産性と技能継承を両立
- **フェールセーフ／フェールソフト** — 誤操作・障害時に安全側へ作動／機能を縮退維持
- **群マネ**（地域インフラ群再生戦略マネジメント）**／ウォーターPPP／PPP・PFI** — 広域・多分野を束ねスケールメリットで VFM を最大化
- **デジタル技術**（PLATEAU・空間ID・デジタルツイン） — 可視化と位置最適化で効率・合意・安全を補完
- **All-hazardアプローチ** — 防災・環境・景観を同一の評価テーブルで統合評価

## 5. 答案を閉じる「残余リスク締め」の定型

選定した解決策の限界を認め、残余リスクと監視体制を末尾で明示すると論旨が閉じます。設問(3)の将来展望や答案の結びにほぼ全て適用できます。

1. 完全な解消は不可能という総監的前提を提示します
2. 残余リスクの監視体制を具体化します（KPI モニタリング・閾値トリガー・センサー／住民協働による早期検知）
3. フィードバック体制を BCP（事業継続計画）と接続します

## 6. 20セル俯瞰マトリクスと本マガジンの使い方

主役となる管理を縦、対立する管理を横に置くと、5 × 4 = 20 セルのトレードオフが並びます。本マガジンは主役管理ごとに5記事へ分け、各記事で4セルを「リード → 起こりうるトレードオフの複数パターン（構造＋解決フレーム）→ 答案ひな型」の型で整理します。


主役管理別の5記事：

- 安全管理を主役に（安全 × 経済性 / 人的資源 / 情報 / 社会環境）
- 経済性管理を主役に（経済性 × 安全 / 人的資源 / 情報 / 社会環境）
- 情報管理を主役に（情報 × 経済性 / 人的資源 / 安全 / 社会環境）
- 人的資源管理を主役に（人的資源 × 経済性 / 安全 / 情報 / 社会環境）
- 社会環境管理を主役に（社会環境 × 経済性 / 安全 / 人的資源 / 情報）

将来課題（2050年に向けた国家的施策）の論点は、設問(3)の専用カタログとして別マガジンで扱います。

## 7. 本マガジンの使い方（逆引き）

試験本番では「お題」だけが与えられ、どの管理が主役かは自分で決めます。だからこそ、本番では次の順に引きます。

1. お題から **主役となる管理** を1つ選びます（人命・防災なら安全、コスト・工期なら経済性、DX・データなら情報、担い手・労働なら人的資源、脱炭素・合意形成なら社会環境）。
2. その主役の記事を開き、**衝突する相手管理のセル**を選びます。
3. セルの「リード」で核同士の対立を1文で宣言し、お題に最も近い**トレードオフのパターン**を選んで「トレードオフの構造」を論拠にし、その「解決策（総監フレーム）」を2〜3個組み合わせ、「答案ひな型」の穴を本業務で埋めます。
4. 最後に §5 の「残余リスク締め」で閉じます。

この4ステップを 20 セルのどこから始めても回せるようにしておけば、お題が読めない局面でも対立構造と解決策を即座に引き出せます。
