# コンクリート主任技士｜令和8年度 四肢択一 予想50問（8分野・全選択肢解説）

![](img/figure-author-authority-concrete.png)

この教材は、技術士（総合技術監理部門）を持つ元・地方自治体の土木職（発注者）がつくっています。コンクリート主任技士・コンクリート診断士にも自分で合格しており、小論文・記述式を書いた当事者です。

総監の5つの管理の視点で記述を分析し、発注者として施工計画書や工事成績評定の書類を審査してきた目で「評価される書き方」を整理しています。

**こんな人のための記事です**

- 過去問を一周し、見たことのない選択肢で総仕上げをしたい
- 材料、耐久性、配合、[品質管理](https://doboku-note.com/docs/pe-comprehensive-management-quality-control?utm_source=note&utm_medium=referral&utm_campaign=cce-r8-mc-50&utm_content=kw-quality-control)、施工、製品、構造を横断して弱点を見つけたい
- 正答番号だけでなく、誤っている語句と修正理由まで確認したい
- 小論文だけでなく、四肢択一の得点を安定させたい

**この記事でわかること**

- 主任技士の主要8分野を、オリジナル50問で一巡できます
- 各選択肢の正誤理由から、似た論点の取り違えを修正できます
- 配合・統計の計算問題は途中式まで再現できます
- 50問の分野別正答率から、試験日までの復習順を決められます

コンクリート主任技士の四肢択一では、技士レベルの知識に加え、複数の要求性能を同時に満たす判断が必要です。強度だけでなく発熱と耐久性、流動性だけでなく材料分離抵抗性、初期性能だけでなく製造・施工・供用中の変動まで見なければなりません。

本教材は、doboku-noteで公開している8分野の過去問解説と体系テキストを土台に、令和8年度の総仕上げ用として新たに作成した四肢択一50問です。実在過去問の文章・数値を置き換えた再録ではありません。

次の三層を重ねて出題範囲を組みました。

1. 主任技士で継続して問われる材料、性質、耐久性、配合、製造、施工、製品、構造の基礎

「予想」は出題の的中を保証する意味ではありません。未知の問題に対応するため、既知の原理を違う条件で使う練習として設計しています。

## 予想問題1｜低熱ポルトランドセメント

低熱ポルトランドセメントの一般的な特性として、適当なものはどれか。

1. C₃Sを多くして初期強度と水和熱を高める。
2. C₂Sを相対的に多くし、水和熱を抑えて長期強度を得る。
3. C₃Aを多くし、耐硫酸塩性を高める。
4. 粉末度を高くすることだけで低発熱化する。

### 正答・解説

**正答：2**。C₂Sは反応が比較的遅く、低発熱・長期強度に寄与します。1は早強側の説明、3はC₃A増加が硫酸塩抵抗性に不利、4は鉱物組成を無視しているため誤りです。

## 予想問題2｜フライアッシュ配合の工程判断

フライアッシュを結合材の一部に用いるマスコンクリートで、温度上昇の抑制と長期耐久性に加え、早期脱型も要求された。配合・施工計画の判断として、最も適当なものはどれか。

1. フライアッシュを用いれば初期強度も必ず増加するため、脱型時強度の確認は省略する。
2. 温度上昇を抑えるには、フライアッシュの品質や置換率にかかわらず単位水量を増やす。
3. 長期強度だけを確認し、初期養生温度と脱型時強度は管理しない。
4. 置換率と養生条件が初期強度・発熱・長期性能へ及ぼす影響を試し練り等で確認し、脱型時強度を満たす工程を定める。

### 正答・解説

**正答：4**。フライアッシュの効果は品質、置換率、温度、養生条件で変わるため、相反する要求を試験と工程計画で調整します。1、3は初期性能の確認を欠き、2は水結合材比と耐久性を悪化させるおそれがあります。

## 予想問題3｜高性能AE減水剤

高性能AE減水剤の使用目的として、最も適当なものはどれか。

1. 同じコンシステンシーで単位水量を低減し、所要の空気を連行する。
2. セメントを用いずに水だけを硬化させる。
3. 粗骨材最大寸法を化学的に小さくする。
4. 凝結時間を条件にかかわらずゼロにする。

### 正答・解説

**正答：1**。高い減水性能とAE性能を利用します。2、3は作用機構と無関係、4は製品種類・温度・使用量で凝結への影響が異なり「ゼロ」にはなりません。

## 予想問題4｜骨材の吸水率

骨材の吸水率が大きい場合に必要な管理として、適当なものはどれか。

1. 含水状態を測定し、有効水量と骨材計量値を補正する。
2. 吸水率と粗粒率を同じ指標として扱う。
3. 絶乾骨材は水を吸わないので補正しない。
4. 表面水が正なら練混ぜ水を増やす。

### 正答・解説

**正答：1**。吸水と表面水を区別して補正します。2は粒度との混同、3は絶乾骨材が吸水するため誤り、4は表面水が水を持ち込むので練混ぜ水を減らします。

## 予想問題5｜練混ぜ水

練混ぜ水の[品質管理](https://doboku-note.com/docs/pe-comprehensive-management-quality-control?utm_source=note&utm_medium=referral&utm_campaign=cce-r8-mc-50&utm_content=kw-quality-control)として、不適当なものはどれか。

1. 油、酸、塩類、有機物などが凝結・強度・耐久性へ及ぼす影響を確認する。
2. 回収水は種類・濃度・使用量を管理する。
3. 飲用水でなければ、品質確認を行っても一律に使用できないと判断する。
4. 水源が変わったときは品質変動を確認する。

### 正答・解説

**正答：3**。飲用水以外でも、適用規格に基づく品質確認で使用可能な場合があります。1、2、4は品質を確保する管理です。

## 予想問題6｜繊維補強コンクリート

短繊維をコンクリートへ混入する目的として、最も適当なものはどれか。

1. ひび割れ後の靱性や剥落抵抗性を改善する。
2. 水セメント比を自動的にゼロにする。
3. すべての鉄筋を無条件に不要にする。
4. 繊維量が増えるほど施工性は必ず向上する。

### 正答・解説

**正答：1**。繊維はひび割れ架橋などに寄与します。2は不可能、3は構造要求に応じた設計が必要、4は過大混入で分散・流動性が悪化するため誤りです。

## 予想問題7｜圧送時のワーカビリティー

同じスランプ値の2配合を長距離圧送したところ、一方だけ圧力上昇と筒先での材料分離が生じた。原因評価として、最も適当なものはどれか。

1. スランプ値が同じなら圧送性も同じなので、配合・材料の確認は不要である。
2. 圧縮強度が同じなら、管内摩擦や材料分離抵抗性に差は生じない。
3. モルタル量、細骨材率、骨材粒形、粘性、分離抵抗性と配管条件を合わせて比較する。
4. 筒先のスランプだけを合わせるため、承認なしに加水する。

### 正答・解説

**正答：3**。圧送性はスランプだけで決まらず、配合の粘性・潤滑性・分離抵抗性と配管抵抗の組合せで評価します。1、2は影響要因を省き、4は水結合材比と品質を変える不適切な対応です。

## 予想問題8｜長期変形の原因分離

プレストレストコンクリート桁で、導入直後の計算値を超える長期たわみが観測された。クリープと乾燥収縮の影響を分けて検討する方法として、最も適当なものはどれか。

1. 載荷直後の弾性たわみだけを再計算し、供用後の計測値は用いない。
2. 乾燥収縮は荷重がなければ生じないと仮定し、湿度履歴を無視する。
3. クリープは部材寸法や載荷材齢に左右されないとして一律値を用いる。
4. 荷重・載荷材齢・温湿度・部材寸法を整理し、載荷供試体の全ひずみから載荷時の弾性ひずみと無載荷供試体の収縮ひずみを差し引く。

### 正答・解説

**正答：4**。クリープひずみは、載荷供試体の全ひずみから載荷直後の弾性ひずみと無載荷供試体の収縮ひずみを差し引いて評価します。1は時間依存変形を除外し、2、3は主要な影響要因を否定しています。

## 予想問題9｜静弾性係数

普通コンクリートの静弾性係数に関する一般的な記述として、適当なものはどれか。

1. 圧縮強度や単位容積質量などの影響を受ける。
2. すべての骨材・強度で一定値である。
3. 応力とひずみの関係とは無関係である。
4. 弾性係数が大きいほど、同じ応力でひずみは大きい。

### 正答・解説

**正答：1**。弾性係数は材料・強度・骨材特性などに依存します。2、3は定義を否定し、4は同じ応力なら弾性係数が大きいほど弾性ひずみが小さいため逆です。

## 予想問題10｜床版仕上げとブリーディング

床版の打込み後、表面にブリーディング水が残っている一方、仕上げ工程の遅れが懸念された。対応として、最も適当なものはどれか。

1. ブリーディング水をセメント粉とともに練り込み、表面を直ちに硬化させる。
2. 水の状態と凝結の進行を確認し、表面へ水を練り込まず適切な時期に仕上げと養生を行う。
3. 工程を優先し、ブリーディング中に過度のこて仕上げを繰り返す。
4. 表面水を除去するため、未凝結コンクリートへ乾燥骨材を散布する。

### 正答・解説

**正答：2**。ブリーディング水を表層へ練り込むと、水セメント比の大きい脆弱層やひび割れを生じやすくなります。1、3、4はいずれも表面品質を損なう対応です。

## 予想問題11｜温度と強度発現

初期材齢の高温履歴に関する一般的な記述として、最も適当なものはどれか。

1. 初期強度を促進する一方、長期的な組織形成へ影響する場合がある。
2. 水和反応を完全に停止する。
3. 凝結を必ず遅らせる。
4. 温度ひび割れと無関係である。

### 正答・解説

**正答：1**。高温は初期反応を促進しますが、温度履歴全体で評価が必要です。2、3は逆、4は部材内外温度差や拘束との関係を無視しています。

## 予想問題12｜高強度コンクリート

高強度コンクリートの性質として、不適当なものはどれか。

1. 低い水結合材比を用いることが多い。
2. 自己収縮や粘性、ポンプ圧送性を確認する。
3. 圧縮強度が高ければ、火災時の爆裂や養生を検討しなくてよい。
4. 材料・製造・施工のばらつき管理が重要である。

### 正答・解説

**正答：3**。高強度化しても、爆裂、温度、収縮、養生など固有の課題を確認します。1、2、4は一般的な管理事項です。

## 予想問題13｜中性化

中性化による鋼材腐食の説明として、適当なものはどれか。

1. CO₂の侵入で細孔溶液のpHが低下し、不動態皮膜が維持されにくくなる。
2. 塩化物イオンがコンクリートから完全に消える現象である。
3. 水セメント比が大きいほど、必ず進行が遅くなる。
4. かぶり厚さは腐食開始時期と無関係である。

### 正答・解説

**正答：1**。2は塩害との混同、3は一般に透気性が高まり進行しやすい方向、4は中性化前線が鋼材へ到達する距離に関わるため誤りです。

## 予想問題14｜塩害

塩害対策として、不適当なものはどれか。

1. 水結合材比を抑え、緻密な組織を確保する。
2. かぶりとひび割れを管理する。
3. 塩化物の供給環境と材料由来塩化物を区別する。
4. 表面塩化物濃度が高い環境ほど、かぶりを小さくする。

### 正答・解説

**正答：4**。厳しい環境では必要な耐久性を確保する方向でかぶり・材料・表面保護などを検討します。1〜3は塩化物侵入と鋼材腐食を抑える基本です。

## 予想問題15｜アルカリシリカ反応

ASRの成立条件の組合せとして、適当なものはどれか。

1. 反応性シリカ、アルカリ、水分
2. 塩化物、酸素、炭酸ガスだけ
3. 凍結温度、乾燥、無反応性骨材
4. 低アルカリ、低湿度、無反応性骨材

### 正答・解説

**正答：1**。反応性骨材、アルカリ、水分が主要条件です。2は鋼材腐食・中性化要因の混同、3、4は成立を抑える側の条件です。

## 予想問題16｜凍害

凍結融解抵抗性の改善として、最も適当なものはどれか。

1. 適切な連行空気と気泡間隔を確保し、飽水度を抑える。
2. 空気量を無制限に増やす。
3. 水結合材比を大きくして空隙を増やす。
4. 養生を短縮して早期に凍結させる。

### 正答・解説

**正答：1**。連行空気は凍結膨張圧の逃げ場となります。2は強度低下、3は透水性・飽水[リスク](https://doboku-note.com/docs/pe-comprehensive-management-risk?utm_source=note&utm_medium=referral&utm_campaign=cce-r8-mc-50&utm_content=kw-risk)、4は初期凍害を招くため誤りです。

## 予想問題17｜化学的侵食

硫酸塩を含む環境での耐久性検討として、適当なものはどれか。

1. 環境濃度、湿潤条件、セメント種類、透水性を合わせて評価する。
2. 圧縮強度だけで化学抵抗性が一意に決まる。
3. C₃Aが多いほど、一般に耐硫酸塩性は必ず高い。
4. ひび割れは侵食速度と無関係である。

### 正答・解説

**正答：1**。材料と曝露条件を統合して判断します。2は物質移動・反応性を無視、3は一般に逆、4は侵入経路になるため誤りです。

## 予想問題18｜複合劣化

塩害と凍害が同時に作用する可能性がある構造物の評価として、最も適当なものはどれか。

1. 一つの劣化だけを選び、相互作用を無視する。
2. 塩分供給、凍結融解、飽水状態、ひび割れ、材料特性を組み合わせて評価する。
3. 外観に損傷がなければ、環境作用は測定しない。
4. 補修後は再劣化の監視を行わない。

### 正答・解説

**正答：2**。複数作用は損傷と物質移動を相互に促進する場合があります。1、3、4は原因推定と[予防保全](https://doboku-note.com/docs/pe-comprehensive-management-preventive-maintenance?utm_source=note&utm_medium=referral&utm_campaign=cce-r8-mc-50&utm_content=kw-preventive-maintenance)を不十分にします。

## 予想問題19｜配合強度の割増し

配合強度を「基準とする強度42.0N/mm²＋1.73×標準偏差」で定める。標準偏差を4.0N/mm²としたとき、配合強度として最も近いものはどれか。

1. 45.5N/mm²
2. 46.0N/mm²
3. 48.9N/mm²
4. 49.7N/mm²

### 正答・解説

**正答：3**。`42.0+1.73×4.0=48.92N/mm²`です。1は係数を掛けずに近似、2は標準偏差だけを加算、4は係数を誤って扱った値です。

2. コンクリートの負担、せん断補強筋、軸力、部材寸法など
3. 曲げひび割れとせん断は無関係
4. せん断補強筋を増やせば、他の破壊形式は無条件に無視できる

### 正答・解説

**正答：2**。せん断抵抗は複数機構で構成されます。1は無関係、3はひび割れ後の抵抗機構に影響、4は上限・定着・圧壊などの検討が必要です。

## 予想問題47｜付着と定着

鉄筋とコンクリートの付着・定着に関する記述として、適当なものはどれか。

1. 鉄筋端部はどこで切ってもよい。
2. ひび割れ、かぶり、横補強筋は付着へ影響しない。
3. 付着により両者の力を伝達し、必要な定着長さを確保する。
4. 異形鉄筋の節は付着と無関係である。

### 正答・解説

**正答：3**。1は力の伝達ができず、2は割裂や拘束へ影響、4は機械的かみ合わせへ寄与するため誤りです。

## 予想問題48｜プレストレスの損失

プレストレスの時間依存損失に関係するものとして、適当な組合せはどれか。

1. 骨材の色、型枠の模様、部材番号
2. スランプ試験の突き回数だけ
3. 荷卸し時の外気温だけ
4. コンクリートのクリープ・乾燥収縮、PC鋼材のリラクセーション

### 正答・解説

**正答：4**。時間とともにコンクリートが変形し、鋼材応力も緩和します。1〜3は損失機構の組合せではありません。

## 予想問題49｜ひび割れ幅

使用限界状態でひび割れ幅を制御する理由として、最も適当なものはどれか。

1. 終局耐力だけが確保されれば、ひび割れは無制限でよい。
2. 耐久性、外観、水密性、使用性を確保する。
3. 鉄筋径・間隔・応力度はひび割れ幅と無関係である。
4. 環境条件による許容の考え方は変わらない。

### 正答・解説

**正答：2**。1は供用性能を無視、3はひび割れ分散と幅へ影響、4は腐食性・水密要求などで制御目標が変わるため誤りです。

## 予想問題50｜限界状態設計

限界状態設計の考え方として、適当なものはどれか。

1. 一つの許容応力度だけで、すべての性能を自動的に満足すると考える。
2. 使用中の変形・ひび割れは照査しない。
3. 終局限界状態・使用限界状態・疲労限界状態などを、作用と抵抗の不確実性を考慮して照査する。
4. 材料強度のばらつきや作用の変動を考慮しない。

### 正答・解説

**正答：3**。性能ごとに限界状態を設定して照査します。1、2、4は複数性能と不確実性を無視しています。
