# コンクリート主任技士 note 商品計画

## 商品の役割

主任技士は四肢択一と小論文の二本立てで、小論文は (3) 業務との関係に自分の立場を書く試験である。受験者は自分の立場の答案を探しに来るので、小論文は**1立場×1テーマを1本**として一度だけ書き、立場別・合格パック・全答案・まるごとへ再収録する。土木の想定工事（1工事1本→分野別セット→完全攻略）、総監の模範論文（職種別マガジン→完全パック）、診断士の記述式（1ケース1本→構造物別→完全パック）と同じ組み方にそろえる。

## 商品ラダー

実価格・noteUrl・公開状態の正本は `content/products/note/<id>.json`（`npm run product -- set` で書き、`src/lib/note-magazines.ts` へ `npm run product -- gen` で生成）。収録数の期待値は `config/note-magazine-membership.json`。

| 段 | 商品 | 中身 |
|---|---|---|
| 単品 | 立場別の答案 1本 | 1立場×1テーマ（40本） |
| 切り口 | 立場別5テーマ（8誌） | その立場の5本＋無料の出題傾向分析 |
| 切り口 | 立場別合格パック（8誌） | 立場別5テーマ＋択一直前3点（予想50問・配合計算・暗記ノート） |
| 全部 | 小論文 令和形式 全40答案（`cce-essay-reiwa-pack`） | 40本＋無料の出題傾向分析 |
| 全部 | まるごとパック（`cce-marugoto-pack`） | 全40答案＋択一3点＋パック案内 |
| 直前 | 択一 直前パック（`cce-takuitsu-chokuzen-pack`） | 予想50問・配合計算・暗記ノート |

## 答案の作り方

- 型と字数帯は `config/cce-essay-history.json` の `answerModel`（立場別記事は `personaArticle`）。(1) 表題・(3) 業務との関係・(4) 今後の対策を立場ごとに書き、(2) 現状と課題は同じテーマで共通にする。
- 執筆は `cce-essay-writer`、採点は `cce-essay-qa`（テーマ単位で8本ずつ）。機械ゲートは `node scripts/check-cce-essay.mjs`（同じテーマで (1)・(4) が同じ文面なら H12 で止める）。
- テーマ別5本（1本に8立場）は note から外し、原稿はココナラ K3 の PDF 素材として残す。
