# コンクリート主任技士 小論文 添削テンプレ（ココナラ `coconala-cce-essay-tensaku`）

受注時の手作業テンプレ。土木の添削エージェント（`civil-keiken-tensaku-drafter` / `-qa`）は経験記述専用なので使わない。出品文で約束した5観点の判定表・NG→OK の書き換え案・読み手視点のコメント・書き直し1回を、この順で下書きする。顧客原稿と下書きはリポジトリに置かず `.tmp/coconala/talkrooms/{id}/` に保存する。

## 1. 受領時の確認（15分）

- 課題文があるか。無ければ「受験年度の課題文（うろ覚えなら要旨）」を依頼する。令和2年度以降の形式は1題・約1,000字・行数指定で、設問は (1) 表題・(2) 現状と課題・(3) 自身の業務との関係・(4) 今後の対策 に置き換えられる（出題履歴の正本は `.claude/config/cce-essay-history.json`）
- 答案が読めるか（画像は全行判読できるか）。読めない行は推測せず質問する
- 字数を数える（空白・改行を除く）。課題の行数指定がわかれば行数も

## 2. 観点別の判定表（出品文の5観点・A/B/C）

| 観点 | 見るところ | C になる典型 |
|---|---|---|
| 題意への応答 | 課題の問いに、設問の順で答えているか | 課題と別のテーマ、(3) や (4) の欠落 |
| 技術的な正確さ | 用語・数値・規格（JIS A 5308、示方書）の正誤 | 規格値の誤り、因果の取り違え |
| 実務経験の具体性 | (3) が本人の立場と業務の事実で書かれているか | 一般論のみ、立場の権限を越えた記述 |
| 構成 | (2) 現状と課題 → (4) 対策が対応しているか | 課題と対策の不一致、結論の欠落 |
| 字数と表現 | 約1,000字・行数指定、常体の統一、一文の長さ | 字数不足・超過、敬体混在 |

## 3. 赤入れ（NG→OK 2〜4点）

- 評価が最も分かれる箇所から順に選ぶ。1点ごとに「原文の引用 → なぜ減点されるか → 書き換え案」
- 書き換え案は本人の事実の範囲で書く。答案に無い業務・数値を足さない（足す必要があるときは質問にする）
- 技術的な指摘は根拠（規格名・示方書の章）を添え、本人が確かめられるようにする

## 4. 読み手視点のコメント（3〜5行）

採点者がどこで評価を決めるかを一言で。立場の選び方で迷っている場合は、令和形式テーマ別教材の「立場別の書き分けポイント」の考え方（決められる範囲と使う指標）で説明する。教材の本文は貼らない。

## 5. 書き直し（1回）

再提出分は前回の赤入れ箇所が直ったかを先に確認し、新たな指摘は重大なものだけにする。

## 6. 送信前の自己点検

- 判定表5観点すべてに A/B/C と理由がある
- 書き換え案に本人が書いていない事実・数値が入っていない
- 合格保証・出題予想の断定を書いていない
- 返信文は運営者が読み、トークルームへ送る（エージェントは送信しない）
