# 転職訴求の編集企画

企画日: 2026-09-08。根拠・優先順位は[訴求設計](../../../docs/marketing/転職アフィリエイト訴求設計.md)。以下は編集用の入力で、noteへそのまま投稿する本文ではない。新規URLの量産ではなく、既存記事を目的別に改稿する。

## 1. 相談の負担を見通せる記事

- **読者／検索意図**：施工管理として在職中。相談はしたいが、連絡や応募を急かされることが心配。「施工管理 転職 相談だけ」「転職エージェント 電話 苦手」を仮説クエリとする。検索量は未取得。
- **サイト**：[辞める前に相談すべきこと](../../site/civil-construction-1/guide-career-consultation-before-quit/article.mdx)。経験の棚卸し→年収内訳・休日・勤務地シート→登録後の説明→連絡希望文→求人の見送り方。
- **note**：[転職エージェントの使い方](転職エージェントの使い方-無料/article.md)。導入は「現場にいる時間に、何度も電話が来たら困る」。読後に「変えたいこと／守りたいこと／連絡方法」の3行を作れる。
- **CTA**：サイトでは相談対象と登録後のやり取りを明記。noteの文脈リンクは条件シートに直結し、`civil-career-agent-howto` と `utm_content=condition-sheet` を使う。自社原稿2本が今回のパイロット。
- **編集境界**：「希望を伝えれば必ず電話がなくなる」は不可。各社の相談可否・連絡対応を一律に保証しない。

## 2. ビルドジョブの評判を、相談前の確認に変える

- **読者／検索意図**：既にサービス名を知り、申し込むか判断したい。「ビルドジョブ 評判／口コミ」は自サイトのGSCで観測済み。
- **サイト**：[既存の評判記事](../../site/civil-construction-1/guide-buildjob-review/article.mdx)。改稿タイトル案「ビルドジョブは土木施工管理に向く？相談前に確認する条件と流れ」。公式で分かること→自分の地域・工種について聞くこと→利用の流れ→応募を見送る判断、の順。
- **note**：[既存の評判記事](ビルドジョブの評判-発注者目線-無料/article.md)を「評判を読む前に、担当してきた工事を3行で整理する」に寄せる。資格名／担当工種／自分の責任範囲の記入例を置く。例は架空の転職成功談にしない。
- **CTA**：「土木の経験と希望条件を相談する」。ブランド名をクリックした読者がどのサービスに進むかを明示し、汎用presetによる別社表示を公開前に解消する。
- **編集境界**：既存の「未経験・地方なら併用が前提」という断定は、公式の対象範囲と個別の求人有無を分けて書き直す。紹介件数・年収増額・承認率は未検証のまま加筆しない。

## 3. 年収を維持しながら働き方を変えたい

- **読者／検索意図**：経験者・有資格者。年収を下げたくないが、休日や家族との時間を確保したい。「土木施工管理 年収 残業」「施工管理 休日 転職」を仮説クエリとする。
- **サイト**：[ホワイトな建設会社の見分け方](../../site/civil-construction-1/guide-white-company/article.mdx)にある求人票・面接の質問を、現職と候補企業を並べる記入シートへ展開。基本給／変動手当／休日出勤／代替要員／現場範囲を比較する。給与記事との重複は、年収の上げ方と勤務条件の確認で分ける。
- **note**：[ホワイトな建設会社の見分け方](ホワイトな建設会社の見分け方-無料/article.md)の導入案「年間休日の数字だけで、次の現場を決めたくない」。一つの質問「休む人の仕事は誰が担当しますか」から現場体制の確認へ進む。
- **CTA**：「休日と年収の希望条件を相談する」。年収アップの保証ではなく、読者が事前に作った条件を相談に持ち込む理由を示す。
- **編集境界**：回答が曖昧な会社を即ブラックと判定しない。求人票で分かることと、配属現場について確認が要ることを分ける。

## 4. 発注者支援と公務員を仕事内容で比べる

- **読者／検索意図**：土木の経験を使いながら、現場常駐や転勤の条件を変えたい。「施工管理 発注者支援」「土木 公務員 民間 比較」を仮説クエリとする。
- **サイト**：[発注者支援業務への転職](../../site/civil-construction-1/guide-hatchu-shien/article.mdx)の仕事内容・働き方・採用ルートを軸に、雇用先／指示系統／常駐先／繁忙期対応／担当範囲を質問表にする。制度を説明する場合は公的資料を改めて確認する。
- **note**：[公務員土木か民間か](公務員土木か民間か-無料/article.md)を入口に、「発注者側へ行けば楽になる、だけでは選べない」を切り口とする。運営者が実際に説明できる自治体業務と、各求人で確認する事項を分ける。
- **CTA**：民間の発注者支援を検討する人には「担当業務と勤務地の条件を相談する」。自治体を志望する人には採用情報の確認を案内し、広告へ無理に寄せない。
- **編集境界**：公務員と民間受託会社を混同しない。「休日が多い」「転勤なし」を職種全体の性質として断定しない。

## 5. 2級・若手が、次の職場で積める経験を選ぶ

- **読者／検索意図**：経験の浅い施工管理担当者。今の現場に不満があり、続けるか移るか迷っている。「2級土木 転職 経験浅い」「施工管理 第二新卒」を仮説クエリとする。
- **サイト**：[20代・第二新卒のキャリア記事](../../site/civil-construction-2/guide-young-career/article.mdx)の強み・未経験・資格取得の説明を、配属時の担当範囲／教える人／一人で任される時期／経験できる工種の確認へ具体化する。
- **noteタイトル案**：「2級土木を取ったあと、年収と一緒に確かめたい『次に任される仕事』」。制作するなら新規候補だが、まず既存サイト記事の反応を見て判断。経験が浅いことを隠す話にはしない。
- **CTA**：「これまでの経験と、次に積みたい経験を相談する」。GKSなど若手向け案件を使う場合も、年齢・経験・地域の現行条件を確認してから選ぶ。
- **編集境界**：2級保有者を一律に未経験として扱わない。資格手当や昇格を保証せず、資格取得支援は会社ごとの確認事項にする。

## 原稿・配信の共通条件

公開情報の事実、読者が書く記入例、運営者の実経験、編集上の仮説を区別する。noteには表や複数行の引用を持ち込まず、サイトへのリンクは正規URLとUTMを含むインラインにする。PRはリンク直前で分かるように表示する。

成果確認は対象記事の流入とCTA表示・クリック、ASPの発生・承認までを追う。noteのスキ数だけで転職ニーズや成約見込みを評価しない。新しい公開・再公開の日を記録し、EXP-008の途中変更と混ぜない。
