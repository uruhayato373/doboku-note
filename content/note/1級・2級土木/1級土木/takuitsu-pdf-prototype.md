# 1級土木 択一・論点別トレーニング（Kindle / note 試作メモ）

> [!note] 位置づけ（2026-06-11 SSOT 整理）
> 本書は 2026-06-09 の試作記録。KDP 出版の戦略・手順の真実源は [Kindle 管理SSOT](../../../../content/kindle/strategy.md) を参照。

択一過去問を有料販売する案の試作記録。**生の年度別過去問をそのまま売る**のは筋が悪い
（自サイトで無料公開中・無料代替が飽和）ため、択一を素材に**論点別へ再構成した編集物**として
価値を載せる。1 ソースから **Kindle 用 EPUB** と **note 用 PDF** の両方を出す。

## 結論（戦略）

- **主チャネルは Kindle (KDP)**。「集客はサイトに依存できない」という悩みに対し、Amazon の
  検索市場・Kindle Unlimited が買い手を連れてくる。note は SNS ファネルが育った後の従チャネル。
- **生の年度別ではなく論点別・年度横断・暗記特化**へ再構成して差別化する（本試作の中身）。
- 1級/2級土木は**試験実施機関（全国建設研修センター）のクレジット表示**で過去問を使用する。

## 何を作ったか

| 項目 | 内容 |
|---|---|
| ジェネレータ | `scripts/build-takuitsu-reconstruct.mjs`（1 ソース → md / 印刷 html / EPUB） |
| 入力 | `src/config/civil-1-exam-questions.json`（H26〜R07・全 1162 問・構造化済み） |
| 試作テーマ | 安全管理（抽出 194 問 → 図版依存 4 問除外・同趣旨 30 問圧縮 → 収録 160 問・9 論点） |
| 出力 | `.tmp/takuitsu-anzen/`：`anzen.epub`（Kindle 入稿）／`article.md`（note 貼付）／`print.html`（PDF 化用） |

### 再構成のしくみ（差別化の中身）

1. **論点別に解体** — 年度別ではなく「足場・墜落／明り掘削・土止め／型枠支保工／車両系建設機械／移動式クレーン・玉掛け／ずい道／酸欠・有害物／感電・架空線／安全衛生管理体制」の 9 論点へ自動振り分け。
2. **論点まとめ** — 各論点の冒頭に、過去問の正答選択肢解説（法令条文付き）を集約・重複圧縮した「覚える正しい知識」を配置。
3. **一問一答（年度横断）** — 同じ論点の問題を H26〜R07 で連続演習。各問に正答＋要点。
4. **同趣旨圧縮** — 反復出題された設問は最古年に集約し「同趣旨で再出題: …」と注記。

## 使い方（再生成）

```bash
# md + 印刷 html + epub をまとめて生成（既定 --format both）
node scripts/build-takuitsu-reconstruct.mjs --theme anzen
#   --format md | epub | both / --outDir <dir>
```

### Kindle (KDP) で出す手順

1. 上記で `anzen.epub` を生成（出典クレジット・免責・著者・目次を内蔵済み・リフロー）。
2. 表紙画像を用意（KDP の Cover Creator か、JPEG 1600×2560 を別途作成）。本 EPUB には表紙画像は未内蔵。
3. [KDP](https://kdp.amazon.co.jp/) で電子書籍を新規作成 → タイトル・著者「架（かける）」・紹介文を入力。
4. 原稿＝`anzen.epub` をアップロード、表紙を設定、プレビューで目次遷移を確認。
5. 価格・KDP セレクト（Kindle Unlimited 対象化）を設定して出版。

> [!note] note でも売る場合
> `print.html` を Chrome で開く → Ctrl+P →「PDF に保存」で note 添付用 PDF。`article.md` は note 直貼り用。

> [!note] テーマ追加
> `THEMES` にテーマ定義（抽出 regex・サブ論点）を足すだけ。土工・コンクリート等は図版依存問題が
> 多いため、図を伴う設問の扱い（画像同梱 or 割愛）を別途設計する。

## 既知の限界（製品化前に手当て）

- **論点分類の混入（2026-07-08 構造是正済み）**: 旧実装は body 全体マッチで他分野の設問を拾っていた（安全管理で48問）。見出し文（lead）判定＋exclude regex に是正し、A-01 は収録127問・9論点に確定。
- **元データ由来の省略**: 一部の解説が元 JSON 時点で「…」で省略されている（真因はサイト MDX 側の尻切れ）。A-01 の正答解説3件は JSON 側を出典ベースで補完済み。ただしパーサー再実行で上書きされるため恒久対応はサイト MDX 修正（別タスク）。
- **図版問題は自動除外**: 「下図」等を含む設問は画像が無いため除外（安全管理は 4 問のみ）。図依存の高い土工・構造系を出す場合は画像同梱の仕組みが必要。
- **表紙画像は別途**: EPUB に表紙を内蔵していない（クラウド環境にラスタライザが無い）。KDP 側で設定する。
- **epubcheck 実施済み（2026-07-08）**: `brew install epubcheck` で導入し、A-01（anzen.epub）は EPUB 3.3 ルールでエラー0/警告0 を確認。以降の生成物も出版前に必ず実施する（オーケストレーションは `/kindle-build` スキル）。
