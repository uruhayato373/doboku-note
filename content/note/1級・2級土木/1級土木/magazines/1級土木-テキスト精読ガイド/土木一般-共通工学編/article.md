# 土木一般・共通工学編｜1級土木 テキスト精読ガイド｜出題頻度・優先度つきで読む

**こんな人のための記事です**

- 第1次検定の「土工」「コンクリート工」「基礎工」等、土木一般・共通工学の範囲をどこから手をつければいいか分からない
- 分野ごとの出題頻度・優先度が分からないまま、全項目を均等に勉強してしまっている
- 各分野の要点をサイトの解説記事で確認しながら、効率よく仕上げたい

**この記事でわかること**

- 土工・建設機械・コンクリート工・基礎工・測量・解体工事の6分野を、出題頻度と優先度つきで整理した精読の地図
- 各分野の頻出テーマ（毎年出題／隔年出題）と、そこから読むべき詳細解説記事への直リンク
- 6分野の中でどこから手をつけるべきかの優先順位

---

本記事は「施工管理・法規編」に続く精読ガイドの第2巻です。土工・建設機械・コンクリート工・基礎工・測量・解体工事の6分野を、doboku-note の各分野解説記事（合計約1,900本の詳細解説と連動）から頻出テーマだけを抜き出し、優先度つきで整理しました。各テーマから該当する詳細解説記事へ直リンクしているので、気になった項目はクリックしてそのまま確認してください。

## 6分野の出題ウェイトと優先順位

土工・コンクリート工・基礎工は第1次検定の主要分野として毎年安定して出題されます。建設機械・測量・解体工事は単独の大問というより、土工・専門土木の設問に組み込まれる形で頻出する分野です。

- **土工**（4〜5問）— 選択問題のため得意分野として確実に得点源にしたい
- **コンクリート工**（5〜8問）— 最重要テーマのひとつ
- **基礎工** — 専門土木（選択解答）の定番分野。実務経験者が取り組みやすい一方、差がつきやすい
- **建設機械・測量・解体工事** — 単独の大問は少ないが、土工・専門土木の設問に組み込まれる形で頻出

## 土工（4〜5問）

第1次検定「土木一般」から毎年出題される主要分野です。選択問題のため、得意分野として確実に得点源にしてください。

- **土質試験**（原位置試験の名称・求められるもの・利用）— 毎年出題 — 優先度 ★★★
- **土量変化率**（L・Cの定義・計算・運搬計画への適用）— 毎年出題 — 優先度 ★★★
- **盛土施工**（締固め機械の選定・建設発生土・情報化施工）— 毎年出題 — 優先度 ★★★
- **軟弱地盤対策**（各工法の原理と適用）— 毎年出題 — 優先度 ★★★
- **のり面保護工**（植生工・構造物保護工の種類と選定）— 隔年出題 — 優先度 ★★☆

→ [土工の重要ポイント（無料）](https://doboku-note.com/docs/civil-construction-1-guide-earthwork-key-points?utm_source=note&utm_medium=referral&utm_campaign=civil1-reading-guide&utm_content=earthwork-key-points)

## 建設機械（土工・専門土木に組み込まれる形で頻出）

単独の大問として毎年固定数が出るわけではありませんが、ブルドーザ・ショベル系掘削機・締固め機械の構造や作業能力は土工分野の設問に組み込まれる形で高頻度に登場します。

- **ショベル系掘削機の分類と掘削方式**（バックホウ・ショベル・ローディングショベル等）— 頻出 — 優先度 ★★★
- **オペレータ保護装置**（ROPS・FOPS・OPG・TOPS）の対象機械 — 頻出 — 優先度 ★★★
- **ブルドーザの走行装置・土工板・作業能力** — 頻出 — 優先度 ★★★
- **締固め機械の分類と使い分け**（ロードローラ・タイヤローラ・タンピングローラ・振動ローラ）— 頻出 — 優先度 ★★★
- **排出ガス対策型・低騒音低振動型建設機械の指定制度** — 隔年出題 — 優先度 ★★☆
- **モータグレーダの分類・構造** — 隔年出題 — 優先度 ★★☆
- **情報化施工・i-Constructionとの関連** — 隔年出題 — 優先度 ★★☆

→ [建設機械の重要ポイント（無料）](https://doboku-note.com/docs/civil-construction-1-guide-machinery?utm_source=note&utm_medium=referral&utm_campaign=civil1-reading-guide&utm_content=machinery)

## コンクリート工（5〜8問・最重要テーマ）

コンクリート分野は毎年5〜8問程度出題される最重要テーマのひとつです。

- **骨材の品質**（細骨材・粗骨材の品質基準、粒度、吸水率）— 毎年出題 — 優先度 ★★★
- **混和材料**（AE剤・減水剤・フライアッシュ・高炉スラグ・シリカフューム）— 毎年出題 — 優先度 ★★★
- **打込み・締固め**（打込み高さ、打重ね時間、バイブレータの使用方法）— 毎年出題 — 優先度 ★★★
- **養生**（湿潤養生期間、寒中・暑中コンクリートの温度管理）— 毎年出題 — 優先度 ★★★
- **鉄筋工**（かぶり、継手、加工・組立）— 毎年出題 — 優先度 ★★★
- **ひび割れ・劣化**（温度ひび割れ、中性化、塩害、アルカリシリカ反応）— 毎年出題 — 優先度 ★★★
- **型枠・支保工**（型枠の存置期間、支保工の取外し条件）— 隔年出題 — 優先度 ★★☆
- **配合設計**（水セメント比、単位水量、スランプ）— 隔年出題 — 優先度 ★★☆

→ [コンクリートの重要ポイント（無料）](https://doboku-note.com/docs/civil-construction-1-guide-concrete-key-points?utm_source=note&utm_medium=referral&utm_campaign=civil1-reading-guide&utm_content=concrete-key-points)

供用後の維持管理（劣化機構・点検・非破壊検査・補修補強）まで踏み込みたい方は、
[コンクリート構造物の維持管理の要点（無料）](https://doboku-note.com/docs/civil-construction-1-guide-concrete-maintenance?utm_source=note&utm_medium=referral&utm_campaign=civil1-reading-guide&utm_content=concrete-maintenance)もあわせてご覧ください。

## 基礎工（専門土木の定番分野）

第1次検定の問題A「専門土木」のなかで毎年出題される定番分野です。構造物の安全性を根本から左右するテーマで、実務経験者にも差がつきやすい分野です。

- **基礎形式の分類**（直接基礎・杭基礎・ケーソン基礎の適用条件）— 毎年出題 — 優先度 ★★★
- **地質調査の手法**（標準貫入試験・サウンディング）— 毎年出題 — 優先度 ★★★
- **土留め・仮締切りの安定検討**（ヒービング・ボイリング・盤ぶくれ）— 毎年出題 — 優先度 ★★★
- **場所打ち杭工法の比較**（オールケーシング・アースドリル・リバース・深礎）— 毎年出題 — 優先度 ★★★
- **既製杭工法**（打込み杭・埋込み杭）の施工管理 — 隔年出題 — 優先度 ★★☆
- **杭基礎の支持機構**（支持杭・摩擦杭）— 隔年出題 — 優先度 ★★☆

→ [基礎工の重要ポイント（無料）](https://doboku-note.com/docs/civil-construction-1-guide-foundation?utm_source=note&utm_medium=referral&utm_campaign=civil1-reading-guide&utm_content=foundation)

## 測量（取りこぼしを防ぐタイプの分野）

出題数自体は多くありませんが、用語の対応関係や数値の入れ替えという単純な引っかけが多く、正確に暗記していれば確実に得点できる分野です。

- **測量法に定める区分**（基本測量・公共測量など）— 頻出 — 優先度 ★★★
- **測量の誤差の分類と消去・調整方法** — 頻出 — 優先度 ★★★
- **GNSS測量**（単独測位・相対測位・RTK法等）— 頻出 — 優先度 ★★★
- **水準測量の許容範囲**（等級別の数値）— 頻出 — 優先度 ★★☆
- **測量の基準**（経緯度原点・水準原点）— 隔年程度 — 優先度 ★★☆
- **セオドライトの4軸条件と器械誤差** — 隔年程度 — 優先度 ★★☆
- **地形測量・写真測量**（UAV等の新しい測量技術）— 近年増加傾向 — 優先度 ★☆☆

→ [測量の重要ポイント（無料）](https://doboku-note.com/docs/civil-construction-1-guide-surveying?utm_source=note&utm_medium=referral&utm_campaign=civil1-reading-guide&utm_content=surveying)

## 解体工事（暗記の精度が得点に直結）

コンクリート構造物の維持管理・更新需要の高まりを背景に、専門土木や施工計画の関連問題として繰り返し出題される分野です。工法の名称と原理の対応関係を問う設問が中心です。

- **解体原理による5工法**（打撃・圧砕・切断・静的破砕剤・転倒）の原理と特徴 — 毎年出題傾向 — 優先度 ★★★
- **切断工法4種**（カッタ・ワイヤーソーイング・コアドリル・ウォータージェット）の使い分け — 頻出 — 優先度 ★★★
- **地上解体工法と階上解体工法**の適用場面の違い — 頻出 — 優先度 ★★☆
- **解体工事の施工の流れ**（事前調査・施工計画・事前措置・解体作業）— 隔年出題 — 優先度 ★★☆
- **構造物解体作業における安全確認事項** — 隔年出題 — 優先度 ★★☆

→ [解体工事の重要ポイント（無料）](https://doboku-note.com/docs/civil-construction-1-guide-demolition?utm_source=note&utm_medium=referral&utm_campaign=civil1-reading-guide&utm_content=demolition)
