# 添削実測サンプル01｜AI下書き（ステップ2・論点抽出）

> 添削テンプレ ステップ2 のプロンプトで提出原稿から抽出した減点ポイントの一次たたき台。
> 運営者はこれを取捨選択し、**最重要の1〜2点だけ**を最終赤入れ（ステップ3）すればよい。

形式：該当箇所 → なぜ減点か → OK例

1. **工事概要「規模：一式」** → 定量性ゼロで工事像が伝わらない → 「延長○○m、幅員○○m、改良土工量 約○○m³」のように数値で示す。
2. **工事概要「立場：現場担当」** → 責任範囲が不明で、判断・指示を語る土台がない → 「現場代理人 兼 主任技術者」など責任の分かる呼称に。
3. **設問1の措置が一般論（バリケード・誘導員・看板）** → どの工事でも書ける作文で、数値・固有性がない → 「車道との離隔○○m、仮囲い高さ○○m、夜間の保安灯○○m間隔、誘導員○名を交差部に配置」など定量で。
4. **設問1と設問2がほぼ同一内容（どちらも誘導員配置→無事故）** → 設問1≠設問2の原則に反する → 設問1=実施した措置、設問2=技術的課題（例：歩行者動線と工事車両動線の交差）とその検討の論理、に役割分担する。
5. **設問2の課題が「事故が起きないように」と抽象** → 防止すべき第三者災害が1つに絞られていない → 「歩行者動線と工事車両出入口が交差し、接触のおそれ」のように現場条件から1つに具体化。
6. **評価が「無事故で完了」のみで措置と未接続** → 結果だけで因果が弱い → 絞った課題に対する措置の効果として無事故を締める。

## 最終赤入れの推奨フォーカス（運営者が1〜2点選ぶ想定）

- 最優先候補：**No.4（設問1≒設問2）** と **No.3（措置の定量化）**。合否を分けやすい2点。
