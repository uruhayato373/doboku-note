# 添削実測サンプル01｜AI下書き（ステップ2・論点抽出）

> 添削テンプレ ステップ2 のプロンプトで提出原稿から抽出した減点ポイントの一次たたき台。
> 運営者はこれを取捨選択し、**最重要の1〜2点だけ**を最終赤入れ（ステップ3）すればよい。

形式：該当箇所 → なぜ減点か → OK例

1. **工事概要「規模：一式」** → 定量性ゼロで工事像が伝わらない → 「延長○○m、幅員○○m、改良土工量 約○○m³」のように数値で示す。
2. **工事概要「立場：現場担当」** → 責任範囲が不明で、判断・指示を語る土台がない → 「現場代理人 兼 主任技術者」など責任の分かる呼称に。
3. **設問1に対応処置と評価が混在** → 2級の（1）は現場状況・技術的課題を書く欄である → 「歩行者動線と工事車両出入口が交差し、接触のおそれがあった」のように現場条件と課題に絞る。
4. **設問2に技術的課題を置き、検討項目がない** → 2級の（2）は検討した項目とその対応処置を書く欄である → 「動線分離方法と誘導員配置を検討し、バリケード○○m・誘導員○名を配置」のように役割分担する。
5. **技術的課題が「事故が起きないように」と抽象** → 防止すべき第三者災害が1つに絞られていない → 設問1で「歩行者動線と工事車両出入口が交差し、接触のおそれ」のように具体化する。
6. **設問2の対応処置に検討項目との対応がない** → 措置だけでは選定過程が伝わらない → 検討項目を先に示し、各項目と実施した措置を対応させる。

## 最終赤入れの推奨フォーカス（運営者が1〜2点選ぶ想定）

- 最優先候補：**No.3（設問1への対応処置混在）** と **No.4（設問2の検討項目欠落）**。現行2級の欄の割り振りに直結する2点。
