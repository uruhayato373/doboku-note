# 添削実測サンプル02｜AI下書き（ステップ2・論点抽出）

> 添削テンプレ ステップ2 のプロンプトで提出原稿から抽出した減点ポイントの一次たたき台。
> 運営者はこれを取捨選択し、**最重要の1〜2点だけ**を最終赤入れ（ステップ3）すればよい。

形式：該当箇所 → なぜ減点か → OK例

1. **工事概要「規模：一式」** → 定量性ゼロ → 「コンクリート数量 約○○m³、躯体寸法 ○○×○○×○○m」など数値で。
2. **工事概要「立場：担当者」** → 責任範囲が不明 → 「現場代理人」「主任技術者」など責任の分かる呼称に。
3. **設問1に養生・温度管理という対応処置が混在** → 2級の（1）は現場状況・技術的課題を書く欄である → 「暑中施工で内外温度差が大きくなり、温度ひび割れのおそれがあった」のように条件と課題に絞る。
4. **設問2に技術的課題を置き、検討項目がない** → 2級の（2）は検討した項目とその対応処置を書く欄である → 「打設時間帯と養生方法を検討し、○時打設・○日間の湿潤養生を実施」のように役割分担する。
5. **技術的課題が「ひび割れが発生しないように」と一般的** → 何のひび割れか（温度ひび割れ／乾燥収縮）が絞られていない → 設問1で「暑中施工で内部温度上昇による温度ひび割れが懸念」と条件から特定する。
6. **設問2の対応処置に管理値・確認方法がない** → 品質は定量が命 → 温度計測・テストピース・スランプ試験など、検討項目に対応する処置と確認手段を入れる。

## 最終赤入れの推奨フォーカス（運営者が1〜2点選ぶ想定）

- 最優先候補：**No.3（設問1への対応処置混在）** と **No.4（設問2の検討項目欠落）**。現行2級の欄の割り振りに直結する2点。
