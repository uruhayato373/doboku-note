# LINE公式 配信台本（一次→二次ブリッジ磁石）

LINE公式アカウントの管理画面で設定する3通。「あいさつメッセージ」1通＋「ステップ配信」2通の構成。
月200通の無料枠を前提に、友だち登録した人だけに送る（一斉配信ではなくステップ配信で使う）。

## 設定の前提

- **トリガー**: 友だち追加
- **配信対象**: 一次おつかれ様ブリッジ磁石の友だち追加者のみ（他の用途と混在させない）
- **停止条件**: 月200通に達する見込みが出たら、以降の新規追加分の配信を止めて手動対応に切り替える（[[feedback_x_suspension_guardrail]] と同種の予防的スロットル。無料枠超過で自動課金プランへ変更しない）

## 運用メモ

- 1通目のPDFリンクは、`magnet-pdf.md` を note の無料記事（または配布用ページ）として公開したURLに差し替える
- 友だち追加CTA自体の文言は `friend-add-cta.md` を参照
- 配信後の反応（クリック率・会員遷移数）は月次で `.claude/state/` 配下に記録する運用先が未定。次回セッションで計測方法を決める
