# 友だち追加CTA文言（一次→二次ブリッジ磁石）

一次検定終了直後〜合格発表前後の期間、X・note・サイトの該当ページに置く「友だち追加」導線の文言。
器（LINE公式アカウント自体の開設・QRコード発行）はユーザー作業。ここでは文言のみを用意する。

## 短文（X投稿・バナー用）

```
一次検定、お疲れ様でした。

第2次検定は10月4日。
「今日から何を始めればいいか」を1枚のPDFにまとめました。
友だち追加ですぐ受け取れます。

→ [LINE公式のURL]
```

## 中文（note記事末尾・サイトCTA用）

```
一次検定を終えた今、次にやることは決まっています。
第2次検定（10月4日）は施工経験記述で大きく差がつく試験です。

「一次おつかれ様→二次の始め方」PDFを、LINE公式アカウントの
友だち追加で無料配布しています。今日から迷わず始めたい方はどうぞ。

友だち追加はこちら → [LINE公式のURL]
```

## ボタン文言（サイト・LP用の短い呼びかけ）

```
二次の始め方PDFを受け取る（友だち追加）
```

## 掲載候補面（優先順）

1. 一次過去問ページ（primary-*）の試験後の共通冒頭CTA差し替え先の1つ（総監の evergreen CTA と同種の扱い）
2. X投稿（一次合格発表8/13前後を想定していたが、現時点では試験後どのタイミングでも成立する内容）
3. note「経験記述-落ちる答案診断-無料」記事末尾（既存リードマグネットからの二段構え）

## 運用メモ

- LINE公式のURL（QRコード・友だち追加リンク）はアカウント開設後にユーザーが発行する。発行後、上記の `[LINE公式のURL]` プレースホルダーを実際のURLへ差し替えて各面に配置する
- 配置後の効果測定はUTM付きリンクで行う想定（既存のnote↔サイトUTM規約に準拠）。具体的なUTMパラメータは配置面が決まってから採番する
