# 技術士 口頭試験対策（全部門共通）— 令和8年度 改訂コンピテンシー対応の想定問答と、部門別の当てはめ例

**こんな人におすすめ**

- 技術士第二次試験の筆記試験に合格し、口頭試験の準備をこれから始める人
- 上下水道・電気電子・農業・機械など、建設部門以外の部門で受験していて、自分の部門に合う口頭試験の教材が見つからない人
- 試問事項と配点、20分の時間の使い方を公式の案内に沿って確認したい人
- 想定問答を丸暗記ではなく、自分の業務経歴に置き換えて準備したい人

**この記事でわかること**

- 総合技術監理部門を除く20部門に共通する口頭試験の試問事項・配点・合否の基準
- 部門が違っても変わらない準備と、部門によって変わる準備の分け方
- 4つの試問事項ごとの想定問答24問と、上下水道・電気電子・農業・機械・建設の当てはめ例
- 業務内容の詳細720字以内を口頭で2分に組み立て直す型と、落ちる回答の型

## 1. 口頭試験の試問事項と配点 — 全部門で同じ

令和8年度の受験申込み案内では、口頭試験は「技術士としての適格性を判定することに主眼をおき」、筆記試験の記述式答案と業務経歴を踏まえて行うとされています。総合技術監理部門を除く技術部門の試問事項と配点は次のとおりです。

- Ⅰ 技術士としての実務能力
  - ① マネジメント、評価：30点
  - ② コミュニケーション、リーダーシップ：30点
- Ⅱ 技術士としての取組姿勢
  - ③ 技術者倫理：20点
  - ④ 継続研さん：20点

試問時間は20分で、10分程度延長される場合もあります。合否は4つの試問事項それぞれについて60％以上の得点で判定されます。合計点で他の項目の不足を補える仕組みではないため、手薄な試問事項を1つでも作らないことが準備の前提になります。

案内には「業務経歴等の内容を確認することがありますが、試問の意図を考え簡潔明瞭にご回答ください」とも書かれています。経歴の説明は求められる場合に備えて短くまとめ、質問の意図に対して結論から答える練習が中心になります。口頭試験は東京都で実施され、日時と会場は筆記試験の合格通知とあわせて届きます。遠方から受験する人は、移動と宿泊の手配も準備の一部です。

### 令和8年度の改訂コンピテンシー

「技術士に求められる資質能力（コンピテンシー）」は、令和5年1月25日の文部科学省 科学技術・学術審議会 技術士分科会で改訂され、令和8年度の第二次試験から改訂後の内容に基づいて実施されます。案内には、筆記試験・口頭試験の試験内容に変更はないと明記されています。

口頭試験の4つの試問事項に関わる主な改訂点は次のとおりです。

- コミュニケーション：情報技術を活用し、多様な関係者と「明確かつ包摂的な意思疎通を図り、協働する」ことが明記された
- 技術者倫理：影響を予見する対象が「社会、経済及び環境」となり、法令等の遵守に加えて「文化的価値を尊重すること」が加わった。「次世代にわたる社会の持続可能な成果の達成」を目指すことも示された
- 継続研さん：CPDを、新しい技術とともに変化し続ける仕事の性質に適応する能力を高めるものとして位置づけた
- 問題解決（主に筆記で問われる）：データ・情報技術の活用、多角的な視点、ステークホルダーの意見の取り入れが明記された

これらの言葉を暗記して口にする必要はありません。自分の業務の中で、データを使って判断した場面、立場の違う人を巻き込んだ場面、社会・経済・環境への影響を先に考えた場面を1つずつ用意しておくと、改訂後の評価軸に沿った答えになります。

### 質問の起点は「業務内容の詳細」720字以内

申込み時に提出した業務内容の詳細は、「目的」「立場と役割」「技術的内容及び課題」「技術的成果」などを、「専門とする事項」を踏まえて720字以内（図表は不可、半角文字も1字）で整理したものです。試験官はこの記述と筆記試験の記述式答案を手元に置いて質問します。書いた内容と話す内容がずれると、そのずれが深掘りの入口になります。

## 2. 部門が違っても変わらない準備、部門で変わる準備

口頭試験の試問事項と配点は、20部門で同じです。一方で、試験官が「この人は自分の部門の技術士として適格か」を確かめるときの具体的な場面は、部門ごとに違います。準備を2つに分けると、他部門向けの教材でも迷わず使えます。

### 部門を問わず同じもの

- 4つの試問事項と配点、20分という時間
- 業務内容の詳細を「立場・課題・判断・成果」の4段で話す型
- 技術士法の3つの義務と2つの責務、公益確保を優先する姿勢
- CPDを実績の羅列ではなく、変化への適応として語る考え方
- 結論から答え、深掘りに備える話し方

### 部門で変わるもの

- 関係者の顔ぶれ：誰と調整し、誰に説明したか
- 成果の指標：何の数値で成果を示すか
- 倫理が問われやすい場面：どんな利害の対立が起きやすいか
- CPDの題材：どの技術・制度の変化に追いついてきたか

次に、受験者数の多い部門を中心に、この4点の当てはめ例を短く示します。あくまで例なので、自分の業務の事実に置き換えてください。

**建設部門の例**

- 関係者：発注者、地元住民、関係機関、協力会社
- 成果の指標：工期、事業費、安全性、供用開始時期
- 倫理の場面：工期やコストの圧力と、安全・品質の確保との対立
- CPDの題材：インフラの老朽化対策、建設現場のデジタル化

**上下水道部門の例**

- 関係者：水道・下水道の事業体、利用者、道路管理者、施工者
- 成果の指標：断水や通水制限の時間、管路の更新延長、耐震化の進み具合、維持管理費
- 倫理の場面：料金や財政の制約と、安全な水の供給・衛生の確保との対立
- CPDの題材：施設の老朽化と更新計画、災害時の事業継続、広域化

**電気電子部門の例**

- 関係者：設備の利用部門、保守部門、メーカー、電力の供給側
- 成果の指標：停電や停止の時間、故障の件数、電力使用量の削減、更新費用
- 倫理の場面：稼働を止めたくない利用部門の要望と、点検・更新による安全確保との対立
- CPDの題材：省エネルギー・脱炭素、設備の監視や制御のデジタル化

**農業部門の例**

- 関係者：土地改良区、農業者、市町村、河川管理者
- 成果の指標：用水の安定供給、受益面積、維持管理の負担、営農への影響
- 倫理の場面：限られた水や予算の配分をめぐる地域内の利害の対立
- CPDの題材：農業水利施設の長寿命化、防災・減災、スマート農業

**機械部門の例**

- 関係者：設計・製造・品質保証の各部門、顧客、協力工場
- 成果の指標：不具合の件数、製造コスト、リードタイム、稼働率
- 倫理の場面：出荷や納期の圧力と、安全性・品質の確認との対立、顧客情報や技術情報の秘密保持
- CPDの題材：設計や生産のデジタル化、安全規格や法令の改正

応用理学・衛生工学・環境・情報工学など、ここに挙げていない部門でも、同じ4点を自分の業務で書き出せば当てはめ例を作れます。

## 3. 筆記合格発表から当日までの準備ロードマップ

令和8年度の筆記試験合格発表は11月上旬（11月4日予定）、口頭試験は12月上旬から令和9年1月中旬のうち、あらかじめ本人に通知される日です。日時の指定や変更はできないため、通知が届いたら受験日から逆算して次の順番で進めます。

### 合格発表直後

- [ ] 業務経歴と業務内容の詳細720字以内を読み返し、何を書いたかを完全に思い出す
- [ ] 第2章の4点（関係者・成果の指標・倫理の場面・CPDの題材）を、自分の業務について書き出す
- [ ] 筆記試験の記述式で書いた内容を、覚えている範囲でメモに残す
- [ ] 通知された日時・会場を確認し、東京までの移動と宿泊を手配する

### 2週目

- [ ] 想定問答バンクの各質問に、自分の業務で答える骨子を作る
- [ ] 改訂コンピテンシーの言葉に対応する場面を、自分の経歴から1つずつ選ぶ
- [ ] 技術士法の義務・責務を条文に沿って説明できるようにする

### 3週目

- [ ] 1問30秒〜1分で、声に出して答える練習をする
- [ ] 業務内容の詳細を第4章の型で2分に組み立て直す
- [ ] 詰まった質問を記録し、骨子を直す

### 前週と前日

- [ ] 可能なら同じ部門の合格者や職場の上司に模擬試問を頼み、20分通しで練習する
- [ ] 新しい論点を増やさず、準備した骨子の見直しに絞る
- [ ] 前日は業務内容の詳細を声に出して読み、早めに休む

他部門の技術士に模擬試問を頼むのも有効です。専門が違う相手に通じる説明になっているかが確かめられ、コミュニケーションの試問事項の練習にもなります。

## 想定問答バンク｜マネジメント・評価

ここからは、4つの試問事項ごとの想定問答です。各質問に「回答の骨子」「落とし穴」を示し、部門によって答えの中身が変わりやすい質問には部門別の当てはめ例を添えています。

この試問事項では、品質・コスト・納期・生産性・リスクの要求を満たすために、人員・設備・金銭・情報といった資源をどう配分したか、そして結果をどう評価して次に生かしたかが問われます。深掘りでは「なぜその優先順位にしたのか」「犠牲にしたものは何か」を繰り返し聞かれると考えておいてください。

**Q1. この業務で、品質・コスト・納期の要求が競合した場面はありましたか。どう資源を配分しましたか。**

回答の骨子：競合した要求を具体的に述べ、どれを優先し、どれで妥協したかを明言します。判断の根拠となった制約条件と、劣後させた要求への手当てを添えます。

落とし穴：優先順位を言わずに「すべてに配慮しました」と答えること。

部門別の当てはめ例：

- 上下水道：更新工事の工期と、断水の影響を小さくする施工方法の費用のどちらを優先したか
- 電気電子：設備更新の停止時間を短くするための仮設設備の費用をどう判断したか
- 機械：試作の追加による納期の遅れと、品質確認の十分さのどちらを取ったか

**Q2. リスクをどのように洗い出し、優先順位をつけましたか。**

回答の骨子：洗い出しの方法（過去事例、関係者への聞き取り、点検データなど）を述べ、影響の大きさと起こりやすさで優先順位をつけた考え方を説明します。最も優先したリスクへの対策で締めます。

落とし穴：リスクを並べるだけで、優先順位の基準が出てこないこと。

**Q3. 業務の途中で計画を見直した経験はありますか。判断の根拠を教えてください。**

回答の骨子：見直しが必要になった状況と、新たに得た情報や制約の変化を述べます。見直し後の計画がどんな効果を上げたかを添えます。

落とし穴：「臨機応変に対応しました」で終わり、判断の根拠がないこと。

**Q4. この業務の成果を、どのような指標で評価しましたか。**

回答の骨子：評価に使った指標を具体的に挙げ、その指標を選んだ理由を説明します。評価の結果と、それを誰にどう報告したかを添えます。

落とし穴：「うまくいきました」という感想で終わること。

部門別の当てはめ例：

- 建設：供用開始の時期、事業費の縮減額、事故ゼロ
- 農業：用水の不足日数の減少、維持管理作業の時間の短縮
- 電気電子：年間の停止時間、電力使用量の削減率

**Q5. 評価の結果を、次の段階や別の業務の改善にどう生かしましたか。**

回答の骨子：得られた教訓を1つに絞り、次の業務でどう反映したかと、その結果の改善を述べます。コンピテンシーの「評価」は、次段階や別業務の改善に資することまでを含みます。

落とし穴：評価と次の業務のつながりが示されないこと。

**Q6. 予算や人員が限られた中で、何を優先し、何を後回しにしましたか。**

回答の骨子：制約の中身を数字で示し、優先した作業と後回しにした作業を明示します。後回しにした作業のリスクをどう管理したかまで話せると、判断に厚みが出ます。

落とし穴：「工夫して乗り切りました」という抽象的な表現にとどまること。

## 想定問答バンク｜コミュニケーション・リーダーシップ

この試問事項では、多様な関係者と明確かつ包摂的に意思疎通を図り協働する力と、関係者の利害を調整して取りまとめる力が問われます。「調整した」と答えれば「具体的にどう調整したか」「譲れなかった一線は何か」と続くのが一般的です。

**Q7. 業務内容の詳細に書いた業務を、2分程度で説明してください。**

回答の骨子：目的と自分の立場を一文で述べ、技術的な課題、比較した案と判断の根拠、成果の順に話します。第4章の型をそのまま使います。

落とし穴：720字の文章を暗唱して時間内に収まらないこと。

**Q8. 利害の異なる関係者を、どのように調整しましたか。**

回答の骨子：対立した関係者と、それぞれの主張を整理して示します。自分がとった具体的な行動（説明の場の設定、代替案の提示など）と、合意に至った理由を添えます。

落とし穴：「話し合いで解決しました」で終わり、調整の手段が見えないこと。

部門別の当てはめ例：

- 上下水道：断水を伴う工事で、利用者・医療機関・道路管理者の要望をどう調整したか
- 農業：用水の配分や施設の更新時期をめぐり、受益者の間の意見をどう取りまとめたか
- 機械：設計変更をめぐる設計部門と製造部門の対立を、どう収めたか

**Q9. 情報技術を活用して、関係者との意思疎通をどう改善しましたか。**

回答の骨子：使った手段（情報共有の仕組み、3次元モデルや図による可視化、遠隔での打合せなど）を具体的に述べ、それによって理解や合意形成がどう変わったかを説明します。

落とし穴：「メールで共有しました」程度で終わり、意思疎通の質の変化に触れないこと。

**Q10. 専門分野の違う相手に、専門用語を使わずに説明した経験はありますか。**

回答の骨子：相手（住民、経営層、他部門の技術者など）を具体的に挙げ、言い換えや資料の工夫、相手の理解をどう確かめたかを述べます。

落とし穴：「分かりやすく説明しました」とだけ答えること。

部門別の当てはめ例：

- 電気電子：停電作業の必要性を、設備を使う側の部門にどう説明したか
- 建設：工事による通行規制の理由を、沿道の住民にどう説明したか

**Q11. あなたが発揮したリーダーシップを、具体的な場面で説明してください。**

回答の骨子：体制と制約を述べ、自分が下した判断・指示・調整を具体的に説明します。その結果、チームや業務にどんな効果があったかを添えます。役職がなくても、論点を整理して関係者を動かした場面はリーダーシップとして語れます。

落とし穴：役職の説明だけで、実際に何を決めたかが伝わらないこと。

**Q12. 意見がまとまらないとき、少数意見をどう扱いましたか。**

回答の骨子：意見が割れた状況を述べ、少数意見を聞き取った方法と、最終案にどう反映したかを説明します。包摂的な協働という改訂の趣旨に沿った答えになります。

落とし穴：「最後は自分が決めました」とだけ述べ、多様な意見を取り入れた過程が見えないこと。

## 想定問答バンク｜技術者倫理

この試問事項では、技術士法の義務と責務の理解と、それが自分の業務でどう具体化されているかが問われます。原則を答えた後に「では実際に上司が反対したらどうするか」と行動まで聞かれることが多いため、自分がどう動くかまで準備します。

**Q13. 技術士法に定める3つの義務と2つの責務を説明してください。**

回答の骨子：3つの義務は、信用失墜行為の禁止（第44条）、秘密保持義務（第45条）、技術士の名称表示の場合の義務（第46条）です。2つの責務は、公益確保の責務（第45条の2）と資質向上の責務（第47条の2）です。列挙した後、自分の業務で特に意識しているものに一言触れます。

落とし穴：名称を言い間違える、または列挙だけで業務との関係に触れないこと。

**Q14. 公益確保の責務は、あなたの業務でどう具体化されていますか。**

回答の骨子：自分の業務が誰の安全・健康・福利に関わっているかを具体的に述べ、それを守るためにとっている行動を1つ挙げます。

落とし穴：「社会のために働いています」という一般論で終わること。

部門別の当てはめ例：

- 上下水道：水質の異常や施設の不具合を把握したときの報告と対応
- 電気電子：感電や火災につながる設備の不具合を見つけたときの停止判断
- 機械：製品の安全上の懸念を、出荷前にどう扱うか

**Q15. 組織の利益と公益が対立したら、どう判断しますか。**

回答の骨子：公益を優先する原則を明言します。そのうえで、データやリスクを示して組織内で説得する手順、必要に応じて上位者や関係機関に相談する道筋を示します。

落とし穴：「上司の指示に従います」と答えること。

**Q16. 業務が社会・経済・環境に与える影響を、どのように予見していますか。**

回答の骨子：自分の業務が影響を及ぼす範囲を、社会・経済・環境の3つに分けて具体的に述べます。影響を予見するために行っていることと、改訂で「経済」が明記された点に触れます。

落とし穴：環境の話だけに偏ること。

**Q17. 秘密保持義務と、関係者への説明責任が両立しにくい場面はありましたか。**

回答の骨子：守るべき情報（顧客の技術情報、個人情報、公表前の計画など）と、説明を求めた相手を具体的に述べます。開示してよい範囲をどう確かめ、誰の了承を得て説明したかを説明します。

落とし穴：「秘密は守ります」とだけ答え、説明責任との折り合いの付け方が見えないこと。

部門別の当てはめ例：

- 機械・電気電子：顧客や協力会社の技術情報を扱いながら、社内外に不具合の原因を説明する場面
- 建設・上下水道・農業：公表前の事業計画について、地域から問い合わせを受けた場面

**Q18. 業務で関わった地域や組織の文化的価値を、どう尊重しましたか。**

回答の骨子：尊重すべき価値（景観、歴史的な施設、地域の慣行、利用者の習慣など）を具体的に述べ、そのために講じた配慮を説明します。改訂で法令等の遵守に「文化的価値を尊重すること」が加わった点に触れます。

落とし穴：法令の遵守だけを話し、文化的価値への配慮が出てこないこと。

## 想定問答バンク｜継続研さん

この試問事項では、CPDの実績を事実で説明できるかと、それを変化への適応としてとらえているかが問われます。「いつ、どれくらい、どう記録しているか」を聞かれても答えられるよう、直近1年程度の取り組みを棚卸ししておきます。

**Q19. 直近で、どのような継続研さんに取り組んでいますか。**

回答の骨子：研修、学会や講習会、資格の学習、社内勉強会などの種類を具体的に挙げ、時間や記録をどう管理しているかに触れます。今後の計画を一言添えます。

落とし穴：学習時間だけを挙げ、得た知識と業務への反映を説明しないこと。

**Q20. 新しい技術や制度の変化に、どう対応してきましたか。**

回答の骨子：最近対応した変化の具体例を挙げ、そのために行った学習と、業務がどう変わったかを説明します。CPDの目的が「変化し続ける仕事の性質への適応」と明確化された点に触れます。

落とし穴：一般論に終わり、具体的な変化の例がないこと。

部門別の当てはめ例：

- 上下水道：施設の耐震化や更新計画、広域化の動きに合わせた学習
- 電気電子：再生可能エネルギーや省エネルギーの技術動向の学習
- 農業：スマート農業や施設の長寿命化の手法の学習
- 機械：設計・生産のデジタル化や安全規格の改正への対応

**Q21. CPDの記録を、どのように管理していますか。**

回答の骨子：記録の方法（所属学協会や日本技術士会のCPD記録、自分の管理表など）と、振り返りの頻度・使い方を述べます。

落とし穴：記録をつけていない、または説明があいまいなこと。

**Q22. 技術士になったら、どの分野の知識を深めたいですか。**

回答の骨子：専門とする事項に関連して深めたい分野を挙げ、業務上の必要性や社会の要請から理由を説明します。

落とし穴：専門と関係のない話をして、業務とのつながりが見えないこと。

**Q23. 若手技術者への技術継承に、どう取り組んでいますか。**

回答の骨子：OJT、勉強会、手引きの整備などの具体的な取り組みを述べ、教えることが自分の研さんにもなっている点に触れます。

落とし穴：「指導しています」とだけ答えること。

**Q24. 他部門や他分野の知識を取り入れた経験はありますか。**

回答の骨子：自分の部門の外から取り入れた知識（情報技術、環境、法務、経営など）と、それが業務の判断をどう変えたかを述べます。部門をまたぐ課題が増えていることを、変化への適応として語れます。

落とし穴：「本を読みました」で終わり、業務への反映がないこと。

## 4. 業務内容の詳細720字以内を口頭2分に組み立て直す型

720字の文章をそのまま読むと2分を超えることが多く、読み上げ調になって質問への反応も遅れます。次の4段の見出しだけをメモに書き、各段で話す中身を声に出して確かめてください。

1. 立場（10〜15秒）：何のための業務で、自分がどの権限と責任を持っていたか
2. 課題（20〜30秒）：直面した技術的な問題と、自分が取り組むと決めた課題を1つ
3. 判断（40〜50秒）：比較した案、採らなかった理由、選んだ理由
4. 成果（20〜30秒）：数値や事実で示す成果と、その後につながったこと

部門別に4段を当てはめると、次のようになります。いずれも説明のための架空の例です。

- 上下水道：立場＝管路更新計画の担当。課題＝断水の影響が大きい幹線の更新順序。判断＝更新の緊急度と断水の影響を点数化して複数案を比較。成果＝計画期間内の更新延長を確保しつつ、断水の回数を抑えた
- 電気電子：立場＝受変電設備の更新の設計担当。課題＝工場を止められる時間が限られる中での切替手順。判断＝仮設設備を使う案と段階的に切り替える案を比較。成果＝停止時間を計画内に収めた
- 農業：立場＝用水路の改修計画の担当。課題＝営農期間中は工事ができないこと。判断＝非かんがい期に工区を分ける案と仮設水路の案を比較。成果＝用水の供給を止めずに改修を終えた
- 機械：立場＝搬送装置の設計改良の担当。課題＝特定部品の摩耗による停止の多発。判断＝材質変更と構造変更の案を寿命試験のデータで比較。成果＝停止の件数を減らし、保守費用を下げた

この型で組み立てられない業務は、深掘りにも耐えにくいと考えてください。想定問答の練習に入る前に、まず自分の経歴を1回この4段で組み立てることをおすすめします。

## 5. 落ちる回答の型と、部門の違いで起きやすい失敗

部門を問わず評価を落としやすい回答には、共通する型があります。

1. 結論が後回し：状況の説明から入り、最後まで聞かないと答えが分からない
2. 暗唱：業務内容の詳細を読み上げるだけで、「なぜそう判断したか」に自分の言葉で答えない
3. 抽象的：「バランスを取りました」のように、数値・条件・手段が出てこない
4. 立場があいまい：自分がどこまでの権限で何を判断したかが伝わらない
5. 一貫性の崩れ：マネジメントの回答と倫理の回答で、優先順位の考え方が矛盾する

これに加えて、部門の違いから起きやすい失敗が2つあります。

1つ目は、部門の専門用語や社内の略語のまま説明してしまうことです。試験官は同じ技術部門の技術士ですが、選択科目や業界が違えば細かな用語は通じないことがあります。コミュニケーションの試問事項でもあるので、専門外の技術士にも通じる言葉で話す練習をしておきます。

2つ目は、企業内の業務で「立場と役割」が見えにくくなることです。製造業や設備の保守では、発注者と受注者のような分かりやすい関係がなく、「チームでやりました」という答えになりがちです。自分が判断した範囲と、判断の結果に責任を持った範囲を、はっきり線引きして話してください。

## 6. 当日チェックリストと20分の使い方

経歴の説明に1〜2分を使っても、残りの大半は質疑です。1問に長く答えると他の試問事項を確かめる時間が減るため、各質問は30秒〜1分を目安に結論から答えます。

- [ ] 業務内容の詳細を見返せる状態にしたか
- [ ] 4つの試問事項それぞれで、1分以内に骨子を答えられるか
- [ ] 技術士法の義務・責務を条文の順に説明できるか
- [ ] CPDの実績を、直近の具体例つきで説明できるか
- [ ] 筆記試験の記述式で書いた内容の要旨を振り返ったか
- [ ] 通知された日時・会場・持ち物を確認したか

分からない質問が来たら、黙り込むより「少し考えさせてください」と断って数秒考えるほうが、あいまいな答えを重ねるより印象がよいことが多いです。緊張で早口になる人は、結論を言った直後に一呼吸置くと、理由を落ち着いて話せます。
