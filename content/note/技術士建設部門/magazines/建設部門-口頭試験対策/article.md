# 技術士 建設部門｜口頭試験対策 — 令和8年度 改訂コンピテンシー対応の想定問答バンクと合格発表後の準備ロードマップ

**こんな人におすすめ**

- 技術士第二次試験 建設部門の筆記試験に合格し、口頭試験の対策をこれから始める人
- 口頭試験で何を、どの資質（コンピテンシー）で問われるのか全体像をつかみたい人
- 想定問答を自分の言葉で準備するための型がほしい人
- 令和8年度の改訂コンピテンシーが口頭試験にどう影響するか知りたい人

**この記事でわかること**

- 口頭試験の全体像と、業務経歴票「業務内容の詳細」720字が質問の起点になる理由
- 筆記試験の合格発表後から口頭試験当日までの準備ロードマップ
- 4つのコンピテンシーの束（コミュニケーション・リーダーシップ／評価・マネジメント／技術者倫理／継続研さん）ごとの想定問答バンク
- 経歴票720字を口頭で2分に圧縮する型と、落ちる回答の型5つ

筆者は技術士（建設部門・総合技術監理部門）に自分自身が合格し、口頭試験を実際に受けた当事者です。あわせて地方自治体の土木職員として工事の発注・監督・積算審査に従事してきた発注者の立場から、多くの技術者の説明を聞いてきました。ただし試験官を務めた経験はありません。本記事の想定問答は、公開されている出題傾向とコンピテンシーの評価軸をもとに運営者が独自に作成したものであり、実際に出題された質問をそのまま再現したものではなく、合格を保証するものでもありません。この前提を踏まえたうえで、準備の材料としてお使いください。

本記事で扱うのは、総合技術監理部門を除く一般部門（建設部門を含む）の口頭試験です。総合技術監理部門は5つの管理という別の評価軸が加わるため、業務経歴の語り方や想定問答の内容がかなり異なります。総監の口頭試験対策は別記事で扱っているため、建設部門をはじめとする一般部門の受験者は本記事を、総監の受験者は総監向けの記事を参照してください。

## 1. 口頭試験の全体像 — 何を、どの資質で問われるか

技術士第二次試験は、専門的学識・問題解決・マネジメント・評価・コミュニケーション・リーダーシップ・技術者倫理・継続研さんという8つのコンピテンシー（資質能力）を評価軸としています。令和8年度の試験からは、このうち問題解決・コミュニケーション・技術者倫理・継続研さんの4項目が改訂され、データ・情報技術の活用、多角的な視点とステークホルダーへの配慮、包摂的な協働、CPDによる変化への適応力が明文化されました。専門的学識・マネジメント・評価・リーダーシップの4項目には実質的な変更がありません。

改訂の背景には、国際エンジニアリング連合（IEA）が定める技術者のコンピテンシー基準への準拠があります。DX・データ活用の進展や、多様な関係者を巻き込んだ協働、持続可能性といった近年の潮流を、技術士に求められる資質能力にも反映させる目的です。口頭試験でこれらのキーワード（データ活用、多角的な視点、包摂的な協働、持続可能な成果、変化への適応）を自分の業務経験と結びつけて語れるかどうかが、改訂後の評価軸に沿った受け答えにつながります。

口頭試験は、筆記試験の論文とあわせて、この8つのコンピテンシーを対話形式で最終確認する場です。試験官の手元には、受験申込み時に提出した業務経歴票「業務内容の詳細」720字があり、この720字が質問の出発点になります。720字は「目的」「立場と役割」「技術的内容及び課題」「技術的成果」の4要素で構成されていて、口頭試験の冒頭で行う経歴説明は、この4要素をそのまま口頭で再現する場面です。720字に書いた内容と口頭で話す内容がずれていると、試験官はそのずれを手がかりに深掘りしてきます。試験時間はおおむね20分程度です。

口頭試験の質問は、1問1答では終わりません。ある質問に答えると、その回答の中の具体的な言葉を手がかりに、さらに一段深い質問が続くという流れが一般的です。たとえば「利害関係者と調整した」と答えれば、「具体的にどう調整したか」「調整の結果、譲歩したのは誰か」というように掘り下げられます。想定問答バンクを練習する際は、1問1答用の回答だけでなく、自分の回答の中の「もう一段掘り下げられそうな言葉」に印をつけ、その先の質問まで想定しておくと、深掘りの連鎖に慌てず対応できます。また、試験官の手元にあるのは業務経歴票だけとは限りません。筆記試験の記述式答案も参照される場合があるため、記述式で示した課題への向き合い方と、口頭試験での説明の間に矛盾がないかも、準備の段階で確認しておく必要があります。

試問事項の正式な名称・時間配分・評価の考え方は年度によって更新されるため、最新の内容は日本技術士会の受験申込み案内で必ず確認してください。本記事では、8つのコンピテンシーのうち口頭試験で対話の材料になりやすい4つを、コミュニケーション・リーダーシップ／評価・マネジメント／技術者倫理／継続研さんという4つの束（コンピテンシーに対応した試問事項）に整理し、それぞれについて想定問答バンクを用意しました。専門的学識・問題解決は主に筆記試験で問われる比重が大きいため、本記事の想定問答バンクでは扱っていません。第4部からは、この4つの束それぞれについて具体的な想定問答をまとめています。コミュニケーション・リーダーシップの束では経歴の2分説明や関係者調整の場面を、評価・マネジメントの束では資源配分やリスクの優先順位づけを、技術者倫理の束では技術士法の義務・責務や改訂で明文化された社会・経済・環境への影響予見を、継続研さんの束ではCPDを「変化への適応」として語る視点を扱います。

建設部門は道路、河川、砂防及び海岸・海洋、都市及び地方計画など複数の選択科目に分かれますが、口頭試験の構造自体はどの選択科目でも共通です。試験官が確認したいのは、選択した専門分野の知識そのものというより、経歴票に書いた業務を通じてコンピテンシーを発揮できているかどうかです。専門分野が違っても、本記事の4つの束と想定問答の使い方は共通して活用できます。

## 2. 筆記合格発表から当日までの準備ロードマップ

口頭試験までの準備期間は、合格発表から本番まで数週間から2ヶ月程度と幅があります。期間の長さにかかわらず、以下の順番を守って準備を進めてください。想定問答の暗記から始めると、経歴票に書いた事実そのものを忘れたまま回答を組み立てることになり、質問の角度が少し変わっただけで対応できなくなります。土台（経歴票の読み返し）→骨組み（想定問答の準備）→仕上げ（声に出す練習）という順番を守ることが、準備期間の長さ以上に重要です。準備期間が短い場合は、各区切りの作業を圧縮して並行して進めてください。それでも、経歴票の読み返しを飛ばして想定問答の暗記から始めることだけは避けてください。

### 合格発表直後

- [ ] 業務経歴票・業務内容の詳細720字を読み返し、自分が何を書いたかを完全に思い出す
- [ ] 4要素（目的・立場と役割・技術的内容及び課題・技術的成果）を、自分の言葉で1分程度で説明できるか声に出して確認する
- [ ] 筆記試験で書いた内容（覚えている範囲）と経歴票の記述に矛盾がないか確認する
- [ ] 日本技術士会の受験申込み案内・口頭試験の実施案内を確認し、試験形式・持ち物・服装の最新情報を把握する

この段階の目的は、想定問答を作ることではなく、申込み時に自分が何を書いたかを完全に思い出すことです。ここが曖昧なまま先に進むと、後の準備全体が的外れになります。

### 2週目

- [ ] 本記事の想定問答バンクを、自分の経歴票の内容に置き換えて回答骨子を作る
- [ ] 令和8年度の改訂コンピテンシー（データ活用・多角的視点・包摂的協働・CPDの適応力）を、自分の経歴のどこに紐づけられるか整理する
- [ ] 技術士法の義務・責務を正確に説明できるようにする

経歴票の再読が終わったら、4つの束それぞれについて、想定される質問と回答の骨子を用意します。回答を一字一句の台本にせず、骨組みだけを頭に入れることが、質問の言い回しが変わっても崩れない準備につながります。この段階では、4つの束のうち手薄になりがちな領域（技術者倫理・継続研さんは後回しにされやすい傾向があります）を、意識して先に着手しておくとよいでしょう。

### 3週目

- [ ] 想定問答バンクの各質問に、声に出して1問あたり30秒〜1分程度で答える練習をする
- [ ] 経歴票720字を、口頭で2分に圧縮する型（第3章）で組み立て直す
- [ ] 詰まった質問・言葉が出てこなかった質問をメモに残し、回答骨子を修正する

頭の中で分かっているつもりでも、声に出すと言葉に詰まる箇所が必ず見つかります。詰まった質問は優先的に繰り返し練習してください。

### 前週

- [ ] 可能であれば第三者に模擬口頭試問の相手を依頼し、本番同様の時間で通しの練習をする
- [ ] 新しい論点を増やすのをやめ、これまで準備した想定問答の見直しに専念する
- [ ] 第5章の当日チェックリストで、持ち物・服装・当日の流れを確認する

一人での練習だけでは気づけない癖や弱点があります。可能であれば、建設部門の合格者や職場の同僚に模擬口頭試問の相手を依頼し、答えにくかった質問を遠慮なく指摘してもらってください。模擬口頭試問を複数回行える場合は、1回目と2回目の間で回答骨子を修正し、変化を確認すると効果的です。

### 前日

- [ ] 経歴票・業務内容の詳細を最終確認し、声に出して読み上げる
- [ ] 会場までの経路・所要時間を確認する
- [ ] 早めに休み、当日に備える

前日に新しい想定問答を増やすと、直前の不安から準備の軸がぶれ、既に固めた回答の質が落ちます。これまでの準備を信じて、早めに休んでください。

## 想定問答バンク｜コミュニケーション・リーダーシップ

この領域では、経歴票に書いた業務を自分の言葉で説明する力と、立場の異なる関係者を調整し取りまとめる力が問われます。改訂コンピテンシーでは、情報技術を活用した意思疎通と、包摂的な協働（一方向の説明ではなく、多様な関係者を巻き込む姿勢）が明文化された点を意識してください。

この束は特に深掘りの連鎖が起きやすい領域です。たとえばQ2で関係者調整の経緯を答えると、「その調整で、最終的に譲れなかった一線は何でしたか」「もし合意できなかったら、次にどう動くつもりでしたか」と続けて問われることがあります。Q5でリーダーシップの発揮を答えた場合も、「その判断に反対した人はいましたか」「その反対にどう向き合いましたか」という形で掘り下げられる可能性があります。1問1答用の回答骨子だけでなく、自分の回答の中の「もう一段掘り下げられそうな言葉」に印をつけ、その先の質問まで用意しておくと、連鎖に慌てず対応できます。

**Q1. 業務経歴票の「業務内容の詳細」720字を、2分程度で説明してください。**

回答の骨子: まず業務の目的と自分の立場を一文で述べます。次に、直面した技術的課題と、比較検討した選択肢、自分が下した判断の根拠を続けます。最後に、成果を数値や事実で示し、それがコミュニケーション・リーダーシップのどちらの発揮につながったかを一言添えて締めます。道路・河川・橋梁いずれの分野でも、この4段の順番自体は変わりません。

落とし穴: 経歴票の文章をそのまま暗唱し、時間内に収まらなくなること。

**Q2.** この業務で、利害の異なる関係者（発注者・住民・協力会社など）をどのように調整しましたか。

回答の骨子: 対立した関係者の立場をそれぞれ整理して示します。次に、自分が仲介・調整のためにとった具体的な行動（説明の場の設定、代替案の提示など）を述べます。最後に、調整の結果として双方がどう納得したか、その調整がリーダーシップの発揮としてどう評価できるかを添えます。

落とし穴: 「話し合いで解決しました」という抽象的な表現にとどまり、調整の具体的な手段が示されないこと。

**Q3. 業務履行の過程で、情報技術を活用してどのように意思疎通を図りましたか。**

回答の骨子: 対面での説明だけに頼らず、どのような情報技術（情報共有システム、可視化資料、遠隔での打合せなど）を使ったかを具体的に述べます。次に、活用によって関係者の理解や合意形成がどう改善したかを説明します。最後に、改訂コンピテンシーで明文化された「情報技術の活用」に触れて締めます。

落とし穴: メールを使った、という程度の一般的な回答にとどまり、情報技術の活用が意思疎通の質をどう変えたかまで踏み込めないこと。

**Q4. 関係者の意見が対立した場面で、どのように合意形成を図りましたか。**

回答の骨子: 対立の構造（誰が何を主張していたか）を簡潔に述べます。次に、一方的な説明ではなく、双方の意見を取り入れながら代替案を提示した経緯を述べます。最後に、包摂的な協働という改訂の趣旨に沿った姿勢と、合意に至った理由を添えます。

落とし穴: 自分の説明で相手を「説得した」という一方向の成功体験としてのみ語り、相手の意見を取り入れた形跡が見えないこと。

**Q5. あなたが発揮したリーダーシップについて、具体的な場面で説明してください。**

回答の骨子: リーダーシップを発揮した場面の状況（人員・組織構成、置かれていた制約）を述べます。次に、自分がどのような判断・指示・調整を行ったかを具体的に説明します。最後に、その結果、チームや業務にどのような効果があったかを添えます。

落とし穴: 役職や立場の説明だけで終わり、実際にどう振る舞い、何を決めたのかが伝わらないこと。

**Q6. 多様な立場・専門分野の関係者に、専門用語を使わずに説明した経験はありますか。**

回答の骨子: 説明した相手（住民、他分野の技術者、発注者内の非技術職など）を具体的に述べます。次に、専門用語をどう言い換えたか、資料をどう工夫したかを説明します。最後に、相手の理解度をどう確認したか（質疑の設け方、資料の見せ方など）を添えます。

落とし穴: 「分かりやすく説明しました」とだけ述べ、具体的な工夫が示されないこと。

**Q7. 説明した内容が相手に十分伝わらなかった経験と、その後どう改善したか教えてください。**

回答の骨子: 伝わらなかった場面を率直に述べます。次に、原因をどう分析したかを説明します。最後に、次の機会にどう改善したかを具体的に添えます。改善の工夫までセットで語れると、コミュニケーション力の伸びしろとして評価されやすくなります。

落とし穴: 失敗の経験を隠し、「特にありません」と答えて学びの姿勢が見えないこと。

**Q8. 経歴票に記載していない業務についても、簡単に教えてください。**

回答の骨子: 経歴票の業務以外の職歴を時系列で1分以内に要約します。次に、コミュニケーションやリーダーシップに関連する部分があれば一言触れます。時系列の説明に終始せず、経歴票との一貫性を保つことを意識してください。

落とし穴: 準備不足で沈黙する、または経歴票外の話を必要以上に広げて時間を使いすぎること。

**Q9. チームの中で意見がまとまらないとき、あなたはどのような役割を果たしますか。**

回答の骨子: 意見がまとまらない典型的な状況を想定して述べます。次に、自分が普段どのような役割（論点整理、少数意見の吸い上げなど）を担っているかを説明します。最後に、その役割が包摂的な協働にどうつながるかを添えます。

落とし穴: 「リーダーとして決断します」とだけ述べ、多様な意見を取り入れるプロセスが見えないこと。

**Q10. 経歴票の5つ以内の業務のうち、この場で最も詳しく話せる自信がある業務はどれですか。理由も教えてください。**

回答の骨子: 業務を1つ選んで結論を先に述べます。次に、選んだ理由（技術的判断とコミュニケーション・リーダーシップの両方が明確に現れている点）を説明します。最後に、他の業務との違いを一言添えて締めます。

落とし穴: 「一番大変だった業務」を基準に選び、コミュニケーション・リーダーシップの観点抜きで技術的な苦労話に終始してしまうこと。

## 想定問答バンク｜評価・マネジメント

この領域では、業務の成果をどう評価し、品質・コスト・工程・リスクといった資源配分をどう判断したかが問われます。評価・マネジメントの評価軸そのものに今回の改訂による変更はありませんが、問題解決の改訂点（データ・情報技術の活用）を踏まえた説明ができると、より一貫した印象を与えられます。

この束では、1つの判断について「なぜその優先順位にしたのか」「もし逆の判断をしていたらどうなっていたか」という形で、根拠を繰り返し掘り下げられる傾向があります。たとえばQ12で経済性管理と工程の優先順位を答えた場合、「その優先順位づけで犠牲にしたものは何ですか」「その犠牲は許容できる範囲だったと、どう判断したのですか」と続けて問われることを想定しておくと、深掘りに動じずに答えられます。評価・マネジメントの束は、経歴説明の束と組み合わせて問われることも多く、1つの業務について両方の観点から交互に質問されることも珍しくありません。

**Q11. この業務の成果を、どのような指標で評価しましたか。**

回答の骨子: 評価に使った指標（数値、期限順守、品質基準など）を具体的に述べます。次に、その指標を選んだ理由を説明します。最後に、評価の結果と、その結果を誰にどう伝えたかを一言で添えます。

落とし穴: 「うまくいきました」という主観的な感想にとどまり、評価の根拠となる指標が示されないこと。

**Q12. 品質・コスト・工程の要求が競合した場面で、資源配分をどう判断しましたか。**

回答の骨子: 競合した要求の具体的な内容を述べます。次に、どの要求を優先し、どの要求で妥協したかを明言します。最後に、その判断の根拠（制約条件、リスクの許容範囲など）と、劣後させた要求への手当てを添えます。

落とし穴: 優先順位を明言せず、すべてに配慮したという両論併記で終えてしまうこと。

**Q13. リスクをどのように洗い出し、優先順位をつけましたか。**

回答の骨子: リスクを洗い出した方法（チェックリスト、過去事例の参照など）を述べます。次に、影響度と発生可能性で優先順位をつけた考え方を説明します。最後に、優先度の高いリスクへの対応策を添えます。

落とし穴: リスクの列挙にとどまり、優先順位をつける基準が示されないこと。

**Q14. 業務の途中で計画を見直した経験があれば、その判断の根拠を教えてください。**

回答の骨子: 計画変更が必要になった状況を述べます。次に、見直しの判断をした根拠（新たに得た情報、制約の変化など）を説明します。最後に、変更後の計画がどのような効果を上げたかを添えます。

落とし穴: 「臨機応変に対応しました」とだけ述べ、判断の根拠が示されないこと。

**Q15. この業務の評価結果を、次の業務にどう生かしましたか。**

回答の骨子: 前の業務で得た評価・教訓を具体的に述べます。次に、次の業務でどう反映したかを説明します。最後に、その結果得られた改善を添えます。

落とし穴: 評価と次の業務の間のつながりが説明されず、単なる経験の羅列で終わること。

**Q16. 予算や人員が制約された状況で、どのようにマネジメントしましたか。**

回答の骨子: 制約の具体的な内容を述べます。次に、制約の中で優先した業務・後回しにした業務を明示します。最後に、その判断が成果にどうつながったかを添えます。

落とし穴: 「工夫して乗り切りました」という抽象的な表現にとどまり、具体的な配分の判断が示されないこと。

**Q17. 業務の進捗管理で、遅延の兆候をどう把握し対応しましたか。**

回答の骨子: 進捗を把握する仕組み（定例会議、工程表の更新頻度など）を述べます。次に、遅延の兆候にどう気づいたかを説明します。最後に、遅延に対して講じた対応策を添えます。

落とし穴: 遅延が起きてから対応した話にとどまり、兆候を事前に把握する仕組みが示されないこと。

**Q18. 複数の候補案を比較検討した経験があれば、判断基準を教えてください。**

回答の骨子: 比較した候補案を簡潔に述べます。次に、比較に用いた基準（データ、コスト、リスクなど）を具体的に説明します。最後に、採用しなかった案を選ばなかった理由を添えます。問題解決の改訂点であるデータ・情報技術の活用にも触れられると、評価の根拠に厚みが出ます。

落とし穴: 結果的に採用した案の説明だけで終わり、比較の過程と判断基準が示されないこと。

**Q19. 成果を評価する際、定量的な根拠をどのように示しましたか。**

回答の骨子: 収集したデータや数値を具体的に述べます。次に、そのデータを使ってどう評価したかを説明します。最後に、評価結果を関係者にどう説明したかを添えます。

落とし穴: 「良い結果が出た」という感想にとどまり、根拠となる数値が示されないこと。

**Q20. マネジメントの観点で、あなたが最も苦手だと感じる場面はどのようなときですか。**

回答の骨子: 苦手な場面（複数の制約が同時に競合する場面など）を率直に述べます。次に、その場面でどのように補っているか（相談、チェックリストの活用など）を説明します。苦手さを隠さず認めたうえで対処法を示す姿勢が、評価につながります。

落とし穴: 苦手分野を隠して「すべて問題ありません」と答え、かえって回答全体の一貫性を疑われること。

## 想定問答バンク｜技術者倫理

この領域では、技術士法に定める義務・責務の正確な理解と、それが自分の業務でどう具体化されているかが問われます。改訂コンピテンシーでは、影響を予見すべき対象が「社会、文化及び環境」から「社会、経済及び環境」に改められ、法令遵守に「文化的価値を尊重すること」が新たに加わりました。あわせて「持続性の確保」が「持続可能な成果の達成」へと表現が更新されています。

技術者倫理の束では、「では、実際にそうした場面に直面したらどうしますか」という仮定の質問が続くことがあります。たとえばQ23で公益優先の原則を答えた場合、「実際に上司がその判断に反対したら、どう説得しますか」という具体的な行動まで掘り下げられることを想定しておいてください。抽象的な原則論だけで終わらせず、自分が実際にどう動くかまで一段落とし込んでおくことが、この束では特に重要です。

**Q21. 技術士法に定める3つの義務と2つの責務を説明してください。**

回答の骨子: 3義務（信用失墜行為の禁止・秘密保持義務・技術士等の名称表示の義務）と2責務（公益確保の責務・資質向上の責務）を簡潔に列挙します。次に、自分が業務上特に意識しているものに一言触れます。用語を正確に言えることは前提として、自分の業務との接続まで話してください。

落とし穴: 名称の一部を言い間違える、または列挙するだけで自分の業務との関連づけがないまま終えること。

**Q22. 公益確保の責務が、あなたの業務でどのように具体化されていますか。**

回答の骨子: 自分の業務で誰の安全・利益を守っているかを具体的に述べます。次に、その責務を意識した具体的な行動を1つ添えます。

落とし穴: 「公共の福祉のために働いています」という一般論のみで終えること。

**Q23. 組織の利益と公益が対立した場合、どう判断しますか。**

回答の骨子: 公益優先の原則を明言します。次に、実際に組織側をどう説得するか（データやリスクの提示など）の道筋を示します。原則論だけでなく、組織内でどう動くかという現実的な手順まで語ってください。

落とし穴: 「組織（上司）の指示に従います」と答え、公益優先の原則に反してしまうこと。

**Q24. 業務の判断が社会・経済・環境に与える影響を、どのように予見していますか。**

回答の骨子: 自分の業務が影響を及ぼす範囲（社会・経済・環境）を具体的に述べます。次に、影響を予見するために行っていること（事前調査、関係者への確認など）を説明します。最後に、改訂で影響予見の対象に「経済」が明記された点にも触れられるとよいでしょう。

落とし穴: 環境影響だけに話が偏り、社会・経済への影響に触れないこと。

**Q25. 法令遵守にあたり、地域の文化的価値をどう尊重しましたか。**

回答の骨子: 業務が関わった地域の文化的価値（景観、歴史的背景など）を具体的に述べます。次に、その価値を尊重するために講じた配慮を説明します。最後に、改訂で法令遵守に「文化的価値を尊重すること」が明文化された点に触れられるとよいでしょう。

落とし穴: 法令の条文遵守の話にとどまり、文化的価値への具体的な配慮が示されないこと。

**Q26. 過去の失敗や反省点から、どのような教訓を得ましたか。**

回答の骨子: 失敗の内容を率直に述べます。次に、その原因をどう分析したかを説明します。最後に、教訓をその後の業務にどう生かしたかを添えます。

落とし穴: 「特にありません」と答え、失敗から学ぶ姿勢が見えない回答をしてしまうこと。

**Q27. 技術士としての信用失墜行為とは、具体的にどのような行為を指しますか。**

回答の骨子: 定義（技術士の信用・品位を損なう行為全般）を述べます。次に、自分の業務に照らした具体例を1つ添えます。

落とし穴: 定義を答えられず沈黙してしまうこと。

## 想定問答バンク｜継続研さん

この領域では、CPD（継続研鑽）の実績を事実ベースで説明できるかが問われます。改訂コンピテンシーでは、CPDの目的が「必要な知見を深める」という資質向上の文脈から、「新しい技術とともに絶えず変化し続ける仕事の性質に適応する能力を高める」という適応力の文脈へと明確化されました。CPDを実績の羅列で終わらせず、変化への適応として語れるように準備してください。

継続研さんの束は、他の3つの束に比べて質問数自体は少ない一方、「それは具体的にいつ、何時間くらい行いましたか」という事実確認の深掘りが起きやすい領域です。たとえばQ28でCPDの取り組みを答えた場合、頻度や時間、記録の有無まで具体的に問われることを想定し、あいまいな記憶のまま答えないよう、事前に自分の実績を棚卸ししておいてください。棚卸しの際は、直近1年程度に絞って構いません。古い実績まで無理に思い出そうとするより、直近の取り組みを具体的に語れることの方が評価されます。

**Q28.** 継続研鑽（CPD）として、直近でどのような取り組みをしていますか。

回答の骨子: 具体的な取り組みの種類（研修・学会参加・自己学習など）を述べます。次に、時間や記録をどう管理しているかに触れます。最後に、今後の計画を一言添えます。

落とし穴: 「特に何もしていません」と答える、あるいは資格取得のための勉強のみをCPDとして挙げてしまうこと。

**Q29. CPDの記録をどのように管理していますか。**

回答の骨子: 記録の方法（日本技術士会のCPD記録の仕組み、自己管理シートなど）を具体的に述べます。次に、記録を振り返る頻度や活用方法を説明します。

落とし穴: 記録をつけていない、または漠然とした説明で終わること。

**Q30. 新しい技術や制度の変化に、どのように対応していますか。**

回答の骨子: 最近対応した変化の具体例（新しい基準、デジタル技術など）を述べます。次に、対応するために行った学習・情報収集を説明します。最後に、CPDの目的が「変化し続ける仕事の性質への適応」へと改訂された点に触れられるとよいでしょう。

落とし穴: 変化への対応を一般論で語り、具体的な事例が示されないこと。

**Q31. 今後、どのような分野の知識を深めたいと考えていますか。**

回答の骨子: 自分の専門分野に関連して、今後深めたい知識・技術を具体的に述べます。次に、そう考えた理由（業務での必要性、社会的な要請など）を説明します。

落とし穴: 専門分野と無関係な話をして、業務との接続が見えないこと。

**Q32. 技術士としての資質を維持・向上させるために、日常的に行っていることはありますか。**

回答の骨子: 日常的な取り組み（業界誌の購読、社内勉強会の主催など）を具体的に述べます。次に、その取り組みを継続している理由を添えます。

落とし穴: 資格取得当時の努力だけを語り、現在の継続的な取り組みが示されないこと。

**Q33. 若手技術者への技術継承について、どのように取り組んでいますか。**

回答の骨子: 技術継承の具体的な取り組み（OJT、勉強会、マニュアル整備など）を述べます。次に、その取り組みが自分自身のCPDにもつながっている点を説明します。

落とし穴: 「指導しています」とだけ述べ、具体的な仕組みや工夫が示されないこと。

## 3. 経歴票「業務内容の詳細」720字を口頭で2分に圧縮する型

業務内容の詳細720字は、「目的」「立場と役割」「技術的内容及び課題」「技術的成果」の4要素で構成されています。この4要素を、口頭試験の冒頭で求められる1〜2分程度の説明にそのまま当てはめると、次のような型になります。

1. 立場の提示（10〜15秒）— 何のための業務で、自分がどの権限・責任を担ったかを一文で述べる
2. 課題の提示（20〜30秒）— 直面した技術的な問題と、その中で自分が取り組むと決めた課題を1つに絞って述べる
3. 判断と工夫（40〜50秒）— 比較した案、採らなかった理由、最終的に選んだ理由まで含めて筋道を説明する
4. 成果と評価（20〜30秒）— 数値や事実に基づく成果と、その成果が今後にどうつながったかを短く添える

720字の文章をそのまま読み上げると2分を超えることが多いため、練習段階では「立場」「課題」「判断」「成果」の4つの見出しをメモに書き出し、各見出しについて何を話すかを声に出して確認してください。文章を一字一句覚えるのではなく、4つの見出しの順番と、それぞれで話す内容の骨組みを覚えることが、質問の角度が変わっても崩れない話し方につながります。

たとえば、河川改修工事の詳細設計を担当した業務であれば、「立場」は「詳細設計の照査を担当する立場」、「課題」は「氾濫計算の条件設定をどう決めるか」、「判断と工夫」は「複数の水理計算条件を比較し、実績降雨データを踏まえて安全側の条件を採用した経緯」、「成果」は「計画高水位に対する余裕高を数値で確保できたこと」というように、4つの見出しに沿って要素を当てはめていきます。道路の詳細設計であれば「立場」は設計協議の窓口、「課題」は交差点部の線形条件、「判断と工夫」は複数案の比較と関係機関協議、「成果」は事業費・安全性の両立といった具合に、業務の種類が変わっても同じ4段の型で組み立てられます。自分の経歴票についても、同じように4つの見出しへ要素を書き出してみてください。

この型は、想定問答バンクのQ1（720字を2分程度で説明する質問）にそのまま使えます。逆に言えば、この型で720字を組み立て直せないうちは、Q1以降の深掘り質問にも対応できません。第4部以降の練習に入る前に、まずこの4段構成で自分の経歴を1回組み立ててみることをおすすめします。発注者としての業務（設計審査、積算審査、事業計画など）であっても、施工・設計を担う受注者側の業務であっても、この4段の型自体は同じように使えます。

## 4. 落ちる回答の型5つ

口頭試験で評価を落としやすい回答には、共通する型があります。想定問答バンクを練習する際、自分の回答が次のいずれかに当てはまっていないか確認してください。

1. 結論を後回しにする — 状況説明から入り、最後まで聞かないと何を言いたいのか分からない回答
2. 経歴票の文章を暗唱するだけ — 「なぜそう判断したのか」という理由の部分に自分の言葉で答えていない回答
3. 抽象的な言葉で終える — 「バランスを取りました」「しっかり対応しました」のように、具体的な数値・条件・手段が示されない回答
4. 立場と判断範囲が曖昧 — 「担当者として頑張りました」のように、自分がどこまでの権限で何を判断したのかが伝わらない回答
5. 一貫性が崩れる — 経歴説明での回答と、倫理・CPDに関する回答の間で、優先順位の考え方が矛盾してしまう回答

たとえば、道路の詳細設計業務で工期短縮を実現した場面を考えてみます。「施工手順を見直し、工期を2週間短縮しました」という説明は、技術的な対応としては正しいものの、それだけでは型2（暗唱するだけ）や型3（抽象的）に近い印象を与えかねません。「工期短縮のため、施工手順の見直しと仮設計画の再検討という2つの案を比較し、後工程への影響とコストの両面から仮設計画の見直しを選びました。この判断は、資源配分の優先順位づけという評価・マネジメントの視点に基づいています」というように、比較した案と判断の根拠、コンピテンシーとの対応まで含めて語ると、同じ工期短縮の実績でも伝わり方が変わります。

これらはいずれも、720字の作り込みの段階（第3章の4要素）に立ち返って自分の業務を整理し直すことで防げます。特に5番目の一貫性の崩れは、準備を4つの束ごとに分けて進めているうちに起こりやすい失敗です。想定問答バンクの練習が一通り終わったら、4つの束をまたいで、自分の回答の優先順位の考え方が矛盾していないかを最後に通しで確認してください。

## 5. 当日チェックリストと20分の時間感覚

口頭試験はおおむね20分程度で行われます。冒頭の経歴説明に1〜2分を使ったとしても、残りの時間の多くは対話形式の質疑に充てられると考えておいてください。1つの質問に長く答えすぎると、他の論点を確認する時間が削られてしまうため、各質問には30秒〜1分程度を目安に、結論から簡潔に答える意識を持つとよいでしょう。

当日は、次の項目を確認してから会場に向かってください。

- [ ] 業務経歴票・業務内容の詳細を、印刷または手元で見返せる状態にしているか
- [ ] 4つのコンピテンシーの束（コミュニケーション・リーダーシップ／評価・マネジメント／技術者倫理／継続研さん）について、それぞれ1分以内で骨子を答えられるか
- [ ] 技術士法の義務・責務を、正確に説明できるか
- [ ] 自分のCPD実績を、直近の具体例つきで説明できる状態にしているか
- [ ] 筆記試験の記述式で書いた内容の要旨を、覚えている範囲で振り返ったか
- [ ] 会場までの経路・所要時間・当日の持ち物を、受験申込み案内で確認したか
- [ ] 服装・受付開始時刻など、当日の流れを受験申込み案内で確認したか

試問事項の正式名称や時間配分、配点・合格基準の詳細は年度によって更新されるため、直前にもう一度、日本技術士会の受験申込み案内で確認しておくと安心です。20分という時間は、準備なしで臨めば曖昧な回答を重ねるうちにあっという間に過ぎてしまいますが、経歴票を4段の型で組み立て直し、4つの束の想定問答を一通り練習しておけば、どの角度から聞かれても落ち着いて結論から答えられる時間でもあります。

緊張で早口になりやすい人は、結論を述べた直後に一呼吸置く意識を持つと、聞き手にも自分自身にも間が生まれ、次の理由を落ち着いて話しやすくなります。分からない質問が来た場合は、沈黙するよりも「少し考えさせてください」と一言断ってから数秒考える方が、あいまいな回答を重ねるより印象がよいことが多いです。
