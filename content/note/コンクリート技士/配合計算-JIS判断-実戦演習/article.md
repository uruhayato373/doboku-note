# コンクリート技士｜配合計算・JIS判断 実戦演習12問（途中式・全選択肢解説）

![](img/figure-author-authority-concrete.png)

この教材は、技術士（総合技術監理部門）を持つ元・地方自治体の土木職（発注者）がつくっています。コンクリート主任技士・コンクリート診断士にも自分で合格しており、小論文・記述式を書いた当事者です。

総監の5つの管理の視点で記述を分析し、発注者として施工計画書や工事成績評定の書類を審査してきた目で「評価される書き方」を整理しています。

**こんな人のための記事です**

- テキストを読めば分かるのに、計算問題になると式を選べない
- 表面水、吸水、絶対容積、細骨材率を同じ解法フローで整理したい
- JISに関する選択肢で、数値の暗記以前に「何を確認する規定か」を見失う
- 正答番号だけでなく、誤答が生まれる計算ミスと判断ミスを潰したい

**この記事でわかること**

- 水結合材比、絶対容積、表面水、吸水、練混ぜ量を一定の手順で計算できます
- 質量と体積、表乾基準と絶乾基準、配合値と現場計量値を区別できます
- 呼び方、試料採取、フレッシュ試験、強度試験、塩化物、記録の役割を説明できます
- 12問すべてで、正答だけでなく残り3肢が誤りになる理由を確認できます

コンクリート技士の択一で難しいのは、公式そのものより「今扱っている数値の基準」です。表乾質量を現場の湿潤質量へ直すのか、絶乾質量から吸水分を求めるのか。材料の質量を絶対容積へ直すのか、絶対容積から質量へ戻すのか。基準を一度取り違えると、計算はきれいに進んでも誤答へ到達します。

JIS判断も同じです。規格番号や限界値を断片的に覚えるだけでは、呼び方、製造、試験、検査のどの場面を問われているかが曖昧になります。本教材では、適用する最新版の規格本文を確認する前提で、技士試験に必要な判断の順序を問題化しました。

全12問は、本教材のために作成した発展演習です。実在過去問やJIS本文の逐語再現ではありません。無料サイトの基礎48問から条件を複合化した計算6問と、異常時対応まで問う品質・JIS判断6問を収録し、各問に途中式または判断手順と、全選択肢の理由を付けています。

**計算編**

## 解く前の6ステップ

1. 求めるものが質量、体積、百分率、判定のどれかを囲む
2. 表乾、絶乾、湿潤のどれを基準にした数値か確認する
3. 密度の単位をkg/Lまたはkg/m³へそろえる
4. 百分率を小数へ直してから式へ入れる
5. 1m³の容積収支では、水・結合材・骨材・空気の合計を確認する
6. JIS判断では、注文、製造、試験、検査、記録のどの段階かを先に決める

## 実戦問題1｜水結合材比と混合材の質量

単位水量174kg/m³、水結合材比48.0%のコンクリートで、結合材の25%を高炉スラグ微粉末とする。セメント量と高炉スラグ微粉末量の組合せとして、最も近いものはどれか。

1. セメント272kg/m³、高炉スラグ微粉末91kg/m³
2. セメント363kg/m³、高炉スラグ微粉末91kg/m³
3. セメント272kg/m³、高炉スラグ微粉末68kg/m³
4. セメント130kg/m³、高炉スラグ微粉末44kg/m³

### 正答と解説

**正答：1**

まず結合材の合計量を求めます。

$$
B = 174 / 0.48 = 362.5\,\mathrm{kg/m^3}
$$

高炉スラグ微粉末は `362.5×0.25=90.625kg/m³`、セメントは `362.5×0.75=271.875kg/m³`。丸めると272kg/m³と91kg/m³です。

選択肢2はスラグを置換ではなく追加し、結合材合計を超えています。選択肢3は、セメント272kgを結合材合計と誤認し、その25%をスラグ量とした値です。選択肢4は単位水量174kgを結合材合計と誤認し、それを75%と25%へ配分した値です。

**誤答原因：** 結合材の合計量を先に確定せず、セメントと混合材を別々に計算すること。

## 実戦問題2｜容積収支と細骨材率

水172kg/m³、セメント344kg/m³、空気量4.5%、細骨材率43.0%とする。セメント、細骨材、粗骨材の密度をそれぞれ3.15、2.60、2.68kg/Lとしたとき、細骨材量と粗骨材量の組合せとして最も近いものはどれか。

1. 細骨材754kg/m³、粗骨材1031kg/m³
2. 細骨材1031kg/m³、粗骨材754kg/m³
3. 細骨材290kg/m³、粗骨材385kg/m³
4. 細骨材675kg/m³、粗骨材675kg/m³

### 正答と解説

**正答：1**

骨材以外の絶対容積は、水172L、セメント `344÷3.15=109.2L`、空気45Lです。したがって全骨材絶対容積は次のとおりです。

$$
V_A = 1000 - 172 - 109.2 - 45 = 673.8\,\mathrm{L}
$$

細骨材絶対容積は `673.8×0.43=289.7L`、粗骨材絶対容積は384.1L。質量へ戻すと、細骨材は `289.7×2.60=753.2kg`、粗骨材は `384.1×2.68=1029.4kg`で、最も近いのは選択肢1です。

選択肢2は細・粗骨材を逆にしています。選択肢3は絶対容積Lを質量kgと取り違えています。選択肢4は細骨材率を質量比50%として扱っています。

**誤答原因：** 細骨材率を質量比と考えること。分母・分子は骨材の絶対容積です。

## 実戦問題3｜細・粗骨材の表面水補正

表乾基準の配合が、水170kg/m³、細骨材760kg/m³、粗骨材980kg/m³である。細骨材の表面水率が3.5%、粗骨材の表面水率が0.8%のとき、現場計量値の組合せとして適当なものはどれか。

1. 細骨材786.6kg、粗骨材987.8kg、水135.6kg
2. 細骨材733.4kg、粗骨材972.2kg、水204.4kg
3. 細骨材786.6kg、粗骨材987.8kg、水170.0kg
4. 細骨材760.0kg、粗骨材980.0kg、水135.6kg

### 正答と解説

**正答：1**

細骨材は `760×1.035=786.6kg`、粗骨材は `980×1.008=987.84kg`を計量します。持込み水は細骨材26.6kg、粗骨材7.84kgです。

$$
W = 170 - 26.6 - 7.84 = 135.56\,\mathrm{kg}
$$

選択肢2は骨材質量と水量の増減を逆にしています。選択肢3は骨材が持ち込む水を差し引いていません。選択肢4は水だけを減らし、所要の骨材固形分を確保するための湿潤質量補正をしていません。

**誤答原因：** 表面水補正を水だけの操作と考えること。骨材は増量し、水は減量します。

## 実戦問題4｜気乾骨材の不足吸水量

粗骨材の絶乾質量が1000kg、吸水率が1.6%、使用時の含水率が0.7%である。この骨材を表乾状態基準の配合に用いるとき、表乾までに不足する水量として適当なものはどれか。

1. 7kg
2. 9kg
3. 16kg
4. 23kg

### 正答と解説

**正答：2**

吸水率と含水率はいずれも絶乾質量を基準とします。表乾までの不足分は `1.6%-0.7%=0.9%` なので、`1000×0.009=9kg`です。

選択肢1は現在の含水量だけを答えています。選択肢3は吸水率1.6%の全量で、すでに含んでいる水を差し引いていません。選択肢4は吸水量と現在含水量を加えています。

**誤答原因：** 「吸水率」と「現在の含水率」の差を取らず、どちらか一方だけを使うこと。

## 実戦問題5｜絶対容積から空気量を求める

1m³のコンクリートに、水168kg、セメント336kg、細骨材790kg、粗骨材1010kgを用いる。各材料の密度を、水1.00、セメント3.15、細骨材2.61、粗骨材2.69kg/Lとするとき、空気量として最も近いものはどれか。

1. 3.2%
2. 4.7%
3. 6.1%
4. 47.0%

### 正答と解説

**正答：2**

材料の絶対容積を合計します。

$$
168 + 336/3.15 + 790/2.61 + 1010/2.69 = 952.8\,\mathrm{L}
$$

空気は `1000-952.8=47.2L`。1m³中の47.2Lは約4.72%です。

選択肢1と3は、密度または体積差の計算を誤った値です。選択肢4は空気のリットル値をそのまま百分率としています。

**誤答原因：** 密度で割って体積へ直す前に質量を合計すること、または空気のLを10で割らず%にすること。

## 実戦問題6｜1バッチ量への換算

1m³当たりの配合が、水166kg、セメント332kg、細骨材770kg、粗骨材1020kgである。練混ぜ量2.75m³の1バッチに必要な水とセメントの組合せとして適当なものはどれか。

1. 水60.4kg、セメント120.7kg
2. 水166kg、セメント332kg
3. 水456.5kg、セメント913kg
4. 水622.5kg、セメント913kg

### 正答と解説

**正答：3**

1m³当たりの単位量へ練混ぜ量を掛けます。水は `166×2.75=456.5kg`、セメントは `332×2.75=913kg`です。

選択肢1は2.75で割っています。選択肢2は1m³の単位量のままです。選択肢4は細骨材など別材料の数値を混同した値です。

**誤答原因：** 「単位量」が1m³当たりであることを忘れ、バッチ容量で割ること。

## 実戦問題7｜呼び方と注文条件

レディーミクストコンクリートの注文・受入れに関する記述として、適当なものはどれか。

1. 呼び強度が同じなら、スランプ、粗骨材最大寸法、セメント種類は確認しなくてよい。
2. 納入書では、発注した呼び方、配合・材料条件、出荷時刻などを照合する。
3. 呼び方は圧縮強度試験後に初めて決める。
4. 粗骨材最大寸法は部材形状や配筋と無関係である。

### 正答と解説

**正答：2**

選択肢2が適当です。注文したコンクリートと納入された荷が一致するかを、呼び方と指定事項、発時刻などの時間情報から確認します。

選択肢1は、同じ呼び強度でも施工性や材料条件が異なる点を見落としています。選択肢3は順序が逆で、必要性能と施工条件から注文時に指定します。選択肢4は、粗骨材最大寸法が配筋間隔、部材寸法、ポンプ圧送などへ影響するため誤りです。

**判断手順：** 強度だけでなく、施工性、材料、寸法、耐久性に関わる指定を一組で照合する。

## 実戦問題8｜試験結果に異常が出たときの初動

同じ荷から採取したスランプ試験の結果が、直前の管理値から大きく外れた。最初に行う対応として、最も適当なものはどれか。

1. 結果を記録から削除し、直前の値を転記する。
2. 試料の代表性、採取・試験手順、経過時間、温度、荷の識別を確認し、適用手順に従って再確認する。
3. 原因を調べず、全荷を自動的に合格とする。
4. 試験値を所定範囲へ合わせるため、採取後の試料へ水を加える。

### 正答と解説

**正答：2**

選択肢2が適当です。異常値を直ちに都合のよい値へ置き換えず、荷・試料・操作・時間・温度を切り分けて、結果が製品変動か試験変動かを確認します。

選択肢1は記録の信頼性を失い、選択肢3は適合性を確認していません。選択肢4は試料を改変するため不適当です。

**判断手順：** 止める、識別する、手順を確認する、必要な再確認を行う、影響範囲を判断する。

## 実戦問題9｜スランプ低下の原因分解

出荷時と比べて荷卸し時のスランプが大きく低下した。原因確認の組合せとして、最も適当なものはどれか。

1. 経過時間、コンクリート温度、骨材含水率、混和剤、運搬中の管理を確認する。
2. 呼び強度だけを確認し、時間と温度は見ない。
3. スランプ低下は常にセメント不足だけが原因と判断する。
4. 荷ごとの記録を比較せず、外観だけで原因を確定する。

### 正答と解説

**正答：1**

選択肢1が適当です。スランプの時間変化は、温度、水分補正、混和剤の適合・添加、運搬時間、攪拌など複数要因で生じます。

選択肢2は主要変動因子を除外し、選択肢3は原因を一つへ決めつけています。選択肢4では再現性のある原因分析ができません。

**判断手順：** 出荷時と荷卸し時の差を、材料、配合、温度、時間、運搬、試験の順で比較する。

## 実戦問題10｜ポンプ圧送前後の空気量

AEコンクリートをポンプ圧送したところ、筒先で空気量が荷卸し時より小さくなった。評価として、最も適当なものはどれか。

1. 圧送条件、配管、吐出状態、試料採取・試験条件を確認し、凍結融解抵抗性と強度への影響を判定する。
2. 空気量は圧送で変化しないため、測定結果を無視する。
3. 筒先の空気量が小さいほど、凍結融解抵抗性は無条件に高くなる。
4. 空気量を戻すため、筒先の試料へAE剤を直接加える。

### 正答と解説

**正答：1**

選択肢1が適当です。圧送に伴う空気量変化は実際の打込み位置の品質へ関わるため、測定と工程条件を結び付けて評価します。

選択肢2は変動可能性を否定し、選択肢3は連行空気の役割を逆にしています。選択肢4は代表試料を改変する不適切な行為です。

**判断手順：** 荷卸し時と筒先を同じ条件で比較し、規定への適合だけでなく使用環境で必要な空気量を確認する。

## 実戦問題11｜強度試験が基準を下回ったとき

標準養生供試体の圧縮強度が判定基準を下回った。原因調査として、最も適当なものはどれか。

1. 材料・計量・練混ぜ記録、荷の識別、採取・成形・養生・試験条件を確認し、構造物への影響を別途評価する。
2. 供試体を廃棄し、結果を無かったことにする。
3. 原因にかかわらず、直ちにセメント量だけを増やす。
4. 供試体の取扱いだけを疑い、製造記録は確認しない。

### 正答と解説

**正答：1**

選択肢1が適当です。製品側の強度不足と試験側の異常を切り分け、影響範囲と構造物の品質を評価します。

選択肢2は不適合の隠蔽、選択肢3は原因分析を飛ばした対症対応です。選択肢4は工程と試験の両方を確認できません。

**判断手順：** 結果を隔離・記録し、試験過程、製造過程、対象範囲、構造物への影響、是正の順で確認する。

## 実戦問題12｜塩化物管理とトレーサビリティー

塩化物含有量と製造記録の管理として、不適当なものはどれか。

1. 材料由来の塩化物とフレッシュコンクリートの測定結果を、適用条件に照らして管理する。
2. 測定機器の点検・校正と、試料採取・測定時刻の記録を行う。
3. 基準から外れた結果が出ても、荷や材料ロットを特定できなくてよい。
4. 異常時は出荷・施工への影響を止め、原因、対象範囲、是正、再発防止を記録する。

### 正答と解説

**正答：3**

選択肢3が不適当です。異常が起きたときに対象を限定し、原因を追跡し、処置の妥当性を確認するため、荷・材料・設備・測定結果を結び付ける記録が必要です。

選択肢1、2、4は適当です。塩化物は測定値だけでなく、試料の代表性、機器の状態、時間情報、材料ロットを含めて管理します。

**判断手順：** 規定値の暗記だけでなく、測る、照合する、止める、範囲を特定する、直す、再発を防ぐという管理の流れで考える。

## 3周復習のやり方

1周目は時間を決めて12問を通し、計算編と判断編の正答率を分けて記録します。2周目は選択肢を隠し、途中式または判断手順を白紙から再現してください。

3周目は、誤りの選択肢を一文だけ直して正しい記述へ変えます。「水を増やす」を「水を減らす」へ変えるだけでなく、なぜその方向になるかまで声に出すと、似た新問にも対応できます。
