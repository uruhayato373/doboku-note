技術士第二次試験 建設部門の道路科目（選択科目II・III）について、令和1〜7年度（R01〜R07）の全出題テーマを年度別・設問種別に整理しました。**舗装と道路法改正が7年連続**で II-1 に出題されているほか、**地盤・土構造物も II-1-4 に7年連続**と、II-1 は出題カテゴリがほぼ固定されています。令和8年度の出題予想も掲載しています。

## 試験の設問構成

道路科目（選択科目0907）の設問構成は以下のとおりです。

| 設問 | 出題数 | 解答数 | 解答字数 | 答案用紙 |
|------|--------|--------|---------|--------|
| II-1 | 4問 | 1問選択 | 600字 | 1枚 |
| II-2 | 2問 | 1問選択 | 1,200字 | 2枚 |
| III | 2問 | 1問選択 | 1,800字 | 3枚 |

II-1は専門知識（説明・概要・手法）、II-2は応用能力（計画立案の担当責任者として）、IIIは課題遂行能力（現状の課題分析〜解決策の提案）を問います。

## テーマ別 出題傾向の分析

### 舗装（II-1-3 に7年連続で出題）

**最も安定した頻出テーマ**です。R01〜R07 の全7年間、II-1 の第3問（II-1-3）として毎年出題されています。

<Callout type="point">
**舗装 出題の流れ（7年分）**
- R01: コンクリート系舗装（連続鉄筋コンクリート・転圧コンクリート）の**構造比較**
- R02: 舗装の**必須性能指標**（構造に関する技術基準）
- R03: 舗装点検要領と**使用目標年数**の設定
- R04: 再生加熱アスファルト混合物の**製造方法と再資源化課題**
- R05: 新設道路における**舗装種別選定**の流れ
- R06: 早期劣化区間に対する**詳細調査**の目的・手順
- R07: 既設舗装材の**再生利用**の技術的留意事項と今後の方向性
</Callout>

設問の切り口は「構造・設計 → 性能基準 → 維持管理（点検・診断）→ 再生利用 → 更なる資源循環推進」と変化し続けています。**出題ネタが枯渇しないテーマ**で、R08 でも確実に出題されるとみてよいでしょう。BIM/CIM を活用した舗装台帳管理や、3Dデータを活用した路面性状評価が次の有力候補です。

### 道路法改正・関係法令（II-1-2 に7年連続）

最新の法改正・制度を問う設問が II-1-2 に毎年登場します。

<Callout type="point">
**法改正 出題の流れ（7年分）**
- R01: **重要物流道路制度**（平成30年道路法改正）
- R02: **歩行者利便増進道路**（令和2年5月道路法改正）
- R03: **特定車両停留施設**（令和2年5月道路法改正）— R2改正から2問目
- R04: **踏切道改良促進法**（令和3年3月改正）
- R05: **車両移動措置**（災害対策基本法）
- R06: **自動運行補助施設**（令和2年5月道路法改正）— R2改正から3問目
- R07: **令和7年道路法改正**（災害対応の深化）
</Callout>

出題のタイミングは「改正の1〜3年後」が多い傾向です。R02 の道路法改正（歩行者利便増進道路・特定車両停留施設・自動運行補助施設の3制度）から合計3問出題されており、**大改正は複数年にわたって出題される**ことが確認されています。

### 地盤・土構造物（II-1-4 に7年連続）

II-1 の第4問（II-1-4）では地盤・のり面・盛土関連が全7年で出題されています。

| 出題年度 | テーマ |
|---------|--------|
| R01 II-1-4 | 切土のり面の変状事例と崩壊メカニズム |
| R02 II-1-4 | 落石対策工（2種類・調査・選定手順） |
| R03 II-1-4 | ICT土工（効果・出来形管理手法） |
| R04 II-1-4 | 道路盛土の地震時安定照査 |
| R05 II-1-4 | 地すべり対策工・グラウンドアンカー工 |
| R06 II-1-4 | 補強土壁（補強メカニズム・適用留意点） |
| R07 II-1-4 | 能登半島地震を踏まえた盛土排水の課題と対策 |

のり面→落石→ICT→地震→地すべり→擁壁→防災と、毎年切り口が変わります。R08 は能登半島地震の教訓を踏まえた「液状化対策」「盛土点検・管理」、またはICT・BIM/CIM と融合した土工管理が有力候補です。

### 防災・災害対応（全設問種別にまたがる）

防災テーマは II-1・II-2・III のいずれにも登場し、年々比重が高まっています。

<Callout type="warn">
**「大規模災害 → 翌年度に詳細技術問題」パターンに注意**

- R02 III-2: 南海トラフ巨大地震への**道路防災対策**（東日本大震災の教訓を踏まえて出題）
- R03 III-1: 関越・北陸道の大雪**大規模車両滞留防止**（R02冬の実被害を踏まえて出題）
- R06 III-2: **道路啓開**（令和6年能登半島地震の直後に出題）
- R07 II-1-4: 能登半島地震を踏まえた**盛土排水**の課題（翌年度に技術問題化）

被災事例は試験直前まで情報更新が必要です。
</Callout>

### 高速道路課題（III・II-2 に登場）

III では高速道路に関する政策課題が繰り返し問われています。

| 出題年度 | テーマ |
|---------|--------|
| R01 III-2 | 道路構造物の定期点検（1巡目完了・今後の展開） |
| R03 III-1 | 大雪による大規模車両滞留の防止 |
| R03 III-2 | 暫定2車線区間の解消 |
| R03 II-2-2 | 高速道路 RC 床版取替え工事 |
| R04 III-2 | 高速道路老朽化（定期点検・修繕・更新） |
| R04 II-2-1 | スマートIC計画 |
| R05 III-2 | SA・PA の多機能化 |

高速道路は「整備→老朽化対策→サービス向上→防災」という多面的な課題が問われます。国土交通省の「高速道路リニューアルプロジェクト」「暫定2車線の4車線化」など最新の政策文書を押さえておくと解答の質が上がります。

### 交通安全・モビリティ（II-2・III に登場）

自転車・生活道路・交通マネジメントなど、地域の交通課題を問う設問が継続して出題されています。

| 出題年度 | テーマ |
|---------|--------|
| R01 II-2-1 | 生活道路の交通安全対策（ゾーン30） |
| R01 III-1 | 東京オリンピックの交通マネジメント |
| R02 III-1 | 自転車活用推進・自動車依存低減 |
| R03 II-2-1 | 生活道路の緊急交通安全対策（子供の通学路） |
| R05 III-1 | 交通安全（時代のニーズへの対応） |
| R07 II-2-1 | 自転車ネットワーク計画 |

「生活道路の安全」と「自転車インフラ」は繰り返し出題されています。R08 では電動キックボード・LRT など新モビリティへの道路空間対応が有力です。

### DX・自動運転・脱炭素（近年 III・II-1 に集中）

近年、道路の「社会的役割の変化」を問う設問が急増しています。

| 出題年度 | テーマ |
|---------|--------|
| R03 II-1-4 | ICT土工（施工 DX の先駆け） |
| R04 III-1 | 道路ニーズの多様化（デジタル技術・MaaS） |
| R06 II-1-2 | 自動運行補助施設（自動運転インフラ整備） |
| R06 II-2-1 | BRT 導入（脱炭素・地域公共交通） |
| R07 II-2-1 | 自転車ネットワーク計画（脱自動車依存） |
| R07 III-1 | 気候変動・道路の脱炭素化 |
| R07 III-2 | インフラ DX（xROAD） |

R07 では III の両問題がそれぞれ「脱炭素」と「DX」で、この流れは R08 でも継続します。

## 令和8年度（R08）の出題予想

<Callout type="note">
あくまで傾向に基づく予想です。合格には幅広いテーマへの対応が必要です。
</Callout>

### 改訂コンピテンシーとの関係

令和8年度からコンピテンシーが改訂され、以下の4点が新たに明文化されました。

- **データ・情報技術の活用**（問題解決）
- **多角的な視点とステークホルダーへの配慮**（問題解決・コミュニケーション）
- **包摂的な協働**（コミュニケーション）
- **持続可能な成果と文化的価値の尊重**（技術者倫理）

詳細: [技術士 コンピテンシー改訂 令和8年度｜新旧対照と二次試験への影響](/docs/pe-construction-competency-revision-r8)

### 予想テーマ（II-1）

| 設問 | 予想テーマ |
|------|-----------|
| II-1-1 | 設計速度の設定（道路区分・地形状況に応じた考え方）、または交差点設計 |
| II-1-2 | R7道路法改正の関連事項（インフラ保全計画・道路管理情報整備）または無電柱化推進法 |
| II-1-3 | 舗装の予防保全（早期対処の経済性・LCC評価）または BIM/CIM を活用した舗装管理 |
| II-1-4 | 液状化対策・盛土の安定管理（能登半島地震の教訓）または切土のり面の ICT 点検 |

### 予想テーマ（II-2・III）

| 設問 | 予想テーマ |
|------|-----------|
| II-2-1 | 新モビリティ（EV充電・LRT・電動キックボード）を考慮した道路空間再配分計画 |
| II-2-2 | インフラ DX を活用した維持管理計画（点群データ・センサー・AI点検） |
| III-1 | 道路の脱炭素化（CNポートフォリオ・材料・施工工程）または能登半島地震を踏まえた半島地域の防災強靱化 |
| III-2 | 高速道路の暫定2車線4車線化の推進策、またはインフラDX（xROAD 展開フェーズ） |

<Callout type="tip">
**対策の優先順位（R08）**

1. **舗装**（7年連続・R08も確実）: 維持管理・LCC・資源循環・DX活用
2. **道路法改正**（7年連続・R08も確実）: R7改正の「インフラ保全強化」「災害対応深化」を詳読
3. **防災・盛土**（R06・R07 連続）: 能登半島地震の教訓と対策工法
4. **DX・脱炭素化**（R07 III 両問題）: xROAD展開・CNポートフォリオ
</Callout>

## 模範解答集（R03〜R07 完全収録）

ここまで整理した出題テーマについて、R03〜R07 の模範解答を note 有料マガジンで公開しています。

選択科目 II-1・II-2・III の各区分を1記事にまとめ、その年度に出題された**全選択肢の解答**を収録。道路科目合格者かつ元・地方自治体土木職（発注者）の視点で、問い分解 → 多面的論点の絞り込み →「現状 → 課題 → 解決策 → 効果・リスク」の骨格でフル解答しています。
