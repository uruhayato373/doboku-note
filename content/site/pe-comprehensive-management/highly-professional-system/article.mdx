## 高度プロフェッショナル制度とは

高度プロフェッショナル制度とは、高度の専門的知識を有し一定の年収要件を満たす労働者を対象に、労働基準法に定める労働時間・休憩・休日・深夜割増賃金に関する規定を適用しない制度である。

2019年4月に働き方改革関連法の施行に伴い、**労働基準法第41条の2**として新設された。

成果で評価される働き方を選択できる制度として導入されたが、長時間労働を助長する懸念もあり、厳格な健康確保措置が義務づけられている。

## 適用要件

高度プロフェッショナル制度を適用するには、業務・年収・同意・決議・届出の5要件をすべて満たす必要がある。

| 要件 | 内容 |
|---|---|
| **対象業務** | 高度の専門的知識等を必要とし、従事した時間と成果の関連性が高くない業務 |
| **年収要件** | 基準年間平均給与額の3倍を相当程度上回る水準（1,075万円以上） |
| **本人同意** | 書面による本人の同意が必要（同意の撤回も可能） |
| **労使委員会の決議** | 委員の4/5以上の多数による決議が必要 |
| **届出** | 労働基準監督署への届出が必要 |

## 対象業務

対象業務は厚生労働省令で限定列挙されており、高度の専門的知識を要し成果と労働時間の相関が低い5業務に限られる。

| 業務 | 具体例 |
|---|---|
| **金融商品の開発** | デリバティブ商品の開発、ストラクチャードファイナンスの組成 |
| **金融商品のディーリング** | 有価証券等の売買・運用 |
| **アナリスト** | 企業・市場の調査・分析 |
| **コンサルタント** | 事業・業務の企画運営に関する助言 |
| **研究開発** | 新たな技術・商品・役務の研究開発 |

## 適用除外される規定

以下の労働基準法上の規定が適用されなくなる。労働時間管理を労働者の自律に委ねる反面、健康確保措置が義務化されている。

| 適用除外される規定 | 内容 |
|---|---|
| **労働時間** | 1日8時間・週40時間の制限なし |
| **休憩** | 休憩時間の付与義務なし |
| **休日** | 週1日・4週4日の法定休日規制なし |
| **深夜割増賃金** | 深夜労働の割増賃金なし |
| **時間外割増賃金** | 時間外労働の割増賃金なし |

## 健康確保措置

適用対象者の健康を守るため、義務的措置と選択的措置が法定されている。いずれかの選択肢を必ず講じなければならない。

| 措置 | 内容 |
|---|---|
| **年間104日以上の休日確保** | 4週間を通じ4日以上の休日を必ず付与（義務） |
| **健康管理時間の把握** | 事業場内外の在所時間＋事業場外の労働時間を把握 |
| **選択的措置（いずれか1つ）** | 勤務間インターバル＋深夜業回数制限、健康管理時間の上限設定、連続2週間の休日、臨時の健康診断 |
| **医師の面接指導** | 健康管理時間が一定基準を超えた場合に義務的に実施 |

## 導入状況と課題

制度導入後も適用労働者数は限定的にとどまっており、以下の課題が指摘されている。

| 課題 | 内容 |
|---|---|
| **導入企業の少なさ** | 厳格な要件により適用労働者は限定的 |
| **長時間労働リスク** | 労働時間規制の適用除外により過重労働のおそれ |
| **成果評価の困難** | 成果と報酬の適切な連動が前提だが評価基準の確立が難しい |
| **同意の自由** | 実質的に自由な同意が確保されるかという懸念 |

## 総合技術監理における位置づけ


総合技術監理キーワード集では[**3.2 労働関係法と労務管理**](/docs/pe-comprehensive-management-keyword-2026#32-労働関係法と労務管理)に位置づけられる。

高度プロフェッショナル制度は、高度人材の自律的で創造的な働き方を実現する制度（人的資源管理）である一方、労働時間規制の適用除外により健康リスクが増大する可能性がある（安全管理）。

総合技術監理者には、制度の適用可否の判断と健康確保措置の確実な実施、そして成果評価制度との連動による適正な運用が求められる。

## 制度創設の経緯

高度プロフェッショナル制度の原型は、2005年に日本経済団体連合会が提言した**ホワイトカラーエグゼンプション**に遡る。欧米では成果で評価される高度専門職に労働時間規制を適用しない仕組みが既に存在しており、日本でも同様の枠組みを求める産業界の要請が高まっていた。

2007年に当初の法案が検討されたが、長時間労働の固定化・過労死助長のおそれがあるとして強い反発を受け廃案となった。その後、産業競争力会議が2014年に再提言し、第189回国会（2015年）に改正案が上程されたが審議未了・廃案となった。

2018年の**働き方改革関連法**に盛り込まれ第196回国会で成立、2019年4月1日に施行された。法案審議過程では「残業代ゼロ法案」と批判された経緯もあり、成立後も年間104日以上の休日確保・健康管理時間の把握・医師面接指導といった厳格な健康確保措置が義務化されている点に、立法上の妥協の産物という性格が表れている。

建設部門の技術者は現状では対象業務の5類型に含まれないが、総合技術監理者としては、制度の適用対象者（金融・コンサルティング分野の高度専門人材）を組織内でマネジメントする場面で本制度の要件・運用を正確に理解する必要がある。
