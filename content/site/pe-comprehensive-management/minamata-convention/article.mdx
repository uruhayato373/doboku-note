## 水俣条約とは

水銀に関する水俣条約（Minamata Convention on Mercury）は、水銀及び水銀化合物の人為的な排出・放出から人の健康及び環境を保護することを目的とする国際条約である。

2013年10月に熊本市・水俣市で開催された外交会議で採択され、2017年8月に発効した。

条約名に「水俣」を冠するのは、日本の水俣病の教訓を世界と共有し、水銀汚染を二度と繰り返さないという国際社会の決意を示すものである。

### 水銀の特性とリスク

- **物理的特性**: 常温で液体の唯一の金属、蒸発しやすい
- **毒性**: 中枢神経障害、腎臓障害、胎児への発達毒性
- **環境動態**: メチル水銀への変換→食物連鎖で生物濃縮（特に大型魚類）
- **代表的被害**: 水俣病（1956年公式確認）、新潟水俣病（1965年）

### 条約の規制内容

| 規制分野 | 内容 |
|---|---|
| **水銀の供給** | 新規水銀鉱山の開設禁止、既存鉱山の15年以内の閉鎖 |
| **水銀添加製品** | 電池、スイッチ・リレー、蛍光灯、体温計、血圧計等の製造・輸出入を2020年以降禁止 |
| **製造プロセス** | クロルアルカリ工業での水銀使用を2025年までに廃止 |
| **小規模金採掘（ASGM）** | 水銀使用の削減・廃絶に向けた国家行動計画の策定 |
| **大気排出** | 石炭火力発電所、廃棄物焼却施設等からの排出にBAT/BEPを適用 |
| **水・土壌への放出** | 放出源の特定と放出削減措置 |
| **水銀廃棄物** | バーゼル条約と整合した環境上適正な管理 |
| **汚染サイト** | 汚染サイトの特定・評価・リスク低減 |

### 日本の対応

| 対応 | 内容 |
|---|---|
| **条約批准** | 2016年2月に締結（条約採択国として率先して対応） |
| **水銀汚染防止法** | 2015年制定、水銀の採掘禁止・特定水銀使用製品の製造禁止等 |
| **大気汚染防止法改正** | 水銀排出施設からの排出規制（排出基準の設定） |
| **廃棄物処理法改正** | 水銀廃棄物の適正処理に関する規定を整備 |
| **水銀使用製品の回収** | 蛍光灯、体温計、血圧計等の回収・適正処理を推進 |

### 水銀汚染防止法の概要

水銀汚染防止法は2015年に水俣条約の国内担保法として制定され、水銀の採掘・製品・貯蔵・再生資源を一体的に規制している。

- **目的**: 水俣条約の的確かつ円滑な実施を確保
- **水銀等の採掘禁止**: 国内での水銀鉱山の新規開設・既存鉱山での採掘を禁止
- **特定水銀使用製品**: 水銀体温計、水銀血圧計等の製造を禁止
- **水銀等の貯蔵**: 環境上適正な方法での貯蔵を義務化
- **水銀含有再生資源**: 管理基準の遵守を義務化

水俣条約の国内担保は水銀汚染防止法単独ではなく、大気汚染防止法との連携で成り立っている点が実務上重要である。[大気汚染防止法](/docs/pe-comprehensive-management-air-pollution-control-act)は第1条の目的規定で「水銀に関する水俣条約の的確かつ円滑な実施を確保するため工場及び事業場における事業活動に伴う水銀等の排出を規制」する旨を明記しており、条約の担保法としての位置づけが条文レベルで組み込まれている。これは石炭火力発電所や廃棄物焼却施設など水銀排出施設からの排出基準を定める根拠である。条約側の「大気排出へのBAT/BEP適用」という国際的な要求水準を、国内の排出基準という具体的な数値規制に落とし込む役割を担っている。総合技術監理の視点では、水銀汚染防止法（製品・鉱山・貯蔵の規制）と大気汚染防止法（排出施設の規制）という2つの法律が水銀のライフサイクルの異なる段階を分担して規制している。単一法での網羅ではなく複数法の組み合わせで条約義務を履行する構造になっている点が、社会環境管理における法体系設計の特徴として押さえておくべきポイントである。

## 総合技術監理における位置づけ


総合技術監理キーワード集では[**6.2 地域環境問題**](/docs/pe-comprehensive-management-keyword-2026#62-地域環境問題)に位置づけられる。

水俣条約は公害の原点である水俣病の教訓に基づく国際枠組みであり、日本が条約採択を主導した経緯から国際的な責任が大きい。建設分野では解体工事における水銀含有機器（蛍光灯等）の適正処理や、土壌・水質の水銀汚染対策が実務上の課題となる。

水俣条約への対応は、5つの管理分野のトレードオフが典型的に現れる場面である。解体工事の元請業者にとって、水銀含有機器（蛍光灯・体温計・血圧計等）の分別回収は追加の手間とコストを発生させる作業であり、経済性管理の観点では工期短縮・コスト圧縮の要請と正面から衝突する。しかし分別を省略して一般廃棄物と混合処理すれば、水銀が焼却施設や埋立処分場から環境中に放出され、社会環境管理上の重大なリスクを生む。ここで安全管理の視点を加えると、水銀蒸気を吸入する作業員の健康リスクも無視できず、破損した蛍光灯の取り扱いには適切な保護具と換気が必要になる。さらに人的資源管理の観点では、現場作業員に水銀含有機器の識別方法と分別手順を教育する必要があり、教育を怠れば善意の作業員でも誤った処理をしてしまう。情報管理の観点では、どの機器にどれだけの水銀が含まれているかという情報を発注者・元請・処分業者の間で正確に伝達し、マニフェスト（産業廃棄物管理票）に反映させる仕組みが欠かせない。総合技術監理の視点は、これら5つの管理分野の要請を単純に足し合わせるのではなく、解体工事という限られた予算と工期の中でどこまでの分別・教育・情報伝達コストを許容するかを、環境リスクの大きさと天秤にかけて判断する調整能力そのものにある。
