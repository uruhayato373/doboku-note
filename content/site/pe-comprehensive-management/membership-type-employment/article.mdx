## メンバーシップ型雇用とは

**メンバーシップ型雇用（属人主義）** とは、職務を限定せず組織の「メンバー」として採用し、会社主導で配置・異動・育成を行う雇用形態である。日本の大企業に特徴的な雇用システムであり、「人に仕事をつける」考え方に基づく。

<Callout type="warn" title="R04 Ⅰ-1-15 の誤答: メンバーシップ型は変化対応が容易ではない">
環境変化への対応力は [ジョブ型雇用](/docs/pe-comprehensive-management-job-type-employment) のほうが高い。メンバーシップ型は内部育成・長期雇用で柔軟な配置が可能な反面、ビジネスモデルの変革や事業の急激な変化には対応が遅れる。過去問 [R04 Ⅰ-1-15](/docs/pe-comprehensive-management-r04-primary#1-15) で「メンバーシップ型はジョブ型に比べ変化が激しい場合で対応が容易」と書き換えた誤答が出題された。
</Callout>

## 日本的雇用慣行の三種の神器

日本的雇用慣行の中核となる三つの慣行を以下に整理する。

| 慣行 | 内容 |
|---|---|
| **終身雇用（長期雇用）** | 定年まで雇用を保障する暗黙の慣行 |
| **年功序列** | 勤続年数・年齢に応じて賃金・地位が上昇 |
| **企業別労働組合** | 企業ごとに組織される労働組合 |

## メンバーシップ型の特徴

メンバーシップ型雇用は、職務を限定せず「人」を会社のメンバーとして雇い、長期にわたり育成・配置する日本型の人事運用である。

- **採用**: 新卒一括採用（ポテンシャル重視）
- **職務範囲**: 包括的・無限定（「なんでもやる」）
- **異動**: 会社主導のジョブローテーション（全国転勤）
- **育成**: OJT中心＋計画的ローテーションでゼネラリスト育成
- **賃金**: 職能給＋年功的運用
- **評価**: 能力・態度・プロセス重視
- **解雇**: 厳しい解雇規制（整理解雇4要件）

## メリットとデメリット

メンバーシップ型雇用は長期雇用を前提とする設計により、人事配置の柔軟性と引き換えに専門性・成果連動性で課題を抱える。

| メリット | デメリット |
|---|---|
| 柔軟な人員配置（異動・配転） | 専門性が育ちにくい |
| 長期的な人材育成が可能 | 転勤負担（WLBの阻害） |
| 組織への帰属意識が高い | 年功的賃金による人件費膨張 |
| 雇用の安定性が高い | 成果と報酬の乖離 |
| チームワーク・協調性が育つ | 同質性が高くイノベーションが起きにくい |

## 変容の動向

近年は人材の流動化・DX 化を背景に、メンバーシップ型の一部にジョブ型を取り込む動きが進んでいる。

| 変化 | 内容 |
|---|---|
| **成果主義の導入** | 年功序列から成果に応じた処遇へ |
| **ジョブ型への移行** | DX人材等の専門職にジョブ型を部分導入 |
| **限定正社員** | 勤務地・職務・時間限定の正社員区分 |
| **ハイブリッド型** | メンバーシップ型とジョブ型の折衷 |
