## デジタルツインとは

デジタルツイン（Digital Twin）とは、物理空間（フィジカル空間）に存在する実体（設備・建物・都市・人体など）を、サイバー空間上にリアルタイムで再現した仮想モデルである。

IoTセンサーから取得したデータをもとに仮想モデルを常時更新し、現実世界の状態を忠実に反映することで、シミュレーション・予測・最適化を可能にする。

「双子（ツイン）」の名が示すとおり、現実の対象物と1対1に対応するデジタルコピーを構築・維持する点が最大の特徴である。過去問 [R04 Ⅰ-1-23](/docs/pe-comprehensive-management-r04-primary#1-23) では、デジタルディスラプション（破壊）・DX（社会組織の変革）・デジタライゼーション（ビジネスモデルのデジタル化）・デジタルファブリケーション（3D 造形）・デジタルツイン（サイバー空間での再現）の 5 用語の定義区別が問われた。

### デジタルツインの構成要素

デジタルツインは IoT センサー・通信・データ基盤・AI・可視化を組み合わせた技術スタックとして構築される。

| 構成要素 | 役割 |
|---|---|
| IoTセンサー | 物理空間のデータ（温度、振動、位置等）をリアルタイム収集 |
| 通信基盤 | センサーデータをクラウド・エッジに伝送（5G、LPWA等） |
| データプラットフォーム | 収集データの蓄積・前処理・統合管理 |
| 仮想モデル | 3Dモデル・物理モデル・数理モデルによる再現 |
| AI・分析エンジン | 異常検知・予測・最適化のためのアルゴリズム |
| 可視化インターフェース | ダッシュボード・AR/VRによる直感的な状態把握 |

### デジタルツインの活用分野

製造業から医療まで、物理対象をサイバー空間で再現することによる最適化・予測が幅広い分野で進んでいる。

| 分野 | 活用例 |
|---|---|
| 製造業 | 工場設備の予知保全、生産ラインのシミュレーション |
| 建設・インフラ | BIM/CIMと連携した施工管理・維持管理 |
| 都市計画 | スマートシティにおける交通・エネルギー・防災のシミュレーション |
| 医療 | 患者の生体データに基づく個別化治療シミュレーション |
| 航空宇宙 | エンジン・機体の劣化予測と寿命管理 |

## サイバーフィジカルシステムとは

サイバーフィジカルシステム（Cyber-Physical System: CPS）とは、物理空間（フィジカル空間）のデータをセンサー等で収集し、サイバー空間で分析・処理した結果を物理空間にフィードバックする仕組みの総称である。

CPSはデジタルツインを包含するより広い概念であり、Society 5.0の技術基盤として位置づけられている。

CPSの本質は、フィジカル空間とサイバー空間のあいだでデータと制御が循環する双方向ループにある。物理対象の状態をサイバー空間へ収集し、分析・予測した結果を再び物理対象へ返す流れを繰り返す。

### デジタルツインとCPSの関係

CPS はより広い枠組みで、デジタルツインはその中核技術として位置づけられる。下表で両者と周辺技術との関係を整理する。

| 概念 | 位置づけ |
|---|---|
| CPS | 物理×サイバーの双方向連携（アーキテクチャ） |
| デジタルツイン | CPS 中核の仮想複製技術 |
| IoT | CPS のデータ収集層 |
| AI | CPS の分析・予測層 |

### Society 5.0とCPS

内閣府が提唱するSociety 5.0は、CPSを基盤とした超スマート社会の実現を目指す構想である。

CPSにより、サイバー空間とフィジカル空間が高度に融合し、経済発展と社会的課題の解決を両立する社会が実現される。

## DX関連 5 用語の定義区別

過去問 [R04 Ⅰ-1-23](/docs/pe-comprehensive-management-r04-primary#1-23) では次の 5 用語の定義区別が問われた。**デジタルツイン** は物理空間の情報を取得しサイバー空間に再現する概念であり、他の用語と混同しない。

| 用語 | 定義 |
|---|---|
| **デジタルディスラプション** | デジタル企業の参入で既存ビジネスモデル・商習慣に風穴が開き、既存企業の存続が困難になること |
| **デジタルトランスフォーメーション（DX）** | デジタル技術の活用による商品・サービス・ビジネスモデルの変革を通じて、社会制度・組織文化にまで及ぶ変革 |
| **デジタライゼーション** | 組織のビジネスモデル全体をデジタル化で一新し、クライアント・パートナーへより良いサービス提供を構築 |
| **デジタルファブリケーション** | 3D スキャナ・3D CAD・3D プリンター等でアイデアをデジタルデータ化し造形 |
| **デジタルツイン** | IoT 等で現実空間の情報を取得し、サイバー空間内に現実空間の環境を再現する概念（本ページの主題） |

## デジタルツイン・CPSの成立背景

デジタルツインという概念が初めて学術的に体系化されたのは2002年である。米ミシガン大学のマイケル・グリーブス博士が製品ライフサイクルマネジメント（PLM）に関する講義で提唱した「情報ミラーリングモデル」がその原点であり、物理モデル・仮想モデル・両者間の情報連携という3要素の構造は現在のデジタルツインにそのまま受け継がれている。

「デジタルツイン」という名称は2010年にNASAのエンジニアが採用したことで普及し、2017年に米ガートナー社が戦略的テクノロジー・トレンドのトップ10に選定したことで製造業・建設業・都市計画など幅広い分野へ浸透した。

CPSの概念は2006年頃から米国国家科学財団（NSF）を中心に研究が進み、ドイツのインダストリー4.0（2011年）がCPSを製造業変革の中核に位置づけたことで国際的に注目された。日本では内閣府が推進する第5期科学技術基本計画（2016年）においてSociety 5.0の技術基盤としてCPSが明記され、BIM/CIM推進やスマートシティ施策と連動する形で建設・インフラ分野での活用が本格化している。

## 総合技術監理における位置づけ


総合技術監理キーワード集では[**4.4 情報通信技術動向**](/docs/pe-comprehensive-management-keyword-2026#44-情報通信技術動向)に位置づけられる。

IoT・AI・VR/ARなどのDX技術と組み合わせて活用され、Society 5.0やスマートシティの文脈では安全管理（5章）とも強く関連する。

過去問 [R02 Ⅰ-1-21](/docs/pe-comprehensive-management-r02-primary#1-21) では Society 5.0 の核心論点として「サイバー空間に存在するクラウドサービスにフィジカル空間にいる人間がアクセスし自ら情報を解析する」という記述（これは Society 4.0 = 情報社会の特徴）が誤答として扱われた。デジタルツイン・CPS はサイバー空間とフィジカル空間を高度に融合し、AI が自動的に解析しフィードバックする仕組みであり、Society 4.0 との本質的違いがここにある。
