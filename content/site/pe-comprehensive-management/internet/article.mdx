## インターネットとは

インターネットとは、TCP/IPプロトコルを基盤として世界中のコンピュータネットワークを相互接続した、地球規模の通信インフラストラクチャである。

1990年代の商用化以降、Webブラウザの普及、ブロードバンドの整備、モバイルインターネットの発展を経て、現在では社会基盤として不可欠な存在となっている。

IoT（Internet of Things）の普及により、人同士の通信にとどまらず、あらゆるモノがインターネットに接続される時代を迎えている。

### インターネットの基盤技術

| 技術 | 概要 |
|---|---|
| **TCP/IP** | インターネット通信の基本プロトコル体系 |
| **DNS** | ドメイン名とIPアドレスの変換システム |
| **HTTP / HTTPS** | Webコンテンツの転送プロトコル（HTTPSは暗号化通信） |
| **SMTP / POP / IMAP** | 電子メールの送受信プロトコル |
| **IPv4 / IPv6** | IPアドレス体系（IPv6は128ビットで枯渇問題を解消） |
| **SSL / TLS** | 通信の暗号化・認証を行うセキュリティプロトコル |

### SNS

SNSはインターネット上で人と人をつなぐプラットフォームであり、情報発信・共有・コミュニケーションの基盤として社会的影響力を持つ。

| 側面 | 内容 |
|---|---|
| **情報発信** | 個人・組織による即時的な情報発信が可能 |
| **災害時活用** | 安否確認・救援情報の共有（東日本大震災以降に注目） |
| **行政活用** | 自治体の広報・住民との双方向コミュニケーション |
| **リスク** | フェイクニュース・炎上・プライバシー侵害 |
| **企業利用** | マーケティング・カスタマーサポート・採用活動 |

### クラウドサービスの普及

インターネットの高速化・大容量化を背景に、クラウドサービスが急速に普及している。各サービス種別の概要と代表的な利用例を以下に示す。

- **SaaS**（Software as a Service）: ソフトウェアをインターネット経由で利用 — メール・文書作成・会計
- **PaaS**（Platform as a Service）: アプリ開発・実行環境を提供 — Webアプリ開発基盤
- **IaaS**（Infrastructure as a Service）: サーバ・ストレージ等のインフラを提供 — 仮想サーバ・データ保管

### インターネットの課題

| 課題 | 概要 |
|---|---|
| **セキュリティ** | サイバー攻撃・不正アクセス・情報漏洩のリスク |
| **デジタルデバイド** | 情報格差（地域間・世代間・経済格差による利用機会の差） |
| **プライバシー** | 個人情報の収集・追跡・プロファイリングへの懸念 |
| **ネットワーク中立性** | 通信事業者によるトラフィック差別の問題 |
| **依存リスク** | インターネット障害時の社会機能への影響 |
