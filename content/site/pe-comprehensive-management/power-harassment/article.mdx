## パワーハラスメントとは

パワーハラスメント（パワハラ）とは、職場において行われる、優越的な関係を背景とした言動であって、業務上必要かつ相当な範囲を超えたものにより、労働者の就業環境が害されるものをいう。

2020年6月に施行された改正労働施策総合推進法（通称：パワハラ防止法）により、事業主にパワーハラスメント防止措置が義務化された（中小企業は2022年4月から義務化）。

## パワハラの3要素

パワハラの定義は以下の3つの要素をすべて満たすものである。

| 要素 | 内容 |
|---|---|
| **優越的な関係を背景とした言動** | 上司から部下に限らず、同僚や部下からでも該当しうる |
| **業務上必要かつ相当な範囲を超えた言動** | 業務指導として社会通念上許容される範囲を超える |
| **労働者の就業環境が害される** | 身体的・精神的な苦痛により就業に支障が生じる |

## パワハラの6類型

| 類型 | 具体例 |
|---|---|
| **身体的な攻撃** | 殴打、足蹴り、物を投げつける |
| **精神的な攻撃** | 人格否定、長時間の叱責、他の労働者の前での威圧的な叱責 |
| **人間関係からの切り離し** | 別室への隔離、仲間外し、無視 |
| **過大な要求** | 達成不可能なノルマの強制、業務と無関係な雑用の強制 |
| **過小な要求** | 合理的な理由なく能力や経験とかけ離れた程度の低い仕事を命じる |
| **個の侵害** | 私的なことに過度に立ち入る、性的指向・病歴等の暴露（アウティング） |

## 法的根拠

| 法令 | 内容 |
|---|---|
| **[労働施策総合推進法第31条](https://laws.e-gov.go.jp/law/341AC0000000132#Mp-At_31)（旧第30条の2）** | 事業主のパワハラ防止措置義務 |
| **[同法第32条](https://laws.e-gov.go.jp/law/341AC0000000132#Mp-At_32)（旧第30条の3）** | 国・事業主・労働者の責務規定 |
| **パワハラ防止指針** | 具体的な防止措置の内容を規定（2020年厚労省告示） |

## パワハラが起きたとき責任はどこへ向かうか

パワハラ防止の中心は、事業主に措置を義務づける[労働施策総合推進法第31条](https://laws.e-gov.go.jp/law/341AC0000000132#Mp-At_31)（2026年10月の改正施行前は第30条の2）である。この条文は行為者を処罰するものではなく、被害者に損害賠償の請求権を直接与えるものでもない。「パワハラ罪」という罪名もないため、責任は言動の中身を刑法・民法の既存の規定に当てはめて考える。

当てはめの順は3段である。言動が犯罪に当たるか、行為者本人に賠償を求められるか、会社はどの筋道で責任を負うか。全体像は次の図のとおり。

### 言動が犯罪に当たるか

パワハラ防止指針は、身体的な攻撃に暴行・傷害を、精神的な攻撃に脅迫・名誉毀損・侮辱・ひどい暴言を挙げている。重い言動は、刑法の罪に当たりうる。

- 殴る・蹴る・物を投げつける: 暴行罪（[刑法208条](https://laws.e-gov.go.jp/law/140AC0000000045#Mp-At_208)）、けがをさせれば傷害罪（同204条）
- 危害を加えると告げて怯えさせる: 脅迫罪（同222条）。それで義務のないことをさせれば強要罪（同223条）
- 人前で事実を挙げて評判を落とす: 名誉毀損罪（同230条）。挙げた事実の有無は問われない
- 事実を挙げずに人前で罵倒する: 侮辱罪（同231条）

名誉毀損罪と侮辱罪は、どちらも「公然と」行われたことが要件になる。二人きりの場での暴言は、この2つの罪には当たらないことが多いが、民事上の責任や防止措置の対象からは外れない。

人間関係からの切り離し、過大・過小な要求、個の侵害といった類型は、多くが民事上の責任と措置義務の問題になる。刑法の罪に問われるのは行為者個人であり、会社が処罰されるわけではない。

### 行為者に賠償を求める

行為者は、故意または過失で他人の権利や法律上保護される利益を侵害したとして、[民法709条](https://laws.e-gov.go.jp/law/129AC0000000089#Mp-At_709)の不法行為責任を負う。侵害されるのは、身体の安全、名誉、人格的な利益などである。賠償は治療費や休業による損害に加え、精神的苦痛への慰謝料にも及ぶ（710条）。

ただし、業務上必要かつ相当な範囲の指導は、通常は違法と評価されない。指導として許される範囲を超えたかどうかが、民事でも違法性の判断の中心になる。

### 会社が負う2つの責任

会社に責任を問う筋道は2つある。

1つ目は使用者責任（[民法715条](https://laws.e-gov.go.jp/law/129AC0000000089#Mp-At_715)）で、行為者の不法行為を前提に、会社が賠償責任を負う。要件は、行為者が会社に使用されていることと、行為が「事業の執行について」なされたことの2点である。

上司が職務上の立場を使って部下を叱責する典型例は、業務との関連が強く、この要件を満たしやすい。選任・監督に相当の注意をしていれば免責されるとただし書は定めるが、実際に免責が認められる場面は一般に限られるとされる。会社が賠償した場合は、行為者への求償もできる（同条3項）。

2つ目は債務不履行責任（[民法415条](https://laws.e-gov.go.jp/law/129AC0000000089#Mp-At_415)）で、会社自身が労働契約に伴う義務を怠った責任である。中心になるのは安全配慮義務で、[労働契約法](/docs/pe-comprehensive-management-labor-contract-act)の[5条](https://laws.e-gov.go.jp/law/419AC0000000128#Mp-At_5)は、労働者が生命・身体等の安全を確保しつつ働けるよう、使用者に必要な配慮を求めている。

この義務は心身の健康にも及ぶ。パワハラを知りながら放置した、相談を受けても調査や配置の見直しをしなかった、といった対応の不備が義務違反として問われうる。

<Callout type="note" title="どちらの筋道で問うかの見分け方">
行為者の不法行為を会社が負う形なら使用者責任（715条）、会社自身の放置や対応の不備なら債務不履行（415条）である。1つの事案で両方が並べて主張されることもある。
</Callout>

行為者に不法行為責任、会社に安全配慮義務違反の責任を認めた裁判例に、誠昇会北本共済病院事件（さいたま地判平成16年9月24日）がある。過去問 [H28 Ⅰ-1-32](/docs/pe-comprehensive-management-h28-primary#1-32) は、会社が行為に加担していなくても法的責任を問われうるかを取り上げており、使用者責任と安全配慮義務の理解が土台になる。

### 下請の作業員に対する言動

建設現場では、元請の職員が下請の作業員を叱責する場面もある。第31条の措置義務は事業主が「雇用する労働者」を守る規定のため、他社の作業員は条文の直接の対象にならない。指針は、他の事業主の労働者に対する言動も、防止の方針の中で併せて示すことが望ましいとしている。

ただし、2026年10月1日施行の[第33条](https://laws.e-gov.go.jp/law/341AC0000000132#Mp-At_33)は、顧客・取引の相手方などの言動から自社の労働者を守る措置を事業主に義務づけた。その指針は「顧客等」の例に取引先の担当者を挙げており、元請の職員の言動で下請の作業員の就業環境が害される場面は、下請の事業主側にこの義務が生じうると読める。元請の側は、下請の事業主から事実関係の確認などへの協力を求められたとき、応ずるように努める（同条3項）。

民事では、元請の設備を使い、事実上元請の指揮監督を受けて働く下請の労働者に、元請が信義則上の安全配慮義務を負うとした最高裁の判例がある（最判平成3年4月11日・三菱重工業神戸造船所事件）。過去問 [H27 Ⅰ-1-27](/docs/pe-comprehensive-management-h27-primary#1-27) でも、安全配慮義務が直接の雇用関係にない下請作業員に及ぶ点が出題された。

### 行政上の対応

刑事・民事とは別に、会社には行政上の対応がある。第31条1項の措置義務と2項の不利益取扱い禁止の違反そのものに、刑事罰は置かれていない。是正は、厚生労働大臣による助言・指導・勧告（[第42条](https://laws.e-gov.go.jp/law/341AC0000000132#Mp-At_42)1項）と、勧告に従わないときのその旨の公表（同条2項）で図られる。

会社の責任を左右するのは、パワハラを知り得たか、知った後にどう動いたかである。事実の確認、被害者の保護、行為者への措置、再発防止が尽くされていたかが問われる。次節の防止措置は行政上の義務であるとともに、会社が民事上の責任を負うかどうかにも関わる。

論述では、防止措置を義務の履行としてだけでなく、放置すれば会社自身が賠償責任と勧告・公表のリスクを負うという観点でも示すと、人的資源管理と社会環境管理の両面から根拠づけられる。

## 事業主に義務づけられる防止措置

| 措置 | 内容 |
|---|---|
| **方針の明確化・周知啓発** | パワハラを行ってはならない旨の方針の明確化、就業規則等への規定 |
| **相談体制の整備** | 相談窓口の設置、相談対応の担当者の選任 |
| **事後の迅速かつ適切な対応** | 事実関係の迅速・正確な確認、被害者への配慮措置、行為者への措置、再発防止策 |
| **プライバシー保護** | 相談者・行為者のプライバシー保護 |
| **不利益取扱いの禁止** | 相談・協力したことを理由とする不利益取扱いの禁止 |

## パワハラに該当しない例

| 類型 | 該当しない例 |
|---|---|
| **身体的な攻撃** | 誤ってぶつかる |
| **精神的な攻撃** | 遅刻等の社会的ルール違反に対する注意 |
| **人間関係からの切り離し** | 新入社員の短期集中研修 |
| **過大な要求** | 繁忙期の通常より多い業務の依頼 |
| **過小な要求** | 体調不良の労働者への軽作業への配置転換 |
| **個の侵害** | 体調を心配して家族の状況を聞く |

## 総合技術監理における位置づけ


総合技術監理キーワード集では[**3.2 労働関係法と労務管理**](/docs/pe-comprehensive-management-keyword-2026#32-労働関係法と労務管理)に位置づけられる。

パワーハラスメントは人的資源管理（職場環境の整備・人材定着）と安全管理（メンタルヘルスの保持・労災防止）に深く関わる。

防止措置の未実施は法令違反であり社会環境管理（コンプライアンス）の問題にもなる。

総合技術監理者には、業務上の指導とハラスメントの境界を適切に判断し、組織として体系的な防止体制を構築することが求められる。
