## 機械学習とは

機械学習（machine learning）とは、コンピュータがデータからパターンや規則性を自動的に学習し、明示的にプログラムされることなく予測・判断を行うことを可能にする人工知能（AI）の中核技術である。

従来のルールベースプログラミングでは人間がすべてのルールを記述する必要があったが、機械学習ではデータ自体からルールを自動抽出する。

Society 5.0やDXの推進において、機械学習は意思決定の高度化・業務の自動化・新たな価値創出の基盤技術として位置づけられている。

モデルの性能評価では **混同行列** から正解率・適合率・再現率・F 値を算出する。正解率＝(TP+TN)/全データ、適合率＝TP/(TP+FP)、再現率＝TP/(TP+FN)、F 値＝適合率と再現率の調和平均。**偽陽性の増加は適合率・正解率に影響するが再現率には影響しない**（過去問 [R03 Ⅰ-1-17](/docs/pe-comprehensive-management-r03-primary#1-17) で混同行列の計算問題として出題）。また [R03 Ⅰ-1-19](/docs/pe-comprehensive-management-r03-primary#1-19) では画像認識のクラウドサービス提供状況（Google・Amazon・Microsoft から既に提供済み）が問われた。

### 機械学習の基本プロセス

機械学習によるデータ活用は、以下のプロセスで実施される。

| ステップ | 内容 |
|---|---|
| 1. データ収集 | 分析対象のデータを収集・蓄積 |
| 2. 前処理 | データクレンジング・正規化・特徴量エンジニアリング |
| 3. 学習 | アルゴリズムにデータを与えてモデルを構築 |
| 4. モデル構築 | 学習結果としてのパラメータ・構造の確定 |
| 5. 推論（予測） | 学習済みモデルを用いて新しいデータに対する予測を実行 |

前処理段階では、欠損値処理・正規化・特徴量の選択と作成などの「データ準備」が分析精度を大きく左右する。

## 学習手法の分類

機械学習は、学習の方法によって大きく3つに分類される。

### 教師あり学習

教師あり学習は、入力データ（特徴量）と正解ラベル（目的変数）のペアから学習を行う手法である。課題の種類・目的・代表的アルゴリズム・適用例を以下に整理する。

- **分類**: カテゴリの予測 — 決定木、ランダムフォレスト、SVM、ロジスティック回帰 — 適用例: 迷惑メール判別、故障予測
- **回帰**: 数値の予測 — 線形回帰、重回帰分析、勾配ブースティング — 適用例: 売上予測、需要予測

分類と回帰の使い分けは、目的変数がカテゴリ（離散値）か数値（連続値）かで判断する。

### 教師なし学習

教師なし学習は、正解ラベルのないデータから構造やパターンを発見する手法である。主要な3手法の目的・アルゴリズム・適用例を以下に示す。

- **クラスタリング**: データのグループ分け — k-means法、階層的クラスタリング — 適用例: 顧客セグメンテーション
- **次元削減**: 変数の圧縮 — 主成分分析（PCA）、t-SNE — 適用例: 高次元データの可視化
- **異常検知**: 外れ値の検出 — Isolation Forest、LOF — 適用例: 不正検知、設備異常検知

教師なし学習はデータの探索的分析に適しており、教師あり学習の前段階としても活用される。

### 強化学習

強化学習は、エージェントが環境との相互作用を通じて、累積報酬を最大化する行動方策を学習する手法である。

正解データは存在せず、行動の結果として得られる「報酬」のフィードバックに基づいて学習を進める。

| 要素 | 説明 |
|---|---|
| **エージェント** | 学習・行動の主体 |
| **環境** | エージェントが相互作用する対象 |
| **状態** | 環境の現在の状況 |
| **行動** | エージェントが選択する操作 |
| **報酬** | 行動の結果として得られる評価値 |

ゲームAI（囲碁・将棋のAlphaGo等）、ロボット制御、自動運転、生産スケジューリングなどに適用されている。

## ディープラーニング

ディープラーニング（deep learning）は、多層のニューラルネットワークを用いた機械学習の一手法である。

従来の機械学習では人間が特徴量を設計する必要があったが、ディープラーニングではデータから特徴量の抽出自体も自動的に学習する点が革新的である。

### 主要なニューラルネットワーク

代表的なニューラルネットワーク4種の略称・特徴・主な用途を以下に整理する。

- **畳み込みニューラルネットワーク（CNN）**: 画像の局所特徴を階層的に抽出 — 主な用途: 画像認識、物体検出
- **再帰型ニューラルネットワーク（RNN/LSTM）**: 時系列データの前後関係を学習 — 主な用途: 自然言語処理、音声認識
- **Transformer**: 自己注意機構（Self-Attention）で長距離依存を処理 — 主な用途: 大規模言語モデル（GPT等）
- **敵対的生成ネットワーク（GAN）**: 生成器と識別器の競争で高品質データを生成 — 主な用途: 画像生成、データ拡張

ディープラーニングの急速な進展が、画像認識・自然言語処理・音声認識の精度を飛躍的に向上させ、[生成AI](/docs/pe-comprehensive-management-generative-ai)の登場を可能にした。

### モデルの評価指標

機械学習モデルの性能評価には、混同行列に基づく以下の指標が用いられる。

| 指標 | 計算式 | 意味 |
|---|---|---|
| **正解率（Accuracy）** | (TP + TN) / 全データ | 全体のうち正しく予測した割合 |
| **適合率（Precision）** | TP / (TP + FP) | 陽性予測のうち実際に陽性の割合 |
| **再現率（Recall）** | TP / (TP + FN) | 正しく検出できた陽性の割合 |
| **F値（F-measure）** | 適合率と再現率の調和平均 | 適合率と再現率のバランス指標 |

※ TP=真陽性、TN=真陰性、FP=偽陽性（第一種の誤り）、FN=偽陰性（第二種の誤り）

偽陽性が増加すると適合率と正解率が低下するが、再現率には影響しない点が試験で問われる。

## 総合技術監理における位置づけ


総合技術監理キーワード集では[**4.1 情報分析と情報活用**](/docs/pe-comprehensive-management-keyword-2026#41-情報分析と情報活用)に位置づけられる。

機械学習は、[データマイニング](/docs/pe-comprehensive-management-data-mining)の中核技術であり、[データクレンジング](/docs/pe-comprehensive-management-data-cleansing)で品質を確保したデータを入力として使用する。

教師なし学習の代表手法である[クラスター分析](/docs/pe-comprehensive-management-cluster-analysis)は、機械学習の重要なサブカテゴリである。

また、[IoT](/docs/pe-comprehensive-management-iot) によるセンサーデータの収集と、[デジタルツイン・CPS](/docs/pe-comprehensive-management-digital-twin-cps) によるシミュレーションは、機械学習の適用領域をさらに拡大している。過去問 [R04 Ⅰ-1-29](/docs/pe-comprehensive-management-r04-primary#1-29) では AI 利活用ガイドラインの文脈で機械学習におけるバイアス（多数派が尊重され少数派が反映されにくい傾向）が論点として取り上げられた。

過去問 [R02 Ⅰ-1-21](/docs/pe-comprehensive-management-r02-primary#1-21) では Society 5.0 における AI（機械学習）の役割として「必要な情報が必要な時に提供される」仕組みが問われた。Society 5.0 の本質は AI が自動的に解析・フィードバック する点にあり、人間が自ら解析する Society 4.0（情報社会）との識別が誤答識別の核心。

過去問 [R02 Ⅰ-1-23](/docs/pe-comprehensive-management-r02-primary#1-23) では機械学習の標準プロセス 「データ収集 → 前処理 → 学習 → モデル構築 → 推論」 の各ステップの用語が問われた。前処理 = 欠損値処理・正規化・特徴量エンジニアリング、推論 = 学習済みモデルで新しいデータを予測する段階、の識別が誤答（可視化・拡張等）との切り分けで重要。
