## 開示請求とは

**開示請求** とは、行政機関の保有する情報の公開に関する法律（情報公開法）に基づき、何人も行政機関の長に対して行政文書の開示を請求できる権利およびその手続きのことである。国民の「知る権利」を具体化する制度である。

## 開示請求の手続き

開示請求の手続きは次の5段階で進む。各ステップで行政機関と請求者の双方に義務が生じる。

| ステップ | 内容 |
|---|---|
| **1. 請求書の提出** | 行政文書開示請求書を行政機関に提出 |
| **2. 受理・補正** | 請求内容が特定できない場合は補正を求める |
| **3. 開示決定等** | 開示・部分開示・不開示の決定（原則30日以内） |
| **4. 開示の実施** | 閲覧または写しの交付 |
| **5. 不服申立て** | 決定に不服がある場合の審査請求 |

## 不開示情報（[**情報公開法第5条**](https://laws.e-gov.go.jp/law/411AC0000000042#Mp-At_5)）

情報公開法第5条は、開示の例外として次の6類型を列挙する。この類型に該当する場合でも全部不開示ではなく部分開示（可分性）が原則である。

| 類型 | 内容 |
|---|---|
| **個人情報** | 特定の個人を識別できる情報 |
| **法人情報** | 法人の正当な利益を害する情報 |
| **国の安全等** | 国の安全・外交上の利益を害する情報 |
| **公共の安全** | 犯罪の予防等に支障を及ぼす情報 |
| **審議検討情報** | 率直な意見交換を不当に損なう情報 |
| **事務事業情報** | 事務事業の適正な遂行に支障を及ぼす情報 |

## 不服申立ての仕組み

開示決定等に不服がある場合、次の3段階の不服申立て手続きが用意されている。

| 手続き | 内容 |
|---|---|
| **審査請求** | 行政機関の長に対する不服申立て |
| **情報公開・個人情報保護審査会** | 第三者機関による審査（諮問・答申） |
| **行政事件訴訟** | 裁判所への提訴も可能 |

## 建設事業との関連

建設部門の技術者が実務で開示請求に関わる主な場面は次のとおりである。

| 場面 | 内容 |
|---|---|
| **入札・契約情報** | 入札結果・契約内容の開示請求 |
| **環境アセスメント** | 環境影響評価書の閲覧・開示 |
| **設計図書** | 公共工事の設計図書の開示 |
| **事故調査報告** | 事故・災害の調査報告書の開示 |

## 情報公開制度の成立背景

情報公開法（行政機関の保有する情報の公開に関する法律）は2001年（平成13年）に施行された。1990年代の行政情報の閉鎖性に対する批判と、地方自治体での情報公開条例の先行実施（神奈川県1983年など）を受けて立法化が進んだ。成立の背景には、公共事業をめぐる不透明な意思決定への市民的関心と、OECDが提唱した「オープンガバメント」の国際潮流がある。

建設分野では大規模公共事業の入札不正問題（1994年ゼネコン汚職事件など）が情報公開への社会的要請を高め、入札・契約情報の開示が制度の重要課題となった。その後2016年の改正で「特定秘密」との調整規定が整備され、情報公開と安全保障情報の管理が法的に整合化されている。
