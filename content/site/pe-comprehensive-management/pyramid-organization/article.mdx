## ピラミッド組織とは

ピラミッド組織（pyramid organization）とは、トップを頂点として**複数の管理階層が順に広がる階層型の組織構造**である。

軍隊や官僚機構に起源を持ち、マックス・ウェーバーが提唱した「官僚制」の原則に基づく最も伝統的な組織形態である。

明確な上下関係と指揮命令系統を特徴とし、大規模組織の統制に適した構造として広く普及している。

### ウェーバーの官僚制の原則

ウェーバーはピラミッド型の階層組織を支える原則として、以下の5項目を提示した。これらが組み合わさることで、組織の予測可能性と一貫性が確保される。

| 原則 | 内容 |
|---|---|
| **階層性** | 上位者が下位者を指揮・監督する明確な序列 |
| **規則による統制** | 業務遂行の手順・基準を規則で定め、属人性を排除 |
| **専門分化** | 各ポストに明確な職務と権限を割り当てる |
| **文書主義** | 意思決定や業務記録を文書化し、継続性を確保 |
| **任命制** | 能力・資格に基づく人材の登用 |

### メリットとデメリット

階層性と規則統制を基盤とするピラミッド組織は、安定した統制力を提供する一方、その硬直性が現代の変化対応を阻む要因となる。

| 区分 | 内容 |
|---|---|
| **メリット** | |
| 指揮命令の明確さ | 上位者→下位者の一元的な命令系統で混乱が少ない |
| 責任と権限の明確化 | 各階層のポストに役割が定められている |
| 大規模組織の統制 | 多数の人員を体系的に管理できる |
| 業務の標準化・安定性 | 規則と手続きにより、一定品質の業務を継続できる |
| **デメリット** | |
| 意思決定の遅延 | 多くの階層を経由するため、承認に時間がかかる |
| 情報伝達の歪み | 階層を重ねるごとに情報が損失・変質する |
| 硬直化・形式主義 | 規則への過度な依存により、柔軟性が失われる |
| イノベーションの阻害 | 前例踏襲が優先され、新しい発想が抑制される |
| セクショナリズム | 部門の壁が高く、横の連携が弱い |

### 適する環境

ピラミッド組織の強みは定型業務の安定的な遂行にある。そのため、以下の条件が揃う環境で特に効果を発揮する。

| 条件 | 理由 |
|---|---|
| **安定した事業環境** | 定型業務の効率的な遂行に適する |
| **大規模な組織** | 多数の人員を統制する仕組みが必要 |
| **安全性・正確性が最優先** | 手続きの標準化により、ヒューマンエラーを抑制 |
| **法令遵守が重要** | 規則と文書主義が法的責任を明確にする |

### フラット組織との比較

管理階層の多寡が両者を分ける主な軸であり、それぞれ統制力と柔軟性のトレードオフを体現している。

| 比較項目 | ピラミッド組織 | フラット組織 |
|---|---|---|
| **管理階層** | 多い（5層以上） | 少ない（2〜3層） |
| **管理スパン** | 狭い | 広い |
| **意思決定** | 集権的・階層経由 | 分権的・現場主導 |
| **統制力** | 高い | 低下しやすい |
| **柔軟性** | 低い | 高い |
| **適する業務** | 定型・安全重視 | 創造・変化対応 |

## 総合技術監理における位置づけ


総合技術監理キーワード集では[**3.1 人の行動と組織**](/docs/pe-comprehensive-management-keyword-2026#31-人の行動と組織)に位置づけられる。

ピラミッド組織は安全管理の観点では指揮命令系統の明確さにより安全責任体制を確立しやすい一方、情報管理の観点では多層構造による情報伝達の遅延・歪みが課題となる。

建設業界は [労働安全衛生法](/docs/pe-comprehensive-management-occupational-safety-act) に基づく元方事業者としての安全管理体制など、ピラミッド型の階層構造を法的にも求められる場面が多い。

過去問 [R04 Ⅰ-1-13](/docs/pe-comprehensive-management-r04-primary#1-13) では、「上意下達の指揮命令系統をはっきりさせ、役割専念の専門性と分業により効率を高めた合理的な組織運営」としてピラミッド組織が問われた。
