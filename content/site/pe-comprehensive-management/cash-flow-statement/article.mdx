## キャッシュ・フロー計算書とは

キャッシュ・フロー計算書（Cash Flow Statement: C/F）とは、**資金（現金及び現金同等物）の増減を表す財務諸表**である。

損益計算書が発生主義に基づく利益を示すのに対し、キャッシュ・フロー計算書は**実際の現金の動き**を示す。利益が出ていても資金が不足すれば倒産に至る（黒字倒産）ため、企業の資金繰りの実態を把握するうえで不可欠な財務諸表である。

## キャッシュ・フローの3区分

資金の動きを**営業活動・投資活動・財務活動の 3 区分のみ**で分類して表示する。「社会貢献活動」「臨時活動」など他の独立区分は存在せず、試験では誤り選択肢として頻出する。3 区分の合計が、期中の**現金及び現金同等物の増減額**となる。

3 区分は「**何の現金か**」「**どの取引で増減するか**」「**符号をどう読むか**」で性格が異なる。営業＝本業の稼ぐ力、投資＝将来への投資姿勢、財務＝資金の調達と返済、と役割を切り分けて捉えると分類問題が解きやすくなる。

<ArticleImage
  src="/posts/pe-comprehensive-management/cash-flow-statement/img/figure-cf-three-sections.svg"
  alt="営業・投資・財務キャッシュ・フローの違い：何の現金か、流入と流出の取引例、望ましい符号の読み方を3区分で比較"
/>

符号の読み方が区分ごとに異なる点が要注意である。営業 CF はプラスであるべき（本業で稼げている）が、投資 CF はマイナスがむしろ前向き（将来へ投資中）、財務 CF はマイナスが返済＝負担減で健全と、同じマイナスでも意味が逆になる。

### 営業活動によるCF

本業で稼いだ資金の動きで、企業の**稼ぐ力**を示す中核指標である。

- **流入（＋）**: 商品販売・サービス提供による収入、売上債権の回収
- **流出（−）**: 仕入代金の支払、人件費、一般管理費、法人税等の支払

<Callout type="note" title="営業CFに含まれる臨時項目">
営業活動 CF は「投資活動・財務活動以外の取引」を包含する区分のため、損害賠償金の支払や災害損失の受取保険金といった**臨時的な項目**もここに入る。「営業=本業のみ」と直感すると誤分類しやすく、試験の引っかけ肢として頻出する。
</Callout>

### 投資活動によるCF

将来の収益獲得や資産運用のための支出入。企業の**成長投資姿勢**を示す。

- **流入（＋）**: 有価証券の売却、固定資産の売却、貸付金の回収
- **流出（−）**: 有価証券の取得、固定資産の取得、貸付金の実行

### 財務活動によるCF

資金調達と返済の動き。**資本構成の変動**を示す。

- **流入（＋）**: 借入金の借入、社債の発行、株式の発行（増資）
- **流出（−）**: 借入金の返済、社債の償還、自己株式の取得、配当金の支払

### 投資CFと財務CFの見分け方

投資 CF と財務 CF はどちらも「お金」や「株式・社債」が登場するため混同しやすいが、見分けの軸は **「お金の運用か、お金の調達・返済か」**の一点である。投資 CF は余剰資金を**何に投じたか／何を売って回収したか**という資産の動き（貸借対照表の左側）、財務 CF は事業の元手を**どこから調達し・どう返したか**という負債・純資産の動き（右側）を表す。

<ArticleImage
  src="/posts/pe-comprehensive-management/cash-flow-statement/img/figure-cf-investing-vs-financing.svg"
  alt="投資CFと財務CFの見分け方：投資はお金の運用で資産が動き、財務はお金の調達と返済で負債・純資産が動く。株式・社債・貸借の紛らわしい3組を投資と財務に振り分けて比較"
/>

混乱の原因は、**同じ「株式」「社債」「貸し借り」でも自分がどちら側かで区分が逆**になる点にある。**相手の証券を持つ（取得・売却）＝投資**、**自分の証券を出す（発行・自社株買い）＝財務**。同様に**お金を貸す（貸付金）＝投資**、**お金を借りる（借入金）＝財務**である。他社株の購入は投資 CF だが自社の増資は財務 CF、他社への貸付は投資 CF だが銀行からの借入は財務 CF、と「自分がどちら側か」で判断すれば取り違えない。

### 利息・配当の表示区分

利息・配当の表示区分は会計基準で異なり、試験頻出論点である。

| 項目 | 日本基準（原則） | IFRS（選択可） |
|---|---|---|
| 受取利息・配当金 | 営業 CF | 営業 or 投資 CF |
| 支払利息 | 営業 CF | 営業 or 財務 CF |
| 支払配当金 | 財務 CF | 営業 or 財務 CF |

日本基準は区分を**固定**するのに対し、IFRS は企業の判断で**選択可**である点が要点。

### 各区分の読み方

3 区分の符号の組合せから企業の状況を類型化できる。

- **営業 CF ＋ / 投資 CF − / 財務 CF −**: 健全な成熟企業の典型（本業で稼ぎ、成長投資と借入返済を両立）
- **営業 CF ＋ / 投資 CF − / 財務 CF ＋**: 成長期（稼ぎながら追加資金を調達して積極投資）
- **営業 CF − / 投資 CF ＋ / 財務 CF ＋**: 資金繰りが厳しい（資産売却と借入でしのぐ要注意状態）
- **営業 CF ＋ / 投資 CF ＋ / 財務 CF −**: 縮小・撤退期（資産を売却して借入を返済）

営業 CF がマイナスのまま複数期続く企業は、本業で稼げていないため**黒字倒産のリスクが高い**と判断される。

## 直接法と間接法

営業活動 CF の表示方法には**直接法**と**間接法**の 2 つがある。

- **直接法**: 営業収入・仕入支出等を直接集計する方法。キャッシュの流れが**直感的に把握できる**利点があるが、総勘定元帳から個別集計が必要で作成負荷が大きい。実務での採用は少数
- **間接法**: 税引前当期純利益に非現金項目を加減算する方法。**損益計算書から機械的に作成できる**ため実務では大多数が採用。利益からキャッシュへの調整プロセスが可視化され、利益と CF の乖離要因を分析しやすい

### 間接法の主な調整項目

間接法では、[減価償却](/docs/pe-comprehensive-management-depreciation)費のような**現金支出を伴わない費用**を加算し、運転資本の増減を調整する。

- **加算項目**: 減価償却費・引当金の増加・支払手形/買掛金（仕入債務）の増加
- **減算項目**: 売上債権の増加・棚卸資産の増加

過去問 [R03 Ⅰ-1-7](/docs/pe-comprehensive-management-r03-primary#1-7) では「売上債権の増加はプラス調整、仕入債務の増加はマイナス調整」という **逆の誤答** が出題された。売上債権↑は現金未回収なのでマイナス、仕入債務↑は現金未支払なのでプラスが正しい。

運転資本（売上債権・棚卸資産・買入債務）の増減は、利益と CF が一致しない主要因である。

### 3区分ごとの増減マトリクス

営業・投資・財務の各 CF について「どの取引が現金を増やし、どの取引が減らすか」を 1 枚に整理すると、試験での分類問題が機械的に解けるようになる。

<ArticleImage
  src="/posts/pe-comprehensive-management/cash-flow-statement/img/figure-cf-changes-matrix.svg"
  alt="キャッシュ・フローの増減マトリクス：営業・投資・財務の3区分それぞれで現金を増やす取引と減らす取引の対応"
/>

マトリクスは次の**調整原則**から導かれる（貸借対照表の借方・貸方と対応）。

- **資産の増加 → 現金の減少**（取得・投下が発生）／**資産の減少 → 現金の増加**（売却・回収が発生）
- **負債・純資産の増加 → 現金の増加**（借入・増資で資金流入）／**負債・純資産の減少 → 現金の減少**（返済・自社株買・配当で資金流出）

この原則が、営業 CF では運転資本（売上債権・棚卸資産・買入債務）の増減として、投資 CF では固定資産・有価証券・貸付金の取得/売却として、財務 CF では借入・返済・増資・配当として現れる。

### 減価償却費の自己金融効果

減価償却費は損益計算書では費用として計上されるが、実際の現金流出はない（過去に固定資産を取得した際に支出済み）。そのため、減価償却費の分だけ**企業内部に資金が留保される**効果が生じ、これを**自己金融効果**（内部留保効果）と呼ぶ。

- 損益上の費用計上で利益は減り、法人税等の減少要因となる
- 減価償却費分の現金は支出されず、企業内に再投資や借入返済の原資として残る
- 間接法の営業活動 CF で税引前当期純利益に減価償却費を加算するのは、この自己金融効果を定量的に可視化する処理である

設備投資を継続する企業にとって、減価償却費は**設備更新の内部資金源**として機能する。

## フリーキャッシュフロー

**フリーキャッシュフロー（FCF）** とは、企業が事業活動から獲得し、自由に使える資金のことで、次の式で求める。

$$
FCF = \text{営業CF} + \text{投資CF}
$$

FCF は、借入返済・株主還元（配当・自社株買い）・新規投資などの原資となる。成長投資を継続しながら FCF がプラスを維持できる企業は財務的に健全とみなされる。[NPV](/docs/pe-comprehensive-management-npv-net-present-value) や [DCF 法](/docs/pe-comprehensive-management-dcf-method)の企業価値評価においても、将来 FCF の現在価値が企業価値の中核となる。

<Callout type="warn" title="FCF の定義の引っかけ">
FCF は「営業 CF ＋ 投資 CF」であり、**「投資 CF ＋ 財務 CF」ではない**。財務 CF（借入・返済・配当）は FCF に含まれない点が試験の頻出引っかけ肢として出題される。FCF は「財務活動に入る前の、事業から生み出される自由資金」を表すため、財務活動と区別される。
</Callout>

## 財務三表における位置づけ

キャッシュ・フロー計算書は、[貸借対照表（B/S）](/docs/pe-comprehensive-management-balance-sheet)および[損益計算書（P/L）](/docs/pe-comprehensive-management-income-statement)とあわせて**財務三表**を構成する。

- キャッシュ・フロー計算書の期末残高は**貸借対照表の「現金及び預金（現金同等物）」と一致**する
- 間接法の起点は**損益計算書の税引前当期純利益**である

### 流動資産との違い

CF 計算書の期末残高が一致するのは B/S の**現金及び現金同等物のみ**であって、**流動資産の総額ではない**点に注意が必要である。

- **流動資産**: 現金及び預金 + **売上債権**（売掛金・受取手形）+ **棚卸資産** + その他の流動資産
- **現金及び現金同等物**: 現金 + 預金 + 3 ヶ月以内に満期が到来する短期投資

売上債権や棚卸資産は流動資産ではあるが**現金化まで時間がかかる**ため、CF 計算書の「現金及び現金同等物」には含まれない。試験では「流動資産の総額 = CF 期末残高」という誤り選択肢が繰り返し出題されている。

### B/S 残高項目は CF に記載されない

CF 計算書は**現金の増減（フロー）** を示す計算書であり、B/S の**残高項目（ストック）そのもの**は記載されない。

- **記載されない例**: 資本金・利益剰余金・借入金残高・売掛金残高
- **記載される例**: 株式の発行（増資）・借入金の借入/返済・売掛金の回収による現金増減

H23 出題で「資本金は CF のどの区分に入るか」を問う誤り肢として出題されている。資本金は**残高概念（B/S 項目）** なので CF 計算書のどの区分にも記載されない（株式発行という取引があれば財務 CF に現金増として記載される）。

3 表を横断的に読むことで、利益・資産・キャッシュの関係を立体的に把握できる。

## 総合技術監理における位置づけ


総合技術監理キーワード集では[**2.5 財務会計**](/docs/pe-comprehensive-management-keyword-2026#25-財務会計)に位置づけられている。

総合技術監理者として、設備投資の意思決定やプロジェクトの経済性評価を行う際、利益だけでなく**資金の流れ**を把握することが重要である。

**建設プロジェクトでの特性**: 大規模な建設プロジェクトは工事期間が長く、工事進行基準による売上計上と出来高払いのタイミングにずれが生じやすい。前払金・中間前払金・出来高払金の受領と、労務費・資材費の支払時期が一致しないため、工事段階ごとに資金繰り計画を立てる必要がある。キャッシュ・フロー管理は事業継続（[BCP](/docs/pe-comprehensive-management-business-continuity-plan) の財務版）の鍵となる。

**投資意思決定との関係**: [投資回収計画](/docs/pe-comprehensive-management-investment-recovery-plan)・[NPV](/docs/pe-comprehensive-management-npv-net-present-value)・[回収期間法](/docs/pe-comprehensive-management-payback-period-method) など投資評価手法はいずれもキャッシュフローに基づく。損益計算書の利益ではなくキャッシュで評価する理由は、貨幣の時間価値を扱う計算に会計上の利益は馴染まないためである。

過去問 [R04 Ⅰ-1-1](/docs/pe-comprehensive-management-r04-primary#1-1) では CF 計算書の 3 区分（営業・投資・財務）の分類が問われ、「社会貢献活動」の独立区分は存在しないという誤答が出題された（株式発行収入は財務 CF、貸付金回収・固定資産売却は投資 CF、販売収入は営業 CF）。過去問 [R02 Ⅰ-1-7](/docs/pe-comprehensive-management-r02-primary#1-7) では、**間接法 CF 計算書では減価償却費を税引前利益に加え戻す**（非資金費用の加算）点が正答として問われ、またフリー CF の定義が「営業 CF + 投資 CF」（財務 CF は含まない）である点も論点となった。

[国際会計基準（IFRS）](/docs/pe-comprehensive-management-ifrs)の適用下では、支払利息・受取利息・配当の表示区分にも差異が生じる場合がある点に留意が必要である。
