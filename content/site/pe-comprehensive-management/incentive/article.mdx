## インセンティブとは

**インセンティブ（Incentive）** とは、個人や集団の行動を特定の方向へ誘導するための誘因・刺激のことである。

経済学では「合理的な行為者が報酬や罰に応じて行動を選択する」という前提に基づき、組織管理では従業員の動機付けと成果向上のための制度設計として活用される。

チェスター・バーナードは組織均衡理論において、組織が存続するためにはメンバーへの「誘因（インセンティブ）」がメンバーの「貢献」を上回る必要があると論じた。

### インセンティブの分類

インセンティブは「金銭的・非金銭的」「正・負」「個人・集団」の3軸で分類できる。それぞれの種類・内容・具体例を以下に示す。

- **金銭的・非金銭的**
  - 金銭的インセンティブ — 報酬・手当・賞与など経済的対価（成果給、業績ボーナス、ストックオプション）
  - 非金銭的インセンティブ — 承認・成長機会・職場環境など（表彰、昇進機会、裁量権の付与、福利厚生）
- **正・負**
  - 正のインセンティブ — 望ましい行動への報酬（目標達成時のボーナス、資格取得支援）
  - 負のインセンティブ — 望ましくない行動への罰・不利益（減給、降格、ペナルティ）
- **個人・集団**
  - 個人インセンティブ — 個人の成果に連動（個人業績給、営業歩合）
  - 集団インセンティブ — チームや組織の成果に連動（部門業績賞与、利益配分制度）

### 教材『人的資源管理』の 5 分類と 3 行動パターン

教材『人的資源管理』では、インセンティブを以下の **5 分類** で整理している（金銭的か否かではなく、満たされる欲求の質で区分）。

/>

- **物質的インセンティブ** — 給与・賞与・報奨金など金銭的な報酬で個人の欲求を満たす
- **評価的インセンティブ** — 表彰などの評価や公の賞賛により「自分も評価されたい」欲求を刺激する
- **人的インセンティブ** — 職場内の人間関係（尊敬する上司の下で働ける、雰囲気の良い職場など）で個人の欲求を満たす
- **理念的インセンティブ** — 仕事への自信や達成意欲が高まるような誘因
- **自己実現インセンティブ** — 自分の能力を十分に発揮できたり、自己の可能性を拡げられるという実感が持てる誘因

また、人の行動パターンを以下の **3 類型**に区分し、各個人の指向や特性に応じて 5 分類のインセンティブを組み合わせて運用する必要があるとされる。

- **経済的行動** — 利害を優先した行動
- **情緒的行動** — 感情に支配された行動
- **管理的行動** — 合理的な思考に従った行動

### バーナードの誘因理論

バーナードは組織が提供する誘因を以下の4種類に分類し、金銭的報酬だけでなく非経済的な誘因の重要性を強調した。

| 誘因の種類 | 内容 |
|---|---|
| **物質的誘因** | 金銭、物品など経済的な報酬 |
| **個人的で非物質的な機会** | 威信、権力、地位など個人的な満足 |
| **好ましい物的条件** | 快適な職場環境、労働条件 |
| **理想の恩恵** | 組織の使命・理念への共感、社会貢献の実感 |

### インセンティブ制度の設計原則

実効性の高いインセンティブ制度を構築するには、以下の5つの設計原則を満たす必要がある。

| 設計原則 | 内容 |
|---|---|
| **明確性** | 何をすれば報酬が得られるかが具体的に示されていること |
| **公平性** | 貢献に見合った報酬配分がなされること |
| **即時性** | 行動と報酬の時間的距離が短いこと |
| **個別適合性** | メンバーの価値観やニーズに合った誘因であること |
| **持続可能性** | 組織の財務的・運営的に継続可能な設計であること |

### インセンティブの副作用

外的報酬に依存するインセンティブ設計は、意図しない行動変容や組織機能の歪みを引き起こすことがある。代表的な副作用を以下に示す。

| 副作用 | 内容 |
|---|---|
| **アンダーマイニング効果** | 外的報酬が内発的動機を低下させる現象 |
| **短期志向の助長** | 成果指標に直結する行動のみに注力し、長期的な価値創造が軽視される |
| **モラルハザード** | 成果の捏造やフリーライダーの発生 |
| **過度な競争** | 個人インセンティブがチーム協力を阻害する |
| **指標のゆがみ** | 測定しやすい指標のみが追求され、測定困難な重要業務が無視される |

## 総合技術監理における位置づけ


総合技術監理キーワード集では[**3.1 人の行動と組織**](/docs/pe-comprehensive-management-keyword-2026#31-人の行動と組織)に位置づけられる。

インセンティブ設計は人的資源管理の中核であると同時に、経済性管理（報酬コストと生産性のバランス）や安全管理（安全行動への正のインセンティブ）とも密接に関連する。

総合技術監理技術者は、金銭的報酬だけでなく非金銭的な誘因も含めた総合的なインセンティブ設計を行い、副作用（[アンダーマイニング効果](/docs/pe-comprehensive-management-intrinsic-motivation)、短期志向など）にも配慮する視点が求められる。[安全管理](/docs/pe-comprehensive-management-safety-control)の文脈では、安全行動への正のインセンティブ設計が事故防止に直結する。[組織コミットメント](/docs/pe-comprehensive-management-organizational-commitment) の 3 次元（情緒的・功利的・規範的）と結びつけて設計することが過去問 [R04 Ⅰ-1-14](/docs/pe-comprehensive-management-r04-primary#1-14) でも問われた。

## インセンティブ概念の歴史的背景

インセンティブが組織管理の中核概念として確立されたのは20世紀前半のことである。

経営学の古典的著作であるチェスター・バーナード『経営者の役割』（1938年）は、組織が存続するためには構成員への「誘因」が「貢献」を上回らなければならないという組織均衡理論を提示した。それまでの古典的管理論が命令・統制に重点を置いていたのに対し、バーナードは**非経済的な誘因**（威信、理念への共感など）の重要性を初めて体系化した点で画期的だった。

1960年代にはダグラス・マクレガーのX理論・Y理論が登場し、人間観の違いによってインセンティブ設計が根本的に変わることが示された。1970年代にはエドワード・デシらの研究によりアンダーマイニング効果が実験的に確認され、「外的報酬が必ずしも動機を高めるわけではない」という逆説的な知見が広まった。

1990年代以降は成果主義賃金の導入とともに、インセンティブ設計の副作用（短期志向、指標のゆがみ、モラルハザード）が実務的な問題として顕在化した。総合技術監理では、こうした歴史的知見を踏まえた上で、技術組織に適した誘因体系を構築することが求められる。
