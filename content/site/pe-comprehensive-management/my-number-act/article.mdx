## マイナンバー法とは

**マイナンバー法**（正式名称：行政手続における特定の個人を識別するための番号の利用等に関する法律）とは、国民一人ひとりに12桁の個人番号（マイナンバー）を付番し、社会保障・税・災害対策の分野で行政手続きの効率化と公正な給付・負担の確保を図る法律である（2013年制定、2016年運用開始）。

マイナンバーは個人情報保護法における「個人識別符号」に該当するが、その取扱いには個人情報保護法よりも**厳格な特別法としての規制**が適用される。

法人には13桁の法人番号が付番され、こちらは原則公開される。

## 制度の概要

| 項目 | 内容 |
|---|---|
| **個人番号** | 住民票を有する全国民に付番される12桁の番号 |
| **法人番号** | 法人等に付番される13桁の番号（原則公開） |
| **利用範囲** | 社会保障、税、災害対策（法定された事務に限定） |
| **マイナンバーカード** | ICチップ搭載の本人確認書類。電子証明書による公的個人認証が可能 |
| **情報提供ネットワークシステム** | 行政機関間の情報連携基盤 |
| **マイナポータル** | 国民が自分の情報を確認できるオンラインサービス |

## 個人番号の利用範囲

マイナンバーの利用は法律で定められた事務に**厳格に限定**されている。

| 分野 | 具体的な利用事務 |
|---|---|
| **社会保障** | 年金、雇用保険、医療保険、生活保護、児童手当 |
| **税** | 確定申告、年末調整、法定調書の作成・提出 |
| **災害対策** | 被災者台帳の作成、被災者生活再建支援金の支給 |

上記以外の目的での利用・収集は原則として禁止されている。

## 特定個人情報の保護

マイナンバーを含む個人情報は「**特定個人情報**」と定義され、通常の個人情報よりも厳格な保護措置が課される。

- **収集・保管**: 個人情報保護法は利用目的の範囲内で許容されるが、特定個人情報は**利用事務に必要な場合に限定**される
- **第三者提供**: 個人情報保護法は本人同意があれば可能だが、特定個人情報は**法定の場合を除き禁止（本人同意でも不可）**
- **オプトアウト**: 個人情報保護法は一定条件下で可能だが、特定個人情報は**全面禁止**
- **目的外利用**: 個人情報保護法は本人同意があれば可能だが、特定個人情報は**法定の場合を除き禁止**
- **監督機関**: いずれも個人情報保護委員会だが、特定個人情報については同委員会が**特別の監視・監督権限**を有する

## 事業者の義務

| 義務 | 内容 |
|---|---|
| **利用目的の明示** | 番号の取得時に利用目的を本人に通知 |
| **本人確認** | 番号の提供を受ける際に本人確認（番号確認＋身元確認） |
| **安全管理措置** | 組織的・人的・物理的・技術的安全管理措置の実施 |
| **特定個人情報保護評価（PIA）** | 行政機関が特定個人情報ファイルを保有する際に実施する影響評価 |
| **廃棄** | 利用事務の終了後、速やかに廃棄または削除 |
| **委託先の監督** | 委託先・再委託先の安全管理を監督 |

## 違反時の制裁

マイナンバー法の罰則は個人情報保護法よりも**重い刑罰**が設定されている。

| 違反行為 | 制裁 |
|---|---|
| **正当な理由なく特定個人情報ファイルを提供** | 4年以下の懲役または200万円以下の罰金（またはこれの併科） |
| **不正な利益を図る目的での提供・盗用** | 3年以下の懲役または150万円以下の罰金（またはこれの併科） |
| **情報提供ネットワークシステムに関する秘密の漏洩** | 3年以下の懲役または150万円以下の罰金（またはこれの併科） |
| **詐欺等による個人番号の取得** | 6月以下の懲役または50万円以下の罰金 |
| **個人情報保護委員会の命令違反** | 2年以下の懲役または50万円以下の罰金 |
