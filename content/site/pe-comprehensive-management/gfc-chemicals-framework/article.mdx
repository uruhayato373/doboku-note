## GFCとは

GFC（Global Framework on Chemicals - For a Planet Free of Harm from Chemicals and Waste）は、化学物質と廃棄物の適正管理に関する世界的枠組みであり、2023年9月の第5回国際化学物質管理会議（ICCM5）で採択された。

SAICM（国際的な化学物質管理のための戦略的アプローチ、2006〜2020年）の後継枠組みとして策定された。

「化学物質と廃棄物による害のない地球」をビジョンに掲げ、2030年以降も継続する長期的な国際協力の基盤を提供するものである。

### SAICMからGFCへの経緯

SAICMの採択から失効、そしてGFCへの移行は以下の流れで進んだ。

| 時期 | 事項 |
|---|---|
| **2002年** | WSSD（持続可能な開発に関する世界首脳会議）で2020年目標を設定 |
| **2006年** | SAICM採択（ICCM1、ドバイ） |
| **2020年** | SAICM目標期限到来、多くの目標が未達成 |
| **2021〜2023年** | 後継枠組みの交渉（IP4, OEWG等） |
| **2023年9月** | ICCM5（ボン）でGFC採択 |

### 5つの戦略目標

GFCは化学物質管理の課題を5つの戦略目標（A〜E）に体系化している。

| 戦略目標 | 内容 |
|---|---|
| **A. リスク削減の強化** | 懸念の高い化学物質のリスク削減措置を各国が実施 |
| **B. 知識と情報** | 化学物質の危険有害性・リスクに関する科学的知見の生成・共有 |
| **C. 課題への対処** | 高懸念物質（PFAS、内分泌かく乱物質、医薬品汚染等）への具体的対応 |
| **D. 安全な代替品・革新的解決策** | グリーンケミストリー、安全な代替品の開発・普及 |
| **E. 実施体制の強化** | 能力構築、技術協力、資金メカニズムの整備 |

### SAICMとの比較

GFCはSAICMを引き継ぎつつ、対象範囲と実施体制の両面で拡充された。主な変更点は以下のとおりである。

- **期限**: SAICM（2006〜2020年）は2020年まで — GFC（2023年〜）は期限なし（長期的枠組み）
- **対象**: SAICM は化学物質のライフサイクル管理 — GFCは化学物質＋廃棄物の統合管理
- **法的拘束力**: SAICM はなし（自主的） — GFCもなし（ただし進捗報告を強化）
- **高懸念課題**: SAICM では新規課題（emerging policy issues）として対応 — GFCは戦略目標Cで明確に位置づけ
- **資金**: SAICM はQSP（Quick Start Programme） — GFCは統合的な能力構築・資金メカニズム

### 対象となる高懸念物質

GFCの戦略目標Cでは、以下の物質群を特定して対応を求めている。

| 物質群 | 概要 |
|---|---|
| **PFAS（有機フッ素化合物）** | 難分解性、「永遠の化学物質」と呼ばれる |
| **内分泌かく乱物質** | ホルモン作用を撹乱し、生殖・発達に影響 |
| **医薬品・パーソナルケア製品** | 排水を通じた水環境汚染 |
| **鉛塗料** | 途上国で依然として使用、子どもの健康被害 |
| **高毒性農薬（HHPs）** | 途上国での不適正使用による健康・環境被害 |

### 日本の対応

GFCを受けて日本は関係省庁連絡会議を設置し、以下の施策を推進している。

- **国内実施計画**: 化学物質管理に関する各省庁連携施策の推進
- **化学物質管理法制**: 化審法、化管法（PRTR法）等の国内法で対応
- **GHS分類**: 化学品の分類及び表示に関する世界調和システムの国内導入済み
- **国際協力**: アジア太平洋地域への能力構築支援

## 総合技術監理における位置づけ


総合技術監理キーワード集では[**6.2 地域環境問題**](/docs/pe-comprehensive-management-keyword-2026#62-地域環境問題)に位置づけられる。

GFCは化学物質のライフサイクル全体を対象とする国際的な管理枠組みであり、国内の[化審法](/docs/pe-comprehensive-management-chemical-substances-review-act)・化管法等の法制度や、企業のサプライチェーン管理と直結する。経済性管理（代替物質への転換コスト）と社会環境管理（化学物質[リスク](/docs/pe-comprehensive-management-risk)の低減）のバランスが問われるテーマである。

## 国際化学物質管理をめぐる背景

化学物質による環境・健康被害への国際的な関心は、1960〜70年代の先進国における農薬・有機水銀汚染（DDT問題、水俣病等）を契機に高まった。1992年のリオ地球サミットではアジェンダ21が採択され、化学物質の安全管理が持続可能な開発の重要課題として位置づけられた。

2002年のWSSD（ヨハネスブルク・サミット）では「2020年までに化学物質の製造・使用による人の健康と環境への著しい悪影響を最小化する」という目標（2020年目標）が合意され、これを受けてSAICMが2006年に採択された。

しかし2020年時点でSAICMの目標は多くが未達成に終わった。PFAS汚染の深刻化、マイクロプラスチック問題の顕在化、プラネタリーバウンダリーへの関心の高まりなど、SAICMが想定していなかった新たな課題が次々と浮上したことも、後継枠組みの必要性を後押しした。

こうした経緯を経て、2023年9月にドイツ・ボンで開催されたICCM5でGFCが採択された。GFCはSAICMの経験を踏まえつつ、廃棄物管理を統合した広範な枠組みとして再構築されたものである。
