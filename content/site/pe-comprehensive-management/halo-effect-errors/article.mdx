## 評価誤差とは

評価誤差とは、**人事評価において考課者の心理的傾向により生じる系統的な偏り**である。適正な評価を阻害する要因となる。

## 主な評価誤差

代表的な評価誤差を以下に整理する。考課者訓練ではこれらの類型を体系的に学習し、自己認識を高めることが防止の出発点となる。

/>

| 評価誤差 | 内容 |
|---|---|
| **ハロー効果** | ある特性の印象に引きずられ、他の評価項目まで同様に評価してしまう |
| **寛大化傾向** | 全体的に甘い評価をつける傾向 |
| **厳格化傾向** | 全体的に厳しい評価をつける傾向 |
| **中心化傾向** | 評価が中央値に集中し、差がつかない傾向 |
| **論理的誤差** | 関連がありそうな評価項目を論理的に同じ評価にしてしまう |
| **対比誤差** | 考課者自身の能力を基準にして評価してしまう |
| **近接誤差** | 評価期間の直近の出来事に影響されやすい傾向 |

## 評価誤差の防止策

評価誤差は考課者が無意識に陥りやすい認知的偏りであるため、組織的な対策が必要になる。個人の努力に依存するのではなく、制度と訓練の両面から防止することが実効性を高める。

- **考課者訓練**: 評価誤差の類型と防止法を体系的に学習する
- **評価基準の明確化**: 行動レベルで具体的な基準を設定する
- **多面評価の導入**: 複数の評価者による偏り軽減
- **評価調整会議**: 考課者間の評価水準を擦り合わせる

## ハロー効果の命名背景と評価誤差研究の展開

評価誤差の概念は、20 世紀初頭の心理学研究に端を発する。ハロー効果という名称を初めて用いたのは米国の心理学者エドワード・ソーンダイク（Edward Thorndike）であり、1920 年の論文「A Constant Error in Psychological Ratings」でこの現象を定式化した。ハロー（halo）とは聖人の頭上に描かれる光輪を指し、ある際立った特性の「光」が他の特性にまで照らし広がる様を比喩したものである。

産業・組織心理学の分野では、1950 年代以降に評価誤差の体系的な研究が進んだ。ハロー効果のほか、寛大化傾向・厳格化傾向・中心化傾向・対比誤差などが同定され、これらを「評価誤差訓練（Rater Error Training）」によって低減できることが実証された。しかし後の研究では、誤差を減らすだけでは正確な評価精度が上がらないことも明らかになり、評価枠組み訓練（Frame-of-Reference Training）や行動観察訓練（Behavioral Observation Training）など、より精緻な考課者訓練が開発されてきた。

日本の企業・行政における人事評価制度では、考課者訓練を通じた評価誤差の抑制が広く実施されており、特に公務部門では人事院・内閣人事局が評価者向けガイドの中でハロー効果を含む評価誤差の認識と防止を明示している。総監技術者は、組織管理者として評価誤差の研究的背景を踏まえ、自組織の評価制度の妥当性を検討する視点を持つことが望ましい。

## 総合技術監理における位置づけ

総合技術監理キーワード集では[**3.4 人材開発**](/docs/pe-comprehensive-management-keyword-2026#34-人材開発)に位置づけられている。

評価誤差は[人事考課の三原則](/docs/pe-comprehensive-management-appraisal-three-principles)の客観の原則に反する事象であり、[バイアス](/docs/pe-comprehensive-management-evaluation-bias)の一類型として人事評価の信頼性に直結する課題である。

5 管理の観点では、評価誤差の放置は人的資源管理の信頼性を損なうだけでなく、組織のモチベーション低下を通じて経済性管理（生産性）にも影響する。総監技術者は、部下の業績評価を行う立場として評価誤差の抑制に責任を持つとともに、組織として考課者訓練の仕組みを整備する視点が求められる。

過去問 [R02 Ⅰ-1-16](/docs/pe-comprehensive-management-r02-primary#1-16) では「ハロー効果 = 個人的な親しみを感じることで生じる評価誤差」という誤答が出題された。ハロー効果は「ある一点の優秀さが他の評価項目にも波及する」認知バイアスであり、個人的親しみによる誤差（= 親近効果・個人的接触誤差）とは区別される点が誤答識別の核心。
