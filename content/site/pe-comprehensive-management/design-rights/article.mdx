## 意匠権とは

**意匠権** とは、**物品、建築物又は画像のデザイン**（視覚を通じて美感を起こさせるもの）を独占的に実施できる権利である。

意匠法（昭和34年法律第125号）に基づき、特許庁への出願・実体審査・登録を経て権利が発生する。

存続期間は**出願の日から25年**であり、2020年の法改正により従前の「登録の日から20年」から大幅に延長された。

[**意匠法第1条**](https://laws.e-gov.go.jp/law/334AC0000000125#Mp-At_1)は「意匠の保護及び利用を図ることにより、意匠の創作を奨励し、もって産業の発達に寄与すること」を目的として規定している。意匠は「物品や物品の部分の形状、模様、色彩又はこれらの結合で、**視覚を通じて美感を起こさせるもの**」と定義され、肉眼で視覚的にとらえられることが要件となる点が他の産業財産権との差分である。

### 意匠法の保護対象

2020年の意匠法改正により、保護対象が大幅に拡大された。各保護対象の内容と代表例は以下のとおりである。

- **物品の意匠**: 物品の形状・模様・色彩又はこれらの結合 — 自動車・家具・容器のデザイン
- **建築物の意匠**: 建築物の形状等（2020年改正で追加） — 商業施設の外観・住宅のデザイン
- **画像の意匠**: 機器に表示される画像（2020年改正で拡充） — GUI・アイコン等
- **部分意匠**: 物品等の部分のデザイン — スマートフォンの背面カメラ部分のデザイン
- **組物の意匠**: 一組の物品全体のデザイン — 一組の食器セット

### 登録要件

意匠登録を受けるには、以下の要件をすべて満たす必要がある。

| 要件 | 内容 |
|---|---|
| **工業上の利用可能性** | 工業的に量産できるものであること |
| **新規性** | 出願前に公知でないこと |
| **創作非容易性** | 当業者が容易に創作できたものでないこと（特許法の「進歩性」に相当） |
| **先願であること** | 同一・類似の意匠は最先の出願のみが登録される |
| **不登録事由に該当しないこと** | 公序良俗に反するデザイン、他人の業務と混同を生ずるもの等でないこと |

### 出願・登録の手続

意匠権の取得は、出願から設定登録まで以下の段階を経る。

| 段階 | 内容 |
|---|---|
| **出願** | 願書と図面（6面図等）を特許庁に提出する |
| **方式審査** | 書類の形式要件を審査する |
| **実体審査** | 新規性・創作非容易性等の登録要件を審査する |
| **登録査定** | 登録要件を満たすと判断された場合に発行される |
| **設定登録** | 登録料の納付により意匠権が発生する |
| **意匠公報** | 登録内容が公報に掲載される（秘密意匠の場合を除く） |

### 関連意匠制度

**関連意匠制度** は、基本となる意匠（本意匠）に類似するバリエーションデザインを保護する制度である。

- **目的**: 一つのデザインコンセプトから生まれるバリエーションを一体的に保護する
- **出願期間**: 本意匠の出願日から10年以内に出願可能（2020年改正で延長）
- **類似の範囲**: 本意匠に類似する意匠のみ登録可能
- **存続期間**: 基礎意匠の出願日から25年
- **意義**: デザイン戦略の幅を広げ、模倣品対策の実効性を高める

### 秘密意匠制度

出願人の請求により、登録後最長3年間、意匠の内容を秘密にできる制度である。

新製品の発売前にデザインが競合他社に知られることを防ぐ目的で利用される。

### 侵害時の救済

意匠権が侵害された場合、権利者は以下の救済手段をとることができる。

| 救済手段 | 内容 |
|---|---|
| **差止請求（37条）** | 侵害行為の停止・予防、侵害品の廃棄を請求できる |
| **損害賠償請求** | 意匠法に損害額の推定規定があり、立証負担が軽減される |
| **信用回復措置（41条で準用）** | 業務上の信用を回復するための措置を請求できる |
| **刑事罰** | 意匠権侵害は10年以下の懲役または1000万円以下の罰金 |

## 意匠制度の歴史と背景

日本における意匠保護の制度的起源は、1888年（明治21年）に制定された**意匠条例**にさかのぼる。当時、殖産興業・輸出振興を国策とした明治政府は、工芸品・染織品のデザインを模倣から守る必要性を認識し、欧州の意匠立法を参照しながら独自の保護制度を整備した。

その後、1921年（大正10年）に意匠法として全面改正され、1959年（昭和34年）の現行意匠法（昭和34年法律第125号）制定に至る。この昭和34年法が現在まで基本骨格を維持しつつ、時代とともに改正を重ねてきた。

### 主要な改正の流れ

現行意匠法（昭和34年法律第125号）は時代の変化に応じて繰り返し改正されてきた。主な改正の経緯は以下のとおりである。

| 時期 | 改正の要点 |
|---|---|
| 1921年（大正10年） | 意匠法として初の全面改正。工業デザイン保護を強化 |
| 1959年（昭和34年） | 現行意匠法制定。物品単位の保護体系を確立 |
| 1998年（平成10年） | 部分意匠制度を導入。物品の一部分のみの保護が可能に |
| 2006年（平成18年） | 存続期間を登録から15年→20年に延長 |
| 2020年（令和2年） | 保護対象を建築物・画像意匠へ拡大、関連意匠の出願期間延長、存続期間を出願から25年に変更 |

2020年改正の背景には、デジタル化・サービス化の進展がある。スマートフォンのGUIや建築物のファサードデザインが企業の競争優位の源泉となるなかで、従来の「物品」概念だけでは保護が困難なケースが増加した。また、グローバルなデザイン保護の国際的調和（ハーグ協定への加盟）も改正を後押しした要因の一つである。

建設分野においては、2020年改正により商業施設・駅舎・公共建築物の外観デザインが初めて意匠登録の対象となった。建設プロジェクトにおける知的財産戦略の観点から、設計段階での意匠出願を検討する機会が増えている。

## 総合技術監理における位置づけ


総合技術監理キーワード集では[**4.3 知的財産権と情報の保護と活用**](/docs/pe-comprehensive-management-keyword-2026#43-知的財産権と情報の保護と活用)に位置づけられる。

意匠権は製品やサービスのデザインを法的に保護し、ブランド価値の向上と模倣品排除に寄与する。建設分野では、2020年改正により建築物のデザインが意匠登録の対象となったことで、商業施設や公共建築物の外観デザインの保護が可能となり、建設プロジェクトの経済性管理における知的財産戦略の選択肢が広がった。知的財産管理の観点では[デジタルライツ](/docs/pe-comprehensive-management-digital-rights)や[デジュール標準](/docs/pe-comprehensive-management-de-jure-standard)とも密接に関連する。

過去問 [R02 Ⅰ-1-17](/docs/pe-comprehensive-management-r02-primary#1-17) では「意匠登録の出願件数は多少の増減を繰り返しながらも比較的推移している」が正しい記述として出題された。**意匠出願は年間約 3 万件前後で安定推移**しており、[商標権](/docs/pe-comprehensive-management-trademark-rights)（増加傾向）や [特許](/docs/pe-comprehensive-management-patent-rights)（横ばい）と動向が異なる点を把握しておく。
