## 労働審判法とは

**労働審判法**（平成16年法律第45号）は、個別労働関係民事紛争を迅速かつ適正に解決するため、地方裁判所における労働審判手続きを定めた法律である。

裁判官1名と労働関係の専門的知識を有する労働審判員2名で構成される労働審判委員会が、原則3回以内の期日で審理し、調停または審判を行う制度として2006年に施行された。

## 法律の概要

労働審判法は2006年に施行され、個別労働関係紛争の迅速解決を地方裁判所で行う制度を整備した。

- **正式名称**: 労働審判法（平成16年法律第45号）
- **目的**: 個別労働関係民事紛争の迅速・適正な解決
- **施行**: 2006年4月
- **管轄**: 地方裁判所
- **所管**: 法務省（裁判所制度として）

## 労働審判委員会の構成

労働審判委員会は3名で構成される。

- **裁判官（労働審判官）**: 1名 — 地方裁判所の裁判官
- **労働審判員**: 2名 — 労働関係の専門的知識・経験を有する者（労使各1名）

## 手続きの流れ

| 段階 | 内容 |
|---|---|
| **1. 申立て** | 労働者または使用者が地方裁判所に申立て |
| **2. 期日の指定** | 申立てから原則40日以内に第1回期日を指定 |
| **3. 審理** | 原則3回以内の期日で審理（調停を試みる） |
| **4-a. 調停成立** | 当事者が合意すれば調停調書を作成（確定判決と同一の効力） |
| **4-b. 労働審判** | 調停不成立の場合、労働審判委員会が審判を下す |
| **5. 異議申立て** | 審判の告知から2週間以内に異議申立てが可能 |
| **6. 訴訟移行** | 異議申立てにより審判は失効し、通常訴訟に移行 |

## 対象となる紛争

| 対象 | 具体例 |
|---|---|
| **解雇・雇止め** | 不当解雇の撤回、地位確認 |
| **賃金** | 未払賃金、残業代の請求 |
| **労働条件の変更** | 配置転換、降格の有効性 |
| **ハラスメント** | パワハラ・セクハラによる損害賠償 |
| **対象外** | 集団的労使紛争、行政事件 |

## 他の紛争解決手段との比較

労働審判・あっせん・民事訴訟の主な相違点は以下のとおりである。

- **実施機関**: 労働審判 = 地方裁判所 / あっせん = 都道府県労働局 / 民事訴訟 = 地方裁判所
- **審理回数**: 労働審判 = 原則3回以内 / あっせん = 原則1回 / 民事訴訟 = 制限なし
- **期間**: 労働審判 = 約3か月 / あっせん = 約1〜2か月 / 民事訴訟 = 1〜2年以上
- **費用**: 労働審判 = 有料（裁判所手数料） / あっせん = 無料 / 民事訴訟 = 有料
- **拘束力**: 労働審判 = あり（異議なければ確定判決と同一効力） / あっせん = なし / 民事訴訟 = あり
- **非公開**: 労働審判 = 非公開 / あっせん = 非公開 / 民事訴訟 = 原則公開

## 総合技術監理における位置づけ


総合技術監理キーワード集では[**3.2 労働関係法と労務管理**](/docs/pe-comprehensive-management-keyword-2026#32-労働関係法と労務管理)に位置づけられる。

労働審判制度は、個別労働紛争解決促進法のあっせん制度と民事訴訟の中間に位置する紛争解決手段である。

総合技術監理の観点では、労働紛争が長期化することによる組織の生産性低下やレピュテーションリスクを回避するため、適切な紛争解決手段の選択が人的資源管理上の重要課題となる。
