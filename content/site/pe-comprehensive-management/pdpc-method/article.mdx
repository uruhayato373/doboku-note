## PDPC法とは

PDPC法（Process Decision Program Chart：過程決定計画図）とは、事態の進展とともに起こりうる問題を事前に予測し、それに対する対策をあらかじめ計画しておく手法である。

新QC七つ道具の1つであり、不確実性の高い計画やプロジェクトにおいて、想定外の事態に備えるために用いられる。

## 作成手順

PDPC 法は、目標に至る正常ルートを起点として、各段階で起こりうる問題を洗い出し、代替ルートを設計していく。以下が標準的な作成ステップである。

| ステップ | 内容 |
|---|---|
| **1. 目標の設定** | 達成すべき目標を明確にする |
| **2. 理想ルートの作成** | 目標に至る理想的な手順（正常ルート）を記述する |
| **3. 問題点の予測** | 各ステップで起こりうる問題・障害を予測する |
| **4. 対策の立案** | 各問題点に対する代替手段・対策を検討する |
| **5. 図の作成** | 正常ルートと代替ルートを矢印で接続した図を作成する |

## 特徴

PDPC 法には、他の問題解決ツールとは異なる独自の性質がある。主な特徴を次に示す。

| 特徴 | 内容 |
|---|---|
| **事前予防型** | 問題が発生する前に対策を準備する |
| **視覚的** | 正常ルートと異常時の代替ルートを図で表現できる |
| **柔軟性** | 計画の進展に応じて図を更新・追加できる |

## 新QC七つ道具における位置づけ

新 QC 七つ道具は、定量データを扱う「QC 七つ道具」に対し、言語情報・定性情報の整理を目的として体系化されたツール群である。各ツールの用途を整理すると、PDPC 法が唯一「事前対応型」の計画手法として位置づけられていることがわかる。

| 道具 | 用途 |
|---|---|
| 親和図法 | 混沌とした情報の整理 |
| 連関図法 | 複雑な因果関係の解明 |
| 系統図法 | 目的と手段の体系的展開 |
| マトリックス図法 | 多元的な関係の整理 |
| **PDPC法** | **不測の事態への事前対応計画** |
| アローダイアグラム法 | 工程管理・日程計画 |
| マトリックスデータ解析法 | 多変量データの分析 |

## PDPC 法の開発背景

PDPC 法は 1968 年、東京大学名誉教授の近藤次郎氏が**東大紛争**の解決手順を体系化する過程で考案した手法である。当時は「重大事故予測法」とも呼ばれ、学生運動への対応という非常に不確実性の高い状況の中で、複数の進行シナリオを事前に設計する必要から生まれた。

1976 年には日本科学技術連盟（JUSE）が新 QC 七つ道具の一つとして体系化し、製造業を中心に広く普及した。品質管理の文脈では、製品の不良発生や生産工程のトラブルに対する代替手順の設計に活用され、自動車・電機産業での実用化が進んだ。当初は軍事・安全工学で使われていた「フォールトツリー解析（FTA）」や「デシジョンツリー」と対比されながら発展し、確率計算を伴わず定性的に代替ルートを設計できる点が特徴として確立された。

総合技術監理の文脈では、プロジェクトの初期段階でリスクシナリオを列挙し、各シナリオへの対処方針をあらかじめ図示しておくことで、安全管理や経済性管理の観点から「想定外」を「想定内」に変換する手段として機能する。近年では BCP（事業継続計画）策定においても、業務中断シナリオの代替手順を設計するフレームとして参照されている。
