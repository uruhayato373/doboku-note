## サイバー安全保障とは

サイバー安全保障とは、サイバー空間における脅威から国家の安全保障、社会経済活動、国民生活を守るための政策・法制度・技術の総体である。

サイバー攻撃の高度化・国家関与の増大に伴い、情報セキュリティの問題は個別組織の対策を超え、国家安全保障上の課題として位置づけられるようになった。

日本では2014年に**サイバーセキュリティ基本法**が制定され、政府全体のサイバーセキュリティ戦略の法的基盤が整備された。

### サイバーセキュリティ基本法

サイバーセキュリティ基本法（2014年制定、2018年改正）は、日本のサイバーセキュリティ政策の根幹を定める法律である。NISCを司令塔として、戦略策定・重要インフラ防護・人材育成を体系的に推進する。

- **目的**: サイバーセキュリティに関する施策を総合的・効率的に推進
- **定義**: サイバーセキュリティ＝情報の漏洩・滅失・毀損の防止と安全管理のための措置
- **司令塔**: 内閣サイバーセキュリティセンター（NISC）
- **基本施策**: サイバーセキュリティ戦略の策定、重要インフラ防護、人材育成、国際連携

### NISC

NISC（National center of Incident readiness and Strategy for Cybersecurity）は、内閣官房に設置されたサイバーセキュリティの司令塔組織である。

| 役割 | 内容 |
|---|---|
| サイバーセキュリティ戦略の策定補佐 | サイバーセキュリティ戦略本部（本部長：内閣官房長官）を補佐 |
| 政府機関の監視 | GSOCによる政府機関への不正通信の監視 |
| 重要インフラ防護 | 重要インフラ事業者との情報共有、演習の実施 |
| インシデント対応 | 政府機関のサイバーインシデントへの対処支援 |

### 重要インフラ防護

サイバー安全保障において、社会機能の維持に不可欠な**重要インフラ**の防護が最重要課題である。

| 分野 | 具体例 |
|---|---|
| 情報通信 | 通信事業者、放送事業者 |
| 金融 | 銀行、証券、保険 |
| 航空 | 航空会社、空港 |
| 鉄道 | 鉄道事業者 |
| 電力 | 電力会社 |
| ガス | ガス事業者 |
| 政府・行政サービス | 中央省庁、地方公共団体 |
| 医療 | 病院、医療情報システム |
| 水道 | 水道事業者 |
| 物流 | 物流事業者 |
| 化学 | 石油コンビナート、化学プラント |
| クレジット | クレジットカード事業者 |
| 石油 | 石油精製・元売事業者 |
| 空港 | 空港運営事業者 |

### 能動的サイバー防御

2022年の国家安全保障戦略において、**能動的サイバー防御**（Active Cyber Defense）の導入が明記された。

能動的サイバー防御とは、サイバー攻撃を受ける前に、攻撃者のサーバへのアクセスや無害化措置を行う積極的な防御手法である。

従来の受動的な防御（攻撃を検知して対処）に加え、脅威情報の収集・分析、攻撃インフラの無害化など、先制的な対策を講じる考え方である。

## 日本のサイバー安全保障政策の発展経緯

日本のサイバーセキュリティ政策は、情報インフラの整備に伴い段階的に強化されてきた。

2000年2月、内閣官房に「情報セキュリティ対策推進室」が設置されたのが制度整備の起点である。当初は行政機関の情報システム保護を主眼としており、安全保障の文脈はまだ希薄だった。

2005年4月に組織が強化され「情報セキュリティセンター（NISC初代）」が発足。2010年に発覚したStuxnet事件は世界的転換点となった。イランの核施設制御システムを標的にしたこのマルウェアは、サイバー攻撃が物理的インフラを破壊しうることを国際社会に示し、日本においても国家安全保障としてのサイバー対策を加速する契機となった。

2013年の「国家安全保障戦略」においてサイバー空間防護が国家戦略に組み込まれ、翌2014年11月にサイバーセキュリティ基本法が議員立法により成立した。2015年1月の全面施行とともに内閣サイバーセキュリティセンター（NISC）が設置され、政府横断の司令塔機能が確立された。

その後2022年の国家安全保障戦略で「能動的サイバー防御」が明記され、2025年7月には組織改編により「国家サイバー統括室（NCO）」へと発展した。この20余年で日本のサイバー安全保障は「情報システム管理」から「国家安全保障の柱」へと質的転換を遂げている。

## 総合技術監理における位置づけ


総合技術監理キーワード集では[**4.5 情報セキュリティ**](/docs/pe-comprehensive-management-keyword-2026#45-情報セキュリティ)に位置づけられる。

サイバー安全保障は個別組織の情報セキュリティ対策を超えた**国家レベルの枠組み**であり、[ISMS（ISO/IEC 27001）](/docs/pe-comprehensive-management-isms-iso27001)や[ゼロトラスト](/docs/pe-comprehensive-management-zero-trust)などの個別対策を包含する上位概念として理解する必要がある。

建設・土木分野は重要インフラ（水道、物流等）に直結しており、サイバー安全保障の対象として求められるセキュリティ水準を理解しておくことは、総合技術監理技術者にとって不可欠である。

過去問 [R02 Ⅰ-1-24](/docs/pe-comprehensive-management-r02-primary#1-24) では [暗号化・デジタル署名](/docs/pe-comprehensive-management-encryption-digital-signature) の仕組みが問われ、共通鍵暗号（同一鍵共有）・公開鍵暗号（受信者が鍵ペア生成）・デジタル署名（送信者が鍵ペア生成）の**鍵生成者と使用者の違い**が核心として出題された。情報セキュリティ対策の実装レイヤーでの正確な理解が問われる典型問。

過去問 [R02 Ⅰ-1-27](/docs/pe-comprehensive-management-r02-primary#1-27) では [IoT](/docs/pe-comprehensive-management-iot) 機器への攻撃影響波及が問われ、「当該機器にとどまる」は誤答（= 他の IoT システムに波及）として扱われた。サイバー安全保障の観点では、**IoT 機器の相互接続性によるリスク連鎖** を前提とした多層防御（Defense in Depth）が不可欠。
