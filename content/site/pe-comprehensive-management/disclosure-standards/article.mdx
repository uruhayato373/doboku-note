## 開示基準とは

**開示基準** とは、行政機関が保有する情報の開示・不開示を判断する際の基準のことである。情報公開法において、原則開示を基本としつつ、不開示とすべき情報の類型（不開示情報）が限定列挙されている。

## 原則開示の考え方

情報公開法は「原則として開示する」姿勢を基本とし、不開示を例外として限定列挙している。以下に4つの基本原則を示す。

| 原則 | 内容 |
|---|---|
| **原則開示** | 行政文書は請求があれば原則として開示する |
| **不開示の限定** | 不開示とできるのは法定の不開示情報に該当する場合のみ |
| **部分開示** | 不開示部分を除いた部分は開示する（容易に区分できる場合） |
| **裁量的開示** | 不開示情報であっても公益上特に必要な場合は開示可能 |

## 不開示情報の判断基準

不開示とできる情報は[情報公開法第5条](https://laws.e-gov.go.jp/law/411AC0000000042#Mp-At_5)で限定列挙されており、6類型に分類される。各類型の判断基準は次のとおりである。

| 不開示情報 | 判断基準 |
|---|---|
| **個人情報** | 特定の個人が識別されるか、または識別され得るか |
| **法人情報** | 法人の権利・競争上の地位等を害するおそれがあるか |
| **国の安全等** | 国の安全・外交上の利益を害するおそれがあるか |
| **公共の安全** | 公共の安全と秩序の維持に支障を及ぼすおそれがあるか |
| **審議検討情報** | 率直な意見交換・意思決定の中立性が不当に損なわれるか |
| **事務事業情報** | 事務事業の適正な遂行に支障を及ぼすおそれがあるか |

## 部分開示と裁量的開示

情報公開法は開示・不開示の二択にとどまらず、次の3つの柔軟な仕組みを設ける。

- **部分開示**（[情報公開法第6条](https://laws.e-gov.go.jp/law/411AC0000000042#Mp-At_6)）: 不開示情報を除いた残りを開示する
- **裁量的開示**（[情報公開法第7条](https://laws.e-gov.go.jp/law/411AC0000000042#Mp-At_7)）: 公益上必要なら不開示情報も開示可とする
- **存否応答拒否**（[情報公開法第8条](https://laws.e-gov.go.jp/law/411AC0000000042#Mp-At_8)）: 文書の存否自体を明らかにしない

## 建設部門における開示判断の実務

建設分野での公共事業では、情報の種類に応じて開示判断が異なる。入札・契約・環境・個人情報の各カテゴリごとの考え方を整理する。

| 情報 | 開示判断の考え方 |
|---|---|
| **入札・契約情報** | 原則開示（透明性の確保） |
| **設計図書** | 原則開示（安全保障上の懸念がある場合は不開示） |
| **積算内訳** | 予定価格の事後公表が一般的 |
| **環境データ** | 原則開示（環境影響評価法との整合） |
| **個人の技術者情報** | 個人情報に該当する部分は不開示 |

## 情報公開制度の成立背景

日本の情報公開制度は、1999年の行政機関情報公開法（平成11年法律第42号）制定を起点とする。戦後の行政運営は「お上が管理」の慣行が根強く、一般市民が行政文書を閲覧するには個別の法的根拠が必要だった。

1990年代の接待汚職・バブル崩壊後の行政不信を受け、「知る権利」と「行政の透明性」を法制化する機運が高まった。地方自治体レベルでは1970年代末から情報公開条例が先行し、国レベルの立法を後押しした。

制定後も2001年の施行当初は請求手続が煩雑で、不開示判断が広く認められていた。2016年の公文書管理法改正および2017年の公文書ガイドライン改訂を経て、文書作成・保存・開示の一体的なルールが整備された。2019年以降は、建設事業を含む公共工事のデジタル化（BIM/CIM導入）に伴い、電子文書の開示請求への対応も課題となっている。

## 総合技術監理における位置づけ


総合技術監理キーワード集では[**4.2 コミュニケーション**](/docs/pe-comprehensive-management-keyword-2026#42-コミュニケーション)に位置づけられる。

開示基準は情報公開法の運用基準であり、技術者は公共事業の透明性確保と、個人情報・法人情報等の保護のバランスを理解する必要がある。[情報開示](/docs/pe-comprehensive-management-information-disclosure)・開示請求・知る権利と一体で把握する。過去問 [R04 Ⅰ-1-20](/docs/pe-comprehensive-management-r04-primary#1-20) では上場企業の法定開示（金商法）と適時開示（取引所規則）の違いが問われた（行政情報の開示基準は情報公開法に基づく別系統の制度）。
