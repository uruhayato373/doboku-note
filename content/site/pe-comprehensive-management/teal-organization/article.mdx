## ティール組織とは

ティール組織（teal organization）とは、フレデリック・ラルーが著書『Reinventing Organizations』（2014年）で提唱した、組織進化モデルの最終段階に位置する組織形態である。

上司の指示や規則による統制ではなく、**メンバー一人ひとりが自律的に意思決定**し、組織の存在目的に向かって進化し続ける組織を指す。

ラルーは人類の意識の発達段階に対応させて組織を5段階に分類し、各段階を色で表現した。

### ラルーの5段階組織モデル

各段階の色・名称・比喩・特徴は以下のとおりである。

- **第1段階・赤（レッド）（衝動型組織）**: 比喩: オオカミの群れ — 力と恐怖による支配。短期的・反応的
- **第2段階・琥珀（アンバー）（順応型組織）**: 比喩: 軍隊 — 厳格な階層と規則。安定性と秩序を重視
- **第3段階・橙（オレンジ）（達成型組織）**: 比喩: 機械 — 目標達成・成果主義。イノベーションと競争
- **第4段階・緑（グリーン）（多元型組織）**: 比喩: 家族 — 合意形成・多様性尊重。文化と価値観を重視
- **第5段階・青緑（ティール）（進化型組織）**: 比喩: 生命体 — 自主経営・全体性・存在目的。自律的な進化

### ティール組織の3つの柱

ラルーはティール組織の特徴を 3 つの柱で整理している。各柱は相互に補強し合う関係にある。

| 柱 | 内容 |
|---|---|
| **自主経営（セルフマネジメント）** | 上司の承認なしにメンバーが意思決定する。助言プロセス（アドバイス・プロセス）により、影響を受ける人や専門家に助言を求めた上で自ら決定する |
| **全体性（ホールネス）** | メンバーが職場で「仮面」をかぶらず、感情・直感・精神性を含む自分全体を表現できる環境を整える |
| **存在目的（エボリューショナリー・パーパス）** | 組織は利益のための機械ではなく、固有の存在目的を持つ生命体と捉える。目的は固定でなく、メンバーと共に進化する |

### メリットとデメリット

自律性を最大化する設計であるため、メリットとデメリットは表裏一体の関係にある。

| 区分 | 内容 |
|---|---|
| **メリット** | |
| 高い適応力 | 環境変化に対して組織全体が有機的に対応できる |
| メンバーの主体性 | 自律的な意思決定によりモチベーションと創造性が高まる |
| 本質的な目的追求 | 短期的な利益でなく、社会的意義のある目的を追求できる |
| **デメリット** | |
| 導入の難しさ | 既存の階層型組織からの移行には意識変革を要する |
| スケーラビリティ | 大規模組織での実績が限られている |
| 安全管理との整合 | 法令で指揮命令系統が求められる業種では適用が難しい |

### ネットワーク組織との違い

ティール組織とネットワーク組織はいずれも水平性を特徴とするため試験で混同が誘導されるが、**管理職・指揮命令系統の有無が最大の判別点**である。

| 観点 | ティール組織 | ネットワーク組織 |
|---|---|---|
| 管理職・指揮命令系統 | 完全に撤廃 | 存在する（弱く水平的） |
| 結びつきの基盤 | 進化する目的とメンバー間の信頼 | 特定の目的・プロジェクトの共有 |
| 組織境界 | 自主経営チームが内部で完結 | 企業間／部門間にまたがり曖昧 |

過去問 [R04 Ⅰ-1-13](/docs/pe-comprehensive-management-r04-primary#1-13) では、イ「指揮命令系統はなく、進化する目的を実現するために相互信頼に基づき独自のルールを工夫する」がティール組織、ア「特定の目的を共有し水平的に柔やかに結びつき、部門や組織の壁を越えて自律的に協働する」がネットワーク組織として問われた。

## 総合技術監理における位置づけ


総合技術監理キーワード集では[**3.1 人の行動と組織**](/docs/pe-comprehensive-management-keyword-2026#31-人の行動と組織)に位置づけられる。

ティール組織は従来の管理手法を根本から問い直す概念であり、人的資源管理における [安全管理](/docs/pe-comprehensive-management-safety-control) や [ウェルビーイング](/docs/pe-comprehensive-management-wellbeing-org) と関連して自律性・内発的動機づけの議論で登場する。

建設業のように安全管理上の法定義務（統括安全衛生責任者の選任等）が厳格な業種では全面的な導入は困難だが、設計部門や DX 推進チームなど創造的業務でティール的な運営を部分的に取り入れる動きがある。[ピラミッド組織](/docs/pe-comprehensive-management-pyramid-organization) の整然とした指揮命令系統と対極にあるため、採用検討時は業務の性質との整合を厳密に評価する必要がある。
