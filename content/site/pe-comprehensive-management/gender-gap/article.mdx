## ジェンダーギャップとは

**ジェンダーギャップ（Gender Gap）** とは、性別に起因する社会的・経済的・政治的な格差のことである。世界経済フォーラム（WEF）が毎年公表する**ジェンダーギャップ指数（GGI）** が国際比較の代表的指標として用いられる。

## ジェンダーギャップ指数の構成

GGIは4つの分野それぞれの代表的指標から算出される。日本は2024年時点で146か国中118位であり、経済・政治分野の格差が順位を引き下げている。

- **経済参画**: 労働参加率、賃金格差、管理職比率 — 日本の順位傾向: 低い
- **教育達成**: 識字率、就学率 — 日本の順位傾向: 高い
- **健康と生存**: 出生時性比、健康寿命 — 日本の順位傾向: 高い
- **政治参画**: 国会議員比率、閣僚比率 — 日本の順位傾向: 非常に低い

## 日本における主な課題

日本のジェンダーギャップは複数の構造的要因が絡み合っている。代表的な課題は以下のとおりである。

| 課題 | 内容 |
|---|---|
| **賃金格差** | 男性を100とした場合、女性は約75（正規雇用） |
| **管理職比率** | 女性管理職比率は約12%（先進国で最低水準） |
| **M字カーブ** | 出産・育児期に女性の就業率が低下する日本特有の現象 |
| **無償労働の偏り** | 家事・育児の負担が女性に集中 |
| **非正規雇用比率** | 女性の非正規雇用比率は約54%（男性は約22%） |

## 建設部門におけるジェンダーギャップ

建設部門は全産業の中でも女性比率が特に低く、国交省・日建連が連携して環境整備と意識変革を進めている。

| 項目 | 現状 |
|---|---|
| **女性技術者比率** | 約6%（全産業平均より低い） |
| **女性技能者比率** | 約2%（極めて低い） |
| **「もっと女性が活躍できる建設業」行動計画** | 国交省（2014年〜）による女性活躍推進 |
| **けんせつ小町** | 日建連の女性活躍推進ブランド |
| **環境整備** | 女性用トイレ・更衣室の現場設置義務化 |

## 国際的な取り組みの歴史と背景

ジェンダーギャップへの国際的な注目は1975年の「国際女性年」（国連）に端を発する。1979年に採択された**女子差別撤廃条約（CEDAW）** は、法的拘束力をもつ最初の包括的な国際条約であり、日本は1985年に批准した。

国内では1985年に**男女雇用機会均等法**が制定され、1999年に**男女共同参画社会基本法**が成立した。2015年には**女性活躍推進法**が施行され、301人以上の企業に行動計画策定が義務付けられた（2022年から101人以上に拡大）。

世界経済フォーラムがGGIを初めて公表したのは2006年である。それ以降、毎年の指数公表が政府・企業の政策立案に活用されるようになり、日本でもGGIランキングの低さが政策議論の材料として広く引用されるようになった。
