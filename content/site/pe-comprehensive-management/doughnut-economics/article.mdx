## ドーナツ経済学とは

**ドーナツ経済学**（Doughnut Economics）とは、英国の経済学者ケイト・ラワース（Kate Raworth）が2012年に提唱した経済モデルである。

GDP成長を目的とする従来の経済学に代わり、「人類が安全かつ公正に活動できる空間」を視覚的に示すフレームワークとして注目されている。

ドーナツ型の図の内側の輪（社会的な土台）と外側の輪（環境の上限）の間の環状領域が、人類にとって「安全で公正な空間」であると定義する。

この比喩をより直感的に言い換えると、ドーナツの内側の空洞部分はエネルギー・水・食料など人が暮らすために必須の資源が欠乏した状態を表し、外側の空間は地球環境に過負荷がかかっている状態を表す。総合技術監理の技術体系においても、プラネタリー・バウンダリー（地球の限界）の概念に付随する形で紹介されており、人類はこの「ドーナツの食べられる部分」の範囲内で経済・社会活動を営む必要がある、という提案として位置づけられている。GDPという単一指標では捉えきれない「欠乏」と「過負荷」を同時に可視化する点が、このモデルの実務的な価値である。

### ドーナツモデルの構造

ドーナツ経済学の中核となる概念は以下の3層構造で理解できる。

| 要素 | 内容 |
|---|---|
| **社会的な土台（Social Foundation）** | すべての人が満たされるべき最低限の生活水準。食料、健康、教育、所得、政治的発言力、社会的公正、ジェンダー平等など12の要素で構成 |
| **環境の上限（Ecological Ceiling）** | 地球が許容できる環境負荷の限界。プラネタリー・バウンダリー（地球の限界）の9つの指標に対応。気候変動、生物多様性の喪失、土地利用変化、窒素・リン循環など |
| **安全で公正な空間** | 社会的な土台と環境の上限の間の環状領域。この空間内に経済活動を収めることが目標 |
| **ショートフォール（不足）** | 社会的な土台を下回る状態。貧困、教育機会の欠如、健康格差など |
| **オーバーシュート（超過）** | 環境の上限を超えた状態。温暖化、オゾン層破壊、生物種の絶滅など |

### プラネタリー・バウンダリーとの関連

ドーナツモデルの環境の上限は、ストックホルム・レジリエンス・センターのヨハン・ロックストロームらが2009年に提唱した「**プラネタリー・バウンダリー**（地球の限界）」に基づいている。

| 指標 | 現状 |
|---|---|
| **気候変動** | 超過（CO2濃度が安全な範囲を超過） |
| **生物多様性の喪失** | 大幅超過（絶滅速度が安全な範囲を大幅に超過） |
| **窒素・リン循環** | 超過（農業由来の窒素・リンが水圏に過剰流入） |
| **土地利用変化** | 超過（森林破壊等による土地利用の変化） |
| **淡水利用** | 超過（一部地域で過剰取水） |
| **海洋酸性化** | 安全範囲内（ただし悪化傾向） |
| **オゾン層破壊** | 安全範囲内（モントリオール議定書の成果） |
| **大気エアロゾル** | 地域的に超過 |
| **新規化学物質** | 超過（プラスチック・化学物質汚染の拡大） |

### 従来の経済学との違い

ドーナツ経済学は、GDP成長を絶対視する従来の経済学と以下の点で本質的に異なる。

- **目標**: 従来の経済学はGDP成長の最大化 — ドーナツ経済学は社会的土台と環境上限の間に収まること
- **成長観**: 従来の経済学は無限の成長を前提 — ドーナツ経済学は「成長に依存しない繁栄」を志向
- **環境**: 従来の経済学は外部性として扱う — ドーナツ経済学は経済活動の絶対的な制約条件
- **分配**: 従来の経済学は成長の結果として波及（トリクルダウン） — ドーナツ経済学は最初から分配を設計に組み込む
- **指標**: 従来の経済学はGDP — ドーナツ経済学は社会的土台12要素＋環境上限9要素

## 総合技術監理における位置づけ


総合技術監理キーワード集では[**6.1 地球的規模の環境問題**](/docs/pe-comprehensive-management-keyword-2026#61-地球的規模の環境問題)に位置づけられる。

ドーナツ経済学はSDGs（持続可能な開発目標）やESGの理論的基盤として引用されることが多く、気候変動・生物多様性・資源循環など複数の環境管理テーマを統合的に捉える視点を提供する。

ドーナツ経済学が投げかける問いは、社会環境管理の枠内にとどまらず5管理のトレードオフに直結する。事業活動を環境の上限内に収めようとすれば、省エネルギー設備の導入や排出削減技術への投資が必要となり経済性管理上のコスト増を招く。一方でコストを優先して環境負荷対策を先送りすれば、社会的な土台側（雇用・地域の生活基盤）を支える事業自体の持続性が損なわれかねない。人的資源管理の観点では、脱炭素・資源循環に対応できる人材の育成・確保が必要になり、情報管理の観点では、CO2排出量や資源投入量を正確に把握・開示するためのデータ基盤整備が求められる。総合技術監理技術士には、環境の上限を守ることと社会的な土台を維持することの両立を、特定の管理領域に偏らせず全体最適として設計する視点が求められる。

関連キーワードとして、[カーボンニュートラル](/docs/pe-comprehensive-management-carbon-neutral)、[気候変動・国際対応](/docs/pe-comprehensive-management-climate-change-international)、[ESG・環境評価](/docs/pe-comprehensive-management-esg-environmental-assessment)との横断的な理解が求められる。

## 実務での具体例

ドーナツ経済学の考え方は、企業のサステナビリティ経営やESG投資の評価軸として実務に取り入れられつつある。従来のCSR（企業の社会的責任）が個別の社会貢献活動として扱われがちだったのに対し、ドーナツ経済学の枠組みを応用した経営評価では、事業活動が環境の上限（温室効果ガス排出量、水資源利用量、廃棄物排出量など）を超過していないか、同時に社会的な土台（従業員の生活賃金、労働安全衛生、地域社会への便益）を満たしているかを同一のダッシュボードで可視化する試みが進んでいる。

自治体レベルでも、都市計画やインフラ整備の方針決定にドーナツ経済学の考え方を援用する事例が国外で報告されており、道路・上下水道・エネルギー網といった社会基盤整備を「環境負荷の上限」と「住民生活の下限」という2つの制約条件の間でどう設計するかという発想は、公共事業のプロジェクトマネジメントにおける総合技術監理的な判断と親和性が高い。
