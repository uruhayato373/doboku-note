## ステークホルダーとは

**ステークホルダー（Stakeholder：利害関係者）** とは、組織やプロジェクトの活動によって影響を受ける、または影響を与えることができる個人・グループ・組織のことである。Freemanにより1984年に体系化された概念で、株主（ストックホルダー）だけでなく、従業員・顧客・地域住民・行政機関等を含む。

## 公共事業の主なステークホルダー

公共事業では、以下の多様な主体がそれぞれ異なる関心事を持つステークホルダーとして関与する。

| ステークホルダー | 関心事 |
|---|---|
| **発注者（行政機関）** | 事業目的の達成、予算・工期の遵守 |
| **受注者（建設会社）** | 利益の確保、品質・安全の実現 |
| **地域住民** | 生活環境への影響、利便性の向上 |
| **利用者** | 施設の機能・安全性・利便性 |
| **関係行政機関** | 法令遵守、許認可条件の履行 |
| **環境団体** | 自然環境・生態系への影響 |
| **金融機関・投資家** | 事業の採算性・リスク |
| **下請業者** | 受注・利益の確保、安全な労働環境 |

## ステークホルダー分析

### 権力／関心マトリクス

権力（影響力）と関心度の組み合わせにより、4象限で対応方針が変わる。

- **権力：高 × 関心度：高** — 密接に管理（Key Player）
- **権力：高 × 関心度：低** — 満足させ続ける
- **権力：低 × 関心度：高** — 情報を提供し続ける
- **権力：低 × 関心度：低** — 最小限の対応

## ステークホルダー・エンゲージメント

ステークホルダーの関与度（エンゲージメント）は以下の5段階で評価し、目標とするレベルへの移行を計画する。

| レベル | 内容 |
|---|---|
| **不認知** | プロジェクトの存在を知らない |
| **抵抗** | プロジェクトに反対している |
| **中立** | 賛成でも反対でもない |
| **支持** | プロジェクトを支持している |
| **主導** | 積極的にプロジェクトを推進 |

## マネジメントの手順

ステークホルダーマネジメントは次の5ステップで構成される継続的プロセスである。

| ステップ | 内容 |
|---|---|
| **1. 特定** | すべてのステークホルダーを洗い出す |
| **2. 分析** | 権力・関心・態度・影響度を評価 |
| **3. 計画** | 各ステークホルダーへの対応戦略を策定 |
| **4. 実行** | コミュニケーション計画に基づく関与 |
| **5. 監視** | ステークホルダーの態度変化を継続的に監視 |

## 総合技術監理における位置づけ


総合技術監理キーワード集では[**4.2 コミュニケーション**](/docs/pe-comprehensive-management-keyword-2026#42-コミュニケーション)に位置づけられる。

ステークホルダー管理はコミュニケーション計画・住民参加・社会的受容（PA）・パブリックリレーションズの前提であり、すべての合意形成活動の出発点となる（[住民参加](/docs/pe-comprehensive-management-citizen-participation)、[コミュニケーション・コントロール](/docs/pe-comprehensive-management-communication-control)、[コミュニケーション計画](/docs/pe-comprehensive-management-communication-planning) と一体で運用）。

過去問 [R04 Ⅰ-1-32](/docs/pe-comprehensive-management-r04-primary#1-32) では JIS Q 31000（リスクマネジメント指針）の前文で「組織の活動はステークホルダとのやり取りを含む」と位置づけられている点が問われた。

過去問 [R02 Ⅰ-1-29](/docs/pe-comprehensive-management-r02-primary#1-29) ではリスクコミュニケーションの対象として多様なステークホルダーが前提となり、「見解や価値観を一致させる」という誤答が出題された。ステークホルダーの**異なる利害・価値観の存在を前提にした相互理解の形成**がリスコミの目的であり、見解の統一ではない。
