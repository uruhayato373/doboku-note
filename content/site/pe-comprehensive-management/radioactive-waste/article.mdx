## 放射性廃棄物とは

放射性廃棄物とは、原子力発電所の運転・廃炉、核燃料の再処理、放射性同位元素の利用等に伴い発生する放射性物質を含む廃棄物の総称である。

放射能レベルに応じて高レベル放射性廃棄物と低レベル放射性廃棄物に大別され、それぞれ異なる処分方法が定められている。

放射性廃棄物の安全な処理・処分は原子力利用の大前提であり、「トイレなきマンション」問題として社会的な関心も高い。

### 分類と処分方法

- **高レベル放射性廃棄物**: 使用済燃料の再処理で生じるガラス固化体 — 地層処分（地下300m以深）
- **低レベル放射性廃棄物（L1）**: 原子炉の制御棒、炉内構造物等 — 余裕深度処分（地下50〜100m）
- **低レベル放射性廃棄物（L2）**: 濃縮廃液固化体、使用済樹脂等 — ピット処分（コンクリートピット）
- **低レベル放射性廃棄物（L3）**: コンクリート、金属等の解体廃棄物 — トレンチ処分（素掘り処分）
- **クリアランス対象物**: 放射能濃度が極めて低いもの — 再利用・一般廃棄物として処分

### 地層処分

| 項目 | 内容 |
|---|---|
| **法的根拠** | 特定放射性廃棄物の最終処分に関する法律（最終処分法、2000年） |
| **実施主体** | 原子力発電環境整備機構（NUMO） |
| **処分深度** | 地下300m以深の安定した岩盤中 |
| **多重バリアシステム** | ガラス固化体＋オーバーパック＋緩衝材＋岩盤（人工バリア＋天然バリア） |
| **管理期間** | 数万年以上の長期安全性を確保 |
| **選定プロセス** | 文献調査→概要調査→精密調査→最終処分地選定 |
| **現状** | 北海道寿都町・神恵内村で文献調査を実施中（2020年〜） |

### 現状・課題

| 課題 | 内容 |
|---|---|
| **処分地選定の難航** | 地層処分の候補地が長年決まらなかった（寿都町・神恵内村で初の文献調査） |
| **社会的受容** | NIMBY問題（「総論賛成・各論反対」）の克服 |
| **超長期の安全性** | 数万年にわたる安全性の実証・説明の困難さ |
| **核燃料サイクル政策** | 再処理路線と直接処分の政策的選択 |
| **廃炉廃棄物の増加** | 原発廃炉の進展に伴う低レベル放射性廃棄物の大量発生 |

## 総合技術監理における位置づけ


総合技術監理キーワード集では[**6.2 地域環境問題**](/docs/pe-comprehensive-management-keyword-2026#62-地域環境問題)に位置づけられる。

放射性廃棄物の管理は安全管理（放射線防護、長期安全性の確保）と社会環境管理（環境保全、住民合意形成）の両面で重要課題である。経済性管理（処分コストの世代間負担）、情報管理（リスクコミュニケーション、超長期の記録保存）も含め、総合技術監理の5管理分野すべてに関わる横断的テーマといえる。
