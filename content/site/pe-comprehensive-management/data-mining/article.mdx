## データマイニングとは

データマイニング（data mining）とは、大量のデータから統計学・機械学習・パターン認識等の手法を用いて、有用な知識・規則性・パターンを自動的に発見する技術である。

ビッグデータ時代の到来により、企業の意思決定支援や科学的発見において、データマイニングの重要性はますます高まっている。

### ビッグデータ分析プロセスにおける位置づけ

データマイニングはビッグデータ分析の中核工程として、5 段階の処理パイプラインの中で位置づけられる。教材『情報管理』ではこの全体プロセスを以下のように整理している。

5 段階の各工程を簡潔に整理する。

- **① データ収集**: 広く散在する多種多様なデータ（構造化データ・非構造化データ・センサーデータ等）を収集
- **② データウェアハウス格納**: 収集データを時系列・内容別に整理して [データウェアハウス](/docs/pe-comprehensive-management-data-warehouse) に保管
- ③ [データクレンジング](/docs/pe-comprehensive-management-data-cleansing): 重複の削除・誤記の修正・表記揺れの正規化を行いデータ品質を確保
- **④ データマイニング**: クレンジング済みデータから規則性・傾向・有用な知見を発見
- **⑤ 活用**: 発見した知見を意思決定や新ビジネス創出に展開

このうち **④ データマイニング** は、**仮説の有無**によって 2 つのアプローチに分かれる。

- 仮説なし → [機械学習](/docs/pe-comprehensive-management-machine-learning): 人工知能を活用してコンピュータがデータから反復的に学習し、自ら相関関係やパターンを発見
- **仮説あり → 統計分析**: 事前に立てた仮説（「A と B には正の相関がある」等）を標本データで検証

教材ではこの 2 アプローチの並立をデータマイニングの本質と位置づけており、「探索的＝仮説なし」と単純化しないことが重要である。

### 主要な手法

データマイニングで用いられる代表的な手法は以下のとおりである（手法 — 目的 — 主な手法 — 適用例の順）。

- **分類（Classification）**: 既知のカテゴリへの振り分け — 決定木、ランダムフォレスト、SVM等 — 迷惑メール判別、信用スコアリング
- **回帰（Regression）**: 数値の予測 — 線形回帰、重回帰、ロジスティック回帰 — 売上予測、需要予測
- **クラスタリング**: グループ分け — k-means法、階層的手法 — 顧客セグメンテーション
- **アソシエーション分析**: 関連ルールの発見 — Aprioriアルゴリズム — バスケット分析（同時購入パターン）
- **系列パターン分析**: 時系列的な順序パターン — 系列パターンマイニング — 購買行動の遷移、Web閲覧パターン
- **異常検知**: 外れ値・異常の検出 — 統計的手法、LOF法 — 不正検知、故障予兆検知

### マーケティング応用：顧客・購買分析

データマイニングの代表的な応用領域として、**顧客行動・購買パターンの分析**がある。総合技術監理キーワード集では、この領域から特に**アソシエーション分析**と **RFM 分析**が頻出概念として挙げられる。

アソシエーション分析（Association Analysis）

顧客が商品を購入する際の購買パターンや履歴を分析し、商品やサービスの **相関関係** を抽出する手法である。「商品 A を買った顧客が同時に商品 B も買う」というような **同時購買パターン** を見つけるバスケット分析が代表例である。

- 代表アルゴリズム: **Apriori アルゴリズム**（頻出アイテムセットを段階的に発見）
- 主要指標: 支持度（Support）、確信度（Confidence）、リフト値（Lift）
- 適用例: コンビニ・スーパーのレシート分析、EC サイトの「この商品を買った人はこちらも購入」レコメンド、棚割り最適化

RFM 分析（Recency-Frequency-Monetary Analysis）

顧客を **3 つの指標** でランク付けして優良顧客を識別する手法である。データマイニングというよりはマーケティングの定量分析手法として位置づけられるが、CRM（顧客関係管理）の代表手法として頻出である。

| 指標 | 内容 | 高ランクの意味 |
|---|---|---|
| **R: Recency（直近購買日）** | 最終購入からの経過日数 | 最近購入＝関心が高い |
| **F: Frequency（購買頻度）** | 一定期間内の購入回数 | 頻繁＝ロイヤル顧客 |
| **M: Monetary（購買金額）** | 累計購入金額 | 高額＝収益貢献度大 |

3 指標それぞれを 5 段階等にランク分けし、組合せで顧客を分類する（例：R5・F5・M5 は最優良顧客）。重点顧客への DM 配信、休眠顧客の掘り起こし、解約予兆の検知などに活用される。

**両者の使い分け**: アソシエーション分析は「**何が一緒に売れるか**」を発見する手法であり、RFM 分析は「**誰が優良顧客か**」を識別する手法である。前者は商品軸、後者は顧客軸の分析という違いを押さえる。

### CRISP-DMプロセスモデル

データマイニングの標準的なプロセスモデルとして、CRISP-DM（Cross-Industry Standard Process for Data Mining）が広く採用されている。

| フェーズ | 内容 |
|---|---|
| 1. ビジネス理解 | 分析目的と要件の明確化 |
| 2. データ理解 | データの収集・探索・品質確認 |
| 3. データ準備 | データクレンジング・変換・特徴量作成 |
| 4. モデリング | 分析手法の選択・モデル構築・パラメータ調整 |
| 5. 評価 | モデルの精度検証・ビジネス目的との整合確認 |
| 6. 展開 | 分析結果の業務適用・運用体制の構築 |

このプロセスは反復的であり、各フェーズ間を往復しながら改善を重ねる。

### テキストマイニング・Webマイニング

データマイニングの対象は構造化データに限らない。

**テキストマイニング**は、自然言語で記述された文書データから有用な情報を抽出する手法であり、形態素解析・構文解析・感情分析等の自然言語処理技術を活用する。

**Webマイニング**は、Webページの内容（コンテンツマイニング）、リンク構造（構造マイニング）、アクセスログ（利用マイニング）を分析対象とする。

## 総合技術監理における位置づけ


総合技術監理キーワード集では[**4.1 情報分析と情報活用**](/docs/pe-comprehensive-management-keyword-2026#41-情報分析と情報活用)に位置づけられる。

データマイニングは、[データクレンジング](/docs/pe-comprehensive-management-data-cleansing)で品質を確保したデータに対して適用される。

分析手法としては[クラスター分析](/docs/pe-comprehensive-management-cluster-analysis)や回帰分析などを包含する上位概念であり、[機械学習](/docs/pe-comprehensive-management-machine-learning)の技術を活用してモデルを構築する。

発見した知見は[データ可視化](/docs/pe-comprehensive-management-data-visualization)を通じて意思決定者に伝達される。

過去問 [R02 Ⅰ-1-23](/docs/pe-comprehensive-management-r02-primary#1-23) では [機械学習](/docs/pe-comprehensive-management-machine-learning) の標準プロセス（前処理・学習・モデル・推論）が問われた。データマイニングの CRISP-DM プロセス（ビジネス理解 → データ理解 → データ準備 → モデリング → 評価 → 展開）は、機械学習プロセスと重なる部分が多く、「データ準備 = 前処理」「モデリング = 学習・モデル構築」「展開 = 推論」 の対応関係で整理できる。
