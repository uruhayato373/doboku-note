## クラスター分析とは

クラスター分析（cluster analysis）とは、複数のデータを類似性に基づいてグループ（クラスター）に分類する多変量解析手法である。

事前にグループの定義を与えず、データの特徴のみからグループ構造を発見する「教師なし学習」の代表的手法である。

顧客セグメンテーション、文書分類、画像認識、異常検知など、幅広い分野で活用されている。過去問 [R04 Ⅰ-1-17](/docs/pe-comprehensive-management-r04-primary#1-17) では「ネットショップ顧客の購買履歴から顧客プロファイリングを行う」事例に対する手法選択でクラスター分析が正答となった（連続量→回帰分析／二値→ロジスティック回帰／分類→クラスター分析 の使い分けが頻出）。

### 階層的クラスター分析と非階層的クラスター分析

クラスター分析は大きく2つの手法に分類される。各特性の対比を以下に示す。

- **代表手法** — 階層的: ウォード法、最短距離法、最長距離法、群平均法 / 非階層的: k-means法、k-medoids法
- **クラスター数** — 階層的: 事前指定不要（デンドログラムで決定） / 非階層的: 事前にk個を指定
- **可視化** — 階層的: デンドログラム（樹形図） / 非階層的: 散布図等
- **計算量** — 階層的: 大（$O(n^2)$以上） / 非階層的: 比較的小（$O(nk)$）
- **適するデータ量** — 階層的: 小〜中規模（数千件程度） / 非階層的: 大規模（数万件以上）
- **特徴** — 階層的: 階層構造を把握できる / 非階層的: 高速で大規模データに対応

過去問 [R06 Ⅰ-1-18](/docs/pe-comprehensive-management-r06-primary#1-18) では「階層的クラスター分析の代表手法は k-means 法」という記述が誤りとして出題された。k-means 法は**非階層的**クラスター分析の代表手法であり、この階層的／非階層的の取り違えが定番の引っかけである。

### k-means法のアルゴリズム

非階層的クラスター分析の代表であるk-means法は、以下のステップを繰り返す。

1. k個の初期クラスター中心（セントロイド）をランダムに配置する
2. 各データ点を最も近いセントロイドのクラスターに割り当てる
3. 各クラスターのセントロイドを再計算する（クラスター内データの平均値）
4. 割り当てが変化しなくなるまで2〜3を繰り返す

k-means法は計算が高速で大規模データに適するが、初期値依存性がある点や、球状のクラスターを仮定する点に注意が必要である。

### 距離の測定方法

クラスター分析ではデータ間の「距離」の定義が分析結果を左右する。

| 距離尺度 | 特徴 |
|---|---|
| **ユークリッド距離** | 最も一般的。直線距離 |
| **マンハッタン距離** | 各軸方向の差の絶対値の和 |
| **マハラノビス距離** | 変数間の相関を考慮した距離 |
| **コサイン類似度** | ベクトルの向きの類似性（テキスト分析で頻用） |

### 関連する多変量解析

クラスター分析と同様、複数の変数を扱う多変量解析の代表手法に**因子分析**と**主成分分析**がある。いずれも「観測された複数の変数」を別の少数の変数に集約・整理する点で共通するが、目的と方向性が異なる。試験では手法選択や用語識別の文脈でクラスター分析と並べて出題されるため、対比して整理する。

**因子分析（Factor Analysis）**

観測された複数の変数の背後に存在する**潜在変数（共通因子）を探索する**手法である。たとえば学力テストの 5 科目の点数（観測変数）から「言語能力」「数理能力」といった見えない因子を推定する。

- 目的: 観測変数 → 背後にある潜在因子の発見
- 方向: 観測 → **潜在**（変数を作り出す側を探る）
- 用途: 心理学のパーソナリティ研究、消費者の購買動機分析、品質管理の本質的要因抽出

主成分分析（PCA: Principal Component Analysis）

複数の相関する変数を、できるだけ情報を失わずに**少数の新しい変数（主成分）に縮約する**手法である。データ全体の傾向や特徴を把握する目的で次元削減に用いられる。

- 目的: 多次元データ → 少数次元への縮約
- 方向: 観測 → **合成変数**（変数を圧縮）
- 用途: 視覚化のための次元削減、特徴量エンジニアリング、ノイズ低減

**3 手法の対比**

| 手法 | 目的 | 主な活用例 |
|---|---|---|
| **クラスター分析** | データを類似性で **グループ分類** | 顧客セグメンテーション、文書分類 |
| **因子分析** | 観測変数の背後の **潜在因子を探索** | 心理特性の分析、購買動機の抽出 |
| **主成分分析** | 多変量を **少数次元に縮約** | 可視化、特徴量削減、ノイズ低減 |

3 手法はいずれも多変量解析だが、**何を出力するか**で区別する。クラスター分析はグループラベル、因子分析は潜在因子の構造、主成分分析は新しい合成変数（主成分）を出力する。

## 総合技術監理における位置づけ


総合技術監理キーワード集では[**4.1 情報分析と情報活用**](/docs/pe-comprehensive-management-keyword-2026#41-情報分析と情報活用)に位置づけられる。

クラスター分析は[データマイニング](/docs/pe-comprehensive-management-data-mining)の主要手法の一つであり、[機械学習](/docs/pe-comprehensive-management-machine-learning)における教師なし学習の代表的アルゴリズムでもある。

分析結果の解釈には[データ可視化](/docs/pe-comprehensive-management-data-visualization)が不可欠であり、デンドログラムや散布図を通じてクラスター構造を把握する。

過去問 [R02 Ⅰ-1-20](/docs/pe-comprehensive-management-r02-primary#1-20) では関連キーワードとして扱われた（正答は移動平均・指数化・[相関分析](/docs/pe-comprehensive-management-correlation-analysis)・[回帰分析](/docs/pe-comprehensive-management-linear-regression) の組合せ）。クラスター分析は **類似性に基づく分類（教師なし）** が目的であり、2 変数の関係把握（相関分析）や予測式の導出（回帰分析）とは目的が異なるため、統計手法選択の設問では識別が必要。
