## 業績連動型賞与制度とは

業績連動型賞与制度とは、企業や部門の業績に連動して賞与（ボーナス）の支給額を決定する制度である。

従来の日本企業では「基本給の何か月分」という固定的な算定方式が一般的であったが、業績連動型では企業の経営成果に応じて賞与原資が変動する。

企業業績と従業員の処遇を直結させることで、経営参画意識の向上と人件費の柔軟な管理を両立することを目的とする。

### 賞与原資の算定方式

| 方式 | 内容 |
|---|---|
| **利益配分方式** | 経常利益や営業利益の一定割合を賞与原資とする |
| **付加価値配分方式** | 付加価値額の一定割合（労働分配率を基準）を賞与原資とする |
| **売上高基準方式** | 売上高の一定割合を賞与原資とする |
| **目標達成度方式** | 事前に設定した業績目標の達成度に応じて原資を決定する |

### 個人への配分方法

| 方法 | 内容 |
|---|---|
| **一律配分** | 全従業員に均等に配分 |
| **基本給比例配分** | 基本給の比率に応じて配分 |
| **評価反映配分** | 個人の人事評価（業績評価・能力評価）を反映して配分 |
| **組み合わせ型** | 基本給比例＋個人評価反映を組み合わせる方式が一般的 |

### 主な業績指標

| 指標 | 内容 |
|---|---|
| **経常利益** | 企業の通常の経営活動による利益。最も広く使われる指標 |
| **営業利益** | 本業からの利益。事業の実力を反映 |
| **EVA（経済付加価値）** | 税引後営業利益 - 資本コスト。株主価値を考慮した指標 |
| **ROE（自己資本利益率）** | 当期純利益 / 自己資本。株主視点の収益性指標 |
| **部門別業績** | 事業部門ごとの売上・利益。部門間の業績差を反映 |

### メリット・デメリット

| 項目 | 内容 |
|---|---|
| **メリット** | 従業員の経営参画意識向上、業績悪化時の人件費自動調整、成果配分の透明性、固定費の変動費化 |
| **デメリット** | 業績悪化時の従業員の生活不安定、外部環境による業績変動が処遇に影響、短期業績偏重のリスク、部門間の不公平感 |

### 固定賞与との比較

| 比較項目 | 業績連動型賞与 | 固定賞与 |
|---|---|---|
| **算定基準** | 企業・部門の業績指標 | 基本給の月数（例：4か月分） |
| **変動性** | 業績により大きく変動 | ほぼ固定 |
| **経営との連動** | 直結 | 間接的 |
| **従業員の安定性** | 低い | 高い |
| **人件費管理** | 柔軟（変動費化） | 硬直的（固定費） |
