## アンコンシャス・バイアスとは

**アンコンシャス・バイアス**（Unconscious Bias：無意識の偏見）とは、自分自身が気づいていない、ものの見方や考え方の偏りのことである。過去の経験・知識・価値観・周囲の環境等から無意識に形成され、意思決定や行動に影響を与える。

## 主な種類

アンコンシャス・バイアスの主な種類を示す。それぞれの傾向と具体例を合わせて把握しておくとよい。

- **確証バイアス**: 自分の信念を裏付ける情報を集める傾向
  - 例: 「やはりこの方法が正しい」と都合のよい情報だけ注目
- **ステレオタイプ**: 特定の集団に対する固定的なイメージ
  - 例: 「女性はリーダーに向かない」「若者は忍耐力がない」
- **ハロー効果**: 一つの特徴で全体を評価する傾向
  - 例: 高学歴→仕事もできるに違いない
- **親和性バイアス**: 自分と似た人を好む傾向
  - 例: 同じ大学出身者を高く評価
- **正常性バイアス**: 異常事態でも「大丈夫」と思い込む
  - 例: 災害時に避難が遅れる
- **アンカリング**: 最初に得た情報に引きずられる
  - 例: 最初の見積額が基準になる

## 人事・組織への影響

アンコンシャス・バイアスは採用・評価・育成・昇進など人事の各場面に影響を与え、組織のダイバーシティ推進を阻む要因となる。

| 場面 | 影響 |
|---|---|
| **採用** | 同質的な人材ばかり採用（多様性の欠如） |
| **評価** | 特定属性の人材を不当に高く/低く評価 |
| **育成** | 「女性だから」「高齢だから」と成長機会を制限 |
| **昇進** | 管理職像のステレオタイプによる登用の偏り |
| **会議** | 特定の人の意見を軽視・無視 |

## 対策

バイアスの影響を最小化するために、組織は以下の手段を組み合わせて導入する。

| 対策 | 内容 |
|---|---|
| **気づきの研修** | 自分のバイアスに気づくワークショップ（IAT等） |
| **構造化面接** | 採用面接の質問・評価基準を統一 |
| **ブラインド審査** | 応募者の名前・性別等を隠して書類選考 |
| **多様な評価者** | 複数の評価者による多面的評価 |
| **データに基づく意思決定** | 主観を排し、客観的データで判断 |
| **チェックリスト** | 意思決定前にバイアスの有無を確認 |

## 総合技術監理における位置づけ


総合技術監理キーワード集では[**3.3 人材活用計画**](/docs/pe-comprehensive-management-keyword-2026#33-人材活用計画)に位置づけられる。

アンコンシャス・バイアスはダイバーシティ経営・ジェンダーギャップ・LGBTQ対応・ポジティブアクション等の多様性推進施策の基盤となる概念であり、安全管理における正常性バイアス・同調バイアスとも関連する。過去問 [R02 Ⅰ-1-12](/docs/pe-comprehensive-management-r02-primary#1-12) ではダイバーシティ・マネジメントは「人権確保」だけでなく**経営戦略として業績 KPI と連動する**べきとの論点が問われ、バイアス解消 → 多様な人材活用 → 業績向上というロジックがダイバーシティ推進の基盤となる。
