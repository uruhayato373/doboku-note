## 定義

**テクニカルスキル**（Technical Skills）とは、専門的な知識・技術・技能であり、業務遂行に直接必要な能力である。**ノンテクニカルスキル**（Non-Technical Skills）とは、人間と人間の関係性を重視した認知的・社会的なスキルであり、安全な業務遂行を支える能力である。

安全管理においては、両者をバランスよく向上させていくことが望ましい。

## ノンテクニカルスキルの構成要素

ノンテクニカルスキルは大きく「認知的スキル」「社会的スキル」「個人資質」の3カテゴリに分類される。各カテゴリに属する具体的なスキルとその内容は以下のとおりである。

| カテゴリ | スキル | 内容 |
|---|---|---|
| **認知的スキル** | 状況認識 | 周囲の状況を正確に把握する |
| | 意思決定 | 適切な判断を行う |
| **社会的スキル** | コミュニケーション | 情報を正確に伝達・共有する |
| | チームワーク | チームとして協力して作業する |
| | リーダーシップ | チームを安全に導く |
| **個人資質** | ストレス管理 | 緊急時に冷静さを保つ |
| | 疲労管理 | 疲労による能力低下を管理する |

## テクニカルスキルとの関係

テクニカルスキルがいくら高くても、ノンテクニカルスキルが不足していると安全が確保できない。航空・医療・原子力等の高リスク産業で特に重視される。

## 総合技術監理における位置づけ


総合技術監理キーワード集では[**5.4 事故・災害の未然防止活動・技術**](/docs/pe-comprehensive-management-keyword-2026#54-事故・災害の未然防止活動・技術)に位置づけられている。

ノンテクニカルスキルは[ヒューマンファクタ](/docs/pe-comprehensive-management-human-factors)への対策として重要であり、[安全教育](/docs/pe-comprehensive-management-safety-education)・[KYT（危険予知訓練）](/docs/pe-comprehensive-management-kyt)を通じて向上させる。[事故の4E対策](/docs/pe-comprehensive-management-four-e-countermeasures)のうちEducation（教育）の中核的な内容である。

また、ノンテクニカルスキルは[人的資源管理](/docs/pe-comprehensive-management-human-resource-management-pillar)とも深く関わる。チームの編成・役割分担・育成計画を担う人的資源管理の視点から見ると、ノンテクニカルスキルの向上は組織全体の安全パフォーマンスを底上げするための投資である。[リスクマネジメント](/docs/pe-comprehensive-management-risk)の観点では、ノンテクニカルスキルの欠如そのものがヒューマンエラーを誘発するリスク要因であり、スキル向上はリスク低減策の一つとして位置づけられる。

## CRM・ノンテクニカルスキルの歴史的背景

ノンテクニカルスキルの概念は、1970年代末の航空業界における重大事故の教訓から生まれた。1978年、米国オレゴン州ポートランドでユナイテッド航空173便がランディングギアのトラブル対応中に燃料切れで墜落した事故では、コックピット音声記録の分析により、機長が副操縦士の警告を受け入れなかったことと乗員間の情報共有不足が主因と結論づけられた。この事故を契機にNASAが主催したワークショップで「コックピット・リソース・マネジメント（CRM）」の概念が体系化され、1981年にユナイテッド航空が世界初の包括的CRM訓練プログラムを開始した。

その後、CRMは医療・船舶・原子力・建設業の高リスク産業へと波及した。航空分野では「クルー（Crew）」を「チーム（Team）」に拡張し、現在の「ノンテクニカルスキル」という用語で概念が統一されている。日本では1998年に国土交通省航空局がCRM訓練を航空会社乗員向けに義務化し、2024年1月の羽田空港衝突事故を受けた航空法改正（令和7年法律第55号）でパイロット全員への「技能発揮訓練」が新たに義務付けられた。医療分野では米国の研究機関AHRQが開発したTeamSTEPPSを日本の病院が導入し、チームワーク向上による医療事故防止の取組みが広がっている。
