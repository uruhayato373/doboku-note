## 不当な取引制限とは

**不当な取引制限**とは、事業者が他の事業者と共同して、相互にその事業活動を拘束し、または遂行することにより、公共の利益に反して一定の取引分野における競争を実質的に制限することをいう（[**独占禁止法第2条第6項**](https://laws.e-gov.go.jp/law/322AC0000000054#Mp-At_2)）。

いわゆる**カルテル**および**入札談合**がこの不当な取引制限に該当する。

独占禁止法における最も典型的な違反行為であり、公正取引委員会による排除措置命令・課徴金納付命令の対象となるほか、刑事罰の適用もありうる。

## 類型

### カルテル

- **価格カルテル**: 競争事業者間で販売価格を取り決める — 例: 建設資材メーカーによる販売価格の共同決定
- **数量カルテル**: 生産量・販売量を制限する — 例: セメント生産量の割当て
- **市場分割カルテル**: 地域・顧客・取引先を分割する — 例: 地域ごとの受注割当て
- **入札カルテル**: 公共工事等の入札で受注予定者を事前に決定 — 例: 建設業者による受注調整

### 入札談合

| 項目 | 内容 |
|---|---|
| **定義** | 入札において、競争事業者間で受注予定者や入札価格を事前に取り決める行為 |
| **官製談合** | 発注者側の公務員が談合に関与する場合（入札談合等関与行為防止法の適用対象） |
| **民民談合** | 民間事業者間のみで行われる談合 |

### 入札談合等関与行為防止法

| 関与行為 | 内容 |
|---|---|
| **談合の明示的な指示** | 受注予定者を特定の事業者にするよう指示 |
| **秘密情報の漏洩** | 予定価格・入札参加者等の秘密情報を漏洩 |
| **入札参加者の指名における恣意的運用** | 特定事業者を有利にする指名 |

## 要件

不当な取引制限の成立には以下の要件が必要である。

| 要件 | 内容 |
|---|---|
| **意思の連絡** | 事業者間で明示的または黙示的な合意が存在すること |
| **相互拘束・共同遂行** | 合意内容に従い相互にその事業活動を拘束または共同して遂行すること |
| **競争の実質的制限** | 一定の取引分野における競争が実質的に制限されること |

## 制裁

| 制裁 | 内容 |
|---|---|
| **排除措置命令** | 違反行為の排除に必要な措置を命令 |
| **課徴金納付命令** | 売上額の**10%**（製造業等）。繰返し違反は1.5倍加算 |
| **刑事罰（個人）** | 5年以下の懲役または500万円以下の罰金 |
| **法人重科** | 法人に対しては**5億円以下の罰金** |
| **指名停止** | 公共工事における指名停止処分 |
| **損害賠償** | 無過失損害賠償責任（第25条） |

## リニエンシー制度

カルテル・入札談合の摘発を促進するため、自主的に違反を申告した事業者に課徴金を減免する制度が設けられている。

- **1位**: 改正前 全額免除 → 改正後 全額免除
- **2位**: 改正前 50%減額 → 改正後 20%減額＋協力度合いに応じた減算（最大40%追加）
- **3〜5位**: 改正前 30%減額 → 改正後 10%減額＋協力度合いに応じた減算
- **6位以降**: 改正前 対象外 → 改正後 5%減額＋協力度合いに応じた減算

2020年改正により、申告順位だけでなく**調査への協力度合い**に応じた減算が導入された。

## 総合技術監理における位置づけ


総合技術監理キーワード集では[**4.3 知的財産権と情報の保護と活用**](/docs/pe-comprehensive-management-keyword-2026#43-知的財産権と情報の保護と活用)に位置づけられる。
