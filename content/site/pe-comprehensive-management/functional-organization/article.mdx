## 職能別組織とは

職能別組織（functional organization）とは、製造・営業・経理・人事など**専門機能ごとに部門を編成**する組織形態である。

<ArticleImage
  src="/posts/pe-comprehensive-management/functional-organization/img/figure-1.svg"
  alt="組織構造7形態の比較：職能別・事業部制・マトリクス・ネットワーク・ピラミッド・ティール・達成型のメリットとリスク"
/>

最も基本的かつ歴史の長い組織構造であり、規模の小さい企業や単一事業を営む企業で広く採用されている。

各部門は自らの専門領域に特化し、全社的な意思決定はトップマネジメントが一元的に行う。過去問 [R03 Ⅰ-1-16](/docs/pe-comprehensive-management-r03-primary#1-16) では職能別組織と事業部制組織の優位性比較が問われた。職能別は「専門知識の蓄積」と「規模の経済（単位コストの低下）」で優位、事業部制は「環境変化への迅速対応」と「次世代経営者の育成」で優位、という対応が核心。

### 組織構造の特徴

機能別組織は専門機能ごとに部門化し、命令系統と意思決定をトップに集中させる集権的構造を持つ。

- **部門化の基準**: 専門機能（製造・営業・経理・技術・人事など）
- **権限の所在**: トップマネジメントに集中（集権的）
- **命令系統**: 単一の指揮命令系統（ワンライン）
- **部門間調整**: トップが直接調整
- **代表的提唱者**: テイラー（科学的管理法）、ファヨール（管理過程論）

### メリットとデメリット

職能別組織の強みは専門性の蓄積と効率性にある一方、集権構造に起因する部門横断の弱さが主な課題となる。

| 区分 | 内容 |
|---|---|
| **メリット** | |
| 専門性の深化 | 同一機能の人材が集まり、技術・知識が蓄積されやすい |
| 規模の経済 | 機能ごとに資源を集約し、重複投資を回避できる |
| 明確な責任 | 各部門の役割と責任範囲が明確である |
| 人材育成 | 専門家としてのキャリアパスを形成しやすい |
| **デメリット** | |
| セクショナリズム | 部門間の壁が高くなり、横の連携が弱くなる |
| トップの負担増大 | 部門間調整がすべてトップに集中する |
| 全社的視点の欠如 | 各部門が自部門の最適化を優先し、全体最適を見失いやすい |
| 環境変化への対応遅延 | 製品・市場単位の意思決定が遅くなる |

### 適する環境

職能別組織は以下のような環境で有効に機能する。

| 条件 | 理由 |
|---|---|
| **単一事業・単一製品** | 部門間調整の複雑さが小さく、トップで管理できる |
| **安定した事業環境** | 環境変化が少なく、専門性の深化が競争力となる |
| **中小規模の組織** | 管理範囲がトップの統制力の範囲内に収まる |
| **技術的専門性が重要** | 特定分野の専門知識の蓄積が競争優位となる |

## 総合技術監理における位置づけ


総合技術監理キーワード集では[**3.1 人の行動と組織**](/docs/pe-comprehensive-management-keyword-2026#31-人の行動と組織)に位置づけられる。
