## 情報漏洩・改ざん・消失とは

**情報漏洩・改ざん・消失**は、情報セキュリティにおける3大脅威であり、それぞれCIAの機密性・完全性・可用性を直接侵害するものである。

| 脅威 | 侵害される要素 | 定義 |
|---|---|---|
| **情報漏洩** | 機密性（C） | 許可されていない者に情報が渡ること |
| **改ざん** | 完全性（I） | 情報が不正に書き換えられること |
| **消失** | 可用性（A） | 情報が失われ、アクセスできなくなること |

これらの脅威は単独で発生するだけでなく、複合的に発生する場合も多い。

たとえば、ランサムウェア攻撃ではデータの暗号化（消失）と情報の窃取（漏洩）が同時に行われるケースが増加している。

## 情報漏洩の手口・原因

### 外部要因

| 手口 | 内容 |
|---|---|
| **標的型攻撃** | 特定組織を狙ったマルウェア・フィッシングメール |
| **不正アクセス** | 脆弱性の悪用やパスワードクラックによる侵入 |
| **サプライチェーン攻撃** | 取引先・委託先を経由した情報窃取 |
| **ソーシャルエンジニアリング** | 人間の心理的弱点を突いた情報詐取 |

### 内部要因

| 原因 | 内容 |
|---|---|
| **誤操作** | メール誤送信、ファイルの公開設定ミス |
| **内部不正** | 退職者・不満社員による意図的な持ち出し |
| **管理不備** | アクセス権限の設定漏れ、退職者IDの未削除 |
| **紛失・盗難** | ノートPC・USBメモリ・書類の物理的紛失 |

### 被害事例

- 個人情報の大量流出による損害賠償（1件あたり数千円〜数万円の賠償金）
- 企業の信用失墜、株価下落
- 行政処分（個人情報保護委員会からの勧告・命令）

## 改ざんの手口・原因

ウェブや通信経路、内部操作を経路とするさまざまな改ざん手口が存在する。

| 手口 | 内容 |
|---|---|
| **Webサイト改ざん** | CMSの脆弱性を突いた表示内容の不正書き換え |
| **SQLインジェクション** | データベースへの不正なSQL文の注入 |
| **中間者攻撃（MITM）** | 通信経路上でのデータの傍受・改変 |
| **DNSキャッシュポイズニング** | DNS応答の改ざんによる偽サイトへの誘導 |
| **内部不正** | 権限を持つ者による意図的なデータ書き換え |

### 被害事例

- 政府機関のWebサイト改ざんによる信頼性の毀損
- 会計データの改ざんによる不正会計
- 制御系システムのデータ改ざんによる安全上の事故

## 消失の手口・原因

データ消失はサイバー攻撃・機器障害・災害・人為ミスを問わず発生する。

| 原因 | 内容 |
|---|---|
| **ランサムウェア** | データを暗号化して身代金を要求 |
| **ハードウェア障害** | ディスク故障、電源障害 |
| **自然災害** | 地震・水害・火災によるデータセンター損壊 |
| **人為的ミス** | 誤削除、バックアップ手順の不備 |
| **サイバー攻撃** | ワイパー型マルウェアによるデータ破壊 |

### 被害事例

- ランサムウェア被害による業務停止（数日〜数週間）
- バックアップ不備による復旧不能
- 災害時のデータセンター損壊による情報消失

## 対策の体系

情報漏洩・改ざん・消失に対応するため、技術的・組織的・物理的対策を多層的に組み合わせる。

| 分類 | 対策 | 対象脅威 |
|---|---|---|
| **技術的対策** | 暗号化（保存時・通信時） | 漏洩 |
| **技術的対策** | ハッシュ関数・デジタル署名 | 改ざん |
| **技術的対策** | バックアップ・冗長化・DR | 消失 |
| **技術的対策** | ファイアウォール・IDS/IPS | 漏洩・改ざん |
| **技術的対策** | ウイルス対策・EDR | 漏洩・改ざん・消失 |
| **組織的対策** | 情報セキュリティポリシーの策定 | 全般 |
| **組織的対策** | セキュリティ教育・訓練 | 全般 |
| **組織的対策** | インシデント対応計画（IRP） | 全般 |
| **物理的対策** | 入退室管理・施錠管理 | 漏洩・消失 |
| **物理的対策** | 耐震・防火・防水対策 | 消失 |

## 情報セキュリティ管理が重要視されるようになった背景

情報漏洩・改ざん・消失への対策が体系化されるまでには、数十年にわたる技術・制度両面での発展があった。

1960〜70年代、メインフレームの共有利用が広まるにつれ、アクセス制御や完全性保護の必要性が認識された。1972年の米国政府のアンダーソン報告では機密性・完全性・可用性の概念が体系的に提示され、後にCIAトライアドとして情報セキュリティの国際標準基盤となった。

インターネットの急速な普及が進んだ1990〜2000年代には、不正アクセスや企業サイトの改ざん事件が相次ぎ、セキュリティ対策の緊急性が高まった。日本では2003年に個人情報保護法が制定（2005年全面施行）されたことで、情報漏洩に対する法的義務と損害賠償リスクが明確化された。

2010年代以降はランサムウェアの台頭により、消失（データの暗号化）と漏洩（データの窃取）が複合する脅威形態が主流となった。2022年の個人情報保護法改正では、個人データの漏洩等が発覚した際の個人情報保護委員会への報告義務が新設され、組織はインシデント対応体制の整備を法的に求められるようになった。

総合技術監理の観点では、情報漏洩・改ざん・消失はいずれも組織のリスクマネジメントと事業継続（[BCP](/docs/pe-comprehensive-management-business-continuity-plan)）に直結する。特に制御系システムへの改ざん攻撃は安全管理分野の重大リスクとして認識されており、2010年代に発覚した産業制御システムへのサイバー攻撃事案以降、インフラ系企業でのセキュリティ投資が加速した。

## 総合技術監理における位置づけ


総合技術監理キーワード集では[**4.5 情報セキュリティ**](/docs/pe-comprehensive-management-keyword-2026#45-情報セキュリティ)に位置づけられる。
