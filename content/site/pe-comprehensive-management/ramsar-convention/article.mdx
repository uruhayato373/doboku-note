## ラムサール条約とは

ラムサール条約（正式名称：特に水鳥の生息地として国際的に重要な湿地に関する条約）は、1971年にイランのラムサールで採択された、湿地の保全と賢明な利用（ワイズユース）を目的とする国際条約である。

本条約は、湿地が水鳥をはじめとする多様な生物の生息地として、また水質浄化・洪水調節・地下水涵養などの生態系サービスの提供源として極めて重要であるとの認識に基づいている。

日本は1980年に加入し、2025年時点で53か所の湿地が登録されている。

### 条約の3つの柱

ラムサール条約は以下の3つの柱で構成される。

| 柱 | 内容 |
|---|---|
| **湿地の保全** | 登録湿地の適切な保全措置を講ずる義務 |
| **賢明な利用（ワイズユース）** | 登録湿地に限らず、すべての湿地の持続可能な利用を推進 |
| **交流・学習（CEPA）** | 湿地の保全と賢明な利用に関する普及啓発・教育・参加の推進 |

### 登録基準

湿地がラムサール条約湿地として登録されるための基準は以下の9つのうち、少なくとも1つを満たす必要がある。

| 基準 | 概要 |
|---|---|
| 基準1 | 自然または自然に近い状態の代表的な湿地 |
| 基準2 | 絶滅危惧種を支える湿地 |
| 基準3 | 生物地理区の生物多様性維持に重要な湿地 |
| 基準4 | 生物のライフサイクルの重要な段階を支える湿地 |
| 基準5 | 定期的に2万羽以上の水鳥を支える湿地 |
| 基準6 | 水鳥の1種の個体数の1%以上を定期的に支える湿地 |
| 基準7 | 固有の魚類の相当な割合を支える湿地 |
| 基準8 | 魚類の食物源・産卵場・稚魚の生育場として重要な湿地 |
| 基準9 | 湿地に依存する鳥類以外の種の個体数の1%以上を定期的に支える湿地 |

### 日本の主な登録湿地

日本の登録湿地53か所のうち、代表的な湿地を登録湿地名・所在地・登録年・主な特徴の順に示す。

- **釧路湿原**（北海道、1980年）— 日本初の登録湿地。タンチョウの繁殖地
- **琵琶湖**（滋賀県、1993年）— 日本最大の淡水湖
- **尾瀬**（群馬・福島・新潟県、2005年）— 本州最大の高層湿原
- **屋久島永田浜**（鹿児島県、2005年）— アカウミガメの産卵地
- **名蔵アンパル**（沖縄県、2005年）— 亜熱帯のマングローブ湿地

## 総合技術監理における位置づけ


総合技術監理キーワード集では[**6.1 地球的規模の環境問題**](/docs/pe-comprehensive-management-keyword-2026#61-地球的規模の環境問題)に位置づけられる。

ラムサール条約は生物多様性条約を補完する湿地特化の国際条約であり、建設事業における湿地保全やミティゲーション（回避・低減・代償）の判断において、総合技術監理者が考慮すべき重要な枠組みである。

過去問 [R02 Ⅰ-1-34](/docs/pe-comprehensive-management-r02-primary#1-34) では「ラムサール条約の対象は水鳥の生息地として国際的に重要な湿地で、**人工のものや一時的なものは含まれない**」という誤答が出題された。**人工湿地（水田等）や一時的湿地も含まれる**点が誤答識別の核心（対象の広範さが本条約の特徴）。

## 条約制定の背景

ラムサール条約が生まれた背景には、20世紀前半から加速した湿地の大規模消失がある。農業開発・都市化・干拓による湿地の排水・転換が世界的に進み、特に渡り鳥の経由地となる湿地の喪失が国際社会の関心を集めた。1960年代に欧州を中心とする自然保護団体が問題を提起し、国際自然保護連合（IUCN）が主導する形で条約交渉が始まった。

1971年に採択された当初、条約の目的は水鳥の生息地保全に限定されていたが、1980年代以降の締約国会議（COP）を通じて「賢明な利用（ワイズユース）」の概念が導入され、保全と利用の両立を図る枠組みへと発展した。2005年のCOP9では「湿地の文化的価値」が認定され、地域社会との共生という視点も加わっている。総合技術監理の観点では、この歴史的経緯が「環境保全と社会・経済的利用のトレードオフをどう調整するか」という5管理の本質的問いと接続される。
