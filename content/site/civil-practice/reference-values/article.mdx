現場で「あの数値、何cmだったか」「何度以下だったか」を確認したいとき、該当する記事を1本ずつ開き直すのは手間でしょう。このページは、「土木施工の実務」カテゴリの記事で一次資料照合済みの管理値だけを、工種ごとに1枚にまとめた早見表です。

ここに載せているのは、数値そのものと、その数値が何を判断するためのものかという最小限の情報だけです。**なぜその数値になっているのか**は、それぞれのリンク先の記事で解説しています。数値の背景を理解せずに早見表の値だけを覚えると、条件が変わったときに応用が利きません。まずは記事を読み、必要なときにこのページで数値を確認する、という使い方を想定しています。

なお、原本の資料に載っていても一次資料で裏付けが取れなかった数値は、このページにも各記事にも載せていません。載っている数値は、いずれも出典を確認したうえで採用したものだけです。

## コンクリート

打込み当日の時間管理、締固め、受入れ検査、配合という4つの記事の管理値をまとめます。

打込み当日の時間の限度は外気温で、季節の区分は日平均気温で決まるという点を混同しないよう注意してください。詳しくは[打込み当日の時間管理](/docs/civil-practice-concrete-placement-timing)で解説しています。

| 項目 | 値 |
|---|---|
| 練混ぜ〜打込み終了 | 2.0h（25℃以下）/1.5h（25℃超） |
| 練混ぜ〜荷卸し | 1.5h（外気温に依らず一定） |
| 許容打重ね時間間隔 | 2.5h（25℃以下）/2.0h（25℃超） |
| 暑中コンクリートの区分 | 日平均気温25℃超 |
| 寒中コンクリートの区分 | 日平均気温4℃以下 |
| 凝結の始発 | 貫入抵抗3.5N/mm²・練混ぜ後2〜4h |
| 凝結の終結 | 貫入抵抗28.0N/mm²・練混ぜ後4〜6h |

締固めの4つの数値は、材料分離をどの段階で止めるかという1本の理屈でつながっています。詳しくは[打込みと締固めを支配する4つの数値](/docs/civil-practice-concrete-compaction-numbers)を参照してください。

| 項目 | 値 |
|---|---|
| 1層の打上がり高さ | 40〜50cm以下 |
| 自由落下高さ | 1.5m以下 |
| バイブレーターの挿入深さ | 下層へ10cm程度 |
| バイブレーターの挿入間隔 | 50cm以下 |
| 1か所あたりの振動時間 | 5〜15秒 |

受入れ検査の合否基準と配合の考え方は、[配合と受入れ検査で何を見るか](/docs/civil-practice-concrete-mix-acceptance)と[単位水量・水和水 計算ツール](/tools/water-content)にまとめました。

| 項目 | 値 |
|---|---|
| 空気量（普通コンクリート） | 4.5%±1.5% |
| 空気量（軽量コンクリート） | 5.0%±1.5% |
| 塩化物イオン量 | 0.30kg/m³以下（承認時0.60kg/m³以下） |
| 強度判定（1回・供試体3個平均） | 呼び強度の85%以上 |
| 強度判定（3回の平均） | 呼び強度以上 |
| 単位水量の目安（粗骨材20mm） | 175kg/m³以下 |
| 水セメント比の目安（一般条件） | 65%以下 |
| 水和反応に必要な水 | セメント質量の25〜30% |

養生と型枠取外しの判断基準は[表面仕上げと養生の時期](/docs/civil-practice-concrete-finishing-curing)と[型枠・支保工はいつ外せるか](/docs/civil-practice-formwork-removal-timing)で解説します。

| 項目 | 値 |
|---|---|
| 初期凍害を受けない圧縮強度 | 5.0N/mm²・達成後さらに2日間0℃以上 |
| 型枠取外し（厚い部材の鉛直面） | 3.5N/mm² |
| 型枠取外し（薄い部材の鉛直面） | 5.0N/mm² |
| 型枠取外し（スラブ・はりの底面） | 14.0N/mm² |
| 標準養生28日相当の積算温度 | 840℃・D（[計算ツール](/tools/concrete-maturity)） |

打設計画の台数と圧送距離は[ポンプ車・ミキサ車は何台必要か](/docs/civil-practice-concrete-pump-capacity)と[配車計算ツール](/tools/concrete-pump-plan)で計算してください。

| 項目 | 値 |
|---|---|
| ポンプ車吐出量（スクイズ式） | 50m³/h程度 |
| ポンプ車吐出量（ピストン式） | 100m³/h超（カタログ値） |
| 現場実質の打込み速度 | 20〜30m³/h |
| 水平圧送可能距離の目安 | 100m |
| 換算長（125A・垂直管） | 1mにつき4m |
| 換算長（125A・90°ベント管） | 1か所につき6m |
| 換算長（フレキシブルホース） | 1本につき20m |

## 型枠・鉄筋

かぶりと継手の管理値です。詳しくは[かぶりが足りないとき何ができるか](/docs/civil-practice-rebar-cover-placement)と[継手を3方式から選ぶ](/docs/civil-practice-rebar-splice-selection)、[鉄筋継手 判定ツール](/tools/rebar-splice-check)にまとめました。

| 項目 | 値 |
|---|---|
| 純かぶりと芯かぶりの差 | 鉄筋径の1/2 |
| 千鳥配置のずらし量 | 継手の長さ＋鉄筋径の25倍以上 |
| ガス圧接ふくらみの直径 | 鉄筋径の1.4倍以上 |
| ガス圧接ふくらみの長さ | 鉄筋径の1.1倍以上 |
| 手動ガス圧接が不可となる径差 | 7mm超（D41-D51の組合せを除く） |
| 結束線の径 | 0.8mm以上（なまし鉄線） |

## 掘削・土留め

架空線の離隔と法令の数値基準は[掘る前に調べておくこと](/docs/civil-practice-excavation-pre-survey)と[溝掘削の土留めをいつ入れるか](/docs/civil-practice-trench-excavation-safety)、[溝掘削 法令チェッカー](/tools/trench-legal-check)で確認してください。

| 項目 | 値 |
|---|---|
| 架空線の離隔（低圧100〜200V） | 約1.0m |
| 架空線の離隔（高圧6,600V） | 約1.2m |
| 架空線の離隔（特別高圧22,000V以上） | 2.0m以上 |
| 作業主任者の選任義務 | 掘削面の高さ2m以上 |
| 掘削面勾配の基準（その他の地山・2m未満） | 90度以下 |
| 掘削面勾配の基準（その他の地山・5m以上） | 60度以下 |
| 土止め先行工法の想定範囲 | 深さ1.5〜4m・幅3m以下 |

土留めの変位管理値は[土留めの変位が管理値を超えたら](/docs/civil-practice-earth-retaining-displacement)にまとめました。

| 項目 | 値 |
|---|---|
| 一次管理値の目安 | 許容変位量のおおむね8割 |
| 二次管理値の目安 | 許容変位量（設計値）相当 |
| 自立式土留めの許容変位量目安 | 掘削深さのおおむね3% |

## 杭

孔壁保護とコンクリート打設の管理値は[場所打ち杭4工法をどう選ぶか](/docs/civil-practice-cast-in-place-pile-methods)と[場所打ち杭のコンクリートと杭頭処理](/docs/civil-practice-pile-concrete-head-treatment)が扱う範囲です。

| 項目 | 値 |
|---|---|
| アースドリル安定液比重（ベントナイト系） | 1.02〜1.20 |
| アースドリル水位差 | 地下水位より1.5m以上 |
| リバース水頭差 | 地下水位より2m以上 |
| トレミー管の挿入長さ | 打設済みコンクリート中に2m以上 |
| 余盛り高さ（無水掘り） | 500mm以上 |
| 余盛り高さ（泥水が多い場合） | 800mm以上 |

## のり面・盛土・地盤改良

保護工の選定と盛土の締固め、地盤改良の深度区分は[のり面保護工をどう選ぶか](/docs/civil-practice-slope-protection-selection)・[盛土の品質をどう確かめるか](/docs/civil-practice-embankment-quality-control)・[土質を見立てて地盤改良と仮締切りを選ぶ](/docs/civil-practice-soil-improvement-sandbag)が扱う範囲です。

| 項目 | 値 |
|---|---|
| 植生工の適用限界勾配（岩・粘性土） | 1:1.0〜1.2 |
| 盛土の締固め度 | 最大乾燥密度の92%以上 |
| 空気間隙率（砂質土） | 15%以下 |
| 飽和度（粘性土） | 85〜95%程度 |
| 地盤改良（浅層混合処理） | 改良深度3m以内 |
| 地盤改良（中層混合処理） | 改良深度10m以内 |
| 地盤改良（深層混合処理） | 改良深度10m超 |

## 舗装・道路

温度管理と道路附属物の基準は[アスファルト舗装の温度と転圧](/docs/civil-practice-asphalt-pavement-control)・[路盤・路床をどう仕上げるか](/docs/civil-practice-subbase-subgrade-control)・[道路の断面を読み附属物と二次製品を納める](/docs/civil-practice-road-fixtures-precast)を確認してください。

| 項目 | 値 |
|---|---|
| 敷均し温度 | 110℃を下回らない |
| 初転圧 | 110〜140℃・ロードローラ10〜12t |
| 二次転圧 | 終了70〜90℃・タイヤローラ8〜20t |
| 交通開放 | 表面がおおむね50℃以下 |
| 構築路床が必要になる目安 | 路床CBRが3未満 |
| 防護柵の設置高さ | 路面から0.6m以上1.0m以下 |
