請け負う工事に建設業許可が要るのかどうかは、思いのほか迷います。小さな補修だから許可はいらないと考えて引き受けたあとで、消費税や支給材料を足すと基準を超えていた。クレーンで機械を所定の位置に置くだけの仕事が、どの業種に当たるのか分からない。下請に出す追加工事の相手が、その業種の許可を持っているのか確かめていない。

こうした場面は、受注する側にも、元請として下請に出す側にも、発注者として契約を見る側にもあります。

この記事では、許可の要否を五つの問いに分けて、上から順に確かめます。建設工事に当たるか、軽微な工事に収まるか、どの業種か、附帯工事として請け負えるか、どの許可区分が要るか、の五つです。あわせて、下請に出すときや発注者として契約を見るときに、施工体制台帳のどこで許可業種を確かめられるかも整理します。

先に結論を書くと、許可の要否は金額だけでは決まりません。分かれ目になるのは、最初の「建設工事か」という入口と、途中の「どの業種か」という判断です。この二つは契約書の題名ではなく、工事の中身で決まります。金額や名称は改正で変わるため、この記事は令和8年（2026年）10月時点の条文と国土交通省の資料を前提にしています。

## 最初の問いは「その仕事は建設工事か」

建設業法は、土木建築に関する工事で別表第一の上欄に掲げるものを「建設工事」と定め（[第2条第1項](https://laws.e-gov.go.jp/law/324AC0000000100#Mp-At_2)）、建設工事の完成を請け負う営業を「建設業」と呼んでいます。元請か下請か、どんな名義で請けるかは問いません。許可の要否を考える入口は、金額ではなく、この定義に当たるかどうかです。

名義を問わないという点は、[第24条](https://laws.e-gov.go.jp/law/324AC0000000100#Mp-At_24)にも表れています。委託その他いかなる名義であっても、報酬を得て建設工事の完成を目的として結ぶ契約は、請負契約とみなされるからです。請負は仕事の完成に対して報酬を支払う契約（[民法第632条](https://laws.e-gov.go.jp/law/129AC0000000089#Mp-At_632)）で、工事の完成を約束せず作業や助言といった事務の処理だけを委ねる準委任とは別物。契約書に「業務委託」と書かれていても、中身が工事の完成を約束するものなら、建設業法の対象です。

逆に、国土交通省が公表した[法令適用事前確認の回答（令和6年8月29日付）](https://www.mlit.go.jp/appli/content/001761742.pdf)では、IoT機器の設置が有償のサービスを提供するための行為にとどまる場合は、工事の完成を請け負う営業に当たらず、許可は要らないと示されています。題名ではなく、何を約束した契約かで決まります。

国土交通省の資料は、維持管理の委託として行う道路の補修作業を建設工事に含まれる例に、維持管理として行う除草や除雪、設計や監理の業務を含まれない例に挙げています（[建設業法等における定義](https://www.mlit.go.jp/common/001172145.pdf)）。測量や警備の委託、資材の売買も、[関東地方整備局の手引き](https://www.ktr.mlit.go.jp/ktr_content/content/000827696.pdf)では建設工事の請負契約と区別して図示されています。

機械設備の運搬や積卸し、製造や運転調整は、土木工作物や建築物の建設、資機材の据付けを行うものではないため、一般に建設工事に当たらないとされています（令和元年5月31日付の回答、[運搬・積卸し](https://www.mlit.go.jp/common/001296382.pdf)と[製造・運転調整](https://www.mlit.go.jp/common/001296380.pdf)）。

迷いやすい作業を、建設工事に当たるかどうかで並べると次のとおりです。

| 作業の中身 | 建設工事か |
|---|---|
| 維持管理の委託として行う道路の補修 | 当たる |
| 維持管理として行う除草・除雪 | 当たらない |
| 設計・監理の業務 | 当たらない |
| 測量の委託 | 当たらない |
| 機械設備の運搬・積卸しだけ | 一般に当たらない |
| 機械設備の製造・運転調整 | 一般に当たらない |
| 設置済みの電気通信設備の改修・修繕・補修 | 当たる（電気通信工事） |
| 電気通信設備の保守（点検・整備・修理）の役務 | 当たらない |

点検と補修は、契約の中で分けて読むのが安全です。電気通信設備については、国土交通省の[許可事務ガイドライン](https://www.mlit.go.jp/totikensangyo/const/content/001860019.pdf)が、設置済みの設備の改修・修繕・補修は電気通信工事に当たる一方、保守の役務提供は当たらないと整理しています。点検だけの契約は工事に当たらなくても、補修や更新を含む契約は、次の金額と業種の問いへ進みます。

もう一つ、建設業は「営業」である点も入口の条件です。国土交通省は、営利の目的で同種の業務を継続的かつ集団的に行うことを営業と解しており、設備の安全対策工事を発注してその設備を売却するだけの事業者は、建設業を営んでいないと回答しています（[令和3年3月2日付](https://www.mlit.go.jp/appli/content/001389162.pdf)）。

## 次の問いは「軽微な工事に収まるか」

建設工事に当たっても、工事1件の請負代金が500万円に満たない軽微な建設工事だけを請け負う営業なら、許可は要りません（[法第3条第1項ただし書](https://laws.e-gov.go.jp/law/324AC0000000100#Mp-At_3)、[施行令第1条の2第1項](https://laws.e-gov.go.jp/law/331CO0000000273#Mp-At_1_2)）。建築一式工事は、1,500万円未満か、延べ面積150㎡未満の木造住宅工事が基準です。この記事は土木の現場を念頭に、500万円の基準で説明します。

基準に当てはめる額は、契約書の請負代金そのままではありません。次の三つの補正が入ります。

/>

たとえば税抜480万円の工事は、税率10%なら税込528万円になり、軽微な工事に収まりません。注文者が材料を支給する工事も、請負代金が小さく見えるだけで、判定額は材料の市場価格の分だけ大きくなります。

分割の扱いは、特に誤解されやすい点です。基準以下に収めるために契約を分けても、正当な理由に基づく分割でない限り、合計額で判断されます。「正当な理由」の中身は、条文にも許可事務ガイドラインにも例示がありません。個別の事例は許可行政庁の判断です。工区や工種を分けて別契約にしているなら、同じ工事の完成を目的とした契約かどうかを、契約の分け方の実質で確かめましょう。

許可なしに軽微な工事を超える工事を請け負うと、3年以下の拘禁刑または300万円以下の罰金が科されます（[法第47条第1項第1号](https://laws.e-gov.go.jp/law/324AC0000000100#Mp-At_47)）。法人には、あわせて1億円以下の罰金が科される場合があります（法第53条）。

## 三つ目の問いは「どの業種の工事か」

許可は29の業種ごとに受けます（法第3条第2項、別表第一）。土木一式と建築一式の二つの一式工事と、27の専門工事があり、業種の内容は昭和47年建設省告示第350号が定めています。具体例と区分の考え方は、[許可事務ガイドライン](https://www.mlit.go.jp/totikensangyo/const/content/001860019.pdf)（令和7年2月1日最終改正）の本文と別表にまとまっています。許可業種が合わなければ、軽微な工事を超える工事は請け負えません。

契約書の工事名と許可業種は、一対一では対応しません。たとえば路線名を冠した道路改良工事には、掘削、路盤、舗装、ガードレールの設置といった工種が並びます。掘削とガードレールはとび・土工・コンクリート工事、舗装は舗装工事というように、業種は工種ごとに分かれます。見るべきは工事名ではなく、仕様書と内訳書の工種です。

業種の決め方は、立場と、工種の見え方で変わります。次の図は、その対応を三つの場合に分けたものです。

### 最初に、元請か下請かを決める

同じ工事でも、元請として請けるのか、下請として請けるのかで、見る業種が変わります。[国土交通省中部地方整備局の資料](https://www.cbr.mlit.go.jp/kensei/info/qa/pdf/R0307/R0307_shiryo_01_gyosyu.pdf)は、土木一式工事と建築一式工事を、大規模または施工内容が複雑な工事を原則として元請の立場で総合的にマネージメントする事業者向けの許可と注記しています。

そのため、一式工事の許可を受けた業者が他の専門工事を単独で請け負うときは、その専門工事の許可が別に要ります（同じ資料の注記）。軽微な工事を除き、一式工事に当たらない単独のとび・土工・コンクリート工事は、土木一式工事の許可だけでは請け負えません。下請として請ける工事は、専門工事の業種で見るのが基本です。

### 仕様書と内訳書の工種を、別表に当てはめる

仕様書と内訳書から工種を拾ったら、告示とガイドラインの別表に照らします。土木の現場で最も多く出会うのが、とび・土工・コンクリート工事です。告示は、その内容を次の五つに分けています。

    "ロ — くい打ち、くい抜き、場所打ぐい",

ホの例示は、地すべり防止、地盤改良、土留め、仮締切り、吹付け、法面保護、道路付属物設置、あと施工アンカーなど。なお、ニに例示されるプレストレストコンクリート工事のうち、橋梁などの土木工作物を総合的に建設するものは、土木一式工事に当たります。

現場で名前の挙がる工種を、許可事務ガイドラインの例示と区分の考え方で業種に当てはめると、次のようになります。

| 工事の内容 | 許可業種 |
|---|---|
| 掘削・盛土・締固め、土留め、仮締切り | とび・土工・コンクリート工事 |
| くい打ち・くい抜き・場所打ぐい | とび・土工・コンクリート工事 |
| コンクリートの打設・圧送 | とび・土工・コンクリート工事 |
| 法枠の設置、モルタル・種子の吹付け | とび・土工・コンクリート工事 |
| 薬液注入・ウェルポイントなどの地盤改良 | とび・土工・コンクリート工事 |
| ガードレール・道路標識の設置 | とび・土工・コンクリート工事 |
| 橋梁等を総合的に建設するプレストレストコンクリート構造物 | 土木一式工事 |
| アスファルト舗装、路盤築造 | 舗装工事 |
| 路面標示 | 塗装工事 |
| 橋梁工事、水門・閘門の門扉設置 | 鋼構造物工事 |
| 河川・港湾のしゅんせつ | しゅんせつ工事 |
| 鉄筋の加工組み立て・継手 | 鉄筋工事 |

ガードレールの設置は、舗装工事と併せて施工されることが多くても、工事の種類は舗装工事ではなく、とび・土工・コンクリート工事です。許可業種は工事の組合せ方ではなく、工事の内容で決まります。区分表は改正されることがあるため、判断するときは国土交通省の最新の資料で確かめてください。

### 複数の工種は、独立した使用目的を持つかで分ける

一つの契約に複数の工種が入るときは、まず、それぞれが独立した使用目的を持つかを見ます。持たない従たる工事は、四つ目の問いで扱う附帯工事の候補です。持つ工種が並ぶときは、工種ごとの専門工事として別々の業種で見るか、一式工事として見るかを決めます。

分かれ目は、総合的な企画、指導、調整が要るかどうかです。告示は土木一式工事を、総合的な企画、指導、調整のもとに土木工作物を建設する工事（補修、改造、解体を含む）と定めています。

一式工事は、必ずしも二つ以上の専門工事の組合せを要件としません。ガイドラインは、工事の規模や複雑さから見て個別の専門工事として施工することが困難なものも含むとしています。ただし、単独の専門工事で説明できる工事を「一式」と呼んで済ませることはできません。

土木一式工事の中で他の専門工事を自ら施工するときは、その工事の専門技術者を置くか、その業種の許可を持つ業者に施工させる必要があります（[法第26条の2第1項](https://laws.e-gov.go.jp/law/324AC0000000100#Mp-At_26_2)）。

### 迷いやすい境界を知っておく

許可事務ガイドラインは、業種の境界が分かれやすい工事について区分の考え方を示しています。土木で出会いやすいものを、四つに絞って整理しました。

- **撤去・解体**: 専門工事で造った目的物だけを解体するなら、その専門工事の業種。総合的な企画、指導、調整のもとに土木工作物や建築物を解体するなら、土木一式工事や建築一式工事です。別表には、工作物の解体を行う解体工事も、独立した業種として置かれています。
- **ブロック**: 根固めブロックや消波ブロックのように規模の大きいものの据付けは、とび・土工・コンクリート工事。擁壁や法面としてコンクリートブロックを積み、または張る工事は、石工事に当たります。
- **鉄骨と屋外広告物**: 鉄骨を製作・加工から組み立てまで一貫して請け負うなら鋼構造物工事で、加工済みの鉄骨を現場で組み立てるだけならとび・土工・コンクリート工事。屋外広告物も同じ考え方で、現場での製作・加工から設置まで一貫して請け負うなら鋼構造物工事、それ以外はとび・土工・コンクリート工事（屋外広告物設置工事）です。
- **トンネル**: トンネルの防水など土木系の防水工事は、防水工事ではなくとび・土工・コンクリート工事。建築系の防水工事だけが防水工事に当たります。トンネルや地下道の給排気のために設置する機械器具の工事は、機械器具設置工事です。

### 機械の据付けは、運搬・揚重・固定・組み立てに分けて見る

機械の据付けは、一つの作業のように見えて、中身によって業種が分かれます。運搬、揚重、固定、組み立てのどこまでを請け負うのかが、見るべき点です。

現場での組み立て、または工作物への取り付けが必要な機械は、機械器具設置工事の領域です。告示は、機械器具の組立て等により工作物を建設し、または工作物に機械器具を取り付ける工事と定め、ガイドラインの別表はプラント設備、運搬機器設置、立体駐車設備などを例示しています。

ただし、電気、管、電気通信、消防施設など専門の工事に当たる機械は、原則としてその専門工事に区分されます（[許可事務ガイドライン](https://www.mlit.go.jp/totikensangyo/const/content/001860019.pdf)の機械器具設置工事の項）。配管や配線の作業そのものも、ガス管配管工事や構内電気設備工事の例示のとおり、管工事や電気工事に当たり得ます。どれにも当たらない機械器具や、複合的な機械器具の設置が、機械器具設置工事です。

同じ「据付け」でも、荷下ろしだけなのか、クレーン等で所定の位置に据えるまでなのか、アンカーで固定するまでなのか、現場の組み立てや取り付けまで含むのかで、答えが変わります。契約の範囲をこの単位で書き分けておくと、あとから業種を説明しやすくなります。

## 四つ目の問いは「附帯工事として請け負えるか」

許可を受けた業種の工事を請け負うときは、それに附帯する別の業種の工事も、許可なしで請け負えます（法第4条）。条文に金額の上限はありません。許可事務ガイドラインは、附帯工事を、主たる工事の施工により必要を生じた従たる工事、または主たる工事を施工するために生じた従たる工事で、それ自体が独立の使用目的に供されないものと説明しています。

具体的な判断の基準は、注文者の利便や請負契約の慣行。工事の準備、実施、仕上げに当たって一連または一体の工事として施工することが必要または相当と認められるかを、総合的に見ます。[国土交通省近畿地方整備局の資料](https://www.kkr.mlit.go.jp/kensei/kensetsu/c9us5e000008u3a4-att/all-data_R8.01.pdf)が挙げる例は、次のとおりです。

| 主たる工事 | 附帯工事の例 |
|---|---|
| 管工事 | 熱絶縁工事 |
| 屋根工事 | 塗装工事 |
| 屋内電気工事 | 内装仕上工事 |
| 建具工事 | コンクリート工事 |

表の例は建築系の工事が中心ですが、土木の工事に当てはめるときの物差しも、同じです。主たる工事を施工するために必要になったか、主たる工事の施工によって必要になったかを見ます。一方、主たる工事とは別の構造物を築造する工事は、同じ契約書に載っていても、独立した使用目的を持つため附帯工事とは言えません。個別の判断は、許可行政庁が行います。

軽微でない附帯工事を自社で施工するときは、その工事について主任技術者と同じ資格要件を満たす専門技術者を現場に置くか、その業種の許可を持つ建設業者に施工させる必要があります（法第26条の2第2項）。資格が備わっていれば、主任技術者や監理技術者が専門技術者を兼ねることもできます。

附帯工事で積んだ経験は、新たにその業種の許可を取るときの実務経験としては認められません（関東地方整備局の許可申請の手引き、前掲）。附帯工事として請けられることと、その業種の許可を持つことは、別の話です。

## 五つ目の問いは「どの許可区分が要るか」

許可は、営業所の置き方で、国土交通大臣許可か都道府県知事許可かが決まります。二つ以上の都道府県に営業所を置くなら大臣許可、一つの都道府県だけなら知事許可です（法第3条第1項）。知事許可でも、営業できる区域や工事を施工できる区域に制限はなく、他県の現場も施工できます。

営業所とは、本店または支店、もしくは常時建設工事の請負契約を締結する事務所をいいます。見積り、入札、狭義の契約締結など、請負契約の締結に係る実体的な行為を行う事務所が該当し、契約書の名義人が代表者かどうかは問いません。本店や支店は、契約を結ばなくても、他の営業所を指導監督するなど営業に実質的に関与していれば営業所に数えられます。

許可を受けた業種を軽微な工事だけで営む場合でも、届出をした営業所以外では、その業種の営業はできません。他県に出張所を置いて見積りや契約を始めるなら、その出張所が営業所に当たるかを先に確かめます。

もう一つの区分は、一般建設業と特定建設業です。発注者から直接請け負う1件の工事について、下請代金の総額が5,000万円以上（建築一式工事は8,000万円以上）になる下請契約を結ぶ場合は、特定建設業の許可が要ります。この金額は消費税を含み、元請が提供する材料等の価格は含みません。令和7年2月1日に、従来の4,500万円（建築一式は7,000万円）から引き上げられました。

判断するのは、元請の請負金額ではなく、一次下請に出す額の総額です。元請の請負金額に上限はなく、一次下請以下の建設業者には、この制限はかかりません。特定建設業の許可がないのに基準以上の下請契約を結ぶと、法第16条に違反し、法第47条の罰則の対象になります。

<Callout type="warn" title="三つの金額を混同しない">
許可の要否を決める500万円（建築一式は1,500万円）と、特定建設業の許可が要る下請代金の5,000万円（建築一式は8,000万円）は、別の制度の金額です。主任技術者・監理技術者の専任を求める請負代金の基準（4,500万円、建築一式は9,000万円）も別にあり、令和7年2月1日に5,000万円と合わせて引き上げられました。
</Callout>

## 下請に出すとき、発注者として契約を見るとき

ここまでの問いは請け負う側の判断として書いてきましたが、同じ問いは、下請に出す元請にも、契約を見る発注者にも当てはまります。下請に出す工事が軽微でなければ、その工事の業種の許可を持つ業者に出さなければなりません。許可のない業者（軽微な工事だけを請け負う者を除く）と下請契約を結んだ建設業者は、指示処分の対象になり、営業の停止を命じられることもあります（[法第28条](https://laws.e-gov.go.jp/law/324AC0000000100#Mp-At_28)）。重層下請と施工体制台帳の読み方は[建設産業の構造](/docs/civil-practice-construction-industry-structure)で、下請の作業員の在留資格の確認は[外国人材の受入れ前の確認](/docs/civil-practice-foreign-workers-site-check)で、元請の指示が偽装請負にならないかは[下請への指示の線引き](/docs/civil-practice-subcontract-instruction-boundary)で続きを追えます。

公共工事では、確かめる場所が決まっています。公共工事の受注者は、下請契約を結んだときに施工体制台帳を作成します（[公共工事の入札及び契約の適正化の促進に関する法律第15条第1項](https://laws.e-gov.go.jp/law/412AC0000000127#Mp-At_15)）。台帳には、下請負人の許可番号と、請け負った工事に係る許可を受けた建設業の種類を書く欄があります（[建設業法施行規則第14条の2](https://laws.e-gov.go.jp/law/324M50004000014#Mp-At_14_2)）。

台帳の写しは、情報通信技術で施工体制を確認できる措置を講じている場合を除き、発注者に提出されます（[同法第15条第2項](https://laws.e-gov.go.jp/law/412AC0000000127#Mp-At_15)）。

許可番号は、国土交通省の[建設業者・宅建業者等企業情報検索システム](https://www.mlit.go.jp/totikensangyo/const/sosei_const_tk3_000037.html)で、許可業種や許可年月日、有効期間を照合できます。掲載の反映には時間差があるため、許可を受けて間もない業者は、許可通知書の写しで確かめましょう。

もう一つ、見落とせないのが社会保険です。令和2年10月から、許可・更新の要件になっています。求められるのは、健康保険、厚生年金保険、雇用保険のそれぞれについて、適用事業所に該当する全ての営業所で届書を提出していること（[建設業法施行規則第7条第2号](https://laws.e-gov.go.jp/law/324M50004000014#Mp-At_7)）。

公共事業労務費調査（令和7年10月調査）の加入率は、企業単位で99.1%、労働者単位で95%でした（[国土交通省の発表](https://www.mlit.go.jp/report/press/tochi_fudousan_kensetsugyo14_hh_000001_00348.html)）。許可の要件は営業所単位の届出で、現場の労働者の加入は、台帳の作業員の記載欄で確かめます。

元請が下請に代金を支払うときは、出来形に対する支払や完成後の支払を受けた場合の下請代金のうち、労務費に相当する部分について、現金で支払うよう適切な配慮をしなければなりません（法第24条の3第2項）。契約の入口で業種と金額を確かめたあとは、支払い方にも目を向けます。

## 許可を取る側・保つ側で、令和2年以降に変わったこと

許可が要ると分かったら、次は取れるのか、保てるのかが問題になります。令和2年10月1日の改正で許可の基準と事業承継の扱いが変わり、令和7年12月12日には改正法が[完全に施行](https://www.mlit.go.jp/report/press/tochi_fudousan_kensetsugyo13_hh_000001_00317.html)されました。要否の判断と並べて押さえておきたい点に絞ります。

許可の基準は、経営体制、営業所技術者、誠実性、財産的基礎の四つで（法第7条、第15条）、令和2年10月から社会保険の加入が加わりました。営業所ごとに専任で置く技術者は、現在の条文では営業所技術者と呼ばれます（以前の専任技術者）。

経営体制は、経営業務の管理責任者としての経験（これに準ずる地位での経験を含む）を持つ常勤役員等が1人いる型（施行規則第7条第1号イ）が基本です。令和2年10月からは、役員等としての経験を持つ常勤役員等に、財務管理・労務管理・業務運営の経験を持つ補佐者を置く型（同号ロ）も認められました。補佐者に求められるのは、それぞれ5年以上の業務経験で、1人が複数を兼ねてもかまいません。

財産的基礎は、一般建設業と特定建設業で基準が違います。

| 区分 | 財産的基礎の基準 |
|---|---|
| 一般建設業 | 次のいずれか — 自己資本500万円以上、500万円以上の資金調達能力、直前5年間許可を受けて継続して営業した実績 |
| 特定建設業 | 次のすべて — 欠損の額が資本金の20%以内、流動比率75%以上、資本金2,000万円以上かつ自己資本4,000万円以上 |

この基準は許可を行うときに判断され、許可を受けたあとに下回っても、直ちに許可の効力に影響するものではありません。一方、経営体制と営業所技術者は、後任がいなくなれば要件の欠如として許可の取消しにつながります（[法第29条第1項第1号](https://laws.e-gov.go.jp/law/324AC0000000100#Mp-At_29)）。

事業承継では、令和2年10月1日から認可制度が始まりました。以前は、事業譲渡や合併、分割のたびに従前の許可を廃業して新規に申請し直す必要があり、廃業から新たな許可までの間は、軽微な工事しか請け負えない空白期間が生じていました。現在は、承継の前にあらかじめ認可を受けておけば、建設業者としての地位を承継でき、空白期間は生じません（[法第17条の2](https://laws.e-gov.go.jp/law/324AC0000000100#Mp-At_17_2)）。

相続も、被相続人の死亡後30日以内に認可を申請すれば、相続人が地位を承継します（法第17条の3）。

承継の認可でも、承継者に許可の要件が備わっている必要があります。承継するのは建設業の全部で、一部の業種だけを承継することはできません。[関東地方整備局の案内](https://www.ktr.mlit.go.jp/ktr_content/content/000877209.pdf)では、承継予定日の90日前までに申請を受け付けています。

令和7年12月12日に完全施行された改正法（[国土交通省の施行予告](https://www.mlit.go.jp/report/press/tochi_fudousan_kensetsugyo13_hh_000001_00317.html)）では、受注者側にも、通常必要な原価に満たない請負代金（正当な理由がある場合を除く）や著しく短い工期での契約が禁じられました（[法第19条の3第2項](https://laws.e-gov.go.jp/law/324AC0000000100#Mp-At_19_3)、[第19条の5第2項](https://laws.e-gov.go.jp/law/324AC0000000100#Mp-At_19_5)）。

あわせて、中央建設業審議会が労務費の基準を作成するようになりました（[法第34条第2項](https://laws.e-gov.go.jp/law/324AC0000000100#Mp-At_34)）。許可の要否の判断そのものは変わりませんが、受注する金額が適正かどうかを確かめる目が、契約の見方に加わります。

## 建設業許可のほかに要る許認可

建設業許可は、ほかの許認可の代わりにはなりません。土木の現場に関わるものでは、次のような手続きが別にあります。

| 営む業 | 別に要る手続き |
|---|---|
| 解体工事業 | 土木工事業・建築工事業・解体工事業のいずれの許可もなければ、都道府県知事への解体工事業の登録 |
| 電気工事業 | 登録電気工事業者の登録。建設業許可を受けた建設業者は、登録を受けたものとみなされ、営業の開始を届け出る |
| 建設工事に伴う廃棄物の運搬 | 産業廃棄物収集運搬業の許可（事業者が自ら運ぶ場合は不要） |
| 宅地建物取引・建築士事務所 | 建設業とは別の免許・登録 |

解体工事業の登録は建設リサイクル法（第21条）、電気工事業の登録は電気工事業の業務の適正化に関する法律（第3条、第34条）が定めています。建設工事に伴う産業廃棄物は、元請業者が事業者として扱われます（廃棄物処理法第21条の3）。下請が運搬する場合には、書面による請負契約で定め、環境省令が定める廃棄物に限って下請を事業者とみなす例外があります。それ以外で下請が運ぶなら、収集運搬業の許可が必要です。

## 迷ったときの確かめ方と、判断の残し方

ここまでの問いで判断が割れるときは、許可行政庁に照会します。大臣許可の窓口は地方整備局、知事許可の窓口は都道府県です。国土交通省には、行為が許可の対象かどうかを事前に確かめる[法令適用事前確認手続](https://www.mlit.go.jp/appli/file000015.html)があり、[建設業法第3条第1項](https://laws.e-gov.go.jp/law/324AC0000000100#Mp-At_3)に関する[回答](https://www.mlit.go.jp/appli/file000016.html)も公表されています。回答は照会者が示した事実だけを前提とした現時点の見解で、司法判断を拘束するものではありません。

判断を毎回その場で下すと、担当が替わったときに根拠が残りません。判断した内容を記録しておけば、次の契約や点検の場面で、同じ迷いを繰り返さずに済みます。
