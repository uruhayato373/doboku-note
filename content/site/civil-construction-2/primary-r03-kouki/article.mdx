## 問題 No.1 土木一般

「土工作業の種類」と「使用機械」に関する次の組合せのうち，**適当でないもの**はどれか。

|  | 土工作業の種類 | 使用機械 |
|---|---|---|
| (1) | 伐開・除根 | タンピングローラ |
| (2) | 掘削・積込み | トラクターショベル |
| (3) | 掘削・運搬 | スクレーパ |
| (4) | 法面仕上げ | バックホウ |

<details>
<summary>解答・解説</summary>

**正解: (1)**

1. 伐開・除根は立木や根株の除去でブルドーザ等が用いられタンピングローラは締固め機械なので誤り ❌

2. トラクターショベルは掘削・積込みに適し正しい ✅

3. スクレーパは掘削・運搬・敷均しを一台で行え正しい ✅

4. バックホウは精密な法面仕上げにも用いられ正しい ✅

<ExamPoint>タンピングローラは締固め用で伐開・除根には使わない</ExamPoint>

</details>

## 問題 No.2 土木一般

土質試験における「試験名」とその「試験結果の利用」に関する次の組合せのうち，**適当でないもの**はどれか。

|  | 試験名 | 試験結果の利用 |
|---|---|---|
| (1) | 土の圧密試験 | 粘性土地盤の沈下量の推定 |
| (2) | ボーリング孔を利用した透水試験 | 土工機械の選定 |
| (3) | 土の一軸圧縮試験 | 支持力の推定 |
| (4) | コンシステンシー試験 | 盛土材料の選定 |

<details>
<summary>解答・解説</summary>

**正解: (2)**

1. 圧密試験は粘性土地盤の沈下量推定に用い正しい ✅

2. 透水試験は地盤の透水係数を求めるもので土工機械の選定には用いず誤り ❌

3. 一軸圧縮試験は粘性土の強度から支持力推定に用い正しい ✅

4. コンシステンシー試験は塑性指数等で盛土材料の選定に用い正しい ✅

<ExamPoint>透水試験は透水係数の把握で機械選定とは結び付かない</ExamPoint>

</details>

## 問題 No.3 土木一般

盛土に関する次の記述のうち，**適当でないもの**はどれか。

**(1)** 盛土の基礎地盤は，盛土の完成後に不同沈下や破壊を生じるおそれがないか，あらかじめ検討する。

**(2)** 建設機械のトラフィカビリティーが得られない地盤では，あらかじめ適切な対策を講じる。

**(3)** 盛土の敷均し厚さは，締固め機械と施工法及び要求される締固め度などによって左右される。

**(4)** 盛土における構造物縁部の締固めは，できるだけ大型の締固め機械により入念に締め固める。

<details>
<summary>解答・解説</summary>

**正解: (4)**

1. 基礎地盤の沈下・破壊の事前検討は盛土の基本で正しい ✅

2. トラフィカビリティー不足には事前対策を講じる正しい記述 ✅

3. 敷均し厚さは機械・施工法・締固め度で決まり正しい ✅

4. 構造物縁部は狭く小型の振動ローラやランマで丁寧に締め固めるべきで誤り ❌

<ExamPoint>構造物縁部の締固めは小型機械で入念に行う</ExamPoint>

</details>

## 問題 No.4 土木一般

地盤改良工法に関する次の記述のうち，**適当でないもの**はどれか。

**(1)** プレローディング工法は，地盤上にあらかじめ盛土等によって載荷を行う工法である。

**(2)** 薬液注入工法は，地盤に薬液を注入して，地盤の強度を増加させる工法である。

**(3)** ウェルポイント工法は，地下水位を低下させ，地盤の強度の増加を図る工法である。

**(4)** サンドマット工法は，地盤を掘削して，良質土に置き換える工法である。

<details>
<summary>解答・解説</summary>

**正解: (4)**

1. プレローディングは事前載荷で圧密を促す工法で正しい ✅

2. 薬液注入は地盤の強度増加や止水を図る工法で正しい ✅

3. ウェルポイントは地下水位を低下させ強度を高める工法で正しい ✅

4. 砂を敷く工法で良質土への置換は置換工法であり誤り ❌

<ExamPoint>サンドマットは軟弱地盤上に砂を敷く排水層工法</ExamPoint>

</details>

## 問題 No.5 土木一般

コンクリートに用いられる次の混和材料のうち，コンクリートの耐凍害性を向上させるために使用する混和材料に**該当するもの**はどれか。

**(1)** 流動化剤

**(2)** フライアッシュ

**(3)** AE 剤

**(4)** 膨張材

<details>
<summary>解答・解説</summary>

**正解: (3)**

1. 流動化剤は流動性を高めるもので耐凍害性向上ではなく誤り ❌

2. フライアッシュは水和熱低減や長期強度に寄与し耐凍害性が主目的でなく誤り ❌

3. AE 剤は微細な空気泡を連行し凍結融解への耐凍害性を高め正しい ✅

4. 膨張材は乾燥収縮の補償に用い耐凍害性向上ではなく誤り ❌

<ExamPoint>耐凍害性向上にはエントレインドエアを生む AE 剤</ExamPoint>

</details>

## 問題 No.6 土木一般

コンクリートの配合設計に関する次の記述のうち，**適当でないもの**はどれか。

**(1)** 所要の強度や耐久性を持つ範囲で，単位水量をできるだけ大きく設定する。

**(2)** 細骨材率は，施工が可能な範囲内で，単位水量ができるだけ小さくなるように設定する。

**(3)** 締固め作業性が良い場合は，最小スランプの自設定を行う。

**(4)** 一般に鉄筋が少ない場合は，最小スランプの目安を小さくする。

<details>
<summary>解答・解説</summary>

2. 細骨材率は単位水量が小さくなるよう適切に設定し正しい ✅

3. 施工性が良ければ最小スランプを設定でき正しい ✅

4. 鉄筋が少ないと充填が容易なため最小スランプを小さく設定でき正しい ✅

<ExamPoint>単位水量は所要の品質を保つ範囲でできるだけ小さく</ExamPoint>

</details>

鉄筋の加工及び組立てに関する次の記述のうち，**適当なもの**はどれか。

**(2)** 鉄筋の継手箇所は，施工しやすいように同一の断面に集中させる。

**(3)** 鉄筋表面の浮きさびは，付着性向上のため，残しておく。

## 問題 No.9 専門土木

既製杭の施工に関する次の記述のうち，**適当でないもの**はどれか。

**(1)** プレボーリング杭工法は，孔内の崩壊を防止し孔壁の崩壊を防ぎながら掘削する。

**(2)** 中掘り杭工法は，ハンマで打ち込む最終打撃方式により先端処理を行うことがある。

**(3)** 中掘り杭工法は，一般に先端開放の既製杭の内部にスパイラルオーガ等を通して掘削する。

**(4)** プレボーリング杭工法は，ソイルセメント状の掘削孔を築造して杭を沈設する。

<details>
<summary>解答・解説</summary>

**正解: (1)**

1. プレボーリングは安定液で孔壁を保護して先行掘削した後に杭を沈設するもので「崩壊を防ぎながら掘削する」とする説明は適切でなく誤り ❌

2. 中掘り杭は最終打撃方式で先端処理することがあり正しい ✅

3. 中掘り杭は先端開放の既製杭内部にオーガを通して掘削し正しい ✅

4. プレボーリングはソイルセメント状の掘削孔に杭を沈設し正しい ✅

<ExamPoint>プレボーリングは先行掘削後に杭を沈設し安定液で孔壁を保護</ExamPoint>

</details>

場所打ち杭の各種工法に関する次の記述のうち，**適当なもの**はどれか。
