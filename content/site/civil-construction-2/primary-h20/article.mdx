## 問題 No.1

土質試験の「目的」とその「土質試験名」との組合せとして，次のうち**適当でないもの**はどれか。

［目的］ ── ［土質試験名］

1. 粘性地盤の沈下量の推定 ── 圧密試験

2. 盛土の締固め度の推定 ── 締固め試験

3. 盛土斜面の安定性の推定 ── 一軸圧縮試験

4. 地盤の透水性の推定 ── 含水比試験

<details>
<summary>解答・解説</summary>

**正解: (4)**

1. 圧密試験は粘性土の圧密沈下量と沈下時間の推定に用いる。組合せは適当。 ✅

2. 締固め試験で最大乾燥密度と最適含水比を求め、盛土の締固め度の管理基準とする。組合せは適当。 ✅

3. 一軸圧縮試験で粘性土の強さ（せん断強さ）を求め、盛土斜面などの安定検討に用いる。組合せは適当。 ✅

4. 含水比試験は土中の水分量を求める試験で、透水性は透水試験で推定する。組合せが適当でない。 ❌

<ExamPoint>透水性の推定は透水試験で、含水比試験は水分量を求める試験</ExamPoint>

</details>

## 問題 No.2

道路の切土法面に関する次の記述のうち，**適当でないもの**はどれか。

1. 法面のはく離が多いと推定される場合や小段の肩が侵食を受けやすい場合は，小段の横断勾配を逆勾配とし，小段に排水溝を設置する。

2. 異なった地質や土質が含まれる場合は，それぞれの地質，土質に対応した安定勾配の平均値を採用し，単一法面とする。

3. 切土法面の丁張りは，その設置位置が直線部の場合，標準設置間隔を10 m とする。

4. 切土法面では，土質，岩質及び法面の規模に応じて，一般に，高さ5〜10 m ごとに小段を設ける。

<details>
<summary>解答・解説</summary>

**正解: (2)**

1. 剥離しやすい法面や小段肩の侵食対策として、小段を逆勾配にして排水溝を設ける。記述は適当。 ✅

2. 異なる地質・土質が含まれる場合は、平均値の単一勾配とせず、それぞれの土質・岩質に応じた勾配で法面を設ける。記述は適当でない。 ❌

3. 切土法面の丁張りは、直線部では10 m 間隔を標準とする。記述は適当。 ✅

4. 切土法面には高さ5〜10 m ごとに小段を設けるのが一般的。記述は適当。 ✅

<ExamPoint>異なる地質は平均勾配の単一法面にせず土質ごとに勾配を変える</ExamPoint>

</details>

## 問題 No.3

道路盛土の路体の締固めに関する下記の文章の□に当てはまる適切な語句の組合せとして，次のうち**適当なもの**はどれか。

盛土の締固めは，一般に盛土材料が砂質土や礫質土の場合，目標とする締固め度を（イ）によって規定するのが普通であり，路体では締め固めた後の（ロ）が，JIS A 1210 に定められた室内の突固め試験によって得られる（ハ）の 90 % 以上となるよう規定する。

（イ） ── （ロ） ── （ハ）

1. CBR ── 含水比 ── 最適含水比

2. CBR ── 含水比 ── 最大乾燥密度

3. 密度 ── 現場乾燥密度 ── 最大乾燥密度

4. 密度 ── 現場湿潤密度 ── 最適含水比

<details>
<summary>解答・解説</summary>

**正解: (3)**

（イ）密度。砂質土・礫質土の締固め度は、CBRや含水比ではなく密度で規定する。

（ロ）現場乾燥密度。締固め後の現場の値は、湿潤密度ではなく乾燥密度で比較する。

（ハ）最大乾燥密度。JIS A 1210 の室内突固め試験で得られる最大乾燥密度の90 % 以上となるよう規定する（最適含水比は密度ではない）。

1. CBR ── 含水比 ── 最適含水比 — （イ）（ロ）（ハ）のすべてが誤りのため誤り ❌

2. CBR ── 含水比 ── 最大乾燥密度 — （イ）（ロ）が誤りのため誤り ❌

3. 密度 ── 現場乾燥密度 ── 最大乾燥密度 — （イ）（ロ）（ハ）のすべてが正しく、組合せとして正しい ✅

4. 密度 ── 現場湿潤密度 ── 最適含水比 — （ロ）（ハ）が誤りのため誤り ❌

<ExamPoint>締固め度は現場乾燥密度÷最大乾燥密度で表す</ExamPoint>

</details>

## 問題 No.4

軟弱地盤対策工の「工法」とその「工法の概要」との組合せとして，次のうち**適当なもの**はどれか。

［工法］ ── ［工法の概要］

1. サンドドレーン工法 ── 地盤中に適当な間隔で鉛直方向に砂柱を設置し，水平方向の圧密排水距離を短縮し，圧密沈下を促進させ，併せて強度を増加させる。

2. 押え盛土工法 ── 盛土側方の地盤に矢板を打設し，地盤の側方変位を減少させる。

3. 載荷重工法 ── 軟弱地盤に荷重を加えて圧密沈下させ，地盤のせん断強さを減少させる。

4. サンドコンパクションパイル工法 ── 地盤に締め固めた砂ぐいを造り，軟弱層を締め固めるとともに砂ぐいの支持力によって安定を増し，沈下量を増加させる。

<details>
<summary>解答・解説</summary>

**正解: (1)**

1. サンドドレーンは砂柱を設けて水平方向の排水距離を短縮し、圧密沈下を促進して強度を増加させる。記述は適当。 ✅

2. 押え盛土工法は盛土側方に盛土をして安定を図る工法で、矢板を打つ工法ではない。記述は誤り。 ❌

3. 載荷重工法は荷重で圧密を進め、地盤のせん断強さを増加させる。減少させるとするのは誤り。 ❌

4. サンドコンパクションパイルは砂ぐいで締固めと支持力増加を図り、沈下量を減少させる。増加させるとするのは誤り。 ❌

<ExamPoint>載荷重は強度増加、SCPは沈下量を減少させる</ExamPoint>

</details>

## 問題 No.5

コンクリートの混和材料等を用いた場合のコンクリートの特性に関する次の記述のうち，**適当でないもの**はどれか。

1. 減水剤を用いたコンクリートは，ワーカビリティーが改善される。

2. AE 剤を用いて空気量を増加させたコンクリートは，圧縮強度が低下する。

3. AE 剤を用いたコンクリートは，凍結融解に対する抵抗性は低下する。

4. フライアッシュの混入量を増やしたコンクリートは，凝結が遅れて初期強度が小さくなる。

<details>
<summary>解答・解説</summary>

**正解: (3)**

1. 減水剤は単位水量を減らし、ワーカビリティーを改善する。記述は適当。 ✅

2. AE剤で空気量が増えると、空気量1 % 増につき圧縮強度は数 % 低下する。記述は適当。 ✅

3. AE剤の微小な空気泡は凍結融解に対する抵抗性を高める。低下するとするのは適当でない。 ❌

4. フライアッシュは混入量を増やすと初期強度の発現が遅れ、凝結も遅れる。記述は適当。 ✅

<ExamPoint>AE剤は凍結融解抵抗性を向上させるが強度は下がる</ExamPoint>

</details>

## 問題 No.6

コンクリートの配合に関する次の記述のうち，**適当でないもの**はどれか。

1. 鉄筋コンクリートの粗骨材の最大寸法は，鉄筋の最小あきの $\frac{3}{4}$ 以下とする。

2. コンクリートのスランプは，運搬，打込み，締固め作業に適する範囲内で，できるだけ小さくする。

3. 水密性を要求されるコンクリートでは，水セメント比の最大値は 55 % とする。

4. 水セメント比は，コンクリートに求められる力学的性能，耐久性，水密性から定まる水セメント比のうちで最大の値を設定する。

<details>
<summary>解答・解説</summary>

**正解: (4)**

1. 粗骨材の最大寸法は鉄筋の最小あきの3/4以下とする。記述は適当。 ✅

2. スランプは作業に適する範囲内でできるだけ小さくする。記述は適当。 ✅

3. 水密性を要求されるコンクリートの水セメント比は55 % 以下を標準とする。記述は適当。 ✅

4. 水セメント比は、強度・耐久性・水密性の各要求から定まる値のうち最小の値を採用する。最大の値とするのは適当でない。 ❌

<ExamPoint>水セメント比は各要求から定まる値のうち最小値を採用</ExamPoint>

</details>

## 問題 No.7

コンクリートの水平打継目の施工に関する次の記述のうち，**適当でないもの**はどれか。

1. コンクリートを打ち継ぐ場合，打継面に敷くモルタルの水セメント比は，使用コンクリートの水セメント比より大きくする。

2. 水平打継目が型枠に接する線は，できるだけ水平な直線になるようにする。

3. コンクリートを打ち継ぐ場合は，既に打ち込まれたコンクリートの表面のレイタンス，緩んだ骨材粒などを完全に除き，十分に吸水させる。

4. 打継目は，できるだけせん断力の小さい位置に設ける。

<details>
<summary>解答・解説</summary>

**正解: (1)**

1. 打継面に敷くモルタルの水セメント比は、使用コンクリートの水セメント比より大きくしない。大きくするとするのは適当でない。 ❌

2. 水平打継目の型枠に接する線は、できるだけ水平な直線とする。記述は適当。 ✅

3. レイタンスや緩んだ骨材粒は完全に除き、十分に吸水させてから打ち継ぐ。記述は適当。 ✅

4. 打継目はせん断力の小さい位置に設け、新旧コンクリートを密着させる。記述は適当。 ✅

<ExamPoint>打継ぎモルタルの水セメント比は大きくせず同等以下にする</ExamPoint>

</details>

3. 骨材の種類

4. 粗骨材の最大寸法

<details>
<summary>解答・解説</summary>

## 問題 No.13

橋梁の架設工法の「工法」とその「架設方法」との組合せとして，次のうち**適当でないもの**はどれか。

［工法］ ── ［架設方法］

1. ベント式工法 ── 橋桁をベントで仮受けしながら部材を組み立て架設する。

2. ケーブルクレーン工法 ── 鉄塔で支えられたケーブルクレーンで橋桁部材を吊り込んで架設する。

3. 片持ち式工法 ── 橋台又は橋脚から，主桁などを片持ち式に張り出して部材を組み立て架設する。

4. 送出し工法 ── 組み立てられた部材を台船で現場までえい航しフローティングクレーンで吊り込み架設する。

<details>
<summary>解答・解説</summary>

**正解: (4)**

品質管理に用いるヒストグラムに関する次の記述のうち，**適当でないもの**はどれか。

1. ヒストグラムは，品質の特性がどんな分布をしているのか，また，その分布が規格値を満足しているかがわかる。

2. ヒストグラムは，安定した工程から得られたデータの場合，左右対称形の整った形となる。

3. ヒストグラムは，規格値や標準値を入れると全体に対しどの程度の不良品，不合格品が出ているかがわかる。

4. ヒストグラムは，個々のデータの状態や時間的順序の変化による品質の情報が得られる。

<details>
<summary>解答・解説</summary>

**正解: (4)**

1. ヒストグラムは分布の形と、規格値を満足しているかがわかる。記述は適当。 ✅

2. 安定した工程では、左右対称の整った分布形になる。記述は適当。 ✅

3. 規格値や標準値を入れると、不良品・不合格品の発生程度がわかる。記述は適当。 ✅

4. ヒストグラムは度数分布なので時間的順序が失われ、時間的変化は管理図でみる。記述は誤り。 ❌

<ExamPoint>ヒストグラムでは時間的変化がわからない</ExamPoint>

</details>

## 問題 No.59

道路舗装におけるアスファルト混合物の現場受入れ時に，品質を確認する項目として，**該当しないもの**は次のうちどれか。

1. 目視による色及びつや

2. 目視による粒度のバラツキ

3. 針入度の測定

4. 温度の測定

<details>
<summary>解答・解説</summary>

**正解: (3)**

1. 現場受入れでは目視による色・つやの確認を行う。 ✅

2. 目視による粒度のバラツキの確認を行う。 ✅

3. 針入度はアスファルト材料の品質試験で、混合物の現場受入れ時の確認項目ではない。 ❌

4. 現場受入れでは混合物の温度の測定を行う。 ✅

</details>

## 問題 No.60

市街地で地下連続壁工法により地下構造物を築造する場合，現場周辺で行う一般的な環境対策調査項目として，**該当しないもの**は次のうちどれか。

1. 地下水水質調査

2. 日照調査

3. 井戸枯れ調査

4. 騒音・振動調査

<details>
<summary>解答・解説</summary>

**正解: (2)**

1. 地下水水質調査は、地下連続壁工法の周辺環境調査として行う。 ✅

2. 日照調査は高層建築物による日影の影響を調べるもので、地下連続壁の環境対策調査項目ではない。 ❌

3. 井戸枯れ調査は、地下水位低下の影響を調べる項目として行う。 ✅

4. 騒音・振動調査は、施工による影響を調べる一般的な項目。 ✅

<ExamPoint>日照調査は地下工事ではなく高層建築物の調査項目</ExamPoint>

</details>

## 問題 No.61

工事現場で発生する建設発生土等の利用に関する次の記述のうち，**適当でないもの**はどれか。

1. アスファルト・コンクリート塊は，再生処理し再生粒度調整砕石として，駐車場の舗装の上層路盤材料に利用できる。

2. 含水率の高い粘性土は，安定処理すれば道路の路体盛土材料として利用できる。

3. コンクリート塊は，再生処理し再生クラッシャーランとして，土木構造物の基礎材に利用できる。

4. 建設汚泥（コーン指数 200 kN/m² 以下）は，そのまま一般堤防の盛土材として利用できる。

<details>
<summary>解答・解説</summary>

**正解: (4)**

1. アスファルト・コンクリート塊は再生粒度調整砕石として、舗装の上層路盤材に利用できる。 ✅

2. 含水率の高い粘性土も、安定処理すれば道路の路体盛土材として利用できる。 ✅

3. コンクリート塊は再生クラッシャーランとして、構造物の基礎材に利用できる。 ✅

4. コーン指数200 kN/m²以下の建設汚泥はそのままでは盛土に使えず、改良等が必要。 ❌
