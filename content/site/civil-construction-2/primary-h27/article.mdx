## 問題 No.1

土質調査に関する次の試験方法のうち，室内試験はどれか。

1. 土の液性限界・塑性限界試験

2. スウェーデン式サウンディング試験

3. オランダ式二重管コーン貫入試験

4. 標準貫入試験

<details>
<summary>解答・解説</summary>

**正解: (1)**

1. 液性限界・塑性限界試験は採取した試料を室内で調べる室内試験で、コンシステンシー限界を求める。 ✅

2. スウェーデン式サウンディングは地盤に貫入して抵抗を測る原位置試験で、室内試験ではない。 ❌

3. オランダ式二重管コーン貫入試験は現地でコーンを貫入させる原位置試験で、室内試験ではない。 ❌

4. 標準貫入試験はボーリング孔内で行いN値を求める原位置試験で、室内試験ではない。 ❌

## 問題 No.2

土工において掘削及び積込みの作業に用いられる建設機械は，次のうちどれか。

1. ブルドーザ

2. 振動ローラ

3. モーターグレーダ

4. バックホゥ

<details>
<summary>解答・解説</summary>

**正解: (4)**

1. ブルドーザは掘削押土・整地・短距離運搬が主で、積込みの主機械ではない。 ❌

2. 振動ローラは盛土などの締固め用の機械で、掘削・積込みには使わない。 ❌

3. モーターグレーダは路面・路盤の整形、敷均し用の機械で、掘削積込みには用いない。 ❌

4. バックホゥは地盤面より低い箇所の掘削と、ダンプトラックへの積込みに用いられる。 ✅

<ExamPoint>建設機械の用途（掘削積込み・締固め・整地）の対応</ExamPoint>

</details>

## 問題 No.3

盛土に適した盛土材料の性質として次の記述のうち，**適当でないもの**はどれか。

1. 粒度配合のよい礫質土や砂質土である。

2. 締固め後の吸水による膨張が大きい。

3. 敷均しや締固めが容易である。

4. 締固め後のせん断強度が高く，圧縮性が小さい。

<details>
<summary>解答・解説</summary>

**正解: (2)**

1. 粒度配合のよい礫質土・砂質土は締固めが良好で、盛土材料に適する。 ✅

2. 締固め後に吸水で膨張が大きいと盛土が変形するため不適当で、膨張性が小さいことが必要。 ❌

3. 敷均しや締固めが容易であることは、盛土材料に求められる性質である。 ✅

4. 締固め後のせん断強度が高く圧縮性が小さいことは、盛土材料の望ましい性質である。 ✅

<ExamPoint>盛土材料に求められる性質は吸水膨張が小さいこと</ExamPoint>

</details>

## 問題 No.4

軟弱地盤における次の改良工法のうち，載荷工法に**該当するもの**はどれか。

1. 深層混合処理工法

2. ウェルポイント工法

3. プレローディング工法

4. バイブロフローテーション工法

<details>
<summary>解答・解説</summary>

**正解: (3)**

1. 深層混合処理工法は、セメント等と原地盤を混合する固結工法で、載荷工法ではない。 ❌

2. ウェルポイント工法は地下水位を低下させる排水（脱水）工法で、載荷工法ではない。 ❌

3. プレローディング工法は盛土等の荷重をあらかじめ載せて圧密沈下を促進させる載荷工法である。 ✅

4. バイブロフローテーション工法は砂地盤を振動と水で締め固める締固め工法で、載荷工法ではない。 ❌

<ExamPoint>軟弱地盤対策の分類（載荷・固結・脱水・締固め）</ExamPoint>

## 問題 No.5

コンクリート用セメントに関する次の記述のうち，**適当でないもの**はどれか。

1. セメントの水和作用の現象である凝結は，一般に使用時の温度が高いほど遅くなる。

2. セメントの密度は，化学成分によって変化し，風化すると，その値は小さくなる。

3. 粉末度とは，セメント粒子の細かさを示すもので，粉末度の高いものほど水和作用が早くなる。

4. 初期強度は，普通ポルトランドセメントの方が高炉セメント B 種より大きい。

<details>
<summary>解答・解説</summary>

**正解: (1)**

1. 凝結は水和反応の現象で、温度が高いほど水和が速まり早くなる。「遅くなる」は誤り。 ❌

2. セメントの密度は成分で変わり、風化すると小さくなる。記述のとおり。 ✅

3. 粉末度が高い（細かい）ほど水和が早く進む。記述のとおり。 ✅

4. 普通ポルトランドセメントは高炉セメントB種より初期強度が大きい。記述のとおり。 ✅

<ExamPoint>温度が高いほどセメントの凝結は早まる</ExamPoint>

</details>

## 問題 No.6

フレッシュコンクリートに関する次の記述のうち，**適当なもの**はどれか。

1. ワーカビリティーは，変形あるいは流動に対する抵抗の程度を表す性質である。

2. ブリーディングは，練混ぜ水の一部の表面水が内部に浸透する現象である。

3. スランプは，軟らかさの程度を示す指標である。

4. コンシステンシーは，打込み・締固め・仕上げなどの作業の容易さを表す性質である。

<details>
<summary>解答・解説</summary>

**正解: (3)**

1. 変形・流動に対する抵抗の程度を表すのはコンシステンシーで、ワーカビリティーは作業の容易さの性質。 ❌

2. ブリーディングは、練混ぜ水の一部が表面へ浮き上がる現象で、内部に浸透する現象ではない。 ❌

3. スランプはスランプコーンを引き上げたときの下がり量で、軟らかさの程度を示す指標である。 ✅

4. 打込み・締固め・仕上げの作業の容易さを表すのはワーカビリティーで、コンシステンシーではない。 ❌

<ExamPoint>ワーカビリティーとコンシステンシーの定義の入れ替え</ExamPoint>

</details>

## 問題 No.7

コンクリートの運搬・打込みに関する次の記述のうち，**適当でないもの**はどれか。

1. コンクリート打込み中に硬化が進行した場合は，均質なコンクリートにあらためて練り直してから使用する。

2. 高所からのコンクリートの打込みは，原則として縦シュートとするが，やむを得ず斜めシュートを使う場合には材料分離を起こさないよう使用する。

3. コンクリートを直接地面に打ち込む場合には，あらかじめ均しコンクリートを敷いておく。

4. 現場内においてコンクリートをバケットを用いてクレーンで運搬する方法は，コンクリートに振動を与えることが少ない。

<details>
<summary>解答・解説</summary>

**正解: (1)**

1. 打込み中に硬化が進行したコンクリートは、練り直して使用してはならない。これが誤り。 ❌

2. 高所からの打込みは縦シュートが原則で、斜めシュートは材料分離に注意して使う。記述のとおり。 ✅

3. 直接地面に打ち込む場合は、あらかじめ均しコンクリートを敷く。記述のとおり。 ✅

4. バケットでのクレーン運搬は、振動が少なく材料分離を起こしにくい。記述のとおり。 ✅

<ExamPoint>硬化が始まったコンクリートは練り直して使わない</ExamPoint>

</details>

## 問題 No.8

各種コンクリートに関する次の記述のうち，**適当でないもの**はどれか。

1. 暑中コンクリートは，材料を冷やすこと，日光の直射から防ぐこと，十分湿気を与えることなどに注意する。

2. 部材断面が大きいマスコンクリートでは，セメントの水和熱による温度変化に伴い温度応力が大きくなるため，コンクリートのひび割れに注意する。

3. 膨張コンクリートは，膨張材を使用し，おもに乾燥収縮にともなうひび割れを防ごうとするものである。

4. 寒中コンクリートは，ポルトランドセメントと AE 剤を使用するのが標準で，単位水量はできるだけ多くする。

<details>
<summary>解答・解説</summary>

**正解: (4)**

1. 暑中コンクリートは、材料を冷やし直射日光を防ぎ、十分湿気を与える。記述のとおり。 ✅

2. マスコンクリートは水和熱による温度応力でひび割れが生じやすく、注意が必要。記述のとおり。 ✅

3. 膨張コンクリートは膨張材で乾燥収縮によるひび割れを防ごうとするもの。記述のとおり。 ✅

4. 寒中コンクリートは、凍害防止のため単位水量をできるだけ少なくする。「多く」は誤り。 ❌

<ExamPoint>寒中コンクリートは単位水量をできるだけ少なくする</ExamPoint>

</details>

## 問題 No.9

既製杭の施工に関する次の記述のうち，**適当でないもの**はどれか。

1. 打込み杭工法で一群の杭を打つときは，周辺部の杭から中心部の杭へと，順に打ち込むものとする。

2. 打込み杭工法で1本の杭を打ち込むときは，連続して行うことを原則とする。

3. 中掘り杭工法は，過大な先掘りを行ってはならない。

4. 中掘り杭工法は，打込み杭工法に比べ支持力が小さい。

<details>
<summary>解答・解説</summary>

**正解: (1)**

1. 一群の杭は、中心部から周辺部へ打つのが原則。周辺から打つと中心部の地盤が締まり打込みにくくなる。 ❌

2. 1本の杭は、途中で中断せず連続して打ち込むのを原則とする。記述のとおり。 ✅

3. 中掘り杭工法は、過大な先掘りをすると支持力が低下するため行ってはならない。記述のとおり。 ✅

4. 中掘り杭工法は、打込み杭工法に比べ一般に支持力が小さい。記述のとおり。 ✅

<ExamPoint>杭群は中心から周辺へ打ち込む順序</ExamPoint>

</details>

## 問題 No.10

場所打ち杭の工法と掘削方法との次の組合せのうち，**適当でないもの**はどれか。

［工法］ ── ［掘削方法］

1. リバースサーキュレーション工法 ── 掘削する杭穴に水を満たし，掘削土とともにドリルパイプを通して孔外の水槽に吸い上げ，水を再び杭穴に循環させて連続的に掘削する。

2. オールケーシング工法 ── ケーシングチューブを土中に挿入し，ケーシングチューブ内の土をハンマーグラブを用いて掘削する。

3. アースドリル工法 ── アースドリルで掘削を行い，地表面からある程度の深さに達したらケーシングを挿入し，地山の崩壊を防ぎながら掘削する。

4. 深礎工法 ── ケーソンを所定の位置に鉛直に据え付け，内部の土砂をグラブバケットで掘削する。

<details>
<summary>解答・解説</summary>

**正解: (4)**

1. リバースサーキュレーション工法は、水を循環させ掘削土を吸い上げる工法で、記述のとおり。 ✅

2. オールケーシング工法は、ケーシングチューブを挿入しハンマーグラブで掘削する。記述のとおり。 ✅

3. アースドリル工法は、掘削が進んだらケーシングを挿入し孔壁を保護する。記述のとおり。 ✅

4. 深礎工法は人力等で掘り進め土留め（ライナープレート等）を行う工法で、ケーソン据付けの説明は別工法のもの。 ❌

<ExamPoint>深礎工法は孔壁を土留めしながら掘る工法</ExamPoint>

</details>

## 問題 No.14

コンクリート構造物の耐久性を向上させる対策に関する次の記述のうち，**適当でないもの**はどれか。

1. 凍結融解に対する抵抗性を向上させるために，AE 剤を用いる。

2. 塩害対策として，鉄筋のかぶりを大きくとる。

3. アルカリシリカ反応対策として，高炉セメント B 種を使用する。

4. 耐久性を高めるために，吸水率の大きい骨材を使用する。

<details>
<summary>解答・解説</summary>

**正解: (4)**

2. 塩害対策では鉄筋のかぶりを大きくとる。記述のとおり。 ✅

3. 高炉セメントB種はアルカリシリカ反応の抑制に有効。記述のとおり。 ✅

4. 吸水率の大きい骨材は凍害等を受けやすく耐久性を下げる。耐久性向上には吸水率の小さい骨材を使う。 ❌

<ExamPoint>耐久性向上には吸水率の小さい骨材を用いる</ExamPoint>

## 問題 No.15

河川堤防に用いる土質材料に関する次の記述のうち，**適当でないもの**はどれか。

1. 堤体の安定に支障を及ぼすような圧縮変形や膨張性がないものであること。

2. できるだけ透水性があること。

3. 有害な有機物及び水に溶解する成分を含まないこと。

4. 施工性がよく，特に締固めが容易であること。

<details>

3. 圧縮強度試験は，一般に材齢28日で行うが，購入者の指定した材齢で行うこともある。

4. 圧縮強度は，1回の試験結果は購入者の指定した呼び強度の強度値の75 % 以上である。

<details>
<summary>解答・解説</summary>

**正解: (4)**

1. 品質管理の項目は、強度、スランプ又はスランプフロー、空気量、塩化物含有量の4項目。 ✅

2. 3回の圧縮強度試験の平均値が、呼び強度の強度値以上であることが合格条件の一つ。 ✅

3. 圧縮強度試験は一般に材齢28日で行うが、購入者が指定した材齢で行うこともある。 ✅

4. 不適当。1回の試験結果は、呼び強度の強度値の85 % 以上でなければならない。75 % ではない。 ❌

<ExamPoint>圧縮強度は1回の試験結果が呼び強度の85 % 以上</ExamPoint>

</details>

## 問題 No.60

建設工事における騒音振動対策に関する次の記述のうち，**適当でないもの**はどれか。

1. 建設機械は，一般に形式により騒音振動が異なり，空気式のものは油圧式のものに比べて騒音が小さい傾向がある。

2. 建設機械は，整備不良による騒音振動が発生しないように点検，整備を十分に行う。

3. 建設機械は，一般に老朽化するにつれ，機械各部にゆるみや磨耗が生じ，騒音振動の発生量も大きくなる。

4. 建設機械による掘削，積込み作業は，できる限り衝撃力による施工を避け，不必要な高速運転やむだな空ぶかしを避ける。

<details>
<summary>解答・解説</summary>

**正解: (1)**

1. 不適当。空気式の建設機械は一般に油圧式より騒音が大きい傾向があり、油圧式の方が小さい。記述は逆。 ❌

2. 建設機械は整備不良による騒音振動が出ないよう、点検・整備を十分に行う。 ✅

3. 老朽化すると各部にゆるみや磨耗が生じ、騒音振動の発生量も大きくなる。 ✅

4. 掘削・積込みでは衝撃力による施工を避け、不必要な高速運転や空ぶかしを避ける。 ✅

<ExamPoint>空気式は油圧式より騒音が大きい傾向にある</ExamPoint>

</details>

## 問題 No.61

建設工事に係る資材の再資源化等に関する法律（建設リサイクル法）における特定建設資材に**該当しないもの**は，次のうちどれか。

1. 木材

2. 土砂

3. コンクリート

4. アスファルトコンクリート

<details>
<summary>解答・解説</summary>

**正解: (2)**

1. 木材は、特定建設資材に該当する。 ✅

2. 土砂は特定建設資材に該当しない。特定建設資材はコンクリート、コンクリートと鉄から成る資材、木材、アスファルト・コンクリートの4種類。 ❌

3. コンクリートは、特定建設資材に該当する。 ✅

4. アスファルト・コンクリートは、特定建設資材に該当する。 ✅

<ExamPoint>特定建設資材に土砂は含まれない</ExamPoint>

</details>
