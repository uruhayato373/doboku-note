2級土木 第2次検定の施工経験記述について、工種別・テーマ別の記入例を集めた資料である。答案づくりの素材として、自分の現場に近い例を選んで使ってほしい。

## 記入例の使い方

施工経験記述は、安全・品質・工程の各管理について「(1) 技術的課題 → (2) 検討した項目と検討理由及び検討内容 → (3) 対応処置とその評価」の流れで書く。ここでは工種別・テーマ別に、この3段構成で**何を書くか**（押さえる観点）を整理する。数値の `〇〇` は、受検者が自分の現場の固有名称・数値を記入するための空欄である。

<Callout type="warn" title="そのまま書き写さない">
記述は模範解答の丸写しではなく、構成と観点を理解したうえで**自分が経験した工事に置き換えてオリジナルで書く**ことが前提である。同じ文章を多数の受検者が書くと不合格の原因となる。経験していない工事を記述し、それが判明した場合は失格となる。
</Callout>

令和6年度以降は設問が2項目構成（現場状況と技術的課題／検討した項目とその対応処置）となる年度があるが、下記の3段構成を理解しておけば、(2) と (3) を「検討項目とその対応処置」としてまとめることで対応できる。

<Callout type="tip" title="フル完成答案は note 有料マガジンで">
本ページは各テーマの「書く観点」を示すものである。(1)(2)(3) をすべて埋めた **複数工種のフル完成答案**、年度別の過去問模範答案、添削例・採点者視点は、note 有料マガジンにまとめている。自分の現場に最も近い工種をそのまま雛形として使える。
</Callout>

## 品質管理の記述の観点

品質管理では、設計図書に定められた工事目的物の品質（規格値）をどう確保したかを記述する。施工時期（気温）や地盤条件に関連づけると、現場特有の課題を書きやすい。工種別に押さえる観点は次のとおり。

- **土工事**（盛土）：高含水比・降雨期での締固め度の確保 → 施工面の排水勾配、ばっ気乾燥や良質土への置換、巻出し厚の管理、RI計器（または砂置換法）での締固め度確認。
- **コンクリート工事**（暑中）：コールドジョイント・乾燥ひび割れの防止 → 遅延型減水剤の使用、打重ね時間間隔の管理、練混ぜ水の冷却、養生剤塗布・湿潤養生。
- **コンクリート工事**（寒中）：初期凍害の防止 → 材料の加温と練上がり温度の確保、運搬時の保温、給熱・保温養生による温度確保。
- **舗装工事**：アスファルト混合物の温度低下対策 → 荷台のシート保温、敷均し温度の測定、初転圧・二次転圧・仕上げ転圧の手順管理。

## 工程管理の記述の観点

工程管理では、現場特有の事情で工事が遅れた（遅れるおそれがあった）場合に、遅延を挽回（予防）するために行った管理を記述する。工種別に押さえる観点は次のとおり。

- **土工事**（造成）：降雨による遅延の挽回 → 仮排水溝の設置でトラフィカビリティを確保、施工班の増班、ネットワーク工程表での進捗フォローアップ。
- **コンクリート工事**（橋脚下部工）：繰返し作業の取り合い調整 → クリティカルパスの重点管理、1日施工量の平準化、手待ちを生じさせない作業手順。
- **舗装工事**（交通規制）：規制時間内の施工量確保 → 過去実績からの人員・機械配置、資機材の仮置きスペース確保、タイムスケジュール化と周知徹底。

## 安全管理の記述の観点

安全管理では、現場で発生しうる労働災害・第三者災害を、どのような対策で防止したかを系統立てて記述する。工種別に押さえる観点は次のとおり。

- **土工事**（重機）：重機と作業員の接触防止 → 作業区域の区分（バリケード・カラーコーン）、誘導員の配置と合図の統一、KY活動と巡視。
- **足場上のコンクリート工事**：墜落・転落の防止 → 手すり・中さん・幅木とメッシュシート、昇降設備の整備、開口部でのフルハーネス使用。
- **工事全般**（夏季）：熱中症の防止 → 日陰の休憩場所と水分・塩分補給、WBGT値の測定と作業時間の調整、安全衛生教育。

<Callout type="warn">
安全管理を選ぶ場合、出題によっては「交通誘導員の配置のみ」の記述は除外される。誘導員配置を扱うときは、バリケード・標識・KY活動・上下作業禁止などの対策と組み合わせて書く。
</Callout>

## 環境対策の記述の観点

環境対策が出題された場合は、現場で発生する騒音・振動、水質汚濁、粉じん、産業廃棄物への対応を、立地に応じて記述する。

- **騒音・振動**：低騒音・低振動型の建設機械を使用し、機械の点検整備を行った。防音シート・仮囲いを設置し、空ぶかし・急発進をしないよう指導した。
- **粉じん**：散水車により定期的に散水し、現場出入口と運搬路に防じんネットを設置した。法面には種子吹付けにより飛散を防止した。
- **水質汚濁**：濁水は沈砂池で土砂を沈降させ、必要に応じて中和・凝集処理を行い、公共用水域への排水基準を満たすよう管理した。
- **産業廃棄物**：現場で分別を徹底し、マニフェストにより適正に処理されたことを確認した。再生資源の活用と建設残土の工事間利用を促進した。

## 工事概要の改善例

設問1の工事概要は、各項目を具体的に書くことで採点者に現場が伝わる。次に改善前後の例を示す。

| 項目 | 改善前（不十分） | 改善後（具体的） |
|---|---|---|
| 工事名 | 道路工事 | 市道〇〇号線 道路改良舗装工事 |
| 発注者名 | 〇〇県 | 〇〇県〇〇土木事務所 |
| 工事場所 | 〇〇県〇〇市 | 〇〇県〇〇市〇〇町〇丁目地内 |
| 工期 | 6月〜9月 | 令和5年6月1日〜令和5年9月29日 |
| 主な工種 | 道路工 | 道路土工、排水構造物工、アスファルト舗装工 |
| 施工量 | 舗装工 | アスファルト舗装 `〇〇〇〇`m<sup>2</sup>、路盤工 `〇〇〇`m<sup>2</sup> |
| 立場 | 社員 | 現場代理人（または主任技術者） |

<Callout type="tip">
工事概要と記述本文の内容は必ず整合させる。例えば本文で「梅雨時期の品質管理」を書くなら、工期はその季節を含む日付にする。工種・施工量と本文で扱う作業が食い違わないようにする。
</Callout>

## 記述後のチェックポイント

書き上げたら、提出前に次の点を確認する。内容が良くても形式の不備は減点につながる。

- **字数**：解答欄の行数・字数に収め、空白行で埋めない。記述量が少なすぎると評価されにくい。
- **対応関係**：(1) 技術的課題と (3) 対応処置が噛み合い、(2) の検討内容が処置の根拠になっているかを確認する。
- **具体性**：「適切に管理した」で終わらせず、数値・材料名・工法名で「何をしたか」を示す。
- **専門用語**：締固め度・スランプ・WBGT 値など、工種に応じた用語を正しく使う。
- **整合**：工事概要の工種・施工量・工期と、本文で述べる作業や季節が矛盾しないようにする。
