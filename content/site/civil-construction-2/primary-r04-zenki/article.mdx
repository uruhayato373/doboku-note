## 問題 No.1

土の締固めに使用する機械に関する次の記述のうち、**適当でないもの**はどれか。

1. タイヤローラは、細粒分を適度に含んだ山砂利の締固めに適している。

2. 振動ローラは、路床の締固めに適している。

3. タンピングローラは、低含水比の関東ロームの締固めに適している。

4. ランマやタンパは、大規模な締固めに適している。

<details>
<summary>解答・解説</summary>

**正解: (4)**

1. タイヤローラは粒度分布の良い砂質土や山砂利の締固めに有効である ✅

2. 振動ローラは砂・砂利・路盤材など粘性の低い材料の締固めに適する ✅

3. タンピングローラは含水比の低い粘性土や関東ロームに適する ✅

4. **ランマやタンパは構造物隅角部や狭隘部の小規模締固め用で、大規模締固めには適さない ❌**

</details>

## 問題 No.2

土質試験における「試験名」とその「試験結果の利用」に関する次の組合せのうち、**適当でないもの**はどれか。

| 試験名 | 試験結果の利用 |
|---|---|
| (1) 標準貫入試験 | 地盤の透水性の判定 |
| (2) 砂置換法による土の密度試験 | 土の締固めの管理 |
| (3) ポータブルコーン貫入試験 | 建設機械の走行性の判定 |
| (4) ボーリング孔を利用した透水試験 | 地盤改良工法の設計 |

<details>
<summary>解答・解説</summary>

**正解: (1)**

1. **標準貫入試験のN値は地盤の硬軟・支持力判定に用い、透水性の判定には透水試験を行う ❌**

2. 砂置換法は現場の土の密度を測り、締固め管理の指標となる ✅

3. ポータブルコーン貫入試験のコーン指数qcは建設機械のトラフィカビリティ判定に用いる ✅

4. ボーリング孔利用の現場透水試験は透水係数を求め、地盤改良の設計に用いる ✅

</details>

## 問題 No.3

道路土工の盛土材料として望ましい条件に関する次の記述のうち、**適当でないもの**はどれか。

1. 盛土完成後の圧縮性が小さいこと。

2. 水の吸着による体積増加が小さいこと。

3. 盛土完成後のせん断強度が低いこと。

4. 敷均しや締固めが容易であること。

<details>
<summary>解答・解説</summary>

**正解: (3)**

1. 圧縮性の小さい材料は完成後の沈下が少なく望ましい ✅

2. 吸水による膨潤が小さい安定した材料が望ましい ✅

3. **盛土材料は完成後のせん断強度が「高い」ことが望ましく、せん断強度が「低い」材料はすべりに対し不安定で誤り ❌**

4. 敷均し・締固めが容易な土質は施工性が高く望ましい ✅

</details>

## 問題 No.4

地盤改良に用いられる固結工法に関する次の記述のうち、**適当でないもの**はどれか。

1. 深層混合処理工法は、大きな強度が短期間で得られ沈下防止に効果が大きい工法である。

2. 薬液注入工法は、薬液の注入により地盤の透水性を高め、強度を増す工法である。

3. 深層混合処理工法には、安定材と軟弱土を混合する機械攪拌方式がある。

4. 薬液注入工法では、周辺地盤等の地下水位の監視が必要である。

<details>
<summary>解答・解説</summary>

**正解: (2)**

1. 深層混合処理工法はセメント系固化材で地盤強度を高め沈下を抑制する ✅

2. **薬液注入工法の目的は地盤の透水性を「低下」させる止水と強度増加であり、透水性を高めるは誤り ❌**

3. 機械攪拌方式（DJM・DM等）は安定材と原位置土を混合する深層混合の代表的工法である ✅

4. 薬液注入は周辺の地下水汚染・水位変動を引き起こす可能性があり監視が必要である ✅

</details>

## 問題 No.5

コンクリートの耐凍害性の向上を図る混和剤として、**適当なもの**は、次のうちどれか。

1. 流動化剤

2. 収縮低減剤

3. AE剤

4. 鉄筋コンクリート用防錆剤

<details>
<summary>解答・解説</summary>

**正解: (3)**

1. 流動化剤は流動性向上が目的で、耐凍害性には直接寄与しない ❌

2. 収縮低減剤はひび割れ抑制を目的とし、耐凍害性とは別の作用である ❌

3. AE剤は微細な独立気泡を連行し、凍結融解による膨張圧を吸収するため耐凍害性が向上する ✅

4. 鉄筋防錆剤は鉄筋腐食を抑制する薬剤で、凍害対策ではない ❌

</details>

## 問題 No.6

レディーミクストコンクリートの配合に関する次の記述のうち、**適当でないもの**はどれか。

1. 単位水量は、所要のワーカビリティーが得られる範囲内で、できるだけ少なくする。

2. 水セメント比は、強度や耐久性等を満足する値の中から最も小さい値を選定する。

3. スランプは、施工ができる範囲内で、できるだけ小さくなるようにする。

4. 空気量は、凍結融解作用を受けるような場合には、できるだけ少なくするのがよい。

<details>
<summary>解答・解説</summary>

**正解: (4)**

1. 単位水量は乾燥収縮・耐久性確保のためできるだけ少なくする ✅

2. 水セメント比は耐久性・強度を満たす最小値とするのが原則である ✅

3. スランプは施工ができる範囲内でできるだけ小さくするのが原則である ✅

4. **凍結融解作用を受ける場合は耐凍害性確保のため、AE剤により空気量をむしろ多く（4〜7%程度）確保する。「できるだけ少なくする」は誤り ❌**

</details>

## 問題 No.7

フレッシュコンクリートの性質に関する次の記述のうち、**適当でないもの**はどれか。

1. 材料分離抵抗性は、フレッシュコンクリート中の材料が分離することに対する抵抗性である。

2. ブリーディングとは、練混ぜ水の一部が遊離してコンクリート表面に上昇する現象である。

3. ワーカビリティーとは、変形又は流動に対する抵抗性である。

4. レイタンスとは、コンクリート表面に水とともに浮き上がって沈殿する物質である。

<details>
<summary>解答・解説</summary>

**正解: (3)**

1. 材料分離抵抗性は骨材・セメントペーストの分離しにくさを表す ✅

2. ブリーディングは練混ぜ水が表面に上昇する現象で正しい ✅

3. **ワーカビリティーは「作業のしやすさ」を表す総合的な性質であり、変形・流動に対する抵抗性はコンシステンシーの定義で、誤り ❌**

4. レイタンスはブリーディングに伴い浮上する微細粒で、打継ぎ前に除去する ✅

</details>

## 問題 No.8

コンクリートの現場内での運搬と打込みに関する次の記述のうち、**適当でないもの**はどれか。

1. コンクリートの現場内での運搬に使用するバケットは、材料分離を起こしにくい。

2. コンクリートポンプで圧送する前に送るモルタルの水セメント比は、使用するコンクリートの水セメント比よりも大きくする。

3. 型枠内における打込みでは、コンクリートを打ち込む前に型枠内を清掃する。

4. 2層以上に分けて打ち込む場合は、上層と下層が一体となるように下層コンクリート中に棒状バイブレータを挿入する。

<details>
<summary>解答・解説</summary>

**正解: (2)**

1. バケットは材料分離が起こりにくく、運搬性に優れる ✅

2. **ポンプ圧送前の先送りモルタルの水セメント比は、後続するコンクリートよりも「小さく」する（強度低下防止のため）。問題文は逆で誤り ❌**

3. 打込み前に型枠内のごみ・水・木くず等を除去清掃するのは基本である ✅

4. 上下層を一体化するため棒状バイブレータを下層に10cm程度挿入するのが標準である ✅

</details>

## 問題 No.9

既製杭の中掘り杭工法に関する次の記述のうち、**適当でないもの**はどれか。

1. 地盤の掘削は、一般に既製杭の内部をアースオーガで掘削する。

2. 先端処理方法は、セメントミルク噴出攪拌方式とハンマで打ち込む最終打撃方式等がある。

3. 杭の支持力は、一般に打込み工法に比べて、大きな支持力が得られる。

4. 掘削中は、先端地盤の緩みを最小限に抑えるため、過大な先掘りを行わない。

<details>
<summary>解答・解説</summary>

**正解: (3)**

1. 中掘り工法はアースオーガを杭内部に挿入し掘削する ✅

2. 先端処理はセメントミルク噴出攪拌方式・最終打撃方式・コンクリート打設方式等がある ✅

3. **中掘り工法は打込み工法に比べて支持力は「小さい」ことが多い。地盤緩みのため支持力評価は注意が必要 ❌**

4. 過大な先掘りは先端地盤の緩みを招くため最小限に抑える ✅

</details>

## 問題 No.10

場所打ち杭の「工法名」と「孔壁保護の主な資機材」に関する次の組合せのうち、**適当なもの**はどれか。

| 工法名 | 孔壁保護の主な資機材 |
|---|---|
| (1) 深礎工法 | 安定液（ベントナイト） |
| (2) オールケーシング工法 | ケーシングチューブ |
| (3) リバースサーキュレーション工法 | 山留め材（ライナープレート） |
| (4) アースドリル工法 | スタンドパイプ |

<details>
<summary>解答・解説</summary>

**正解: (2)**

1. **深礎工法は山留め材（ライナープレート等）で孔壁保護する。安定液は他工法用で誤り ❌**

2. オールケーシング工法は全長ケーシングチューブで孔壁保護する ✅

3. **リバース工法はスタンドパイプ＋静水圧（水）で孔壁保護する ❌**

4. **アースドリル工法は安定液（ベントナイト）で孔壁保護する ❌**

</details>

土留めに関する次の記述のうち、**適当でないもの**はどれか。

鋼材の溶接継手に関する次の記述のうち、**適当でないもの**はどれか。

</details>

鋼道路橋に用いる高力ボルトに関する次の記述のうち、**適当でないもの**はどれか。

1. 高力ボルトの軸力の導入は、ナットを回して行うことを原則とする。

2. 高力ボルトの締付けは、連結板の端部のボルトから順次中央のボルトに向かって行う。

3. 高力ボルトの長さは、締付け長さに所要の長さを加えたものとしなければならない。

4. 高力ボルトの摩擦接合は、ボルトの締付けで生じる部材相互の摩擦力で応力を伝達する。

**正解: (2)**

</details>

河川堤防に用いる土質材料に関する次の記述のうち、**適当でないもの**はどれか。

</details>

## 問題 No.16

河川護岸に関する次の記述のうち、**適当なもの**はどれか。

1. 高水護岸は、高水時に表法面、天端、裏法面の堤防全体を保護するものである。

2. 法覆工は、堤防の法面をコンクリートブロック等で被覆し保護するものである。

3. 基礎工は、根固工を支える基礎であり、洗掘に対して保護するものである。

4. 小口止工は、河川の流水方向の一定区間ごとに設けられ、護岸を保護するものである。

<details>
<summary>解答・解説</summary>

**正解: (2)**

2. 法覆工は堤防・河岸の法面を被覆して保護する護岸の主体構造で正しい ✅

3. **基礎工は法覆工を支える基礎で、根固工とは別物 ❌**

4. **小口止工は護岸の縦断方向の端部に設け、護岸の損傷拡大を防ぐもの。「流水方向の一定区間ごと」は横帯工等で誤り ❌**

</details>

## 問題 No.17

砂防えん堤に関する次の記述のうち、**適当でないもの**はどれか。

1. 水抜きは、一般に本えん堤施工中の流水の切替えや堆砂後の浸透水を抜いて水圧を軽減するために設けられる。

2. 袖は、洪水を越流させないために設けられ、両岸に向かって上り勾配で設けられる。

3. 水通しの断面は、一般に逆台形で、越流する流量に対して十分な大きさとする。

4. 水叩きは、本えん堤からの落下水による洗掘の防止を目的に、本えん堤上流に設けられるコンクリート構造物である。

<details>
<summary>解答・解説</summary>

**正解: (4)**

1. 水抜きは施工中の流水処理と堆砂後の浸透水排水のため設ける ✅

2. 袖は越流防止のため両岸に向かって上り勾配で設ける ✅

3. 水通しは逆台形断面で計画流量に対し十分な余裕を持たせる ✅

4. **水叩きは本えん堤の「下流側」に設けて落下水による洗掘を防ぐもの。「上流」に設けるは誤り ❌**

</details>

## 問題 No.18

地すべり防止工に関する次の記述のうち、**適当なもの**はどれか。

1. 排土工は、地すべり頭部の不安定な土塊を排除し、土塊の滑動力を減少させる工法である。

2. 横ボーリング工は、地下水の排除を目的とし、抑止工に区分される工法である。

3. 集水井工は、地すべり規模が小さい場合に用いられる工法である。

4. 杭工は、杭の挿入による斜面の安定度の向上を目的とし、抑制工に区分される工法である。

<details>
