## 問題 No.1

下図の土の構成を表した模式図の記号を用いて，「間隙比 $e$」を求める次の式のうち，**正しいもの**はどれか。

<ArticleImage src="/posts/civil-construction-2/primary-r07-zenki/img/q01-fig.webp" alt="土の構成を表した模式図（体積と質量）" width={1260} height={680} />

1. $e = \dfrac{V_w}{V_s}$

2. $e = \dfrac{V_v}{V_s}$

3. $e = \dfrac{V_w}{V_v}$

4. $e = \dfrac{m_s}{V_s}$

<details>
<summary>解答・解説</summary>

**正答：2**

1. **水の体積を土粒子体積で割っており含水比の意味、間隙比の定義ではない ❌**
2. 間隙比は間隙体積を土粒子体積で割った値で正しい ✅
3. **水の体積を間隙体積で割った値は飽和度に相当、誤り ❌**
4. **質量と体積の比は密度に相当し体積比ではない、誤り ❌**

<ExamPoint>間隙比は間隙体積を土粒子体積で除す</ExamPoint>

</details>

## 問題 No.2

下図の各サウンディングの測定方法に関する下記の文章中の（イ）〜（ハ）の次の組合せのうち，**適当なもの**はどれか。

<ArticleImage src="/posts/civil-construction-2/primary-r07-zenki/img/q02-fig.webp" alt="各サウンディングの測定方法を示した図" width={1943} height={976} />

1. 標準貫入試験は，ハンマを落下させ，サンプラーを30 cm貫入させるのに要する（イ）を計る。
2. オランダ式二重管コーン貫入試験は，貫入コーンを押込み速さ1 cm/s程度で押入し，深さ25 cmごとの（ロ）を計る。
3. スクリューウェイト貫入試験（旧名称：スウェーデン式サウンディング）は，質量が5，15，25，50，75，100 kgとなるようにおもりを段階的に載荷し，各荷重ごとの（ハ）を記録する。

|  | （イ） | （ロ） | （ハ） |
|---|---|---|---|
| (1) | 打撃回数 | 打撃回数 | 沈下量 |
| (2) | 打撃回数 | 貫入抵抗 | 沈下量 |
| (3) | 沈下量 | 貫入抵抗 | 打撃回数 |
| (4) | 打撃回数 | 貫入抵抗 | 沈下量 |

<details>
<summary>解答・解説</summary>

**正答：4**

1. **ロが打撃回数で誤り、オランダ式は貫入抵抗を計る ❌**
2. 各サウンディングと測定量の組合せが一部誤り ❌
3. **イが沈下量で誤り、標準貫入試験は打撃回数N値を計る ❌**
4. イ＝打撃回数、ロ＝貫入抵抗、ハ＝沈下量で正しい ✅

<ExamPoint>各サウンディングの測定量（打撃回数・貫入抵抗・沈下量）を混同しない</ExamPoint>

</details>

下図の単純梁に集中荷重 $P$ が作用した場合の曲げモーメント図として，**適当なもの**は次の図のうちどれか。ただし，梁の自重は考慮しないものとする。

3. 左で正、右で負となる三角形分布

4. 等分布荷重型の放物線分布

## 問題 No.4

下図において，点Oの周りに矢印の向きで力 $P_1$，$P_2$ が作用する場合において，点Oに対する力のモーメント（$M_O$）は次の値のうち，**正しいもの**はどれか。ただし，各力のモーメントの符号は，点Oを中心として時計まわりを正，反時計まわりを負とする。

<ArticleImage src="/posts/civil-construction-2/primary-r07-zenki/img/q04-fig.webp" alt="点Oの周りに力P1、P2が作用する図" width={1280} height={390} />

1. $M_O = 62$ [kN・m]

2. $M_O = 44$ [kN・m]

3. $M_O = 38$ [kN・m]

4. $M_O = 22$ [kN・m]

<details>
<summary>解答・解説</summary>

**正答：1**

左側の$P_1$（上向き10 kN、距離7 m）は時計まわりで$+10 \times 7 = +70$ kN・m、右側の$P_2$（上向き4 kN、距離2 m）は反時計まわりで$-4 \times 2 = -8$ kN・m。合算すると$M_O = 70 - 8 = +62$ kN・m。

1. $M_O = 62$ kN・mで計算結果と一致 ✅
2. **44は両モーメントの符号誤認による値、誤り ❌**
3. **38は距離か力の値の誤読、誤り ❌**
4. **22は減算順や符号取り違え、誤り ❌**

<ExamPoint>力のモーメントは力×距離を回転方向の符号付きで合算</ExamPoint>

</details>

## 問題 No.5

下図の完全流体におけるベルヌーイの定理において，図中の（イ）〜（ハ）の次の組合せのうち，**適当なもの**はどれか。ただし，水の密度は$\rho$，重力の加速度は$g$，断面①，②における平均流速は$v_1$，$v_2$，圧力の強さは$p_1$，$p_2$とし，1つの水平面を基準にとって断面①，②の基準面から流れの中心までの高さを$z_1$，$z_2$とする。

<ArticleImage src="/posts/civil-construction-2/primary-r07-zenki/img/q05-fig.webp" alt="完全流体におけるベルヌーイの定理の図（（イ）〜（ハ）が空欄）" width={1675} height={806} />

|  | （イ） | （ロ） | （ハ） |
|---|---|---|---|
| (1) | $v_1^2 / g$ | エネルギー | $p_2 / 2g$ |
| (2) | $v_1^2 / 2g$ | 動水 | $p_2 / \rho g$ |
| (3) | $v_1^2 / g$ | 動水 | $p_2 / \rho g$ |
| (4) | $v_1^2 / 2g$ | エネルギー | $p_2 / 2g$ |

<details>
<summary>解答・解説</summary>

**正答：2**

1. **速度水頭はv²/2gで分母に2が必要、ロもエネルギーでなく動水勾配 ❌**
2. 速度水頭$v_1^2/2g$、勾配線は動水勾配線、圧力水頭$p_2/\rho g$で正しい ✅
3. **速度水頭の分母が誤り（2が欠落） ❌**
4. **ロのエネルギー、ハの分母2gが圧力水頭として誤り ❌**

<ExamPoint>速度水頭v²/2g・動水勾配線・圧力水頭p/ρgの用語を正確に対応させる</ExamPoint>

</details>

## 問題 No.8

道路における盛土の施工に関する次の記述のうち，**適当なもの**はどれか。

1. 盛土の締固めの目的は，土の間隙に含まれる水分量を少なくすることにより，透水性を低下させ，土を安定した状態にすることである。

2. 盛土における構造物縁部の締固めは，ブルドーザ等できるだけ大型な締固め機械により入念に締固めるものとする。

3. 浸水により強度が低下するおそれがあることから，道路土工盛土工指針では施工含水比として最適含水比と乾燥側の含水比の範囲で締固めるように規定されている。

4. 構造物裏込め部の施工は，雨水の流入をできるだけ防止すると共に，浸透水に対しては地下排水溝を設けて処理することが望ましい。

<details>
<summary>解答・解説</summary>

**正答：4**

1. **締固めで少なくするのは間隙中の空気量、水分量を少なくして透水性を低下させるは誤り ❌**
2. **構造物縁部は小型機械で入念に締固めるのが原則、大型機械は誤り ❌**
3. **盛土の施工含水比は最適含水比付近で規定され、本記述の規定内容は誤り ❌**
4. 雨水の流入防止と地下排水溝による浸透水処理で適切、正しい ✅

<ExamPoint>盛土締固めは間隙中の空気量を減らすことが目的</ExamPoint>

</details>

- 移動式クレーンの作業においては，原則として（ハ）を行う者を指名しなければならない。
- 移動式クレーンの運転者を，荷をつったままで（ニ）から離れさせてはならない。

|  | （イ） | （ロ） | （ハ） | （ニ） |
|---|---|---|---|---|
| (1) | 中止 | 合図 | 監視 | 運転位置 |
| (2) | 注意して実施 | 合図 | 監視 | 旋回範囲 |
| (3) | 中止 | 玉掛け | 合図 | 運転位置 |
| (4) | 注意して実施 | 玉掛け | 合図 | 旋回範囲 |

<details>
<summary>解答・解説</summary>

**正答：3**

1. **ロが「合図」、ハが「監視」で誤り ❌**
2. **イが「注意して実施」は誤り、中止が正解 ❌**
3. イ＝中止、ロ＝玉掛け者、ハ＝合図、ニ＝運転位置で正しい ✅
4. **イが「注意して実施」で誤り ❌**

<ExamPoint>強風時の移動式クレーン作業は注意継続でなく中止が原則</ExamPoint>

</details>

## 問題 No.65

品質管理に用いられるx̄-R管理図に関する下記の①〜④の4つの記述のうち，**適当なもののみを全てあげている組合せ**は次のうちどれか。

1. x̄管理図は，組ごとの分布の幅によって工程のばらつきの変化を管理する管理図である。

4. x̄-R管理図は，各組の平均値の変動とばらつきの変化を同時に管理する管理図である。

1. ①②

2. ③④

3. ①②③

4. ②③④

<details>
<summary>解答・解説</summary>

**正答：2**

## 問題 No.66

盛土の締固めにおける品質管理に関する下記の①〜④の4つの記述のうち，**適当なもののみを全てあげている組合せ**は次のうちどれか。

4. 盛土の締固めは，法面の安定や土の含水比の増加等を目的とし，必要な強度特性が得られるように行う。

1. ②③

2. ③④

3. ①②③

4. ②③④
