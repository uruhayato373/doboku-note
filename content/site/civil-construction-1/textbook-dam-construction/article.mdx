1級土木施工管理技士の試験では、ダムの**基礎処理グラウチングの種類と施工位置**（コンソリデーション・カーテン・ブランケットの対象と目的の違い、ステージ注入工法の削孔順序）が繰り返し問われる。あわせて**コンクリートダムの打込み工法**（柱状ブロック工法のリフト高、RCD工法の横継目間隔・許容時間・降雨中止基準）と、**フィルダムの盛立て**（遮水ゾーンと他ゾーンで異なる施工上の判定基準）も頻出である。

出題の多くは、似た名称のグラウチング同士の対象や目的を入れ替える、あるいは数値基準（リフト高・横継目間隔・許容時間）の桁や上下限を逆にする形式である。ここでは基礎処理から打込み、養生、フィルダムの盛立てまでを施工の流れに沿って整理し、頻出の引っかけパターンを明示する。マスコンクリートの温度管理の一般原則は[寒中・暑中・マスコンクリートと品質管理・検査](/exam/civil-construction-1/textbook/special-concrete-inspection)で扱っており、本記事ではダム固有の養生方法に絞って扱う。

## ダムの構造形式と施工の全体像

ダムは水圧の支持機構によっていくつかの形式に分かれ、採用する形式によって基礎処理・打込み・養生の方法が大きく異なる。**重力式コンクリートダム**は堤体の自重によって水圧などの荷重を支える構造であり、日本のコンクリートダムの主流形式である。これに対し**アーチ式コンクリートダム**は、水圧の大部分をアーチ作用によって両岸の岩盤に伝達する構造で、重力式より堤体積を小さくできる反面、両岸の岩盤に高い強度が求められる。

フィルダムは岩石や土砂などの自然材料を用いる大規模盛土構造物で、代表的な**中央コア型ロックフィルダム**は堤体中央部に遮水性材料の**コア**を配置し、その両側にフィルタ材を挟んで透水性の**ロック**材を盛り立てる断面構成をとる。コアが水を止め、ロックが堤体の安定を支えるという役割分担であり、この位置関係を逆にした記述（コア=透水・ロック=遮水）が頻出の誤り選択肢になる。

| 形式 | 水圧の支持機構 |
|:--|:--|
| 重力式コンクリートダム | 堤体の自重で支持 |
| アーチ式コンクリートダム | 両岸の岩盤へ伝達 |
| 中央コア型ロックフィルダム | 盛立部の自重＋コアの遮水 |

重力式コンクリートダムが自重で水圧に抵抗するのに対し、水圧を両岸の岩盤に伝達するのはアーチ式の説明であり、この2つを入れ替えた選択肢が繰り返し出題されている。

堤体内には点検や排水、計器観測、グラウチングの施工基地として**監査廊**（通廊）が設けられ、後述するカーテングラウチングの施工位置（コンクリートダムか、ロックフィルダムか）によって基地となる通路の名称が変わる。堤体完成後も監査廊は維持管理の主要な巡視ルートとして機能し続ける。

ダム本体工事に先立つ**準備工**では、工事用道路や土捨場の整備など、施工に必要な設備・機械を配置するための工事を行う。ダムは大規模かつ長期にわたる工事となるため、施工設備の適切な配置が安全な施工の前提になる。あわせて**転流工**により、工事期間中の河川の流れを一時的に迂回させる。日本の河川は比較的川幅が狭く流量が少ない河川が多いため、川の全断面にトンネルを掘って迂回させる**仮排水トンネル方式**が広く用いられる。

この論点は[2級土木 令和6年度後期](/exam/civil-construction-2/primary/r06-kouki) 問28 で問われた。

## 基礎掘削

ダムの基礎掘削は、堤体を支持するのに十分な強度を持つ岩盤を露出させる工事である。硬岩の**粗掘削**には火薬を用いた発破掘削工法が用いられ、掘削計画面に近い部分は小ベンチ発破工法やプレスプリッティング工法などにより基礎地盤への損傷を抑える。掘削は一般に**ベンチカット工法**（せん孔・発破により上方から下方へ段階的に切り下げる工法）が用いられ、大量掘削を理由にブレーカ工法のみで施工するという記述は誤りである。

計画面から50cm程度を残した部分は、火薬を使用せず小型ブレーカや人力により仕上げる**仕上げ掘削**を行う。仕上げ掘削は着岩面の劣化防止の観点から、粗掘削と連続して速やかに、堤体の盛立てあるいはコンクリート打設の直前に施工することが多い。掘削中に掘削計画面より早く所要の強度の地盤が現れれば掘削を終了し、逆に予期しない断層や弱層が現れた場合は掘削線の変更や基礎処理の追加を検討する。堤敷外の掘削面は、施工中・完成後の法面の安定性や経済性に加え、景観や緑化にも配慮して定める。

掘削面の岩盤評価は、堤体形式ごとに着目点が異なる。重力式や中空重力式のコンクリートダムでは、堤体から基礎地盤へ伝わる荷重の分布をもとに堤体の安定性を検討するため、堤体底面に接する岩盤が底面の応力に耐えられるかどうかが判断の中心になる。粗掘削の工法選定も同様で、硬岩には発破掘削工法、表土・軟岩・風化岩・節理の発達した岩にはブルドーザやリッパを利用した機械掘削工法を用いるというように、地質条件に応じて使い分ける。

この論点は[平成30年度 問題A](/exam/civil-construction-1/primary/h30-a) 問33 で問われた。

## 基礎処理のグラウチング

ダムの基礎地盤・リム部地盤は、天然の岩盤であっても程度の差はあれ亀裂や弱部を含むため、グラウチングによってセメントミルクを注入し遮水性の改良と地盤の補強を行う。グラウチングは目的と対象によって次の3種に大別される。

| グラウチングの種類 | 主目的・対象 |
|:--|:--|
| コンソリデーション | 着岩部付近の弱部補強と遮水性改良 |
| カーテン | 高透水部の遮水性改良（主目的） |
| ブランケット | フィルダム基礎岩盤浅部の遮水性改良 |

**コンソリデーショングラウチング**は、主にコンクリートダムの着岩部付近において、断層・破砕帯・強風化岩などの弱部の補強と、カーテングラウチングとあいまった遮水性の改良を目的として、堤敷ほぼ全面に格子状の孔配置で行う。

**カーテングラウチング**は、ダムの基礎地盤及びリム部地盤のうち浸透路長が短い部分と、貯水池外への水みちとなるおそれのある高透水部の遮水性改良を主目的とする、比較的深い削孔長のグラウチングである。施工位置は堤体の形式によって異なり、コンクリートダムでは上流フーチングまたは堤内通廊から、ロックフィルダムでは**監査廊**から、リム部では地表またはリムグラウチングトンネルから行うのが一般的である。

**ブランケットグラウチング**は、コンソリデーショングラウチングと似た浅い施工深度を持つが対象がフィルダムの基礎岩盤である点が異なる。基礎地盤の浅い箇所の遮水性改良と、ダム堤体との密着性の改良を目的とする。

セメントミルクの配合（水セメント比W/C）は、ルジオン値に応じた初期配合と地盤の透水性状を考慮した配合切替え基準にあらかじめ従い、**濃度の薄いものから濃いものへ**順次切り替えながら注入する。基礎グラウチングの削孔・注入方式には、全長を一度に削孔した後に下位ステージから上位ステージへ向けて注入する**パッカー注入工法**と、1ステージ5m程度の深さごとに削孔と注入を繰り返す**ステージ注入工法**があり、後者はほとんどのダムで採用されている標準的な方式である。

<Callout type="warn" title="頻出論点：ステージ注入工法の削孔・注入の順序">
ステージ注入工法は標高の上位のステージから下位のステージへ向かって削孔と注入を交互に行う。下位から上位へ向かう順序はパッカー注入工法の説明であり、両者を入れ替えた選択肢が繰り返し出題されている。
</Callout>

この論点は[令和7年度 問題A](/exam/civil-construction-1/primary/r07-a) 問38 で問われた。

## コンクリートダムの打込み工法

コンクリートダムの打込み工法は、縦継目と横継目で区画したブロックごとに打ち込む**柱状ブロック工法**と、超硬練りコンクリートを面状に敷き均す**RCD工法**が中心である。柱状ブロック工法では、コンクリートの熱放散・打設工程・打継面の処理などを考慮して**リフト高0.75〜2.0m**を標準とし、運搬用バケットは下端が打込み面上1m以下に達するまで下ろしてから放出する。バケット高さを2m程度まで下ろすとする記述は、材料分離のおそれがあるため誤りとなる。

**RCD工法**は、従来の重力式コンクリートダムに要求される機能・品質・安全性を低下させることなく施工を合理化する工法で、ダンプトラックなどで運搬した超硬練り貧配合のRCD用コンクリートをブルドーザで薄層に敷き均し、振動目地切機で横継目を設置したのち振動ローラで締め固める。敷均し厚さは、0.75mリフトの場合は3層、1mリフトの場合は4層とし、振動ローラで締め固めた後の層厚が25cm程度となるよう27cm程度に敷き均す例が多い。横継目はダム軸に**直角**に設け、貯水池からの漏水経路となりやすい上流端付近には主副2枚の止水板を設置する。

**拡張レヤー工法**（ELCM）は、従来のブロックレヤー工法をダム軸方向に拡張し、複数ブロックを一度に打ち込んで堤体を面状に打ち上げる合理化工法である。名称の似た**レヤー工法**は横継目のみを設けて縦継目を設けずに層状に打ち上げる工法であり、両者の継目構成を取り違えないよう区別する。このほか、ダムコンクリートの特殊な運搬工法として、ポンプ圧送とディストリビュータを組み合わせるPCD工法や、らせん状の羽根を持つ管を回転させて連続運搬するSP-TOM工法がある。

| 項目 | 標準値 |
|:--|:--|
| 柱状ブロックのリフト高 | 0.75〜2.0m |
| 運搬バケット下端の高さ | 打込み面上1m以下 |
| RCD横継目の間隔 | ダム軸方向15m |
| RCD敷均し（0.75mリフト） | 3層に敷均し |
| RCD敷均し（1mリフト） | 4層に敷均し |
| 練混ぜ〜締固め許容時間（夏季） | 3時間程度 |
| 練混ぜ〜締固め許容時間（冬季） | 4時間程度 |
| 降雨中止基準（有スランプ） | 1時間4mm以上 |
| 降雨中止基準（RCD用） | 有スランプより厳しい |
| 横継目上流端の止水板 | 主副2枚 |

<Callout type="reference" title="出典">
[国土交通省 関東地方整備局「RCD工法による建設」](https://www.ktr.mlit.go.jp/sagami/sagami00018.html)
</Callout>

練混ぜから締固めまでの許容時間は、材料・配合・気温・湿度によって変わるが、**夏季3時間程度・冬季4時間程度**を標準とする。降雨によるコンクリート品質への悪影響を避けるため、有スランプコンクリートは1時間当たり**4mm以上**、RCD用コンクリートは薄層で表面が露出するため**それより小さい降雨強度**で打込みを中止する。RCD用コンクリートは表面が薄層で露出面積が大きいぶん降雨の影響を受けやすいため、有スランプコンクリートより厳しい基準になっている点に注意する。

この論点は[令和3年度 問題A](/exam/civil-construction-1/primary/r03-a) 問34 で問われた。

## ダムコンクリートの配合区分と要求性能

ダムコンクリートは、堤体の部位ごとに求められる性能が異なるため、**外部・内部・構造用・着岩**の4区分に分けて配合を設計する。

| 配合区分 | 要求性能 |
|:--|:--|
| 外部コンクリート | 気象作用への耐久性・水密性・すりへり抵抗性 |
| 内部コンクリート | 自重で荷重を支える強度・水密性・均質性 |
| 構造用コンクリート | 鉄筋・埋設物との付着性、狭あい部への施工性 |
| 着岩コンクリート | 岩盤との付着性、不陸のある岩盤への施工性 |

**外部コンクリート**は気象作用に直接さらされる部位のため、耐久性・水密性に加えてすりへり作用や凍結融解作用に対する抵抗性が求められる。**内部コンクリート**は水圧などの荷重を自重で支える堤体の大部分を占める部位で、所要の単位容積質量・強度・水密性・均質性が要求される一方、施工量が大きいため発熱量が小さく施工性に優れることも重視される。

**構造用コンクリート**はゲート室や監査廊の周囲など鉄筋や埋設構造物が入る部位に用いられ、狭あい部への打込み性が求められる。**着岩コンクリート**は内部コンクリートと同じ機能を持ちながら、不陸のある岩盤に対しても容易に打ち込めて一体性を確保できる施工性が必要になる。ダムの越流部・導流部・減勢部の表面は流水によるすりへり作用に耐える必要があり、局部不陸の許容値は**6mm以下**を標準として平滑に仕上げる。

骨材の貯蔵では、安定した表面水率を確保するために雨水を避ける上屋を設け、**細骨材は3〜4日以上、粗骨材は7日以上**の水切り時間を確保する。セメントは、水和熱を抑制することが求められるダムコンクリートには**中庸熱ポルトランドセメント**が用いられ、RCD用コンクリートはさらに単位セメント量を少なくした貧配合として水和熱を抑える設計とする。

この論点は[令和5年度 問題A](/exam/civil-construction-1/primary/r05-a) 問34 で問われた。

## 養生と温度ひび割れ対策

ダムコンクリートの養生方法は、気温・湿度などの環境条件やリフトスケジュールを考慮して定める。打込み面の乾燥・急冷を防ぐため、**柱状ブロック工法では湛水養生**が、**RCD工法や拡張レヤー工法ではスプリンクラーによる散水養生**が一般的に行われる。工法によって適した養生方法が異なる点が出題の軸になる。

RCD工法は超硬練りコンクリートを薄層に敷き均す低発熱型の工法であり、パイプクーリングのような特別な冷却養生を必要としない。水和発熱が大きいと決めつけてパイプクーリング養生を前提とする記述は誤りである。

<Callout type="warn" title="頻出論点：RCD工法の低発熱性">
RCD工法は超硬練り・薄層転圧により水和発熱を抑えた工法であり、パイプクーリングなどの特別な冷却養生を一般的には必要としない。「水和発熱が大きくパイプクーリングが一般的」とする記述は誤りである。
</Callout>

打込み面の岩盤や水平打継目にモルタルを敷き込む際は、乾燥した面のままではモルタル中の水分が失われて確実な付着力が得られないため、あらかじめ吸水させ**湿潤状態**にしておく必要がある。また、暑期の温度応力を抑える対策として、コンクリート材料の一部または全部をあらかじめ冷却し打込み温度を低下させる**プレクーリング**が用いられる。

この論点は[平成26年度 問題A](/exam/civil-construction-1/primary/h26-a) 問33 で問われた。

## フィルダムの盛立てと遮水ゾーンの施工

フィルダムは、盛立部が自然材料の大規模盛土構造物、洪水吐きや監査廊などの構造物部がコンクリート構造物となるため、両系統の施工設備を必要とする。中央コア型ロックフィルダムの盛立てでは、ブルドーザによる敷均しをダム軸に直交する方向に行い、均等な厚さに仕上げる。ダム軸に平行な方向へ敷き均すと層内が水みちになりやすいため避ける。盛立ては基本的に上下流方向の勾配をつけず水平に行うが、排水を考慮して上下流方向に2%程度の勾配をつけることも許容される。

遮水ゾーンの盛立面に遮水材料をダンプトラックで撒き出す際は、できるだけフィルタゾーンを走行させ、遮水ゾーン上の走行は最小限の距離にとどめる。遮水ゾーンの**着岩部**では、大きい礫を含む遮水材料をそのまま固い岩盤に接すると水みちとなる空隙ができやすいため、遮水材料よりも粒径の小さい**着岩材**を人力または小型の締固め機械で施工するのが一般的である。転圧用機械は、従来はタンピングローラが多く用いられてきたが、近年は振動ローラの採用が増えている。

フィルダムの基礎掘削は、ゾーンによって判定基準が異なる点にも注意する。**遮水ゾーン**の基礎は止水性・変形性を重視し所要の性能が得られるまで掘削するのに対し、遮水ゾーン以外の透水ゾーン・半透水ゾーンの基礎は支持力・せん断強度を基準に掘削の要否を判断する。同じ「基礎掘削」でも要求される条件が異なるため、判定基準を入れ替えた記述に注意する。

この論点は[平成28年度 問題A](/exam/civil-construction-1/primary/h28-a) 問34 で問われた。
