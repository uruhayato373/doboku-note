1級土木施工管理技士の試験では、**切土法面の標準勾配**（硬岩1:0.3〜1:0.8・軟岩1:0.5〜1:1.2 等）、**小段の設置基準**、**法面崩壊が懸念される地山条件とその対策**、**法面保護工（植生工・構造物工）の選定基準**、および**法面排水工の分類**（表面排水・地下排水）が頻出。

## 切土の基本的な考え方

自然地盤はきわめて不均質であり、切土法面は施工後も時間の経過とともに状況が変化していくことが多い。切土法面の勾配は、土質調査の結果を基礎データとしつつも、現地の法面の土質・地質・高さ・湧水・風化の程度・亀裂や崩壊の状況、降雨等の自然条件を総合的に考慮し、近隣の既存法面の実績も参考にして経験的に決定する。

### 切土法面の標準勾配

切土法面の勾配は、地山の土質・切土高さに応じた標準値を参考に決定する。硬岩・軟岩の区別は、主として岩石のせん断強さと割れ目の多さから判断される。

| 地山の土質 | 切土高さ・勾配の目安 |
|:--|:--|
| 硬岩 | 1:0.3〜1:0.8 |
| 軟岩 | 1:0.5〜1:1.2 |
| 砂（締まっていないもの） | 1:1.5〜（上限は定めない） |
| 砂質土（密実なもの） | 5m以下 1:0.8〜1.0／5〜10m 1:1.0〜1.2 |
| 砂質土（密実でないもの） | 5m以下 1:1.0〜1.2／5〜10m 1:1.2〜1.5 |
| 礫・岩塊まじり砂質土（密実なもの） | 10m以下 1:0.8〜1.0／10〜15m 1:1.0〜1.2 |
| 礫・岩塊まじり砂質土（密実でないもの） | 10m以下 1:1.0〜1.2／10〜15m 1:1.2〜1.5 |
| 粘性土 | 0〜10m 1:0.8〜1.2 |
| 岩塊・玉石まじり粘性土 | 5m以下 1:1.0〜1.2／5〜10m 1:1.2〜1.5 |

[公益社団法人 日本道路協会](https://www.road.or.jp/)「道路土工―切土工・斜面安定工指針」
</Callout>

標準値はあくまで目安であり、地質・地盤条件や地下水条件が複雑な場合は、別途安定計算等の検討を行って勾配を決定する。

## 切土法面の形状

  src="/posts/civil-construction-1/textbook-cut-slope-protection/img/figure-cut-slope-shape.svg"
  alt="切土法面の形状（単一勾配・勾配変化と小段・法肩のラウンディング）と小段が果たす役割"
  width={400}
  height={500}
/>

地質・土質が深さ方向・縦断方向にほぼ一様な場合は、**単一勾配の法面**を採用する。地質・土質が層ごとに異なる場合は、各層に適した勾配を採用し、勾配の変換点に**小段**を設けるのが一般的で、安定性・施工性の面でも有利である。

切土高さが5〜10m以上になると小段を設ける。小段の幅は1.0〜2.0m程度とし、法面下方に向けて5〜10%程度の横断勾配をつけて排水を促す。土質・岩質が変化する場合は、その境界の位置に小段を合わせるのが合理的である。

小段には次のような役割がある。

- 法面を流れる雨水の勢いをそぐ
- 小段に設けた排水溝から水を法面外へ導く
- 法面の点検・補修・補強の足場として利用できる

法肩付近は侵食を受けやすく植生も定着しにくいため、最上段などの法肩に丸みをつける**ラウンディング**を行うことがある。

## 切土法面の安定性の検討

<Callout type="warn" title="試験頻出：法面崩壊のおそれがある地山条件">
次のような土質・地質の地山を切り取る際は、法面崩壊のおそれがあるため特に注意が必要である。地山条件ごとに崩壊のパターンと対策が異なる点が繰り返し出題される。
</Callout>

- **崩積土・風化岩の切土** — 堆積・風化・地震等で生じた崩積土は、自然斜面の傾斜が現状でかろうじて安定しているにすぎないため、切り取ると崩壊するおそれがある。想定される崩積土の上方に小段を設けて受ける、地質・湧水・風化の程度等を考慮した安定勾配とする、大規模な排土で滑動側の重量を減らす、地下排水溝・水平排水孔で地下水位を低下させる、土留めや杭工で補強する、などの対策をとる
- **侵食に弱い土質（シラス・まさ等）の切土** — 表面水による侵食に特に弱い土は土砂流出が起こりやすいため、力学的安定性だけでなく雨水等による侵食に対する検討もあわせて必要になる。法面・小段の排水を十分に行うとともに、密な植生による法面保護工を施す
- **泥岩・粘板岩等、風化が速い岩の切土** — 掘削直後は安定していても、応力解放後の乾湿の繰返し等により急激に風化が進み、法面崩壊に至る場合が多い。風化の進行を抑える対策と、万一崩壊しても被害を最小限にとどめる対策をあわせて検討する
- **割れ目の多い岩の切土** — 割れ目の発達度合い・破砕の程度を考慮し、周辺の既存法面の実績を参照して勾配を決める
- **割れ目が流れ盤となる場合の切土** — 岩の割れ目の方向が地層の傾斜方向と同じ「流れ盤」では、割れ目に沿った滑りが生じやすいため、割れ目の深さ・方向を確認したうえで勾配を検討する
- **地下水が高い場合の切土** — 浸透水・湧水によって法面が不安定になりやすいため、地下排水溝・水平排水孔等の地下排水工で地下水位を低下させ、法面の安定化を図る
- **長大法面となる場合の切土** — 地層構成が複雑になりやすく崩壊事例も多いため、施工段階に応じて安定した勾配となるよう計画する。急傾斜地では、地山の岩質のまま急勾配とするか、剛性の高い構造物で保護して急勾配とするかを比較検討する

盛り返しや段丘、軟弱地盤、亀裂の多い地盤、既往の崩壊跡地、大規模な切土斜面などでは、十分な地盤・土質調査を行い、可能な範囲で安定計算を実施したうえで、法面勾配や必要な対策工法を決定する。

## 切土法面の施工

### 岩盤法面の施工

落石のおそれのある浮石はていねいに取り除き、取り除くことが困難な大きな岩石はアンカー等で固定する。仕上げ法面には30cm程度の余裕を持たせることが多い。施工中に発見した亀裂は、地質状態・湧水等の状況から大規模な崩壊の原因とならないよう初期対策を計画し、コンクリート張り工・枠工・モルタル吹付工等で法面を保護する。

### 土砂法面の施工

仕上げ後の法面は降雨等で侵食されやすいため、できるだけ早期に法面保護工を施工する。施工中に地中排水の湧出が見られる場合は、湧水量に応じた排水工を施工する。法枠工等を施工する際は、法肩や小段の仮排水設備を確保しておく。工事後に乾燥亀裂や表面侵食が生じることがあり、軽微な場合はアスファルト系材料の吹付け、著しい場合は石張り工・ブロック張り工・法枠工で対応する。

### 切土時の排水処理

1. 切土面に流入する表面水を遮断するため、周囲に素掘りの溝等を設けたん水を防ぐ
2. 地形の低い場所で自然排水が不可能なときは、集水井を設けてポンプ排水する
3. 集水施設や法面保護工は、法面の仕上げ後なるべく早い時期に施工する
4. 切土と盛土の接続部では、切土側から盛土面へ雨水が流れ込むのを防ぐため境界付近に排水溝を設ける
5. 地下水位の高い切土部では、地下水を排水するため十分な数のトレンチを設ける
6. 地下水位を低下させる場合は、周辺の井戸・用水等への影響を確認してから対策に着手する

## 土取場および土捨場の施工

### 土取場の施工

切取高が大きい場合、地山の一般的な掘削方法として次のような工法が用いられる。

| 掘削の対象 | 掘削方法 |
|:--|:--|
| 土砂の掘削 | ベンチカット工法（階段状に掘削）／ダウンヒルカット工法（下り勾配を利用して掘削・運搬） |
| 岩の掘削 | 発破による掘削／リッパによる掘削／静的破砕剤による掘削 |
| 転石・玉石まじりの掘削 | 大型バックホウやクレーン等で、大きさや混入度合いに応じて処理する |

### 土捨場の施工

土捨場は、谷間や急崖、池沼、低地等の地盤的に不良な箇所に設置されることが多い。本工事と同様に、事前の排水対策、法面防護工の計画、通行や斜面通過の確保、必要に応じた沈砂池の設置などを考慮して管理する。土量の変化や土質・容量の変化、トラフィカビリティ確保のための良質土の混入なども考慮し、十分な余裕を持たせる。

## 法面保護工

<ArticleImage
  src="/posts/civil-construction-1/textbook-cut-slope-protection/img/figure-slope-protection-selection.svg"
  alt="法面保護工の選定（植生工・構造物工の使い分け）と両者の違い"
  width={400}
  height={500}
/>

法面保護工は、法面の侵食を防止し安定を図るもので、植物を用いる**植生工**と、コンクリート等の構造物による**構造物による法面保護工**の2種類に大別される。法面保護は安定確保だけでなく、環境の保全や良好な景観の維持も重要な目的である。

### 法面保護工の選定

- 法面が安定した土質と考えられる場合は、植生工を用いる
- 侵食されやすく崩れやすい場合は、植生工に構造物工を併用する
- 湧水のある場所は、法枠工・ブロック張り工・石張り工が効果的である
- 法面が軟弱で崩れやすい場合は、ブロック張り工・石張り工を用いる
- 風化しやすい土砂・軟岩にはモルタル・コンクリート吹付工を用いるが、湧水のある箇所では短期間で剥落することがあるため注意する
- 落石のおそれのある法面には落石防護工・アンカー工を用いる
- 湧水の多い法面にはじゃかご工が土砂の流出防止に効果的である

法面の下部など排水がたまりやすい部分には、水平排水孔や地下排水溝などの地中排水施設を設ける。実際には単独の工種で完結させず、複数の工種を組み合わせて用いるのが一般的である。

### 植生工

植生工は、法面に芝などの植物を繁茂させることで、法面の侵食や表面の崩壊を防止する。

| 工種 | 目的・特徴 |
|:--|:--|
| 種子吹付工 | 種子・肥料等を水に溶かして吹き付ける。比較的安定した切土面に適用 |
| 植生シート工 | 植生シートを法面に張り付ける。切土・盛土法面の全面植生 |
| 張芝工 | 芝を法面に貼り付ける。主に盛土法面の植生保護に用いる |
| 植生基材吹付工 | 植生基材・肥料等を吹き付ける。植生に適さない土砂法面の全面被覆に用いる |
| 筋芝工 | 芝を筋状に施工する。盛土法面の植生と筋間の土留めを兼ねる |
| 植生土のう工 | 種子・肥料を含ませた土のうを法面下部に設置する |
| 植生ネット工 | 植物材料を含んだネットを法面に被せ、全面を植生する |

施工にあたっては、以下の点に留意する。

- **土壌が植物の生育に適していること** — 雨水がかからない高架下等では構造物による保護工が有効。やせた切土法面では追肥が必要になる
- **施工に適した時期であること** — 一般に春・秋が植種（植えつけ）の適期とされる
- **法面勾配が適当であること** — 勾配が急になるほど活着が悪くなるため、一般に1:0.8より緩やかにする。凍上・凍結で活着が悪化しやすい寒冷地では、1:1.5より緩やかにする

### 構造物による法面保護工

植生による保護が困難な法面、植生のみでは不安定と考えられる法面、崩落・落石のおそれがある法面などには、石材・コンクリート・鋼材・プラスチック等の構造物による保護工を用いる。単独あるいは組み合わせて用いられ、植生工と併用されることも多い。

| 工種 | 目的・特徴 |
|:--|:--|
| 編柵工 | 木杭に竹やそだを編み込み法面を押さえる。小規模な侵食・崩落の抑制に用いる |
| じゃかご工 | 金網製のかごに砂利・玉石を詰めて設置する。湧水の多い法面の保護に効果的 |
| プレキャスト枠工 | 工場製作の枠材を法面に設置する。複雑な形状の法面にも対応しやすい |
| モルタル・コンクリート吹付工 | 風化しやすい土砂・軟岩の法面に吹き付ける。湧水箇所は剥落に注意する |
| 吹付枠工 | 法面上に格子状にコンクリートを吹き付ける。アンカー工の併用で安定性が高まる |
| 現場打ちコンクリート枠工 | 現場でコンクリート枠を打設する。高い安定性が期待できる |
| ブロック張工・コンクリート張工 | ブロックやコンクリート板で法面を覆う。裏込め材・水抜孔を併設する |
| 擁壁工 | 法面の侵食・崩壊を防止するコンクリート構造物。小規模な場合は定型製品も使われる |
| グラウンドアンカー工 | アンカーで法面を地盤内部に固定する。他工種と組み合わせて用いる |

吹付枠工・現場打ちコンクリート枠工の施工では、次の点に留意する。

1. 凹凸の著しい法面は型枠の据付けが難しいため、下地吹付けで凹凸を減らす
2. 湧水箇所には湧水・排水処理を行う
3. 型枠はモルタルが硬化するまで変形しないよう強固に組み立てる
4. 継手は隣り合う型枠の中央部で行い、端部で品質が低下しないよう処理する

### 法面排水工

法面崩壊の原因は、多くの場合、地表水または浸透水に関係している。法面排水工は、大別すると**表面排水工**と**地下排水工**に分かれる。

- **表面排水工** — 法面の表面を水が流下しないよう、法肩に設ける**法肩排水溝**、長大法面の小段に設ける**小段排水溝**、これらの水を法尻に導く**縦排水溝**（U形溝や半円ヒューム管等）を組み合わせて設置する
- **地下排水工** — 法面の安定に悪影響を与える浸透水を地中で排除する施設。溝の中に砕石等を詰めた**暗渠排水**、湧水のある法面に水平に穴あき管を挿入する**水平排水孔**などがある

道路盛土では、盛土内の間隙水圧を低下させるため、砂の水平排水層（厚さ20〜30cm程度）を設けることがある。高含水比の材料で高盛土をする場合は特に有効で、近年は排水機能の高いジオテキスタイルが用いられることもある。
