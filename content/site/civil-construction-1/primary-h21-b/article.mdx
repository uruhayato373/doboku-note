## 問題 No.1

基準点などの水平位置を求める測量に関する次の記述のうち，**適当でないもの**はどれか。

1. 公共測量の水平位置は，平面直角座標系による X 座標，Y 座標で表示する。

2. トータルステーションは，既設の観測地点から目標地点の水平位置を求めることができる。

3. 公共測量の水平位置座標は，既設の観測地点から目標地点の水平角と斜距離により算出することができる。

4. GPS 測量機は，人工衛星から発射される電波を受信して観測地点の水平位置を求めることができる。

<details>
<summary>解答・解説</summary>

**正答：3**

1. 公共測量の水平位置は平面直角座標系の X 座標・Y 座標で表示する。記述のとおり。 ✅
2. トータルステーションは既知点から目標点までの角度と距離を観測し、水平位置を求められる。 ✅
3. 斜距離だけでは水平位置は出ない。鉛直角などで水平距離に換算して用いる必要があり、不適当。 ❌
4. GPS 測量機は衛星からの電波を受信して観測点の位置（水平位置）を求められる。 ✅

<ExamPoint>水平位置の算出に使うのは水平角と水平距離（斜距離の換算が必要）</ExamPoint>

</details>

## 問題 No.2

高さを求める測量に関する次の記述のうち，**適当でないもの**はどれか。

1. 公共測量の高さ（標高）は，平均海面からの高さを基準として表示する。

2. 一般に，トータルステーションは，電子レベルよりも正確に高さ（標高）を求めることができる。

3. トータルステーションは，観測した斜距離と鉛直角により，観測点と視準点の高低差を算出できる。

4. 電子レベルは，2つの測点上に設置されたバーコード標尺を読み取り，2つの測点間の高低差を自動的に算出できる。

<details>
<summary>解答・解説</summary>

**正答：2**

1. 標高は平均海面（東京湾平均海面）を基準とした高さで表示する。 ✅
2. 高さの精度は水準測量（電子レベル）の方が高く、トータルステーションの方が正確とはいえず不適当。 ❌
3. 斜距離と鉛直角から高低差を $S\sin\alpha$ 等で算出できる（間接水準測量）。 ✅
4. 電子レベルはバーコード標尺を自動読取りし、2点間の高低差を算出できる。 ✅

<ExamPoint>高さの精度は電子レベル（直接水準測量）がトータルステーションより上</ExamPoint>

</details>

## 問題 No.3

公共工事標準請負契約約款における工事の一時中止に関する次の記述のうち，**正しいもの**はどれか。

1. 発注者が工事の一部の施工を一時中止させる場合には，建設機械器具等を保持するための費用については負担の対象とならない。

2. 工事の一時中止による工期の変更は，工事の全部が中止となった場合に限られる。

3. 発注者が工事の施工を一時中止させた場合，工事の続行に備えて保持しておく労働者の費用は負担の対象とならない。

4. 自然的又は人為的な事象により請負者の責任によらず工事の施工ができない場合以外でも，発注者が必要があると認めるときは，工事を一時中止させることができる。

<details>
<summary>解答・解説</summary>

**正答：4**

1. 工事の一部の中止でも、建設機械器具等の保持など必要な増加費用は発注者が負担の対象となり得る。 ❌
2. 一時中止に伴う工期変更は、工事の一部が中止の場合も対象で、全部中止に限らない。 ❌
3. 工事続行に備えて保持する労働者の費用も、必要な増加費用として負担の対象となる。 ❌
4. 請負者の責に帰さない事由以外でも、発注者は必要と認めるときは工事を一時中止させることができる。 ✅

<ExamPoint>一時中止は発注者の必要で可能・一部中止も対象・保持費用は負担対象</ExamPoint>

</details>

## 問題 No.5

建設機械の排出ガス対象機械のうち，「特定特殊自動車排出ガスの規制等に関する法律（オフロード法）」に**該当する建設機械**は次のうちどれか。

1. クローラ型のバックホウ（バケット平積容量 0.6 m³ 級）

2. 可搬式のエンジン掛け空気圧縮機（吐出空気量 11.0 m³/min 級）

3. ナンバー付きのラフテレーンクレーン（クレーン能力 50 t 級）

4. 可搬式の発動発電機（発電出力 200 kVA 級）

<details>
<summary>解答・解説</summary>

**正答：1**

1. クローラ型バックホウは公道を走らない特殊自動車で、オフロード法の規制対象となる建設機械に該当する。 ✅
2. 可搬式のエンジン掛け空気圧縮機は自走する車両でなく、オフロード法の対象外。国土交通省の指定制度で排出ガス対策を進める機種である。 ❌
3. ナンバー付きのラフテレーンクレーンは道路運送車両法の排出ガス規制を受けるため、オフロード法の対象には当たらない。 ❌
4. 可搬式の発動発電機は自走しない可搬式建設機械で、オフロード法の対象外。国土交通省の指定制度で扱われる機種である。 ❌

<ExamPoint>オフロード法は公道を走らない特殊自動車が対象。可搬式機械は対象外</ExamPoint>

</details>

<summary>解答・解説</summary>

## 問題 No.7

仮設工事に関する次の記述のうち，**適当なもの**はどれか。

1. 指定仮設は，重要な仮設物について構造，形状寸法，品質及び価格の指定を受けて施工するため，設計変更の対象とはならない。

2. 任意仮設は，請負者が任意にその計画立案を行い実施されるもので，そのすべての責任は請負者が有するものである。

3. 仮設構造物の安全率は，一般に，本体構造物と同じ安全率で計画される。

4. 仮設工事に使用する材料の計画にあたっては，一般の市販品はできる限り使用を避ける。

<details>
<summary>解答・解説</summary>

**正答：2**

1. 指定仮設も、条件の変更があれば設計変更の対象となる。「ならない」は誤り。 ❌
2. 任意仮設は請負者が計画・施工し、責任も請負者が負うもの。記述のとおり。 ✅
3. 仮設構造物の安全率は、一般に使用期間の短さなどから本体構造物より割り引いて計画する。同じとするのは誤り。 ❌
4. 仮設材は転用・調達のしやすさから、一般の市販品をできるだけ使用する。避けるのは誤り。 ❌

<ExamPoint>任意仮設は請負者責任・指定仮設も設計変更対象</ExamPoint>

## 問題 No.8

建設工事における環境保全対策に関する次の記述のうち，**適当でないもの**はどれか。

1. 周辺環境の保全に対する検討事項としては，騒音，振動，粉塵，大気汚染等があり，例えば粉塵発生の防止を図るには，工事箇所における散水や粉塵ネットの設置が行われる。

2. 施工機械の選定にあたっては，作業能力を優先して決定し，工事現場への騒音，振動の影響にも配慮する。

3. 材料の選定にあたっては，循環型社会形成の観点から「建設工事に係る資材の再資源化等に関する法律（建設リサイクル法）」等に基づき再利用，再生利用できるものを使用する。

4. 資機材の調達にあたっては，「国等による環境物品等の調達の推進等に関する法律（グリーン購入法）」等に基づき CO₂ の排出抑制に配慮する。

<details>
<summary>解答・解説</summary>

**正答：2**

1. 粉塵の防止には散水や粉塵ネットの設置が行われる。適当。 ✅
2. 機械選定は作業能力だけで決めず、低騒音・低振動の機械を選ぶなど環境影響を優先して配慮する。能力優先は不適当。 ❌
3. 建設リサイクル法等に基づき、再利用・再生利用できる材料を選定する。適当。 ✅
4. グリーン購入法等に基づき、CO₂ の排出抑制に配慮した資機材を調達する。適当。 ✅

<ExamPoint>機械選定は作業能力より騒音・振動など環境影響への配慮が先</ExamPoint>

</details>

## 問題 No.9

品質管理に関する次の記述のうち，**適当でないもの**はどれか。

1. 品質管理の目的は，設計図書，仕様書に示された品質規格に合致する工事目的物を，経済的につくり出すための管理手法である。

2. 測定値が規格値を満足しない場合は，品質に異常が生じたものとして，その原因を追及し，再発しないよう処置する。

3. 通常行われる土工の品質管理は，主に盛土の締固めが中心となり，一般に施工時の乾燥密度により管理する。

4. 品質管理の手法は，一般に，施工後に各種試験を行い，品質が所定の目標を満足しない場合には必要な措置をとり，品質の確保をはかるものである。

<details>
<summary>解答・解説</summary>

**正答：4**

1. 規格に合致する工事目的物を経済的につくる管理手法という趣旨で適当。 ✅
2. 規格を満足しない測定値は異常として原因を追究し、再発防止の処置をとる。適当。 ✅
3. 土工の品質管理は盛土の締固めが中心で、乾燥密度により管理する。適当。 ✅
4. 品質管理は施工後の試験で確認するのではなく、施工の各段階でデータを取り管理して品質をつくり込む。不適当。 ❌

<ExamPoint>品質管理は施工途中のつくり込み、施工後の検査だけではない</ExamPoint>

</details>

## 問題 No.11

工程計画立案時の建設機械の稼働率と制約条件に関する次の記述のうち，**適当でないもの**はどれか。

1. 土工作業の施工可能日数を把握するには，工事着手後に，当該地方の気象，地山性状，建設機械のトラフィカビリティの調査等を行う。

2. 土工作業では，稼働率に影響を及ぼす最大要因は天候であり，降水量，降水日の分布，土質による工事再開までの乾燥程度が施工可能日数を決定する。

3. 稼働率算定に際し必要となる主な調査項目には，天候，風速，凍結，潮位，出水時期等がある。

4. 施工可能日数を算出する場合は，建設工事の騒音・振動の規制によって作業時間，作業期間の制約を受ける場合があり，これらもよく調査する。

<details>
<summary>解答・解説</summary>

**正答：1**

1. 施工可能日数の把握は工事着手前の調査で行う。着手後に行うとしている点が不適当。 ❌
2. 土工の稼働率に最も影響するのは天候で、降水量・降水日の分布や乾燥程度が施工可能日数を決める。 ✅
3. 稼働率算定では天候・風速・凍結・潮位・出水時期などを調査する。適当。 ✅
4. 騒音・振動の規制による作業時間・期間の制約も調査して施工可能日数を算出する。適当。 ✅

<ExamPoint>施工可能日数の調査は着手前（着手後は誤り）</ExamPoint>

</details>

## 問題 No.12

工程管理の基本的な考え方に関する次の記述のうち，**適当でないもの**はどれか。

1. 工事の進捗管理は，施工計画の立案と実施の「改善機能」及び評価と処置の「統制機能」に大別される。

2. 工程管理は，施工計画において品質，原価，安全など工事管理の目的とする要件を総合的に調整し，策定された基本の工程計画をもとにして実施する。

3. 工程管理を行う場合は，常に工事の進捗状況を把握して計画と実施のずれを早期に発見し，必要な是正措置を講ずる。

4. 工程管理は，工事の施工段階を評価測定する基準を時間におき，労働力，機械設備，資材などの生産要素を，最も効果的に活用することを目的としている。

<details>
<summary>解答・解説</summary>

**正答：1**

1. 「統制機能」と「改善機能」の組合せが逆。計画の立案と実施が「統制機能」、評価と処置が「改善機能」である。 ❌
2. 基本の工程計画は品質・原価・安全などを総合的に調整して策定し、それに基づき実施する。適当。 ✅
3. 進捗を常に把握し、計画とのずれを早期に発見して是正措置を講ずる。適当。 ✅
4. 時間を基準に、労働力・機械・資材などの生産要素を最も効果的に活用するのが目的。適当。 ✅

<ExamPoint>統制機能と改善機能の対応を入れ替えた引っかけ</ExamPoint>

</details>

2. 入退場時の人員点検は酸素欠乏危険作業で必要な措置で、省略してはならず不適当。 ❌
3. 酸素濃度 18 % 以上を保つよう換気する。適当。 ✅
4. 酸素欠乏危険作業主任者に作業を指揮させる。適当。 ✅

<ExamPoint>酸欠作業では入退場時の人員点検が必要</ExamPoint>

## 問題 No.27

下記は，品質管理を行う管理項目を示したものである。品質管理の手順の組合せとして，次のうち**適当なもの**はどれか。

- （イ）「処置の結果」をチェックする。
- （ロ）「品質特性」を決める。
- （ハ）「作業標準」を決める。
- （ニ）「品質標準」を決める。

1. （ハ）→（ロ）→（ニ）→（イ）

2. （ニ）→（ハ）→（ロ）→（イ）

3. （ニ）→（ロ）→（ハ）→（イ）

4. （ロ）→（ニ）→（ハ）→（イ）

<details>
<summary>解答・解説</summary>

**正答：4**

（イ） 最後の手順で、定めた標準どおりに管理した結果として処置の結果をチェックし、効果を確かめる。 ✅

（ロ） 最初の手順で、管理の対象とする品質特性を決める。これを決めないと標準の設定に進めない。 ✅

（ハ） 三番目の手順で、品質標準を達成するための作業標準を決める。品質標準の後に定める。 ✅

（ニ） 二番目の手順で、品質特性に対して目標となる品質標準を決める。作業標準より先に定める。 ✅

1. 作業標準を先に決める順で、品質特性が最初でないため適当でない。 ❌
2. 品質標準が最初で、品質特性が作業標準より後の順となり適当でない。 ❌
3. 品質標準が品質特性より先となる順で適当でない。 ❌
4. 品質特性、品質標準、作業標準を決めた後、処置の結果をチェックする順が正しい。 ✅

<ExamPoint>品質管理は特性と標準を決めてから作業標準を定め、最後に結果を確認する流れ</ExamPoint>

</details>

## 問題 No.28

<details>
<summary>解答・解説</summary>

**正答：4**

1. 呼び強度 40 は普通コンクリートの範囲で、高強度コンクリートの区分ではない。 ❌
2. 呼び強度 55・60 の高強度コンクリートはスランプでなくスランプフローが規定される。 ❌

4. 購入者は単位セメント量の下限値または上限値を指定できる。記述のとおり。 ✅
