## 問題 No.1

公共測量に使用される各種測量機に関する次の記述のうち**適当でないもの**はどれか。

1. トータルステーション（TS）は，従来のセオドライトと光波測距儀を一体化したもので，測角と測距を同時に行うことができる。

2. 光波測距儀による距離測定には，光波を発信・受信する光波測距儀と光波を反射する反射プリズムとが用いられる。

3. GPS 測量機は，人工衛星から発せられる測位等の情報を持つ電波を受信する測量機で，受信点の座標や受信点間の相対的な位置関係を求めることができる。

4. 電子レベルは，観測者に代わってディテクター・ダイオード・アレーがバーコードを識別し，そのパターンを自動的に解読することにより標尺の読定値が得られるが，機械と標尺間の距離測定はできない。

<details>
<summary>解答・解説</summary>

**正答：4**

1. TSはセオドライトと光波測距儀を一体化した測量機で、角度と距離を同時に観測できる。記述のとおり適当。 ✅
2. 光波測距儀は、測距儀本体から出した光波を反射プリズムで返し、その往復時間や位相差から距離を求める。記述は適当。 ✅
3. GPS測量機は衛星からの電波を受信し、受信点の座標や点間の相対位置を求める。記述は適当。 ✅
4. 電子レベルは標尺のバーコードを自動で読み取るだけでなく、機械と標尺間の距離も測定できる。「距離測定はできない」は誤り。 ❌

<ExamPoint>電子レベルは読定値だけでなく視準距離も測れる点の見落とし</ExamPoint>

</details>

## 問題 No.2

水準測量に用いるレベルに関する次の記述のうち**適当でないもの**はどれか。

1. 自動レベルは，円形水準器及び主水準器軸と視準線との平行性の点検調整を行う。

2. 電子レベルは，水準測量作業用電卓（データコレクタ），パソコン等に観測データ（ディジタルデータ）を自動入力できるため汎用性が高い。

3. 自動レベルは，望遠鏡の多少の傾きにかかわらず，常に自動的に視準線を水平にできる。

4. 電子レベルは，円形水準器及び視準線の点検調整並びにコンペンセータ（補正装置）の点検を行う。

<details>
<summary>解答・解説</summary>

**正答：1**

1. 自動レベルには主水準器がなく、点検調整は円形水準器の調整と視準線の点検調整、コンペンセータの点検である。「主水準器軸と視準線との平行性」は誤り。 ❌
2. 電子レベルは観測データをデータコレクタやパソコンへ自動入力でき、汎用性が高い。記述は適当。 ✅
3. 自動レベルは、望遠鏡の多少の傾きがあってもコンペンセータにより視準線を自動的に水平にする。記述は適当。 ✅
4. 電子レベルも円形水準器・視準線の点検調整とコンペンセータの点検を行う。記述は適当。 ✅

<ExamPoint>自動レベルには主水準器がないこと</ExamPoint>

</details>

## 問題 No.3

公共工事標準請負契約約款におけるかし担保に関する次の記述のうち**誤っているもの**はどれか。

1. 発注者は，工事目的物にかしがあるときは，契約書に定められたかし担保期間に応じて，請負者に対して修補を請求することができる。

2. 発注者の支給材料の性質又は監督員の指図により生じた場合の工事目的物のかしは，原則として，発注者は請負者に修補又は損害賠償の請求はできない。

3. 発注者が工事目的物の引渡しの際にかしがあることを知った場合，その旨を直ちに請負者に通知しなければ，修補又は損害賠償の請求はできない。

4. かしの重要度にかかわらず，その修補に過分の費用を要するときは，発注者は請負者に修補を請求することができない。

<details>
<summary>解答・解説</summary>

**正答：4**

1. 発注者は、工事目的物にかしがあるときは、契約で定めたかし担保期間内に請負者へ修補を請求できる。記述は正しい。 ✅
2. かしが発注者の支給材料の性質や監督員の指図によって生じたときは、請負者に修補や損害賠償を請求できない。ただし、請負者が不適当と知りながら通知しなかった場合は除く。記述は正しい。 ✅
3. 発注者は、引渡しの際にかしを知ったときは、直ちに請負者へ通知しなければ、修補や損害賠償を請求できない。記述は正しい。 ✅
4. 修補を請求できないのは、かしが重要でなく、かつ修補に過分の費用を要するときである。重要度にかかわらずとする点が誤り。 ❌

※出題後の改正: 公共工事標準請負契約約款は民法改正に合わせて改められ、「かし担保」は「契約不適合責任」となり、追完の請求を制限するのは「過分の費用を要するとき」のみとなった（国土交通省・中央建設業審議会資料）。

<ExamPoint>修補請求の制限は「重要でない」かつ「過分の費用」の両方が要件</ExamPoint>

</details>

## 問題 No.4

公共工事標準請負契約約款において，請負者が設計図書と工事現場の不一致などの事実を発見した場合に，監督員に書面により通知して，確認を求めなければならない事項として，次のうちこれに**該当しないもの**はどれか。

1. 工事の施工にあたり，当初計画の施工機械を現場の土質に見合った機械に変更するとき

2. 工事の施工にあたり，設計図書の表示が明確でなく，どのように施工してよいか判断がつかないとき

3. 工事の施工にあたり，工事現場の形状，地質，湧水等の状態が，設計図書に示された施工条件と実際の現場条件が一致しないとき

4. 工事の施工にあたり，図面と仕様書が一致しないときで，どちらに従って施工してよいかわからないとき

<details>
<summary>解答・解説</summary>

**正答：1**

1. 施工機械を土質に合わせて変更するのは請負者の施工方法の判断事項であり、設計図書との不一致の確認事項ではない。通知・確認を求める事項に該当しない。 ❌
2. 設計図書の表示が明確でないときは、監督員に書面で通知し確認を求める事項に該当する。 ✅
3. 現場の形状・地質・湧水等の状態が設計図書の施工条件と一致しないときは、該当する。 ✅
4. 図面と仕様書が一致しないときも、設計図書間の不一致として該当する。 ✅

<ExamPoint>施工機械の選定は請負者の裁量で条件変更の通知事項ではない</ExamPoint>

</details>

## 問題 No.5

工事用電力設備に関する次の記述のうち**適当なもの**はどれか。

1. 電力会社から受電する電圧が6,000V を超える場合の電気工作物の工事にあたっては，労働安全衛生法による電気主任技術者の選任が必要とされる。

2. 契約電力を，負荷設備と受電設備の値のうち，いずれか大きいものとすると経済的である。

3. 出力1,000kW 以上の発電機を工事現場で使用するときは，使用場所管内の労働基準監督署に，電気主任技術者の選任届等の所定の手続きを行う。

4. 工事現場に設置する自家用受変電設備の位置は，一般に，できるだけ負荷の中心の近くを選ぶ。

<details>
<summary>解答・解説</summary>

**正答：4**

1. 受電電圧が6,000Vを超える電気工作物の主任技術者の選任は、電気事業法に基づくものである。労働安全衛生法とする点が誤り。 ❌
2. 契約電力は負荷設備と受電設備のうち小さい方を基準にすると経済的である。大きい方とする記述は誤り。 ❌
3. 出力1,000kW以上の発電機は電気事業法の手続き（主任技術者の選任等）が必要で、届出先も労働基準監督署ではない。誤り。 ❌
4. 自家用受変電設備は、電力損失や電圧降下を抑えるため、できるだけ負荷の中心近くに設置する。記述は適当。 ✅

<ExamPoint>電気主任技術者は電気事業法、契約電力は小さい方を基準</ExamPoint>

</details>

## 問題 No.6

施工計画にあたっての事前調査には，契約条件にかかわる事項と現場条件にかかわる事項があるが，そのうちの契約条件についての主な事前調査事項として，(イ)〜(ニ)のうち**適当なものをすべて選んだ組合せ**は，次のうちどれか。

- (イ) 資材，労働費などの変動に基づく請負代金
- (ロ) 材料の供給源と価格及び運搬路
- (ハ) 工事材料の品質や検査の方法
- (ニ) 施工法，仮設規模，施工機械の選択

1. (イ) (ニ)

2. (イ) (ハ)

3. (イ) (ロ) (ハ)

4. (ロ) (ハ)

<details>
<summary>解答・解説</summary>

**正答：2**

1. (イ)は契約条件だが、(ニ)の施工法・仮設規模・施工機械の選択は施工計画で検討する事項で契約条件ではない。 ❌
2. (イ)請負代金の変動条件と(ハ)工事材料の品質・検査方法は、いずれも契約条件の事前調査事項である。 ✅
3. (ロ)材料の供給源・価格・運搬路は現場条件の調査事項であり、契約条件ではない。 ❌
4. (ロ)は現場条件の調査事項で、契約条件の組合せに含まれない。(イ)も落ちている。 ❌

<ExamPoint>契約条件の調査（代金・品質・検査）と現場条件・施工計画事項の区別</ExamPoint>

</details>

## 問題 No.7

施工計画の立案に関する留意点として次の記述のうち**適当でないもの**はどれか。

1. 現場で組み合わせて使用する機械を選択する場合は，最も経費がかかる機械の施工能力を他の機械の施工能力と同等か幾分低くなるようにする。

2. 基本方針や施工計画は，現地事前調査を行なって工事現場の制約条件を理解している現場担当者だけの経験と技術力で定める。

3. 設計図書には仮設工事の施工数量が示されない場合が多いので，請負者は設計図をもとに施工方法を考慮して施工に必要な数量を算出する必要がある。

4. 施工機械を工期を通じて同じ台数で計画すると，稼働日数の少ない遊休状況が発生する場合がある。

<details>
<summary>解答・解説</summary>

**正答：2**

1. 組合せ機械では、最も経費のかかる主機械の稼働を落とさないよう、他の機械の能力を主機械と同等か幾分高めにそろえる。この考え方に沿うため適当である。 ✅
2. 基本方針や施工計画は、現場担当者だけの経験と技術力で定めてはならない。会社の組織を活用し、社内の経験と技術力を結集して定める。「だけで」とする点が誤り。 ❌
3. 仮設工事の数量は設計図書に示されないことが多い。請負者は設計図をもとに施工方法を考慮して必要な数量を算出する。記述は適当である。 ✅
4. 工期を通じて機械を同じ台数で計画すると、稼働日数の少ない遊休状況が生じることがある。記述は適当である。 ✅

<ExamPoint>施工計画は現場担当者だけでなく組織的に立案する</ExamPoint>

</details>

## 問題 No.8

仮設備に関する次の記述のうち**適当なもの**はどれか。

1. 仮設備は，発注者が指定する指定仮設と施工者の判断に任せる任意仮設があるが，特別な場合を除いては施工者の企業努力や技術力が発揮できる任意仮設とされることが多い。

2. 仮設構造物は，構造計算を省略する場合が多いが，構造計算を行う場合は，使用目的や使用期間，重要度等の諸条件に係らず，永久構造物と同様の安全率を採用する。

3. 仮設備計画の立案においては，仮設備の種類，諸元，数量，配置計画を検討することが必要で，それらの維持や撤去等に関しては施工段階で対応するため，計画段階では特に考慮しない。

4. 仮設備とは，工事用道路，コンクリート打設設備，山留め，締切りなど工事の施工に直接関係するものをいい，工事の施工に直接関係しない作業員の宿泊設備や倉庫などは含まれない。

<details>
<summary>解答・解説</summary>

**正答：1**

1. 仮設備は指定仮設と任意仮設があり、施工者の技術力を生かせる任意仮設とされることが多い。記述は適当。 ✅
2. 仮設構造物は使用目的・期間・重要度に応じて安全率を選び、永久構造物と同じにするとは限らない。誤り。 ❌
3. 仮設備計画では、設置だけでなく維持や撤去も計画段階で考慮する必要がある。誤り。 ❌
4. 仮設備には、直接仮設（工事用道路等）のほか、作業員宿舎や倉庫などの間接仮設も含まれる。誤り。 ❌

<ExamPoint>指定仮設と任意仮設、仮設の安全率は条件で変える</ExamPoint>

</details>

## 問題 No.9

下図は土木工事の請負契約の流れを示したものである。この請負契約における，建設業法に定められている施工体制台帳等に関する次の記述のうち**適当でないもの**はどれか。

ただし，A 社から B 社への契約額は 3,000万円以上とする。

<ArticleImage src="/posts/civil-construction-1/primary-h18-b/img/q09-fig.webp" alt="発注者（国・地方公共団体・民間）から特定建設業者A社（元請），B社（1次下請），C社（2次下請），D社（3次下請）へ請負契約①〜④でつながる契約の流れ図" width={1947} height={411} />

1. A 社は B 社に「施工体制台帳及び施工体系図作成工事である」旨を通知するとともに，当該事項を記載した書面を工事現場の見やすいところに掲げる。

2. B 社は C 社に対して「その請け負った工事を他の建設工事を営む者に請け負わせたときは再下請負通知書を提出しなければならない」旨を通知し，B 社は A 社に対して再下請負通知書を提出する。

3. C 社は，作成した再下請負通知書を，必ず B 社を経由して A 社に提出するものであり，直接 A 社に提出してはならない。

4. D 社のように，その請け負った建設工事を他の建設業者に請け負わせていないときは，再下請負通知書の作成は生じない。

<details>
<summary>解答・解説</summary>

**正答：3**

1. 元請（A社）は下請（B社）へ、施工体制台帳及び施工体系図の作成工事である旨を通知し、その旨を記載した書面を工事現場の見やすい場所に掲げる。記述は適当である。 ✅
2. 下請（B社）は、さらに請け負わせた相手（C社）へ再下請負通知書の提出が必要な旨を通知し、B社自身もA社へ再下請負通知書を提出する。記述は適当である。 ✅
3. 再下請負通知書は元請へ提出するもので、上位の下請を経由して出すことも認められるが、必ず経由しなければならず直接出してはならないとはされない。断定した記述が誤り。 ❌
4. D社のように、請け負った工事を他の建設業者に請け負わせていなければ、再下請負通知書の作成は生じない。記述は適当である。 ✅

※出題後の改正: 施工体制台帳の作成を要する下請契約の総額の基準は5,000万円（建築一式は8,000万円）に引き上げられた（建設業法施行令第7条の4、令和7年2月1日施行）。なお公共工事では、平成27年4月から下請契約の金額にかかわらず作成が必要になっている（入札契約適正化法）。

<ExamPoint>再下請負通知書は「経由のみ・直接不可」と断定した記述が誤り</ExamPoint>

</details>

## 問題 No.10

品質管理に関する次の記述のうち**適当でないもの**はどれか。

1. 品質管理の目的は，契約約款，設計図書等に示された規格を十分満足するような構造物を最も経済的に施工することである。

2. 品質管理計画を作成するためには，共通仕様書・特記仕様書・図面等や打合せ等により発注者の要求品質を正しく把握する必要がある。

3. 品質管理の第一の目的は，品質に不良が発生しないように，材料及び工程を管理することではなく，不良箇所の発見である。

4. 工事中の品質保証活動は，品質に焦点をあわせて要求品質を施工段階でつくり込み達成するために，改善提案と条件変化への対応を行うことである。

<details>
<summary>解答・解説</summary>

**正答：3**

1. 品質管理の目的は、規格を満足する構造物を最も経済的に施工することである。記述は適当。 ✅
2. 品質管理計画は、共通仕様書・特記仕様書・図面等で発注者の要求品質を把握して作成する。記述は適当。 ✅
3. 品質管理の第一の目的は、不良を発見することではなく、不良が発生しないよう材料と工程を管理することである。記述は逆で誤り。 ❌
4. 品質保証活動は、要求品質を施工段階でつくり込み、改善提案や条件変化への対応を行うものである。記述は適当。 ✅

<ExamPoint>品質管理は不良の発見でなく不良を作らない工程管理</ExamPoint>

</details>

3. 分別解体を行うこととなっている工事については，工事に着手する日の7日前までに，工事着手の時期及び工程の概要，分別解体の計画などの事項について，受注者が都道府県知事に届け出なければならない。

4. 「特定建設資材」とは，再資源化が特に必要なコンクリート，コンクリート及び鉄から成る建設資材，木材及び建設発生土の4品目である。

<details>
<summary>解答・解説</summary>

**正答：1**

1. 再資源化は、建設資材廃棄物を資材・原材料として再利用できるようにすること、又は熱を得るための利用ができる状態にすることである。記述は正しい。 ✅
2. 建築物の解体工事で分別解体が必要な規模は、床面積80平方メートル以上である。100平方メートルは誤り。 ❌
3. 分別解体の届出は、工事着手の7日前までに発注者（又は自主施工者）が都道府県知事に行う。受注者が届け出るは誤り。 ❌
4. 特定建設資材は、コンクリート、コンクリート及び鉄から成る資材、木材、アスファルト・コンクリートの4品目で、建設発生土は含まれない。 ❌

</details>

## 問題 No.35

産業廃棄物処理におけるマニフェスト制度に関する次の記述のうち**誤っているもの**はどれか。

1. 排出事業者は，産業廃棄物の処理を委託する際に，収集運搬業者（処分のみを委託する場合は処分業者）に対してマニフェストを交付し，処理修了後処理業者からその旨必要な事項を記載した写しを受け取ることにより，適正に処理されたか確認しなければならない。

2. 排出事業者が古紙や鉄くずなど専ら再生利用の目的となる産業廃棄物の処理を行う業者に当該産業廃棄物のその処理を委託する場合は，マニフェストの交付を要しない。

3. マニフェストの交付は，排出事業者となる元請負業者が下請負業者に解体工事などの一部の工事を請け負わせて施工する場合には，その下請負業者が行うものとする。

4. 排出事業者は，所定の期間内に最終処分業者からの最終処分終了の報告がない場合には，処理状況を把握し適切な処置を講ずるとともに，その旨を関係都道府県知事に報告しなければならない。

<details>
<summary>解答・解説</summary>

**正答：3**

1. 排出事業者は、委託時に運搬業者（処分のみなら処分業者）へマニフェストを交付し、処理終了後に写しを受け取って確認する。記述は正しい。 ✅
2. 専ら再生利用の目的となる産業廃棄物（古紙・鉄くず等）の処理を委託する場合は、マニフェストの交付を要しない。記述は正しい。 ✅
3. 排出事業者は元請業者であり、下請が施工する場合でもマニフェストは元請が交付する。下請が行うとする点が誤り。 ❌
4. 所定の期間内に最終処分終了の報告がないときは、処理状況を把握して適切な措置を講じ、都道府県知事に報告する。記述は正しい。 ✅

</details>
