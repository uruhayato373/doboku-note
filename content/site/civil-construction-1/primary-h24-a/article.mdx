## 問題 No.1

土の原位置試験に関する次の記述のうち，**適当なもの**はどれか。

1. 現場密度を測定する方法には，ブロックサンプリング，砂置換法，RI 計器による方法があり，現場含水量と同時に測定できる方法は砂置換法である。

2. トラフィカビリティは，コーンペネトロメータの貫入抵抗から判定されるもので，原位置又は室内における試験で計測する。

3. ベーン試験は，主として硬い砂地盤のせん断強さを求めるもので，ボーリング孔を用いて行う。

4. 現場透水試験は，軟弱地盤の土の強度を評価したり，掘削に伴う湧水量や排水工法を検討するために行われるものである。

<details>
<summary>解答・解説</summary>

**正答：2**

1. 誤り。現場密度と現場含水量を同時に測定できるのは RI 計器による方法で、砂置換法では含水量は採取した試料から別に求める。 ❌
2. 記述のとおり。トラフィカビリティはコーンペネトロメータの貫入抵抗（コーン指数）で判定し、原位置でも室内（供試体）でも試験できる。 ✅
3. 誤り。ベーン試験は軟弱な粘性土のせん断強さを求める試験で、硬い砂地盤には適さない。 ❌
4. 誤り。現場透水試験は透水係数を求めて湧水量や排水工法を検討する試験で、軟弱地盤の強度評価の試験ではない。 ❌

<ExamPoint>現場密度と含水量を同時に測れる方法・ベーン試験の適用地盤の取り違え</ExamPoint>

</details>

## 問題 No.2

切土の法面保護工に関する次の記述のうち，**適当でないもの**はどれか。

1. 湧水量が多い法面では，法面保護工として一般に植生工を採用する。

2. 植物の生育に適した法面勾配は，一般に軟岩や粘性土では1:1.0〜1.2より緩い場合，砂や砂質土では1:1.5より緩い場合である。

3. 寒冷地のシルトの多い法面では，凍上や凍結融解作用によって植生がはく離したり滑落するおそれがある場合は，法面勾配を緩くすることや法面排水を行うことが望ましい。

4. 土質や湧水の状況が一様でない法面については，排水工などの地山の処理を行った上で，景観に配慮してなるべく類似した工法を採用することが望ましい。

<details>
<summary>解答・解説</summary>

**正答：1**

1. 誤り。湧水量が多い法面は植生が定着しにくく、排水工や構造物による保護工で湧水処理を先に行う。植生工を一般に採用するとはいえない。 ❌
2. 記述のとおり。植物の生育に適した勾配は軟岩・粘性土で 1:1.0〜1.2 より緩い場合、砂・砂質土で 1:1.5 より緩い場合とされる。 ✅
3. 記述のとおり。凍上・凍結融解で植生がはく離するおそれがあるときは、勾配を緩くし法面排水を行うのが望ましい。 ✅
4. 記述のとおり。土質や湧水が一様でない法面は、排水工など地山処理を行ったうえで景観に配慮し、類似した工法を採用する。 ✅

<ExamPoint>湧水の多い法面に植生工を一般採用してよいとする誤り</ExamPoint>

</details>

## 問題 No.3

盛土における基礎地盤の処理に関する次の記述のうち，**適当でないもの**はどれか。

1. 基礎地盤に極端な凹凸や段差があり盛土高さの低い場合は，均一な盛土になるように段差などの処理を施すが，盛土高さが高い場合には盛土面に影響が小さいため段差処理は行わない。

2. 基礎地盤の準備排水は，盛土工で最も大切なものの1つであり，原地盤を自然排水可能な勾配に整形し素掘りの溝や暗渠などにより工事区域外に排水する。

3. 表層に軟弱層が存在している基礎地盤は，盛土基礎地盤に溝を掘って盛土の外への排水を行うことにより，盛土敷の乾燥をはかりトラフィカビリティが得られるようにする。

4. 基礎地盤の勾配が1:4程度より急な場合には，盛土との密着を確実にするために段切りを行うとともに敷均し厚を管理して十分な締固めを行うことが重要である。

<details>
<summary>解答・解説</summary>

**正答：1**

1. 誤り。基礎地盤の極端な凹凸や段差は、盛土高さの高低にかかわらず均一な盛土になるよう処理する。高い盛土なら処理不要とはいえない。 ❌
2. 記述のとおり。準備排水は盛土工で最も大切なものの1つで、自然排水可能な勾配に整形し、溝や暗渠で区域外へ排水する。 ✅
3. 記述のとおり。表層の軟弱層は溝を掘って排水し、盛土敷を乾燥させてトラフィカビリティを確保する。 ✅
4. 記述のとおり。基礎地盤の勾配が 1:4 程度より急な場合は、盛土との密着のため段切りを行い、敷均し厚を管理して十分締め固める。 ✅

<ExamPoint>盛土高さが高くても基礎地盤の段差処理は省略できない</ExamPoint>

</details>

<details>
<summary>解答・解説</summary>

3. 誤り。ローラの軌跡管理は走行回数（締固め回数）を管理する工法規定方式の管理技術で、品質規定方式ではない。 ❌
4. 記述のとおり。マシンガイダンスは3次元設計データと TS・GNSS の計測で施工精度を得るもので、丁張りなしで施工できる。 ✅

<ExamPoint>ローラ軌跡管理は工法規定方式であり品質規定方式ではない</ExamPoint>

## 問題 No.5

地盤の液状化の対策工法に関する次の記述のうち，**適当でないもの**はどれか。

1. サンドコンパクションパイル工法は，振動機を用いて地盤内に砂杭を造成して周辺地盤を締め固めることにより，地盤全体として液状化に対する抵抗を増大させるものである。

2. グラベルドレーン工法は，地盤に礫や人工材料を用いて壁状や円柱状のドレーンを設置し，地盤内の密度を増大させることにより液状化を防止するものである。

3. ディープウェル工法は，地盤の地下水をポンプで排水し地下水位を低下させることにより，液状化の発生する可能性を軽減するものである。

4. 深層混合処理工法は，地盤内に安定材をかくはん混合して化学的に改良し液状化に対する抵抗を増大させるものである。

<details>
<summary>解答・解説</summary>

**正答：2**

1. 記述のとおり。サンドコンパクションパイル工法は砂杭を造成して周辺地盤を締め固め、地盤全体の液状化抵抗を高める密度増大工法である。 ✅
2. 誤り。グラベルドレーン工法は礫等のドレーンで過剰間隙水圧を速やかに消散させて液状化を防ぐもので、密度増大が目的ではない。 ❌
3. 記述のとおり。ディープウェル工法は地下水位を低下させ、液状化の発生する可能性を軽減する。 ✅
4. 記述のとおり。深層混合処理工法は安定材をかくはん混合して化学的に固結させ、液状化抵抗を増大させる固結工法である。 ✅

2. コンクリートの表面がすり減り作用を受ける場合は，そうでない場合と比較して，細骨材に含まれる微粒分量の最大値を小さくする。

<details>
<summary>解答・解説</summary>

**正答：4**

## 問題 No.7

コンクリートの配合設計に関する次の記述のうち，**適当なもの**はどれか。

1. コンクリートの設計基準強度は，配合強度を下回る確率が5％以下になるよう定めるとよい。

2. 水セメント比は，コンクリートに要求される強度，耐久性，水密性，ひび割れ抵抗性及び鋼材を保護する性能を考慮して，これらから定まる値のうち最大の値を設定するとよい。

3. エントレインドエアは，ワーカビリティの改善にも寄与し，空気量が増すほどコンクリート強度は大きくなるので，できるだけ大きく設定するとよい。

4. 所要の圧縮強度を満足するよう配合設計する場合は，セメント水比と圧縮強度との関係がある程度の範囲内で直線的になることを利用するとよい。

<details>
<summary>解答・解説</summary>

**正答：4**

1. 誤り。配合強度が設計基準強度を下回る確率を 5％以下とするのであり、設計基準強度と配合強度の関係が逆である。 ❌
2. 誤り。水セメント比は強度・耐久性・水密性などから定まる値のうち最小の値を設定する。最大値ではない。 ❌
3. 誤り。空気量は多いほど強度が低下するため、できるだけ大きくするのは不適当で、一般に 4〜7％程度とする。 ❌
4. 記述のとおり。セメント水比と圧縮強度はある範囲で直線関係にあり、この関係から所要強度を得る配合を定める。 ✅

<ExamPoint>設計基準強度と配合強度の関係・水セメント比は最小値を採用</ExamPoint>

</details>

## 問題 No.8

1. 骨材に付着している粘土の量が多い場合には，コンクリートの単位水量が増加し乾燥収縮は大きくなる。

3. 同一単位水量の AE コンクリートでは，空気量が多いほど乾燥収縮は小さい。

**正答：3**

2. 記述のとおり。粗骨材の最大寸法が大きいほど必要な単位水量は少なく、乾燥収縮を小さくできる。 ✅
3. 誤り。単位水量が同一なら空気量は乾燥収縮にほとんど影響せず、空気量が多いほど小さくなるとはいえない。 ❌

## 問題 No.11

型枠に作用するコンクリートの側圧に関する次の記述のうち，**適当なもの**はどれか。

1. スランプが同じコンクリートの場合，コンクリートの温度が低くなるほど，型枠に作用する側圧は大きくなる。

2. スランプが同じコンクリートの場合，コンクリートの圧縮強度が小さいほど，型枠に作用する側圧は大きくなる。

3. スランプが同じコンクリートの場合，打上り速度を大きくするほど，型枠に作用する側圧は小さくなる。

4. 施工条件が同じ条件の場合，コンクリートのスランプを小さくするほど，型枠に作用する側圧は大きくなる。

<details>
<summary>解答・解説</summary>

**正答：1**

1. 記述のとおり。コンクリート温度が低いと凝結が遅れ、液状に近い期間が長くなるため側圧は大きくなる。 ✅
2. 誤り。側圧はスランプ・温度・打上り速度などで決まり、圧縮強度が小さいほど大きくなるとはいえない。 ❌
3. 誤り。打上り速度を大きくするほど、液圧に近い状態の範囲が広がり側圧は大きくなる。 ❌

2. 請負契約の当事者は，請負契約の内容で工事内容など契約書に記載されている事項を変更するときは，その変更の内容を書面に記載し，署名又は記名押印をして相互に交付しなければならない。

3. 注文者は，建設工事の請負契約を締結する以前，又は入札を行う以前に，工事内容，請負代金の額，工事着手の時期及び工事完成の時期等についてできる限り具体的な内容を提示しなければならない。

4. 注文者は，請負契約を締結後，自己の取引上の地位を不当に利用して，その注文した建設工事に使用する資材若しくは機械器具又はこれらの購入先を指定し，これらを請負人に購入させてその利益を害してはならない。

<summary>解答・解説</summary>

**正答：3**

1. 正しい。注文者は、地位を不当に利用して、通常必要と認められる原価に満たない請負代金で契約を締結してはならない。 ✅
2. 正しい。契約内容の変更は、その内容を書面に記載し、署名又は記名押印して相互に交付しなければならない。 ✅
3. 誤り。契約締結前・入札前に注文者が具体的に提示するのは、工事内容や着手・完成時期などで、請負代金の額は含まれない。 ❌
4. 正しい。契約締結後に、地位を不当に利用して資材や機械器具・購入先を指定し購入させ、請負人の利益を害してはならない。 ✅

2. 正しい。特定建設業者は、下請負人が施工に関する法令に違反しないよう指導に努める。 ✅

4. 正しい。元請負人は、下請負人から完成の通知を受けた日から20日以内で、できる限り短い期間内に完成確認の検査を完了しなければならない。 ✅

## 問題 No.58

2. 床下がコンクリートで覆われた構造で最下階の居室の床が木造である場合は，床の高さを45 cm以上とする規定が適用される。
