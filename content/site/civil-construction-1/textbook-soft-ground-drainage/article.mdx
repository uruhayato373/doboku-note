1級土木施工管理技士の試験では、**軟弱地盤対策工法の原理別分類**（圧密・排水／締固め／固結／荷重軽減／構造物・補強）と**代表工法名の組合せ**、**液状化対策の考え方**、および**排水工法の選定**（重力排水・強制排水・電気浸透と透水性の関係）が頻出。

## 軟弱地盤の性質と施工の考え方

軟弱地盤は、泥炭や有機質土からなる含水量の極めて大きい地盤と、緩い状態にある砂質土からなる地盤の2種類に大別される。軟弱地盤の上に盛土等の構造物を築造すると、地盤の安定性不足や過大な沈下によって問題を起こすことが多い。施工上も、地盤の軟弱さによるトラフィカビリティ不足などで困難な問題が生じやすい。

軟弱地盤は複雑な性質を持ち、限られた土質調査だけで地盤状況を完全に把握することは難しい。計算による数値的判断のみに頼らず、周辺の施工実績や経験を参考にすることも重要であり、施工中も地盤の状況を継続的に観測し、必要に応じて計画を見直す姿勢が求められる。盛土の基礎地盤としての軟弱地盤の判定目安（N値・コーン指数・一軸圧縮強度）は[盛土](/docs/civil-construction-1-textbook-embankment)の記事で解説している。

## 地下水位と間隙水圧から地盤の強さを読む

軟弱地盤の沈下、地震時の液状化、降雨後ののり面の崩れは、別々の項目として覚えてしまいがちである。ところが水位計や間隙水圧計の値を前にすると、三つに共通する問いが浮かぶ。土の粒子どうしが、どれだけの力で押し合っているかという問いで、それを左右するのが水の圧力である。

地中のある深さには、その上にある土と水の重さが**全応力** $\sigma$ としてかかる。この荷重は、土粒子の骨格が受け持つ分と、粒子のすき間の水が受け持つ分に分けて考える。骨格が受け持つ分を**有効応力** $\sigma'$、水が受け持つ分を**間隙水圧** $u$ と呼び、次の関係にある。

$$
\sigma = \sigma' + u \;\;\Longrightarrow\;\; \sigma' = \sigma - u
$$

下の図は、地下水面が浅い地盤の深さ方向の分布である。地下水面より上では水圧が 0 なので、有効応力は全応力と等しい。地下水面より下では、水圧が水の単位体積重量 $\gamma_w$（約 9.8 kN/m³）に比例して深さとともに増え、その分だけ有効応力が全応力より小さくなる。

有効応力が要になるのは、土のせん断強さを決めるのが全応力ではなく有効応力だからである。モール・クーロンの破壊基準では、せん断強さ $\tau_f$ を次のように表す。

$$
\tau_f = c' + \sigma' \tan\phi'
$$

$c'$ は粘着力、$\phi'$ は内部摩擦角で、どちらも有効応力で整理した値である。同じ荷重がかかっていても、水圧が上がって $\sigma'$ が減れば $\tau_f$ は下がり、水圧が抜けて $\sigma'$ が増せば上がる。

水位と水圧の動きを場面ごとに並べると、軟弱地盤の工法も液状化も同じ式で読める。

| 場面 | 水圧と有効応力の動き |
|:--|:--|
| 地下水位を下げる | 間隙水圧が減り、有効応力が増す。粘土は圧密して沈み、強度も増す |
| 粘土の上へ盛土を急いで載せる | 水が抜けず間隙水圧が過剰に残る。有効応力が増えず、強度が伸びない |
| 地震で揺すられる緩い飽和砂 | 間隙水圧が急に上がり、有効応力がほぼ 0 になる |
| 雨がしみ込んだ斜面 | 水位が上がり間隙水圧が増す。有効応力が減ってすべりやすくなる |

1行目は地下水位低下工法の原理である。水位が下がると、それまで浮力として打ち消されていた分が有効応力となって下層の軟弱層に載り、圧密が進む。

[令和元年度 問題A](/exam/civil-construction-1/primary/r01-a)と[平成27年度 問題A](/exam/civil-construction-1/primary/h27-a)の問題 No.5 は、この説明を軟弱地盤対策工法の選択肢の一つとして出している。

2行目は、後述の緩速載荷工法やバーチカルドレーン工法のねらいにあたる。盛土を載せた直後の粘土は、荷重の大半を過剰な間隙水圧で受けており、水が抜けるにつれて有効応力が増え、強度も伸びていく。載荷の速さを抑えるか排水距離を短くして、水が抜ける時間を確保する工夫が、これらの工法である。

液状化は、3行目で $u$ が全応力 $\sigma$ に近づいた極端な場合である。砂は粘着力 $c'$ がほぼ 0 なので、$\sigma'$ がなくなればせん断強さ $\tau_f$ もほぼ失われ、地盤が液体のように振る舞う。粘土のように粘着力で踏みとどまれないぶん、緩い砂では有効応力の低下がそのまま強度の消失になる。

監督や検査の場面では、地下水位、間隙水圧計、沈下量の三つの値を並べて読む。載荷を進めたのに水圧が消散していない、水位を下げたのに間隙水圧が下がっていない、といった組合せは、有効応力が見込みどおりに増えていない合図である。答案には「水位が下がる、水圧が減る、有効応力が増える、圧密が進む」と原因から結果まで一続きで書くと、工法の原理を押さえていることが伝わる。

## 地下水の揚水が地盤沈下を起こすしくみ

地盤沈下という言葉は、盛土の下の圧密沈下から地震後の沈下まで幅広く使われる。原因を切り分けるには、まず沈み方を見るのが早い。

| 沈み方 | まず疑う原因 |
|:--|:--|
| 広い範囲が年単位でゆっくり沈む | 地下水の揚水による水位低下 |
| 新しい盛土や構造物の周りだけが沈む | 載荷による軟弱粘土の圧密 |
| 地震の直後に低地の一部が急に沈む | 液状化 |
| 掘削や排水をした現場の周辺が沈む | 水位低下と地盤の緩み |

環境省の概況は、地盤沈下の多くを、地下水の過剰な採取で水位が下がり、粘土層が収縮するために生じる現象と整理している。この機構は、水の動きを順にたどると分かりやすい。揚水量が雨水や河川水による涵養量を上回ると、砂れき層などの帯水層の水位が下がる。

すると、帯水層にはさまれた粘土層の間隙水が帯水層へ押し出される。前の節の式で見れば、粘土層の $u$ が減って $\sigma'$ が増えたことになり、粘土層は圧密して厚さを縮める。縮んだぶんが、そのまま地表の沈下量になる。

揚水をやめて水位が戻っても、地盤は元の高さには戻らない。環境省は、一度沈下した地盤はもとに戻らず、沈下量が年々積算される点を地盤沈下の特徴に挙げている。年間の沈下量がわずかでも、長い目で見れば構造物の損壊や、洪水時の浸水の増大を招くおそれがある。

その典型が東京の江東地区である。環境省の令和6年度の概況では、東京都の関東平野南部で累計沈下量が最大の水準点は江東区南砂二丁目で、大正7年から令和6年までに 449.67cm（約 4.5 m）に達している。沈下が認められた地域のうちゼロメートル地帯にあたる面積は、東京都で 124.3km² である。

江東地区では、大正の初めから沈下が注目されていた。戦時中は揚水量が減って沈下が一時止まったが、昭和25年ごろから経済の復興とともに再び激しくなり、昭和40年代には各地で年間 20cm を超える沈下が記録された。

こうした経緯から、昭和31年に工業用水法が、昭和37年に建築物用地下水の採取の規制に関する法律（ビル用水法）が制定された。どちらも政令で指定した地域の井戸を、ストレーナーの位置と揚水機の吐出口の断面積を基準にして許可制とする。対象は、前者が工業用の地下水、後者が冷房設備や水洗便所など建築物の用に供する地下水である。

ビル用水法の指定地域は、沈下によって高潮や出水などの災害が生じるおそれのある地域である。沈下は戻らないので、浸水を防ぐ備えも長く必要になる。地方公共団体も条例や要綱で規制しており、令和7年3月現在で都道府県が31件、市区町村が370件ある。こうした規制の結果、長期的には地盤沈下は沈静化の傾向にある。

工事で地下水を汲み上げる場面でも、同じ機構が働く。揚水を伴う掘削排水を計画するときは、周辺に沈下しやすい粘土層があるか、揚水する帯水層の水位を観測できるかを、設計の段階で確かめる。排水に条例の規制がかかるかどうかは自治体によって異なるので、許可や届出の要否も早めに確認する。

<Callout type="warn" title="水位を下げる操作は効果と副作用が対になる">
地下水位を下げると、地下水位低下工法のように圧密を進めて強度を増やせ、液状化の発生を防ぐ対策にもなる。同じ操作が、周囲の粘土層を圧密させ、近くの井戸水の枯渇や広い範囲の沈下を招くこともある。効果を狙う範囲と、影響が及ぶ範囲を分けて確かめる。
</Callout>

## 液状化とその対策

<Callout type="warn" title="試験頻出：液状化対策の5つの視点">
液状化対策は、①過剰間隙水圧の発生を防ぐ（締固め・置換・地下水位低下）、②発生した過剰間隙水圧を速やかに消散させる（ドレーン）、③砂粒骨格のずれ変位を防ぐ（薬液注入等の固化）、④地盤の変形を抑制する（遮水壁等）、⑤液状化層に支持力を期待せず杭で上部構造を支える、の5方向に整理できる。
</Callout>

**液状化**とは、地震動等により地盤中の間隙水圧が上昇して有効応力が減少し、緩い砂質土がせん断強さを失う現象をいう。埋立地や新しく造成された地盤など、粒子の緩い飽和砂質地盤で発生しやすく、地盤の水平方向の流動や構造物の沈下・傾斜などの被害をもたらす。

### 液状化が地表と構造物に出す被害

液状化は、揺れの強さだけでなく土地の成り立ちでも出方が決まる。国土地理院の土地条件図は、被害を受けやすい代表的な地形として、盛土地・埋立地、旧河道、砂丘の縁辺部、砂丘間低地・砂州間低地を示している。

国土交通省の発生傾向図は、埋立地や干拓地、低地の盛土造成地、砂利などの採取跡の埋戻し地、谷埋め盛土造成地で、顕著な液状化被害が出ているとする。水田や池沼を埋めた宅地は低地の盛土造成地にあたるので、現場に入る前に旧版地図や土地条件図で土地の履歴を確かめ、柱状図で砂層の緩さと地下水位を見ておく。

揺れの後に最初に目に入るのは、割れ目や側溝から水と砂が噴き出す噴砂である。国土交通省は、液状化の被害の例として、噴水・噴砂、建物の沈下・傾斜、マンホールや埋設管の浮上り、地盤の流動、道路やライフライン施設の被害を挙げている。噴砂の跡は、その付近の砂が液状化した証拠であり、構造物を調べる範囲を決める手がかりになる。

構造物の被害は、液状化した地盤との重さの比べ合いと、基礎の支え方で分かれる。

- **直接基礎や摩擦杭の構造物** — 液状化した層が支持力や周面摩擦を受け持てなくなるため、沈んで傾く。
- **支持杭の構造物** — 杭先端が締まった層に届いているので、建物自体はほとんど動かない。周囲の地盤だけが下がり、出入口や配管の取合いに段差ができる。
- **地中の構造物・埋設管・マンホール** — 液状化した地盤より軽いと浮力を受け、浮き上がる。

ただし、液状化した地盤が低い方へ流れ出す（地盤の流動）と、支持杭にも横から力が加わるおそれがある。支持杭だから安全とは言い切れないので、護岸の近くなど地盤が動きやすい位置では、杭の水平力も確かめる。

点検や調書では、被害を「沈む・傾く・浮く・段差」のどれかに分け、基礎形式と地盤条件に結びつけて記録する。沈下・傾斜なら直接基礎の支持力、段差なら支持杭と周辺地盤の差、浮上りなら地中構造物の軽さが論点になり、杭で支える、地盤を改良する、浮上りを防ぐといった対策の選び方へ話がつながる。

[令和2年度 問題A](/exam/civil-construction-1/primary/r02-a)の問題 No.46 と[令和6年度 問題A](/exam/civil-construction-1/primary/r06-a)の問題 No.51 は、軟弱地盤や液状化のおそれがある地盤での上水道管の布設を出題している。管の被害を、継手の可とう性や地盤改良といった対策に結びつける設問である。

軟弱地盤対策工法は、原理によって圧密・排水工法、締固め工法、固結工法、荷重軽減工法、構造物・補強による対策に大別できる。1種類の工法のみで目的を達成できないことも多く、効果を十分に検討したうえで、必要に応じて複数の工法を組み合わせる。

### 圧密・排水工法

この系統の工法では、地盤中の水を排出して圧密を早め、地盤強度を高める。施工時のトラフィカビリティを改善するとともに、供用開始後に残る沈下を小さくすることがねらいである。

| 工法名 | 原理・特徴 |
|:--|:--|
| 表層排水工法 | トレンチで表面水を排除し表層の含水比を低下させ、トラフィカビリティを確保する |
| サンドマット工法 | 厚さ50〜120cm程度の砂を敷き均し、排水層と施工基盤を兼ねさせる |
| 緩速載荷工法 | 地盤が破壊しない範囲で時間をかけて盛土を立ち上げ、圧密を進行させる |
| 盛土載荷重工法 | 計画荷重と同等以上の荷重を先行載荷する（プレロード工法・サーチャージ工法） |
| バーチカルドレーン工法 | 鉛直の排水路（サンドドレーン・ペーパードレーン）で排水距離を短縮し圧密を促進する |
| 真空圧密工法 | ドレーン材と気密シートで地盤を覆い、真空ポンプで間隙水を強制的に排水する |
| 地下水位低下工法 | 地盤内の水位を下げて有効応力を増大させ、圧密沈下を促進する |
| グラベルドレーン工法 | 砂質土地盤に透水性の排水管（ドレーン）を設け、地震時の過剰間隙水圧を速やかに消散させて液状化を防止する |

**バーチカルドレーン工法**は、圧密に要する時間が排水距離の2乗に比例することを利用し、地中に鉛直の排水路を設けて排水距離を短縮する工法である。**サンドドレーン工法**は透水性の高い砂を用いた砂柱を打設し、**ペーパードレーン工法**（PVD工法）はペーパーやプラスチック製の人工ドレーン材を用いるため施工速度が速く経済的である。**盛土載荷重工法**のうち、将来の荷重と同等以上の荷重をあらかじめ載荷するものを**プレロード工法**、計画荷重を超える荷重を一時的に載荷し放置期間後に余分な分を取り除くものを**サーチャージ（余盛り）工法**という。

図で追うのは、地盤の水が排水路へ到達するまでの距離である。ドレーン自体が地盤を締め固めるのではなく、水の出口を増やして圧密を早める。実際の沈下予測では、地盤の圧密特性やドレーンの配置・排水条件も考慮する。

### 締固め工法

地盤に砂等を圧入する、または振動を与えることで締固め、液状化の防止・強度増加・沈下低減を図る工法である。振動を利用する振動締固め工法と、振動を用いない静的締固め工法に分類される。

| 工法名 | 原理・特徴 |
|:--|:--|
| サンドコンパクションパイル工法 | 振動・衝撃で地盤中に砂杭を造成し密度を増加させる。液状化対策や粘性土の複合地盤化に利用する |
| 振動棒工法（ロッドコンパクション工法） | ロッドを振動させながら地中に貫入させ、緩い砂地盤を締め固める |
| バイブロフローテーション工法 | 棒状の振動機で水を噴射しながら締固め、生じた空隙に砂利を充填する |
| バイブロタンパー工法 | 強力な起振機とタンパーの組合せで振動エネルギーを地盤に伝え密度を高める |
| 重錘落下締固め工法 | 重錘をクレーンで落下させ、衝撃と振動により地盤を締め固める |
| 静的締固め砂杭工法 | 振動を用いず、ケーシングの圧入・回転で砂杭を形成して締め固める |
| 静的圧入締固め工法 | 流動性の低い注入材を静的に圧入して固化させ、液状化の防止を図る |

サンドコンパクションパイル工法は、砂地盤では間隙比を減少させて密度を増加させ、粘性土地盤では砂杭が鉛直方向の排水路として機能し、砂杭と粘性土からなる複合地盤として支持力の向上を図る。緩い粘性土地盤では、施工中の振動によって地盤を乱し強度を低下させることがあるため注意が必要である。

### 固結工法

セメントや石灰等の固化材を土と混合し、化学反応を利用して地盤を固結する工法である。

| 工法名 | 原理・特徴 |
|:--|:--|
| 表層混合処理工法 | 生石灰・セメント等を表層の軟弱地盤と混合し、トラフィカビリティと施工性を高める |
| 深層混合処理工法（機械攪拌工法） | 固化材と原位置の土を撹拌翼で強制的に混合し、円柱状の改良体を造成する |
| 深層混合処理工法（高圧噴射攪拌工法） | 高圧で噴射した固化材で地盤を切削しながら混合し、改良体を造成する |
| 石灰パイル工法 | 生石灰を柱状に打設する。吸水反応による体積膨張で周辺地盤の圧密を促進する |
| 薬液注入工法 | 地盤の空隙に薬液を注入し、止水または地盤の強度増強を図る |
| 凍結工法 | 凍結管と呼ばれる鋼管を設置し、地盤中の間隙水を人工的に凍結して掘削面の安定や湧水阻止を図る |

深層混合処理工法による改良体は、複合地盤として評価される。改良体の強度は原地盤中と異なり施工条件の影響を受けやすいため、試験室で配合試験を行って固化材の配合を決定する。

### 荷重軽減工法・構造物と補強による対策

土に比べて軽量な材料を用いる、または構造物・補強材で対処することで、地盤中の応力増加やすべり・側方流動の抑制を図る工法群である。

| 工法名 | 原理・特徴 |
|:--|:--|
| 軽量盛土工法（EPS工法等） | 発泡スチロールブロック等の軽量材で盛土を構築し、地盤への荷重を軽減する |
| カルバート工法 | カルバートを連続して地中に埋め、盛土荷重の一部を置き換える |
| 盛土補強工法 | 帯鋼やジオテキスタイル等を盛土内に敷設し、すべり破壊や側方流動を抑制する |
| 押え盛土工法 | 本体盛土の側方に先行して盛土を施工し、すべりに対する抵抗力を高める |
| 地中連続壁工法 | 場所打ち鉄筋コンクリート壁で周囲を締め切り、側方変位や液状化変形を抑制する |
| 矢板工法 | 側方の地盤に矢板を打設して連続壁とし、側方変位を抑制する |
| 杭工法 | 杭を地中に打設して荷重を下層へ伝達し、不等沈下や液状化被害の防止を図る |
| 敷設工法 | ジオテキスタイル等の敷設材でトラフィカビリティを確保し、局部的な沈下を抑制する |
| 掘削置換工法 | 軟弱層の一部または全部を掘削し、良質土に置き換えて安定性を高める |

軽量盛土材には水砕スラグ・石炭灰・火山灰等のほか、発泡スチロールブロック（EPS）が用いられる。EPSは単位体積重量がおおむね0.1〜0.3kN/m³程度と、通常の土砂と比べて数十分の一に軽く、軟弱地盤上の盛土や地すべり地の盛土荷重軽減に有効である。土に発泡ビーズを混合する**気泡ビーズ混合軽量土工法**や、土・水・セメント・気泡を混合する**気泡混合軽量土工法**も同様に荷重軽減の目的で用いられる。

押え盛土工法は、本体盛土より先に、あるいは同時に施工することが原則で、後から施工しても抵抗力の増加効果は期待しにくい。掘削置換工法は、置き換えた分だけ沈下量が変化するため、周辺への影響を含めた整合性の検討が必要である。

## 排水工法（掘削時の地下水処理）

<ArticleImage
  src="/posts/civil-construction-1/textbook-soft-ground-drainage/img/figure-drainage-method-selection.svg"
  alt="排水工法の選定（重力排水工法・強制排水工法・電気浸透工法の使い分け）"
  width={400}
  height={500}
/>

排水工法は、地下水位以下の掘削を行う際に、掘削作業を容易にするとともに、掘削面および周辺の崩壊や変形を防止する目的で用いられる。地下水位を下げることで、機械掘削による標準的な作業が可能になり、湧水によるボイリング等の抑制、土留めに作用する側圧の軽減、下層の軟弱地盤の強度増加といった効果が得られる。一方で、周辺の井戸水の枯渇や広範囲の地盤沈下を招くおそれがあるため、対策前に周辺への影響を確認する必要がある。

排水工法は、自然流下・重力で集水した地下水をポンプで排水する**重力排水工法**と、真空の力で強制的に吸い上げる**強制排水工法**に大別される。

| 工法 | 特徴 |
|:--|:--|
| 釜場排水工法 | 掘削面より低い集水場に水を集め、水中ポンプで排水する。小規模掘削向け |
| 深井戸排水工法（ディープウェル工法） | 径600mm程度の井戸用鋼管を設置し、水中ポンプで排水する。広範囲・大量の排水に適する |
| ウェルポイント工法 | 真空ポンプで強制的に排水する。揚水高さは理論上約10mだが、実用上は6〜7m程度が限度 |
| 深井戸真空工法 | ウェルポイントと同様の原理で、井戸内に複数段のポンプを設置し、より深い揚水を可能にする |
| 電気浸透工法 | 地中に直流を通し、間隙水を陽極側へ移動させて排水する。透水性の低い土に用いる |

<Callout type="reference" title="出典">
[公益社団法人 地盤工学会](https://www.jiban.or.jp/)
</Callout>

**釜場排水工法**は排水量の少ない小規模な掘削に適するが、掘削が深くなりボイリングのおそれがあるときは注意を要する。**深井戸排水工法**は広範囲に地下水位を低下させる場合や透水性が大きく排水量が多い場合に適する。**ウェルポイント工法**は、揚水流速が大きい場合に多段配置が必要になり、砂礫層では井戸の配列が困難で排水量が多い場合には適用しにくい。**深井戸真空工法**は、井戸の周囲を粘土で大気と絶縁し、内部の複数段ポンプにより数十mの深度まで揚水できる。

### 排水工法の選定

排水工法の選定は、土の透水性と関連づけて考える。透水係数が大きい粗粒土には重力排水工法が適し、重力排水では十分な効果が得にくい中程度の透水係数の土にはウェルポイント工法等の強制排水工法を用いる。透水係数が極めて小さい土には電気浸透工法を用いることがある。数値はあくまで目安であり、地盤の成層状態、掘削箇所の形状・規模・深度、周辺環境等を総合的に考慮して工法を選定する。
