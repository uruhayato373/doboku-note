## モータグレーダ

モータグレーダは、路面・地表などの平面仕上げを主目的にした、軽切削や材料の混合・敷均し・整形などを行うホイール式の建設機械である。

### 特徴と適応作業

モータグレーダの構造には、以下の特徴がある。

1. 長い前後輪の軸距のほぼ中央にブレードを装備している。
2. 前輪車軸に揺動機構を装備しており、前輪が前車軸中央のピンを中心に揺動する（傾ける）ことができる。
3. 前輪車軸揺動機構とは別に、タイヤを左または右に傾けることができる（リーニング）。
4. 6車輪の後4輪は、タンデム装置によりタンデム軸受を中心に揺動できる。

前輪または後輪が地表の凹凸に乗ると、車体は前後方向へ傾き、ブレードにもその動きが伝わる。モータグレーダには、ブレードの変位を車輪の変動量のおおむね1/8まで抑える機構が備わるため、高精度の平面仕上げが可能である。

モータグレーダの用途は、次表のように平滑度を要求される道路建設を中心に、グラウンド整形、圃場整備、建設現場の仮設道路維持、砂利道補修、除雪等の作業に用いられる。

| 作業の種類 | 用途 |
|---|---|
| 切削・整形 | 砂利道、土砂道等の整形、補修 / 現場内走路の整形、補修 / 溝、側溝堀り / テラス造成 / 路床、路盤の整形 / 法面切削、整形 / 広場の整形 |
| 材料の混合・土砂の移動 | 路盤材の敷均し / 路盤材の混合 / 表土のはぎ取り / 溝の埋戻し / 土寄せ / 散土 |
| 障害物の除去 | 除雪 / 除草 |
| その他 | アスファルト舗装などの掘起こし |

### 分類

均し作業を主用途とするモータグレーダでは、けん引力や機械質量よりも、1回の走行で施工できる**ブレードの最大幅**を機械規模の指標にすることが多い。呼称には作業性を左右するフレーム形式も組み合わせ、「○.○m級、車体屈折式」のように表す。

ブレード長による区分は、4.9 m以上が超大型、4.0 m以上が大型、3.0 m以下が小型で、その間を中型とする。ブレードは前後輪の間へ収める構造なので、その長さは車体全長や最小回転半径にも影響する。したがって、この区分は現場の広さや旋回条件に適合する機械を選ぶ目安になる。

## 締固め機械

道路、港湾、空港、ダムなどでは、盛土や舗装材料の空隙を減らして密度と強度を高めるために締固め機械を使う。材料へ与える作用は輪荷重、衝撃、振動などである。原理別には **静的締固め**（ロードローラ・タイヤローラ・タンピングローラ）と **動的締固め**（振動ローラ・振動コンパクタ・ランマ）に大別できる。次図で代表機種と適用土質の関係を確認する。

### 諸元、性能

締固め機械を選定するときに確認する主要諸元を、意味と単位に着目して整理する。

**(1) 線圧**: 車輪荷重を車輪の締固め幅で割った単位幅当たりの荷重であり、N/cmで示す。ロードローラや振動ローラの能力を比べる指標になる。

**(2) 輪荷重**: 軸荷重をタイヤ本数で除して求める1輪当たりの荷重で、単位はN/本である。タイヤローラでは、値が大きいほど深い部分へ締固め作用が届きやすい。

**(3) 接地圧**: タイヤが地面に伝える平均荷重を接地面積で割った値で、Paで表す。タイヤ空気圧にほぼ等しく、高めると表層付近の密度を上げやすい。

**(4) 起振力**: 起振機内の偏心質量を回転させたときに発生する遠心力で、Nを単位とする。振動式の締固め機械が材料へ与える動的作用の目安である。

**(5) 締固め幅**: 1回の通過によって締め固められる全幅で、cm（mm）で表す。ただし、案内輪と駆動輪の線圧が異なるマカダムローラでは、全幅にわたる締固め効果が異なるため、注意が必要である。

### ロードローラ

ロードローラは、最も一般的に使用されている締固め機械のひとつで、ほぼ平らになった盛土面をさらに締め固めるのに用いられる。

ロードローラは、道路工事のアスファルト混合物や路盤の締固めおよび路床の仕上げ転圧に多く用いられるため、この名称がつけられている。鉄輪ローラとも呼ばれ、鉄輪を3輪を持つ**マカダム形**のローラと、機械全幅の鉄輪ローラを有する2軸式と3軸式**タンデム形**のローラの2種類がある。

#### マカダムローラ

マカダムローラの構成は二つに分かれる。固定フレーム式は前輪で操向して後輪を駆動し、屈折フレーム（アーティキュレートフレーム）式は全輪を駆動する。どちらも10〜12 t級が多いが、近年はアーティキュレート操向が主流である。

固定フレーム式のものは、車輪の質量分布がおおよそ案内輪（前輪）3、駆動輪（後輪）7程度の割合で、かつロールの幅は駆動輪のほうが狭いので、線圧は駆動輪のほうがはるかに大きく、締固めは後輪で行う必要がある。

屈折フレーム（アーティキュレートフレーム）式のものは、比較的新しい機械で、前後輪駆動、全輪同一直径、全輪同一線圧となっており、約54〜69 kN/mくらいのものが多い。

マカダムローラは、その高い線圧によって砕石や砂利道の締固めやアスファルト混合物の**初期転圧に最も有効**とされているが、仕上精度はタンデムローラに劣る。次図に固定フレーム式マカダムローラの外観を示す。

#### タンデムローラ

タンデムローラには、2軸タンデムローラと、3軸タンデムローラがある。2軸タンデムローラは、8〜10 t級のものが一般的である。質量分布は前・後輪ほぼ同等か、後輪がやや大きいぐらいであり、ローラの幅はほぼ等しいので、線圧はマカダムローラほど前後輪の差がなく、ほぼ同等か駆動輪のほうがやや大きい。

タンデムローラは、締固め力ではマカダムローラに劣るが、仕上げ面の平坦性が優れ、仕上げ面にすじを残すことが少ないため、**アスファルト混合物の仕上げ用**として多く用いられる。しかし、最近ではあまり使用されておらず、屈折フレーム式のマカダムローラやタンデム型振動ローラにとって替わっている。次図にタンデムローラ（2軸式）の外観を示す。

#### ロードローラの特徴

**1) 長所**

1. 線圧が高いので、施工条件がよければ効果的な締固めができる。特に、単粒砕石などの締固めに有効である。
2. 平坦で美しい面を得やすく、タイヤローラやタンピングローラによる転圧後の整形、アスファルト混合物の締固めと最終仕上げに向く。
3. 比較的低価格で、故障が少ない。

**2) 短所**

1. 移動速度が遅く、急坂路の走行がしにくい。
2. 車輪の粘着係数が小さくスリップを起こしやすいので、軟弱地や傾斜地での使用が困難である。また、線圧の高い機械は、路肩部での作業に危険が伴う。
3. 含水比の高い粘性土、均一な粒径の砂質土に対しては、締固め効果が少ない。
4. 土質によっては、その締固め力が表層に近い所に集中し、表面に堅いからを作るような状態で締固め、有効な締固め深さが浅くなったり、波打ちを起こして十分な締固めができないことがある。

### タイヤローラ

タイヤローラは、ロードローラと同じくアスファルト混合物や路盤、路床の締固めに使用される。

タイヤローラは鉄輪ローラより締固め能力がやや小さい。走行方式は自走式と被けん引式だが、被けん引式には取り回し上の制約があるため、日本では**自走式**が一般的である。機械規模は3 t級の小型から8.5〜25 t級の大型まで幅広く、規模に応じて構造も異なる。

路面の凹凸に対して各輪の荷重を均等に保つため、タイヤローラには特殊な懸架機構が使われる。車輪を固定支持すると、凸部や支持力の高い箇所に荷重が集中し、凹部や弱い箇所が十分に締まらない。この偏りを防ぐ支持方式には相互揺動式と独立支持式があり、一般には相互揺動式を採用する。

また、前軸および後軸のタイヤが互いに同じわだちの上を通らないように、操向輪（前輪）が3〜5本、駆動輪（後輪）が4〜6本と駆動輪のほうが1本多く、1回の通過で踏み残しが生じないようになっている。

空気タイヤは、鉄輪にくらべ粘着係数が大きい（すべりにくい）ため大きいけん引力を得ることができ、勾配のある場所やすべりやすい条件での転圧が比較的容易にできる。さらに、走行速度が最高20〜25 km/hと速いため、自走による回送も可能である。

タイヤローラは、輪荷重に加えてタイヤ空気圧を調整することで締固め作用を変えられる。接地圧は内圧におおむね比例するため、空気圧を上げて接地面積を小さくすると、表層への作用が強くなる。運用の基本は、**砕石**では**接地圧を高く**、**粘性土**では**接地圧を低く**設定することである。

また、自重のかわりにバラスト（水や鉄など）積込み量を多くできるため、バラストを積んで輪荷重を増やし、下層への締固め力を大きくすることができる。したがって、土質や施工条件によってバラストの量を増減し、タイヤ空気圧の調節と併用して、比較的広範囲の材料の締固めに適応でき、含水比の高い砂質土や、鋭敏な粘性土、硬岩以外の材料はほとんど締め固めることができる。

タイヤのニーディング作用（こね返し）は、敷き均したアスファルト混合物の砕石周囲へモルタルを行き渡らせ、表面のシール性を高める。また、砕石を壊さずに舗装体内で粒子の向きを整えるため、舗装の安定度向上にも寄与する。

接地圧を約0.1〜0.7 MPaの範囲で変えられることを利用し、転圧初期や支持力の小さい粘土ではバラストを載せず、空気圧も低めにする。締固めの進行に伴って地盤支持力が増したら、バラストと空気圧を段階的に上げる。目安となる接地圧は土の支持力より2〜8割ほど高い値である。低空気圧でバラストが多いとタイヤのたわみが過大になり、寿命を縮めるので減載する。なお、接地圧が同じでもバラストを減らせば接地面積が小さくなり、締固めの到達深さは変化する。

### タンピングローラ

タンピングローラは、鋼板製の中空円筒（ドラム）の外周に10〜20 cmの長さの突起を60〜100本程度植えつけたもので、突起（フート）の形によりシープスフートローラ（脚の先端が羊蹄状に太いもの）、テーパフートローラ（脚の根本が太く先端にゆくほど細い）などがある。

国産の機種では、自走式で質量20〜30 t、被けん引式で質量1.5〜14 tぐらいまであり、アースダム、築堤、道路、飛行場、その他大規模な厚い盛土の締固め作業に使用される。また、バラストはドラム内に水または砂などを積み込めるようになっている。

タンピングローラの締固め効果は、質量および突起の数、形状、寸法、配列などによって異なるため、使用目的、土質などに応じて機種が選択される。

タンピングローラは、突起の先端に荷重を集中させることができるため、土塊や岩塊などの破砕や締固めに効果があり、土工作業での**重転圧**に有効である。また、粘性土の締固めにも効果的といわれているが、鋭敏比の大きい高含水比粘性土では、突起による土のこね返しによってかえって土を軟化させることがあるため、注意が必要である。また、均一の粒径の砂には向かない。次図にシープスフート型タンピングローラの外観を示す。

### 振動ローラ

振動ローラは、車輪内においた起振機によって転圧輪を強制振動させ、自重の1〜5倍の**起振力**による動荷重で土の粒子をゆさぶって、土粒子間の変形抵抗を小さくし、粒子自身の移動を容易にしながら、機械の自重によって締め固める機械である。比較的小型でも高い効果をあげることができ、1台で路盤から表面仕上げまでの一連の締固め作業に適用できるだけでなく、締固め回数が少なくてすむという利点がある。

起振装置は、偏心体を油圧により高速回転させるもので、1軸と2軸式とがある。2軸式には、相対する2個の偏心体がそれぞれ自転しながら車輪とともに公転し、水平方向の振動を発生させるものと、2個の偏心体が固定された相対する軸の上で、同調しながら反対方向に回転し、垂直振動を発生させるものとがある。

1軸式の中には、偏心体の内部に自由可動のウェイトを設け、振幅を高・低の2段階に切り替えられる機種もある。

振動ローラは駆動形式によって、自走式、被けん引式、ハンドガイド式に分かれる。搭乗型では起振装置を車輪内へ収めるのに対し、ハンドガイド式などの小型機ではフレームへ取り付ける構成が多い。

機械の大きさは運転質量を基準とし、「○○t級」のように表示する。

適用できる材料と施工分野は幅広く、振動ローラはアスファルト舗装からダム工事におけるコンクリート締固めまで利用される。

適応する土質は、岩塊、単粒度の砂、礫混り砂、砂質土などの締固めに効果があるが、含水比の高い砂質土や鋭敏な粘性土には不適当である。

振動ローラは、タイヤローラやマカダムローラのような静的ローラに比べて、次のような特徴がある。

1. 振動により締固め効果が深層まで及ぶので、材料の層の**敷均し厚さを厚く**できる。
2. 締固め効果が大きく、**少ない転圧回数**で十分な締固め度が得られる。また、同程度の締固め効果を期待する場合、ロードローラに比べて**小型**のもので対応できる。
3. 起振力、振動数、振幅、走行速度を変えることにより、材料の性状に応じた締固めができる。
4. アスファルト舗装の締固めにおいて、同一ローラを使用して種々のアスファルトの締固めができるなど、混合物の温度に対して適応性が広い。
5. 熟練したオペレータを必要とする。

### 振動コンパクタ

振動コンパクタ（平板式振動締固め機械）は、偏心軸を高速回転させて遠心力を発生させる起振機を平板の上に直接装備したもので、この振動によって締固めと自走を同時に行う。一般にハンドガイド式が多く、適応土質は振動ローラとほぼ同じであり、盛土の法面や法肩、狭い箇所の路床、構造物の裏込め、埋戻し、狭い箇所のアスファルト混合物などの締固めに使用される。

### ランマ

ランマは、2〜4 kW（約3〜6 PS）程度の小型エンジン（最近では電動機を用いたものもある）のクランク軸の回転を上下動に変え、スプリングを介して振動板（平板）に連続的に振動を与え、材料の表面をたたいて締め固めるもので、機械質量は50〜60 kg前後のものが多い。高含水比の砂質土、粘性土以外の土質に広く利用でき、補助締固め機械として、狭い場所、ほかの大型締固め機械が使えない場所、路肩、小規模の埋戻し部分の締固めに使用される。
