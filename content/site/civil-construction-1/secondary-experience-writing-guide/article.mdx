1級土木 第2次検定の必須問題である施工経験記述について、出題傾向・過去の問題例・記述上の留意点・出題項目に応じたヒント文章案までを一通り整理する。まずは何が問われ、どの観点で書くのかという全体像から押さえていく。

自治体などの発注者側で工事監督を担当している場合は、受検資格としての実務経験と、試験で扱う工事経験を分けて確認する必要がある。現行の手引における発注者経験の扱いと、題材を棚卸しする手順は[土木公務員に1級土木施工管理技士は必要か](/docs/civil-construction-1-public-servant-merit)で整理している。

## 出題傾向

施工経験記述は、受検者自身が携わった土木工事での現場の施工管理を書かせる問題で、第2次検定では毎年必ず出題される必須の問題である。

過去の指定項目を振り返ると、工程管理だった平成24年度を除き、平成23年度以降は品質管理と安全管理のどちらかが指定されてきた。

なお、令和6年度から出題形式が見直され、5つの管理項目のうち2つが設問1・設問2に指定され、同一の工事について両方を必答する形式へ変わった。詳しくは後述の「令和6年度からの出題形式の見直し」を参照。

平成23年度から令和2年度までの指定項目を、項目ごとに年度をまとめると次のとおりである。いずれの年度も、現場の状況を踏まえて特に気を配った点を述べさせる設問であった。

- **品質管理**: 平成25年度、27年度、30年度、令和元年度、令和2年度
- **安全管理**: 平成23年度、26年度、28年度、29年度
- **工程管理**: 平成24年度

いずれの年度も、記述事項の構成は共通して次のとおりである（`○○`には出題年度の施工管理テーマ項目が入る）。

**〔設問1〕**

<div className="list-plain">

- (1) 工事名
- (2) 工事の内容 — 1）発注者名　2）工事場所　3）工期　4）主な工種　5）施工量
- (3) 工事現場における施工管理上のあなたの立場

</div>

**〔設問2〕**

<div className="list-plain">

- (1) 具体的な現場状況と特に留意した技術的課題
- (2) 技術的課題を解決するために検討した項目と検討理由及び検討内容
- (3) 技術的課題に対する検討2)の結果、現場で実施した対応処置とその評価

</div>

## 過去の問題例

令和2年度の実地試験の問題を、解答欄の形式は想定のうえで再現すると次のようになる。品質管理を題材として、現場の状況と技術的課題、課題の解決に向けた検討の項目・理由・内容、実施した処置とその評価の順に書かせる構成である。

### 令和2年度〔問題1〕

> **〔問題〕** あなたが経験した土木工事の現場において、その現場状況から特に留意した品質管理に関して、次の〔設問1〕、〔設問2〕に答えなさい。
>
> **〔注意〕** あなたが経験した工事でないことが判明した場合は失格となります。

**〔設問1〕** あなたが経験した土木工事に関し、次の事項について解答欄に明確に記述しなさい。

> **〔注意〕**「経験した土木工事」は、あなたが工事請負者の技術者の場合は、あなたの所属会社が受注した工事内容について記述してください。従って、あなたの所属会社が二次下請業者の場合は、発注者名は一次下請業者名となります。
>
> なお、あなたの所属が発注機関の場合の発注者名は、所属機関名となります。

**(1) 工事名**

**(2) 工事の内容**
- 1）発注者名
- 2）工事場所
- 3）工期
- 4）主な工種
- 5）施工量

**(3) 工事現場における施工管理上のあなたの立場**

**〔設問2〕** 上記工事の現場状況から特に留意した品質管理に関し、次の事項について解答欄に具体的に記述しなさい。

(1) 具体的な現場状況と特に留意した**技術的課題**

(2) 技術的課題を解決するために**検討した項目**と**検討理由及び検討内容**

(3) 上記検討の結果、**現場で実施した対応処置とその評価**

## 令和6年度からの出題形式の見直し

令和5年度までの施工経験記述は、品質管理・安全管理・工程管理のいずれか1つの施工管理項目が指定され、設問1で工事概要、設問2でその管理項目について記述する形式であった。

令和6年度からは、品質管理・安全管理・工程管理・施工計画・環境対策の5つの管理項目のうち **2つが設問1・設問2に指定** され、同一の工事について両方を必答する形式へと変わった。設問1と設問2は **同一内容の解答は不可** であり、同じ工事の異なる管理側面を書き分ける必要がある。

**令和6年度から2テーマ必答に変わっている**。令和5年度以前と令和6年度以降では、設問の構成が次のように異なる。どの2つの管理項目が指定されても対応できるよう、5管理すべてを準備しておく。

**令和5年度以前（1つの管理項目）**

- 指定された1つの管理項目（品質・安全・工程など）について記述する。
- 設問1で工事概要、設問2でその管理項目の現場状況・技術的課題・検討・対応処置・評価を記述する。

**令和6年度以降（2つの管理項目を必答）**

- 工事概要を記述したうえで、設問1と設問2にそれぞれ異なる管理項目が指定される。
- 設問1・設問2とも「現場状況 → 技術的課題 → 検討項目 → 対応処置 → 評価」を記述する。
- 各設問の解答欄は（1）（2）の2区画で、**検討した項目は（1）側に入る**。
  （1）具体的な現場状況と特に留意した技術的課題と、その課題を解決するために検討した項目／
  （2）（1）で記述した検討項目の対応処置とその評価。
- 設問1と設問2は同一内容の解答にできない。

図は[令和7年度の公式問題・問題1](https://www.jctc.jp/wjctcp/wp-content/uploads/2025/10/20251006d_mondai.pdf)の区画を基に、当サイトが学習用に整理した。受検時はその年度の設問の言い回しと指定項目を優先する。

この（1）（2）の区切りは、2級とは異なる。過去問の答案や他級向けの解説を流用するときに
最も事故が起きやすい箇所なので、次の対比を頭に入れてから書き始めてほしい。

<Callout type="warn" title="2級とは検討項目を入れる区画が異なる">
2級は「（1）現場状況・技術的課題／（2）検討した項目とその対応処置」で、**検討した項目が（2）側**に入る。
1級で2級の区切り方を使うと、（2）に検討・対応処置・評価の3要素が乗る。1級の解答欄は1区画あたり
おおむね8行・1行25字程度＝200字前後なので、物理的に収まらない。過去問の答案や他級向けの解説を
そのまま流用するときは、どちらの区切りで書かれたものかを必ず確かめる。
</Callout>

### 近年の出題テーマ

令和3年度から令和7年度までに指定された管理項目テーマと出題形式を一覧にまとめる。令和6年度を境に1テーマから2テーマ必答へ移行している点に注目してほしい。

| 年度 | 出題テーマ | 形式 |
|---|---|---|
| 令和7年度 | 品質管理・環境対策 | 2テーマ必答 |
| 令和6年度 | 安全管理・施工計画 | 2テーマ必答 |
| 令和5年度 | 品質管理 | 1つの管理項目 |
| 令和4年度 | 安全管理 | 1つの管理項目 |
| 令和3年度 | 安全管理 | 1つの管理項目 |

<Callout type="reference" title="出典">
[1級土木施工管理技術検定 試験問題・正答肢（全国建設研修センター）](https://www.jctc.jp/exam/doboku-1)
</Callout>

令和6年度以降は2つの管理項目が指定されるため、どの2つが出ても書けるよう、一つの工事を5管理すべての視点から整理しておくとよい。

### 令和7年度〔問題1〕（現行形式の例）

> **〔問題〕** あなたが経験した土木工事を1つ選び、工事概要を具体的に記述したうえで、次の〔設問1〕、〔設問2〕に答えなさい。

**〔設問1〕** 工事概要に記述した工事の「品質管理」に関し、具体的な現場状況・技術的課題・検討項目・対応処置・評価を記述する。

**〔設問2〕** 工事概要に記述した工事の「環境対策」に関し、同様に記述する。ただし、設問1と同一内容の解答は不可とする。

### 現行の受検の手引でみる工事内容の区分

上の表と、この後の「対象とは認められない工事等」の表は、もっと古い手引に基づく整理で、現行の区分とは名称や例示が異なり、食い違う行もある。令和8年度の手引のうち新受検資格用は、建設業法の業種（土木一式、とび・土工・コンクリート、石、鋼構造物、舗装、しゅんせつ、塗装、水道施設、解体の各工事）で受注・発注された工事を対象とし、その中身を「工事内容」の区分で例示している。旧受検資格用は、工事種別と工事内容を一つの表で示す形をとる。

新受検資格用では、判定を二段で行う。契約上の業種が前段の九つのいずれかであることを確かめ、次に工事の中身が区分に載っているかを見る。業種が対象外で受注された工事は、区分に載る内容でも算入できない。ただし、元請けが建築一式工事でも、下請けとして対象の業種で発注された部分（PC杭工事や山留杭工事など）は、その下請期間を算入できる。

土木に関わる主な区分と、手引が挙げる代表的な工事内容は次のとおりである。

| 工事内容の区分 | 手引が挙げる代表的な工事内容 |
|---|---|
| 河川工事 | 築堤、護岸、水制、床止め、水門、樋門（樋管）、排水機場、河道掘削、河川維持（構造物の補修） |
| 道路工事 | 道路土工、路床・路盤、法面保護、舗装、ガードレール設置、カルバート、区画線、道路維持（構造物の補修） |
| 海岸工事 | 海岸堤防、海岸護岸、消波工、離岸堤、突堤、養浜、防潮水門 |
| 砂防工事 | 山腹工、堰堤、地すべり防止、がけ崩れ防止、雪崩防止、渓流保全 |
| ダム工事 | 転流工、堤体基礎掘削、コンクリートダム築造、基礎処理、ロックフィルダム築造 |
| 港湾工事 | 航路浚渫、防波堤、護岸、けい留施設、埋立 |
| 鉄道工事 | 軌道盛土・切土、軌道敷設（架線工事を除く）、ホーム構築、踏切道設置、高架橋、鉄道トンネル |
| 空港工事 | 滑走路整地、滑走路舗装、エプロン造成、滑走路排水施設 |
| 発電・送変電工事 | 取水堰、送水路、発電所設備のコンクリート基礎、鉄塔設置、太陽光発電施設の基礎・造成 |
| 通信・電気土木工事 | 通信管路敷設、とう道築造、鉄塔設置、地中配管埋設、無電柱化土木（ケーブル引込のみを除く） |
| 上水道工事 | 公道下の配水本管敷設、取水堰、導水路、浄水池・配水池の設置 |
| 下水道工事 | 公道下の本管路敷設、管路推進、更生、ポンプ場・終末処理場の設置 |
| 土地造成工事 | 切土・盛土、法面処理、擁壁、調整池、分譲宅地・工場用地の造成、公園・運動場の造成 |
| 農業土木工事 | 圃場整備、土地改良、農地造成、農道整備、用排水路、溜池 |
| 森林土木工事 | 林道整備、擁壁、法面保護、谷止、治山堰堤 |
| 地下構造物工事 | 地下横断歩道、地下駐車場、共同溝、電線共同溝、情報ボックス、ガス本管埋設、土留め、路面覆工 |
| 橋梁工事 | 橋梁上部（桁の製作・架設、床版）、橋台・橋脚、杭基礎・ケーソン基礎、耐震補強、歩道橋 |
| トンネル工事 | 山岳トンネル（掘削・覆工・坑門）、シールド、開削、水路トンネル |

表の読み方は四点ある。まず、個人宅地内の工事は、舗装・造成・塗装・薬液注入・地盤改良などで除外される。次に、河川維持工事と道路維持工事は「構造物の補修」であれば対象になり、路面清掃や除草のような維持の作業は対象にならない。三つ目に、後ろの表が維持・修繕として対象外にしている区画線工事は、現行の手引では道路工事の例に入っている。最後に、工場での製作は一律に対象外ではなく、鋼構造物工事のうち橋梁・水門扉の工場での製作は対象の例に挙がる。対象外の例は、新受検資格用の手引では、二次製品などを工場で製作・加工するだけで設置を行わない場合とされている。

区分の名称や例示は改訂のたびに入れ替わる。申し込む年度の手引の別表で、自分の工事が載っているかを必ず照合する。

令和8年度の手引は、[新受検資格用](https://www.jctc.jp/kentei/themes/tebiki_1d03_08_new.pdf)と[旧受検資格用](https://www.jctc.jp/kentei/themes/tebiki_1d03_08_old.pdf)に分かれており、旧受検資格での受検は令和10年度まで経過措置として可能とされている。旧受検資格用は区分を記号で示すが、河川や道路などの土木の工事内容はおおむね共通している。

### 対象とは認められない工事等

試験機関である（一財）全国建設研修センターでは土木施工管理に関する実務経験として認められていない工事や業務がある。経験記述にあたっては以下のような工事と業務は不適当であり避けなければならない。

**土木施工管理に関する実務経験として認められない工事**

| 区分 | 内容 |
|---|---|
| 工場製作 | プレキャストコンクリート製品製作、鋼構造物製作 |
| 建築 | ビル建築の杭・基礎工事、建築物の外構工事 |
| 設備 | ビル建築の給排水・衛生・空気調和設備工事 等 |
| 解体 | 土木・建築構造物の解体・撤去 |
| 機械器具設置工事 | プラント設備、運搬機器設置 |
| 維持・修繕 | トンネル内設備工事（照明器具取替え含む）、法面の植生工事（小規模）、防護柵等設置工事（小規模）、区画線工事、しゅんせつ船の運航 等 |

土木施工管理に関する実務経験として認められる業務と立場及び略歴

| 区分 | 内容 |
|---|---|
| 施工管理 | 主任技術者、現場代理人、工事主任、施工監督 等 |
| 設計監理 | 工事監理者 |
| 施工監督 | 発注者側の現場監督技術者 等 |

土木施工管理に関する実務経験として認められる業務と立場及び略歴

| 区分 | 内容 |
|---|---|
| 設計 | 設計業務 |
| 調査 | 調査業務（地質調査、測量調査、環境調査等） |
| 積算 | 積算業務 |
| 事務 | 営業、事務 |
| 教育研究 | 教育、研究 |

> ※ 上記はいずれも土木施工管理に関する実務経験としては認められない。

詳細については、令和3年度の受験申込書に同封されている「受験の手引」を参照してください。

### 迷いやすい工事の可否と、分かれ目になる条件

名称が似ていても、受注の仕方や場所、規模によって結論が変わる工事がある。上の二つの表（主な工事種別の表と、認められない工事の表）はもっと古い手引に基づく整理で、現行の手引と食い違う行がある。解体工事、ビル建築の杭・基礎工事、鋼構造物の製作などがその例である。

現行の手引で見る分かれ目は、場所、規模、本体か付帯か、土木か建築か、の四通りに整理できる。次の表はこの順に並べている。

| 工事 | 可否の分かれ目 |
|---|---|
| 地盤改良 | 土木工事としては対象。個人宅地内は対象外 |
| 薬液注入 | トンネルの止水・固結や推進管周囲の補強は対象。個人宅地内は対象外 |
| 浄化槽 | ビル・工場などの大型浄化槽は対象。個人宅等の小規模なものは対象外 |
| 機械の基礎 | 機械・タンク・煙突に伴うコンクリート基礎は対象。機械本体の設置は対象外 |
| 解体工事 | 橋脚・擁壁などの土木構造物の解体は対象。一戸建て個人住宅の解体は対象外 |
| 杭工事 | ビル・マンション等の既製杭・場所打ち杭は対象。個人宅地内でも杭・土留めは対象 |

解体工事は、手引の新旧で扱いが分かれる。旧受検資格用の手引は、橋脚・道路擁壁・大型浄化槽・地下構造物（タンク）などの土木構造物の解体を対象とし、建築物建屋解体と建築物基礎解体は一律に対象外とする。新受検資格用の手引は、建設業法の業種で受注された目的物の解体に加えて、「解体工事」として受注された集合住宅・店舗・倉庫などの建築物の解体も対象とする。除かれるのは、建築一式工事として受注された建築物の解体と、一戸建て個人住宅の解体である。

建築物の基礎まわりは、旧受検資格用の手引が線を引いている。ビル・マンション等の杭工事は対象でも、躯体工事や仕上げ、杭頭処理、建築基礎としての地盤改良（砂ぐい・柱状改良など）は対象外とされ、建築物における薬液注入も同様である。新受検資格用の手引でも、建築の躯体工事（コンクリートの打設・圧送を含む）と内装・仕上げは対象外の例に挙がっている。

どちらの手引が自分に当てはまるかは、受検資格の区分で決まる。工事ごとに可否を暗記するより、契約上の業種、工事の内容、除外の条件の三点を順に当てる習慣をつけておくと、題材選びで迷いにくい。

### 対象外になりやすい工事・作業の具体例

手引は、認められない工事内容を例示している。外れる理由は大きく三つに分けられる。施工ではなく作業や業務であること、土木ではない別の工事であること、場所や規模の除外に当たることである。次の表はこの順に並べている。題材を選ぶ段階で、当たらないかを確かめておく。

| 対象外の工事・作業 | 外れる理由 |
|---|---|
| 路面清掃、除草、除雪、流木処理 | 維持のための作業で、施工管理を伴う工事ではない |
| ボーリング調査、さく井、埋蔵文化財の発掘調査 | 調査の業務で、工事の施工ではない |
| 工場での生コン・アスコン・二次製品の製造管理 | 工場内の製造で、現場の施工管理ではない |
| 架線、ケーブル引込、電柱設置、変電所の建屋 | 電気工事や建屋工事にあたる |
| プラント設備、運搬機器、立体駐車設備の設置 | 機械器具設置工事にあたり、土木の工事内容ではない |
| 植栽、修景、遊具・防球ネットの設置 | 造園や公園施設の工事にあたる（公園・運動場の造成は対象） |
| 敷地内の給排水配管、フェンス・門扉・ブロック塀 | 公道下の本管工事ではなく、敷地内の設備や外構にあたる |
| 個人宅地内の造成・擁壁・地盤改良・建屋解体 | 個人宅地内の工事は除外される（杭と土留めを除く） |

名前が似ていて混同しやすいものもある。「ボーリンググラウト工事」は地盤を処理する工事として対象に入るが、地質調査のボーリングは調査の業務なので対象外である。また、アルバイトの作業員としての経験や、雑役務・単純労務だけの経験は、工事の種類にかかわらず対象外になる。これらは次項で、職務の側から整理する。

### 工事は対象でも、職務が施工管理でなければ算入されない

手引は、実務経験を、工事の施工計画の作成や、工程・品質・安全などの管理に直接かかわった技術的な職務の経験と定めている。具体的には、請負者の従業員として施工を管理した経験、発注者の従業員として発注工事の施工を指導・監督した経験、工事監理を受託した者として工事監理を行った経験のいずれかで、補助者としての経験も含まれる。

自分の経験に施工管理の実質があるかは、次の三つの問いで順に確かめられる。

<ArticleImage src="/posts/civil-construction-1/secondary-experience-writing-guide/img/figure-experience-check-flow.svg" alt="施工管理の実質があるかを三つの問いで確かめる判定フロー。一つでも「いいえ」なら実務経験に算入できない。" width={400} height={500} />

一つ目の問いで外れるのは、着工前の設計だけの業務、積算、測量・調査・点検、保守・維持・メンテナンスの業務である。ただし、施工中の工事測量は算入できる。測量という名前で一律に外れるのではなく、施工中の工事を進めるための測量かどうかで分かれる。また、河川・道路の維持工事のうち構造物の補修は工事として対象であり、外れるのは点検や保守を業務として行う場合である。

二つ目の問いで外れるのは、アルバイトによる作業員の経験、工程・品質・安全の管理を含まない雑役務や単純な労務、単なる掘削・コンクリートの打設・建設機械の運転・ごみ処理、単に塗料を塗る作業や薬液を注入するだけの作業である。作業をしたかどうかではなく、その作業をどう管理したかが問われる。

三つ目の問いは、請負者としての施工管理、発注者としての施工の指導・監督、工事監理のいずれの職務かを見る。外れるのは、現場事務や営業、官公庁での行政・行政指導、研究所や学校での研究・教育の業務である。自治体などの発注者側の技術者は、設計・積算・行政の業務と、発注工事の施工を指導・監督した期間を分けて考える。算入できるのは後者だけである。

手引には、これらの例示に当たらなくても、施工管理の実務経験と認められない業務や作業はすべて対象外とする旨の但し書きがある。判断に迷う業務は、申込みの前に全国建設研修センターへ確認する。

## 記述上の留意事項

### 記述全般

記述全般としての注意点は、1級土木施工管理技士にふさわしい用語及び内容と論理構成をもって記述することが求められるので、まずは施工管理のテキストや施工管理に関する各協会の基準書等をよく読み、用語を頭に入れておく必要がある。しかし、記述内容があまりにもテキストどおりの過ぎるのもよくないため適度なアレンジは必要である。

なお、安全管理の出題の際は、「労働安全衛生法」をはじめとする法律や手引きも各種出されているので、一読しておくとよい。

また、記述で特に重要なことは「具体的に記述する」ことである。結果の記述をするだけでは伝わらないため、必ず「何を」「どのように」をセットにして記述するとよい。

品質管理であれば、品質を保証するための計画と技術的背景が見えるような記述がポイントであり、安全管理の出題であれば、安全管理の考え方が見えることがポイントとなる。

1. 誤字、脱字に気をつける。
2. 段落文では、「です・ます」調は使わない。「である」「であった」を使う。
3. 記述は箇条書きでもよいが、簡素になりすぎると具体性が欠ける。字数との関係で、適宜書き分ける。
4. 文字は丁寧に記入する。少し下手でもなるべく大きく書くこと。自分の「関係者名刺」に書いてあるような文字で書くとよい。

<Callout type="note" title="自分の経験記述、合格水準に届いているか（PR）">
第2次検定の経験記述は配点が大きく、合否を分けやすい。一方、独学では「自分の答案が採点者に伝わるか」を客観的に確かめる手段がない。誤字・論理の飛び・具体性の不足は、書いた本人ほど気づきにくい。
</Callout>

### 評価されやすい記述の姿勢と、避けたい書き方

経験記述は、工事の事実を並べる答案ではなく、技術者としてどう判断したかを読ませる答案である。次の五つの構えを、書く前、書くとき、書いた後に分けて決めておくと迷いが減る。

**書く前に、課題を一つに絞る。** 範囲を広げるほど各論が薄くなり、検討と対応処置の対応も崩れる。一つの課題に対して、原因、検討、処置、評価が一本の線でつながる形にする。

**安全管理では、題材の選び方に注意する。** KY活動や安全パトロール、新規入場者教育のような通常の安全活動は、どの現場でも行うため課題になりにくい。作業床の高さ、重機と作業員の近接、第三者や交通との近接など、その現場に固有の危険から課題を立てる。

**書くときは、手続きではなく技術で書く。** 「関係機関と協議した」「施工計画書を作成した」といった手続きの記述は、どの現場でも成り立つ。何を測り、何と比べ、どの工法・材料・管理方法を選んだかまで書くと、現場に立った人の答案になる。

**数値は、出どころを示せるものだけを書く。** 試験成績や日報で裏づけられる数値と、その因果で書き、根拠を示せない最大級の表現は削る。問題の〔注意〕にあるとおり、経験した工事でないと判明すれば失格となる。確かめられない誇張は、得にならない。

**読み手ごとに、確かめてほしい点を決めて渡す。** 同じ工種を知る人には技術の誤りを、別の工種の人には専門用語に頼って説明を飛ばした箇所を、工事に詳しくない人には状況から課題への筋が追えるかを頼む。自分では気づきにくい誤字や論理の飛びも、読み手が変わると見つかる。

### 出題項目

出題項目は大別すると以下のとおり、「施工計画」、「品質管理」、「工程管理」、「安全管理」の4つである。

### 工事名

工事の目的（河川名、路線名、施設名等）、工事の場所（地区・地先名称）、工事の種類等（建設工事、補修工事、築造工事等）がわかるように具体的に記述する。ひらがなのタイトルは漢字に変えてもよい。

原則として契約書及び工事用看板のとおり記入するが、長い場合は（　）書きで概要としてもよいし、略称にしてもよい。

組み合わせた工事名の事例は以下のとおりである。

**(良い例)**

- a. 県道路改良工事
- b. ○○地区○○道路建設工事
- c. 国道○○号○○橋橋梁上部工事
- d. ○○地区河川改修工事
- e. ○○処理場汚水ポンプ棟建設工事
- f. 市道幹線○○号道路改良舗装工事
- g. ○○地区護岸災害復旧工事
- h. ○○雨水幹線管渠築造工事

### 工事名と立場を選ぶときの補足

建築工事の基礎に関わる経験を使う場合は、工事名の後ろに括弧書きで「基礎工事」「杭工事」と添え、主な工種にも杭工事や山留め工事のように土木の部分が分かる語を入れる。「新築工事」とだけ読める記述では建築全体の経験に見え、手引が対象とする杭工事や土留め工事の経験であることが伝わらない。

題材にする工事は、規模が大きく、複数の工種や制約条件をもつ公共工事が書きやすい。公共工事は、契約図書や仕様書、施工管理基準が整っているため、管理値や判断の根拠を具体的に示せる。判定に説明が要る工事（前節で挙げた個人宅地内の工事や小規模な設備工事など）は、ほかに題材があれば避ける。

「監督員」は発注者側の呼称である。請負者の技術者が自分の立場を監督員と書くと、発注者名との組合せが合わなくなるため、現場代理人や主任技術者のような請負者側の語に置き換える。発注者側の職員として書く場合は、発注者名が所属する機関名になる点も合わせて確かめる。

立場の欄には、現場での職務上の立場（現場代理人、主任技術者、監理技術者、工事主任など）を書く。作業主任者のように労働安全衛生法に基づいて作業ごとに選任される役割や、保有資格の名前は、施工管理上の立場を示す語ではない。手引が従事内容の欄に挙げる立場も、請負者の施工管理（主任技術者、監理技術者、監理技術者補佐など）、発注者側の監督員、工事監理等の三つに分かれている。

### 発注者名

会社に所属する受検者は、**自社へ直接工事を注文した相手**を確認する。元請会社であれば元の発注機関、一次下請会社であれば元請会社、二次下請会社であれば一次下請会社が該当する。「下請なら必ず工事全体の元請を書く」とは限らない。

<ArticleImage src="/posts/civil-construction-1/secondary-experience-writing-guide/img/figure-direct-orderer.svg" alt="工事の契約関係と、自社への直接の発注者のたどり方" />

[令和7年度の公式問題・問題1の注意書き](https://www.jctc.jp/wjctcp/wp-content/uploads/2025/10/20251006d_mondai.pdf)では、発注機関に所属する場合は所属する発注機関名を記入するよう指定されている。図はこの注意書きと契約関係を当サイトが整理したもの。工事概要の記入方法と、受検資格に算入できる実務経験の条件は別に確認する。

発注者名は、略さずに正式な名称で書く。

- 官公庁の場合、「国土交通省」だけでは足りない。地方整備局と、国道（河川）事務所などの事務所まで書く。
- 県の場合も、県名だけにせず、土木事務所のような出先の機関名まで書く。
- 発注者が民間の会社であれば、個人の氏名ではなく会社名（例：`○○`建設(株)）を書く。

### 工事場所

題材にした工事の施工場所は、都道府県名から市・郡、さらに町村名まで、特定できる細かさで書く。

- 郡や町で止めず、地先まで続ける（例：`○○`県`○○`郡`○○`町`○○`地先）。
- 市内の場所は、町名の後ろに丁目まで付ける（例：`○○`県`○○`市`○○`町`○`丁目）。

### 工期

工期の欄は、次の五点に気をつけて書く。

- 範囲は自社が請け負った分とする。下請として受けた工事なら、その下請部分の工期を書く。
- 工期が2か月未満の小さな工事や軽微な工事は、1級の題材としては評価が下がるおそれがある。下請であっても、受注後の労務・資機材の手配期間を含めて2か月以上を要した工事を選ぶのが望ましい。
- 完成して1〜5年ほどの工事を目安に選ぶ。施工中の工事は避ける。10年以上前の工事も避ける。
- 年号を付け、年月日まで省略せずに書く。

### 具体的な現場状況と特に留意した技術的課題

記述事項のポイントは以下の6つの要素を的確に文章にまとめることにある。

> **技術的課題**（テーマの前段）＝「課題が生じる現場や施工の状況及び」＋「原因」＋「工事の規模（工事名、工事量から工種等を整理した技術的課題の特定）」

1. まず、工事の概要と工事名の違い。工事の概要は記述する内容（たとえば品質管理に関連する工事の一部分）を説明する工事の規模とか、工事内容であること。
2. 工事概要は工事の中のどの施工部分について記述するかの概略でよい。
3. 構造（形式や構造形式の選定）、施工法（工法・施工方法の記述）、資材（材料特性等の記述）、等のいずれかの概要を的確に記述する。ただし、安全管理に関しての場合は「安全確保のためどのような対応が必要だったのか」が事前に検討されていることが伝わるような記述がよい。そのうえで、具体的に「何が原因で課題が発生したか」を明記する。
4. できるだけ具体的に記述する。

> 「現場は○○が○○であった」の場合、原因としての「○○が」は、
>
> - 「現場条件」：粘性土地盤であり……、周辺に住宅が……
> - 「気象条件」：梅雨の期間に当たり……、冬季の平均気温が……
> - 「作業条件」：大型機械の搬入が困難な……、施工ヤードが狭く……
>
> 「状況」としての「○○であった」は、
>
> - 「品質管理」：コンクリート打設時の品質管理が……
> - 「安全管理」：作業員の墜落防止措置を……
> - 「工程管理」：工程の遅延を防ぐため……
>
> のように、状況を伝えるのが具体的であり、その上で技術的課題を明記する。

また、施工管理項目として「品質管理」が確定された場合、「○○の品質管理に留意した」と思いつくだけではなく「品質管理」というテーマのどの分野に焦点を合わせたのかまで踏み込んで記述すること。**課題の範囲**と合わせて記述することがポイントになる。

- 「工程管理」上の記述なのか「品質管理」について記述しているのか……判別しにくい。
- 「対処策」まで記述しないこと。
- 「工程短縮」と「品質管理」を一緒にしていないか。
- 段階的な調査の結果や、自らの施工法をあいまいな表現とならないように記述する。

記述スペースを意識して記述してから練習に移ること。（最大10行程度）

短い文章で多くの記述を割くことは困難であるため、記述スペースの範囲内で精一杯記述する。

相応の知識を持ち記述内容に反映していること、実際の経験に基づくことが重要である。

### 状況と課題を三段で組み、検討につなぐ

状況と課題の記述は、目的・概要、状況、課題の三段に分けて組むと、読み手が現場の絵を描いてから課題に入れる。

令和6年度以降は、工事名・立場・発注者名・場所・工期・主な工種・施工量を書く〔工事概要〕が別の欄になっており、設問（1）の現場状況・課題・検討した項目は1区画（200字前後）に収める。そのため一段目は、対象部分の規模か工法を1文で示すだけにとどめ、字数は状況と課題に回す。設問の区画は[令和7年度 第2次検定](/docs/civil-construction-1-secondary-r07)で確かめられる。

一段目の目的・概要は、その工事が何のためのどんな工事で、記述の対象が工事のどの部分かを示す。工事名の言い換えにせず、対象にする部分の規模、工法、材料のうち一つを挙げる。

二段目の状況は、課題の原因になった条件を数値で書く。「暑かった」ではなく打込み時のコンクリート温度、「軟弱だった」ではなく地盤のN値や含水比、「交通量が多い」ではなく規制できる時間帯で示す。品質なら打込み温度や運搬時間、安全なら作業床の高さや近接距離、工程なら作業可能日数のように、管理項目ごとに測れる条件がある。

三段目の課題は、状況の最後の一文を原因として受け、一文で言い切る。「○○であったため、○○が○○になるおそれがあり、○○の確保が課題であった」の形にする。

四段目にあたる検討した項目の書き方は、次の「検討した項目と検討理由及び検討内容」で扱う。

### 検討した項目と検討理由及び検討内容

1. 技術的な課題を明確にするとともに自分が何を目的にして（何を確保しようとして）どのような検討をしたか、技術的に問題点を具体的に示すこと。
2. ここは、内容そのものに一つだけに注目して集中して記述することがよい。課題についての文は短く、課題に至った理由と具体的内容の記述は長く書く。
3. 「解決方法」と書くと解を明確にする記述（間に合わなかったのに○○した）が求められるため避ける。

> 例：「地下水位低下工法、期間と作業場所の施設、構造物基礎形式の検討（メリット、デメリット）」
>
> 上記のような技術的検討を明確に記述する。
>
> さらにどういう結論に至ったかについて、スペースを考慮して記述する。根拠を基に結論を書く。

検討は項目ごとに、確保したいもの、その項目を挙げた理由、長所と短所の順にそろえる。長所だけを並べると比べた形にならず、短所に触れておくと選んだ根拠が立つ。検討には、どの手法が有効と判断したかの結論と根拠を書き、実施した工法・数値は対応処置に書く。

令和6年度以降の形式では、検討した項目は（1）の区画の後半に書く。区画の残りは限られるので、検討の理由は項目ごとに短く絞り、対応処置は（2）の区画に回す。令和5年度以前の形式では、検討理由と検討内容を独立した区画に書けるが、処置まで書き込まない点は同じである。

### 課題に対する検討の結果、現場で実施した対応処置とその評価

1. 技術的な検討の結果に基づきどのように対処したかについて記述するが、対応処置には具体的な数値を入れることが重要である。
2. 品質管理の場合は対応処置のベースとなる管理基準を明示して、対応処置は「工法、機械、材料、管理方法」をできるだけ具体的に記述する。
3. このような結果を出すことができたとの効果の記述を最後の3〜4行に記述するのがよい。

上記「検討結果」の記述は結果だけにしない。

- 例（悪い例）：地盤改良工法とした。
- 例（良い例）：○○の理由から○○工法を用いることとした。ただし、○○であるので○○にも留意した。

**(評価について)**

「評価」は施工した結果に対する評価のことである。記述としてはスペースの残りがわずかであるから、あまり多くを書けない。したがって、結論めいた評価にして端的に書くことが求められる。

- 上記の1.工事（施工）の結果としての評価であること。
- 上記の2.工事に対する自分の対処が正しかったとする補足的な内容であること。

記述スペースとの関係で記述の長さは限定される。記述の具体例としては以下のようになる。

- 上：「この結果、○○の品質が確保され、予定工期内に工事を完了できた。」
- 上：「この結果、○○日短縮することができ、工期内に工事が完了した。」等

#### 施工計画と施工管理の視点の違い

**施工計画**は施工着手前に工事内容（設計図書、仕様書、材料、方法、構造、資金）を検討することをいい、施工管理の視点と重なる部分もある。建設機械の使用計画、原価管理、品質管理の計画、工程計画、実行予算、施工方法の選定など全般的に事前に検討するもの（これらを「施工計画」と総称する）をいい、かつ社会的責任のもとに施工管理するものである。

## 出題項目に応じた現場でのヒント文章案

### 施工計画

施工計画の出題に際しては施工に先立つ事前の検討と各種工事への工種ごとの施工計画を記述することで対応する。施工の確認事項として施工計画書を作成して、主だった工種ごとに現場の施工計画・施工方法の設計と見直しの合理性の判定として工種ごとの施工計画を立案し記述する。

1. 現場条件としての制約事項と設計条件の見直しについて留意した。
2. 関連各社との施工条件、工法の比較検討、施工安全対策について留意した。
3. 関係者との協議書をまとめた。

**〔現場における施工（施工計画）（主として土木工事の場合）〕**

- **掘削や基礎工事　舗装工事**: 地盤条件に左右される現場において、相互の施工に影響の出ない施工計画を立案した。例えば、同一施工ヤードにおける掘削と舗装工の競合を避ける施工計画を策定した。地盤条件に対応した地盤改良の施工計画を立案した。
- **コンクリート工事**: 寒中あるいは暑中コンクリート施工に対する品質確保・温度管理の施工計画を立案した。
- **既設構造物に近接しての施工**: 近接の程度に合った工法・機種選定・防護方法等について施工計画をまとめた。
- **道路橋下に近接する地下埋設物がある場合**: 関連事業者との協議・施工条件・工法の比較検討・安全対策について施工計画を立案した。

上記のほか以下のヒントも検討されたい。

- 三角の地形部分から上下流部のコンクリート打設をするために、延長が長くなるため、コンクリートの配合についての施工計画を立案した。
- 仮設道路・仮設備の施工計画について検討した。
- 交差点部および流路工の施工計画について検討した。盛替え施工計画を策定した。
- 当初計画では仮締切の締切りが大きく半川施工が2回とも規模が大きいため、仮設構造物の規模について検討した。結果的に場内に仮置きすることで、盛替え数量および施工日数を短縮した。
- トンネル坑口部において、トンネル本体の施工と並行し、その施工区間の施工計画について検討した。

### 品質管理

**品質管理**とは、設計図書に基づいて施工し、工事目的物の所定の品質を確保するとともに品質の向上を図ることをいう。設計図書に定められた工事目的物の品質の仕様、形状及び寸法を実現するために主要品質の管理項目の設定、施工管理の方法などの管理内容を記述する。

**品質管理**をさらにいえば、設計図書に示された工事目的物の品質についての考え方の記述であり、品質管理の領域には以下がある。

1. 盛土、路盤工における締固めの管理（密度、含水比）
2. コンクリート工における部材のスランプ、空気量、圧縮強度、打設温度、養生

**出来形管理精度**の例としては以下のようなことがあげられる。

1. アスファルト舗装工における基層工
2. 長構造物の形状管理基準を遵守するための計測方法と`RI`管理方法

**〔参考：場面における品質管理の例〕**

現場の区分ごとに、着目する品質項目・測定方法・管理方法を整理すると以下のようになる。

- **盛土**: 品質項目＝締固め度、含水比 — 測定方法＝`RI`計、砂置換法 — 管理方法＝管理基準値確認
- **路盤工**: 品質項目＝支持力（`CBR`値）、締固め度 — 測定方法＝平板載荷試験、砂置換法 — 管理方法＝管理基準内
- **表層・基層**: 品質項目＝温度（敷均し温度）、締固め度 — 測定方法＝温度計、コア抜き — 管理方法＝温度管理、密度

〔現場における施工管理項目・品質管理〕（建設関連工事およびワンフロアー工区の場合）

- **粒度と品質の選定と管理**: コンクリート用骨材のふるい分け試験を行い、粗骨材の品質管理を実施した。【課題例】コンクリート材料に`JIS`規格品以外のものを使用するため、規格にない品質のものを管理する必要があった。舗装については路盤材の品質管理を行った。
- **鉄筋**: 配筋は定められた場所に正しく配置されていること（かぶりの確保）。鉄筋の配筋について、行政庁検査においてかぶりや、あきの確保不良を指摘されることが多い。鉄筋組立後の検査を確実にする品質管理を行った。
- **品質**: 材料搬入時の受入検査を確実に実施し、不良品の排除を行った。秋〜冬季はコンクリートの硬化が遅延する可能性があるため養生方法を工夫した。
- **表層・基層**: 舗装工事において表層の平坦性と品質を確保するため、施工温度管理に留意した。舗装の転圧温度を管理し、所定の締固め度を確保した。
- **コンクリート（運搬・打設管理）**: コンクリートの打設計画によりコンクリートプラントとの距離が離れている場合は、運搬時間を考慮し、レディーミクストコンクリートの配合設計を行い、現場到着時のスランプ、空気量の管理を確実にした。さらに工場で製造してから現場到着、打設までの時間を管理し、内部温度差を最小限にし、コールドジョイント対策を行った。また、運搬時間に対する品質確保として、打設後の養生方法を検討し、ひび割れ抑制を図った。
- **寒中コンクリート**: 冬期施工のコンクリート打設に際し、所定の初期強度確保のために保温養生等の検討を行った。配合設計を確認して、実際の施工温度管理に注意した。
- **暑中コンクリート**: 夏期施工のコンクリート打設に際し、練り混ぜ温度の上昇をおさえるとともに打設後のひび割れ対策としてパイプクーリングなどの対策を行い、打設後の湿潤養生を実施した。

### 工程管理

**工程管理**とは、施工計画に基づき工事の着手から完成に至るまでの間の各作業の管理を行うものである。

具体的には工程管理においては、毎日あるいは毎週、毎月と定期的に工事進捗の結果を把握し工程表との比較により工程を管理していくことが重要となる。具体的に管理の対象として以下がある。

1. 天候不順（外的要因、障害等）
2. 工事変更（設計変更等）
3. 使用機械等の故障

工事の進捗を計量的に把握するために定量化された進捗をもとに、それ以降の工程を見直して、その遅延を挽回し、その管理を重要視するが、工程の管理方式を採用して、主として自らの施工計画（施工工程）の内容を記述する。

このようにして作られた施工計画における外的要因等の配慮と施工計画上の工程に関する課題はリスクに対応して工程管理をしていくことのポイントとなる。

**〔現場における施工管理・工程管理〕（土木工事の場合）**

- **準備工**: 事前調査の結果、地下埋設物が計画より大幅に支障となることが判明し、関係機関との協議に時間がかかったため工程の見直しを行った。工程表を見直し、工法変更・施工機械の変更により工程の挽回を図った。代替案として1日当たりの施工量を増やすため、施工班を増班した。現場、作業員、施工機械の増加による工期短縮に努めた。
- **土留工**: 土留め工事の施工において、地下水位が高く難透水層が深い位置にあったことから当初計画の止水矢板では止水が不十分であることが判明し、工法の検討を行い工程の遅延を最小限に抑えた。
- **土工事杭工**: 土工事と杭工事が同時期に競合する工程であったため、施工順序の検討を行い、安全性を確保しつつ工程短縮を図った。
- **基礎工**: 基礎工事において当初の地盤調査と実際の地盤状況が異なることが判明し、基礎工法の変更が必要となった。工程への影響を最小限にするため、代替工法の比較検討を速やかに行った。
- **橋梁工**: 工程管理上の課題として、架設工事期間中に河川の出水期と重なるため、出水期前に主要工種を完了させる工程計画の見直しを行った。
- **舗装工**: 工程管理において、既設舗装の撤去と新設舗装の施工を交通規制の範囲内で完了させるため、施工手順と施工機械の配置を検討した。
- **マンホール工**: マンホールの設置工事において、プレキャスト部材を使用し、ジョイントを接着して工期を短縮した。
- **管渠工**: 管渠工事において、推進工法の採用により工期短縮を図った。
- **舗装補修工**: 交通量の多い道路において限られた規制時間内で舗装補修を完了させるため、工程管理の検討を行った。

### 工程の遅れの原因と、出来高管理の書き分け

遅れを書く前に、何で遅れを捉えたかをそろえておく。出来高管理は、出来形管理と混同されやすい。次の表は、上から順に、見る対象、比べる相手、記録の形、属する管理を対比している。

| 出来高管理 | 出来形管理 |
|---|---|
| 進み具合を見る | 完成した形を見る |
| 工程表の計画と比べる | 設計値と実測値を比べる |
| 累計の曲線で表す | 管理図表に記録する |
| 工程管理で使う | 出来形管理基準で行う |

出来形管理は、国土交通省地方整備局が発注する土木工事に適用される土木工事施工管理基準で、出来形を測定項目と測定基準に従って実測し、設計値と実測値を対比した管理図表で管理するものと定められている（[土木工事施工管理基準及び規格値（案）](https://www.mlit.go.jp/tec/content/001990185.pdf)・令和8年3月）。ほかの発注者の工事では、その発注者の基準に照らして書く。出来高は、その時点までに施工した分を、全体に対する割合や金額の累計で表したものである。

全体の進み具合は、曲線式工程表で管理する書き方が有効である。横軸に工期、縦軸に出来高の累計をとり、予定と実績の曲線の開きから遅れを早く捉える。許容範囲の帯（バナナ曲線）に実績が収まっているかを見る方法もある。

曲線では個々の作業の前後関係は分からないため、バーチャートやネットワーク式の工程表と組み合わせて、遅れた作業を特定する。曲線の描き方は[工程図表](/docs/civil-construction-1-textbook-schedule-charts)で確かめられる。

次に、遅れの原因を何に置くかで答案の性格が決まる。書きやすく説得力があるのは、施工者の段取りの外にある要因である。これを、調査や計画の段階で見込めたかどうかで分けると、書く中身が決まる。

見込めた要因（雨天や出水期の作業不能日、地元や関係機関との協議にかかる期間）は、見込みの置き方と、見込んだうえで何を準備したかまで書ける。施工中に判明した要因（想定外の湧水、地質の変化）は、判明した時点の測定値と、計画をどう組み直したかを書ける。

人員の手配漏れや段取りの不良を原因に据えると、技術の検討より自社の不手際の報告に読まれやすい。機械の故障を選ぶときも、故障そのものではなく、工程への影響をどう見積り、どう挽回したかを軸にする。

答案では、管理に使った工程表の種類、遅れを判断した数値（予定出来高と実績出来高の差など）、原因、挽回策の順に書くと、工程管理の記述として筋が通る。

### 安全管理

**記述上の目のつけどころ**：安全管理とは、施工に従事する者ならびに現場周辺の住民の安全確保と労働災害の予防に関するものである。

安全管理の概要としては、それらを踏まえたうえでの具体的な対処と工事内容にあった土工事、基礎工事、躯体工事、仕上げ工事、設備工事などの各工種において、さまざまに存在する危険に対して安全管理の具体策を記述することである。

安全管理の概要としては以下のとおりである。

- **体制と運営の仕組み**: 安全施工サイクルを回す活動、安全管理体制の整備、現場安全委員会の開催、安全の当番を現場の人が順に務める制度。
- **作業前後の確認と教育**: `KY`活動（危険予知活動）、ツールボックスミーティングの充実と作業場所ごとへの広がり、新規入場者への教育、安全点検、安全作業標準の整備と活用。
- **知識と意識を高める取組**: 講習会・研修会・見学会の開催、映像などの視聴覚教材を使った教育、場内放送による呼びかけ、特別安全日の設定。
- **参加意欲を引き出す仕組み**: 作業員からの提案制度、現場どうしや班どうしの安全競争、安全表彰。

> ※ どの現場でも行う安全活動をそのまま書くより、そこに工夫を加えた点や新しく始めた取組を書いたほうが評価されやすい。

### 公衆災害

公衆災害は、工事が原因となって周囲の人々の生命・身体・財産に危害を及ぼしたり、迷惑をかけたりすることをいう。第三者が死傷した場合に限らず、第三者の家屋や車両を壊した場合も含まれる。

ガス・水道・電気といった供給施設や、公道を傷つけた場合も公衆災害にあたる。

このうち交通安全対策は、次の三つの面に分けて書くと整理しやすい。

- **表示と照明**: 渋滞や交通上の危険を防ぐ道路標識・標示板、保安灯、遠くからでも工事箇所が確認できて安全に走行できる保安施設、迂回路の入口や要所の案内標示板、高い構造物や危険箇所の照明。
- **通行空間の確保**: 車道の幅員、歩行者の通路、車両が通れる路面、道路の排水。
- **誘導と維持管理**: 作業場所の付近で交通の流れを妨げない誘導、交通安全のために設けた施設を良好な状態に保つこと。

### 現場施工の安全管理

**作業者の安全管理（労働災害）**、建設機械の作業の安全管理（建設災害）などがある。安全管理の記述に関しては、それらを踏まえたうえでの具体的な対処と工事内容にあった各工種で存在する危険に対して安全管理の具体策を記述することである。

安全管理の記述は次のとおりである。

1. 作業場所の安全管理
2. 作業環境整備
3. 安全活動
4. `KY`活動
5. ツールボックスミーティングの充実、現場場所への拡張

**〔現場における施工管理項目・安全管理〕**

- **安全管理全般**: 安全施工サイクルにもとづき全工事の安全管理を行った。工事の着手前にリスクアセスメントを行い、危険作業を抽出して対策を検討した。日々の`KY`活動を確実に実施し、危険作業の低減に努めた。危険予知活動の結果を受け、危険作業の低減のために安全ミーティングを行い、指差し呼称、危険作業の抽出と対策を実施した。安全パトロールを毎日実施し、不安全行動・不安全状態の是正を行った。ヒヤリハット活動を推進し、事故の未然防止に努めた。
- **急斜面での作業**: 切土法面の施工において、急勾配の法面作業が伴うことから、作業員の墜落・転落防止対策が課題であった。作業員に対する安全帯（ハーネス型）の使用を義務づけるとともに、`○○`m以上（`○○`mを超える）の法面では親綱の設置と防護ネットの設置を行った。
- **高所足場での作業**: 橋梁工事において足場上での作業が多く、墜落災害防止が重要課題であった。足場の設置基準の遵守、手すり・中さん・巾木の設置、安全ネットの張設を行い、毎日の点検を実施した。
- **大規模掘削作業**: 大規模な掘削作業において、法面崩壊・土砂崩壊による労働災害の防止が課題であった。地山の状態を観察し、必要に応じて法面勾配の変更や土留め支保工の設置を行った。

## 経験記述は完成答案を雛形にするのが最短

「どう書けばいいか分からない」状態を最短で脱するには、答案の型と完成例を手に入れ、自分の現場の工種・テーマに置き換えて書き上げるのが近道である。

<Callout type="tip" title="2テーマの全組合せまで備えるなら">
本文中間で案内した完成答案集に加えて、現行の 2 テーマ必答形式を組合せ単位で準備したい場合は、5 管理の全 10 組合せを網羅した組合せ大全が対応します。
</Callout>
