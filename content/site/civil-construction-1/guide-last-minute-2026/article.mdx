2026-05-16 時点で、第1次検定まで約7週間、第2次検定まで約20週間です。残り時間で成果を最大化するには、1次は問題B（施工管理）の完全暗記と問題Aの分野絞りが最短ルート。2次は経験記述の型を1次前から並行して仕込んでおくと焦りません。本ガイドでは、この直前期にやるべきことを日程順に整理します。

## 試験スケジュール

2026年度の主要な日程は以下のとおりです。

| 時期 | イベント |
|---|---|
| 2026年3月上旬 | 受験申込受付開始 |
| 2026年7月初旬 | **第1次検定**（日曜日） |
| 2026年9月上旬 | 1次合格発表 |
| 2026年10月初旬 | **第2次検定**（日曜日） |
| 2026年1月下旬 | 2次合格発表（予定） |

<Callout type="note" title="日程の確認先">
正式な試験日・申込期間は一般財団法人 全国建設研修センターの公式サイトで必ず確認してください。年度によって1〜2週間前後することがあります。
</Callout>

試験の出題構成・合格基準の全体像は[出題傾向と得点戦略](/docs/civil-construction-1-guide-strategy)で詳しく解説しています。

## 第1次検定 直前対策（残り7週間）

### 試験構成の再確認

第1次検定は96問出題・65問解答のマークシート方式です。

- **問題A**（61問出題・30問選択）: 土木一般・専門土木・法規
- **問題B**（35問必須）: 施工管理

合格ラインは全体の60%。65問中39問以上の正解が目安です。問題Aで選択を活かして苦手を回避し、問題Bで確実に得点する戦略が最も再現性が高いでしょう。

### 問題B（施工管理）— 最優先

問題Bは35問すべて必須解答。[施工管理4大管理まとめ](/docs/civil-construction-1-guide-four-management)を軸に、以下の順で完全暗記を目指します。

- **安全管理**（8〜10問）: 統括安全衛生責任者の選任要件、特定元方事業者の義務、度数率・強度率の計算式
- **品質管理**（5〜7問）: X̄-R管理図の読み方、コンクリートの品質規格値、アスファルト舗装の締固め度
- **工程管理**（5〜7問）: ネットワーク工程表のクリティカルパス、フロート計算
- **環境保全**（5〜7問）: 騒音規制法85dB・振動規制法75dBの基準値、特定建設作業の届出先
- **施工計画**（3〜5問）: 仮設計画、工種別施工手順

<Callout type="warn" title="問題Bは選択不可">
問題Bは全問必須解答のため、苦手分野を切り捨てることができません。安全管理が最多出題ですので、労働安全衛生法の数値（50人・30人の選任要件、高さ2m以上の墜落防止など）は確実に押さえてください。
</Callout>

品質管理の詳細は[品質管理の要点](/docs/civil-construction-1-guide-quality-management)、工程管理の詳細は[工程管理の要点](/docs/civil-construction-1-guide-schedule-management)で確認できる。

### 問題A — 分野を絞って選択

#### 土木一般（15問出題・12問選択）

3問だけ捨てられます。土工・コンクリート・基礎工の3分野が均等に5問ずつ出題されるため、全分野を押さえるのが効率的です。

- **土工**: 締固め機械の適用土質、盛土材料の品質基準
- **コンクリート**: スランプ・空気量の規格値、各種セメントの特性
- **基礎工**: 打込み杭・場所打ち杭の施工上の留意点

コンクリートの詳細は[コンクリートの重要ポイント](/docs/civil-construction-1-guide-concrete-key-points)を参照してください。

#### 専門土木（34問出題・10問選択）

24問を捨てられます。**得意な3〜4分野に絞る**のが鉄則です。

以下の分野から10問が確保できる組み合わせを選んでください。

- **土工・軟弱地盤**: 圧密沈下、地盤改良工法
- **コンクリート構造物**: 鉄筋のかぶり厚、ひび割れ対策
- **河川・砂防**: 護岸工、堰・水門の構造
- **道路・舗装**: アスファルト混合物の品質、路床・路盤の規格値
- **上下水道**: 管の接合方法、推進工法

R07の第1次検定の出題傾向は[令和7年度 第1次検定 問題A](/docs/civil-construction-1-primary-r07-a)で確認できます。

#### 法規（12問出題・8問選択）

4問を捨てられます。[法規の重要ポイント](/docs/civil-construction-1-guide-law-key-points)の9法のうち、以下の4法が優先度が高いでしょう。

| 法令 | 頻出テーマ |
|---|---|
| 建設業法 | 主任技術者・監理技術者の専任要件、下請契約の制限 |
| 労働安全衛生法 | 特定元方事業者の義務、特別教育・技能講習 |
| 労働基準法 | 労働時間・割増賃金・年次有給休暇の数値 |
| 建築基準法 | 建築確認申請が不要な工事、仮設建築物の扱い |

### 1次検定 7週間スケジュール

残り7週間は以下のフェーズで配分する。

| 週 | フォーカス |
|---|---|
| 1週目（今） | 問題Bの安全管理・施工計画を過去問で一通り把握 |
| 2週目 | 問題Bの品質管理・工程管理・環境保全を集中 |
| 3週目 | 問題Aの土木一般15問を5年分の過去問で反復 |
| 4週目 | 専門土木で選択する3〜4分野を確定し過去問5年分 |
| 5週目 | 法規の優先4法を過去問で確認。弱点の問題Bを再補強 |
| 6週目 | R07・R06・R05の模擬演習（時間計測）。苦手箇所の絞り込み |
| 試験前週 | 正答率が低い問題のみ再確認。新規学習はしない |

R06・R05の出題は[令和6年度 第1次検定 問題A](/docs/civil-construction-1-primary-r06-a)・[問題B](/docs/civil-construction-1-primary-r06-b)でそれぞれ演習できます。

<Callout type="tip" title="過去問3周の鉄則">
同じ問題が毎年表現を変えて繰り返し出題されます。新しい参考書を買うより、過去問3〜5周のほうが得点に直結します。1周目は解説を読みながら、2周目以降は正誤確認にとどめて速度を上げてください。
</Callout>

## 第2次検定 直前対策（残り約20週間）

1次合格者のみが受験できますが、**経験記述の草稿は1次試験前から作成しておく**のが強く推奨されます。1次合格後では準備期間が2〜3ヶ月しかありません。

第2次検定の構成は以下のとおりです。

- **問題1（必須）**: 施工経験記述（品質管理・安全管理・工程管理・環境管理のいずれか）
- **選択問題（1）**: 問題4〜7から2問選択
- **選択問題（2）**: 問題8〜11から2問選択

### 経験記述（問題1）— 最重要

経験記述は配点が最も高く、**白紙や題意外の記述は不合格**になります。

記述する工事は**自分が直接関与した土木工事**に限ります。工種・規模・現場状況を具体的な数値で示すことが採点の基準です。

#### 3点セットで草稿を作る

[施工経験記述 出題傾向と対策](/docs/civil-construction-1-secondary-experience-writing-guide)の分析から、採点で評価される記述には以下の3点セットがあります。

1. **現場状況**: なぜその管理が必要だったか（地盤条件・気象・近接施工等）
2. **工夫・対策**: 具体的に何をしたか（工法・機材・数値目標）
3. **効果・結果**: どう良くなったか（定量的に）

[施工経験記述 改善例](/docs/civil-construction-1-secondary-experience-writing-examples)では失敗例と改善後の対比を確認できます。

#### R03〜R07の経験記述テーマ

直近5年のテーマは以下のとおりです。

| 年度 | 設問1 | 設問2 |
|---|---|---|
| R07 | 品質管理 | 環境対策 |
| R06 | 品質管理 | 安全管理 |
| R05 | 品質管理 | 工程管理 |
| R04 | 品質管理 | 安全管理 |
| R03 | 品質管理 | 工程管理 |

R03〜R07で設問1は**品質管理が5年連続**で出題されています。設問2は安全管理・工程管理・環境対策が交互に出題される傾向だ。

<Callout type="warn" title="環境対策は3軸で準備">
R07設問2の環境対策は「周辺環境（騒音・振動・水質）」「自然環境（生態系）」「建設副産物（CO2削減・再資源化）」の3軸から1つを選んで記述する形式でした。2026年度も同様の可能性があるため、3軸それぞれの草稿を用意しておくと安心です。
</Callout>

直近の経験記述問題は[令和7年度 第2次検定](/docs/civil-construction-1-secondary-r07)で確認できます。

### 学科記述（選択問題）— 5分野の基礎を固める

選択問題は以下の5分野から出題されます。自分が選ぶ4問（1＋2から各2問）を事前に決めておいてください。

#### コンクリート工

配合・打込み・養生の数値管理が頻出です。

- **水セメント比**: 水密性が必要な構造物は55%以下
- **打重ね時間**: 外気温25℃以下は2.5時間以内、25℃超は2時間以内
- **湿潤養生期間**: 普通ポルトランドセメントは最低5日

[コンクリート工 基礎解説](/docs/civil-construction-1-secondary-concrete-basics)で詳細を確認してください。

#### 土工

土の締固めと軟弱地盤対策が頻出です。

- **締固め管理**: 最大乾燥密度の90%以上（盛土の品質管理）
- **軟弱地盤対策**: サンドドレーン工法、プレロード工法の適用条件

[土工 基礎解説](/docs/civil-construction-1-secondary-earthwork-basics)を参照してください。

#### 品質管理

統計的手法（管理図・ヒストグラム）と検査方法が頻出です。

[品質管理 基礎解説](/docs/civil-construction-1-secondary-quality-management-basics)を参照してください。

#### 工程・施工計画

ネットワーク工程表の計算と施工手順の論述が出題されます。

[施工計画 基礎解説](/docs/civil-construction-1-secondary-construction-plan-basics)を参照してください。

#### 安全管理（労働安全衛生法）

設置届・特別教育・作業主任者の選任区分が最頻出です。特に高所作業（2m以上）と土止め支保工の規定は必ず確認してください。

### 2次検定 20週間スケジュール

1次試験前の準備を含め、以下のフェーズで進める。

| 時期 | フォーカス |
|---|---|
| 5〜6月（今） | 経験記述の草稿を品質管理・安全管理・環境対策の3テーマで作成 |
| 7月（1次直前） | 1次検定に集中。経験記述草稿はいったん置く |
| 8月（1次合格後） | 経験記述草稿を見直し・精度向上。学科記述5分野の基礎を確認 |
| 9月前半 | 選択する4問の分野を確定。R07・R06の過去問で解答パターンを掴む |
| 9月後半 | 経験記述の清書。学科記述の頻出数値・キーワードを暗記 |
| 試験前週 | 経験記述の最終確認のみ。新しい分野には手を出さない |

## 過去問頻出パターン（R03〜R07）

### 1次検定の共通テーマ

R03〜R07で繰り返し出題されるテーマを分野別に整理した。

**施工管理（問題B）の安定テーマ**
- 統括安全衛生責任者の選任基準（50人・30人）
- ネットワーク工程表のクリティカルパス計算
- X̄-R管理図の読み方と工程の安定判断
- 騒音85dB・振動75dBの特定建設作業基準

**法規の安定テーマ**
- 主任技術者と監理技術者の専任要件（建設業法）
- 安全衛生推進者の選任人数基準（労安法）
- 年次有給休暇の発生要件と付与日数（労基法）

### 2次検定の共通テーマ

R03〜R07の2次検定では以下のパターンが繰り返されています。

- 経験記述: **品質管理が設問1に連続出題**。対象工事の具体性と数値記述が採点の分岐点
- コンクリート工: 養生方法と期間の論述
- 土工: 盛土の締固め管理手順
- 安全管理: 労働安全衛生法に基づく設置届・資格者の配置

[令和7年度 第1次検定 問題B](/docs/civil-construction-1-primary-r07-b)と[令和7年度 第2次検定](/docs/civil-construction-1-secondary-r07)で直近の問題を確認してください。

## 当日の持ち物・直前1週間チェック

### 試験当日の必携品

忘れると受験できないものを確認しておこう。

- 受験票（写真貼付済み）
- 鉛筆またはシャープペンシル（複数本）、消しゴム
- HBの鉛筆が推奨（マークシートは濃く塗りつぶせる硬さ）
- 時計（スマートウォッチ不可）
- 身分証明書
- 昼食・飲み物（会場周辺に店舗がない場合あり）

### 直前1週間のチェックリスト

1次・2次それぞれ、最後の1週間は新しいことに手を広げず、確認事項を絞り込みます。

<Callout type="note" title="1次検定（7月）の直前1週間">
- 問題Bの頻出数値（50人・30人・2m・85dB・75dB）をまとめた自作メモを作る
- 苦手だった問題だけ再確認する（新しい分野は手を出さない）
- 試験会場までの交通手段と所要時間を確認する
- 試験開始・終了時刻と問題A・Bそれぞれの解答時間配分を確認する
</Callout>

10月の2次検定でも、直前1週間の過ごし方は同じ発想です。

<Callout type="note" title="2次検定（10月）の直前1週間">
- 経験記述を音読し、工種・現場状況・工夫・効果の3点セットが漏れていないか確認する
- 選択した4問分野の頻出キーワードをまとめた自作メモを最終確認する
- 3問以上解答した場合は減点（選択問題は必ず2問ずつ）を再確認する
- 解答用紙の選択欄に○印を忘れずに記入する（採点除外の防止）
</Callout>
