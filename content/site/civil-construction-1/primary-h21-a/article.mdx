## 問題 No.1

土の原位置試験に関する次の記述のうち，**適当でないもの**はどれか。

1. 盛土の品質管理の目的で行う現場密度の測定は，締固めた土の締固め度，飽和度，空気間隙率等を求めるものである。

2. 一般にトラフィカビリティは，コーンペネトロメータで測定した塑性指数で示される。

3. ベーン試験は，軟弱な粘性土，シルト，有機質土のせん断強さを現地において測定するものである。

4. 現場透水試験は，地盤に井戸又は観測孔を設け，揚水又は注水時の水位や流量を測定し，地盤の原位置における透水係数を求めるものである。

<details>
<summary>解答・解説</summary>

**正答：2**

1. 現場密度の測定は、締固めた土の乾燥密度から締固め度を、さらに飽和度や空気間隙率を求めるもので、盛土の品質管理に用いる。 ✅
2. トラフィカビリティ（建設機械の走行性）は、コーンペネトロメータで測定したコーン指数で示す。塑性指数ではない。 ❌
3. ベーン試験は、軟弱な粘性土・シルト・有機質土の原位置でのせん断強さ（非排水せん断強さ）を求める試験である。 ✅
4. 現場透水試験は、井戸や観測孔で揚水・注水時の水位や流量を測り、原位置の透水係数を求める試験である。 ✅

## 問題 No.2

土工作業における土量の変化率に関する次の記述のうち，**適当でないもの**はどれか。

1. 土量の変化率Lは，地山土量をほぐした土量で除したものであり，土の運搬計画を立てるときに用いられる。

2. 土量の変化率Cは，締固めた土量を地山の土量で除したものであり，土の配分計画を立てるときに必要である。

3. 土量の変化率Cは，その工事に大きな影響を及ぼす場合，試験施工によってその値を求めることが望ましい。

4. 岩石の変化率は，測定そのものが難しいために，施工実績を参考にして計画し，実態に応じて変更していくことが望ましい。

<details>
<summary>解答・解説</summary>

**正答：1**

1. Lは「ほぐした土量÷地山土量」で表す。記述は地山土量をほぐした土量で除しており、分子と分母が逆である。 ❌
2. Cは「締固め後の土量÷地山土量」で、土の配分計画（切土と盛土の土量配分）に必要な値である。 ✅
3. Cが工事に大きく影響する場合は、試験施工で値を求めることが望ましい。 ✅
4. 岩石は変化率の測定自体が難しく、施工実績を参考に計画し、実態に応じて見直していくのがよい。 ✅

<ExamPoint>土量変化率LとCの定義（分子・分母の取り違え）</ExamPoint>

</details>

## 問題 No.3

盛土の施工に関する次の記述のうち，**適当でないもの**はどれか。

1. 盛土の締固め時には，含水比の調整を丁寧に行う必要がある。

2. 締固め中に降雨があったときは，雨水が締固めている土に浸入しにくいように，表面に勾配をつけて締め固める。

3. 切土と盛土の境界部においては，完成後に盛土部が沈下することが多いので，盛土部の地山の傾斜地盤には段切りを行なってはならない。

4. 構造物の周辺は，締固め機械が近寄りにくいので，小型の突固め機等を使用して入念に締め固めることが必要である。

<details>
<summary>解答・解説</summary>

**正答：3**

1. 締固めの良否は含水比に大きく左右されるため、含水比の調整を丁寧に行う。 ✅
2. 降雨時は表面に勾配をつけて排水し、雨水が締固め中の土に浸入しにくくする。 ✅
3. 傾斜地盤上の盛土では、盛土と地山を一体化し滑りを防ぐため段切りを行う。段切りを行ってはならないとする記述が誤り。 ❌
4. 構造物周辺は大型機械が近寄れないため、小型の突固め機等で入念に締め固める。 ✅

<ExamPoint>切盛境界・傾斜地盤の盛土で段切りは必須</ExamPoint>

</details>

## 問題 No.4

土工工事の施工時における排水に関する次の記述のうち，**適当でないもの**はどれか。

1. 砂質土で盛土する場合は，雨水により盛土材料の含水量が増大し，せん断強度が低下する場合があるので法面付近ですべりが生じやすい。

2. 軟弱地盤上に盛土をする場合は，盛土内に地下水が上昇して，悪影響を及ぼすことがあるので，軟弱地盤の表面に排水層として敷砂を施工するとよい。

3. 切土部は，常に切土法面からの雨水等が湛水しないように法尻部にトレンチを設け排水するとよい。

4. 礫質土で盛土する場合は，盛土材料の排水性が良好であるが，雨水により土中の間隙水圧が上昇しやすく，法面付近でのすべりが生じやすい。

<details>
<summary>解答・解説</summary>

**正答：4**

1. 砂質土は雨水で含水量が増すとせん断強度が低下しやすく、法面付近ですべりが生じやすい。 ✅
2. 軟弱地盤上の盛土では、地盤表面に敷砂を施工して排水層とし、盛土内への地下水上昇を防ぐ。 ✅
3. 切土部は法尻部にトレンチ（排水溝）を設け、法面からの雨水が湛水しないよう排水する。 ✅
4. 礫質土は排水性が良好で、雨水が入っても間隙水圧が上昇しにくい。間隙水圧が上昇しやすいとする記述が誤り。 ❌

<ExamPoint>礫質土は排水性が良く間隙水圧が上がりにくい</ExamPoint>

</details>

## 問題 No.5

軟弱地盤対策工法に関する次の記述のうち，**適当でないもの**はどれか。

1. サンドマット工法は，敷砂を地盤上に施工して，軟弱層の圧密のための上部排水層の役割を果たすものである。

2. ペーパードレーン工法は，粘性土の地盤中にネット状の袋に詰めた砂の排水層を鉛直方向に設置し，圧密排水を促進させるものである。

3. 地下水低下工法は，地盤中の地下水位を低下させることにより軟弱層の圧密促進を図るもので，一般にウェルポイント，ディープウェルなどがある。

4. 置換工法は，軟弱土を良質土に置換えることにより盛土に対する安定確保と沈下量の減少を図るものである。

<details>
<summary>解答・解説</summary>

**正答：2**

1. サンドマットは敷砂による上部排水層で、軟弱層の圧密排水の役割とともに施工機械の走行性も確保する。 ✅
2. ネット状の袋に砂を詰めて鉛直に設置するのは袋詰めサンドドレーン工法。ペーパードレーンは紙（カードボード）製のドレーン材を打設する工法である。 ❌
3. 地下水低下工法は、ウェルポイントやディープウェルで地下水位を下げ、有効応力を増して圧密を促進する。 ✅
4. 置換工法は、軟弱土を良質土に入れ替え、盛土の安定確保と沈下量の減少を図る。 ✅

## 問題 No.7

コンクリートに使用する砕砂に関する次の記述のうち，**適当なもの**はどれか。

1. 砕砂は，川砂と比べて粒形が丸みをおびている。

2. 材料分離を抑えるには，砕砂中に3～5％の石粉が混入しているほうが効果がある。

3. 砕砂の粒形判定実積率は，小さいほうがよい。

4. 砕砂の密度に関する品質は，表乾密度を標準とする。

<details>
<summary>解答・解説</summary>

**正答：2**

1. 砕砂は岩を砕いて作るため角張った粒形で、丸みをおびているのは川砂の方である。 ❌
2. 砕砂に石粉が3〜5％程度含まれると、粘性が増して材料分離抑制に効果がある。 ✅
3. 粒形判定実積率は大きいほど粒形が良い（丸みがある）。小さいほうがよいとする記述は逆である。 ❌
4. 砕砂の密度の品質規定は、表乾密度ではなく絶乾密度を標準とする。 ❌

## 問題 No.8

コンクリートの配合に関する次の記述のうち，**適当なもの**はどれか。

1. 同一な配合条件における単位水量は，粗骨材の最大寸法が20 mm の場合と40 mm の場合を比べると，一般に，40 mm の場合の方が少なくなる。

2. 水セメント比が同じで，AEコンクリートとそうでないコンクリートを比較した場合，AEコンクリートの方が凍結融解作用に対する抵抗性ならびに圧縮強度とも大きくなる。

3. 細骨材率は，コンクリート中に含まれる全骨材質量に対する細骨材の質量の比を示したものである。

4. 水セメント比は，強度と耐久性及び水密性から必要とされる水とセメントの質量比のうち，最も大きい値とする。

<details>
<summary>解答・解説</summary>

**正答：1**

1. 粗骨材の最大寸法が大きいほど、同じスランプを得るのに必要な単位水量は少なくなるため、40mmのほうが20mmより少なくなる。 ✅
2. 同じ水セメント比では、AEコンクリートは凍結融解抵抗性が高まるが、空気量が増えるため圧縮強度は低下する。強度も大きくなるとする点が誤り。 ❌
3. 細骨材率は、全骨材の絶対容積に対する細骨材の絶対容積の比で表す。質量比ではない。 ❌
4. 水セメント比は、強度・耐久性・水密性などから求めた値のうち最小の値とする。最大とする点が誤り。 ❌

<ExamPoint>細骨材率は絶対容積比・水セメント比は最小値を採る</ExamPoint>

</details>

## 問題 No.9

コンクリートの締固めに関する次の記述のうち，**適当でないもの**はどれか。

1. 締固めにおいては，内部振動機をコンクリート中に鉛直に差し込み，引き抜くときはゆっくりと引き抜くようにする。

2. 締固めにおいては，打ち込まれたコンクリートからエントレインドエアを追い出すようにする。

3. いったん締固めが完了した後，再振動を行う場合は，再振動によってコンクリートの締固めが可能な範囲でできるだけ遅い時期がよい。

4. 締固めにあたっては，上下層が一体となるように内部振動機を下層のコンクリート中に10 cm 程度挿入しなければならない。

<details>
<summary>解答・解説</summary>

**正答：2**

1. 内部振動機は鉛直に差し込み、引き抜くときは穴が残らないようゆっくり引き抜く。 ✅
2. 締固めで追い出すのは巻き込んだ空気（エントラップトエア）である。AE剤が連行した微細な空気（エントレインドエア）は残すべきもので、追い出さない。 ❌
3. 再振動は、再振動で締固めが可能な範囲でできるだけ遅い時期に行うと、沈下ひび割れの防止や強度増進に効果がある。 ✅
4. 上下層を一体化させるため、振動機は下層のコンクリート中に10cm程度挿入する。 ✅

<ExamPoint>エントレインドエア（連行空気）とエントラップトエア（巻込み空気）の区別</ExamPoint>

</details>

## 問題 No.10

鉄筋の加工及び組立に関する次の記述のうち，**適当でないもの**はどれか。

1. 重ね継手の重ね合せの部分は，鉄線によりしっかりと緊結するが，焼きなまし鉄線で巻く長さは短くするのがよい。

2. 鉄筋は，常温で加工することが原則である。

3. 型枠に接するスペーサは，モルタル製あるいはコンクリート製を使用することが原則である。

4. やむを得ず溶接した鉄筋を曲げ加工する場合には，溶接した部分より鉄筋直径分だけ離れたところで行うことが原則である。

2. 鉄筋は常温で加工するのが原則である。 ✅
3. 型枠に接するスペーサは、モルタル製またはコンクリート製を原則とする。 ✅
4. 溶接した鉄筋を曲げる場合は、溶接部から鉄筋直径の10倍以上離れた位置で行うのが原則である。直径分では不足。 ❌

## 問題 No.11

コンクリートの養生に関する次の記述のうち，**適当でないもの**はどれか。

1. 日平均気温が15℃以上で高炉セメントB種を用いたコンクリートの湿潤養生期間は，7日とするのが標準である。

2. 膜養生は，コンクリート表面の水光りが消えた後，十分に時間が経過してから行うのがよい。

3. 型枠及び支保工の取外しに必要な圧縮強度が早期に得られた場合でも，定められた標準的な湿潤養生期間を保つ必要がある。

4. 海水，アルカリや酸性の水などの侵食作用を受ける場合には，普通の場合よりも養生期間を延ばす必要がある。

<summary>解答・解説</summary>

2. 膜養生剤は、表面の水光りが消えた直後に散布する。十分時間が経過してからでは、ひび割れ等が生じてしまい効果が薄れる。 ❌
3. 型枠取外しに必要な強度が得られても、標準的な湿潤養生期間は確保する。 ✅
4. 海水や酸性水などの侵食作用を受ける場合は、普通の場合より養生期間を延ばす。 ✅

<ExamPoint>膜養生剤の散布時期は水光りが消えた直後</ExamPoint>

## 問題 No.12

既製杭の施工におけるプレボーリング杭工法に関する次の記述のうち，**適当なもの**はどれか。

1. 根固め液は，所定の支持力を発現するため，掘削孔の先端部周辺から杭頭部までの孔壁周辺の砂質地盤と十分にかくはんしながら確実に注入する。

2. 杭を沈設する際には，孔壁を削ったり杭体を損傷させないで，注入した杭周固定液が杭頭部からあふれないように施工する。

3. 地盤の掘削抵抗を減少させるため，掘削中は掘削液を掘削ビットの先端部から吐出させ，その量は掘削速度に応じて調節する。

4. 杭周固定液に用いるセメントミルクは，杭周固定液の硬化に伴うブリーディングや逸水によって液面が沈降し，掘削孔壁と杭体との間に隙間が生じることがあるが，補充する必要はない。

<details>
<summary>解答・解説</summary>

**正答：3**

1. 根固め液は、掘削孔先端部周辺の支持層の地盤と十分にかくはんして注入する。杭頭部までの孔壁周辺とする範囲の記述が誤り。 ❌

騒音規制法に基づき，指定地域内で特定建設作業を伴う建設工事を行う場合，市町村長に届け出る事項として，**該当しないもの**は次のうちどれか。

1. 特定建設作業の開始及び終了の時刻

2. 特定建設作業にかかる工事規模及び概算工事費

3. 騒音の防止の方法

4. 特定建設作業の場所及び実施の期間

<details>
<summary>解答・解説</summary>

**正答：2**

1. 特定建設作業の開始及び終了の時刻は、届出事項に含まれる。 ✅
2. 工事規模・概算工事費は届出事項に含まれない。届出事項は氏名、場所、期間、作業の種類、騒音の防止方法、時刻などである。 ❌
3. 騒音の防止の方法は、届出事項に含まれる。 ✅
4. 特定建設作業の場所及び実施の期間は、届出事項に含まれる。 ✅

<ExamPoint>届出事項に工事規模・概算工事費は含まれない</ExamPoint>

</details>

## 問題 No.60

振動規制法による指定地域内で次の作業をいずれも2日間行なった。特定建設作業に**該当しないもの**は次のうちどれか。

1. 鋼球を使用してボックスカルバートを破壊する作業

2. 作業地点が1日100メートル以上連続的に移動する締固めを，8トンの振動ローラを用いて行う作業

3. ジャイアントブレーカで，橋台1基のパラペットの取壊しを行う作業

4. 工事延長40メートルの区間の舗装版取壊しを，舗装版破砕機を使用して行う作業

<details>
<summary>解答・解説</summary>

**正答：2**

1. 鋼球を使用して工作物を破壊する作業は特定建設作業に該当する。 ✅
2. 振動ローラによる締固め作業は、振動規制法の特定建設作業に該当しない。ここで挙がる8トンの振動ローラの作業は対象外。 ❌
3. ジャイアントブレーカによる取壊し作業は、1日の作業地点移動が50 m を超えなければ特定建設作業に該当する。橋台パラペットは移動しないので該当。 ✅
4. 舗装版破砕機の作業は、1日の作業地点の移動が50 m を超えなければ該当する。工事延長40 m なので該当。 ✅

<ExamPoint>振動ローラの締固めは特定建設作業ではない</ExamPoint>

</details>

## 問題 No.61

海上衝突予防法上，港内において，浚渫船が日没後に浚渫作業を行うとき，他の船舶の通航の妨害となるおそれがある場合に表示しなければならない燈火に関する次の記述のうち，**誤っているもの**はどれか。

1. 作業によって他の船舶の通航の妨害となるおそれがある側のげんに，紅色の全周燈2個を垂直線上に掲げる。

2. 対水速度がある場合は，マスト燈2個及びげん燈一対を掲げ，かつ，できる限り船尾近くに船尾燈1個を掲げる。

3. 最も見えやすい場所に紅色のせん光燈1個を掲げ，かつ，その垂直線上の上方及び下方にそれぞれ紅色の全周燈1個を掲げる。

4. 他の船舶が通航することができる側のげんに，緑色の全周燈2個を垂直線上に掲げる。

<details>
<summary>解答・解説</summary>

**正答：3**

1. 障害物側（通航の妨害となるおそれがある側）のげんに、紅色の全周燈2個を垂直線上に掲げる。記述のとおり。 ✅
2. 対水速度がある場合は、マスト燈2個、げん燈一対、船尾燈を掲げる。記述のとおり。 ✅
3. 浚渫船など操縦性能制限船の燈火は紅白紅の全周燈3個で、せん光燈ではない ❌
4. 通航できる側のげんに、緑色の全周燈2個を垂直線上に掲げる。記述のとおり。 ✅

<ExamPoint>運転不自由・作業船の燈火は紅白紅の全周燈3個（せん光燈ではない）</ExamPoint>

</details>
