## アスファルト舗装の補修

アスファルト舗装の補修工法には、①構造的対策を目的としたもの、②機能的対策を目的としたものがある。

**構造的対策**は、主として全層に及ぶ補修工法で、舗装の強度低下に起因した破損が路床・路盤層にまで及ぶ構造的破損に対して実施する。**機能的対策**は主として表層の補修工法で、舗装の強度低下に対応した施工ではなく、路面の表面・基層のみに局部的な凹凸などの対策を行うものである。機能的対策の中には、予防的維持あるいは応急的に行う補修工法も含まれる。

### アスファルト舗装の破損の種類

アスファルト舗装の破損は多種多様であり、破損が生じる要因には舗装材料、舗装構造、施工、供用中の劣化や疲労があって、複数の要因が相互に影響し合い破損の原因となっている場合もある。主な破損の種類と状況は次のとおりである。

| 破損の種類 | 主な状況・発生位置 |
|---|---|
| 亀甲状ひび割れ（路床・路盤の支持力低下） | 主に走行輪跡部に発生 |
| ひび割れ（アスファルト混合物の劣化・老化） | 路面全体から発生し舗装全体へ拡大 |
| 温度応力によるひび割れ（横方向） | ほぼ一定間隔で発生。寒冷地に多い |
| 施工目地部のひび割れ | 縦方向。施工目地部に発生 |
| リフレクションクラック | コンクリート版・セメント安定処理路盤がある場合に、下層のひび割れが反映して発生 |
| ヘアークラック | 微細な縦方向のひび割れ。走行輪跡部に発生 |
| ポットホール | 舗装の劣化・老化等により路盤材が湧き出し、局部的な穴となる |
| ブリージング（フラッシュ） | アスファルト分が表面ににじみ出る現象 |
| 骨材飛散 | 走行輪跡部・舗装全面で骨材が飛散し路面が荒れる |
| わだち掘れ（路床・路盤の支持力低下） | 走行輪跡部が沈下する |
| わだち掘れ（塑性変形） | アスファルト混合物の側方流動による走行輪跡部の変形 |
| 平たん性の不良 | 路面の凹凸。走行輪跡部や交差点等に発生 |
| 骨材の剥落 | 走行輪跡部で骨材やバインダが剥がれる |
| 騒音値の増加 | 路面の荒れ・空隙の目詰まり等による走行音の増大 |

舗装の補修には維持と修繕がある。維持は、舗装の供用性能の低下防止または若干の向上を目的として実施する補修で、構造的な強化を目的としない。修繕は、舗装の構造強化を目的として実施する補修で、大幅に供用性能を回復させる。新設された舗装は当初は高い供用性能を持つが、交通開始後は交通量や疲労の影響で供用性能が徐々に低下し、破損の限界に達した時点で打換え等の修繕を行って新設時と同等の供用性能を回復する。この繰り返しが舗装のライフサイクルである。

### 補修工法の種類

アスファルト舗装の主な補修工法の種類と概要は次のとおりである。

| 補修工法の種類 | 概要 |
|---|---|
| **打換え工法**（再舗装） | 既設舗装を路盤もしくは路床まで打ち換える工法。切削などによる撤去材の再生利用を含む場合もある。 |
| **局部打換え工法** | 破損が局部的な区間について、当該箇所のみを対象に打ち換える工法。 |
| **線状打換え工法** | 線状に発生したひび割れに沿って舗装を打ち換える工法。 |
| **路上路盤再生工法** | 既設アスファルト混合物層を現位置で破砕し、セメントやアスファルト乳剤等の安定材を添加・混合して締め固め、路盤として再生する工法。 |
| **表層・基層打換え工法** | 表層・基層を打ち換える工法。オーバーレイ工法と組み合わせて用いられることも多い。 |
| **オーバーレイ工法** | 既設路面上に、厚さ**3**cm以上の加熱アスファルト混合物層を舗設する工法。機能向上や性能回復を目的とする場合も含む。 |
| **路上表層再生工法** | 既設路面の表層を加熱軟化させ、必要に応じて新規アスファルト混合物や再生用添加剤を加えて混合し直した材料で舗設する工法。乳剤式と加熱式がある。 |
| **薄層オーバーレイ工法** | 既設路面上に、厚さ**3**cm未満の薄い加熱アスファルト混合物層を舗設する工法。路上路盤再生工法との組み合わせも多い。 |
| **切削工法** | 路面の凹凸や不良部分を切削除去し平たん性を回復する工法。オーバーレイ工法・表面処理工法の事前処理として行われることも多い。切削深さはわずか（数mm程度）だが、費用対効果は比較的大きい。 |
| **シール材注入工法** | ひび割れに注入材料（加熱型・エマルション型等）を充填する工法。ひび割れの程度によって材料を使い分ける。 |
| **表面処理工法** | 既設路面の表面に乳剤を散布し、砂・砕石等を散布してローラで転圧する工法。アーマーコート工法（散布式）・スラリーシール工法・マイクロサーフェシング工法などがある。ひび割れ・骨材飛散・路面劣化などに対処する。 |
| **パッチング・段差すり付け工法** | ポットホール・くぼみ・段差などを応急的に処理する工法。パッチング材にはセメント系・アスファルト系・樹脂系がある。 |

### アスファルト舗装の補修工法の選定

補修工法の選定にあたっては、破損の程度に応じ、構造的対策と機能的対策のどちらが必要かを見極めたうえで、打換え・既設路盤再生・薄層オーバーレイ・オーバーレイ・路上表層再生等の候補から工法を絞り込む。選定の留意点を以下に示す。

- 流動によるわだちが原因で破損面積が大きい場合は、原因となっている箇所を除去したうえで表層・基層打換え工法を選定する。
- ひび割れの程度が大きい場合は、路床・路盤の破損の可能性が高いため、オーバーレイ工法より打換え工法を選定する。
- 路面のたわみが大きい場合は、路床・路盤のたわみ調査を実施してその原因を把握したうえで工法を選定する。路床・路盤に破損が生じている場合は、打換え工法を選定することが望ましい。
- 補修工法の選定においては、**舗装発生材を極力少なくすること**を考慮して工法の選定や断面の設計を行うことが重要である。
- オーバーレイ厚さは、沿道条件などから最大でも**15**cm程度とする。これ以上の厚さが必要となる場合は、他の工法を検討する。

### アスファルト舗装の打換え工法の留意点

打換え工法、局部打換え工法および線状打換え工法の施工上の留意点を以下に示す。

**1) 既設舗装の撤去**

- 既設舗装の撤去にあたり周囲への影響を及ぼすおそれがある場合は、施工箇所の周囲をコンクリートカッターで切削し、端部を明確に区切る（端部切り）。
- 2層以上の舗装を撤去する場合は、運搬しやすいよう細かく破砕するとともに、必要に応じて中間引き抜きも行う。
- ある程度大きな面積を撤去する場合は路面切削機械を使用することが効率的である。規模の大きな縦横打換えにおいては、大型の切削機械を使用することも有効である。
- 路床はできるだけ乱さないよう薄層ずつ掘削し、やむを得ず転石等で深掘りとなった箇所は良質土で埋め戻したうえで十分に締め固めておく。

**2) 加熱アスファルト混合物の施工**

- 施工に際しては下層の不陸（凹凸）を矯正し、特に下層が粒状路盤や路床の場合には、緩んだ箇所を十分に締め固めたのち各層ごとに仕上げる。
- 供用後の雨水浸透を防ぐため、継目部の締固めは特に入念に行い、加熱アスファルト混合物の締固めの留意点に準じて施工する。
- 線状打換えなどの施工では、供用後に継目部で段差が生じやすいので、施工上面と既設路面との間に段差が生じないよう入念に締め固めて仕上げておく。
- 加熱アスファルト混合物を1日のうちに2層以上舗設する場合や、早期の交通開放が必要な場合には、施工直後の混合物温度が交通開放温度まで十分に下がっているか、舗装表面の温度を確認する必要がある。
- 初期わだちの発生を抑制する必要がある場合には、必要に応じて通常より温度を約**30**℃程度低減させた中温化アスファルト混合物を用いる中温化技術を利用することがある。
- 表層の施工は、平坦性を確保するため、同じ厚みで連続的に舗設できる範囲をまとめて施工することが望ましい。

### アスファルト舗装のオーバーレイ工法の留意点

オーバーレイ工法、切削オーバーレイ工法および薄層オーバーレイ工法の施工上の留意点を以下に示す。

**1) オーバーレイ工法**

- 必要に応じて、側溝、街灯、マンホール、ガードレールなどの**蓋上げ**を行う。
- 既設表層の不良部分や大きな不陸（凹凸）は事前に処理しておく。
- 平坦性を確保するため、事前にレベリング工を行うことがある。
- タックコートは、既設路面に均一かつ確実に付着するよう、ごく薄めに塗布する。
- リフレクションクラックの発生を抑制・遅延させる場合は、クラック抑制シートの設置や、応力緩和層としての砕石マスチック舗装、改質アスファルト・改質アスファルト乳剤を用いた応力緩和層の採用などの対策を講じる。

**2) 切削オーバーレイ工法**

- 切削作業能率が交通等の影響を受ける場合には、路面ヒータなどを使用する。
- 切削くずはきれいに除去し、特に継目部などに切削くずを巻き込まないようにする。

**3) 薄層オーバーレイ工法**

- 薄層オーバーレイの施工後は、一般に早期の交通開放を避け、供用後の雨水浸透を防止するための養生を行う。
- 薄い混合物は温度低下が早いため、寒冷期には速やかに施工を行う。

## コンクリート舗装の補修

コンクリート舗装の補修工法は、補修の対象がコンクリート版そのものなのか、版の表面部なのかにより、**構造的対策**（工法）と**機能的対策**（工法）とに分けられる。

### 補修工法の種類（構造的対策）

構造的対策として用いる主な補修工法を次に示す。

| 工法 | 概要 |
|---|---|
| **打換え工法** | 広範囲にわたりコンクリート版そのものの破損が生じた場合に行う。コンクリートによる打換えとアスファルト混合物による打換えがあり、いずれの場合も路盤・路床等の補修措置を施したうえで行うこともある。 |
| **局部打換え工法** | 連続鉄筋コンクリート版において鉄筋が露出する程度の破損に対し現地で行う工法。鉄筋の腐食による欠損部を補修するため、板厚を確保したコンクリートを打設する。 |
| **オーバーレイ工法** | 既設路面上にアスファルト混合物層を舗設する工法。既設路面を基盤として使用するため、不良部分は事前に処理しておく。必要に応じて接着剤やパッチ修繕を行ったうえで実施する。 |
| **バーステッチ工法** | ひび割れを生じたコンクリート版に対し、ひび割れをまたぐように斜め孔をあけ、異形鉄筋（バー）をダウエルバーと同様の方法で埋め込み、版を一体化させて補強する工法。 |
| **注入工法** | コンクリート版の下に空洞が生じた場合、空洞部に材料を注入し版を支持させる工法。注入材料にはセメントミルク、アスファルト系材料等がある。 |

### 補修工法の種類（機能的対策）

機能的対策として用いる主な補修工法を次に示す。

| 工法 | 概要 |
|---|---|
| **粗面処理工法** | コンクリート版表面を、機械等により縦方向または横方向に粗面化する工法。 |
| **グルービング工法** | コンクリート版表面に溝を切る工法。排水性やすべり抵抗性の改善を目的とし、通常は交通方向に対して横方向に溝を切ることが多い。 |
| **パッチング工法** | コンクリート版に生じた破損箇所を材料で充填し、元の形状に復旧する工法。セメント系・アスファルト系・樹脂系のパッチング材が用いられる。 |
| **表面処理工法** | コンクリート版表面にペイントやポリマー等を塗布し、すべり抵抗の低下防止や目地部の補修等に用いる。ヘアークラック等の表面ひび割れには乳剤系表面処理などが行われる。 |
| **シーリング工法** | 目地部やひび割れに緩み・隙間が生じた場合の補修として行う工法。版間の空洞部からの浸水を防ぐため、シール材を注入する。 |

### コンクリート舗装の補修工法の選定

補修工法は、路面状況や目地の荷重伝達率等を調査し、コンクリート版の破損の種類と程度に応じて、上記の構造的対策・機能的対策の工法一覧から選定する。

### コンクリート舗装の打換え工法の留意点

- 既設コンクリート版の撤去は、版1枚を最小単位として行う。
- 路盤の掘削は、隣接する健全な部分に損傷を与えないよう、あらかじめカッタなどで切断したうえで行い、重機による振動の影響を抑えることが重要である。
- 路盤の締固めにあたっては、端部や隅角部の締固めが不十分になりやすいので、タンピングランマやハンドガイドローラなどを使用し、入念に締め固めるよう注意する。
- 既設コンクリート版と打換えコンクリート版とが接する縦目地には、原則としてタイバーを設置する。タイバーの設置はドリル削孔による。
- 既設の路側構造物と打換えコンクリート版との間には、瀝青系目地材などを用いて縁切りを行い、自由膨張できるようにしてから施工する。

### コンクリート舗装の局部打換え工法の留意点

**1) 隅角部の局部打換え**

- ひび割れの周囲をコンクリートカッタで**2〜3**cmの深さに切断する。このとき、切断線が交わる角の部分は応力集中を軽減するため丸みをつけておく。
- 鉄網は切断線に沿って切り、仕上げとする。鉄網を全て残すことが困難な場合は、**20〜30**cmを残して切り取ってよい。
- 路床・路盤に問題がある場合は補修・置換えを行う。施工面積が小さく転圧作業が困難な場合は、ソイルセメントなどで置き換えるとよい。
- 既設部分のコンクリートはチッピングにより細かく割り崩し、微粒粉を除去したのち、十分な付着性能を持つコンクリートを打設する。

**2) 版の横断方向のひび割れに沿う局部打換え**

- 版の横断方向に沿ってひび割れが生じた場合、そのひび割れが目地から**3**m以内であれば隅角部の局部打換え工法を適用し、目地から**3**m以上**5**m未満の部分に生じた場合は、そのひび割れ部を目地に準ずる方法で切断して局部打換えを行う。
- ひび割れが版の横断方向のほぼ全幅にわたる場合は、版1枚単位での打換えを行う。

### コンクリート舗装のオーバーレイ工法の留意点

付着オーバーレイ工法の施工上の留意点を以下に示す。

- 付着オーバーレイ工法は、既設コンクリート版の上に新しいコンクリートを**5〜10**cm厚で打設する工法で、広範囲に破損が生じたコンクリート版全体を補修する場合に用いる。
- 施工の要点は既設コンクリート版の清掃であり、ショットブラストなどにより適切な粗さに研磨する。
- ポルトランドセメントを用いた場合は、通常マットによる湿潤養生を行う。超早強セメントを用いた場合は、シート養生とし散水養生は行わない。

## 橋面舗装の補修

橋面舗装の補修工法は一般舗装と同様のものを選定するが、橋面舗装の特性を考慮する。目地に沿ってはパッチング、目地切り直し、表面処理などにより適切な処理を行い、補修においては主として表層・基層打換え工法が用いられる。施工上の留意点を以下に示す。

- 橋面舗装は水の影響で損傷が進行しやすいため、ひび割れなどは早期にシールすることが望ましい。
- 表層（レベリング層）まで撤去する場合は、床版を傷めない施工方法の採用が重要である。特に鋼床版の場合には高力ボルトなどの損傷を防ぐため、上層を切削したのち、残りの層をハンドブレーカやウォータージェットなどで除去することが推奨される。
- 伸縮装置周辺や桁端部付近などの既設設備・材料の撤去は、それらを傷めないようハンドブレーカなどを使用する。
- 鉄筋端部の腐食状況を事前に調査しておく。さびの発生状況や床版との付着状態を確認し、状況に応じてディスクサンダーやワイヤーブラシなどと人力を併用するなど、より経済的な表面処理方法を選択する。
- 表層の施工においては、特に路面排水に留意して仕上げる。

## 舗装の品質管理

舗設工事において施工後に不合格箇所が発見された場合、手直しが非常に困難であり、再施工となると大変な労力と経費が必要である。所定の品質を確保するため、各工程において自主的な品質管理を行う必要がある。

**頻出論点**: アスファルト混合物の温度管理の数値（敷均し・初転圧・二次転圧・交通開放）と、下層路盤の締固め度管理の試験頻度（おおむね1,000m²に1回）は特に頻出。

### 品質管理の基本方針

品質管理の項目・種類・管理の限界および過去の施工実績などを考慮し、最も効率的かつ効果的な品質管理を行うよう定める。留意点を以下に示す。

- 各工程の初期の施工では、各項目の試験頻度を多めにし、その時点の作業員・施工機械等の組合せによる作業能力を速やかに把握しておく。
- 作業員や施工機械の組合せに変化が生じた場合には、同様に試験頻度を増やし、新たな組合せによる作業能力を把握し直す。
- 施工が定めた管理限界を十分満足していることが確認できれば、それ以降の試験頻度は減らしてよい。
- 試験頻度が1日1〜2回の場合、プロットした点が規格値の限界付近を示した場合や、一方に偏っているなどの異常が生じた場合は、直ちに試験頻度を増やして異常の有無を確認する。
- 試験箇所の選定は、原則として無作為（ランダム）に行う。

ごく小規模な工事では、品質管理試験を行ってもその効果を現場に十分反映させる前に工事が終了することが多い。このような場合の品質管理は、次のように行う。

- 材料の基準試験値により、仕様を満足する材料であることを確認する。
- 工事が作業標準どおりに施工されているかをチェックシートで管理する。この際、施工状況をよく観察し、異常の早期発見に努める。

### 工種別品質管理の留意点

**路床**

構築路床の品質管理は、品質規定方式または工法規定方式により行う方法があり、土質等を考慮して選定する。

- 品質規定方式 — ①最大乾燥密度の密度比（締固め度）による方法、②空気間隙率または飽和度による方法、③強度特性等による方法
- 工法規定方式 — ①締固め機械の機種と転圧回数による方法

**下層路盤**

- 締固め度の管理は、おおむね**1,000**m²に1回の頻度で試験を行う。試験施工や工事の初期には頻度を増やして施工能力を把握し、現場作業が定常化すれば転圧回数（締固め回数）による管理に切り換えることも可能である。施工規模が大きい場合はプルーフローリングを行い、異常な沈下がないか観察する。
- 粒度の管理は随時目視観察を行い、異常が認められた場合はふるい分け試験を行う。
- 含水比の管理は、通常は目視観察による。
- PI（塑性指数）の管理は、含水比などと同様に目視観察による。

**粒度調整路盤（上層路盤）**

締固め度、含水比およびPIの管理は下層路盤の場合に準ずる。粒度の管理は、ふるい分け試験を1日1〜2回実施する。

**セメント・石灰安定処理路盤（上層路盤）**

締固め度、粒度、含水比の管理は粒度調整路盤の場合に準ずる。セメント（石灰）量の管理も、粒度調整路盤の場合に準ずる。

**表層・基層（加熱アスファルト混合物）および混合安定処理路盤**

- アスファルトプラントの計量印字記録により、混合物の配合・管理状況を確認する。現場の混合物が規格値を外れるおそれがある場合は、必要に応じてアスファルト抽出試験を行う。
- 作業員や施工機械の組合せに変化が生じない限り、粒度・密度・含水比等の測定値による品質管理では、抽出試験を毎回行う必要はない。
- 締固め度の確認は、舗装からコアを採取し、供試体の密度を測定して行う。測定結果をもとに現場における締固め状況を把握し、必要に応じて転圧回数の見直しなどを行う。

### 舗設時の温度管理

アスファルト混合物の締固め作業は、①継目転圧、②初転圧、③二次転圧、④仕上げ転圧の順序で行い、敷均し後はできるだけ速やかに締め固めるのが原則である。アスファルト混合物は、高温すぎても低温すぎても十分な締固め効果が得られないため、適切な温度管理が必要である。

- 敷均し時の混合物の温度は、一般に**110**℃を下回らないようにする。
- 初転圧は、ヘアクラックが生じない限りできるだけ高い温度で行う。ただし温度が高すぎると混合物が落ち着きにくくなる。初転圧温度は一般に**110〜140**℃である。
- 二次転圧の終了温度は、一般に**70〜90**℃である。
- 転圧終了後の交通開放は、舗装表面の温度がおおむね**50**℃以下となってから行う。
