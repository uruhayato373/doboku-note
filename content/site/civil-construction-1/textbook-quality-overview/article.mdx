品質管理の全体像として、その定義・目的とPDCAによる管理の進め方を整理する。個別の管理項目に入る前に、品質管理という営みの枠組みを押さえておきたい。

## 品質管理の概説

### 品質管理の定義

品質管理は、設計図・仕様書が求める形状と規格を満たす土木構造物を、経済的に造るための**全施工段階にわたる管理体系**である。工程の問題を把握して改善策を講じ、欠陥の発生を未然に抑えることで、工事への信頼性を高める。

日本産業規格 JIS Z 8101-1981（1999年廃止、ISO 9000ファミリーへ統合）は、品質管理を、購入者が求める品質の製品・サービスを経済的に生み出すための仕組みと捉えていた。その考え方を整理すると次のようになる。

1. 提供する製品・サービスが、顧客の求める品質、価格、納期を満たすこと
2. 各職場・部署が、より低い費用と短い時間で効率よく提供すること
3. 固有技術に加えて統計的な管理手法を使い、全社で実行すること

品質管理を有効に機能させるには、市場調査、研究、企画、開発、設計、生産準備、購買、外注、製造、検査、出荷、販売、アフターサービスだけでなく、財務・経理、人事、総務を含む全社的な活動が必要である。

対象範囲によって、品質管理は狭義と広義に分けられる。

- 狭義では、顧客へ提供する製品そのものを管理対象とする。
- 広義では、顧客・社会の要求に合う製品やサービスを生み出すTQM（総合的品質管理）やTQC（全社的品質管理）まで含める。

なお、本書で取り扱う品質管理は、主として統計的手法を利用した、工事の施工段階での品質向上のための手法としての狭義の品質管理に関するものである。

### 品質管理に関するISOの規格体系

ISO規格は国際標準化機構が制定する国際的な規格である。建設業で主に用いられるのは、品質マネジメントを扱うISO 9000ファミリーと、環境マネジメントを扱うISO 14000ファミリー（シリーズ）である。認証は、受注者が発注者・社会・組織自身の要求事項へ適合できる能力を持つことを、第三者の審査登録機関が証明する仕組みである。

国内では、公益財団法人日本適合性認定協会がISOの「認定機関」として、複数の審査登録機関を審査・認定している。

#### 1.2.1 ISO 9000 ファミリー

企業などの組織は、顧客要求を情報として取り込み（インプット）、製品・サービスへ反映して提供する（アウトプット）。入力を出力へ変換する一連の活動が「プロセス」である。変化する要求へ対応できるよう、このプロセスを継続して改善する仕組みが品質マネジメントシステムとなる。

品質マネジメントシステムでは、顧客の信頼と満足を目標に品質方針・品質目標を定め、その達成に向けて組織を指揮・管理する。組織構造、責任、手順、工程、経営資源など、受注から生産・販売までの活動全体が対象である。ISO 9000ファミリーは、その基本概念・用語、要求事項、パフォーマンス改善、監査を規定する。

**（1）ISO 9000 ファミリーの全体構成**

ISO 9000ファミリーには4つの中核規格があり、組み合わせて利用することで効果を高められる。

ISO 9000ファミリーが扱う対象は、組織構造、責任分担、手順、工程、経営資源である。

**（2）ISO 9000 ファミリーの特徴**

**1）あらゆる業種および規模への適用可能性の向上**

あらゆる産業および規模の組織にも適用できるような用語の選択、要求事項の記述がされている。

**2）品質マネジメントの原則の採用**

品質マネジメントには、後掲の（3）1）〜7）に示す7原則がある。目的達成には、各原則を理解して実務へ反映することが必要である。

**3）プロセスアプローチの採用**

システムを構築・実施・改善するとき、各プロセスを明確にし、相互につながる一連の仕組みとして適用する。

**4）顧客志向の重視**

顧客満足をはじめ、ニーズの把握、要求事項の理解、顧客との意思疎通を重視する。

**5）継続的改善の導入**

マネジメントシステムの運用全体へ、継続改善の考え方を組み込む。

**6）資源の運用管理の充実**

人、設備、資材、資金、技術、情報、作業環境などの資源を重要な管理対象として扱う。

**7）トップマネジメントの責任および役割の拡大ならびに明確化**

経営者が果たす責任と役割を重視し、トップマネジメントが実施する事項を明確にする。

**（3）品質マネジメントの原則**（ISO 9000：2015年版より抜粋）

**1）顧客重視**

最も重視するのは、顧客要求を満たし、さらに期待を上回ろうとする姿勢である。

**2）リーダーシップ**

各階層のリーダーは目的と方向をそろえ、組織目標の達成へ人々が参加できる環境をつくる。

**3）人々の積極的参加**

組織には、力量を備え、権限を与えられた人々の参画が不可欠である。全体で参加が進むほど、価値を生み出す能力は高まる。

**4）プロセスアプローチ**

相互に関係するプロセスを理解し、一つのシステムとして運用すれば、一貫して予測可能な成果を、より効果的・効率的に得られる。ここでプロセスとは、経営資源を管理してインプットをアウトプットへ変える活動をいう。

**5）改善**

継続的な改善は、組織が成功を維持するための重点事項である。

**6）客観的事実に基づく意思決定**

データと情報を分析・評価したうえで判断すれば、望ましい成果を得られる可能性が高まる。

**7）関係性管理**

継続的な成功には、協力会社を含む利害関係者との関係を適切に管理する必要がある。

**（4）プロセスとそのアプローチ**（ISO 9001）

**1）プロセスの特色**

- 何を目的として、どのような活動や作業をどの範囲で行い、どのような結果（アウトプット）を得るかを明確にできる。
- P−D−C−Aサイクルがすべてのプロセスに適用可能。サイクルを回すことにより、**継続的改善**が実施される。

P−D−C−Aサイクルとは、

- **Plan**: 顧客要求と組織方針に沿う成果を得るため、目標とプロセスを定める。
- **Do**: 定めたプロセスを実行し、その有効性も確認する。
- **Check**: 方針・目標・製品要求に照らして工程と製品を監視・測定し、結果を報告する。
- **Act**: プロセスの実績を継続的に改善する処置を行う。

**2）プロセスアプローチ**

- プロセスアプローチは、個々のプロセスを明確にし、相互作用を捉えて全体を管理する考え方である。
- 各プロセスのつながり、組合せ、相互作用を継続的に管理できる。これにより、システム全体の活動を整合した実務的な流れとして運営できる。

**（5）ISO 9001 認証取得の活用**

ISO認証は、顧客要求に適合できる組織能力を第三者の審査登録機関が証明するものである。発注者は、受注者が要求を満たせるか評価する材料として利用できる。

国土交通省や一部自治体のISO 9001活用工事では、認証受注者が自ら行う品質管理を利用する。監督業務の一部を受注者の検査記録確認へ置き換え、品質確保と業務効率化を図っている。

#### 1.2.2 ISO 14000 ファミリー

ISO 14000ファミリーは、環境保全の数値規制や基準値そのものを定めない。組織が環境方針を自主的に設定・実行するためのマネジメントシステムと、それを支える手法を規定する一連の規格である。

#### 1.2.3 ISO 9000 ファミリーとISO 14000 ファミリーの比較

ISO 9000とISO 14000の各ファミリーは、いずれも組織運営の仕組みであるマネジメントシステムを扱い、要求事項にも多くの共通点がある。

ただし目的は異なる。ISO 9000ファミリーは顧客ニーズへ対応する品質マネジメントを運用し、満足される製品・サービスの提供を目指す。ISO 14000ファミリーは幅広い利害関係者と環境保護の要請へ対応し、環境マネジメントの運用によって負荷を低減する。

両ファミリーの中核規格は、それぞれISO 9001とISO 14001である。

各々の規格の主な共通点・相違点は次のとおりである。

#### 共通点（両規格に共通）

- 組織のマネジメントシステムを取り扱っている
- P−D−C−A サイクルを運用の基本としている
- 規格の周辺にファミリー規格を持っている
- 手順化・文書化・記録化を要する
- トップマネジメント（経営者）の責任・役割の明確化が求められる
- 第三者審査登録制度の基準である

#### 相違点

- **目的**
  - ISO 9001: 顧客満足を高める
  - ISO 14001: 環境負荷の低減
- **対象**
  - ISO 9001: 顧客のみ（供給者と購入者の二者関係）
  - ISO 14001: 消費者・株主・地域住民・利害関係者など社会のすべての人々（組織と社会全体の関係）
- **要求要素の力点**
  - ISO 9001: Do（実施・運営）と Check（監視・測定）
  - ISO 14001: Plan（方針・計画）
- **その他**
  - ISO 14001 固有: 環境法規の制約、環境側面への配慮、緊急時対応、監視測定といった環境固有の領域がある

## 品質管理の方法

### 品質管理の目標

土木工事の品質管理では、直接的には次の二点を確かめる。

1. 構造物が定められた**規格に適合**すること。
2. 品質を作り出す過程である**工程が安定**すること。ここでいう工程は、工期上の工程とは異なる。

品質管理では、発注者が求める規格・品質へ適度な余裕をもって適合させながら、構造物を経済的に施工する。まず、検査した各データが規格値を十分満たす必要がある。一方、余裕が過大で、そのために必要以上に高価な材料や過剰な施工を用いるなら不経済であり、適切とはいえない。

次に、個々の値が規格内でも散らばりが異常に大きければ、工程は安定していない。未検査部分の品質も信頼しにくくなる。したがって、規格適合と工程安定を適切な範囲で同時に実現することが目標となる。

一般に、規格適合は**ヒストグラム**や**工程能力図**で、工程安定は**管理図**で確認する。各手法の要点を以下に示す。図解は [ヒストグラム](/docs/civil-construction-1-textbook-histogram) と [管理図](/docs/civil-construction-1-textbook-control-chart) で詳しく扱う。

#### 工程能力図

- **特徴**: 横軸に時間や測定 No.、縦軸に品質特性値をとり、規格値を示す線を記入してデータを時間順に打点した図。**規格値で管理する**
- **目的・利点**: 時間的な品質変動や傾向がわかる。規格値との関係がわかる
- **欠点**: 統計的手法が使われていないため、工程の異常は判断できない

#### ヒストグラム

- **特徴**: 横軸に品質特性値、縦軸に度数をとり、規格値を示す線を記入して品質特性の分布状態を表した度数分布図。**規格値で管理する**
- **目的・利点**: 分布の状態から規格値・中心位置（平均値）の関係がわかる。工程の状態を把握できる
- **欠点**: 時間的変化や変動の様子がわからない

#### 管理図

- **特徴**: 品質データを統計的に処理し平均値やバラツキの範囲などに対する管理限界線を求めて記入し、その後のデータの平均値やバラツキの範囲を打点した図。**管理限界線で管理する**
- **目的・利点**: 工程が安定しているかどうかを評価する
- **欠点**: 規格値との関係はわからない

### 品質管理の手順

工程能力図、ヒストグラム、管理図を作る前に、管理する品質特性を選び、品質標準を設定し、それを守る作業標準を定める。品質管理を進める順序と品質特性の例を次に示す。

| 手順 | 内容 |
|:--|:--|
| 手順1 **品質特性の選定** | 管理しようとする品質特性を選定する。一般的な品質特性の例は下表のとおり。 |
| 手順2 **品質標準の設定** | 選定した特性ごとに、設計図・仕様書の規格を余裕をもって満たせる施工管理上の目安を定める。実行可能な値とし、通常は平均値とばらつき幅で表す。 |
| 手順3 **作業標準の決定** | 品質標準を達成する作業方法を定める。構造物が標準を満たせるよう、各作業の使用資機材や手順を具体化する。 |
| 手順4 **データ採取** | 作業標準に従って施工し、一定の期間、データを採る。試験方法および検査方法の標準を定める。 |
| 手順5 **分析確認** | 工程能力図やヒストグラムで各データの規格適合を確認し、続いて管理図で工程の安定性を判定する。 |
| 手順6 **作業方法の見直し** | 施工の途中で管理図により工程に異常が生じたと判定された場合、原因を追求し、再発しないよう作業方法を見直すなどの処置をとる。 |
| 手順7 **作業の継続** | 引き続き作業を続け、データを監視しながら、前回と同程度の期間（例えば1か月）、あるいは、データが一定の数（例えば20点）に達したら、手順5以下を繰り返す。 |

この手順は、具体的に品質管理を進めるときに実行していく順序であるが、手順5から7における統計的手法として、工程能力図、ヒストグラムや管理図などが用いられる。

### 品質特性の選定

品質管理は、構造物に要求される規格・品質、すなわち設計品質を正確に理解することから始まる。設計品質は通常、設計図書、とりわけ仕様書に示される。その達成に向け、具体的に何を管理対象とするか事前に整理する。この対象項目を**品質特性**といい、管理特性・管理項目とも呼ぶ。

品質特性には、次の条件を備えるものを選ぶのが望ましい。

1. **工程**（作業）の状態を総合的に示せること。
2. 最終品質へ**大きく影響**すること。
3. **代用特性**なら真の品質特性と密接に関係し、工程要因を採る場合も両者の関係が明確であること。
4. 容易に測定できること。
5. 測定結果を工程への処置につなげやすいこと。
6. 結果が早く得られること。
7. できるだけ工程の早い段階で測れること。

③の工程要因を品質特性とする場合とは、例えば、土の締固め管理の基準には乾燥密度などを規定する品質規定方式と締固め機械や転圧回数などの施工方法を基準とする工法規定方式があるが、工法規定方式を用いる場合がこれに相当する。

| 対象工種 | 管理する特性 | 確認方法 |
|:--|:--|:--|
| **土工** 材料 | 最適含水比・最大乾燥密度 | 締固め試験 |
| | 粒度 | ふるい分け試験 |
| | 自然含水比 | 含水比試験 |
| | 液性限界 | 液性限界試験 |
| | 塑性限界 | 塑性限界試験 |
| | 透水係数 | 透水試験 |
| | 圧密係数 | 圧密試験 |

### 品質標準の設定

品質標準は、施工で実現を目指す品質上の目標である。設計品質をそのまま標準にすると、品質特性のばらつきが大きいときに不適合が生じるおそれがある。このため設計品質に対して余裕を持たせる。ただし、統計理論だけで合理的かつ妥当な値を決めるのは難しい場合が多い。

そこで、土木工事においては、過去の実績や試験施工などをもとに当初の概略標準を定め、施工の過程に応じて結果をフィードバックしながら、標準を改訂していく方法をとる場合が多い。

### 作業標準の決定

品質標準を決める際は、その品質を実現する作業方法と使用資機材も、作業標準として具体的に定め、作業者全員へ周知する。

作業標準は、同じような条件での過去の施工実績・経験、または事前の試験施工・実験結果を参考に決定する。

作業標準を定めるときは、次の事項に注意する。

1. 不良が生じる前に管理できる手順とすること。
2. 最終品質へ重大な影響を与える要因は、詳細かつ具体的に定めること。
3. 工程異常時に、担当者・処置内容・実施範囲が明確になるよう決めること。
4. 作業標準の間で矛盾がないこと。
5. 作業標準は明文化しておき、技術の蓄積を図るよう心がけること。

先手管理の例として、打設前に型枠寸法を確認し、現場搬入時にコンクリートのスランプを測る手順がある。不良なコンクリートを打設する前に止められる仕組みを作業標準へ組み込む。
