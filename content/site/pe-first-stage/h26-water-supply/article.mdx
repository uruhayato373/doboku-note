## Ⅲ-1

水道施設計画に関する次の記述のうち、最も不適切なものはどれか。

1. 浄水施設能力は、計画浄水量のほかに、予備力を確保して決定することが望ましい。予備力は、場内施設を系列化した浄水場の場合、1系列相当分とし計画浄水量の25％程度を標準とする。

2. 計画取水量は、計画1日最大給水量に25％程度の余裕を見込んで決定することを標準とする。

3. 給水人口規模が大きい上水道事業において、配水池の有効容量は、計画1日最大給水量の12時間分を標準とする。

4. 目標とする配水管の最小動水圧は、150 kPa以上、最大静水圧は740 kPa以下を基本とする。

5. 自然流下式の導水管を設計する際、平均流速は、バルブ操作時の異常な流量変動による水圧の不安定化や管内面の摩擦等を考慮して、許容最大限度を3.0 m/秒程度とする。

<details>
<summary>解答・解説</summary>

**正答：2**

計画取水量は、浄水場での損失水量や作業用水を見込んで、計画1日最大給水量に10％程度の余裕を加えた量とするのが標準である。25％は浄水施設能力の予備力の目安であり、取り違えている。

1. 浄水施設は、系列化した場合に1系列相当分（計画浄水量の25％程度）の予備力を持たせるのが標準である。正しい ✅

2. 余裕は25％ではなく10％程度が標準で、数値が誤っている。誤り ❌

3. 大規模な事業の配水池容量は、計画1日最大給水量の12時間分を標準とする。正しい ✅

4. 配水管の最小動水圧は150 kPa以上、最大静水圧は740 kPa以下を基本とする。正しい ✅

5. 自然流下式の導水管は、流速の許容最大限度を3.0 m/秒程度とする。正しい ✅

## Ⅲ-3

次のア）〜オ）の記述に対応する取水施設の組合せとして、最も適切なものはどれか。

ア）取水口施設でスクリーン、ゲート又は角落し、砂溜等と一体となり機能する。

イ）河川の水深が一定以上の所に設置すれば年間の水位変化が大きくとも安定した取水が可能である。取水口を上下数段に設けて選択取水ができる。

ウ）河川水を堰上げし、計画取水位を確保することにより、安定した取水を可能にするための施設であり、堰本体取水口・沈砂池等が一体となって機能する。

エ）取水口部を複断面河川の低水護岸に設けて表流水を取水し、管渠部を経て堤内地に導水する施設である。

オ）湖沼の中・小量取水施設として多く用いられている。構造が簡単で施工も比較的容易である。水中に没して設けられるため、湖沼表面の水は取水できない。

1. ア：取水塔、イ：取水門、ウ：取水堰、エ：取水管渠、オ：取水枠

2. ア：取水門、イ：取水塔、ウ：取水堰、エ：取水枠、オ：取水管渠

3. ア：取水堰、イ：取水塔、ウ：取水門、エ：取水管渠、オ：取水枠

4. ア：取水堰、イ：取水門、ウ：取水管渠、エ：取水塔、オ：取水枠

5. ア：取水門、イ：取水塔、ウ：取水堰、エ：取水管渠、オ：取水枠

<details>
<summary>解答・解説</summary>

**正答：5**

アはスクリーンやゲートと一体の取水門、イは上下数段の取水口で選択取水できる取水塔、ウは河川水を堰上げする取水堰、エは低水護岸から管渠で導水する取水管渠、オは水中に没して設ける取水枠である。

1. アを取水塔、イを取水門としており、ゲートと一体の取水口は取水門、多段の選択取水は取水塔である。誤り ❌

2. エを取水枠、オを取水管渠としているが、低水護岸から管渠で導くのが取水管渠、湖沼の水中に没して設けるのが取水枠である。誤り ❌

3. アを取水堰、ウを取水門としており、堰上げして取水位を確保する施設は取水堰である。誤り ❌

4. オの取水枠だけが合っており、アは取水門、イは取水塔、ウは取水堰、エは取水管渠であるべきところを入れ違えている。誤り ❌

5. ア取水門、イ取水塔、ウ取水堰、エ取水管渠、オ取水枠で、すべての記述に対応する ✅

## Ⅲ-4

浄水処理の凝集に関する次の記述のうち、最も適切なものはどれか。

1. 浄水処理において使用できる凝集剤の種類として、硫酸アルミニウム、ポリ塩化アルミニウム、鉄系凝集剤がある。高分子凝集剤の浄水処理での使用は認められていない。

2. 撹拌には、凝集剤を急速に拡散させ、コロイド粒子を互いに結合し、微小フロックを形成させる急速撹拌と、微小フロックを互いに衝突させながら凝集させ、成長させるために行う緩速撹拌がある。

3. アルカリ度は凝集効果に影響を与える重要な因子である。アルカリ度が低い場合は、緩衝作用が小さいので、適度なアルカリ度を保持するために酸剤の注入が必要である。

4. 水温が高い場合には、低い場合と比べてフロックの成長は遅くなる。

5. フロック形成池における撹拌の程度を評価する指標としてCT値がある。これは、凝集剤注入率Cに滞留時間Tを乗じた値である。

<details>
<summary>解答・解説</summary>

**正答：2**

凝集の撹拌は、薬品を拡散させる急速撹拌と、フロックを成長させる緩速撹拌の二段階で行う。

1. 水道施設維持管理指針2006（7.3.2）は、硫酸アルミニウム、ポリ塩化アルミニウム、鉄系凝集剤に加えて高分子凝集剤を凝集剤に挙げ、処理水中の残留アクリルアミドモノマー濃度の上限を定めて使用を認めている。使用が認められていないとする記述は誤りである。誤り ❌

2. 急速撹拌で薬品を拡散して微小フロックを形成し、緩速撹拌でフロックを衝突させて成長させる。正しい ✅

3. アルカリ度が低いと凝集剤の加水分解でpHが下がりすぎるため、酸剤ではなくアルカリ剤を注入する。誤り ❌

4. 水温が低いと粘性が大きくなり、水道施設設計指針2012（5.3.2）も水温が10℃前後を下回るとフロックの形成が著しく悪くなると述べている。水温が高いと成長は速くなるので、「遅くなる」は逆である。誤り ❌

5. フロック形成池の撹拌の程度を表す指標は、速度勾配Gと滞留時間Tの積であるGT値であり、CT値は消毒効果の指標である。誤り ❌

## Ⅲ-5

沈殿に関する次の記述のうち、最も不適切なものはどれか。

1. 沈殿効率は、表面負荷率に反比例し、沈殿池の水深、長さ、滞留時間に無関係である。

2. 普通沈殿池は、緩速ろ過池と組み合わせて設けられ、自然沈降によって懸濁物質を除去するものである。

3. 薬品沈殿池は、薬品注入、混和、フロック形成を経て大きく成長したフロックをできるだけ沈殿させ、後に続く急速ろ過池への負担を軽減するために設ける施設である。

4. 高速凝集沈殿池は、薬品注入、急速撹拌、フロック形成、沈殿処理を1つの槽の中で行う沈殿池で、運転操作は横流沈殿池に比べ容易である。

5. 沈殿池に堆積したスラッジを排水処理施設へ送るための設備を排泥設備という。

<details>
<summary>解答・解説</summary>

**正答：4**

高速凝集沈殿池は一つの槽で処理を完結する一方、池内に多量のフロックを保持するため、水道施設維持管理指針2006（7.5.4）が述べるとおり、原水水質や流量が急変するとフロックが流出して沈殿水質が悪化しやすく、運転管理上の注意点が多い。

1. 理想的な沈殿池では、粒子の除去率は表面負荷率（流量÷沈殿面積）の逆数に比例し、水深や滞留時間には直接関係しない。正しい ✅

2. 普通沈殿池は緩速ろ過池と組み合わせて用い、自然沈降で懸濁物質を除去する。正しい ✅

3. 薬品沈殿池は、凝集で大きく成長させたフロックを沈殿させ、急速ろ過池の負担を軽くする。正しい ✅

4. 1槽で凝集から沈殿までを行う点は正しいが、原水水質や流量の急変に弱く運転管理に注意を要するため、横流沈殿池より容易とする部分が誤りである。誤り ❌

5. 沈殿池のスラッジを排水処理施設へ送る設備を排泥設備という。正しい ✅

## Ⅲ-6

急速ろ過池に関する次の記述のうち、最も不適切なものはどれか。

1. 原水中の懸濁物質を薬品によって凝集させた後、粒状層に比較的速い流速で水を通し濁質を除去する役割を果たす。

2. 一般的に、濁質当たりの凝集剤量（ALT比）の高いフロックは強度が低い。

3. 砂だけをろ材とする単層ろ過池では、ろ材の粒径分布幅を大きくすることにより、ろ層内部の抑留容量を十分に利用することができる。

4. 粒径と空隙率を水流方向に向かって、徐々に小さくなるようなろ層構成とすることで、高度の除濁能力と大量の抑留機能を合わせ持つことができる。

5. 通常の単層ろ過を上向流でろ過する方法（上向流ろ過）には、ろ過速度を大きくするとろ層が膨張して濁質が漏洩する欠点がある。

<details>
<summary>解答・解説</summary>

**正答：3**

単層ろ過池でろ材の粒径分布幅（均等係数）が大きいと、洗浄時に細粒が上層に偏って堆積し、表層で目詰まりしやすくなる。ろ層内部の抑留容量を使い切れないので、粒径をそろえることが望ましい。

1. 急速ろ過は、凝集後の水を粒状層に比較的速い流速で通して濁質を除く。正しい ✅

2. ALT比が高いフロックは含水率が高くやわらかく、強度が低い。正しい ✅

3. 粒径分布幅を大きくすると表層に目詰まりが集中するため、抑留容量を十分に利用できず、記述が逆である。誤り ❌

4. 水流方向に向かって粒径と空隙率を小さくする構成は、除濁能力と抑留量を両立できる。正しい ✅

5. 上向流ろ過は、ろ過速度を大きくするとろ層が膨張して濁質が漏れる欠点がある。正しい ✅

## Ⅲ-7

浄水処理における消毒に関する次の記述のうち、最も不適切なものはどれか。

1. 次亜塩素酸と次亜塩素酸イオンは、いずれも消毒効果を有し、この両者を遊離残留塩素という。

2. 次亜塩素酸より、次亜塩素酸イオンの方が消毒効果は強い。

3. 水中のアンモニアと塩素の反応により生じるクロラミン類のうち、モノクロラミンとジクロラミンは消毒効果を有するが、トリクロラミンは有しない。

4. 前塩素処理と中間塩素処理は、アンモニアや鉄・マンガンの除去など、主に消毒以外の目的で行われる。

5. 水道水の消毒に用いられる塩素剤には、液化塩素、次亜塩素酸ナトリウム、次亜塩素酸カルシウム（高度さらし粉）がある。

<details>
<summary>解答・解説</summary>

**正答：2**

遊離残留塩素のうち、消毒効果が強いのは次亜塩素酸（HOCl）であり、次亜塩素酸イオン（OCl⁻）は電荷を持つため細菌の細胞膜を通りにくく、効果が弱い。

1. 次亜塩素酸と次亜塩素酸イオンを合わせて遊離残留塩素という。正しい ✅

2. 消毒効果は次亜塩素酸の方が強く、次亜塩素酸イオンの方が強いとする記述が逆である。誤り ❌

3. モノクロラミンとジクロラミンは結合残留塩素として消毒効果を持ち、トリクロラミンは持たない。正しい ✅

4. 前塩素処理と中間塩素処理は、アンモニアや鉄・マンガンの酸化除去など、消毒以外を主目的とする。正しい ✅

5. 塩素剤には、液化塩素、次亜塩素酸ナトリウム、次亜塩素酸カルシウムがある。正しい ✅

## Ⅲ-8

我が国におけるオゾン処理を用いた高度浄水処理方法として、適用可能な処理フローの組合せは次のうちどれか。

（ア）凝集沈殿 → オゾン処理 → 粒状活性炭処理 → 砂ろ過 → 塩素処理 → 浄水池・配水池

（イ）凝集沈殿 → 砂ろ過 → オゾン処理 → 粒状活性炭処理 → 塩素処理 → 浄水池・配水池

（ウ）凝集沈殿 → 砂ろ過 → 粒状活性炭処理 → オゾン処理 → 塩素処理 → 浄水池・配水池

（エ）凝集沈殿 → 粒状活性炭処理 → 砂ろ過 → オゾン処理 → 塩素処理 → 浄水池・配水池

1. ア、イ

2. イ、ウ

3. ウ、エ

4. ア、エ

5. イ、エ

<details>
<summary>解答・解説</summary>
