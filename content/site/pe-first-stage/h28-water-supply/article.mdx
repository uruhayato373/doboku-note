## Ⅲ-1

水道管路の更新計画に関する次の記述のうち、最も不適切なものはどれか。

1. 管路更新には、多額の費用と長期にわたる工事期間が必要となるため、管路の劣化状況などを基準として、地震対策を勘案した管路更新計画を策定し、計画的かつ継続的に管路を更新していくことが重要である。

2. 管路更新は、経年化による漏水・破裂の予防、濁水防止、通水能力の回復等を目的として実施される。また、需要者サービス向上の観点から、残留塩素濃度の低減化、直結給水の拡大、耐震性の向上等を目的に実施されることが多くなっている。

3. 管路の更新は、管路診断結果を基にして、これに水運用上の重要度、他企業埋設物との関連、道路占用・道路使用許可上の諸条件を考慮し、更新優先度を定量化して更新計画を策定する。

4. 管路更新の工法は、「更新工法」と「更生工法」とに大別される。両工法とも、機能の低下した管を新しい管に取り替えて機能を向上させる工法であり、恒久的な対策である。

5. 優先的に更新対象とすべき管種としては、石綿セメント管、鉛管、経年鋳鉄管などがある。

<details>
<summary>解答・解説</summary>

**正答：4**

1. 費用と工期の大きい管路更新は、劣化状況や地震対策を踏まえた更新計画により、計画的かつ継続的に進める必要があり適切 ✅
2. 更新の目的は漏水・破裂の予防、濁水防止、通水能力の回復に加え、残留塩素濃度の低減化、直結給水の拡大、耐震性の向上などサービス向上にも広がっており適切 ✅
3. 管路診断結果に水運用上の重要度、他企業埋設物、道路占用・道路使用許可の条件を加味して優先度を定量化する手順で適切 ✅
4. 更新工法は古い管を新管に取り替える工法だが、更生工法は既設管を撤去せず管内面にライニングを施して機能を回復させる工法である。両工法を「管を新しい管に取り替える」とし「恒久的」と一括した点が誤りで**最も不適切** ❌
5. 石綿セメント管、鉛管、経年鋳鉄管は破損や水質面の問題が大きく、優先的に更新すべき管種であり適切 ✅

## Ⅲ-2

水道水源に関する記述のうち、最も不適切なものはどれか。

1. 湖沼や貯水池を水源とする場合には、大腸菌の増殖により異臭味障害やろ過障害を引き起こすことがある。

2. 離島や淡水が不足する地域の都市などで、海水の淡水化によって水を得ているところがある。

3. 地下水が取水できる場所においても、一部の地域では、条例に基づき地下水の汲み上げが規制されている。

4. 河川の水質は、季節的に変動し、特に洪水期などの出水期には濁度が増加したり、溶存物質量の変化が大きい。

5. 伏流水は、河川水（湖沼水）が河床（湖沼床）又はその付近に潜流している不圧地下水の一種である。

<details>
<summary>解答・解説</summary>

**正答：1**

1. 湖沼や貯水池で異臭味障害やろ過障害を起こす原因は、富栄養化に伴う藻類（植物プランクトン）の異常増殖である。大腸菌の増殖とした点が誤りで**最も不適切** ❌
2. 離島や淡水に乏しい地域では海水淡水化により水源を確保している例があり適切 ✅
3. 地盤沈下の防止などのため、条例で地下水の揚水が規制される地域があり適切 ✅
4. 河川水は出水期に濁度が上がり溶存物質量の変動も大きくなるため適切 ✅
5. 伏流水は河床や湖沼床付近を潜流する不圧地下水の一種で、記述は定義どおり適切 ✅

## Ⅲ-3

浄水処理に関する次の組合せのうち、最も不適切なものはどれか。

1. pH値の調整 ― 酸、アルカリ剤

2. 色度の除去 ― 凝集沈殿処理、活性炭処理、オゾン処理

3. トリハロメタン低減対策 ― 活性炭処理、前塩素処理

4. トリクロロエチレン低減処理 ― エアレーション、粒状活性炭処理

5. アンモニア態窒素の除去 ― 生物処理、塩素処理

<details>
<summary>解答・解説</summary>

**正答：3**

1. pH調整には酸剤とアルカリ剤を用いるため適切 ✅
2. 色度は凝集沈殿処理、活性炭処理、オゾン処理で除去できるため適切 ✅
3. トリハロメタンは原水中の前駆物質と塩素が反応して生成する。前塩素処理は生成を増やす側の操作で、低減対策には前駆物質を除く凝集沈殿や活性炭処理に加え、塩素の注入点を後段へ移す中間塩素処理などを用いる。前塩素処理を低減対策に挙げた点が誤りで**最も不適切** ❌
4. トリクロロエチレンは揮発性が高く、エアレーションと粒状活性炭処理で低減できるため適切 ✅
5. アンモニア態窒素は生物処理による硝化と、塩素処理（不連続点塩素処理）で除去できるため適切 ✅

## Ⅲ-4

凝集処理に関する次の記述の、［ア］〜［オ］に入る語句の組合せとして、最も適切なものはどれか。

凝集作用の原理から、アルミニウム塩などは水中のアルカリ分と反応して、アルカリ分が減少する。凝集剤の多くは［ア］であるため凝集剤の添加によってpHが［イ］する。pHが適正凝集域以下に低下する場合には［ウ］剤を注入する。

貯水池や湖沼などを水源とする場合などは、炭酸同化作用により原水のpHが［エ］する。このような原水が浄水場に入ると凝集性能が低下するため、pH調整法として［オ］剤を注入する。

1. ア：酸　イ：低下　ウ：アルカリ　エ：上昇　オ：酸

2. ア：アルカリ　イ：上昇　ウ：酸　エ：低下　オ：酸

3. ア：酸　イ：低下　ウ：アルカリ　エ：上昇　オ：アルカリ

4. ア：アルカリ　イ：上昇　ウ：酸　エ：上昇　オ：アルカリ

5. ア：酸　イ：低下　ウ：アルカリ　エ：低下　オ：アルカリ

<details>
<summary>解答・解説</summary>

**正答：1**

アルミニウム塩や鉄塩は酸性の凝集剤で、加水分解によりアルカリ分を消費するため、添加するとpHが低下する。pHが適正凝集域を下回るときはアルカリ剤で補う。湖沼や貯水池では藻類が炭酸同化作用で水中の二酸化炭素を消費するためpHが上昇する。凝集は高pH側で性能が落ちるため、酸剤を注入して適正域へ下げる。以上から ア：酸、イ：低下、ウ：アルカリ、エ：上昇、オ：酸 となる。

1. ア酸、イ低下、ウアルカリ、エ上昇、オ酸の全てが上記と一致し正しい ✅
2. アを「アルカリ」、イを「上昇」、ウを「酸」、エを「低下」としており、アからエまで逆で誤り ❌
3. オを「アルカリ」としているが、pHが上昇した原水には酸剤を注入するため誤り ❌
4. アを「アルカリ」、イを「上昇」、ウを「酸」、オを「アルカリ」としており誤り ❌
5. エを「低下」、オを「アルカリ」としているが、炭酸同化作用ではpHが上昇し、調整は酸剤で行うため誤り ❌

## Ⅲ-5

浄水場の砂ろ過方式に関する次の記述のうち、最も不適切なものはどれか。

1. 緩速ろ過方式は、原水水質が良好で濁度も低く安定している場合に採用される。

2. 緩速ろ過方式は、維持管理が簡単で、敷地面積に制約がある場合に採用される。

3. 緩速ろ過方式は、原水水質によって、沈殿池を設ける場合と省略する場合とがある。

4. 急速ろ過方式は、凝集剤を注入して原水中の懸濁物質をあらかじめ凝集してフロックとし、沈殿池で沈降分離した後、ろ過するもので、高濁度原水にも対処できる。

5. 急速ろ過方式は、緩速ろ過方式よりも粗いろ過砂を使用し、ろ過速度が緩速ろ過の30倍程度又はそれ以上の速さでろ過するものである。

<details>
<summary>解答・解説</summary>

**正答：2**

1. 緩速ろ過は生物膜の浄化作用に頼るため、良好で濁度が低く安定した原水に向き適切 ✅
2. 緩速ろ過のろ過速度は4〜5m/日と遅く、同じ水量を処理するのに広い敷地が必要になる。敷地面積に制約がある場合に採用するとした点が誤りで**最も不適切** ❌（維持管理が簡単という点は正しい）
3. 原水水質によって普通沈殿池を設ける場合と省略する場合があるため適切 ✅
4. 急速ろ過は凝集沈殿を前処理とするため高濁度原水にも対処でき適切 ✅
5. 急速ろ過は粗い砂を用い、ろ過速度120〜150m/日と緩速ろ過の30倍程度以上であり適切 ✅

## Ⅲ-6

水道用沈殿池に関する次の記述のうち、最も不適切なものはどれか。

1. 沈殿効率は表面負荷率に反比例する関係になっており、沈殿池の沈降面積を大きくしたり、フロックの沈降速度を大きくしたり、流量を少なくすることで沈殿効率を高めることが可能である。

2. 普通沈殿池は、緩速ろ過池と組合せて設けられるもので、自然沈降により懸濁物質を除去するもので、沈殿時間は8時間が標準である。

3. 傾斜板式沈殿池は、沈殿池内に傾斜板等の沈降装置を挿入して、一種の多階槽式沈殿池を構成し除去率を高めようとしているものであり、沈降装置には、波形、平板、正方形、六角形等の形状があり、傾斜板の傾斜角は60°とする。

4. 高速凝集沈殿池は、フロックの形成を既成フロックの存在下で行うことにより、凝集沈殿の効率を向上させることを目的にしており、原水濁度は10度以上、最高濁度は1,000度以下とする。

5. 横流式沈殿池の形式には、スラリー循環形、スラッジ・ブランケット形、複合形があり、池数は原則として2池以上とする。

<details>
<summary>解答・解説</summary>

**正答：5**

1. 沈殿効率は表面負荷率（流量÷沈降面積）に反比例し、沈降面積やフロック沈降速度を大きくするか流量を減らせば高まるため適切 ✅
2. 普通沈殿池は緩速ろ過池と組み合わせて用い、沈殿時間は8時間が標準で適切 ✅
3. 傾斜板式沈殿池は多階槽式沈殿池の一種で、傾斜板の傾斜角は60°とするため適切 ✅
4. 高速凝集沈殿池は既成フロックの存在下でフロックを形成させる方式で、原水濁度10度以上、最高1,000度以下が適用条件であり適切 ✅
5. スラリー循環形、スラッジ・ブランケット形、複合形は高速凝集沈殿池の形式であり、横流式沈殿池の形式ではない。横流式は長方形の池を水平に流す形式で、形式を取り違えており**最も不適切** ❌

## Ⅲ-9

給水方式に関する次の記述のうち、最も不適切なものはどれか。

1. 直結式には、配水管の動水圧により直接給水する直結直圧式と、給水管の途中に増圧給水設備を設置し、圧力を増して直結給水する直結増圧式がある。

2. 受水槽式には、受水槽に受水した水を、ポンプで高置水槽へ圧送し、そこから自然流下で給水する高置水槽式、ポンプにより圧力タンクに貯留し、その内部圧力により給水する圧力水槽式、ポンプで直接給水するポンプ直送式がある。

3. 直結式は省エネルギーの観点から有効であるが、直結給水の範囲を拡大する場合、給水装置からの逆流防止対策を講じる必要がある。

4. 直結増圧式は、一時に多量の水を使用するものや使用水量の変動が大きい施設・建物等で、配水管の水圧低下を引き起こすおそれがある場合に採用する。

5. 受水槽式は、断水時や災害時に水を確保できる長所があるが、定期的な点検や清掃など適正な管理が必要である。

<details>
<summary>解答・解説</summary>

**正答：4**
