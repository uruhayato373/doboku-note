## Ⅲ-1

下図は、定水位透水試験の模式図である。容器Ⅰの中に長さ$L$、断面積$A$の円筒形の砂供試体を作製し、容器Ⅰ上部の水面を一定位置に保ちながら給水を行う。砂供試体を通過した水を、パイプを通して容器Ⅱに導き、容器Ⅱの水位を一定に保ちながら、容器Ⅰからあふれ出た水の量を測定する（このとき、水頭差$h$は一定に保たれる）。容器Ⅰからあふれないように給水し、定常状態になったときに、容器Ⅱからあふれ出た水の量を測定すると、単位時間当たりの流量が$Q$であった。ダルシーの法則が成り立つとき、この砂供試体の透水係数$k$と$Q$、$h$、$L$、$A$の関係を表している式として、最も適切なものはどれか。

<ArticleImage src="/posts/pe-first-stage/r07-construction/img/q01-fig.webp" alt="定水位透水試験の模式図。容器Ⅰ内に長さL・断面積Aの砂供試体を入れ上部から給水し、金網・パイプを介して容器Ⅱへ導く。容器ⅠとⅡの水位差がh、容器Ⅱからの流量がQ" width={895} height={1023} />

1. $QA = k\dfrac{L}{h}$

2. $\dfrac{Q}{A} = k\dfrac{L}{h}$

3. $\dfrac{Q}{A} = khL$

4. $QA = k\dfrac{h}{L}$

5. $\dfrac{Q}{A} = k\dfrac{h}{L}$

<details>
<summary>解答・解説</summary>

**正答：5**

ダルシーの法則は、流量$Q$、透水係数$k$、動水勾配$i=h/L$、断面積$A$を用いて

$$Q = k\,i\,A = k\,\frac{h}{L}\,A$$

と表される。両辺を$A$で割れば、流速（ダルシー流速）$v=\dfrac{Q}{A}=k\dfrac{h}{L}$ が得られる。動水勾配$i$は水頭差$h$を浸透距離$L$で割った$h/L$である点が要点。

1. 左辺が流速$Q/A$ではなく積$QA$で、かつ動水勾配が$L/h$と逆になっており誤り ❌
2. 左辺は$Q/A$で正しいが、動水勾配が$h/L$ではなく$L/h$と逆になっており誤り ❌
3. 動水勾配が$h/L$ではなく$khL$（$L$を掛けている）となっており誤り ❌
4. 動水勾配は$h/L$で正しいが、左辺が流速$Q/A$ではなく積$QA$となっており誤り ❌
5. $\dfrac{Q}{A}=k\dfrac{h}{L}$ はダルシーの法則そのもの（流速＝透水係数×動水勾配）で正しい ✅

## Ⅲ-2

上層が砂、下層が飽和正規圧密粘土の水平成層地盤がある。層厚は、上層の砂地盤が10m、下層の粘土地盤が12mである。地下水位は地表面と一致し、地盤の静止土圧係数$K_0$は上層、下層ともに0.5である。砂の飽和単位体積重量は$\gamma_{\mathrm{sat}}=20\mathrm{kN/m^3}$、粘土の飽和単位体積重量は$\gamma_{\mathrm{sat}}=18\mathrm{kN/m^3}$、水の単位体積重量は$\gamma_w=10\mathrm{kN/m^3}$である。静水圧状態を仮定して、下層の粘土層中心（深度16m）における鉛直有効応力と水平応力（全応力）の値として、最も適切な組合せはどれか。

1. 鉛直有効応力：148kN/m²、水平応力：74kN/m²

2. 鉛直有効応力：308kN/m²、水平応力：160kN/m²

3. 鉛直有効応力：308kN/m²、水平応力：154kN/m²

4. 鉛直有効応力：148kN/m²、水平応力：234kN/m²

5. 鉛直有効応力：148kN/m²、水平応力：154kN/m²

<details>
<summary>解答・解説</summary>

**正答：4**

深度16m（砂10m＋粘土6m）における各応力を求める。

全鉛直応力：

$$\sigma_v = 20\times 10 + 18\times 6 = 200 + 108 = 308\ \mathrm{kN/m^2}$$

間隙水圧（静水圧、地下水位は地表面と一致）：

$$u = 10\times 16 = 160\ \mathrm{kN/m^2}$$

鉛直有効応力：

$$\sigma_v' = \sigma_v - u = 308 - 160 = 148\ \mathrm{kN/m^2}$$

水平有効応力：$\sigma_h' = K_0\,\sigma_v' = 0.5\times 148 = 74\ \mathrm{kN/m^2}$

水平全応力（間隙水圧を戻す）：$\sigma_h = \sigma_h' + u = 74 + 160 = 234\ \mathrm{kN/m^2}$

よって鉛直有効応力$148\,\mathrm{kN/m^2}$・水平（全）応力$234\,\mathrm{kN/m^2}$の組合せとなる。

1. 鉛直有効応力は正しいが、水平応力が水平有効応力（74）になっており全応力ではないため誤り ❌
2. 鉛直有効応力に全応力308を当てており誤り ❌
3. 鉛直有効応力に全応力308を当てており誤り ❌
4. 鉛直有効応力148・水平全応力234で正しい ✅
5. 水平応力が234ではなく154で誤り ❌

<ExamPoint
  summary="有効応力＝全応力−間隙水圧、水平有効応力＝K₀×鉛直有効応力"
  items={[
    "全応力は飽和単位体積重量×層厚を積み上げて算定",
    "間隙水圧は静水圧 u = γw × 水位以下の深さ",
    "水平全応力 = K₀·σv' + u（有効応力に水圧を戻す）",
  ]}
/>

</details>


## Ⅲ-3

土の基本的な性質に関する次の記述のうち、最も不適切なものはどれか。

1. 細粒土のコンシステンシー限界の1つで、土を練り返したときの液性状態と塑性状態の境界の含水比を液性限界という。

2. 土中の間隙が水で完全に満たされ、一部に気体が存在する状態を不飽和という。

3. 粒度（粒径分布をいう）が良いとは、土を構成する土粒子を粒径によって区分けしたときの分布状態のことで、塑性図によっても知ることができる。

4. 最大間隙比とは、砂の最も緩い状態における間隙比のことであり、砂の相対密度を求めるために必要な間隙比の1つである。

5. 土の単位体積当たりの質量を土の密度といい、土粒子の質量だけを考える場合を乾燥密度という。

<details>
<summary>解答・解説</summary>

**正答：3**

1. 液性限界の定義（液性状態と塑性状態の境界の含水比）として正しい ✅
2. 「間隙が水で完全に満たされ、一部に気体が存在する」は矛盾した表現に見えるが、間隙が水で満たされていない（気体を含む）状態を不飽和とする趣旨であり、不飽和の説明としては適切 ✅
3. 粒度は粒径加積曲線で表され、塑性図（液性限界・塑性指数で細粒土を分類する図）で「粒度の良否」を知ることはできない。塑性図と粒度を混同しており**最も不適切** ❌
4. 最大間隙比は相対密度の算定に必要な指標であり正しい ✅
5. 乾燥密度の説明（土粒子の質量に着目した密度）として正しい ✅

## Ⅲ-4

構造物の基礎に関する次の記述のうち、最も不適切なものはどれか。

1. 浅い基礎の鉛直支持力は、底面での支持力（杭等の場合は、先端支持力）と地盤との摩擦抵抗（周面摩擦力）を加えたものである。

2. 杭は木材、鋼材、コンクリート、複合杭等があり、工場等で製造された既製杭と、現場において地盤に剛性してコンクリートを打設して製造する場所打ちコンクリート杭に大別される。

3. 浅い基礎の沈下は、即時沈下と圧密沈下に分けられる。即時沈下は荷重の載荷に伴なう全応力変化とほぼ同時に発生する沈下であり、圧密沈下は長期にわたって過剰間隙水圧の消散とともに継続的に生ずる沈下である。

4. 浅い基礎は、フーチング基礎と、上部構造のすべての柱や壁からの荷重を単一の基礎スラブで受けるべた基礎に分けられる。

5. 既製杭の設置方法として、杭を地盤に打ち込む打込み杭、圧入することにより設置する圧入杭と、あらかじめ孔を造成し設置したり、杭の中空部を利用して地盤を掘削しながら設置したりする埋込み杭がある。

<details>
<summary>解答・解説</summary>

**正答：1**

1. 「浅い基礎」の鉛直支持力は主に底面の支持力（地盤反力）によるもので、周面摩擦力を主体に加えるのは杭基礎（深い基礎）の考え方である。浅い基礎の支持力に周面摩擦力を加えるとする記述は**最も不適切** ❌
2. 既製杭と場所打ち杭の分類として正しい（細かな表現の乱れはあるが趣旨は適切） ✅
3. 即時沈下（載荷とほぼ同時）と圧密沈下（過剰間隙水圧の消散に伴い長期に進行）の区別として正しい ✅
4. 浅い基礎をフーチング基礎とべた基礎に分ける説明は正しい ✅
5. 既製杭の設置工法（打込み杭・圧入杭・埋込み杭）の説明として正しい ✅

## Ⅲ-5

長さ$L$ [mm]の片持ちばりにおいて、固定端から距離$a$ [mm]の位置に集中荷重$P$ [N]が鉛直下向きに静的に作用している。集中荷重$P$ [N]は弾性変形を生じさせるのに十分に大きい正の値とする。はりの断面二次モーメントは$I$ [mm⁴]、ヤング率は$E$ [N/mm²]であり、長手方向に一定とする。せん断変形を無視した場合、この片持ちばりの先端のたわみ$\delta$ [mm]として、最も適切なものはどれか。ただし、距離$a$ [mm]は正の値である。

<ArticleImage src="/posts/pe-first-stage/r07-construction/img/q05-fig.webp" alt="片持ちばりの図。固定端から距離aの位置に集中荷重Pが鉛直下向きに作用し、固定端から先端までの全長がL" width={972} height={674} />

1. $\dfrac{Pa^2}{6EI}(3L-a)$

2. $\dfrac{2Pa^3}{3EI}$

3. $\dfrac{PL^3}{6EI}$

4. $\dfrac{PL^2a}{6EI}$

5. $\dfrac{P(4a^3+L^3)}{6EI}$

<details>
<summary>解答・解説</summary>

**正答：1**

片持ちばりの固定端から距離$a$の点に集中荷重$P$が作用するとき、荷重点より先端側（$a$から$L$まで）はモーメントを受けず直線のまま回転するため、先端のたわみは荷重点のたわみと荷重点のたわみ角による寄与の和となる。

荷重点（$x=a$）でのたわみと回転角は

$$\delta_a = \frac{Pa^3}{3EI},\qquad \theta_a = \frac{Pa^2}{2EI}$$

先端まで距離$(L-a)$の直線延長を加えて

$$\delta = \delta_a + \theta_a (L-a) = \frac{Pa^3}{3EI} + \frac{Pa^2}{2EI}(L-a) = \frac{Pa^2}{6EI}(3L-a)$$

1. $\dfrac{Pa^2}{6EI}(3L-a)$で正しい ✅
2. 荷重が先端に作用する場合（$a=L$）の形に近いが一般の$a$には対応せず誤り ❌
3. 先端集中荷重$\dfrac{PL^3}{3EI}$とも異なり誤り ❌
4. 次元・係数が合わず誤り ❌
5. 導出式と一致せず誤り ❌

  summary="片持ちばりの中間荷重は荷重点のたわみ＋たわみ角×残り長さで先端たわみを求める"
  items={[

    "荷重点より先は曲げを受けず直線のまま回転する",

## Ⅲ-6

長さ$L$ [mm]の単純ばりに対して、支点Bに反時計回りにモーメント荷重$M$ [N·mm]が静的かつ弾性内で作用している。この単純ばりの支点Aの鉛直反力$V_A$ [N]と支点Bの鉛直反力$V_B$ [N]の組合せのうち、最も適切なものはどれか。

<ArticleImage src="/posts/pe-first-stage/r07-construction/img/q06-fig.webp" alt="単純ばりの図。左の支点A・右の支点Bで支持され、支点Bに反時計回りのモーメント荷重Mが作用する。支間長はL、各支点に上向きの鉛直反力VA・VB" width={981} height={404} />

1. $V_A = 0$、$V_B = 0$

2. $V_A = \dfrac{M}{L}$、$V_B = -\dfrac{M}{L}$

3. $V_A = -\dfrac{M}{2L}$、$V_B = \dfrac{M}{2L}$

4. $V_A = \dfrac{M}{L}$、$V_B = 0$

5. $V_A = 0$、$V_B = \dfrac{M}{L}$

<details>
<summary>解答・解説</summary>

**正答：2**

支点A・Bで支持された単純ばりにモーメント荷重$M$のみが作用する場合、鉛直方向の荷重がないため反力は偶力（大きさが等しく向きが逆）となる。

支点Aまわりのモーメントのつり合いから、

$$V_B \cdot L + M = 0 \quad\Rightarrow\quad V_B = -\frac{M}{L}$$

鉛直方向のつり合い$V_A + V_B = 0$より、

$$V_A = -V_B = \frac{M}{L}$$

したがって$V_A=\dfrac{M}{L}$、$V_B=-\dfrac{M}{L}$となる（大きさ$M/L$の偶力で互いに逆向き）。

1. 反力がともに0では偶力Mとつり合わず誤り ❌
2. $V_A=\dfrac{M}{L}$、$V_B=-\dfrac{M}{L}$で偶力としてつり合い正しい ✅
3. 大きさが$M/2L$では偶力Mとつり合わず誤り ❌
4. $V_B=0$では鉛直方向のつり合いを満たさず誤り ❌
5. $V_A=0$では鉛直方向のつり合いを満たさず誤り ❌

<ExamPoint
  summary="モーメント荷重だけの単純ばりは大きさM/Lの偶力（逆向き等大）になる"
  items={[
    "鉛直荷重がないので2つの反力は等大・逆向き（偶力）",
    "支点まわりのモーメントつり合いで V = M/L を算定",
    "符号は座標系の取り方で変わるが大きさは必ず M/L",
  ]}

## Ⅲ-7

鋼構造物の溶接継手の設計上の留意点に関する次の記述のうち、最も不適切なものはどれか。

1. 連結部の構造はなるべく単純にし、応力の伝達を明確にする。溶接の集中、交差は避け、必要に応じてスカラップ（切欠き）を設ける。

2. 衝撃や繰返し応力を受ける継手はできるだけ突合せ溶接（開先）グルーブ溶接にする。

4. 溶接箇所はできるだけ少なくし、溶接量も必要最小限とする。

5. 溶接継手の組立方法、溶接順序を十分考慮し、できるだけ上向き溶接が可能な構造とする。

<details>
<summary>解答・解説</summary>

**正答：5**

1. 連結部を単純にし応力伝達を明確化、スカラップで溶接の集中・交差を避ける配慮は適切 ✅

3. 偏心を避け板厚差を小さくする配慮は適切 ✅
4. 溶接箇所・溶接量を必要最小限にする配慮は適切 ✅
5. 上向き溶接は施工性・品質が劣り欠陥を生じやすいため避けるべきで、「上向き溶接が可能な構造とする」のは設計上の留意点として**最も不適切**（下向き溶接ができる構造とするのが望ましい） ❌

## Ⅲ-8

1. 厚膜被覆は、ゴムやプラスチックなどの有機材料を1mm以上の厚膜に被覆した長期間の耐久性を有する防食法であり、主として港湾・海洋鋼構造物の飛沫・干満部の防食に用いられる。

## Ⅲ-17

非圧縮性完全流体の定常流れでは、流線上で次式のベルヌーイの定理が成立する。

$$\frac{v^2}{2g} + z + \frac{p}{\rho\,g} = \text{一定}$$

ここで、$g$は重力加速度、$\rho$は水の密度、$v$は高さ$z$の点における流速、$p$は高さ$z$の点における水の圧力である。

下図のように、水面の水位変化が無視できる十分広い水槽から、水槽に鉛直に取り付けられた断面積一定の細い管路で排水する場合、点Bと点Cの流速は等しくなる。このとき管路中心線上の点Bにおける水の圧力を、ベルヌーイの定理を適用して算出すると、最も適切なものはどれか。

<ArticleImage src="/posts/pe-first-stage/r07-construction/img/q17-fig.webp" alt="水槽から鉛直の管路で排水する模式図。水槽水面が点A、管路途中が点B、管路出口が点C。基準面からの高さが点BでzB、点AでzA" width={933} height={1185} />

1. $\rho\cdot g\cdot z_B$

2. $\rho\cdot g\,(z_A - z_B)$

3. $\rho\cdot g\,(z_C - z_B)$

4. $2\rho\cdot g\,(z_A - z_B)$

5. $2\rho\cdot g\,(z_C - z_B)$

<details>
<summary>解答・解説</summary>

**正答：3**

水面（点A、流速ほぼ0・圧力大気圧0）と点B、出口点C（圧力大気圧0）でベルヌーイの定理を適用する。

水面Aと出口Cの間で（$v_A\approx 0$、$p_A=p_C=0$）、出口流速$v_C$は

$$z_A = \frac{v_C^2}{2g} + z_C \quad\Rightarrow\quad \frac{v_C^2}{2g} = z_A - z_C$$

点Bと点Cは断面積一定の同じ管路上で流速が等しい（$v_B=v_C$）。点Bと点Cの間でベルヌーイの定理を適用すると、

$$\frac{v_B^2}{2g} + z_B + \frac{p_B}{\rho g} = \frac{v_C^2}{2g} + z_C + \frac{p_C}{\rho g}$$

$v_B=v_C$、$p_C=0$より、

$$\frac{p_B}{\rho g} = z_C - z_B \;(<0)$$

$p_B = \rho\,g\,(z_C - z_B)$ となる。$z_C < z_B$（点Bは点Cより高い位置）のため $p_B < 0$、すなわち管路途中の点Bは負圧（大気圧以下）となる。

1. $\rho\cdot g\cdot z_B$ は位置水頭のみで誤り ❌
2. $\rho\cdot g\,(z_A - z_B)$ は点AとBの高さ差で誤り ❌
3. $\rho\cdot g\,(z_C - z_B)$ で正しい ✅
4. $2\rho\cdot g\,(z_A - z_B)$ は係数2が不要かつ点AとBの差で誤り ❌
5. $2\rho\cdot g\,(z_C - z_B)$ は係数2が不要で誤り ❌

    "断面積一定の管路では連続式より流速が等しい",
    "管路途中（出口より高い点）は負圧（大気圧以下）になり得る",

2. 深層混合処理工法は、現地、粉末状あるいはスラリー状のセメント等を地中の安定材と原位置の地盤とを強制的に攪拌混合することによって、その化学的固結作用で地盤を強化する工法である。

3. サンドコンパクションパイル工法は、衝撃荷重や振動荷重によって砂を地盤中に圧入し砂柱を造成する工法であり、緩い砂質地盤や粘土質地盤に対して締固め効果による液状化防止の目的で用いられる。

4. プレボーリング工法は、あらかじめ地盤にアースオーガなどにより杭径より10cm程度大きめの孔をあけ、その中に既製杭を挿入する工法で、杭先端の支持力増加のため、最終打撃を行うものと、根固め液を注入した後圧入するものがある。

5. RCD工法は、セメント量の少ない超硬練りのコンクリートをブルドーザで敷き均し、振動ローラで締め固める、ダム全面（一層高伸）を連続的に打設する工法である。

<details>
<summary>解答・解説</summary>

**正答：3**

1. バーチカルドレーン工法・サンドドレーン工法（鉛直排水で圧密促進）の説明は適切 ✅
2. 深層混合処理工法（セメント系固化材を原位置土と攪拌混合し固結）の説明は適切 ✅
3. サンドコンパクションパイル工法は緩い砂質地盤の締固め（液状化防止）に有効だが、粘土質地盤に対しては締固めではなく砂杭による複合地盤としての改良（強度増加・沈下低減）が目的であり、「粘土質地盤に対して締固め効果による液状化防止」とするのは誤りで**最も不適切** ❌
4. プレボーリング工法（先行削孔して既製杭を挿入）の説明は適切 ✅
5. RCD工法（超硬練りコンクリートを敷均し・振動ローラ転圧、面状工法）の説明は適切 ✅

2. 品質管理の目的には、契約条件、設計図書等に示された規格を十分満足するような構造物を最も経済的に施工することにある。

3. 工程の安全管理では、工事を安全に進めるうえで重要であり、いかに労働災害や傷害現場の第三者災害を防止するために常に心がけておくことが必要である。

4. 工程管理は、施工計画に基づいて施工の安全、品質の確保、工事の低減の前提のもとに工程を確保し、結局与え工法とすることが活動である。

5. 施工計画は、「安全施工で確保」と「工事現場周辺の環境との調和の維持」を前提として、「品質、工程、経済性」の3条件を満足するように工事を行う方針と方法を計画することである。

4. 工程管理（安全・品質・コストを踏まえ工程を確保する活動）の説明は概ね適切（表現の乱れはあるが趣旨は適切） ✅
5. 施工計画（安全・環境調和を前提に品質・工程・経済性を満足する計画）の説明は適切 ✅
