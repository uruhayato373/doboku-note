技術士第一次試験の専門科目（建設部門）は、土質から建設環境まで16の分野にまたがる35問から25問を選ぶ試験です。どの分野を厚く学び、どの分野は過去問の頻出語句だけ押さえれば十分か、判断がつかないまま手を広げすぎていませんか。

この記事では、令和元年度から令和7年度までの過去問実物から分野ごとの出題数を数え、16分野の出題数の目安と、25問を選び切るための戦略を整理します。読み終えると、どの分野に学習時間を厚く配分すべきかの優先順位が見えてくるはずです。

結論から言えば、分野ごとの出題数には4問の分野から1問の分野まで明確な差があります。出題数の多い分野を軸に据えつつ、1問しかない分野も広く浅く拾う姿勢のほうが、25問の確保には安全です。

## 専門科目（建設部門）とは — 35問中25問を選ぶ試験

専門科目（建設部門）は35問中25問を選択解答する方式で、[技術士第一次試験とは](/exam/pe-first-stage/guide/overview)で整理したとおり、出題範囲は土木・建設分野の広い領域に及びます。[勉強法の記事](/exam/pe-first-stage/guide/study-plan)でも専門科目を学習の主戦場に据える配分を示しましたが、範囲が広いと言われても、実際に何分野からどれだけ出題されているかまでは掴みにくいものです。

そこで本記事では、令和元年度から令和7年度までの7年分・245問の過去問を分野ごとに数え直し、出題数の目安を一覧にしました。次の章から具体的な内訳を見ていきます。

## 分野別の出題数の目安

35問を分野別に数えると、次の表のとおりです。土質及び基礎・都市及び地方計画・水理の3分野が各4問で最も多く、港湾空港・砂防・道路・鉄道・トンネルの5分野は各1問にとどまります。

| 分野 | 出題数の目安（35問中） |
|---|---|
| 土質及び基礎 | 4問 |
| 構造力学 | 2問 |
| 鋼構造 | 3問 |
| コンクリート | 3問 |
| 都市及び地方計画 | 4問 |
| 水理 | 4問 |
| 河川 | 2問 |
| 海岸 | 2問 |
| 港湾空港 | 1問 |
| 砂防 | 1問 |
| 電力土木 | 2問 |
| 道路 | 1問 |
| 鉄道 | 1問 |
| トンネル | 1問 |
| 施工計画 | 2問 |
| 建設環境 | 2問 |

分野ごとの出題例（年度は令和、r07 は令和7年度）は次のとおりです。

- 土質及び基礎: r07: 透水試験・有効応力／r01: 斜面安定支持力基礎
- 構造力学: r07: 片持ちばりたわみ・単純ばり反力
- 鋼構造: r07: 溶接継手・腐食及び防食・鋼橋維持管理
- コンクリート: r07: 材料・鉄筋コンクリート構造・劣化機構
- 都市及び地方計画: r07: 市街地開発事業・コンパクトシティ・都市防災
- 水理: r07: ベルヌーイの定理・河川流出解析・開水路
- 河川: r07: 河川堤防・河川護岸
- 海岸: r07: 海岸工学・海岸保全施設の設計
- 港湾空港: r07: 港湾の施設
- 砂防: r07: 砂防施設
- 電力土木: r07: 電源別発電電力量構成比・水力発電
- 道路: r07: 舗装の種類
- 鉄道: r07: 鉄道の線路
- トンネル: r07: 山岳トンネルの計画
- 施工計画: r07: 施工工法・施工管理
- 建設環境: r07: 建設環境関係法令・建設環境一般

<Callout type="note" title="出題数は年度により1問前後する">
上表は令和元年度から令和7年度までの過去問を数えた目安で、固定の配点表ではありません。たとえば令和3年度は構造力学寄りの設問が1問多く、鋼構造が1問少ない年でした。分野の並びそのものは年度を通じておおむね一致していますが、境界の問番号は年によって前後すると考えて学習計画を組んでください。
</Callout>

## 土質・構造力学・鋼構造・コンクリート — 力学系12問の傾向

Ⅲ-1からⅢ-12までは、土質及び基礎・構造力学・鋼構造・コンクリートという力学系4分野で構成されます。令和7年度では、透水試験や有効応力といった土質の基本計算、片持ちばりのたわみと単純ばりの反力を求める構造力学、溶接継手や腐食・防食を扱う鋼構造、材料からコンクリート構造の劣化機構までが問われました。

令和5年度・令和元年度を見ても、土質は三相構成や透水・斜面安定支持力基礎、構造力学は断面二次モーメントや断面力図、コンクリートはフレッシュコンクリートの性質やRC構造の設計といった、実務でも扱う基本事項が繰り返し問われています。数値計算を含む設問が多い分野ですが、公式を丸暗記するのではなく、単位と条件を書き出してから代入する手順を身につけておくと、初見の数値に置き換わっても対応しやすくなります。

## 都市及び地方計画・水理・河川砂防海岸・港湾空港 — 計画系14問の傾向

Ⅲ-13からⅢ-26までは、都市及び地方計画・水理・河川・海岸・港湾空港・砂防という計画・水工系6分野、合計14問という構成です。令和7年度では、市街地開発事業やコンパクトシティ、都市防災、国土形成計画といった都市計画の制度が4問、ベルヌーイの定理や河川流出解析、開水路の流れ、土砂移動を扱う水理が4問出題されました。

河川・海岸は河川堤防や河川護岸、海岸工学や海岸保全施設の設計が各2問、港湾空港と砂防はそれぞれ1問です。令和3年度でも都市計画・再開発・交通需要調査といった同系統のテーマが並んでおり、制度の名称と数値要件を正確に区別できるかを問う設問が多い点は年度を通じて共通しています。

<Callout type="note" title="計画系は制度名の混同に注意">
市街地開発事業と都市再開発事業、高水護岸と低水護岸のように、似た名称の制度・施設を入れ替えて誤りの選択肢を作る出題が目立ちます。名称を覚えるだけでなく、根拠法や適用場面の違いまで押さえておくと、選択肢の誤りを見分けやすくなります。
</Callout>

## 電力土木・道路・鉄道・トンネル・施工計画・建設環境 — 残り9問の傾向

Ⅲ-27からⅢ-35までは、電力土木・道路・鉄道・トンネル・施工計画・建設環境の6分野、合計9問です。令和7年度では、電源別発電電力量の構成比と水力発電が電力土木の2問、舗装の種類が道路の1問、鉄道の線路が鉄道の1問、山岳トンネルの計画がトンネルの1問、施工工法と施工管理が施工計画の2問、建設環境関係法令と建設環境一般が建設環境の2問という内訳でした。

道路・鉄道・トンネルはいずれも1問ずつしか出題されないため、深掘りするより過去問に出た用語を確実に押さえる学習で十分です。一方、建設環境は環境影響評価法を軸にした法令問題が繰り返し出題されており、条文の対象事業や手続きの流れを整理しておくと得点しやすくなります。

## 25問をどう選ぶか — 選択の戦略

35問中25問を選ぶ以上、10問は解答しなくてよい計算です。ここで、港湾空港・道路・鉄道・トンネル・砂防のように出題数が1問しかない分野を最初から捨てる戦略を考える方もいるでしょう。しかし、この5分野を丸ごと外すと5問分の選択余地しか残らず、残り30問の中から25問を確保する必要が生じ、力学系や計画系で少しでも失点すると一気に苦しくなります。

得意分野を核にしながらも、1問しか出ない分野を無理に外さず、過去問で見た論点だけは判定できる状態にしておくほうが、25問を確保するうえで安全です。特に力学系12問と都市計画・水理8問の合計20問で確実に得点できる状態を作り、残り15問（河川・海岸・港湾空港・砂防・電力土木・道路・鉄道・トンネル・施工計画・建設環境）から5問分の余裕を持って選べる状態を目指すと、本番での選択に迷いが生じにくくなります。

## 分野別の学習優先度

出題数の多い分野から優先して学習時間を配分するのが基本です。土質及び基礎・都市及び地方計画・水理の3分野は各4問と最も出題数が多く、この3分野を軸に据えると15分の1問弱に相当する配点を安定して確保できます。次いで鋼構造・コンクリートが各3問、構造力学・河川・海岸・電力土木・施工計画・建設環境が各2問という順で、優先度を組み立てるとよいでしょう。

港湾空港・砂防・道路・鉄道・トンネルの5分野は各1問にとどまるため、参考書を通読するより、過去問で実際に問われた用語と正誤の判断根拠を確認する程度の学習に留めても大きな失点にはつながりません。限られた学習時間を、出題数の多い分野の理解を深めることに優先して振り向ける組み方が、25問の確保という観点では合理的です。

分野別の出題傾向を掴んだら、次は試験日から逆算した週次の学習計画に落とし込む段階です。専門科目・基礎科目・適性科目の時間配分と週単位の回し方は、別記事で具体的に整理しています。

令和元年度から令和7年度までの全560問・全選択肢解説をまとめたPDF教材でも、分野ごとに問題を通しで確認できます。
