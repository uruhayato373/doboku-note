## Ⅲ-1

次の河川水を水源とする取水施設の特徴に関する次の記述のうち、適切なものはいくつあるか。

（ア）取水門は、流況、河床、取水位が安定していれば工事及び維持管理も比較的容易で安定した取水が可能であるが、渇水時、洪水時、氷結時には、取水量の確保措置及び調整が必要である。

（イ）取水塔は、大量取水の場合経済的であることが特徴であり、流況の安定している河川で大量に取水する場合に特に優れている。取水堰に比較して、一般的に経済的である。

（ウ）取水管渠は、流況が不安定で水位の変動が多い河川にも適し、施設は地盤以下に築造するので流水の阻害や治水、舟運等に支障がない。

（エ）取水堰は、安定した取水と沈砂効果が大きいことが特徴であり、開発が進んでいる河川等における大量取水の場合に適しているが、河川の流況が不安定な場合には適していない。

1. 0

2. 1

3. 2

4. 3

5. 4

<details>
<summary>解答・解説</summary>

**正答：3**

適切なのは（ア）と（イ）の2つ。水道施設設計指針の取水施設選定表（表-2.1.1）では、取水堰は流況が不安定な河川にも適し、取水管渠は流況が安定し水位変動の少ない河川に適するとされる。

1. 適切な記述は（ア）（イ）の2つあり、0とはならない。 ❌

2. 適切な記述は（ア）（イ）の2つで、1つではない。 ❌

3. （ア）取水門は流況・河床・取水位が安定していれば施工・維持管理が容易で、渇水時・洪水時・氷結時に措置が必要、（イ）取水塔は大量取水で経済的で堰より一般に経済的、の2つが適切。 ✅

4. （ウ）は取水管渠が流況不安定で水位変動の多い河川にも適するとする点、（エ）は取水堰が流況不安定な場合に適さないとする点が誤りで、3つにはならない。 ❌

5. 4つとも適切とはならず、（ウ）（エ）が誤り。 ❌

## Ⅲ-2

上水道の計画に関する次の記述のうち、最も不適切なものはどれか。

1. 計画給水量の算定に用いられる負荷率は、1日最大給水量に対する1日平均給水量の割合をパーセントで表したもので、一般的に小規模の都市ほど高くなり、都市の規模が大きくなるにつれて低くなる傾向がある。

2. 計画有効率は、今後の給・配水整備計画などを反映させ設定することとするが、漏水防止対策の将来計画など諸条件に配慮して可能な限り高い目標値とすることが望ましい。

3. 水需要予測に当たっては、節水や水の循環利用等の水需要に影響を与える要因や、地下水利用の動向等にも配慮することが必要である。

4. 用途別使用水量とは、使用水量を用途別に分類したもので、生活用水量、業務・営業用水量及び工場用水量などである。

5. 目標とする配水管の最小動水圧は150kPa以上、最大静水圧は740kPa以下を基本とする。

<details>
<summary>解答・解説</summary>

**正答：1**

負荷率は小規模な都市ほど水使用の変動が大きく低くなり、大規模な都市ほど平準化されて高くなる。記述は傾向が逆である。

1. 負荷率は小規模都市ほど低く、大都市ほど高くなる傾向のため、逆に述べており誤り。 ❌

2. 有効率は漏水防止の将来計画を反映し、可能な限り高い目標値とするのが望ましく適切。 ✅

3. 節水、水の循環利用、地下水利用の動向は水需要に影響する要因で、予測で配慮するため適切。 ✅

4. 用途別使用水量は生活用、業務・営業用、工場用などに分類したもので適切。 ✅

5. 給水管分岐箇所の配水管内で最小動水圧0.15MPa（150kPa）以上、最大静水圧0.74MPa（740kPa）以下とされ適切。 ✅

3. 高速凝集沈殿池における表面負荷率は、横流式の沈殿池よりも大きく設定することが標準的である。

## Ⅲ-4

（ウ）凝集沈殿 → 砂ろ過 → 粒状活性炭処理 → オゾン処理 → 塩素処理 → 浄水池・配水池

（エ）凝集沈殿 → 粒状活性炭処理 → 砂ろ過 → オゾン処理 → 塩素処理 → 浄水池・配水池

1. ア，エ

2. ア，イ

3. ウ，エ

1. （エ）は活性炭がオゾンより前にあり、オゾンの効果を活性炭で受ける流れにならず不適。 ❌

2. （ア）は前オゾン、（イ）は後オゾンで、いずれもオゾンの後に粒状活性炭がある適用可能なフロー。 ✅

3. （ウ）（エ）とも活性炭の後にオゾンがあり不適。 ❌

4. （イ）は適切だが、（ウ）は活性炭が先でオゾンが後のため不適。 ❌

5. （イ）は適切だが、（エ）は活性炭が先でオゾンが後のため不適。 ❌

## Ⅲ-5

水道のろ過に関する次の記述のうち、最も適切なものはどれか。

1. 均等係数とは、砂の粒度加積曲線（粒径累積曲線）において70%通過径と20%通過径の比をいう。また、急速ろ過池用のろ過砂の均等係数は、1.7以上である。

2. 多層ろ過池は、細粒砂を上層、粗粒砂を下層に用いることによって、ろ過機能を向上させるもので、ろ過速度は300m／日以上が可能である。

3. 緩速ろ過は、砂層表面における付着及び、ふるい分け作用のみによって、水中の不純物を捕捉、抑留する浄化方法で、ろ過速度は10m／日程度である。

4. 直接ろ過法（マイクロフロック法）は、凝集過程で微細なフロックを作り、沈殿池を通さずに直接ろ過池でろ過する方式であり、原水水質が良好で長期に安定している場合に採用される。

5. 自然平衡型ろ過池は、流入水量と流出水量とが自然に平衡する方式のものであるが、配管等の構造が複雑で、ろ過のスロースタート、洗浄のスローダウンが難しい。

<details>
<summary>解答・解説</summary>

**正答：4**

直接ろ過は低濁度で長期に安定した原水を対象とし、混和後にフロック形成・沈殿を省いてろ過する。

1. 均等係数は60%通過径と10%通過径の比で、急速ろ過砂は1.7以下とされ、数値も向きも誤り。 ❌

2. 多層ろ過は上層に粗粒、下層に細粒のろ材を用いる方式で、細粒砂を上層とする点が逆であり、ろ過速度も240m／日以下が一般的で300m／日以上は誤り。 ❌

3. 緩速ろ過は付着・ふるい分けのほか生物の作用も働き、ろ過速度も4〜5m／日程度のため誤り。 ❌

4. 低濁度で長期に安定した原水に採用される直接ろ過の記述で適切。 ✅

5. 自然平衡型は流量制御装置を持たず構造が簡単で、スロースタートも自然に行われるため誤り。 ❌

2. 塩素ガスは空気より軽く、刺激臭のガスである。

3. 液化塩素中の有効塩素は、約50%である。

4. 水道で使用される次亜塩素酸ナトリウムの食塩分は4%より高いことが望ましい。

## Ⅲ-7

水道の配水管の洗浄及び消毒に関する次の記述のうち、最も不適切なものはどれか。

1. 管の洗浄は、洗浄排水に色度が認められなくなるまで行う。

2. 管内面に老朽化等による夾雑物（錆等）が多量に付着している場合は、流速を上げることでさらに濁水が増長することがあるので注意が必要である。

3. 効果的に洗浄するためには管内流速を1.0m/s以上とすることが望ましい。

4. 管の消毒において、当該区間への塩素水注入・洗浄水の排水が可能な場合は、洗浄排水を続けながら、上流端の消火栓、分水栓等の開口部から、プランジャポンプなどにより、管内の残留塩素濃度が10mg/L程度になるように塩素水を注入する。

5. 管の消毒において、塩素を含む水を排水する場合、放流先の状態に応じて、塩素臭や魚類のへい死などが発生しないよう、中和処理・脱塩素処理（亜硫酸ナトリウム・チオ硫酸ナトリウム等）を行うことが必要である。

<details>
<summary>解答・解説</summary>

**正答：1**

洗浄は洗浄排水に濁質が認められなくなるまで行うとされており、色度を基準とする記述は適切でない。

1. 洗浄の終了は洗浄排水に濁質が認められなくなるまでで、色度を基準とする点が誤り。 ❌

2. 錆などが多量に付着する管では流速増大で濁水が増すことがあり、注意が必要で適切。 ✅

3. 洗浄効果を上げるには管内流速1.0m/s以上が望ましく適切。 ✅

4. 洗浄排水を続けながら残留塩素10mg/L程度となるよう塩素水を注入する方法で適切。 ✅

5. 塩素を含む排水は亜硫酸ナトリウムやチオ硫酸ナトリウムで脱塩素して放流するため適切。 ✅

## Ⅲ-9

配水管の施工方法に関する次の記述のうち、最も不適切なものはどれか。

1. 推進工法は、軌道、河川、幹線道路等の横断に適用されることが多く、施工延長50〜100m前後が一般的であるが、土質条件や工法によっては長距離施工も可能である。

2. シールド工法は、内径1,000mm以上で施工延長500〜1,000mを標準とするが、蛇行修正は容易ではない。

3. 不断水工法を採用するときは、試験掘りなどにより既設管の管種、外形、真円度、穿孔機の設置スペース等を確認する。

4. 既設管内布設工法には、道路の掘削をできるだけ少なくし、既設管路を利用して既設管の改良又は更新を行う既設管内挿入工法や既設管内巻込工法等がある。

5. 既設管路更生工法は、管内に沈積又は結節して大きくなった錆こぶによって機能が低下した管路を、種々の機材を使用して通水能力の回復及び赤水発生防止を図るものであり、鋳鉄管又は鋼管等を対象とする。

<details>
<summary>解答・解説</summary>
