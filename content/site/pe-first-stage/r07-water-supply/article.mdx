## Ⅲ-1

水道法第二十二条の四に定められた、水道施設の計画的な更新等に関する次の記述の、［　］に入る語句の組合せとして、最も適切なものはどれか。

水道事業者は、［ア］から、給水区域における［イ］に鑑み、水道施設の計画的な更新に努めなければならない。

水道事業者は、国土交通省令で定めるところにより、［ウ］に要する費用を含み、その事業に係る収支の見通しを作成し、これを公表するよう努めなければならない。

1. ア：短期的な観点、イ：水道施設の更新の需要、ウ：水道施設の点検

2. ア：長期的な観点、イ：水道施設の更新の需要、ウ：計画の策定

3. ア：短期的な観点、イ：一般の水の需要、ウ：計画の策定

4. ア：長期的な観点、イ：一般の水の需要、ウ：水道施設の更新

5. ア：予防保全の観点、イ：水道施設の更新の需要、ウ：水道施設の点検

<details>
<summary>解答・解説</summary>

**正答：4**

条文は「長期的な観点から、給水区域における一般の水の需要に鑑み、水道施設の計画的な更新に努めなければならない」と定め、収支の見通しには「水道施設の更新に要する費用を含み」と規定する。よってア＝長期的な観点、イ＝一般の水の需要、ウ＝水道施設の更新となる。

1. アが短期的な観点となっており、条文の「長期的な観点」と異なるため誤り ❌

2. イが水道施設の更新の需要となっており、条文は「一般の水の需要」であるため誤り ❌

3. アが短期的な観点、ウが計画の策定となっており、いずれも条文と異なるため誤り ❌

4. ア＝長期的な観点、イ＝一般の水の需要、ウ＝水道施設の更新で条文どおりのため正しい ✅

5. アが予防保全の観点、イが水道施設の更新の需要となっており、条文と異なるため誤り ❌

## Ⅲ-2

上水道の計画に関する次の記述のうち、最も不適切なものはどれか。

1. 施設の整備は、非常時においても可能な限り給水を確保するために、浄水場の予備力確保や、送配水管ネットワークの強化、基幹管路の二重化、設備機器の防災性の向上など、システムとしての対応力を向上させる必要がある。

2. 維持管理は、技術者の減少と外部委託化の進展を考慮し、デジタル技術を活用した維持管理手法の導入や、維持管理マニュアルの整備、システムの自動化・簡素化・ネットワーク化を進める必要がある。

3. 施設の改良・更新は、将来の水需要や給水サービスのレベルを勘案し、施設の統廃合やダウンサイジングも含めた施設規模の適正化や再構築、様々なリスクに対する安全度など、水道システム全体を捉えて検討する必要がある。

4. 浄水施設の予備力は、改良・更新時における能力減少への対応や災害・事故時等の安定性を高めるための能力として、1系列相当分程度又は、計画浄水量の25%程度を標準とする。

5. 給水人口規模が大きい水道事業において、配水池の有効容量は計画一日最大給水量の24時間分を標準とし、災害時の飲料水を貯留するための緊急遮断弁を設置することが望ましい。

<details>
<summary>解答・解説</summary>

**正答：5**

配水池の有効容量は、計画一日最大給水量の12時間分を標準とし、需要の変動への対応や非常時の貯留を確保する。緊急遮断弁は、災害時に配水池内の水を貯留するために設置が望ましい設備である。

1. 浄水場の予備力確保、管路の二重化、設備の防災性向上は、非常時の給水確保策として適切 ✅

2. デジタル技術の活用、マニュアル整備、自動化・簡素化は、技術者減少への維持管理上の対応として適切 ✅

3. 統廃合・ダウンサイジング、将来需要、リスクへの安全度を水道システム全体で検討する方針は適切 ✅

4. 予備力を1系列相当分程度又は計画浄水量の25%程度とする記述は、改良・更新時の能力減少や災害・事故時への対応という趣旨に合い適切 ✅

5. 有効容量の標準は24時間分ではなく12時間分であり誤り（緊急遮断弁の設置が望ましい点は正しい） ❌

## Ⅲ-3

地下水に関する次の記述のうち、最も不適切なものはどれか。

1. 過剰な地下水の揚水は、地下水位の低下や地盤沈下を発生させるので、地下水の保全上、取水量の適正な管理が重要である。

2. 浅井戸の水質は、深井戸に比べて地表の影響を受けやすく、とくに人家の近在する場合は汚水の浸入による汚染が発生することがある。

3. 深井戸は、被圧地下水を取水する管井戸で、帯水層内の土質によっては、鉄、マンガンなどの鉱物性物質が溶解していることがある。

4. 伏流水は、河川やその周辺地域において透水層内を潜流している状態の地下水であり、河川が増水したときであっても河川の濁度がそのまま表れることはない。

5. 地中ダムは、地下の帯水層に不透水性の壁を設けることによって、地下水の流れを遮断し、ダム上流側の帯水層内の砂、れき層の空隙に水を貯留するものである。

<details>
<summary>解答・解説</summary>

**正答：4**

伏流水は河床下の砂れき層を流れる水で、河川水がろ過された形で得られるが、河川の水質の影響を強く受ける。増水時には濁度が上昇することがあり、「濁度がそのまま表れることはない」とは言えない。

1. 過剰揚水は地下水位低下や地盤沈下を招くため、取水量の適正管理が重要で正しい ✅

2. 浅井戸は地表の影響を受けやすく、近隣の汚水浸入による汚染のおそれがあり正しい ✅

3. 深井戸は被圧地下水を取水する管井戸で、鉄・マンガンが溶存することがあり正しい ✅

4. 伏流水は河川水の影響を受け、増水時には濁度が上昇しうるため、「現れることはない」は誤り ❌

5. 地中ダムは不透水壁で地下水流を遮断し、上流側の砂れき層の空隙に貯留するもので正しい ✅

## Ⅲ-4

取水施設のうち取水堰に関する次の記述の、［　］に入る語句の組合せとして、最も適切なものはどれか。

取水堰は、河川水を堰上げし、計画水位を確保することにより安定した取水を可能とするため、河川を［ア］して設けられる施設であり、引き上げ式ゲート若しくは起伏式ゲートなどからなる堰本体と［イ］からなる。

取水堰は、比較的大量に取水する場合、農業用水等の他の利水と合同で取水する場合、［ウ］場合、利水が進んでいる河川等で［エ］を必要とする場合などに適している。

1. ア：横断、イ：取水口、ウ：河川の流況が不安定な、エ：正確な取水調整

2. ア：上越し、イ：取水口、ウ：河川の蛇行部で取水する、エ：一定流速の確保

3. ア：横断、イ：集水埋渠、ウ：河川の蛇行部で取水する、エ：正確な取水調整

4. ア：横断、イ：取水口、ウ：河川の蛇行部で取水する、エ：正確な取水調整

5. ア：上越し、イ：集水埋渠、ウ：河川の流況が不安定な、エ：一定流速の確保

<details>
<summary>解答・解説</summary>

**正答：1**

水道施設設計指針（2012）2.3.1は、取水堰を河川を横断して設ける施設とし、堰本体と取水口からなると定める。適用条件には、比較的大量の取水、他の利水との合同取水、河川の流況が不安定な場合、利水が進んだ河川で正確な取水調整を必要とする場合が挙げられている。

1. ア＝横断、イ＝取水口、ウ＝河川の流況が不安定な、エ＝正確な取水調整で正しい ✅

2. アが上越しで、取水堰は河川を横断して設ける施設であり、ウの蛇行部やエの一定流速の確保も適用条件に挙げられていないため誤り ❌

3. イが集水埋渠で、堰本体と組み合わせるのは取水口であり、ウの蛇行部も適用条件に挙げられていないため誤り ❌

4. ウの「河川の蛇行部で取水する」は適用条件に挙げられておらず、正しくは「河川の流況が不安定な」であるため誤り ❌

5. アが上越し、イが集水埋渠、エが一定流速の確保で、いずれも取水堰の構成や適用条件と異なるため誤り ❌

## Ⅲ-5

浄水処理の凝集に関する次の記述のうち、最も不適切なものはどれか。

1. 凝集に影響を与える要因には、撹拌、pH値、アルカリ度、水温等がある。これらが複雑に作用し、凝集剤の注入率に大きく影響する。

2. 凝集剤の注入率は、原水の水質状況や沈殿池、ろ過池等の施設の違いによっても異なることから、注入率の決定に当たっては、処理する原水を用いてジャーテストを行うのが基本である。

3. 混和池には、凝集剤を注入した後、直ちに急速な撹拌を与え、凝集剤を原水中に均一に拡散させることのできる適切な混和装置を設ける。

4. フロック形成池の滞留時間は、計画浄水量の60分程度を標準とする。

5. pH調整剤であるアルカリ剤には、水道用水酸化ナトリウム、水道用水酸化カルシウム、水道用炭酸ナトリウムがあり、アルカリ度が不足する場合に使用される。

<details>
<summary>解答・解説</summary>

**正答：4**

フロック形成池の滞留時間は、計画浄水量に対して20〜40分を標準とする。60分程度という値は標準から外れている。

1. 撹拌・pH・アルカリ度・水温が複合して注入率に影響するという記述は正しい ✅

2. 注入率は原水を用いたジャーテストで決めるのが基本で正しい ✅

3. 混和池は凝集剤注入後に急速撹拌で均一に拡散させる装置を設けるもので正しい ✅

4. 滞留時間の標準は60分ではなく20〜40分であり誤り ❌

5. アルカリ剤として水酸化ナトリウム、水酸化カルシウム、炭酸ナトリウムを用い、アルカリ度不足時に使うことは正しい ✅

## Ⅲ-6

浄水処理における沈殿池の設計に関する次の記述のうち、最も不適切なものはどれか。

1. 横流式沈殿池の形状は長方形とし、沈殿部の長さは幅の3〜8倍を標準とする。

2. 横流式沈殿池の有効水深は3〜4m程度とし、堆泥深さとして30cm以上を見込む。

3. 横流式沈殿池の池底には排泥及び清掃に便利なように、排泥口に向かって勾配をつける。

4. 高速凝集沈殿池における表面負荷率は、横流式沈殿池よりも大きく設定することが標準的である。

5. 水平流式の傾斜板等の沈降装置を設置する場合、装置の傾斜角は45°とする。

<details>
<summary>解答・解説</summary>

**正答：5**

傾斜板・傾斜管等の沈降装置は、沈殿した汚泥が自重で滑り落ちるように、傾斜角を60°とする。

1. 横流式沈殿池は長方形で、長さは幅の3〜8倍が標準であり正しい ✅

2. 有効水深3〜4m程度、堆泥深30cm以上の見込みは正しい ✅

3. 排泥のため池底に排泥口へ向かう勾配をつけることは正しい ✅

4. 高速凝集沈殿池の表面負荷率は横流式より大きい設定が標準的で正しい ✅

5. 傾斜角は45°ではなく60°が標準であり誤り ❌

## Ⅲ-7

浄水処理の急速ろ過に関する次の記述のうち、最も不適切なものはどれか。

1. クリプトスポリジウム等による水道原水の汚染のおそれが高く、ろ過設備のみで対応する場合、ろ過池の出口の濁度を0.1度以下に維持するよう運転管理を行う。

2. 急速ろ過法のろ過速度は、単層ろ過では120〜240m／日、多層ろ過では120〜150m／日を標準とする。

3. 急速ろ過池でろ過するだけではコロイドや懸濁物質の十分な除去は期待できないため、必ず凝集剤を用いて処理を行う。

4. 多層ろ過池は、砂単層のろ過池と比較して、ろ層の単位体積当たりの濁質抑留量が大きく、ろ過効率が高いという特徴をもつ。

5. ろ層の洗浄は、逆流洗浄に表面洗浄を組合せた方式を標準とし、ろ層全体が効率よくかつ効果的に洗浄できるものとする。また、洗浄には、原則、浄水を用いる。

<details>
<summary>解答・解説</summary>

**正答：2**

標準のろ過速度は、単層ろ過が120〜150m／日、多層ろ過が120〜240m／日である。選択肢は単層と多層の数値を入れ替えている。

1. クリプトスポリジウム対策でろ過のみの場合、ろ過水濁度を0.1度以下に維持することは正しい ✅

2. 単層120〜240m／日、多層120〜150m／日は逆で、正しくは単層120〜150m／日、多層120〜240m／日であり誤り ❌

3. 急速ろ過は凝集剤を用いた前処理が前提であり正しい ✅

4. 多層ろ過は濁質抑留量が大きく、ろ過効率が高いという記述は正しい ✅

5. 逆流洗浄に表面洗浄を組合せ、洗浄水は原則浄水を用いることは正しい ✅

## Ⅲ-8

水道施設におけるオゾン処理に関する次の記述のうち、最も不適切なものはどれか。

1. オゾン処理では、難分解性の有機物の生物分解性を増大させる。

2. オゾン処理は単独では使用できず、その後段に粒状活性炭処理設備を設置することとされている。

3. オゾンは、強い酸化力で原水に含まれる臭化物イオンを酸化することで、臭素酸を生成しない。

4. オゾンは微生物に対して塩素よりも強い不活化力を示すが、残留性に乏しいため、我が国の水道では塩素に代わる消毒剤としては使用できない。

5. 排オゾンが大気中に放出されると、労働安全衛生あるいは環境上の問題を引き起こすおそれがある。

<details>
<summary>解答・解説</summary>

**正答：3**

オゾンが臭化物イオンを含む原水と反応すると、発がん性が指摘される臭素酸が生成する。このため、臭素酸の生成抑制が高度浄水処理の設計上の課題となっている。

1. オゾン処理は難分解性有機物を低分子化し、生物分解性を増大させるため正しい ✅

2. オゾン処理の後段には粒状活性炭処理設備を設置するものとされており正しい ✅

3. 臭化物イオンの酸化により臭素酸が生成するため、「生成しない」は誤り ❌

4. オゾンは塩素より不活化力が強いが残留性に乏しく、水道では塩素の代替消毒剤にできないため正しい ✅

5. 排オゾンは放出されれば労働安全衛生・環境上の問題を生じうるため正しい ✅

## Ⅲ-9

水道施設における紫外線処理に関する次の記述のうち、最も不適切なものはどれか。

1. 薬品等を添加する必要がないので、薬品の残留がない。
