3. B　＝　A　＝　C

4. B　＜　A　＝　C

5. B　＜　A　＜　C

<summary>解答・解説</summary>

**正答：5**

直列のBは $0.9^2=0.81$、単独のAは $0.9$、並列のCは $1-(1-0.9)^2=0.99$ なので、$B<A<C$ となる。

1. B ＞ A ＞ C — 直列のBは $0.9^2=0.81$、単独のAは $0.9$、並列のCは $1-(1-0.9)^2=0.99$ なので、$B<A<C$ となる。したがって「B ＞ A ＞ C」ではなく「B ＜ A ＜ C」となるため誤り ❌
2. B ＞ A ＝ C — 直列のBは $0.9^2=0.81$、単独のAは $0.9$、並列のCは $1-(1-0.9)^2=0.99$ なので、$B<A<C$ となる。選択肢の「B ＞ A ＝ C」はこの計算・定義と一致しないため誤り ❌
3. B ＝ A ＝ C — 直列のBは $0.9^2=0.81$、単独のAは $0.9$、並列のCは $1-(1-0.9)^2=0.99$ なので、$B<A<C$ となる。この照合結果は「B ＜ A ＜ C」であり、「B ＝ A ＝ C」は条件を満たさないため誤り ❌
4. B ＜ A ＝ C — 直列のBは $0.9^2=0.81$、単独のAは $0.9$、並列のCは $1-(1-0.9)^2=0.99$ なので、$B<A<C$ となる。よって「B ＜ A ＝ C」という値・式・組合せは導かれないため誤り ❌
5. B ＜ A ＜ C — 直列のBは $0.9^2=0.81$、単独のAは $0.9$、並列のCは $1-(1-0.9)^2=0.99$ なので、$B<A<C$ となるため正しい ✅

コンピュータで数値計算を実施する場合に、誤差が生じることがある。いま、0.01をコンピュータ内部で表現した値を100回足したところ答えが1にはならなかった。プログラム自体に誤りは無いとすると、1にならなかった原因の誤差として最も適切なものはどれか。なお、コンピュータ内部では数値を2進数で扱っており、0.01は2進数では循環小数で表現するものとする。

1. 桁落ち

2. 情報落ち

3. オーバーフロー

4. アンダーフロー

5. 丸め誤差

<details>
<summary>解答・解説</summary>

**正答：5**

10進小数0.01は2進数では循環小数となる。有限ビットへ丸めた近似値を100回加えるため、丸め誤差が累積する。

1. 桁落ち — 桁落ちは近接する数の減算で有効桁が失われる誤差であり、本問の循環小数の表現誤差とは異なる ❌
2. 情報落ち — 情報落ちは桁の大きく異なる数の加算等で小さい数の情報が失われる誤差である ❌
3. オーバーフロー — オーバーフローは計算値が表現可能な最大値を超える現象である ❌
4. アンダーフロー — アンダーフローは絶対値が表現可能な最小値より小さくなる現象である ❌
5. 丸め誤差 — 0.01は2進有限小数で表せず、有限桁へ丸めた値を反復加算するため誤差が累積する ✅

## Ⅰ-2-2

ある村に住民A,B、C,Dの4名が住んでいる。ここでは、重要なことがらの決定には全員が会議に出席して決めることになっているが、以下のように、他人の意見を見ながら自分の意見を決める住民がいる。
※住民Cは、住民AとBが共に議案に賛成のときに反対し、それ以外のときは議案に賛成する。
※住民Dは、住民AとCが共に議案に賛成のときに反対し、それ以外のときは議案に賛成する。
このとき、次の記述のうち最も適切なものはどれか。なお、住民は、必ず賛成か反対のどちらかの決定をするものとする。

1. 住民Cが議案に賛成するのは、住民Aと住民Bが共に賛成するときだけである。

2. 住民Cが議案に賛成するのは、住民Aと住民Bの賛否が異なるときだけである。

3. 住民Dが議案に賛成するのは、住民Aと住民Bが共に賛成するときだけである。

4. 住民Dが議案に賛成するのは、住民Aと住民Bの賛否が異なるときだけである。

5. 住民Bが議案に賛成すれば、必ず住民Dも議案に賛成する。

<details>
<summary>解答・解説</summary>

**正答：5**

Bが賛成の場合、Aが賛成ならCは反対、Aが反対ならA自身が反対となる。いずれもAとCが同時に賛成しないため、Dは必ず賛成する。

1. 住民Cが議案に賛成するのは、住民Aと住民Bが共に賛成するときだけである。 — CはAとBがともに賛成のときだけ反対し、それ以外では賛成するため、記述は真逆である ❌
2. 住民Cが議案に賛成するのは、住民Aと住民Bの賛否が異なるときだけである。 — CはAとBの賛否が異なる場合だけでなく、両者が反対の場合にも賛成する ❌
3. 住民Dが議案に賛成するのは、住民Aと住民Bが共に賛成するときだけである。 — DはAとBがともに賛成の場合だけでなく、両者反対やA反対・B賛成でも賛成する ❌
4. 住民Dが議案に賛成するのは、住民Aと住民Bの賛否が異なるときだけである。 — A賛成・B反対ではCが賛成となってDは反対する一方、A反対・B賛成ではDは賛成する ❌
5. 住民Bが議案に賛成すれば、必ず住民Dも議案に賛成する。 — Bが賛成なら、Aの賛否にかかわらずAとCが同時に賛成とはならず、Dは必ず賛成する ✅
