## Ⅲ-1

令和元年10月1日に施行された水道法の一部を改正する法律における、関係者の責務に関する次の記述の、［　］に入る語句の組合せとして、最も適切なものはどれか。

国は、水道の［ア］に関する基本的かつ総合的な施策を策定し、及びこれを推進するとともに、都道府県及び市町村並びに水道事業者及び水道用水供給事業者に対し、必要な技術的及び財政的な援助を行うよう努めなければならない。

都道府県は、その区域の［イ］に応じて、その区域内における市町村の区域を超えた広域的な水道事業者等の間の［ウ］その他の水道の［ア］に関する施策を策定し、及びこれを実施するよう努めなければならない。

市町村は、その区域の［イ］に応じて、その区域内における水道事業者等の間の［ウ］その他の水道の［ア］に関する施策を策定し、及びこれを実施するよう努めなければならない。

水道事業者等は、その経営する事業を適正かつ能率的に運営するとともに、その事業の［ア］に努めなければならない。

1. ア：基盤の強化、イ：自然的社会的諸条件、ウ：連携等の推進

2. ア：持続的な経営、イ：財政的諸条件、ウ：連携等の推進

3. ア：基盤の強化、イ：財政的諸条件、ウ：連携等の推進

4. ア：持続的な経営、イ：財政的諸条件、ウ：予防保全型管理

5. ア：基盤の強化、イ：自然的社会的諸条件、ウ：予防保全型管理

## Ⅲ-2

水源の水質管理に関する次の記述のうち、最も不適切なものはどれか。

1. 湖沼や貯水池で水温成層が形成されると、表層では障害となる藻類が発生しやすくなる一方、下層では無酸素化が生じ、鉄、マンガンなどの溶出が起きる。

2. 選択取水とは、取水口（放流口）を水深によって選択することにより、洪水後の濁水や藻類による異臭味水などの水質障害を避ける方法で、水温成層が形成されているときが効果的である。

3. 河床に付着藻類が繁殖した河川や停滞水域を持つ河川では、藻類の光合成によって水中の炭酸イオンが消費され、pH値が著しく低下することがある。

4. 河川において鉱工業排水が流入する場合は、ヘキサメチレンテトラミン等の浄水処理対応困難物質が混入するおそれがある。

5. 地下水は一般的に汚染の機会が少ないが、トリクロロエチレンやテトラクロロエチレン、1，4－ジオキサンなどによる地下水汚染が問題となっている。

<details>
<summary>解答・解説</summary>

**正答：3**

藻類は光合成で水中の二酸化炭素や炭酸イオンを取り込むため、藻類が増殖した水域では水の緩衝力が失われ、pHは低下ではなく上昇する。

1. 水温成層が形成されると、日射を受ける表層で藻類が増え、停滞する下層は有機物の分解で溶存酸素が失われ、底泥から鉄・マンガンが溶け出す。記述は正しい ✅
2. 選択取水は水深ごとに水質が異なる成層期に、濁りや異臭味の少ない層から取水する対策であり、記述は正しい ✅
3. 光合成による炭酸イオンの消費はpHを上昇させる方向に働き、「著しく低下する」は逆である ❌
4. ヘキサメチレンテトラミンは鉱工業排水に由来し、塩素処理でホルムアルデヒドを生成するため浄水処理が難しい物質である。記述は正しい ✅
5. 地下水は地表水より汚染の機会が少ないが、塩素系有機溶剤（トリクロロエチレン、テトラクロロエチレン）や1，4－ジオキサンによる汚染が問題となっている。記述は正しい ✅

## Ⅲ-3

水道の貯水施設に関する次の記述のうち、最も不適切なものはどれか。

1. コンクリートダムは、基礎地盤あるいは堤体自体の沈下に対してもそれに追従し、十分安定した状態を保っていられるという、フィルダムにはない特長がある。

2. フィルダムの場合は、洪水越流による安全上の問題が、コンクリートダムの場合に比べはるかに大きいことから、原則として、ダム堤体とは別に洪水吐きを設ける。

3. 重力式ダムは、ダムの高さに対応して岩盤に伝わる力が大きくなるため、最大断面付近の基礎岩盤は、十分なせん断強度を有する堅硬な岩盤が必要である。

4. アーチ式ダムの場合は、重力式ダムの場合より河床部におけるせん断強度の制約は少ない。ただし、上部まで岩盤が堅硬であり、アーチ推力に十分抵抗できる強度が必要である。

5. 流入土砂対策には、貯水池周辺の斜面安定、貯砂ダムの設置、堆積土砂の掘削・浚渫、土砂バイパス、土砂フラッシング、樹林帯の設置などがある。

<details>
<summary>解答・解説</summary>

**正答：1**

沈下に追従できるのは、変形に順応する土や岩石を積み上げたフィルダムの特長である。剛なコンクリートダムは不同沈下に弱く、堅硬な岩盤を基礎とするのが前提となる。

1. 沈下への追従性はフィルダムの特長であり、コンクリートダムにはない。「フィルダムにはない特長」は逆である ❌
2. フィルダムは堤体を越流水が流れると侵食・決壊のおそれが大きいため、堤体とは別に洪水吐きを設ける。記述は正しい ✅
3. 重力式ダムは自重で水圧に抵抗し、基礎岩盤にはダム高に応じた大きな力が伝わるため、せん断強度の高い堅硬な岩盤が必要である。記述は正しい ✅
4. アーチ式ダムは水圧をアーチ作用で両岸の岩盤に伝えるため、河床部のせん断強度の制約は重力式より小さいが、上部の岩盤にもアーチ推力に耐える強度が求められる。記述は正しい ✅
5. 貯水池への流入土砂対策として、斜面安定、貯砂ダム、掘削・浚渫、土砂バイパス、フラッシング、樹林帯が挙げられる。記述は正しい ✅

## Ⅲ-4

浄水処理における凝集に関する次の記述の、［　］に入る語句の組合せとして、最も適切なものはどれか。

凝集処理の機能は、凝集剤を添加後できるだけ［ア］に撹拌して、濁質を微小なフロックに凝集させる前段と、生成した微小フロックを大きく成長させるために、［イ］に撹拌する後段とに分けられる。前段を［ウ］、後段を［エ］という。

［ウ］を外部から与える機械的エネルギーにより行う場合、［オ］による方式や拡散ポンプによる方式などが用いられる。

1. ア：急速、イ：緩やか、ウ：混和、エ：フロック形成、オ：フラッシュミキサ

2. ア：急速、イ：緩やか、ウ：フロック形成、エ：混和、オ：フロキュレータ

3. ア：緩やか、イ：急速、ウ：フロック形成、エ：混和、オ：フロキュレータ

4. ア：緩やか、イ：急速、ウ：混和、エ：フロック形成、オ：フラッシュミキサ

5. ア：緩やか、イ：急速、ウ：混和、エ：フロック形成、オ：フロキュレータ

<details>
<summary>解答・解説</summary>

**正答：1**

凝集剤を添加した直後は、凝集剤を水中へ均一に分散させ濁質と接触させるため急速に撹拌する（混和）。その後、微小フロックどうしを衝突・合体させて大きく育てるため緩やかに撹拌する（フロック形成）。混和を機械的に行う装置がフラッシュミキサ、フロック形成を行う装置がフロキュレータである。

1. 前段は急速撹拌の混和、後段は緩やかな撹拌のフロック形成で、混和の機械式装置がフラッシュミキサであり正しい ✅
2. 前段をフロック形成、後段を混和としており、前段と後段が入れ替わっている ❌
3. ア・イの急速と緩やかが逆であり、ウ・エも入れ替わっている ❌
4. ア・イの急速と緩やかが逆である（前段を緩やかに撹拌すると凝集剤が分散しない） ❌
5. ア・イが逆であるうえ、混和を行う機械式装置がフロキュレータとなっている ❌

## Ⅲ-5

浄水処理の砂ろ過に関する次の記述のうち、最も不適切なものはどれか。

1. 緩速ろ過方式は、急速ろ過方式に比べ、広い面積が必要であるとともに、砂の削り取りのための作業が必要である。

2. 砂ろ過には急速ろ過方式と緩速ろ過方式があり、緩速ろ過方式は、一般に原水水質が良好で濁度も低く安定している場合に採用され、急速ろ過方式は、緩速ろ過方式では対応できない原水水質の場合などに採用される。

3. ろ過砂の粒度加積曲線上の通過率60％と10％の粒径の比を均等係数という。

4. ろ過砂の粒度加積曲線上の通過率50％の粒径を有効径という。

5. ろ過速度は、緩速ろ過方式の場合4～5m／日程度、急速ろ過方式の場合120～150m／日程度として設計することが一般的である。

<details>
<summary>解答・解説</summary>

**正答：4**

有効径は、粒度加積曲線上で通過率10％に相当する粒径であり、50％ではない。均等係数は通過率60％の粒径$D_{60}$を有効径$D_{10}$で割った値である。

$$
U_c = \frac{D_{60}}{D_{10}}
$$

1. 緩速ろ過はろ過速度が小さいため広い面積が必要で、ろ過層表面の汚れた砂を削り取る作業も要る。記述は正しい ✅
2. 緩速ろ過は水質が良好で濁度が低く安定した原水に、急速ろ過はそれ以外の原水にも対応できる方式として採用される。記述は正しい ✅
3. 均等係数は通過率60％と10％の粒径の比$D_{60}/D_{10}$であり、記述は正しい ✅
4. 有効径は通過率10％の粒径$D_{10}$であり、「50％」は誤りである ❌
5. ろ過速度は緩速ろ過が4～5m／日、急速ろ過が120～150m／日が一般的で、記述は正しい ✅

## Ⅲ-6

浄水処理における消毒に関する次の記述のうち、最も不適切なものはどれか。

1. 給水栓における水が、遊離残留塩素を0.1mg／L（結合残留塩素の場合は、0.4mg／L）以上保持するように塩素消毒をする。

2. 前塩素処理は、塩素剤を沈殿池以前の着水井、混和池等で注入する方法で、トリハロメタン生成の抑制やかび臭対策に有効である。

3. 次亜塩素酸と次亜塩素酸イオンは、いずれも遊離塩素又は遊離残留塩素である。

4. 不連続点塩素処理は、原水にアンモニア態窒素が存在する場合に、遊離残留塩素を検出するように不連続点を超えて塩素を注入する方法で、アンモニア態窒素を除去することができる。

5. 塩素剤には、次亜塩素酸ナトリウム、液化塩素及び次亜塩素酸カルシウム（高度さらし粉を含む）がある。

<details>
<summary>解答・解説</summary>

**正答：2**

前塩素処理は、有機物が多く残る沈殿前の水に塩素を注入するため、塩素が有機物と反応してトリハロメタンなどの消毒副生成物を増やしやすい。抑制ではなく、生成の増加が問題となる処理である。

1. 水道法施行規則が定める給水栓の残留塩素の保持基準で、遊離残留塩素0.1mg／L以上（結合残留塩素は0.4mg／L以上）である。記述は正しい ✅
2. 前塩素処理はトリハロメタンの前駆物質と塩素が接触するため、トリハロメタン生成の抑制には不利であり、「抑制に有効」は誤りである ❌
3. 次亜塩素酸（HOCl）と次亜塩素酸イオン（OCl⁻）は、いずれも遊離塩素に分類される。記述は正しい ✅
4. 不連続点を超えて塩素を注入するとアンモニア態窒素が酸化・分解され、その後に遊離残留塩素が現れる。記述は正しい ✅
5. 水道で用いる塩素剤は、次亜塩素酸ナトリウム、液化塩素、次亜塩素酸カルシウム（高度さらし粉を含む）である。記述は正しい ✅

## Ⅲ-7

我が国におけるオゾン処理を用いた高度浄水処理方法について、適用可能な処理フローの組合せとして、最も適切なものはどれか。

（ア）凝集沈殿 → 粒状活性炭処理 → 砂ろ過 → オゾン処理 → 塩素処理 → 浄水池・配水池

（イ）凝集沈殿 → 砂ろ過 → 粒状活性炭処理 → オゾン処理 → 塩素処理 → 浄水池・配水池

（ウ）凝集沈殿 → 砂ろ過 → オゾン処理 → 粒状活性炭処理 → 塩素処理 → 浄水池・配水池

（エ）凝集沈殿 → オゾン処理 → 粒状活性炭処理 → 砂ろ過 → 塩素処理 → 浄水池・配水池

1. ア、エ

2. ア、イ

3. ウ、エ

4. イ、ウ

5. イ、エ

<details>
<summary>解答・解説</summary>

**正答：3**

オゾン処理を用いた高度浄水処理では、オゾンで有機物を分解して生分解しやすくしたうえで、後段の粒状活性炭（生物活性炭）で吸着・生物分解する。したがって、粒状活性炭処理はオゾン処理の直後（下流）に置く。オゾン処理を砂ろ過の前に置くか後に置くかで、（ウ）と（エ）の2通りの組合せが成り立つ。

1. （ア）は粒状活性炭がオゾン処理より前にあり、オゾンの生成物を活性炭で処理できないため不適である ❌
2. （ア）と（イ）はいずれも粒状活性炭処理がオゾン処理の前にあり、不適である ❌
3. （ウ）は砂ろ過後にオゾン・粒状活性炭、（エ）は凝集沈殿後にオゾン・粒状活性炭・砂ろ過の順で、いずれもオゾン処理の後に粒状活性炭が続き適用可能である ✅
4. （イ）は粒状活性炭がオゾン処理の前にあり不適である ❌
5. （イ）が不適であり、組合せとして成立しない ❌
