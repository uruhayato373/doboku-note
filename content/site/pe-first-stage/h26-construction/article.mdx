## Ⅲ-1

土の基本的性質に関する次の記述のうち、最も不適切なものはどれか。

1. 間隙比$e$と間隙率$n$の関係は、$n=e/(1+e)\times100$［%］である。

2. 飽和度$S_r$は、含水比$w$、比重$G_s$、間隙比$e$を用いて$S_r=wG_s/e$の関係から求められる。

3. 締固めエネルギーが異なっても、同じ土であれば最適含水比やそれに対応する最大乾燥密度は同じ値となる。

4. コンシステンシー指数$I_c$は、液性限界$w_L$、含水比$w$、塑性指数$I_p$を用いて$I_c=(w_L-w)/I_p$と定義される。

5. 液性指数が大きいほど、土の鋭敏比が増大する。

<details>

<summary>解答・解説</summary>

**正答：3**

1. 全体積を $V_s(1+e)$、間隙体積を $eV_s$ と置けば、間隙率は $n=e/(1+e)\times100$ となる。 ✅

2. 含水比と土粒子比重から水の体積を表すと、飽和度は $S_r=wG_s/e$ で求められる。 ✅

3. 締固めエネルギーを大きくすると、一般に最大乾燥密度は増加し、最適含水比は低下するため、同じ値にはならない。 ❌

4. コンシステンシー指数は自然含水比の液性限界からの隔たりを塑性指数で除した $I_c=(w_L-w)/I_p$ である。 ✅

5. 液性指数が大きい土ほど練返しによる強度低下が大きくなりやすく、鋭敏比も増大する。 ✅

## Ⅲ-2

土の透水に関する次の記述のうち、最も不適切なものはどれか。

1. 土の透水性を定量的に表す透水係数は、土の種類、密度や飽和度などによって大きく異なる。

2. 動水勾配と土中を流れる流速との間に、水の流れが層流である限り比例関係が成り立つ。この関係をダルシーの法則という。

3. 土の室内透水試験には、定水位透水試験と変水位透水試験がある。定水位透水試験は、透水係数が$10^{-9}\sim10^{-5}\,\mathrm{m/s}$のシルトや細粒分を含む土に適用される。

4. 締固めた供試体を用いた室内透水試験の結果は、アースダムや堤防、道路、埋立地といった人工造成地盤の透水性、浸透水量を推定することに利用されることが多い。

5. 透水係数が$10^{-9}\,\mathrm{m/s}$未満の土は、実質上不透水であると考えてもよい。

<details>

<summary>解答・解説</summary>

**正答：3**

1. 透水係数は粒径・間隙構造・密度・飽和度に左右されるため、土質と状態で大きく変化する。 ✅

2. 層流域ではダルシー則 $v=ki$ が成立し、流速は動水勾配に比例する。 ✅

3. 定水位透水試験は透水性の高い砂・礫質土に適し、透水性の低いシルトや細粒分を含む土には変水位透水試験を用いる。 ❌

4. 締固め供試体の透水試験は、堤防や道路など人工造成地盤の浸透特性を推定する目的に適する。 ✅

5. 透水係数が $10^{-9}\,\mathrm{m/s}$ 未満なら水の移動が極めて小さく、実質的な不透水層として扱える。 ✅

## Ⅲ-3

土圧、支持力、基礎及び斜面安定に関する次の記述のうち、最も不適切なものはどれか。

1. 杭の鉛直支持力は、先端支持力と周面抵抗力からなる。

2. 擁壁などが前方に移動するときのように、土が水平方向に緩む方向で変形していくとき，水平土圧が次第に減少して最終的に一定値に落ち着いた状態を受働状態という。

3. 地盤が構造物の荷重を支える能力を支持力という。

4. 斜面のすべりに対する安全率の値を具体的に求める方法には、すべり面の形状を円形と仮定する円弧すべり解析と、任意形状のすべり面を対象とした非円形すべり面解析がある。

5. 地すべり対策工は、地すべりの発生機構及び規模に応じて、抑制工と抑止工を適切に組み合わせて計画する。

2. 擁壁が前方へ動き土が緩むときは主働状態である。受働状態は擁壁が土を押して圧縮するときに生じる。 ❌

3. 支持力は地盤が破壊せずに構造物荷重を支えられる能力を指す。 ✅

4. 斜面安定解析は仮定するすべり面に応じ、円弧すべり解析と非円形すべり面解析を使い分ける。 ✅

5. 地すべり対策は地下水排除等の抑制工と杭工等の抑止工を機構・規模に応じて組み合わせる。 ✅

## Ⅲ-4

土の圧密に関する次の記述のうち、最も不適切なものはどれか。

1. 圧縮曲線とは、圧密試験で得られた圧密圧力と間隙比又は体積比の関係を、圧密圧力を対数目盛りにとって描いた曲線である。

2. 正規圧密とは、土が現在受けている有効土被り圧の大きさが先行圧密圧力より小さくなっている状態をいう。

3. 過圧密比とは、地盤内で現在受けている有効土被り圧に対する圧密降伏応力の比である。

4. 圧密とは、土が内部間隙水の排出を伴いながら徐々に圧縮していく現象をいう。

5. 圧密降伏応力とは、粘土が弾性的（可逆的）な挙動を示す過圧密の範囲から塑性的（非可逆的）な挙動を示す正規圧密の範囲に移行する境界の応力をいう。

<details>

<summary>解答・解説</summary>

**正答：2**

1. 圧縮曲線は圧密圧力を対数軸に取り、圧密試験で得た間隙比又は体積比との関係を描く。 ✅

2. 正規圧密は現在の有効土被り圧が過去最大の圧密圧力に等しい状態である。現在圧が先行圧密圧力より小さいのは過圧密である。 ❌

3. 過圧密比は圧密降伏応力を現在の有効土被り圧で除した比である。 ✅

4. 飽和土の圧密は過剰間隙水圧の消散と排水を伴って時間とともに進む圧縮である。 ✅

5. 圧密降伏応力は可逆的な過圧密域から非可逆的な正規圧密域へ移る境界応力である。 ✅

## Ⅲ-5

土のせん断に関する次の記述のうち、最も不適切なものはどれか。

1. 応力経路は、主としてせん断過程における地盤材料の応力状態の変化を、2つの応力成分を両軸にとった応力平面上の点の軌跡として表したものである。

2. 圧密非排水試験とは、供試体をある圧力で圧密したのち、排水あるいは吸水を許さずにせん断する試験である。

3. 鋭敏比とは、粘性土の乱さない試料と、これを同じ含水比のまま十分に練り返した試料のそれぞれの非排水せん断強さの比である。

4. 飽和粘土の非排水せん断強さ$c_u$と一軸圧縮強さ$q_u$の関係は、$c_u=q_u/2$で表される。

5. ダイレイタンシーとは、せん断に伴い応力を変えようとする性質である。

<details>

<summary>解答・解説</summary>

**正答：5**

1. 応力経路は応力平面上でせん断過程の応力状態を点の軌跡として表す。 ✅

2. 圧密非排水試験は所定圧力で圧密した後、排水・吸水を許さずにせん断する。 ✅

3. 鋭敏比は乱さない試料の非排水せん断強さを同含水比で練り返した試料の強さで除した比である。 ✅

4. 飽和粘土の一軸圧縮試験では破壊時のモール円から $q_u=2c_u$、すなわち $c_u=q_u/2$ となる。 ✅

5. ダイレイタンシーはせん断に伴って体積を変えようとする性質である。原文の「応力を変えようとする」は誤りである。 ❌

## Ⅲ-7

長さ $3L$［mm］の片持ばりの先端に集中荷重 $P$［N］が鉛直下向きに静的かつ弾性内で作用している。はりの断面二次モーメントは $I$［mm⁴］、ヤング率は $E$［N/mm²］であり、せん断変形は無視する。片持ばり先端のたわみ $\delta_o$［mm］として正しいものはどれか。

1. $\dfrac{PL^3}{EI}$

2. $\dfrac{3PL^3}{EI}$

3. $\dfrac{6PL^3}{EI}$

4. $\dfrac{9PL^3}{EI}$

5. $\dfrac{27PL^3}{EI}$

<details>

<summary>解答・解説</summary>

**正答：4**

1. $PL^3/EI$ は長さを $L$ とした係数であり、$\ell=3L$ の三乗と公式の分母3を反映した係数9になっていない。 ❌

2. $3PL^3/EI$ は長さを3倍した効果を一次で扱った値で、たわみが長さの三乗に比例することを反映していない。 ❌

3. $6PL^3/EI$ は公式 $P\ell^3/(3EI)$ へ $\ell=3L$ を代入した $27/3=9$ と一致せず、係数を6としている。 ❌

4. 片持ばり先端の集中荷重によるたわみは $\delta=P\ell^3/(3EI)$ である。$\ell=3L$ を代入すると $\delta=P(3L)^3/(3EI)=9PL^3/EI$ となる。 ✅

5. $27PL^3/EI$ は $(3L)^3$ の係数27を分母の3で除しておらず、正しいたわみの3倍である。 ❌

## Ⅲ-9

鋼構造物に関する次の記述のうち、最も不適切なものはどれか。

1. 高力ボルト引張接合継手では、継手材片間に働く力を材片間の摩擦力によって伝達する。

2. 引張力を受ける部材にボルト孔が設けられる場合の有効断面積には、幅と板厚の積からボルト孔の断面積を引いた純断面積を用いる。

3. 部材が薄板により構成される場合には、面内に圧縮応力が作用しても座屈が生じないように補剛設計が行われる。

4. 鋼橋の設計において、鋼材は弾性限度内において応力－ひずみは直線的に比例するものと仮定する。

5. 溶接継手の設計に当たっては、溶接が集中しないこと、確実に施工できること、検査しやすいようにすること等の点について考慮する。

<details>

<summary>解答・解説</summary>

**正答：1**

1. 材片間の摩擦力で伝達するのは高力ボルト摩擦接合であり、引張接合はボルト軸方向の引張力で外力に抵抗する。 ❌

2. 引張材の耐力はボルト孔欠損を除いた純断面積で評価する。 ✅

3. 薄板の圧縮部材は局部座屈を防ぐため、補剛材や幅厚比の制限を用いて設計する。 ✅

4. 鋼材は弾性限度内でフックの法則に従うものとして、応力とひずみを直線比例で扱う。 ✅

5. 溶接継手は応力集中を避け、施工性と検査性を確保できる配置・形状とする。 ✅
