# 主任技士 小論文のテーマ傾向 — 何が問われてきたか（通常動画 台本）

## 悩みと約束（0:00-0:15）

どんなテーマが出るか分からないと、経験の棚卸しをどこから始めればいいか迷います。この動画では、出題されやすいテーマの傾向と、経験を備えておく引き出しの作り方を説明します。

## 誤解しやすい前提

過去の特定年度に何が出たかを暗記しても、本番で同じテーマが出る保証はありません。テーマは丸暗記の対象ではなく、傾向として捉え、領域横断で応用できる経験を増やしておくほうが再現性は高くなります。

## 説明ブロック

### 1. テーマは年度暗記でなく傾向で捉える

まず前提から。この試験で問われるのは、日々のコンクリート実務と地続きのテーマばかりです。だからこそ「去年は何が出た、一昨年は何が出た」と年度単位で暗記する準備は割に合いません。どのテーマが来ても差し出せる経験の引き出しを先に揃える——それが準備の本筋です。

### 2. 論じやすい4つの領域を押さえる

耐久性は中性化・塩害・凍害・アルカリシリカ反応など、劣化機構と抑制対策。品質管理は配合設計・受入検査・打込みや養生の管理・強度のばらつき低減。環境配慮は混和材の活用や資源循環、CO2排出の低減。施工トラブル対応はひび割れやコールドジョイント、豆板など現場で起きうる不具合の原因と対策です。

### 3. 経験を「事象→原因→対策→結果と留意点」で言語化する

準備の方法は、この4つの領域ごとに、自分が経験した事象、その原因、採った対策、結果と留意点を1セットずつ言語化しておくことです。テーマが決まってから考えるのではなく、試験前にストックしておきます。

### 4. ストックした経験ブロックを組み替えて本論にする

テーマが変わっても、ストック化した経験ブロックを組み替えれば本論が書けます。同じ現場の経験でも、切り口を変えれば別の領域のテーマにも転用できることがあります。引き出しは領域単位で持っておくのがコツです。

## 動画内要約

テーマ対策は「年度暗記をやめる → 4領域を押さえる → 事象・原因・対策・留意点で言語化する → 組み替えて使う」の順で進めます。傾向を知れば、経験の棚卸しに迷いません。
