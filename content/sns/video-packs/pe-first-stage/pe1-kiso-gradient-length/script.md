# 技術士一次 基礎科目 勾配ベクトルと最急勾配の長さを取り違えない（通常動画 台本）

## 悩みと約束（0:00-21）

令和七年度の基礎、第一群の三の二で問われた論点、勾配のベクトルと長さの取り違えです。結論です。勾配は、偏微分を並べたベクトルです。最急勾配の長さは、そのベクトルの大きさ、つまりノルムです。順序は、偏微分、点を代入、ベクトル、ノルムの四手順。仮の関数で一回通して計算します。

## 誤解しやすい前提

勾配ベクトルを求めたところで手が止まり、そのまま選択肢に丸を付けてしまう。ベクトルと長さは別物なので、ベクトルの形のまま答えても、長さを問う設問の答えにはなりません。

## 説明ブロック（動画の提案）

### 1. 仮の例を置く

仮の例で進めます。実際の出題でも、公式の過去問でもありません。関数は、エフ、エックス、ワイ、イコール、三エックスの二乗、引く、エックスワイ、足す、ワイの二乗。点は、エックスが一、ワイが二です。

### 2. 偏微分から点の代入まで

第一手順は偏微分です。エックスで微分するときは、ワイを定数と見ます。エフエックスは、六エックス引くワイ。ワイで微分するときは、エックスを定数と見ます。エフワイは、マイナスエックス足す二ワイ。まだ数は入れません。

第二手順は点の代入です。エックスが一、ワイが二を、二本の式へ入れます。エフエックスは、六引く二で四。エフワイは、マイナス一足す四で三。代入はこの段階で一度だけ行います。

### 3. ベクトルからノルムへ

第三手順で、二つの値を組にします。勾配ベクトルは、四、三。これは向きと大きさを持つ矢印で、エックス方向に四、ワイ方向に三進む形です。ここで出てくるのは、まだ長さではなくベクトルです。

第四手順がノルムです。成分を二乗して足し、平方根を取ります。四の二乗は十六、三の二乗は九、合わせて二十五。平方根は五です。これが最急勾配の長さで、答えは五になります。

### 4. 取り違えの確認と意味

よくある三つの誤りを、独自の例として同じ数で確認します。実際の選択肢ではありません。四と三の組のままは、ベクトルであって長さではない。四足す三の七は、成分の足し算で、長さではない。二十五は、平方根を忘れた形です。正しい長さは五です。

最急勾配の長さの意味も押さえます。勾配ベクトルの向きは、関数が最も急に増える向きです。その長さは、その向きに進むときの増え方の大きさです。向きは矢印、急さは長さと分けて覚えます。

## 具体例と図解

仮の例 f(x,y)=3x²−xy+y²、点(1,2) は説明用で、実際の出題でも日本技術士会の公式問題でもない。令和7年度 基礎Ⅰ-3-2 の論点（勾配は偏微分の組、最急勾配の長さはそのノルム、ベクトルと長さの取り違え）だけを参照し、関数・点・数値は別に作った。数値は ∂f/∂x=6x−y=4、∂f/∂y=−x+2y=3、grad f=(4,3)、‖grad f‖=√25=5。誤りの例は、よくある取り違えとして作った独自例で、実際の選択肢ではない。(4,3) のまま、4+3=7、根を忘れた25。図は偏微分・代入・ベクトル・ノルムの四手順と、(4,3) を斜辺5の直角三角形で示す簡略版にする。
