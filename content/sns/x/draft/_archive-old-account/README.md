# _archive-old-account — 旧アカウント（@dobokunotecom）退避

2026-06-12 に「platform manipulation and spam」で凍結された旧アカウント時代の
X ドラフト群。`_` 接頭辞のため `x-schedule-guard` / `x-schedule-view` /
`x-sync-status` のスキャン対象外（新アカウントのクリーン SSOT を汚さない）。

- **これらの status.json の `scheduled_at` は旧アカウントの予約であり、もう存在しない**。
  新アカウントで publish-x の対象にしてはいけない（凍結文面の再投稿になる）。
- **tweets.md の文面はネタとして再利用可**。ただし新アカウントで使う際は
  near-duplicate にならないようフック・語順・CTA を作り変える（`x-post-policy.md` §11.1）。

詳細 → `.claude/knowledge/reference/x-post-policy.md` §11.5（アカウント境界 epoch）。
