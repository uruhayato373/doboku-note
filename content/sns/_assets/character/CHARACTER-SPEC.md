# doboku-note キャラクターデザイン設定書

## 1. キャラクター概要

### キャラクター名
doboku-note 先生

### 役割
土木系資格の学習をわかりやすく解説する、現場経験豊富な土木技術者キャラクター。

### 年齢設定
40代男性

### 職業設定
土木技術者・現場監督・資格試験解説者

### キャラクターの印象
- 低めの男性ボイスに合う落ち着いた雰囲気
- 信頼感がある
- 知的で専門性が高い
- 現場経験が豊富
- 厳しすぎず、親しみやすい
- 若手技術者や資格受験者を導く先生役
