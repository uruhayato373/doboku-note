## 投稿手順

### ステップ 1: Stories 起動

IG アプリ → プロフィール画面 → 「+」ボタン → 「ストーリーズ」

### ステップ 2: 4枚の投稿順序

以下の順番で1枚ずつ投稿する（4枚連投）。

**01-cover.png を投稿**
1. 画像を選択
2. テキストを追加:
   ```
   🆕 発売！技術士建設部門 必須科目I 模範解答
   R03〜R07 5年分 + R08予想4本
   ```
3. ステッカーは設定しない
4. 「シェア」→ 次の枚へ

**02-content.png を投稿**
1. 画像を選択
2. テキストを追加:
   ```
   元公務員（発注者）視点の論述テンプレ
   設問(1)〜(3) 字数配分・構成方針付き
   ```
3. 投票ステッカーを追加:
   - 質問文: 「試験直前の模範解答、欲しい？」
   - 選択肢1: 「はい」
   - 選択肢2: 「迷ってる」
4. 「シェア」→ 次の枚へ

**03-target.png を投稿**
1. 画像を選択
2. テキストを追加:
   ```
   設問の書き方に迷っている人へ 📖
   「発注者視点って何？」と思ったら読んで
   ```
3. 質問ステッカーを追加:
   - 質問文: 「どの科目で受験しますか？」
4. 「シェア」→ 次の枚へ

**04-cta.png を投稿**
1. 画像を選択
2. テキストを追加:
   ```
   note マガジンで公開中
   試験まで1ヶ月、今すぐ確認を
   ```
3. リンクスタンプを追加:
   - URL: `https://note.com/dobokunote/m/m0f3bc3933454`
   - ラベル: 「マガジンを見る」（任意）
4. 「シェア」

## ハイライト追加

投稿後、4枚をまとめてハイライトに保存する。

- ハイライト名: **建設部門BK-I**
- 追加方法: 各 Stories を表示 → 右下「ハイライト」→「建設部門BK-I」を選択（なければ新規作成）
- 4枚すべてを同一ハイライトに集約する

## 推奨投稿時刻

**平日 07:00 JST**（受験者の朝活・通勤前の確認時間帯）

次点: 平日 21:00 JST（帰宅後の学習時間帯）

曜日優先度: 火 > 金（戦略 v7 §2 Instagram 高リーチ曜日）

試験本番が近い時期（6〜7月）は受験者の情報収集頻度が高まるため、早期の投稿が効果的。
