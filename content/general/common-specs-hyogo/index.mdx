## 土木工事共通仕様書【兵庫県】

兵庫県土木部が発注する土木工事の施工に関する共通的な仕様を定めたものである。

:::tip
近畿地方整備局版は[土木工事共通仕様書（案）【近畿地方整備局】](/docs/general/common-specs)を参照してください。
:::

## 構成

| 編 | 名称 | 概要 |
|---|---|---|
| 第1編 | [共通編](#第1編-共通編) | 総則、土工、無筋・鉄筋コンクリート |
| 第2編 | [材料編](#第2編-材料編) | 一般事項、土木工事材料、港湾工事材料 |
| 第3編 | [土木工事共通編](#第3編-土木工事共通編) | 総則、一般施工（共通的工種、河川・海岸・砂防土工、法面工、舗装、鋼橋架設、植栽等） |
| 第4編 | [港湾工事共通編](#第4編-港湾工事共通編) | 総則、共通仮設、一般施工（浚渫、基礎工、本体工、被覆・根固工等） |
| 第6編 | [河川編](#第6編-河川編) | 築堤・護岸、浚渫、水門、堰、排水機場、床止め・床固め、河川維持・修繕 |
| 第7編 | [河川海岸編](./07-coastal) | 海岸堤防・護岸、突堤・人工岬、海域堤防、浚渫（海岸）、養浜 |
| 第8編 | [砂防編](./08-erosion) | 砂防堰堤、流路、斜面対策 |
| 第9編 | [ダム編](./09-dam) | コンクリートダム、フィルダム、基礎グラウチング |
| 第10編 | [道路編](#第10編-道路編) | 道路改良、舗装、橋梁、トンネル、シェッド、共同溝、道路維持・修繕、雪寒 |
| 第11編 | [港湾編](./11-port) | 航路・泊地・船だまり、防波堤、防潮堤、護岸・岸壁、桟橋、臨港道路 |
| 第12編 | [港湾海岸編](./12-port-coastal) | 堤防・防潮堤・護岸、突堤、離岸堤、樋門・水門、養浜 |
| 第13編 | 下水道編 | 管路（開削・推進・シールド）、処理場・ポンプ場 |
| 第14編 | 公園緑地編 | 基盤整備、植栽、施設整備、グラウンド・コート、自然育成 |
| 第15編 | [水道編](./15-water) | 管路（管布設、水管橋） |

:::note
第5編は欠番です。
:::
