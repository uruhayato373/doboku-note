# 品質管理および検査

完成したコンクリート構造物が所要の性能を有することを確認できるように、合理的かつ経済的な検査計画を定め、工事の各段階で必要な検査を行う。標準示方書では、「検査」とは、製造、施工されたコンクリート、部材、構造物などが、当初設定した要求性能を満足し、受取り可能かどうかを判定することとしている。コンクリート構造物の施工にあたって、検査の対象となるものは、個々の材料の品質、コンクリートの品質、施工の品質、できあがった構造物の品質などがあり、検査の実施の体制についても、種々のものがある。

材料や製品の検査は購入者が行い、構造物の発注者は書類等でそれを確認する場合が多い。レディーミクストコンクリートは、施工者が購入するため、原則として施工者が検査することになるが、検査を依頼して行うことも多く、施工者は十分把握しておく必要がある。施工に関する検査や竣工検査は、一般には、構造物の発注者が行う。

検査は、あらかじめ定めた判定基準に適合しているか否かを、必要な測定や試験を行った結果に基づいて判定する。試験を行う場合は、客観的な判定が可能な手法を用いる。一般的には、JISまたは土木学会規準に定められた方法に従って行うのを原則としている。検査の結果、合格と判定されない場合は、適切な処置を講じ所定の性能を満足するようにしなければならない。

**表3.40 コンクリートの性能と関係する主な指標**

| コンクリートの性能 | 関係する主な指標 |
|---|---|
| 断熱温度上昇特性 | 結合材の品質、単位結合材量、温度（打込み時） |
| 強度 | セメント（結合材）水比 |
| 中性化速度係数 | 結合材の品質、有効水結合材比 |
| 塩化物イオンに対する拡散係数 | 水セメント比（塩化物イオン量：内的塩害の場合） |
| 凍結融解抵抗性 | 水セメント比、空気量、骨材の品質 |
| 耐化学的侵食性 | 結合材の品質、水結合材比 |
| 耐アルカリ骨材反応性 | 骨材および結合材の品質、単位セメント量 |
| 透水係数 | 水セメント比 |
| 耐火性 | 骨材の品質、単位水量 |
| 収縮特性 | コンクリート材料の品質、単位水量、単位セメント量 |
| ワーカビリティー | 粗骨材の最大寸法、スランプ、ブリーディング率（量）、目視による材料分離の程度 |
| ポンパビリティー | 骨材の品質、粗骨材の最大寸法、スランプ、ブリーディング率（量）、目視による材料分離の程度 |
| 凝結特性 | セメントの品質、混和材料の品質、温度（打込み時） |

## 10.1 検査計画

検査計画の設定は、施工計画に対応して、検査する項目の選定、必要な人員配置、試験・検査方法の選択、試験・検査の時期や頻度、試験・検査の適用方法などについて行う。検査は、構造物の重要性、工事の種類および規模、工事期間、材料や適用施工法の信頼性・熟練度、施工の時期、その後の施工工程への影響度、効率などを考慮して計画する。

検査計画は、コンクリートの製造に関する検査、施工工程における検査、できあがったコンクリート構造物について立案する。標準的な工事の場合、表3.41に従って検査を行えばよい。

|---|---|---|---|
| プロセスごとの検査 | コンクリート材料 | セメント、水、骨材、混和材料等 | 確認 |
| — | コンクリート製造設備 | 貯蔵設備、計量設備、ミキサ等 | 確認 |
| — | レディーミクストコンクリート | スランプ、空気量、塩化物イオン量、強度等 | 確認 |
| — | 補強材料 | 鉄筋の品質等 | 確認 |
| 施工 | コンクリート工 | 運搬、打込み、養生等 | 直接 |
| — | 鉄筋工 | 鉄筋の径、数量、加工寸法、固定方法、スペーサの配置・数（かぶり）、鉄筋の配置、継手等 | 直接 |

所要の性能を有するコンクリートを製造するためには、セメント、水、細骨材、粗骨材、混和材料等が配合設計において選定された品質のものであることが重要である。このため、材料の受入れ検査時に試験を行い、その品質を確認する必要がある。セメント、混和材料等の検査は、製造工場の試験成績表を確認する方法によってよい。

製造設備の検査は、表3.42を標準としている。

**表3.42 製造設備の検査**

| 種類 | 項目 | 試験方法 | 時期・頻度 | 判定基準 |
|---|---|---|---|---|
| 材料の貯蔵設備 | 必要とする項目 | 目視、設備の構造図の確認、温度・湿度測定 | 工事開始前および工事中 | 施工標準の規定に適合すること |
| 計量設備 | 計量器計量精度（静荷重） | 分銅または電気式検査器による荷重と表示値の誤差測定 | 工事開始前、工事中1回/6か月以上 | 計量法の使用公差以内であること |
| — | 計量制御装置計量精度（動荷重） | 設定値と実計量値の誤差測定 | 工事開始前、工事中1回/1か月以上 | 所要の精度以内であること |
| ミキサ | バッチミキサ練混ぜ性能 | JIS A 8603の方法 | 工事開始前、工事中1回/年以上 | JIS A 8603に適合すること |
| — | 連続ミキサ練混ぜ性能 | JSCE-I501およびJSCE-I502の方法 | — | JSCE-I501およびJSCE-I502に適合すること |

製造工程の検査は、コンクリートの圧縮強度管理データを調べ、所定のばらつきの範囲に入っていることを確認することで行う。

## 10.2 レディーミクストコンクリートの受入れ検査

レディーミクストコンクリートの品質管理は打込み時に行うのがよいが、荷卸しから打込み終了まで品質変化が把握できている場合には、荷卸し地点で確認してもよい。レディーミクストコンクリートの受入れ検査を、表3.43に示す。

**表3.43 コンクリートの受入れ検査**

| 項目 | 試験方法 | 時期・頻度 | 判定基準 |
|---|---|---|---|
| フレッシュコンクリートの状態 | コンクリート主任技士やコンクリート技士またはそれと同等の技術を有する技術者による目視 | 荷卸し時、随時 | ワーカビリティーが良好で、性状が安定していること |
| スランプ | JIS A 1101の方法 | 荷卸し時、1回/日または構造物の重要度と工事の規模に応じて20〜150m³ごとに1回、および荷卸し時に品質の変化が認められた時 | 許容誤差：スランプ5cm以上8cm未満:±1.5cm / スランプ8cm以上18cm以下:±2.5cm |
| 空気量 | JIS A 1116、JIS A 1118、JIS A 1128の方法 | — | 許容誤差：±1.5% |
| フレッシュコンクリートの単位水量 | フレッシュコンクリートの単位水量試験から求める方法 | — | 許容範囲内にあること |
| フレッシュコンクリートの温度 | JIS A 1156の方法 | — | 定められた条件に適合すること |
| 塩化物イオン量 | JIS A 1144の方法または信頼できる機関で評価を受けた試験方法 | 荷卸し時、海砂を使用する場合2回/日、その他の場合1回/週 | 原則として、0.30kg/m³以下 |
| アルカリシリカ反応対策 | 配合計画書の確認 | 工事開始時、および材料あるいは配合が変化したとき | 対策がとられていること |
| 配合（計量値） | 計量印字記録等 | 適宜 | 許容範囲内にあること |
| 圧縮強度（一般の場合、材齢28日） | JIS A 1108の方法 | 荷卸し時、1回/日または構造物の重要度と工事の規模に応じて20〜150m³ごとに1回 | 設計基準強度を下回る確率が5%以下であることを、適当な生産者危険率で推定できること |

### (1) スランプ試験

スランプ試験は、現場におけるコンクリートの軟らかさを判断するために広く用いられている。一般に、この試験によって均等質なコンクリートが造られているかどうかも判断できる。したがって、スランプの試験値に変化が認められた場合には、所定のコンクリート材料と所定の方法でコンクリートが正常に造られているかどうか、骨材の粒度が設定の範囲内にあるかどうか、骨材の表面水率が適正に管理されているかどうか、などを検討する必要がある。

スランプの値は、スランプコーンにコンクリートを3層に分けて詰め、各層ごとに突き棒で25回一様に突き、表面を均した後、スランプコーンを静かに鉛直に引き上げ、コンクリートの中央部で下がりを0.5cm単位で測定したものを指す。

### (2) 空気量試験

フレッシュコンクリートでは、同じコンクリート材料を用い、同じ配合のコンクリートで作業を進めている場合でも、骨材の粒度、気温などが変化すると空気量が相当変わることがある。空気量の変動は、コンクリートのワーカビリティー、強度および耐久性などに影響を与える。そのため、フレッシュコンクリートを用いる場合には、空気量が適切かどうかを確かめるために、試験を行う。特に、凍結融解作用に対する抵抗性に与える影響は大きく、凍結融解作用に対する抵抗性を検査する必要がある場合には、適切な頻度で空気量を確認する必要がある。

**表3.46 荷卸し地点での空気量およびその許容差（単位：%）**

| コンクリートの種類 | 空気量 | 空気量の許容差 |
|---|---|---|
| 普通コンクリート | 4.5 | ±1.5 |
| 軽量コンクリート | 5.0 | ±1.5 |
| 舗装コンクリート | 4.5 | ±1.5 |
| 高強度コンクリート | 4.5 | ±1.5 |

### (3) 塩化物イオン含有量試験

コンクリートに含まれる塩化物含有量は、荷卸し地点で、塩化物イオンとして、0.30 kg/m³以下でなければならない。ただし、購入者の承認を受けた場合には、0.60kg/m³以下とすることができる。なお、塩化物含有量の検査は、工場出荷時でも、荷卸し地点での所定の条件を満足するので、工場出荷時に行うことができる。

### (4) 温度測定試験

コンクリートの温度は、フレッシュコンクリートの品質、水和熱による温度変化、強度発現性、硬化後の品質などに影響を与えるため、特にマスコンクリート、寒中コンクリートあるいは暑中コンクリートの施工において重要な管理項目である。

暑中コンクリートでは、打込み時のコンクリートの温度は35°C以下、寒中コンクリートの打込み時の温度は5°C〜20°Cとする。

### (5) 単位水量測定試験

コンクリートの強度および耐久性に大きく影響するのは、水セメント比である。したがって、水セメント比を受入れ時に検査することは極めて重要である。フレッシュコンクリートの水セメント比を測定する方法には、フレッシュコンクリートの単位水量試験から求めた単位水量と、製造設備の自動計量記録装置から求めた単位セメント量とから計算により求める方法がある。

近年、フレッシュコンクリートの単位水量を推定する試験方法として、エアメータ法、水中質量法、高周波加熱乾燥法（電子レンジ法）、減圧式加熱乾燥法、乾燥炉法、静電容量法、連続式RI法、水濃度測定法、塩分濃度差法などが開発されている。これらのうち、比較的よく使われている試験法とその測定原理を表3.47に示す。なお、各検査の結果不合格とされたコンクリートは、用いてはならない。

**表3.47 レディーミクストコンクリートの単位水量測定試験**

| 名称 | 原理 |
|---|---|
| エアメータ法 | 単位水量が増加するとコンクリートの単位容積質量が小さくなる。この性質を利用し、単位容積質量の違いから単位水量を推定する。 |
| 高周波加熱乾燥法（電子レンジ法） | コンクリートからふるい分けたモルタル分を、電子レンジで加熱乾燥させ、質量の減少量とコンクリートの単位水量の相関性が高いことを利用し、コンクリートの単位水量を推定する。 |
| 減圧式加熱乾燥法 | 水は減圧乾燥すると、約50°Cで沸点に達する。試料を減圧室で加熱乾燥し、その前後の質量差より単位水量を推定する。 |
| 静電容量法 | 物質の誘電率が水分量によって変化することを応用。モルタル中の静電容量と水分率の関係式をあらかじめ求めておき、機械でモルタル中の静電容量を測定することにより単位水量を推定する。 |

### (6) 強度試験

強度の検査は、コンクリートの配合検査を行うことを標準とするが、配合検査を行わない場合は、JIS A 1108の方法に従って、圧縮強度試験を行って確認することが必要になる。現状では、JIS A 5308（レディーミクストコンクリート）においては強度試験を行うことが定められている。

試験回数は、普通コンクリート、軽量コンクリートおよび舗装コンクリートにあっては、150m³について1回、高強度コンクリートにあっては、100m³について1回の割合を標準とするとしているので、3回の試験値が得られる450m³が1つの検査ロットとなる（標準示方書では、「試験回数は、荷卸し時に1回/日または構造物の重要度と工事の規模に応じて20〜150m³ごとに1回、および荷卸し時に品質変化が認められたとき」とされている）。しかし、検査ロットの大きさは、構造物の規模や工事における作業区画の大きさなどに応じて定めることが必要な場合もあるので、購入者と生産者とが協議して定めることとされている。

コンクリートの強度は、一般に、標準養生を行った円柱供試体の材齢28日における圧縮強度を標準とする。コンクリートの強度は、次の条件を満足するものでなければならない。

**(a)** 1回の試験の結果は、購入者が指定した呼び強度の値の85%以上。

**(b)** 3回の試験の平均値は、購入者が指定した呼び強度の値以上。

ここでの1回の試験結果とは、任意の1運搬車から採取した試料でつくった3個の供試体の圧縮強度の平均値である。また、圧縮強度を行う供試体の材齢は、指定がない場合は28日、指定がある場合には購入者が指定した日数とする。

{/* 図3.42 強度試験の合否判定 */}

| 呼び強度 | 3個の供試体の圧縮強度の平均値（N/mm²） | — | — | 判定条件：個々の試験値は17.9N/mm²以上 | 判定条件：3回の試験値の平均値は21N/mm²以上 | 判定 |

## 10.3 施工の検査

### (1) 鉄筋の加工および組立の検査

鉄筋の加工および組立の検査では、鉄筋の種類・径・数量、鉄筋の加工寸法、スペーサの種類・配置・数量、鉄筋の固定方法、組み立てた鉄筋の配置（継手および定着の位置・長さ、かぶり、有効高さ、中心間隔）を目視やスケールによる測定により行う。

**表3.49 鉄筋の加工および組立の検査**

| 項目 | 試験方法 | 時期・頻度 | 判定基準 |
|---|---|---|---|
| 鉄筋の種類・径・数量 | 製造会社の試験成績表による確認、目視、径の測定 | 加工後 | 設計図書どおりであること |
| 鉄筋の加工寸法 | スケール等による測定 | — | 所定の許容誤差以内であること |
| スペーサの種類・配置・数量 | 目視等 | — | 床版、はり等の底面部で1m²あたり4個以上。柱等の側面部で1m²あたり2個以上 |
| 鉄筋の固定方法 | — | — | コンクリートの打込みに際し、変形・移動のおそれのないこと |
| 重ね継手および定着の位置・長さ | — | 組立後および組立後長期間経過したとき | 設計図書どおりであること |
| かぶり | スケールによる測定および目視等 | — | 鉄筋の直径以上で、かつ耐久性を満足するかぶり以上 |
| 有効高さ | — | — | 許容誤差：設計寸法の±3%または±30mmのうち小さいほうの値（標準） |
| 中心間隔 | — | — | 許容誤差：±20mm（標準） |

鉄筋の加工寸法の許容誤差は、組み立てた鉄筋の配置の許容誤差に直接影響するので、構造物の種類や重要度、部材の寸法ならびに誤差の方向によって定めるものとするが、一般には表3.50を目安とするとよい。

**表3.50 加工寸法の許容誤差**

| 鉄筋の種類 | 記号 | 許容誤差（mm） |

| 径28mm以下の丸鋼・D25以下の異形鉄筋 | a, b | ±15 |
| 径32mm以下の丸鋼・D29以上D32以下の異形鉄筋 | a, b | ±20 |
| — | 加工後の全長 L | ±20 |

### (2) 鉄筋の継手の検査

鉄筋の継手にガス圧接継手、溶接継手、機械式継手等を用いる場合には、必要に応じて、使用前に継手の強度を確かめなければならない。鉄筋の継手の検査項目は、継手の種類によって異なるが、重ね継手の場合、位置、継手長さを目視およびスケールによる測定により行う。ガス圧接継手の場合、外観検査と超音波探傷検査（JIS Z 3062）により行う。

**表3.51 ガス圧接継手の検査**

#### 外観検査

規格値（熱間押抜法以外の場合）：

1. 軸心の偏心が鉄筋径（径の異なる場合は細いほうの鉄筋）の1/5以下
2. ふくらみは鉄筋径（径の異なる場合は細いほうの鉄筋）の1.4倍以上。ただし、SD490の場合は1.5倍以上
3. ふくらみの長さが1.1D以上。ただし、SD490の場合は1.2倍以上
4. ふくらみの頂点と圧接部のずれがD/4以下
5. 著しいたれ下がり、折れ曲がりがない

規格値を外れた場合の対応：

- ①は、圧接部を切り取って再圧接し、外観検査および超音波探傷検査を行う
- ②③は、再加熱し、圧力を加えて所定のふくらみに修正し、外観検査を行う
- ④は、圧接部を切り取って再圧接修正し、外観検査および超音波探傷検査を行う
- ⑤は、著しい折れ曲がりが生じた場合は、再加熱して修正し、外観検査を行う。また、著しい焼き割れおよび垂れ下がりなどが生じた場合は、圧接部を切り取って再圧接し、外観検査および超音波探傷検査を行う

#### 超音波探傷検査

各検査ロットごとに30箇所のランダムサンプリングを行い、超音波探傷検査を行った結果、不合格箇所数が1箇所以下のときはロットを合格とし、2箇所以上のときはロットを不合格とする。JIS Z 3062では、合否判定レベルを-24dBとしている。

不合格ロットの全数について超音波探傷検査を実施し、その結果不合格となった箇所は、補強筋（ラップ長の2倍以上）を添えるか、圧接部を切り取って再圧接する。圧接部を切り取って再圧接によって修正する場合には、修正後外観検査および超音波探傷検査を行う。

## 10.4 コンクリート構造物の検査

### (1) 表面状態の検査

表面状態の検査は、補修、手直し等の処置を施す前に行う。

**表3.52 表面状態の検査**

| 項目 | 試験方法 | 判定基準 |
|---|---|---|
| 露出面の状態 | 目視 | 露出面が平坦であり、欠けた箇所、鉄筋の露出、かぶり不足の兆候、コールドジョイント、豆板、砂すじ等の初期欠陥が認められず、外観が正常であること |
| ひび割れ | 目視およびクラックスケールによる測定 | ひび割れ幅が、あらかじめ定めた許容ひび割れ幅以下であること |
| 空洞、浮き | 打音 | 異音が生じないこと |
| 打継目の状態 | 目視 | 打継目において、新旧コンクリートの一体性が保たれていると判断されること |

検査の結果、コンクリートの表面に突起、すじなどが認められた場合には、取り除いて平らに仕上げる。豆板、欠けた箇所等は、不完全な部分を取り除いて補修を行う。かぶり不足の徴候が認められる箇所は、かぶり検査を行い、必要に応じて適切な補修を行う。許容されたものより大きいひび割れに対しては、適切な補修を行う。

外部から塩化物の影響を受けるおそれのあるコンクリート構造物では、コンクリート表面のひび割れの入念な検査を行い、有害なひび割れが生じている場合には適切な処置を行う。

### (2) 非破壊検査

コンクリート構造物が設計どおりの性能を有しているかどうかの最終検査で、品質・性能を直接確認することも重要である。また、コンクリート構造物の維持管理のために、構造物の強度やかぶり等の測定が必要となる場合があり、その方法として非破壊検査がある。

**表3.53 コンクリート構造物の非破壊検査の種類**

| 対象 | 非破壊検査法の種類 | 原理など |
|---|---|---|
| 配筋・かぶり厚さ | 電磁波レーダ法 | 電磁波を放射し、鉄筋から反射してきた反射波を受信して計測 |
| — | 電磁誘導法 | 電流の電気的変化を検出して、磁界中の良導体（鉄筋）を探査 |
| — | X線法 | X線をコンクリート構造物の断面方向に透過させ、撮影された透過画像から内部の様子を確認 |
| 強度 | リバウンドハンマ法（反発度法） | コンクリート表面に重錘を衝突させ、その反発度を測定することにより強度を推定 |
| — | 超音波法 | 強度と音速の高い相関関係を利用して推定 |
| — | 衝撃弾性波法 | コンクリート表面をインパクタで打撃し、入力した縦弾性波速度と強度の関係式から推定 |
| 施工不良（ジャンカ・コールドジョイント・内部空洞） | 打音法 | コンクリート表面をハンマで打撃し、打撃音を測定し、打撃力や打撃音の分析から内部空洞などの欠陥の有無を検知 |
| — | 電磁波レーダ法 | 電磁波を放射し施工不良箇所の比誘電率が異なっていることから、反射してきた反射波を受信して検出 |
| — | 衝撃弾性波法 | コンクリート表面をインパクタで打撃し、縦弾性波が施工不良箇所の存在による伝搬速度の低下、伝搬経路の伸長、欠陥表面の反射、曲げ振動の発生などの性質を利用して検出 |
| 劣化・損傷（浮き、はくり） | 赤外線法（サーモグラフィー法） | コンクリート表面温度を赤外線カメラにより計測し、温度分布状況から空洞等を検知 |
| 劣化・損傷（ひび割れ） | 超音波法（直接回折波法） | 超音波を発信による圧縮波を検出してひび割れ深さを測定 |
| — | 衝撃弾性波法 | コンクリート表面をインパクタで打撃し、縦弾性波がひび割れ先端を回折することによる伝搬時間差から深さを測定 |
| — | X線法 | X線をコンクリート構造物に透過させ、撮影された透過画像からひび割れの分布状況を検出 |
| 鉄筋腐食 | 電気化学的方法 | 自然電位法は、腐食により変化する鉄筋の電位を測定することで鉄筋腐食を診断する方法 |

:::note
**コンクリートの反発度の測定方法（JIS A 1155）について**

普通コンクリートの反発度を、リバウンドハンマによって測定する方法である。反発度と強度の関係を示す理論式がないため、反発度から強度に換算するには実験的に得られた換算式や換算図が使用される。このため、精度を上げるには、同一のコンクリート構造物から採取したコアの圧縮強度を用いて補正することが望ましい。

**① リバウンドハンマの点検**
- 測定前および測定後に、リバウンドハンマの点検を行う
- 点検はテストアンビルを打撃してその反発度を測定することにより行う（テストアンビルはリバウンドハンマの点検および検定に用いる鋼製の器具）

**② 測定箇所の選定**
- 測定箇所は、厚さ100mm以上の床版や壁部材、一辺長150mm以上の柱やはり部材の表面とする
- 測定箇所は、部材の縁部から50mm以上離れた内部から選定する
- 測定箇所は、表面組織が均一で、かつ平滑な平面部とする
- 測定箇所は、露出砂利などの部分および表面はく離、凹凸のある部分を避ける

**③ コンクリート表面の処理**
- 測定面にある凹凸や付着物は、研磨処理装置などで平滑に磨いて取り除き、コンクリート表面の粉末その他の付着物を拭き取ってから測定する
- 測定面に仕上げ層や上塗り層がある場合には、これを除きコンクリート面を露出させた後、上記の処理を行ってから測定する

**④ 測定方法**
- 測定は、環境温度が0〜40°Cの範囲内で行う
- ハンマの作動を円滑にさせるため、測定に先立ち数回の試し打撃を行う
- ハンマが測定面に常に垂直方向になるよう保持し、ゆっくり押して打撃する
- 1箇所の測定では、互いに25〜50mmの間隔をもった9点について測定する
- 測定後のリバウンドハンマの点検によって、リバウンドハンマの反発度が製造時の反発度より3%以上異なっていたら、直前に行った点検以後の測定値は用いてはならない
:::
