## 土木工事共通仕様書（案）【近畿地方整備局】

本仕様書は、近畿地方整備局が発注する土木工事の施工に関する共通的な仕様を定めたものである。

:::tip
兵庫県版は[土木工事共通仕様書【兵庫県】](/docs/general/common-specs-hyogo)を参照してください。
:::

## 構成

| 編 | 名称 | 概要 |
|---|---|---|
| 第1編 | [共通編](./01-common) | 総則、土工、無筋・鉄筋コンクリート |
| 第2編 | [材料編](./02-materials) | 一般事項、土木工事材料 |
| 第3編 | 土木工事共通編 | 総則、一般施工（共通的工種、河川・海岸・砂防土工、法面工、舗装、鋼橋架設、植栽等） |
| 第6編 | [河川編](./06-river-01) | 築堤・護岸、浚渫、水門、堰、排水機場、床止め・床固め、河川維持・修繕 |
| 第7編 | [河川海岸編](./07-coastal) | 海岸堤防・護岸、突堤・人工岬、海域堤防、浚渫（海岸）、養浜 |
| 第8編 | [砂防編](./08-erosion) | 砂防堰堤、流路、斜面対策 |
| 第9編 | [ダム編](./09-dam) | コンクリートダム、フィルダム、基礎グラウチング |
| 第10編 | 道路編 | 道路改良、舗装、橋梁、トンネル、シェッド、共同溝、道路維持・修繕、雪寒 |

:::note
第4編、第5編、第11〜15編は本版には収録されていません。
:::
