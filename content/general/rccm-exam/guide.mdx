# RCCM試験 概要と対策ガイド

## 1. RCCMとは

### 1.1 資格の概要

**RCCM**（Registered Civil Engineering Consulting Manager：シビルコンサルティングマネージャ）は、一般社団法人 建設コンサルタンツ協会が実施する資格試験に合格し、登録を受けた技術者の称号である。建設コンサルタント業務における**管理技術者**および**照査技術者**として従事するために必要な資格として位置付けられている。

建設コンサルタント業務の品質確保には、豊富な実務経験と高度な技術力を持つ技術者が不可欠である。RCCMは、こうした技術者の資質を客観的に証明する資格として、業界で広く認知されている。

### 1.2 資格の位置付け

国土交通省の「建設コンサルタント登録規程」において、建設コンサルタントが登録を受けるためには、技術管理者を配置する必要がある。この技術管理者の要件として、**技術士**とともに**RCCM**が認められている。

また、公共事業の業務発注において、管理技術者や照査技術者の資格要件としてRCCMが求められることが多い。

### 1.3 取得のメリット

- **管理技術者・照査技術者への就任**: 建設コンサルタント業務の管理技術者・照査技術者として業務に従事できる
- **技術管理者の要件充足**: 建設コンサルタント登録規程に基づく技術管理者の要件を満たす
- **業務受注における評価**: プロポーザル方式や総合評価方式の入札において、配置技術者の資格として評価される
- **技術力の証明**: 建設コンサルタント分野における専門技術力と管理能力を客観的に証明できる
- **キャリアアップ**: 技術士取得に向けた中間的なステップとしても活用できる

## 2. 試験の概要

### 2.1 試験日程

| 項目 | 時期 |
|---|---|
| 受験申込 | 例年7月〜8月頃 |
| 試験日 | 例年11月（年1回） |
| 合格発表 | 翌年3月頃 |

:::note
最新の試験日程は、一般社団法人 建設コンサルタンツ協会の公式サイトで確認すること。
:::

### 2.2 受験資格

受験には、建設コンサルタント等業務に関する実務経験が必要であり、**学歴に応じて必要な経験年数**が異なる。

| 学歴 | 必要実務経験年数 |
|---|---|
| 大学院修了（修士・博士） | 5年以上 |
| 大学卒業（4年制） | 7年以上 |
| 短期大学・高等専門学校卒業 | 9年以上 |
| 高等学校卒業 | 11年以上 |

- 実務経験は、建設コンサルタント業務（計画、調査、設計、施工管理、維持管理等）に関するものであること
- 受験部門に関連する業務経験を有していることが求められる

### 2.3 技術部門

RCCMの技術部門は、建設コンサルタント登録規程に基づく**22部門**から選択する。

| 番号 | 部門名 | 番号 | 部門名 |
|---|---|---|---|
| 1 | 河川、砂防及び海岸・海洋 | 12 | 建設環境 |
| 2 | 港湾及び空港 | 13 | 機械 |
| 3 | 電力土木 | 14 | 電気電子 |
| 4 | 道路 | 15 | 地質 |
| 5 | 鉄道 | 16 | 土質及び基礎 |
| 6 | 上水道及び工業用水道 | 17 | 鋼構造及びコンクリート |
| 7 | 下水道 | 18 | トンネル |
| 8 | 農業土木 | 19 | 施工計画、施工設備及び積算 |
| 9 | 森林土木 | 20 | 建設機械 |
| 10 | 水産土木 | 21 | 都市計画及び地方計画 |
| 11 | 廃棄物 | 22 | 造園 |

受験は1回の試験で**1部門のみ**。複数部門を取得する場合は、年度を分けて受験する必要がある。

### 2.4 合格率

RCCM試験の合格率は例年 **約40〜50%** で推移している。技術士の第二次試験（合格率約10〜15%）と比較すると合格率は高いが、実務経験を有する技術者のみが受験するため、受験者のレベルが高い中での合格率であることに留意する。

## 3. 試験構成と各問題の対策

RCCM試験は、以下の5つの問題で構成される。試験時間は午前・午後に分かれて実施される。

| 問題 | 内容 | 形式 | 配点の目安 |
|---|---|---|---|
| 問題1 | 業務経験論文 | 記述式 | 高 |
| 問題2 | 管理技術論文 | 記述式 | 高 |
| 問題3 | 一般知識（択一） | 四肢択一 | 中 |
| 問題4-1 | 専門技術（択一） | 四肢択一 | 中 |
| 問題4-2 | 専門技術（記述） | 記述式 | 中 |

### 3.1 問題1: 業務経験論文

#### 概要

自らが携わった建設コンサルタント業務の中から1つを選び、その業務における技術的課題、解決策、成果について論述する。管理技術者または照査技術者としての資質を評価する最重要問題の一つである。

#### 出題形式

事前に提出する「業務経歴票」に記載した業務の中から出題される。試験当日に、指定されたテーマに沿って論文を作成する。

#### 対策のポイント

1. **業務経歴票の準備が最重要**
   - 技術的難易度の高い業務を選定する
   - 自分が主体的に関与し、技術的判断を行った業務を選ぶ
   - 管理技術者・照査技術者として求められる視点（品質管理、工程管理、技術的判断）が記述できる業務を選ぶ

2. **論文構成の基本パターン**
   - 業務の概要（目的、規模、条件）
   - 技術的課題の抽出と分析
   - 課題に対する解決策の立案と実施内容
   - 得られた成果と今後の課題

3. **評価されるポイント**
   - 技術的課題の的確な把握
   - 解決策の論理性・妥当性
   - 管理技術者としてのマネジメント能力
   - 専門技術力の深さと幅

### 3.2 問題2: 管理技術論文

#### 概要

建設コンサルタント業務の管理技術に関する問題であり、**技術者倫理**、**照査技術**、**業務管理**などのテーマが出題される。管理技術者として必要な知識・判断力を問う問題である。

#### 主な出題テーマ

- **技術者倫理**: 公益の確保、説明責任、技術者の行動規範
- **照査技術**: 成果品の品質確保、照査のプロセスと方法
- **業務管理**: 工程管理、コスト管理、人材育成
- **社会的課題への対応**: 防災・減災、インフラ老朽化、環境保全、i-Construction

#### 対策のポイント

1. **技術者倫理の理解**
   - 技術士倫理綱領・建設コンサルタンツ協会の行動規範を理解する
   - 具体的な倫理的ジレンマに対する対応方針を整理しておく
   - 公益確保、安全の優先、説明責任の3点を軸に論述できるようにする

2. **照査に関する知識**
   - 照査の目的（成果品の品質確保）を理解する
   - 照査の手順（計画→実施→記録）を体系的に整理する
   - 照査技術者の役割と責任を明確にする

3. **最新の技術動向の把握**
   - BIM/CIM、i-Construction の動向
   - 国土強靱化、流域治水などの政策動向
   - 気候変動適応策、カーボンニュートラルなどの社会的課題

### 3.3 問題3: 択一問題（一般知識）

#### 概要

建設コンサルタント業務に必要な一般的知識を問う四肢択一問題。土木工学の基礎知識、関連法規、社会資本整備に関する幅広い知識が問われる。

#### 主な出題分野

| 分野 | 出題内容の例 |
|---|---|
| 土木工学全般 | 構造力学、水理学、土質力学、材料学 |
| 測量 | 測量の基礎、GNSS測量、写真測量 |
| 関連法規 | 建設業法、建設コンサルタント登録規程、公共工事品確法 |
| 社会資本整備 | インフラ長寿命化、防災・減災、環境保全 |
| 技術管理 | 品質マネジメント、リスクマネジメント |
| 情報技術 | BIM/CIM、GIS、ICT施工 |

#### 対策のポイント

1. **幅広い基礎知識の習得**
   - 土木工学の各分野について、基礎的な知識を偏りなく学習する
   - 過去問の出題傾向を分析し、頻出分野を把握する

2. **法規・制度の理解**
   - 建設業法、品確法、入契法の基本的な規定を押さえる
   - 建設コンサルタント登録規程の内容を理解する

3. **過去問演習の反復**
   - 過去5年分程度の問題を繰り返し解く
   - 正解の理由だけでなく、不正解の選択肢がなぜ誤りかを理解する

### 3.4 問題4-1: 択一問題（専門技術）

#### 概要

受験する技術部門に関する専門的知識を問う四肢択一問題。部門固有の技術基準、設計手法、施工技術等について出題される。

#### 対策のポイント

1. **技術基準の把握**
   - 受験部門に関連する技術基準・指針の内容を理解する
   - 改定されたばかりの基準は出題されやすい

2. **部門別の重点分野**
   - 例: 道路部門 → 道路構造令、道路土工指針、舗装設計施工指針
   - 例: 河川部門 → 河川砂防技術基準、河川管理施設等構造令
   - 例: 鋼構造及びコンクリート → 道路橋示方書、コンクリート標準示方書

3. **過去問の徹底分析**
   - 部門ごとの出題傾向を把握する
   - 技術基準の改定に伴う新しい出題に注意する

### 3.5 問題4-2: 記述問題（専門技術）

#### 概要

受験部門の専門技術に関する記述式問題。与えられたテーマについて、技術的な知識と応用力を論述形式で解答する。

#### 対策のポイント

1. **体系的な知識の整理**
   - 部門の主要テーマについて、背景・課題・対策・留意点を体系的に整理する
   - 「設計」「施工」「維持管理」の各段階での技術的ポイントを押さえる

2. **論述の構成力**
   - 結論を先に述べ、理由・根拠を後に示す構成を心がける
   - 具体的な数値や基準名を挙げて説得力を持たせる

3. **図表の活用**
   - 必要に応じて図や表を用いて、分かりやすく説明する
   - 概念図やフロー図は評価されやすい

## 4. 学習戦略

### 4.1 学習スケジュールの目安

RCCM試験は例年11月に実施されるため、**6月頃から本格的な学習**を開始するのが望ましい。以下に、約5か月間の学習スケジュール例を示す。

| 時期 | 学習内容 |
|---|---|
| 6月〜7月 | 過去問分析、弱点の把握、業務経歴票の作成開始 |
| 8月 | 択一対策（問題3・問題4-1）の集中学習、業務経歴票の完成 |
| 9月 | 論文対策（問題1・問題2）の骨子作成、択一対策の継続 |
| 10月 | 論文の模擬執筆と推敲、択一問題の総復習 |
| 11月（試験前） | 全体の最終確認、時間配分の練習 |

### 4.2 分野別の学習優先度

合格のために、以下の優先順位で学習を進めることを推奨する。

| 優先度 | 分野 | 理由 |
|---|---|---|
| 最優先 | 問題1（業務経験論文） | 配点が高く、事前準備で大きく差がつく |
| 最優先 | 問題2（管理技術論文） | 配点が高く、テーマを予測して準備可能 |
| 高 | 問題4-2（専門技術・記述） | 記述式のため事前準備が有効 |
| 中 | 問題3（一般知識・択一） | 過去問の反復で得点を確保できる |
| 中 | 問題4-1（専門技術・択一） | 過去問の反復で得点を確保できる |

### 4.3 論文対策の具体的方法

1. **骨子の作成**: テーマごとに「背景→課題→解決策→結論」の骨子を作成する
2. **模擬論文の執筆**: 制限時間内に論文を書き上げる練習を繰り返す
3. **第三者によるレビュー**: 同僚や上司に論文を読んでもらい、客観的な評価を受ける
4. **複数テーマの準備**: 出題テーマが予測できない場合に備え、3〜5テーマ程度は準備する

### 4.4 択一対策の具体的方法

1. **過去問5年分の反復**: 最低3回は繰り返し、正答率80%以上を目標とする
2. **分野別の弱点補強**: 正答率の低い分野を重点的に学習する
3. **最新の技術動向の確認**: 新しい技術基準や政策動向も出題されるため、直近の動向を確認する

## 5. 技術士との違い

RCCMと技術士は、いずれも建設コンサルタント業務に関わる重要な資格であるが、以下の点で異なる。

| 比較項目 | RCCM | 技術士（建設部門） |
|---|---|---|
| 実施団体 | 建設コンサルタンツ協会 | 日本技術士会（国家資格） |
| 資格の性格 | 民間資格 | 国家資格（文部科学省所管） |
| 技術部門 | 22部門 | 建設部門（11科目） |
| 試験構成 | 論文＋択一 | 第一次試験＋第二次試験（論文＋口頭） |
| 合格率 | 約40〜50% | 第二次試験 約10〜15% |
| 受験資格 | 実務経験（5〜11年） | 第一次試験は制限なし、第二次試験は実務経験要 |
| 業務上の位置付け | 管理技術者・照査技術者 | 管理技術者・照査技術者（より上位の評価） |
| 名称独占 | なし | あり（「技術士」は名称独占） |
| 更新制度 | あり（4年ごとの更新登録） | なし（永続） |

### 技術士との使い分け

- **RCCM**: 技術士取得前の段階で管理技術者・照査技術者として活躍するために有効。技術士を目指す上での実力確認にも活用できる
- **技術士**: 建設コンサルタント業界における最上位の技術者資格。プロポーザルにおいてRCCMより高い評価を受けることが多い

RCCMを取得した後に技術士を目指すキャリアパスが一般的であり、RCCM試験の学習経験は技術士試験の準備にも大いに活かされる。
