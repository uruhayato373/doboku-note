## 発生土利用基準について

### 1. 目的

本基準は、建設工事に伴い副次的に発生する土砂や泥（以下「発生土」という。）の土質特性に応じた区分基準及び各々の区分に応じた適用用途標準等を示すことにより、発生土の適正な利用の促進を図ることを目的とする。なお、本基準については、今後の関係法令及び基準類等の改・制定や技術的な状況の変化等を踏まえ、必要に応じ、見直しを行うものとする。

### 2. 適用

本基準は、発生土を建設資材として利用する場合に適用する。ただし、利用途が限定されており、各々の利用の用途に応じた基準等が別に策定されている場合には、別途規定されている基準によるものとする。なお、建設汚泥の再利用については「建設汚泥処理土利用技術基準」（国官技第50号、国官総第41号、平成18年6月12日）を適用するものとする。

### 3. 留意事項

本基準を適用し、発生土を利用するにあたっては、関係法規を遵守しなければならない。

### 4. 土質区分基準

#### (1) 土質区分基準

発生土の土質区分は、原則として、コーン指数と土質材料の工学的分類体系を指標として、表-1に示す土質区分基準によるものとする。なお、土質改良を行った合には、改良後の性状で判定するものとする。

#### (2) 土質区分判定のための調査試験方法

土質区分判定のための指標を得る際には、表-2に示す土質区分判定のための調査試験方法を標準とする。

### 5. 適用用途標準

発生土を利用する際の用途は、土質区分に基づき、表-3に示す適用用途標準を目安として、個々の事例に即して対応するものとする。

### 6. 関連通達の廃止

本通達の発出に伴い、「発生土利用基準について」（国官技第31号、国官総第669号、平成16年3月31日）は廃止する。

5. 判定の方法でモールドに挿入のうえ試料に対し、コーンペネトロメーターで測定したコーン指数（表-2参照）とする。処理及び判定方法については別に定めるものとする。

7. 土質材料の工学的分類は75mm以下の土に適用する。
8. 砂及び砂と同等の品質を満たすものについては産業廃棄物処理法の対象となる廃棄物（建設工事等から生ずる廃棄物の適正処理について（通知）平成10年6月16日　環産第46号、同10号、同16号、同43号、同13号　建技第276号）の50%、137%、41%、18%、12%とする。
9. 改良土と同等と扱える区分も適宜設定可能とする。

:::note 凡例

- ◎：そのままで使用が可能なもの。
- ○：留意事項に配慮すれば、基本的に使用可能。機種の選定、構造・施工法の変更により使用可能な場合がある。
- △：直接上との配合なく利用した場合には留意が必要。配合等を行えば上位の適用用途標準に従い使用可能な場合がある。
- ×：そのままの利用は困難。安定処理により性質を安定させて使用可能。
- 粒度分布注意：利用用途先の材料の最大粒径、または、一層の仕上り厚の1/2を超える粒径を含む場合の対応が必要。
- 最大粒径注意：利用用途先の上層の最大粒径、または一層の仕上がり厚の制約による対応の検討が必要。
- 排水注意：含水比の大きさ、天日乾燥、水切り節約を行って、含水比の低下を図ることにより利用可能な場合がある。
- 施工機械の選定注意：施工性に留意し施工機械の選定を行う（事前に検討）。
- 粒度分布注意：マウンドの安定に適する粒度分布の確認が必要。（個別に検討）。
- 淡水域利用注意：淡水域において発生土を利用する場合はpH等に配慮する。

注意事項：表にない適用用途に発生土を使用する場合は、本表に該当する適用用途標準を目安として、個々の事例に即して対応するものとする。

:::

### 参考表　コーン指数（qc）の測定方法

「締固めた土のコーン指数試験方法（JIS A 1228）」（地盤工学編「土質試験の方法と解説　第一回改訂版」pp.266-268）をもとに作成

| 項目 | 内容 |
|:---|:---|
| **試料** | 4.75mmふるいを通過したもの。ただし、改良土の場合は9.5mmふるいを通過させたものとする。 |
| **供試体の作成** | - |
| モールド | 内径 100±0.4mm |
|  | 容量 1,000±12 cm³ |
| ランマー | 質量 2.5±0.01kg |
| 突固め | 3層に分けて突き固め、各層ごとに30±0.15cmの高さから25回突き固める。 |
| **測定** | - |
| コーンペネトロメーター | 底面の面積3.24cm²、先端角度30度のもの。 |
| 貫入速度 | 1cm/s |
| 貫入方法 | モールドをつけたまま、筒底にコーンの先端を供試体上面から5cm、7.5cm、10cm貫入した時の貫入抵抗力を求める。 |
| **計算** | - |
| 貫入抵抗力 | 貫入量5cm、7.5cm、10cmに対する貫入抵抗力を平均して、平均貫入低抗率を求める。 |
| コーン指数（qc） | 平均貫入低効力をコーン先端の底面積3.24cm²で除する。 |

:::note 注
ただし、ランマーによる突固めが困難な場合は、足圧と等価とする。
:::
