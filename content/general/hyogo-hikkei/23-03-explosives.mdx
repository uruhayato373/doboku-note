## 火薬類譲受許可証継続許可申請書

規則第38条第1項の譲受許可証の譲渡人記載欄に余白がなくなった時、その交付を受けた兵庫県知事又は県民局長にこの様式を用いて継続申請する。

## 火薬類譲受（渡）許可証再交付申請書

### 再交付申請を行うことのできる場合

1. 許可証を喪失したとき
2. 許可証を汚損したとき
3. 許可証を盗取されたとき

:::note
- 上記1、3に該当するときは遅滞なく、その旨を警察官又は海上保安官に届け出なければならない。
- 上記2の場合は申請時に旧許可証を添付すること。
- 申請の際は始末書を必ず添付すること。
- 譲受消費許可を受け譲受許可証とあわせて消費許可証も事故に会ったときは、消費許可証再交付申請も併せて行うこと。
:::

### 再交付を受けた後

許可証の再交付を受けた後旧許可証を発見したときは、5日以内に旧許可証を交付先に返納すること。

## 始末書（譲受・消費許可証紛失等の場合）

### 記載方法

1. この始末書は記載の一例である。
2. 特に許可証を紛失、盗取された場合、その事故の発生状況を詳細に記載すること。
3. 紛失、盗難等の場合事故届を最寄の警察官又は海上保安官に届出る必要があるので届出た警察署、届出年月日等を記入すること。

## 火薬類消費許可証再交付申請書

### 再交付申請を行うことのできる場合

1. 許可証を喪失したとき
2. 許可証を汚損したとき
3. 許可証を盗取されたとき

上記1、3に該当するときはその旨を遅滞なく警察官又は海上保安官に届け出ること。上記2の場合は申請時に旧許可証を添付すること。

### 再交付申請手続

- 許可証が喪失、盗取されたため交付年月日、番号等不明の場合は交付元の都道府県を確かめて申請すること。
- 申請の際は始末書（記載例参照）を必ず添付すること。
- 譲受消費許可で消費許可証と合わせて譲受許可証も事故にあった時は譲受許可証再交付申請も併せて行うこと。

### 再交付を受けた後

許可証の再交付を受けた後旧許可証を発見したときは、5日以内に旧許可証を交付先に返納すること。

## 火薬類譲受許可証の譲受先変更願

許可を受けた際譲受許可証に記載されていた譲受先に変更が生じた場合にこの様式を使用する。

### 記載方法

- 譲受先が複数の場合は、その譲受先を記入すること。
- 願書提出の際許可証も同時に提出すること。
- 変更になった場合新しい販売店の残火薬類保管引受書を添付すること。

## 火薬類消費計画書記載事項変更届

火薬類の消費の方法並びに火薬類を取扱う必要のある者の氏名に変更が生じた場合にこの様式を用いる。

### 変更届で対応できない場合

以下の場合は変更届では不可であって、再許可申請を行うこと。

1. 火薬類の種類及び数量、目的、場所、日時ならびに危険予防の方法に変更のあった場合
2. 消費の方法のうち1日の最大消費量の変更に伴なって火薬類取扱所の存置量が変更する場合は別途火薬類取扱所設置場所等変更届を提出

### 変更内容に伴なう添付書類

#### 消費の方法の変更の場合

「火薬類消費計画書その1＝消費の方法」の従前と変更後をそれぞれ添付すること。

#### 火薬類取扱従事者の変更の場合

1. 従事者に交代があった場合 — 記載欄に「従事者の交代」と記入し新旧の「火薬類消費計画書その2＝火薬類取扱者名簿」をそれぞれ添付。
2. 従事者の追加もしくは削除の場合 — 記載欄に「追加」もしくは「削除」と記入し新の取扱者名簿のみを添付。
3. 取扱者の変更が保安責任者の選解任を伴う変更であれば別途、選解任届を提出。

## 代表者等変更届

火薬類譲受許可証、火薬類消費許可申請証、火薬庫設置等許可申請証の記載事項の変更届に使用する。

変更届を提出できるのは以下の場合：

1. 代表者の変更
2. 事務所所在地の変更
3. 電話番号の変更等

### 留意事項

- 火薬類消費許可申請書又は火薬庫等許可申請書の記載事項変更届の場合は許可になった年月日、許可番号を記入して届出ること。
- 法人の場合、代表者（現場代理人）の変更のときは改めて委任状を添付すること。

## 火薬類取扱所（火工所）設置場所等変更届

以下の場合にこの届出の様式を用いる。

1. 火薬類取扱所の位置、構造を変更する場合
2. 火薬類取扱所の最大存置量を変更する場合
3. 定置構造（建物）の火工所の位置構造を変更する場合

### 記載方法

- 該当する項目の従前、変更後の内容を簡潔に記入。
- 不要な欄は斜線を引いておくこと。
- テント式等の移動する火工所の場合であって位置の変更を予め届出しているときはこの届出は不要。

### 変更手続

あらかじめ届出ること。ただし、天変地異によって早急に復旧しなければならないときはこの限りでない。

### 添付書類

- 取扱所の位置を変更した場合：取扱所付近見取図
- 取扱所の構造を変更した場合：取扱所構造図
- 火工所の位置を変更した場合：火工所付近見取図
- 火工所の構造を変更した場合：火工所構造図

### 変更に伴なうその他の届出

1. 取扱所の存置量の変更で1日の最大消費見込量の変更を伴なう場合、火薬類消費計画書変更届を別途提出すること。
2. 火薬類取扱所を設けなくてよい場合の火工所で定めてある存置量の変更は、取扱所を設けなければならない場合もあるので事前に許可する行政庁の担当者に相談すること。

## 火薬類消費帳簿

兵庫県火薬類施行細則（第20条関係）様式第19号

### 記帳義務

1. 火薬又は爆薬を1箇月に25kg以上消費する消費者は、消費帳簿等を備えなければならない。（法第41条第1項）
2. 記載すべき事項は消費した火薬類の種類及び数量並びに消費の年月日及び場所とすること。（規則第56条の5第1項）
3. 保存期間は記載の日から1年。（規則第56条の5第2項）
4. 記載事項が法定要件に合致しており、かつ必要に応じ直ちにその記載事項が確認できる状態によるものであれば、磁気媒体によるデータ管理方法でも差し支えない。

### 消費帳簿についての留意事項

1. 火薬類取締法第11条の規定により火薬類を貯蔵する場所を所有、又は占有しない消費業者は、1日の消費作業終了後残火薬類が生じた場合、必ずその日のうちに火薬類譲受先販売業者に預け入れること。
2. 残火薬類を火薬類譲受先販売業者に預け入れた場合、必ず預かり証を貰っておくこと。

### 記載例の要点

- 月の最後の発破で残火薬が出た場合は、月計の残量欄に残火薬の数量を記入する。
- 翌月の最初の発破日の記載は、前月最後の発破における残火薬の数量を左肩に小書きし、受入数量は新たに受け入れた数量のみ記載する。
- 預け分を受け入れる場合は、左肩に小さめに記入し、受入数量は新たに受け入れた数量のみ記入する。

## 火薬類消費報告書

兵庫県火薬類施行細則（第21条関係）様式第20号

### 報告義務

1. 年度終了後30日以内に提出すること。
2. 当該年度の消費が0であっても報告すること。
3. 報告すべき消費者 — 火薬又は爆薬1箇月に25kg以上消費する消費者。

### 提出時期

消費者は、4月から翌年3月までの間に消費した火薬類の種類毎の数量を集計したものを翌年4月30日までに県知事（各県民局長）あて報告すること。

| 事例 | 提出時期 |
|---|---|
| 年度中に終了した場合 | 消費終了報告書と同時報告 |
| 年度を越えて消費を終了した場合 | 各年度分をそれぞれ報告 |
| 年度を越えて消費を継続する場合 | 前年度分は翌年度4月30日まで、継続分は消費終了時に報告 |

## 火薬類消費終了報告書

以下に該当する時に提出する。

1. 消費期間が満了したとき
2. 火薬類に関する工事が完了したとき
3. 火薬類に関する工事を中止若しくは廃止したとき

### 記載方法

- 報告書提出の際は必ず許可証をあわせて返納すること。
- 消費終了時に残火薬類の有無にどちらかに○をつける。
- 残火薬類がある場合はその措置の方法を選択：
  1. 譲渡許可を受けて販売店へ譲渡
  2. 廃棄許可を受けて廃棄
  3. 引続き火薬類譲受消費許可を受けた

:::note
- 許可証の有効期間満了前でも、消費が終了したとき若しくは消費を要しなくなった場合は、すみやかに報告すること。
- 消費の許可を受けずに消費している場合（例：コンクリート破砕器を同一の消費地において1日につき150個以下を消費している場合等）もこの様式にて報告すること。
:::

## その他の申請書類

### 火薬類譲受許可申請書（別表第6）

施行規則第35条関係の様式。火薬類を譲渡しようとする場合に使用する。

### 甲種・乙種・丙種 火薬類取扱（製造）保安責任者免状交付申請書（別表第15）

免状の交付申請に使用する様式。

### 甲種・乙種・丙種 火薬類取扱（製造）保安責任者免状再交付申請書（別表第18）

免状を喪失、汚損、盗取された場合の再交付申請に使用する。紛失・盗難等の場合は警察官又は海上保安官に届け出なければならない。申請の際は始末書を必ず添付すること。

### 火薬類取扱（製造）保安責任者免状記載事項変更及び書換申請書

変更及び書換申請を行うことのできるのは、氏名を変更したときに限られる。

書換理由の例：
1. 婚姻による氏の変更
2. 養子縁組による氏の変更
3. 復籍による氏の変更
4. 離籍による氏の変更

### 記載方法

1. 書換の理由を詳細に記入すること。
2. 書換の理由を証明する書類（戸籍抄本等）を必ず添付のこと。
3. 申請の際本免状を必ず添付のこと。

## 事故報告

火薬類による事故が発生した場合、火薬類取締法第46条の規定により兵庫県知事に報告する。

### 報告事項

1. 事故発生日時
2. 事故発生場所
3. 被害の状況
4. 事故発生の原因となった火薬類の種類、数量、およびその状態
5. 状況
6. 原因（含、推定原因）
7. 処理（今後の処置を含む）
8. 参考（例えば病院関係、補償問題および今後の問題等について）

:::note
3及び4の火薬類の状態等については、図面あるいは写真等添付のこと。
:::

## 保安管理の組織

保安管理組織は事業所の規模により若干異なり、企業の実情に即応したものとすべきである。

### (1) 少量消費者（1日に25kg以下の火薬類を消費する場合）

```
作業所長
├─ 消費場所
│   ├─ 取扱保安責任者
│   │   └─ 同上代理
│   └─ 取扱副保安責任者
├─ 火工所
│   ├─ 出納責任者
│   └─ 火工作業員
├─ 運搬員
└─ 発破場所
    ├─ 発破作業指揮者
    ├─ 発破作業記録者
    ├─ 発破技士
    └─ 見張人
```

### (2) 最大消費量（1日に25kgを超える火薬類を消費する場合）

```
作業所長
├─ 消費場所
│   ├─ 取扱保安責任者
│   │   └─ 同上代理
│   └─ 取扱副保安責任者
├─ 火薬類取扱所
│   ├─ 出納責任者
│   └─ 取扱作業員
├─ 運搬員
├─ 火工所
│   ├─ 出納責任者
│   ├─ 火工責任者
│   └─ 火工作業員
└─ 発破場所
    ├─ 発破作業指揮者
    ├─ 発破作業記録者
    ├─ 発破技士
    └─ 運搬員
```

### 帳簿の管理

- **火薬類取扱所** — 火薬類の受払い及び消費残数量をその都度明確に記録
- **火工所** — 火薬類の受払い及び消費残数量をその都度明確に記録
