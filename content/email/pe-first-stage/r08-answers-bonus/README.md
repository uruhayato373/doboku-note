# 技術士一次 令和8年度 解答速報の登録特典（DN-0981）

解答速報ページ `/exam/pe-first-stage/guide/r08-answers` でメール登録した人へ、Brevo の自動応答で渡す特典の原稿。速報ページの本文（公式の確認先・正答・自己採点の説明）は隠さず、ここにある「+α」だけを登録の特典にする（docs/strategy/10_リスト化・自社オーディエンス戦略.md の A. リードマグネット）。

| ファイル | 中身 | 渡し方 |
|---|---|---|
| [self-scoring-sheet.md](./self-scoring-sheet.md) | ①科目別の自己採点シート（合格ラインとの差）と復習シート | 印刷用 PDF にして登録直後のメールに添付（PDF は配布を始めるときに作る） |
| [next-steps.md](./next-steps.md) | ②結果別の次の一手（合格圏・ボーダー・届かない） | 登録直後のメール本文、または同じ PDF の後半 |
| ― | ③合格発表日の通知 | Brevo の配信で送る（日付は日本技術士会の公表後に決める） |
| [emails.md](./emails.md) | 確認メールと特典メールの文面 | Brevo のテンプレートに入れる |

PDF は `node scripts/magazine-to-pdf.mjs --spec "scripts/pdf-specs/技術士一次-R8速報-登録特典.json"` で作る（出力 `.tmp/pe1-r08-bonus-pdf/`）。配る PDF は Drive vault の `制作物/` に置き、リンクを知っている人が見られる共有にして特典メールに貼る（公開 R2 に置かない・asset-storage-policy.md）。

## 根拠にした事実（2026-11-09 確認）

- 合否決定基準: 基礎・適性・専門の各科目で 50% 以上の得点（文部科学省「技術士試験合否決定基準」令和8年1月19日、日本技術士会 011588 の添付 PDF）
- 解答数: 基礎 30 問中 15 問（5 群×各 3 問）、適性 15 問、専門 35 問中 25 問（サイトの速報ページ・概要ページと同じ）
- 正答の公表予定 11/24、合格発表は令和9年2月に官報掲載（受験申込み案内・実施案内。速報ページと同じ）
- 合格ラインの問題数は「1 問 1 点で数えた目安」として書いた（基礎・適性 8 問、専門 13 問）。配点が問題ごとに違うとは公表されていないが、断定はしない

## 守ること

- 価格を書かない。商品は note のページへ送る（価格の正本は config/products.json）
- 公式の正答・正答訂正が出たら、それだけを採点の根拠にするよう書く。非公式の速報を勧めない
- 合否を言い切らない（目安・見込みの表現にとどめる）
- リンクには `utm_source=brevo&utm_medium=email&utm_campaign=pe1-r08-bonus` を付ける
