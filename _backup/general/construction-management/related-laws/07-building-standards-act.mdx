## 7 建築基準法

### 7.1 基本的事項

建築基準法は、建築物の敷地、構造、設備および用途に関する**最低の基準**を定めて、公共の福祉の増進に寄与することを目的としている。（法第1条）

建築基準法に関連する用語の定義は、表7.17のとおりである。

#### 表7.17 建築基準法に関連する用語の定義（法第2条）

| 用語 | 定義（意味） | 注意事項 |
|---|---|---|
| 建築物 | 土地に定着する工作物のうち、(1)屋根および柱を有するもの、(2)屋根および壁を有するもの、(3)(1)および(2)に附属する門もしくは塀、(4)観覧のための工作物、(5)地下の工作物内に設けられた事務所、店舗等、(6)高架の工作物内に設けられた事務所、店舗、倉庫、興行場等、(7)建築物内等に設置された建築設備 | 鉄道および軌道の線路敷地内の運転保安に関する施設、プラットホームの上家、貯蔵槽は、建築物から除外されている。 |
| 特殊建築物 | 学校、体育館、病院、劇場、観覧場、集会場、展示場、百貨店、市場、公衆浴場、旅館、共同住宅、寄宿舎、工場、車庫、倉庫、汚物処理場等 | — |
| 建築設備 | 建築物に設ける電気、ガス、給水、排水、換気、冷暖房、消火、排煙、汚物処理場の設備または煙突、エレベーター、避雷針 | 浄化槽は、建築設備である。 |
| 居室 | 居住、執務、作業、集会、娯楽その他これらに類する目的のために継続的に使用する部屋 | 更衣室は、居室ではない。 |
| 主要構造部 | 壁、柱、床、はり、屋根または階段。ただし、構造上重要でない間仕切壁、間柱、最下階の床、ひさし等は除く | 最下階の床等は、主要構造部ではない。 |
| 建築 | 建築物を新築し、増築し、改築しまたは移転すること | — |
| 設計図書 | 建築物、その敷地または工作物に関する工事用の図面（現寸図その他これに類するものを除く。）および仕様書をいう | — |
| 建築主 | 建築物に関する工事の請負契約の注文者または請負契約によらないで自らその工事をする者をいう | — |
| 設計者 | その者の責任において、設計図書を作成した者をいう | — |
| 工事施工者 | 建築物、その敷地もしくは工作物に関する工事の請負人または請負契約によらないで自らこれらの工事をする者をいう | — |
| 特定行政庁 | 建築主事を置く市町村の区域については当該市町村の長、その他の市町村の区域については都道府県知事をいう | — |

### 7.2 建築確認・完了検査

#### (1) 建築確認（法第6条、第6条の2）

建築の計画が建築基準法令（政令や条例を含む）の規定に適合しているかどうかを、建築の**着工前**に、都道府県もしくは市町村の**建築主事**または**指定確認検査機関**の確認を受けなければならない。

建築主事は、建築確認を行うために都道府県と特定の市町村に置かれる機関で、建築基準適合判定資格者の登録を受けた者の中から、都道府県知事または市町村長が任命する。

指定確認検査機関は、国土交通大臣または都道府県知事に指定され、建築確認検査の業務を行うことができる。

#### (2) 建築物の完了検査（法第7条、第7条の2）

建築主は、建築確認を受けなければならない建築物の工事を完了させたときには、その旨を工事完了の日から**4日以内**に建築主事または指定確認検査機関に到着するよう申請して、当該敷地、構造および建築設備に関する法令等に適合しているかどうかの、建築主事または指定確認検査機関の検査を受けなければならない。

### 7.3 単体規定

**単体規定**は、建築物および敷地の安全性、防火および避難、衛生などに関する基準を定めたもので、**全国の建築物に適用**される規定である。

#### (1) 敷地の衛生および安全（法第19条）

1. 建築物の敷地は、当該敷地に接する道路の境より高くなければならない。また、建築物の地盤面は、これに接する周囲の土地より高くなければならない。ただし、敷地内の排水に支障のない場合等はこの限りではない。
2. 次の土地に建築物を建築する場合は、盛土、地盤の改良、その他衛生上または安全上必要な措置を講じなければならない。
    - 湿潤な土地
    - 出水のおそれの多い土地
    - ごみ等により埋め立てられた土地
3. 建築物の敷地には、雨水および汚水を排水・処理するための下水管（溝）またはためます等を設置しなければならない。

#### (2) 構造耐力（法第20条第1項）

建築物の構造耐力については、自重、積載荷重、風圧、土圧、水圧、地震その他の振動および衝撃に対して**安全な構造**でなければならない。

#### (3) 居室の採光および換気（法第28条）

1. 住宅、学校、病院、診療所、寄宿舎、下宿その他これらに類する建築物の居室（事務室を含む）には、採光のための窓その他の開口部を設けなければならない。その採光に有効な部分の面積は、その居室の床面積に対して、住宅にあっては**1/7以上**、その他の建築物にあっては**1/5〜1/10**の間において政令で定める割合以上としなければならない。ただし、地階もしくは地下工作物内に設ける居室その他これらに類する居室または温湿度調整を必要とする作業を行う作業室その他用途上やむを得ない居室については、この限りでない。（法第28条第1項）
2. 居室（事務室を含む）には換気のための窓その他の開口部を設け、その換気に有効な部分の面積は、その居室の床面積に対して**1/20以上**としなければならない。ただし、政令で定める技術的基準にしたがって次の換気設備を設けた場合においては、この限りでない。（法第28条第2項、令第20条の2）
    - 自然換気設備
    - 機械換気設備
    - 中央管理方式の空気調和設備

#### (4) 地階における住宅等の居室（法第29条）

住宅の居室、学校の教室、病院の病室または寄宿舎の寝室で地階に設けるものは、壁および床の防湿の措置その他の事項について、衛生上必要な技術的基準に適合するものとしなければならない。

#### (5) 電気設備（法第32条）

建築物の電気設備は、法令等に定める安全および防火に関する工法によって設けなければならない。

#### (6) 避雷設備（法第33条）

高さ**20m**をこえる建築物には、有効に避雷設備を設けなければならない。ただし、周囲の状況によって安全上支障がない場合においては、この限りではない。

#### (7) 居室の床の高さおよび防湿方法（令第22条）

最下階の居室の床が木造である場合における床の高さおよび防湿方法は、次のとおりとしなければならない。

1. 床の高さは、直下の地面からその床の上面まで**45cm以上**とすること
2. 外壁の床下部分には、壁の長さ**5m以下**ごとに、面積**300cm&sup2;以上**の換気孔を設け、これにねずみの侵入を防ぐための設備を設けること

ただし、床下をコンクリート、たたきその他これらに類する材料で覆う場合および当該最下階の居室の床の構造が、地面から発生する水蒸気によって腐食しないものとして、国土交通大臣の認定を受けたものである場合においては、この限りでない。

### 7.4 集団規定

**集団規定**は、市街地における建築のルールを定めたもので、都市計画法に定める**都市計画区域および準都市計画区域内**の建築物または建築物の敷地に限って適用される規定である。（法第41条の2）

#### (1) 接道義務（法第43条第1項）

建築物の敷地と道路との関係は、防災上重要な事項となっており、建築基準法において道路とは幅員**4m**（都道府県都市計画審議会の議を経て指定する区域内においては6m）以上のものをいうと規定されている。なお当該建物の敷地は、道路に**2m以上**接することを義務づけている。

#### (2) 用途地域（法第48条）

都市計画において定められる**用途地域**は（表7.18）、それぞれの地域の役割を決めて、その区域の環境を決めるものである。

都市計画における用途地域の目的を達成するため、建築基準法においては、それぞれの用途地域内に建築物の用途を定めており、これを**用途規制**と呼んでいる。

#### 表7.18 用途地域一覧表

| 用途地域 | 用途地域 |
|---|---|
| 第1種低層住居専用地域 | 準住居地域 |
| 第2種低層住居専用地域 | 近隣商業地域 |
| 第1種中高層住居専用地域 | 商業地域 |
| 第2種中高層住居専用地域 | 準工業地域 |
| 第1種住居地域 | 工業地域 |
| 第2種住居地域 | 工業専用地域 |

#### (3) 容積率（法第52条）

**容積率**とは、建築物の延べ面積（同一敷地内に2以上の建築物がある場合には、その延べ面積の合計）の敷地面積に対する割合をいい、用途地域ごとに定められる。

#### (4) 建ぺい率（法第53条）

**建ぺい率**とは、建築面積（建物の水平投影面積）の敷地面積に対する割合をいい、用途地域ごとに定められる。

#### (5) 防火地域、準防火地域の建築物の屋根（法第62条）

防火地域および準防火地域の建築物の屋根は、火の粉による火災の発生を防止するために必要とされる技術的基準に適合したものとしなければならない。

#### (6) 建築物の敷地が区域、地域または地区の内外にわたる場合の措置（法第91条）

建築物の敷地が区域、地域または地区の内外にわたる場合には、その建築物または敷地の全部について、敷地の**過半が属する**区域、地域または地区内の建築物に関するこの法律の規定を適用する。

### 7.5 現場事務所等の仮設建築物に対する規制緩和

非常災害が発生したときに、緊急に設置する応急仮設建築物（即刻復旧すべきものであるため）または建設工事現場に設ける**現場事務所、下小屋、材料置場**などの仮設建築物（工事期間中しか使用されない、使用期間が短いため）については、建築基準法の**適用除外または適用の緩和措置**が講じられている。仮設建築物に対する建築基準法の主な適用・不適用については、表7.19のとおりである。（法第85条）

仮設建築物は、(1)建築確認・完了検査等の手続きが不要であり、(2)単体規定には適用される規定と適用されない規定がある。(3)集団規定は適用されないが、唯一、防火地域または準防火地域にある延べ面積**50m&sup2;をこえる**仮設建築物の屋根の構造に限り、集団規定の適用を受ける。

#### 表7.19 現場事務所等の仮設建築物に対する建築基準法の主な適用・不適用一覧

| 区分 | 条文 | 内容 |
|---|---|---|
| **適用されない主な規定** | 手続き | 建築確認申請手続き、建築工事の完了検査、建築物を建築または除却する場合の届出 |
|  | 単体規定 | 建築物の敷地の衛生および安全に関する規定、高さ20mを超える建築物への避雷設備の設置、居室の床の高さおよび防湿方法の規定 |
|  | 集団規定 | 建築物の敷地は道路に2m以上接すること（接道義務）、用途地域ごとの制限、延べ面積の敷地面積に対する割合（容積率）、建築面積の敷地面積に対する割合（建ぺい率）、第1種低層住居専用地域等の建築物の高さの制限、防火地域内・準防火地域内の建築物の耐火性、防火地域または準防火地域内の屋根の構造（50m&sup2;以内） |
| **適用される主な規定** | 資格 | 建築士による一定規模以上の建築物の設計および工事監理 |
|  | 単体規定 | 建築物は、自重、積載荷重、積雪、風圧、地震等に対して安全な構造とする（構造耐力）。居室（事務室を含む）への採光および換気のための窓の設置。地階における住宅等の居室の防湿措置。電気設備の安全および防火工法。 |
|  | 集団規定 | 防火地域または準防火地域内の屋根の構造（50m&sup2;をこえる場合に限る）は、次のいずれかとする。(1)不燃材料で造るかまたはふく、(2)耐火構造の屋根（屋外に面する部分を準不燃材料で造ったもので、屋根勾配が30°以内のもの）の屋外面に断熱材および防水材を張ったもの、(3)準耐火構造の屋根（屋外に面する部分を準不燃材料で造ったもの） |
