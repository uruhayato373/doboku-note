# リサイクル法（資源の有効な利用の促進に関する法律）

## 法の目的（法第1条）

1. 資源の有効な利用の確保を図る。
2. 使用済物品等および副産物の発生を抑制する。
3. 再生資源および再生部品の利用の促進に関する所用の措置を講ずる。

## 用語の定義（法第2条）

### 建設工事における副産物

土木建築に関する工事（建設工事）に伴い副次的に得られた物品をいう。

### 再生資源

現場に受け入れるもので、下記の3種類（令第2条、別表第2）

使用済物品等または副産物のうち有用なものであって、原材料として利用できるものまたはその可能性のある資源をいう。

- イ 土砂（建設発生土）
- ロ コンクリートの塊
- ハ アスファルト・コンクリートの塊

※なお、国土交通省のリサイクルホームページでは、（ ）内の名称を用いている。

### 特定再利用業種（令第2条、別表第2）

再生資源または再生部品を利用することが技術的および経済的に可能であり、かつ、再生資源等の有効な利用を図る上で特に必要なものとして政令で定められた再生資源または再生部品ごとに政令で定められた業種をいう。

建設業は、上記イ〜ハの3つの再生資源に対する特定再利用業種として指定されている。

### 指定副産物

現場から排出されるもので、下記の4種類（令第7条、別表第7）

建設工事に係る副産物で、その全部または一部を再生資源として利用を促進することが再生資源の有効な利用を図る上で特に必要なものとして、業種ごとに政令で定めるものをいう。

建設業では、下記の4種類が指定副産物に定められている。

- イ 土砂（建設発生土）
- ロ コンクリートの塊
- ハ アスファルト・コンクリートの塊
- ニ 木材（建設発生木材）

※なお、国土交通省のリサイクルホームページでは、（ ）内の名称を用いている。

### 指定副産物事業者（法第34条、令第22条、別表第7）

事業場において、指定副産物に係る業種に属する事業を行う者をいう。建設業においては、年度の施工金額が50億円以上の業者をいう。

## 特定再利用事業者（建設工事事業者）の行うべき事項

（法第15条、建設業に属する事業を行う者の再生資源の利用に関する判断の基準となるべき事項を定める省令第3条〜第9条）

### 再生資源の利用

再生資源を建設資材として用いることにより、**再生資源を利用する**こと。

### 建設発生土の利用

**建設発生土**については、表6.6の区分に従って利用すること。

| 区分 | 説明 | 利用用途 |
|---|---|---|
| 第1種建設発生土 | 砂、礫およびこれらに準ずるものをいう。 | 工作物の埋戻し材料、土木構造物の裏込材、道路盛土材料、宅地造成用材料 |
| 第2種建設発生土 | 砂質土、礫質土およびこれらに準ずるものをいう。 | 土木構造物の裏込材、道路盛土材料、河川築堤材料、宅地造成用材料 |
| 第3種建設発生土 | 通常の施工性が確保される粘性土およびこれに準ずるものをいう。 | 土木構造物の裏込材、道路路体用盛土材料、河川築堤材料、宅地造成用材料、水面埋立て用材料 |
| 第4種建設発生土 | 粘性土およびこれに準ずるもの（第3種建設発生土を除く）をいう。 | 水面埋立て用材料 |

### コンクリート塊の利用

**コンクリートの塊**については、表6.7の区分に従って利用すること。

| 区分 | 主な利用用途 |
|---|---|
| 再生クラッシャーラン | 道路舗装およびその他舗装の下層路盤材料、土木構造物の裏込材および基礎材、建築物の基礎材 |
| 再生コンクリート砂 | 工作物の埋戻し材料および基礎材 |
| 再生粒度調整砕石 | その他舗装の上層路盤材料 |
| 再生セメント安定処理路盤材料 | 道路舗装およびその他舗装の路盤材料 |
| 再生石灰安定処理路盤材料 | 道路舗装およびその他舗装の路盤材料 |

（注）1）「その他舗装」とは、駐車場の舗装および建築物等の敷地内の舗装をいう。
2）道路舗装に利用する場合においては、再生骨材等の強度、耐久性等の品質を特に確認のうえ利用するものとする。

### アスファルト・コンクリート塊の利用

**アスファルト・コンクリートの塊**については、表6.8の区分に従って利用すること。

| 区分 | 主な利用用途 |
|---|---|
| 再生クラッシャーラン | 道路舗装およびその他舗装の下層路盤材料、土木構造物の裏込材および基礎材、建築物の基礎材 |
| 再生粒度調整砕石 | その他舗装の上層路盤材料 |
| 再生セメント安定処理路盤材料 | 道路舗装およびその他舗装路盤材料 |
| 再生石灰安定処理路盤材料 | 道路舗装およびその他舗装路盤材料 |
| 再生加熱アスファルト安定処理混合物 | 道路舗装およびその他舗装上層路盤材料 |
| 表層基層用再生加熱アスファルト混合物 | 道路舗装およびその他舗装基層用材料および表層用材料 |

（注）1）「その他舗装」とは、駐車場の舗装および建築物等の敷地内の舗装をいう。
2）道路舗装に利用する場合においては、再生骨材等の強度、耐久性等の品質を特に確認のうえ利用するものとする。

### 再生資源の発生した工事現場での利用

建設工事事業者は、再生資源の工事現場内利用に努めること。

### 再生資源利用計画の作成および管理体制の整備

- イ 発注者から直接工事を請け負った建設工事事業者（元請業者）は、表6.9に該当する建設工事を施工する場合、あらかじめ再生資源利用計画を作成すること。
- ロ 建設工事事業者は、工事完成後速やかに、再生資源利用計画の実施状況を記録すること。
- ハ 建設工事事業者は、再生資源利用計画と実施状況の記録を、工事完成後1年間保存すること。
- ニ 建設工事事業者は、再生資源利用計画の作成等再生資源の利用に関することを適切に行うため、工事現場に責任者を置くなど、管理体制の整備を行うこと。

**再生資源利用計画の該当工事等**

| 計画を作成する工事 | 定める内容 |
|---|---|
| 次のいずれかに該当する建設資材を搬入する建設工事：1. 土砂 …… 1,000m&sup3;以上 / 2. 砕石 …… 500t以上 / 3. 加熱アスファルト混合物 … 200t以上 | 1. 建設資材ごとの利用量 / 2. 利用量のうち再生資源ごとの利用量 / 3. その他再生資源の利用に関する事項 |

## 指定副産物事業者の行うべき事項

（建設業に属する事業を行う者の指定副産物に係る再生資源の利用の促進に関する判断の基準となるべき事項を定める省令第3条〜第8条）

### 指定副産物に係る再生資源の利用の促進

建設工事事業者は、再資源化施設の活用を図ることなどにより、指定副産物に係る再生資源の利用を促進すること。

### 建設発生土の利用の促進

1. 工事現場から搬出する場合、利用または搬出に関する情報の収集、提供を行うことにより、他の建設工事での利用を促進すること。
2. このため、発生土の性質の区分に努めるとともに、必要に応じ、保管場所の確保に努めること。

### 再資源化施設への搬入

コンクリート塊、アスファルト・コンクリート塊および建設発生木材の利用促進再資源化施設の受入条件などを勘案し、分別ならびに破砕または切断を行った上で、再資源化施設に搬入すること。

### 再生資源利用促進計画の作成および管理体制の整備

- イ 発注者から直接建設工事を受注した建設工事事業者（元請業者）は、表6.10に該当する建設工事を施工する場合、再生資源利用促進計画を作成しなければならない。
- ロ 建設工事事業者は、工事完成後速やかに、再生資源利用促進計画の実施状況を記録すること。
- ハ 建設工事事業者は、再生資源利用促進計画の実施状況の記録を、工事完成後1年間保存すること。
- ニ 建設工事事業者は、再生資源利用促進計画の作成等再生資源の利用の促進に関する事務を適切に行うため、工事現場に責任者を置くなど、管理体制の整備を行うこと。

**再生資源利用促進計画の該当工事等**

| 計画を作成する工事 | 定める内容 |
|---|---|
| 次のいずれかに該当する指定副産物を搬出する建設工事：1. 建設発生土 …… 1,000m&sup3;以上 / 2. コンクリート塊・アスファルト・コンクリート塊・建設発生木材 … 合計200t以上 | 1. 指定副産物の種類ごとの搬出量 / 2. 指定副産物の種類ごとの再資源化施設または他の建設工事現場などへの搬出量 / 3. その他指定副産物に係る再生資源の利用の促進に関する事項 |
