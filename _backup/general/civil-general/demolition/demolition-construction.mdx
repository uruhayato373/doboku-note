# 解体工事の施工

## 2.1 一般的な流れ

解体工事の一般的な施工の流れは、建設工事に係る資材の再資源化等に関する法律（建設リサイクル法）の規定を基本とし、概略は次のとおりである。

### (1) 事前調査

事前調査は、施工計画を策定する前提となる。事前調査の主な項目および内容等は表6.1のとおりである。

| 項目 | 内容 | 注意点 |
|---|---|---|
| 土木構造物 | 構造・規模 | 合成構造等 |
| 敷地 | 形状・面積・高低差等 | |
| | 工事障害物等 | |
| | 地下埋設物等 | |
| | 地下水位等 | 河川、海岸等 |
| 道路 | 搬入・搬出路等 | 幅員、舗装、経路等 |
| | 交通量・交通規制等 | 一方通行、橋梁の重量制限、トンネル、陸橋等 |
| 近隣 | 隣接する構造物等 | 現状、損傷度合等 |
| | 近隣住民等 | 生活状況等 |
| 関係機関 | 行政施設 | 行政機関、警察署、消防署、監督署等 |
| | 病院、学校等 | 救急病院等 |
| 廃棄物 | 種類・量 | 特定建設資材等 |
| | 処理施設 | 中間処理施設、最終処理施設等 |

### (2) 施工計画

施工計画の種類および内容等は、表6.2のとおりである。

| 施工計画の種類 | 内容 | 備考 |
|---|---|---|
| 準備作業計画 | 各種届出、近隣対策、障害物処理、残存物品処理等 | 人員確保等 |
| 仮設計画 | 仮囲い、足場、廃棄物飛散防止等 | 壁繋ぎ、外壁との離隔距離等 |
| 解体作業計画 | 工法・機械選定、作業手順、分解計画等 | 機材・人員配置等 |
| 工程計画 | 工程表作成等 | バーチャート工程表 |
| 安全衛生管理計画 | 公衆・労働災害防止等 | 墜落・機械・崩壊災害等 |
| 環境保全計画 | 騒音・振動・粉じん対策等 | |
| 廃棄物処理計画 | 再資源化、適正処理等 | 委託契約、マニフェスト等 |
| 終結作業計画 | 整地、原状回復等 | 発注者との協議 |

### (3) 事前措置

解体作業を順調に進めるためには、解体作業前に適切な事前措置を行うことが必要である。事前措置の主な項目および内容等は、表6.3のとおりである。

| 項目 | 措置内容 | 備考 |
|---|---|---|
| 作業場所の確保 | 道路の使用・占用許可、解体用重機の設置場所、運搬車両の待機場所等 | 分解解体 |
| 搬出経路の確保 | 障害物の除去、歩道の切り下げ、交通誘導員の配置等 | 廃棄物等の搬出 |
| その他 | 近隣に対する広報（説明会、チラシ配布等）、法令既定の届出等 | |

### (4) 解体作業

#### 1) 仮設・養生

解体工事に使用する仮囲いや足場等の仮設は、建設工事の場合とほぼ同様である。

##### ① 足場（外部足場）

枠組足場や単管足場などを使用する。小規模構造物等の解体においては丸太足場を使用する場合もある。手すり先行足場も普及しつつある。壁つなぎは、新設工事の場合に比べ間隔を密にする。防音パネルを使用する場合は、悪天候によりパネルが飛散したり足場そのものが倒壊したりする事故が少なくないため、特に注意が必要である。外壁との間隔は、使用する圧砕機等の解体用機械に応じて、新設工事の場合よりも広くするのが一般的である。

##### ② 防音パネル・シート

騒音防止や粉じん飛散防止を目的に、防音パネルまたは防音シートを使用する。さらに、防音パネルの飛散防止のため防音パネルの上からネット養生を行うこともある。ちなみに、振動防止のための効果的な養生はあまりない。防振溝を設ける方法はあるが、施工例は少ない。

##### ③ 散水設備

解体作業中の粉じん飛散防止には、散水が効果的である。散水作業には、高水圧を得るための散水機、計画的な配管および散水作業員が必要である。なお、多量に散水する場合は、排水処理が必要な場合もある。

##### ④ 照明設備

解体作業中の構造物等の内部は、防音パネル等で遮光されているため、照度が不足する場合が多い。既設の照明設備が使用できない場合は、仮設の照明設備が必要である。

##### ⑤ 換気設備

構造物等内部の解体作業においては、粉じんの外部への飛散は防げる反面、作業員が粉じんにばく露するおそれがある。作業員には適切な呼吸用保護具を使用させ、場合によっては集じん機能を有する換気設備が必要である。

#### 2) 橋脚等の土木構造物の解体

橋脚等の土木構造物の解体作業は、鉄筋コンクリート造、鉄骨造等の構造により異なる。

##### ① 鉄筋コンクリート造構造物等の解体

機械作業工法および、機械作業工法と手作業工法の併用工法がある。機械作業工法は、大型ブレーカや圧砕機等を使用して解体する工法である。地上部の解体は圧砕機を中心に行い、基礎部等の大断面部材はブレーカを併用するのが一般的である。手作業工法は、大ハンマやハンドブレーカを使用して解体する工法である。小規模構造物の場合や解体用機械が搬入できない場合に採用する。さらに、補助的にカッタ工法、ワイヤソーイング工法、コアドリル工法等を併用することもある。柱、壁等の解体は転倒工法が効果的である。一般的には、5〜6階建てまでは地上解体、それ以上10〜12階建てまでは階上解体、さらにそれ以上の場合はタワークレーン等を用いたブロック解体が適している。

##### ② 鉄骨造構造物等の解体

機械作業工法および、機械作業工法と手作業工法の併用工法がある。機械作業工法は、鉄骨切断機を使用して部材を切断しながら解体する工法である。手作業工法は、ガス溶接器を使用して部材を溶断しながら解体する工法である。部材が高所から落下するおそれがある場合には、移動式クレーン等で仮吊りして作業する必要がある。機械作業工法と手作業工法の併用工法は、手作業の丁寧さと機械作業の効率性を兼ね備えており、通常はこの方法で解体する。

##### ③ 鉄骨鉄筋コンクリート造構造物等の解体

鉄筋コンクリート造および鉄骨造の解体工法を組み合わせる。両方の作業主任者を選任（兼任も可能）して配置する。

#### 3) 基礎・基礎杭の解体

基礎の解体工法は、地上部と基本的には同様である。部材断面が大きい場合は、ブレーカ、カッタ、ワイヤソーイング、コアドリル工法を使用し、条件がよければ微小爆破工法などによるブロック割りも併用する。山留を設置する場合には、解体施工中の地山の崩壊等に注意が必要である。

基礎杭は、地上部の解体と同時に撤去するか、または地上部の解体後に時間をおいて基礎杭のみを撤去する。残置する場合は、廃棄物の処理及び清掃に関する法律（廃棄物処理法）の規制等に留意する必要がある。

撤去方法には、杭抜用機械等を使用して引き抜く方法とオーガボーリング等で破砕し破砕物を回収する方法がある。なお、撤去した後は、良質土や土砂で埋戻しを行う。

#### 4) 整地

解体工事が完了した後は、跡地を整地する。土砂に廃棄物が混入した場合は総体として廃棄物になるので、廃棄物の残渣は徹底的に取り除く必要がある。なお、必要な場合は客土を行うこと。

## 2.2 構造物解体（取壊し）工法における必要な措置

代表的な構造物取壊し工法における施工上必要な措置については、「土木工事安全施工技術指針」等に、次のように示されている。

### (1) 圧砕工法、大型ブレーカ等

- ① 重機作業半径内への立入禁止措置を講ずること。
- ② 重機足元の安定を確認すること。
- ③ 騒音、振動、防塵に対する周辺への影響に配慮すること。
- ④ ブレーカの運転は、有資格者によるものとし、責任者から指示されたもの以外は運転しないこと。

### (2) 転倒工法

- ① 小規模スパン割のもとで施工すること。
- ② 自立安定および施工制御のため、引ワイヤ等を設置すること。
- ③ 計画に合った足元縁切りを行うこと。
- ④ 作業前に一定の合図を定め、周知徹底を図ること。
- ⑤ 転倒作業は必ず一連の連続作業で実施し、その日中に終了させ、縁切りした状態で放置しないこと。

### (3) カッタ工法

- ① 回転部の養生および冷却水の確保を行うこと。
- ② 切断部材が比較的大きくなり、クレーン等による仮吊り、搬出が必要となるため、クレーン作業に関する留意事項を確実に遵守すること。

### (4) ワイヤソーイング工法

- ① ワイヤソーにゆるみが生じないよう必要な張力を保持すること。
- ② ワイヤソーの損耗に注意を払うこと。
- ③ 防護カバーを確実に設置すること。

### (5) ウォータージェット工法

- ① 高圧水が噴射するノズルから半径5 m以内には、作業員以外立ち入れない措置をとること。
- ② コンクリート片等の飛散に備えて、防護ネットを設置すること。
- ③ 防護カバーを使用し、低騒音化を図ること。
- ④ スラリーを処理すること。

### (6) 静的破砕剤工法

- ① 削孔長は決められた長さ以内で使用すること。また、削孔径は上限を超えて使用しないこと。
- ② 練混ぜ水は清浄な水を使用し、水の温度は適用温度範囲の上限を超えて使用しないこと。
- ③ 破砕剤充填後は、充填孔からの噴出に留意すること。また、充填後は防護シートを被せ亀裂発生まで養生し、二次破砕は亀裂の発生後に行うこと。
- ④ 膨張圧発現時間は気温と関係があるため、適切な破砕剤を使用すること。
- ⑤ 水中（海中）で使用する場合は、材料の流出・噴出に対する安定性、充填方法および水中環境への影響に十分配慮すること。

## 2.3 構造物解体（取壊し）作業における安全確認事項

「建設機械施工安全マニュアル」における、代表的な構造物取壊し作業の安全確認事項については、表6.4、表6.5、表6.6のとおりである。

### 表6.4 圧砕機・大型ブレーカによる取壊し作業時の安全確認事項

| 作業工種 | 作業手順 | 安全確認事項 |
|---|---|---|
| 圧砕機・大型ブレーカによる取壊し | エンジンを始動 | エンジン始動の際、警告のためホーンを鳴らす。 |
| | 構造物を大きく解体 | 誘導員を配置し、関係者以外立入禁止措置をする。粉塵防止、常時散水を実施する。倒壊範囲の予測、作業員・重機は安全作業位置へ設置する。解体片は適宜整理し、崩壊防止に努める。休止・終了時は、解体物の安定（転倒防止、浮き片除去）を確保する。キャブ前面に防護装置を装備する。散水栓、ホース取回しを確認する。重機に近接して作業する場合、重機を停止する。重機との接触等防止するため、誘導員を配置する。作業再開前、解体物の安定（転倒、剥落はないか）を確認する。折ったコンクリート塊の上を安易に歩かない。 |
| | アタッチメントの交換、機械点検 | 点検中はアタッチメントの着地、安全レバーロック、エンジン停止する。 |
| | 解体片を小割作業 | 積込み能力に余裕を持たした大きさに小割りする。小割り解体片の崩壊を防止する。落差の大きい施工場所では破壊解体片の落下に伴う破砕飛散に対する防護を行う。 |
| | 解体片の積込み | 運転者と手順、作業量、積載能力、作業合図等を確認する。過積載にならないよう、積載量を確認する。積込み解体片の安定を確認する。 |

### 表6.5 カッタによる取壊し作業時の安全確認事項

| 作業工種 | 作業手順 | 安全確認事項 |
|---|---|---|
| カッタによる取壊し | (1)カッタ取付け・カッタを躯体に取付け | 安全帯及び防護メガネを使用する。撤去側躯体ブロックへのカッタ取付けを禁止する。アンカー設置時は、ジャンカ、空洞等を確認する。ブレード、防護カバーを確実に設置、特にブレード固定用ナットは十分に締め付ける。ギアボックス、モーター設置時の合図を確認する。電源ケーブルの取回し経路、保護を確認する。 |
| | 外れ止めアンカーを設置 | 躯体に外れ止め取付け用アンカーを事前に配置する。切断面付近にはシートを設置し、冷却水の飛散防止を図る。 |
| | (2)切断作業・試運転を行う・切断を開始・ブレードを交換 | 切断中は監視員を配置し、関係者以外の立入禁止措置をする。切断の進行に合せ適宜、切断面へのキャンバー打込み、ずれ止め設置を行う。ブレードの正常作動を確認する。ブレード周辺から作業員を避難させ、安全確認後実施する。 |
| | (3)小割作業 | 積込み能力に余裕を持たした大きさに小割りする。小割り解体片の崩壊を防止する。落差の大きい施工箇所では、破壊解体片の落下に伴う破砕、飛散に対する防護を行う。粉塵対策を行う。 |
| | (4)積込み作業 | 運転者と手順、作業量、積載能力、作業合図などを確認する。過積載にならないよう、積載量を確認する。積込み解体片の安定を確認する。 |
| | (5)片付け作業・カッタを取外す | カッタの片付けは電源OFF を確認後とし、他者が不用意に電源を入れないよう明示する。 |

### 表6.6 ワイヤソーイングによる取壊し作業時の安全確認事項

| 作業工種 | 作業手順 | 安全確認事項 |
|---|---|---|
| ワイヤソーイングによる取壊し | (1)ワイヤソーイング設置・ガイドプーリの設置 | アンカー設置時は、ジャンカ、空洞等を確認する。本体の設置カバー、回転方向の防護フェンス、ネット等を設置する。切断面角付近は、冷却水の飛散があるのでシート等を設置して飛散防止の養生をする。高所作業の際は安全帯を使用する。ワイヤの状態検査実施と確実に設置する。機械停止の確認、設置作業中を明示する。ワイヤとプーリの間に指を挟まぬよう注意する。スリーブ圧着が確実であるかを目視確認する。ワイヤに緩みが生じないよう、2、3人で引いてまわせる程度までワイヤを張る。躯体に外れ止め取付け用アンカーを事前配置する。電源ケーブルの取回し経路、保護を確認する。 |
| | (2)切断作業・試運転の実施・切断を行う・ワイヤを点検、交換 | 切断中は監視員を配置し、関係者以外立入禁止とする。切断の進行に合わせ、適宜切断面へのキャンバー打込み、ずれ止めを設置する。点検の際は特に接続スリーブの断面減少に注意する。試運転を行い、ワイヤソーイングマシン、プーリ、ワイヤの正常作動を確認する。破断防止のため早めの点検、交換を実施する。交換は電源OFFを確認、交換作業中を明示する。 |
| | (3)小割作業 | 積込み能力に余裕を持たした大きさに小割りする。小割り解体片の崩壊を防止する。落差の大きい施工場所では、破壊解体片の落下に伴う破砕、飛散に対する防護を行う。 |
| | (4)積込み作業 | 運転者と手順、作業量、積載能力、作業合図等を確認する。過積載にならないよう、積載量を確認する。解体片の安定を確認する。 |
| | (5)片付け作業・ワイヤ、機械等の片付け | 片付けは電源OFFを確認後とし、片付け作業中を明示する。 |
