# 基礎工の概説

## 1.1 基礎工の分類と定義

基礎とは、下部構造の一部で、躯体からの荷重を地盤に伝える構造部分をいう。下部構造は、上部構造からの荷重を直接受ける橋脚・橋台などの躯体と、荷重を地盤に伝達する基礎から構成される。基礎は、一般に、コンクリート構造または鋼構造であり、木造のものは現在ほとんど見られない。

基礎工は、直接基礎、杭基礎（既製杭・場所打ち杭）、ケーソン基礎（オープンケーソン・ニューマチックケーソン）、その他の特殊基礎（鋼管矢板基礎・多柱式基礎・地中連続壁基礎など）に大別できる。

{/* 図4.1 基礎工の分類 */}

- **浅い基礎**
  - 直接基礎
    - 原地盤をそのまま利用するもの
    - 地盤改良を行うもの（地盤改良、安定処理、軟弱地盤工法）
- **深い基礎**
  - 杭基礎
    - 既製杭基礎（木杭、RC杭、PHC杭、SC杭、鋼杭）
    - 場所打ち杭基礎
      - 人力・機械掘削（深礎）
      - 機械掘削（オールケーシング、リバース、アースドリル）
  - ケーソン基礎
    - オープンケーソン
    - ニューマチックケーソン
    - 設置ケーソン
  - 特殊基礎（鋼管矢板基礎、多柱式基礎、地中連続壁基礎など）

{/* 図4.2 基礎の種類 */}

## 1.2 各種基礎形式と特徴

### (1) 直接基礎

直接基礎は、浅い基礎に分類され、良質な支持層が地表から5m程度の比較的浅い箇所に出現する場合に採用される。鉛直荷重は直接基礎底面の鉛直地盤反力のみで抵抗させ、水平荷重は直接基礎底面のせん断地盤反力のみで抵抗させることが多い。

{/* 図4.3 直接基礎の種類 */}

直接基礎の種類は以下のとおりである。

- (a) 独立フーチング
- (b) 連結フーチング
- (c) 壁のフーチング
- (d) ベた基礎

### (2) 杭基礎

杭基礎は、深い基礎に分類され、既製杭工法と場所打ち杭工法がある。

{/* 図4.4 杭工法の分類 */}

- **既製杭工法**
  - 打込み杭工法
    - 打撃工法
    - 振動工法（バイブロハンマ工法）
  - 埋込み杭工法
    - 中掘り杭工法
    - プレボーリング杭工法
    - 鋼管ソイルセメント杭工法
    - 回転杭工法
    - ジェット工法
    - 圧入工法
- **場所打ち杭工法**
  - 機械掘削工法
    - オールケーシング工法
    - リバース工法
    - アースドリル工法
    - その他のアースオーガ工法
  - 人力・機械掘削工法
    - 深礎工法

### (3) ケーソン基礎

ケーソン基礎は、鉄筋コンクリート製の箱を地上でつくり、箱内部を掘削して地中に沈めるものである。圧縮空気で水を排除して人力掘削または機械掘削するニューマチックケーソンと、バケット等で掘削するオープンケーソン（ウェル、井筒とも称する）がある。このほか、明石海峡大橋主塔基礎が代表例の鋼製設置ケーソンがある。

{/* 図4.5 ニューマチックケーソンの施工順序 */}

{/* 図4.6 オープンケーソンの施工順序 */}

両工法の特徴を以下に示す。

| 項目 | ニューマチックケーソン | オープンケーソン |
|---|---|---|
| 周辺地盤への影響 | 地下水位の低下などがなく、周辺地盤をゆるめることが少ない。 | 地下水位の低下および、外水をよびやすく、地盤をゆるめることが多い。ボイリング、ヒービング現象の発生に注意。 |
| 施工深さ | 気圧作業になり、労務管理から、施工深さは地下水位下35m（ぐらい）が限度である。 | 周辺摩擦を減殺できると、相当の深さまで施工可能、地下水位下60mぐらいの例がある。 |
| 地盤の確認 | 作業室に作業員が降りるので、確認容易。 | 水中作業になることが多く、確認困難。 |
| 機械設備 | 送気設備を含めて、機械電気設備が大がかり。工費割高。 | 比較的簡単で、工費が割安。 |
| 工期（障害物除去） | 障害物の除去が容易、しかも沈下が計画的にできて工期が安定。 | 沈下途中に障害物が出ると除去に手間取り、工期が不安定。 |
| 環境対策 | コンプレッサーの騒音・振動、エアロックからの排気音が問題になる。 | 騒音・振動源をもたず、地盤への影響が少ないので、市街地施工に適する。 |
| 工事の確実性 | 作業室内は排水しての作業になり、確実性が高い。長大橋の基礎に多数使用されている。 | 一般に水中掘削作業になるため、手探り作業になり確実性に乏しい。重要な構造物では沈下完了後止水し、コンクリート打設が考慮される。 |

### (4) 特殊基礎

特殊基礎の代表例として、鋼管矢板基礎がある。この基礎は、連結継手がついている鋼管矢板を環状に打ち込み、頭部をフーチングで結合したものである。打ち込んだ基礎の一部を締切工として兼用できるため、工事中に河川等の流水断面を減らすことが少なく、また剛性が大きいため、構造上も締切として信頼性が高く、施工例が増加している。

{/* 図4.7 鋼管矢板基礎 */}

このほか、大鳴門橋の主塔基礎に用いられている多柱式基礎や、場所打ち鉄筋コンクリート壁式地中連続壁を基礎として利用する地中連続壁基礎がある。

## 1.3 計画の基本

基礎工を計画するとき、次の事項が基本になる。

1. 構造物としての使用目的をみたす十分な機能をもつこと。
2. 安全・確実に施工できる十分な施工性をもち、経済的であること。
3. 使用状態になってからの維持補修が容易であること。
4. 構造物として耐久性が高いこと。

## 1.4 計画のための調査

### (1) 基礎地盤の調査

基礎工は、地盤との結合のうえで成り立つ。構造物を計画するとき、この結合をスムーズにするために、地盤の性状を明らかにすることが要求される。その一方、構造物の建設の前後において、地盤をはじめとする環境条件に変化が少なく、調和が保たれることも要求される。この2つの目的をもって、地盤調査が行われる。

調査においては、最初に地盤の構成を確認する必要がある。次いで、支持力・土圧を求める調査が行われる。また、沈下や変形特性を求める調査も極めて重要である。さらに、耐震性に関連する液状化についての調査や、鋼杭の腐食についての腐食環境調査が行われる。

調査は、予備調査と本調査に分かれている。

- **予備調査**は、基礎を施工する地盤を構成する地層の性状の概要を把握し、基礎型式の選定、予備設計、本調査の計画等に必要な資料を得るために行う資料調査、現地踏査、物理探査等の調査である。
- **本調査**は、基礎の詳細設計を行うために必要な地盤条件や施工条件、設計に用いる地盤定数等を明らかにするため、基礎を施工する位置で行うボーリング、サンプリング等の調査である。

### (2) 施工条件に関する調査

構造物の建設には、その周辺の環境条件を考慮することが必要となる。工事にあたっては、工事の影響を事前に予測し、必要な手当をするとともに、工事中に生ずる変化を追跡して、事業の円滑な進捗を図ることも要求されている。

施工条件に関する調査項目は、次のとおりである。

1. 工事現場の立地条件（工事用地の境界等）
2. 近接構造物および埋設構造物（位置、現状、構造形式、基礎形式）
3. 地下水分布と地盤条件（地下水位、掘削対象土・掘削底の地質）
4. 気象条件（雨、風、波浪、潮位）
5. 周辺道路および交通状況

また、工事のための仮設構造物では、工事中の安全性の確保のほかに、工事完了後の撤去が容易であることも計画上の要素となる。

## 1.5 基礎形式の選定

### (1) 選定の条件

基礎形式の選定にあたり、考慮する条件を以下に示す。

1. 上部構造の形式とその荷重の規模
2. 建設地点の地形地質や地盤沈下等の地盤変動の状況
3. 工事の安全、確実性と平易さ
4. 近接構造物や地下埋設物の状況
5. 腐食環境（電食や塩水の存在など）
6. 工事用地
7. 資材の搬入条件
8. 工期および工事実施期間
9. 公害防止に関する条例による制限の有無
