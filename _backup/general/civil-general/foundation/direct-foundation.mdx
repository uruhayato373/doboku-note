# 直接基礎

直接基礎は、良質な支持層が浅い位置に存在する場合に採用される。良質な支持層の目安は、砂・砂礫ではN値が30以上、粘性土ではN値が20以上かつ圧密のおそれがないこと等である。

直接基礎の設計では、次の事項を満足しなければならない。

1. 直接基礎は、鉛直支持、水平支持（滑動）、転倒に対して安定であること。
2. 基礎の変位量が許容変位量を超えないこと。
3. 基礎の各部材の応力度が許容応力度を超えないこと。

## 4.1 施工

### (1) 開削工

直接基礎の施工は、開削（オープン掘削）による場合が多い。地下水位が低いまたは小規模な場合には、素掘りが可能であるが、条件が満たされないと、排水工や土留め工が必要となる。

素掘りの場合の基準は、労働安全衛生規則で、表4.8のように掘削面の高さや勾配が定められている。

**表4.8 土質ごとの掘削高さと法勾配**

| 地山の種類 | 掘削面の高さ（m） | 掘削面の勾配（度） |
|---|---|---|
| 岩盤または堅い粘土からなる地山 | 5未満 | 90以下 |
| 岩盤または堅い粘土からなる地山 | 5以上 | 75以下 |
| その他の地山 | 2未満 | 90以下 |
| その他の地山 | 2以上5未満 | 75以下 |
| その他の地山 | 5以上 | 60以下 |
| 砂からなる地山 | 5未満または— | 35以下 |
| 発破で崩壊しやすい状態になっている地山 | 2未満または— | 45以下 |

地下水位が高い場合は、排水を行い、地下水位を低下させる。排水法は、対象土質に応じて適切な工法を選定する。

- **砂利、砂の多い層**: 重力排水（例：ディープウェル、釜場排水）
- **粘土やシルト混じり砂層、砂質粘土層**: 強制排水（例：ウェルポイント）

排水によって、掘削面とその外周との間に水位差が生じるため、ヒービングやボイリングなどの底盤破壊現象の発生に注意が必要である。

### (2) 基礎底面の処理

直接基礎は、外力をほとんどその底面で地盤に伝える。したがって、基礎底面と地盤のなじみは、非常に重要である。

#### 1) 基礎底面処理の留意事項

1. 掘削によって支持地盤を緩めない。底面に乱れがあれば、人力で丁寧に均す。
2. 掘削底面を長時間放置すると、緩みや風化を招くので、コンクリート打設直前に新鮮な面を出すか、均しコンクリートで掘削底面を被覆する。
3. 直接基礎の適用深度は、陸上で5m未満、水上施工で水深5m未満である。
4. 直接基礎の支持層は、砂質土・砂礫でN値30程度以上、粘性土でN値20程度以上である。
5. 直接基礎の一部に支持層として不適当な地盤が存在する場合や斜面上に直接基礎を設ける場合は、コンクリートで置き換える。置き換える際には、底面を水平に掘削し、浮き石などは完全に除去して岩盤底面を十分洗浄し、そのうえに置換えコンクリートを直接施工する。
6. 掘削底面が階段状になる場合には、特に地山の緩みがないことを確認する。
7. 基礎が滑動する際のせん断面は基礎の床付け面のごく浅い箇所に生じるため、施工時に地盤を過度に乱さない。
8. 河川敷内や海中の基礎は、洗掘の影響を考慮して、少なくとも現地盤面から将来の低下を見込んだ位置まで下げて、設計上の地盤面とする。

#### 2) 地盤の種別、工種に応じた直接基礎の施工上の留意事項

**① 砂地盤**

{/* 図4.18(a) 砂地盤の場合 */}

- 栗石や砕石のかみ合いが期待できるようにある程度の不陸（凹凸）を残して基礎底面地盤を整地し、その上に栗石や砕石を敷き均す。
- 割栗石基礎工を施工した後、均しコンクリートを施工する。
- 滑動抵抗を増すため底面に突起を設ける場合は、栗石を貫いて、支持地盤に十分貫入させる。

**② 岩盤**

{/* 図4.18(b) 岩盤の場合 */}

- 地山の緩んだ部分を取り除いて、均しコンクリートを打設する。
- 均しコンクリートと基礎地盤が十分かみ合うよう、基礎底面地盤はある程度の不陸（凹凸）を残し、平滑な面としない。

**③ 埋戻し**

{/* 図4.18(c) 水平支持力が不足する場合は突起をつける */}

- フーチングの根入れ部分で水平抵抗をとらせる場合は、埋戻し土砂を十分に吟味し、支持地盤より緩めた状態にしない。
- 岩盤を切り込んで施工するときは、掘削したずりではなく、場合によっては貧配合のコンクリートで埋め戻す。
