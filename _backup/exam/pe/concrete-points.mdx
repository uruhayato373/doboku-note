# 技術士一次試験 鋼構造及びコンクリートの要点

技術士一次試験 建設部門の専門科目のうち、「鋼構造及びコンクリート」分野（8問出題）の要点を整理する。

## 1. コンクリートの材料

### 1.1 セメント

#### ポルトランドセメントの種類と特徴

ポルトランドセメントは、**セメントクリンカー**に凝結調節剤として少量の**石こう**を添加し、粉砕したものである。クリンカーは主要な4つの化合物からなり、これらの含有率と粉末度によって各種セメントの性質が決まる。

| 化合物 | 略号 | 水和反応速度 | 強度への寄与 | 水和熱 | 化学抵抗性 |
|---|---|---|---|---|---|
| けい酸三カルシウム | C₃S | 比較的速い | 28日以内の早期強度 | 中 | 中 |
| けい酸二カルシウム | C₂S | 遅い | 28日以後の長期強度 | 小 | 大 |
| アルミン酸三カルシウム | C₃A | 非常に速い | 1日以内の早期強度 | 大 | 小 |
| 鉄アルミン酸四カルシウム | C₄AF | かなり速い | ほとんど寄与しない | 中 | 中 |

:::tip[頻出ポイント]
- **C₃S** が多い → 早期強度が大きい（早強・超早強ポルトランドセメント）
- **C₂S** が多い → 長期強度が大きく水和熱が小さい（低熱ポルトランドセメント）
- **C₃A** が少ない → 硫酸塩に対する化学抵抗性が大きい（耐硫酸塩ポルトランドセメント）
- **比表面積**が大きい → 水和が早く、強度発現が早く、水和熱が高く、乾燥収縮が大きい
:::

各種ポルトランドセメントの特徴は以下のとおりである。

| 種類 | 比表面積（cm²/g） | 特徴 |
|---|---|---|
| 普通 | 2,500以上 | 最も多く使用される（国内生産量の約70%） |
| 早強 | 3,300以上 | C₃Sが多く微粉砕。初期強度が大きい。冬期・寒冷地工事向き |
| 超早強 | 4,000以上 | 材齢1日で普通の7日とほぼ同じ強度 |
| 中庸熱 | 2,500以上 | 水和熱が低い。ダムなどマッシブなコンクリート向き |
| 低熱 | 2,500以上 | C₂S比率を増加。水和熱が最も低く長期強度が大きい |
| 耐硫酸塩 | 2,500以上 | C₃Aが著しく少ない。硫酸塩を含む土壌・海洋構造物向き |

#### 混合セメント

| 種類 | 混合材 | B種の混合率 | 特徴 |
|---|---|---|---|
| 高炉セメント | 高炉スラグ | 30超〜60%以下 | 長期強度増進、化学抵抗性大、水和熱小、ASR抑制効果 |
| シリカセメント | シリカ質混合材 | 10超〜20%以下 | ポゾラン反応により長期強度増進、化学抵抗性大 |
| フライアッシュセメント | フライアッシュ | 10超〜20%以下 | ワーカビリティー向上、長期強度増進、乾燥収縮小 |

:::tip[頻出ポイント]
- **高炉セメントB種・C種**、**フライアッシュセメントB種・C種** はアルカリ骨材反応（ASR）の抑制対策に有効
- 混合セメントは共通して**初期強度が小さく、長期強度が大きい**
- セメントの**風化**：空気中の水分・炭酸ガスと反応し、凝結が遅くなり強度が低下する
:::

### 1.2 混和材料

混和材料は、使用量の多少により**混和剤**（容積に算入しない）と**混和材**（容積に算入する）に分類される。

#### 主な混和剤

| 種類 | 効果 |
|---|---|
| AE剤 | 微細な独立気泡を連行。ワーカビリティー改善、耐凍害性向上、ブリーディング低減 |
| 減水剤（標準形） | 同一ワーカビリティーで単位水量を低減。コンクリートを緻密化 |
| AE減水剤 | AE剤＋減水剤の効果を兼備 |
| 高性能AE減水剤 | 高い減水効果＋空気連行性。スランプロス低減効果。高強度コンクリート向き |
| 流動化剤 | スランプを大きくする。スランプロスが課題 |

:::tip[頻出ポイント]
- AEコンクリートでは、**空気量1%増加につき圧縮強度は4〜6%減少**する
- AE剤の最大の特徴は**耐凍害性の向上**
:::

#### 主な混和材

| 種類 | 特徴 |
|---|---|
| フライアッシュ | ポゾラン活性。単位水量低減、水和熱低減、長期強度増進、乾燥収縮低減 |
| 高炉スラグ微粉末 | 潜在水硬性。水和熱低減、長期強度増進、塩化物イオン浸透抑制 |
| シリカフューム | 強度増加が著しい。水密性・化学抵抗性向上。単位水量は増加 |
| 膨張材 | 硬化過程で膨張し、乾燥収縮ひび割れを低減 |

### 1.3 骨材

#### 骨材の分類と基本

- **細骨材**：10mmふるいを全部通り、5mmふるいを質量で85%以上通るもの（砂など）
- **粗骨材**：5mmふるいに質量で85%以上とどまるもの（砂利、砕石など）
- 骨材はコンクリート容積の**約7割**を占める

:::tip[頻出ポイント]
- **砕石**は砂利より表面が粗 → セメントペーストとの付着がよく、同一水セメント比で強度が大きい
- 骨材に要求される性質：清浄・堅硬・耐久的で適切な粒度、有害物を含まない
- **アルカリシリカ反応性**を有する骨材はASRの原因となる
:::

## 2. コンクリートの配合設計

### 2.1 フレッシュコンクリートの性質

| 用語 | 定義 |
|---|---|
| ワーカビリティー | 材料分離を生じることなく、運搬・打込み・締固め・仕上げが容易にできる程度 |
| コンシステンシー | フレッシュコンクリートの変形・流動に対する抵抗性 |
| ポンパビリティー | コンクリートの圧送を可能にする品質・性能 |
| フィニッシャビリティー | 表面仕上げの容易さ |
| ブリーディング | 打込み後、セメント・骨材の沈下に伴い水が表面に浮き上がる現象 |
| レイタンス | ブリーディングに伴い表面に浮かぶ微細物質。強度・水密性が小さく、打継面の弱点になるため除去が必要 |

### 2.2 配合設計の要点

配合設計では、所要の品質とワーカビリティーが得られる範囲で、**単位水量をできるだけ少なく**するのが原則である。

#### 水セメント比と強度

コンクリートの強度は**水セメント比**（W/C）によって支配される（水セメント比説）。セメント水比（C/W）と圧縮強度の関係は次の直線式で実用的に表される。

$$
\sigma = A + B \cdot (C/W)
$$

:::tip[頻出ポイント]
- **水セメント比が小さい**ほど → 強度大、耐久性高い、密実
- **水セメント比が大きい**ほど → 強度小、乾燥収縮大、透水性大
:::

#### 配合強度

配合強度 $f'_{cr}$ は、現場のコンクリート圧縮強度の試験値が設計基準強度 $f'_{ck}$ を**下回る確率が5%以下**となるように定める。

#### 粗骨材の最大寸法

- 鉄筋コンクリート：部材最小寸法の **1/5以下**
- 無筋コンクリート：部材最小寸法の **1/4以下**
- 鉄筋の最小あきの **3/4以下**、かぶりの **3/4以下**

#### スランプ

- 運搬・打込み・締固めに適する範囲内で**できるだけ小さく**定める
- スランプ試験（JIS A 1101）：コーンを引き上げた直後の頂部からの下がりの値

### 2.3 硬化コンクリートの強度

| 強度の種類 | 圧縮強度に対する割合 |
|---|---|
| 引張強度 | 圧縮強度の**約1/10** |
| 曲げ強度 | 圧縮強度の**1/5〜1/8** |

:::tip[頻出ポイント]
- 強度は**材齢28日**の圧縮強度を基準とする
- 養生温度が高い → 初期強度大、長期強度は低温養生のほうが大きい
- 湿潤養生を継続 → 強度は増加し続ける。中止すると強度増進が止まる
- 供試体の $h/d$ 比が小さい → 見かけの強度が大きくなる（標準は $h/d = 2$）
:::

## 3. コンクリートの耐久性

### 3.1 中性化

| 項目 | 内容 |
|---|---|
| 現象 | 空気中のCO₂がコンクリート内に侵入し、Ca(OH)₂と反応してCaCO₃となり、pHが低下。鋼材位置まで達すると腐食が発生 |
| 劣化指標 | 中性化深さ、鋼材腐食量 |
| 対策 | かぶりを大きくする、表面仕上げ（タイル・石張り）、気密性塗装 |

:::tip[頻出ポイント]
- 中性化深さは**時間の平方根**に比例する（$d = A\sqrt{t}$）
- 水セメント比が大きい → 中性化速度が速い
:::

### 3.2 塩害

| 項目 | 内容 |
|---|---|
| 現象 | コンクリート中の塩化物イオンにより鋼材腐食が促進され、ひび割れ・はく離・断面減少が生じる |
| 塩分の供給源 | 海水飛沫、飛来塩化物、凍結防止剤、海砂 |
| 対策 | 塩化物イオン量の制限、混合セメントの使用、W/C低減、かぶり確保、エポキシ樹脂塗装鉄筋、電気防食 |

:::tip[頻出ポイント]
- 塩化物イオン量の規制値：フレッシュコンクリート中 **0.30 kg/m³ 以下**
- 高炉セメント使用により塩化物イオンの浸透抑制が可能
:::

### 3.3 凍害

| 項目 | 内容 |
|---|---|
| 現象 | コンクリート中の水分が凍結膨張し、水圧によりコンクリートが破壊される。スケーリング、微細ひび割れ、ポップアウト |
| 対策 | AE剤・AE減水剤の使用（エントレインドエアの連行）、耐凍害性骨材の使用、W/C低減 |

:::tip[頻出ポイント]
- 凍害対策の基本は**AE剤**によるエントレインドエア（空気量 **4〜7%**）
- エントレインドエア：微細な独立気泡が凍結膨張圧を吸収する
:::

### 3.4 アルカリ骨材反応（ASR）

| 項目 | 内容 |
|---|---|
| 現象 | コンクリート中のアルカリと骨材中の反応性シリカが反応し、膨張性物質が生成。吸水膨張により亀甲状ひび割れが発生 |
| 対策（3つの方法） | 下記参照 |

**アルカリ骨材反応の3つの抑制対策**（国土交通省通達）：

1. **アルカリ総量の抑制**：コンクリート1m³あたりのアルカリ総量をNa₂O換算で **3.0 kg/m³ 以下**
2. **抑制効果のある混合セメントの使用**：高炉セメント（B種・C種）、フライアッシュセメント（B種・C種）
3. **安全な骨材の使用**：アルカリシリカ反応性試験（化学法・モルタルバー法）で**無害**と確認された骨材

:::tip[頻出ポイント]
- 土木構造物では対策1・2を優先する
- 亀甲状ひび割れはASRの典型的な外観特徴
:::

## 4. 鉄筋コンクリートの設計

### 4.1 鉄筋の基本

#### 鉄筋の種類と機械的性質

| 種類 | 降伏点（N/mm²） | 引張強さ（N/mm²） | 備考 |
|---|---|---|---|
| SR235（丸鋼） | 235以上 | 380〜520 | 丸鋼 |
| SD295（異形棒鋼） | 295以上 | 440〜600 | 一般的に使用 |
| SD345（異形棒鋼） | 345〜440 | 490以上 | 最も多く使用 |
| SD390（異形棒鋼） | 390〜510 | 560以上 | 高強度 |
| SD490（異形棒鋼） | 490〜625 | 620以上 | 高強度 |

:::tip[頻出ポイント]
- SR = 丸鋼（Round bar）、SD = 異形棒鋼（Deformed bar）
- 数字は降伏点の下限値を表す
- 異形棒鋼はリブにより付着力に優れる
:::

#### かぶりと鉄筋のあき

- **かぶり**：鉄筋表面からコンクリート表面までの最短距離
  - 鋼材の防食（中性化・塩害対策）、付着力の確保、耐火性の確保のために必要
- **鉄筋のあき**：隣り合う鉄筋間の最短距離
  - コンクリートの充填性確保のために粗骨材最大寸法の4/3倍以上が必要

### 4.2 曲げに対する設計

#### 曲げモーメントに対する断面の釣合い

鉄筋コンクリートはりの曲げ設計では、以下の仮定に基づく。

1. **平面保持の仮定**：断面は変形後も平面を保つ
2. コンクリートの引張応力は無視する
3. 鉄筋は降伏強度まで応力を負担する

:::tip[頻出ポイント]
- **釣合い鉄筋比**：引張鉄筋の降伏とコンクリートの圧壊が同時に生じる鉄筋比
- 靭性確保のため、実際の鉄筋比は釣合い鉄筋比より小さく設計する（**引張鉄筋が先に降伏**する設計）
- 複鉄筋断面：圧縮側にも鉄筋を配置し、靭性や変形性能を向上
:::

### 4.3 せん断に対する設計

#### せん断破壊の特徴

- 曲げ破壊に比べて**脆性的**で危険
- せん断補強鉄筋（**スターラップ**、**折曲げ鉄筋**）により防止

:::tip[頻出ポイント]
- **斜めひび割れ**：せん断力によって部材軸に対して約45度の方向に生じる
- スターラップ（あばら筋）：部材軸と直交方向に配置する閉合型のせん断補強鉄筋
- せん断耐力は **コンクリートの負担分 + せん断補強鉄筋の負担分**
- せん断補強鉄筋の効果：斜めひび割れの進展抑制、コンクリートの拘束
:::

### 4.4 付着と定着

#### 付着応力

- 鉄筋とコンクリートの界面に生じるせん断応力
- 付着が切れると鉄筋が抜け出し、部材としての性能を失う

#### 定着

- 鉄筋をコンクリート中に十分な長さ埋め込み、鉄筋の応力を伝達すること
- **基本定着長**：鉄筋の降伏強度を伝達するために必要な最小の埋込み長さ

:::tip[頻出ポイント]
- 異形棒鋼はリブにより**機械的付着**が大きく、丸鋼より付着力に優れる
- 定着の方法：直線定着、フック付き定着
- **フック**の種類：半円形フック、直角フック、鋭角フック（135度）
- 鉄筋の**重ね継手**の長さ ≧ 基本定着長
:::

## 5. 鋼構造

### 5.1 鋼材の基本的性質

#### 応力度とひずみの関係

鋼材は弾性域では**フックの法則**に従い、応力度はひずみに比例する。

$$
\sigma = E \cdot \varepsilon
$$

ここに、$E$：ヤング係数（$2.0 \times 10^5$ N/mm²）

| 用語 | 定義 |
|---|---|
| 比例限度 | 応力度とひずみが比例関係を保つ上限 |
| 弾性限度 | 荷重除去で変形が完全に回復する上限 |
| 降伏点 | 応力度が増加しなくてもひずみが増大し始める点 |
| 引張強さ | 応力度の最大値 |
| 破断伸び | 破断時の伸びの割合（延性の指標） |

:::tip[頻出ポイント]
- 鋼材のヤング係数は鋼種にかかわらず一定（$E = 2.0 \times 10^5$ N/mm²）
- ポアソン比 $\nu = 0.3$
- 線膨張係数 $\alpha = 12 \times 10^{-6}$ /°C
- 降伏比（= 降伏点 / 引張強さ）が低いほど靭性に優れる
:::

#### 鋼材の種類

| 鋼種 | 降伏点（N/mm²） | 引張強さ（N/mm²） | 用途 |
|---|---|---|---|
| SS400 | 235〜245以上 | 400〜510 | 一般構造用圧延鋼材 |
| SM490 | 315〜325以上 | 490〜610 | 溶接構造用圧延鋼材 |
| SMA490W | 315〜325以上 | 490〜610 | 耐候性鋼材（無塗装） |

### 5.2 座屈

#### 圧縮部材の座屈

軸圧縮力を受ける細長い部材は、材料強度に達する前に**横方向に変形**して耐力を失う。これを**座屈**という。

**オイラーの座屈荷重**：

$$
P_{cr} = \frac{\pi^2 E I}{(kL)^2}
$$

ここに、$E$：ヤング係数、$I$：断面二次モーメント、$kL$：有効座屈長さ

:::tip[頻出ポイント]
- **細長比** $\lambda = kL / r$ （$r$：断面の回転半径）が大きいほど座屈しやすい
- 座屈応力は細長比の2乗に反比例する
- 支持条件による有効座屈長さ係数 $k$：両端ピン $k=1.0$、一端固定・他端自由 $k=2.0$、両端固定 $k=0.5$、一端固定・他端ピン $k=0.7$
:::

#### その他の座屈

| 座屈の種類 | 内容 |
|---|---|
| 局部座屈 | 薄板要素が圧縮力を受け、板面外に波打つように変形する現象。幅厚比の制限で防止 |
| 横座屈 | はりのフランジが面外に変形する現象。横補剛材の設置で防止 |

### 5.3 接合

#### 高力ボルト接合

| 接合形式 | メカニズム |
|---|---|
| 摩擦接合 | ボルト軸力で締付けた接合面の摩擦力で応力を伝達。**最も一般的** |
| 引張接合 | ボルト軸方向の引張力で応力を伝達 |
| 支圧接合 | ボルト軸部のせん断力と母材の支圧力で応力を伝達 |

:::tip[頻出ポイント]
- 高力ボルト摩擦接合の耐力は**ボルト軸力 $\times$ 摩擦係数 $\times$ 摩擦面数**で決まる
- 接合面は**赤錆状態**またはブラスト処理（摩擦係数の確保）
- トルシア形高力ボルト（S10T）：締付け完了時にピンテールが破断して管理が容易
- ボルトの締付け順序：群の**中央から外側**へ
:::

#### 溶接接合

| 溶接の種類 | 特徴 |
|---|---|
| 完全溶込み開先溶接 | 母材と同等の強度。最も信頼性が高い |
| 隅肉溶接 | 重ね継手やT継手に使用。のど厚で強度を計算 |
| 部分溶込み開先溶接 | 完全溶込みが不要な箇所に使用 |

:::tip[頻出ポイント]
- 隅肉溶接の**有効のど厚** $a = S / \sqrt{2}$（$S$：隅肉サイズ）
- 隅肉溶接の強度照査は**のど断面のせん断**で行う
- 溶接欠陥：アンダーカット、ブローホール、スラグ巻込み、融合不良、割れ
- 溶接残留応力：溶接部に引張残留応力が生じ、疲労強度に影響
:::

### 5.4 疲労

- 繰返し荷重により応力が材料の静的強度より低い値でも破壊が生じる現象
- **S-N曲線**（応力範囲と繰返し回数の関係）で疲労寿命を評価
- 応力集中部（溶接止端、ボルト孔周辺など）で疲労き裂が発生しやすい

:::tip[頻出ポイント]
- 疲労強度は**応力範囲**（最大応力−最小応力）に支配される
- **応力比**（= 最小応力 / 最大応力）は疲労強度にほとんど影響しない
- 溶接継手の疲労等級は継手の形式・品質で決まる
:::

## 6. プレストレストコンクリート（PC）

### 6.1 PCの基本原理

プレストレストコンクリートは、外力によってコンクリートに生じる引張応力を打ち消すように、あらかじめ圧縮力（プレストレス）を導入したコンクリートである。

$$
\text{コンクリートの応力} = \frac{P}{A} + \frac{P \cdot e \cdot y}{I} + \frac{M \cdot y}{I}
$$

ここに、$P$：プレストレス力、$A$：断面積、$e$：偏心量、$I$：断面二次モーメント、$M$：外力による曲げモーメント

### 6.2 PC鋼材とプレストレスの導入方法

| 方式 | 特徴 |
|---|---|
| プレテンション方式 | コンクリート打設前にPC鋼材を緊張。付着力でプレストレスを導入。工場製品向き |
| ポストテンション方式 | コンクリート硬化後にPC鋼材を緊張。定着具でプレストレスを導入。現場施工向き |

### 6.3 プレストレスの損失

プレストレス力は導入後に減少する。主な損失要因は以下のとおりである。

| 損失要因 | 発生時期 |
|---|---|
| 弾性変形（他のPC鋼材の緊張による） | 緊張直後 |
| 摩擦損失（シースとPC鋼材の摩擦） | 緊張直後（ポストテンションのみ） |
| 定着時のセットバック（くさびの引込み） | 定着時 |
| コンクリートのクリープ | 長期 |
| コンクリートの乾燥収縮 | 長期 |
| PC鋼材のリラクセーション | 長期 |

:::tip[頻出ポイント]
- **クリープ**：持続荷重下で時間とともにひずみが増加する現象
- **リラクセーション**：一定ひずみ下で応力が時間とともに減少する現象
- プレテンション方式では摩擦損失は発生しない
- ポストテンション方式ではグラウトの充填によりPC鋼材を防食する
:::

### 6.4 PCの設計

| 設計区分 | 特徴 |
|---|---|
| フルプレストレッシング（I種PC） | 使用状態で引張応力を許容しない。ひび割れなし |
| パーシャルプレストレッシング（II種PC） | 使用状態で引張応力を許容するが、ひび割れは許容しない |
| パーシャルプレストレッシング（III種PC） | 使用状態でひび割れを許容する |
