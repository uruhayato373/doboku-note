# 技術士一次試験 施工計画の要点

技術士一次試験 建設部門「施工計画、施工設備及び積算」の出題範囲から、頻出テーマを体系的に整理する。

## 1. 施工計画の基本

### 施工計画の目的

施工計画の目的は、設計図書に基づき、施工手段を効率的に組み合わせて、適切な品質の目的構造物を、環境保全を図りつつ、**最小の価格で工期内に安全に完成させること**にある。

施工計画は、**安全性**を前提として次の 3 条件の調和を保つ計画である。

| 条件 | 内容 |
|---|---|
| 品質 | 設計図書に基づく品質の確保 |
| 経済性 | 最小の原価での施工 |
| 工期 | 契約工期内の完成 |

### 施工手段（5M）

施工計画で組み合わせる 5 つの施工手段を **5M** と呼ぶ。

| 施工手段 | 英語 |
|---|---|
| 人・労力 | Men |
| 材料 | Materials |
| 方法 | Methods |
| 機械 | Machinery |
| 資金 | Money |

### 施工計画の作成手順

施工計画の作成手順は、大きく次の 4 段階で構成される。

1. **事前調査の実施** — 契約条件・現場条件を確認する
2. **基本計画の作成** — 主要工種の施工方法の概略検討、経済性比較
3. **詳細計画の作成** — 機械選定、人員配置、工程、仮設備、工事費積算
4. **管理計画の作成** — 現場組織、配員計画、資金計画、安全衛生計画

:::note[試験のポイント]

- 施工計画の目的は「品質・経済性・工期」の 3 条件の調和であり、**安全性は前提**である
- 施工手段 **5M** の構成要素は頻出。特に「Methods（方法）」が施工計画の核である
- 施工計画は **1 案だけでなく複数の代案**を作成し比較検討する

:::

### 事前調査

事前調査は施工計画の前提条件となるため、特に念入りに実施する。

#### 契約条件の確認

- 契約書の内容（損害の取扱い、支払条件、数量変更等）
- 設計図書の確認（図面と現場の相違、数量の違算、規格値・基準値）
- 監督職員の指示・承諾・協議事項の範囲

#### 現場条件の調査

- **自然・気象条件** — 地形・地質・土質・地下水、水文気象データ
- **仮設計画** — 施工方法、仮設方法・規模、施工機械
- **資機材** — 材料の供給源・価格・運搬路、労務供給
- **輸送** — 道路状況、現場搬入路
- **近隣環境** — 用地買収状況、隣接工事、騒音・振動基準
- **建設副産物** — 処理方法・処理条件

### 仮設備計画

仮設備は工事施工のために必要な臨時的工事施設であり、工事完成後は原則撤去される。

| 区分 | 内容 | 契約上の取扱い |
|---|---|---|
| **指定仮設** | 発注者が設計仕様・数量・施工方法等を指定 | 設計変更の対象 |
| **任意仮設** | 施工者の自主性と企業努力に委ねる | 変更対象とならないことが多い |

仮設備工事は、さらに次のように分類される。

- **直接仮設** — 本工事施工に直接必要（土留め、仮締切り、足場、支保工等）
- **共通仮設**（間接仮設） — 工事遂行に間接的に必要（現場事務所等）

### 施工計画書

受注者は、工事着手前に施工計画書を監督職員に提出する。主な記載事項は次のとおりである。

1. 工事概要
2. 計画工程表
3. 現場組織表
4. 指定機械
5. 主要船舶・機械
6. 施工方法
7. 施工管理計画
8. 安全管理
9. 緊急時の体制・連絡先

:::note[試験のポイント]

- 指定仮設と任意仮設の**契約上の取扱いの違い**が頻出
- 事前調査は「契約条件の確認」と「現場条件の調査」の 2 つに大別される
- 施工計画書の記載事項は土木工事共通仕様書に規定されている

:::

## 2. 工程管理

### 工程管理の目的

工程管理は、施工計画をもとに工事の進度を時間的に管理し、**工期内に所定品質の構造物を経済的に完成させる**ことを目的とする。

工程管理は、三大管理（品質・原価・工程）すべてに影響する重要な管理である。

### 工程管理の手順（PDCA）

| 段階 | 内容 |
|---|---|
| **Plan** | 施工計画、工程計画（工程表の作成）、使用計画（労務・機械・資材） |
| **Do** | 工事の実施、指示、承諾、協議、段階検査 |
| **Check** | 作業量管理、進度管理（計画と実績の比較）、手配管理 |
| **Act** | 是正処置（作業改善、工程促進、再計画） |

### 工程図表の種類

| 工程図表 | 長所 | 短所 |
|---|---|---|
| **バーチャート** | 作成・修正が容易。各作業の所要日数がわかる | 工期に影響する作業（クリティカルパス）が不明 |
| **ガントチャート** | 作成が容易。各作業の進捗度合がわかる | 所要日数がわからない。工期影響が不明 |
| **斜線式工程表** | 施工場所と施工時期の進捗が直視的にわかる | 工種間の相互関係が不明確 |
| **曲線式工程表** | 全体の出来高進捗が把握できる | 個別作業の詳細がわからない |
| **ネットワーク式** | 作業の相互関係・クリティカルパスが明確 | 作成に手間がかかる |

### ネットワーク式工程表

#### 基本用語

| 用語 | 説明 |
|---|---|
| **作業（アクティビティ）** | 矢線（→）で表す。尾が開始、頭が終了 |
| **イベント（結合点）** | ○で表す。作業の前後関係を明示 |
| **ダミー（疑似作業）** | 点線矢印。所要時間ゼロの疑似作業 |
| **所要時間** | 作業の開始から終了までに要する時間（日単位が一般的） |

#### 基本ルール

- 結合点に入る矢線（先行作業）が**すべて完了**した後でなければ、後続作業は開始できない
- イベント番号は**同じ番号が 2 つ以上**あってはならない

#### 作業時刻

| 時刻 | 略称 | 意味 | 計算方向 |
|---|---|---|---|
| 最早開始時刻 | EST | 次の作業を最も早く開始できる時刻 | 左→右（足し算、最大値を採用） |
| 最遅完了時刻 | LFT | 工期内完了のため遅くとも終了すべき時刻 | 右→左（引き算、最小値を採用） |
| 最早完了時刻 | EFT | 作業が最も早く終了できる時刻 | EST + 所要時間 |
| 最遅開始時刻 | LST | 遅くとも開始すべき時刻 | LFT − 所要時間 |

#### クリティカルパス（CP）

- ネットワーク上の各経路のうち**最も日数が長い経路**
- クリティカルパス上の作業は**すべてのフロートが 0**
- クリティカルパス上の全イベントで **EST = LFT**
- クリティカルパスは**必ずしも 1 本とは限らない**
- **工期短縮**はクリティカルパスに着目する

#### 余裕時間（フロート）

| フロート | 略称 | 定義 | 特徴 |
|---|---|---|---|
| **全余裕時間**（トータルフロート） | TF | 全体工期に影響を及ぼさずに取り得る最大の余裕 | 使うと後続作業のフロートに影響 |
| **自由余裕時間**（フリーフロート） | FF | 後続作業の最早開始時刻に影響を与えない余裕 | 自由に使える余裕時間 |
| **干渉余裕時間**（インターフェアリングフロート） | IF | TF − FF | 使わなければ後続作業に投入可能 |

$$
\text{TF} = \text{LFT} - \text{EST} - \text{所要時間}
$$

$$
\text{FF} = \text{後続のEST} - \text{当該のEST} - \text{所要時間}
$$

:::note[試験のポイント]

- 各工程図表の**長所・短所**の比較は頻出（特にバーチャートとネットワーク式）
- ネットワーク式工程表の計算問題（EST、LFT、クリティカルパス、フロート）は毎年のように出題される
- **EST は左→右で足し算（最大値）**、**LFT は右→左で引き算（最小値）** を取る
- TF = 0 の経路がクリティカルパス

:::

### 工程計画の基本

#### 作業可能日数

$$
\text{作業可能日数} \geq \frac{\text{工事量}}{\text{1日平均施工量}}
$$

作業可能日数は、工期中の暦日数から定休日・天候その他の作業不能日数を差し引いて算定する。

#### 施工速度と原価の関係

- 施工速度が遅い → 施工効率が悪く単位原価は**高い**
- 施工速度を上げる → 出来高が増加し単位原価は**低下**
- さらに速度を上げる（突貫工事） → 機械の大型化等で単位原価は**再上昇**
- 採算を確保できる範囲内で最も効率的な速度 = **最適工期**

## 3. 原価管理（積算）

### 原価管理の目的

原価管理とは、最も経済的な施工計画に基づき**実行予算（予定原価）**を設定し、工事進捗に伴う**実施原価（実際原価）**と比較して差異を分析し、工事利益を確保するために費用を管理することである。

### 原価管理の手順（PDCA）

| 段階 | 内容 |
|---|---|
| **Plan** | 実行予算の作成（最も経済的な施工計画に基づく） |
| **Do** | 原価発生の統制（実施原価をできる限り低く抑える） |
| **Check** | 実施原価と実行予算の対比（工種別・費目別） |
| **Act** | 施工計画の再検討、原価引下げの措置 |

### 工事費の構成

工事費の基本的な構成は次のとおりである。

```
工事費
├── 工事原価
│   ├── 直接工事費
│   │   ├── 材料費
│   │   ├── 労務費
│   │   └── 直接経費（機械経費、特許使用料、水道光熱電力料等）
│   └── 間接工事費
│       ├── 共通仮設費（運搬費、準備費、事業損失防止施設費、安全費等）
│       └── 現場管理費（労務管理費、租税公課、保険料、福利厚生費等）
└── 一般管理費等（役員報酬、従業員給料手当、法定福利費、利益等）
```

| 費目 | 内容 |
|---|---|
| **直接工事費** | 工事目的物を施工するために直接必要な費用（材料費・労務費・直接経費） |
| **間接工事費** | 工事施工に間接的に必要な費用（共通仮設費・現場管理費） |
| **一般管理費等** | 本社の一般管理活動に必要な費用と利益 |

### 原価発生の統制

原価発生を統制するための基本原則は次のとおりである。

1. **原価比率の高いもの**に重点を置いて費用低減を図る
2. 原価低減の**可能性が高いもの**に重点を置いて合理化する
3. **損失費目**を見つけ出し重点的に改善する
4. 実施原価が実行予算を**超過する傾向**の費目を早期に改善する
5. 常に実際の作業量を調査し、標準作業量と比較する

:::note[試験のポイント]

- 工事費の構成（直接工事費・間接工事費・一般管理費等）の体系は頻出
- **直接工事費**の3要素（材料費・労務費・直接経費）を正確に区分できること
- 原価管理は **PDCA サイクル**（実行予算→統制→対比→再検討）で実施する
- **実行予算**と**実施原価**の違いを明確に理解すること

:::

## 4. 品質管理の基礎

### 品質管理の定義

品質管理とは、設計図・仕様書に示された形状と規格を十分満足する構造物を**最も経済的に**作るための、すべての段階における品質の管理体系である。

### 品質管理の目標

品質管理の直接の目標は次の 2 点である。

1. 構造物が**規格を満足**していること
2. **工程（品質が作り出される過程）が安定**していること

### 品質管理の手順

| 手順 | 内容 |
|---|---|
| 1. 品質特性の選定 | 管理対象となる品質特性を選定 |
| 2. 品質標準の設定 | 規格をゆとりをもって満足する施工管理の目安を設定 |
| 3. 作業標準の決定 | 品質標準を満足させるための作業方法を決定 |
| 4. データ採取 | 作業標準に従って施工し、データを採取 |
| 5. 分析確認 | 工程能力図・ヒストグラム・管理図で品質確認 |
| 6. 作業方法の見直し | 異常発生時に原因追求し作業方法を改善 |
| 7. 作業の継続 | 引き続きデータを監視し手順 5 以降を繰り返す |

### 品質管理の統計的手法

| 手法 | 特徴 | 管理基準 | 利点 | 欠点 |
|---|---|---|---|---|
| **工程能力図** | 横軸に時間、縦軸に品質特性値をプロット | 規格値 | 時間的な品質変動がわかる | 工程の異常は判断できない |
| **ヒストグラム** | 品質特性の度数分布図 | 規格値 | 分布状態・中心位置・規格値の関係がわかる | 時間的変化がわからない |
| **管理図** | 管理限界線を設定しデータを打点 | 管理限界線 | 工程の安定性を評価できる | 規格値との関係がわからない |

### ISO9000 ファミリー

品質マネジメントシステムの国際規格。7 つの品質マネジメントの原則は次のとおりである。

1. **顧客重視** — 顧客の要求を満たし期待を上回る
2. **リーダーシップ** — 目的と方向性の一致
3. **人々の積極的参加** — 権限付与と参画
4. **プロセスアプローチ** — 相互関連するプロセスの管理
5. **改善** — 継続的改善の重視
6. **客観的事実に基づく意思決定** — データ・情報の分析に基づく決定
7. **関係性管理** — 利害関係者との関係管理

:::note[試験のポイント]

- 品質管理の 2 つの目標（規格の満足＋工程の安定）を区別して理解する
- **工程能力図**・**ヒストグラム**・**管理図**の違い（管理基準が規格値 or 管理限界線）は頻出
- 品質管理も PDCA サイクルで実施する
- ISO9000 の品質マネジメント原則 7 項目の内容を把握する

:::

## 5. 建設機械の選定

### 建設機械選定の 3 つの検討項目

1. **工事現場への適合性** — 工事条件に最も適した機械の選定
2. **経済性** — 最も経済的な機械の調達と運用
3. **合理的な組合せ** — 最も合理的な機械の組合せ

### 工事現場への適合性（土工機械の例）

選定にあたり考慮する工事条件は次のとおりである。

- 取り扱う土の種類、土質条件、地下水の状況
- 工事量、掘削深さ、運搬距離
- 機械作業の自由度

### 経済性の検討

以下の条件を考慮して経済性を判断する。

- 工事単価、工事規模・施工速度（1 時間平均施工量）
- 機械損料・運転経費
- 納期、運搬条件・設置場所
- 運転手の能力
- 市場に出回っている普及度の高い標準機械

### 機械の合理的な組合せ

- **主作業**を明確に選定し、主作業を中心に各工程の施工速度を検討する
- 流れ作業の最大施工速度は、各分割工程のうち**最小の施工速度**で決まる
- **従機械**は主機械の作業能力と**同等またはやや上回る**能力とする
- 機械故障による全体の作業休止を防ぐため、作業全体の効率化を図る

:::note[試験のポイント]

- 建設機械選定の 3 項目（適合性・経済性・組合せ）の内容を整理する
- 組合せ作業の最大施工速度は**最小の分割工程の施工速度**で決まる
- 従機械は主機械の能力以上とし、**全体のバランス**を保つ

:::

## 6. 施工管理の三大管理の相互関係

施工管理の三大管理（品質・原価・工程）は互いに**相反する関係**にある。

| 関係 | 概要 |
|---|---|
| **工程と原価** | 施工速度を上げると原価は下がるが、ある限度を超えると原価は再上昇する（**最適工期**の存在） |
| **品質と原価** | 品質を高くすると原価も高くなる |
| **品質と工程** | 品質を高くすると施工速度は遅くなる |

:::note[試験のポイント]

- 三大管理の相互関係は、3 つの曲線で概念的に表される
- 施工速度には**最適工期**（採算面で最も経済的な速度）がある
- 突貫工事は原価が上昇する代表例

:::
