# 情報管理（Information Management）

## 概要

**データセキュリティ・IT戦略・DX推進** により、経営効率化と競争力強化を実現する管理技術です。

**出題の傾向:**
- IT戦略・DX推進 40%
- サイバーセキュリティ 35%
- BIM/CIM等の建設技術 25%

**注:** 最新トレンド色が強く、毎年出題内容が更新されます。

---

## 重要キーワード（35個）

### IT戦略・DX（12個）

```
01. DX（デジタルトランスフォーメーション）
    既存のビジネスモデルをデジタル化で変革
    
02. IT戦略             経営戦略に基づくIT活用計画
03. クラウド化         オンプレミス → パブリッククラウド
04. データ分析・BI     ビジネスインテリジェンス活用
05. AI（人工知能）     予測、最適化、自動化
06. IoT（モノのインターネット）
    センサーで施工現場のリアルタイム監視
    
07. RPA（ロボティック・プロセス・オートメーション）
    定型業務の自動化
    
08. デジタルツイン    仮想空間での施工シミュレーション
09. エッジコンピューティング
    現場で低遅延処理を実現
    
10. ビッグデータ活用   膨大なログ・センサーデータの分析
11. プラットフォーム化 他企業とのデータ連携
12. サブスクリプション型サービス
    所有 → 利用（結果提供型）へシフト
```

### BIM/CIM等の建設技術（10個）

```
13. BIM（ビルディング・インフォメーション・モデリング）
    建築・構造・設備を統合3Dモデル化
    
14. CIM（建設情報モデリング）
    大規模土木工事向けBIM（ダム、道路、橋梁）
    
15. 3Dレーザースキャン  現況測量の自動化・高精度化
16. ドローン・UAV      空撮、進捗管理、測量
17. MR/AR/VR          混合現実での安全教育、施工ナビゲーション
18. クラウド施工管理   複数拠点でのリアルタイム共有
19. IoTセンサー        沈下計、加速度計のデータ自動収集
20. ウェアラブル       作業員の位置・体調リアルタイム監視
21. 労務管理システム   QRコード、顔認証での入退場管理
22. 進捗管理システム   写真+AI で工程把握の自動化
```

### セキュリティ・個人情報保護（13個）

```
23. サイバーセキュリティ    不正アクセス、ウイルス防止
24. 情報セキュリティ基本方針   組織全体の方針宣言
25. 三大要素             機密性（C）、完全性（I）、可用性（A）
26. 認証（Authentication）  パスワード、多要素認証（MFA）
27. 暗号化              データ保護、通信の秘密化
28. ファイアウォール    内部ネットワーク保護
29. 侵入検知・防止（IDS/IPS）
    不正アクセスの検出・遮断
    
30. 個人情報保護法（APPI）
    個人情報の収集・保管・利用ルール
    
31. GDPR（EU一般データ保護規則）
    欧州の個人情報規制（国際取引時に必須）
    
32. インシデント対応   セキュリティ事故の報告・対応体制
33. アクセス権管理（IAM）
    誰がどのデータにアクセスできるか管理
    
34. バックアップ・復旧 災害対応、システム復旧計画
35. セキュリティ監査   定期的な脆弱性診断
```

## DX推進の段階

```
【段階1：デジタイゼーション】
アナログ → デジタル への単なる変換
（紙の書類をPDFにする等）
成果: 事務作業の時間削減

【段階2：デジタライゼーション】
デジタル化した業務プロセスを最適化
（入力 → 承認 → 出力のワークフロー自動化）
成果: 業務効率化、ヒューマンエラー削減

【段階3：デジタル変革（DX）】
ビジネスモデル・経営そのものを変革
（従来型の施工 → データ駆動の最適施工へ転換）
成果: 市場競争力向上、新規ビジネス創出
```

## BIMを活用した施工メリット

```
【設計段階】
□ 衝突検出（各工事の干渉確認）
□ 数量自動算出（建材量の正確把握）
□ コスト見積の自動生成

【施工計画段階】
□ 施工手順のシミュレーション
□ 工事工程の事前検証
□ 安全リスク事前抽出

【施工段階】
□ AR/VRで作業員へのナビゲーション
□ IoTセンサーでリアルタイム進捗把握
□ 品質記録の自動化（写真+AI 判定）

【竣工後】
□ 保守管理情報の蓄積
□ 次工事への知見活用
```

## 過去問分析

### パターン1: DX推進の課題

```
【例】
「建設業界の労働力不足に対して、
 DXをどのように活用すべきか」

→ 回答例：
  1. ロボット化・ドローン利用で現場作業を削減
  2. BIM/CIM で設計段階での誤り削減
  3. IoT センサーで無人監視可能に
  4. AI で最適な施工計画の自動生成
  5. データ分析で生産性向上の経営判断
```

### パターン2: セキュリティリスク対応

```
【例】
「クラウドシステム導入により、
 サイバーセキュリティ上のリスクが増加した。
 対策を述べよ」

→ 回答例：
  □ 多要素認証（MFA）の導入
  □ データ暗号化（転送中・保管時）
  □ 定期的なセキュリティ監査
  □ インシデント対応計画の策定
  □ 従業員のセキュリティ教育強化
```

## 出題のポイント

```
✅ DX ＝「新しい技術導入」ではなく「ビジネス変革」
✅ セキュリティは「コスト」ではなく「経営基盤」
✅ 人手不足の解決をIT で説明
✅ 生成AIなど最新トレンドへの言及
❌ 「技術ありき」の説明
❌ セキュリティと利便性の対立を前提とする
```
