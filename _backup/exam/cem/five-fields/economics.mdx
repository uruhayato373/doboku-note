# 経済性（Economics）

## 概要

限られた経営資源（予算・人員・時間）を最適配分し、**最大の価値を生み出す** 管理技術です。

**出題の傾向:**
- VE・VA分析 40%
- 品質・コスト管理 40%
- 生産性向上・原価企画 20%

---

## 重要キーワード（35個）

### VE（バリューエンジニアリング）関連（12個）

```
01. VE定義              目的機能を最小コストで実現
02. VA（バリュー分析）  既存製品のコスト削減
03. 機能分析           「必要な機能」vs「実装機能」
04. FAST図             機能の関係を図式化
05. 価値 (V)           機能 ÷ コスト （高いほど良い）
06. VE手法             ブレーンストーミング、チェックリスト
07. ターゲットコスト   目標原価設定、逆算設計
08. 標準化/規格品化    カスタム→既成品への切り替え
09. 工程削減           施工方法の効率化
10. 材料代替           高価材料→低価格代替品
11. 外注 vs 内製       コスト比較による選択
12. VE提案制度         従業員からの改善提案
```

### 品質管理・コスト管理（15個）

```
13. 品質管理（QC）      ばらつき低減、不良品ゼロ
14. 統計的品質管理（SQC） 抜き取り検査、管理図
15. 品質コスト論        予防 > 検査 > 失敗対応
16. 予防費             教育、検査装置、設計確認
17. 鑑定費             検査・試験、試験装置
18. 失敗費             不良品修復、廃棄、返品対応
19. 外部失敗費         クレーム対応、保証
20. 原価構成           直接材料費 + 労務費 + 経費
21. 変動費 vs 固定費    操業度による分類
22. 原価差異分析       予算 vs 実績の分析
23. 標準原価           基準となる予定原価
24. 予定価格           機械・工期から算出
25. 見積原価           入札時の積算
26. 実績原価           工事完了後の原価
27. 原価率管理         コストを%で監視
```

### 生産性向上・経営指標（8個）

```
28. 生産性             産出量 ÷ 投入量
29. 工期短縮           機械化、平行作業、IT活用
30. 労働生産性         成果 ÷ 労働時間
31. 資本生産性         売上 ÷ 投下資本
32. ROI（投資利益率）   利益 ÷ 投資額 × 100%
33.採算分岐点         損益分岐点計算
34. キャッシュフロー    資金流動管理
35. IRR（内部収益率）   ファイナンス指標
```

## VE の 5段階法

```
【Phase 1: 情報段階】
└─ 対象製品・工事の機能・コストを把握

【Phase 2: 創造段階】
└─ ブレーンストーミングで改善案を発想
　（常識に縛られない）

【Phase 3: 判定段階】
└─ 改善案を評価・絞り込み
　（実現可能性、コスト削減効果）

【Phase 4: 詳細検討段階】
└─ 有望案を詳細設計
　（品質・安全への影響確認）

【Phase 5: 提案段階】
└─ 成果報告・実装承認取得
```

## 品質コスト論の活用

```
【コスト構成】

┌──────────────────────────────────────┐
│ 総品質コスト = 予防費 + 鑑定費 + 失敗費  │
└──────────────────────────────────────┘

【理想的な配分（成熟企業）】
予防費 30% ： 鑑定費 30% ： 失敗費 40%
↓
実績（未熟企業）
予防費 5% ： 鑑定費 35% ： 失敗費 60%

【改善策】
→ 予防に投資（教育、設計品質向上）
→ 失敗費を削減
→ 総コスト低下
```

## 過去問分析

### パターン1: VE 適用の判定

```
【例】
「大規模構造物の基礎工を設計する際、
 VEを適用する際の注意点は？」

→ 回答例：
  ✅ 基本的に安全・機能は維持
  ✅ 施工方法の見直しで工期短縮
  ✅ 材料の標準化・規格品化を検討
  ❌ 安全係数の削減は厳禁
  ❌ 環境対応コストは削減対象外
```

### パターン2: 原価管理の実務問題

```
【例】
「工事原価が予定価格を30%超過している。
 総合技術管理の視点から、
 今後の対応策を述べよ」

→ 回答例：
  1. 原価差異分析（予定 vs 実績 の詳細把握）
  2. 超過の原因特定（機械化不足？設計変更？）
  3. 残工事での効率化策（人員配置、機械種、工法）
  4. 協力企業との単価交渉
  5. 全社レベルでの類似工事への水平展開
```

### パターン3: 生産性向上戦略

```
【例】
「現場労働力不足が経営課題である場合、
 経済性の観点からの対応を述べよ」

→ 回答例：
  ・ロボット化、ドローン活用
  ・プレファブ化、工場施工推進
  ・労働環境改善による離職防止
  ・高齢技能者の活用
  ・給与・処遇の改善投資
  
  → 「効率化」＝「コスト削減」ではなく
    「生産性向上」＝「利益増加」へシフト
```

## 最新トレンド（2024-2025年）

### 1. デジタル化による原価削減

```
□ AI による原価予測
□ IoT で機械運用効率化
□ 3Dレーザースキャン、ドローン調査
```

### 2. サーキュラルエコノミー対応

```
□ 廃棄物→資源への転換
□ リサイクル材料の活用
□ 環境コスト（カーボン価格）への対応
```

### 3. 働き方改革による採算性向上

```
□ 長時間労働削減 → 生産性向上
□ 給与引上げ → 人材確保
□ 働き手不足への機械化投資
```

## 出題のポイント

```
✅ VE は「品質低下」ではなく「無駄排除」
✅ 経済性＝ 単純なコスト削減ではなく「価値最大化」
✅ 予防に投資することで総コスト削減を実現
✅ 労働生産性向上は経営戦略の重要テーマ
❌ 「安全」「環境」とのトレードオフを前提とする
❌ 短期利益のみを優先
```
