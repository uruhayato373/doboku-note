# 技術士（総合技術監理部門）について

技術士総合技術監理部門は、複数の技術部門の知識を統合し、**経営戦略・品質管理・安全管理・情報管理・人的資源管理**などの管理技術を問う、技術士資格の最上位部門です。

## 資格位置づけ

| 項目 | 内容 |
|---|---|
| **資格名** | 技術士（総合技術監理部門）（Comprehensive Engineering Management） |
| **位置づけ** | 技術士21部門の統括部門（最高難度） |
| **試験体制** | 2段階（第一次試験・第二次試験） |
| **受験者数** | 年700～1,000人程度（全部門比では小規模） |
| **合格率** | 約20～25%（第二次試験） |

## 受験資格（第二次試験）

以下のいずれかに該当する必要があります：

1. **第一次試験合格者** 
   - いかなる技術部門でも可

2. **技術士補** 
   - APEC エンジニア登録者含む

3. **認定実務経歴者**
   - 総合技術監理部門の場合、技術管理職としての実務経験が必要

## 試験構成の特徴

### 必須科目（選択不可）

5つの管理技術を必須で対策：

| 管理技術 | 出題形式 | 内容範囲 |
|---|---|---|
| **安全管理** | 択一式・論文式 | 労働安全衛生、事業継続計画、リスクマネジメント |
| **社会環境との調和** | 択一式・論文式 | 環境規制、社会コンプライアンス、SDGs対応 |
| **経済性** | 択一式・論文式 | コスト管理、品質・生産性の最適化、VE |
| **情報管理** | 択一式・論文式 | データセキュリティ、IT戦略、DX推進 |
| **人的資源管理** | 択一式・論文式 | 人材育成、組織構築、モチベーション管理 |

### 選択科目

20の技術部門（土木、機械、電気など）のいずれかから1科目選択：

- 建設部門、機械部門、電気電子部門など既存の21部門から選択
- 選択科目の内容は各部門の技術士二次試験と同一

## 試験難易度・対策期間

| 項目 | 目安 |
|---|---|
| **難易度** | ⭐⭐⭐⭐⭐（最難） |
| **合格までの勉強時間** | 600～1,000時間 |
| **推奨対策期間** | 6～12ヶ月 |
| **必須科目の対策** | 3～6ヶ月（5分野 × 毎日キーワード学習） |
| **選択科目+論文訓練** | 3～6ヶ月（過去問分析・答案作成） |

### 他資格との比較

```
総合技術監理部門 ⭐⭐⭐⭐⭐ ← ここ
├ 難易度は技術部門の2次試験と同等だが
├ 5分野の横幅が広く
└ 管理・経営知識が深い必要

1級土木施工管理技士 ⭐⭐⭐⭐
├ 学習範囲は限定的
├ 実務経験者向け
└ 出題予測しやすい

技術士（土木・建設など） ⭐⭐⭐⭐⭐
├ 総合技術監理と同じ難易度
├ ただし1分野に特化
└ 深い専門知識を問われる
```

## 受験をおすすめする人

- **複数技術部門の知識を持つ技術者**
  - 土木施工管理から経営層への昇進準備
  - プロジェクト統括職

- **経営視点が必要な職務**
  - 技術部門長
  - プロジェクト管理・建設管理の責任者

- **キャリアの集大成**
  - 技術士複数部門取得済み
  - 最終キャリア目標として技術士総合技術監理を志向
