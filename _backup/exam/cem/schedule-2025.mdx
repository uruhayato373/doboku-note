# 2025年度（令和7年度）技術士 総合技術監理部門 試験日程

## 📅 試験日程一覧

| 項目 | 日程 | 備考 |
|---|---|---|
| **受験申込期間** | **4月1日(火)～4月15日(火)17:00** | WEB受付のみ |
| **第二次試験（筆記試験）** | | |
| └ 必須科目 | **7月20日(日) 9:00～17:30** | 2時間択一 + 3.5時間論文 |
| └ 選択科目 | **7月21日(月・祝) 9:00～17:30** | 5.5時間（マークシート＋論文） |
| **口頭試験** | **12月～1月（予定）** | 受験者に個別通知 |
| **合格発表** | **9月上旬（予定）** | 公益社団法人 日本技術士会 HP |

## 受験申込の流れ

### Step 1: 申込前の準備（3月中）

```
□ 受験資格の確認
  └ 第一次試験合格者か、技術士補か、認定実務経歴者か
□ 選択科目の決定
  └ 20技術部門から1つ選択（土木、機械、電気など）
□ 本人確認書類の準備
  └ 運転免許証、パスポート、マイナンバーカード等
```

### Step 2: WEB申込（4月1日～15日）

1. **日本技術士会 試験情報サイト** にアクセス
   - URL: https://www.engineer.or.jp/

2. **「受験申込」ボタンから登録**
   - メールアドレス・パスワード設定
   - 個人情報入力（住所、生年月日、連絡先）

3. **受験資格情報を入力**
   - 第一次試験合格年度 または
   - 技術士補登録番号 または
   - 実務経歴書（写真付き）

4. **選択科目を選択**
   - 例: 建設部門、機械部門、電気電子部門など

5. **確認・決済**
   - 申込内容確認
   - 受験手数料： **12,500円**

### Step 3: 受験票受取（6月下旬予定）

- 郵送で受験票が届く
- 必ず本人確認書類と照合して確認
- 試験日に持参必須

### 口頭試験（12月～1月予定）

| 項目 | 内容 |
|---|---|
| **実施期間** | 令和7年12月～令和8年1月 |
| **実施地** | 東京都（予定） |

## よくある質問

### Q1: 第一次試験は何で合格すればいい？

複数の技術部門（土木、建築、機械など）のいずれでも構いません。ただし受験者の大半は土木系です。

### Q2: 選択科目は何を選ぶべき？

**おすすめ: 建設部門**
- 1級土木施工管理技士と親和性高い
- 実務経験で学習時間短縮可
- 過去問・テキスト・講座が豊富

他の選択肢:
- 機械部門（製造業出身）
- 電気電子部門（設計・施工担当）

### Q3: 受験手数料は？

**12,500円**（一括払い）
- クレジットカード、銀行振込に対応
- 申込時に即座に支払い

### Q4: 願書に記載する実務経歴は？

総合技術監理部門志願者の場合、**技術管理職**としての経歴を重視：
- プロジェクト監理者
- 工事担当者（安全管理・品質管理責任）
- 組織の管理職経験

単なる「施工技術者」では資格要件を満たさない場合があります。申込前に日本技術士会に相談。

### Q5: 試験当日に電卓は持込可？

**可能**です。ただし制限あり：
- 4則演算機能のみ
- グラフ機能・プログラミング機能は不可
- 計算が必要な問題は稀

### Q6: 受験地は固定？

筆記試験は国内複数会場で実施。申込時に最寄会場を選択できます（北海道、東北、関東、中部、近畿、中国、四国、九州）。

口頭試験は**東京都に統一**です。
