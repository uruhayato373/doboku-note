## Obsidianの使い方　- How to use obsidian

### 記法　- notation

- [[Obsidian Calloutの使い方]]

### プラグイン　- Plugin

インストールしているプラグイン。

| 名称                 | 概要                         |
| ------------------ | :------------------------- |
| [[Tag Wrangler]]   | タグペインからrenemaやmergeができる。   |
| [[Git]]            | obsidianをGitHubにバックアップできる。 |
| Advanced Tables    | 表をカスタマイズできる。               |
| Recent Files       | 最近開いたファイルの一覧を表示する。         |
| Auto Link Title    | リンクのタイトルを自動的に付与できる。        |
| Image Toolkit      | 画像表示の設定が可能。                |
| [[Auto Card Link]] | リンクをカード表示できる。              |
| [[iconize]]        | フォルダにアイコンを設定できる。           |
| [[PDF ++]]         | PDFに注釈できる                  |
| TaskNotes          | タスク管理できる                   |
