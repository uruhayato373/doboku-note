## 仕事外収入の構築（最重要）

55歳退職には金融資産だけでは不十分。**収入の柱を複数作る**必要がある。

### 収入の4本柱

```
柱1: 配当・分配金収入     → 年60〜100万円
柱2: コンテンツ収入       → 年60〜120万円
柱3: 技術コンサル・副業   → 年100〜200万円
柱4: 退職金 + iDeCo      → 一時金で住宅ローン完済
```

### 柱1: 配当・分配金収入

| 項目 | 詳細 |
|---|---|
| 投資先 | 高配当日本株（TOPIX高配当ETF）、J-REIT、米国高配当ETF（VYM/HDV） |
| 配当利回り目標 | 3.5〜4.5% |
| 55歳時の配当原資 | NISA成長投資枠 約600〜800万円 |
| 年間配当見込み | 約24〜36万円（非課税） |
| 追加：NISA外の高配当投資 | 退職金の一部を投入 → 年間配当40〜60万円 |
| **柱1合計** | **年60〜100万円** |

### 柱2: コンテンツ収入（今から育てる）

既に持っているプラットフォームを活用:

| プラットフォーム | 現状 | アクション | 目標収入 |
|---|---|---|---|
| **stats47** | 統計データ可視化サイト | SEO強化、広告収入 | 月1〜3万円 |
| **kazu-note (note.com)** | 断酒・筋トレ記事 | 有料記事・メンバーシップ | 月1〜3万円 |
| **doboku-note** | 土木技術ノート | 技術者向けニッチSEO | 月2〜5万円 |
| **技術書執筆** | 未着手 | 奥義ダイジェストの知見を書籍化 | 印税年10〜30万円 |
| **Udemy/技術講座** | 未着手 | 土木技術のオンライン講座 | 月1〜3万円 |

## リスクと対策

| リスク | 影響 | 対策 |
|---|---|---|
| 株価暴落 | 資産評価額の一時的減少 | インデックス長期保有で回復を待つ。55歳時に現金比率を上げる |
| 教育費の超過 | 私立理系・大学院進学 | 奨学金の活用、子どもにアルバイト推奨 |
| 病気・怪我 | 収入途絶 | 生活防衛資金200万＋就業不能保険 |
| 住宅ローン金利上昇 | 返済額増加 | 固定金利への借り換え検討 |
| 副業禁止 | コンテンツ収入不可 | 家族名義での運営、退職後に本格化 |
| インフレ | 生活費増加 | 株式投資はインフレヘッジになる |

## まとめ: 9年ロードマップ

```
46-48歳  基盤構築期    NISA・iDeCo開始、コンテンツ種まき
49-50歳  教育費ピーク  投資減額、貯蓄取り崩し（耐える期間）
51-52歳  回復期        投資再加速、コンテンツ収益化
53-54歳  全力投資期    最大限の資産積み上げ
55歳     セミリタイア  退職金でローン完済、週2-3日の技術コンサル
```

> [!tip] 最も重要なこと
> **完全な経済的自立（FIRE）は9年では難しいが、セミリタイア（好きな仕事だけする生活）は十分に実現可能。** 鍵は「教育費ピークを乗り切ること」と「コンテンツ収入を今から育てること」の2つ。
