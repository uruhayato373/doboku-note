##  １人ブラック企業の習慣はやめる

何がダメだったのか？という振り返りは、自分を責めるだけの毎日になってしまう。
自分にダメなところを直すのではなく、自分にあるものを探す。


## 目標設定はやめる

毎年毎年同じことを書くけど、まったく行動していない。[[memos/メモをとれば財産になる]]にも同じことが書いてあった。

自分のまだ見ぬ可能性は、目標に入れられない。

## とにかく書く

毎日書き出すことで言語化は上達していく。自分の「信念」と「固定観念」が見えてくる。　→　どんなメガネをかけているのか。




## 振り返るための７つのスキル

### 切り分ける

自分で変えられることか、かえられないことか

| 変えられること | 変えられないこと |
| ------- | -------- |
| 主観      | 出来事      |
| 自分      | 他人       |
| 行動      | 結果       |
| 未来      | 過去       |


### 意味づける

起きた出来事に価値・可能性を見出す　→　自分になにができるのか？どう行動できるのか？

### 絞る

何が自分にとって大切なのか
情報量が多いと人間は迷い、意思決定ができなくなる。　[[少なければ即ち得、多ければ即ち惑う]]


### つなげる

自分におきる出来事が、次にどうつながっていくのか？


### 抽象化

自分の特徴や傾向

出来事からの気づきや学び


### 具体化

行動できるように落とし込む

次はどうするのか？



### 新しいメガネにかけかえる

じぶんの認識、主観、固定観念

→　新しい考え方
