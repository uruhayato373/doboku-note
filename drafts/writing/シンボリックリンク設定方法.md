## projects/stats47 シンボリックリンク設定

`projects/stats47` は外部リポジトリ（stats47/docs）へのリンク。
OS間でパスが異なるため、**Git管理から除外**し、各端末で個別にリンクを作成する運用とした。

- `.gitignore` に `projects/stats47` を追加済み

### Mac（初回 or pull後にリンクが消えた場合）

```bash
cd ~/obsidian
ln -s /Users/minamidaisuke/stats47/docs projects/stats47
```

### Windows（設定済み）

管理者権限不要のジャンクション（/J）を使用。

```cmd
mklink /J C:\Users\m004195\obsidian\projects\stats47 C:\Users\m004195\stats47\docs
```
