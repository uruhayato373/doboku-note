# 第26条(有料の橋又は渡船施設の工事の検査）

1. 道路管理者が届出事項を遵守して事業を行うべきことは当然であるが、このうち工事方法に関する事項は、その実施の如何によって構造規格、工事費用、利用者の受益等の点に影響を及ぼし、ひいては事業の実施そのものを実質的に不適正ならしめるおそれがある基本的な事項であるので、本条では、特に工事に関する検査制度を設けたところである。したがって、その制度の趣旨において、国の負担金又は補助金が支出される事業について国土交通大臣が行う検査の制度(施行令第二十五条・第三十条）とは当然に異なるものがある(特別措置法第二十七条関係参照）。

2. 検査は「工事の途中において」及び「工事が完了した場合」に行われる。いわゆる中間検査及び完了検査である。中間検査は通常工事が相当程度進捗した段階で行われる。また完了検査は道路管理者からの検査の申請(施行規則第四条第二項)に基づいて行われる。

3. 検査は、当該橋又は渡船施設の構造及び施工方法について行われる(施行規則第四条第一項）。いずれも届出事項である工事方法の一部である。

4. 検査は、都道府県道については国土交通大臣、市町村道については都道府県知事が行う。

5. 検査の結果、適正でない点があれば、その是正の措置がとられる。特に当該橋又は渡船施設の構造が道路構造令に定める技術的基準に適合しないと認められるときは、「工事方法の変更その他必要な措置」をとるべきことを命ぜられる場合がある。この場合の「工事方法」は届出事項のそれではなく、現実に実施されている工事方法を意味するところはもちろんである。なお、この規定は法第七十五条第一項(法令違反等に関する監督)に対する特別規定であると解される。いずれの規定に基づく監督権限も同質のものではあるが、本条に基づく権限は特別の検査制度と一体として行使される点に意義がある。

6. 完了検査に合格した後でなければ、当該橋又は渡船施設の供用を開始することができない。この場合の供用の開始は、法第十八条第二項の規定による供用の開始であると解される。したがって、新設の場合はともかく、改築の場合で既に供用されているときは、あらためて本条の供用の開始を行う必要はないが、本項の趣旨から、完了検査に合格した後でなければ料金徴収を開始できないと解される（特別措置法第二十八条・第二十九条参照）。
