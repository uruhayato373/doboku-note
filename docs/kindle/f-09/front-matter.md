# はじめに

本書は、技術士第二次試験（総合技術監理部門）の必須科目（記述式）について、令和3年度から令和7年度までの5年分の問題を、都道府県または市の港湾課（港湾及び空港分野の発注・監督を担う立場）から解いた模範論文集です。各年度とも「A案：港湾施設（岸壁・防波堤）の維持管理・老朽化対策版」「B案：岸壁改良・水深増深事業版」の2バージョンを併記しており、5年分×2案で計10本の3,000字級フル論文を収録しています。

対象読者は、都道府県または市の港湾課・港湾事務所で港湾及び空港分野の発注・監督業務に携わり、総合技術監理部門の受験を予定している方です。既存の岸壁・防波堤の点検発注・補修工事・長寿命化計画の策定といった維持管理業務が中心の方はA案を、岸壁改良・水深増深・防波堤新設といった建設プロジェクトが中心の方はB案を、まずご自身の業務経験に近いほうから読み進めることを想定しています。

総合技術監理部門の必須科目は、経済性管理・人的資源管理・情報管理・安全管理・社会環境管理という5つの管理分野の視点から、自身の業務経験に基づいて論じる記述式試験です。毎年度テーマは変わりますが、問われる構成（現状の把握、近い将来の施策、より広い視点からの考察という三層構造が基本形。ただし令和5年度はSWOT分析・戦略立案という別形式）と、施策ごとに複数の管理分野にまたがるトレードオフを明示する要求は年度を通じて共通しています。本書はその年度ごとのテーマの違いに対して、港湾担当という一貫した立場からどう答案を組み立てるかを示すものです。

使い方としては、まず次章「自治体港湾担当の立場で総監記述式をどう書くか」で、この立場ならではの強み・頻出する管理分野の組み合わせを把握したうえで、続く「模範論文の読み方・活用ガイド」で答案の型と自分の業務への置き換え方をつかみ、本編（令和3〜7年度・各A案B案）を通しで読むという順序を推奨します。本書の論文はそのまま暗記して使うものではなく、ご自身が管轄する港湾施設の数・予算規模・組織体制・実際の事業内容に置き換えて再構成するためのテンプレートとして提示しています。

# 自治体港湾担当の立場で総監記述式をどう書くか

以下は、本書に収録した5年分・10本の論文に共通して現れる構成上の傾向を、実際の記述内容に基づいて整理したものです。

**経済性管理と安全管理の組み合わせが、維持管理・新設整備を問わず最も頻出する。** 港湾担当の業務は、岸壁・防波堤の水中部の点検や海上での出来形確認など、水中・海上という「目視も接近も困難な」環境での作業を伴う。このため潜水士による点検・確認を、水中ドローン（ROV）・AI画像解析・マルチビーム音響測深機といった技術で代替する施策が、5年分の論文でほぼ毎年繰り返し取り上げられている。この代替には導入費用・運用コストが発生する一方、潜水士の作業リスク（水中作業の事故・悪天候下の強行点検）を低減できるため、経済性管理と安全管理を対立させながら段階導入・費用対効果の可視化で折り合いをつける構成が定型になっている。他分野の担当者にはない「水中」という制約が、港湾担当ならではの論点の源泉になっている。

**経済性管理と社会環境管理の組み合わせは、カーボンニュートラル港湾化（CNP）と地域の利害調整の場面で立つ。** 港湾担当の業務には「物流機能の維持」と「カーボンニュートラル港湾化」という二重の目的が繰り返し設定されている。CNP形成（水素・アンモニア受入拠点の整備、荷役機械の電動化、洋上風力対応岸壁の整備等）は多額の投資を要し、採算の見込める大規模港湾に整備が集中する一方、地方港湾では投資が進まず取り残される構造的な対立を生む。また新技術の仕様書への義務化は、対応力の乏しい地元中小業者の入札参加を排除し競争低下・寡占化を招くリスクがあり、経済性管理（費用対効果・競争性の確保）と社会環境管理（地域産業の受発注機会・漁業者や港湾利用者との合意形成）のトレードオフとして繰り返し扱われている。

**情報管理と人的資源管理の組み合わせは、データ統合基盤の構築場面で立つ。** 点検データ・補修履歴・海象観測データ・AIS船舶動静データ・BIM/CIMモデルなど、港湾担当が扱うデータは種類が多く、これらを統合した情報プラットフォームやデジタルツインの構築が施策として繰り返し提案されている。しかしこうした基盤を発注者側で審査・運用できる職員が不足し、委託先の成果物を適切に評価できなければ品質を担保できないという課題が、情報管理と人的資源管理の対立として設定される。

**社会環境管理は、漁協・船社・物流事業者という港湾特有の利害関係者との調整として具体化する。** 損傷情報の外部公開に伴う保安リスク（テロ・破壊工作対策）と情報公開の要請の両立、浚渫や施設補修による漁業・航行への影響と合意形成、CO2削減効果の定量計算を誇張した場合の信頼失墜リスクなど、港湾特有の利害関係者を想定した社会環境管理の論点が各年度で具体的に描かれている。

**少子高齢化の文脈では、潜水士・非破壊検査技術者という専門資格保有者の枯渇が他分野以上に深刻な論点として設定される。** 潜水士等の資格は取得難度・身体負荷が高く若手への訴求力が限定的であるため、包括委託・広域連携・専門職コースの体系化といった施策が、経済性管理と人的資源管理のトレードオフとして描かれている。

**発注者としての権限を施策に織り込む。** 点検委託・工事発注仕様書への新技術要件の段階的義務化、総合評価落札方式での加点、港湾整備事業費補助・国土強靱化関連補助・カーボンニュートラルポート形成計画関連補助といった国の補助制度の活用、近隣港湾管理者との広域連携・データ共有プラットフォームの共同構築は、収録した10本の論文を通じて繰り返し登場する打ち手である。これらは発注者という立場だからこそ行使できる手段であり、総合技術監理の視点から見た「組織を俯瞰し具体的な権限で課題を動かす」姿勢を示す材料になる。

これらの傾向は、港湾担当という立場の業務実態（水中・海上という特殊な作業環境、物流機能維持とカーボンニュートラル港湾化の二重の目的、漁協・船社・物流事業者という特有の利害関係者、専門資格保有者の確保難）から必然的に導かれるものであり、他分野の担当者が同じテーマを論じる場合とは異なる管理分野の組み合わせになりやすい。自身の答案を組み立てる際は、まず自分の業務が維持管理寄りかA案、新設・改良寄りかB案かを見極め、経済性管理×安全管理を基本線としつつ、自分の実務でより強く経験している管理分野（社会環境管理での漁業者調整、人的資源管理での技術継承など）を厚く記述するとよい。

# 模範論文の読み方・活用ガイド

**答案構成の型**。収録した論文はいずれも、(1)取り上げる事業・組織の内容と現状（現在の取組状況・現在の課題を含む）、(2)近い将来（おおむね5年以内）に導入すべき施策を複数（多くは2つ）、(3)より広い視点からの考察、という三層構造で組み立てられている。ただし年度によって(3)の位置づけは異なり、取り上げた事業・組織の枠を超えた国としての施策を問う年度（令和6・7年度）、5〜10年後の将来技術を問う年度（令和3年度）、組織のSWOT分析と戦略立案という別形式を取る年度（令和5年度）がある。年度ごとの設問要求は本書の各章冒頭に問題文を再掲しているので、まず設問の型を確認してから論文本文を読むことを勧める。

**トレードオフの書き方**。(2)以降の設問では、多くの年度で「2つ以上の管理分野の視点を含めること」「解答欄にどの分野の視点かを明記すること」が明示的に求められている。収録論文はこの要求に沿って、各施策の効果と課題をそれぞれ異なる管理分野から記述し、施策を進める際に生じる管理分野間の対立（例：水中作業の安全性を高める技術導入がコスト増を招く、といった構造）を明示している。答案を書く際は、効果を書く管理分野と課題を書く管理分野をあえて変え、両者の対立関係を一文で示す練習をすると型が身につきやすい。

**A案・B案の使い分けと数値の置き換え**。A案・B案は同じテーマに対する2つの異なる業務背景（既存施設の維持管理と、岸壁改良・水深増深等の新設・改良プロジェクト）からの解答例であり、どちらか一方をそのまま覚えるのではなく、自分の実際の業務に近いほうを選び、管轄する港湾施設の規模・予算・組織の職員数・事業費といった数値を自分の職場の実態に置き換えて書き直すことを前提としている。前提条件を差し替えても、三層構造とトレードオフの明示という骨格はそのまま流用できる。

**採点者視点でのチェックポイントの使い方**。各年度の論文末尾には、その年度で採点者が確認すると考えられる要点を整理して付している。答案を書き終えたら、まずこのチェックポイントと照らして、要求されている要素（管理分野の明記、項目数の過不足、トレードオフの有無など）が抜けていないかを確認する使い方を想定している。
