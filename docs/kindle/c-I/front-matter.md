# はじめに

本書は、技術士第二次試験 建設部門 必須科目Iの過去問を令和3年度から令和7年度まで5年分、I-1・I-2の両問題（計10設問分）の模範解答を収録した演習書です。

必須科目Iは建設部門を受験するすべての者が解答する共通科目で、2問題（I-1・I-2）のうち1問題を選択し、答案用紙3枚・約1,800字以内で論述する形式です。試験時間は必須科目のみで2時間が割り当てられています。設問は毎年「(1) 多面的な観点から技術課題を3つ抽出する」「(2) 最重要課題に対する複数の解決策を示す」「(3) その解決策を実行しても生じるリスク、または波及効果・懸念事項とその対応策を示す」「(4) 技術者としての倫理・社会の持続性の観点から必要な要件を述べる」という4段構成で一貫しています。本書ではI-1・I-2それぞれについて、この4段構成に沿ったフル模範解答を収録しているため、本番でどちらの問題を選んでも対応できるよう両方を演習できる構成になっています。

模範解答は、公共工事の発注・監督業務に携わってきた合格者の視点から執筆しています。必須科目Iは国土交通白書や社会資本整備重点計画など行政の政策文書を出典とする出題が多く、技術的な解決策を並べるだけでなく「発注者としてどの施策を制度化し、誰の合意を得て進めるか」という行政実務の視点を答案に盛り込めるかが評価を左右します。本書の模範解答では、各設問に「発注者視点の核心論点」を明示し、この視点をどう論述に落とし込むかを具体的に示しています。

対象読者は、技術士第二次試験 建設部門の受験を予定しており、必須科目Iの答案の骨格・字数感覚・観点の立て方を過去問演習で身につけたい方です。通勤・通学時間などの隙間時間にスマートフォンやタブレットで読み進められるよう、設問ごとに区切って構成しています。

使い方としては、まず次章「この科目の出題傾向」で5年分の出題テーマと設問形式の変化を把握し、続く「学習ガイド」で答案構成の型と時間配分の考え方をつかんだうえで、本編（年度別のフル模範解答）を通しで読み、自分が学習中の年度・テーマと照らし合わせて答案構成の参考にする、という順序を推奨します。

なお、選択科目（II-1・II-2・III）の対策は必須科目Iと別の出題範囲となるため、本書には含まれていません。選択科目の各専門分野については、同シリーズの別冊で模範解答を収録しています。

# この科目の出題傾向（令和3〜7年度）

以下は本書に収録した過去問本文（試験問題・設問文）に基づく傾向であり、他年度の推測は含みません。

## 出題テーマの変遷

必須科目Iは毎年、性格の異なる2つの政策テーマがI-1・I-2として対になって出題されています。

令和3年度は「循環型社会の構築（建設廃棄物問題）」（I-1）と「激甚化・頻発化する風水害への対応」（I-2）、令和4年度は「インフラ分野のDX推進」（I-1）と「2050年カーボンニュートラル」（I-2）、令和5年度は「巨大地震対策と強靱な社会の構築」（I-1）と「社会資本メンテナンス第2フェーズ」（I-2）、令和6年度は「拠点連結型国土・社会資本整備」（I-1）と「大規模災害DX」（I-2）、令和7年度は「持続可能な建設業の実現」（I-1）と「経済成長の実現」（I-2）が出題されました。

5年間・10設問のテーマを大きく分類すると、「防災・災害対応」（令和3年度I-2の風水害、令和5年度I-1の巨大地震、令和6年度I-2の大規模災害DX）が3設問と最も多く出現しています。次いで「環境・脱炭素」（令和3年度I-1の循環型社会、令和4年度I-2のカーボンニュートラル）が2設問、「インフラ老朽化・維持管理」（令和5年度I-2、令和6年度I-1の一部）が関連する形で登場しており、令和7年度は「建設業の担い手・働き方」「経済成長と社会資本整備の意義」という、従来のインフラ技術課題とはやや異なる政策系テーマが新たに出題されています。DXは令和4年度・令和6年度にテーマそのものとして出題される一方、それ以外の年度でも解決策の具体策（BIM/CIM、ICT施工、AI画像診断、センサーによる遠隔監視等）としてほぼ毎年の模範解答に登場しており、テーマとしてだけでなく解決策の共通言語として定着している点が特徴です。

## 設問(3)の問い方の違い

設問(3)は年度・問題によって問い方が2種類に分かれており、この違いは答案の書き方に直結するため注意が必要です。

1つは「解決策を実行しても新たに生じうるリスクとその対応策」を問うリスク型で、令和3年度のI-1・I-2、令和4年度のI-2、令和5年度のI-1・I-2、令和6年度のI-2がこの形式です。もう1つは「解決策を実行して生じる波及効果と、専門技術を踏まえた懸念事項への対応策」を問う波及効果型で、令和4年度のI-1、令和6年度のI-1、令和7年度のI-2がこの形式です。令和7年度のI-1はさらに別の言い回しで「解決策に関連して新たに浮かび上がってくる将来的な懸念事項とその対策」を問うており、波及効果への言及なしに懸念事項のみを問う形式でした。

リスク型は解決策の負の側面（リスク）とその対応策を論じればよいのに対し、波及効果型は解決策がもたらすプラスの効果（波及効果）を先に示したうえで、そのうえで生じる懸念事項への対応策を論じる必要があります。同じ年度でもI-1とI-2で問い方が異なる場合があるため、本番では設問文の文言（「リスク」か「波及効果」か「懸念事項」か）を必ず確認してから解答構成を組み立てる必要があります。

## 観点明記の指示の明確化

課題抽出（設問(1)）において「観点を明記したうえで課題を示す」という要求は、令和3年度の設問文にもすでに「それぞれの観点を明記したうえで、課題の内容を示せ」という形で含まれており、5年間を通じて要求内容自体は一貫しています。一方、令和6年度・令和7年度の設問では、この要求が本文とは別に「（※）解答の際には必ず観点を述べてから技術課題を示せ」という独立した注記として重ねて明記されるようになりました。要求の中身が変わったわけではありませんが、直近2年は「観点→課題」という記述順序の遵守がより強く求められている点は、答案作成上の実務的な注意点として押さえておく必要があります。

## 字数配分の傾向

5年10設問のフル模範解答の総字数は、いずれも約1,540〜1,644字の範囲に収まっており、答案用紙3枚・約1,800字の上限に対して150〜260字程度の余裕を残す分量で構成されています。設問別の内訳をみると、設問(1)の課題抽出と設問(2)の解決策がそれぞれ330〜520字程度と字数配分の中心を占め、設問(3)は280〜400字程度、設問(4)の技術者倫理は10設問すべてで320字以内に収まり、4設問中もっとも短い配分となっています。

# 学習ガイド

**答案構成の型を固定する** 必須科目Iは「(1)課題3つの抽出（観点明記）→(2)最重要課題への複数の解決策→(3)リスクまたは波及効果・懸念事項への対応策→(4)技術者倫理・社会の持続性」という4段構成が5年間一貫しています。この型を先に体に染み込ませておけば、初見の政策テーマが出題されても骨格で迷わず書き始められます。特に設問(1)は「観点」と「課題」を分けて書く順序が明確に求められているため、「【観点：○○】○○という課題がある」という形で観点を先出しする書き方を徹底してください。

**時間配分の考え方** 必須科目Iの試験時間は2時間、答案用紙3枚・約1,800字以内です。まず問題選択（I-1かI-2か）に数分、続いて課題3つ・最重要課題・解決策・設問(3)（リスクまたは波及効果）・設問(4)（倫理）の骨子をメモ書きで固める構成メモの時間を20〜30分程度確保し、残り時間を清書に充てる配分が目安になります。設問(1)と(2)に字数の半分以上を割く年度が多いため、構成メモの段階でこの2問にどれだけの分量を割くかを先に決めておくと、後半の設問(3)(4)で時間切れになるリスクを抑えられます。

**設問(3)の文言を必ず確認する** 前章で述べたとおり、設問(3)は年度・問題によって「リスク」を問う形式と「波及効果＋懸念事項」を問う形式が混在しています。リスク型のつもりで波及効果型の設問に答えると、プラスの効果への言及が欠落した片手落ちの答案になります。本番では設問文の末尾（「リスクとそれへの対応策」か「波及効果と懸念事項への対応策」か）を必ず確認し、問われている内容に過不足なく答える意識を持ってください。

**発注者視点を答案に落とし込む** 必須科目Iは行政の政策文書（国土形成計画、社会資本整備重点計画、担い手3法改正等）を出典とする出題が多く、技術的な解決策だけでなく「発注者としてどの制度を設計し、どの予算・人員配分で実行し、誰との合意形成を経るか」という行政実務の視点が答案の説得力を左右します。本書の模範解答は、この視点を各設問の「発注者視点の核心論点」として明示しているので、答案作成時の着眼点として参照してください。

**頻出テーマから優先的に固める** 出題傾向で示したとおり、5年間で「防災・災害対応」が3設問と最も多く出題されています。学習の優先順位に迷ったら、まず防災・災害対応の3設問（令和3年度I-2、令和5年度I-1、令和6年度I-2）を通しで読み、課題抽出から解決策・リスク対応・倫理までの論理展開のパターンを掴むことを勧めます。そのうえで環境・脱炭素、インフラ老朽化・維持管理、DX、建設業の担い手・経済成長という残りのテーマ系統についても、それぞれ最低1設問は目を通し、初見の政策テーマが出ても同じ4段構成で対応できる状態を目指してください。
