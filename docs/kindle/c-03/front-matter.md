# はじめに

本書は、技術士第二次試験 建設部門「都市及び地方計画」選択科目の過去問を、令和3年度から令和7年度まで5年分・全15設問セット（選択科目II-1・II-2・IIIの3科目×5年度）にわたって収録した模範解答集です。

著者は地方自治体の土木職として都市計画・まちづくり関連業務の発注・監督に携わった経験を持ちます。本書の解答はコンサルタントとして受注する側ではなく、業務を発注し進行管理する側、すなわち行政（発注者）の立場から答案を組み立てている点が特徴です。制度の説明にとどまらず、「行政の担当責任者として何を調査し、誰と調整し、どう合意形成を図るか」という実務プロセスを答案の骨格に据えています。

選択科目には3つの出題形式があります。II-1は専門知識の応用能力を問う科目で、4設問から1問を選び答案用紙1枚（約600字）で解答します。II-2は問題解決能力を問う科目で、2設問から1問を選び答案用紙2枚（約1,200字）で解答します。IIIは課題遂行能力を問う科目で、2問題から1問を選び答案用紙3枚（約1,800字以内）で「課題3つの抽出→最重要課題への複数解決策→解決策実行後の残余リスク・懸念事項への対策」という3段構成で解答します。本書はこの3形式それぞれについて、出題された全設問の模範解答を収録しているため、本番でどの設問を選んでも対応できるよう準備できます。

対象読者は、技術士第二次試験 建設部門「都市及び地方計画」科目の受験を予定している方です。都市計画・まちづくり分野の技術士第二次試験は、都市計画法・都市再生特別措置法・都市緑地法・都市公園法・土地区画整理法など複数の法制度にまたがる知識と、それを行政実務にどう落とし込むかという応用力の両方が問われます。本書は次章の出題傾向分析でこの科目の骨格を把握したうえで、年度別の設問・論述方針・模範解答を通しで読み、自分の言葉で答案を再現する練習に使うことを想定しています。

なお、本書の模範解答は令和8年度に改訂された技術士コンピテンシー（データ・情報技術の活用、ステークホルダーとの合意形成、社会・経済・環境の三側面での持続可能な成果の追求）を踏まえて記述しています。これは特定年度の予想問題ではなく、今後の技術士第二次試験に共通して求められる評価軸であるため、本書は年度を問わず使える内容として構成しています。

# 出題傾向（令和3〜7年度）

以下は本書に収録した5年分・全40設問（II-1が4設問×5年度=20、II-2が2設問×5年度=10、IIIが2問題×5年度=10）の実際の出題内容を横断して読んだ傾向であり、本書収録範囲に基づく実測です。令和8年度以降の出題を予想するものではありません。

**防災・災害リスクへの対応は5年連続で出題されている**。R03のII-1-1（防災集団移転促進事業・土地区画整理事業による震災復興）、R04のII-1-1（立地適正化計画と特定都市河川浸水被害対策法による災害ハザードエリア規制）、R05のII-1-1（令和5年5月施行の宅地造成及び特定盛土等規制法）とII-2-1（立地適正化計画の防災指針案作成）、R06のII-2-2（広域避難地・地域防災拠点機能を持つ防災公園整備）、R07のII-1-1（日本海側半島地域の大規模地震災害からの持続可能な復興）まで、形を変えながら毎年出題されている。都市計画分野における防災は制度・計画・施設整備のいずれの切り口でも問われる中核テーマである。

**立地適正化計画（都市再生特別措置法）は複数年度・複数形式にまたがる頻出テーマである**。R04のII-1-1（災害ハザードエリアとの関係）とIII-1（コンパクト・プラス・ネットワークによる駅まち空間再構築）、R05のII-1-3（都市機能誘導区域・居住誘導区域の設定と誘導方法）とII-2-1（防災指針の追加）、R07のIII-1（人口減少地方都市における立地適正化計画の新規策定）と、II-1・II-2・IIIのいずれの形式でも取り上げられている。制度の基本構造（誘導区域の設定根拠・誘導手法・届出制度）を正確に説明できることに加え、防災・人口減少・公共交通といった個別課題と組み合わせて出題される傾向がある。

**民間活力の導入（PFI・Park-PFI・指定管理者制度）も5年連続で出題されている**。R03のII-2-2（廃校活用の事業推進、市所有権保持型PPP）、R04のII-2-2（競技場への指定管理者制度導入）、R05のII-2-2（都市公園法に基づくPark-PFIを活用した公園再整備）、R06のII-1-1（PFI事業の特徴と期待される効果）、R07のII-1-4（Park-PFIの法令上の特例措置）と、毎年いずれかの設問形式で出題されている。制度の仕組みの説明だけでなく、行政（発注者）が公募条件の設計・審査・モニタリングをどう担うかという実務プロセスが問われる。

**空き家・住宅団地の老朽化と再生は隔年ペースで出題されている**。R04のIII-2（高度成長期に開発された分譲マンション主体の大規模住宅団地の再生）、R05のIII-1（人口減少地方都市の空き家対策の充実・強化）、R07のIII-2（大都市郊外の戸建て住宅地を含む住宅団地の再生）と、III（課題遂行能力）の問題として繰り返し出題されている。いずれも「多面的な観点から課題を3つ抽出し、最重要課題への複数解決策と、実行後の残余リスクを示す」という共通の答案構成が求められる。

**緑地・グリーンインフラに関する制度知識も継続的に問われている**。R03のII-1-4（都市公園・生物多様性保全）、R05のIII-2（緑の基本計画改定とカーボンニュートラル）、R06のII-1-4（市民緑地契約制度と市民緑地認定制度の比較）と、都市緑地法に基づく複数の制度が個別に問われている。

**景観・歴史的資産の活用も3年度で出題されている**。R03のIII-2（歴史的資産を観光資源として活用する事業）、R04のII-2-1（歴史的風致維持向上計画に基づくまちなみ整備）、R07のII-2-2（旧街道沿いの宿場町における景観計画の新規策定）である。文化財保護・景観法・指定管理者制度など複数の法制度を横断して問われる点が共通する。

**土地区画整理・換地に関する実務知識も繰り返し出題されている**。R03のII-1-1（震災復興における土地区画整理事業）、R06のII-2-1（低未利用地の集約・共同化を目的とした小規模土地区画整理事業）、R07のII-1-2（換地計画における照応の原則・換地の定め方・決定手続き）である。

**データ・情報技術の活用は年を追って具体化している**。各年度の解答は人口動態データ・GISデータ・ハザードデータなどの活用を答案に反映しているが、R07のII-2-1では3D都市モデル（PLATEAU）を活用した駅前空間再構築という、より具体的なデータ基盤の活用が新たに出題されている。制度知識だけでなく、行政がどのデータをどう使って合意形成・意思決定を行うかという実務的な視点が年々明確に問われるようになっている。

# 学習ガイド

**出題形式ごとに答案の型を固定する**。II-1は「制度の正確な説明＋具体的な内容」を600字で簡潔にまとめる形式であり、法令の条文番号・制度名を正確に書けるかが得点を左右する。II-2は「調査・検討すべき事項→業務手順（留意点・工夫点）→関係者との調整方策」という3段構成が毎年共通しており、この型を先に暗記してしまえば、どの設問が出題されても骨格に沿って書き進められる。IIIは「多面的な観点からの課題3つ抽出→最重要課題への複数解決策→解決策実行後の残余リスク・懸念事項への対策」という3段構成で、文字数配分の目安は課題抽出に3割弱、解決策に4割強、残余リスクに2割強である。

**防災・立地適正化計画・民間活力導入の3テーマは優先して固める**。出題傾向分析で示したとおり、この3テーマはいずれも5年連続または複数年度・複数形式にまたがって出題されている。特に立地適正化計画は都市機能誘導区域・居住誘導区域の設定根拠や誘導手法など基本構造を正確に説明できることが前提になり、防災指針・災害ハザードエリア・コンパクトシティなど他のテーマとの組み合わせ問題にも対応しやすくなる。

**関係者調整は「グループ分けして具体的手法を書く」型で対応する**。II-2で共通して求められる関係者調整は、行政内部・鉄道事業者や道路管理者などの権限主体・住民や商業者・専門家といった形で関係者を3〜4グループに分類し、それぞれに対する具体的な調整手法（個別協議・説明会・ワークショップ・サウンディング調査等）を挙げる書き方が効果的である。

**行政（発注者）の立場を答案に明示する**。本書の模範解答が一貫して重視しているのは、コンサルタントとしての技術提案ではなく、行政の担当責任者として調査・発注・監督・合意形成をどう進めるかという視点である。受験者自身の実務経験が民間コンサルタント寄りであっても、「発注者は何を確認し、何を審査し、どう説明責任を果たすか」という視点を答案に加えることで、行政計画に関わる出題への対応力が高まる。

**時間配分の目安**。試験時間は選択科目全体（II・III）で3時間30分である。II-1（600字）に30分程度、II-2（1,200字）に60分程度、III（1,800字以内）に100分程度を目安に配分し、残り時間を見直しに充てる進め方が現実的である。設問選択は冒頭5分程度で全設問に目を通し、確実に骨格を書ける設問を選ぶことを優先する。
