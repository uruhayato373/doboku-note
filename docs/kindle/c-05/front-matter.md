# はじめに

本書は、技術士第二次試験 建設部門 選択科目「鋼構造及びコンクリート」について、令和3年度から令和7年度までの過去5年分・全設問の模範解答を収録した一冊です。

選択科目「鋼構造及びコンクリート」は、専門知識を問うII-1（答案用紙1枚・約600字、4設問中1設問を選択）、応用能力を問うII-2（答案用紙2枚・約1,200字、2設問中1設問を選択）、課題遂行能力を問うIII（答案用紙3枚・約1,800字、2設問中1設問を選択）の3区分で構成されます。本書は各年度・各区分について、本番でその年に実際に出題された設問をすべて掲載しています。II-1であれば4問全部、II-2であれば2問全部、IIIであれば2問全部という形で、令和3〜7年度の5年間に出題された全40設問（II-1が20問、II-2が10問、III が10問）を網羅しました。本番でどの設問が出題されても、まず「型」を思い出せる状態を作ることを目的としています。

模範解答は、鋼構造物・コンクリート構造物の発注・監督業務に携わった元公務員（発注者）としての実務経験に基づいて執筆しています。設計書の材料規格や検査基準の妥当性を確認する立場、施工計画書の品質管理項目を審査する立場、点検データを補修設計の根拠として活用する立場など、施工者・設計者とは異なる発注者ならではの着眼点を、可能な限り各設問の解答に反映しました。

本書は無料で公開しているウェブ記事の転載ではありません。この「はじめに」を含む出題傾向分析と学習ガイドは本書のために新たに書き下ろし、5年分を横断してはじめて見えてくる出題パターンを整理しています。

対象読者は、今後（本書の性質上、特定の年度を問わず）技術士第二次試験 建設部門「鋼構造及びコンクリート」を受験する技術者です。令和8年度からコンピテンシー（技術士に求められる資質能力）の改訂が予定されていますが、改訂後もデータ活用、ステークホルダーとの合意形成、社会・経済・環境の三側面を意識した成果という視点は、答案に厚みを持たせるうえで恒常的に有効な観点です。本書の模範解答は、この改訂後の視点も踏まえて執筆しています。

使い方としては、まず各設問の「論述骨子」（3本柱）で答案の骨格を把握し、次にフル模範解答で実際の文章化の水準を確認し、最後に「採点者が見るポイント」で自己採点の基準を持つ、という順序をおすすめします。答案そのものを丸暗記するのではなく、論理連鎖の組み立て方と発注者視点の着眼点を自分の実務経験に置き換えて答案を作る練習に活用してください。

# 令和3〜7年度 選択科目「鋼構造及びコンクリート」の出題傾向分析

本章の数値・分類は、本書に収録した令和3〜7年度・全40設問の問題文を実際に読み込んで集計したものであり、一般論や推測ではありません。

## II-1（専門知識、答案用紙1枚・約600字、4設問中1設問を選択）

| 年度 | II-1-1 | II-1-2 | II-1-3 | II-1-4 |
|---|---|---|---|---|
| R03 | 脆性破壊・疲労破壊の特徴と防止 | 高力ボルト接合（摩擦・支圧） | 高強度鉄筋・コンクリートの特性 | 非破壊検査（既設ひび割れ調査） |
| R04 | 防食機構と劣化対処 | 鋼部材の座屈 | 混合セメント（高炉・フライアッシュ）の特徴 | 充填不良の発生原因と対策 |
| R05 | 鋼部材の損傷（腐食・疲労き裂・変形）と補修 | き裂の非破壊検査 | プレキャスト工法の設計留意点 | 寒中コンクリートの品質確保 |
| R06 | 溶接欠陥 | 応力-ひずみ曲線と機械的性質 | コンクリート変状（ASR・塩害・火害） | 温度ひび割れ |
| R07 | 座屈現象 | 高力ボルト摩擦接合（ボルトの種類） | 暑中コンクリート | 機械式定着 |

5年分を並べると、**設問番号の位置と分野の対応が完全に固定**されていることが確認できます。II-1-1とII-1-2は5年間すべてで鋼構造分野（破壊・損傷・座屈・溶接・接合）、II-1-3とII-1-4は5年間すべてでコンクリート分野（材料・変状・品質管理・特殊工法）が出題されており、この対応関係に例外はありません。本番でどちらか一方が得意であれば、II-1-1・II-1-2かII-1-3・II-1-4のどちらかを重点的に固めるだけで、4設問中1設問を選ぶという出題形式に対して合理的な学習配分ができます。

分野内の内訳を見ると、鋼構造分野では「破壊・損傷・座屈・溶接欠陥」に類する力学的な劣化・損傷メカニズムを問う設問が5年連続でII-1-1に配置されています（R03脆性破壊・疲労破壊、R04防食機構、R05損傷と補修、R06溶接欠陥、R07座屈）。高力ボルト接合はR03・R07の2年度で出題され、いずれもII-1-2の位置です。

コンクリート分野では、施工時の品質管理（調合・打込み・養生・寒中/暑中施工）に関する設問がR04（充填不良）・R05（寒中コンクリート）・R07（暑中コンクリート）の3年度でII-1-4に、コンクリートの劣化・変状メカニズム（ASR・塩害・混合セメントの特徴・非破壊検査によるひび割れ調査）に関する設問がR03・R04・R06の3年度で出題されています。プレキャスト工法（R05）、機械式定着（R07）のように、特定の工法・部材に着目した設問がII-1-3の位置に単発で出題される年度もあります。

## II-2（応用能力、答案用紙2枚・約1,200字、2設問中1設問を選択）

| 年度 | II-2-1 | II-2-2 |
|---|---|---|
| R03 | 接合部・打継ぎ部の不具合再発防止 | 老朽化構造物の耐震補強 |
| R04 | 工期短縮の技術的工夫 | 突発的作用（火災・衝突）後の調査・部材再利用 |
| R05 | 超過外力に対する冗長性・復旧性の確保 | 点検困難部の損傷推定と健全性評価 |
| R06 | 施工計画変更時の安全性再検討 | 改築・改修・補強時の不具合・不整合対応 |
| R07 | 耐久性確保の検討 | 大規模地震で損傷した構造物の恒久復旧計画 |

II-2もII-1と同様に、**設問番号の位置と局面が5年間一貫して固定**されています。II-2-1は5年間すべてで新設・計画・設計段階のテーマ（接合部不具合の再発防止、工期短縮、超過外力への冗長性確保、施工計画の見直し、耐久性確保の検討）、II-2-2は5年間すべてで既設構造物の維持管理・災害後対応のテーマ（耐震補強、突発的作用後の調査、点検困難部の評価、改築改修時の不具合対応、大規模地震後の復旧計画）です。

なお、II-2の設問はいずれも「(1) 調査・検討すべき事項の説明」「(2) 業務手順とそれぞれの留意点・工夫点」「(3) 関係者との調整方策」という3項目の小問構成が5年間共通して使われています（設問文の細部は年度によって変わりますが、小問の骨格は同一です）。

## III（課題遂行能力、答案用紙3枚・約1,800字、2問題中1問題を選択）

| 年度 | III-1 | III-2 |
|---|---|---|
| R03 | 新材料・新工法の活用 | 予防保全型メンテナンス |
| R04 | 老朽化対策の優先順位付け | サプライチェーンマネジメント |
| R05 | 技術・技能の伝承と次世代育成 | 省力化・働き方改革に向けた業務効率化 |
| R06 | 老朽化インフラと維持管理配慮 | カーボンニュートラル |
| R07 | 供用中構造物の大規模補修・補強 | i-Construction2.0による生産性向上 |

IIIはII-1・II-2ほど設問番号と分野の対応が厳密ではありませんが、テーマの頻度には明確な傾向があります。「老朽化」「維持管理」「メンテナンス」に類するテーマは、R03（予防保全型メンテナンス）・R04（老朽化対策の優先順位付け）・R06（老朽化インフラ）・R07（供用中構造物の大規模補修・補強）の4年度・5年中4年度で出題されており、IIIの最頻出テーマです。このうちR04・R06・R07の3回はIII-1の位置に配置されています。

もう一方の設問は、その年の社会情勢・国の政策動向を反映したテーマが選ばれる傾向があります。R04サプライチェーンマネジメント、R05省力化・働き方改革、R06カーボンニュートラル、R07 i-Construction2.0による生産性向上と、脱炭素・DX・働き方改革・資材調達リスクといった、国土交通省の政策文書で扱われるトピックが並びます。このうちR05・R06・R07の3回はIII-2の位置に配置されています。技術者不足・人材育成（R05技術・技能の伝承）も、こうした社会情勢テーマの一種として捉えられます。

## 全体を通じた傾向

II-1・II-2は設問番号の位置と分野・局面の対応が5年間例外なく固定されている一方、IIIはテーマの入れ替わりがあるものの「老朽化・維持管理」が最頻出という骨格は変わりません。3区分を通じて共通するのは、鋼構造・コンクリートいずれの分野でも「メカニズムの説明」「調査・検討の視点」「設計・施工上の留意点」という論述の型が繰り返し求められる点です。次章の学習ガイドでは、この型を軸にした準備の進め方を示します。

# 学習ガイド

## 3区分の位置づけと時間配分

選択科目（II・III）は3時間30分（210分）の記述試験で、II-1（約600字）・II-2（約1,200字）・III（約1,800字）の合計約3,600字を書き上げます。文字数の比率で単純に配分すると、II-1に35分前後、II-2に70分前後、IIIに105分前後となりますが、実際には構成を考える時間（課題の抽出・骨子の組み立て）に文字数以上の比重がかかるため、答案作成の前に各区分でどのくらいの時間で構成メモを作れるかを演習段階で計測しておくことをおすすめします。特にIIIは「課題を3つ多面的に抽出する」「最重要課題を選んで理由を述べる」「新たなリスクを想定する」という3段の論理構成を答案用紙3枚に落とし込む必要があり、構成の組み立てに時間がかかりやすい区分です。

## 攻略の順序

前章の傾向分析を踏まえると、次の順序で準備を進めると学習の網羅性を効率的に確保できます。

1. **II-1の分野固定を利用する**: II-1-1・II-1-2は鋼構造、II-1-3・II-1-4はコンクリートという対応が5年間固定されているため、自分の実務経験が鋼構造寄りかコンクリート寄りかに応じて、どちらの2問を重点的に固めるかを早めに決めます。もう一方の分野も最低限の知識は押さえておくと、得意分野側の設問が難化した年度でも選択の幅が残ります。
2. **II-2の局面固定を利用する**: II-2-1は新設・計画・設計段階、II-2-2は既設構造物の維持管理・災害後対応という局面が5年間固定されています。自分が経験してきた業務局面（新設中心か、維持管理中心か）に合わせて、どちらの答案パターンを主軸にするかを決めます。「(1)調査・検討事項→(2)業務手順と留意点→(3)関係者調整」という3項目の骨格は年度が変わっても共通するため、この骨格に沿った答案の型を先に固めてしまうのが効率的です。
3. **IIIは老朽化・維持管理テーマを優先する**: IIIは5年中4年度で老朽化・維持管理系のテーマが出題されているため、この分野の課題抽出・解決策の引き出しを最優先で準備します。もう一方の社会情勢テーマ（脱炭素・DX・働き方改革・資材調達等）は、国土交通省の政策文書や年度ごとの白書のキーワードを押さえておくと対応の幅が広がります。

## 答案作成上の注意点

II-1は答案用紙1枚という制約の中で、専門用語の定義・メカニズムの説明・留意点を過不足なく書き切る訓練が必要です。本書の各設問には「求められていること」「論述骨子（3本柱）」を示しているため、まず骨子だけを自分で書き出してから模範解答と見比べる練習が効果的です。

II-2とIIIは、いずれも設問文の指示（小問構成）に忠実に答案を組み立てることが最重要です。特にIIIでは「課題」「解決策」「新たなリスク」を混同せず、指定された観点数（多くは3つ）を満たしているかを答案作成後に必ず見直してください。

いずれの区分でも、本書の模範解答に共通する「発注者視点」（材料証明書・試験記録・点検データの審査、施工計画書の妥当性確認など）は、実務経験に応じて自分自身の視点（設計者・施工者・調査者としての着眼点）に置き換えて答案に反映することをおすすめします。採点者は特定の立場を求めているわけではなく、実務に基づいた専門的な判断根拠が示されているかを見ています。
