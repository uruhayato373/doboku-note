# はじめに

本書は、技術士第二次試験 建設部門「河川、砂防及び海岸・海洋」選択科目について、令和3年度から令和7年度までの5年分・全15設問（各年度：選択科目II-1・II-2・IIIの3区分）の模範解答を収録した演習書です。

著者は河川・砂防・海岸・海洋分野の発注・監督業務に携わった元公務員（発注者）であり、本書の模範解答はいずれも工事や業務を発注する立場から審査・監督してきた経験に基づいて執筆しています。設計書や施工計画書を審査する側が何を確認し、何を論点として重視するかという視点は、答案作成において受験者が見落としがちな「採点者が実際に見ているポイント」を補う手がかりになります。

技術士第二次試験の選択科目は、II-1（専門知識、答案用紙1枚・4設問中1問選択）、II-2（応用能力、答案用紙2枚・2設問中1問選択）、III（課題解決能力、答案用紙3枚・2問題中1問題選択）の3区分で構成され、選択科目全体で3.5時間・答案用紙6枚を使って解答します。本書はこの3区分すべてについて、各年度に出題された設問を本番で選ばれなかったものも含めて全問収録し、フル模範解答と論述の骨格（求められていること・論述骨子・採点者視点の着眼点）を示しています。

対象読者は、技術士第二次試験 建設部門「河川、砂防及び海岸・海洋」を受験予定で、答案用紙1枚〜3枚それぞれの論述密度・時間配分の感覚をつかみたい方、他の受験生の再現答案だけでなく発注者側の視点を取り入れた模範解答を参照したい方です。

使い方としては、まず次章「この科目の出題傾向」で河川・ダム・砂防・海岸という4分野がどのような順序・頻度で出題されてきたかを把握したうえで、本編（年度別5章、各章II-1・II-2・III）を通しで読み、自分が弱い分野の設問を優先的に読み返す、という順序を推奨します。II-1は専門知識の正確さ、II-2とIIIは業務手順・課題抽出・解決策・リスク対応という論理構成そのものが問われるため、暗記ではなく「論述の型」を体得することを意識して読み進めてください。

# この科目の出題傾向（令和3〜7年度）

以下はいずれも本書に収録した15設問の本文に基づく傾向であり、他年度への推測は含みません。

## II-1（専門知識）：河川・ダム・砂防・海岸の4分野が毎年順番に出題される

II-1は4設問（II-1-1〜II-1-4）のうち1問を選ぶ形式ですが、5年分の設問を並べると、出題順序が令和3〜7年度のすべての年度で「II-1-1＝河川、II-1-2＝ダム、II-1-3＝砂防、II-1-4＝海岸・海洋」という同じ分野配置になっていることが分かります。この構成は5年間例外なく一貫しており、本番でどの分野を選ぶか事前に方針を決めやすい構造です。

**河川（II-1-1）** は、堤防・護岸という構造物そのものを問う設問（令和3年度：土堤のすべり破壊・パイピング破壊、令和5年度：土堤の利点欠点と余裕高、令和7年度：護岸の機能と安全性能照査）と、浸水想定・基本高水という計画論を問う設問（令和4年度：想定最大規模降雨等2種類の外力による浸水想定、令和6年度：河川の重要度と基本高水の設定）が交互に出題されています。構造（施設そのものの設計・破壊メカニズム）と計画（外力設定・想定区域）の両輪を押さえておく必要があります。

**ダム（II-1-2）** は5年間で毎回異なる切り口が出題されており、令和3年度はダム再生の技術的方策、令和4年度はダム総合点検と漏水計測データの分析、令和5年度は重力式コンクリートダムの構造設計、令和6年度はダム操作（異常洪水時防災操作・事前放流等）、令和7年度はダムのサイト選定と、計画・設計・点検・操作・維持管理というダム事業のライフサイクル各段階が年度ごとに一巡する形で出題されています。特定の切り口に絞らず、ダム事業の一連の流れを把握しておく必要がある分野です。

**砂防（II-1-3）** は、砂防堰堤の型式・安定計算という設計そのものを問う設問（令和3年度：透過型・不透過型の分類と安定計算、令和5年度：コンクリートスリット砂防堰堤の計画留意点）に加え、流木捕捉施設計画（令和4年度）、土砂災害の緊急調査（令和6年度）、砂防堰堤の除石計画（令和7年度）という維持管理・災害対応系の設問が令和4年度以降に増えており、設計知識だけでなく施設の維持管理・災害時対応まで出題範囲が広がっている傾向が見られます。

**海岸・海洋（II-1-4）** は、波浪観測とゼロアップクロス法による有義波算出（令和3年度）、設計高潮位の設定方法（令和4年度）、砂浜の防護機能と耐波性能（令和5年度）、津波浸水想定の設定（令和6年度）、海岸保全施設の面的防護方式（令和7年度）と、外力（波浪・高潮・津波）の設定から施設計画（砂浜・面的防護）まで幅広いテーマが出題されており、毎年異なる切り口で問われています。

## II-2（応用能力）：「業務を担当することとなった場合」という想定形式が一貫

II-2は2設問中1問を選ぶ形式で、答案用紙2枚を使い、(1)業務着手時に収集・整理すべき資料や情報、(2)業務を進める手順と留意点・工夫点、(3)関係者との調整方策、という3小問の構成が5年間すべての設問で共通しています。テーマは、インフラの老朽化（長寿命化）対策計画（令和3年度）、大規模地震発生時の防災施設被災対応（令和4年度）、総合的な土砂管理計画（令和5年度）、災害に強いまちづくり計画（令和6年度）、UAVを活用した被災状況把握（令和7年度）などが出題されており、いずれも「河川・砂防・海岸・海洋のいずれかの分野を対象として」自分で分野を選択したうえで業務手順を論じる形式です。維持管理計画、災害時の初動対応、住民・関係機関との合意形成、新技術（UAV・センシング等）の活用という切り口が繰り返し登場しています。

## III（課題解決能力）：新技術活用・既存ストック活用・複合災害対応が繰り返し軸になる

IIIは2問題中1問題を選ぶ形式で、答案用紙3枚を使い、(1)多面的な観点から課題を3つ抽出、(2)最重要課題への解決策、(3)解決策実行後の波及効果とリスク対応、という3小問の構成が5年間共通しています。テーマは、水防災分野の遠隔化（令和3年度）、地震・津波センシング情報の活用（令和3年度）、防災まちづくり（令和4年度）、気候変動と既存ストック活用（令和5年度）、大規模地震と複数災害への事前防災対策（令和6年度）、流域治水（令和6年度）、持続可能なインフラメンテナンス（令和7年度）、総合土砂管理（令和7年度）と、新技術・DXの活用、既存インフラの維持管理・長寿命化、複数の災害リスクを組み合わせた総合的な防災対応という3つの軸が年度をまたいで繰り返し出題されています。

なお、令和8年度からは技術士に求められる資質能力（コンピテンシー）の改訂が予定されており、点検・観測・センシングデータの活用、住民・関係機関との合意形成、社会・経済・環境の三側面での持続可能な成果という観点がこれまで以上に重視される見込みです。本書の模範解答は、この改訂後のコンピテンシーを踏まえた論述構成で執筆しています。

# 学習ガイド

**分野配置を先に決めておく**　II-1は「河川→ダム→砂防→海岸・海洋」という分野配置が固定されているため、本番でどの分野を選ぶか事前に方針を持っておくと迷いが減ります。得意分野が河川なら常にII-1-1を検討する、といった形で選択の軸を決めておくと、答案構成に充てる時間を確保しやすくなります。

**答案用紙の分量に合わせて論述密度を変える**　II-1は答案用紙1枚（約600字）で1つの専門知識を過不足なく説明する密度、II-2は答案用紙2枚（約1,200字）で業務手順を3小問に分けて体系的に展開する密度、IIIは答案用紙3枚で課題抽出・解決策・波及効果という論理の連鎖を組み立てる密度が求められます。本書はいずれの区分もこの分量に沿って模範解答を示しているので、まず分量の感覚を体で覚えることを優先してください。

**「求められていること」を最初に言語化する**　いずれの区分でも、設問文には解答すべき小問が明示されています。答案を書き始める前に、求められている論点を箇条書きで洗い出し、抽出漏れがないか確認する習慣をつけると、採点者が見る「論点の網羅性」を落とさずに済みます。

**II-2・IIIは3本柱の論理構成で組み立てる**　II-2は「収集情報→業務手順→関係者調整」、IIIは「課題抽出→解決策→波及効果とリスク対応」という決まった論理の型があります。本書の各設問には「論述骨子（3本柱）」を明記しているので、まずこの型に自分の知識を当てはめる練習から始めると、限られた時間内で答案の骨格を安定させやすくなります。

**時間配分の目安**　選択科目は3.5時間で答案用紙6枚（II-1：1枚、II-2：2枚、III：3枚）を仕上げる必要があります。構成検討に全体の3割程度、残りを執筆に充てるのが一般的な目安です。特にIIIは3枚と分量が多いため、課題抽出の段階で時間をかけすぎず、早めに執筆へ移る時間感覚を過去問演習で身につけておくことを勧めます。
