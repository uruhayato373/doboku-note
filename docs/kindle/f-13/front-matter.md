# はじめに

本書は、技術士第二次試験（総合技術監理部門）必須科目（記述式）の令和3年度から令和7年度までの5年分すべてに対し、建設コンサルタント会社の道路・橋梁設計部門でプロジェクトマネージャーとして発注者折衝・品質管理・協力会社管理を担ってきた経験を題材にした模範論文集です。

総合技術監理部門の必須科目は、受験者自身が経験した事業・組織を取り上げ、経済性管理・人的資源管理・情報管理・安全管理・社会環境管理という5つの管理分野の視点からトレードオフを整理して論じる記述式試験です。出題テーマは年度ごとに変わりますが（データ利活用・DX推進・SWOT分析と戦略立案・カーボンニュートラル・少子高齢化）、建設コンサルタントとして道路・橋梁分野を受託してきた経験者にとって、書ける論点とトレードオフの型には共通するパターンがあります。本書はその型を、5年分の実際の答案を通じて示します。

各年度の模範論文は、いずれも次の2パターンを併記しています。

- **A案：橋梁点検・補修設計業務版（既存施設管理型）** — 発注者から受託した橋梁群の定期点検結果を分析・評価し、補修工法の選定と補修設計図書の作成、長寿命化修繕計画の策定支援を担う立場から書いた答案
- **B案：道路設計・4車線化検討業務版（改良型）** — 2車線区間の4車線化などの改良事業を対象に、交通需要分析・道路構造検討・詳細設計図書の作成・住民説明支援を担う立場から書いた答案

同じ道路・橋梁設計部門でも、既存施設の維持管理を軸にした業務を担うか、新設・改良系の設計業務を担うかで、書きやすい経験や事例は変わります。本書は両方の答案を年度ごとに収録することで、自分の実務により近い側を選んで読み進められる構成にしています。

対象読者は、建設コンサルタント会社で道路設計・橋梁設計・維持管理計画策定のいずれかの実務経験を持ち、総合技術監理部門の記述式受験を予定している方です。本書に収録した答案例をそのまま暗記して使うのではなく、次章で示す受注者コンサルという立場ならではの論点の選び方と、続く章の答案構成の型を理解したうえで、自分が実際に携わった業務の規模・組織体制・発注者・経験事例に置き換えて再構成する土台として使うことを想定しています。

使い方としては、まず次章「道路橋梁コンサルの立場で総監記述式をどう書くか」で、この立場が5管理のうちどこで強みを発揮しやすく、どこが発注者側とは異なる制約として現れるかを把握し、続く「模範論文の読み方・活用ガイド」で答案の構成の型と自分の経験への置き換え方をつかんだうえで、本編（年度別5章、各章A案・B案）を通しで読み、自分の志望テーマ・志望年度に近い答案から重点的に読み込む、という順序を推奨します。

# 道路橋梁コンサルの立場で総監記述式をどう書くか

5年分・10パターン（各年度A案・B案）の答案を通して見ると、道路橋梁コンサルという立場には、5管理のうち直接コントロールできる分野と、発注者側の制度・慣行という外部要因として扱わざるを得ない分野に、明確な線引きがあります。

**経済性管理は、業務費・受注単価・投資回収という、受注者コンサルが自らの意思決定として扱える中核分野です。** 令和3年度A案では、AIモデルの開発・更新費用を単発受注では回収しづらいため複数業務への横展開でコストを分散する事業計画が課題として挙げられ、令和5年度A案戦略1では受注単価の維持と投資回収計画を財務計画に明示する構成になっています。令和6年度A-1施策では「環境設計費」という業務単価区分を発注者仕様書に提案することでCO2管理の工数を費用として適正計上する克服策が示され、令和7年度施策A-1では、AI学習データの整備コストが中小コンサルには過重な負担になりうる点がトレードオフとして扱われています。いずれも「発注者から与えられた予算の範囲でやりくりする」のではなく、業務計画書・見積書・仕様書提案という受注者側の権限で費用構造そのものを組み替える論点が中心です。

**人的資源管理は、技術者不足・育成・協力会社管理という形でほぼ全年度に一貫して現れます。** 令和3年度A案では熟練技術者の退職や協力会社のキャパシティ不足による業務品質維持のリスクが、令和4年度A案・B案ではBIM/CIM習熟技術者への業務集中と二重運用の常態化が、令和5年度A案・B案では上位有資格技術者への依存とその育成プログラムが、令和7年度A案では少子化による理工系人材の絶対数減少とベテラン診断技術者の退職加速が、それぞれ課題として設定されています。令和7年度A案の「診断技術アドバイザー制度」（退職予定の上席技術者を業務委託で継続参画させる仕組み）は、この立場に特有の技術継承の工夫の一例です。協力会社を含めた体制全体を組み替えられる受注者側の裁量が、他の立場では代替しにくい強みになっています。

**情報管理は、点検データ・BIM/CIMモデル・クラウド共有基盤という具体的なデータ資産を軸に、毎年中心的な論点になっています。** 令和3年度A案では点検写真と設計図・補修履歴が別システムに孤立している課題からBIM/CIM統合による発注者・協力会社間のデータ連携へ、令和5年度A案では10年以上蓄積した点検履歴データベースを組織の強み（S1）として位置付ける構成になっています。同時に、令和3年度B案ではETC2.0プローブデータの個人情報保護、令和7年度施策A-2ではクラウド共有に伴う情報漏洩対策とアクセス権限の層別管理が課題として扱われ、「データ資産の蓄積・活用」と「情報漏洩・セキュリティ対策」の両立が繰り返されるトレードオフの型になっています。

**安全管理は、点検作業そのものの安全性よりも、AI・デジタル技術による判定精度と発注者の信頼確保という形で現れる年度が多く、他の3分野に比べると答案の主軸には据えにくい分野です。** 令和3年度A案方法2では、BIM/CIMモデルの属性情報を施工会社が誤って信頼すると施工ミスに直結するリスクへの二重確認体制が、令和6年度A案施策A-2では、AI点検の判定精度に対する発注者の信頼確保が「情報管理×安全管理」のトレードオフとして扱われています。安全管理を単独の主論点として展開するより、情報管理や人的資源管理と組み合わせた副軸として使う構成が、5年分を通じて一貫しています。

**社会環境管理は、発注者側の制度・予算慣行や住民合意形成という、受注者コンサルの努力だけでは動かせない外部要因として現れる年度がほとんどです。** 令和3年度A案では、継続支援サービス型の契約に対する管理責任の帰属・データ滅失時の補償など「契約上・法的に未整備な領域」が業界団体との協議が必要な課題として、令和4年度A案・B案では発注者の予算制度が単年度契約を原則とすることが業態変革の最大の障害として、令和7年度施策1では発注者側のDX対応能力の不均一さ（特に小規模自治体の人員・予算・ITリテラシー不足）が挙げられています。自治体・発注者が誘導・規制の権限を直接持つ立場とは異なり、受注者コンサルは提案・働きかけを通じて制度側を動かす立ち位置になる点が、社会環境管理の書き方における最大の違いです。

まとめると、道路橋梁コンサルの答案は「経済性管理（業務費・投資回収）と人的資源管理（技術者育成・協力会社管理）を軸に、情報管理（データ資産の蓄積とセキュリティ）を組み合わせ、発注者側の制度的制約（社会環境管理）にどう働きかけるかを克服策として示す」という型で一貫しています。5年分の採点者視点チェックポイントに共通して現れるのは、受注者としての権限（業務計画書への仕様明記、標準成果物仕様の提案、総合評価落札方式の加点要件への対応、業界団体・国土交通省との制度化協議）を施策に必ず織り込み、「発注者に依存するだけでなく自ら制度化を働きかける立場」を示すことです。この型は出題テーマが変わっても再現性が高く、本書収録の5年分いずれの答案でも共通して確認できます。

# 模範論文の読み方・活用ガイド

**答案構成の型を年度ごとに把握する** 令和3年度・令和6年度・令和7年度は、いずれも「現在の状況・取組と課題」→「近い将来（概ね5年以内）に導入する2つの施策（5管理のうち2つ以上を明記）」→「より遠い将来、または事業・組織の枠を超えた国としての施策」という三層構造で共通しています。一方、令和4年度は「デジタル技術の利用の変遷」→「DXとしての取組」→「13週タスクフォースによる5か年DX推進計画」という設問固有の構成、令和5年度は対象が事業・プロジェクトではなく「組織」に切り替わり、SWOT分析（強み・弱み・機会・脅威を各2項目）からS×O・W×O・W×Tのクロス戦略を3本立案する構成になっています。同じ道路橋梁コンサルという立場でも、年度によって答案の骨格そのものが異なる点は、読み進める前に必ず押さえておく必要があります。

**A案・B案は自分の実務に近い方を土台に選ぶ** A案（橋梁点検・補修設計業務）は定期点検結果の分析・補修工法選定・補修設計・長寿命化修繕計画の策定支援が実務の中心である場合に、B案（道路設計・4車線化検討業務）は交通需要分析・道路構造検討・詳細設計図書の作成・住民説明支援が実務の中心である場合に、それぞれ土台として使いやすい構成です。両方を読み比べ、自分の経験でより具体的なエピソードを書ける側を選ぶことを推奨します。

**数値・組織設定は自分の所属先に置き換える** 本書の答案は、対象橋梁数・業務期間・業務費・担当技術者数といった業務や組織の規模を具体的な数値で設定していますが、これは答案に具体性を持たせるための例示です。そのまま暗記するのではなく、自分が実際に担当した（あるいは経験した）業務の規模・体制・発注者に置き換えて書き直すことを前提にしてください。

**施策のアイデアは自分が実際に検討・経験したものに寄せる** 本書の施策（AI損傷診断・点群データ活用、BIM/CIMによるデータ統合、ETC2.0プローブデータによる需要予測の高精度化など）は、道路橋梁コンサルが書きやすい論点の一例です。試験本番では、自分が実際に検討したことがある取組、あるいは自分の所属先で導入が議論されている取組に寄せて書き直す方が、具体性と説得力が増します。答案の骨格（現状の課題設定→施策→トレードオフの明示→克服策）だけを流用し、中身は自分の経験で埋め直す使い方を想定しています。

**採点者視点のチェックポイントは年度を超えて共通する** 本書の各年度の末尾には、その年度固有の注意点に加えて、次の3点がほぼ毎年共通して挙げられています。第一に、施策ごとに5管理のうち2つ以上の視点を解答欄に分野名を明記して記述すること（多くの年度で必須要件として明示されており、書き漏らしは減点事由になりやすい点です）。第二に、受注者コンサルとしての権限（業務計画書への仕様明記、標準成果物仕様の提案、総合評価落札方式の加点要件への対応、業界団体・国土交通省との制度化協議）を施策の具体策に必ず織り込むこと。第三に、トレードオフを「対立の指摘」で終わらせず、両立させるための克服策まで書き切ることです。この3点は、テーマが変わっても答案の骨格として毎年繰り返し求められています。
