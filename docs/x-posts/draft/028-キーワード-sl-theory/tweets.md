## Tweet 01: 定義編

【総監キーワード解説】SL理論 #1

SL理論（状況対応型リーダーシップ）とは、部下の「成熟度（Maturity）」に応じてリーダーシップスタイルを変えるべきという理論。

Hersey & Blanchard が1969年に提唱。

「最善のリーダーシップは1つではない」が前提。部下の発達段階を診断し、適切なスタイルを選ぶことが管理者の役割。

## Tweet 02: 4スタイル×成熟度編

【総監キーワード解説】SL理論 #2

成熟度（M1〜M4）とリーダーシップスタイル

M1（能力低・意欲高） → S1：指示型（高タスク・低関係）
M2（能力低・意欲低） → S2：コーチング（高タスク・高関係）
M3（能力高・意欲低） → S3：参加型（低タスク・高関係）
M4（能力高・意欲高） → S4：委任型（低タスク・低関係）

成熟度が上がるにつれ指示を減らし、自律性を高めるのが基本方向。

## Tweet 03: 実践適用編

【総監キーワード解説】SL理論 #3

SL理論の実践での落とし穴

▼ 新入社員（M1）に委任はNG
  → やる気はあっても能力不足。指示型で丁寧に導く

▼ ベテラン（M4）に細かい指示はNG
  → マイクロマネジメントでモチベーション急落

▼ 成熟度は「業務ごと」に変わる
  → 同じ人でも新しい業務ではM1に戻る

「あの人は優秀だから放置」が最も危険なエラー。

## Tweet 04: 試験頻出ポイント編

【総監キーワード解説】SL理論 #4

試験で狙われる 3 つのポイント

1. M4 → S4（委任型）は「低関係」だが「無関心」ではない
   → 信頼委任であり、節目のフィードバックは必要

2. M2 の「能力低・意欲低」にはコーチングが有効
   → 指示（タスク）と支援（関係）の両方が必要

3. PM理論との比較
   PM理論：「高P高M を目指す」（普遍）
   SL理論：「状況によって切り替える」（条件適応）
