## Tweet 01: 定義編

【総監キーワード解説】KYT #1

KYT（危険予知訓練）とは、作業や職場に潜む危険要因を発見・解決する能力を高める小集団訓練。

Kiken（危険）Yochi（予知）Training（訓練）の頭文字。

1974年に住友金属工業で開発。建設・製造・医療・交通など幅広い分野で活用される「ゼロ災運動」の中核手法。

## Tweet 02: 4ラウンド法編

【総監キーワード解説】KYT #2

KYT 基礎4ラウンド法（4R法）

1R：現状把握「どんな危険が潜んでいるか」
  → 危険要因を自由に洗い出す（否定しない）

2R：本質追求「これが危険のポイントだ」
  → 最も重要な危険に絞り込む（◎印）

3R：対策樹立「あなたならどうする」
  → 具体的な対策を発案

4R：目標設定「私たちはこうする」
  → チームの行動目標を宣言（指差し呼称で締め）

## Tweet 03: 効果と限界編

【総監キーワード解説】KYT #3

KYT の効果と限界

▼ 効果
・危険感受性の向上（見えない危険を「見える化」）
・集団の安全意識・コミュニケーションの活性化
・ハインリッヒの法則のヒヤリハット削減に直結

▼ 限界・注意点
・形式的な実施では効果ゼロ
・全員が発言できる心理的安全性が前提
・危険要因を継続的に更新する仕組みが必要
