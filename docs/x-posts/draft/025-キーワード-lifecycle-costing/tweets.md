## Tweet 01: 定義編

【総監キーワード解説】LCC（ライフサイクルコスト）#1

LCC とは、製品・設備・インフラを取得から廃棄・解体まで、全期間にかかるトータルコスト。

LCC = 取得費（初期コスト）
     + 維持管理費（運用・保守・修繕）
     + 廃棄・更新費

「安く買って高く維持」のワナを回避する経済性評価の基本。

## Tweet 02: LCCの内訳編

【総監キーワード解説】LCC #2

土木インフラ（橋梁等）の LCC 内訳の目安

  建設費：30〜40%
  維持管理費（50年分）：40〜50%
  解体・廃棄費：10〜15%

→「建設費は LCC の一部に過ぎない」

含まれるコストの例:
設計・調達費 / 設置・試運転費 / エネルギー費 / 定期点検・修繕費 / 更新・改修費 / 廃棄・撤去費

## Tweet 03: LCCとLCAの違い編

【総監キーワード解説】LCC #3

LCC vs LCA（混同注意）

▼ LCC（Life Cycle Cost）
  ライフサイクル全体の「コスト（金銭）」の評価
  → 経済性管理の手法

▼ LCA（Life Cycle Assessment）
  ライフサイクル全体の「環境負荷（CO₂・廃棄物等）」の評価
  → 社会環境管理の手法（ISO 14040）

LCC は「お金」、LCA は「環境」。総監では「経済性と環境性のトレードオフ」として両方がセットで問われる。

## Tweet 04: 引っかけポイント編

【総監キーワード解説】LCC #4

試験で狙われる 3 つのポイント

1. LCC は「建設費のみ」ではない
   → 維持管理費・廃棄費を含む全期間のトータルコスト

2. 「初期費用が安い = LCC が安い」は誤り
   → エネルギー費・修繕費が高ければ LCC は大きくなる

3. LCC vs LCA の混同
   → LCC = コスト / LCA = 環境負荷

将来コストを現在価値に割り引いて比較するのが正式な手法。
