# iOS 択一アプリ 試作方針 v1.0

最終更新: 2026-10-09（施工管理は種目ごとに分け、管工事は土木の反応を見て決める。§3.3）

> [!important] このドキュメントの位置づけ
> 過去問の択一を iOS アプリで試し、「作る手間・使い心地・App Store での反応」の感触を掴むための方針。2026-09-29 の運営者判断（総監・技術士・1級土木でまず試作）を受け、凍結中の iOS 仕様（backlog DN-0400）と [06_PWA過去問アプリ設計方針.md](./06_PWA過去問アプリ設計方針.md) のどこを引き継ぐかを決める。作業手順は backlog DN-0453 で持つ。

## 1. 結論

| 論点 | 決定 |
|---|---|
| 土台 | 06 の「資格別アプリ × 共通エンジン」と、Web 演習の正規化（`scripts/build-quiz-data.mjs` → `src/lib/quiz/types.ts` の共通スキーマ）をそのまま使う。DN-0400 の旧仕様は機能の候補としてだけ使う |
| アプリの単位 | 資格の系統でまとめる。**技術士**（第一次試験＋総監 択一）と**土木施工管理技士**（1級＋2級 第一次検定）。施工管理は種目ごとに別アプリにし、管工事・建築・電気工事は土木と混ぜない（§3.3）。アプリを開いたら試験を選ぶ |
| 出す順番 | 技術士アプリを第一次試験だけで先に出す（試験 2026-11-22）→ 総監をアップデートで足す → 土木施工管理技士アプリを 2027 年春に出す（2級前期は例年 6 月、1級は 7 月） |
| 作り方 | SwiftUI のネイティブアプリ。問題文・選択肢・解説だけ WKWebView で表示し、Web 版の数式 HTML と図をそのまま使う |
| 配信 | 無料・広告なし・アプリ内課金なし・日本のみ。計測は App Store Connect の標準分析だけ（分析 SDK を入れない） |
| 置き場 | アプリのコードは別リポジトリ（非公開）。問題データの生成はこのリポジトリ |

## 3. 試験の比較とアプリへのまとめ方（2026-10-09 時点）

| 項目 | 技術士 第一次 | 総監 択一 | 1級土木 第一次検定 | 2級土木 第一次検定 |
|---|---|---|---|---|
| 入れるアプリ | 技術士 | 技術士 | 土木施工管理技士 | 土木施工管理技士 |
| 手元の問題 | 1,830 問（基礎 470・適性 240・建設 560・上下水道 560） | 720 問（平成21〜令和8年度） | 1,162 問（12 年度） | 630 問（令和3〜7年度の前期・後期） |
| データの形 | 描画済みの数式 HTML・図あり | ほぼテキスト | テキスト中心・図 88 点 | テキスト中心・図 58 点 |
| Web 演習 | 公開中 | 未公開（正規化の対象外） | 公開中 | 未公開（正規化の対象外） |
| 次の試験 | 2026-11-22 | 2027 年 7 月（例年） | 2027 年 7 月（例年） | 2027 年 6 月の前期（例年） |
| App Store の競合 | 建設部門の専門科目アプリ ¥300（令和3〜5年度の 3 年分・★2.7／6 件）。基礎科目は別アプリ | 総監専用の択一アプリは見当たらない | TK office ¥1,600（18 年分 5,802 問・★4.5／381 件・最新版は 6 月 16 日）ほか、無料・監修付きなど複数。ドリルラボは 1級の第一次検定版を出していない | ドリルラボ「過去問ドリル」（12 回分・★4.7／443 件・全問は ¥1,870）ほか |

競合は 2026-10-09 に App Store の公開ページで確認した範囲。2026-05 時点の 17 本の横断調査は DN-0400 に残っている。

### 3.1 系統で 2 本にまとめる理由

06 §2 の「1 アイコン = 1 資格」は、受験者層が重ならない資格（1級土木と総監など）を混ぜないための原則。同じ人が順に受けていく系統（技術士は第一次→第二次→総監、土木は 2級→1級）なら、1 本にまとめたほうが次の試験へそのまま続けられる。系統をまたぐ技術士と土木は分ける。

- **審査**: 同じ作りのアプリを並べると、スパム（ガイドライン 4.3）扱いされることがある。ただし種目・級ごとに同じ作りのアプリを 13 本以上出している会社（ドリルラボ）もあり、中身が違えば分けても通る。まとめる主な理由は次の手間。
- **手間**: 審査・スクリーンショット・更新を 2 本分で済ませられる。2級土木 630 問もほぼ追加の手間なく載る。
- **収益化**: 有料にするときは、試験ごとにアプリ内課金で分けられる。

**代わりに失うもの**: アプリ名は 30 字なので、全試験名を名前に入れられない。「1級土木施工管理技士 過去問」で探す人には、試験名そのままの競合アプリより不利になりうる。サブタイトルとキーワード欄で補い、App Store の表示回数で確かめる（§6）。

### 3.2 出す順番の理由

- **技術士アプリを第一次試験で先に出す**: 試験が 6 週間後で、反応を見る機会が今年のうちに来る。競合は部門・科目ごとに分かれた 3 年分程度で、基礎・適性・専門を 15 年度分まとめて出せば収録量で勝てる。数式と図を含むので、ここで作った表示部品が全試験に効く。
- **総監をアップデートで足す**: テキストのみで、エンジンを変えずに試験設定とデータだけで載るかを確かめるのに向く。専用アプリが無い一方、受験者は年 3〜4 千人と少ない。7 月の試験に向けて 2027 年春までに足す。
- **土木施工管理技士アプリを 2027 年春に出す**: 2 本目のアプリを同じエンジンで作れるかを確かめる。1級は TK office が収録量・評価とも強いので、技術士アプリの反応を見てから差別化（図・解説の深さ・サイト記事との行き来）を決める。2級後期（2026-10-25）には間に合わない。

### 3.3 施工管理は種目ごとに分ける

| 種目 | 第一次の受験者（R7） | App Store の主な競合（2026-10-09） | 手元のデータ |
|---|---|---|---|
| 1級土木 | 47,715 人 | TK office（上表） | 1,162 問・全選択肢の解説付き |
| 2級土木 | 前期 14,030 人＋後期 24,556 人 | ドリルラボ（上表） | 630 問・全選択肢の解説付き |
| 1級管工事 | 23,826 人 | ドリルラボ「過去問ドリル」14 回分・★4.7／1,422 件・全問は ¥1,870・最新版は 9 月 1 日。ReCorrect「30日合格プログラム」¥1,800・約 250 問 | 問題 PDF 15 年度分（DN-0454）。構造化と解説はこれから |
| 2級管工事 | 前期 4,895 人＋後期 9,409 人 | ドリルラボ「過去問ドリル」16 回分・★4.6／1,032 件・全問は ¥1,870・2025 年度分を追加済みで最新版は 2026-10 上旬。ほかは 2023-05 で更新が止まった無料アプリ | 問題 PDF 11 年度分（DN-0454）。同上 |

競合はどれも種目ごと・級ごとの別アプリで、種目をまたいでまとめたアプリは見当たらない。

**種目で分ける理由**
- **受験者が違う**: 土木は道路・河川などの土木工事、管工事は建物の空調・給排水の設備工事で、勤め先の業種も分かれる。「受験者層が重ならない資格は混ぜない」という 06 §2 の原則がそのまま当てはまる。
- **探し方が種目名**: 受験者は「管工事 過去問」のように種目名で探す。名前 30 字に種目名を並べると、どの検索でも種目名そのままの競合に埋もれる。
- **まとめても手間が減らない**: 問題は種目ごとに別物で、エンジンは共通なので、分けても手間は増えない。

**管工事は土木の後に、反応を見て決める**: 「ダウンロードが多いのに更新が止まっている」のは 2級の古い無料アプリだけで、主力のドリルラボは 1級・2級とも評価 1,000 件超で更新も続いている。収録回数も手元のデータと同程度なので、収録量では勝てない。違いを出せるのは「全問無料・全選択肢の解説」だけで、それが有料の既存アプリに対して効くかは土木アプリで先に確かめられる（§6）。効くと分かり、DN-0454 で解説が揃ったら管工事アプリを作る。建築・電気工事も同じ扱い（1級建築は TK office が★4.7・評価約 700 件）。

**級はまとめたまま試す**: 競合は級ごとにも分けている。1級と 2級を 1 本にすると「2級土木施工管理技士」のような検索で不利になりうるので、級ごとの表示回数を見て（§6）、埋もれていたら分ける。

## 4. 作り方

### 4.1 方式

| 方式 | 採否 | 理由 |
|---|---|---|
| SwiftUI ＋ 問題表示だけ WKWebView | **採用** | 画面遷移・進捗・通知はネイティブで手触りを確かめられる。数式 HTML は KaTeX の CSS とフォントを同梱すれば JavaScript なしで表示できる |
| Web 版を包む（Capacitor など） | 不採用 | Web 版と同じ体験になり、iOS で何が変わるかを試せない。Web をそのまま包んだアプリは審査（ガイドライン 4.2 最低限の機能）で落ちやすい |
| React Native・Flutter | 不採用 | iOS だけで試すので利点が無い。数式表示は結局 WebView になる |

### 4.2 構成

```
doboku-note（このリポジトリ）
  scripts/build-quiz-data.mjs  … 既存の正規化。総監・2級土木をここへ足す
  iOS 向けの書き出し            … 正規化済み JSON に図を添えて、ID を検査して渡す
        │（JSON と図をアプリへ同梱）
        ▼
iOS リポジトリ（別・非公開）
  QuizEngine（Swift Package）  … 出題・採点・進捗・統計・画面・問題表示・試験の切り替え
  系統別アプリ（target）        … 技術士／土木施工管理技士。収録する試験の設定・アイコン・問題データだけを持つ
```

- 正規化は Web 演習と同じものを使い、iOS 用に別の変換を作らない。iOS 向けに足すのは図の同梱と ID の検査だけ。
- 進捗は問題 ID で持つ。ID が変わると学習履歴が消える（旧調査で低評価の原因になった例がある）ので、書き出し時に ID の重複と、前回から消えた ID があれば止める。
- 問題データはアプリに同梱し、更新はアプリのアップデートで配る。追加は年 1 回の新年度が主なので、サーバからの差分取得は作らない。
- 別リポジトリにするのは、Xcode の生成物・署名設定・アイコンをこのリポジトリの build と品質検査から切り離すため。

### 4.3 最初の 1 本に入れる機能

| 入れる | 今回は入れない |
|---|---|
| 初回に試験を選び、後から切り替えられる。進捗は試験ごとに分ける | 試験をまたぐ統計 |
| 年度別・科目別・ランダム 10／20 問・間違い復習 | ログイン・端末間同期 |
| 即時採点・全選択肢の解説 | 課金・広告 |
| 科目別の正答率と「続きから」 | AI 解説 |
| 試験日カウントダウン・任意のローカル通知 | サーバからのプッシュ通知・分析 SDK |
| 完全オフライン | iPad 専用レイアウト |
| サイトの元記事へのリンク・誤りの報告 | note 商品への購入導線 |

> [!warning] note の購入導線を入れない理由
> アプリ外でのデジタルコンテンツ購入への誘導は App Store 審査ガイドライン 3.1 の扱いで、日本ではスマホ新法の施行に合わせて条件が変わっている。試作では無料のサイト記事へのリンクに留め、収益化を決めるときに最新の規約を確かめる。

## 5. 配信の決め事

- 無料・広告なし・アプリ内課金なし。有料にするにはアプリ内課金の契約・銀行口座・税務情報の登録が要り、感触を掴む目的には要らない。Web 版の「全問無料」とも揃う。
- 配信地域は日本のみ。EU で配信すると、事業者として住所・電話番号の公開を求められる。
- 学習履歴は端末の中だけに置き、App Store のプライバシー表示は「データの収集なし」にする。サイトの `/privacy` にアプリの項目を足す。
- アプリ名は名前 30 字・サブタイトル 30 字・キーワード欄 100 字に検索語を振り分ける。案は「技術士 過去問」＋「第一次試験・総監 択一 全選択肢解説」、「土木施工管理技士 過去問 1級・2級」＋「第一次検定 全選択肢解説」。決めるのは運営者。

> [!important] 運営者が決めること・やること（Claude Code では代われない）
> - **Apple Developer Program の登録**（年 $99）。個人で登録すると App Store の販売者名に本名が出る。法人で登録するには D-U-N-S 番号が要り、日数がかかる
> - **Xcode の導入**。2026-10-09 時点でこの Mac は Command Line Tools だけで、`xcodebuild` とシミュレータが動かない。数十 GB 使うので先に `npm run check-disk-hygiene` で空きを確かめる。導入後の `sudo xcode-select -s /Applications/Xcode.app` はパスワードが要る
> - **実機確認**。TestFlight の内部テスト（App Store Connect のメンバー 100 人まで）は審査なしで自分の iPhone に入れられる
> - **過去問の転載条件の確認**（**未確認**）。日本技術士会・全国建設研修センターの過去問をアプリで配布してよいか。サイト掲載と同じ扱いで作り始めるが、App Store へ公開する前に出題元の利用条件を読む

## 6. 何をもって「感触」とするか

| 見るもの | 中身 | 取り方 |
|---|---|---|
| 作る手間 | 1 本目にかかった作業量。総監が試験設定とデータだけで載ったか。土木アプリを同じエンジンで作れたか | 作業記録 |
| 使い心地 | 運営者が実機で 1 週間使って出た違和感の数と中身 | TestFlight |
| App Store の反応 | 表示回数・製品ページ閲覧・初回ダウンロード・ダウンロード率・継続率（1 日・7 日） | App Store Connect の分析（継続率は共有に同意した端末だけ） |
| Web との関係 | 同じ期間の Web 演習の `quiz_start` | GA4 |

| まとめ方の当否 | 試験名・級で検索したときに表示されているか（とくに第一次試験・総監・2級を名前に入れきれない場合） | App Store Connect の検索語別の表示 |
| 全問無料の効き目 | 製品ページを見た人のうちダウンロードした割合。土木アプリで有料の既存アプリと並んだときに選ばれるか（管工事を作るかの判断材料。§3.3） | App Store Connect の分析 |

初回は目標値を置かず、基準値を取る。技術士第一次試験の後（2026-12）に、総監の追加と土木アプリの公開まで進めるか、有料にする価値を探すかを決める。未計測の項目を 0 や効果ありとして扱わない。

## 7. リスク

| リスク | 対策 |
|---|---|
| 同じ作りのアプリを並べると、審査でスパム（ガイドライン 4.3）扱いされることがある | 系統でまとめ（§3.1）、種目ごとのアプリは名前・アイコン・構成（科目・管理区分・分野）を変える |
| 試験前に間に合わない | 審査への提出は 2026-11-08（試験 2 週間前）を期限にする。過ぎたら技術士アプリは TestFlight 止まりにし、総監を足して 2027 年春に公開する |
| 1 本に試験を詰めて画面が分かりにくくなる | 最初に試験を選ばせ、選んだ試験以外は画面に出さない |
| 解説の誤りが残る（アプリは直すのに審査が要る） | 品質検査済みの Web 版データだけを使い、アプリ内に誤りの報告を置く |
| 初めての提出で差し戻される | 提出前にプライバシー表示・サポート URL・スクリーンショット・審査用メモを揃える。差し戻しの理由は記録して 2 本目に活かす |

## 8. 旧 iOS 仕様（DN-0400）との関係

- **引き継ぐ**: 試験日カウントダウンとリマインダー（旧調査で安く効果が大きいとされた）、今どこにいるかが分かる進捗表示（旧調査で他社アプリの低評価の理由だった）、学習履歴を消さないこと（同）。
- **引き継がない**: 総監を最初にする前提、¥1,800 の買い切りと Free／Premium の境界、サーバからの差分取得。
- 有料化を検討するときは 06 §5 の価値の境界（問題は無料・学習管理に値付け）から考え直す。
