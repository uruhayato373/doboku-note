## 1. 結論

1. **サイトの建設専門 R01〜R05・R01 再試験は、正答と正答の選択肢の理由だけにする。** ほかの選択肢の理由と ExamPoint（要点）は商品だけに入れる。R06・R07 と基礎・適性は今のまま（比べる相手と、無料の代わりがある科目）。
2. **新しく作る商品は note の「建設専門 解説集」1 本だけ。** 価格は ¥1,180 で試す。分野別 11 冊・年度別・基礎や適性の単品は作らない。分野別は解説集の中の並べ方（索引）として入れる。
3. **既存の商品の価格は据え置く。** note 合本 ¥1,480・直前パック ¥1,980・暗記ノート ¥980、Kindle 合本 ¥1,480・科目別 ¥980。Kindle の 2 冊（d-00・d-03）は 11/24 に改定したばかりで、効果を測る前に動かさない。合本 d-00 は 2027-03 に位置づけを見直す。
4. **作るのは 2027-03〜07、売る山は 2027-10〜11。** 次の試験は 2027-11 で、直前パックが売れたのも 10/22〜11/18 だった。サイトの解説を絞るのは商品ができてから（逆順にすると、解説が消えたのに買える物が今と同じになる）。

## 2. 根拠

### 2-1. 流入は解説の本文で来ていない

- 過去問ページは 6,905 セッション（GA4 2026-10-23〜11-19）。うち Google 検索のクリックは 851（GSC）。検索語は「試験名＋年度＋過去問／解説」で、論点の語（解説の本文に当たる語）のクリックは 5。
- 閲覧の大半は資格トップや年度の一覧から問題を解きに来る繰り返しの利用者（技術士一次のトップは 258 人で 1,143 セッション）。
- 広告は問題の間に出ていて、解説の中には無い。
- 一方「解答・解説」は月 58,000 回開かれ（技術士一次 r07-basic は 621 セッションで 3,046 回）、今は 1 円にもなっていない。

## 3. 分冊と価格の判断

| 候補 | 判断 | 理由 |
|---|---|---|
| 建設専門 解説集（note・R01〜R07＋再試験） | **作る**（¥1,180） | 無料の全肢解説が無い唯一の科目。サイトを絞る年度の買い先になる。価格は競合 ¥1,000 と合本 ¥1,480 の間（競合は問題文を載せない。こちらは実問題つき）。数字から出した値ではない仮説 |
| 建設 11 分野別の分冊 | 作らない（索引にする） | 1 分野は約 20 問で薄い。専門科目は 35 問から 25 問を選ぶ試験なので、苦手な分野を飛ばす読者に「分野別の索引」は効くが、冊にする必要は無い |
| 年度別 | 作らない | 年度で買う理由が弱い。R06・R07 はサイトが無料のまま |
| 基礎・適性の note 単品 | 作らない | 無料の代わりがきく。Kindle d-01・d-02 と同じ中身 |
| Kindle の新しい分冊 | 作らない | `04_収益化戦略.md` の「KDP は維持だけ」 |
| Kindle の値下げ・廃止 | しない（2027-03 に見直し） | 11/24 改定の効果が未測定 |

note の価格の段: 暗記ノート ¥980（入口）→ 建設専門 解説集 ¥1,180（本命）→ 合本 ¥1,480 → 直前パック ¥1,980（束・試験前 1 か月に前面へ）。サイトの導線は、絞った年度の建設専門ページから解説集へ、それ以外から暗記ノートか直前パックへ送る。

**商品にだけ入れる中身**（優先順）: ①建設 11 分野別の索引と並べ替え ②年度をまたいだ頻出論点の整理（出題回数の表と ExamPoint の集約・回数はスクリプトで数える）③計算問題の型（建設専門では量が少なく後回し）。

## 4. 変える過去の決定

- `04_収益化戦略.md:41`「サイトの全問無料は続ける」→ 建設専門の一部の年度で、全選択肢の理由と要点を有料にする試行を足す（問題文と正答は全問無料のまま）。
- メモ「総監過去問折衷案」（2026-06-18・全選択肢の正誤の理由は過去問ページに残す）→ 総監には適用しない。技術士一次の建設専門の試行の年度だけ例外とする。

## 5. 先に確かめること（承認の前後で）

| 項目 | なぜ | 確かめ方 |
|---|---|---|
| **KDP セレクトの独占の条件** | Kindle の日本 70% はセレクト登録が条件で、d-01・d-02 は 70%（＝セレクト）。一方 note の合本 PDF とサイトに同じ基礎・適性の中身がある。セレクトは電子の中身を Amazon だけにする条件なので、規約に触れているおそれがある | KDP の規約（セレクトの独占の範囲・無料の Web 公開の扱い）を読む。触れるなら、d-01・d-02 をセレクトから外す（35% に下がる）か、note 合本から基礎・適性を外すかを決める |
| 70% の価格帯の上限 | 記録の間で ¥1,250 と ¥1,650 が食い違う（メモは 2026-09-23 の告知で ¥1,650） | KDP の価格ページ |
| Kindle 4 冊の今の販売価格 | 台帳は d-00 ¥1,480・d-01〜03 ¥980。戦略の文書（`09:19`・`09:118`）は「合本 ¥990・建設専門 ¥490」で古い | KDP の本棚（運営者）。台帳に合わせて 09 を直す |
| 演習アプリの抜け道 | `/tools/kakomon-quiz/pe-first-stage` のデータが全選択肢の解説を持っていれば、サイトを絞っても読める | `public/quiz/pe-first-stage.json` の生成元（build-quiz-data）を読む |

## 6. 判定（サイトを絞ってから 4 週間）

- 続ける・広げる: 対象の年度のセッションの比が R06・R07 に対して 2 割以上落ちず、解説集か合本の売上、または建設専門の Kindle の既読が増えた。
- 戻す: 比が 3 割以上落ち、売上が増えない。サイトの設定から年度を外すだけで戻る。
- 欠測は 0 と扱わない（AdSense のページ別は 11/23 に GA4 とつないだばかり）。
