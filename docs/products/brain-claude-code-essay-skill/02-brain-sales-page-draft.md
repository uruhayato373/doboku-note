## 冒頭コピー

施工経験記述をAIへ頼むと、文章はそれらしく整います。

しかし、工事規模、施工量、担当した立場、現場で実際に行った処置までAIに補わせると、それは自分の施工経験ではありません。また、長い文章ができても、本番の解答欄に収まらなければ使えません。

この商品は、完成答案を配る教材ではありません。

あなた自身の工事経験を入力し、Claude Codeで、

1. 設問の要求を整理する
2. 不足情報を止める
3. 答案の骨子を作る
4. 字数内で答案案を作る
5. 別エージェントで矛盾を確認する

ためのローカル作業環境です。

## この商品の特徴

### 設問制約を先に固定

いきなり作文を始めず、問題文から「何を書くか」「何項目か」「何字以内か」を先に抽出します。

### 不明情報を勝手に埋めない

工事名、工期、施工量、役割、処置が入力に無ければ、Claude Codeは `UNKNOWN` として止まります。

### 作成と評価を分離

答案を書く役と、矛盾や不足を確認する役を分けます。AIが自分の作文をそのまま自己承認する流れを避けます。

### 解答欄の字数を確認

文章の見栄えだけでなく、指定した上限へ収まるかをローカルスクリプトで確認します。

### 最終判断は本人

生成物は答案案です。実際の工事経験との一致、法令・規格、試験要領を本人が確認して完成させます。
