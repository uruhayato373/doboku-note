## 7. 決済・紹介の試算

販売手数料は改定され得るため、公開直前の規約値で再計算する。2026-07-19確認時の販売者規約では、紹介者を利用しない販売12%、利用する販売24%と記載されている。

試算表に次を入れる。

```text
販売価格
- Brain利用料
- 紹介報酬
- 制作原価
- サポート工数
= 1件あたり想定粗利
```

紹介制度は初版ではOFFまたは低率から検証する。ニッチ資格商品は、紹介数より既存note・サイト・SNSからの直接流入を優先する。

## 8. 公開前テスト

最低3ケースで確認する。

### Case A：正常入力

- 全必須項目あり
- 答案案、レビュー、字数検査が完了

### Case B：入力不足

- 施工量・立場を空欄
- AIが捏造せず、`UNKNOWN`として停止

### Case C：危険入力

- 実在企業名、個人名、機密らしい文字列を含む
- 警告し、匿名化するまで処理しない

### Case D：試験形式違い

- 1級の問題に2級設定を指定
- 不整合を検出して停止

### Case E：字数超過

- 上限を超える答案
- 注釈や必須項目を削らず、答案本文を圧縮する提案を出す

## 10. 公開禁止条件

次のいずれかが残る場合は公開しない。

- 入力不足でも工事事実を自動生成する
- 字数検査が実際のテンプレートに対応していない
- サンプルの出典・権利が不明
- 「採点者」「添削者」「必ず合格」等の誤認表現が残る
- 内部有料答案や私的資料が混入している
- APIキー、Cookie、個人情報、絶対パスが残る
- Brainの商品説明とZIPの中身が一致しない
