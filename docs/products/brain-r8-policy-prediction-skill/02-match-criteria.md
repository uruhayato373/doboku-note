# 一致・部分一致・不一致 判定基準

> [!note]
> 商品②のバックテストとケーススタディで、「事前に用意したテーマ／施策」と「実際の出題」の
> 一致度を、**後知恵で甘くならないよう事前に**定義する基準書（企画 §13 step 2）。
> この基準は結果を見る前に固定し、判定のたびに緩めない。

## 0. 原則

- 判定は**単語一致ではなく論点一致**で行う。テーマ名の表記ゆれ（地方創生／東京一極集中／
  地域の持続可能性）は同一論点として扱ってよいが、**判定理由を必ず文章で残す**。
- 各判定に「なぜその区分か」の根拠と、反証（外れている部分）も併記する。
- 判定者は結果（実際の出題）を見てから基準を作らない。基準はこの文書で固定する。

## 1. 判定対象の2レイヤー

事前収録物は2階層で評価する。混同しない。

| レイヤー | 事前収録物 | 実際の出題との照合対象 |
|---|---|---|
| L1 テーマ | 出題候補テーマ（例: 地方創生） | I-2 記述式の**出題テーマ** |
| L2 施策部品 | 国家施策の答案部品（例: 6案） | 設問(3)で**実際に書ける施策**か（設問要求への適合） |

L1で当たってもL2が使えなければ商品価値は限定的、という評価を保つ。

## 2. L1 テーマの一致区分

| 区分 | 定義 | 例 |
|---|---|---|
| 一致 | 事前収録テーマが、実際の出題テーマと**同一論点**。答案の主軸をそのまま使える | 事前=地方創生 / 出題=地方創生 → 一致 |
| 部分一致 | 事前収録テーマが出題テーマと**隣接・内包関係**。骨子の相当部分を流用できるが、主軸の再設定が要る | 事前=人口減少 / 出題=地方創生（人口減少を内包するが主軸は地域政策）→ 部分一致 |
| 不一致 | 論点がずれ、答案の主軸として流用できない | 事前=防災 / 出題=地方創生 → 不一致 |

### 部分一致の線引き（甘くしないための追加条件）

次を**両方**満たすときのみ部分一致とする。片方でも欠ければ不一致。

1. 事前収録の骨子（現状課題→5管理トレードオフ→施策方向）の**過半が流用可能**である
2. 出題の主軸に対して、事前収録が**上位概念・下位概念・隣接概念**のいずれかで論理的に接続する

「なんとなく関連する」は不一致に倒す。

## 3. L2 施策部品の適合区分

設問(3)は「課題と施策の組合せを2つ、各600字以内、5管理2つ以上のトレードオフ明記」が要求
（証拠台帳 E・実記事の解答様式より）。事前施策部品を次で評価する。

| 区分 | 定義 |
|---|---|
| 直接使用可 | 事前施策が、実際の設問要求（字数・トレードオフ・国家スケール）を満たしそのまま転写できる |
| 要改変 | 施策の骨子は使えるが、字数調整・トレードオフの明示・設問文言への合わせ込みが必要 |
| 使用不可 | 設問要求に構造的に合わない（業界内施策に閉じる・国家スケールに届かない等） |

判定では「事前収録の6案のうち何案が直接使用可／要改変か」を数で示す。

## 4. カバレッジと外れ方の開示（的中率の誇張を防ぐ）

的中率という単一指標を使わない。次を必ずセットで示す（企画 §9・§12）。

- **上位候補数 K**: 事前に何テーマを上位候補として固定していたか（Kを増やせば当たるのは当然、を防ぐ）
- **カバレッジ**: 上位K候補のうち、実際の出題を含んでいたか（一致／部分一致／不一致）
- **外れ候補**: 上位に挙げたが出題されなかったテーマと、その理由
- **見逃し**: 上位に入れられなかったが出題されたテーマ（あれば）

「K=3で1年当てた」と「K=20で1年当てた」は価値が違う。Kを常に明記する。

## 5. R8 の判定（本基準の適用例・確定）

- L1: 事前=地方創生・東京一極集中 / 出題=地方創生 → **一致**
  - 根拠: 出題テーマの主軸（地方創生2.0・東京一極集中是正）が事前収録テーマと同一論点。
- L2: 事前6案が設問(3)要求（国家スケール・5管理トレードオフ明記）を満たす構造 → **要改変〜直接使用可**
  - 各案が「①課題と施策／②有効性と実現性／③障害と克服策（5管理2つ以上）」の三要素で
    構成され、設問(3)の解答様式に整合。実際の設問文言への合わせ込みは要改変。
- K: この判定を使う際は、事前に固定していた上位候補数Kを `03-backtest-protocol.md` の
  R8時点分析で明示する（後知恵でKを縮めない）。

## 6. 禁止事項

- 出題を見てから区分の定義を緩める
- テーマ名の単語一致だけで「一致」と主張する
- 外れ候補・見逃しを開示せずカバレッジだけ見せる
- L1一致をもってL2（施策の使用可否）まで当たったと拡大表現する
