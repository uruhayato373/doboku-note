> **v2 (2026-05-19)** — [05_iOSベンチマーク調査.md](./05_iOSベンチマーク調査.md) を反映してブラッシュアップ。
> v1 からの主要変更点: ①Onboarding に「学習履歴永続保証」「法改正なし」訴求追加、②演習タブに試験日カウントダウン常駐、③問題演習画面に一問一答/4択 dual モードトグル追加、④解説画面に段階開示（方針→ヒント→解答）追加、⑤設定タブに試験日リマインダー設定追加。
> 主要 8 画面のワイヤーフレーム + 画面遷移図 + Free/Premium UI 挙動の真実源。SwiftUI 実装時はこのドキュメントを参照する。

## 画面マップ（全体構造）

```
[起動]
  ↓
[Splash] ──(初回起動)──> [Onboarding 3step] ──> [Home Tab]
              │
              └──(2回目以降)──────────────────> [Home Tab]

[Home Tab] — 下部4タブ
 ├─ 演習 (Practice)
 │   ├─ 演習モード選択
 │   ├─ 年度別 → 年度選択 → 問題演習 → 結果サマリー
 │   ├─ ランダム → 問題演習 → 結果サマリー
 │   └─ 5管理別 → カテゴリ選択 → 問題演習 → 結果サマリー
 ├─ キーワード (Keywords)
 │   ├─ 5管理カテゴリ一覧
 │   ├─ 検索
 │   └─ キーワード詳細 (Free=概要 / Premium=詳細)
 ├─ 進捗 (Progress)
 │   ├─ 正答率推移 / 5管理レーダー / streak
 │   └─ 苦手問題ブックマーク
 └─ 設定 (Settings)
     ├─ Premium 購入 → StoreKit シート
     ├─ データ更新 / 利用規約 / プライバシーポリシー
     └─ 運営者プロフィール (合格体験リンク)
```

## ナビゲーション原則

| 原則 | 内容 |
|---|---|
| **タブ常駐** | 下部 4 タブは常に表示（深い階層からも 1 タップで戻れる） |
| **モーダル使い分け** | 課金・設定詳細・解説詳細はモーダル（タブ階層を汚さない） |
| **戻る** | iOS 標準 swipe-back + 左上 < ボタン |
| **Premium ゲート** | コンテンツ自体は見えるが操作不可 + 解放 CTA を必ず併設（隠さない） |
| **オフライン挙動** | 全画面オフライン動作。同期不要のメッセージで明示 |

### 4-B. 一問一答モード（v2 追加、TK office ベストプラクティス踏襲）

```
┌─────────────────────────┐
│ ← R07 12/40   [4択|一問] │  ← モード切替（永続設定）
├─────────────────────────┤
│                         │
│ Ⅰ-1-12  経済性管理       │
│                         │
│ ─── 選択肢 2 について ─ │  ← 5 選択肢を個別に ○×判定
│                         │
│ 企業におけるBCMは、自社  │
│ の人的・物的被害の軽減が │
│ 主である目的であるため、 │
│ 委託先・調達先・供給先な │
│ どは、BCMの活動や対策の  │
│ 検討範囲には含まれない。 │
│                         │
│ ─────────────────       │
│                         │
│ この記述は適切？         │
│                         │
│  ┌─────┐  ┌─────┐    │
│  │  ○  │  │  ×  │    │  ← 二択ボタン
│  └─────┘  └─────┘    │
│                         │
│ 残り 4 / 5 選択肢        │
│                         │
├─────────────────────────┤
│ [🔖 ブックマーク] [スキップ]│
└─────────────────────────┘
```

**モード設計の根拠**:

- **4 択モード**: 本番試験と同じ形式、最終確認・直前期に最適
- **一問一答モード**: 各選択肢を個別に ○×判定する形式。同じ問題で 5 倍の演習量を稼げる、選択肢ごとの理解度を把握できる（TK office で標準化済）
- **モード切替は永続設定**: 設定タブで「デフォルトモード」を選択可能、演習中の切替は次問から有効

**インタラクション**:
- **4 択**: 選択肢タップ → ラジオボタン状態変更、フッター「回答 →」がアクティブ → タップで即座に正誤フィードバック（緑/赤ハイライト）→ 0.5 秒後に画面 5 解説画面へ自動遷移
- **一問一答**: ○/× タップ → 即座に正誤フィードバック + 1 行解説 → 自動で次の選択肢へ → 5 選択肢完了で問題全体の解説画面（画面 5）へ
- メニュー (⋮): 「解答を見ずに次へ」「演習を中断」

**段階開示の根拠（TK office ベストプラクティス踏襲）**:

| 段階 | 内容 | 目的 |
|---|---|---|
| **Step 1 方針** | 問題のアプローチ・着眼点（50-100 字） | 「何を考えれば解けるか」のメタ認知 |
| **Step 2 ヒント** | 核心となる知識・定義（100-200 字） | 完全な答えを見ずに自力で考えるための補助線 |
| **Step 3 解答全文** | 各選択肢の正誤判定 + ExamPoint + 関連キーワード | 復習時の網羅的参照 |

**適用ルール**:
- 5 管理間トレードオフ問題（情報管理 × 安全管理 等）: **段階開示を必ず適用**
- 純粋知識問題（用語の定義等）: 5-B 全文表示モードがデフォルト、ユーザー設定で段階開示に切替可能
- データ契約: `questions.json` に `explanation_stages: { approach, hint, full }` フィールドを追加（[03_iOSデータパイプライン.md](./03_iOSデータパイプライン.md) §1.2 schema 拡張）

## Free / Premium 境界 UI 挙動の原則

| 場所 | Free 表示 | Premium 表示 |
|---|---|---|
| 年度別演習リスト | R07 = 完全解放 / R01-R06 = 🔒 + 「Premium を見る」CTA | 全年度解放、進捗バッジ |
| ランダム演習 | R07 内 40 問からランダム | 全 280 問からランダム |
| 5 管理別演習 | 各管理から R07 出題分のみ | 全年度から該当管理を抽出 |
| キーワード詳細 | 概要 100 文字のみ、詳細部分は半透明オーバーレイ + CTA | 完全表示 |
| 進捗ダッシュボード | Free 範囲の正答率のみ | 全範囲の正答率 + 弱点分析 |
| この問題に登場 | Premium 出題は 🔒 マーク付きで表示（カニバりを煽らない） | 全表示・タップで該当問題へ遷移 |

**設計原則**:
- **隠さず・ロック表示する**: Premium コンテンツの存在自体は見せる（価値訴求）
- **CTA は嫌味にしない**: ロック画面に強い広告型 CTA を貼らず、控えめなボタンに留める
- **Free で十分試せる**: R07 全 40 問 = 受験 1 年分相当の品質体感ができる

## エッジケース UI 挙動

| ケース | 挙動 |
|---|---|
| 初回起動 + オフライン | Splash で「ネット接続が必要です。Wi-Fi をオンにしてください」表示、待機 |

| iCloud 同期（v1.1+） | MVP では端末ローカルのみ。v1.1 で iCloud 同期検討 |

## クリティカル UX 判断

| 判断 | 採用案 | 理由 |
|---|---|---|
| 課金訴求の頻度 | 自然な動線 (ロック画面のみ) + 進捗 7 日目のソフトプロンプト | 押し付けがましい全画面広告は審査リスク + UX 悪化 |
| 解説の即時表示 | 回答直後に自動遷移 (0.5秒間) | 「次へ」タップ強制は摩擦、学習リズム維持 |
| ブックマークの位置 | ヘッダー右の単独アイコン + 結果画面の「復習」CTA 両方 | 学習中も振り返り時もアクセス可能 |
| 進捗 streak の重み | 大きく表示 | 継続学習の動機づけ、買い切りユーザーの定着率に寄与 |
| 広告 | **入れない** | 買い切りモデルなので広告不要、UX 最優先 |
