# 1級土木 施工管理・法規編 テキスト → サイト拡充計画

> [!info] このドキュメントの位置づけ
> `docs/textbook/１級土木施工管理技士/テキスト（施工管理・法規編）`（全7章・320k字・133図の内部リファレンス）を、サイト `civil-construction-1` の textbook/guide ページへ**もれなく展開**するための棚卸し＋拡充計画。2026-07-03 に全7章 × 既存34 textbook ページを4並行エージェントで突合して作成。着手時はこの計画を起点に、各ページ執筆で `docs/reference/content-authoring.md`・`content-principles.md` を Read する。

## 目的

テキストの論点（施工管理5大管理＋法規）を**自前の文章＋自前SVG図**でサイトに網羅し、一次検定「問題B 施工管理」の得点源ページ群を厚くしてオーガニック流入を伸ばす。既存 pillar `guide-*`＝俯瞰／`textbook-*`＝原典に近い各論、の二層分業を踏襲する。

## 制約（最重要・著作権）

> [!warning] スキャン本文・図の直接転載は禁止
> テキストは市販書スキャンのOCR＝**公開禁止（`README.md` 冒頭に明記）**。サイトへ出すのは論点・定義を根拠にした**自前の書き起こし**のみ。図133点も市販書クロップのため、**自前SVGを新規作成**して置き換える（トレース・直接転載は不可、概念のみ借用しレイアウトは独自化）。

> [!warning] スキャン図の一時プレースホルダ運用
> ドラフト中はスキャン図を**ローカル一時プレースホルダ**として使ってよいが、本番に到達させない：ドラフトは `published: false`、スキャンPNGは commit / R2 同期される path に置かず `.tmp/` 配下に留め、公開・deploy 前に**必ず自前SVGへ置換**する。公開時にスキャン残置ページがあれば要フラグ。

> [!note] OCR近似＝数値は原典照合必須
> LLM-OCRのため条文数値・法令名・条番号は近似。人数/面積/高さ/dB/金額/日数などは執筆前に e-Gov・国交省一次情報で照合してから本文化する（各章のリスク節に具体箇所を列挙）。

## フェーズと着手順

配点（問題B 安全8〜10問・環境5〜7問が最大級）と「穴」の大きさから、以下の順で進める。

- **フェーズ0（緊急是正・拡充と独立）** — 法規の金額基準・就業制限表。本番公開中の可能性がある正誤に関わるため先行。
- **フェーズ1（第5章 安全管理 新規7ページ）** — 最大の穴・最大配点。着手順: safety-scaffolding → excavation-shoring → management-system → machinery-crane → industrial-safety-law → risk-assessment → work-environment。
- **フェーズ2（第6章 環境保全 新規4ページ）** — 着手順: byproduct-recycle → waste-disposal-manifest → noise-vibration-regulation → water-air-soil-pollution。
- **フェーズ3（第2〜4章 既存深掘り＋SVG）** — 工程図表・NW計算・X̄-R実図など。
- **各フェーズ完了時** — `guide-*` 末尾「テキスト参照」表へ新ページを追記 → 同一 commit で `npm run refresh-indexes`、新規ページは `npm run ogp`。
