## 2. site / note 境界の方針

過去問模範解答の扱いについて3つの選択肢を検討した結果、当初は**方針C（ハイブリッド）**で確定した。

| 方針 | 説明 | 採否 |
|---|---|---|
| A. 全てnote有料化 | R04を"無料サンプル"として残し、R01〜R07 の有料パックをnote A-2で販売 | ❌ |
| B. 全てサイト無料 | 16年分すべてサイトで公開、noteからは削除 | ❌ |
| **C. ハイブリッド** | サイトには「着眼点・骨子」のみ、noteに「完成答案」 | ✅ 当初採用 |

### ⚠️ 現状との乖離（要再検討）

方針Cでは「サイト=着眼点のみ、note=完成答案」だったが、実際には **H28〜R07 の10年分について、ガチンコ技術士学園等の既存模範論文を site に掲載**する運用に変化している。

**現状の運用は実質「方針B（全てサイト無料）寄り」**になっており、note A-2「R01〜R07 論文合格答案実例集 ¥2,480」の商品性と矛盾する。次の意思決定が必要:

1. **既存の site 模範論文を引き続き掲載**し、note A-2 は廃止または別コンセプト（例：添削付き、複数パターン比較など）に変更する
2. site 掲載は「出典が明示された外部の模範論文の引用・解説」として位置づけ、note A-2 は「運営者自身が執筆するオリジナル答案」として差別化する
3. 方針Cに戻し、既存の site 模範論文を削除 / 着眼点解説に変換する

現実的には **案2** が最も摩擦が少ない（既存資産を活かしつつ有料商品の独自性を確保）。

### 3.1 テーマ駆動 5 管理横串 論文骨子テンプレート（旧 23 統合）

Guide 系の Q2-A-7 と並行して、**どのテーマにも対応できる統合型**の論文骨子テンプレを整備する。これは運営者の受験準備の副産物として note 商品 P-04 / E-1 / E-2 の主材料を兼ねる。

**用途**:

1. **本人の練習ツール** — 過去問を本テンプレに流し込むことで、15 分で骨子を作る訓練
2. **note P-04「論文骨子テンプレート（テーマ × 5 管理 統合テンプレ）」（¥1,980）の主材料** — 5 枚構成章立て + 主要 5 テーマ × 5 管理マッピング集 + 定型フレーズ集で構成
3. **note E-1（解答全文再現 ¥1,980）/ E-2（私はこう書いた ¥2,480）の下地** — 試験後に本テンプレで構築した骨子をそのまま解答再現に展開

**全体目標**: 2026-05-15 に完成済み。

**テンプレート構造**（テーマ非依存の普遍フレームワーク）:

1. 課題抽出（1 枚目）— テーマを 5 管理に分解し各管理の課題を明示
2. 解決策（2〜3 枚目）— 管理間トレードオフを 2〜3 ペア特定し統合的解決策を提示
3. 波及効果（4〜5 枚目）— 5 管理全体の展望とフォローアップ

**制約**（[../../note/技術士総監/noteコンテンツ計画.md](../../content/note/技術士総監/noteコンテンツ計画.md) 準拠）:

- **「模範解答」は作らない** — 骨子と定型フレーズのみに留め、設問ごとの「正解」を書かない
- **定型フレーズは汎用表現のみ** — 特定の業務事例や実名を含めない（運営者の業務経歴は本人の練習ノートに留め、公開テンプレには載せない）

### 着眼点解説の構成テンプレート

各記事は以下の構成で統一:

1. **前文の要点抽出** — 何が問われているか
2. **表面テーマ vs 本質テーマ** — 問題文の奥にある構造的課題
3. **5管理での切り口マップ** — どの管理を主軸にすべきか
4. **トレードオフの候補** — 典型的な対立構造3〜5個
5. **避けるべき落とし穴** — 不合格答案の典型パターン
6. **次のステップ** — note A-2（完成答案実例集）への導線
