# 試験日・合格発表日の当日ページの型

2026-10-25（2級土木 第二次検定の試験日）に、事前に公開していた当日ページ `civil-construction-2/guide-r08-secondary-answers` が 1 日で 3,764 クリック、28 日で 5,252 クリック（サイト全体の 60%）を取った。3 か月で最大の成果で、同じ型を次の試験日へ当てる（gsc-management.md 2026-11-11）。

> [!important] 作るのは「その年の事実がある日」だけ
> 資格と日付を機械的に横展開しない。中身の薄いページの量産は Google のスパム方針（scaled content abuse）の対象になる。検索の実績か、その年に固有の事実（問題の公表・正解の掲載日・出題の変化）があるときだけ作る。

## 日付ごとの判断（対応表と点検）

- 対応表は `config/exam-day-pages.json`。`config/exam-calendar.json` の試験日・合格発表日ごとに、`page`（当日ページ）・`card`（作ると決めて起票済み）・`skip`（作らない理由）のどれかを書く
- 週次レビューが `npm run check-exam-day-pages` で今後 21 日の日付を読み、未判断と記事が無いものを処置する

## 型

| 項目 | 決まり |
|---|---|
| 公開 | 試験日の 1〜2 週前。公開したら登録リクエストを送る（`npm run gsc-indexing:request` か URL 検査） |
| 題名・seoTitle | 資格名・年度・「解答速報」または「解答例」・試験日を入れる。検索語の語順に合わせる |
| 最初の画面 | 共感の 1 段落の直後に、検索への直答を 1 文で置く（公式の正解はいつ・どこで出るか） |
| 本文 | 試験の概要・公式の正解や問題の公表の有無と確認先・自己採点の進め方・合格発表までの日付（2 列の表）・次の一歩 |
| 事実 | 公式に無い正答・推定の解答を作らない。公表の有無・日付は実施機関の公式ページで確かめ、出典の URL を本文に置く。日付は `exam-calendar.json` だけを使う |
| 導線 | 過去問・学習計画への内部リンク。note の教材は `src/lib/magazine-placement.ts` に配線する（試験前は直前の教材、翌日からは年度に依存しない教材へ切り替える）。配線しないと `magazine-cta-reachability` が落ちて本番に出せない |
| 試験日以降 | 時制は試験日以降に読んでも自然にする。合格発表日まで同じページで受ける |
| 効果の記録 | 試験日の翌週に、前後 7 日のクリック・検索語と、その後の行き先（note・登録）を gsc-management.md に書く |

## 合格発表日は、原則として新しいページを作らない

2026-08〜11 の GSC の記録では、「合格発表」を含む検索の表示は 2級土木 15・技術士二次 8・ほかの資格は 0 だった。試験日の「解答」の検索とは桁が違う。合格発表日は、試験日の当日ページ（合格発表日までの流れを書いてある）か既存の年度のページで受ける。ただしこの記録はサイトの表示が少なかった 8〜9 月を含むので、2027 年の合格発表日のあと、表示が出ていれば判断を見直す。

| 2027-01-15 | コンクリート技士 | 試験日の当日ページ `concrete-engineer/guide-r08-answers` で受ける（正解肢の掲載も同じ日） |
