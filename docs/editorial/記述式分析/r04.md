| (1) | Ⅰ | 事業/組織の概要・役割・立場、経営資源、アウトプット、業務プロセス、過去のデジタル技術利用の変遷（効用と副作用） | 管理対象明示、デジタル変遷の振り返り |
| (2) | Ⅰ-Ⅱ 橋渡し | 既に実施／直近開始の DX 取組、概要・活用デジタル技術・変革の内容、利点と問題点（5 管理視点） | 現在進行形 DX、5 管理ラベル |

**特徴: 三層構造との部分的不一致**

- 問い (1) は明確に Ⅰ 層（管理対象＋現状）— ここまでは R07 と同形式
- 問い (2) は **Ⅱ 層を「現在進行形の DX 取組」として書かせる**（R07 の Ⅱ 層は「5 年内施策」だが R04 は「既実施・直近開始」）
- 問い (3) は **Ⅱ 層的（事業内 DX 計画）と Ⅲ 層的（地域経済循環共生圏まで広げる）が混在** — 国レベル提言まで広がりにくい
- R05 のような「三層に当てはまらない」とまでは言えないが、**Ⅲ 層的なスケール拡張は問題文設計上ややシュリンクする**

## 2. Ⅰ層分析: 管理対象と前提条件（問い (1)）

- **管理対象**: グリーンインフラ研究開発フィールド整備事業（建設会社の研修所敷地内、10 年スパンの長期事業）
- **立場**: 技術開発・設計・管理運営の **リーダー**（事業統括 PM）
- **置かれた前提条件**:
  - 予算 8 億円、人員 30 名（企画 3 / 人事 2 / 設計 5 / R&D 5 / 施工管理 10 / 施設管理 5）
  - 設備: 設計室、作業所、整備後の研究開発フィールド（レインガーデン・試験圃場・地域交流施設）
  - 期間構成: 企画 1 年 + 設計 1 年 + 施工 1 年 + 管理運営 7 年（長期運営フェーズが主）
  - 既存デジタル技術: ドローン点群データ取得、3D 設計活用、敷地・水系・植生のデータ統合（管理運営の一元化）
  - 効用: データ一元化による管理運営効率化
  - **副作用: データ取得・編集・管理の作業増、メンバー業務負担増、能力不足、採算一時低下**
- **「Ⅱ・Ⅲ への伏線」になっている要素**:
  - 「副作用としての業務負担増・能力不足」→ 問い (2) の問題点（**メンテナンスコスト増**）と問い (3) の最大障害（**人的資源管理の人材・能力不足**）に直結
  - 「管理運営フェーズ 7 年」の長期性 → 問い (3) で「中長期視点」と「メンバー継続性」の議論への伏線
  - 「研修所敷地内 + 災害時一時避難場所として行政連携」→ 問い (3) で「地元出身者・監督行政・地元企業」とメンバー多様化への接続

## 4. Ⅲ層分析: DX 推進計画と最大リスク（問い (3)）

R04 の問い (3) は将来の DX 推進計画を「メンバー構成 / 工程 / 最重要工程 / 実現目標 / 最大障害と克服策」の 5 部構成で書かせる。R07 の Ⅲ 層（国レベル施策×2）とは異なる **計画立案型** 設計。

### メンバー構成（多視点性の仕掛け）

| 母体 | 役割 |
|---|---|
| 当事業のメンバー（管理運営） | 現場知 |
| デジタル推進担当（若手） | デジタル化の作業中心 |
| 経営企画担当（中堅 15 年級） | 役員・経営層との橋渡し |
| 地元出身者 | 地域接続 |
| 監督行政担当者 | 行政連携 |
| 地元企業 | 地域協働 |

**評価ポイント**: メンバー出身母体を **6 系統に多様化**することで「複数視点」要求を満たしている

### 工程計画（13 週、5 段階）

| 段階 | 内容 | 期間 |
|---|---|---|
| ⅰ 現状・課題把握 | 経営資源（人モノ金）+ 時間軸（短期/中長期）でヒアリング・アンケート | 3 週 |
| ⅱ 実現目標の設定 | 将来像、ブレインストーミングで参画意識醸成 | 3 週 |
| ⅲ 取組内容の検討 | 実現に必要なプロセスと取組 | 2 週 |
| ⅳ 関係機関 WG・打合せ | 進捗・課題共有、次回までの予定確認 | 3 週 |
| ⅴ 計画取りまとめ | 報告書・ブックレット | 2 週 |

### 最重要工程と理由

- **最重要工程**: ⅱ 実現目標の設定
- **理由**: 「メンバー全員が議論を重ねることで、**初期段階でゴールイメージを共有**し、参画意識・実現に向けた解決策を持つ体制・機運醸成」

### 実現目標・取組内容・最大障害

- **実現目標**: 「DX による当事業の施設を中心とした **地域経済循環共生圏** の実現」
- **取組内容**: 「**官民連携・分野横断協働型のデジタルプラットフォームの構築**」（グリーンインフラ × 防災 × 公共医療を接続。一時避難場所マップ + PCR 検査の地域医療接続）
- **最大障害**: **人的資源管理の視点** —「関係者増加によるコミュニケーション・情報処理の人材・能力不足」
- **克服策**: **情報管理の視点** —「メンバーの埋没知・個人知を定例会議でリスト化、形式知・組織知として活用」

### 最大リスク類型

- **トレードオフ激化型** + **組織弱点露呈型**
  - 関係者多様化による意思決定遅延・能力不足（組織弱点）
  - DX 推進と既存業務継続の同時進行（トレードオフ）

### 克服策が「管理行為」になっているか

- **Y（強）**: 形式知化・組織知化という **情報管理の体制整備** が回答。「新ツール導入」ではなく「ナレッジマネジメント体制の整備」で締めている

### Ⅰ→Ⅱ→Ⅲ の因果連鎖の強度

- **強度: 強**
- **強い点**:
  - Ⅰ で置いた「副作用 = 業務負担増・能力不足」が問い (2) の問題点（メンテコスト）と問い (3) の最大障害（人的資源不足）に **垂直に連結**
  - Ⅰ で挙げた「行政連携・地域接続」が問い (3) のメンバー構成（地元出身者・行政・地元企業）に **接続**
  - 模範解答が **「組織弱点 → 解決策」** の連鎖で書かれている
- **弱い点**:
  - 問い (3) の「実現目標」が **国レベルではなく地域レベル**（地域経済循環共生圏）にとどまる。R07 のような国レベル提言までスケール拡張できていない（問題文設計上の制約だが、Ⅰ→Ⅱ→Ⅲ の単調なスケール拡張になっていない）
  - 「最も重要な工程」の理由付けが「機運醸成」止まり。総監視点（5 管理間トレードオフ）からの理由付けが薄い

## 7. 受験準備への含意（運営者ノート）

### 自分が R08 で使えるか

- **「副作用 → 最大障害」の垂直連結は超強力**: Ⅰ で「これまでの取組の副作用」を 1〜2 つ書いておくと、問い (3) の「最大障害」がそこから自然に導出できる。R08 でも Ⅰ で副作用を必ず置く
- **メンバー多様化 6 系統は流用可**: 計画立案系の問いが来たら、事業内 + 行政 + 地元 + 専門 + 経営 + 若手 の 6 系統で多視点を演出
- **形式知化・ナレッジマネジメント型** は R07 NM 型と通底する **暗黙知 → 形式知 → 組織知** の流れで万能。情報管理の主管理 / 副管理どちらでも使える
- **同管理内トレードオフ型**: 「経済性管理の視点で利点 = 生産性向上、問題点 = メンテコスト増」のように **同じ管理視点で正反対の評価** を書く型はあらゆる施策評価で使える

### 真似すべき定型表現

- **5 管理ラベル明示**: 「**①利点 1) 経済性管理の視点**: 〜」「**①問題点 1) 情報管理の視点**: 〜」のように **管理ラベルを段落冒頭に置く**（R07 と共通の型）
- **施策具体化の三つ組**: 取組名（**デジタルツイン化**）+ 具体的アウトプット（社内研修プログラム）+ 動機（コロナ感染対策）の三要素を含める。「DX を推進する」「人材育成を強化する」のような方針止まりは減点
- **工程計画は数値明示**: 「3 週」「2 週」と日数を明示し、5 段階以内に収める。13 週総量は「四半期 1 サイクル」感が出る
- **地域接続キーワード**: 「地元出身者」「行政連携」「地域経済循環共生圏」「官民連携」「分野横断協働」を散りばめ、地域接続性を演出
- **克服策の管理行為化**: 「メンバーの埋没知を定例会議で **リスト化** し、形式知・組織知として **活用** する」のように、**リスト化／統一化／段階導入／体制整備** で締める

### 落とし穴

- **問い (3) で国レベルまでスケール拡張する難しさ**: R04 模範解答は地域レベルにとどまり、R07 のような国施策提言はしていない。ただ R08 のテーマが「**社会課題型**」（少子高齢化・CN 等）なら国レベル拡張が必須、「**DX 型**」「**戦略フレームワーク型**」（SWOT）なら地域・組織レベルで OK
- **5 管理被覆の偏り**: R04 模範解答は経済性・人的資源・情報の 3 管理に集中、安全管理と社会環境管理がほぼ登場しない。R08 では意識的に 5 管理全部に触れる（特に**社会環境管理**は CN・SDGs・地域接続で繋げられる）
- **「最重要工程の理由」が薄くなりがち**: R04 模範解答は「機運醸成」止まり。総監視点（5 管理間トレードオフ・組織弱点・外部環境変化）から **「だからこの工程が要」** という理由付けまで書ければ加点
- **「過去の振り返り」を冗長にしない**: 問い (1) ③（過去のデジタル技術の利用変遷）に紙幅を取られすぎると、問い (2)(3) で施策密度が落ちる。**過去 = ½ 枚、現在 DX = 1 枚、将来計画 = 2 枚** のバランスが目安

### R07 との比較（2 件目で見えた共通点・差分）

- **共通点（型として確立）**:
  - 5 管理ラベル明示（『（◯◯管理）の視点』）
  - 副管理に経済性管理を頻繁に置く
  - 管理行為で締める克服策（リスト化・標準化・段階導入）
  - Ⅰ で前提条件 → Ⅱ・Ⅲ で伏線回収の因果連鎖
- **差分（テーマ依存）**:
  - 問い (3) のスケール: R07 は **国レベル**、R04 は **地域レベル**
  - 5 管理被覆: R07 は 4 管理（情報・経済性・人的・安全）、R04 は 3 管理（経済性・人的・情報）
  - トレードオフ表現: R07 はラベル + 宣言文、R04 は同管理内対比で構造表現
  - パターン主役: R07 は **NM 型 + OJT 正社員登用型**（社会課題型）、R04 は **デジタルツイン × 外販型 + 形式知化型**（DX 型）
