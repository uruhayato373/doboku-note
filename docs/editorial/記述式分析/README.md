## スキーマ: パターン抽出マトリクス

`_matrix.md` / `_matrix.json` の共通スキーマ。**模範解答パターン単位の flat な行**。

| カラム | 型 | 値域 / 例 |
|---|---|---|
| `year` | string | `r07`, `h28` |
| `pattern_id` | string | `r07-1`, `r07-2`（年度内連番。1 年に複数模範解答があるとき 1 行/パターン） |
| `theme` | string | `少子高齢化` |
| `theme_category` | enum | `社会課題型` / `DX型` / `リスク型` / `環境型` |
| `subject` | string | `地方環境調査事務所`（題材）|
| `L1_scope` | enum | `事業` / `組織全体` / `部署` / `国` |
| `L1_role` | enum | `PM` / `部門長` / `経営層` / `行政` |
| `L1_premise_keywords` | string[] | `[地方, 中小, 人材流出]` |
| `L2_main_management` | enum | `経済性` / `安全` / `人的資源` / `情報` / `社会環境` |
| `L2_sub_managements` | enum[] | `[情報, 人的資源]` |
| `L2_measure_count` | int | `2` |
| `L2_concreteness` | enum | `高`（固有名詞・数値あり）/ `中` / `低` |
| `L2_effect_problem_pairs` | int | 効果と問題点のセット数 |
| `L2_tradeoff_pairs` | string[] | `[情報×経済性, 人的×経済性]` |
| `L3_max_risk_type` | enum | `トレードオフ激化` / `組織弱点露呈` / `規模拡大破綻` / `外部環境変化` |
| `L3_countermeasure_is_management_act` | bool | `true` / `false` |
| `L3_causal_consistency` | enum | `強` / `中` / `弱` |
| `pattern_tags` | string[] | `[NM型, OJT正社員登用型, データ標準化型]` |
| `source_mdx_path` | string | `content/site/pe-comprehensive-management/r07-secondary/article.mdx` |
| `analyzed_at` | date | `2026-04-29` |

## 型と特殊解の区別ルール

`pattern_tags` のうち **2 年以上で観測** されたものを `_patterns.md` に「型」として昇格、再現条件を記述する。1 年限りは「特殊解」として年度シートに留める。

## verify 条件

### Step 1（年度シート）

- [ ] Ⅰ・Ⅱ・Ⅲ の 3 セクションが埋まっている
- [ ] Ⅱ層で 5管理タグが施策ごとに付いている
- [ ] Ⅲ層の最大リスクが 4 類型のいずれかに分類されている
- [ ] cem-qa 流用 5 軸採点が記入され、加重スコアが計算済み
- [ ] 受験準備への含意欄に最低 3 点書かれている
- [ ] 原文の連続 50 字以上の一致なし（grep ベース機械チェック）

### Step 2（マトリクス）

- [ ] 全模範解答パターンが行として展開されている
- [ ] `_patterns.md` に最低 5 件の型が抽出されている
- [ ] `theme_category` × `L2_main_management` のクロス集計表が完成
- [ ] `_matrix.json` が JSON Schema バリデーションを通る

### Step 3（運営者ノート）

- [ ] 主管理ごとの定型施策ストック（5 管理 × 各 3 施策以上）
- [ ] トレードオフ宣言の定型表現テンプレ集
- [ ] Ⅰ で置く前提のボイラープレート

## 著作権配慮

- 原文転載禁止。要約 + 構造化のみ
- 連続 50 字以上の原文一致なしを Step 1 verify チェック項目化
- 出典は元 MDX のフロントマター（`source_pdf` 等）から引き継ぎ、年度シート Section 0 メタデータに明記
