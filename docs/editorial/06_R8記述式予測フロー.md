## 背景

総監記述式（必須科目 I-2）の出題テーマは、当該年度前後の各省庁白書・閣議決定・国家戦略と強く連動する。特に R3 以降の「定着期」では、社会課題（DX・カーボンニュートラル・少子高齢化）を前提に組織施策を複数設計する設問が増えており、R8 予測の精度は note 有料マガジン M3「R8 予想問題集」（¥2,480）の差別化価値を直接決める。

予測の質を担保するには、以下 3 軸での透明な評価が不可欠:

- **(A) 根拠の明確性** — R7 白書のどの特集テーマに直接対応するか
- **(B) 模擬試験立案可能性** — 過去 5 年（R03-R07）から派生可能 + 3 ペルソナで対立構造を描けるか
- **(C) 模範解答作成可能性** — pattern-essay-* + r0X-essay-* に類似骨子が既存し、3 ペルソナ三層構造で書けるか

本ドキュメントは、この 3 軸を「テーマ → 予想問題 → 模範解答」の 3 段階に適用し、各段階で何をどう判定するかを定式化する。

## 1. 3 段階フローの全体像

```
[Stage 1: テーマ予測]
  入力: R7 白書 28 冊 + 過去 17 年出題テーマ表
  出力: 候補テーマ N 本（現状 6 本、A-F）
  品質基準: 3 軸 ◎◎◎ → 最有力 / ◎◎○ → 有力 / ◎○○ → 主役副軸
  サイト: /docs/pe-comprehensive-management-r8-essay-keyword-forecast (テーマ俯瞰ハブ、無料)
  note: M3 マガジン序章で「なぜこの 6 本か」の論拠を 5,000 字で展開（有料）

↓ 3 軸 ◎ 以上のテーマのみ次段へ

[Stage 2: R8 予想問題立案]
  入力: Stage 1 のテーマ + 過去問形式（II-2 / III の構造）
  出力: 各テーマで II-2 形式 3 設問 × 600字×5枚相当の問題文
  品質基準: 過去 5 年と軸が重複しない / **固定 3 ペルソナ（ゼネコン / 河川コンサル / 道路発注者）すべてで管理対象設定可能** / 5 管理対立が複数軸で描ける
  サイト spoke: 想定問題文 + 解答方向性 + 固定 3 ペルソナ別の管理対象設定例 + 業界外受験者へのアレンジ（M4 経由）
  note: M3 第 1-6 章で 6 テーマ全部の予想問題完成形（有料）

↓ 固定 3 ペルソナすべてで「管理対象 → 施策 → 将来展望」が組めるテーマのみ次段へ

[Stage 3: ペルソナ模範解答作成]
  入力: Stage 2 の予想問題 + pattern-essay-* / r0X-essay-* 流用元（固定 3 ペルソナ準拠）
  出力: **固定 3 ペルソナ × テーマ別の完全解答**（三層構造、600字×5枚 × 3 ペルソナ）
  品質基準: 各ペルソナで採点ポイント明示 / 三層構造の論理連続 / 5 管理対立の統合解決
  サイト: pattern-essay-* / r0X-essay-* で「思考フレーム」のみ公開（無料、ハブ、固定 3 ペルソナ準拠）
  note: M3 各章末尾で「**固定** 3 ペルソナフル解答骨子」（有料、3,000字×3ペルソナ）
```

## 2. 各段階の品質基準と判定方法

### Stage 1: テーマ予測の 3 軸判定

| 軸 | ◎ 基準 | ○ 基準 | △ 基準 |
|---|---|---|---|
| A. 根拠 | R7 白書 2 冊以上で直接特集 | R7 白書 1 冊で言及 | R7 白書での扱いが間接的 |
| B. 立案 | R03-R07 派生 + 3 ペルソナ対応 | 一部ペルソナに偏る | 5 管理対立が読み取りにくい |
| C. 解答 | pattern-essay + r0X-essay 既存流用可 | 一部新規執筆要素 | 既存リソース薄、新規負荷大 |

判定の入力データソース:
- (A) 軸: `/docs/pe-comprehensive-management-whitepaper-study-map`（28 白書 R7 特集要約）+ NotebookLM 白書ノートブック（ID: `2bf7f0dd-3935-49be-8cef-2d428c59eaa9`）
- (B) 軸: `/docs/pe-comprehensive-management-essay-exam-strategy`（H21-R07 出題テーマ表 + 三層構造定義）
- (C) 軸: `pattern-essay-*` 3 本 + `r0X-essay-*` の既存 mdx 棚卸

### Stage 2: 予想問題立案の検証ポイント

- 過去 5 年（R03-R07）のメインテーマ軸と重複しない（同じ軸での再出題回避傾向）
- 5 管理ペアが少なくとも 2 つ（主軸 + 副軸）で描ける
- 設問構造が II-2 / III の公式形式に合致（4 設問構成 / 各 600 字相当 / 計 5 枚）
- 3 ペルソナそれぞれで管理対象を具体設定可能

### Stage 3: 模範解答の三層構造採点

- Ⅰ 管理対象と前提条件（1 枚目）
- Ⅱ 施策 — 5 管理視点の対立解決（2-4 枚目）
- Ⅲ 将来展望（5 枚目）

採点ポイント:
- 管理対象の具体化（ペルソナ業務に即した固有名詞）
- トレードオフの統合解決（ALARP / リスクベース判断 / LCA / 段階的実施 / 合意形成）
- 残余リスクの監視計画（締めの定型）

## 3. サイト / note 分業（Red Line #5/#7/#8 適用）

| 段階 | サイト無料 | note 有料 | ペルソナ責任 |
|---|---|---|---|
| Stage 1 テーマ予測 | 候補テーマ俯瞰 + 3 軸スコア + 関連 KW + 関連白書 | M3 序章「なぜこの 6 本か」5,000 字深掘り | 共通（ペルソナ非依存） |
| Stage 2 予想問題（テーマ別 spoke） | 想定問題文 + 解答方向性 + **固定 3 ペルソナ別の管理対象設定例** + 業界外受験者アレンジ | M3 第 1-6 章 6 テーマ完全予想問題 | サイト = 固定 3 ペルソナ縦串 / note = 全展開 |
| Stage 3 模範解答 | pattern-essay 3 本 / r0X-essay（思考フレーム、固定 3 ペルソナ準拠） | M3 各章末尾「**固定** 3 ペルソナフル解答骨子」3,000 字×3 | サイト・note とも固定 3 ペルソナ |

**境界ルール（Red Line #7 適用）**: サイトは「思考フレーム = 抽象」、note は「具体数字 × ペルソナ展開」。3 軸 ◎ のテーマでもサイトには採点基準・フル解答は載せず、note 専有とする。

**ペルソナ統一の原則（2026-05-19 追記、Red Line #8 適用 / 2026-05-21 環境調査ペルソナ廃止により 3 ペルソナへ改訂）**: Stage 2/3 でサイトに展開する spoke は **固定 3 ペルソナ**（ゼネコン / 河川コンサル / 道路発注者）を縦串で揃える。テーマ別に「製造業」「IT サービス」「エネルギー会社」「社会保障コンサル」等の業界を H3 化する動的ペルソナは禁止（試験本質「テーマ不明 → 自分のペルソナで全対応」と矛盾するため）。業界外受験者の救済は spoke 末尾「業界外受験者へのアレンジ」段落で 1 行マッピングのみ示し、深掘りは note M4「解答テンプレ 3D マトリクス」（300 セル）に分業する。詳細は [content-principles.md §21](../../.claude/knowledge/reference/content-principles.md) を参照。

## 6. Red Line #8 候補

R8 予測の質保証ルールとして、以下のいずれかが必要:

**選択肢 1: 既存 Red Line #7 への統合**
> Red Line #7（サイト = 思考フレーム、note = 具体数字 × ペルソナ展開）の末尾に「予測も同じ境界に従う: 候補テーマ俯瞰はサイト、3 軸スコアの根拠詳細・予想問題完成形・ペルソナ別フル解答は note 専有」を追記

**選択肢 2: Red Line #8 として新設**
> Red Line #8: 予測コンテンツは 3 軸スコア（根拠・立案・解答）の透明判定を必須とする
> - サイトには 3 軸スコア（◎○△）のみ公開
> - スコアの根拠詳細・予想問題・模範解答は note 専有
> - 根拠未明示の予測（「なんとなく出そう」）を有料コンテンツに含めない

**推奨**: 選択肢 2（新設）。理由 = Red Line #7 は「コンテンツ種別の境界」だが、#8 は「予測の質保証」で論理層が異なる。混同を避けるため独立ルール化。

確定は `/content/note/技術士総監/noteコンテンツ計画.md` 編集時に行う。

## 8. 学び・注意事項

- **3 軸スコアの目的は「数の絞り込み」ではなく「透明性の付与」**: 6 → 10 にテーマを増やすより、6 のままで「なぜこの 6 本か」を 3 軸で説明する方が note 購買動機が立つ
- **NotebookLM auth は週 1 回程度で expired する**: バッチ実行前に `notebooklm login` を確認する運用が必要
- **G/H/J（エネルギー安保 / 経済安保 / AI ガバナンス）は単独テーマ化せず既存テーマに統合**: 5 管理対立構造が読み取りにくい / 既存解答骨子薄の理由で 3 軸 △ になるため、E/B/F に統合する方が論理整合
- **I（災害復旧 × レジリエンス）は独立追加価値あり**: 能登復旧の出題確度が高く、防災白書 R7 + 消防白書 R7 の根拠も明瞭。A（気候変動適応）に統合 or 独立 7 テーマ目化のいずれも検討に値する
