## 確立した手法（再現手順・03〜06で踏襲）

### 1. 図クロップ（書籍写真→クリーン図）
- textbook `img/figNN.png` は**スマホで撮った書籍ページ写真**（指写り込み・傾き・ヘッダ/フッターあり）。
- `sharp` で `extract` 分数トリム（指=左/右端、フッター=下、ヘッダ=上）。**クロップ後に必ず Read で目視**し、指除去・行ラベル列が切れていないか確認して微調整。
- `webp({quality:82})` で `.webp` 生成。`.png`(マスター)＋`.webp` 両方を site の `img/` に置く（git追跡→main pushでR2自動同期）。
- 参照は `<ArticleImage src="/posts/{slug}/img/figNN.webp" alt="..." width={W} height={H} caption="出典: …" />`（既存490例すべて .webp 直参照）。alt は図の内容を説明。
- **出典表記は必須**（image-policy.md）。textbook の `図の出典:`/`資料）` 行を**クルフトとして消さず**、原典（多くは国土交通省＝白書・年報・統計・省庁HP）を確認し、画像直前に `{/* source: 国土交通省「…」, 政府標準利用規約 */}` ＋ ArticleImage の `caption="出典: …"` を付ける。原典が政府機関でない書籍オリジナル作図は埋め込まずテキスト化。

### 2. 逐語スプライス（機械抽出＝逐語を構造的に保証）
- LLMに打ち直させると逐語が崩れるため**スクリプトで textbook 行範囲を機械抽出**して差し込む。雛形＝`.tmp/splice-iji-kanri.mjs`（02用・コピーして節別に作る）。
- 処理: site各`###`見出し → textbook該当`####`ブロック行範囲を `extractBody(start,end)` で抽出 → 本文置換。
  - ブロック先頭の`####`行は落とす（site の`###`を使う）。内部`####`小見出しは保持。
  - 除去: `<!-- p.NN -->`ページマーカー / `（図:…）`説明 / `図の出典:…` / `資料）…` / 節別の孤立キャプション(DROP_EXACT)。
  - `![図NN](img/figNN.png)` → 対応 ArticleImage に置換（位置そのまま）。
- 欠落論点は新設（02では「国土形成計画(全国計画・維持管理関連)」を 中長期コスト管理 直後に挿入）。
- **post-process（クリーン化・節別に手当て）**: ①OCR誤り是正 ②4列表→3列に縮約（CLAUDE.md「4列以上禁止」） ③OCR崩壊した複雑表→ネスト箇条書き（regexアンカーでマッチ） ④陳腐化是正 ⑤書籍内部参照除去 ⑥`\n{3,}`→`\n\n`。

### 3. 検証→コミット
- `node .claude/scripts/validate-mdx.mjs <article>` パス / U+FFFD=0 / 空ヘッダ表行`^\|\s*\|`=0 / 4列表=0 / `（図`・`図の出典`・`資料）`・`本章`・`次ページ`・`骨子案`=0。
- `npm run refresh-indexes` 実行後、**iji-kanri無関係なインデックス変更(src/config/*.json)は `git checkout` で revert**（他セッションの未コミット変更を巻き込まない）。
- `git add` は記事`article.mdx`＋`img/`のみ明示。コミット。
