## このセッションで学んだ教訓

1. **X のハッシュタグ最適数は 1-3 個**（IG/note の 20+ とは別系統）→ `feedback-x-hashtag-count` memory 新設
2. **大量予約投稿はバッチ分割が安全**（1 バッチ 21 件 × 5 = 90 件、各 10-15 分）
3. **手元 Playwright スクリプト + status.json で再開可能**（途中失敗時は --tweet N 個別再実行で穴埋め）
4. **戦略 v6 を厳守すれば 90 件でも自然な多様性が出る**（D27 + N24 + C15 + M13 + S11 のミックスで内容重複ゼロ）
5. **並行エージェントの「巻き込み commit」は実害なし**だが、commit メッセージの正確性は下がる
