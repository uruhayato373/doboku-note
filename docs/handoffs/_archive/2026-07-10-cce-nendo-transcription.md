## 手順（既存パターン再利用）

1. **D1 正答マップ**（親）: 上記で H28 済み。H27/H26 は解答一覧ページを親が直読して作成。
2. **D2 転記 workflow**（並行・sonnet・1問1worker）: worker に「年度・問題番号・doc9 のページ範囲・既存設問書式見本（`primary-materials` の `### 平成30年度 問題3`）」を渡し、**問題文＋選択肢(1)-(4)を原典転記（解説は書かない）**。図問題は図クロップ（.tmp出力・**答え漏らし厳禁**＝設問文下の【解答】や解説を絶対に含めない [[exam-problem-figure-no-answer]]）。返却=structured JSON。
   - workflow 雛形: `cce-rescan-figure-extract`（session workflows/scripts）を転記用に改変。または前回の転記知見（memory `project_concrete_chief_engineer` の doc02-07 手順）。
3. **D3 解説生成 workflow**（並行・sonnet）: worker に「転記済み問題文＋正答（マップ）＋既存解説スタイル見本＋関連する項目別解説章（`docs/textbook/コンクリート主任技師2024/0N_*.md`）」を渡し、正答根拠＋各選択肢の適否＋ポイント（体言止め）を生成。
   - **親検算必須**: 計算問題（配合・製造QC統計）は全数、知識問題はサンプル。`past-exam-qa` エージェントで分野ごと2-3問監査。
4. **D4 挿入**（親・Edit）: 問題内容で8分野へ振り分け→各記事の年度降順の正位置（R01 の後に H30→…→H26）へ `### 平成N年度 問題N` + `<details>` 形式で挿入。図は `img/` に配置し `<img>`（寸法属性なし＝既存流儀）。図の台帳 manual_needs に source_pdf/page 記録。**BSD sed の `\|` 非対応・zsh 非語分割に注意**（`.webp` 直指定・`while read`）。
5. **D5 検証・commit**（年度単位）: `npm run refresh-indexes` → 8記事+図+台帳を pathspec で commit（`git add -A` 禁止）。pre-commit MDX ゲート通過。1年度ごとに commit。
6. deploy（develop→main）・backlog/census/memory 更新。

## リスク・教訓
- **解説自作の fact リスク**が最大。項目別解説章を根拠に渡す＋計算全数検算＋past-exam-qa で担保。前回 2022本のボケ縦書きで「ガラ落ち転写・数値捏造」が発生したが、今回は**鮮明な横書き**でOCR条件は良好。
- 図問題（H28問1 水和発熱グラフ, 問7 打継目図, 問28 施工組織図, 問29 ひび割れ図 等）は答え漏らし厳禁をプロンプトで強制。
- 並行 workflow は同時2本まで（3本でストール）。
- 転記量が大きい。年度単位 commit で進捗を確定し、容量切れ時はこの handoff を更新（どの年度まで完了か明記）。
