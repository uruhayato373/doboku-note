## 3. 残作業 — note への実投稿

ブラウザ操作が要るためこの環境からは実行できない。手順は以下。

1. note にマガジン「コンクリート診断士 記述式｜問題A・問題B 模範答案集」を作成（掲載文は `docs/note/コンクリート診断士/magazines/コンクリート診断士-記述式-模範答案集/note掲載文.txt`、カバーは同ディレクトリの `_cover.png`）

3. 各 `article.md` の `noteUrl` / `noteId` / `notePublishedAt` を埋める
4. `src/lib/note-magazines.ts` の `cd-essay-magazine` を `published: true` にし `noteUrl` を入れる
5. `npm run verify-note-magazines` で SoT とライブを突合

4 を実行した時点で **`guide-essay`（inline+sidebar）／`textbook-assessment`・`textbook-repair`（sidebar）** の3面で CTA が出る（`magazine-placement.ts` 配線済み）。

## 4. 落とし穴（次に触る人へ）

### 4-1. `check-note-boundary` は未公開記事を検査しない

`notePricing: paid` **かつ published（noteUrl/noteId あり）** の記事だけが対象。未公開マガジンは検査対象ゼロで緑になる。実際、診断士8本は `paidBoundary` が**1本も無い**まま「577件 OK」の緑を出していた。境界が無いまま公開すると全文ロックか全文漏洩になる。**未公開マガジンの公開前は、境界H2の実在を手で確認すること。**

今回の設定（[note-api-verification.md](../../.claude/knowledge/reference/note-api-verification.md) の SSOT 表にも追記済み）:
- 問題A・問題B（7本）→ `答案の方針`（想定問題＝問題文は無料のつかみに残す）
- 解法ガイド → `問題Bの答案の型（5ステップ）`

### 4-2. `r2-sync.yml` はアップロードのみで削除しない

リポジトリから画像を消しても R2 に残り、URL 直叩きで取得できる。著作権対応で撤去したはずの書籍スキャン79件が CDN 上に残っていた。

対処として `scripts/delete-r2-objects.mjs` ＋ `r2-delete.yml`（workflow_dispatch・既定 dry-run）を新設。**削除は明示リスト（`.claude/config/r2-delete-list.txt`）方式**で、自動 prune は採らない（R2 にしかない成果物を巻き込むため）。エッジキャッシュは `max-age=14400` なので削除後も最大4時間は 200 が返る。

### 4-3. `check-figure-canvas` の過去問ディレクトリ免除に診断士の命名が漏れていた

免除パターンが `h24-primary` / `primary-h26-*` しか知らず、`primary-exercise-NN` が対象外だった。修正済み。

### 4-4. `audit-svg` の P6 が `url(#...)` を色として誤検知

ハッチングパターン参照を allowlist 外の色 "url" として MEDIUM を上げていた。修正済み。偽の赤はゲートの信頼を削ぐ。
