# ハンドオフ: 1級土木 過去問図の「答え漏らし写り込み」是正

作成: 2026-07-08 / 状態: **方針決定待ち（じっくり検討）**。2ページ着手済み・残りは大規模手作業のため保留。

## 背景（発見の経緯）

admin ギャラリー（記事図版タブ）で 1級土木 primary（過去問1次）の図クロップ品質が低い、という指摘から調査。実体は「クロップが甘い」ではなく、より重い **答え漏らし** だった。

図は問題PDFでなく**解答・解説資料**からクロップされており、図の上下に本文が写り込んでいる。その中に

> 「したがって，⑵は適当である。」 「【正解】⑷」

など**正答を明示する記述**が含まれる（公開中ページで受験者に答えが見えている＝ `docs/reference/image-policy.md` の答え漏らし禁止に違反）。加えて問題文（「適当なものはどれか」）・凡例外テキストの写り込みも多い。

## 3つの重要な制約（実証済み）

1. **スキル再抽出は不可能**: 問題PDF（`docs/textbook/１級土木施工管理技士/過去問/{H30,R01,R02,R07}/…問題A.pdf`）は**完全テキストのみ**（"DHP-A.smd" ＝テキスト起こし版・埋め込み画像0・pdftoppm でも図が出ない）。**H26/H27 は PDF 自体なし**。→ 図は**解答資料側にしか存在しない**ので、`/civil-figure-rework`（問題PDFから切り出す設計）は全ページで空 spec を返す。**このスキルは本件に使えない**。
2. **自動クロップは信頼不可**: OCR で文章行を検出して切る方式は、図の**凡例**（"Uc≥10：粒度分布がよい。" 等、句点を含む正当な図要素）を文章と誤認して**図を切りすぎる**。問題文が図の高さまで及ぶページでは逆に**図をクリップ**する。→ **1図ずつ目視の手作業が必須**。
3. **一部は切り直し不可**: 元クロップ時点で図が既に見切れている図（例: `h30-a-fig-04` の図2/図3、`r01-b-fig-03` の網目工程図）は、元図が手元に無いため**切り直しでは直せない**。→ **SVG再描画 or 除去**が必要。

## 実行手順（手動・1図ずつ）

```bash
# 1. 現図を確認（webp→png変換して Read）
sips -s format png <img.webp> --out /tmp/x.png   # Read で目視、テキスト帯の位置を判断
# 2. 上帯 or 下帯を除外して切り出し（frac は目視で調整、-trim で外周白を詰める）
magick <src.png> -crop ${W}x$((H-y0))+0+${y0} +repage -trim +repage -bordercolor white -border 12 <out.png>
# 3. OCR で答え/文章が消えたか検証
tesseract <out.png> - -l jpn --psm 6   # 「したがって」「適当」「正解」等が消えたこと
# 4. 実ファイルへ適用 + webp 生成
cp <out.png> <real.png>; magick <real.png> -quality 82 <real.webp>
# 5. MDX の width/height を新寸法へ更新（重要・アスペクト比崩れ防止）
# 6. node .claude/scripts/audit-exam-figures.mjs で broken_image_reference:0 確認
# 7. ページ単位でコミット（明示 pathspec・並行セッション注意）
```
