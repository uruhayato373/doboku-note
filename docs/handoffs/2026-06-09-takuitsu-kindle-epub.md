# 択一 Kindle/note 販売 試作（2026-06-09）

## 背景・意思決定

「サイトのアクセスが期待できないので、択一を PDF で note 販売したらどうか」という相談から出発。
検討の結果、以下を合意した。

- **生の年度別過去問をそのまま売るのは筋が悪い**（自サイトで無料公開中・無料代替が飽和）。
  択一を素材に**論点別へ再構成した編集物**として価値を載せる。
- **主チャネルは Kindle (KDP)**。Amazon の検索市場・Kindle Unlimited が集客を肩代わりするため、
  「サイト集客ゼロ」の悩みに最も効く。note は SNS ファネルが育った後の従チャネル。
- 著作権は **1級/2級土木は試験実施機関（全国建設研修センター）のクレジット表示**で使用可（ユーザー判断）。

## 実施内容

1 ソース（構造化全問 JSON）から **Kindle 用 EPUB** と **note 用 PDF/Markdown** を出すジェネレータを試作。

| 項目 | 内容 |
|---|---|
| ジェネレータ | `scripts/build-takuitsu-reconstruct.mjs`（`--format md\|epub\|both`） |
| 入力 | `src/config/civil-1-exam-questions.json`（H26〜R07・1162 問・構造化済み） |
| 試作テーマ | 安全管理（抽出 194 → 図版依存 4 除外・同趣旨 30 圧縮 → **収録 160 問・9 論点**） |
| 出力（.tmp） | `anzen.epub` / `article.md` / `print.html` |
| 試作メモ | `docs/note/1級土木/takuitsu-pdf-prototype.md` |

### 差別化の中身（再構成ロジック）

1. 論点別に解体（足場・墜落／明り掘削・土止め／型枠支保工／車両系建設機械／クレーン・玉掛け／ずい道／酸欠・有害物／感電・架空線／安全衛生管理体制 の 9 論点へ自動振り分け）
2. 各論点冒頭に「論点まとめ（覚える正しい知識）」＝正答選択肢解説（法令条文付き）を集約・重複圧縮
3. 一問一答を年度横断で連続演習・各問に正答＋要点
4. 同趣旨の反復設問は最古年に集約し注記

### 検証済み

- EPUB 構造: mimetype 先頭・無圧縮、container/opf/nav/ncx 完備
- 全 XHTML/OPF/NCX が **well-formed**、未エスケープ `&`・文字化け・数式混入なし
