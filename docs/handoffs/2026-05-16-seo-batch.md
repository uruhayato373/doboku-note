## キーとなる気づき

### 1. svg-audit のバグ (見逃しゾーン)

`detect.mjs` の `TOKENS_PATH` 解決が `.claude/design-system/svg-tokens.json`（実在しない）を指していて、`ALLOWED_COLORS` が空セットになっていた。結果として **SVG の全色が「allowlist 外」と誤判定**されていた可能性が高い（過去の svg-audit 結果も同じバグの影響を受けている）。

修正後、figure-2-4.svg は 8 件 → 2 件 → 0 件 と段階的にクリーン化。今後 svg-audit を再実行する際は、ロード失敗時の警告 (`console.warn`) を必ず確認すること。

### 2. seoTitle suffix 重複バグ (構造的問題)

Next.js metadata の `title template` `%s | doboku-note` は自動付与されるため、frontmatter の `seoTitle` に `| doboku-note` を手書きすると重複する。本日 22 件修正したが、他カテゴリ（reference 系・guide 系）にも同じパターンが残っている可能性あり。次回 GSC 取得時にチェックポイント。

memory: `metadata-title-template` 参照。

### 3. note.com 動線が依然 Hidden Winner

GA4 でセッション 92 / engagement rate 76% / 4.4 sessions/user という最高水準の流入源。本日は手をつけなかったが、note 記事追加 or CTA 改善で sessions を倍増できる可能性が高い。
