# AdSense「有用性の低いコンテンツ」— 低品質ページ抽出と対応方針

作成: 2026-07-04 / 対象: doboku-note 全 1,051 URL / 却下理由: 「有用性の低いコンテンツ」（直近1-2ヶ月で2-3回）

---

## 結論（先に）

1. **主因は「薄い/独自性の低いページがサイトの25%を占める」こと**。Google URL Inspection（2026-07-01, 全1,051 URL）で **265本（25.2%）が非インデックス**。Google 自身が「クロール済み - インデックス未登録」240本＋「検出 - 未登録」25本と判定している。AdSense の「有用性の低いコンテンツ」はこの構造をほぼ直接反映する。
2. **画像クロップは主因ではない**。懸念された極小PNG 8枚を実測 → 解像度は 500〜1215px 幅で十分、小サイズは単純な線画ゆえの高圧縮。過去の審査分析にも画像指摘なし。→ **今回の審査対策から画像は外してよい**（200×180の2枚のみ小さいが機能はしている）。
3. **内部品質スコアは当てにならない**（最重要）。非インデックスの166本のCEMキーワードページは **全て内部ルーブリックに合格**（weighted 2.2〜3.0・うち54本が2.8以上）しているのに Google はインデックスしていない。内部ルーブリック（構造30%・モバイル25%・原則20%・参考資料15%・リンク10%）は**体裁の遵守度**を測っており、Google が見る**独自の情報価値**とは別物。→ 「weighted ≥ 2.5 をQAゲートにする」旧方針は無効（既に満たしている）。判定は**実際の散文密度**で行う。
4. **長い非インデックスページ（過去問・textbook）は「薄い」のではなく「重複/独自性」問題**。過去問CEMは3万字超でも非インデックス。過去問設問文は競合サイト（pejp.net 等）に逐語で存在するため Google が重複と見なす。長くしても直らない。別処置（独自の解説・傾向分析レイヤーの付加）か構造的な割り切りが必要。

## なぜ「有用性の低いコンテンツ」なのか（因果整理）

AdSense 審査は **人間のレビュアーがサイトをサンプリングして総合価値を判定**する。Google 検索のインデックス判定とは別プロセスだが、**同じ根**を見る:

- **辞書型テンプレの大量生産**: CEMキーワードは640ページが「定義→図→位置づけ→参考資料」の同一テンプレ。各ページの独自散文が130〜数百字だと、レビュアーにも Google にも「量産された薄いページ」に見える。166本が非インデックスなのはこの兆候。
- **過去問の逐語転載**: 過去問設問は公開情報だが競合と重複。解答解説の独自性が薄いと「付加価値の少ないアフィリエイト/スクレイプ的コンテンツ」と判定されうる。
- **サイト全体の希釈**: 良質なガイド記事があっても、薄いページが25%あると平均品質が下がる。

→ **AdSense に効くのは「レビュアーがサンプリングしそうなページ（＝インデックス済みで流入のある実記事）の価値を担保しつつ、薄いページの割合を下げる」こと。** ユーザー方針で noindex は不使用のため、**薄いページを実質的に厚くする**のが唯一の手段。

## 対応方針（優先度順）

### 最優先: W1 CEMキーワード薄層（166本）を散文増補

- **QAゲートの変更**: 内部 weighted は使わない（既に合格）。判定は **本文実測字数 + 独自散文の密度**。目標: 各ページ本文 3,000字以上、かつ定義の丸写しでなく「実務での使われ方・試験での問われ方・関連概念との差異」を独自に記述。
- **着手順**: 本文短い順。本文2,000字未満の24本 → 2,500字未満の70本 → 残り。
- **手段**: `keyword-rewriter`（Generator）で増補 → スポットで `cem-qa` ＋ **人手読み**で散文が実質的に増えたか確認（rubric合格だけで満足しない）。事実加筆時は WebSearch 一次情報照合（LLM は試験統計・制度を外す）。
- **規模の正直な見積もり**: 166本の品質リライトは**複数セッションの作業**。本セッションでは最短ページから着手し、完了数と残リストを本レポート末尾に記録する。

### W2 転職ガイド8本

`guide-qa` → `guide-rewriter`。年収・統計は `guide-fact-checker` 必須。

### W3/W4/W5/W7 長尺の重複ページ（本質は独自性）

- **長くする処置は無効**（既に長い）。過去問は各年度ページ冒頭に「その年度の出題傾向・分野構成・難易度・攻略順序」の**独自散文**を付加して転記オンリー構造を解消（`past-exam-rewriter`、設問文・正答は不変）。
- ただし過去問は構造的に重複性が高く、全てをインデックスさせるのは困難。**AdSense 対策としての優先度は W1 より低い**（レビュアーが薄いと感じるのは短いページ）。

### 補助（軽量・即効）

- **極小PNG**: 対応不要（実測で解像度十分）。200×180の `fig-2-42a/b` のみ将来余裕があれば再描画候補。
- **CLS超過2ページ**（`civil-construction-1-primary-r07-a` 0.176 / `pe-comprehensive-management-r07-primary` 0.151）: AdSense枠に `width`/`height` 明示。UX/CWV改善で審査にプラス。

## 再申請 SOP（ユーザー作業）

1. リライト＆deploy 後、GSC で sitemap 再送信 ＋ 強化した主要URL 10〜20本の手動インデックス登録リクエスト。
2. インデックス反映を1〜2週間観察（非インデックス率が下がるか）。
3. **前回却下から2〜4週間空けて再申請**（短間隔の連続再申請は逆効果）。
4. 既存チェックリスト: `docs/project/_archive/03_civil-adsense-resubmission.md:147-191` を流用。
