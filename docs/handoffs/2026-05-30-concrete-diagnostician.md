## 過去問（択一）— 非出荷の判断と根拠

方針: ユーザー判断で「技報堂本から転記（下書き限定）」「フルスロットル」。公式は正解肢のみ公開で問題文非公開のため、原典が唯一の出所。

実施: PDF9（厳選101問の前半）を **rotate 90°CW → 左右分割 → transcribe→verify** workflow（26頁・問題53・エージェント52・約145万トークン）。

結果（`/.tmp/cd-transcribe-report.json`）:
- **照合パス 3頁 / 26頁（問題5/53のみ）**
- **問題の58%（31/53）が図依存**（選択肢が図・写真）→ テキストのみ転記では不完全
- テキスト問題でも逐語誤りが頻発（照合が具体検出: 「藻類」→「漆喰」, 「ような」脱落, 「ブラケット」→「プラケット」, 「バー法」→「バーで法」等）
- **正答が別頁**にあるケースが多く、エージェント提示の正答は一部推定（捏造リスク）

判断: プロジェクトの**反捏造ゲート**（content-principles / exam-content-policy の原典視覚突合必須）に照らし、誤りを含む転記は下書きでも**出荷しない**。

## 過去問を正しく整備するための継続手順（follow-up）

1. **回転補正パイプライン（実証済）**: `pdftoppm -r 200` → `magick -rotate 90` → 左右分割。スクリプト雛形 `/.tmp/render-rot.sh`。診断士スキャンは頁により回転が不統一（PDF9問題頁=90°回転、PDF10解答頁=正立）なので頁ごとに確認。
2. **図依存問題は図クロップ必須**: 選択肢が図の問題は、civil-exam-figure 方式（高解像度頁→bbox→crop→webp）で図を収録してからでないと成立しない。図クロップ雛形 `/.tmp/crop-figures.mjs`（正規化bbox→crop）。
3. **正答は解答一覧表で確定**: 厳選101問の解答一覧は PDF10 p16-18（正立・読める）。`問題番号→正答` を一括転記して各問に紐付ける（頁内の解説のみに頼らない）。
4. **逐語は transcribe→verify→self-repair ループ**: 雛形 `/.tmp/wf-transcribe.mjs`。verify の具体指摘を feedback に再transcribe。テキストのみ問題から着手し、図依存は (2) と合流。
5. 残り: PDF9 後半の照合不合格分 + PDF10（問題54-101、図依存が多い）。記述式（II部, PDF7-9）は別途。

代替案: 上記は労力大。ユーザー当初案どおり、択一は**運営者オリジナル作問**（分野別・公開可能）に切替える選択肢も有力。
