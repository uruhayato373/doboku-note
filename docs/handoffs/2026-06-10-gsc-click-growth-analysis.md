## 結論

クリックが伸びない真因は **CTR が低いことではなく、増えた露出（impression）の 62% が受験者に届かない一般用語に乗っていること**。さらに受験意図クエリの中でも、勝てているページが**ページ1下部（6〜9位）に滞留**しており、上位3位に届いていない。ページ不足ではなく**順位停滞**が問題。

## 技術SEO監査（2026-06-10 追記2）— 真の制約はドメイン権威

「他にSEOでできることは」の問いを受けた全面監査の結論：**on-page SEO は既に強く、伸びしろは off-page（権威）にある**。

### 監査結果
- **SEO基盤: 良好**。docs ページは canonical・TechArticle JSON-LD・FAQPage schema・BreadcrumbList を出力済み。sitemap/RSS 生成あり。PSI 平均 SEO 98.8 / Performance 95.5 / A11y 95.7。
- **CWV: ほぼ良好、局所違反2件のみ**。`textbook-quality-management-text`（PERF69/CLS0.11/TBT644）、`primary-h26-a`（TBT289）。`/category` が SEO83（description は出力済み、要因は別・低優先）。
- **🔴 最大の制約: インデックス未登録 ~40%**（2026-04-27 url-inspection 189URL サンプル: 登録113 / 検出-未登録61 / 未認識14）。未登録に `fmea` `fail-safe` `eta` 等の受験コア語を含む。**未登録ページは何をしても露出ゼロ**。
- **未登録の原因切り分け**: 未登録ページは薄くない（平均2583字 vs 登録済み2720字・中央値2522字）。`fmea` は内部リンク8本＋pillar 構造あり。→ **薄さでもリンク不足でもなく、若いサイトが類似661ページを一度に出したことによる Google のクロール/インデックス予算の出し惜しみ**（典型）。
- **訂正**: 先に「HAZOP/RCA は専用ページ無し」としたが誤り。`hazop`(HAZOP)・`root-cause-analysis`(根本原因分析) は存在。コンテンツギャップは実質なし。

### 含意（投資の向き）
on-page をこれ以上いじっても限界効用は小さい。**クリックを伸ばす本命レバーは「ドメイン権威の獲得 → インデックス登録率の改善」**で、これは note/SNS/YouTube の外部流入・被リンク・指名検索＝既存の多チャネル戦略がそのまま SEO レバーになる。SEO 専用の追加作業より、既存戦略の継続が効く。

### できること（優先度順・権威レバー中心）
1. **インデックス再計測**（CI 経由・url-inspection / coverage）。データが6週間前で古い。露出が伸びている以上、登録率は改善している可能性あり → まず現状把握。※ローカルは社内プロキシで GSC API 遮断のため CI 供給が必要。
2. **優先受験語ページの手動インデックス申請**（GSC URL検査 → 登録リクエスト）。`fmea` 等のコア語を優先。
3. **類似ページの大量追加を一旦抑制**。未登録が捌けるまで新規量産は登録率を下げうる。
4. **外部権威の継続獲得**（note/SNS/YouTube）＝インデックス登録率を底上げする本命。
5. **CWV 局所修正**（`textbook-quality-management-text` の CLS/TBT）。ランキング微改善。
6. **データ起点の略語タイトル補完**（GSC で略語クエリ露出のあるページ限定。OEE/許容原価は対応済。無差別217件の一括書換は禁止＝大半ノイズ）。
