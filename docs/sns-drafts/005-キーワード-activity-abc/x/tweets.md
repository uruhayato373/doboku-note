## Tweet 01: 定義編

【総監キーワード解説】活動基準原価計算 ABC #1

ABC（Activity Based Costing）とは、製品やサービスが消費するアクティビティ（活動）を基準に間接費を配賦する原価計算手法。

従来の直接作業時間配賦では多品種少量生産の原価が歪むという問題を解消する。

## Tweet 02: 手順編

【総監キーワード解説】ABC #2

ABC の手順は 4 ステップ:

1. アクティビティを識別（検査・段取替え・運搬等）
2. コストプール（費用集計単位）を設定
3. コストドライバー（配賦基準）を選定
4. コストドライバー量に応じて製品にコスト配賦

「何の活動が」「どれだけの量で」コストを発生させたかを追跡するのが核心。

## Tweet 03: 2 段階配賦編

【総監キーワード解説】ABC #3

ABC の精度を支える 2 段階配賦

▼ リソースドライバー（資源ドライバー）
資源 → 活動 への配賦
例: 人件費を作業時間で活動に割り当てる

▼ アクティビティドライバー（活動ドライバー）
活動 → 製品 への配賦
例: 検査回数を製品に割り当てる

「資源 → 活動 → 製品」の 2 段階が ABC の特徴。

## Tweet 04: 引っかけポイント編

【総監キーワード解説】ABC #4

試験で狙われる引っかけ 3 つ

1. ABC ≠ ABM。ABC は計算手法、ABM は ABC の結果を活用した管理手法
2. MFCA との違い。MFCA は物質・エネルギー流れで集計（ISO 14051）、ABC は活動単位
3. 適用範囲。多品種少量生産で有効、少品種大量生産では従来法で十分

MFCA は経済性 × 社会環境管理の接点で頻出（H21・H26・R01）。

## Tweet 05: 計算例 + CTA

【総監キーワード解説】ABC #5（最終回）

計算例: 製品 A・B の検査時間 100 時間と 200 時間、検査費総額 60,000 円

▼ 配賦率 = 60,000 / 300 = 200 円 / 時間
▼ 製品 A 配賦額 = 200 × 100 = 20,000 円
▼ 製品 B 配賦額 = 200 × 200 = 40,000 円

ABC の核心は「活動量に比例して配賦」すること。doboku-note で全解説。
