- メインテキスト:

### Slide 3: 5 段階ピラミッド（メインビジュアル）

- 上部ラベル: 「核心の図解」(positive #3a7d44)
- 図解: 既存 SVG `maslow-pyramid.svg` を全面表示
- 注記:
  - 下から: 生理的 → 安全 → 社会的 → 承認 → 自己実現
- 強調: 「下位欲求の充足が上位欲求の発現条件」(brand)

### Slide 4: 第 1〜2 段階（低次欲求）

- 上部ラベル: 「低次欲求」(brand)
- リスト:
  - **第 1: 生理的欲求** — 食事・睡眠など生存に不可欠 / 職場: 適切な賃金、休憩時間
  - **第 2: 安全欲求** — 身体的・経済的な安全 / 職場: 雇用の安定、労働安全衛生、福利厚生
- 補足: 「ここが満たされなければ高次へ進めない」

### Slide 5: 第 3〜4 段階（中次欲求）

- 上部ラベル: 「中次欲求」(brand)
- リスト:
  - **第 3: 社会的欲求（所属と愛）** — 集団に所属・仲間が欲しい / 職場: 人間関係、チームへの帰属
  - **第 4: 承認（尊厳）欲求** — 他者から認められたい / 職場: 昇進、表彰、専門資格の取得
- 補足: 「第 3 と第 4 を逆順に覚える誤りが多い」

### Slide 6: 第 5 段階 + 自己超越（高次欲求）

- 上部ラベル: 「高次欲求」(brand)
- メインテキスト:
  - **第 5: 自己実現欲求** — 自分の可能性を最大限発揮 / 職場: 挑戦的なプロジェクト、創造的業務
- 補足:
  - 晩年のマズロー: 自己実現の上位に **自己超越欲求**（他者・社会への貢献）を加え 6 段階説も提唱
- 強調: 「自己実現は他の欲求と性質が異なる」(positive)

### Slide 7: 欠乏欲求 vs 成長欲求

- 上部ラベル: 「2 つの性質」(brand)
- 比較表:
  - **欠乏欲求（第 1〜4）**: 不足すると不満が生じる / 充足すれば動機づけが弱まる
  - **成長欲求（第 5）**: 満たされてもさらに追求し続ける
- 強調: 「自己実現だけが性質的に独立」(positive)

### Slide 8: 実務への適用

- 上部ラベル: 「マネジメントへの応用」(brand)
- メインテキスト: 「部下が現在どの段階か見極める」
- 例:
  - 雇用不安（安全欲求）を抱える部下 → 自己実現的課題は効果薄
  - 安全・社会的欲求が充足 → 承認・成長機会の提供が効果的
- 補足: 「ハーズバーグの二要因理論と組み合わせて施策立案」

### Slide 9: 引っかけポイント

- 上部ラベル: 「試験で狙われる」(warn #d4a017)
- 番号付きリスト:
  1. **段階の順序を逆** — 承認 ⇔ 社会的の入れ替え誤りが多い
  2. **ハーズバーグと混同** — マズロー = 5 段階、ハーズバーグ = 動機づけ vs 衛生の 2 要因
  3. **マクレガー XY と混同** — マクレガー = 人間観の 2 分類（X 性悪・Y 性善）
