[5-17秒] 問題提示
「品質管理における管理限界の説明として正しいものはどれでしょうか。選択肢は、1、製品の規格値に基づいて設定される値。2、統計的に計算される工程監視用の値。3、顧客が要求する品質の許容範囲。4、管理図の中心線と同じ意味です。」

[17-20秒] 沈黙（考える時間）

[20-25秒] 答え発表
「正解は、2、統計的に計算される工程監視用の値です。」

[25-36秒] 解説
「管理限界は工程のばらつきをもとに統計的に計算される値であり、製品の規格値とは全く異なる概念です。管理限界を規格値に設定するのは誤りです。この混同を狙った出題は頻出なので注意しましょう。」
