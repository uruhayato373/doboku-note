[5-16秒] 問題提示
「売上高の年間平均倍率を求めるのに適した平均はどれでしょうか。なお、一昨年から昨年は 2 倍、昨年から今年は 8 倍です。選択肢は、1、算術平均。2、幾何平均。3、調和平均。4、加重平均です。」

「正解は、2、幾何平均です。」

[24-35秒] 解説
「倍率・比率・成長率の平均には幾何平均を用います。速度の平均は調和平均、試験の平均点のような単純な代表値は算術平均です。3 種類の使い分けは頻出なので整理しておきましょう。」
