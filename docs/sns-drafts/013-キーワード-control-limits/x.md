## Tweet 01: 定義編

【総監キーワード解説】管理限界 #1

管理限界（Control Limits）とは、上方管理限界線（UCL）と下方管理限界線（LCL）であり、工程が統計的管理状態にあるかどうかを判定する基準線。

中心線（CL）から ±3σ（標準偏差の 3 倍）の位置に設定。

## Tweet 02: 管理図の構成編

【総監キーワード解説】管理限界 #2

管理図は 3 本の水平線で構成

▼ UCL — CL + 3σ（上方管理限界線）
▼ CL — データの平均値（中心線）
▼ LCL — CL − 3σ（下方管理限界線）

±3σ で約 99.7% が範囲内に収まる。

## Tweet 03: 管理限界 vs 規格限界編

【総監キーワード解説】管理限界 #3

最重要の混同ポイント

▼ 管理限界 — 工程のばらつきから統計算出（±3σ）
▼ 規格限界 — 設計で決定（製品が満たすべき値）

管理限界 < 規格限界 が望ましい。

混同すると本質を見失う。

## Tweet 04: 異常判定編

【総監キーワード解説】管理限界 #4

異常判定 3 ルール

1. 点が管理限界線を超える
2. 点が中心線の片側に連続して並ぶ（連）
3. 点が一方向に連続して増減（傾向）

管理限界内でも連・傾向があれば異常！
