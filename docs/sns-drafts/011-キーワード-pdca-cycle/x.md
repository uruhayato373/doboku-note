## Tweet 01: 定義編

【総監キーワード解説】PDCA サイクル #1

PDCA サイクルとは、継続的改善を実現する循環型マネジメント手法。

Plan（計画）→ Do（実行）→ Check（検証）→ Act（改善）の 4 段階を繰り返し、回し続けるほど業務水準が螺旋階段状に向上する。

## Tweet 02: 4 段階編

【総監キーワード解説】PDCA #2

4 段階の内容

▼ P: Plan 計画 — 目標設定・行動計画の策定
▼ D: Do 実行 — 計画に基づき実施
▼ C: Check 検証 — 実績・課題の評価
▼ A: Act 改善 — 標準化・次計画への反映

A は Action ではなく Act！

## Tweet 04: 引っかけポイント編

【総監キーワード解説】PDCA #4

試験で狙われる引っかけ 3 つ

1. 段階順序の入れ替え — 正解は P → D → C → A
2. Action と Act の混同 — 正解は Act（改善）
3. OODA との混同 — OODA（Observe/Orient/Decide/Act）は別の意思決定ループ
