## doboku-note のポジショニング

### 強み

1. **技術ドキュメントとしての品質**: MDX + KaTeX（数式）+ Mermaid（図表）で、Google Sites やブログ勢より表現力が高い
2. **横断的なカバレッジ**: 土木工学・道路・河川・法律を一箇所でカバー。競合は特定分野特化が多い
3. **サーバーコスト極小**: Cloudflare Pages で運営コストがほぼゼロ → 収益化のハードルが低い
4. **法律カテゴリの独自性**: 「土木技術者が知るべき法律」という切り口は競合不在

### 弱み（改善機会）

1. **コンテンツ量が圧倒的に少ない**: 16ファイル vs 競合は数百〜数千ページ
2. **河川・法律カテゴリが未開始**: サイト構成で謳っているが中身がない
3. **資格試験対策コンテンツなし**: 施工管理技士・技術士の検索需要を取れていない
4. **AdSense 未最適化**: 導入済みだが配置・形式の最適化がされていない
5. **アフィリエイト未導入**: 書籍・通信講座のリンクが一切ない

### 脅威

1. **アガルートのSEO攻勢**: 無料コラム大量投入で検索上位を独占。資格試験系クエリで正面衝突する
2. **過去問ドットコムの壁**: 過去問解説で勝負するのは困難（75万ユーザー、90資格）
3. **企業メディアのドメインパワー**: マネーフォワード、契約ウォッチ等は法律系クエリでドメイン力で上位
4. **PRIDE（ティーネットジャパン）**: 土木×法律で400ページ超。doboku-note の法律カテゴリと直接競合
