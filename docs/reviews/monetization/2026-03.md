|---|---|---|---|
| 悲観（現状） | 2,000 | ¥300 | **¥600** |
| 標準（半年後） | 10,000 | ¥500 | **¥5,000** |
| 楽観（1年後） | 50,000 | ¥700 | **¥35,000** |

- **UX影響**: 低（記事末尾1箇所から開始）

- **検証実験**: 記事末尾1箇所配置 → 2週間でRPM・直帰率を計測。成功基準: RPM≥¥200

### 4. 資格試験対策 × note有料記事販売（推奨: ★★★★☆）

- **仕組み**: doboku-note.com の無料リファレンスを土台に、試験対策に特化した有料コンテンツを note.com で販売
- **プラットフォーム**: note.com（手数料: 単品10%、定期マガジン20%、決済・集客基盤が不要）

#### 棲み分け戦略

| | doboku-note.com（無料） | note.com（有料） |
|---|---|---|
| **役割** | リファレンス・基礎知識・網羅的解説 | 再構成・要点整理・解法パターン・テンプレート |
| **読者行動** | 検索で来て調べる | 「合格したい」動機で購入する |
| **コンテンツ例** | 共通仕様書の全文解説、道路法の逐条解説 | 「1級土木 頻出50選」「技術士 論文テンプレ」 |
| **SEOへの影響** | 直接的にインデックス対象 | noteドメインからの被リンク＋ブランド認知 |

**原則**: 無料サイトに既にある内容をそのまま有料化しない。**無料=素材、有料=加工品**として明確に差別化する。

## 収益シナリオ全体像（6ヶ月後）

| 収益源 | 悲観 | 標準 | 楽観 |
|---|---|---|---|
| AdSense | ¥600 | ¥5,000 | ¥35,000 |
| Amazon 書籍 | ¥18 | ¥315 | ¥6,000 |
| 通信講座アフィリエイト | ¥225 | ¥5,000 | ¥80,000 |
| **note有料記事** | **¥10,800** | **¥72,900** | **¥270,000** |
| **合計** | **¥11,643** | **¥83,215** | **¥391,000** |

**note有料記事が収益構造を根本的に変える。** 広告・アフィリエイトは PV 依存（トラフィック×低単価）だが、note は価値×購入者数で収益が決まる。少ないトラフィックでも高い収益を狙えるため、現在のサイト規模（672ページ、PV 1,000〜5,000）でも十分に機能する。

AdSense + AmazonLink の配置は数時間で完了する。それと並行して4月中にnoteテスト販売を開始し、収益の柱を早期に確立する。
