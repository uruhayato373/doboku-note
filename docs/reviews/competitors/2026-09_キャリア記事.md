# 転職メディア競合（キャリア記事の勝ち型）

> [!note]
> 2026-09-22 時点の調査記録（旧 docs/strategy/07 の該当節を移したもの）。数字・競合名は調査時点のスナップショット。引用時は調査日を確認する。索引は [README](./README.md)。

> **個人サイト型の競合は別節**: 同じキャリア記事の SERP には求人事業者メディアだけでなく、運営者ペルソナが重なる個人サイトも入る。→ [現場技術者のキャリアノート（genba-career.com）](#現場技術者のキャリアノートgenba-careercom)

試験対策の競合とは別軸。キャリア記事の SERP は**求人事業者が自社メディアとして運営する「おすすめ○選」型のリスティクル**が占める。運営元が紹介先の一方でもあるため、順位は掲載都合で動きうる。

観測（2026-08-21）: 主要クエリの上位は同型の比較記事で埋まり、掲載されるサービス数値（求人件数・満足度）は各社公式ではなく**記事間で相互に転記**されている。実際に公式サイトを開くと、求人件数を出さない社、対応エリアを書かない社があり、公表の粒度は揃っていない。

doboku-note の差別化は 3 点。

1. **公表値だけで比較し、書かれていない項目は「記載なし」と明示する** — 転記された数値を並べる記事に対し、一次確認と確認日を持つ。何を公表していないかも判断材料として出す
2. **資格・工種・工事規模・役割で評価が変わることを説明できる** — 求人事業者のメディアは職種の粒度で止まる。土木の工種差と発注者/元請/下請の立場差を扱えるのは試験サイト側の資産
3. **発注者側から見た「任せやすい技術者」の条件を語れる** — 運営者の真正な経験座（元自治体土木）。転職支援者・採用担当者としての実績は主張しない

Red Line: 実利用していないサービスの体験談、転職成功例、想定年収、成功率、口コミの転載はしない。実装ルールは `.claude/knowledge/reference/affiliate-operations.md`。

### SERP 現況の再観測（2026-09-22・土木公務員クラスタ 6 クエリ）

第 2 波の企画に合わせ、6 クエリ（公務員 土木 辞めたい／土木 公務員 年収 給料表／公務員 技術職 勉強法／RCCM とは／土木公務員 技術士 必要／発注者支援 転職）の上位 3〜4 件、**計 20 URL を実読**した。**うち 2 件は内容を取得できていない**（`dobomen.com` は DNS 到達不可、`note.com/mechaservant` の該当記事は 404 でアカウントが休止中）。取得できなかったものを「競合が居ない」とは扱わない。順位は日・地域・パーソナライズで動くため「上位に出た」までを記録し、N 位とは書かない。

**上位を占める型はクエリで割れる。**

| クエリ | 上位の型 |
|---|---|
| 公務員 土木 辞めたい | 個人ブログと求人事業者が拮抗 |
| 土木 公務員 年収 給料表 | 予備校 2＋個人ブログ 1 |
| 公務員 技術職 勉強法 | 予備校・スクールが占める |
| RCCM とは | 業界団体の公式・業界メディア・求人事業者が混在 |
| 土木公務員 技術士 必要 | 個人ブログ・講習機関・業界メディアが混在 |
| 発注者支援 転職 | 求人事業者（専門特化サイト含む）がほぼ独占 |

**一人称の体験が効くクエリと、公式が動かないクエリを分けて扱う。** 「辞めたい」「年収 給料表」「技術士 必要」の 3 つは、経歴開示を伴う個人ブログが上位に出ている。本サイトは他者の体験談を書けない規約なので、ここは同じ武器では戦えない。一方「RCCM とは」は建設コンサルタンツ協会の公式ページが上位＝制度の一次情報そのもので代替不可。「発注者支援 転職」は公式ではなく求人事業者が占めており、**制度の仕組み・必要資格・キャリアパスをまとめた解説型のページが見当たらなかった**＝コンテンツで割り込む余地がある。

**一次資料の個別リンクは、思ったほど貼られていない。** 20 件中、一次資料を実際にリンクしていたのは 7 件で、多くは制度名の言及止まりだった。個別 URL まで揃っていたのは `conma.jp` の技術士記事（e-Gov 技術士法・日本技術士会の試験実施大綱 PDF・e-Stat 賃金構造基本統計調査）が最も密度が高い。本サイトが「制度名＋PDF の個別 URL＋確認日」まで出せば差になりうるが、**順位や CTR への効果は未検証**なので施策の前提にはしない。

取得方法は WebFetch のページ要約で、逐語確認はしていない。単独ソースにしか出てこない属性（運営主体名など）は未検証として扱う。

### キャリア記事の勝ち型（実読から抽出）

14 本すべてが同一の骨格で書かれており、再現可能なテンプレートになっている。

1. **想定読者の明示**（多くの記事が「この記事の想定読者」を独立ブロックで置く）
2. **一人称の経歴開示を冒頭に**（「32歳のとき、地方公務員を辞めて建設コンサルタントに戻りました」）
3. **判断軸の番号付け**（判断①健康ライン → ②自分の頑張りで変えられるか → ③市場価値を数字で見る）
4. **③の位置に CTA を置く**（「市場価値を数字で見る」は読者の次の行動と広告が一致する唯一の場所。全記事で CTA はここか記事末の `SPONSOR — 広告(PR)` 枠）
5. **反対側も書く**（「辞めない方がいい人も、はっきりいる」「やめたほうがいい転職」）
6. **記事間を実名リンクで回す**（年収記事 ⇄ エージェント記事 ⇄ 判断軸記事 ⇄ 体験記の相互リンク。年収記事が最も多く参照される「証拠置き場」になっている）

**エンジンは「自分の実額・実年齢・身体症状の開示」**。年収記事は 24→38 歳の 4 段階を実額（400万→450万→600万弱→650万）で表にし、「線が立ち上がっている場所は昇給ではなく転職」と読ませる。公的統計は使わず、代わりに「あくまで一人の技術者の実例で、地域差・会社差は大きい」と限定を付けて信頼を担保している。

doboku-note の同種記事はこの逆で、公的データ（job tag の平均年収約600万、建設業 29歳以下 約12%、上限規制 月45時間）を根拠に三人称で書く（`content/site/civil-construction-1/guide-quit-or-stay/article.mdx`）。**論点の網羅では負けていないが、読者が「この人の話」として読む力では負けている。**

### 脅威評価と差別化所見

**脅威は限定的だが、当たる面が 1 つだけ深い。**

- 試験対策本体は競合しない（過去問 0 本・総監 0 本）。**受験者を取られる恐れはほぼない**
- 当たるのは**キャリア/転職クラスタのみ**。ここは doboku-note にとって転職アフィリの収益面であり、13 の SEO 戦略の主戦場でもある。同一広告主・同一キーワード・同一ペルソナで、相手は一人称の物語を持っている
- ただし相手の**権威性は doboku-note が上回る**。RION は RCCM 保有・技術士は受験中で、資格記事も「私も挑戦しており」の立場。doboku-note の運営者は技術士（建設部門・総合技術監理部門）を含む 10 資格保有（`src/config/author.ts`）。「取った人が書いている」は相手が原理的に出せない差
- 実務設計解説 45 本は doboku-note の空白だが、**試験対策ハブという事業定義の外**。道路構造令の数値（片勾配・視距・縦断曲線）だけは 1 級土木・技術士の出題範囲と重なるため、試験文脈での新設候補としては検討余地がある

**結論**: 対抗すべきはキャリア記事 1 領域に絞る。打ち手は「相手が持たない権威（資格保有・発注者の座）で、相手と同じ一人称の具体性を出す」こと。企画は [13_土木公務員SEO戦略2026-08.md](../../strategy/13_土木公務員SEO戦略2026-08.md) の「キャリア記事ラインナップ」節に置く。
