## マガジン設計

### コンセプト

「合格答案の『空気』を月2回吸い込む」

- 技術士二次の論文は「型」+「空気感」で決まる
- 型は N-4 で提供済み。本マガジンは「合格する論文はここが違う」を実例で伝える
- 添削形式で「よくあるNG」と「合格レベルへの修正」を見せる

```
## 添削ポイント（5つ）

### ポイント1: 「多面的」の意味を正しく使えているか
[NG例] 「技術的課題、技術的な問題、技術に関する事項」← 全部同じ視点
[OK例] 「技術的課題、社会的課題、経済的課題」← 3つの異なる切り口
→ 採点者は「多面的」=「異なるカテゴリの視点」を求めている

### ポイント2: 解決策に具体的技術名があるか
[NG例] 「新技術を活用して効率化を図る」
[OK例] 「UAV搭載型レーザスキャナによる3次元測量を導入し、測量工程を従来比40%短縮する」
→ 抽象的な記述は「理解していない」と見なされる

### ポイント3〜5: [同様の構成]

---

## 今回のセルフチェック
□ 課題が3つの「異なる視点」から書かれているか
□ 解決策に固有名詞（技術名・制度名・数値）が入っているか
□ リスクが解決策の「裏返し」になっているか
□ 倫理と持続可能性が空疎なお題目になっていないか
□ 答案の90%以上を埋められたか
```

## 運用設計

### 制作フロー

1. 過去問からテーマを選定 + 模範論文の構成メモ（30分）
2. 模範論文の執筆（2時間）
3. 添削ポイント / ビフォーアフターの作成（1.5時間）
4. セルフチェック・校正（30分）
5. note投稿・マガジンに追加（15分）
- **1回あたり制作時間: 約4〜5時間**
- **月間制作時間: 約8〜10時間**

### コンテンツのストック管理

- 5大テーマ × 4問題タイプ = 20パターン → 10ヶ月分のネタ
- 毎年の新傾向を1〜2本追加すれば年間を通して配信可能
- 模範論文は蓄積資産 → バックナンバーとして継続販売

### KPI

| 指標 | 目標 |
|---|---|
| 月間購読者数 | 30人以上（= ¥30,000/月） |
| 購読継続率 | 60%以上 |
| N-4からの転換率 | 15%以上（N-4購入者 → マガジン購読） |
