## 棲み分け原則（全記事共通）

| 無料（doboku-note.com） | 有料（note.com） |
|---|---|
| テキスト全文（辞書） | 要点整理・チェックリスト（ナビ） |
| 過去問の個別解説 | 出題傾向の分析・頻出論点の抽出 |
| 法律の逐条解説 | 条文穴埋めドリル（反復演習） |
| 制度解説・学習方針 | テンプレート・ワークシート（実践ツール） |

**原則: 無料サイトに既にある内容をそのまま有料化しない。無料=素材、有料=加工品。**
