## 骨子（目次構成）

### 冒頭（〜1,000字）

- **リード文**: 「技術士一次は35問中25問を選ぶ試験。どの25問を選ぶかで合否が決まる」
- **合格率と難易度**: 建設部門の合格率30〜50%。正答率50%で合格（13/25問）
- **本ノートの使い方**: 選択戦略を決める → 選んだ科目の要点を集中学習 → 過去問で確認

### 第1章: 科目選択の最適戦略（〜2,000字）

- **1.1 試験構成の確認**

  | 科目 | 出題数 | 選択 |
  |---|---|---|
  | 基礎科目 | 30問 | 15問（6群×各3問） |
  | 適性科目 | 15問 | 15問（全問必答） |
  | 専門科目（建設部門） | 35問 | 25問 |

- **1.2 専門35問の科目別出題数**

  | 科目 | 出題数 | 難易度 | 学習効率 |
  |---|---|---|---|
  | 土質及び基礎 | 4問 | ★★★ | 高（計算パターン化） |
  | 鋼構造及びコンクリート | 8問 | ★★☆ | 最高（最多出題、体系的） |
  | 都市及び地方計画 | 4問 | ★★☆ | 中（暗記中心） |
  | 河川、砂防及び海岸・海洋 | 9問 | ★★★ | 高（最多出題） |
  | 港湾及び空港 | 1問 | ★☆☆ | 低 |
  | 電力土木 | 2問 | ★★☆ | 低 |
  | 道路 | 1問 | ★☆☆ | 低 |
  | 鉄道 | 1問 | ★☆☆ | 低 |
  | トンネル | 1問 | ★★☆ | 低 |
  | 施工計画・施工設備及び積算 | 2問 | ★☆☆ | 高（実務直結） |
  | 建設環境 | 2問 | ★☆☆ | 中 |

- **1.3 推奨選択パターン3つ**

  - **パターンA（集中型）**: 河川9 + コンクリート8 + 土質4 + 施工2 + 環境2 = 25問。捨て科目を明確に
  - **パターンB（広域型）**: 河川9 + コンクリート8 + 土質4 + 都市計画4 = 25問。暗記で都市計画をカバー
  - **パターンC（安全策）**: 27〜28問分を準備し、本番で解きやすい25問を選択

### 第2章: 鋼構造及びコンクリート — 8問の要点（〜4,000字）

最多出題。体系的に学べば8問中6問以上は確実。

- **2.1 コンクリートの材料と配合**
  - セメントの種類と特性（普通・早強・中庸熱・高炉・フライアッシュ）
  - 配合設計の基本（W/C比、単位水量、スランプ、空気量の相互関係）
  - → doboku-note.com: civil-general/mix-design

- **2.2 コンクリートの耐久性**
  - 中性化・塩害・凍害・アルカリシリカ反応の4大劣化メカニズム
  - 各劣化の対策一覧表

- **2.3 鉄筋コンクリートの設計**
  - 限界状態設計法の基本
  - かぶり・定着・継手の数値基準

- **2.4 鋼構造の基本**
  - 溶接の種類と欠陥
  - 高力ボルト接合（摩擦接合・引張接合）
  - 疲労設計の考え方

- **2.5 頻出過去問パターン3選**（解法の型を示す）

### 第3章: 河川、砂防及び海岸・海洋 — 9問の要点（〜4,000字）

出題数最多。水理学の計算問題がカギ。

- **3.1 水理学の必須公式**
  - 連続の式、ベルヌーイの定理、マニングの公式
  - 開水路の等流・不等流
  - → doboku-note.com: river/hydraulics

- **3.2 河川計画**
  - 基本高水流量の算定
  - 計画高水位と堤防高の決定
  - → doboku-note.com: river/flood-control

- **3.3 治水・利水施設**
  - ダムの種類と特徴（重力式・アーチ式・フィルダム）
  - 河川構造物（堰・水門・床止め・護岸）

- **3.4 砂防**
  - 砂防ダムの機能と設計
  - 土石流対策

- **3.5 海岸・海洋**
  - 波の基本特性
  - 海岸保全施設

- **3.6 頻出計算問題の解法3選**

### 第4章: 土質及び基礎 — 4問の要点（〜2,500字）

計算問題が多いが、パターンは限定的。

- **4.1 土の基本的性質**
  - 含水比・間隙比・飽和度の関係
  - 粒度分布と土の分類（統一分類法）

- **4.2 土の力学特性**
  - 圧密理論（テルツァギの一次元圧密）
  - せん断強さ（モール・クーロンの破壊規準）
  - 土圧（ランキン土圧・クーロン土圧）

- **4.3 基礎工**
  - 直接基礎の支持力公式
  - 杭基礎の支持力算定

- **4.4 軟弱地盤対策**
  - プレロード工法、サンドドレーン工法、深層混合処理工法
  - 対策工法の選定フロー

- **4.5 頻出計算問題の解法2選**

### 第5章: その他の科目 — 補完用要点（〜2,500字）

- **5.1 都市及び地方計画**（4問）: 都市計画法の用途地域、市街化区域/調整区域の区分
- **5.2 施工計画・積算**（2問）: 工程管理の基本（CPM）、建設機械の生産性計算
- **5.3 建設環境**（2問）: 環境影響評価法の手続き、騒音・振動の環境基準
- **5.4 道路・トンネル・鉄道**（各1問）: 最低限の暗記事項

### 第6章: 基礎科目・適性科目の攻略（〜2,000字）

- **6.1 基礎科目**: 6群×各3問選択。確率・統計と情報基礎が得点源
- **6.2 適性科目**: 技術士法・技術者倫理。常識で解ける問題が多い
- **6.3 時間配分**: 基礎1時間 + 適性1時間 + 専門2時間

### 巻末付録

- **付録A**: 科目別・必須公式集（A4で2枚に集約）
- **付録B**: 暗記事項チェックリスト
- **付録C**: 推奨学習スケジュール（3ヶ月版）
