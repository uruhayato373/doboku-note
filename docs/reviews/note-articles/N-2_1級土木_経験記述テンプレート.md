## 骨子（目次構成）

### 冒頭（〜800字）

- **リード文**: 「経験記述は事前準備で9割決まる。本番で考えるのではなく、書くことが決まっている状態で臨む」
- **出題テーマの傾向分析**:
  - R2, R元, H30, H27, H25: **品質管理**（最頻出）
  - H29, H26, H23: **安全管理**
  - H24: **工程管理**
  - → 品質管理 + 安全管理を準備すれば、直近10年の出題をカバー
- **5パターンの使い方**: 全パターンを読む → 自分の経験に最も近い2パターンを選ぶ → 穴埋め → 添削

### 第1章: 経験記述の「型」を理解する（〜1,500字）

- **1.1 必ず守る3段構成**

  ```
  (1) 現場状況と技術的課題（具体的な条件 → 何が問題だったか）
  (2) 検討項目と検討理由・検討内容（何を比較検討したか → なぜその方法を選んだか）
  (3) 対応処置とその評価（実際に何をしたか → 結果どうなったか）
  ```

- **1.2 採点者が見ているポイント**
  - 具体性: 「安全に配慮した」→ NG、「高さ5mの法面に落石防護柵H=1.2mを設置した」→ OK
  - 数値: 必ず寸法・数量・日数・温度などの数値を入れる
  - 因果関係: 課題 → 検討 → 対応 が論理的につながっているか
  - 実体験: 教科書的な記述は即座に見抜かれる

- **1.3 NG例 vs OK例（比較表）**
  - NG: 「品質管理に留意して施工を行った」
  - OK: 「気温35℃の暑中コンクリート打設において、練り混ぜから打込み完了まで90分以内を厳守し、打設後は散水養生を7日間実施した」

### 第2章: テンプレート5パターン（〜8,000字）

各テンプレートの構成:
1. **適用場面**: このテンプレートが使える工種・状況
2. **穴埋め式テンプレート**: [  ] に自分の数値・現場情報を入れる
3. **記入例（完成版）**: 穴埋め済みの模範解答
4. **カスタマイズのコツ**: 自分の経験に合わせる調整ポイント

#### パターン1: 品質管理 × コンクリート工（最頻出）

**適用場面**: 橋梁下部工・擁壁・水路等のコンクリート構造物施工

**テンプレート**:

```
(1) 現場状況と技術的課題
本工事は[都道府県名][市区町村名]における[工事名]で、[構造物名]の
[コンクリート体積]m³のコンクリート打設を行うものであった。
施工時期が[月]月であり、[暑中/寒中]コンクリートに該当したため、
[温度管理/ひび割れ対策/強度確保]が技術的課題であった。

(2) 検討項目と検討理由・検討内容
以下の3点について検討した。
① [配合設計に関する検討]: ...
② [打設方法に関する検討]: ...
③ [養生方法に関する検討]: ...
[選定理由]を踏まえ、[採用した方法]を選定した。

(3) 対応処置とその評価
[具体的な対応処置を数値入りで記述]
その結果、[品質管理基準値]を満足し、[ひび割れ等の品質不良]も
発生しなかった。
```

**記入例（完成版）**: 暑中コンクリートの品質管理を題材にした模範解答（約600字）

---

#### パターン2: 品質管理 × 土工（盛土の締固め管理）

**適用場面**: 道路盛土・河川堤防・宅地造成等の盛土工事

**テンプレート**:
- 課題: 含水比の高い盛土材料の品質確保
- 検討: 締固め度の管理方法（乾燥密度規定 vs 空気間隙率規定）
- 対応: RI計器による品質管理 + 試験盛土の実施

---

#### パターン3: 安全管理 × 掘削・土留め工

**適用場面**: 深さ3m以上の開削工事、地下埋設物近接施工

**テンプレート**:
- 課題: 掘削深さ[  ]mの開削工事における[地山崩壊/地下水/埋設物]のリスク
- 検討: 土留め工法の選定（鋼矢板/親杭横矢板/SMW）+ 計測管理計画
- 対応: 地中変位計の設置 + 日常点検チェックリストの運用

---

#### パターン4: 安全管理 × 高所作業・重機作業

**適用場面**: 橋梁上部工・ビル解体・大型クレーン作業

**テンプレート**:
- 課題: 高さ[  ]mでの[作業内容]における墜落・転落リスク
- 検討: 仮設計画（足場の種類・安全帯取付設備）+ 作業手順の策定
- 対応: ツールボックスミーティング + KY活動 + 安全パトロール

---

#### パターン5: 工程管理 × 工期短縮

**適用場面**: 工期に余裕がない工事、追加工事による工期圧迫

**テンプレート**:
- 課題: 当初工期[  ]日に対し、[追加工事/天候不良/設計変更]により[  ]日の遅延が見込まれた
- 検討: 工期短縮策（施工方法の変更/並行施工/施工体制の増強）のCPM分析
- 対応: ネットワーク工程表の見直し + クリティカルパス上の作業の[具体的短縮策]

### 第3章: 自分の経験を整理するワークシート（〜1,500字）

- **3.1 経験整理シート**
  - 過去5年の主要工事を一覧化する表
  - 各工事で「技術的課題」「検討事項」「対応と結果」を記入する欄
  - 品質管理・安全管理の両方で書ける工事を★マーク

- **3.2 テンプレートの選び方フローチャート**

  ```
  あなたの主な施工経験は？
  ├── コンクリート構造物 → パターン1
  ├── 盛土・土工 → パターン2
  ├── 掘削・土留め → パターン3
  ├── 高所・重機作業 → パターン4
  └── 工期に苦労した → パターン5
  ```

- **3.3 下書き → 推敲のステップ**
  - Step 1: テンプレートに穴埋め（30分）
  - Step 2: 数値が入っているか確認（チェックリスト）
  - Step 3: 声に出して読む（不自然な箇所を修正）
  - Step 4: 600字以内に収まっているか確認
  - Step 5: 他者に読んでもらう（可能なら）

### 第4章: 本番の時間配分と注意点（〜1,000字）

- 経験記述に使える時間: 約45分
