## コンテンツの3層構造

doboku-noteのコンテンツを、3事業への貢献度で分類する。

```
【Layer 1: SEO集客層】 ← doboku-note の検索流入を最大化
│  技術リファレンス、試験対策まとめ、法規解説
│  → 全ページにAdSense + AmazonLink
│
【Layer 2: 書籍導線層】 ← 書籍購入への動線
│  試験対策ガイド、得点戦略、おすすめ参考書
│  → 記事末尾に「著者の書籍」CTA
│
【Layer 3: 講座導線層】 ← Udemy受講への動線
│  入門解説、学習ロードマップ、つまずきポイント解説
│  → 記事末尾に「動画で学ぶ」CTA
```

| サイトの資産 | 書籍への効果 |
