## 単体ループ（doboku-note）

### 1. 資格試験SEOループ（推奨度: ★★★★★）

```
試験対策コンテンツ公開
    ↓
受験者が「1級土木施工管理 過去問」等で検索
    ↓
doboku-note に流入・学習
    ↓
合格 → 後輩・同僚に「あのサイト良かった」と共有
    ↓
口コミ＋被リンク増加
    ↓
ドメイン権威向上 → さらに検索流入増
    ↓ (繰り返し)
```

| 基準 | 評価 | 備考 |
|---|---|---|
| 適合度 | 5/5 | 受験者は最大のターゲット。施工管理技士だけで年間20万人受験 |
| 現在の成熟度 | 2/5 | 1級土木施工管理は充実。技術士・RCCM・コンクリート技士はゼロ |
| 実装コスト | S | 既存のPDF変換スキルで過去問解説を量産可能 |
| 成長速度 | 中期（3-6ヶ月） | SEOインデックスに時間がかかるが、試験シーズンで爆発的流入 |
| 複利効果 | **高** | 合格者の口コミは毎年蓄積。被リンクもドメイン全体を押し上げ |

**具体的アクション**:
1. 技術士一次試験の過去問解説を優先作成（11月試験 → 8月までに公開）
2. 「出題傾向と得点戦略」ページを各資格で作成（検索需要大）
3. 試験3ヶ月前にSNS（X）で告知投稿

```
    ↓

    ↓
検索順位↑ → さらに流入増
    ↓ (繰り返し)
```

| 基準 | 評価 | 備考 |
|---|---|---|
| 適合度 | 5/5 | 「PDFの壁を壊す」はdoboku-note最大の差別化 |

| 実装コスト | S-M | PDF変換スキルが整備済み。1冊あたり数時間 |
| 成長速度 | 長期（6-12ヶ月） | 技術者は保守的だが、一度使うとリピーターになる |
| 複利効果 | **非常に高** | 公的資料は改訂頻度が低く、コンテンツが長期間有効 |

**具体的アクション**:

### 3. 季節性ループ（推奨度: ★★★★☆）

```
試験シーズン到来（6月・7月・10月・11月）
    ↓
受験者が大量に検索
    ↓
流入急増 → AdSense・アフィリエイト収益ピーク
    ↓
収益でコンテンツ投資（書籍購入、ツール改善）
    ↓
コンテンツ充実 → 翌年さらに流入増
    ↓ (毎年繰り返し)
```

| 基準 | 評価 | 備考 |
|---|---|---|
| 適合度 | 4/5 | 資格試験は年間スケジュールが固定で予測可能 |
| 現在の成熟度 | 1/5 | 試験カレンダーに連動した施策なし |
| 実装コスト | S | コンテンツ公開タイミングを試験日から逆算するだけ |
| 成長速度 | 中期（次の試験シーズンで効果発現） |
| 複利効果 | **高** | 毎年同じ時期に需要が来る。蓄積型 |

**具体的アクション**:
1. 試験カレンダーページを作成（常設）
2. 試験3ヶ月前にコンテンツ公開を完了する逆算スケジュール
3. 試験直前に「直前チェックリスト」を公開（バイラル狙い）

## 3事業クロスループ（最重要）

### 5. コンテンツ→書籍→講座フライホイール（推奨度: ★★★★★）

```
doboku-note で技術ノートを無料公開
    ↓
検索流入で月間10万ユーザー獲得
    ↓
サイト内で書籍（有料）を紹介
    ↓
読者が書籍を購入 → Amazonレビュー増
    ↓
書籍の信頼性↑ → 「この著者の講座も受けよう」
    ↓
Udemy講座を受講 → レビュー増
    ↓
講座の信頼性↑ → 「このサイトの著者は信頼できる」
    ↓
サイトのE-E-A-T向上 → 検索順位↑ → さらに流入増
    ↓ (フライホイール加速)
```

**このループが3事業を束ねる核心**:

```
         ┌──────────────────────────────┐
         │                              ↓
    doboku-note ──→ 書籍販売 ──→ Udemy講座
    (無料・集客)    (中額・信頼)   (高額・関係)
         ↑                              │
         └──────────────────────────────┘
              E-E-A-T・ブランド強化
```

| 基準 | 評価 | 備考 |
|---|---|---|
| 適合度 | 5/5 | 3事業が相互強化する理想的な構造 |
| 現在の成熟度 | 1/5 | doboku-noteのみ稼働。書籍・講座は未着手 |
| 実装コスト | L | 書籍執筆＋講座制作に数ヶ月必要 |
| 成長速度 | 長期（12-18ヶ月で完成） |
| 複利効果 | **最高** | 3事業の相互送客で指数的に成長 |
