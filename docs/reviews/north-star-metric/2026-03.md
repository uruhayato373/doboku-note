# 3事業 North Star Metric 定義

> 作成日: 2026-03-30
> 対象: doboku-note / 技術書執筆 / Udemy技術講座

---

## ビジネスゲーム分類

| 事業 | ゲーム | 理由 |
|---|---|---|
| doboku-note | **Productivity + Attention** | 技術リファレンスとして業務・学習効率化（Productivity）＋ SEO流入・閲覧時間（Attention） |
| 技術書執筆 | **Transaction** | 書籍購入という1回の取引がゴール |
| Udemy技術講座 | **Productivity + Transaction** | 受講による学習効率化（Productivity）＋ 講座購入（Transaction） |

3事業は相互に送客する構造。doboku-note がトップオブファネル（集客）、書籍・講座がマネタイズ層。

---

## 事業1: doboku-note

### NSM: **月間オーガニック検索流入ユーザー数**

- **定義**: Google検索経由でdoboku-noteに訪問したユニークユーザー数（月間）
- **現在値**: 推定 1,000〜5,000（初期段階、GA4要確認）
- **目標値**: 30,000（6ヶ月後） / 100,000（1年後）

### 7基準チェック

| 基準 | 評価 | 根拠 |
|---|---|---|
| 理解しやすい | ○ | 「月に何人が検索から来たか」— 即座に理解可能 |
| 顧客中心 | ○ | 検索で辿り着く＝ユーザーの課題に応えている証拠 |
| 持続的価値 | ○ | リピーター化すれば月次で安定成長 |
| ビジョン整合 | ○ | 「土木技術の知識体系を広く届ける」に直結 |
| 定量的 | ○ | GA4/GSCで正確に計測可能 |
| アクション可能 | ○ | コンテンツ追加・SEO最適化で直接改善できる |
| 先行指標 | ○ | 検索流入↑ → 広告収益・アフィリエイト・書籍販売の全てに先行 |

### Input Metrics

| # | Input Metric | 定義 | NSMとの関係 | 施策例 |
|---|---|---|---|---|
| 1 | **公開ページ数** | content/配下の公開済みMDXファイル数 | ページ数↑ → ロングテールKW増 → 検索流入↑ | PDF→MDX変換、試験対策記事追加 |
| 2 | **検索上位率** | GSCで掲載順位10位以内のクエリ割合 | 上位率↑ → CTR↑ → 流入↑ | タイトル最適化、内部リンク強化 |
| 3 | **コンテンツ鮮度** | 直近30日に更新されたページ割合 | 鮮度↑ → クロール頻度↑ → インデックス改善 | 定期的な加筆・修正 |
| 4 | **被リンク数** | 外部サイトからの参照リンク数 | 被リンク↑ → ドメイン権威↑ → 全体順位↑ | 公的資料のHTML化による自然リンク獲得 |

```
月間オーガニック検索流入ユーザー数
├── 公開ページ数（現在908→目標1,200）
├── 検索上位率（目標: 主要KWの30%が10位以内）
├── コンテンツ鮮度（目標: 月10%以上更新）
└── 被リンク数（目標: 月5本増）
```

### 計測方法

| 指標 | データソース | 更新頻度 |
|---|---|---|
| NSM（検索流入） | GA4 / GSC | 週次 |
| 公開ページ数 | `find content/ -name "*.mdx" \| wc -l` | 週次 |
| 検索上位率 | GSC Performance | 月次 |
| コンテンツ鮮度 | git log | 月次 |
| 被リンク数 | GSC Links | 月次 |

## 事業2: 技術書執筆

### NSM: **累計販売部数**

- **定義**: 出版した技術書の累計販売部数（電子+紙）
- **現在値**: 0（未着手）
- **目標値**: 500部（出版後6ヶ月） / 2,000部（出版後1年）

### 7基準チェック

| 基準 | 評価 | 根拠 |
|---|---|---|
| 理解しやすい | ○ | 「何冊売れたか」— 明快 |
| 顧客中心 | ○ | 購入＝読者が価値を認めた証拠 |
| 持続的価値 | ○ | ロングテール販売で年単位の収益 |
| ビジョン整合 | ○ | doboku-noteの知見を書籍として体系化 |
| 定量的 | ○ | 出版社/Amazon KDPの販売レポートで計測可能 |
| アクション可能 | ○ | 内容充実・プロモーション・doboku-noteからの導線で改善可能 |
| 先行指標 | ○ | 販売部数 → レビュー増 → 信頼性↑ → さらなる販売・講座受講 |

### Input Metrics

| # | Input Metric | 定義 | NSMとの関係 |
|---|---|---|---|
| 1 | **原稿完成率** | 目標ページ数に対する執筆済み割合 | 完成しなければ販売0 |
| 2 | **doboku-noteからの導線CTR** | サイト→書籍購入ページへの遷移率 | サイトが最大の販促チャネル |
| 3 | **Amazon レビュー数** | 書籍のレビュー件数 | レビュー↑ → 検索順位↑ → 販売↑ |

## 事業3: Udemy/技術講座

### NSM: **月間有料受講者数**

- **定義**: Udemyまたは自社プラットフォームでの月間新規有料受講者数
- **現在値**: 0（未着手）
- **目標値**: 50人/月（公開後6ヶ月） / 200人/月（公開後1年）

### 7基準チェック

| 基準 | 評価 | 根拠 |
|---|---|---|
| 理解しやすい | ○ | 「月に何人が講座を買ったか」 |
| 顧客中心 | ○ | 受講＝学習ニーズへの回答 |
| 持続的価値 | ○ | 良い講座はレビュー経由で複利的に成長 |
| ビジョン整合 | ○ | 動画で土木技術を伝える新チャネル |
| 定量的 | ○ | Udemyダッシュボードで計測可能 |
| アクション可能 | ○ | 講座内容・プロモーション・価格で改善可能 |
| 先行指標 | ○ | 受講者↑ → レビュー↑ → 信頼性↑ → さらなる受講・書籍販売 |

### Input Metrics

| # | Input Metric | 定義 | NSMとの関係 |
|---|---|---|---|
| 1 | **講座完成率** | カリキュラムに対する収録・編集済み割合 | 完成しなければ受講者0 |
| 2 | **受講完了率** | 講座を最後まで視聴した受講者の割合 | 完了率↑ → レビュー↑ → Udemy内ランキング↑ |
| 3 | **doboku-noteからの導線CTR** | サイト→講座ページへの遷移率 | サイトが最大の集客チャネル |

## 3事業統合メトリクスツリー

```
【最上位目標】月間総収益 10万円
│
├── doboku-note NSM: 月間検索流入ユーザー 100,000
│   ├── 公開ページ数 1,200+
│   ├── 検索上位率 30%
│   ├── コンテンツ鮮度 月10%更新
│   └── 被リンク数 月5本増
│       │
│       ├──→ AdSense収益: 月2〜5万円
│       ├──→ アフィリエイト収益: 月1〜3万円
│       ├──→ 書籍販売導線
│       └──→ 講座販売導線
│
├── 技術書 NSM: 累計販売部数 2,000
│   ├── 原稿完成率
│   ├── サイト→書籍 CTR
│   └── Amazonレビュー数
│       └──→ 印税: 年10〜30万円
│
└── Udemy NSM: 月間有料受講者 200
    ├── 講座完成率
    ├── 受講完了率
    └── サイト→講座 CTR
        └──→ 講座収益: 月1〜3万円
```

**核心**: doboku-note の検索流入が全事業のトップオブファネル。まずここに全リソースを集中し、月間10万ユーザーを達成してから書籍・講座に展開する。
