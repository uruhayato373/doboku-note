# サイト全体UI・UXレビュー

## 結論

優先するのは、スマホメニューの操作不具合、検索条件の保持、資格トップから過去問への入口の改善。サイト全体のカード・画像・フッターを作り直す段階ではなく、既存の整理を生かして「目的の情報を選ぶまで」を短くする。

以下の指摘は全体点検時の観測。続くユーザーの「すべて実装して」により、同日8項目を実装した。改善効果をアクセス解析で実証したものではない。

| 項目 | 反映内容 |
|---|---|

| 検索 | q・category・pageのURL同期、戻る・再読み込み、資格のみ解除／検索リセット、古い応答の破棄、44px操作領域と選択ARIA、暗色時の文字色 |

| 基準類 | 機関10・文書72ページの白い本文面とコンパクトなヘッダー。章選択を先頭へ、管理情報は出典詳細へ収納。原典リンク・判読注記は維持 |

## 優先する改善

### 1. スマホメニューの下部へ移動できない【不具合・優先高】

全ページ共通。375×812でメニューを開くと内容の高さは889px、最後のリンクの下端は873pxとなり画面外へ出る。メニュー自体は高さ812pxで `overflow-y: visible`。下へスクロールしてもメニューの `scrollTop` は0のまま、背面ページだけ900px移動した。下部のAboutが隠れ、背面の「上へ戻る」ボタンもメニュー上に重なる。Escapeによる閉じる操作は動作した。

**改善:** メニュー内を縦スクロール可能にし、開いている間は背面のスクロールを止める。短い画面でも最後のリンクと閉じる操作へ到達できるようにする。

**確認箇所:** `src/components/layout/Header.tsx:334`。再検証は375×667・375×812と横向きで、末尾への到達、背面の固定、閉じた後のスクロール位置復元を確認する。

### 2. 検索条件が保持されず、選択操作も小さい【不具合・優先高】

`/search?q=コンクリート` で「技術士 第一次試験」を選択してもURLは検索語だけ。再読み込みすると資格の絞り込みが解除される。リセット後は入力が空になる一方、URLには元の検索語が残るため、再読み込み時に以前の検索が復活する構造になっている。

資格ボタンは実測34px高で、サイト標準の44pxより小さい。選択中の状態を示す `aria-pressed` もない。34pxであることだけを根拠にWCAG違反とは判定していない。

**改善:** 検索語・資格・ページ番号をURLに同期し、読み込み・戻る・共有・リセットの状態をそろえる。資格ボタンは44px以上にし、選択状態を支援技術にも伝える。「資格だけ解除」と「検索をすべて消去」も目的が分かる文言にする。

**確認箇所:** `src/app/search/SearchPageClient.tsx:42`、`src/hooks/useSearch.ts:151`、`src/components/search/SearchFilters.tsx:24`。

### 3. 資格トップの過去問への入口がスマホで隠れる【構成・優先高】

学習メニューは既にあり、ページ内リンクも動作している。ただし項目が多い資格では横スクロールとなり、375px幅で初めに見えるのは約2項目。頻繁に使う「過去問／問題を解く」が画面外になる。

本文を順に読む場合、過去問の見出しは1級土木でページ上端から約3,610px、2級土木で約3,587px、技術士建設部門で約5,007px。ページの長さ自体を不具合とはしないが、初学者向けガイドと日常の演習を同じ順序だけで案内している。

**改善:** スマホでも「過去問」「テキスト」「受験ガイド」が一目で選べる2〜3列の入口にする。人気記事は学習の主要操作より後ろへ配置するか、少数に圧縮する。PCの右サイドバーは関連資格の羅列より、その資格で次に使う演習・記述対策・苦手分野の復習を優先する。

**確認箇所:** `src/components/category/CategoryJumpNav.tsx:62`、資格トップの各セクション。

### 4. 基準類の下層ページに大きなヘッダーと管理用情報が残る【統一性・優先中】

`/standards` のトップは改善済みだが、機関別10ページ・文書別72ページは大きな帯状ヘッダーを使う。文書ページには分冊数や原本SHA-256が先頭に表示され、重複文書ではnoindexの説明も見える。

`/standards/kinki/common` のスマホ表示では「章から読む」が約590px、最初の章リンクは約790px付近。読むための選択肢より、説明とメタ情報が先行する。

**改善:** トップ・記事と同じカードと余白の規則へそろえ、先頭は文書名・機関・版と「章を選ぶ」に絞る。ハッシュ・索引制御・変換単位は出典詳細へ収納する。原典へのリンクや、読解に影響する判読不能の注記は必要な場所に残す。データ利用が目的の `/standards/data` は技術情報を掲載する意義があり、一律削除しない。

**確認箇所:** `src/app/standards/[agency]/page.tsx:39`、`src/app/standards/[agency]/[document]/page.tsx:82`、同ファイル96行の重複案内。

### 5. 無料ツールへ共通ナビから直接行けない【回遊・優先中】

13ツールは用途別に整理されているが、共通ヘッダー・スマホメニュー・フッターに `/tools` への入口がない。トップなどからは到達できるため孤立ページではないものの、記事を読んで計算・演習へ進む際に探し直す必要がある。

**改善:** 共通ナビに「計算・演習」を追加し、教材・基準類との違いが分かる名称にする。右サイドバーや記事末尾では、記事内容に対応するツールを1〜2件だけ案内する。全ツールを各所へ並べる必要はない。

**確認箇所:** `src/components/layout/Header.tsx`、`src/components/layout/Footer.tsx:6`。

### 6. テーマ詳細は記事より絞り込みの面積が大きい【密度・優先中】

`/topics/concrete` の375px表示ではヘッダーに続いて、資格・記事種類・検索の3つの入力欄が縦に並び、最初の812px内に記事カードが入らない。絞り込み機能と分類は改善済みで有用だが、初回訪問時に内容を見て選ぶまでが長い。

**改善:** 記事内検索を1行で置き、資格・種類は「絞り込み」の開閉欄にまとめる。「はじめに読む」を早く見せる。選択済み条件と解除操作は閉じても分かる形にする。

**確認箇所:** `src/components/topics/TopicArticles.tsx:22`、`src/app/topics/[slug]/page.tsx`。

### 7. トップの更新情報が資格選択を押し下げる【構成・優先低】

スマホのトップではヒーローの後に更新4件が並び、「対応する資格・試験」は約800pxから始まる。調査時の更新4件は転職関連で、試験を選んで学びたい訪問者にとっては主要操作までの寄り道になる。ヒーロー内の資格選択ボタンは既に存在する。

**改善:** 資格一覧を更新情報より先へ出すか、更新情報を1〜2件に圧縮する。下部の「最新の記事」との重複も整理する。最適な件数は資格選択のクリック率と更新欄の利用率で判断する。

**確認箇所:** `src/app/page.tsx:70`、同ファイル106行。

### 8. 明暗切替の初回操作が見た目と一致しない【不具合・優先中】

テーマ設定を保存していない端末で、OSをライト配色にしてアクセスすると、月アイコンのボタンを1回押してもライトのまま。表示中の配色ではなく、保存設定の値が `system` か `light` かで次の状態を分岐しているため。実機では操作前が `dark: false / 保存値なし`、操作後も `dark: false / 保存値light` となった。OSがダークの場合は1回でライトへ切り替わった。

また、新規アクセス時にメニューを開くボタンへ自動的にフォーカスが移ることも確認した。閉じた後のフォーカス復帰処理が初回表示にも実行されており、触っていないメニューに選択枠が出る。

**改善:** 明暗切替は実際の表示状態 `resolvedTheme` を反転し、アイコン・読み上げ名・表示ラベルも同じ状態から決める。メニューへのフォーカス復帰は「開いた状態から閉じた時」に限定する。

**確認箇所:** `src/components/ui/ThemeToggle/ThemeToggle.tsx:32`、`src/components/layout/Header.tsx:153`。

- 観測157 URLはすべてHTTP 200。2画面幅でページ全体の横はみ出し、未捕捉のJavaScript実行エラー、存在しないページ内アンカーは0件。`main` とその `h1` は各1個。

- 公開フラグ1,206記事と公開索引1,206件の不一致は0件。削除済み記事が現在の索引へ再混入した形跡はない。
- UI静的検査159ファイル、資格カリキュラム186参照、公開記事と統合転送の照合は成功。
- 全1,225ソース記事の太字・表の実パース検査は成功。

## 実装順と完了条件

1. メニューを直す。短い画面で末尾リンクを押せ、背面が動かず、閉じた後に元へ戻れること。
2. 検索状態と共通操作を直す。同じURLなら資格・ページも復元され、リセット後の再読み込みで元の検索が復活しないこと。明暗切替は初回から1回で反転すること。
3. 資格トップと共通ナビを直す。375pxで過去問への入口が横スクロールなしに見え、各ページからツールへ直接進めること。
4. 基準類下層・テーマ・トップの情報順を整える。カード化だけでなく、最初の内容や操作の表示位置が改善したことを同じ画面サイズで比較する。

検証データは `.tmp/sitewide-review/` に保存。`pages.json`、`inventory.json`、`interactions.json`、スクリーンショットが今回の測定根拠。開発中の状態のため、別タスクの変更・再ビルドで数値や画像は変わり得る。
