# サイト全体のサムネイルと回遊UI調査

## 調査範囲と結論

公開サイトの全37ページ定義、8資格のトップ、15テーマ、13ツールを対象に、共通コンポーネントと記事・画像台帳を調査した。59 URL を開発サーバーで表示し、375×812 と1280×800の幅でページ高・リンク・画像・横はみ出しを取得した。59 URL はすべてHTTP 200で、測定時の横はみ出しは0件だった。主要一覧はスクリーンショットも確認した。

`content/site` の `published !== false` のMDXは1,211件。これは公開フラグの棚卸しであり、リダイレクト・一覧非表示等を除いた公開URL数ではない。本文1,211件の個別目視ではなく、全ページ形式の調査と代表記事の実表示を組み合わせている。管理アプリ、外部の販売サイト、検索順位・クリック率の調査は対象外。

**優先するのは、既存画像枠の修正と軽量化、長大なテーマ別一覧の整理、主任技士・診断士への画像付き一覧の展開。** 画像は選択肢を見分ける手掛かりになる場所に置く。年度比較表、用語索引、基準書本文、計算フォームは情報密度を保つ。

> [!note]
> 以下は調査時の観測と改善案。2026-09-08にユーザー指示で全改善項目を実装へ進めた。開発環境では表示対象のOGPを既存テンプレートから生成する。ローカルの代替画像表示を本番の画像欠落と判定していない。

### 実装内容（2026-09-08）

画像共通表示・3サイズWebP生成/検査/R2供給、最新記事の比率修正、8資格のガイドとコンクリート3資格の一覧、実務の工種別ジャンプ/代表画像、15テーマの入口記事/分類/絞り込み、テーマアイコン、13ツールの用途分類/入力→結果案内、検索の資格追加/画像/種類表示、基準書カードのメタ情報を実装。

供給スクリプトはローカル生成と`--supply`を分離し、公開R2は既存OGP供給ワークフローへ配線。取得できない派生画像は原本へ戻す。本番反映・R2への実供給は未実施で、ローカル生成と実表示を検証する。

同日、別タスク「基準ページのUI/UX改善」でユーザーが要点ガイド5記事の削除を指示した。この変更を優先し、基準ガイドの画像付き一覧は対象から外し、記事0件となった`/standards/guides/[slug]`のページ定義も削除した。旧記事を再公開せず、基準文書カードの改善は維持する。

実装確認では28一覧ページで記事リンク保持と375px/1280pxの横はみ出し0を確認（基準ガイド削除前の測定）。15テーマの資格フィルター・解除・0件表示、JavaScript無効時の全リンク保持も確認した。代表6ページは明暗×2画面幅で確認。ローカル生成483枚のサイズ検査を実施し、336px版161枚の中央値は4,872 bytes、最大7,562 bytes。161記事には後から削除された基準ガイド5件を含む。検索結果の`.html`を正規URLへ変換し、スマホのページ切替ボタンは折り返して表示する。

本番相当の静的出力で、テーマ絞り込み解除と画像404時の原本への切替はPC・スマホの4ケースが成功した。検索検証では同一キーワードでも資格変更のたびに全件データを再取得して待ち時間が長くなる問題を検出し、直近1キーワードの結果を再利用するよう修正。修正後の開発環境では、2資格での絞り込み・ページ送り・横はみ出しなし・記事データの追加取得なしをスマホで確認した。検索索引は削除済み5記事を除いた1,959ページ、sitemapは1,514 URLへ再生成した。

最終検証では検索修正を含む本番ビルドが正常終了し、静的出力の検索テストもPC・スマホの2ケースが成功した。上記の4ケースと合わせ、追加E2Eの6ケースを確認済み。コードの型検査・ESLint・UI検査・差分の空白検査も完了。本番へのデプロイとR2派生画像の実供給は実施していない。

## 実測メモ

375px幅でのページ全体の高さ。本文・ヘッダー・フッター等を含み、画像読み込みやフォントで多少変動する。長さだけで不具合とは判定していない。

| ページ | テーマに属する記事数 | 高さの概数 |
|---|---:|---:|
| コンクリート | 90 | 19,250px |
| 人的資源管理 | 148 | 26,415px |
| 情報管理 | 146 | 26,233px |
| 経済性管理 | 128 | 23,063px |
| 安全管理（総監） | 127 | 22,950px |
| 社会環境管理 | 120 | 22,028px |
| 環境・脱炭素 | 100 | 18,783px |
| ツール一覧 | 13ツール | 3,901px |
| 実務トップ | 約50 | 6,581px |

画像台帳の`site-ogp-png`は1,574件、中央値580,270 bytes（約580KB）。台帳には現行公開記事以外も含む。技士17件の台帳合計は8,542,751 bytes（約8.5MB）。これは台帳上の元PNGサイズで、実測の初期通信量ではない。遅延読み込みはあるが、スクロールして読むと各画像の取得が発生するため、サムネイル用画像の分離が有効。

トップの最新記事は画像枠を実測し、4件中3件が128×182px、1件が128×160px。元画像の1200:630とは比率が一致しない。ソースの`object-cover`と組み合わせると、読み込み成功時も横方向が大きく切れる構造。実測時は外部画像取得が制限され、画像内容そのものの切れ方は未確認。

## 実装時の受け入れ条件

- 各一覧の公開記事リンクが欠落・重複しない。絞り込み解除で全件へ戻れる。
- モバイルでタイトルを判読でき、写真・OGPだけに意味を依存しない。
- 画像に固定した寸法・縦横比を設定し、読み込み前後で位置が動かない。
- 画像が取得できない場合もタイトルとリンクを利用できる。
- サムネイルは既存の画像資産と共通レンダラを利用する。画像生成・R2供給・サイズ検査まで繋ぐ。
- キーボードフォーカス、375px/1280px、明暗テーマ、記事リンク数を確認する。
- テーマの全件表示を整理しても、検索エンジンやJavaScript無効時から記事を辿れる構造を保つ。
- 検索結果の改修はPagefindを生成した本番相当環境で検索・絞り込み・ページ切替を確認する。
