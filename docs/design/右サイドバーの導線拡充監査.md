# 右サイドバーの導線拡充監査

## 対象と判定方法

公開サイトの全36ページ定義、全公開フラグMDX 1,206件の表示条件、8資格＋実務の9トップ、基準類の5形式を調査。右列は `TwoColumnShell` を使う資格・実務トップ、MDX記事、基準類トップ／機関／文書／分冊／章に集約される。本文中の補足用 `aside` は右列に数えない。管理アプリ・外部販売サイトは対象外。

全記事のDOMを個別目視した検査ではなく、全件のメタデータを実際の分類・商品選定関数へ通した機械調査と、開発サーバーの代表URL確認を組み合わせた。公開フラグ件数は転送元・カテゴリ非表示も含み、検索対象URL数ではない。商品は `published` とURL、広告は既存の選定ルール、外部商品は `listed` を参照した。販売サイトの最新価格・ASPの実際の提携状態は今回は再照合していない。

有効な代表38 URLのHTTP 200を確認した。初回に推測した建設部門の `guide/overview` は存在しなかったため、索引に実在する `keywords/bosai-kokudo-kyoujinka` へ差し替えて確認し、サイトの不具合には数えていない。主任技士トップ・一次試験ガイド・実務トップの3画面は1280px／375pxでブラウザ表示を採取し、横はみ出し0。PCでは長い著者紹介と広告が学習ナビより先に来ることも確認した。

> [!note]
> 初回は監査のみ。その後ユーザーの「できることはすべて実装して」に従い、下記の実装記録を追加した。監査時の件数・非対応条件は改修前の観測として残す。外部公開は行っていない。

## 実装記録（2026-09-08）

- 主任技士・診断士・一次トップに公開商品1点を追加。文言・価格・URLは商品台帳から解決し、モバイルは末尾に表示。
- 6カテゴリの279記事に同分野・同科目・同年度を優先する復習ナビを追加。自己リンク・非公開・カテゴリ非表示・重複を除外し、最大9記事。スマホも折りたたみナビで共用。
- 一次39過去問のツール条件を実際の年度・科目slugに修正。既存の関連ツール対応を記事右列にも表示し、実務トップには工種ジャンプと現場ツールを追加。
- コンクリート系・一次の記事は、既存の本文商品選定に適合する主教材だけを右列に1点表示。HUB教材との二重枠を防止。
- 診断士トップの汎用的な配合・養生ツールを外し、実在するガイドへの「最初に読む・対策を選ぶ」を資格トップに追加。人気順位を仮作成しない。
- コンクリート・鉄筋・土工・安全の基準章から、公開済み実務解説を最大2件表示。実務記事から基準一覧へ戻れるリンクも追加。タイトルが対応しない章には出さない。
- 記事右列の著者紹介は開閉式として学習ナビへの到達距離を短縮。広告や商品は追従させない。

新規ASP案件・外部販売状態の未確認商品は追加していない。ココナラ／Brainは既存の記事末尾導線を保ち、同じ目的の商品を右列へ重ねない。右列のないページへ新設はしていない。

全279記事のナビ除外条件と一次39過去問の演習導線、公開商品の解決・無関係な商品の非表示は `npx tsx tests/sidebar-discovery.test.ts` で検査できる。基準のコンクリート章は実務リンク2件とHTTP 200、一般章は追加リンク0を確認。

改修後は3資格トップ・実務トップ・6カテゴリ代表記事の計10ページをPC／スマホで操作確認し、教材の各可視面1枠・折りたたみ復習ナビ・一次演習リンク・工種アンカー・横はみ出し0を確認。主任技士PC・診断士スマホ暗色・基準章の実表示も確認した。UI検査は163ファイルで合格。今回の差分について本番ビルド・デプロイは行っていない。

## 広告・外部商品の判断

- 8資格トップは現在すべて広告1枠。MDX記事も共通の広告枠がある。新たな転職バナーの積み増しより、同じ枠の文脈と位置を整える。
- `/practice` の広告0は確認したが、空いているだけで追加しない。資格取得後のキャリア・働き方と接続する文脈を用意する場合のみ既存案件の適合を再確認する。
- 通信講座・書籍広告を新たに出すには、資格との適合・提携・素材の登録状態を別途確認する。今回のコード調査から「掲載可能な新規ASP案件がある」とは結論しない。
- ココナラ／Brainの選定ルールは1級17記事・2級8記事・総監24記事に公開登録商品を返す。すでに記事末尾に描画される。添削・答案作成などの高適合記事で右列への短い案内は候補だが、note・広告・外部商品を全部同時に並べることは避ける。
- 商品や広告を追従させず、既存の目次・設問・復習ナビだけを追従させる。記事では著者と広告の下に学習ナビがあるため、追加により目次がさらに下がらないよう通常フローの高さも見直す。

## 基準類・右列のないページ

基準トップはテーマ6件・実務3件・比較・データ利用がすでに整備されており、優先度は低い。機関一覧／文書／分冊／章は資料内ナビが主役。章の内容と対応する実務・計算リンクを少数足す余地はあるが、すでにある本文内の `StandardTopicLinks` 等と重複を確認する。基準原文に資格教材や転職広告を一括追加する根拠は今回得られていない。

トップ、資格一覧、テーマ一覧・詳細、検索、リンクハブ、13ツール、About、問い合わせ、プライバシー、規約、キーワード索引、基準比較・データ配布は右列なし。全36ページ定義のレイアウトを確認し、商品枠のための右列新設は推奨しない。テーマなら関連記事内、検索なら結果の関連性、ツールなら計算結果の次の行動として評価する。

## 実装する場合の順序と検証

1. 3資格トップの商品枠と実務トップの工種・ツールナビ。
2. 一次39過去問のツール判定修正、6カテゴリの分野・年度ナビ。
3. 非HUB資格の記事に、本文との重複を調整した教材1点と関連ツール。
4. 基準章と実務記事の対応を限定的に追加。

教材の公開状態・URL・価格を台帳で一元管理し、PC／モバイルの各可視面は主教材1点・広告1枠を基本とする。広告ピクセルを重複発火させず、同じ記事への自己リンク・非公開記事リンクを除外。記事内アンカー、375px／1280px、明暗テーマ、目次への到達性、クリック計測の位置ラベルを検査する。人気順位は計測値がある場合だけ使用する。
