# YouTube 戦略 — 技術士（総合技術監理部門）v3

**策定日**: 2026-04-13（v3: 合格体験者ポジションと立ち上げ時期を反映）
**対象**: 技術士 総合技術監理部門（主）／建設部門（従）
**位置づけ**: **運営者の受験記を軸にしたチャンネル + doboku-note / note への送客**
**関連**: [04_コンテンツロードマップ.md](./04_コンテンツロードマップ.md), [05_収益化戦略.md](./05_収益化戦略.md)

## エグゼクティブサマリー（v3）

- **★2026年7月の技術士総監2次筆記を運営者本人が受験**。その受験記をチャンネルの中核に据える（v2の「合成音声スライド型」から「受験記×肉声型」に方針転換）
- **立ち上げ時期**: **2026年7月下旬（試験直後）**。v2 の「Phase 1進捗70%を GO/NO-GO 条件」を撤廃し、**試験後に強制立ち上げ**に変更
- **顔出しは任意**。声のみ＋スライドでも立ち上げ可。成功要件は「テンポと投稿頻度」
- **直接収益は補助的**（市場天井が狭い）。**note/サイト送客器 + 合格体験ブランディング**として位置付ける
- **競合は4〜5チャンネルのみ、登録者1万人超の技術士専業は存在しない**。総監部門はほぼ競合ゼロ
- **差別化の決定打**: 既存の700キーワード＋過去問資産に加え、**運営者自身の受験体験（他人が絶対書けない一次情報）** を注入できる

## 1. 採用フォーマット（v3 で方針変更）

### 採用する形式

**運営者の肉声ナレーション + Claude生成スライド + 短尺3〜10分**

### v2 からの変更点

v2 では「VOICEVOX + 合成音声」を想定していたが、v3 では**運営者本人の声と受験体験を前面に出す**方針に変更。理由:

1. **一次情報の価値**: 合格体験者の肉声で語ることが競合との決定的差別化になる
2. **顔出しは任意**: 声のみでも十分に「本人性」を伝えられる
3. **学習コスト**: 合成音声パイプラインの構築コストを、自分の声の録音に回した方が早い

### 根拠

- 中小企業診断士など隣接資格では「受験合格者本人の受験記」チャンネルが安定的に伸びている
- 棚田行政書士チャンネル（20万登録）の分析から、**成功要件は「声質」ではなく「毎日に近い投稿頻度」と「10秒以内離脱を防ぐテンポ」**
- 10秒以内の離脱を防ぐオープニング設計は必須

## 2. 市場規模と集客見込み

### 母集団（令和7年度）

| 指標 | 値 | 出典 |
|---|---|---|
| 技術士一次 受験者 | 17,013名（合格率33.8%） | 文科省統計 |
| 技術士二次 受験者 | 24,135名（合格率11.4%） | 文科省統計 |
| **総合技術監理部門 二次** | **2,618名（合格率20.7%）** | R6統計 |
| 建設部門 二次 | 約1万名（全部門の40〜50%） | — |

### 到達可能母集団と天井

- 年間アクティブ受験者: 全部門で**4〜5万人強**（一次＋二次、重複除く）
- リピート学習者を含めても**実質5〜6万人規模**
- **宅建の1/5〜1/6**の市場サイズ
- 棚田チャンネル20万登録を5年で到達したペースから単純換算 → **技術士専業の天井は4〜5年で登録3,000〜6,000人**

### 再生数の相場感

- 1動画あたり**数百〜数千**
- 1万再生はスター級・合格発表期の季節動画のみ
- 100万再生は構造的に不可能

### 収益性の結論

**広告収益単独では赤字確実**。ただし1動画が総監受験者の1%（≒30人）に届けば、note/サイト送客として十分機能する。

## 3. 競合マップ

**1万人超の技術士専業チャンネルは日本に存在しない**。

| チャンネル | 主宰 | フォーカス | 形式 | 弱点 |
|---|---|---|---|---|
| 技術士Lock-On | 匠習作（機械・総監） | 二次全般／論文／口頭 | 顔出し長尺講義 | 有料講座販促、短尺不在 |
| 技術士合格セオリー | 4部門技術士ぺんた | 合格ノウハウ／添削経験 | 顔出しなし中頻度 | 更新不定期 |
| 技術士ライトハウス | coolangeng.com | 一次・二次／トレードオフ記事 | 講座抜粋 | 静的・ほぼ休眠 |
| SAT公式チャンネル | SAT株式会社 | 現場系資格全般 | プロ制作スライド | 技術士単体ではない |
| Yokosuba技術士受験講座 | gijyutushijyuken.com | 二次論文の法則 | 顔出し低頻度 | ブログ主体 |

### 空白の度合い

- **総監部門特化**: 事実上ゼロ（Lock-Onが部分的に触れる程度）
- **短尺スキマ時間型**: 全チャンネルが「長尺講義」または「有料講座販促」で、3〜5分の独立コンテンツが皆無
- **音声主体のながら聴取型**: 診断士のダンシ君スタイルが技術士には持ち込まれていない

## 5. 参入戦略

### 基本方針

1. **目的を「note/サイト送客」に固定**。チャンネル登録者をKPIにしない
2. **既存MDX→スライド自動化パイプラインを先に構築**（Claude + satori/Remotion等）。手動制作はMDX執筆時間を食い潰す
3. **最初の10本は総監キーワード特化**。差別化が最も鋭い領域で、既存資産の転用コストがほぼゼロ

### KPI設計

| 指標 | 採用 | 理由 |
|---|---|---|
| チャンネル登録者数 | ❌ 主KPIにしない | 市場天井が狭いため無意味 |
| **概要欄クリック率** | ✅ 主KPI | 送客器としての機能を測定 |
| **doboku-note UTM流入（YouTube経由）** | ✅ 主KPI | 実際の送客効果を定量化 |
| **note商品ページへの遷移率** | ✅ 主KPI | マネタイズ貢献度 |
| 1動画あたりの再生数 | △ 補助指標 | コンテンツ品質の参考値 |
| 視聴完了率 | △ 補助指標 | テンポ改善のシグナル |

### 投稿形式の初期プロトタイプ

- **尺**: 3〜5分（スキマ時間消費型）
- **音声**: VOICEVOX（声質より安定性）
- **スライド**: Claude生成 + satori/Remotion で半自動化
- **オープニング**: 10秒以内で結論を提示（離脱防止）
- **概要欄**: doboku-note記事リンク + note商品リンク（UTM付き）
- **投稿頻度**: 週2〜3本（毎日は無理、週1では初動評価でアルゴリズムに拾われない）

## 6. リスクと対策

| リスク | 影響度 | 対策 |
|---|---|---|
| 動画編集工数がサイトコンテンツ拡充を圧迫 | **高** | パイプライン構築を先行。手動編集は禁止 |
| YouTubeアルゴリズムの初動評価で埋もれる | 中 | 週2〜3本の定期投稿を3ヶ月以上継続。途中で止めない |
| Lock-Onが「総監×スキマ時間」に参入 | 低 | 有料講座販促モデルとバッティングするため参入可能性は低い |
| VOICEVOXの商用利用規約違反 | 低 | 事前にライセンス条件を確認（キャラクター別に規定あり） |
| 音声品質がチャンネル離脱を招く | 中 | ABテストで音声を複数試す。完走率を指標化 |

## 7. 着手判断（v3 で刷新）

### v3 方針: Q3 試験後に強制立ち上げ

v2 の「Phase 1進捗70%を GO/NO-GO 条件」は撤廃。運営者の試験受験という一回性のイベントを最大限に活かすため、**7月の試験直後に強制立ち上げ**する。試験当日の熱量は時間経過で確実に失われるため、条件を積んで遅延するリスクの方が大きい。

### Q2（4-6月）: 準備フェーズ

- [ ] YouTube チャンネル開設・アート設定
- [ ] 収録機材の選定・導入（マイク、スクリーン収録ソフト）
- [ ] スライド生成ワークフロー確立（Claude + satori/Remotion）
- [ ] 録音・編集ワークフロー検証（1本を本番品質で仮制作）
- [ ] 初期20本の構成メモ作成（試験前でもできる範囲で）

**Q2 では動画は投稿しない**。試験勉強の邪魔になるため、準備のみにとどめる。

### Q3（7-9月）: 本格立ち上げフェーズ

- [ ] **7月中旬: 運営者が技術士総監2次筆記を受験**
- [ ] 試験翌週: 初動画投稿（試験当日の話 + 論文組み立て解説）
- [ ] 週1本ペースで8月・9月を継続
- [ ] サイト連携（各動画の詳細は doboku-note へ誘導）
- [ ] 3ヶ月で登録 200 / 月間再生 5,000 を達成 → 隔週ペースに切替継続
- [ ] 未達成 → 投稿を止めず内容を見直す（途中離脱が最悪）

### Q4（10-12月）: 合格発表対応フェーズ

- [ ] 10月末: 筆記合格発表対応
  - 合格時: 「筆記合格しました」動画投稿（E-E-A-T 強化の最大機会）
  - 不合格時: 「不合格から学んだこと」動画投稿（次年度受験者への価値）
- [ ] 11月〜: 1級土木2次・技術士1次の季節スポット動画
