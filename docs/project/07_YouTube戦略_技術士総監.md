# YouTube 戦略 — 技術士（総合技術監理部門）

**策定日**: 2026-04-13
**対象**: 技術士 総合技術監理部門（主）／建設部門（従）
**位置づけ**: doboku-note / note への送客チャネル検討
**関連**: [04_コンテンツロードマップ.md](./04_コンテンツロードマップ.md)

## エグゼクティブサマリー

- **顔出しなしで参入可能**。成功要件は「声質」ではなく「テンポと投稿頻度」
- **独立収益は期待しない**（市場天井が狭い）。**note/サイト送客器**として割り切る
- **競合は4〜5チャンネルのみ、登録者1万人超の技術士専業は存在しない**。総監部門はほぼ競合ゼロ
- 既存の700キーワード＋過去問資産を**1トピック1本の短尺動画**に再パッケージするのが最強の差別化

---

## 1. 顔出しなしフォーマットの実現可能性

### 採用する形式

**VOICEVOX + Claude生成スライド + 短尺3〜5分**

### 根拠

- 中小企業診断士など隣接資格では2026年時点で「対面→AI音声・スライド」への転換が広がっている
- 棚田行政書士チャンネル（20万登録）の分析から、**成功要件は「声質」ではなく「毎日に近い投稿頻度」と「10秒以内離脱を防ぐテンポ」**
- 10秒以内の離脱を防ぐオープニング設計（高速カット）は必須

## 2. 市場規模と集客見込み

### 母集団（令和7年度）

| 指標 | 値 | 出典 |
|---|---|---|
| 技術士一次 受験者 | 17,013名（合格率33.8%） | 文科省統計 |
| 技術士二次 受験者 | 24,135名（合格率11.4%） | 文科省統計 |
| **総合技術監理部門 二次** | **2,618名（合格率20.7%）** | R6統計 |
| 建設部門 二次 | 約1万名（全部門の40〜50%） | — |

### 到達可能母集団と天井

- 年間アクティブ受験者: 全部門で**4〜5万人強**（一次＋二次、重複除く）
- リピート学習者を含めても**実質5〜6万人規模**
- **宅建の1/5〜1/6**の市場サイズ
- 棚田チャンネル20万登録を5年で到達したペースから単純換算 → **技術士専業の天井は4〜5年で登録3,000〜6,000人**

### 再生数の相場感

- 1動画あたり**数百〜数千**
- 1万再生はスター級・合格発表期の季節動画のみ
- 100万再生は構造的に不可能

### 収益性の結論

**広告収益単独では赤字確実**。ただし1動画が総監受験者の1%（≒30人）に届けば、note/サイト送客として十分機能する。

## 3. 競合マップ

**1万人超の技術士専業チャンネルは日本に存在しない**。

| チャンネル | 主宰 | フォーカス | 形式 | 弱点 |
|---|---|---|---|---|
| 技術士Lock-On | 匠習作（機械・総監） | 二次全般／論文／口頭 | 顔出し長尺講義 | 有料講座販促、短尺不在 |
| 技術士合格セオリー | 4部門技術士ぺんた | 合格ノウハウ／添削経験 | 顔出しなし中頻度 | 更新不定期 |
| 技術士ライトハウス | coolangeng.com | 一次・二次／トレードオフ記事 | 講座抜粋 | 静的・ほぼ休眠 |
| SAT公式チャンネル | SAT株式会社 | 現場系資格全般 | プロ制作スライド | 技術士単体ではない |
| Yokosuba技術士受験講座 | gijyutushijyuken.com | 二次論文の法則 | 顔出し低頻度 | ブログ主体 |

### 空白の度合い

- **総監部門特化**: 事実上ゼロ（Lock-Onが部分的に触れる程度）
- **短尺スキマ時間型**: 全チャンネルが「長尺講義」または「有料講座販促」で、3〜5分の独立コンテンツが皆無
- **音声主体のながら聴取型**: 診断士のダンシ君スタイルが技術士には持ち込まれていない

## 5. 参入戦略

### 基本方針

1. **目的を「note/サイト送客」に固定**。チャンネル登録者をKPIにしない
2. **既存MDX→スライド自動化パイプラインを先に構築**（Claude + satori/Remotion等）。手動制作はMDX執筆時間を食い潰す
3. **最初の10本は総監キーワード特化**。差別化が最も鋭い領域で、既存資産の転用コストがほぼゼロ

### KPI設計

| 指標 | 採用 | 理由 |
|---|---|---|
| チャンネル登録者数 | ❌ 主KPIにしない | 市場天井が狭いため無意味 |
| **概要欄クリック率** | ✅ 主KPI | 送客器としての機能を測定 |
| **doboku-note UTM流入（YouTube経由）** | ✅ 主KPI | 実際の送客効果を定量化 |
| **note商品ページへの遷移率** | ✅ 主KPI | マネタイズ貢献度 |
| 1動画あたりの再生数 | △ 補助指標 | コンテンツ品質の参考値 |
| 視聴完了率 | △ 補助指標 | テンポ改善のシグナル |

### 投稿形式の初期プロトタイプ

- **尺**: 3〜5分（スキマ時間消費型）
- **音声**: VOICEVOX（声質より安定性）
- **スライド**: Claude生成 + satori/Remotion で半自動化
- **オープニング**: 10秒以内で結論を提示（離脱防止）
- **概要欄**: doboku-note記事リンク + note商品リンク（UTM付き）
- **投稿頻度**: 週2〜3本（毎日は無理、週1では初動評価でアルゴリズムに拾われない）

## 6. リスクと対策

| リスク | 影響度 | 対策 |
|---|---|---|
| 動画編集工数がサイトコンテンツ拡充を圧迫 | **高** | パイプライン構築を先行。手動編集は禁止 |
| YouTubeアルゴリズムの初動評価で埋もれる | 中 | 週2〜3本の定期投稿を3ヶ月以上継続。途中で止めない |
| Lock-Onが「総監×スキマ時間」に参入 | 低 | 有料講座販促モデルとバッティングするため参入可能性は低い |
| VOICEVOXの商用利用規約違反 | 低 | 事前にライセンス条件を確認（キャラクター別に規定あり） |
| 音声品質がチャンネル離脱を招く | 中 | ABテストで音声を複数試す。完走率を指標化 |

---

## 7. 着手判断

### GO条件

- [ ] MDX→スライド自動化パイプラインの技術検証が完了している
- [ ] 04_コンテンツロードマップ Phase 1（サイトの総監記述式基礎整備）が70%以上進捗している
- [ ] 週2〜3本の投稿を3ヶ月以上継続できる時間的余力が見込める

### NO-GO条件（いずれか該当で見送り）

- パイプライン構築に1ヶ月以上かかる見込み
- サイトの総監Phase 1が遅延している
- 他チャネル（note本体、アフィリエイト）の立ち上げで余力がない

---

## 8. 次のアクション（優先順位付き）

1. **MDX→スライド自動化パイプラインの技術調査**（satori/Remotion/Claude API）
2. **VOICEVOX商用利用ライセンスの確認**
3. **プロトタイプ動画1本制作**（総監キーワード「フォロワーシップ」など、既存記事から変換）
4. **プロトタイプを関係者に見せてテンポ・音声品質をフィードバック**
5. Phase 1 の進捗確認後、本格着手のGO/NO-GO判断
