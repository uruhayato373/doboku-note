# iOS アプリ画面設計 — 技術士（総合技術監理部門）対策アプリ

> **v1 (2026-05-19)** — 仕様書 v2 ([01_iOSアプリ仕様.md](./01_iOSアプリ仕様.md)) Phase 0-3 として作成。主要 8 画面のワイヤーフレーム + 画面遷移図 + Free/Premium UI 挙動の真実源。SwiftUI 実装時はこのドキュメントを参照する。

## 画面マップ（全体構造）

```
[起動]
  ↓
[Splash] ──(初回起動)──> [Onboarding 3step] ──> [Home Tab]
              │
              └──(2回目以降)──────────────────> [Home Tab]

[Home Tab] — 下部4タブ
 ├─ 演習 (Practice)
 │   ├─ 演習モード選択
 │   ├─ 年度別 → 年度選択 → 問題演習 → 結果サマリー
 │   ├─ ランダム → 問題演習 → 結果サマリー
 │   └─ 5管理別 → カテゴリ選択 → 問題演習 → 結果サマリー
 ├─ キーワード (Keywords)
 │   ├─ 5管理カテゴリ一覧
 │   ├─ 検索
 │   └─ キーワード詳細 (Free=概要 / Premium=詳細)
 ├─ 進捗 (Progress)
 │   ├─ 正答率推移 / 5管理レーダー / streak
 │   └─ 苦手問題ブックマーク
 └─ 設定 (Settings)
     ├─ Premium 購入 → StoreKit シート
     ├─ データ更新 / 利用規約 / プライバシーポリシー
     └─ 運営者プロフィール (合格体験リンク)
```

## ナビゲーション原則

| 原則 | 内容 |
|---|---|
| **タブ常駐** | 下部 4 タブは常に表示（深い階層からも 1 タップで戻れる） |
| **モーダル使い分け** | 課金・設定詳細・解説詳細はモーダル（タブ階層を汚さない） |
| **戻る** | iOS 標準 swipe-back + 左上 < ボタン |
| **Premium ゲート** | コンテンツ自体は見えるが操作不可 + 解放 CTA を必ず併設（隠さない） |
| **オフライン挙動** | 全画面オフライン動作。同期不要のメッセージで明示 |

**StoreKit 2 フロー**:
1. 「選択」タップ → `Product.purchase()` 呼び出し

4. 全 Premium 機能がリアルタイム解放（再起動不要）
5. クーポン発行: アプリ内通知 + コピー可能なクーポンコード表示

## Free / Premium 境界 UI 挙動の原則

| 場所 | Free 表示 | Premium 表示 |
|---|---|---|
| 年度別演習リスト | R07 = 完全解放 / R01-R06 = 🔒 + 「Premium を見る」CTA | 全年度解放、進捗バッジ |
| ランダム演習 | R07 内 40 問からランダム | 全 280 問からランダム |
| 5 管理別演習 | 各管理から R07 出題分のみ | 全年度から該当管理を抽出 |
| キーワード詳細 | 概要 100 文字のみ、詳細部分は半透明オーバーレイ + CTA | 完全表示 |
| 進捗ダッシュボード | Free 範囲の正答率のみ | 全範囲の正答率 + 弱点分析 |
| この問題に登場 | Premium 出題は 🔒 マーク付きで表示（カニバりを煽らない） | 全表示・タップで該当問題へ遷移 |

**設計原則**:
- **隠さず・ロック表示する**: Premium コンテンツの存在自体は見せる（価値訴求）
- **CTA は嫌味にしない**: ロック画面に強い広告型 CTA を貼らず、控えめなボタンに留める
- **Free で十分試せる**: R07 全 40 問 = 受験 1 年分相当の品質体感ができる

## エッジケース UI 挙動

| ケース | 挙動 |
|---|---|
| 初回起動 + オフライン | Splash で「ネット接続が必要です。Wi-Fi をオンにしてください」表示、待機 |
| 2 回目以降 + オフライン | Home 表示、ヘッダーに「オフライン」インジケータ。全機能動作 |
| Premium 購入後にデータ未更新 | Premium フラグは即反映、コンテンツは次回更新時に同期 |
| 購入失敗（決済キャンセル） | 「購入をキャンセルしました」スナックバー、Free のまま継続 |
| データ更新でスキーマ変更 | manifest version が major bump → 「アプリの更新が必要」ダイアログ + App Store リンク |
| iCloud 同期（v1.1+） | MVP では端末ローカルのみ。v1.1 で iCloud 同期検討 |

## クリティカル UX 判断

| 判断 | 採用案 | 理由 |
|---|---|---|
| 課金訴求の頻度 | 自然な動線 (ロック画面のみ) + 進捗 7 日目のソフトプロンプト | 押し付けがましい全画面広告は審査リスク + UX 悪化 |
| 解説の即時表示 | 回答直後に自動遷移 (0.5秒間) | 「次へ」タップ強制は摩擦、学習リズム維持 |
| ブックマークの位置 | ヘッダー右の単独アイコン + 結果画面の「復習」CTA 両方 | 学習中も振り返り時もアクセス可能 |
| 進捗 streak の重み | 大きく表示 | 継続学習の動機づけ、買い切りユーザーの定着率に寄与 |
| 広告 | **入れない** | 買い切りモデルなので広告不要、UX 最優先 |
