## 1. 方法（この版の位置づけ）

この第1版は **方式B（事前登録・pre-registration）** に限定した、git 日付で固定された実物だけの
検証。憶測の盲検スコアリング（方式A/C）は含めない。「いま採点して当たっていた」は主張しない。

- 根拠は git の初出コミット日時と frontmatter のみ（`01-evidence-ledger.md`）。
- 対象年度の実出題テーマ（ground truth）: R6=カーボンニュートラル / R7=少子高齢化 / R8=地方創生。

### 2-3. R8の正直な総括

- **当てたのは「本命1点狙い」ではなく、K=11の候補セット**の1つ。Kが11と広い点を隠さない

  設問(3)で使える国家施策6案を用意していた」。**「予想問題集の本命が的中」とは言わない。**

## 3. R6（カーボン）・R7（少子高齢化）— 前向き検証は**不能**（隠さず記録）

- 設問(3)国家施策バンク（カーボン・少子高齢化を含む11テーマ）の git 初出は **2026-06-01**。
  これは R6(2024)・R7(2025) の**試験より後**。
- したがって、バンクに R6/R7 テーマが入っていても、それは**事後収録（後知恵）であり前向き予測
  ではない**。R6/R7 の「的中」としてカウントしてはならない。
- リポジトリを調べた範囲で、**R6/R7 の試験前に固定された候補予測の git-dated artifact は存在
  しない**。よって repo ベースの前向きバックテストは R6/R7 では成立しない。

## 5. 結論（この版で言えること／言えないこと）

**言える**:
- 設問(3)国家施策バンク（K=11・2026-06-01 git固定）に地方創生を含め、R8で一致した。
- 施策6案は設問(3)の構造に整合していた。
- これは日付が git で固定された、後知恵でない前向きの1データ点である。

**言えない（この版では）**:
- 「予想（本命）が的中した」— 本命は気候変動適応で外した。
- 「R6/R7 も当てていた」— バンクは事後作成で前向き検証にならない。
- 「予測精度が高い」— 前向きデータ点は R8 の1件、しかも K=11 の広い網。精度主張には R6/R7 の
  方式C検証と、Kを絞った予測の成績が要る。

## 6. R6/R7 統制 run（方式C相当・2026-07-22 実施）

`03-backtest-protocol.md` §3 の「出題を知らないエージェントへ当時資料のみを渡す統制 run」を実施した。

**方法**: 各年度3体の独立エージェント（レンズ分散: A=白書・閣議決定起点 / B=過去問距離・出題者心理起点 / C=社会統計・構造変化起点）。カットオフ=試験前日（R6=2024-07-13・R7=2025-07-19）。入力=カットオフ以前公表の資料台帳（白書2024=2024-06-28公表・骨太・国土形成計画・GX法・こども未来戦略・国土強靱化計画等）。8軸0-3採点・**K=5事前固定**・落選理由・汚染自己申告を必須出力。outcome は非開示。判定は `02-match-criteria.md`（論点一致・迷ったら不一致に倒す）。

**結果**:

| 年度 | 実出題 | lens-A | lens-B | lens-C | K=5カバレッジ |
|---|---|---|---|---|---|
| R6 | カーボンニュートラル | 一致（GX・脱炭素 2位） | 一致（GX・エネ転換 2位） | 一致（GX・エネ構造転換 **1位・24/24**） | **3/3** |
| R7 | 少子高齢化 | 不一致（隣接=担い手不足5位・少子化財源は落選） | 一致（少子化・高齢化×公共サービス維持 5位） | 不一致（隣接=生産年齢人口減×建設業4位） | **1/3** |

**解釈（商品設計の妥当性の定量裏付け）**:
- 政策文書上の必然が強い年（R6カーボン=GX法・エネ基本計画）は K=5 でも全レンズが捕捉。
- 出題が「政策の背後の社会構造」へ振れる年（R7少子高齢化）は K=5 で 1/3 のみ。**少数絞りは外しやすい**。
- 副次観測: R7 の run 上位に「地方創生」が 2/3 で出現（A=3位・C=2位）→ **翌年R8で実出題**（K=11バンクが git 実証で一致）。上位候補は年をまたいで当たりに行く＝幅広備蓄の再利用価値。
- 総合: 「一点予想ではなく K=11 の幅広備蓄＋答案部品化」という商品②の設計は、統制 run の外れ方によって定量的に支持される。

**盲検性の限界（隠さず開示）**:
- エージェントの知識カットオフ（2026-01）は R6/R7 の実施後を含み、**後知恵バイアスを構造的に完全排除できない**。緩和策=outcome非開示・当時資料への根拠紐付け強制・汚染自己申告・年度断定の禁止。
- **汚染イベント1件**: 初回 R6 lens-C がリポジトリ内 protocol の ground truth 表を読んで自己申告→**無効化**し、ツール完全禁止のクリーン再実行で置換した（本表の R6 lens-C は再実行値）。教訓として、エージェント採点 run はツール遮断（リポジトリ・Web不可）を必須とする。
- したがって本統制 run は「参考統制値」であり、真の前向き証拠は依然として R8 の git 事前登録（§2）のみ。実績表現では統制 run を「的中」と呼ばず「方法の挙動検証」として扱う。
