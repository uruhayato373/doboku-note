> **再発防止ガード**: 本文 prose への廃止アフィリ（添削サービス/講座ブランド等）再提案を `npm run check-affiliate-prose`（denylist=`src/config/affiliate-prose-denylist.json`）で機械検知。pre-commit（staged）＋ `r2-audit.yml`（全量 backstop）に配線済み。

- **学習・受験意図 → note（自社・高粗利）が独占。** 学習スパンドの導線は note CTA に一本化する。
- **キャリア意図 → 転職アフィリ（唯一の稼働アフィリ）。** 建設・施工管理特化の転職エージェント/サイト。会員登録・無料相談などの低ハードル成果で **¥25,000〜¥50,000/件**。受験者＝資格でキャリアアップを狙う層と一致し、note と財布が別なので競合しない。年収・キャリア・転職を扱うガイド記事との相性が最も高い。配置は `CareerAffiliate`（記事末・本文インライン）と `SidebarAdBanner`（PC サイドバー）。
- **note ドメインパワー活用（2026-07-14 戦略転換・ユーザー指示）。** 従来の「学習→note独占／キャリア→サイトのアフィリ」に加え、**note.com 自体でも BuildJob/キャリアの指名・比較・顕在クエリを取りに行く**（note の高 DA で新規サイトページより早く上位化しうるため、多少のサイトとの共食いは許容）。キャリア意図の**無料 note 記事**に生 A8 リンク（note 専用 mat `4B5OO5+FHBA2+5B0Y+NTJWY`・PR 表記必須）を置き、対応するサイト高意図記事と相互リンク（`utm_medium=referral`）で権威を渡し合う。**note 有料の学習商品（模範論文/経験記述）は非侵食**。数値（BuildJob 公式の 163万/50,529人/4.8）は景表法リスクで note でも不掲載＝定性記述。実装状況＝既存キャリア note 8本＋新規 N7-N9（ビルドジョブの評判/転職エージェント比較/辞める前確認）を 2026-07-14 に公開済み。**さらに 2026-07-14 横展開**：高流入の受験ガイド/資格ハブ 3本（2級受験資格 n6e6db14f4dfc・2級と1級どちらから n28133dda5888・資格活用キャリアマップ nd2f697ffbc4a）に実務者セグメント限定の A8（NTJWY）＋サイト動線を追加、総監マネー系 3本（n05800ac28d27/n9376aac312df/n700c51ea6f00）は動線のみ（総監＝シニア層で BuildJob ミスマッチのため A8 なし）で新規公開。**設計・記事一覧の真実源は `08_転職アフィリ記事ビルド計画.md` §note 記事（N1-N12＋総監マネー系）**。

## 運用ポリシー

### 配置原則
- doboku-note のメイン導線は「ここだけで合格できる」体験。アフィは**補完ポジション**で配置
- 講座は「独学派 + 部分的講座活用」スタンスで紹介（記述添削など穴を埋める前提）
- LP煽り表現（「絶対合格」等）は禁止

### 配置候補ページ
- 技術士総監ハブページ（補完導線）
- 記述式対策ページ（添削サービス比較）
- 1級土木の問題集ページ（参考図書）

### 公開タイミング
- 講座申込ピーク（1〜3月）の前、**11〜2月**に公開
- 二次試験本番（7月）から逆算してコンテンツ整備

### 配置パターン（テキスト vs バナーの使い分け）

| 配置 | 形式 | 理由 |
|---|---|---|
| 本文中インライン | テキスト | 自然な文脈で挿入できる、煽り感が出ない |
| Callout 内（補足・参考） | テキスト | 「記述添削は外注も選択肢」のような自然な形 |
| 比較表のセル | テキスト | レイアウト崩れ防止 |
| 記事末のCTA | バナー | 視覚的訴求、行動喚起 |
| hubページの補完導線セクション | バナー | 「もっと深く学ぶ」「添削が欲しい」用の出口 |
| ファーストビュー（記事冒頭） | 使わない | 「ここだけで合格」のメイン導線と矛盾するため |

### バナー実装時の必須ルール
1. **計測ピクセル（1x1 img）は必ずセットで貼る** — 外すと成果が計測されない
2. **`loading="lazy"` を付ける** — ファーストビュー外でもLCPに影響を残さない
3. **`width` / `height` を指定する** — CLS（レイアウトシフト）防止
4. **`alt` を埋める** — 空 alt は規約違反ではないが、アクセシビリティ向上のため記入
5. **A8.net 新形式バナー（JavaScript型）は使わない** — Next.js では動かない。必ず「旧版を表示する」でシンプル `<a><img/></a>` 形式を取得

### 再検討トリガー

以下に該当したら管理方式を見直す。

1. **講座アフィが 5 件以上 / 配置が数十か所規模になったら** — **解決済み（2026-06-16）**: 全 A8 creative はコンポーネント／config に集約され、**MDX 本文の生 mat 直書きは 0**（GKS=`<CareerAffiliate program="gks">`、独学カード／SAT 技術士=`<CourseAffiliate program="...">`、独学インライン=`<DokugakuKeikenLink>`、独学バナー=`<DokugakuBanner>`、SAT テキスト=`<SatTextLink>`）。mat 変更は各コンポーネント／config 1 箇所で全配置に反映。`scripts/check-affiliate-mats.mjs` が **(a) 未登録 mat=ERROR、(b) MDX への生 mat 直書き=ERROR、(c) 失効 creative の配置=WARN** を機械検知（pre-commit／`npm run check-affiliate-mats`）。残課題は講座 creative の `affiliate-courses.json` 一元化（任意・現状はコンポーネント分散で運用可）。
2. **ページ別の成果分析が必要になったら** — 同一案件は全ページで同じ creative URL を使うため、A8 レポートではページ別のクリック/成約を区別できない。ページ別に最適化したい場合は、ページごとに別リンクを発行するか計測層を追加する必要がある。

### 計測ラベルの命名規約（GA4 クリック計測）

アフィリエイトリンクは `data-cta="affiliate"` ＋ `data-cta-label="{label}"` を持ち、`AnalyticsProvider` が `affiliate_cta_click`（eventName）として GA4 へ送る（集計は **eventName ベース**でラベル allowlist は無いため、新ラベルは自動で計測に乗る）。ラベルは以下の規約で付ける。

- **サイドバー枠**: `{Program}-sidebar`（例 `GKS-sidebar` / `BuildJob-sidebar`）。`SidebarAdBanner` の `trackLabel`。
- **本文インライン カード**: `CareerAffiliate` / `SchoolAffiliate` は `service` 名がラベルになる（例 `GKSキャリア`）。
- 注意: 同一 eventName に集約されるため、A8 レポートと併せないと **プログラム別・サーフェス別のクリックはページ単位でしか分離できない**（ビルドジョブ単独 CTR が要るなら GA4 取得に `customEvent:` ディメンションを追加）。
