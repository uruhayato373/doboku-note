## 収益方針: 書籍＝補完 / 講座＝主力（二層構造）

アフィリエイトは「補完ポジション」だが、その中でも単価が二層に分かれる。書籍を高単価に置き換えるのではなく、二層を併用する。

- **書籍（Amazon/楽天、もしも経由）＝ 補完層。** 単価が低い（書籍 ≈ 3%、¥3,000 で約¥90）。撤去はしない — 試験対策記事に自然に置け、読者の信頼・回遊に効く。`<BookCard>`（もしも かんたんリンク）で記事末に配置済み。収益主力には数えない。
- **資格講座（A8.net 等）＝ 主力層。** 技術士・施工管理技士の通信講座は ¥30,000〜¥100,000+ の高額商材。1 件成約で書籍数十〜百冊分。記述添削・業務経歴票添削など「独学では埋めにくい穴」を補う文脈で訴求でき、サイトの受験者層と完全一致。

**注力方針**: 申請中の講座提携（アガルート・スタディング）の承認を進め、主要講座を A8.net 中心に開拓・配置する。配置は記述式対策ページ・hub 末尾の補完導線（`CourseAffiliate` コンポーネント）。書籍 `<BookCard>` はそのまま補完として継続。

## 運用ポリシー

### 配置原則
- doboku-note のメイン導線は「ここだけで合格できる」体験。アフィは**補完ポジション**で配置
- 講座は「独学派 + 部分的講座活用」スタンスで紹介（記述添削など穴を埋める前提）
- LP煽り表現（「絶対合格」等）は禁止

### 配置候補ページ
- 技術士総監ハブページ（補完導線）
- 記述式対策ページ（添削サービス比較）
- 1級土木の問題集ページ（参考図書）

### 公開タイミング
- 講座申込ピーク（1〜3月）の前、**11〜2月**に公開
- 二次試験本番（7月）から逆算してコンテンツ整備

### 配置パターン（テキスト vs バナーの使い分け）

| 配置 | 形式 | 理由 |
|---|---|---|
| 本文中インライン | テキスト | 自然な文脈で挿入できる、煽り感が出ない |
| Callout 内（補足・参考） | テキスト | 「記述添削は外注も選択肢」のような自然な形 |
| 比較表のセル | テキスト | レイアウト崩れ防止 |
| 記事末のCTA | バナー | 視覚的訴求、行動喚起 |
| hubページの補完導線セクション | バナー | 「もっと深く学ぶ」「添削が欲しい」用の出口 |
| ファーストビュー（記事冒頭） | 使わない | 「ここだけで合格」のメイン導線と矛盾するため |

### バナー実装時の必須ルール
1. **計測ピクセル（1x1 img）は必ずセットで貼る** — 外すと成果が計測されない
2. **`loading="lazy"` を付ける** — ファーストビュー外でもLCPに影響を残さない
3. **`width` / `height` を指定する** — CLS（レイアウトシフト）防止
4. **`alt` を埋める** — 空 alt は規約違反ではないが、アクセシビリティ向上のため記入
5. **A8.net 新形式バナー（JavaScript型）は使わない** — Next.js では動かない。必ず「旧版を表示する」でシンプル `<a><img/></a>` 形式を取得
