最終更新: 2026-04-05

## ビジョン

「1級土木施工管理技士」と「技術士（総合技術監理部門）」の2試験に特化した技術ノートとアプリで、受験者と技術者の学習を支援する。

---

## 2事業の構造

**判断基準: Claude Code で自動化できる割合が高い事業に集中する。**

| 事業 | 役割 | 収益モデル | 優先度 |
|---|---|---|---|
| **doboku-note**（Webサイト） | SEO集客の入口。信頼構築の場 | AdSense + アフィリエイト + note有料記事 | Phase 1 実装中 |
| **iOSアプリ** | スキマ時間の学習体験。両試験の過去問演習 | 広告 + サブスク（¥600/月） | **Web収益化後に着手判断**（条件: Web月間収益 ≥ ¥15,000） |

2事業は相互送客で成長を加速する:

- doboku-note → アプリ: 試験対策ページで「スキマ時間に過去問演習」を訴求 → DL
- アプリ → doboku-note: 「詳しい解説はdoboku-noteで」→ サイトPV増・E-E-A-T向上

### 捨てたもの

| 捨てたもの | 理由 |
|---|---|
| 書籍（KDP） | 校正・構成・プロモーションに人間の判断が大きく、自動化困難 |
| Udemy講座 | 顔出し・声出し・動画編集が必須。Claude Code の恩恵ゼロ |

## 競合環境（2026-04-05調査）

### 1級土木施工管理技士の市場

**3層の競合構造**が存在する:

| 層 | 競合 | SEO上の脅威 |
|---|---|---|
| **無料過去問サイト** | 過去問ドットコム、施工管理ドットコム、どぼくじら、ちゃんさと、施工管理求人.com | 中（過去問キーワードで競合） |
| **大手資格スクール** | CIC、アガルート、日建学院、TAC、総合資格学院 | **高（情報系キーワードで上位独占）** |
| **有料講座・添削** | 施工管理合格ネット、独学サポート事務局 | 低（有料のためSEO直接競合なし） |

**最重要な発見**: 大手スクールが「試験日程」「勉強法」「合格率」「受験資格」等の情報系キーワードを独占。ドメインパワーの差が大きく、正面から勝つのは困難。

### 技術士（総合技術監理部門）の市場

**無料Webコンテンツが圧倒的に不足**しているブルーオーシャン:

| 層 | 競合 | 状況 |
|---|---|---|
| **無料Web** | pejp.net（25年分過去問）、技術士道（総監特化、kope.info）、鹿夫（certlabo.com）、過去問ドットコム | いずれも部分的。キーワード集の体系的Web解説は**市場に存在しない** |
| **有料講座** | ガチンコ技術士学園（59,400円）、スタディング、アガルート、新技術開発センター等8社 | 有料が主戦場。無料での差別化余地が大きい |

**最重要な発見**: 文科省キーワード集（5管理26節200超キーワード）をWebで体系的に解説しているサイトは皆無。doboku-noteの100トピック＋pe-section-mapは市場唯一のポジション。

### 両試験の横断: 競合ゼロ

1級土木＋技術士総監を同一サイトで横断学習できるサービスは存在しない。総監受験者の多くは1級土木有資格者であり、この接点は強力な差別化要素。

**詳細レポート**: `docs/reviews/competitor-audit/2026-04-04_civil-construction-1.md`, `docs/reviews/competitor-audit/2026-04-05_pe-comprehensive-management.md`

## 成長戦略：2つのループ × ロングテールSEO

### SEO戦略の基本方針（競合分析に基づく）

| 方針 | 理由 |
|---|---|
| **情報系キーワードを避ける** | 「試験日程」「勉強法」「合格率」は大手スクールの独壇場 |
| **ロングテールに集中する** | 「令和7年 土木一般 問3 解説」「技術士 総監 フォロワーシップ」等の個別キーワード |
| **技術士総監を優先公開する** | 競合が弱いブルーオーシャン。コンテンツ公開だけで市場リーダー |
| **構造化データで強化する** | Quiz/FAQ schema で検索結果の表示面積を拡大 |

### 1. 技術リファレンス SEO ループ（★★★★★）

**仕組み**: 体系的な技術ノートを公開 → 技術者が業務中に検索 → ブックマーク・社内共有 → 被リンク増加 → ドメイン権威向上 → 新規ページも上位表示しやすくなる

| 基準 | 評価 |
|---|---|
| 適合度 | 5/5（1級土木+技術士総監は体系的・検索性重視） |
| 現在の成熟度 | 3/5（約320ファイル。SEO効果が出始める段階） |
| 実装コスト | S（公開済み。SEO最適化で加速） |
| 成長速度 | 中期（3-6ヶ月） |
| 複利効果 | 高（被リンク蓄積→ドメイン権威→新規ページも上位に） |

**具体的な攻め方**:
- **技術士総監のキーワード解説**: 「技術士 総監 [キーワード名]」で200超のロングテールを狙える。競合は kope.info のみ
- **1級土木のテキスト教科書**: textbook/配下のコンテンツで体系的学習を提供（建設データジャーナルの連載形式に類似）
- **分野別横断整理**: 「コンクリートの養生 過去問まとめ」等のテーマ別切り口

### 2. 資格試験 SEO ループ（★★★★☆）

**仕組み**: 試験対策コンテンツ公開 → 受験者が試験前に検索 → 学習・ブックマーク → 合格後に後輩・同僚に共有 → 翌年の受験者がさらに検索

| 基準 | 評価 |
|---|---|
| 適合度 | 4/5（1級土木7月・技術士は11月と季節性が読みやすい） |
| 現在の成熟度 | 2/5（試験対策ガイド・問題集が変換中） |
| 実装コスト | M（既存資産の再構成で対応） |
| 成長速度 | 中期（季節性あり。試験3-4ヶ月前に急増） |
| 複利効果 | 中（毎年同じ試験があるため安定的に蓄積） |

**具体的な攻め方**:
- **過去問の個別問題解説**: 「令和7年 1級土木 問A-3 解説」等。大手スクールが手薄なロングテール
- **第2次検定の記述対策**: 無料Web公開サイトが極めて少ない。最大の差別化機会
- **技術士総監の択一解説**: certlabo.com の詳細さ × 過去問ドットコムのアクセシビリティの中間

**季節性**:
- 4月上旬: 1級土木申込締切 **← 今ここ**
- 6月: 2級土木第一次試験（需要ピーク）
- 7月5日: 1級土木第一次試験（需要ピーク）
- 7月中旬: 技術士二次試験（論文対策需要ピーク）
- 10月4日: 1級土木第二次試験
- 11月: 技術士一次試験 / RCCM

### ループ間の相乗効果

- ループ1（技術リファレンス）→ トラフィックがSEOデータを生む
- ループ2（資格試験）→ 受験者流入がnote有料記事の見込み客になる
- **横断効果**: 1級土木の受験者が技術士総監コンテンツを発見 → リピーター化

全ループが互いを強化するフライホイール構造。起点はループ1（SEO流入）。

## Pre-Mortem（失敗シナリオと対策）— 競合分析反映版

| シナリオ | 対策 |
|---|---|
| 計画を立てるだけで実装が進まない | 「Sコスト」タスクは当日中に完了。計画と実装の乖離を週次レビューで検出 |
| 情報系キーワードに時間を使ってしまう | 「試験日程」「勉強法」「合格率」は大手スクールの独壇場。ロングテールに集中する |
| 技術士総監コンテンツのSEO最適化が進まない | 270ファイルは公開済みだがtitle/description・内部リンク未最適化。4月中にSEO改善してGSCインデックス構築 |
| ドメインパワー不足でロングテールも順位が上がらない | 270ファイルのインデックス蓄積で3-6ヶ月で改善見込み。構造化データ（Quiz/FAQ schema）で補強 |
| 既存競合がコンテンツ更新で追いつく | kope.info・certlabo.comは個人運営で更新頻度が低い。先行量で差をつける |
| 大手スクール（アガルート等）が総監SEOに本腰 | 「無料×体系的×全文検索」の組み合わせは大手が真似しにくい。早期のインデックス構築が鍵 |
| noteが売れない | 2週間で5部未満 → note縮小してアフィリエイトに集中 |
| iOSアプリに既に強力な競合（5,551問アプリ） | テキスト教科書連動・横断学習・間隔反復で差別化。過去問数だけの勝負は避ける |
| 5チャネル並行でリソース分散 | 実質3チャネル（AdSense+アフィリエイト+note）に絞る。iOSアプリは条件付き |
