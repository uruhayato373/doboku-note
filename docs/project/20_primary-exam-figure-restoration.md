## 抽出手順

### ステップ1: PDF ページを PNG にレンダリング

```bash
python3 -c "
import fitz
doc = fitz.open('path/to/exam.pdf')
page = doc[page_num - 1]
pix = page.get_pixmap(dpi=150)
pix.save('/tmp/page.png')
"
```

- 解像度: 150dpi（メモリ記録: 200dpi だと 2000px 制限エラー）
- A4 @ 150dpi ≈ 1240 × 1754 px

### ステップ2: 図の領域をクロップ

```bash
convert /tmp/page.png -crop WxH+X+Y -trim +repage output.png
```

- 各問題の図の位置はページ内で異なるため、PDF を Read して目視確認 → 座標指定
- 一部の問題は図が選択肢に含まれる（曲げモーメント図 4 種、ひび割れ 4 種）→ まとめて 1 枚にするか個別にするか判断

### ステップ3: MDX ファイルに `<img>` タグを挿入

```html
<img src="/posts/civil-construction-1/primary-r07-a/img/r07-a-fig-01.png" alt="土の構成の模式図" loading="lazy" />
```

- 命名規約: `{exam-id}-fig-{sequential}.png`
- 挿入位置: 「下図」の直後（問題文と選択肢の間）
- 「※図は省略」がある場合は削除

## 品質基準

- 図がページ上で問題文と選択肢の間に正しく表示されること
- `alt` テキストが図の内容を適切に説明していること
- 画像サイズが適切であること（幅 600-800px 程度）
- ダークモードでの視認性（白背景の図は問題ないが、必要に応じて確認）

## 検証方法

- `npm run build` が成功すること
- dev サーバーで各問題ページを開き、図が正しい位置に表示されていることを目視確認
- 「※図は省略」テキストが残っていないことを grep で確認
