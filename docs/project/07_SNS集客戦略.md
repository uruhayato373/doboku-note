# SNS集客戦略 v3

doboku-note（1級土木施工管理技士 / 技術士総合技術監理部門 特化サイト）への流入を SNS から獲得するための方針。

最終更新: 2026-04-13（v3: 合格体験者ポジションと YouTube 昇格を反映）

## 1. 基本方針

- **Q2 の主戦場は X（旧Twitter）**。受験生コミュニティが活発で即効性が高い
- **★Q3 から YouTube を主力チャネルに昇格**。運営者本人の技術士総監2次筆記受験（2026-07）を軸にした「受験記チャンネル」として立ち上げる。v2では「Phase 3 以降、動画制作コストが高く初期向けでない」としていたが、**合格体験者ポジションを活かすため Q3 必須立ち上げに変更**
- **Instagram は画像自動生成が整ってから着手**（Q3 以降）。ストック性を活かした補助チャネル
- NSM（月間オーガニック検索流入ユーザー数）への直接貢献は限定的でも、**指名検索・被リンク・権威性**を通じて間接的に SEO を底上げする

## 2. チャネル別の位置づけ（v3）

### X（主力・Q2〜継続）

- **目的**: 受験生の日常導線に入り込み、サイトへの流入と指名検索を作る
- **コンテンツ**: 過去問1問 + 解説リンク、キーワード解説の要約、試験日程リマインダー
- **★Q3追加**: 運営者の学習進捗・試験当日の所感をリアルタイムで発信 → 受験記者としての認知獲得
- **頻度**: 1日1〜2投稿。固定ポスト（pinned）に「サイト紹介 + 無料過去問リンク」
- **運用**: `/x-post` スキルで下書き生成 → 手動投稿
- **KPI**: フォロワー数、プロフィールクリック率、サイト流入セッション数
- **トレードオフ**: 投稿が流れやすく継続が必須

### ★ YouTube（Q3 から主力・v3で昇格）

- **目的**: 技術士総監2次筆記（2026-07）の受験記を軸にしたチャンネル。note/サイトへの送客と、直接広告収益の両方を狙う
- **コンセプト**: 「2026年度 技術士総監 受験記 + doboku-note 解説」
- **立ち上げ時期**: 2026年7月下旬（試験後）
- **コンテンツ（Q3 初期20本）**:
  1. 試験当日の流れ・持ち物・メンタル管理
  2. 2026年度 2次筆記 解答再現（抜粋）
  3. 論文の組み立て方（自分の解答を素材に）
  4. 5管理を横串で書く技術
  5. 使用教材のレビュー × 3本
  6. 働きながら3ヶ月で準備する計画
  7. 過去問の着眼点解説 × 5本
  8. 頻出テーマ解説 × 5本
  9. 受験中の失敗談
  10. 次年度受験者へのアドバイス
- **形態**: 声のみ＋スライド可（顔出しは後から検討）
- **投稿頻度**: 週1本 → 3ヶ月後に隔週
- **KPI**: 概要欄クリック率、doboku-note UTM流入（YouTube経由）、note商品ページ遷移率
- **判断基準**: 3ヶ月でチャンネル登録 200 / 月間再生 5,000 を達成できれば継続
- **詳細**: `07_YouTube戦略_技術士総監.md` を参照

### Instagram（補助・Q3 以降）

- **目的**: 画像カルーセルで「試験対策まとめ」をストックし、保存・シェアから流入
- **コンテンツ**:
  - 過去問1問 = 画像カルーセル（問題 → 選択肢 → 解答 → 解説 → サイト誘導）
  - キーワード解説の図解（BCP、リスクマネジメント等）
- **頻度**: 週2〜3投稿で十分
- **画像生成**: satori + resvg-js（既存 `/generate-ogp` と同じスタック）で静的カルーセル画像を自動生成
- **KPI**: 保存数、プロフィールアクセス、リンククリック
- **立ち上げ条件**: YouTube チャンネルが軌道に乗った後（Q4以降）

### TikTok / YouTube Shorts（2027年以降）

- YouTube 本チャンネルが軌道に乗った後、Shorts / TikTok に横展開
- 動画化の第一弾は「過去問1問を30秒で解説」形式

## 3. アカウント戦略：独自アカウント vs 個人アカウント

**結論: doboku-note 専用の独自アカウントを作成する。**

### 独自アカウントが望ましい理由

| 観点 | 理由 |
|---|---|
| **ブランド一貫性** | サイト名と一致したハンドル（例: `@doboku_note`）で指名検索・認知が積み上がる |
| **フォロワーの文脈** | 受験対策目的でフォローした人にだけリーチが届く。個人アカでは技術・プライベート投稿が混ざりノイズになる |
| **資産性** | 将来 iOSアプリ・note 有料記事をローンチした時、アカウントごと譲渡・共同運用が可能 |
| **分析の純粋性** | GA4 の参照元として `doboku-note-x` を識別しやすく、施策評価が明確 |
| **リスク分離** | 炎上・凍結時の影響範囲を限定できる |

### 独自アカウントの弱点と対策

- **初期のフォロワーゼロ問題** → 個人アカウントから固定ポストで相互紹介、または初期の数十ポストをバックデートで積む
- **運用負荷** → `/x-post` スキルで下書き自動化、投稿だけ手動に留める

### 推奨セットアップ

- **X**: `@doboku_note`（または類似の空き名）
  - プロフィール: 「1級土木施工管理技士・技術士総合技術監理の無料過去問解説サイト運営」
  - 固定ポスト: サイトトップ + 人気過去問1問
  - ヘッダー画像: satori で生成（サイトロゴ + キャッチコピー）
- **Instagram**: `@doboku_note`（X と統一）
  - bio リンク: サイトトップ（または Linktree で過去問・キーワードへ複数導線）
  - Phase 2 開始時に作成。Phase 1 では予約のみ

## 5. 計測と意思決定

- **GA4 の UTM パラメータ**を全 SNS リンクに付与（`utm_source=x` / `utm_source=instagram`）
- **月次レビュー**で SNS 経由セッション数・直帰率・指名検索数を確認
- 3ヶ月継続して NSM への寄与が見えなければ撤退・方針転換

## 6. やらないこと

- **有料広告は当面使わない**。オーガニックと SEO に集中
- **毎日複数プラットフォームを同時運用しない**。Phase ごとに1チャネルずつ立ち上げる
- **個人的な意見・政治・時事ネタへの言及は避ける**。試験対策アカウントとしての信頼性を守る

## 7. フォロワーゼロから立ち上げる1年戦略（X）

資格試験は年サイクル（1次6月・2次10月・合格発表1月）で需要が動くため、1年間を通じて試験カレンダーに同期させるのが最も効率的。ただし最初の90日が最大の山場なので、年次目標より **90日ごとのマイルストーン** で管理する。

### Month 0: 立ち上げ準備（1週間）

- [ ] アカウント作成（`@doboku_note`）、プロフィール・ヘッダー画像設定（satori で生成）
- [ ] **30投稿分の下書きを `/x-post` で一括生成**して予約投稿（空アカウントに見せない）
- [ ] フォロー対象100件リストアップ: 1級土木受験生、技術士受験生、建設会社勤務、資格系インフルエンサー、建設系YouTuber
- [ ] 固定ポスト設定: 「無料過去問○○問を解説しています」+ サイトリンク

### Month 1-3: 基礎固め（目標100フォロワー）

- **毎日1〜2投稿を継続**（これが9割）
- 投稿パターンを3種類で回す:
  1. 過去問1問 + 解説リンク
  2. キーワード解説の要約
  3. 学習Tips・試験情報
- 受験生ツイートに **1日10件リプライ**（宣伝なし、純粋な補足や励まし）
- 週1で `#1級土木施工管理技士` `#技術士` のハッシュタグ投稿
- **撤退判断**: 3ヶ月で50フォロワー未満なら投稿内容を見直す

### Month 4-6: 1次試験直前ブースト（目標500フォロワー）

- 1次試験は毎年 **6月第1日曜**。試験3ヶ月前から需要ピーク
- 「試験○日前カウントダウン」投稿を日次で
- 過去問解説の頻度を倍に（1日2〜3投稿）
- 試験当日は「お疲れさまでした」投稿で合格発表までフォロワー維持

### Month 7-9: 2次試験ブースト（目標1500フォロワー）

- 2次試験（**10月第1日曜**）対策にシフト
- 記述式・経験記述の解説は画像カルーセル化 → **Instagram連携開始の好機**
- note の有料記事ローンチを検討（予想問題集・経験記述テンプレート等）

### Month 10-12: 合格発表・次年度誘導（目標3000フォロワー）

- 合格発表（**1月**）での「合格報告RT」で一気に認知拡大
- 次年度受験生の早期囲い込み（「来年受験する方はフォロー」投稿）
- 1年の振り返りスレッドで権威性を蓄積

### 成功の鍵

- **投稿より「返信」が効く**: 受験生コミュニティは狭いので、役立つリプライ10件 > 無反応な投稿10件
- **試験日程に全振り**: 6月・10月・1月の3ピークを逃さない
- **3ヶ月で諦めない**: X は3ヶ月目までが最も伸び悩む。ここで多くが脱落する

### 90日マイルストーン管理

| 時点 | フォロワー目標 | 主要KPI | 撤退/見直し基準 |
|---|---|---|---|
| Day 90 | 100 | 日次投稿継続率90%以上 | 50未満なら投稿内容を見直し |
| Day 180 | 500 | サイト流入月100セッション | 200未満なら固定ポスト・プロフィール改善 |
| Day 270 | 1500 | サイト流入月500セッション | 800未満なら Instagram 投入を前倒し |
| Day 365 | 3000 | サイト流入月1500セッション | 1500未満なら全体戦略の再設計 |
