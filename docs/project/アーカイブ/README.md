# docs/project/アーカイブ/

時限的だが履歴として参照価値のあるプロジェクト文書を保管する。`docs/project/` 直下は「現時点で真実源として生きている」文書のみ、`アーカイブ/` は「役目を終えた handoff や完結済みプロジェクトの記録」を格納する。

削除ではなく archive に残す理由:
- session-handoff のような時限文書は、再参照時に git log から掘り起こすより直接読めた方がコスト低
- 「なぜその判断をしたか」を知るための一次資料

## 収録ルール

- 文書の役目が終わっている（Phase 完結 / サイクル終了 / プロジェクト中止）
- 現在の運用には不要だが、将来の設計判断で参照する可能性がある
- 削除すると履歴が追いにくくなる内容（handoff / ADR 一次資料等）

現時点で active な文書かどうか迷ったら、`docs/project/` 直下に残す。
