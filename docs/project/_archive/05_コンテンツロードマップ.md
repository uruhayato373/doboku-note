## note 有料記事：棲み分け原則（v3 で「合格体験シリーズ」を追加）

| カテゴリ | doboku-note.com（無料） | note.com（有料） |
|---|---|---|
| 基礎資産 | リファレンス・網羅解説 | 要点整理・テンプレート・ドリル |
| **合格体験（★v3追加）** | 試験当日の所感・学習ログの一部（集客用） | **解答再現・論文全文・学習記録の完全版** |
| 読者行動 | 検索で来て調べる | 「合格したい」動機で購入する |

**原則: 無料サイトに既にある内容をそのまま有料化しない。無料=素材、有料=加工品。**
**★v3 追加原則: 本人の受験体験に基づく一次情報は note 有料の独占コンテンツ。他人が書けない＝最強の差別化。**

## 基本方針: サイト先行・note/YouTube 後追い

noteとYouTubeの売上・再生数はサイト流入（NSM）に依存するため、集客エンジンとしてのサイトを先に整備し、そこで築いた信頼を有料商品と動画に転換する。

### なぜサイト先行か

1. **noteの売上はサイト流入に依存する** — SEOで来た読者が「信頼 → 有料購入」と進む
2. **「ここだけで合格できる」が無料の信頼を作る** — 記述式の考え方・骨組みがサイトにある状態が前提
3. **コンテンツの二度使い** — サイト記事を再編集・圧縮して note / YouTube スクリプトに転用
4. **★v3追加: 試験勉強そのものがサイト記事になる** — 運営者の論文練習・学習ログがそのまま無料記事の素材

### 3ヶ月区切りの原則

**「70%の完成度で次へ進む」** を徹底する。特に Q2 は本人の試験勉強が最優先のため、サイト更新は「完璧を目指さず、学習の副産物として積み上げる」スタイルで進める。

### やらないこと（各試験共通）

- 完成答案の無料公開（→ note で有料化）
- キーワードのTop100絞り込みの無料公開（→ note で有料化）
- 口頭試験対策の網羅的無料公開（→ note で有料化）
- **★v3追加: 運営者自身の論文全文の無料公開（→ note 合格体験シリーズで有料化）**
