| 競合 | 強み | doboku-noteとの差別化 |
|---|---|---|

| **SAT / アガルート / スタディング** | 通信講座各社。大量のSEOコンテンツ+広告予算 | 無料リファレンスとして補完的な位置。アフィリエイトで連携 |
| **過去問.com 系アプリ** | 累計60万DL。1級土木の過去問演習に特化 | モダンUI+サイト連携+第2次試験対応で差別化 |

### doboku-noteの差別化

- 公的技術資料のMDX化（原典PDFの構造化・検索可能化）は競合不在
- 2試験に特化した体系的コンテンツ整理
- 無料リファレンス + 有料テンプレートの棲み分け
- 技術士総監は競合が比較的少なく、100ファイルの未公開資産が差別化の源泉

## 各チャネルの詳細

### 1. AdSense（今すぐ）

- AdSenseUnit コンポーネントを新規作成し、記事末尾に1箇所配置
- **実装状況**: layout.tsx にスクリプト追加 + コンポーネント作成が必要（v1で「読込済み」としていたのは誤り）
- **CVR計算**: 月間3,000 PV × RPM ¥150 / 1,000 = ¥450/月（現時点）。UU成長に比例して増加
- **予想収益**: 悲観 ¥300/月 → 標準 ¥2,250/月 → 楽観 ¥15,000/月
- **備考**: 公開ページ数が少ない段階ではAdSenseポリシー審査に懸念あり。技術士総監の公開化でページ数を増やしてから申請推奨

### 2. 通信講座アフィリエイト（並行検証）

- A8.net / もしもアフィリエイト経由でアガルート・SAT・スタディング等と提携
- **実装状況**: ASP未登録。4月中に登録+比較記事1本作成で開始
- **報酬単価**: 1件 ¥3,000〜¥10,000（書籍の10〜100倍、note記事1部の3〜11倍）
- **CVR計算**: 月間3,000 UU × 比較記事CTR 5% × 申込CVR 2% = 月3件 → ¥9,000-30,000/月。ただし初期は比較記事への流入が少なく、月1件程度が現実的
- **前提**: 比較記事（「1級土木 通信講座 比較」等）の作成が必須
- **予想収益**: 悲観 ¥0/月 → 標準 ¥5,000/月 → 楽観 ¥40,000/月

### 3. note 有料記事（並行検証）

- 既存MDX資産を「試験対策」の切り口で再構成して note.com で販売
- **実装状況**: 商品設計完了。テスト販売準備中
- **CVR計算**: 月間3,000 UU → note遷移率2% = 60人/月 → note購入CVR 3% = 1.8部/記事。3記事で月5.4部 × ¥900 × 0.9 = **¥4,374/月**（現時点）。6ヶ月後（30,000 UU想定）で月54部 → **¥43,740/月**
- **現実的な標準値**: 季節変動込みで **¥15,000/月**（6ヶ月平均）
- **テスト販売**: N-1「1級土木施工管理 頻出論点50選」¥980 を4月に販売開始
- **判断基準**: 2週間で5部以上 → 本格展開
- **予想収益**: 悲観 ¥5,000/月 → 標準 ¥15,000/月 → 楽観 ¥80,000/月

### 4. Amazon 書籍アフィリエイト

- 各技術ノート末尾に「参考書籍」セクション + AmazonLink
- **実装状況**: コンポーネント未作成（v1で「実装済み」としていたのは誤り）
- **紹介料率**: 書籍3%固定（1冊あたり ¥90〜¥240）
- **対象書籍**: 試験対策12冊 + 専門技術書11冊 計23冊を特定済み
- **予想収益**: 悲観 ¥18/月 → 標準 ¥200/月 → 楽観 ¥3,000/月

### 5. iOSアプリ（Web収益化後に着手判断）

- 広告（AdMob）+ サブスク課金（¥600/月）
- **着手条件**: Web月間収益 ≥ ¥15,000 を達成してから開発に着手
- **理由**: 個人運営で5チャネル並行は非現実的。Web収益化の土台を固めてからリソースを投入
- **CVR計算**: 月間200-300 DL × サブスク転換率3% = 月6-9人の新規課金。解約率20%で定常60-75人 × ¥600 + AdMob = **¥25,000/月**
- **予想収益**: 悲観 ¥3,000/月 → 標準 ¥25,000/月 → 楽観 ¥70,000/月

### 6. YouTube 合成音声スライド動画（Phase 2 検討）

- Claude Codeでスライド生成 → VOICEVOX等の合成音声で解説動画を制作
- **メリット**: 顔出し・声出し不要。Google検索 + YouTube検索の2軸でトラフィック獲得
- **対象コンテンツ**: 「1級土木施工管理技士 勉強法」「1級土木 過去問 解説」等
- **リスク**: 動画制作のオペレーション安定化にコストがかかる
- **判断**: Phase 2でテスト動画1本を制作し、視聴数・チャンネル登録率で継続判断

### 7. LINE公式（Phase 2 検討）

- 無料枠（月1,000通）で試験直前リマインダー → note/アフィリエイト告知
- **メリット**: プッシュ通知でリピート訪問を促進。試験直前の購買意欲が高いタイミングでアプローチ
- **実装**: サイト上にフォロー誘導バナーを設置 → 試験2ヶ月前から配信開始
- **判断**: 友だち登録数100人を目標に検証。Phase 2（5-6月）に開設

## リスクマトリクス

| リスク | 深刻度 | 発生確率 | 対策 |
|---|---|---|---|
| **noteプラットフォーム依存** | 高 | 中 | noteの収益比率を50%以下に抑制。自前課金（Stripe）はPhase 3以降で検討 |
| **Google検索アルゴリズム変動** | 高 | 中 | E-E-A-T強化（著者プロフィール充実）、被リンク獲得、構造化データ追加 |
| **過去問の著作権** | 中 | 低 | 解説は完全オリジナルを徹底。出典明記。試験実施機関の公開方針を確認 |
| **試験制度変更** | 低 | 低 | 2試験特化でリスク分散。技術士総監は制度的に安定 |
| **実行リソース不足** | 高 | 高 | チャネル数を実質3に絞る（AdSense + アフィリエイト + note）。iOSアプリは条件付き |

## 凍結した候補

| 候補 | 凍結理由 |
|---|---|
| 有料検索 + AI Chat SaaS | Clerk+Stripe+Vectorize の構築コスト大。現在のPV規模ではROI不足 |
| 法人ナレッジベースライセンス | 営業チャネルがなく個人運営では困難（ただし「法人お問い合わせ」ボタンの設置は工数ゼロのため検討可） |
| 書籍（KDP） | 校正・構成・プロモーションに人間の判断が大きく、自動化困難 |
| Udemy講座 | 顔出し・声出し・動画編集が必須。Claude Code の恩恵ゼロ |
