## エグゼクティブサマリー

v2（2026-04-04策定）からの主要変更点:

1. **合格体験者ポジションを中核差別化に据える**: **サイト運営者本人が技術士総監 2 次筆記試験に合格済み**。学習過程と試験体験が一次ソースになり、競合（情報整理屋中心）に対する強力な差別化を形成する
2. **YouTube と iOS を「両方残す」**: v2では YouTube を「検討中」、iOS を「Web 収益¥15k 後に判断」としていたが、合格体験者ストーリーを軸に両方を Q3-Q4 で段階的に立ち上げる方針に変更
3. **収益化の時間軸を「試験カレンダーに合わせて組み直し」**: 7月の筆記試験を起点に、Q2=学習×整備、Q3=試験後のまとめ＆立ち上げ、Q4=合格発表後スケールの3段階に再編
4. **iOS アプリの着手条件は維持**: 「Web 月間収益 ≥ ¥15,000」の条件は変えない（リソース分散を防ぐため）。ただし **筆記合格発表（10月末）を着手シグナルの追加条件**として加える

### v4 補足（2026-04-26）: SNS チャネルの量産型への転換

- **YouTube/Instagram は完全自動 SNS 量産チャネルに転換**（[07_SNS集客戦略 v5](./07_SNS集客戦略.md)、[26_Instagram投稿自動化アーキテクチャ v3](./26_Instagram投稿自動化アーキテクチャ.md)）。受験勉強優先という運営者の制約下で SNS 運用の人手依存をゼロにする。**v5/v3（2026-04-28）で IG を Carousel + Reels の両軸へ転換**（YT Shorts mp4 を IG Reels に流用）
- **5 チャネル統合ファネル**（X / YouTube / IG / note / サイト）の動線設計・UTM 統一・季節調整は [27_5チャネル動線設計.md v1](./27_5チャネル動線設計.md) を真実源とする。note ↔ サイトの検索競合防止（Red Line #5）の運用ルールも 27 §7 弱点 3 で定式化
- **合格体験者ポジションは note 商品（E-1〜E-4）と iOS アプリで担保**: SNS では機械生成のキーワード解説を量産、受験記の追体験コンテンツは note 側で展開
- **役割分担**: SNS = ストック性のある送客器（量産・継続性重視）、note・iOS = 一次情報の独占商品（高単価・希少性重視）
- 詳細: [Umbrella Issue #161](https://github.com/uruhayato373/doboku-note/issues/161)

### doboku-noteの差別化（v3 で再定義）

1. **一次ソースとしての合格体験**: 運営者本人が技術士総監 2 次筆記試験に合格済み。解答再現・論文構成・学習法が全て**本人の経験に基づく一次情報**となる。情報整理屋中心の競合との決定的な違い
2. **体系リファレンス × 受験記のハイブリッド**: 677ファイルの技術士総監コンテンツ（知識基盤）と、合格体験（ストーリー）を同じドメインで提供できる。競合はどちらか一方
3. **公的技術資料のMDX化**: 原典PDFの構造化・検索可能化は競合不在
4. **Phase 1 の 2 試験（1級土木・技術士総監）を深掘り**: 広く浅くではなく、資格ごとに「ここだけで合格できる」深さを積み上げ、段階的にハブを拡張

## 合格体験者ポジションの活用戦略

### なぜ決定的な差別化になるか

- 総監を受験する層は「合格した人のリアルな体験」を強く求める（情報整理記事より信頼される）
- 論文再現（特に自分の解答の全文公開）は**競合が絶対に作れないコンテンツ**（他人の論文は再現できない）
- サイト運営者＝受験者という構造は E-E-A-T（経験・専門性・権威性・信頼性）の全軸を一気に埋める

### 合格前と合格後のコンテンツ価値

| 時期 | コンテンツ種別 | 価値 |
|---|---|---|
| **受験前（〜7月）** | 学習過程の記録・使用教材レビュー・論文骨組みテンプレ | 「これから受験する人の参考」として有効 |
| **試験直後（7月後半〜10月）** | 解答再現・論文全文・手応え分析・反省点 | 合格発表前でも note/YouTube で高い関心。**次年度受験者への貴重な資料** |
| **筆記合格発表後（10月末〜）** | 「筆記合格者の学習法」として権威性が急上昇 | 有料商品の訴求力が一段上がる |
| **最終合格後（2027-03〜）** | 「総監合格者による解説」が全コンテンツに適用可能 | サイトの E-E-A-T 全面強化 |

### 失敗時のリスク管理

- 筆記不合格でも「不合格体験記」として note 有料化可能（むしろ失敗の方が学びが多い）
- 運営上のリスクは低い。合格を前提にして戦略を組まず、**体験自体をコンテンツ化するスタンス**を取る

## 各チャネルの詳細

### 1. AdSense（Q2 即実装）

- AdSenseUnit コンポーネントを新規作成し、記事末尾に1箇所配置
- **実装状況**: layout.tsx にスクリプト追加 + コンポーネント作成が必要
- **CVR計算**: 月間3,000 PV × RPM ¥150 / 1,000 = ¥450/月（現時点）。UU成長に比例して増加
- **予想収益**: 悲観 ¥300/月 → 標準 ¥2,250/月 → 楽観 ¥15,000/月
- **備考**: 技術士総監 677 ファイルの公開化は完了済み。ポリシー審査の懸念は緩和されている

### 2. 通信講座アフィリエイト（Q2 並行検証）

- A8.net / もしもアフィリエイト経由でアガルート・SAT・スタディング等と提携
- **実装状況**: ASP未登録。4月中に登録+比較記事1本作成で開始
- **報酬単価**: 1件 ¥3,000〜¥10,000
- **CVR計算**: 月間3,000 UU × 比較記事CTR 5% × 申込CVR 2% = 月3件 → ¥9,000-30,000/月。ただし初期は月1件程度が現実的
- **予想収益**: 悲観 ¥0/月 → 標準 ¥5,000/月 → 楽観 ¥40,000/月

### 3. note 有料記事（基礎）: Q2 テスト販売

- 既存MDX資産を「試験対策」の切り口で再構成して note.com で販売
- Q2 は N-1（1級土木）・B-1（総監キーワードTop100）等の**既存資産ベース**の商品を先行投入
- **予想収益**: 悲観 ¥5,000/月 → 標準 ¥15,000/月 → 楽観 ¥80,000/月

### 4. Amazon 書籍アフィリエイト（Q2 即実装）

- 各技術ノート末尾に「参考書籍」セクション + AmazonLink
- **紹介料率**: 書籍3%固定（1冊あたり ¥90〜¥240）
- **予想収益**: 悲観 ¥18/月 → 標準 ¥200/月 → 楽観 ¥3,000/月

### ★ 6. YouTube（v4: 総監キーワード解説 量産チャンネル）: Q2 基盤整備 → Q3 から週 3 本

**v4（2026-04-26）で「受験記チャンネル」から「TTS 量産チャンネル」に転換**。詳細は [07_SNS集客戦略.md v4](./07_SNS集客戦略.md) の YouTube セクション参照。

- **コンセプト**: 技術士総監 694 キーワード + 過去問 680 問を TTS + 自動スライドで量産。Shorts 主力（30-60 秒）、補助で 5 管理別解説の標準動画（3-5 分）
- **配信形態**: 顔出しなし固定。VOICEVOX TTS + Satori 自動スライド + ffmpeg。完全機械生成
- **初期コンテンツ**: 総監キーワード解説 Shorts × 30 本（運営者の手作業ゼロで量産）
- **受験記コンテンツは note 商品（E-1〜E-4）に集約**。YouTube からは概要欄リンクで送客のみ
- **目的**: 直接の広告収益 + note・サイトへの流入経路（v3 と同じ）
- **判断基準**: 3ヶ月で月間再生 5,000 を達成できれば継続。未達でも自動投稿継続（止めるコストの方が高い）
- **予想収益**: 悲観 ¥0/月 → 標準 ¥3,000/月 → 楽観 ¥20,000/月（直接収益。間接的な note 送客効果は別）
- **関連 Issue**: [#161 Umbrella SNS 自動投稿基盤](https://github.com/uruhayato373/doboku-note/issues/161)（子 #162-#168）

## リスクマトリクス（v3 更新）

| リスク | 深刻度 | 発生確率 | 対策 |
|---|---|---|---|
| **筆記試験不合格** | 中 | 中 | 不合格でも「挑戦記」として note/YouTube コンテンツ化可能。サイトの基礎価値は変わらない |
| **試験対策の負荷でサイト更新停滞** | 高 | 高 | Q2 は「70%完成度で次へ」を徹底。学習＝コンテンツ化の一体運用 |
| **noteプラットフォーム依存** | 高 | 中 | noteの収益比率を50%以下に抑制。自前課金（Stripe）はPhase 3以降で検討 |
| **Google検索アルゴリズム変動** | 高 | 中 | E-E-A-T強化（合格体験で自然に強化される）、被リンク獲得、構造化データ追加 |
| **YouTube 初期の伸び悩み** | 中 | 高 | 伸びなくても「note 送客経路」として機能すれば十分。直接収益を前提にしない |
| **実行リソース不足** | 高 | 高 | 試験勉強 × サイト更新 × YouTube × note の並行は過負荷。Q2 は学習最優先、Q3 で一気に出力 |
