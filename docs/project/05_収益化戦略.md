## エグゼクティブサマリー

v2（2026-04-04策定）からの主要変更点:

1. **合格体験者ポジションを中核差別化に据える**: 2026-07 に**サイト運営者本人が技術士総監2次筆記を受験**する。学習過程と試験体験が一次ソースになり、競合（情報整理屋中心）に対する強力な差別化を形成する
2. **YouTube と iOS を「両方残す」**: v2では YouTube を「検討中」、iOS を「Web 収益¥15k 後に判断」としていたが、合格体験者ストーリーを軸に両方を Q3-Q4 で段階的に立ち上げる方針に変更
3. **収益化の時間軸を「試験カレンダーに合わせて組み直し」**: 7月の筆記試験を起点に、Q2=学習×整備、Q3=試験後のまとめ＆立ち上げ、Q4=合格発表後スケールの3段階に再編
4. **iOS アプリの着手条件は維持**: 「Web 月間収益 ≥ ¥15,000」の条件は変えない（リソース分散を防ぐため）。ただし **筆記合格発表（10月末）を着手シグナルの追加条件**として加える

### doboku-noteの差別化（v3 で再定義）

1. **一次ソースとしての合格体験**: 2026-07 に運営者本人が技術士総監2次筆記を受験。解答再現・論文構成・学習法が全て**本人の経験に基づく一次情報**となる。情報整理屋中心の競合との決定的な違い
2. **体系リファレンス × 受験記のハイブリッド**: 677ファイルの技術士総監コンテンツ（知識基盤）と、受験記（ストーリー）を同じドメインで提供できる。競合はどちらか一方
3. **公的技術資料のMDX化**: 原典PDFの構造化・検索可能化は競合不在
4. **Phase 1 の 2 試験（1級土木・技術士総監）を深掘り**: 広く浅くではなく、資格ごとに「ここだけで合格できる」深さを積み上げ、段階的にハブを拡張

## 合格体験者ポジションの活用戦略

### なぜ決定的な差別化になるか

- 総監を受験する層は「合格した人のリアルな体験」を強く求める（情報整理記事より信頼される）
- 論文再現（特に自分の解答の全文公開）は**競合が絶対に作れないコンテンツ**（他人の論文は再現できない）
- サイト運営者＝受験者という構造は E-E-A-T（経験・専門性・権威性・信頼性）の全軸を一気に埋める

### 合格前と合格後のコンテンツ価値

| 時期 | コンテンツ種別 | 価値 |
|---|---|---|
| **受験前（〜7月）** | 学習過程の記録・使用教材レビュー・論文骨組みテンプレ | 「これから受験する人の参考」として有効 |
| **試験直後（7月後半〜10月）** | 解答再現・論文全文・手応え分析・反省点 | 合格発表前でも note/YouTube で高い関心。**次年度受験者への貴重な資料** |
| **筆記合格発表後（10月末〜）** | 「筆記合格者の学習法」として権威性が急上昇 | 有料商品の訴求力が一段上がる |
| **最終合格後（2027-03〜）** | 「総監合格者による解説」が全コンテンツに適用可能 | サイトの E-E-A-T 全面強化 |

### 失敗時のリスク管理

- 筆記不合格でも「不合格体験記」として note 有料化可能（むしろ失敗の方が学びが多い）
- 運営上のリスクは低い。合格を前提にして戦略を組まず、**体験自体をコンテンツ化するスタンス**を取る

## 各チャネルの詳細

### 1. AdSense（Q2 即実装）

- AdSenseUnit コンポーネントを新規作成し、記事末尾に1箇所配置
- **実装状況**: layout.tsx にスクリプト追加 + コンポーネント作成が必要
- **CVR計算**: 月間3,000 PV × RPM ¥150 / 1,000 = ¥450/月（現時点）。UU成長に比例して増加
- **予想収益**: 悲観 ¥300/月 → 標準 ¥2,250/月 → 楽観 ¥15,000/月
- **備考**: 技術士総監 677 ファイルの公開化は完了済み。ポリシー審査の懸念は緩和されている

### 2. 通信講座アフィリエイト（Q2 並行検証）

- A8.net / もしもアフィリエイト経由でアガルート・SAT・スタディング等と提携
- **実装状況**: ASP未登録。4月中に登録+比較記事1本作成で開始
- **報酬単価**: 1件 ¥3,000〜¥10,000
- **CVR計算**: 月間3,000 UU × 比較記事CTR 5% × 申込CVR 2% = 月3件 → ¥9,000-30,000/月。ただし初期は月1件程度が現実的
- **予想収益**: 悲観 ¥0/月 → 標準 ¥5,000/月 → 楽観 ¥40,000/月

### 3. note 有料記事（基礎）: Q2 テスト販売

- 既存MDX資産を「試験対策」の切り口で再構成して note.com で販売
- Q2 は N-1（1級土木）・B-1（総監キーワードTop100）等の**既存資産ベース**の商品を先行投入
- **予想収益**: 悲観 ¥5,000/月 → 標準 ¥15,000/月 → 楽観 ¥80,000/月

### 4. Amazon 書籍アフィリエイト（Q2 即実装）

- 各技術ノート末尾に「参考書籍」セクション + AmazonLink
- **紹介料率**: 書籍3%固定（1冊あたり ¥90〜¥240）
- **予想収益**: 悲観 ¥18/月 → 標準 ¥200/月 → 楽観 ¥3,000/月

### ★ 6. YouTube（総監受験記チャンネル）: Q3 後半に立ち上げ

- **コンセプト**: 「2026年度 技術士総監 受験記」を軸にしたチャンネル。試験直後〜口頭試験までの追体験動画を主軸に
- **配信形態**: 顔出し or 声のみ＋スライド（立ち上げ時は負担軽減のため声のみ可）
- **初期コンテンツ**:
  - 試験当日の手応え・再現解答の話
  - 使用教材の実レビュー
  - 論文の組み立て方（自分の解答を素材に）
  - サイト連携（各動画の詳細は doboku-note の記事へ誘導）
- **目的**: 直接の広告収益 + note・サイトへの流入経路
- **判断基準**: 3ヶ月でチャンネル登録 200 / 月間再生 5,000 を達成できれば継続
- **予想収益**: 悲観 ¥0/月 → 標準 ¥3,000/月 → 楽観 ¥20,000/月（直接収益。間接的な note 送客効果は別）

### 7. iOSアプリ（Q4 着手判断）

- 広告（AdMob）+ サブスク課金（¥600/月）
- **着手条件（v3で強化）**:
  1. Web 月間収益 ≥ ¥15,000
  2. **かつ 筆記合格発表済み（2026年10月末以降）** — 「合格者本人が設計した演習アプリ」として訴求するため
- **CVR計算**: 月間200-300 DL × サブスク転換率3% = 月6-9人の新規課金。定常60-75人 × ¥600 + AdMob = **¥25,000/月**
- **予想収益**: 悲観 ¥3,000/月 → 標準 ¥25,000/月 → 楽観 ¥70,000/月

### 8. LINE公式（Q3検討）

- 無料枠（月1,000通）で試験直前リマインダー → note/アフィリエイト告知
- 10月の1級土木2次、11月の技術士1次に合わせてリマインダー配信を試す
