## 各チャネルの詳細

### 1. AdSense（今すぐ）

- AdSenseUnit コンポーネントを記事末尾に1箇所配置するだけで開始
- **実装状況**: スクリプト読込済み（layout.tsx）。広告ユニットが未配置
- **予想収益**: 悲観 ¥600/月 → 標準 ¥5,000/月 → 楽観 ¥35,000/月
- **リスク**: 16ページ時点ではポリシー審査に懸念あり。公開ページ数増加後に申請

### 2. Amazon 書籍アフィリエイト（今すぐ）

- 各技術ノート末尾に「参考書籍」セクション + AmazonLink（associateId設定済み）
- **実装状況**: コンポーネント実装済み。MDX内での使用がまだ
- **紹介料率**: 書籍3%固定（1冊あたり90〜240円）
- **対象書籍**: 試験対策12冊 + 専門技術書11冊 計23冊を特定済み
- **予想収益**: 悲観 ¥18/月 → 標準 ¥315/月 → 楽観 ¥6,000/月

### 3. 通信講座アフィリエイト（4月以降）

- A8.net / もしもアフィリエイト経由でアガルート・SAT・スタディング等と提携
- **実装状況**: ASP未登録
- **報酬単価**: 1件3,000〜10,000円（書籍の10〜100倍）
- **前提**: 比較記事（「1級土木 通信講座 比較」等）の作成が必須
- **予想収益**: 悲観 ¥225/月 → 標準 ¥5,000/月 → 楽観 ¥80,000/月

### 4. note 有料記事（4月テスト販売開始）

- 既存672ページ+100ファイルのMDX資産を「試験対策」の切り口で再構成
- **実装状況**: 商品設計完了。N-6テスト販売準備中
- **新規執筆コスト**: 低い（既存資産の再構成）
- **季節性**: 試験直前期に需要が読みやすい
- **収益の主力**: 標準シナリオで Web 側収益の87%を占める見込み
- **詳細**: `04_コンテンツロードマップ.md` を参照

### 5. iOSアプリ（Phase 2・7月目標）

- 広告（AdMob）+ サブスク課金（¥600/月）
- **開発状況**: 技術設計完了。実装開始予定
- **役割**: doboku-noteからの相互送客で両事業が成長
- **予想収益**: 悲観 ¥5,000/月 → 標準 ¥47,000/月 → 楽観 ¥92,000/月

## 検証ロードマップ

### Phase 1（4月）: 即時実装 + note テスト販売

- ✅ AdSense 広告ユニット配置（記事末尾1箇所）
- ✅ AmazonLink 配置（主要20ページ）
- ✅ note.com アカウント開設 → N-6「2級土木 最短合格ルートマップ」¥500 テスト販売
- **判断**: RPM≥¥200 → 広告拡大 / note 2週間で5部 → 本格展開

### Phase 2（5-6月）: アフィリエイト + note 本格展開

- A8.net 登録 → 通信講座プログラム提携
- 比較記事作成（「1級土木通信講座比較」等）
- note 本格展開: N-1「1級土木 頻出50選」N-2「経験記述テンプレ」
- **判断**: note月間売上≥¥20,000 → マガジン開始検討

### Phase 3（7-9月）: 最適化 + スケール

- Phase 1/2 データに基づく配置最適化
- note 技術士向け記事投入（N-3「技術士一次科目別要点」等）
- マガジン M-1 開始判断（月間売上≥¥30,000 が条件）
