## 1. 背景と目的

doboku-note 運営者は技術士・総合技術監理部門（総監）二次試験に合格済み。中核差別化（v3 戦略「合格体験者ポジション」）の基礎工事として、過去問模範解答から **「考え方（思考パターン）」を構造化抽出する**。

抽出された型は以下に転用される。

- 合格体験コンテンツの裏付けデータ（運営者本人の答案ストックと突合）
- `essay-exam-strategy` の実証強化（三層構造の説明に「型 N 件のうち X 件が…」のデータを追加）
- Q2-A-8 頻出テーマ × 5管理 15 本の選定根拠
- Q2-A-9 過去問着眼点解説 7 本の素材
- note A-1〜A-3 商品（記述式 論文骨子テンプレート・テーマ駆動 5 管理横串フレームワーク / 合格答案実例集 / 思考パターン解説）

## 2. 分析対象の決定

### 2.1 出題傾向の変化点

`essay-exam-strategy/article.mdx` で既に整理されている通り、総監記述式の出題は次の 3 期に分かれる。

| 期 | 年度 | 中心テーマ |
|---|---|---|
| 初期 | H19-22 | BCP・リスク分析・不測の事態 |
| 中期 | H23-27 | 外部環境変化のシナリオ設計 |
| **近年** | **H28-R07** | **DX・データ・CN・少子高齢化など社会課題 + 実現性・障害・克服策** |

R08 受験の予測には近年期がもっとも有用であり、本プロジェクトは **H28 以降に分析対象を限定** する。

### 2.2 対象 8 年分の確定

H28-R07 の 10 年中、R03 のみ他者模範解答が掲載されておらず（[08 計画書](./08_記述式コンテンツ戦略.md) §1 参照）、本プロジェクトでは除外。最終的な分析対象は次の **8 年分**:

```
H28 / H29 / H30 / R01 / R02 / R04 / R05 / R06 / R07
                          ※ R03 は除外
```

実際の年度数は 9 だが、上の年度範囲で R03 を抜くと 8 年。

## 3. 分析フレーム

既存 [`essay-exam-strategy/article.mdx`](../../.local/r2/posts/pe-comprehensive-management/essay-exam-strategy/article.mdx) で確立された **三層構造** をそのまま採用する。

```
Ⅰ 管理対象と前提条件        ← 設計図
        ↓ 因果連鎖
Ⅱ 施策（効果＋問題点）       ← 5管理の組み合わせ + トレードオフ宣言
        ↓ 因果連鎖
Ⅲ 将来展望と最大リスク       ← 1つに絞る + 管理行為で克服
```

総監記述式の問題文は、設問 (1)(2)(3) がそれぞれ Ⅰ/Ⅱ/Ⅲ に対応する設計になっているため、模範解答も三層に分解可能。

## 4. 出力物

### 4.1 各年度の三層分析シート

ファイル: `essay-analysis/{year}.md`（年度別）。テンプレ詳細は [essay-analysis/README.md](./essay-analysis/README.md)。

各シートは以下を含む:
- 0 メタデータ / 1 問題文の三層対応 / 2 Ⅰ層分析 / 3 Ⅱ層分析 / 4 Ⅲ層分析
- 5 抽出された思考パターン（仮説）
- 6 評価（cem-qa ルーブリック流用、5 軸 0〜3 点）
- 7 受験準備への含意（運営者ノート）

**原文転載禁止**。要約 + 構造化のみ。連続 50 字以上の原文一致なしを verify チェック項目化。

### 4.2 パターン抽出マトリクス（8 年横断）

- `essay-analysis/_matrix.md` — 人間用、md 表
- `essay-analysis/_matrix.json` — 機械用（後の `/exam-keyword-cycle` `/verify-exam-coverage` 連携で使用）

両者は同一スキーマ（パターン単位の flat な行）。スキーマ定義は [essay-analysis/README.md](./essay-analysis/README.md) §スキーマ参照。

### 4.3 抽出された型

- `essay-analysis/_patterns.md` — `pattern_tags` のうち **2 年以上で観測** されたものを「型」として昇格、再現条件を記述

### 4.4 運営者ノート

- `essay-analysis/_owner-prep-notes.md` — 抽出された型を「自分が R08 でどう使うか」視点で再言語化

## 5. 作業ステップ

### Step 1: 年度別三層分析シート作成（8 年分、3×3 反復）

各イテレーション後にテンプレートと `pattern_tags` 語彙を見直し、次イテレーションに反映。

| イテレーション | 年度 | ねらい |
|---|---|---|
| 1 | R07 → R06 → R05 | 直近の出題傾向の現在値。テンプレ実用性検証 |
| 2 | R04 → R02 → R01 | 中期、DX/リスク系 |
| 3 | H30 → H29 → H28 | H28 以降の変曲点を確定 |

1 年あたりの作業時間目安: 1〜2 時間。

### Step 2: パターン抽出マトリクス作成

8 年分の `{year}.md` から `_matrix.md` / `_matrix.json` を生成。`pattern_tags` を名寄せし、出現年度数を集計。**2 年以上で観測されたタグを `_patterns.md` に「型」として昇格**。

### Step 3: 運営者の受験準備ノート言語化

抽出された型を「自分が R08 でどう使うか」視点で `_owner-prep-notes.md` に再言語化。

各 step の詳細な verify 条件は [essay-analysis/README.md](./essay-analysis/README.md) §verify 条件 参照。

## 10. 想定リスクと未解決事項

| リスク / 論点 | 対処 |
|---|---|
| 8 年×複数パターン年度の表現 | マトリクスは「年度行」ではなく「パターン行」で正規化 |
| 1 セッションで全 8 年は工数超過 | 3×3 反復で実施。各イテレーション後にテンプレ改訂を許容 |
| 思考パターンと特殊解の区別が主観的 | 「2 年以上観測 = 型に昇格」のルールで機械判定 |
| 著作権配慮 | 連続 50 字以上の原文一致なし、を verify チェック項目化。出典は元 MDX から引き継ぐ |
| 複数選択科目の重み付け | 全パターンを行展開し `pattern_tags` で名寄せ。1 年で複数科目に同型が出るほど信頼性が高い扱い |
| R03 除外で 1 年分のデータ欠損 | 受け入れ。型抽出は 8 年で十分（2 年以上観測ルール）|
| 後続スキル連携 | `_matrix.json` のスキーマを Step 2 で確定させ、`/exam-keyword-cycle` `/verify-exam-coverage` の入力として使えることを保証 |
