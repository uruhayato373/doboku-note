## ビジョン

土木・建設系の実務資格試験対策ハブとして、技術ノートとアプリで受験者と技術者の学習を支援する。現在は「1級土木施工管理技士」と「技術士（総合技術監理部門）」を Phase 1 として整備中、将来的に技術士（建設部門）・コンクリート主任技師・コンクリート診断士・行政書士（建設業許可等の法務系）へ段階的に拡張する。

**v3 の軸（2026-04-13策定）**: 運営者本人が技術士総監 2 次筆記試験に合格済み。合格体験（学習ログ・解答再現・論文全文）を中核差別化に据え、情報整理屋中心の競合に対する決定的優位を形成する。

## 事業構造

**判断基準: Claude Code で自動化できる割合が高い事業に集中する。+ 合格体験者ポジションを活かせる事業に重点投資する。**

| 事業 | 役割 | 収益モデル | 優先度 |
|---|---|---|---|
| **doboku-note**（Webサイト） | SEO集客の入口。信頼構築の場 | AdSense + アフィリエイト + note有料記事 | **Q2即整備** |
| **note 合格体験シリーズ** | 一次情報による高単価note商品 | 単品 ¥1,480〜¥2,980 + マガジンパック | **Q3 試験後投入（v3で新設）** |
| **YouTube チャンネル** | TTS 量産×サイト送客（v4：自動化） | 広告収益＋動線 | **Q2 基盤整備 → Q3 量産開始（v4で転換）** |
| **iOSアプリ** | スキマ時間の過去問演習 | 広告 + サブスク（¥600/月） | **Q4 着手判断**（条件: Web収益 ≥¥15k + **筆記合格必須**） |

4事業は相互送客で成長を加速する:

- doboku-note → YouTube: 「動画解説はこちら」のCTA
- YouTube → doboku-note: 概要欄から記事リンクで送客
- doboku-note/YouTube → note 合格体験シリーズ: 熱量の高い受験者に高単価商品を販売
- doboku-note/note → iOSアプリ: 「過去問演習はアプリで」と誘導
- iOSアプリ → doboku-note: 「詳しい解説はサイトで」→ サイトPV増・E-E-A-T向上

### 捨てたもの

| 捨てたもの | 理由 |
|---|---|
| 書籍（KDP） | 校正・構成・プロモーションに人間の判断が大きく、自動化困難 |
| Udemy講座 | 動画編集が必須。YouTube で代替可能 |
| 受験記型YouTube（v4で廃止） | TTS 量産に再転換（v4）。自動化優先・受験記コンテンツは note E シリーズに集約 |

## 競合環境（2026-04-13 時点）

### 1級土木施工管理技士の市場

**3層の競合構造**が存在する:

| 層 | 競合 | SEO上の脅威 |
|---|---|---|
| **無料過去問サイト** | 過去問ドットコム、施工管理ドットコム、どぼくじら、ちゃんさと、施工管理求人.com | 中 |
| **大手資格スクール** | CIC、アガルート、日建学院、TAC、総合資格学院 | **高（情報系キーワードで上位独占）** |
| **有料講座・添削** | 施工管理合格ネット、独学サポート事務局 | 低 |

**最重要な発見**: 大手スクールが「試験日程」「勉強法」「合格率」「受験資格」等の情報系キーワードを独占。ドメインパワーの差が大きく、正面から勝つのは困難。

### 技術士（総合技術監理部門）の市場

**無料Webコンテンツが圧倒的に不足**しているブルーオーシャン:

| 層 | 競合 | 状況 |
|---|---|---|
| **無料Web** | pejp.net（25年分過去問）、技術士道（総監特化、kope.info）、鹿夫（certlabo.com）、過去問ドットコム | いずれも部分的。キーワード集の体系的Web解説は**市場に存在しない** |
| **有料講座** | ガチンコ技術士学園（59,400円）、スタディング、アガルート、新技術開発センター等8社 | 有料が主戦場 |
| **既存YouTube** | 技術士Lock-On、技術士合格セオリー 等 | 顔出し長尺講義中心。登録1万人超の技術士専業チャンネルは日本に存在しない |

**v3 での重要な発見**: 総監受験記を**一次情報**で発信している現役受験者・合格者のブログ・YouTube はほぼ存在しない。運営者本人が合格者として発信することで、この空白を埋められる。

### 両試験の横断 + 合格者本人: 競合ゼロ

1級土木＋技術士総監を同一サイトで横断学習できるサービスは存在せず、**さらに運営者自身が合格者**という構造は完全に独自。

## 成長戦略：3つのループ × ロングテールSEO

### SEO戦略の基本方針

| 方針 | 理由 |
|---|---|
| **情報系キーワードを避ける** | 「試験日程」「勉強法」「合格率」は大手スクールの独壇場 |
| **ロングテールに集中する** | 「令和7年 土木一般 問3 解説」「技術士 総監 フォロワーシップ」等 |
| **技術士総監を優先公開する** | 競合が弱いブルーオーシャン |
| **★受験体験ベースのE-E-A-T強化** | 運営者の受験記事で「経験」軸を圧倒的に強化 |
| **構造化データで強化する** | Quiz/FAQ schema で検索結果の表示面積を拡大 |

### 1. 技術リファレンス SEO ループ（★★★★★）

**仕組み**: 体系的な技術ノートを公開 → 技術者が業務中に検索 → ブックマーク・社内共有 → 被リンク増加 → ドメイン権威向上 → 新規ページも上位表示しやすくなる

| 基準 | 評価 |
|---|---|
| 適合度 | 5/5 |
| 現在の成熟度 | 3/5（約733ファイル） |
| 実装コスト | S（公開済み。SEO最適化で加速） |
| 成長速度 | 中期（3-6ヶ月） |
| 複利効果 | 高 |

### 2. 資格試験 SEO ループ（★★★★☆）

**仕組み**: 試験対策コンテンツ公開 → 受験者が試験前に検索 → 学習・ブックマーク → 合格後に後輩・同僚に共有 → 翌年の受験者がさらに検索

| 基準 | 評価 |
|---|---|
| 適合度 | 4/5 |
| 現在の成熟度 | 2/5 |
| 実装コスト | M |
| 成長速度 | 中期（季節性あり） |

**季節性**:
- 4月: 1級土木申込締切
- 6月: 2級土木第一次試験
- 7月5日: 1級土木第一次試験
- **7月中旬: 技術士二次試験 ← 運営者本人が受験**
- 10月: 1級土木第二次試験
- **10月末: 技術士 筆記合格発表 ← iOS 着手シグナル**
- 11月: 技術士一次試験 / RCCM
- **2027年3月: 技術士 最終合格発表 ← サイト全面ブランディング更新**

### ★ 3. 合格体験ループ（★★★★★・v3で新設）

**仕組み**: 運営者が試験を受ける → 学習過程・解答再現・論文構成を note/YouTube で公開 → 次年度受験者の購買動機になる → リピート販売（合格体験商品は年サイクルで継続販売可能）

| 基準 | 評価 |
|---|---|
| 適合度 | 5/5（他人が絶対に書けない独占コンテンツ） |
| 現在の成熟度 | コンテンツ未公開段階（Q3 試験後に起動） |
| 実装コスト | S（試験勉強と自然に重なる） |
| 成長速度 | 速（試験直後の熱量で一気に立ち上がる） |
| 複利効果 | 極大（合格後の権威性でサイト全体のE-E-A-Tが上がる） |

### ループ間の相乗効果

- ループ1（技術リファレンス）→ トラフィックがSEOデータを生む
- ループ2（資格試験）→ 受験者流入が note 有料記事の見込み客になる
- **★ループ3（合格体験）→ ループ1/2 に「受験合格者による」という権威性を注入**

全ループが互いを強化するフライホイール構造。起点はループ1（SEO流入）→ ループ3（合格体験）で一気に跳ね上がる設計。

## Pre-Mortem（失敗シナリオと対策）— v3 反映版

| シナリオ | 対策 |
|---|---|
| 試験勉強でサイト更新が止まる | Q2 は「学習の副産物として積み上げる」方針を徹底。完璧を捨てる |
| 筆記試験不合格 | 「挑戦記・不合格体験記」として note 有料化可能。合格前提の戦略を組まない |
| 試験後に note/YouTube 立ち上げの熱量を失う | 試験翌週に E-1 販売・初動画投稿を強制的にスケジュール化 |
| 計画を立てるだけで実装が進まない | 「Sコスト」タスクは当日中に完了。週次レビューで検出 |
| 情報系キーワードに時間を使ってしまう | ロングテール＋合格体験に集中 |
| ドメインパワー不足でロングテールも順位が上がらない | インデックス蓄積で3-6ヶ月で改善見込み |
| 大手スクールが総監SEOに本腰 | 「無料×体系的×**合格者本人**」の組み合わせは大手が真似しにくい |
| noteが売れない | 2週間で5部未満 → N-1 は縮小、合格体験シリーズ（Q3）に賭ける |
| YouTube の初期伸び悩み | 直接収益を前提にしない。note 送客経路として割り切る |
| 4事業並行でリソース分散 | Q2 は実質3チャネル（AdSense+アフィリエイト+note）。YouTube/iOS はQ3/Q4から段階投入 |
