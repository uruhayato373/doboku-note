## なぜ Kindle か

| 課題 | KDP による解決 |
|---|---|
| サイト集客ゼロでも売れない | Amazon の検索市場・Kindle Unlimited が買い手を連れてくる |
| 生の年度別過去問は差別化にならない | 「論点別再構成＋論点まとめ」で編集物として価値を上乗せ |
| note は SNS ファネルが育つまで集客弱い | KDP を先行させ、note は SNS 育成後の従チャネルに |

**KDP の優位点**: ISBN 不要・即日出版・改訂無制限・Kindle Unlimited 経由で受験期に大量読了が発生しやすい。

## KDP アカウント設定（初回のみ）

### 1. アカウント登録

1. [kdp.amazon.co.jp](https://kdp.amazon.co.jp) にアクセス
2. 既存の Amazon アカウントでサインイン（新規作成でも可）
3. 著者名・住所・電話番号を登録

### 2. 税務情報（必須・後でやると支払い止まる）

1. KDP ダッシュボード → 「アカウント」→「税務情報」
2. **マイナンバー（個人番号）**を入力
3. **W-8BEN フォーム**を提出（日米租税条約で米国源泉税を 0% に）
   - 「個人」→「日本在住」→「条約国の恩恵を受ける」を選択
   - これをやらないと米国販売分から **30% 源泉徴収**される

> [!warning] W-8BEN の有効期限
> W-8BEN は提出から **3年間**有効。有効期限が切れると自動的に 30% 源泉徴収に戻るので、KDP から届くリマインドメールを見落とさない。

### 3. 銀行口座登録

1. 「アカウント」→「受取情報」→「銀行口座を追加」
2. 日本の銀行口座（口座番号・支店コード・SWIFT コード）を入力
3. 最低支払額: **¥1,500**（電子書籍）。翌月末に自動振込。

### 4. 著者ページ（Author Central）

- [authorcentral.amazon.co.jp](https://authorcentral.amazon.co.jp) で著者プロフィールを作成
- 著者名「架（かける）」でページを作成し、全作品を紐付け
- プロフィール文に「元・地方自治体土木職（発注者）」「技術士総合技術監理部門合格」を明記して差別化

### Kindle Unlimited（KDP Select）

- **KDP Select に登録を推奨**（90日独占・Amazon 以外では販売不可）
- KU 読了 1ページあたり約 ¥0.5〜¥0.6 の KENP レート
- 安全管理（160問・推定450ページ相当）1読了 ≈ ¥200〜¥270
- 試験シーズン（6〜7月）に月50回読了なら ¥10,000〜¥13,500/冊

> [!note] KDP Select の制約
> 90日間は Amazon 独占（note PDF 販売と競合しないので実質問題なし）。90日ごとに自動更新されるため、note PDF 販売を始める場合は更新前に Select を外す。

> [!warning] KDP コンテンツポリシーのリスク（要確認・断定しない）
> KDP には「web 上で無料公開されているコンテンツ」の出版を制限するコンテンツガイドラインがあり、当サイトの過去問解説ページ（無料公開）との関係で**審査リジェクトの可能性はゼロではない**（外部仕様のため要確認。初回出版時の審査結果で実態を確かめる）。緩和策 = ①A系は論点別再構成＋論点まとめという**サイトに存在しない編集物**にする ②D系は**書き下ろし前付け（はじめに・出題傾向分析・学習ガイド）を必ず内蔵**する ③出典クレジット・免責を内蔵する。KDP Select（独占）加入の最終判断は出版直前にユーザーが行う。

## 制作パイプライン（2026-07-08 整備）

構成設計（Generator）・ビルド（決定的スクリプト）・評価（Evaluator）の分業。エージェント詳細は [agents-registry.md](../../reference/agents-registry.md)。

```
/kindle-build {書籍ID}
 ├─ 構成定義あり → 決定的ビルド（LLM不使用）
 │    A系: build-takuitsu-reconstruct.mjs --theme {key}
 │    D系: build-pe1-kindle.mjs --spec scripts/kindle-specs/{id}.json
 ├─ 構成定義なし → kindle-book-composer（Generator）
 │    A系: THEMES 論点分類設計（件数を本書と突合） / D系: spec + 書き下ろし前付け
 └─ ビルド後 → epubcheck → kindle-book-qa（Evaluator）5軸監査
      ①原稿完全性 ②構成整合 ③EPUB技術 ④KDP規約適合 ⑤商品性 → FAIL は修正して再ビルド（最大2周）
```

機械検証 = `epubcheck`（brew 導入済み・EPUB 3.3 ルール）。Kindle Previewer 3 の目視（目次・改ページ・数式）は GUI のためユーザー作業。

## 既知の課題・留意点

- **論点分類の混入（2026-07-08 構造是正済み）**: 旧実装は body 全体の部分文字列マッチで他分野の設問を大量に拾っていた（A-01 で48問）。**見出し文（lead）判定＋exclude regex** に是正。以降のテーマも同方式で設計する。
- **元データの尻切れ解説（2026-07-08 JSON 側は全量補完）**: `civil-1-exam-questions.json` の派生元サイト MDX（`primary-{年度}-{a,b}`）に「…」で切れた条文引用・「正答」のみのプレースホルダ等が散在していた。A シリーズ収録範囲（6テーマ＋合本）を機械スイープで全量検出（約200件）し、**e-gov 等での条文照合つきで JSON 側を全件補完済み**（2026-07-08、複数バッチ）。ただし**パーサー（`.claude/scripts/sns/parse-civil-1-questions.mjs`）再実行で上書きされる**ため、恒久対応はサイト MDX 側の修正が必要（別タスク）。**A-01 出版版にはこの破損が約100件残っているため、補完後 EPUB の再アップロード（コンテンツ更新）を推奨**。
- **図版依存設問は自動除外**: 「下図」等を含む設問は画像なしで除外（安全管理は 4問のみ）。図依存の高い土工・構造系には別途画像同梱の仕組みが必要。
- **著作権クレジット**: 全国建設研修センターの過去問を出典表示で使用（EPUB 内に免責・クレジット内蔵済み）。ユーザーの判断で使用しているため、運用上問題が発生した場合は即座に KDP から取り下げる。
- **epubcheck**: `brew install epubcheck` で導入済み（openjdk 同梱・2026-07-08）。出版前に必ず実施する（A-01 は EPUB 3.3 ルールでエラー0/警告0 を確認済み）。
- **KDP コンテンツポリシー**: 上記「KDP コンテンツポリシーのリスク」参照。初回審査の結果を本書に記録して以降の判断材料にする。
