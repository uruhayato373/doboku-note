# 戦略ドキュメント索引（01_戦略）

このディレクトリは**トピック軸**（プロダクト → 設計思想 → 事業 → 収益化 …）で並ぶ**全資格共通の横断戦略**の置き場です。資格別の実行（価格・リリース・マガジン・メンバーシップ）の真実源は、`docs/note/{資格}/noteコンテンツ計画.md`（2026-06-11 SSOT 再編で移譲済み）。note チャネルの索引は [../../note/README.md](../../note/README.md) を参照。

> [!important] 2 軸の役割分担
> **横断方針 = この `01_戦略/`** ／ **資格別実行 = `docs/note/{資格}/`**。
> 「この戦略はどこ？」に迷ったら、下の「トピック軸インデックス」（何の戦略か）か「資格軸インデックス」（どの資格か）のどちらかから辿る。
