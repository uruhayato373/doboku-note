## 各資格の評価

### Tier 1 最優先: コンクリート技士

詳細: [`docs/project/01_戦略/07_競合調査.md` #コンクリート技士](./07_競合調査.md#コンクリート技士)

**評価の決め手**

1. **競合の構造的な穴**: 大手通信講座が未参入（アガルートでもコラムのみ、専用講座なし）。個人ブログ（Rikisei、kenchik.info）が散在するのみで、Web の網羅的過去問解説に空白がある
2. **既存資産の高い流用率**: 配合・打込み・締固め・養生は 1 級土木と重複度 80%。1 級土木の 30-40 ページを再編集すれば 1 ヶ月で 50 ページの基盤コンテンツが立ち上がる
3. **読者層の自然な接続**: doboku-note の既存読者（1 級土木受験者・技術者）にとってコンクリート技士は次のキャリアステップ。クロスセルが効く
4. **市場規模**: 年 8,500 人 × 受験料 11,000 円 = 9,400 万円の試験手数料市場、対策市場全体は 2-3 億円

**展開時のリスク**

- JIS 規格・骨材試験の細目は新規執筆が必要（流用できない 45-50%）

### Tier 1 最優先: コンクリート主任技士

詳細: [`docs/project/01_戦略/07_競合調査.md` #コンクリート主任技士](./07_競合調査.md#コンクリート主任技士)

**評価の決め手**

1. **増分コスト最小の理想的拡張**: 技士コンテンツの 60-70% + 技術士総監の記述式論述ノウハウ転用で、技士と並行整備すれば追加執筆は 15-20 ページで済む
2. **競合 2 強寡占で個人運営向き**: 行ってクラブログ・koneka1130 の 2 サイトが寡占、大手通信講座（SAT・アガルート）は未参入。記述式対策は平岩陸書籍がデファクトで Web の網羅的解説に空白
3. **5 資格横断ポジション**: 1 級土木 + 総監 + コンクリート 3（技士 / 主任技士 / 診断士）の横断構造は他競合追従不可
4. **市場規模**: 年 2,900 人 × 受験料 14,300 円 = 約 4,150 万円の試験手数料収入、対策市場 1.2-1.5 億円
5. **試験形式変更（2020 年〜）への対応**: 「小論文 1,000 字 × 1 題」体系への現行対応がまだ薄く先行余地あり

**展開時のリスク**

- 記述式 6 年分の模範解答整備は手間（ただし総監で培ったノウハウで効率化可能）
- 受験者数が技士の 1/3 で、AdSense 単独では収益化困難 → note 有料記事（¥1,500 × 5-6 本）が必須

**技士との並行整備の理由**: 技士受験者の多くが主任技士を意識しており、両試験の違い・段差を丁寧に解説したサイトが少ない。同時整備により「コンクリート資格の総合学習ハブ」ポジションを最短で確立できる。

### Tier 2 中期: コンクリート診断士

詳細: [`docs/project/01_戦略/07_競合調査.md` #コンクリート診断士](./07_競合調査.md#コンクリート診断士)

**評価の決め手**

1. **高単価市場**: 受検者数は年 3,030 人と少ないが、1 人当たり受験料 + 講習会 + 書籍で **10 万円超の LTV**。周辺市場規模 3 億円
2. **競合の空白**: 大手スクール（SAT・アガルート）が未参入で、個人運営者の介入余地が大きい。日経 BP・ブレインセンター・秀和書籍・個人ブログに分散
3. **追い風**: 国土交通省の橋梁点検義務化（2023 年〜）と老朽化インフラ予防保全政策で需要が構造的に伸びている
4. **運営者の権威性**: 運営者ペルソナに「コンクリート診断士」が含まれており、保有資格による信頼性で参入可能（運営者の保有資格はメモリ `project_operator_pe_comprehensive_pass` 参照）

**展開時のリスク**

- 記述式（論述）の模範解答整備は手間がかかる（総監で培った論述ノウハウは流用可能）
- 受験前に講習会受講が必須のため、講習会連動コンテンツ（直前対策）の差別化が問われる

**展開順序の提案**: コンクリート技士 + 主任技士（並行整備）→ 診断士 の 2 段階。主任技士保有者は診断士試験で基礎試験免除になり、主任技士の記述式実績で読者の信頼を獲得してから診断士へ自然送客できる。

### Tier 2 中期: 2 級土木施工管理技士

詳細: [`docs/project/01_戦略/07_競合調査.md` #2級土木施工管理技士](./07_競合調査.md#2級土木施工管理技士)

**評価の決め手**

1. **市場規模**: 年間延べ 46,007 人で 1 級と同等オーダー、市場規模 2.76 億円
2. **2 級 → 1 級 → 技術士の一気通貫キャリアパス**: 競合各社が単一資格特化のため、doboku-note の **多資格横断構造** が唯一無二の差別化軸
3. **令和 6 年制度改正後の穴**: 受験資格緩和・経験記述設問 2 題化・字数削減への対応が競合各社で連載中・未完結。先行参入の余地あり
4. **既存資産流用率 60%**: 1 級土木の教科書系コンテンツがそのまま流用可能

**展開時のリスク**

- 大手スクール（SAT・アガルート）が SEO で強い。情報系キーワードは正面勝負困難
- 過去問解説は 2 級専用の新規作成必須（問題が異なる）
- 読者は若年層・未経験者が中心で、客単価は 1 級より低い（AdSense + 1 級有料導線の二段構えが現実的）

### Tier 3 選択的: 技術士（建設部門）

詳細: [`docs/project/01_戦略/07_競合調査.md` #技術士建設部門](./07_競合調査.md#技術士建設部門)

**評価の決め手**

1. **最大市場**: 技術士の中で受験者最多（二次 14,094 人）、周辺市場込み 25-40 億円
2. **大手寡占の壁**: アガルート・スタディング・ガチンコ・TCI・SAT の 5 社が添削・動画・選択科目全網羅で寡占
3. **市場の空白**: **選択科目別の無料 Web 知識コンテンツ**と **1 級土木との横断学習動線** に空白
4. **添削領域には不参入が妥当**: 個人運営では添削サービスの品質・スケールで大手に勝てない

**展開時のリスク**

- 専門科目 12 すべては非現実的。**上位 3 科目（施工計画・河川砂防・必須Ⅰキーワード集）に絞れば受験者の約 30% にリーチ可能**
- 受験料の値上げ（令和 8 年 1 月から 14,000→20,500 円）で受験者数は微減する可能性
- 添削以外の領域（過去問解説・口頭試験対策・業務経歴票指南）で差別化を狙う

### Tier 4 非推奨: 技術士（情報工学部門）

詳細: [`docs/project/01_戦略/07_競合調査.md` #技術士情報工学部門](./07_競合調査.md#技術士情報工学部門)

**非推奨の根拠**

1. **市場規模の小ささ**: 二次受験者 430 人（建設部門の 1/33、応用情報の 1/500）
2. **読者属性の完全断絶**: 土木受験者と情報工学受験者の重なりはほぼゼロ。既存読者への提供価値が生まれない
3. **権威性の不在**: 運営者ペルソナ（自治体土木職退職者 + 土木系 6 資格）で情報工学の権威性を担保できず、ブランド毀損リスク
4. **IT 業界の標準は IPA 系**: 応用情報・高度試験が事実上の標準で、技術士情報工学への動機が構造的に弱い
5. **既存資産の流用可能性ゼロ**: 1 級土木・総監 649 トピックの流用が極めて低く、新規執筆コストが正当化されない

**代替提案**: 情報工学部門には参入せず、総監コンテンツ内の「情報管理」セクションを CIM/BIM・i-Construction・DX 文脈で深化させる方が、既存ドメインの強化として整合性が高い。

## 集中戦略との整合

### 2026 の集中先（実勢）

2026 は既存資格に集中する方針。ただし当初想定の「総監＋1 級土木の 2 軸」は実勢とずれ、**建設部門 2 次を note 商品として前倒し稼働**（実証済み成長株）、**2 級土木は Phase 0 前倒し着手済み**。本戦略の Tier 1（コンクリ系）にはこの期間は **着手しない**。

理由:
- 建設部門 2 次が最高転換率で伸びており、リソースはまず実証済みの深掘りに配分するのが合理的
- コンクリ系は WTP 未実証（流入 98・売上 0）で、先行投資の実売シグナルが無い
- 既存資格の SEO 浸透が進行中で、追加領域への注力は機会損失

### 着手判定の前提条件（2026-07 時点の状態を併記）

Tier 1（コンクリート技士）の着手前に以下を確認する:

1. ~~**Web 月間収益 ≥ ¥15,000 達成**~~ — **達成済み**（2026-06 実績 ¥217,760）。ただし達成はコンクリ前倒しの十分条件ではない（WTP 未実証のため）
2. **技術士総監 最終合格発表（2027 年 3 月）** — 「合格者ポジション」確立後の方が新規領域でも信頼を勝ち取りやすい
3. **既存資格（建設部門・土木）のマネタイズが安定** — 特に 1 級土木の未収益化ギャップ（[11_STP分析2026-07.md](./11_STP分析2026-07.md)）を先に埋める
4. **コンクリ系の実売シグナル** — 下書き公開後に流入・WTP を実測してから拡張判断（憶測で前倒ししない）

## 2027 Q1 以降の展開ロードマップ案

実際の着手タイミングは Web 月間収益・既存資産の浸透度を見て判断する。以下は条件達成後の標準シナリオ。

### Phase A（2027 Q1-Q2）: コンクリート技士 + 主任技士 並行立上げ

| 期間 | 内容 | 目標 |
|---|---|---|
| Q1 前半 | 1 級土木のコンクリート関連 30-40 ページを再編集 + 技士独自の JIS 規格・配合計算ページ 10-15 本を新規執筆 | 技士 50 ページ立上げ |
| Q1 後半 | 主任技士独自論点 15-20 ページ + 総監記述ノウハウを転用した記述式テンプレ 3 テーマ | 主任技士 20 ページ立上げ |
| Q2 前半 | 過去問解説（技士直近 5 年 + 主任技士直近 6 年の択一部分） | 過去問 15 セット |
| Q2 後半 | SEO 浸透 + note 有料記事テスト販売（主任技士記述式模範解答 ¥1,500 × 5-6 本） | 月間 PV 5,000、note 5 部販売 |

技士と主任技士を **同時整備** する理由: 受験者層が重なり（技士受験者の多くが主任技士を意識）、両試験の違いを丁寧に解説したサイトが市場に存在しない。先行者の優位を最短で確保できる。

### Phase B（2027 Q2-Q3）: コンクリート診断士 + 2 級土木

選択肢:
- **B1 案: 診断士先行** — 単価高・運営者保有資格・橋梁点検需要追い風。主任技士で記述式の信頼を獲得済みなら自然送客
- **B2 案: 2 級土木先行** — 市場大・既存資産流用率高い・若年層 AdSense と相性良

判断基準: Phase A の note 有料記事販売実績を見て、**有料商品が売れる読者層が育っているなら診断士先行、AdSense トラフィック獲得が優先なら 2 級先行**。

### Phase C（2027 Q4 以降）: 技術士建設部門の上位 3 科目

技術士総監で論述ノウハウが確立されており、建設部門特有の論点だけ追加すれば参入可能。**専門科目を絞る**（施工計画 + 河川砂防 + 必須Ⅰキーワード集）戦略で参入難易度を下げる。

### Phase D（2028 以降）: 評価し再判断

- 行政書士（建設業許可等の法務系、[`03_事業戦略.md`](./03_事業戦略.md) v3 のビジョンに記載）
- ~~RCCM~~（**不採用確定**: 受験者=建設コンサルタント専業、元公務員ブランドが差別化にならない。2026-06-09）
- 測量士・測量士補（年 13,363 + 3,717 人、土木隣接領域）

| リスク | 影響 | 緩和策 |

| **リソース分散** | 既存 2 軸（総監 + 1 級土木）の品質低下 | Phase A は **1 ヶ月で 50 ページ集中投入**、その後 SEO 浸透待ち。並行で 2 資格以上は着手しない |
| **大手スクールの参入** | コンクリート技士市場に大手が後発で入る可能性 | 1 級土木との横断構造を早期確立し、模倣困難な差別化を作る |
| **コンクリート技士市場の停滞** | 受験者数 8,500 で頭打ちの可能性 | 診断士・主任技士の上位資格への送客で LTV を引き上げる |
| **運営者リソースの枯渇** | 5 資格運営は個人運営者には過負荷 | Claude Code による自動化を前提とし、6 資格 = サイト + iOS + YouTube + note の事業全体で 1 日 4 時間以下の運営工数に収める |

### 中リスク要因

| リスク | 影響 | 緩和策 |
|---|---|---|
| 受験料値上げ（技術士建設） | 受験者の微減 | Tier 3 のため緊急度低い |
| AI 検索（SGE）による無料コンテンツ流入減 | SEO 戦略全体の見直し必要 | iOS アプリ・note 有料記事の比率拡大で対応 |
