## Q1: 顧客は誰か？どんな洞察があるか？

### 対象セグメント

| セグメント | 規模 | 支払い意思 | 優先度 |
|---|---|---|---|
| **技術士（総合技術監理部門）受験者** | 年間約 3,000〜4,000 人（2 次筆記） | 極高（上位資格・キャリア投資） | Phase 1 主力 |
| **1 級土木施工管理技士受験者** | 年間約 51,000 人（1 次） | 中〜高（合格への投資） | Phase 1 主力 |

### 5 つの洞察

1. **「体験者の一次情報」を強く求めている** — 情報整理記事より合格者本人の論文・勉強記録・解答再現が圧倒的に信頼される。総監受験者に特に顕著
2. **体系的リファレンスが存在しないブルーオーシャン** — 総監キーワード集の体系的 Web 解説は市場に存在しない（2026-04-05 競合調査時点）
3. **受験前後でニーズが変わる** — 受験前は「網羅性・正確性」を求め、試験直後〜合格発表前は「解答再現・他者との比較」、合格後は「後輩への推薦」に変わる
4. **建設業の業務特性でスキマ時間学習ニーズが高い** — 現場監理職は長時間労働かつ移動が多い。スマホ + 短時間コンテンツの需要が大きい
5. **合格後に口コミで波及する** — 受験者コミュニティは SNS よりも社内推薦・勉強会経由で広がる。一人の合格者が複数の後輩を誘導するパターンが多い

## Q2: 顧客の主要な問題は何か？

| # | 問題 | 根拠・データ |
|---|---|---|
| 1 | **「ここだけで合格できる」ワンストップ学習リソースがない** | 技術士総監の無料 Web コンテンツは部分的（pejp.net・kope.info 等）。通し学習できる無料サービスは不在（競合調査 2026-04-05） |
| 2 | **合格体験者による一次情報コンテンツがほぼ存在しない** | 総監受験記を一次情報で発信しているブログ・YouTube はほぼ存在しない。情報整理屋中心のコンテンツが大半（03_事業戦略.md §競合環境） |
| 3 | **知識の断片化 — キーワード・過去問・論文構成が繋がっていない** | 現行サービスは過去問演習または解説記事のどちらか一方。キーワード理解 → 過去問演習 → 論文への実践という学習経路が成立しない |

## Q3: 解決策は何か？なぜこの方法が正しいか？

### 解決策

**「体系リファレンス × 合格体験者ポジション」のハイブリッド**

- **体系リファレンス（Web）**: 技術士総監 677 ファイル + 1 級土木 56 ファイルの体系的 MDX コンテンツ。キーワード → 過去問 → 論文の学習経路を 1 ドメインで完結させる
- **合格体験者ポジション（note・YouTube）**: 運営者本人の受験記・解答再現・論文全文を「他人が絶対に書けない一次情報」として展開。E-E-A-T（経験・専門性・権威性・信頼性）を全軸で担保

### なぜこれが正しいか

| 検証軸 | 判断 |
|---|---|
| 競合が作れるか | **No** — 体系リファレンス（733 ファイル）と合格体験（論文全文）を同一ドメインで持つ競合はゼロ（競合調査） |
| 自動化できるか | **Yes（一部）** — リファレンスは Claude Code で量産可能。SNS 投稿は TTS + 機械生成で人手ゼロ化 |
| 顧客の支払い意思があるか | **Yes** — 受験料 ¥14,000 に対して ¥1,480〜¥2,980 の合格体験シリーズは 10〜21% の相場内。アプリは ¥1,800（隣接競合 TK office ¥1,600 と整合） |
| SEO で勝てるか | **Yes（ロングテール）** — 情報系キーワードは大手スクールの独壇場。技術用語・過去問のロングテールは競合が弱く、総監キーワードはブルーオーシャン |

## Q4: どんな顧客体験を提供するか？一番大事なメリットは何か？

### 4 ステップ学習ジャーニー

```
[検索 → 発見]          [深掘り]              [習得・演習]          [口コミ]
Google 検索             サイト無料コンテンツ    note 有料商品         合格後
キーワード/過去問で       総監 677 ページ         合格体験シリーズ       後輩・同僚に共有
上位表示               1 級土木 56 ページ        E-1〜E-4 (¥1,480〜)   → 次年度受験者が
                       ↓ 過去問演習は           ↓ スキマ時間演習       サイトを検索
                       ↓ アプリで              iOS アプリ（¥1,800）
                       過去問 17 年分
                       680 問 × 5 管理
```

### 最重要メリット

> **受験者が初めて「ここだけで総監を攻略できる」と感じる唯一のサービス**

他のサービスは「情報整理記事のみ」か「過去問演習のみ」か「高額有料講座」のいずれか。doboku-note は無料リファレンス（広さ）＋合格者一次情報（深さ）＋過去問アプリ（定着）を 1 ドメインで提供する唯一の入口となる。

## Q5: どう成功を定義・測定するか？

### NSM（North Star Metric）

> **月間オーガニック検索流入ユーザー数**

オーガニック流入はサービス価値（コンテンツ品質 × SEO）の結果指標であり、note 購買 / iOS DL / 広告収益の全収益チャネルの上流にある。

### 3 層 KPI

| 層 | 指標 | 目標（2026 末） |
|---|---|---|
| **教育成功** | 技術士総監 2 次 合格率貢献（アンケートNPS） | NPS ≥ +40 |
| **NSM（流入）** | 月間オーガニック UU | Phase 1: 10,000 UU |
| **収益** | 月間合計収益 | Phase 2 着手条件: ¥15,000/月 |

### Phase 別成功基準

| Phase | 完了条件 |
|---|---|
| **Phase 1（現在）** | 1 級土木 + 技術士総監の「ここだけで合格」体験が成立 |
| **Phase 2（拡張）** | Web 月収 ¥15,000 達成 + 筆記合格発表（2026-10） |
| **Phase 3（スケール）** | 技術士（建設部門）等の追加 + iOS アプリ収益化 |

### 収益 KPI（四半期別）

| 時期 | 主な収益源 | 目標 |
|---|---|---|
| Q2（〜2026-06） | AdSense + アフィリエイト + note 基礎テスト | ¥5,000〜¥20,000/月 |
| Q3（2026-07〜09） | note 合格体験シリーズ（E-1/E-2） + SNS 送客開始 | ¥20,000〜¥50,000/月 |
| Q4（2026-10〜12） | note E-4（筆記合格後） + iOS 着手判断 | ¥30,000〜¥100,000/月 |
