## 4. 構造的な弱点

1. 専門土木ブロックが丸ごと空白（一次の大出題群なのに0本）。
2. primary の非対称：後期(kouki)5本に ExamPoint あり／前期(zenki)5本に無し。同じ過去問資産で学習体験が不統一。
3. 科目guideの図表不足：管理図・ヒストグラム・ネットワーク図・スランプ等の視覚化がテキストのみ。
4. 二次の完成答案は有料(note)でサイト側は最小限（＝収益設計上の意図。欠落ではなく仕様）。
5. キャリア系9本は厚い＝アフィリ転職導線の柱。拡充対象は学習系で、キャリア系は現状維持。
