# 総監キーワード IT トレンド図版整備計画

## 背景

総監キーワードページのうち IT 系（IoT・生成 AI・クラウド等）は抽象概念が多く、図解の費用対効果が最も高いにもかかわらず**図版がほぼ皆無**。`docs/textbook/図解最新ITトレンド/図解最新ITトレンド.pdf`（NetCommerce「コレ1枚でわかる最新 IT トレンド・改訂第5版」全 204 ページ）の図解構成を**参考（下敷き）**にして、doboku-note のデザイントークンで自前 SVG を量産する。

## 方針（重要）

- PDF の図解を**そのまま転載しない**。`docs/reference/image-policy.md` の禁止ソース「他社書籍・教材のスキャン」に該当し、全スライドに NetCommerce ロゴが入っているため。
- PDF は**論点の参考**として使い、SVG は `create-svg` スキルに従い doboku-note デザイントークンで新規制作する。
- `image-policy.md` L72「写真の参考 SVG 化禁止／翻案権」に留意。**特定スライドのレイアウトを丸写ししない**。技術的事実そのもの（AI の包含関係、クラウドの責任分界等）を自分の構図で描き直す。
- SVG は `.local/r2/posts/pe-comprehensive-management/{slug}/img/figure-{N}.svg`。`<ArticleImage>`（alt のみ・caption なし）で本文に挿入。
- 1 ページ完了ごとに即コミット。本ファイルの進捗表を同時更新する。

## ワークフロー（1 ページあたり）

1. 対象ページの `article.mdx` を Read し、既存本文との重複を避けた「図に任せる範囲」を決める。
2. PDF 該当ページを参考に論点を整理（レイアウトは流用しない）。
3. `create-svg` スキルに従い `figure-{N}.svg` を制作（viewBox ≤ 400px、デザイントークン、フォント ≥ 13px）。
4. SVG 監査: `node .claude/skills/quality/check-mdx/scripts/rules/svg/audit.mjs --file=<svg> --fail-on=HIGH`
5. `<ArticleImage>`（alt のみ）で本文の適切な位置に挿入。
6. `npm run refresh-indexes` → 当該 MDX＋SVG＋本ファイルを `git add` 明示指定 → コミット。
7. 本ファイルの進捗表を更新。

## 検証

- SVG 監査が HIGH 0 件。
- `npm run build` 成功。
- dev サーバーで対象ページを開き、図がダーク／ライト両モードで視認できること。
