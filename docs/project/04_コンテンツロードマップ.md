## note 有料記事：棲み分け原則

| | doboku-note.com（無料） | note.com（有料） |
|---|---|---|
| 役割 | リファレンス・基礎知識・網羅的解説 | 再構成・要点整理・テンプレート・ドリル |
| 読者行動 | 検索で来て調べる | 「合格したい」動機で購入する |
| コンテンツ例 | 共通仕様書の全文解説、施工管理の詳細 | 「1級土木 頻出50選」「技術士 論文テンプレ」 |

**原則: 無料サイトに既にある内容をそのまま有料化しない。無料=素材、有料=加工品。**

## PDF→MDX 変換ワークフロー（試験問題集の記事化）

技術士総監の試験問題（過去問）を PDF から Markdown に変換し、ブログ記事として公開するプロセス。

### ワークフローの流れ

1. **PDF 取得**: 技術士会公式サイトから試験問題 PDF をダウンロード
2. **OCR / テキスト抽出**: PDF → テキスト変換（必要に応じて手動補正）
3. **Markdown 構造化**: テキスト → Markdown 記事（問題 + 選択肢 + 解説）
4. **frontmatter 設定**: メタデータ追加（title, category, tags, published）
5. **記事配置**: `.local/r2/posts/pe-comprehensive-management/r{year}-{type}/article.mdx`
6. **公開化**: `published: false` → `true` に変更してサイトに反映

### frontmatter テンプレート（試験問題）

```yaml
---
title: "技術士二次試験 総合技術監理部門 令和{YY}年度 {形式}"
type: 試験問題
category: 技術士（総合技術監理部門）
tags:
  - 技士（総合技術監理部門）
  - {形式}  # 択一式 or 記述式
  - 令和{YY}年度
created: {YYYY-MM-DD}T00:00:00.000Z
source_pdf: "{公式URL}"
published: true  # ← 公開化時に true に
---
```

### ツール・リソース

| 役割 | ツール | 用途 |
|---|---|---|
| **PDF読み込み** | Claude API / vision | PDF ページを画像化して OCR |
| **テキスト構造化** | General-purpose Agent | Markdown 形式への変換 |
| **品質検証** | Content-QA Agent | 問題/選択肢/解説の整合性確認 |
| **記事配置** | Manual | `.local/r2/posts/` へのコピー |

## 収益ファネル（複数チャネル並行）

doboku-note.com 無料コンテンツ（SEO検索流入）
  ↓ 信頼構築（専門性を証明）
  ├→ 通信講座比較記事 → アフィリエイト成約（¥3,000-10,000/件）
  ├→ 試験対策ページ末尾CTA → note 単品購入 → マガジン購読
  ├→ AdSense 広告表示 → 受動的収益
  └→ 参考書籍セクション → Amazon 購入
  ↓ 合格後に後輩へ口コミ
  ↓ 新規流入

**CTA配置ルール**: 試験対策と直結するページのみに限定。全ページに貼らない。
**チャネル判断**: 4月のデータで通信講座アフィリエイトとnoteの実績を比較し、効果の高い方にリソースを集中する。
