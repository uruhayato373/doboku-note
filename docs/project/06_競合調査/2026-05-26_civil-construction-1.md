### 1.2 制度変更によるインパクト（重要）

**令和6年度（2024）からの受検資格緩和**: 第一次検定の実務経験要件が撤廃され、**19歳以上**であれば学歴・実務経験を問わず受検可能になった。

- 第一次検定 受検者数: 32,931人（R5）→ 51,193人（R6、**+55.4%**）→ 47,715人（R7、R6からは -6.8%）
- 合格率は低下傾向: 49.5% → 44.4% → 43.1%（**過去10年で最低水準**）
- 第二次検定は実務経験要件が残るため、第一次の急増ほどの増加は起きず受検者数は安定的に 24,000-27,000人台で推移

出典: 受検資格制度改正の概要（国土交通省）<https://www.mlit.go.jp/tochi_fudousan_kensetsugyo/const/content/001707687.pdf>

### 1.3 市場規模の概算

**受検手数料**: 第一次 12,000円 / 第二次 12,000円（いずれも非課税、ネット申込手数料 250円別途）

| 第二次 受検料収入 | 24,667 × 12,000 = **約 3.0 億円** |
| **公的試験フィーの一次受験料規模** | **約 8.7 億円/年** |

### 1.4 受検者層の構造変化（2025年の特異点）

- 19歳以上要件化により**大学生・新社会人**の参入が顕在化（情報源: <https://note.com/masa_highway/n/ne05ac74f5c4a>「若年層・女性が牽引する変革の兆し」）
- 「中堅社員の資格」から「若手も挑戦する資格」へ
- 学習教材ニーズが**社内研修＋現場経験前提**から、**ゼロから体系的に学べる無料Web教材**へシフトしている可能性

### 5.2 競合と比べた強み・弱み

**強み**
- **第二次検定の全問 Web 掲載**（R3〜R7、5 年分）: PDF 配布主流の競合に対する明確な差別化。
- **教科書系コンテンツの厚み**（24 本）: 体系的に「ここで学べる」体験。CIC・アガルートの無料コラムと近い厚みを無料で提供。
- **技術士（総監）との横断**: 1 級土木 + 技術士の両対応は市場で唯一。
- **MiniSearch 全文検索 + MDX 構造化**: 競合の PDF 配布より検索体験が圧倒的に強い。

**弱み**
- 第一次の個別問題解説（**問題ごとの「なぜこの選択肢が誤りか」レベル**）は過去問ドットコム・建設データジャーナルに後れを取る。

- iOS 過去問アプリ既存プレイヤー（5,551 問収録）に対し、Phase 2 アプリの差別化軸（テキスト連動 + 横断学習 + 間隔反復）はまだ未着手。

## 7. doboku-note の現状ポジションと次の打ち手

R6→R7 で受検者市場は **49,000人規模で安定** し、**若年層流入による合格率低下**（過去10年で最低の 43.1%）が新トレンド。学習教材ニーズは「実務経験ベース」から「ゼロから体系的に学べる無料 Web 教材」へシフトしており、これは doboku-note の **教科書系 24 本 + 第二次全問 Web 掲載** という資産が刺さるタイミング。一方、直近 2 ヶ月で **建設データジャーナル**・**土木のトリセツ note** が R7 解説で先行参入しており、問題単位ロングテール SEO の競争が激化中。次の打ち手は (1) **R7 第一次・第二次の独自解説を即時拡充**してロングテール巻き返し、(2) **第二次経験記述テンプレートの強化**（最大の SEO 穴）、(3) iOS アプリの差別化軸（テキスト連動・横断学習）の早期プロトタイプ化で、Phase 2 着手前にコンテンツ資産で先行優位を確保する。
