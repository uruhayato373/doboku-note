## 進捗トラッキング

5 本（安全・経済性・人的資源・情報・社会環境）の執筆進捗と目標日付は Umbrella Issue で追跡（`.claude/reference/docs-issue-separation.md`）。着手時に Issue を切り、本 md 冒頭に「追跡 Issue: #N」を記す。

**全体目標**: 2026-05-15 までに 5 本完成。残り半月を過去問 3 題への当てはめ検証、6 月以降は本試験対策に集中。

## テンプレート共通構造

`essay-template-safety` で確立した 5 セクション構成を他 4 管理でも踏襲する。差分は主軸管理の扱いとトレードオフペアのみ。

1. 主軸管理が中心になる出題の型（3 パターン前後、過去問への言及を含む）
2. 5 枚構成の骨子テンプレート（600 字×5 枚、章ごとの定型フレーズを `<WritingTip>` で提示）
3. トレードオフ展開の標準パターン（主軸管理×他管理 2〜3 ペア）
4. 過去問への当てはめ例（1〜2 題）
5. 学習フェーズでの運用フロー（`<Callout type="note">`）

## Red Line

[19_note-content-runway-2026.md](./19_note-content-runway-2026.md) の Red Line に準拠する。特に本テンプレシリーズでは以下を徹底する。

- **「模範解答」は作らない** — 骨子と定型フレーズのみに留め、設問ごとの「正解」を書かない
- **定型フレーズは汎用表現のみ** — 特定の業務事例や実名を含めない（運営者の業務経歴は本人の練習ノートに留め、公開テンプレには載せない）
- **合格発表まで本テンプレの有料販売は行わない** — サイト公開は可（P-04 は合格後に販売開始）
