# 総監キーワード2026 集客強化戦略

**作成日**: 2026-04-16
**対象**: 技術士総合技術監理部門（pe-comprehensive-management）キーワードページ群
**現状**: クエリ「総合技術監理 キーワード集 2026」「総監キーワード2026」で平均掲載順位 **7位**
**目的**: 平均7位 → トップ3圏内（CTR 3〜5倍）への押し上げと、流入後のCVR最大化

## 背景

- pe-comprehensive-management 配下に **649 キーワードページ** を整備済み（Phase G-2〜G-4 で品質改善完了、thin content ゼロ化達成）
- **すでに `keyword-2026/article.mdx`（1528行）というハブページが存在**し、5管理体系で 649 キーワードのうち 653 件への内部リンクを網羅。クエリ「総合技術監理 キーワード集 2026」と完全一致しており、平均7位を取っている主因はこのページと推定
- 関連ハブとして `exam-index/article.mdx`（試験ガイド）も存在
- 平均7位は「あと一押しでトップ3」のポジション。トップ10内では1位 vs 7位で CTR が約5倍差
- v3戦略（運営者本人が2026-07に技術士総監2次筆記受験）と連動させ、合格体験者ポジションで差別化

2. **施策1: タイトル全件統一** — スクリプトで一括処理可能

3. **施策2: meta description 全件リライト** — `keyword-rewriter` エージェントでバルク処理
   - ✅ **2026-04-17 完了**: `scripts/bulk-rewrite-descriptions.mjs` を新規作成。既存 description の末尾定型句（「総合技術監理の試験対策〜」等）を削り、5管理分類ラベルと「技術士総合技術監理キーワード集2026（XX管理）。5管理トレードオフ・過去問演習リンク付き。」を付与。`group: keyword` の 649 件すべてを 82〜138 字（avg 96字）にリライト。短すぎる core は title からフォールバック生成。idempotent ガード（2重実行検出）込み。誤って 2回 apply した事故を `scripts/fix-duplicated-description-suffix.mjs` で 606 件一括修復
