## Tweet 01: 定義編

【総監キーワード解説】PM理論 #1

PM 理論 = リーダーシップを2機能で評価する行動理論。
P機能：目標達成に向けた計画・指示・督促
M機能：チームの人間関係・士気を高め維持

三隅二不二（九州大、1966年）が提唱した日本発の理論。

## Tweet 02: 4タイプ編

【総監キーワード解説】PM理論 #2

PM 理論の4タイプ：
PM型（P高M高）：最良
Pm型（P高M低）：成果は出るが人間関係を壊す
pM型（P低M高）：雰囲気良いが成果なし
pm型（P低M低）：最悪

業績・満足度とも PM > pM > Pm > pm の順。

## Tweet 03: SL理論との違い編

【総監キーワード解説】PM理論 #3

PM理論 vs SL理論：
PM理論：高P高M を普遍的に目指す（行動育成）
SL理論：成熟度に応じてスタイルを切り替える（状況適応）

PM理論 = 行動測定・育成 / SL理論 = 状況判断に使う。

## Tweet 04: 試験頻出ポイント編

【総監キーワード解説】PM理論 #4

試験頻出 3 論点：
①Pm型 = 長期的に集団を壊す（短期成果と混同注意）
②M機能の具体例 = 褒める・相談・仲裁・関係調整
③PM理論の限界 = 状況・文化を考慮しない
→ SL理論で補完する関係にある
