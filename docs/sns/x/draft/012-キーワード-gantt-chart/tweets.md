## Tweet 04: PERT/CPM との比較編

【総監キーワード解説】ガントチャート #4

ガント vs PERT/CPM
視認性: ガント=直感的 / PERT=複雑
依存関係: ガント=困難 / PERT=明確
CP識別: ガント=不可 / PERT=可
適用: ガント=小日程 / PERT=中大規模

限界: 依存関係を明示できない。
