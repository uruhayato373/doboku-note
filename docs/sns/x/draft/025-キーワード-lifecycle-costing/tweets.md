## Tweet 01: 定義編

【総監キーワード解説】LCC（ライフサイクルコスト）#1

製品・設備・インフラの取得から廃棄まで全期間のトータルコスト。
LCC = 取得費 + 維持管理費 + 廃棄費。
「安く買って高く維持」のワナを回避する経済性評価の基本。

## Tweet 02: LCCの内訳編

【総監キーワード解説】LCC #2

土木インフラ（橋梁等）の LCC 目安：
建設費 30〜40% / 維持管理費 40〜50% / 解体費 10〜15%

「建設費は LCC の一部に過ぎない」が試験の核心。
維持管理費が最大コストドライバーになる。

## Tweet 03: LCCとLCAの違い編

【総監キーワード解説】LCC #3

LCC vs LCA（混同注意）
LCC = コスト（経済性管理）
LCA = 環境負荷・CO₂（社会環境管理 / ISO 14040）

総監では「経済性と環境性のトレードオフ」として両方セットで問われる。

## Tweet 04: 引っかけポイント編

【総監キーワード解説】LCC #4

試験頻出 3 論点：
①LCC = 建設費のみは誤り（全期間トータル）
②初期安い ≠ LCC 安い（運用・修繕で逆転）
③LCC = コスト / LCA = 環境負荷（別概念）

将来コストを現在価値に割引比較するのが正式手法。
