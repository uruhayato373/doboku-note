## Tweet 02: 4 段階編

【総監キーワード解説】PDCA #2

4 段階の内容
P: Plan — 目標設定・行動計画の策定
D: Do — 計画に基づき実施
C: Check — 実績・課題の評価
A: Act — 標準化・次計画への反映

A は Action ではなく Act！

## Tweet 04: 引っかけポイント編

【総監キーワード解説】PDCA #4

引っかけ 3 つ
1. 段階順序の入れ替え — 正解は P→D→C→A
2. Action と Act の混同 — 正解は Act（改善）
3. OODA との混同 — OODA は別の意思決定ループ
