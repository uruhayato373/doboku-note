## 1. キーワードの核心

**PDCA サイクル** とは、継続的改善を実現するための **循環型マネジメント手法**。Plan（計画）→ Do（実行）→ Check（検証）→ Act（改善）の 4 段階を繰り返す。

**位置づけ**: 技術士総合技術監理キーワード集 2026 の **2.1 事業企画**。あらゆる管理活動の基盤フレームワーク。

**関連キーワードページ**: [https://doboku-note.com/docs/pe-comprehensive-management-pdca-cycle](https://doboku-note.com/docs/pe-comprehensive-management-pdca-cycle)

## 2. 4 段階の内容

| 段階 | 英名 | 内容 |
|---|---|---|
| P | Plan | 目標設定・行動計画の策定 |
| D | Do | 計画に基づき実施 |
| C | Check | 実績・課題の評価 |
| A | Act | 標準化・次計画への反映 |

回し続けるほど業務水準が **螺旋階段状に向上** する。

## 3. 適用範囲

PDCA は ISO マネジメントシステム（品質・環境・労働安全衛生・情報セキュリティ等）の中核をなす。

- ISO 9001（品質）/ ISO 14001（環境）/ ISO 45001（労働安全衛生）/ ISO/IEC 27001（情報セキュリティ）
- 個人の業務改善から組織の経営計画まで適用可能
- 計画立案 → 実行 → 評価 → 改善の循環は科学的アプローチの基盤

## 4. 引っかけポイント（試験で狙われる）

1. **段階の順序**: 正解は **P → D → C → A**。順序の入れ替えは頻出引っかけ。
2. **A は Action ではなく Act**: 改善（Act）が正確。Action（行動）と混同しない。
3. **C と A の混同**: Check は評価のみ、Act は改善・標準化・次計画への反映。
4. **OODA との混同**: OODA（Observe / Orient / Decide / Act）は別の意思決定ループ。PDCA とは異なる。
5. **継続性が本質**: 1 回回して終わりではなく、回し続けることで水準向上。

## 5. 過去問引用

PDCA は ISO マネジメントシステムや継続的改善の文脈で出題される。**ISO14001 EMS** との関連で出題されることが多い。

**典型出題パターン**:

> 環境マネジメントシステム（EMS）における PDCA サイクルについて最も適切な記述はどれか。

選択肢の中で「Action」と「Act」の混同や、段階順序を入れ替えた誤りが頻出。
