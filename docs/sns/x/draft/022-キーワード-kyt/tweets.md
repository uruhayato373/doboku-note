## Tweet 02

【総監キーワード解説】KYT #2

KYT 基礎4R法:

1R：現状把握「どんな危険が潜むか」
2R：本質追求「ここが危険ポイント」（◎で絞り込み）
3R：対策樹立「あなたならどうする」
4R：目標設定「私たちはこうする」（指差し呼称で締め）
