## Tweet 01: 定義編

【総監キーワード解説】5S #1

5S = 整理・整頓・清掃・清潔・躾。
職場の環境改善・品質向上・安全確保の基本活動。

整理：不要物除去 / 整頓：定位置管理 / 清掃：点検しながら清潔化
清潔：3S の状態を維持 / 躾：ルールを習慣化

## Tweet 02: 順序と理由編

【総監キーワード解説】5S #2

5S の順番と理由：
①整理：スペース確保・紛失防止
②整頓：探す時間ゼロ
③清掃：亀裂・油漏れを早期発見
④清潔：①〜③を維持するルール
⑤躾：文化化（最も難しい）

最終目標は「自律的に動く組織文化」。

## Tweet 03: 安全管理との関係編

【総監キーワード解説】5S #3

5S は安全管理の基盤でもある：
整理：転倒・挟まれ防止
整頓：非常口・消火器の定位置
清掃：油・水のスリップ防止
清潔：整備不良の早期発見
躾：安全ルール徹底

KYT と組み合わせ安全文化を形成する。
