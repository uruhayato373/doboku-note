## Tweet 01: 定義編

【総監キーワード解説】5S #1

5S とは「整理・整頓・清掃・清潔・躾」の頭文字。

職場の環境改善・品質向上・安全確保の基本活動。

・整理（Seiri）：不要なものを除去
・整頓（Seiton）：すぐ取り出せる状態に配置
・清掃（Seiso）：きれいにしながら点検する
・清潔（Seiketsu）：3S の状態を維持する
・躾（Shitsuke）：ルールを習慣化させる

## Tweet 02: 順序と理由編

【総監キーワード解説】5S #2

5S を順番どおり実施する理由

① 整理：不要物除去 → スペース確保・紛失防止
② 整頓：定位置管理 → 探す時間ゼロ・効率UP
③ 清掃：清掃しながら設備異常を早期発見（亀裂・油漏れ）
④ 清潔：①〜③の状態を「維持」するルールが必要
⑤ 躾：清潔を習慣・文化にする（最も難しい）

最終目標は「自律的に動く組織文化」。

## Tweet 03: 安全管理との関係編

【総監キーワード解説】5S #3

5S は品質だけでなく「安全管理」の基盤でもある

・整理：不要物による転倒・挟まれ事故を防ぐ
・整頓：非常口・消火器の定位置管理
・清掃：油・水の放置 → スリップ事故防止
・清潔：整備不良設備の早期発見
・躾：安全ルールの徹底

「5S はゼロ災（無事故）の土台」。KYT・ヒヤリハット活動と組み合わせて安全文化を形成する。

## Tweet 04: 引っかけポイント編

【総監キーワード解説】5S #4

試験で狙われる 3 つのポイント

1. 「清潔」≠ 掃除すること
   → 「清潔」= 整理・整頓・清掃の状態を「維持」すること

2. 5S の最終目標は「躾（文化化）」
   → ルールを守らせるのではなく自律的に守れる状態を作る

3. 5S は品質管理だけでなく安全・生産性にも直結
   → 総監では「5管理横断的な改善活動」として位置づける
