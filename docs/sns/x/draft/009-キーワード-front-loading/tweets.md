## Tweet 01: 定義編

【総監キーワード解説】フロントローディング #1

フロントローディング（Front Loading）とは、開発プロセスの初期段階に負荷を集中させ、後工程で発生しうる問題を前倒しで検討・解決する手法。

設計変更や手戻りを早期に発見・対処することで、品質向上・工期短縮・コスト低減を同時に実現する。
