## Tweet 02: 理由（why）

キーワード集は「概念体系順」に並んでいる。出題頻度順ではない。

均等通読すると、17年で1回しか出ない項目も毎年出る項目も同じ時間を使う。

安全管理のPL法（製造物責任法）は過去17年中10年で出題される頻出論点。それを2周目に回す読み方は損だ。
