【総監キーワード解説】ハーズバーグ二要因理論 #1

## Tweet 02: 二要因編

【総監キーワード解説】ハーズバーグ #2

二要因の分類：
動機づけ要因（仕事の内容）
 例: 達成感・承認・責任・成長・昇進
 充足 → 積極的な満足
衛生要因（仕事の環境・条件）
 例: 給与・会社方針・人間関係
 充足 → 不満足の解消止まり

## Tweet 03: マズローとの対応編

【総監キーワード解説】ハーズバーグ #3

マズロー欲求 5 段階との対応：
動機づけ要因: 高次欲求（自己実現・承認欲求）
衛生要因: 低次欲求（社会的・安全・生理的）

衛生要因を整えても不満解消止まり。積極的動機づけにはならない。

## Tweet 04: 職務充実編

【総監キーワード解説】ハーズバーグ #4

積極的動機づけには職務充実（job enrichment）が必要：
権限の委譲・責任範囲の拡大
達成感のある目標設定・成長機会の提供

給与などの衛生要因改善だけでは不満解消止まり。
