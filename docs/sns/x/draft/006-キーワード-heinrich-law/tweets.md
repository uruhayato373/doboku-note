## Tweet 01: 定義編

【総監キーワード解説】ハインリッヒの法則 #1

1件の重大事故の背後に29件の軽微事故・300件のヒヤリハットが存在する経験則（1:29:300の法則）。1929年に安全技師ハインリッヒが約50万件の労働災害から導出。

## Tweet 02: ピラミッド構造編

【総監キーワード解説】ハインリッヒの法則 #2

労働災害ピラミッド。
重大事故1件: 死亡・重傷等
軽微な事故29件: 軽傷を伴う事故
ヒヤリハット300件: 事故未遂・異常体験

重大事故1件の背後に必ず329件の予兆が隠れている。
