## Tweet 01: 定義編

【総監キーワード解説】SL理論 #1

SL理論 = 部下の成熟度に応じてスタイルを変える状況対応型リーダーシップ。Hersey & Blanchard 提唱（1969）。

「最善のスタイルは1つでない」が前提。
部下の発達段階を診断し適切なスタイルを選ぶ。

## Tweet 02: 4スタイル×成熟度編

【総監キーワード解説】SL理論 #2

M1（能力低・意欲高）→ S1 指示型
M2（能力低・意欲低）→ S2 コーチング
M3（能力高・意欲低）→ S3 参加型
M4（能力高・意欲高）→ S4 委任型

成熟度が上がるにつれ指示を減らし自律性を高める。

## Tweet 03: 実践適用編

【総監キーワード解説】SL理論 #3

SL理論の落とし穴：
M1（新入）に委任 → 能力不足で失敗
M4（ベテラン）に細かい指示 → モチベ急落
成熟度は業務ごとに変わる → 新業務では M1 に戻る

「優秀だから放置」が最も危険なエラー。

## Tweet 04: 試験頻出ポイント編

【総監キーワード解説】SL理論 #4

試験頻出 3 論点：
①S4（委任型）は「無関心」でなく「信頼委任」。節目フィードバックは必要
②M2 にはコーチング（タスク高・関係高）が有効
③PM理論（普遍型）vs SL理論（条件適応型）の違いを押さえる
