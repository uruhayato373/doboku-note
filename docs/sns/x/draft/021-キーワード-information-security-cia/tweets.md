## Tweet 01: 定義編

【総監キーワード解説】情報セキュリティ CIA #1

情報セキュリティの3大要素「CIA トライアングル」

▼ Confidentiality（機密性）
  認可された者だけが情報にアクセスできること

▼ Integrity（完全性）
  情報が正確・完全で改ざんされていないこと

▼ Availability（可用性）
  必要なときに情報・システムが利用できること

この3つのバランスが情報管理の基本。

## Tweet 02: 脅威と対策編

【総監キーワード解説】情報セキュリティ CIA #2

CIA それぞれへの脅威と対策

▼ 機密性の脅威：不正アクセス・盗聴
  対策：暗号化・アクセス制御・認証強化

▼ 完全性の脅威：改ざん・データ破損
  対策：デジタル署名・ハッシュ値検証・バージョン管理

▼ 可用性の脅威：DoS攻撃・障害・災害
  対策：冗長化・バックアップ・BCP

## Tweet 03: トレードオフ編

【総監キーワード解説】情報セキュリティ CIA #3

CIA のトレードオフ（総監で最も問われる視点）

機密性↑ = アクセス制限強化 → 可用性↓（使いにくくなる）
可用性↑ = いつでもアクセス可 → 機密性↓（漏えいリスク↑）

「完全なセキュリティ」は存在しない。

リスクベースアプローチで「許容できるリスク水準」を設定し、業務目的に応じて CIA のバランスを最適化することが総監の役割。

## Tweet 04: 引っかけポイント編

【総監キーワード解説】情報セキュリティ CIA #4

試験で狙われる引っかけ 3 つ

1. C は「機密性」であり「暗号化」そのものではない
   （暗号化は機密性を確保する手段のひとつ）

2. 「完全性 = 完璧なシステム」ではない
   →「情報が改ざんされていないこと」が定義

3. 可用性はセキュリティの3要素に含まれる
   →「守ること」だけでなく「使えること」もセキュリティ
