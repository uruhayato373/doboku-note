## Tweet 01

【総監キーワード解説】情報セキュリティCIA #1

情報セキュリティの3大要素:

C（機密性）：認可者のみアクセス可
I（完全性）：改ざんされていないこと
A（可用性）：必要時に利用できること

3つのバランスが情報管理の基本。

## Tweet 02

【総監キーワード解説】情報セキュリティCIA #2

CIA各要素の脅威と対策:

C（機密性）：不正アクセス→暗号化・アクセス制御
I（完全性）：改ざん→デジタル署名・ハッシュ検証
A（可用性）：DoS・障害→冗長化・BCP

## Tweet 03

【総監キーワード解説】情報セキュリティCIA #3

CIAのトレードオフ（総監で頻出）:

機密性↑→可用性↓
可用性↑→機密性↓

完全なセキュリティは存在しない。リスクベースで許容水準を設定し、業務に応じてCIAを最適化するのが総監の役割。

## Tweet 04

【総監キーワード解説】情報セキュリティCIA #4

試験の引っかけ3点:

1. C＝機密性（≠暗号化。暗号化は手段のひとつ）
2. I＝改ざんなし（≠完璧なシステム）
3. A（可用性）もセキュリティの3要素。「使えること」もセキュリティ
