## Tweet 01: 定義編

【総監キーワード解説】冗長性 #1

システム構成要素を多重化し、一部故障でも他が代替してシステム全体の信頼性を維持する設計手法。単一故障による安全機能喪失を防ぐ基盤概念。

## Tweet 02: 3 種類編

【総監キーワード解説】冗長性 #2

冗長化の 3 種類：
待機冗長: 主系故障時に切替（UPS）
並列冗長: 常時並列稼働、一方故障でも維持（二重化センサー）
多数決冗長: 複数出力を多数決で判定（航空機 3 重化）

動作タイミングが異なる！

## Tweet 03: フォールトトレランス編

【総監キーワード解説】冗長性 #3

冗長性はフォールトトレランス（故障許容設計）の主要な実現手段。

冗長性=手段、フォールトトレランス=特性。

冗長化により単一故障でも機能を維持し、安全性と可用性を両立する。
