## Tweet 01: 損益分岐点（変動費率と限界利益率の取り違え）

【総監 択一の罠①】
「変動費率40%」で損益分岐点を出すとき、限界利益率を40%で計算したら不正解。
限界利益率＝1−変動費率＝60%。損益分岐点売上高＝固定費÷0.6。
"変動費率"と"限界利益率"の取り違えが定番の引っかけ。

## Tweet 02: 品質（管理限界と規格値の混同）

【総監 択一の罠②】
管理図の「管理限界線」を製品の「規格値」に合わせて引く——これは✕。
・管理限界＝工程のばらつき(±3σ)で決まる
・規格値＝顧客が決める合否基準
"工程が安定か"と"製品が合格か"は別問題。

## Tweet 03: 安全（リスクゼロと書く誤り）

【総監 択一の罠③】
安全対策で「リスクをゼロにする」と書くと減点。総監の前提は"リスクは消えない"。
正しくは ALARP＝合理的に可能な限り低減し、残余リスクは受容・監視。
"ゼロ"でなく"許容水準まで下げる"。
