## Tweet 01: 定義編

【総監キーワード解説】活動基準原価計算 #1

ABC（Activity Based Costing）は、製品が消費するアクティビティを基準に間接費を配賦する手法。従来の直接作業時間配賦では多品種少量生産の原価が歪む問題を解消する。

## Tweet 02: 手順編

【総監キーワード解説】ABC #2

手順4ステップ。
①活動を識別（検査・段取替え・運搬等）
②コストプールを設定
③コストドライバーを選定
④量に応じて製品へ配賦

「何の活動が」「どれだけ」コストを発生させたかを追跡するのが核心。

## Tweet 03: 2 段階配賦編

【総監キーワード解説】ABC #3

ABCの2段階配賦。
リソースドライバー: 資源→活動への配賦（例:人件費を作業時間で割当）
アクティビティドライバー: 活動→製品への配賦（例:検査回数で割当）
「資源→活動→製品」の2段階がABCの特徴。

## Tweet 04: 引っかけポイント編

【総監キーワード解説】ABC #4

試験の引っかけ3つ。
①ABC≠ABM（ABCは計算手法、ABMはその結果を活用した管理手法）
②MFCAとの違い（MFCAは物質・エネルギー流れで集計、ISO14051）
③多品種少量で有効、少品種大量では従来法で十分

## Tweet 05: 計算例 + CTA

【総監キーワード解説】ABC #5

例: 検査費60,000円、製品A検査100h・製品B検査200h。
配賦率=60,000/300=200円/h。
A配賦額=20,000円、B配賦額=40,000円。
核心は「活動量に比例して配賦」すること。
