## Tweet 02: 要点圧縮・3管理（日 7/20 20:10）

2級経験記述で覚える枠は3つだけ。品質・安全・工程。令和6年度からはこのうち2つが指定され、同じ工事で両方を書く形式になった。自分の1工事でこの3管理を用意しておけば、どの組合せが来ても対応できる。

## Tweet 04: 反論・規模ではない（火 7/22 08:05）

2級だから経験が浅くて書けない、と不安になる必要はない。主任技術者クラスの大現場でなくていい。小規模でも、自分が段取りや確認に関わった工事なら十分題材になる。規模ではなく関与の深さを書くんだ。
