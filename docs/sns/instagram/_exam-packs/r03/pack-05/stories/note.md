# R3 過去問 #5 ストーリー投稿手順

## 投稿フロー

```
1. フィードに R3 過去問 #5 カルーセル投稿（先に投稿しておく）
       ↓ 同日中
2. ストーリーに 4 枚を順番に連投（01 → 02 → 03 → 04）
   - 各ストーリーに caption.txt のテキストを重ねる（タップでテキスト追加）
   - 02-problem, 04-cta にはリンクスタンプで カルーセル投稿 URL or サイト URL を貼る
       ↓ 24h 以内
3. ストーリーを「ハイライトに追加」
   - ハイライト名: 「R3 過去問」（複数パックを 1 ハイライトに集約）
   - 24h 過ぎたストーリーはハイライト追加不可
```

## 4 枚の役割

1. `01-cover.png` — 興味喚起・パック告知（Stories 専用文言）
2. `02-problem.png` — Q1 を見せて「解いてみて」
3. `03-answer.png` — Q1 の解答「答え合わせ」
4. `04-cta.png` — 「全パックはフィードへ」誘導

## キャプション案

`caption.txt` 参照。各ストーリーに重ねるテキストを 1 行ずつ。

## リンクスタンプの貼り方

### 推奨
- 02-problem.png に「カルーセル投稿 URL」（IG 内部リンク）
- 04-cta.png に「doboku-note.com の R3 解説ページ」（外部リンク）

### IG Web 版の場合
- リンクスタンプ機能のみ利用可（投稿ステッカーは未対応）
- スマホアプリでは「ステッカー → 投稿を追加」で URL 不要

## ハイライト戦略

- 1 ハイライト「R3 過去問」に 全パック × 4 枚を集約（上限 100）
- IG プロフィール訪問者が「タップ 1 回で R3 全パックの試食」が可能
- 拡張：他年度完成時は年度別ハイライト（例「R05 過去問」）を追加
