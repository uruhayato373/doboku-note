# yt-shorts-script: 損益分岐点・限界利益・優劣分岐点 (2026-08-28)

[01 cover]
損益分岐点・限界利益・優劣分岐点。技術士総合技術監理部門の重要キーワードです。

[02 definition]
損益分岐点・限界利益・優劣分岐点とは、損益分岐点とは、**売上高と総費用が等しくなり、利益がゼロとなる売上高または販売数量**である。CVP分析の中核概念である。

[03 examPoint]
試験ポイント1。BEP売上高＝固定費÷限界利益率で計算する

[04 examPoint]
試験ポイント2。安全余裕率＝1−損益分岐点比率で経営の安全度を示す
