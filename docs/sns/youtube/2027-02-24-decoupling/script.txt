# yt-shorts-script: デカップリング (2027-02-24)

[01 cover]
デカップリング。技術士総合技術監理部門の重要キーワードです。

[02 definition]
デカップリングとは、経済成長（GDP増加）と環境負荷（資源消費・汚染物質排出）の関係を切り離すことを意味する概念である。

[03 examPoint]
試験ポイント1。相対的デカップリング：環境負荷の増加率 ＜ 経済成長率（多くの先進国で進展）

[04 examPoint]
試験ポイント2。絶対的デカップリング：経済成長しながら環境負荷が減少（持続可能な開発の目標）
