# yt-shorts-script: 特性要因図 (2026-09-25)

[01 cover]
特性要因図。技術士総合技術監理部門の重要キーワードです。

[02 definition]
特性要因図とは、**特性要因図**とは、品質問題や不具合現象の原因を体系的に整理し、主原因（大骨）と副原因（中骨・小骨）の関係を魚の骨のような図式で表現する分析手法である。

[03 examPoint]
試験ポイント1。考案者は石川馨（1943年）。別名イシカワ図・フィッシュボーン図

[04 examPoint]
試験ポイント2。基本構造は4M（Man・Machine・Method・Material）。拡張版は5M+1Eや6M
