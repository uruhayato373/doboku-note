# yt-shorts-script: デポジット制度 (2027-03-05)

[01 cover]
デポジット制度。ぎじゅつしそうごうぎじゅつかんりぶもんの重要キーワードです。

[02 definition]
デポジット制度とは、**製品の価格に一定の預り金（デポジット）を上乗せし、使用後に容器等を返却した際に預り金を返金する制度**である。

[03 examPoint]
試験ポイント1。購入時に預り金を上乗せし、返却時に返金する仕組み

[04 examPoint]
試験ポイント2。高い回収率の実現と散乱防止が主なメリット
