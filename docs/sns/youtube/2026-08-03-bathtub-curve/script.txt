# yt-shorts-script: バスタブカーブ (2026-08-03)

[01 cover]
バスタブカーブ。技術士総合技術監理部門の重要キーワードです。

[02 definition]
バスタブカーブ（寿命特性曲線）とは、設備や部品の故障率が使用開始からの時間経過とともにどのように変化するかを示した曲線である。

[03 examPoint]
試験ポイント1。初期故障期：故障率減少→デバッギング・慣らし運転で初期不良を除去

[04 examPoint]
試験ポイント2。偶発故障期：故障率一定→予知保全（CBM）または事後保全（BM）が合理的
