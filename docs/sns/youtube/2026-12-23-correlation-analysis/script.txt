# yt-shorts-script: 相関分析 (2026-12-23)

[01 cover]
相関分析。技術士総合技術監理部門の重要キーワードです。

[02 definition]
相関分析とは、2つの変数の間にどの程度の関連性があるかを定量的に評価する統計手法である。

[03 examPoint]
試験ポイント1。相関係数は -1〜1 の値をとり、絶対値が1に近いほど線形関係が強い

[04 examPoint]
試験ポイント2。相関は因果ではない。第三の変数が介在する擬似相関に注意

[05 cta]
詳しい解説は概要欄のリンクから、doboku-note のキーワードページをご覧ください。
