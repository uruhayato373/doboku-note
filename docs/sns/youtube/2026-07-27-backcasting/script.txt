# yt-shorts-script: バックキャスティング (2026-07-27)

[01 cover]
バックキャスティング。技術士総合技術監理部門の重要キーワードです。

[02 definition]
バックキャスティングとは、**将来のあるべき姿（目標）を先に設定し、そこから現在に向けて逆算して必要な施策・行動を導き出すアプローチ**である。

[03 examPoint]
試験ポイント1。将来のあるべき姿を起点に現在への道筋を逆算する（フォアキャスティングは現状の延長線上で予測）

[04 examPoint]
試験ポイント2。長期的・革新的な目標設定に適する。現状延長では解決できない構造的課題に有効

[05 cta]
詳しい解説は概要欄のリンクから、doboku-note のキーワードページをご覧ください。
