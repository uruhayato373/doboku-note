# yt-shorts-script: 能力考課 (2026-11-16)

[01 cover]
能力考課。技術士総合技術監理部門の重要キーワードです。

[02 definition]
能力考課とは、**業務遂行に必要な知識・技能・判断力等の保有能力を評価する人事考課の一分野**である。成果考課・情意考課とともに人事考課の三要素を構成する。

[03 examPoint]
試験ポイント1。知識・技能・判断力・企画力・指導力が主な評価項目

[04 examPoint]
試験ポイント2。発揮能力（実際に発揮された能力）を中心に評価

[05 cta]
詳しい解説は概要欄のリンクから、doboku-note のキーワードページをご覧ください。
