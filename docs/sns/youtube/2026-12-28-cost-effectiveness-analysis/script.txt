# yt-shorts-script: 費用効果分析 (2026-12-28)

[01 cover]
費用効果分析。技術士総合技術監理部門の重要キーワードです。

[02 definition]
費用効果分析とは、代替案ごとの**費用と非貨幣単位の効果**を比較し、経済性を評価する手法である。

[03 examPoint]
試験ポイント1。CEA は効果を貨幣化できない分野（医療・教育・防災）で用いる

[04 examPoint]
試験ポイント2。CBA（貨幣ベース）・CEA（効果単位ベース）・CUA（効用ベース）の3手法は効果の測り方で使い分ける

[05 cta]
詳しい解説は概要欄のリンクから、doboku-note のキーワードページをご覧ください。
