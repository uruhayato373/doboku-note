# yt-shorts-script: 情報漏洩・改ざん・消失 (2027-02-05)

[01 cover]
情報漏洩・改ざん・消失。技術士総合技術監理部門の重要キーワードです。

[02 definition]
情報漏洩・改ざん・消失とは、**情報漏洩・改ざん・消失**は、情報セキュリティにおける3大脅威であり、それぞれCIAの機密性・完全性・可用性を直接侵害するものである。

[03 examPoint]
試験ポイント1。漏洩→機密性(C)、改ざん→完全性(I)、消失→可用性(A)を侵害

[04 examPoint]
試験ポイント2。内部要因（誤操作・内部不正）が情報漏洩原因の大きな割合を占める
