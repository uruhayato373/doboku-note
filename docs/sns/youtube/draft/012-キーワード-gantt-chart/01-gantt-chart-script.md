## ナレーション原稿（VOICEVOX 用）

[0-5秒] 問題提起
「ガントチャートで、クリティカルパスは識別できる。○か×か。」

[5-15秒] 構成要素の紹介
「ガントチャートは横軸に時間、縦軸に作業項目を置き、各作業の期間を横棒バーで表す工程管理図です。直感的で、小日程計画や進捗管理に広く使われます。」

[15-18秒] 沈黙（考える時間）

[18-30秒] 解説
「正解は×。ガントチャートは作業間の依存関係を明示できないため、クリティカルパスは識別できません。これは PERT/CPM の機能です。実務では PERT/CPM でクリティカルパスを識別し、ガントチャートで進捗を可視化する併用が標準です。」

[30-40秒] CTA
「PERT/CPM との比較や引っかけポイントは、概要欄のリンク doboku-note にまとめています。」
