## ナレーション原稿（VOICEVOX 用）

[0-5秒] 問題提起
「総監 R7 択一、財務会計の問題です。」

[5-18秒] 問題提示
「次のうち最も適切なものはどれでしょうか。1 財務会計は内部関係者への報告が目的、2 企業会計原則は処理方法を毎期見直すよう求める、3 減価償却は取得金額を一定方法で各年分の経費として配分する手続、4 機械装置は減価償却資産に含まれない、5 CF 計算書は営業・投資・社会貢献の 3 部分。」

[18-21秒] 沈黙（考える時間）

[21-26秒] 答え発表
「正解は、3、減価償却の定義です。」

[26-38秒] 解説
「財務会計は外部利害関係者への報告で、内部報告は管理会計です。CF 計算書は営業・投資・財務活動の 3 部門で、社会貢献活動は含まれません。継続性の原則により会計方法は毎期同じものを採用します。」

[38-43秒] CTA
「財務諸表の詳細は doboku-note にまとめています。」
