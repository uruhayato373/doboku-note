## ナレーション原稿（VOICEVOX 用）

[0-5秒] 問題提起
「総監 R7 択一、信頼性指標 MTBF と MTTR の計算問題です。」

[5-18秒] 問題提示
「3 機種のサーバの稼働状況、機種 A は総時間 117 万時間、稼働率 0.91、故障 1110 件。機種 B は 118 万時間、0.92、1105 件。機種 C は 123 万時間、0.94、1085 件。MTBF と MTTR の比較で最も適切なものはどれでしょうか。」

[18-21秒] 沈黙（考える時間）

[21-26秒] 答え発表
「正解は、5、機種 C の MTTR が機種 B より小さい、です。」

[26-38秒] 解説
「MTBF は稼働時間割る故障件数、MTTR は停止時間割る故障件数で計算します。機種 C は MTTR が約 68 時間、機種 B は約 85.5 時間で、稼働率が高いほど MTTR は小さくなる傾向があります。」
