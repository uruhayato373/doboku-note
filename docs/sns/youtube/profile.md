# YouTube チャンネルプロフィール文案

YouTube チャンネル（運用予定 `@doboku-note` 想定）のチャンネル設定 SSoT。
個別動画の概要欄テンプレは戦略 docs `docs/project/03_SNS/01_SNS集客戦略.md` §YouTube を参照（本ドキュメントは扱わない）。

## 仕様

| 項目 | 上限 | 備考 |
|---|---|---|
| チャンネル名 | 100 字 | 検索インデックスの最重要要素。SEO キーワードを含める |
| ハンドル (@xxx) | 30 字 | URL の `youtube.com/@xxx` 部分。半角英数・アンダースコア・ハイフン |
| チャンネル説明文 (About) | **1000 字** | SEO 強。X (160)・IG (150)・note (140) と比較して圧倒的余裕 |
| リンク（プロフィール表示） | 14 個（バナー表示は 5 個） | サイト・note・X・IG・問い合わせ等を網羅可 |
| バナー（チャンネルアート） | 2048×1152 px (推奨)、セーフエリア 1546×423 | TV・PC・モバイルで切れない領域に重要要素配置 |
| アイコン | 800×800 px (推奨) | サイトと統一推奨 |

## チャネル役割（戦略 v6）

- YouTube = **SEO・カタログ動線**（→サイト→note）
- **Shorts 主力**（週 3 本・1080×1920・30-60 秒・1 動画=1 キーワード or 1 過去問）
- TTS (VOICEVOX) + Satori 自動スライド + ffmpeg + YouTube Data API
- 競合空白: 「総監部門特化」「短尺スキマ時間型」「TTS 量産高頻度」の 3 軸（戦略 docs §YouTube）
- 標準動画は Phase 4 (2026-10〜) で導入予定（5 管理別解説・トレードオフ等）

詳細: `docs/project/03_SNS/01_SNS集客戦略.md` v6 §YouTube

## 推奨セットアップ

### チャンネル名（候補）

#### 案 A（推奨・31 字）
```
doboku-note｜技術士総監・1級土木 試験対策
```
検索で「技術士」「総監」「1級土木」「試験対策」が拾える。サイト名連動でブランド一致。

#### 案 B（30 字・短め）
```
doboku-note｜土木系資格 試験対策ハブ
```
他資格展開を視野に入れたい時の選択肢。

#### 案 C（40 字・SEO 全振り）
```
技術士総監・1級土木 試験対策ch | doboku-note
```
SEO キーワード先頭配置だが、ブランド認知より検索流入を優先する戦略。

```
@doboku-note
```

X (`@dobokunotecom`)・IG (`@doboku_note`) と表記揺れがあるが、YouTube は `-` を使えるためサイトドメインに最も近い形を採用。

## About 文 採用版（案 A・約 720 字）

```
このチャンネルは「技術士（総合技術監理部門）」と「1級土木施工管理技士」の試験対策に特化した、短尺動画チャンネルです。

▼ どんなチャンネル？
通勤・休憩・寝る前のスキマ時間で、試験頻出キーワードや過去問 1 問を 30〜60 秒の Shorts で復習できる構成です。週 3 本ペースで投稿しています。

▼ 運営者
元・地方自治体の土木職（発注者）として勤務後に退職、6 資格を取得しています：
・1 級土木施工管理技士
・1 級舗装施工管理技術者
・コンクリート主任技士
・コンクリート診断士
・技術士（建設部門）
・技術士（総合技術監理部門）

発注者として培った実務経験と、自身の受験経験をもとに動画を制作しています。

▼ 主な投稿テーマ
・技術士総監 5 管理（経済性／人的資源／情報／安全／社会環境）キーワード解説
・技術士総監 過去問（H21-R7）1 問 1 答
・1 級土木施工管理技士の試験対策

▼ こんな方におすすめ
・社会人で勉強時間が取れない方
・通勤や移動中にスキマ学習したい方
・テキストを読むのが苦手な方
・耳と目で繰り返しインプットしたい方

▼ 関連リンク
詳細解説（無料サイト）→ https://doboku-note.com
模範論文・予想問題（note）→ https://note.com/dobokunote
入口まとめ → https://doboku-note.com/links
X（試験情報・更新告知）→ https://x.com/dobokunotecom

▼ お問い合わせ
https://doboku-note.com/contact

#技術士 #技術士総監 #1級土木施工管理技士 #総合技術監理 #社会人勉強 #資格試験 #スキマ学習
```

**構成意図**:
1. 1 行サマリ（検索に乗せたいキーワードを冒頭に）
2. どんなチャンネルか（差別化要素 = 短尺 × 試験対策）
3. 運営者（信頼根拠 = 発注者退職 + 6 資格）
4. 投稿テーマ（コンテンツ予告）
5. こんな方におすすめ（ターゲット明示でフォロー判断を促進）
6. 関連リンク（YouTube → サイト → note の動線）
7. お問い合わせ
8. ハッシュタグ風キーワード（YouTube 検索アルゴリズム用）

## 運用メモ

- チャンネル名・ハンドルを変更する場合、X (`docs/sns/x/draft/033-pinned-profile/tweets.md`) と IG (`docs/sns/instagram/profile.md`) の経歴・資格表記の整合を確認する
- 「合格者」と「合格済み」の表記方針はメモリ `project_operator_pe_comprehensive_pass.md` 準拠。年度はぼかす
- 個別動画の概要欄テンプレは戦略 docs `docs/project/03_SNS/01_SNS集客戦略.md` §YouTube の「概要欄テンプレ（共通）」セクションに集約済（本ドキュメントには複写しない）
- YouTube ハンドルは一度設定すると 14 日待機しないと変更できない。慎重に決定
- バナー画像は `scripts/gen-youtube-banner.mjs` 等で生成予定（未実装、Q3 量産フェーズで対応）
- YouTube の運用本格化は戦略 v6 Q3（2026-07〜）から。Q2 はテストチャンネルでの品質確認のみ
- `npm run` 既存スクリプトでチャンネル設定変更は不可（YouTube Studio Web UI で手動設定）
