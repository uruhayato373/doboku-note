## 2. 画面の型

サムネと本編3コマの目視から、競合の画面は次の4型に分かれる。

| 型 | 例 | 画面にあるもの |
|---|---|---|
| 実写の講師＋資料 | ひげごろー、日建学院、GET研究所 | 顔出しの講師、ホワイトボード、手元カメラで解答用紙に赤ペン、四択と「正解は2」 |
| スライド＋キャラクター | 土木マン、雅、ちゃんさと | 赤帯の見出し、設問の要語を赤枠、右側の人物が図を指す、吹き出しの一言 |
| PDF への書き込み | Yoko Hirano、土木マン（穴埋め） | 過去問 PDF・出題傾向表への手書き、黄色マーカー |
| 読み上げ音声の一問一答 | 建設資格データ研究所 | 上に穴埋めの問題文、中央に大きな答えのカード、下に読み上げの字幕帯（VOICEVOX） |

自社の公開版は濃紺の表紙のあと、白地に見出しとカード2〜3枚が続く。先生（キャラクター）は表紙だけで、解説中は出ない。図は1本に1枚あるかどうか。

### キャラクターの置き方

- **常駐**: 画面の右下に小さく置き続ける（ちゃんさとの女性アバター。画面幅の1割ほど）
- **案内**: 右側に立たせ、左の図や本文を指す。吹き出しで一言を添える（雅の似顔絵、土木マンの2級の型）
- **サムネだけ**: サムネで大きく見せ、本編には出さない（ちゃんさとの白クマ、土木マンの穴埋め）

3型とも、人物は図や本文の隣に立ち、図の上に重ねない。

### 図の使い方

- **解答用紙そのもの**: 工事概要の記入用紙に赤ペンで書き込む（日建学院4分）、解答用紙の行数と「1行30字・200〜220字で準備」（土木マン）
- **悪い例と良い例の対比**: 「NG例② 施工量があいまい」→「× 単位を書かない」「✓ 掘削工 V=○m³」（ちゃんさと）
- **出題傾向の表・グラフ**: 年度×テーマの表、過去10回の円グラフ（Yoko Hirano、雅のサムネ）
- **寸法入りの手描き図・写真**: 内部振動機の挿入間隔、スクレーパの写真、ローラーとランマのイラスト（雅）

### 売り方の画面

本編の中に宣伝画面を1枚入れる例が多い。雅はメンバーシップ（月190円）、土木マンは自著の問題集、Yoko Hirano は無料動画とメンバーシップ動画の本数と書籍、ひげごろーはライブの告知。ちゃんさとは最後の60秒でココナラ（07b §3）。

### サムネ

太い2〜3行の見出し（黄・赤・白の縁取り）と、右側の人物（実写かキャラクター）。言葉は「こんな記述は不合格！」「合格率90%超」「全189問 約90分で総まとめ」「聞き流しOK」「NG例7つ」のように、数・量・使い道を示す。自社の A案（先生＋2行の極太見出し）は見た目では見劣りしない。差はサムネより尺・形式・題名の言葉にある。

## 3. 10秒ごとの画面

自社の旧形式と図解版の試作を、同じ方法（設計尺の無音プレビュー→10秒ごとに1枚）で比べた。

| | 旧形式 `koji-gaiyo-7items` | 図解版 `koji-gaiyo-sheet-zukai` |
|---|---|---|
| 尺（設計） | 405秒・9画面 | 199秒・18画面 |
| 10秒ごとの比較で直前と同じ画面 | 40回中32回 | 19回中2回 |
| 先生 | 表紙だけ | 全解説画面の右列（ポーズは場面の役割で変える） |
| 図 | 縦フロー1枚 | 解答用紙7行の記入イメージ5枚、悪い例と良い例の対比5枚、縦フロー1枚 |
| 冒頭 | 表紙15秒 | 表紙5秒→悪い例の解答用紙 |

旧形式の設計尺は台本より長く、公開版の実尺は171秒・9画面（平均19秒に1回の切り替え）。図解版の設計尺は読み上げ速度（1秒5.5字）から見積もった値で、実尺は Mac で音声を作ってから確かめる。

## 4. doboku-note への示唆（提案・未承認）

公開・商品化は、いずれもユーザー承認後に行う（[06](./06_動画コンテンツ運用設計.md) §10）。どれから進めるかの判断は backlog DN-0594。

1. **画面は図解版の形にそろえる**。1場面8〜15秒、先生を右列に常駐させ、記事の「悪い例／良い例」の表は対比、解答用紙が出る論点は記入イメージで見せる。悪い例と良い例の文字は36px未満にしない。手順は video-content-policy §4。承認済み84本（公開70本）の作り直しは、図解版の試作を1本公開して視聴維持を比べてから決める。
2. **既存パックを束ねた30〜60分の「総まとめ」「聞き流し」を作る**。新しい台本は要らず、承認済みパックの音声と画面をチャプター付きで連結する。候補は1級二次の経験記述（howto 15本）、1級一次の学科（exam-point 37本）、2級の直前まとめ。競合の再生が最も多い型で、自社に無い。
3. **過去問の一問一答（読み上げ）を作る**。建設資格データ研究所が VOICEVOX で同じ型を作り、90分で24,735回再生している。自社は VOICEVOX と過去問データの両方を持つ。送り先は一次の頻出論点・過去問 PDF・模試（[DN-0279](../../.claude/todo/backlog.md) の無料模試と同じ線）。
4. **添削の見本を図解版で見せる**。解答用紙の図と先生の赤ペンで、伏せ字の架空答案を直す。ココナラ診断・添削の画面での見本になる。実在の受検者の答案は同意なしに使わない。
5. **Shorts を出す**。派生 Shorts 222本は関連動画の設定待ちで非公開のまま（[DN-0110](../../.claude/todo/backlog.md)）。発見の入口が無い状態が続いている。

### 再取得手順（次回の定点観測用）

一覧（再生数・尺）は IP の制限を受けにくい。映像は制限を受けやすいので、Mac の deno と最新 yt-dlp で取る（手順と罠は memory の reference_competitors_civil「競合YouTube動画の映像解析の手順と罠」）。

```bash
# 一覧: 日本語の題名と、数値の再生数（英語表示）を動画IDで結合する
yt-dlp --flat-playlist --extractor-args "youtube:lang=ja" --playlist-end 100 --print "%(id)s	%(title)s	%(duration)s" "<チャンネルURL>/videos"
yt-dlp --flat-playlist --extractor-args "youtube:lang=en" --playlist-end 100 --print "%(id)s	%(view_count)s" "<チャンネルURL>/videos"
# 画面: サムネと自動3コマ（映像を取らずに見られる）
curl -sO "https://i.ytimg.com/vi/<ID>/maxresdefault.jpg"   # maxres1.jpg〜maxres3.jpg が本編の3コマ
# 10秒ごと: 360p を取得して切り出し、分析後に削除する
yt-dlp --js-runtimes deno -f 18 -o "<ID>.mp4" "https://www.youtube.com/watch?v=<ID>"
ffmpeg -i <ID>.mp4 -vf "fps=1/10,scale=480:-1,tile=4x6" -frames:v 1 <ID>_10s.jpg
```
