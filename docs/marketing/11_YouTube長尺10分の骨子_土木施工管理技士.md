# YouTube 10〜15分の解説動画の骨子（1級・2級土木施工管理技士）

既存の分析を素材にした、無料の 10〜15 分の解説動画（看板の網羅型・思考系）の型の考え方と、無料と有料の線引き。1 本ごとの企画（題名案・視聴者・章立て・素材・送り先）は動画パックの `video-pack.json`（`outline`）が正本で、この文書には写さない。

**作成**: 2026-11-23（同日、1 本ごとの骨子を動画パックへ移した）
**親 SSOT**: [07_YouTube戦略_土木施工管理技士.md](./07_YouTube戦略_土木施工管理技士.md)（ポジショニング・Red Line）／[06_動画コンテンツ運用設計.md](./06_動画コンテンツ運用設計.md)（動画パック・KPI）。型の採否の正本は `config/youtube-formats.json`、競合の結論は `config/competitor-positions.json`、試験日は `config/exam-calendar.json`、商品と価格は `config/products.json`（この文書に価格は書かない）

> [!important] 前提の訂正：チャネルは既にある
> doboku-note の YouTube チャネル（@doboku-note）は 2026-09 から稼働しており、土木の通常動画は動画パック 25 本（公開・予約・描画済みなど。`content/registry/publications/youtube/`）がある。ただし型は 2〜8 分の単論点（`single-topic-text`・`single-topic-zukai`）で、2026-10-08 時点で再生中央値 4 回・尺の中央値 2.5 分。この文書の動画は**新しい面ではなく、同じチャネルに「10〜15 分の看板（網羅型）と思考系」という型を足す試行**である。型は 2026-11-23 に `youtube-formats.json` へ trial で足した（看板の網羅型 `kanban-survey`・思考系 `mindset`、どちらも 10〜15 分）。

## 1. 設計の考え方

- **2本の型を組み合わせる**: 看板（網羅型）＝「何年分で何が何回出たか」を全部見せる。思考系＝「落ちる人の思い込み」を元発注者の採点目線で正す。網羅型で検索から入り、思考系を「2本目に観る動画」にする
- **競合と当たらない角度**: 年度別の通し解説（日建学院・雅が寡占）はやらない（07 §10）。網羅型は「年度」ではなく「テーマの出題履歴」で切る。思考系は題名に発注者の視点を出す（競合 35 本中 1 本しかない：`competitor-positions.json` の civil-second-answer）
- **収録の手間**: 顔出しなし・スライド＋声。スライドはサイトの表・図をそのまま使い、新しく図を起こさない。章の切れ目は YouTube のチャプター（概要欄のタイムスタンプ）で出す
- **週 1 本・4〜8 週で判定**: 毎日出さない。1 本ごとに台本 QA（`video-content-qa`）と承認を通す既存の工程に乗せる

### 無料と有料の線引き（共通）

| 動画で出す（無料） | 動画で出さない（note 有料） |
|---|---|
| 試験の仕組み（日程・科目・合格基準・合格率・勉強時間の目安） | 模範答案・解答例の一式 |
| 出題履歴の集計（何年分で何テーマが何回）と今年の見立て | 経験記述のテンプレ・置換ガイド・添削観点の一覧 |
| 落ちる人の共通点と、採点者（元発注者）が読む順番 | 暗記ノート（穴埋め一問一答）・出る順ランキングの全表 |
| 1 問を丸ごと解いて見せる見本（サイトで既に無料公開している問題だけ） | 残り全問の解説・予想模試 |

> [!warning] 出し惜しまない分析と、売っている分析の境目
> note には「出題分析と直前の重点」（`civil-1-r8-bunseki`・`civil-2-r8-bunseki`）が単品で売られている。動画で出す集計は**サイトで既に無料公開している表の範囲**（経験記述の年度別テーマ・合格率・分野構成）に留め、商品側の「出る順トップ10」「日割りロードマップ」は出さない。境目は台本 QA の Red Line 軸で見る。

公開する月・本数の正本は `config/channel-annual-plan.json` の枠（slots）と行（entries）、1 本の企画は動画パック、状態はコンテンツ台帳。管理画面は `/sns/youtube/longform`（枠）と `/content/video`（企画ボード）。

| 動画パック | 型 | 年間計画の枠 |

| `civil-construction-1/c1-keiken-shudai-rireki`（1級 経験記述の出題全履歴） | kanban-survey | `c1-kanban-keiken-2027` |

思考系は網羅型の「2本目に観る動画」として関連動画・終了画面で組にする。技術士の段は候補 1 本に留め、先の 4 本の結果を見てから採否を決める。

## 3. 判定（4〜8 週）

- **見る数字**: 動画ごとの視聴回数・平均視聴時間（維持率曲線は再生 50 回以上で判定。DN-1063）、`utm_source=youtube`・`utm_campaign={packId}` のサイト・note への流入、note の売上の流入元
- **計測の穴**: 概要欄の先頭のリンクが note へ直行だと GA4 から見えない（DN-1086 の 2026-11-12 の実査）。サイトの該当ページを経由するリンクと note 直行のリンクを並べ、どちらが押されたかを分けて見る
- **続ける条件の考え方**: 既存の単論点の動画（再生中央値 4 回）と比べて、視聴回数と流入が上回るか。欠測を 0 と読まない。数値の閾値は最初の 4 本が出そろった時点で決める

## 4. 制作の流れ

企画のパックから `/video-content` の工程（台本 → 機械ゲート → `video-content-qa` → 承認）に乗せる。台本の前に確かめる点（数字の原典照合など）は各パックの `outline.beforeScript` に書く。
