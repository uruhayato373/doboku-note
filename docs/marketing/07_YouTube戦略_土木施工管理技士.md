## 1. 目的とスコープ

土木施工管理技士の YouTube チャネルを**経験記述ファネルの入口**として運用する。総監（05）と同じく送客器＋権威性蓄積装置であり、登録者・広告収益を目的化しない。ただし総監と違い市場規模が大きい（§2）ため、「検索面の占有」ではなく**「二次検定・経験記述の悩み直撃」で競合空白を取る**ことを軸に置く。

### 総監（05）との構造差

| 論点 | 総監（05） | 1級・2級土木（本書） |
|---|---|---|
| 市場規模 | 二次受験者 約 2,600 名/年 | 1級一次 47,715・二次 24,667（R7）＋2級 年間計 46,007（R6）＝**約 30 倍** |
| ロング競合 | 特化チャンネル実質不在＝先占可能 | 年度別過去問解説は雅（≈38.5k）・日建学院（≈39.5k）が寡占＝**レッドオーシャン。正面から参入しない** |
| Shorts 経路 | 経路B（`per-problem-shorts.mjs` YT 専用再描画）が正 | **経路A（IG Reels mp4 派生）が主**（IG 一次制作の資格。05 §3 の資格差を踏襲） |
| 主送客先 | note 有料マガジン（E 系） | **メンバーシップ＋ココナラ添削・診断**（単価・LTV の本体） |
| 主戦テーマ | 択一・キーワード・記述式思考 | **施工経験記述（書き方・診断・添削前準備）** |

### 空白と参入判断（2026-09 改訂）

- **年度別過去問のロング解説はやらない**。雅・日建学院と同じ型で後発参入しても勝ち筋がない（旧判定を 2026-09 実測でも維持。両者とも横ばいで寡占継続）
- **経験記述 howto は空白ではなくなった**（2026-09 修正）。GET研究所が講習型 howto を先行占有。ただし実測 13 チャンネルのいずれも**個別答案への診断・添削を主題にした動画は持たない** → 主戦場を「経験記述特化」全体から**「診断・添削という商品接続型」へ狭く再定義**する。howto 系パックは「発注者として答案のどこを見るか」の一人称視点で GET研究所の一般講習と差別化する
- **Shorts は「完全空白」ではないが経験記述特化の Shorts はゼロ**（2026-09 修正）。ジョウ所長（現場ノウハウ）・はじめよう資格の勉強（学科過去問）が稼働中。経路A（IG 派生）の低コスト構造は維持し、経験記述の悩み直撃 Shorts で面を取る
- 聞き流し暗記型は日建学院に実績があるが後追いが少ない。参入は pilot 判定後（§9）
- **「元発注者」属性は独占ではない**（2026-09 追加）。土木の資格チャンネル（元国交省・NEXCO）が部分先行。「元自治体土木職」という発注者類型＋添削・診断商品線の組み合わせで差別化する

### ポジショニング宣言（2026-09 改訂）

> **診断・添削の商品接続 × 発注者（元自治体）視点 × 顔出しなし TTS**

学科の知識解説は競合が厚く、サイト（無料網羅）と Shorts に委ねる。howto は GET研究所の一般講習と重なるため、通常動画は「発注者として答案のどこを見るか」という一人称の権威性と、診断・添削・完成答案ライブラリへの商品接続（実測 13 チャンネルの誰も持たない）で差別化する。

## 3. チャネル設計

### 二層構造（06 §2.2 の土木適用）

| 層 | 中身 | 制作系統 | 稼働 |
|---|---|---|---|
| **Tier 1** | Shorts（9:16・30-60 秒） | 経路A＝IG Reels mp4 の ffmpeg トリム派生（01 v7 の原則どおり）＋動画パック派生 Shorts | IG 一次制作に連動 |
| **Tier 2** | 通常動画（16:9・5-15 分） | 動画パック一次制作（`content/sns/video-packs/civil-construction-{1,2}/`） | pilot 2 本 QA 合格済み・レンダリング待ち（DN-0110 Phase 1 残） |

- Shorts は外部 URL へ直接送らず、**YouTube の関連動画で該当通常動画へ**送る（06 §2.2）
- 通常動画のクリック可能な概要欄から送客する。UTM は `utm_source=youtube&utm_medium=video&utm_campaign={packId}&utm_content=longform|shorts`（video-content-policy 準拠）
- 総監の Shorts 台帳（`.claude/state/youtube-schedule.json`）は総監専用であり、土木の台帳を混ぜない。土木の公開状態は `.claude/state/video-content-status.json` に一元化する

### 1動画1主CTA（06 §2.3 の対応表を土木で具体化）

| 悩み | 動画で答える範囲 | 主CTA（論理 ID 例） |
|---|---|---|
| 何の工事を題材にできるか分からない | 判断基準・NG 例 | ココナラ S3 作成（`coconala-sakusei`） |
| 答案が一般論になる・減点が不安 | 診断の観点・失敗原因 | ココナラ S1 診断（`coconala-shindan`）／S2 添削 |
| 課題・検討・対応処置の書き方が分からない | 構成の型・順序 | note 完成答案系マガジン・メンバーシップ |
| 学科の頻出論点が覚えられない | 整理法・引っかけ 1 点 | note 暗記ノート・出る順 |
| 学習順序が分からない | ロードマップ | `/links`・サイトもくじ |

## 5. 制作パイプライン

06 §5・video-content-policy が真実源。土木固有の差分のみ記す。

- レンダリング: `npm run render-longform`（storyboard→1920×1080 PNG＋ASS 字幕＋VOICEVOX/ffmpeg mp4）。**会社 PC は `--skip-tts` で PNG/ASS まで、mp4 生成・アップロードは Mac または GitHub Actions**（確立済み分担）
- Shorts 派生: 経路A（IG Reels 派生）が主。パック派生 Shorts は各通常動画から 2 本（video-pack.json の `outputs.shorts`）
- 品質: 機械ゲート `npm run check-video-content` ＋ 意味評価 `video-content-qa`（6 軸 avg 2.0 以上・BLOCK なし）。公開は**ユーザー承認後のみ**（06 §10）
- QA 横断指摘（pilot 4 本共通）: 出典記事の既存 SVG 図版を scene visual に埋め込む renderer 拡張が未実装（DN-0110 Phase 1 残(2)）。土木の経験記述系は文字中心で成立するため P1/P2 はブロッカーにしない。P3（学科の図解論点）は拡張後に着手する

## 7. KPI と判定

KPI 体系は 06 §9 を継承し二重定義しない。土木固有の主 KPI は次の 3 つ。

- `utm_source=youtube` のサイト・note 流入（GA4・`utm_campaign={packId}` join は `/metrics/video` 実装済み）
- **ココナラへの遷移・相談/受注シグナル**（orders-log で動画起点を照合）
- **メンバーシップ「土木セコカン合格ラボ」の入会導線クリック**

判定時点・継続/停止ラインは DN-0110 Phase 4（pilot 公開後 6 週間）が真実源。本書はそこへ土木の判定材料（P1/P2 と P3/P4 のどちらが送客したか）を追加する: 送客が P1/P2 に偏れば P3/P4 の量産を止め、経験記述特化へ絞る。

## 8. リスクと対策

| リスク | 影響度 | 対策 |
|---|---|---|
| ロング過去問解説の後追い参入（雅・日建と正面衝突） | 高 | §2 で構造的に回避。P3 は「1 論点整理」に角度限定 |
| 模範答案・完成答案の中身が動画で漏れる（会員ライブラリ・買い切りの毀損） | 高 | 動画は「構成の型・診断の観点」まで。答案実文は note/会員へ温存。`video-content-qa` の Red Line 軸で検査 |
| 経験記述の捏造を助長する表現 | 中 | 「経験していない工事の創作はしない」（ココナラ運用と同じ Red Line）。動画でも「自分の工事に置き換える」枠組みで語る |
| 過去問問題文の転載（著作権） | 中 | 論点要約のみ。全文転載しない（05 §10 と同じ運用） |
| TTS 量産の「繰り返しコンテンツ」判定 | 中 | タイトル/概要の使い回し禁止。悩み・構成をパックごとに固有化（video-pack.json の pain/promise が担保） |
| YouTube 制作がサイト MDX・note 制作を圧迫 | 中 | pilot 判定前は月 2 本上限（§6）。半手動の P1/P2 が増えすぎたら Shorts 派生へ寄せる |

## 10. やらないこと（Red Line）

- **年度別過去問のロング通し解説**（雅・日建学院の寡占面へ後発参入しない）
- **完成答案・模範答案の実文を YouTube で公開しない**（会員ライブラリ・買い切りマガジンの囲い込み。動画は型と観点まで）
- **経験していない工事・事実の創作を推奨する表現**（添削・作成サービスと同じ捏造 Red Line）
- **サイト記事・note 本文の逐語読み上げ**（06 §10）
- **過去問問題文の全文転載**
- **Shorts 説明欄の外部 URL を主導線とみなすこと**（06 §10）
- **pilot 判定前の公開量産（月 2 本超の通常動画公開）・全記事一括動画化**。企画パック・台本・QA の在庫化はこの制限の対象外（2026-09-01 改訂）
- **登録者数・広告収益の目的化**（市場は総監より大きいが、送客 KPI を主軸に維持）
