# 販売動線分析: ちゃんさと（YouTube・X・ココナラ・note） 2026-09

1級・2級土木施工管理技士の競合「ちゃんさと」の集客から販売までを、YouTube 全131本と X 200投稿の実データで分解した記録。YouTube 戦略の本体は [07_YouTube戦略_土木施工管理技士.md](./07_YouTube戦略_土木施工管理技士.md)、チャンネル横断の定点観測は [07a_YouTube競合分析_土木施工管理技士_2026-09.md](./07a_YouTube競合分析_土木施工管理技士_2026-09.md)、価格・品揃えの比較は [09_販売チャネル競合分析.md](../strategy/09_販売チャネル競合分析.md) §D が真実源。本書はこの1社の動線だけを扱う。

**調査日**: 2026-09-23
**対象**: YouTube @chansato8（登録1.34万・長尺105本＋ショート26本・累計163万再生）／X @dobokusekoukan（フォロワー1,118）／ココナラ「ちゃんさと技師」／note chansato_st／ブログ chansato.com
**方法**: YouTube は yt-dlp で全動画の数値・概要欄・上位コメント・自動字幕を取得し、映像は ffmpeg で1本ごとに「画面切替12コマ・冒頭45秒・最後の60秒・販売語が出た時刻」の4枚に切り出した。X は twitter CLI（読み取りのみ）で直近200投稿。映像と字幕の読み取りはサブエージェント（Sonnet）9体で分担し、集計は機械で行った。切り出した画像・字幕は分析後に削除した。

## 結論

- **試験の段階ごとに売る物を切り替えている**。一次検定期（3〜6月）は note の模試 PDF（¥1,980）と公式 LINE の先行案内、二次検定期（7〜10月）はココナラの経験記述の添削・作成代行（¥6,000〜32,000）に絞る。2026年7月以降は概要欄から LINE が消え、1行目がココナラになった。
- **2026年から販売を本格化した**。動画内で販売先に触れた本数は 2022〜2025年の 13/76本（17%）から、2026年は 25/29本（86%）に増えた。投稿数も 2025年の13本から、2026年は9月までに29本。
- **集客用と販売用の動画が分かれている**。再生を集めるのは1級一次の過去問・「聞き流しOK」系（再生中央値 18,656・19,545）。売上につながる経験記述の動画は再生が最も少ない（中央値 6,850、全体は 12,924）。
- **X では売らずに信頼をためる**。200投稿のうちリンク付きは約2割で、反応上位10件はすべてリンクなし。販売の投稿は、一次の合格発表日や試験直前など受験者の関心が高い日に集中させる。締切は全商品「本試験1週間前」に統一している。
- **自社の前提と食い違う**。07 §2 は「個別答案の診断・添削を商品につなぐ土木チャンネルは無い」としているが、ちゃんさとはその形で運営しており、ココナラの経験記述市場で販売実績が最大（995件）。

## 3. YouTube の作り

**本編では売らず、最後の1か所で売る**。多くの動画は最後の60秒で「ココナラ添削・作成サービス」の宣伝画面→「概要欄をチェック」（LINE・過去問ダウンロード・チャンネル登録）の順に出す。本編中の宣伝はほぼない。動画内の誘導は、ココナラが38回と最も多く、ブログ17回、LINE 12回、Amazon 6回、note 5回（105本の集計）。

**同じ形式の無料版で有料版を売る**。4月の「模試30問」と9月の「無料模擬テスト8問」は、同じ形式の note の有料 PDF へつないでいる。9/19 の動画だけは、普段のココナラの宣伝画面を note 模試の画面に丸ごと差し替えた。

**宣伝専用の動画がある**（2025-01）。次の流れで1本を作っている。

1. 出題形式が変わったことを伝える
2. 視聴者の不安を代弁する
3. サービスの流れを図で示す
4. 期間限定の割引額を示す
5. ココナラの画面を録画し、メッセージの送り方を実演する
6. 問い合わせ文の例として「YouTube見ました。割引希望です」を示す

問い合わせ文の例は、流入元の確認にもなっている。

**信頼の作り方**:

- 2022年末に実績（105名・250テーマ超）と料金を公開した
- 合格者の工事の種類や合格報告を紹介している
- 誤りの訂正を概要欄で公表している
- 自分が担当した現場の写真を使っている

コメント欄には合格報告が多く、社会的証明として働いている。

**再生が伸びる型**:

| 型 | 本数 | 再生中央値 |
|---|---:|---:|
| タイトルに「聞き流しOK」 | 9 | 19,545 |
| 対象が1級一次 | 15 | 18,656 |

- **サムネのデザイン自体は再生数を左右していない**。上位20本と下位20本の比較で、デザインに系統的な差はなかった。差が出たのは「聞き流しOK」「〇分講義」「出題率」「解きまくる」など、使い道と量を伝える言葉と、出題の多いテーマを選んでいるかどうか。
- **ショートは販売に使っていない**。26本中24本が2023年3〜6月に集中しており、概要欄・画面・音声のどこにも誘導がない。以後はほぼ投稿していない。

## 4. X の使い方

200投稿（2026-02-16〜09-23、固定ポスト1件を含む）のうち、型を判定できた199件の内訳。

| 型 | 件数 | 反応の中央値（いいね＋RT） |
|---|---:|---:|
| 学習ノウハウ | 65 | 16 |
| YouTube の告知（リンクあり） | 28 | 12 |
| YouTube の予告（リンクなし） | 22 | 15 |
| ココナラの宣伝 | 22 | 14 |
| 受験者への励まし | 12 | 21 |
| note・書籍の宣伝 | 14 | 16〜18 |
| その他（人柄・クイズ・実績・連絡など） | 36 | — |

- **リンクは固定ポストとプロフィールに任せる**。固定ポストはココナラ添削のカード（2022年1月から固定）、プロフィールのリンクは公式 LINE。個々の投稿にはリンクを貼らないことが多い。予告（リンクなし）の反応率は 1.89% で、告知（リンクあり）の 1.08% を上回った。
- **売る日を選ぶ**。宣伝投稿で最も反応が大きかったのは、1級一次の合格発表日（8/13）に祝辞と一緒に添削を案内した投稿（いいね48）。平常時はノウハウだけを投稿している。
- **締切をひとつに決めて繰り返す**。添削の受付、購入者の質問、note 模試の割引の締切を、すべて「本試験1週間前」にしている。購入者への連絡（「質問は9/27まで」）を公開の投稿で行い、見込み客にも「買った後も面倒を見てもらえる」ことを見せている。
- **新商品は4回に分けて告知する**。「制作中」→「完成間近」→「発売・割引」→「割引の最終日」の順（6月の1級一次模試。9月の二次模試も同じ順で進行中）。
- **信頼は件数より雰囲気で見せる**。
  - 「依頼が立て込んでいる」という近況を繰り返し投稿する
  - Amazon の売れ筋1位や、他の講師が書籍を買ったことなど、第三者の評価を紹介する
  - AI を使わず手作業で添削していることを強調する
  - 独学で落ち、添削を受けて合格した人の体験談を紹介する

## 5. doboku-note への示唆

対象は、経験記述を書けない・自分の答案が合格水準か不安な1級・2級土木の受験者と、一次で本番形式の実力を確かめたい受験者（HARM は A）。需要の証拠として、ちゃんさとのココナラ販売が 867件（7月）→995件（9/23 のプロフィール表示）に伸びた（[09](../strategy/09_販売チャネル競合分析.md) §D7 と同日の実測）。自社のココナラでは、人の作業を伴う出品の受注がまだ0件。

> [!important] 07 §2 の前提を見直す
> 「実測13チャンネルのいずれも、個別答案の診断・添削を主題にした動画は持たない」は、ちゃんさとを調査対象に入れていなかったために出た結論。ちゃんさとは経験記述の動画→ココナラ添削の動線で最大の実績を持ち、「聞き流し」型も運用している。発注者視点を差別化の軸として打ち出すなら、ちゃんさと（元県職員7年・添削の販売995件）と比べて何が違うのかを言い直す必要がある。2026-09-23 に、ポジショニングは維持したまま、技術士（建設部門・総合技術監理部門）の保有を差別化の軸にすると決めた（ちゃんさとの公開資格は1級土木施工管理技士など。伝え方は 07 §2）。

ちゃんさとで確認できた型のうち、自社の商品と運営形態で取り入れられるもの。

1. **試験の段階ごとに主力の販売先を切り替える**。一次期は模試 PDF（note・ココナラ C8）、二次期は経験記述の診断・添削。07 §6 の季節カレンダーに追記した（2026-09-23）。概要欄への実装は backlog DN-0278。
2. **無料の模試から同じ形式の有料版へつなぐ**。問題数を減らした無料版を動画か記事で出し、有料の3回分へ誘導する。既存の模試資産を流用できる。動画パックの制作は backlog DN-0279。
3. **X は平常時はノウハウだけにして、販売は合格発表日と試験直前に集中させる**。締切は「本試験1週間前」のようにひとつに決め、新商品は予告→発売→最終日の順で告知する。リンクは固定ポストとプロフィールに集める。ポリシーと10月の投稿計画への反映は backlog DN-0280。
4. **問い合わせの定型文で流入元を取る**。「YouTube を見た」などの一文を指定すると、動画から来た受注を数えられる。07 §7 の KPI（動画起点の受注照合）に使える。2026-09-23 に土木経験記述の4出品の購入前相談へ「何で知ったか一言」を追記し、live に反映した（PR #595）。視聴者限定の割引を付けるかは、ココナラの規約を確認してから決める（未確認）。
5. **誘導のないショートは量産しない**。ちゃんさとは誘導のないショートを3か月で止めている。自社のショートは関連動画の設定を前提にしており、条件が違う。効果は 07 §9 Phase B の観測で判断する。
6. **保有資格を前に出す**。ココナラの土木経験記述4出品のタイトル・キャッチコピー・本文に、技術士（建設部門・総合技術監理部門）と1級土木の保有を追記し、live に反映した（PR #595）。YouTube の制作表記と概要欄は backlog DN-0278。
7. **4テーマ分の添削を品揃えに加える**。ちゃんさとは4テーマ相当の添削 ¥24,000 を155件売っている。2026-09-24 に ¥12,000・週1名で出すと決めた（ココナラ展開キット §2）。全5テーマ版（`coconala-tensaku-4theme`）としてココナラ service 4418735 で出品済み。

次の検証: 07 §9 Phase B の6週間観測で、動画起点のココナラ問い合わせと note 模試の購入が立つかを見る。その際、上の1〜7のうちどれを入れたかを記録する。

## 6. 限界と未確認

- X は 2026-02-16 以降の200件だけ。それ以前は検索 API が 404 を返し、取得できなかった。
- 公式 LINE のあいさつや配信内容は、友だち追加をしないと見られないため確認していない。
- 売上の内訳は分からない。ココナラの販売数とレビューは公開値、note の購入数は非公開。YouTube から来た売上の割合も分からない。
- 再生数は累計のため、古い動画ほど多くなる。型別の中央値は、公開時期の偏りを補正していない。
- 自動字幕は誤変換が多く、「購入者」（コンクリートの JIS 用語）などで販売語を誤検出した。販売の判定は画像で補正した。
