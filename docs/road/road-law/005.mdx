

# 第５条


第三条第二号の一般国道(以下「国道」という。)とは、高速自動車国道と併せて全国的な幹線道路網を構成し、かつ、次の各号のいずれかに該当する道路で、政令でその路線を指定したものをいう。

一 国土を縦断し、横断し、又は循環して、都道府県庁所在地(北海道の支庁所在地を含む。)その他政治上、経済上又は文化上特に重要な都市(以下「重要都市」という。)を連絡する道路

二 重要都市又は人口十万以上の市と高速自動車国道又は前号に規定する国道とを連絡する道路

三 二以上の市を連絡して高速自動車国道又は第一号に規定する国道に達する道路

四 港湾法(昭和二十五年法律第二百十八号)第二条第二項に規定する国際戦略港湾若しくは国際拠点港湾若しくは同法附則第二項に規定する港湾、重要な飛行場又は国際観光上重要な地と高速自動車国道又は第一号に規定する国道とを連絡する道路

五 国土の総合的な開発又は利用上特別の建設又は整備を必要とする都市と高速自動車国道又は第一号に規定する国道とを連絡する道路

前項の規定による政令においては、路線名、起点、終点、重要な経過地その他路線について必要な事項を明らかにしなければならない。



本条は、一般国道の意義及び路線の指定について規定したものである。

旧道路法では、国道の路線は、東京市を中心に神宮、府県庁所在地、師団司令部所在地等に達する路線とされ、中央集権的、軍事的色彩の強いものであったが、新道路法は政治・経済・文化上の観点に基づいている。

また、「道路法の一部を改正する法律」(昭和三十九年法律第百六十三号)による改正前の国道は、一級国道と二級国道とに区分され、前者は改正後の本条第一項第一号に該当し、後者は同項第二号から第四号までに該当じ、両者とも全国的な幹線道路網を形成するものではあるが、前者はより枢要なものとして、管理主体、管理費用の負担等を異にしていた。

しかしながら、道路交通の発達、特にその長距離化・広域化により、両者を区別して取り扱うことが交通政策上必ずしも適当ではなくなったので、全国的な幹線道路網の整備及び管理を一体的かつ効率的に行うために両者を一体化し、一般国道として取り扱うこととなったものである。

## 一 第一項関係

一般国道(以下「国道」という。）は、高速自動車国道と併せて全国的な幹線道路網を構成するものであるほか、次のいずれかの要件を備えていなければならない。すなわち、

### 1. 国土を縦断し、横断し、又は循環して、都道府県庁所在地（北海道の支庁所在地を含む。）その他政治上、経済上又は文化上特に重要な都市を連絡する道路であること。

本号は、国道としての最も基本的な基準を定めたものである。旧道路法における国道は、前述のとおり、政治的、軍事的観点から位置づけられていたが、新道路法においては、国道を新憲法下の文化国家、福祉国家の幹線道路の枢要部分にふさわしいものとして、政治、経済、文化の諸活動すなわち国民の社会生活の基盤をなすものとしてとらえている。

「政治上、経済上又は文化上特に重要な都市」とは、都道府県庁所在地(北海道の支庁所在地を含む。）のほか、政治上、経済上又は文化上の諸要素を基にして、全国的な幹線道路網を構成するという国道の性格に鑑み、全国的な見地から重要と判断される都市を意味し、人口、工業出荷額、自動車保有台数等を参考にして判断されよう。

「縦断」とは、路線が日本列島の中心線に沿う方向にあること、「横断」とは、それを横切る方向にあること、「循環」とは、路線が環状になっていることをいう。

### 2. 重要都市又は人口十万以上の市と高速自動車国道又は前号に規定する国道とを連絡する道路であること。

### 3. 二以上の市を連絡して高速自動車国道又は第一号に規定する国道に達する道路であること。

すなわち、高速自動車国道又は第一号に規定する国道に達するまでに起終点、又は経過地として二以上の市が含まれている道路でなくてはならない。

### 4. 港湾法第二条第二項に規定する国際戦略港湾若しくは国際拠点港湾若しくは同法附則第二項に規定する港湾、重要な飛行場又は国際観光上重要な地と高速自動車国道又は第一号に規定する国道とを連絡する道路であること。

すなわち、交通上特に重要な地点である特定の港湾、飛行場、観光地を国道の起終点としてとらえたものである。これに該当する国道はこれらの重要地点からの交通を高速自動車国道又は第一号に該当する国道にのせ、あるいはこれらの国道からこれらの重要地点へ至る交通を媒介するという役割を果たすわけである。

## 第二項関係

国道を指定する政令においては、路線名、起点、終点、重要な経過地その他路線について必要な事項を定めることとなっているが、その他必要な事項としては、延長、重複する場合の重複延長などが考えられよう。しかし、現行政令においては、路線名、起点、終点及び重要な経過地を定めるにとどまっている。政令であるから当然に官報に掲載されて公布されるので、地方道の路線の認定の場合のように特別の公示を要しない。
