## Red Line（絶対に守るルール）

以下はコンテンツ戦略・SEO 資産・商品信頼性を守る恒久ルール。番号は他ドキュメント（content-principles.md・magazine-placement.ts 等）からの参照を壊さないため維持する。

1. **【解除｜2026-05-22】勉強時間との配分制約** — 旧ルール「勉強時間の 30% を超える note 執筆をしない」。運営者は総監合格済み・退職者であり受験勉強がないため失効。ただし note 執筆がサイトの MDX 整備（次項）を圧迫しない配慮は継続する
2. **note 執筆のためにサイトの MDX 整備を止めない** — note は sold out したら終わりだが doboku-note は SEO 資産として永続する。**サイト → note への変換** はあっても逆方向はない
3. **【解除｜2026-05-22】不合格時の撤退対応** — 旧ルール「不合格時は有料販売を 2 週間以内に停止し『不合格体験記』へリブランディング」。運営者は合格済みのため失効。「合格体験」系商品（E-1〜E-4）を平常商品として運用できる
4. **note と doboku-note に「同一文」の解説を重複させない（verbatim 重複の禁止）／角度を変えれば両載は可**（重複コンテンツ禁止の再定義｜2026-06-03 改訂） — 判定基準は「両方に出すか否か」ではなく「**同じ文章か／角度・意図が違うか**」。旧ルールは「同じ技術解説を両方載せない」と両載自体を禁じていたが、実害は verbatim 重複に限られるため再定義した。
   - ❌ **verbatim（ほぼ同一文）の両載は禁止**。別ドメインでも Google はクロスドメイン重複と判断して片方を正規化・フィルタし、DA の高い note を残して doboku-note（所有資産）を沈める。note 側からサイトへ cross-domain canonical を張れないため、育てたいサイトが消える。これが本ルールの実害。
   - ✅ **角度・意図を変えた両載は可**（むしろ別クエリで両ドメインが立ち SERP 面積が増える）。役割を分離する — **note = 体験・感情ストーリー・要約・有料誘導**（消費完結型・BOFU）／**doboku-note = 中立・体系・データ準拠の技術解説**（SEO 本体・MOFU）。
   - **立ち上がり期の踏み台運用**: 新規ドメインは順位確立に数週〜数ヶ月かかるため、立ち上がり期は被リンク・DA のある note を先に検索面へ出して流入と売上を作ってよい（note の DA に意図的に依存する）。ただし note は**借地**（AdSense 不可・販売手数料・規約/凍結リスク・導線非所有）で、AdSense 収益・導線制御・永続資産・売却可能性はサイトにしか乗らない。**最良の SEO 資産の「永住地」を note にしない** — サイトが育つにつれ重心をサイトへ移す。
   - カニばりが実害化するのは「**同一クエリの正面競合**」時のみ。切り口が分かれていれば両立する（civil guide クラスタで実証 → `docs/project/04_運営/06_seo-note-synergy-strategy.md`）。同一クエリ競合が GSC で確認された場合のみ canonical 選定＋301 統合を検討する。
5. **サイト = 思考フレーム / note 無料 = 集客装置 / note 有料 = ペルソナ別フル模範論文・テンプレ**（2026-05-25 三層に再定義） — サイトは抽象的な思考プロセス（ALARP / リスクベース判断 / ミティゲーション階層 / LCA 等の汎用フレーム）を扱う。note 無料記事（M2 白書 R7 完全対応集・F-06 R8予想問題）は具体的な数字（白書 R7 の予防保全 3 割縮減 / 特定技能 18.1 万人 等）と全テーマ俯瞰で SNS 集客 + 後続商品送客装置として機能する。note 有料マガジン（M3/M9/M5-8/M12）はペルソナ別フル模範論文 3,000 字 × ペルソナ × テーマ + 5 管理体系学習 + クロストレードオフ引き出しで「最後の一歩」を担う（M4 解答テンプレ3D は 2026-06-01 企画中止）。サイト記事に白書の具体数字を入れすぎたら note 集客装置の意味が薄れ、note 無料記事にペルソナ別フル模範論文まで載せたら有料マガジンが空洞化するため、三層の境界線を意識する（2026-05-18 mlit-whitepaper-2025 撤去 / 2026-05-25 M2 無料リード磁石化の根拠ルール）
6. **予測コンテンツは 3 層分業 — サイト hub = テーマ俯瞰 / サイト spoke = 予想問題文 + 解答方向性 / note = ペルソナ別フル答案** — R8 予想問題のような「将来出題」コンテンツは、サイト無料 hub 記事で「どのテーマか」を俯瞰提示し、サイト無料 spoke 記事で「予想問題文 + 三層構造による解答の方向性（概要）」までを公開、note 有料マガジン M3 で「ペルソナ別フル模範解答（3,000 字×3）+ 採点ポイント + 完全骨子」を独占提供する 3 層構造を維持する。サイト spoke を作らずに hub だけで終わると読者は「テーマだけ知って終わり」になり M3 への動線が弱い、逆に spoke に模範解答まで載せると M3 価値毀損となる。両者を踏まえた 3 層分業が必須。**サイト spoke は固定 3 ペルソナ**（ゼネコン / 河川コンサル / 自治体 道路担当）**で全テーマを縦串展開する。テーマ別に最適業界を選ぶ動的ペルソナは試験本質**（テーマ不明 → 自分のペルソナで全対応）**を裏切るため禁止。3 ペルソナ外の業界**（製造業・IT・エネルギー・商社・社会保障等）**の受験者向けの業界外救済は spoke 末尾「業界外受験者へのアレンジ」段落で 1 行マッピングを示し、具体的なテンプレ展開は note M4「解答テンプレ 3D マトリクス」**（¥2,980、300 セル）**に分業する。詳細は [content-principles.md §21](../../reference/content-principles.md) を参照**（2026-05-18 r8-essay-keyword-forecast 3 層化決定時に新設、2026-05-19 spoke 固定 4 ペルソナ化を追記、2026-05-21 環境調査ペルソナ廃止により固定 3 ペルソナへ）

## 検討して見送った収益化案

### note メンバーシップ（継続課金）— 検討・見送り（2026-05-21）

買い切りマガジンに代えて note メンバーシップで継続課金する案（R8 予想問題のメンバーシップ限定化／¥980 読み放題プラン／択一 ¥980・記述 ¥1,480 のサブスク階層）、およびサイトの択一式過去問解説をパスワードで囲いメンバーシップで鍵を配る案を検討し、いずれも見送った。

**見送り理由**:

1. **季節商材に継続課金が乗らない** — R8 予想問題の価値は 2026 年 7 月の試験日でゼロになる。会員は 5〜6 月入会・7 月解約で購読は最長 2〜3 ヶ月。継続課金のメリットが構造的に出ず、実質「期間限定の買い切り」にしかならない
2. **読み放題は複数買い客の単価を縮める** — ¥980/月の読み放題は、M3 + M4 + 模範論文と複数買いする最良客（客単価 ¥4,000〜7,000）を ¥980 × 2〜3 ヶ月に縮小させる。新規流入が 3 割増えても総額は約 2 割減と試算
3. **解約忘れは当て込めない** — 試験という鋭いイベントが全員に同時に解約トリガーを発火させ、note も毎月課金通知を送るため忘れが起きにくい。仮に取れても数千〜1.5 万円規模で、信頼毀損リスクに見合わない（Red Line #1・#4 の精神に反する）
4. **サイトのパスワードゲートは SEO エンジンを止める** — 過去問解説は無料公開だから SEO 流入を生み、AdSense・アフィリエイト・note 送客で換金されている。ゲートすると流入が崩落し収益チャネル #1（AdSense）ごと枯れる。加えて静的サイト（Cloudflare Pages / SSG）のクライアント側パスワードは技術的に鍵にならず、共通パスワードは狭い受験者コミュニティで即漏洩する

**過去問解説の換金は iOS アプリが担当** — 「過去問本文・解説は iOS 独占」（[04_収益化戦略.md](../../project/01_戦略/04_収益化戦略.md) の Red Line 運用表）。サイトでは無料維持し SEO エンジンとして機能させ、換金は iOS アプリ買い切り ¥1,800（R01〜R06 が Premium）で行う。サイトの過去問解説文は運営者オリジナルのため、無料公開そのものに著作権上の懸念はない。

> [!important] 択一 PDF を note 従チャネルとして併記（2026-07-11・iOS 凍結中の現実対応）
> 上記「過去問解説の換金は iOS 担当」は**サイトの過去問解説ページ**の話。別途、Kindle 択一シリーズ（B 総監）と同一原稿から生成した **A4 印刷用 PDF を note 有料記事に添付**する従チャネルを新設した（iOS 過去問アプリが着手条件未達で凍結中のため、当面の択一換金の受け皿）。SKU（`published:false`・`src/lib/note-magazines.ts`）＝ `tankan-takuitsu-reiwa-pdf`（令和 全280問 ¥980）／`tankan-takuitsu-heisei-pdf`（平成 全400問 ¥980）。原稿 = `docs/note/技術士総監/総監択一-過去問PDF-{令和,平成}/`、生成 = `npm run build-takuitsu-pdf --spec scripts/kindle-specs/{b-reiwa,b-heisei}.json`。対象本は **KDP Select 非加入**で Kindle と同時併売（[08_Kindle出版戦略.md](../../project/01_戦略/08_Kindle出版戦略.md)）。iOS が実装され次第、演習体験は iOS・紙面反復は PDF と棲み分ける。残 = 実機 note 公開 → noteUrl 記入 + `published:true`。
