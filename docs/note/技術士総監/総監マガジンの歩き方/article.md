# 総監マガジンの歩き方｜3つの質問で「あなたに必要な1冊」が3分で決まる案内図

総監の記述式教材は、突きつめると4種類しかありません。**書き方の「型」・施策の「弾薬」・本番の「演習」・あなたの立場の「実例」**です。

doboku-note には記述式の模範論文・教材が20冊以上ありますが、全部を買う必要はありません。この記事は、3つの質問に順に答えるだけで、あなたにいま必要な組み合わせが3分で決まる案内図です。

書いているのは、総合技術監理部門に合格した元自治体の土木職（発注者側）です。自分が受験生だったときに「どれから手をつければいいのか」がいちばん知りたかったので、その地図をそのまま記事にしました。

## まず結論 — 必要なのは「共通装備＋あなたの立場の1冊」

先に結論を出します。読み飛ばす方はここだけで完結します。

総監の記述式は、どのテーマが出ても、5つの管理（経済性・安全・人的資源・情報・社会環境）の**トレードオフを自分の業務に置き換えて論じる**試験です。だから必要なものは2階建てになります。

- **共通装備**（テーマを問わず効く土台）
  - 書き方の「型」＝5管理クロス・トレードオフ
  - 施策の「弾薬」＝設問(3)で書く国家施策のストック
  - 本番の「演習」＝今年のヤマを想定したR8予想問題
- **あなたの立場の1冊**（自分の分野の完成答案）＝14ペルソナから1つ

「分野が決まらない・全部不安」という方だけ、最初から全部入りの**完全パック**を選ぶのが早道です。

では、あなたに必要な組み合わせを3つの質問で決めていきます。

---

## 質問① あなたは発注者ですか、受注者ですか

最初の分かれ道は「立場」です。総監の答案は、立場によって5管理トレードオフの組み立てが変わるからです。

- **発注者**（自治体・国などの公務員技術者）— 住民・議会・予算という制約の中で、地域全体の最適を考える立場。施策には条例改正・基準づくり・補助制度など「ルールを動かす」手段が使えます。
- **受注者**（建設コンサル・ゼネコン）— 工程・利益・労務・技術力という制約の中で、調査設計や施工を高度化する立場。施策は技術開発・社内体制・提案が軸になります。
- **どちらでもない**（製造・IT・エネルギー等の業界外）— ペルソナに依存しない共通装備（型・弾薬・演習）を主軸にしつつ、いちばん業務が近い1冊を参考に添えるのがおすすめです。

立場が決まったら、次は分野です。

## タイプ別おすすめセット（実例4パターン）

組み合わせ方を、4つのケースで具体的にお見せします。買うもの・読む順・かける週数まで書き切ります。

**ケース1：自治体 道路担当・初受験**
まず「型」（5管理クロス・トレードオフ ¥1,980）で対立構造の作り方を頭に入れ、次に自分の立場の完成答案として道路担当の模範論文（¥2,480）を読みます。残り2週間でR8予想問題集（¥3,480）を本番形式で演習。型→実例→演習の順で、合計3冊・約6週間が標準です。

**ケース2：ゼネコン・再受験**（記述で落ちた方）
落ちた原因はたいてい「施策の薄さ」です。設問(3)国家施策バンク（¥2,980）で弾薬を補充し、ゼネコンの模範論文（¥2,480）で施工側の答案の組み立て直しを行います。型がぐらついている自覚があれば5管理クロス（¥1,980）も足します。弾薬→実例の順で約4週間。

**ケース3：製造業など業界外・初受験**
特定ペルソナに寄せず、共通装備を主軸にします。5管理クロス（型 ¥1,980）と設問(3)国家施策バンク（弾薬 ¥2,980）で土台を作り、いちばん業務が近いペルソナ1冊を「翻訳の参考」に読みます。最後にR8予想問題集（¥3,480）で演習。約6週間。

**ケース4：分野異動直後・全部不安**
分野が固まらない方は、最初から全部入りの完全パック（¥9,800）が結局いちばん安く済みます。型・弾薬・演習・全ペルソナの実例がそろうので、どのテーマ・どの立場で問われても対応できます。

## よくある質問

**Q. 複数の分野にまたがっています。どのペルソナを選べばいいですか。**
記述式で題材にする予定の業務で選んでください。答案は1つの管理対象に絞って書くので、いちばん書きやすい現場を持つ分野が正解です。

**Q. 自分の分野が早見表にありません。**
総監の答案は「テーマが何であれ、自分のペルソナで全対応する」のが本質です。早見表にない分野の方は、いちばん業務が近い1冊を参考にしつつ、共通装備（型・弾薬・演習）で自分の答案を組み立ててください。

**Q. 単品を買った後で、まとめて欲しくなったら損ですか。**
共通装備や単品を先に買い、後から完全パックに切り替える方も多いです。まず1〜2冊で手応えを確かめ、必要に応じて買い足す進め方で問題ありません。

**Q. R8予想は来年も使えますか。**
予想問題そのものは年度限定ですが、5管理トレードオフの組み立て方・設問(3)の施策ストックは翌年以降も資産として残ります。季節商材と恒久教材を分けて考えてください。
