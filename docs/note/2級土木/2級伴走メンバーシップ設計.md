## 1. 狙いと前提

2級二次検定の核は **施工経験記述（自由記述・一発勝負）**。独学者が「自分の解答が合っているか一人で判定できない」唯一の領域で、伴走・添削と構造的に相性が最も良い。2級は1級より独学・初学者比率が高く、伴走需要が強い層。

既存の経験記述コンテンツ資産（後述）がすでに揃っており、メンバーシップは **ゼロからではなく既存資産のバンドル＋伴走レイヤーの追加** で成立する。

> [!important] この設計が成立する条件＝定員制
> 「週1本/人」の添削上限は**一人あたり**のキャップであり、運営者の**総工数**は `会員数 × 週1本` で青天井に伸びる。総工数を縛る唯一の仕掛けが **定員（人数上限）**。定員を入れることで (1) 総添削量が固定され工数が読める、(2) 「満席」が希少性になり値付けと解約抑止に効く。**定員のない月額恒久メンバーシップは「売れるほど赤字」になる。**

## 5. 週次運用フロー（添削の半自動化）

総工数を定数に近づけるため、フル添削でも **テンプレ駆動の半自動** にする。

1. **提出**（会員）: 指定フォーマット（工事概要＋設問1/2）で週1本提出
2. **一次処理**（半自動）: 字数ゲート自動チェック → AI下書きで論点漏れ・減点ポイントを抽出
3. **赤入れ**（運営者）: AI下書きをベースに最終判断・採点者視点の一言を付す（ここだけが人的工数）
4. **返却**: NG→OK 形式で返却。共通の誤りは「今月の重点」に集約して全員配信（1対多に変換）

## 6. 添削テンプレ（手順Cで先に作る）

添削の所要時間を定数化するためのチェックリスト雛形。

- [ ] 工事概要：工種・規模・自分の立場が具体か
- [ ] 設問対応：設問1（課題と対応）と設問2が**別内容**になっているか
- [ ] 3管理整合：選んだ管理（安全/品質/工程）とエピソードが一致しているか
- [ ] 数値の具体性：定量（数値・基準値）が入っているか
- [ ] 字数：解答欄字数に収まっているか（超過＝即減点リスク）
- [ ] R6新形式対応：条件提示・新項目への対応が古い型のままでないか

## 11. スコープ・サイト境界・集客動線

### 11.1 一次/二次スコープ — 二次（経験記述）特化が正

伴走（添削）が価値になるのは **二次＝経験記述だけ**。一次は択一で答え合わせが効くため添削価値がゼロ。一次に工数を割くと破綻する。

- **添削対象は二次（経験記述）のみ**。人的工数はここに集中
- **一次対策はサイト無料＋（将来）PWA過去問演習に委譲**。メンバー特典として無料記事をバンドルするのはコストゼロだが、添削工数はかけない

> [!important] シーズンの山は後期のみ
> 後期（10月）は一次＋二次が同日だが、伴走商品が機能するのは **二次がある後期だけ**。前期（6月）は一次のみ＝伴走は機能しない。前期は「一次対策サイトで集客し、後期メンバーシップの見込み客を貯める期間」と位置づける（§7 の「年2山」は集客の山であり、伴走の山は後期1つに訂正）。

### 11.2 サイトとの使い分け — 4層モデルの最上段

既存の Red Line #5（note↔サイトの検索競合回避）と整合。層ごとに売り物が違うのでカニバらない。

| 層 | 売り物 | 例 |
|---|---|---|
| サイト無料（SEO/AdSense・中立体系） | 汎用知識 | 型・出題傾向・記入例・過去問・一次対策全般 |
| note無料クラスター（運営者一人称） | 悩みの顕在化 | 落ちる答案・テーマ選び（リード記事） |
| note有料単発 | 正解の提示 | 完成答案集・過去問模範答案集 |
| **メンバーシップ（新・最上段）** | **あなたの答案への添削** | 個別フィードバック（人的伴走） |

サイト＝「正しい書き方」／単発note＝「模範答案」／メンバーシップ＝「**あなた個人の答案**の添削」。知識→模範→個別と段階的に違うため競合しない。

### 11.3 集客動線 — 単発購入者からのアップセルが主軸

コールド客にいきなり月額継続課金は売れない。既存ファネルの「その先」に最上段として乗せる。

```
サイトSEO＋SNS → note無料クラスター（悩み顕在化）
  → note有料単発（「この人の答案は信頼できる」とトラスト構築）
  → メンバーシップ（「答案は買った。でも"自分の答案"が合ってるか不安」→ 添削）
```

- **主軸**: 単発note（過去問模範答案集／完成答案集）購入者へのアップセル。財布を開き信頼した層が最も転換する
- **CTA設置**: 既存A層クラスター・B4（二次検定の全体像）・サイト `secondary-*` ページにメンバーシップ導線
- **タイミング**: 後期向けに7-8月集客、**9-10月直前期が転換ピーク**

> [!warning] A8.net 添削アフィリと競合
> 集客クラスターでは、サイト改善例ページ（`secondary-experience-writing-examples`）の CTA に **A8.net の添削アフィリ**を既に設置済み。自社メンバーシップ（添削）を立てるとバッティングする。改善例ページ CTA を **アフィリ→自社メンバーシップに切替えるか**を判断する（自社の方が LTV は高いが、母数が立つまではアフィリ併用も可）。
