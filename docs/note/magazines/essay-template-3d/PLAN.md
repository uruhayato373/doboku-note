## コンセプト

**「読む」コンテンツではなく「埋める」ワークシート型マガジン**

3D マトリクス: テーマ軸（20）× 5管理軸（5）× ペルソナ軸（4） = **400 セル**

各セルに:
- 該当する論点
- 5 管理での捉え方
- ペルソナ固有の文脈

→ 受験者が「テーマと業務を入力」すれば論文の骨子が出てくる**逆引き辞書**。

## 差別化

| 項目 | 本マガジン | 競合 |
|---|---|---|
| 形式 | 逆引き辞書（マトリクス） | 一般論的解説 |
| 完成度 | ワークシート（埋める） | 模範解答（読む） |
| 個別化 | ペルソナ × テーマで具体化 | 抽象的 |
| 試験当日の使い方 | 「テーマ確認 → セル特定 → 骨子展開」3 分 | 別途暗記必要 |
| 付録 PDF | あり（ワークシート + チェックリスト） | なし |

**最大の差別化**: 「型」を提供（Red Line 内）。模範解答ではなく「骨子の枠」。
