# 【もくじ】doboku-note コンテンツ総合案内 — 土木・建設の資格対策まるごとマップ

doboku-note をご覧いただきありがとうございます。記事と有料マガジンが増えてきたので、**どこから読めばいいか・何を買えば仕上がるかを1ページで探せる総合もくじ**を用意しました。このページはブックマーク推奨です（更新のたびに追記していきます）。

筆者は自治体土木職（発注者）として勤務し退職、1級土木施工管理技士・技術士（建設部門・総合技術監理部門）ほかを保有しています。**「発注者・合格者の視点」**を軸に、各資格で「無料で全体像をつかむ → 有料で答案・論文を仕上げる」導線でコンテンツを揃えています。

**このページの使い方**

- 受験する資格の見出し（H2）まで飛んでください
- 各資格は「① まず読む（無料）」→「② 仕上げる（有料マガジン）」の順で並んでいます
- 目的から探したい方は、最後の「目的から逆引き」セクションへ
- note アプリでリンクが開きにくいときは、リンクを長押し→「ブラウザで開く」をお試しください
