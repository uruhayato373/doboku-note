1級・2級土木 施工管理技士の「合格伴走」会員

毎月届く予想問題で手を動かし、あなたの答案はプロの添削で仕上げる。試験本番まで伴走する会員制ラボです。

経験記述は「自分の答案が合っているか」を一人では判定できない試験。だからこそ、月例の予想問題で実戦感覚を養い、経験記述はマンツーマン添削で合格水準まで引き上げます。

2 つのプラン

ベース（通年）：完成答案ライブラリ読み放題＋学科記述・経験記述の予想問題を毎月配信。一次・二次対策を通年で。

添削つき（受験シーズン・定員制）：上記すべて＋あなたの施工経験記述を毎週 1 本マンツーマン添削。

完成答案ライブラリは会員なら読み放題。印刷して手元に残したい方には、印刷用PDFつきの買い切りパックもご用意しています。まずは無料の「経験記述 字数カウントツール」からお試しを。最短ルートで一発合格を目指すあなたへ。

※本会員は合格を保証するものではありません。

## プラン名・プラン説明（貼付用）

note の各プランに設定する「プラン名」と「説明文」（各 140 字以内）。**価格は note のプラン設定側で入力**し、説明文には書かない（改訂追従不能を避ける）。**完成答案ライブラリは会員読み放題として訴求してよい**（2026-07-01 ピボットで内包化）。ただし **FLOW＝月例予想・毎週添削は会員限定の価値**として書く（買い切りに出さない）。
