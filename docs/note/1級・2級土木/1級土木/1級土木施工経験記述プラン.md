## マガジン構成案（執筆時の指針）

- 配置: `docs/note/1級土木/magazines/1級土木-施工経験記述-完成答案集/`（2級マガジン構造＝`_meta.yaml` / `hashtags.txt` / テーマ別サブフォルダ を踏襲）。
- 記事構成: **5管理 × 各記事**（品質管理 / 安全管理 / 工程管理 / 施工計画 / 環境対策）。各記事に複数工種の**フル完成答案（監理技術者レベル）** ＋ **現行形式（R06-R07: 2テーマ必答・各2項目）と旧形式（3項目）両対応** ＋ **自分の現場への置換ガイド** ＋ **減点される典型NG答案→合格答案** ＋ **採点者視点チェックポイント**。
- R06-R07 の固定2テーマ出題（品質×環境、安全×施工計画 等）に対応するため、各記事末尾に「もう一方の管理項目との組合せ早見表」を付ける。
- 価格案: **¥2,480（5本セット）** 帯（2級が¥1,980/3本。1級は5管理・監理技術者で厚い）。最終決定は公開時、SoT は `_meta.yaml` / `note-magazines.ts`。
- 紙/PDF版: `magazine-to-pdf` で `scripts/pdf-specs/1級土木-施工経験記述-完成答案集.json` を作成（2級で検証済み）。

## Red Line（本ライン恒久ルール）

1. **サイト＝型・改善例・ヒント / note＝工種別フル完成答案**。同じ文章を両方に置かない。サイトと**別の現場設定**で書き下ろす。
2. **市販本・サイト本文の逐語転載禁止**。記述例は運営者の1級実務経験で独自再構成。
3. **「模範解答」と打ち出さず「改変前提テンプレ」**。各答案に置換ガイドを併記し丸写し→失格を抑止。
4. **サイト MDX 整備を止めて note を書かない**（総監 Red Line #2 継承）。
5. 技術記述問題（問題2-11）の**年度別解説**はマガジン化しない（サイトの基礎解説300KB＋過去問年度別解答が網羅、Red Line #4 リスク大）。ただし**サイト無料と非重複の加工付加価値**（テーマ横断・H30-R07 8年分の頻度分析・出る順・暗記特化）がある学科記述ラインは、本経験記述マガジンとは**別建て SKU**で扱う＝`civil-1-gakka-kijutsu`（テーマ別出る順）/`civil-1-anki-note`（直前暗記ノート）（2026-07-03 新設。真実源は [noteコンテンツ計画.md §9](../noteコンテンツ計画.md)）。
