# 施工管理を辞める前に確認すること｜勢いで退職届を出す前に【無料】

「もう辞めよう」と決めた勢いのまま退職届を出すと、次の職場でまた同じ壁にぶつかることがあります。

私は元自治体の土木職員として、発注者の立場で多くの技術者を見てきました。辞める判断そのものが悪いのではなく、**判断に必要な情報をそろえないまま動くこと**が失敗のもとです。退職届を出す前に確認しておくべきことを、チェックリストとして整理します。

## なぜ「辞める前」に確認するのか

退職してから動くと、収入が途切れる焦りから条件の悪いオファーをのみがちです。逆に、在職中に相場と選択肢を把握しておくと、次の3つが手に入ります。

- 現職に残る場合の交渉材料（自分の市場価値を根拠に待遇を見直せる）
- 転職する場合の冷静な判断軸（勢いではなく事実で選べる）
- 「辞める＝建設業界を去る」ではないという選択肢の広さ

確認すること自体にリスクはありません。むしろ、確認しないまま辞めることの方がリスクです。

## 確認1：自分の市場価値を知る

最初に、自分の経験と資格が転職市場でどう評価されるかを棚卸しします。次の4つを整理してください。

- 工種：道路・河川・造成・上下水道など、担当した分野
- 工事規模：請負金額・工期・体制（何名の現場か）
- 役割：主任技術者／監理技術者／担当者など、責任範囲
- 資格：1級・2級土木施工管理技士、その他の保有資格

工程・品質・安全・原価を管理してきた経験は、人手不足の現場ほど評価されます。棚卸しの仕方は[1級土木の市場価値](https://doboku-note.com/docs/civil-construction-1-guide-market-value?utm_source=note&utm_medium=referral&utm_campaign=civil-career-before-quit&utm_content=market-value)も参考になります。

## 確認2：年収の現在地を知る

次に、いまの年収が水準に対して高いか低いかを確認します。自分の位置が分かると、「転職で本当に上がるのか」「現職で交渉する余地があるのか」が見えてきます。資格手当や役職での上げ方は[年収を上げる方法](https://doboku-note.com/docs/civil-construction-1-guide-salary-up?utm_source=note&utm_medium=referral&utm_campaign=civil-career-before-quit&utm_content=salary-up)で確認できます。

## 確認3：働き方の選択肢を並べる

「施工管理を辞める＝建設業界を去る」ではありません。同じ資格・経験を活かせる働き方は複数あります。

- 同業でより条件の良い会社
- 発注者支援業務（施工の経験を活かして発注者側へ回る）
- 建設コンサル・設計
- 公務員（土木職）

発注者支援業務は、施工の経験を活かしながら発注者側に回る道です。私が身を置いていた発注者の世界に近く、働き方が安定しやすい選択肢です。詳しくは[発注者支援業務への転職](https://doboku-note.com/docs/civil-construction-1-guide-hatchu-shien?utm_source=note&utm_medium=referral&utm_campaign=civil-career-before-quit&utm_content=hatchu-shien)をご覧ください。選択肢を知らないまま二択で悩むより、並べて比べるだけで気持ちは軽くなります。

## 急かされずに進めるコツ

市場価値と年収相場は、転職エージェントの無料相談で効率よく確認できます。「相談したら断りづらいのでは」という不安には、次で対処できます。

- 温度感を最初に伝える（「今すぐではなく、まず相場だけ」と言えばそれに合わせてもらえる）
- 応募は自分で決める（エージェントは応募や入社を強制できない）
- 在職中でOK（辞めてからより、在職中に相場を押さえる方が安全）

自分の市場価値と年収相場を具体的に知りたいなら、建設・施工管理に特化した転職エージェントの無料キャリア面談で、いまの経験・資格で狙える求人と想定年収を確認できます。登録・相談は無料で、在職中でも動くかは提示された条件を見てから決められます。

## おわりに

施工管理を辞める前に確認すべきは、**市場価値・年収の現在地・働き方の選択肢**の3つです。この3つは、転職するかどうかに関係なく、現職で交渉する材料にもなります。

今すぐ転職すると決めていなくても、相場と自分の評価だけ確認しておくと、勢いで辞めて後悔するリスクを避けられます。退職届を出すのは、事実をそろえて「続ける・環境を変える・転職する」を並べて比べたあとでも遅くありません。
