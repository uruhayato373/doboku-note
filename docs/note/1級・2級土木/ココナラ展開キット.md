## 3. 出品文面（貼付用ドラフト）

### S1: 経験記述 合格診断

**タイトル（候補・25字前後）**:
- 「土木施工管理の経験記述を採点者目線で合格診断します」
- サブ: 「元自治体土木（発注側）が減点ポイント3つを即指摘」

**サービス内容（貼付用）**:

```
1級・2級土木施工管理技士 第2次検定の施工経験記述（問題1）について、
あなたの下書き（1テーマ分）を採点者目線でチェックし、以下を返却します。

・合格可能性の判定（A: このままでも戦える / B: 要修正 / C: 書き直し推奨）
・減点ポイント ワースト3（該当箇所→なぜ減点か→改善の方向性）
・字数チェック（解答欄に収まるか／短すぎないか）

私は元自治体土木職員（発注者側＝採点する側の視点）で、1級・2級土木の
経験記述の完成答案・置換ガイドを100本以上執筆してきました。
「どこで減点されるか」を発注者側の目で具体的に指摘します。

※本サービスは診断のみです（書き換え文の提供は「添削」サービスで承ります）
※答案の代筆は行っておりません（受験の公正のため）
※合格を保証するものではありません
```

### S2: 経験記述 添削（2テーマセット）

**タイトル（候補）**:
- 「新形式対応・土木施工管理の経験記述を発注者目線で添削します」
- サブ: 「工種別の完成答案100本超を書いた採点者視点で赤入れ＋書き直し1回」

**サービス内容（貼付用）**:

```
1級・2級土木施工管理技士 第2次検定の施工経験記述（問題1）を、
令和6年度からの新形式（2テーマ必答）に対応して添削します。

【含まれるもの】
・2テーマ分の赤入れ添削（NG箇所→OK例の書き換え案つき）
・チェックリスト形式の判定表（工事概要の具体性／設問1と2の書き分け／
　数値の定量性／字数／新形式対応 など6観点）
・採点者視点のコメント（どこで差がつくか）
・書き直し1回（赤入れを反映した再提出分を再チェック）

【私の強み】
元自治体土木職員（発注者側＝採点する側）として工事成績評定・検査に
携わった経験と、1級・2級土木の工種別完成答案・添削事例100本以上の
執筆実績があります。「あなたの工事のどこを書けば伝わるか」を
工種別の引き出しから具体的に提案します。

【オプション】
＋あなたの工種に近い完成答案サンプル2本（PDF）

【お願い】
・購入後、ヒアリングシート（定型・5分で書けます）にご記入ください
・答案の代筆（ゼロからの作成代行）は受験の公正のため行っておりません。
　ご自身の下書きを合格水準に引き上げるサービスです
・合格を保証するものではありません

```

## 5. 運用フロー・工数設計

| ステップ | 担当 | 所要 |
|---|---|---|
| 購入通知→ヒアリングシート送付 | 運営者（定型文） | 2分 |
| シート受領→.md 保存→ `/keiken-tensaku` 実行 | 運営者＋エージェント | 5分 |
| 添削下書きの取捨選択・トーン調整（最終赤入れ） | 運営者 | 10〜30分 |
| 返却＋書き直し再チェック（S2） | 運営者 | 15分 |

- **AI利用の扱い**: 出品文面のFAQで開示済み（機械処理＝自動化・最終判断＝人間）。ココナラの AI 生成コンテンツ規約は出品前に現行文言を要確認。
- **外部誘導禁止**: ココナラ規約により note・自サイトへの誘導は書かない。導線は逆向きのみ（note 記事末・サイト CTA→「単発で見てほしい方はココナラへ」）。この逆向き導線も、会員ローンチ後は会員優先に切替判断。
- 添削済みデータは匿名化して [添削事例アーカイブ](メンバーシップ/添削事例アーカイブ/) へ蓄積（1対多の資産化・会員コンテンツへ転用）。

## 6. KPI・撤退ライン

- **計測**: 週次で 閲覧数/お気に入り/購入数/評価 を記録（`docs/todo/weekly.md` の週次レビューに1行）。売上は [sales-tracking.md](../../reference/sales-tracking.md) の枠組みへ channel=coconala で追記。
- **成功の感触**: 4週間で S1+S2 合計5件以上 → 継続・価格引き上げ検討。
- **撤退**: 4週間で S2 が3件未満 → 出品は残すが投資停止（看板維持のみ）。主戦場を合格ラボ（会員）へ全振り。
- 8〜9月が経験記述需要のピーク（1級二次 10月上旬・2級後期二次 10月下旬）。**7月中の出品開始が理想**。
