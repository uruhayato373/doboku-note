## 1. メンバーシップ成立性の判断

### 1.1 競合 2 事例から抽出した「成立の鍵」

| 事例 | 形態 | 成立要因／不成立要因 |
|---|---|---|
| sosou_nino（総監 ¥4,980〜9,900/月） | コンテンツ配信型（週5配信・毎日更新） | 成立要因はフォロワー 3,740＋5,936 記事の**先行蓄積**。配信型は「既に大きいオーディエンス」を前提とする換金装置であり、商品設計だけ真似ても成立しない |
| TechPro史（建設部門 ¥500/月） | コンテンツ配信型（音声特化・低価格） | フォロワー 69 で低価格でも伸びていない。**低価格化はオーディエンス不足を解決しない**ことの傍証 |

**結論**: メンバーシップ成立の鍵は「①大きなオーディエンス × 配信型」か「②小さなオーディエンスでも成立する非スケール個別価値（添削）× 定員制」の二択。doboku-note（note フォロワー約 25）に①の道はない。**②なら成立する**。本書はこの「添削（非スケール）」を**上位の添削層**に据え、加えて build-once でスケールする「予想ドリップ＋演習」を**通年のベース層**として重ね、2 層で構成する（§1.4・§2）。

- 添削の需要側の実証は chansato_st（元公務員 × 経験記述添削、cocona 800 名超）。「自分の答案を見てほしい」需要は 1級・2級土木で確実に存在する。
- 添削の供給側の論理: 経験記述は「自分の解答が合っているか一人で判定できない」唯一の領域で、添削と構造的に相性が良い。
- 総監 noteコンテンツ計画.md「検討して見送った収益化案」（2026-05-21、配信型・読み放題の見送り）とも整合する。**見送ったのは配信型であり、添削型・build-once ドリップ型は別物**。

### 1.2 季節商材で成立する条件（10月一斉解約問題）

1級・2級とも二次検定は 10 月。添削層は試験翌月の一斉解約を**避けられない前提**として仕様に織り込む。ただし**ベース層（通年）を受け皿に置くことで、退会ではなくダウングレードへ誘導**できる点が一本化の最大の効用（§1.4）。

- **添削層は「年間 MRR 商品」と偽装しない** — 最初から「シーズン制（7月開講〜10月試験）」と明示して売る。月額 ¥2,980 × 4 ヶ月 ≒ ¥12,000 の「実質コース商品」を、note の仕組み上メンバーシップで提供しているだけ、と運営側も認識する。解約は失敗ではなく仕様。
- **オフシーズン（11〜5月）の縮小運営は添削層のみ** — オフシーズンは添削を停止するが、**ベース層は通年で継続価値を持つ**（週1予想ドリップ・添削事例アーカイブ・(2027〜)過去問 PWA）。シーズン終了後、添削層会員は**退会ではなくベース層 ¥1,480 へダウングレード**できる（受け皿の存在が全面解約を防ぐ）。加えてオフシーズンは (1) 合格発表（1級12月・2級1〜2月）までの質問受付、(2) 不合格時の「来季継続割」案内（再入会優先枠）、(3) 翌季に向けた工事概要ネタ出しシートの先行配布、を提供する。
- **年 2 山の獲得サイクル** — 2級は前期（6月一次）が集客の山・後期（10月二次）が添削の山。1級は 7月一次 → 10月二次。**7〜8 月に両級の一次受験者が最も熱い**ため、添削層の募集はここに当てる。一次受験者はそのままベース層（1次予想ドリップ）の通年顧客になりうる。

### 1.3 運営コスト（添削スケール問題）

結論: **定員のない月額「添削」は売れるほど赤字。スケールはベース層（build-once）で取る**。

- **添削層**は定員制（初期 10 名）＋ 週 1 本/人の添削キャップ。テンプレ駆動＋AI 一次処理（字数ゲート・論点漏れ抽出）→ 人的工数は最終判断と採点者視点コメントのみ（§7.1）。共通の誤りは「今月の重点」全体配信に集約（1対1 を 1対多へ変換）。
- **ベース層**は build-once（週1予想ドリップ・PWA・アーカイブ）で**定員無制限**。人的労働が会員数に比例しないため、ここで母数とスケールを取り、添削層の定員 10 が埋まらないリスク（最大リスク）をベース層の通年売上が下支えする。

### 1.4 なぜ 2 系統を 1 メンバーシップに統合するか（一本化の論理）

①添削層と②ベース層は、**同じ受験者の学習タイムラインの別フェーズ**を狙う。重ねると互いの弱点を相殺する。

| | ① 添削層（上位） | ② ベース層（通年） |
|---|---|---|
| 狙うフェーズ | 2次経験記述・直前期 | 1次＋演習・通年 |
| 機構 | 人的添削（非スケール・定員10） | build-once（予想ドリップ・PWA・アーカイブ。スケール） |
| 単独での弱点 | **オフシーズン価値ゼロ**（11〜6月は縮小・全面解約） | **個別フィードバックの希少価値がない** |
| 相手が埋める穴 | ②の通年価値が解約の受け皿になる | ①の添削が「あなた個人への価値」を与える |

- **整合点**: ①の Red Line「一次に**添削工数**を割かない」（§4-5）は、②の週1予想ドリップ（build-once・添削労働ではない）と矛盾しない。1次は build-once コンテンツで内包し、人的添削は 2次経験記述に限定する。
- **note 上の実装**: 1 メンバーシップに 2 プラン（ベース／添削つき）を設定する（プラン複数運用・プラン別定員の実機検証は §6・ローンチ判断基準）。

2. **ベース層 ¥1,480 の根拠**: 04_収益化戦略 v6 の PWA メンバーシップ既定 ¥1,000/月 を、週1予想ドリップ＋PWA＋1次基礎の厚みで上振れさせた設計値（同書 v6/v8 の ¥1,480〜1,980 レンジの下端）。単発マガジン（¥2,480〜3,480）より低くし、通年継続の心理障壁を下げる。
3. **市場最大化**: 1級（受験者約 5.1 万人/年）を含めることで定員 10 が埋まりやすい。1級・2級の経験記述は設問構造が近く（工事概要＋課題対応記述）、添削チェックリストの 7 割は共用できる。1級経験記述マガジン（3 本公開済）の購入者というアップセル母体を最初から使える。

## 4. 懸念・Red Line

1. **定員なし恒久「添削」禁止** — 添削は売れるほど赤字。定員と添削キャップは添削層の生命線。スケールはベース層（build-once）で取る。
2. **代筆をしない** — 添削は「本人が書いた答案への赤入れ」まで。答案の代筆・実質的な書き起こしは、経験記述の本人作成原則に反し受験者を失格リスクに晒す＋運営の信頼を破壊する。商品ページに「代筆は行わない」を明記。
3. **合格保証・合格率を謳わない** — 添削実績が立つまで数字は出さない。立った後も「合格保証」は恒久禁止。
4. **サイト無料資産を会員限定化しない** — `secondary-*` 等のサイト無料記事は SEO エンジン。ゲートすると流入ごと枯れる（総監計画の見送り判断と同一論理）。ベース層の予想ドリップは**新規 build-once**であり、サイト無料記事の囲い込みではない。
5. **一次対策に添削工数を割かない** — 人的添削の対象は二次（経験記述）のみ（§7.1）。1次はベース層の build-once 予想ドリップで内包し、添削はしない（§1.4・§3.1）。
6. **A8.net 添削アフィリとの動線競合を放置しない** — 自社メンバーシップ開始時に、サイト改善例ページの添削アフィリ CTA を自社導線へ切替えるか判断（§7.3 の宿題）。
7. **note↔サイトの verbatim 重複禁止**（総監計画 Red Line #4 準拠）— 会員限定記事にサイト記事を転載しない。
8. **買い切りマガジン購入者を毀損しない** — 特典同梱で「単品で買って損した」感を出さないよう、メンバーシップの主価値は添削（単品では買えない価値）と通年ドリップ（継続供給）に置き、訴求でも添削を主役にする。買い切りマガジン購入者は永久アクセスで grandfather（04_収益化戦略 v6 原則と整合）。
9. **2 系統を別商品として二重定義しない** — 1級・2級土木のメンバーシップ真実源は本書のみ。04_収益化戦略 v6/v8 で 1級・2級土木向けの独立メンバーシップを再定義しない（cross-exam 概念＝建設部門先行に限定）。

## 5. ローンチ判断基準（段階ローンチ）

PWA（1級・2級版）が 2027 着手のため、2 層は段階的に立ち上げる。

### 5.1 2026 シーズン（先行ローンチ）

**添削層**（即ローンチ可。以下を**すべて**満たしたら募集開始 — 目標: 2026-07 募集 → 8 月開講 → 10 月試験）

2. **見込み客プールゲート**: 1級・2級の経験記述系 買い切りマガジンの累計購入が **10 部以上**（アップセル母体の存在確認）。未達なら募集を 1 ヶ月遅らせ、単発販売とサイト/SNS 集客を先に太らせる。
3. **特典整備ゲート**: 2級 完成答案集（公開作業中のもの）の note 公開完了＋特典同梱方式（§3.3 注記）の実機検証完了。
4. **商品ページゲート**: シーズン制（7〜10月）・定員・週 1 本キャップ・代筆禁止・解約自由を商品ページに明記した文言の完成。

**ベース層（PWA 抜き先行）**（週1予想ドリップ＋添削事例アーカイブで先行可）

5. **予想ドリップ供給ゲート**: 1級・2級版の週次予想パイプライン（1次基礎＋2次お題、AI 生成＋運営者レビュー）が **4〜8 週連続で破綻なく供給**できることを確認（04_収益化戦略 v6/v8 の検証ゲートと同型）。
6. **プラン実機ゲート**: note メンバーシップで 2 プラン（ベース／添削つき）＋プラン別定員が運用可能か実機検証（§6）。不可ならベース層を先行単独運用し、添削はシーズン限定の別プランで追加。

### 5.2 2027 以降（PWA 統合）

## 7. 運用詳細（添削フロー・層別ポジショニング）

先行検討で確立した運用設計を本書に統合する（旧 2級伴走ドラフトの §5/§11 を吸収）。

### 7.1 週次添削フロー（半自動化・添削層）

総工数を定数に近づけるため、フル添削でもテンプレ駆動の半自動にする（テンプレ実体は [2級経験記述-添削テンプレ.md](../2級土木/2級経験記述-添削テンプレ.md)）。

1. **提出**（添削層会員）: ベース層の「週次お題」に沿い、指定フォーマット（工事概要＋設問1/2）で週 1 本提出
2. **一次処理**（半自動）: 字数ゲート自動チェック → AI 下書きで論点漏れ・減点ポイントを抽出
3. **赤入れ**（運営者）: AI 下書きをベースに最終判断・採点者視点の一言を付す（ここだけが人的工数）
4. **返却**: NG→OK 形式で返却。共通の誤りは「今月の重点」に集約して全員配信（1対多に変換 → 添削事例アーカイブへ蓄積）

### 7.2 4 層モデル（サイト境界・カニバリ回避、§4 Red Line #4/#7 と整合）

| 層 | 売り物 | 例 |
|---|---|---|
| サイト無料（SEO/AdSense） | 汎用知識 | 型・出題傾向・記入例・過去問・一次対策全般 |
| note 無料クラスター（一人称） | 悩みの顕在化 | 落ちる答案・テーマ選び |
| note 有料単発 | 正解の提示 | 完成答案集・過去問模範答案集 |
| **メンバーシップ ベース層** | **通年の演習・予想・蓄積** | 週1予想ドリップ・過去問 PWA(2027〜)・添削事例アーカイブ |
| **メンバーシップ 添削層（最上段）** | **あなたの答案への添削** | 個別フィードバック（人的伴走）・題材診断・ペースメーカー |

サイト＝「正しい書き方」／単発 note＝「模範答案」／メンバーシップ ベース＝「通年の演習と予想」／添削層＝「あなた個人の答案の添削」。段階が違うため競合しない。

### 7.3 集客動線（単発購入者からのアップセルが主軸）

コールド客に月額継続課金は売れない。既存ファネルの最上段に乗せる: サイト SEO＋SNS → note 無料クラスター → note 有料単発（トラスト構築）→ メンバーシップ ベース層（通年・低障壁）→ 添削層（シーズン・高単価）。**主軸は単発 note 購入者へのアップセル**。後期向けに 7-8 月集客、9-10 月直前期が添削層の転換ピーク。ベース層は一次受験者（6〜8 月）を通年顧客化する入口。

> [!warning] A8.net 添削アフィリとの競合
> 改善例ページ（`secondary-experience-writing-examples`）の CTA に A8.net 添削アフィリを設置済み。自社メンバーシップ開始時に、アフィリ→自社導線へ切替えるか判断する（自社の方が LTV は高いが、母数が立つまで併用も可）。
