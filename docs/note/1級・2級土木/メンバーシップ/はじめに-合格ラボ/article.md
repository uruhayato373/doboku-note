# 「土木セコカン合格ラボ」をはじめます｜経験記述は"独りで答え合わせできない"試験だから

はじめまして。「架（かける）」と申します。

地方自治体の土木職（発注者）として、道路や河川など公共インフラの計画・設計・発注・工事監督を横断的に担い、退職しました。在職中から、1級土木施工管理技士や技術士（建設部門・総合技術監理部門）などを取得しています。

この note で、1級・2級土木施工管理技士の受験者に向けた会員制ラボ **「土木セコカン合格ラボ」** をはじめます。

この記事では、なぜはじめるのか、どんな場にしたいのかをお話しさせてください。

## なぜ「合格ラボ」なのか

施工経験記述（第2次検定 問題1）は、少し特殊な試験です。

過去問の模範解答を読んでも、いざ自分の現場で書くと「これで受かるのか」が自分では判定できない。択一のように正解と照合できないからです。

誰かに見てもらわないと、独学では手応えがつかめない——ここが経験記述の最大の壁です。

私は発注者として、たくさんの技術者が書いた書類を「評価する側」で見てきました。どこで加点され、どこで減点されるか。その **採点者視点** を、これから受験に向かうあなたへ架け渡したい。

それが、このラボをはじめる理由です。

## どんな場にしたいか

「読むだけ」で終わらせず、手を動かして合格に近づく場にします。

毎月、学科記述と経験記述の予想問題を配信します。手を動かし、実戦感覚を養うためです。

施工経験記述の完成答案ライブラリは、会員なら読み放題。自分の現場に近い工種を選び、5管理（品質・工程・安全・施工計画・環境）の書き方をいつでも確認できます。

そして添削つきプランでは、あなたの答案を毎週1本マンツーマンで添削します。NG→OK の赤入れと、採点者視点のフィードバックつきで。

一人で抱え込まず、試験本番まで一緒に走る。そんな伴走の場にしたいと考えています。

## 2つのプラン

**通年プラン**は、完成答案ライブラリ読み放題＋月例予想配信。一次・二次を通年で対策できます。

**添削つきプラン**は、通年の全内容に加えて、あなたの経験記述を毎週1本マンツーマン添削（受験シーズン限定・定員制）。

くわしい内容と価格は、各プランのページでご確認ください。
