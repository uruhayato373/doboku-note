# 添削実測サンプル02｜提出原稿（会員役のNG答案・品質/コンクリート）

> お題02「環境条件に左右されるコンクリート品質の確保」に対する、**典型的な落ちる答案**を会員役で作成したもの。実測用にわざと減点ポイントを複数含ませている。2級想定（設問1/設問2形式）。

- 工事名：○○調整池 築造工事
- 発注者：○○県

- 規模：一式

## 設問1（具体的な措置）

本工事は夏季のコンクリート打設であり、品質の確保が心配であった。そこで、しっかりと養生を行い、温度管理にも気を付けながら、良いコンクリートを打設するよう努めた。打設後も丁寧に管理を行い、品質の良いコンクリートを確保することができた。

## 設問2（技術的な課題と対応）

夏場で気温が高かったため、コンクリートにひび割れが発生しないようにすることが課題であった。養生をしっかりと行うことで、ひび割れもなく、良い品質のコンクリートを確保することができた。
