# 添削実測サンプル02｜AI下書き（ステップ2・論点抽出）

> 添削テンプレ ステップ2 のプロンプトで提出原稿から抽出した減点ポイントの一次たたき台。
> 運営者はこれを取捨選択し、**最重要の1〜2点だけ**を最終赤入れ（ステップ3）すればよい。

形式：該当箇所 → なぜ減点か → OK例

1. **工事概要「規模：一式」** → 定量性ゼロ → 「コンクリート数量 約○○m³、躯体寸法 ○○×○○×○○m」など数値で。
2. **工事概要「立場：担当者」** → 責任範囲が不明 → 「現場代理人」「主任技術者」など責任の分かる呼称に。
3. **設問1が「しっかり養生」「良いコンクリート」と主観的** → 管理基準値・試験方法がなく、実際に管理したか確認できない → 「内外温度差○○℃以内、スランプ○○cm、打重ね時間間隔○○分以内を管理し、○○で確認」と定量化。
4. **設問1と設問2が重複（どちらも養生→良い品質）** → 設問1≠設問2の原則に反する → 設問1=実施した管理・措置、設問2=技術的課題（例：暑中による温度上昇・コールドジョイント）と検討の論理、に分ける。
5. **設問2の課題が「ひび割れが発生しないように」と一般的** → 何のひび割れか（温度ひび割れ／乾燥収縮）が絞られていない → 「暑中施工で内部温度上昇による温度ひび割れが懸念」と条件から特定。
6. **試験・確認がない** → 品質は定量が命 → 温度計測・テストピース・スランプ試験など確認手段を1つ入れる。

## 最終赤入れの推奨フォーカス（運営者が1〜2点選ぶ想定）

- 最優先候補：**No.3（規格値・試験の欠如）** と **No.4（設問1≒設問2）**。品質管理の合否を分ける2点。
