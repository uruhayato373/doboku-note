# 添削実測サンプル01｜提出原稿（会員役のNG答案・安全/公衆災害）

> お題01「供用中・近接施工での公衆（第三者）災害の防止」に対する、**典型的な落ちる答案**を会員役で作成したもの。実測用なので、わざと減点ポイントを複数含ませている。2級想定（設問1/設問2形式）。

## 工事概要

- 工事名：市道○○線 道路改良工事
- 発注者：○○市
- 工期：令和○年4月〜令和○年12月
- 工種：道路改良
- 規模：一式
- 立場：現場担当

## 設問1（具体的な措置）

本工事は供用中の市道に近接した工事であった。第三者が現場に立ち入らないようにバリケードを設置し、交通誘導員を配置して安全に注意した。また、注意喚起の看板を立てて、事故が起きないように努めた。これらにより、安全に工事を進めることができた。

## 設問2（技術的な課題と対応）

本工事は一般車両や歩行者が多く通行する場所であったため、第三者の事故が起きないようにすることが課題であった。そこで、交通誘導員を増員し、現場全体に注意を払いながら慎重に作業を進めた。その結果、無事故で工事を完了することができた。
