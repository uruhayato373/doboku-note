## 会員への無料導線記事（note 無料・全て下書き）

会員固有の価値（添削・予想・伴走）に角度を合わせた無料記事。既存の集客5本（[1級クラスター](../1級土木/1級土木-集客記事クラスター.md)）は買い切り完成答案集へ送客するため、それとは別角度で会員へ送る。すべて `noteStatus: draft`。

## 崩してはいけない一線（Red Line #10・非重複の生命線）

- **完成答案（過去問模範答案・フル完成答案）をここに置かない** — それは買い切りマガジン（ストック）の領分。会員に入れると価格逆転が復活する（計画 §2.3）。
- 会員のお題は **「お題＋着眼点＋提出枠」まで**。模範答案を書くと完成答案集と重複し、会員に入る理由が消える。
- 添削は **本人答案への赤入れのみ。代筆しない**（Red Line #2）。

## ローンチ前の最優先（計画 §5.1 ゲート1）

会員募集の前に、[2級経験記述-添削テンプレ.md](../2級土木/2級経験記述-添削テンプレ.md) を使って **サンプル2本を自分で添削し、1本30分以内に収まるか実測**する。これが定員（初期10名）の唯一の根拠。

## 級差の扱い（1級・2級 合算メンバーシップ）

お題はテーマ（安全/品質/工程…）共通で出し、各お題の「提出フォーマット」節で級別の答案形式差を明記する。

- **1級**: 令和6年度〜 2テーマ必答・各2項目（設問形式が刷新）／令和5年度以前は3項目
- **2級**: 設問1（具体的措置）／設問2（技術的課題と対応）
