## 崩してはいけない一線（Red Line #10・ライブラリ内包モデル / 2026-07-01 転換）

> [!warning] 旧「完成答案を会員に入れない」は失効
> 完成答案（過去問模範答案・完成答案集・完全攻略パック）は、買い切りマガジンを**会員特典マガジンに紐付けて内包**する（＝会員読み放題・ガード3 実機検証済み）。旧・非重複二刀流の「会員に入れない」は失効（計画 §1.4）。

- **このフロー dir（予想問題／学科記述予想／添削事例）には完成答案そのものを書き下ろさない** — お題＝**「お題＋着眼点＋提出枠」まで**。完成答案は既存の買い切りマガジンを特典紐付けで提供する（二重制作しない）。
- **FLOW（月例予想・毎週添削・締切伴走）を買い切りマガジンに出さない** — 出すと会員になる理由が消える（＝唯一の一線）。
- 添削は **本人答案への赤入れのみ。代筆しない**（Red Line #2）。
