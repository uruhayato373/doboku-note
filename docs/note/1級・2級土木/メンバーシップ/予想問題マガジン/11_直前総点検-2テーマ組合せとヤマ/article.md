# 直前総点検｜経験記述 — 2テーマ必答の組合せ・ヤマ予想・提出前チェック

> これは会員専用の「直前まとめ」です。模範答案は載せていません。これまでの週次お題で書きためた答案を、本番形式に組み上げて仕上げます。

## この回でやること

試験直前のこの回は、新しいお題ではなく**仕上げ**です。これまでの10週で書いた各テーマの答案を、本番の出題形式に組み直し、最後の穴を埋めます。

## 1. 2テーマ必答への組合せ（特に1級・令和6年度〜）

1級は5管理から2テーマ必答・各2項目。**同一工事で設問1≠設問2**を書き分ける必要があります。これまでのお題で作った引き出しを、相性のよい組合せにしておきましょう。

- 書きやすい組合せの例：安全×工程、品質×工程、施工計画×安全、環境×施工計画
- **同一工事で2テーマ**書けるか、または**別工事を2つ**用意するかを決めておく
- どちらが来ても対応できるよう、**主軸2テーマ＋予備1テーマ**を準備

2級も、選べるテーマ（安全・品質・工程）のうち**手薄なものを1つ潰して**おくと安心です。

## 2. ヤマ予想（出題されやすいテーマの目星）

過去の傾向から、準備の優先度をつけます（あくまで予想・保証ではありません）。

- **安全管理**：毎年の主力。労働災害・公衆災害のどちらでも書ける状態に。
- **品質管理**：コンクリート・土工の2系統を確保。
- **工程管理**：遅延回復・管理手法のどちらかは書けるように。
- 施工計画・環境対策は、2テーマめの相方として1本ずつ持っておく。

## 3. 提出前チェックリスト(本番で見直す観点)

- 工事概要：工種は数値つき／立場は責任の分かる呼称か
- 設問1と設問2が**別内容**か
- 防止すべき災害／確保すべき品質が**1つに絞られている**か
- 処置に**数値・管理基準・試験方法・有資格者の選任**が入っているか
- 「実施した」で終わらず、**無事故で完了／規格値を確保**の評価で締めているか
- 解答欄の字数に収まっているか（[字数カウントツール](https://doboku-note.com/tools/keiken-charcount)）

## 4. 最後の添削に出すなら

直前に1本だけ出すなら、**本番で第一候補にするテーマ**の答案を出してください。最重要の1〜2点に絞って赤入れし、当日そのまま使える状態に仕上げます。

本番、これまで書きためた引き出しから手が動けば準備は十分です。落ち着いて、自分の工事を、採点者に伝わる言葉で。
