# 添削事例アーカイブ 01｜工事概要の「具体性」で減点される


![技術士（総合技術監理部門）を持つ元発注者が、施工管理技士の記述を分析して作成。総監＝上位資格の分析力、元発注者＝採点者の視点、施工管理技士＝合格した当事者](img/figure-author-authority.png)

> 会員添削の NG→OK を匿名化して蓄積する会員専用アーカイブ。提出者個人が特定されないよう、工種・数値・固有名は改変しています。あなたの添削で出た共通の誤りも、ここに転記して 1対多で学べる形にします。

## どこが問題だったか

工事概要は本文の前提です。ここが抽象的だと、後ろの設問1・2がどれだけ良くても「**どんな工事か分からない＝記述の信頼性が落ちる**」として印象が下がります。今回の提出で最も多かったのが「規模」「立場」のあいまいさでした。

## NG → OK

**NG**（提出原文）

- 工事名：道路改良工事
- 工種：道路工
- 規模：一式
- 立場：現場担当

問題点：工種が「道路工」では何をしたのか分からない。規模が「一式」では定量性ゼロ。立場「現場担当」は責任範囲が不明で、主任技術者／監理技術者としての判断を語る土台がない。

**OK**（書き換え例）

- 工事名：○○線 道路改良工事
- 工種：道路改良（路床・路盤工 ○○m、アスファルト舗装 ○○㎡、擁壁工 L=○○m）
- 規模：延長 ○○m、幅員 ○○m、土工量 約○○m³
- 立場：現場代理人 兼 主任技術者

なぜ：工種を**具体作業＋数量**で示すと、後段のエピソードに現実味が出る。立場を明示すると「自分が判断した／指示した」という記述が成立する。

## 採点者視点の一言

工事概要は答案の「身分証明書」。**工種は数量つきで、立場は責任が分かる呼称で**書くだけで、本文の説得力が一段上がります。次は設問1の措置に同じ密度の数値を入れていきましょう。

## この事例から全員配信に回した共通の誤り（今月の重点）

- 規模を「一式」で済ませる → **延長・面積・土工量のいずれか1つは数値を入れる**
- 立場を「担当」で済ませる → **現場代理人／主任技術者／監理技術者** など責任の分かる呼称にする
