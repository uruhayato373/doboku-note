# 【土木もくじ】1級・2級土木施工管理技士 対策コンテンツ総合案内

1級・2級土木施工管理技士（第2次検定）の対策コンテンツを1ページで探せるもくじです。ブックマーク推奨（更新のたびに追記します）。

第2次検定の山場は「施工経験記述」です。doboku-note では、**工種×テーマ別の完成答案**と**過去問の年度別模範答案**を、1級・2級それぞれに用意しています。答案はそのまま写すのではなく、自分の工事概要に合わせて改変する前提の「型」です。

> 他資格（技術士総監・建設部門 ほか）も含めた全体の入口は、[doboku-note 総合案内](https://note.com/dobokunote/n/n296a88f64ac2)からどうぞ。

## 伴走する（会員制メンバーシップ）

過去問の完成答案は上の買い切りマガジンで永久に手元に置けます。これに対し、**毎月届く予想問題**（学科記述＋経験記述のテーマ予想）と、**受験シーズン限定のマンツーマン添削**で合格まで伴走するのが会員制「**土木セコカン合格ラボ**」です。予想問題＋添削が中身で、買い切り（過去問の完成答案）とは役割が異なります。最短ルートで一発合格を目指す人向けです。
