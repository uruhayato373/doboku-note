# 【土木もくじ】1級・2級土木の教材、どれを買う？状況別に「まず1冊」がわかる全案内

1級・2級土木施工管理技士の第2次検定は、市販テキストと過去問演習だけでは「施工経験記述の合格答案」までは埋まりません。工種を選び、5つの管理をどう書き分けるか——ここでつまずく人がとても多いところです。

このもくじは、元・地方自治体の土木職（発注者側）として工事の発注・監督・審査に携わり、1級土木施工管理技士に合格した運営者が、対策コンテンツを1ページにまとめたものです。

「どれから読めばいいか」「何を買えば仕上がるか」を、あなたの状況から逆算して選べるようにしました。ブックマーク推奨です（更新のたびに追記します）。

なお、収録している完成答案は「そのまま写す」ものではなく、自分の工事概要に合わせて改変する前提の「型」です。

他資格（技術士総監・建設部門ほか）も含めた全体の入口は、[doboku-note 総合案内](https://note.com/dobokunote/n/n296a88f64ac2)からどうぞ。

過去問の解説・テキストは、サイト [doboku-note](https://doboku-note.com/?utm_source=note&utm_medium=referral&utm_campaign=civil-mokuji&utm_content=intro) で無料公開しています。

## まず選ぶ「1冊」— 状況別ガイド

迷ったら、いまの自分に近いものを1つ選んでください。

- **1級で、二次をまるごと最短で仕上げたい** → 二次検定まるごとパック
- **1級で、経験記述の完成答案を一式そろえたい** → 施工経験記述 完全攻略パック
- **2級で、経験記述を書けるようにしたい** → 想定工事バンク（工種×5管理フル）
- **過去問の年度別模範答案で演習したい** → 施工経験記述 過去問 模範答案集（1級／2級）
- **まだ買わずに全体像だけつかみたい** → 下の「無料で全体像をつかむ」から

各教材の中身は、このあとのセクションで順に説明します。

## 1級土木の有料教材

**二次検定まるごとパック**（経験記述＋学科記述＋直前暗記）— 二次対策で何を買うか迷うなら、まずこれ。施工経験記述の完成答案、学科記述（問題2〜11）の出る順、直前暗記までを1つに束ねた最上位パックです。

単品で買い集めるより割安に、二次の主要領域を一気にカバーできます。

https://note.com/dobokunote/m/md29a34906314

**施工経験記述 完全攻略パック**（想定工事×5管理 全網羅）— 経験記述に特化して仕上げたい人向け。想定工事から自分の現場に近いものを選び、品質・工程・安全・施工計画・環境の5管理すべての完成答案をそろえられます。

「自分の工事でどう書くか」を一望できる構成です。

https://note.com/dobokunote/m/m8290970a7f05

**施工経験記述 完成答案集**（5管理）— まず1本、管理項目別の型がほしい人の入口。5つの管理それぞれの完成答案を読み、自分の答案の骨組みを固めるところから始められます。

https://note.com/dobokunote/m/m150c9db08902

そのほかの1級教材（目的に合わせて追加）:

- [施工経験記述 過去問 模範答案集（R03-R07）](https://note.com/dobokunote/m/m3a578194a0a9) — 出題された年度の設問でそのまま演習したい人向け
- [2テーマ組合せ大全（5管理 全10組合せ）](https://note.com/dobokunote/m/m74cfd7c695d6) — R6以降の「2テーマ必答」に何が出ても対応したい人向け
- [二次学科記述 テーマ別 出る順（問題2〜11）](https://note.com/dobokunote/m/mcfe1059b3335) — 経験記述以外の学科記述も出る順で固めたい人向け

## 2級土木の有料教材

**施工経験記述 想定工事バンク**（工種×5管理フル）— 2級で経験記述を書けるようにする主力。想定工事から選び、5管理の完成答案をそろえられます。初めての受験でも「何を書くか」で手が止まらなくなります。

https://note.com/dobokunote/m/m8554e87ca6ec

**施工経験記述 完成答案集**（安全・品質・工程）— 2級で頻出の3管理にしぼった入口の1冊。まず型を読んで、自分の工事概要に合わせて書き替える練習から始められます。

## 会員制で伴走する

買い切りマガジンは、過去問の完成答案を永久に手元に置ける教材です。

これに対し、**毎月届く予想問題**（学科記述＋経験記述のテーマ予想）と、**受験シーズン限定のマンツーマン添削**で合格まで伴走するのが会員制「**土木セコカン合格ラボ**」です。

予想問題と添削が中身で、買い切り（過去問の完成答案）とは役割が異なります。最短ルートで一発合格を目指す人向けです。
