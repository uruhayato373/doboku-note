# 主：必出の3管理

## 品質管理（継手の水密性・通水前水圧試験の合格）

### 採点者が見るポイント（品質管理）

- 上水道圧力管特有の品質課題（継手水密性・水圧試験）が1つに絞られているか。
- 試験方法（水圧試験圧・保持時間）と**合否基準**が明示されているか。
- 「水圧試験合格」「漏水なし」と客観指標で締めているか。

### 現行形式（令和6年度〜：設問2項目）

**(1) 具体的な現場状況と特に留意した品質管理上の技術的課題**

本工事は市道に埋設された既設老朽管の更新工事であり、ダクタイル鋳鉄管を開削布設するものであった。上水道の配水管は常時水圧がかかる圧力管であり、継手部の施工不良があると埋設後に漏水が生じ、道路の空洞化や周辺建物への浸水被害を招く。また、埋め戻し後に漏水が発覚すると再掘削を余儀なくされ、工程にも多大な影響が出る。そのため、各継手の接合精度と水密性を確保し、埋め戻し前の水圧試験で合格基準を達成することが品質管理上の技術的課題となった。

**(2) (1)の技術的課題を解決するために検討した項目とその対応処置**

ⅰ）継手水密性を確保するため、各接合箇所でゴム輪の装着状態・挿入深さをチェックリストで全数確認し、規格外品は使用しなかった。ⅱ）管の不均等な沈下を防ぐため、基礎砕石を所定厚に均一に敷設して管体を水平に据え付け、管軸のずれを抑えた。ⅲ）埋め戻し前に区間ごとに水圧試験を実施し、`〇〇`MPa で `〇〇` 分間保持して水圧降下が規定値以内であることを確認してから埋め戻した。これにより全延長で継手の水密性を確保し、水圧試験に合格した。

### 旧形式（令和5年度以前：3項目）への組み替え

旧形式では、上の (1) を技術的課題に、継手確認・基礎砕石・水圧試験の3項目を「理由と検討内容」として (2) に、実施内容と水圧試験合格の評価を (3) に分ける。品質管理では (2) で**合否基準**（水圧試験値・保持時間）を先に示すと、(3) の処置が基準達成に向けた行動として読め、説得力が増す。

### 置換ガイド／減点NG→OK（品質管理）

**置換ポイント**

- 管種・継手方式：ダクタイル鋳鉄管・ゴム輪 → 自分の現場の管種・接合方式に置換
- 水圧試験条件：`〇〇`MPa・`〇〇`分 → 自分の現場の水道管理者が定めた試験条件に置換
- 基礎仕様：基礎砕石の敷設厚 → 自分の現場の設計仕様に置換

**減点NG例**

> 配水管の品質が大切なので、丁寧に施工して継手から水が漏れないようにした。

品質課題が抽象的で、試験方法・合否基準・管理手順がない。合格水準は「圧力管の漏水リスク（条件）→ 継手水密・水圧試験（品質課題）→ 全数確認・基礎砕石・水圧試験（手段）→ 合格基準達成（評価）」の連鎖。

## 安全管理（既設埋設物（ガス管・電力ケーブル）の損傷防止）

### 採点者が見るポイント（安全管理）

- 防止すべき災害が「既設埋設物の損傷」に1つに具体的に絞られているか。
- 試掘・手掘り切替え・立会いなど**具体的な手順**が書かれているか。
- 「損傷ゼロで完了」と安全管理として成立する評価で締めているか。

### 現行形式（令和6年度〜：設問2項目）

**(1) 具体的な現場状況と特に留意した安全管理上の技術的課題**

本工事の施工箇所は市道の交差点付近であり、掘削断面内にガス管・電力ケーブル・既設水道管が輻輳して埋設されていた。掘削機械がガス管に接触するとガス漏洩・爆発につながる重大災害になり、電力ケーブルを損傷すると周辺の停電を招く。埋設物の位置は台帳と実際が異なるケースもあり、図面情報だけで機械掘削を行うことは危険であった。そのため、既設埋設物を傷つけずに安全に掘削を完了させることが安全管理上の技術的課題となった。

**(2) (1)の技術的課題を解決するために検討した項目とその対応処置**

ⅰ）掘削着手前に道路管理者・ガス会社・電力会社から埋設台帳を取り寄せ、試掘により各埋設物の実位置・深さ・方向を現地確認してから本掘削の計画を確定した。ⅱ）既設埋設物の直上 `〇〇`cm の範囲は機械掘削を中止して手掘りに切り替え、埋設物を露出させてから吊り防護または受け防護を施した。ⅲ）掘削中はガス会社・電力会社の立会いを求め、ガス検知器を配備するとともに作業員全員に各埋設物の位置と緊急連絡先を周知した。これにより既設埋設物を損傷させることなく、安全に掘削・布設を完了した。

### 旧形式（令和5年度以前：3項目）への組み替え

旧形式では (1) 課題（既設埋設物の損傷防止）、(2) 検討した項目とその理由（試掘・手掘り切替え・立会い体制）、(3) 実施内容と評価（埋設物露出・防護・損傷ゼロ）に分ける。安全管理は災害を1つに絞り、具体的な手順と体制を示すと説得力が増す。

### 置換ガイド／減点NG→OK（安全管理）

**置換ポイント**

- 既設埋設物の種類：ガス管・電力ケーブル → 自分の現場で問題となった埋設物に置換
- 手掘り切替え深さの基準 → 自分の現場で定めた管理基準に置換
- 関係者の立会い：ガス会社・電力会社 → 自分の現場の各埋設物管理者に置換

**減点NG例**

> 埋設物があるので注意して掘削し、事故が起きないようにした。

埋設物の種類・災害の具体性・試掘手順・手掘り切替え・立会い体制がすべて欠落。安全管理は「現場条件→災害種類→具体的手順・数値→無事故の評価」の連鎖が必須。

## 工程管理（道路占用期間・断水切替え時間内での布設完了）

### 採点者が見るポイント（工程管理）

- 道路占用制限と断水切替え可能時間という制約条件が明示されているか。
- 施工日数の試算・切替え前日準備など計画が具体的か。
- 進捗管理の手法と「占用・断水制限内完了」の評価で締めているか。

### 現行形式（令和6年度〜：設問2項目）

**(1) 施工条件や現場周辺の状況の観点から、工程管理上、留意した事項**

本工事の施工箇所は幹線市道であり、道路管理者から道路占用期間を `〇〇` 日以内とする制限があった。また、既設管との接続・切替え作業は水道管理者が認める断水可能時間（`〇〇` 時間以内）に完了させる必要があり、この時間を超えると住民への断水が長引いて苦情につながる。掘削から布設・埋め戻し・舗装復旧までの全工程を占用期間内に収めつつ、断水切替え作業を時間制約の中で確実に完了させることが工程管理上留意した事項となった。

**(2) (1)で記述した留意事項に対して講じた対策とその理由**

ⅰ）占用期間内に全工程を収めるため、布設延長 `〇〇〇`m を日当たり施工量 `〇〇`m で割り付けて必要施工日数を算出し、埋め戻し・舗装復旧の日数を加えてネットワーク工程表に組み込んだ。ⅱ）断水切替え作業を時間内に終わらせる目的で、切替え前日に接続部の開削・準備を完了させ、当日は専任班を配置して既設管との接続と通水確認を連続して実施した。ⅲ）遅れを早期に検知して挽回するため、週次で実進捗と工程表を照合し、掘削の遅れが生じた際は班を増員して占用期間内に埋め戻し・舗装復旧まで完了させた。

### 旧形式（令和5年度以前：3項目）への組み替え

旧形式では (1) 留意事項（道路占用・断水時間制約）、(2) 検討内容と理由（施工日数試算・切替え前日準備・週次管理）、(3) 実施と評価（専任班配置・増員・期間内完了）に分ける。工程管理は「制約→影響→試算・計画→進捗管理→工期達成」の連鎖で書く。

### 置換ガイド／減点NG→OK（工程管理）

**置換ポイント**

- 道路占用期間・断水時間制限 → 自分の現場の道路管理者・水道管理者が定めた制限値に置換
- 日当たり施工量・施工日数 → 自分の現場の班構成・機械編成の実績に置換
- 切替え専任班の構成 → 自分の現場の実体制に置換

※ 工程管理の設問(2)は「講じた**対策とその理由**」が問われる（品質・安全の「対応処置」とは設問文が異なる）。各対策に「〜のため」と採用理由を1つずつ添えて書く。

**減点NG例**

> 工期が短いので急いで施工し、なんとか道路を返すことができた。

占用制限・断水時間・施工日数試算・計画手順・進捗管理がすべて欠落。工程管理は制約条件と定量的な手段・評価が必須。

# 備え：保険としての施工計画・環境（現状は経験記述では未出題）

> **ここからは「保険」です** 施工計画・環境対策は、令和3〜7年度の問題1（経験記述）では出題されていません。無理に主の3管理より先に覚える必要はありません。出題範囲が広がった場合に備え、同じ上水道配水管布設の工事で書けるように用意したものです。

## 施工計画（試掘・交通規制・断水計画と水道管理者協議）

### 採点者が見るポイント（施工計画）

- 着手前の**事前検討**であって、施工中の管理になっていないか。
- 交通規制・断水計画・埋設物調査など複数の制約を整合させた計画立案が示されているか。
- 関係者（水道管理者・道路管理者・警察）との協議に触れているか。

### 現行形式（令和6年度〜：設問2項目）

**(1) 具体的な現場状況と特に留意した施工計画上の技術的課題**

本工事は幹線市道での配水管布設であり、着手前に交通規制計画・断水計画・既設埋設物の事前調査・水道管理者と道路管理者への工事協議という複数の準備が必要であった。交通規制の規模は警察との協議で決まり、断水の範囲と時間帯は水道管理者との協議で確定するため、いずれかが遅れると着手日程が後ろ倒しになる。また埋設物の調査結果によって掘削計画の変更が生じる可能性もあった。これらを着手前に整合させ、実行可能な計画にまとめることが施工計画上の技術的課題となった。

**(2) (1)の技術的課題を解決するために検討した項目とその対応処置**

ⅰ）着工前に試掘を行い、ガス管・電力ケーブル・既設水道管の実位置・深さを確認して掘削深度と管路計画の干渉確認を確定した。ⅱ）道路管理者・警察と協議して片側交互通行と夜間作業の区間を事前に確定し、警備員配置計画を施工計画書に明記した。ⅲ）水道管理者と断水区域・断水時間帯・住民への広報内容・緊急時の給水車配置を協議して確認し、関係各者の承認を得てから着工した。これにより複数の制約を事前に整合させ、着工後のやり直しや中断を防いだ。

### 置換ガイド／減点NG→OK（施工計画）

**置換ポイント**

- 試掘調査の対象埋設物 → 自分の現場で問題となった埋設物に置換
- 交通規制の形態：片側交互通行・夜間作業 → 自分の現場で採った規制方法に置換
- 協議相手：水道管理者・道路管理者・警察 → 自分の現場の関係者に置換

**減点NG例**

> 工事前に計画を立てて施工した。

制約条件・事前検討の具体内容・関係者協議がすべて欠落。施工計画は「制約→複数事項の事前検討→計画への反映→評価」が核心。

## 環境対策（建設残土・掘削濁水の適正処理と住民への断水広報）

### 採点者が見るポイント（環境対策）

- 立地から生じる環境課題（残土・濁水・生活支障）が1つに絞られているか。
- 発生源での対策が具体的か（一般論でないか）。
- 住民への事前周知・苦情対応に触れているか。

### 現行形式（令和6年度〜：設問2項目）

**(1) 具体的な現場状況と特に留意した環境対策上の技術的課題**

本工事は住宅地内の市道で施工するため、掘削残土の場内仮置きが困難で適正な残土処理が求められるとともに、掘削排水（濁水）が側溝に流出して周辺環境を汚染するおそれがあった。また、工事に伴う断水が事前に周知されなければ、住民が日常生活に支障をきたして苦情が発生する。これらは工事の信頼性に直結するため、残土・濁水の適正処理と住民への断水事前広報が環境対策上の技術的課題となった。

**(2) (1)の技術的課題を解決するために検討した項目とその対応処置**

ⅰ）発生した掘削残土は当日中に産業廃棄物マニフェストを発行して適正処分業者へ搬出し、残土の野積みを生じさせなかった。ⅱ）掘削排水は濁水処理装置でSS濃度 `〇〇`mg/L 以下に処理してから側溝へ放流し、未処理水の直接排水を禁止した。ⅲ）断水予定の `〇〇` 日前に断水区域の全世帯へ断水のお知らせを配布し、断水時間・給水車の場所・問い合わせ先を明示して住民からの苦情を防いだ。これにより残土・濁水を適正に管理し、住民への事前周知で苦情を生じさせずに工事を完了した。

### 置換ガイド／減点NG→OK（環境対策）

**置換ポイント**

- 濁水のSS管理値 → 自分の現場の放流基準値に置換
- 断水広報の配布時期 → 自分の現場で定めた事前周知期間に置換
- 残土の搬出先 → 自分の現場の処分方法・処分業者に置換

**減点NG例**

> 残土は適切に処理し、周辺に迷惑をかけないよう工事した。

残土処理の具体手順・濁水対策・住民周知の内容がすべて欠落。環境対策は「立地→課題→発生源対策→測定・近隣対応→基準達成」の連鎖。

## 2テーマ必答（R06+）早見表：この工事で出やすい管理の組合せ

令和6年度以降は設問1・設問2で異なる管理項目が出題される。同一の上水道配水管布設工事の中で2管理を切り分ける組合せを示す。主となる3管理の組合せを優先して準備する。

**品質×工程**（主×主）
設問1で「継手の水密性確保と水圧試験合格（全数確認・水圧試験）」、設問2で「道路占用・断水時間制約内での布設完了（施工日数試算・切替え前日準備・週次管理）」を書く。

**安全×工程**（主×主）
設問1で「既設埋設物（ガス管・電力ケーブル）の損傷防止（試掘・手掘り切替え・立会い）」、設問2で「占用期間・断水時間内の工程確保（施工日数試算・専任班配置・増員）」を書く。令和7年度の出題形式に近い。

**品質×安全**（主×主）
設問1で「継手水密性・水圧試験合格の品質確保」、設問2で「既設埋設物損傷防止の安全管理」を書く。両者は同一工事で独立して成立する。

**品質×環境／安全×施工計画**（保険の組合せ）
出題範囲が広がった場合に備え、主の管理に施工計画・環境を組み合わせて書けるようにしておく。あくまで保険であり、まずは主3管理の組合せを固めることを優先する。
