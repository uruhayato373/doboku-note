# 主：必出の3管理

## 品質管理（消波ブロック製作品質・据付精度の確保）

### 採点者が見るポイント（品質管理）

- 確保すべき品質が「製作品質（コンクリート強度・寸法）」と「据付精度（法線・天端高・かみ合わせ）」の2段階で示されているか。
- 品質を脅かす現場条件（型枠精度・波浪環境・乱積みのかみ合わせ不良）が具体的か。
- 試験・測定方法と**管理基準達成**の評価で締めているか。

### 現行形式（令和6年度〜：設問2項目）

**(1) 具体的な現場状況と特に留意した品質管理上の技術的課題**

本工事は`〇〇`海岸の護岸前面に消波ブロックを`〇〇〇`個製作し乱積みで据え付けるものであった。ブロックは現場ヤードで製作するため、型枠の組立精度と養生管理がコンクリート強度・寸法に直結した。また据付時は乱積みのかみ合わせが不十分なままだと波浪の繰返し作用でブロックが移動し消波機能を損ない、法線と天端高の出来形精度も護岸として要求される設計値内に収める必要があった。そのため消波ブロックの製作品質の確保と、据付時の法線・天端高・かみ合わせ精度の確保が品質管理上の技術的課題となった。

**(2) (1)の技術的課題を解決するために検討した項目とその対応処置**

ⅰ）型枠精度を確保するため、型枠組立後に寸法を全数計測して許容誤差`〇〇`mm以内を確認してからコンクリートを打設し、`〇〇`日間以上の湿潤養生後に脱型して強度試験体を採取し設計基準強度以上を確認した。ⅱ）据付時はクレーンで1個ずつ吊り降ろし、隣接ブロックとのかみ合わせを目視確認しながら乱積みの交互配置を守って据え付けた。ⅲ）法線と天端高は丁張りで管理し、出来形確認測量で設計値`〇〇`m以内に収まることを確認した。これにより製作品質・据付精度とも管理基準を確保した。

### 旧形式（令和5年度以前：3項目）への組み替え

旧形式では、上の (1) を技術的課題に、製作・据付・出来形確認の3項目を「理由＋検討内容」として (2) に、実施内容（全数寸法計測・湿潤養生・丁張り管理）と評価を (3) に分ける。品質管理では (2) で**管理基準値**（強度・寸法誤差・天端高許容値）を先に示すと、(3) の処置が基準に対する行動として読め説得力が増す。

### 置換ガイド／減点NG→OK（品質管理）

**置換ポイント**

- 品質項目・管理基準：寸法誤差`〇〇`mm・天端高`〇〇`m以内 → 自分の現場の規格値に置換
- ブロック種別・積み方：`〇〇`t型の乱積み → 自分の現場のブロック型式・質量・積み方に置換
- 試験・測定：湿潤養生日数・強度試験 → 自分の現場で実施した養生方法・試験に置換

**減点NG例**

> 消波ブロックの製作時にきちんと管理して、品質を確保した。

品質項目が不明で管理基準値・試験方法がなく、何をどのように管理したかが見えない。合格水準は「製作条件（型枠・養生）と据付条件（波浪・かみ合わせ）→品質課題→管理基準値→処置→基準達成」の連鎖。

## 安全管理（クレーン吊り荷落下・波浪による作業員の水難防止）

### 採点者が見るポイント（安全管理）

- 防止すべき災害が1つに具体的に絞られているか（クレーン吊り荷の落下または波浪による水難を選択）。
- 立入禁止範囲・作業中止基準・有資格者など**数値と固有名**が入っているか。
- 「無事故で完了」と安全管理として成立する評価で締めているか。

### 現行形式（令和6年度〜：設問2項目）

**(1) 具体的な現場状況と特に留意した安全管理上の技術的課題**

本工事は海岸の護岸前面に大型クレーンで消波ブロック（`〇〇`t型）を吊り降ろす作業であり、据付位置でのかみ合わせ確認に誘導員が法面上に立つ必要があった。クレーンの吊り荷が落下した場合、法面上の作業員が直撃を受け重大災害に至るおそれがある。また海岸での作業は潮位や波浪の急変により法面上の作業員が波に足をさらわれる水難リスクも常にあった。そのため、クレーン吊り荷の落下による災害防止と、波浪・高潮時の作業員水難防止が安全管理上の技術的課題となった。

**(2) (1)の技術的課題を解決するために検討した項目とその対応処置**

ⅰ）吊り荷直下への立入を禁止するため、クレーン旋回半径内を立入禁止ゾーンに設定し誘導員を配置して、作業員が据付位置を離れてから吊り下ろす手順を確立した。ⅱ）波浪・潮位状況はラジオ気象情報と港湾管理者の波浪予報で毎朝確認し、波高`〇〇`m以上または高潮警報発令時は法面上の作業を即時中止する基準を全員に周知した。ⅲ）法面上の作業員には必ずライフジャケットを着用させ、作業指揮者の直接指揮のもと一人作業を禁止した。これにより吊り荷事故・水難事故を生じさせず、無事故でブロック据付を完了した。

### 旧形式（令和5年度以前：3項目）への組み替え

旧形式では (1) 課題（吊り荷落下・水難）、(2) 検討した項目とその理由（立入禁止・作業中止基準・ライフジャケット）、(3) 実施内容と評価（誘導員配置・波高基準・無事故）に分ける。安全管理は災害を1つに絞り、数値と設備名で処置を示すと説得力が増す。

### 置換ガイド／減点NG→OK（安全管理）

**置換ポイント**

- 吊り荷の質量・クレーン種別 → 自分の現場のブロック重量・使用クレーン型式に置換
- 作業中止基準の波高 → 自分の現場で設定した数値（プレースホルダ`〇〇`m）に置換
- 誘導員・作業指揮者の体制 → 自分の現場の有資格者・配置に置換

**減点NG例**

> 海の近くなので危険に注意し、安全を確保して作業した。

災害が絞られず、立入禁止範囲・中止基準・装備・体制がない。安全管理は「現場条件→災害種類→数値入りの処置→無事故の評価」の連鎖が必須。

## 工程管理（潮位・波浪制約下での据付進捗確保）

### 採点者が見るポイント（工程管理）

- 潮位・波浪という海岸特有の制約条件が明示されているか。
- 施工可能時間・必要据付数の試算や機械・人員計画が具体的か。
- 進捗管理の手法と「工期内完了」の評価で締めているか。

### 現行形式（令和6年度〜：設問2項目）

**(1) 施工条件や現場周辺の状況の観点から、工程管理上、留意した事項**

本工事は海岸の護岸前面に消波ブロック`〇〇〇`個を据え付けるもので、据付は低潮位時の施工可能時間帯（1日あたり約`〇`時間）に限定され、波高`〇〇`mを超えると作業を中止しなければならなかった。施工可能時間帯が短い中で台風・低気圧の来襲による中断が加わると、1日の据付個数を確保できず工程が遅延するおそれがあった。一度遅延すると潮位制約のある据付工程は挽回が難しく工期を逸脱しかねないため、制約時間帯内で計画個数を確実に据え付けることが工程管理上留意した事項となった。

**(2) (1)で記述した留意事項に対して講じた対策とその理由**

ⅰ）限られた施工可能時間で工期内に据え付けるため、潮位表から月間の施工可能日数と1日当たり据付可能個数を試算し、1日`〇〇`個を目標値として工程表に組み込んだ。ⅱ）目標個数を安定して確保する目的で、クレーン`〇`台と誘導員・据付作業員各`〇`名を編成し、吊り降ろしとかみ合わせ確認を並行できる体制を整えた。ⅲ）遅れを早期に把握して挽回するため、週次で実績据付数と計画数を照合し、波浪中断分は施工可能日に集中施工して補い、工期内にすべて据え付けた。

### 旧形式（令和5年度以前：3項目）への組み替え

旧形式では (1) 留意事項（潮位・波浪制約下での工程確保）、(2) 検討内容と理由（施工可能時間・個数試算・機械編成）、(3) 実施と評価（週次照合・集中施工・工期内完了）に分ける。工程管理は「制約→影響→試算・機械計画→進捗管理→工期達成」の連鎖で書く。

### 置換ガイド／減点NG→OK（工程管理）

**置換ポイント**

- 施工可能時間・作業中止波高 → 自分の現場の潮位条件・気象基準に置換
- クレーン台数・作業員編成 → 自分の現場の実投入体制に置換
- 週次照合・集中施工 → 自分の現場で採った進捗管理・挽回策に置換

※ 工程管理の設問(2)は「講じた**対策とその理由**」が問われる（品質・安全の「対応処置」とは設問文が異なる）。各対策に「〜のため」と採用理由を1つずつ添えて書く。

**減点NG例**

> 波が高い日は休んで、天気がいいときに頑張って間に合わせた。

制約の具体性・施工可能日数の試算・機械計画・進捗管理がすべて欠落。工程管理は制約条件と定量的な手段・評価が必須。

# 備え：保険としての施工計画・環境（現状は経験記述では未出題）

> [!note] ここからは「保険」です
> 施工計画・環境対策は、令和3〜7年度の問題1（経験記述）では出題されていません。無理に主の3管理より先に覚える必要はありません。出題範囲が広がった場合に備え、同じ海岸護岸消波工事で書けるように用意したものです。

## 施工計画（ブロック製作ヤード確保・海象把握・関係者協議）

### 採点者が見るポイント（施工計画）

- 着手前の**事前検討**であって、施工中の管理になっていないか。
- 製作ヤード・据付方法・海象条件という複数の制約を整合させた計画立案が示されているか。
- 関係者（海岸管理者・漁業協同組合）との協議に触れているか。

### 現行形式（令和6年度〜：設問2項目）

**(1) 具体的な現場状況と特に留意した施工計画上の技術的課題**

本工事は`〇〇`海岸での消波ブロック製作・据付工事であり、海岸内での製作ヤード確保、潮位・波浪予報に基づく施工時期の計画、海岸管理者と漁業協同組合との事前協議という複数の制約が着手前に整合を要した。製作ヤードを確保できなければ現場打設が成立せず、海象の把握が不十分なまま計画を立てると施工可能時間の見込みが狂い、漁業操業期間との重複があれば調整も必要であった。そのため複数の制約を事前に整合させ実行可能な計画にまとめることが施工計画上の技術的課題となった。

**(2) (1)の技術的課題を解決するために検討した項目とその対応処置**

ⅰ）海岸護岸前面に面積`〇〇〇`m²以上の製作ヤードを海岸管理者の許可を得て確保し、型枠・養生区画・重機動線を着工前の配置計画として施工計画書に明記した。ⅱ）過去`〇`年分の潮位表と気象庁の波浪予報を整理して月別の施工可能日数を推定し、波高`〇〇`m超の作業不能日も見込んだ工程表を作成した。ⅲ）着工前に海岸管理者・地元漁業協同組合と施工範囲・期間・濁り対策・漁業操業との調整方法を協議し、合意内容を施工計画書に反映した。この計画により、重なる制約を事前に整合させ工事を円滑に進めることができた。

### 置換ガイド／減点NG→OK（施工計画）

**置換ポイント**

- 製作ヤード面積・許可機関 → 自分の現場の実ヤード規模・所管機関に置換
- 参照した潮位・波浪データ → 自分の現場で参照した資料・予報機関に置換
- 漁業協同組合との協議内容 → 自分の現場で実際に協議した関係者・内容に置換

**減点NG例**

> 海岸工事なので漁師さんに迷惑をかけないよう注意して計画した。

制約条件・ヤード計画・海象条件の事前把握・関係者協議の具体的内容がすべて欠落。施工計画は「制約→複数事項の事前検討→計画への反映→評価」が核心。

## 環境対策（コンクリート製作・ブロック据付に伴う海水濁りの低減）

### 採点者が見るポイント（環境対策）

- 海岸工事特有の環境課題（海水の濁りによる海生生物への影響）が1つに絞られているか。
- 発生源での対策が具体的か（一般論でないか）。
- 測定基準値に触れ、関係者対応で締めているか。

### 現行形式（令和6年度〜：設問2項目）

**(1) 具体的な現場状況と特に留意した環境対策上の技術的課題**

本工事は海岸の護岸前面での消波ブロック据付工事であり、クレーンによるブロックの吊り降ろし作業や製作ヤードでのコンクリート打設に伴うセメント分の流出によって、周辺海域に濁りが発生し海生生物の生育環境を損なうおそれがあった。海岸管理者・漁業協同組合からも水質への影響を最小限にするよう求められており、濁り（SS値）を基準値`〇〇`mg/L以下に保ちながら施工することが環境対策上の技術的課題となった。

**(2) (1)の技術的課題を解決するために検討した項目とその対応処置**

ⅰ）製作ヤードでのコンクリート打設面にはセメントペースト流出防止のため排水升と沈砂池を設け、上澄みのみを処理してから排水した。ⅱ）ブロック据付時の海底砂巻き上がりを最小限にするため、クレーンの吊り下ろし速度を抑え、吊り荷が海面に触れる直前に一旦停止し静かに着底させる手順を定めた。ⅲ）作業中は作業船からSS計で海水の濁りを定期測定し、`〇〇`mg/Lを超えた場合は当該作業を中断する基準を設け、漁業協同組合に測定結果を報告した。これにより海水の濁りを基準値以内に保ち、海生生物への影響なく工事を完了した。

### 置換ガイド／減点NG→OK（環境対策）

**置換ポイント**

- SS基準値 → 自分の現場で設定した`〇〇`mg/L（現場設定値のためプレースホルダ化）に置換
- 排水升・沈砂池の規模 → 自分の現場の設備に置換
- 測定頻度・中断基準 → 自分の現場で採用した管理基準に置換

**減点NG例**

> 海の近くなので汚さないように注意して工事した。

環境課題が絞られず、発生源対策・測定・基準値・関係者対応が欠落。環境対策は「立地→課題→発生源対策→測定・関係者対応→基準達成」の連鎖。

## 2テーマ必答（R06+）早見表：この工事で出やすい管理の組合せ

令和6年度以降は設問1・設問2で異なる管理項目が出題される。同一の海岸護岸消波工事の中で2管理を切り分ける組合せを示す。主となる3管理の組合せを優先して準備する。

**品質×工程**（主×主）
設問1で「消波ブロックの製作品質確保と据付精度管理（型枠全数計測・湿潤養生・丁張り管理）」、設問2で「潮位・波浪制約下での据付個数確保（施工可能時間試算・機械編成・週次照合）」を書く。

**安全×工程**（主×主）
設問1で「クレーン吊り荷の落下・海岸波浪時の水難防止（立入禁止・波高基準・ライフジャケット）」、設問2で「潮位・波浪制約下での工程確保（個数試算・体制整備・集中施工）」を書く。令和7年度の出題形式に近い。

**品質×安全**（主×主）
設問1で「消波ブロック製作品質・据付精度の確保」、設問2で「クレーン据付時の落下・水難防止」を書く。両者は同一工事で独立して成立する。

**品質×環境／安全×施工計画**（保険の組合せ）
出題範囲が広がった場合に備え、主の管理に施工計画・環境を組み合わせて書けるようにしておく。あくまで保険であり、まずは主3管理の組合せを固めることを優先する。
