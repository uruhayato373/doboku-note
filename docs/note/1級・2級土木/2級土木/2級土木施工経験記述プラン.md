### 著作権の扱い（最重要）

- 文字起こしは**市販本のスキャン**。記入例・本文の**逐語転載は禁止**。

- 記入例・解説は**運営者の 1級土木 実務経験に基づき独自表現で再構成**（civil-secondary-exam-writer / civil-textbook-rewriter と同じ「著者独自表現」原則）。

## Phase 2：note 有料マガジン（工種×テーマ 完成答案集）

**目的**: 直販収益。総監「模範論文」マガジンの土木版。

### 商品設計

- 原稿配置: `docs/note/2級土木/magazines/2級土木-施工経験記述-完成答案集/`（総監マガジンと同じ `_meta.yaml` / `hashtags.txt` / `_cover.png` / テーマ別サブフォルダ構造）。
- 記事構成（案）: **テーマ別 3 記事**（品質管理 / 工程管理 / 安全管理）、各記事に **3工種（土工・コンクリート・舗装）の完成答案**を収録 ＋ 工事概要の書き方 ＋ **R6新形式（条件提示型）答案** ＋ 環境保全。
- 各完成答案 = 試験字数規模の (1)(2)(3) フル答案 ＋ 「**自分の現場への置換ガイド**」 ＋ 「**採点者が減点する箇所**」。
- 価格帯: 単品 ¥1,980 / セット ¥2,480（総監踏襲、最終決定は公開時）。
- **紙/PDF 版**: `magazine-to-pdf` スキルで `scripts/pdf-specs/2級土木-施工経験記述-完成答案集.json` を作り A4 印刷版を同時納品（include/exclude DSL で CTA・採点者視点等を出し分け）。

### 失格リスク回避（施工経験記述 固有）

- 施工経験記述は「**自分が経験した工事**」が大前提。経験した工事でないと判明したら**失格**。
- よって商品は「コピペ用模範解答」ではなく「**改変前提のテンプレ＋型＋減点回避**」として打ち出す。各答案に置換ガイドを必ず併記し、丸写し量産→失格を構造的に抑止（1級改善例ページの注意書きと同思想）。

### サイト連携（magazine-placement 配線）

- `src/lib/note-magazines.ts` に新 `MagazineId` エントリ追加（`published: false` で着手、note 公開後に URL 投入＋ true）。
- `src/lib/magazine-placement.ts` に `civil-construction-2/secondary-*`（過去問年度 + experience-writing-guide/examples）→ 本マガジンの配置追加。
- `utmContentFor` の prefix strip に `civil-construction-2-` を追加（軽微なコード変更）。

### Phase 2 完了条件

- 原稿完成（U+FFFD ゼロ・逐語転載なし）。
- PDF spec で A4 版検証（A/B 答案両収録・除外 0 件・文字化け 0）。

## Red Line（本ライン恒久ルール）

1. **サイト＝型・チェックリスト / note＝工種別フル完成答案**。同じ文章を両方に置かない（Red Line #4/#5 の土木版）。
2. **市販本の逐語転載禁止**。様式・出題傾向・受検要件は事実として流用可、記入例・解説は運営者の実務経験で独自再構成。
3. **「模範解答」と打ち出さず「改変前提テンプレ」**として売る。各答案に置換ガイドを併記し丸写し→失格を抑止。
4. **サイト MDX 整備を止めて note を書かない**（総監 Red Line #2 を継承。サイトは永続 SEO 資産）。
5. 1級横展開は **2級の効果測定（オーガニック流入・note 販売）後**に判断。先回りで 1級まで作らない。
