## Context

書籍市場が年間 3,000〜4,000 人の総監受験者を相手に成立している事実から、note 有料販売のニーズは確実にある。運営者自身が 2026-07 受験中であるため、**勉強過程と試験本番の経験が一次コンテンツ化** できる構造を狙う。

ただし「合格前に解答のコツを有料販売する」のは **不合格時に信頼が崩壊するリスク** があるため、**段階投下** が必須。本書ではその段階と、各段階で「無料で出すもの」「有料で出して安全なもの」を記事単位で規定する。

---

## Red Line（絶対に守るルール）

以下は受験リスクと信頼リスクを同時に引き上げるため、合格発表まで禁止とする。

1. **合格前に「模範解答」「A評価狙いの論文」「採点基準の解説」を有料販売しない** — 不合格時に虚偽広告相当になる。ただし「業務立場別の論文構成例」「予想問題＋骨子」は OK
2. **勉強時間の 30% を超える note 執筆時間を割かない** — 本戦略の土台は合格そのもの
3. **note 執筆のためにサイトの MDX 整備を止めない** — note は sold out したら終わりだが doboku-note は SEO 資産として永続する。**サイト → note への変換** はあっても逆方向はない
4. **不合格時は有料販売を 2 週間以内に停止 or 再編** — 「合格体験」系は即時取り下げ、「不合格体験記」へリブランディング
5. **note と doboku-note に同じ技術解説を両方載せない（重複コンテンツ禁止）** — note のドメインパワーで短期的に検索上位を取れても、同一の技術解説を両方に置くと Google はほぼ確実に note 側を正として doboku-note を低評価化する。役割を明確に分離する — **note = 体験談・感情ストーリー・要約（消費完結型）**／**doboku-note = 体系的な技術解説（SEO 本体）**
6. **未合格者は独自データ分析を有料販売しない** — 自前模範論文や自前統計を「データ駆動」「機械分析」として有料商品化すると、(1) 分析対象が自分の作文であれば循環論証、(2) 不合格時に「分析の前提となる論文群の信頼性破綻」が露見、(3) 「未合格者がデータで語る権威性」自体が成立しない。**売れるのは「他者の経験」「公式情報の整理」「自分が書いた成果物そのもの（模範論文）」のみ**。サイト無料公開で「素材データ集約」として開示するのは可だが、戦略化・商品化しない（2026-05-18 M1「データ駆動戦略」撤回の根拠ルール）
7. **サイト = 思考フレーム、note = 具体数字 × ペルソナ展開** — サイトは抽象的な思考プロセス（ALARP / リスクベース判断 / ミティゲーション階層 / LCA 等の汎用フレーム）を扱い、note は具体的な数字（白書 R7 の予防保全 3 割縮減 / 特定技能 18.1 万人 等）と 3 ペルソナへのアレンジを扱う。両者の境界線を曖昧にすると Red Line #5（重複コンテンツ禁止）違反になる。サイト記事に白書の具体数字を入れすぎたら note 購入動機が弱まる、note マガジンに思考フレームの抽象論を入れすぎたらサイトと重複する、の双方向で違反検知（2026-05-18 mlit-whitepaper-2025 撤去の根拠ルール）
8. **予測コンテンツは 3 層分業 — サイト hub = テーマ俯瞰 / サイト spoke = 予想問題文 + 解答方向性 / note = ペルソナ別フル答案** — R8 予想問題のような「将来出題」コンテンツは、サイト無料 hub 記事で「どのテーマか」を俯瞰提示し、サイト無料 spoke 記事で「予想問題文 + 三層構造による解答の方向性（概要）」までを公開、note 有料マガジン M3 で「ペルソナ別フル模範解答（3,000 字×3）+ 採点ポイント + 完全骨子」を独占提供する 3 層構造を維持する。サイト spoke を作らずに hub だけで終わると読者は「テーマだけ知って終わり」になり M3 への動線が弱い、逆に spoke に模範解答まで載せると M3 価値毀損となる。両者を踏まえた 3 層分業が必須。**サイト spoke は固定 3 ペルソナ（ゼネコン / 河川コンサル / 自治体 道路担当）で全テーマを縦串展開する。テーマ別に最適業界を選ぶ動的ペルソナは試験本質（テーマ不明 → 自分のペルソナで全対応）を裏切るため禁止。3 ペルソナ外の業界（製造業・IT・エネルギー・商社・社会保障等）の受験者向けの業界外救済は spoke 末尾「業界外受験者へのアレンジ」段落で 1 行マッピングを示し、具体的なテンプレ展開は note M4「解答テンプレ 3D マトリクス」（¥2,980、300 セル）に分業する。詳細は [content-principles.md §21](../reference/content-principles.md) を参照**（2026-05-18 r8-essay-keyword-forecast 3 層化決定時に新設、2026-05-19 spoke 固定 4 ペルソナ化を追記、2026-05-21 環境調査ペルソナ廃止により固定 3 ペルソナへ）

## 検討して見送った収益化案

### note メンバーシップ（継続課金）— 検討・見送り（2026-05-21）

買い切りマガジンに代えて note メンバーシップで継続課金する案（R8 予想問題のメンバーシップ限定化／¥980 読み放題プラン／択一 ¥980・記述 ¥1,480 のサブスク階層）、およびサイトの択一式過去問解説をパスワードで囲いメンバーシップで鍵を配る案を検討し、いずれも見送った。

**見送り理由**:

1. **季節商材に継続課金が乗らない** — R8 予想問題の価値は 2026 年 7 月の試験日でゼロになる。会員は 5〜6 月入会・7 月解約で購読は最長 2〜3 ヶ月。継続課金のメリットが構造的に出ず、実質「期間限定の買い切り」にしかならない
2. **読み放題は複数買い客の単価を縮める** — ¥980/月の読み放題は、M3 + M4 + 模範論文と複数買いする最良客（客単価 ¥4,000〜7,000）を ¥980 × 2〜3 ヶ月に縮小させる。新規流入が 3 割増えても総額は約 2 割減と試算
3. **解約忘れは当て込めない** — 試験という鋭いイベントが全員に同時に解約トリガーを発火させ、note も毎月課金通知を送るため忘れが起きにくい。仮に取れても数千〜1.5 万円規模で、信頼毀損リスクに見合わない（Red Line #1・#4 の精神に反する）
4. **サイトのパスワードゲートは SEO エンジンを止める** — 過去問解説は無料公開だから SEO 流入を生み、AdSense・アフィリエイト・note 送客で換金されている。ゲートすると流入が崩落し収益チャネル #1（AdSense）ごと枯れる。加えて静的サイト（Cloudflare Pages / SSG）のクライアント側パスワードは技術的に鍵にならず、共通パスワードは狭い受験者コミュニティで即漏洩する

**過去問解説の換金は iOS アプリが担当** — 「過去問本文・解説は iOS 独占」（[04_収益化戦略.md](../project/01_戦略/04_収益化戦略.md) の Red Line 運用表）。サイトでは無料維持し SEO エンジンとして機能させ、換金は iOS アプリ買い切り ¥1,800（R01〜R06 が Premium）で行う。サイトの過去問解説文は運営者オリジナルのため、無料公開そのものに著作権上の懸念はない。

**将来の再検討条件** — メンバーシップ自体は否定しない。Phase R-3（2026 年 10 月末・筆記合格発表後）に、運営者が受験生でなくなり Red Line #2 の制約が外れた段階で、「合格者主宰の総監受験者コミュニティ」（白書月次更新・Q&A 等、更新で価値が出る中身）として再検討する。
