# 技術士 建設部門｜建設環境 R06 選択科目II-1 模範解答

## この記事でわかること

- 令和6年度 技術士第二次試験 建設部門 選択科目II-1（建設環境）の設問構成と論述方針
- 元公務員（発注者）視点の論述アプローチと3本柱

## 問題文について

本試験の問題文は日本技術士会公式サイトで公開されています。

II-1は4設問（II-1-1〜II-1-4）のうち1設問を選択し、答案用紙1枚にまとめる形式です。本記事ではII-1-4「歴史的な町並みの保全・活用」を選択し解答します。保全・活用の必要性を論じたうえで、関連法制度の概要と発注者が関わる具体的な実施内容を論述します。

## 設問構成と論述方針

### II-1-4. 歴史的な町並みの保全・活用の必要性と関連法制度

**求められていること**: 歴史的な町並みを保全・活用する必要性を論じ、関連法律または制度を1つ挙げてその概要を説明する

**発注者視点の核心論点**: 地方公共団体として歴史的建造物が立地する地域で道路・公園・排水等の公共工事を発注する際、景観・文化財への影響を回避するための事前調整と設計条件への反映が不可欠であり、その行政的管理責任を論述に盛り込む

**論述骨子（3本柱）**:
1. 保全・活用の必要性（地域アイデンティティの継承・観光資源化・防災面の課題解消）
2. 歴史的風致維持向上特別措置法（歴まち法）の概要
3. 法に基づく計画制度と発注者が担う公共事業との調整

### II-1-4（約540字）

**選択設問: II-1-4**

**（1）歴史的な町並みを保全・活用する必要性**

歴史的な町並みは、地域固有の歴史・文化・技術が凝縮した不可逆的資産であり、一度失われれば再現不可能である。保全・活用の必要性は3点ある。第一に、地域アイデンティティの継承であり、祭礼・伝統産業と一体の景観維持で次世代への文化的継承が図られる。第二に、観光・地域振興への寄与であり、歴史的環境は地域ブランドとして交流人口の拡大に直結する。第三に、防災との両立であり、老朽化建造物の耐震補強・防火対策を保全と並行させることで居住環境の安全性も確保できる。

**（2）歴史的風致維持向上特別措置法（歴まち法）の概要と活用**

平成20年施行の歴まち法は、市町村が歴史的風致維持向上計画を策定し、国土交通・農林水産・文部科学の三大臣の認定を受けることで国・都道府県から支援を受けられる制度である。認定計画では重点区域を設定し、伝統的建造物の修理・修景補助、電柱地中化・石畳舗装等の景観整備、歴史的建物の活用支援を一体的に推進する。公共工事発注者は重点区域内での道路改良・排水整備において色彩・素材・線形を計画と整合させた設計条件を設定し、着工前の景観担当協議を義務付けることで景観保全と事業執行の両立を図る。

## 元公務員（発注者）からのコメント

元公務員として発注者の立場から建設環境工事の発注・監督に携わった実務経験から書いた解答例です。

実際の発注者業務では、歴史的街並みが残る地区での道路改良・側溝整備において、歴まち法の重点区域内では着工前に文化財・景観担当部局との協議が必須でした。舗装の色・縁石の素材・電柱の扱いまで「景観整合設計」として仕様書に盛り込み、施工中の変更が生じた場合も必ず協議を経てから設計変更するという手順が徹底されていました。受験者がこの設問で陥りやすい失敗は「保全の必要性」を精神論で書いてしまうことです。法制度の具体名・計画認定スキーム・支援措置を盛り込むことで得点に直結します。
