# 技術士 建設部門｜河川・砂防及び海岸・海洋 R04 選択科目II-1 模範解答

## この記事でわかること

- 令和4年度 技術士第二次試験 建設部門 選択科目II-1（河川、砂防及び海岸・海洋）の設問構成と論述方針
- 河川・砂防合格者（発注者）視点の論述アプローチと3本柱
- フル模範解答（約540字）

## 問題文について

本試験の問題文は日本技術士会公式サイトで公開されています。

II-1 は4設問（II-1-1〜II-1-4）から1設問を選択し、答案用紙1枚にまとめる形式です。本記事では **II-1-3** を選択します。土砂災害における流木の被害への影響を論じ、移動形態の違いに基づく砂防基本計画の施設計画について述べる問題です。

## 設問構成と論述方針

### II-1-3. 流木の影響と砂防施設計画

**求められていること**: 土砂災害における流木の被害・復旧への影響を説明し、土石流区間・掃流区間の移動形態の違いを踏まえた流木捕捉施設計画の概要と留意点を論述すること

**発注者視点の核心論点**: 施設配置計画の査定段階で「区間特性に応じた捕捉効率の根拠」を求める発注者の審査視点と、維持管理費（流木の撤去・運搬コスト）の積算根拠を確保する重要性

**論述骨子（3本柱）**:
1. 流木の被害・復旧への影響（橋梁閉塞・復旧障害の二重性）
2. 移動形態の区間別特性（土石流区間は一体移動、掃流区間は個別流下）
3. 施設計画の概要と留意点（区間別の捕捉工設置、天端高・開口部・土砂通過性の確保）

### II-1-3（約540字）

**1. 流木が被害の発生や復旧に及ぼす影響**

流木は被害拡大と復旧困難の二面で影響する。被害面では、橋梁・函渠への流木閉塞が背水氾濫を引き起こし、土石流に混入した流木は破壊力を増幅して家屋被害を拡大する。復旧面では、堆積土砂に絡み合った流木の除去・分別処理が重機作業を妨げ、工期延長とコスト増大をもたらす。

**2. 移動形態の区間別特性**

土石流区間では流木が土砂・礫と一体となって高速流下し、巨大な破壊エネルギーを持つ。掃流区間では勾配低下に伴い土砂と分離し、個々の流木が水流で個別流下するため、分散した状態で下流に到達する。

**3. 砂防基本計画における施設計画の概要と留意点**

土石流区間には、土砂と流木を一体捕捉できるスリット砂防えん堤を配置する。開口部幅は想定最大流木径を考慮して設定し、土砂通過性と流木捕捉を両立させる。掃流区間では流木止工を設置し、流域立木量調査に基づく貯留容量を確保する。留意点として、流木貯留容量は立木量調査結果を根拠に算定し、維持管理での定期的な流木撤去の作業性と費用を設計段階から積算することが不可欠である。スリット開口部は施工後の観測データで逐次検証し、捕捉効率の継続確認体制を整備する。

## 採点者が見るポイント

| チェック項目 | この解答での対応 |
|---|---|
| 課題の本質を把握しているか | 流木の「被害拡大」と「復旧困難」の二面性を明確に区分して論述 |
| 技術的解決策が論理的か | 区間特性（土石流・掃流）の違いに応じて施設種別を選択し根拠を明示 |
| リスク・課題が盛り込まれているか | 流木撤去の維持管理費積算・施工後の検証体制を留意点として記述 |
| 専門知識の深さが示されているか | スリット砂防えん堤・開口部寸法・流木止工・流木貯留容量の具体的記述 |

## 河川・砂防合格者からのコメント

この科目の合格者として申し上げると、II-1-3 の流木問題は「移動形態の違い」を正確に区分できるかどうかが得点の分岐点です。土石流区間と掃流区間を混同した解答は、設問の核心を外したと判定されやすい。

実際の発注者業務では、砂防えん堤の設計査定において「なぜスリット形式を選択したか」「開口部寸法の根拠となる流木径はどこから来るか」を受注コンサルに詳細説明させてきました。立木量調査の精度が施設規模の妥当性に直結するため、計画段階での現地踏査結果の記録管理が不可欠です。この発注者審査の視点を答案に盛り込むことで、「技術士としての総合判断力」を採点者に示すことができます。
