# 技術士 建設部門｜鋼構造及びコンクリート R05 選択科目II-2 模範解答

## この記事でわかること

- 令和5年度 技術士第二次試験 建設部門 選択科目II-2（鋼構造及びコンクリート）の設問構成と論述方針
- 元公務員（発注者）視点の論述アプローチと3本柱
- フル模範解答（約1080字）

## 問題文について

本試験の問題文は日本技術士会公式サイトで公開されています。

II-2は2設問（II-2-1、II-2-2）のうち1設問を選択し、答案用紙2枚以内で解答する形式です。本記事ではII-2-2を選択して解答します。設問は、老朽化した地上構造物の健全性評価において、接近・目視が困難な点検困難部（狭隘部・密閉部・不可視部）の損傷程度を推定する業務について、調査・検討計画の立案から関係者調整まで担当責任者の立場で論述することを求めています。

## 設問構成と論述方針

### II-2-2. 老朽化地上構造物の健全性評価（点検困難部の損傷推定）

**求められていること**: 点検困難部の具体事例と想定損傷を設定し、損傷程度の推定から健全性評価に至る調査・業務手順・関係者調整を担当責任者として論述すること。

**発注者視点の核心論点**: 道路・橋梁管理者（発注者）として老朽化構造物の維持管理委託を行う際、点検困難部の調査手法の妥当性確認・調査費用の根拠審査・構造物の供用継続判断が発注者の行政責任であり、この視点を業務手順と関係者調整に盛り込むことが差別化軸となる。

**論述骨子（3本柱）**:
1. 点検困難部の事例設定と調査・検討事項：RC床版と鋼主桁の接合部（不可視部）を事例に、非破壊検査と解析による損傷推定方法を整理する
2. 業務手順と留意点：予備調査から詳細調査・健全性評価・報告書作成までの段階的手順と各段階の工夫
3. 関係者調整方策：道路管理者・点検業者・施工者・住民との調整と情報共有方法

### II-2-2（約1060字）

**1. 点検困難部の具体事例と調査・検討すべき事項**

対象構造物は供用40年を経過した道路橋（RC床版＋鋼合成I桁橋、支間22m）とし、点検困難部として3事例を設定する。

第一に、主桁上フランジとRC床版の接合部（不可視部）である。床版コンクリートに覆われているため目視不能であり、疲労き裂・ずれ止めジベルの損傷・鋼材腐食が想定損傷となる。赤外線サーモグラフィによる剥離・空洞探査と電磁波レーダ法による鉄筋腐食位置推定を組み合わせて損傷範囲をマッピングする。

第二に、鋼主桁フランジとウェブの交差隅角部（狭隘部）である。桁端部に近い隅角部は接近が困難であり、疲労き裂・溶接部割れが想定損傷として重要である。超音波探傷試験（UT）の自動走査装置と磁粉探傷試験（MT）を適用し、き裂深さを計測する。

第三に、桁端部伸縮継手装置の遮水構造（密閉部）である。漏水による塩化物イオンの浸透が鋼桁端部の腐食断面減少を引き起こすリスクがある。超音波肉厚計で残存板厚を測定し、断面欠損率から耐荷力低下量を推定する。

各調査結果は道路橋定期点検要領の損傷程度区分（eⅠ〜eⅢ）に照合し、解析モデルを更新して現行基準との乖離を定量評価する。

**2. 業務手順と留意点・工夫**

（手順1）文献調査・予備検討：竣工図・既往点検記録・補修履歴を収集して損傷集中箇所を事前絞り込み、疲労蓄積量の概算により詳細調査の優先順位を設定する。

（手順2）非破壊調査：各機器の適用限界（深度・分解能・誤報率）を事前確認し調査手法の組合せを決定する。調査は夜間帯・軽交通時に集中させてインフラ利用者への影響を最小化する。調査データはBIM/CIMに取り込んで損傷マップを可視化する。

（手順3）解析・健全性評価：損傷状況を反映した有限要素解析モデルを作成し、活荷重・疲労荷重に対する安全余裕を定量化する。eⅢ（緊急対応）該当部材が検出された場合は速やかに道路管理者へ報告し、通行規制の要否を協議する手順を明確化する。

（手順4）報告書作成：技術的根拠・補修優先順位・概算費用を体系的に整理し、発注者の補修計画決定に活用できる形式で提出する。

**3. 関係者との調整方策**

道路管理者（発注者）とは業務着手時に調査範囲・手法・工程を書面確認し、中間報告の機会を設けて予算対応を事前に検討できる環境を整える。学識経験者・第三者機関との技術協議を経て損傷推定の妥当性を客観的に担保することで、発注者の意思決定を支援する。点検業者とは調査精度の品質基準を仕様書に明示してデータ品質を現場段階で管理し、近隣住民へは夜間規制を事前周知して地域との信頼関係を維持する。

## 採点者が見るポイント

| チェック項目 | この解答での対応 |
|---|---|
| 課題の本質を把握しているか | 点検困難部を3類型（不可視部・狭隘部・密閉部）に分類し、それぞれに適した非破壊検査手法を対応させて論述 |
| 技術的解決策が論理的か | 赤外線サーモグラフィ・電磁波レーダ・UT・MTの手法と適用根拠を具体的に示し、損傷評価基準（点検要領の損傷程度区分）まで言及 |
| リスク・課題が盛り込まれているか | eⅢ該当時の緊急報告手順・交通規制・調査機器の適用限界を業務手順に組み込み |
| 関係者調整が具体的か | 道路管理者・学識経験者・点検業者・住民の4者それぞれに対して調整内容を個別に記述 |

## 元公務員（発注者）からのコメント

元公務員として鋼構造及びコンクリート工事の発注・監督に携わった実務経験から書いた解答例です。

実際の橋梁維持管理業務では、点検困難部の調査を委託する際に技術仕様書の精度が成果品の質を直接左右する。非破壊検査手法の選定理由・適用限界・品質基準を仕様書に明記しなければ、業者まかせになり損傷の見落としリスクが高まる。設問3の関係者調整で「発注者への中間報告」を明示することは、補修優先度決定の意思決定支援として発注者側から最も評価される論述軸である。eⅢ判定時の即報義務も行政実務上の実態を反映した記述であり、採点者が実務感覚を持つ場合に高く評価される。
