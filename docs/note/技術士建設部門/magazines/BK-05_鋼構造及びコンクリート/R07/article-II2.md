# 技術士 建設部門｜鋼構造及びコンクリート R07 選択科目II-2 模範解答

## この記事でわかること

- R07年度 技術士第二次試験 建設部門 選択科目II-2（鋼構造及びコンクリート）の設問構成と論述方針
- 元公務員（発注者）視点の論述アプローチと3本柱
- フル模範解答（約1,060字）

## 問題文について

本試験の問題文は日本技術士会公式サイトで公開されています。

選択科目II-2は2設問（II-2-1・II-2-2）から1問選択し、答案用紙2枚以内で記述する形式です。II-2-1は「鋼構造物・コンクリート構造物の耐久性確保」、II-2-2は「大規模地震損傷構造物の恒久復旧計画」を題材とした業務遂行能力を問う設問です。

## 設問構成と論述方針

### II-2-1. 耐久性確保を担当する技術者としての業務遂行

**求められていること**: 特定の構造物を設定し、耐久性確保のための調査・検討事項、業務手順と留意点、関係者との調整方策を体系的に論じる能力

**発注者視点の核心論点**: 発注者は設計段階で耐久性要求水準を設定し、施工監理では品質検査・記録管理により仕様適合を確認する。維持管理段階の点検計画策定まで含めた総合的耐久性管理が発注者責務である。

**論述骨子（3本柱）**:
1. 対象構造物（塩害環境下の既設RC橋梁）と耐久性確保のための調査・検討事項
2. 業務手順：現状調査→劣化診断→補修設計→施工→竣工検査の各段階の留意点と工夫
3. 発注者・設計者・施工者・維持管理担当部署との調整方策

### II-2-1（約1,060字）

**1. 対象構造物・条件設定と調査・検討すべき事項**

対象構造物は、沿岸部に位置する供用後30年の既設RC橋梁（上部工：T桁橋）とする。飛来塩分と橋面排水機能の経年低下が重なり、桁端部・支承廻り・橋脚頭部で塩害による鉄筋腐食が顕在化している。点検記録では断面欠損および著しいひび割れが確認されており、残余供用期間30年を確保するには基準類の最低仕様に加えて更なる耐久性検討が必要である。

調査・検討すべき事項は以下のとおりである。第一に、目視・打音・コア採取による中性化深さおよび塩化物イオン浸透深度の実測を行い、劣化グレードと残存断面性能を定量評価する。第二に、飛来塩分量の実測データを用いた塩化物イオン浸透解析を実施し、無対策時の腐食拡大速度を予測する。第三に、断面修復・表面保護・電気防食等の工法を比較し、LCCおよび施工制約（交通規制・床下作業空間）を考慮したうえで最適工法を選定する。

**2. 業務手順と各段階の留意点・工夫**

手順1「詳細調査・診断」: 交通規制を最小化するため夜間・休日に調査を集中させる。コア採取位置は代表性を確保しつつ構造的影響を回避する箇所とし、採取後は速やかに補修して供用性を維持する。

手順2「補修設計」: 劣化グレードに応じた補修範囲区分けを行い、将来の再劣化リスクを踏まえた断面修復材の選定基準を設計図書に明記する。留意点として、補修後の部材剛性変化が支承・伸縮装置に与える影響を確認し、必要に応じて関連部材の調整設計を同時に行う。

手順3「施工段階の品質管理」: 鉄筋防錆処理の塗布量・均一性を第三者検査で確認し、断面修復材の養生温度・湿潤期間を記録する。表面保護材は乾燥条件・塗重ね間隔を厳守し、膜厚管理記録を書面保存する。施工検査と記録の完結性を監理上の最重要事項と位置付ける。

手順4「竣工検査・維持管理計画策定」: 電位差測定等の非破壊検査で補修効果を初期確認する。補修後10年の点検計画（頻度・手法・着目部位）を維持管理計画書にとりまとめ、次期担当者への申し送り事項として記録する。

**3. 関係者との調整方策**

設計者とは業務着手前に劣化診断結果の解釈基準と補修仕様の合意水準を共有し、設計変更時の意思決定フローを明確化する。施工者とは騒音・粉塵対策を事前協議し、工程変更時の速報ルートを定める。道路管理部門（維持管理担当）とは竣工後の点検計画を共同策定し、補修工法の技術的根拠を引き継ぎ維持管理継続性を確保する。施工中の通行規制については所轄警察・道路利用者代表に事前説明を行い、地域の理解を得てから着工する。

## 採点者が見るポイント

| チェック項目 | この解答での対応 |
|---|---|
| 課題の本質を把握しているか | 塩害環境という具体条件と残余供用年数から耐久性確保の必要性を論理的に設定 |
| 技術的解決策が論理的か | 調査→予測→工法選定→施工管理→維持管理計画という連続的な業務フローで展開 |
| リスク・課題が盛り込まれているか | 供用中施工の制約（交通規制・夜間作業）、補修後の剛性変化リスク、記録継続性を明示 |
| 関係者調整が具体的か | 設計者・施工者・維持管理部門・警察・住民と相手別に調整内容を明確化 |

## 元公務員（発注者）からのコメント

発注者として鋼構造及びコンクリート工事の発注・監督に携わった経験から述べると、塩害劣化橋梁の補修業務では「調査→設計→施工」の各段階で意思決定の分岐が多く、発注者が判断基準を明確に設定していないと工期・費用・品質のいずれかが犠牲になる事態が生じやすい。実務では補修設計の中間確認会議で劣化グレードの解釈差異が顕在化するケースが多く、設計着手前に評価基準を合意することが後工程の混乱を防ぐうえで最も効果的であった。また竣工後の記録整備は維持管理部門への確実な技術引き継ぎに直結するため、書面管理の徹底を発注条件として契約に明記した。
