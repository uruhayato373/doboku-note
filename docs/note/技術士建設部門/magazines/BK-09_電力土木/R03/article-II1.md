# 技術士 建設部門｜電力土木 R03 選択科目II-1 模範解答

## この記事でわかること

- 令和3年度 技術士第二次試験 建設部門 選択科目II-1（電力土木）の設問構成と論述方針
- 元公務員（発注者）視点の論述アプローチと3本柱
- フル模範解答（約540字）

## 問題文について

本試験の問題文は日本技術士会公式サイトで公開されています。

選択科目II-1は4設問（II-1-1〜II-1-4）から1設問を選択する形式です。本記事では**II-1-4**（着床式洋上風力発電機の基礎構造形式と安全性評価）を選択して解答します。再生可能エネルギー主力電源化の政策潮流を背景に、設計段階の安全性照査という技術的核心を問う設問です。

## 設問構成と論述方針

### II-1-4. 着床式洋上風力発電機の基礎構造形式と安全性評価

**求められていること**: 代表的な基礎構造形式を1つ選定し特徴を述べたうえで、設計における安全性評価の観点から照査すべき事項を3つ以上示すこと

**発注者視点の核心論点**: 発注者として設計図書を審査する際、安全性照査項目が基礎形式の特性に対応して網羅されているか確認する視点が差別化軸となる

**論述骨子（3本柱）**:
1. モノパイル基礎の構造特性（断面・支持機構・適用水深の限界）
2. 波浪・風荷重・地震力に対する応力照査（疲労破壊を含む）
3. 洗掘・腐食・液状化リスクに対する地盤・耐久性照査

### II-1-4（約540字）

**選定構造形式: モノパイル基礎**

モノパイル基礎は直径4〜10m程度の大径鋼管杭を海底地盤に打設しタワーを直接支持する構造で、施工の単純さと工期短縮の観点から水深30m以浅の砂質地盤を中心に最も普及している。水深増加とともに杭径・板厚が増大するため座屈と疲労への配慮が不可欠となる。

**安全性評価の照査事項**

第一は**複合外力に対する部材応力照査**である。波浪・風・潮流・地震の各荷重組合せを網羅し、杭頭部の曲げモーメントとせん断力が許容値以下であることを確認する。特に50年再現期待値の極端荷重下での塑性変形の有無を照査する。

第二は**疲労破壊に対する累積損傷評価**である。定常運転中の繰返し荷重に対し、S-N曲線を用いた疲労寿命計算で供用25〜30年間の損傷度が1.0を超えないことを確認する。溶接継手部は応力集中係数を考慮して評価する。

第三は**洗掘・液状化・腐食に対する耐久性照査**である。海底砂の洗掘は支持力低下と固有振動数変化を招くため洗掘深を設計に織り込む。加えて液状化ポテンシャルの評価と防食被覆厚が耐用年数を確保するかを確認する。

設計審査の実務では、上記3項目の根拠条件（荷重値・安全率・腐食速度）の妥当性確認が品質確保の要諦となる。

## 採点者が見るポイント

| チェック項目 | この解答での対応 |
|---|---|
| 課題の本質を把握しているか | モノパイル基礎特有の構造課題（水深増大・疲労・洗掘）を明示 |
| 技術的解決策が論理的か | 応力照査・疲労評価・耐久性照査の3区分で体系化 |
| リスク・課題が盛り込まれているか | 疲労破壊・洗掘・液状化・腐食の4リスクを具体的に言及 |

## 元公務員（発注者）からのコメント

元公務員として電力土木工事の発注・監督に携わった実務経験から述べると、着床式洋上風力の基礎設計審査では「荷重組合せの網羅性」と「疲労評価の前提条件設定」が最も確認を要する箇所です。特に設計耐用年数25〜30年に対し腐食余裕をどのように算定しているかは、発注者として設計変更コストに直結する判断ポイントとなります。受験生の方は、単なる知識列挙にとどまらず照査の「なぜ」を論述に盛り込むことで答案の説得力が増します。
