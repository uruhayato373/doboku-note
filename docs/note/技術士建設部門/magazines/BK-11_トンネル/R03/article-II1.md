# 技術士 建設部門｜トンネル R03 選択科目II-1 模範解答

- 元公務員（発注者）視点の論述アプローチと3本柱

## 問題文について

本試験の問題文は日本技術士会公式サイトで公開されています。

II-1はII-1-1〜II-1-4の4設問から1設問を選択し、答案用紙1枚にまとめる形式です。本記事ではII-1-2（ロックボルトの性能・効果）を選択して模範解答を示します。

## 設問構成と論述方針

### II-1-2. ロックボルトの性能と効果

**求められていること**: ロックボルトの性能をその内容とともに示したうえで、効果が期待される地山条件を明示しながら効果を3つ以上述べること。

**発注者視点の核心論点**: 発注者として施工計画の審査時にロックボルトの配置・引抜き試験の品質確認を行う立場から、性能メカニズムを正確に把握し、地山条件に応じた適切な選定を監理する視点を盛り込む。

**論述骨子（3本柱）**:
1. ロックボルトの主要性能（補強・縫い付け・吊り下げ・内圧効果）
2. 地山条件別の期待効果その1・その2（緩み地山・塑性地山）
3. 地山条件別の期待効果その3（節理卓越地山）と発注者視点の品質確認

### II-1-2（約540字）

**ロックボルトの性能**

ロックボルトは地山内に挿入・定着される棒状の補強材で以下の性能を有する。補強効果とは引張力で地山を拘束し見かけの強度・剛性を高める性能である。縫い付け効果とは不連続面を跨いで打設し剪断変位に抵抗する性能である。吊り下げ効果は崩落しやすい岩塊を安定岩盤に固定する機能である。

**効果と地山条件**

（1）緩み土圧低減効果――風化岩盤や亀裂が卓越した裂かい性地山では掘削による応力解放で地山が緩みやすい。ロックボルトを放射状に打設することで緩み域の拡大を抑制し吹付けコンクリートへの緩み土圧を低減する効果が期待できる。

（2）塑性域抑制効果――土被りが大きく側圧の高い軟岩など塑性的挙動を示す地山では、掘削後に塑性域が拡大し変位が増大する。補強効果により見かけの粘着力・内部摩擦角を高め塑性域の進展を抑制する効果が期待できる。発注者の立場では、引抜き試験で定着力を確認させ品質管理を監理することが重要となる。

（3）剪断補強効果――層理面・断層・節理が卓越し掘削断面に対して不利な走向・傾斜をもつ岩盤では不連続面に沿った滑落が生じやすい。ロックボルトが不連続面を横断して打設されることで縫い付け効果が発揮され剪断変位を拘束して崩落を防止する効果が期待できる。

## 採点者が見るポイント

| チェック項目 | この解答での対応 |

| 課題の本質を把握しているか | ロックボルトの各性能（補強・縫い付け・吊り下げ）を定義・内容とともに明示 |

## 元公務員（発注者）からのコメント

元公務員として発注者の立場でトンネル工事の発注・監督に携わった経験から書いた解答例です。

実際の発注者業務では、山岳トンネルの施工管理においてロックボルトの定着長・配置密度・引抜き試験結果を設計図書と照合する検査業務が日常的に発生します。地山が設計段階の想定と異なる場合の設計変更判断では、補助工法の追加・ロックボルト本数の増減を受注者と協議するため、各効果のメカニズムを正確に理解しておくことが発注者側の技術力として求められます。
