## 差別化ポジション：「元公務員（発注者）が書いた模範解答」

### なぜ元公務員ポジションが決定的な差別化になるか

建設部門 2次試験の受験層（建設コンサル・ゼネコン・自治体技術職）の多くは「受注者側」の論述に偏りがちで、**発注者視点の採点軸**（安全・環境・コスト・品質の統合管理、住民対応、委託監督の責任）が弱い。

元公務員（発注者）として全11分野の工事を発注・監督してきた視点は、民間技術者が最も欠きやすい論述軸を補完できる。これが「元公務員が書いた模範解答」の本質的な価値。

### 運営者の具体的な根拠

- **元・地方自治体の土木職（発注者）** として工事発注・監督・積算審査に長年従事
- **道路・河川・都市計画の3科目で建設部門合格済み** → この3科目は合格論文の構成を直接再現できる
- 残8科目も発注者として工事に関わってきた実務経験が論述の信頼性を担保する
- 技術士（総合技術監理部門）合格済み → 5管理横断の視点が全分野の論述に反映される

### 各商品の訴求フレーミング

**全商品共通の軸**: 「元・地方自治体の土木職（発注者）として○○工事の発注・監督を担ってきた経験から書いた模範解答」

合格3科目（道路・河川・都市計画）には「合格者が書いた」を追加する。残8科目は「元公務員として関与してきた実務経験から書いた」とし、合格資格の有無は明記しない（発注者実務の事実は全科目で真実）。

## 商品ラインナップ

### 価格：コンテンツ量で段階化（2026-06-09 改訂・旧「¥1,980統一」を撤回）

> **改訂理由**: 旧「全商品¥1,980統一」は分量を無視した安売りだった。特に道路（BK-01）は **35本のフル模範解答で¥1,980＝1本¥57** と過小。建設部門 2次の受験層は現役エンジニア（多くは会社費用・資格手当あり）で支払い意思が高く、競合の通信講座は ¥30,000〜100,000+。受験料も令和8年から ¥20,500（32年ぶり値上げ）。これらを踏まえ、分量に応じた段階価格へ改める。

**単品（5年分セット）**

| 区分 | 価格 | 根拠 |
|---|---|---|
| 必須科目Ⅰ（BK-I） | **¥2,480** | 全受験者必須・最重要。R8予想も追加予定 |
| 選択科目 標準（BK-02〜11） | **¥3,480** | II-1複数＋II-2＋III＝必須Ⅰの3〜4倍の分量 |
| 道路（BK-01・35本特盛） | **¥3,980** | II-1を4問個別収録の最大ボリューム |

旧¥1,980統一からの値上げ。ブランド軸「元公務員（発注者）が書いた模範解答」は据え置き、価格だけ分量整合へ。

> **価格ラダー最終評価（2026-06-11）**: 上記の段階価格（BK-I ¥2,480 / 標準 ¥3,480 / 道路 ¥3,980 / 科目パック ¥4,980 ローンチ → ¥5,980 → ¥6,980）を**最終確定として維持する**。根拠: (1) 建設部門の受験層は現役エンジニアで会社費用・資格手当の補助が利き、WTP は総監の個人負担層より構造的に高い — 総監単品（¥1,980〜2,480）より一段強気の ¥2,480〜3,980 は整合的。(2) 競合アンカーが二重に効く: 受験料 ¥20,500（令和8年〜）に対しパック ¥4,980 は約1/4、通信講座 ¥30,000〜100,000+ に対し1/6〜1/20。アンカーとの距離が十分にあり、値頃感を保ったまま段階値上げの余地（¥6,980 でも受験料の1/3）を残せる。(3) バンドル成立条件（パック ¥4,980 ＜ 単品合計 ¥5,960〜6,460）を満たし、割引率 16〜23% は「束ねの礼儀」程度に抑えて単品の価格信頼を毀損しない。(4) 値上げは検証ゲート（2ヶ月10部）クリアを条件とし、実売の証拠なしに先行値上げしない — プリローンチ市場で価格の正解は売って初めて分かるため。

### LP 訴求コピー（2026-06-11 確定）

**BK-I 必須科目Ⅰ模範解答集 ¥2,480 — 全受験者向け**

> 必須科目Ⅰは、建設部門の全受験者 約1.8万人が必ず解く科目でありながら、市販の教材はキーワード集と書き方論に偏り、「完成答案を5年分読む」機会がほとんどありません。本マガジンは、令和3〜7年度の5年分について、設問分解から論述骨子、1,800字のフル模範解答までを収録。執筆者は元・地方自治体の土木職（発注者）として工事の発注・監督・積算審査に携わり、道路・河川・都市計画の3科目で建設部門に合格しています。受注者側の受験者が見落としやすい発注者視点（住民対応・法令遵守・総合調整）の論述軸を、各解答にコメントとして付しました。再受験すれば受験料は¥20,500。その約8分の1で、全受験者共通の最重要科目の完成答案が手に入ります。

**科目別 合格パック ¥4,980 — 「必須Ⅰ＋選択科目まるごと」**

> 建設部門の答案は「必須Ⅰ＋選択科目」の組み合わせがすべてです。本パックは、あなたが本番で実際に解くその組み合わせを、そのまま束ねました。必須科目Ⅰ模範解答集（5年分）に、あなたの選択科目の模範解答集（II-1・II-2・III の5年分）を加えた2マガジン構成。単品合計¥5,960〜6,460が¥4,980です。落ちてもう一度払う受験料は¥20,500、通信講座なら¥30,000から。その数分の1で、あなたの科目の過去問5年分フル模範解答が、元公務員（発注者）の採点視点コメントつきでそろいます。書き方を教える教材は世にあふれていますが、「自分の科目の完成答案を5年分通読する」体験は、ここでしか手に入りません。

**BK-01 道路 選択科目 模範解答集 ¥3,980 — 合格者視点の最強商品**

> 道路科目の模範解答集として最大級の35本収録。II-1は4問すべてを個別に解答し、II-2・IIIも令和3〜7年度の5年分をフル答案で収めました。執筆者は道路科目の合格者です。さらに、元・地方自治体の道路担当（発注者）として、舗装・橋梁・交差点改良・維持管理の工事発注・監督を長年担ってきました。合格答案の構成を知る「受験者の眼」と、工事を審査してきた「発注者の眼」の両方から、各解答に論述のポイントを付しています。道路は建設部門で最大級の受験者を抱える科目。差がつくのは専門知識の量ではなく、出題者（発注者側）の問題意識に正面から応える論述です。¥3,980は1本あたり約¥114、通信講座の添削1回分にも満たない投資です。

## 制作パイプライン

### 全科目共通（エージェント分業）

```
[pe-construction/ 問題文MDX（既存）]
    ↓ 建設部門2次向けエージェント（初稿生成）
        入力: 問題文 + 専門分野 + 科目種別（I/II-1/II-2/III）+ 元公務員視点の採点軸
[初稿：設問分解 + 論述骨子 + フル解答（発注者視点のコメント付き）]
    ↓ 運営者レビュー（実務妥当性・論述構成・合格者感覚で精度確認）
[完成稿：元公務員視点の解説コメント付き]
    ↓ note格納（マガジン記事形式）
```

### 建設部門2次向けエージェントの設計方針

- 既存 `civil-secondary-exam-writer`（1級土木2次向け）の設計を参考に別エージェントとして新設
- 入力: 問題文MDX + 専門分野 + 科目種別（I / II-1 / II-2 / III）+ 発注者採点視点
- 出力: 設問分解 → 論述骨子 → フル解答（各科目の所定答案枚数に対応）
- **元公務員（発注者）視点の論述軸を全科目共通で組み込む**: 安全管理・品質確保・住民対応・法令遵守・総合調整の視点
- pe-construction/ の既存MDXをそのまま入力に使えるパイプラインを構築

## Red Line（絶対に守るルール）

1. **訴求の誠実さを保つ** — 合格3科目は「合格者が書いた」を明記。その他は「元公務員として発注・監督に携わった実務経験から書いた」とする。合格スコープ外を「合格者解答」と偽らない
2. **サイトの問題文をnoteに転載しない** — pe-construction/ の問題文MDXはサイト側資産。note記事には「設問文は日本技術士会の公式サイト参照」と誘導
3. **総監商品との混合販売は避ける** — 総監受験者と建設部門受験者は重複するが、別ファネルとして設計。バンドルは試験シーズン終盤に限定検討
4. **サイトのSEO資産を止めない** — note執筆がサイトのpe-construction/ 整備（模範解答・visible:true化）を圧迫しない
