# 【建設部門もくじ】技術士 第二次試験 建設部門 模範解答 総合案内

技術士 第二次試験 建設部門の対策コンテンツを1ページで探せるもくじです。ブックマーク推奨（更新のたびに追記します）。

書いているのは、地方自治体の土木職（発注者側）として勤務し退職、技術士（建設部門・総合技術監理部門）ほかを保有する者です。建設部門の模範解答集は、**必須科目Iと各選択科目について、その区分で出題された全選択肢の解答を網羅収録**しています。合格科目（道路・河川・都市計画）は「合格者が書いた」解答、それ以外は「元公務員（発注者）が監修した」解答という位置づけです。

> 他資格（総監・1級/2級土木 ほか）も含めた全体の入口は、[doboku-note 総合案内](https://note.com/dobokunote/n/n296a88f64ac2)からどうぞ。
