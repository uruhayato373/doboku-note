# 1級土木 施工経験記述｜令和8年度 予想 2テーマ組合せ（品質管理＋安全管理）

**こんな人のための記事です**

- 1級土木施工管理技士 第2次検定 問題1（施工経験記述）の令和8年度の出題テーマ組合せを予想して準備したい
- 令和6年度（安全×施工計画）・令和7年度（品質×環境）の次に来る2テーマ必答の組合せを先回りして対策したい
- 同一工事で「品質管理」と「安全管理」をどう書き分けるか、完成した文章で確認したい

**この記事でわかること**

- 令和8年度の出題予想とその根拠（過去の出題サイクルからの読み）

施工経験記述は「自分が経験した工事」を書く問題であり、経験していない工事を書いたことが判明すると失格となる。本記事の記述例はそのまま書き写すためのものではなく、**構成・表現・具体性の水準を確認し、自分の現場に置き換えるための雛形**である。数値の `〇〇` は自分の現場の値に必ず差し替える。予想は過去の出題傾向からの推定であり、的中を保証するものではない。

## 出題予想の根拠

令和6年度の検定見直しで、問題1は「1つの工事で2つの管理テーマを必答」する形式に変わった。これまでの組合せは次のとおりである。

- **令和6年度**：安全管理 → 施工計画
- **令和7年度**：品質管理 → 環境対策

ここから読み取れる傾向は次の3点である。第一に、設問1には**品質管理・安全管理という現場管理の中核テーマ**が据えられている。第二に、設問2には**施工計画・環境対策という、計画段階や周辺配慮に関わるテーマ**が組み合わされてきた。第三に、2年連続で**同じ組合せは出ていない**。

この傾向を踏まえると、令和8年度は「中核テーマ同士を組み合わせる」方向、すなわち **品質管理 ＋ 安全管理**が有力な候補となる。品質と安全はいずれも旧形式（令和5年度以前）で頻出だった2大テーマであり、現行の2テーマ必答形式でまだ組み合わされていない。同一工事で品質と安全を**評価軸の異なる論点に切り分けて書けるか**が問われる組合せであり、受検者の準備の盲点になりやすい。

なお、これはあくまで過去の出題サイクルからの推定である。実際には施工計画や工程管理が再登場する可能性もあるため、本マガジンの他テーマや完成答案集（5管理）とあわせ、どの2テーマが来ても対応できる準備をしておくことを勧める。

## 予想問題（令和8年度）

> **問題1**　あなたが経験した土木工事を1つ選び、工事概要を具体的に記述したうえで、次の〔設問1〕、〔設問2〕に答えなさい。なお、あなたが経験した工事でないことが判明した場合は、失格となります。

**〔工事概要〕**（① 発注者名　② 工事場所　③ 工期　④ 主な工種　⑤ 施工量、立場 を含む）

**〔設問1〕** 工事概要に記述した工事の「**品質管理**」に関し、次の事項について解答欄に具体的に記述しなさい。

- (1) 具体的な現場状況と特に留意した品質管理上の技術的課題と、その課題を解決するために検討した項目
- (2) (1)で記述した検討項目の対応処置とその評価

**〔設問2〕** 工事概要に記述した工事の「**安全管理**」に関し、次の事項について解答欄に具体的に記述しなさい。

- (1) 具体的な現場状況と特に留意した安全管理上の技術的課題と、その課題を解決するために検討した項目
- (2) (1)で記述した検討項目の対応処置とその評価

## 工事概要（記入例）

- **工事名**：`〇〇`海岸 高潮対策（堤防・消波工）工事
- **発注者名**：`〇〇`県`〇〇`港湾事務所
- **工事場所**：`〇〇`県`〇〇`市`〇〇`地先（海岸）
- **工期**：令和`〇`年`〇`月`〇`日〜令和`〇`年`〇`月`〇`日
- **主な工種**：海岸堤防工、消波ブロック被覆工、根固めブロック据付工
- **施工量**：消波ブロック `〇〇`t型 `〇〇〇`個、根固めブロック `〇〇〇`個、堤防延長 `〇〇〇`m
- **立場**：監理技術者

この工事は、波浪・潮位・干満という海岸特有の条件のもとで、所定の品質（ブロックの形状・据付精度）を確保しつつ、重量物の海上・水際作業を安全に行うという、品質と安全の両面が問われる現場である。設問1で品質、設問2で安全を、同一工事の別々の論点として書き分ける。

## 完成答案：設問1（品質管理）

**(1) 具体的な現場状況と特に留意した品質管理上の技術的課題と、検討した項目**

本工事は、`〇〇`海岸で高潮対策として `〇〇`t 型の消波ブロックと根固めブロックを据え付けるものであった。製作ブロックは所定の質量・形状を満たす必要があり、据付けは波浪と潮位の影響を受ける水際で行うため、ブロックの品質と据付精度（位置・かみ合わせ・天端高）の確保が品質管理上の技術的課題であった。解決のため、ⅰ）ブロックの強度・形状の品質確認、ⅱ）据付位置・天端高の出来形管理、ⅲ）波浪・潮位を踏まえた据付時期の管理、を検討した。

**(2) 検討項目の対応処置とその評価**

ⅰ）製作ではスランプ `〇〇`±`〇`cm、圧縮強度を材齢 `〇〇` 日で設計基準強度以上に管理し、脱型後に主要寸法を全数計測して不良品を排除した。ⅱ）据付けは丁張りと基準点を設け、潜水士と測量で位置・天端高を `〇〇`cm 以内の許容差で管理し、かみ合わせを確認しながら所定の積み形状を確保した。ⅲ）潮位表と波浪予測をもとに据付を干潮前後の静穏時に限定した。これらにより規格を満たすブロックを設計どおりの精度で据え付け、所定の品質で完成させた。

## 完成答案：設問2（安全管理）

> 品質管理（設問1）が「ブロックの強度・据付精度」を扱うのに対し、設問2は**重量物の水際・海上作業に伴う労働災害・公衆災害の防止**という、評価軸の異なる論点で書く。

**(1) 具体的な現場状況と特に留意した安全管理上の技術的課題と、検討した項目**

本工事は、`〇〇`t の重量ブロックをクレーンで吊り、波浪と干満のある水際で据え付けるものであった。重量物の吊込み作業中の吊り荷の落下・クレーンの転倒、滑りやすい消波ブロック上や水際での作業員の墜落・転落・水没が懸念され、これら労働災害の防止が安全管理上の技術的課題であった。解決のため、ⅰ）クレーン作業（地盤・定格荷重・玉掛け）の安全、ⅱ）水際・ブロック上での墜落・転落・水没防止、ⅲ）波浪・潮位の変化に応じた作業中止基準、を検討した。

**(2) 検討項目の対応処置とその評価**

ⅰ）クレーン設置箇所は敷鉄板で接地圧を分散し、定格荷重 `〇〇`% 以下で運用、有資格者の玉掛けと合図者専任を徹底した。ⅱ）作業員に救命胴衣とフルハーネスを使用させ、ブロック上に親綱と昇降設備を設けて転落を防止し、監視船と監視員を配置した。ⅲ）波高 `〇〇`m 以上または風速 `〇〇`m/s 以上で作業を中止する基準を定め、作業可能時間帯を朝礼で周知した。これにより吊り荷の落下・墜落・水没を生じさせず無事故で完了した。

## 設問1と設問2の書き分け（品質×安全の組合せのポイント）

予想される令和8年度の組合せでは、同一工事で**品質**と**安全**を別々の論点に分離して書くことが核心となる。混同しやすいため、次のように軸を固定する。

- **守るもの**：工事目的物の出来（強度・形状・据付精度） → 人の命・身体（労働災害・公衆災害の防止）
- **課題の主語**：ブロックの品質・据付精度が確保できるか → 重量物作業・水際作業で災害が起きないか
- **処置の中身**：規格値・試験・計測・許容差 → 法令・有資格者選任・保護具・作業中止基準
- **締めの評価**：「所定の品質を確保した」 → 「無事故で完了した」

同じ「波浪・潮位・重量ブロック」という現場条件を起点にしながら、品質では**規格値と計測**へ、安全では**法令と保護具・中止基準**へと論点を分岐させると、2設問が重複しない。

## 採点者視点のチェックポイント

- 設問1（品質）と設問2（安全）が、同じ工事でも**評価軸の異なる論点**で書けているか（同一内容は不可）。
- 品質：確保すべき品質項目と**規格値・許容差・試験／計測**が明示されているか。「良いものを造った」等の主観語で終わっていないか。
- 安全：防止すべき災害が**具体的に絞られ**、**法令・有資格者の選任・数値入りの管理基準**（作業中止基準等）が書けているか。
- 監理技術者として、品質では**計画段階の品質確保**、安全では**作業計画書・安全体制**に触れているか。
- 各設問が (1) 課題＋検討項目 / (2) 対応処置＋評価 の2項目で書けているか。

## 自分の現場への置換ガイド

- **工事**：海岸堤防 消波ブロック被覆・根固め → 品質と安全を両方書ける自分の工事
- **設問1**（品質）：ブロックの強度・形状・据付精度 → 強度／締固め度／出来形／かぶり 等の品質課題
- **設問2**（安全）：重量物吊込み・水際の墜落／水没 → 墜落／崩壊／接触／公衆災害 から1つに絞る
- **規格値・基準**：スランプ・据付許容差・作業中止基準 → 自分の現場の管理基準値・法令

品質は「規格値 → 脅かす条件 → 検討 → 試験・計測を伴う処置 → 規格値達成」、安全は「現場条件 → 災害（1つ）→ 検討（法令含む）→ 数値入り処置 → 無事故」の連鎖で書く。工種を変えるときは、品質側は規格値・試験方法を、安全側は想定災害・法令・保護具をセットで入れ替える。設問1と設問2の内容が重ならないよう、必ず別々の論点に振り分けること。
