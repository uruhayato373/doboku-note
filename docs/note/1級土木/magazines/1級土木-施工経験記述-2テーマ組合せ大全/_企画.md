# 1級土木 施工経験記述｜2テーマ組合せ大全（企画ブリーフ）

## 背景・狙い

令和6年度以降、1級の問題1は **5管理から2テーマが選ばれ、同一工事で設問1・設問2に書き分ける（同一内容不可）** 形式（R06=安全×施工計画／R07=品質×環境）。
本マガジンは **5管理の2テーマ全組合せ C(5,2)=10通り** に対し、各組合せ **想定工事①②③** のフル模範答案を収録し、「**どの組合せが来ても自分の工事で書き分けられる**」状態を作る。投機的予想ではなく **形式の全網羅**（的中・不的中の概念がない）。`civil-1-yosou-essay`（予想問題集）を転換。

## 形式（各記事＝1組合せ）

- `## 想定工事①：{工事名}` → `### 〔工事概要〕（記入例）` → `### 設問1（{テーマA}）(1)…/(2)…` → `### 設問2（{テーマB}）(1)…/(2)…`
- 設問1＝テーマA・設問2＝テーマB を **評価軸の異なる論点に分離（同一内容不可）**。R06/R07形式（各2項目・各欄8行＝190字以内/上限200）。
- 答案は ⅰ）型完結文の散文。規格・法定の固定値はリテラル、現場固有値のみ `〇〇`。
- 想定工事①②③は別現場・別工種・別論点。**既存マガジン（過去問集・完成答案集）と重複させない**。
