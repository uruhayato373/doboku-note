# 1級土木 択一・論点別トレーニング PDF（試作メモ）

note で「択一過去問 PDF」を有料販売する案の試作記録。**生の年度別過去問をそのまま売る**のは
筋が悪い（自サイトで無料公開中・無料代替が飽和・図版の権利リスク）ため、択一を素材に
**論点別へ再構成した編集物**として価値を載せる方向で 1 テーマ試作した。

## 結論（戦略）

- **本命**: 択一は無料リードマグネット化し、有料は記述式（経験記述・模範論文）に集中（4 本柱戦略と整合）。
- **択一を有料化するなら**: 年度別の束ではなく、本試作のように**論点別・年度横断・暗記特化**へ再構成する。
- サイト SEO に依存せず note＋SNS（IG 過去問パック等）を配信レイヤーにする発想自体は妥当。

## 何を作ったか

| 項目 | 内容 |
|---|---|
| ジェネレータ | `scripts/build-takuitsu-reconstruct.mjs` |
| 入力 | `src/config/civil-1-exam-questions.json`（H26〜R07・全 1162 問・構造化済み） |
| 試作テーマ | 安全管理（抽出 194 問 → 同趣旨圧縮で 164 問・9 論点） |
| 出力 | `.tmp/takuitsu-anzen/article.md`（note 貼付 SoT）＋ `print.html`（印刷用） |

### 再構成のしくみ（差別化の中身）

1. **論点別に解体** — 年度別ではなく「足場・墜落／明り掘削・土止め／型枠支保工／車両系建設機械／移動式クレーン・玉掛け／ずい道／酸欠・有害物／感電・架空線／安全衛生管理体制」の 9 論点へ自動振り分け。
2. **論点まとめ** — 各論点の冒頭に、過去問の正答選択肢解説（法令条文付き）を集約・重複圧縮した「覚える正しい知識」を配置。
3. **一問一答（年度横断）** — 同じ論点の問題を H26〜R07 で連続演習。各問に正答＋要点。
4. **同趣旨圧縮** — 反復出題された設問は最古年に集約し「同趣旨で再出題: …」と注記（編集された教材としての価値）。

## 使い方（再生成 → PDF 化）

```bash
# 1) 再構成ソースを生成（md + 印刷 html）
node scripts/build-takuitsu-reconstruct.mjs --theme anzen
#    任意: --outDir <dir>

# 2) PDF 化（ローカルの Chrome で。クラウド環境には Chrome が無い）
#    print.html を Chrome で開く → Ctrl+P → 「PDF に保存」
#    ※ レイアウト CSS は scripts/magazine-to-pdf.mjs と同系統（紙のハウススタイル）
```

> [!note] テーマ追加
> `scripts/build-takuitsu-reconstruct.mjs` の `THEMES` にテーマ定義（抽出 regex・サブ論点）を足すだけ。
> 土工・コンクリート等は図版依存問題があるため、図を伴う設問の扱いを別途検討する。

## 既知の限界（製品化前に手当て）

- **論点まとめの混入**: 複合設問（例: 足場の問題に酸欠の選択肢）から他論点の知識が一部混ざる。製品化時は人手で剪定する。
- **元データ由来の省略**: 一部の解説が元 JSON 時点で「…」で省略されている。
- **図版問題**: 安全管理は図依存が 6.5%（12/184）と低く影響軽微。図依存の高い土工・構造系を出す場合は要対応。
- **最終 PDF はローカル生成**: クラウド環境に Chrome / 変換系が無いため、印刷 PDF はローカルで作る。
