## 「試験概要」と「傾向と対策」

コンクリート技士・主任技士は、レディーミクストコンクリートおよびコンクリート製品の製造、コンクリートの工事、ならびにコンクリートの試験研究等に関する業務に携わる技術者の資格として、その技術の向上をはかるとともに、コンクリートに対する信頼性を高め、建設産業の進歩発展に寄与することを目的として制定された制度である。

コンクリート技士は、コンクリートの製造、施工、試験、検査および管理などの日常業務を実施する能力がある技術者であると、されている。

コンクリート主任技士は、コンクリートの製造、工事、および研究における計画、管理、指導などを実施する能力のある高度の技術をもつ技術者が求められる、とされている。

試験では、上記の条件を満たす知識、技能を有しているかどうかを問うためにコンクリート技術に関連する種々の事項からまんべんなく出題されている。

別表に、日本コンクリート工学会による「選考の基準」を示す。

**●出題形式・解答時間**

- 従来、四肢択一問題30題、小論文1題であったが平成30年からは四肢択一問題27題、小論文1題となり、解答時間は平成25年にそれまでの3時間から3時間30分に変更された。
- なお、令和2〜5年度の試験は、四肢択一式25問と小論文1問のみ、解答時間は3時間であった。
- 四肢択一問題は正答のみに点が与えられ、誤答および無答は零点となる。
- 小論文は、四肢択一問題である程度の点数を取らないと採点者に読んでもらえない。また、過去には、四肢択一問題と小論文の合計点で合否が決まることもあったが、最近でいくら高得点をとっても小論文の得点が低すぎると不合格となる場合もある。

**●出題分野**

別表の過去の分野別出題頻度表を見れば明らかなように、各分野の出題頻度は、ここ数年ではほとんど変わっていない。すべての分野を網羅するように出題するという方針が見てとれる。

**●解答にあたって**

- 四肢択一問題は、適当(正しい)、不適当(誤っている)のいずれを選ぶのかを間違えずに、各肢すべてを慎重に読んでから答える。
- 四肢択一問題では、誤った複雑をするとその数にたどり着くという肢が用意されていることがある。正答肢を選んだと思われた場合も、他の肢のどこが正答でないのかを判断すべきである。
- 小論文作成に割ける時間は少ないと考えるべきである。「てにをは」の整った文章を書くのが望ましいが、体裁は箇条書形式でもよいので、第一に、的確なキーワードを示すこと、論旨を明確にすることに主眼をおくべきである。

### 選考の基準

| 項目 | コンクリート技士 | コンクリート主任技士 |
|---|---|---|
| 1. 土木学会コンクリート標準示方書(ただし、構造設計関連の内容は除く) 日本建築学会建築工事標準仕様書 JASS5鉄筋コンクリート工事 | 内容を理解する能力。 | 内容を理解し応用する能力。 |
| a. コンクリート用材料の品質試験および管理 | JISに規定されている試験についての実施能力と結果の判定能力。通常使用される材料について試験し、その結果をコンクリートの調(調)合計算に活用する能力。材料を選定する能力。 | 自らの能力に加え、JISに規定されていない試験方法以外の応用的試験を実施し、結果を判定する能力。新材料についても、それらの試験方法を発案し、使用法を改善する能力。 |
| b. コンクリートの配(調)合設計 | 通常使用されるコンクリートについて配合理論を理解し、所要の性能を満足し、かつ経済性を考慮した配(調)合を定めることができる能力。 | 自らの能力に加え、特殊なコンクリートについても配(調)合を定めることができる能力。 |
| c. コンクリートの試験 | JISに規定されている試験についての実施能力と結果の判定能力。 | 自らの能力に加え、JISに規定されていない試験以外の応用的試験を実施し、試験結果からコンクリートの品質を総合的に判定する能力。 |
| d. プラントの計画管理 | 基本的計画に基づいてプラントの性能を確保する能力。日常の整備保全をする能力。 | 自らの能力に加え、プラントを計画する能力。一般管理および応用的管理をする能力。 |
| e. コンクリートの製造および品質管理 | 定められた方法で、計画通り(計画図表)に対する現場検査(現場調査)に従う能力。コンクリートの製造に関し変化に応じた配(調)合を調整する能力。製造記録を機械の適切な処理、点検能力。コンクリートの品質管理を行い、その結果をコンクリートの品質管理に反映させる能力。 | 自らの能力に加え、コンクリート品質の変動要因を解析し、製造、品質、品質管理水準を向上させる能力。異常事態に対して適切な処置をする能力。 |
| f. コンクリートの施工 | 施工計画に基づいて必要な施工管理をし、施工管理を効率的に指導し、現場技術員を育成する能力。施工に係るコンクリートの問題に関する一連の知識。 | 自らの能力に加え、工事条件や関連事項を考慮した施工が可能になるよう施工計画を立案し、各種試験と現場での状況がよく一致するように管理する能力。その応用ができる能力。 |
| g. コンクリートに関わる環境問題 | コンクリートおよびコンクリート構造物に関わる環境問題についての基礎的な知識と理解力。 | コンクリートおよびコンクリート構造物に関わる環境問題についての一般的な知識と理解力。 |
| h. その他 | コンクリートおよびコンクリート構造物に関わる基礎的な知識と理解力。 | コンクリートおよびコンクリート構造物に関わる知識と理解力。 |
| 2. 関係法令(土木建築基準法施行令ならびにコンクリートの品質ならびに施工に関係する事項) およびコンクリート関係のJIS | 内容についての基本的な知識。 | 内容および〔判読不能〕解説のあるものについても含めての知識。 |
| 小論文 | | 与えられた課題について、実務経験を踏まえた内容の小論文を記述する能力。 |
