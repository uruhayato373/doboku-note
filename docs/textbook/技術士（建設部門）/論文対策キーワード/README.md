- **第2章 導入**（章扉＋「本章では…6つのテーマを取り上げている」）は `01_社会資本整備.md` 冒頭の `## 第2章 キーワード解説（本章の構成）` に収録。

- 見出し階層: H1=節名／`## 第2章…`・`## おわりに`（特例）／`###`=小節（2.x.1 現状や背景・2.x.2 計画や政策）／`####`=キーワード項目（(1)(2)…）。
- 図・グラフ・フロー図は **PDFから該当図をクロップして `img/figNN.png` に保存し、`![図NN](img/figNN.png)` で埋め込み**（直下に元の `（図: …）` キャプションも残置＝データ検索用）。**全31図を埋め込み済み**（fig15/21/30 は単ページ分割版が破損していたため元スプレッドから直接クロップ）。
- 白書・計画からの引用囲みは `> ` 引用ブロックで再現。
- スキャンのかすれ・誤植は各バッチで「原文ママ」前提で逐語転記（疑わしい箇所は前後文脈で補完）。書類6 に同一見開きの重複スキャン（p188-189）があったが本文は1回のみ転記。
