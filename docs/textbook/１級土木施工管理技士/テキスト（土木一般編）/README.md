## 文字起こし方法

- PyMuPDFで全385ページを幅2200pxにレンダリング → サブエージェント `scanned-textbook-transcriber` に6ページ/バッチ（全65バッチ）でファンアウト高解像度OCR。
- 各バッチが逐語転記した`.md`を章順に連結し、H1＋出典ブロックを付与。3桁節（N.M.K）の見出しを`####`へ降格。
- 確認済みの系統誤読「築造→施造」を全章一括補正。U+FFFD（文字化け）は全章0件。
- **図(320点)**: 各図プレースホルダのキャプションを `civil-exam-figure-extractor`（章別ジョブをファイル読込→40図ずつ順次グループ処理でレート制限抑制）に渡し、候補ページ（±2窓）から領域(bbox)を検出 → 該当ページを2600pxで再レンダリングして比率クロップ → `img/` 保存・本文埋め込み（`![図番号](img/{章}-fig{NN}.png)`、Obsidian相対パス表示可）。確信度0.55未満は誤クロップ回避のため未埋め込み。

## 既知の限界（要注意・原文ママ前提）

> [!note] LLM-OCRのため**字句は近似**。正確な引用は必ず原典PDFで照合すること。
- **字句の誤読**: 高解像度でも漢字の誤読が残りうる（例: 築造→施造は補正済だが、類似の取り違えが残存しうる）。
- **密な段落の言い換え/節落ち**: 数値・施工手順・配合・規格値が詰まった段落で、原文に無い言い換え・脱落が生じている箇所がある。**数値・規格・配合・寸法の一字一句は原典PDFで確認**。
- **図のクロップは自動bbox**: 領域はLLMが自動判定したもの。隣接本文が一部入る／稀に範囲が前後にずれる場合がある。原典PDFが最終的な正。`（図: 説明）`プレースホルダはデータ検索用に各画像の直後に残置。
- **ページ番号**: 各ページ境界の`<!-- p.NN -->`は原書の印字ノンブル。図版頁等で連番が飛ぶことがある。
