## 文字起こし方法

- PyMuPDFで全327ページを幅2200pxにレンダリング → サブエージェント `scanned-textbook-transcriber` に6ページ/バッチ（全59バッチ）でファンアウト高解像度OCR。
- 各バッチが逐語転記した`.md`を章順に連結し、H1＋出典ブロックを付与。3桁節（N.M.K）の見出しを`####`へ降格。
- 確認済みの系統誤読「築造→施造」を全章一括補正。U+FFFD（文字化け）は全章0件。

## 既知の限界（要注意・原文ママ前提）

> [!note] LLM-OCRのため**字句は近似**。正確な引用は必ず原典PDFで照合すること。
- **字句の誤読**: 高解像度でも漢字の誤読が残りうる（例: 築造→施造は補正済だが、類似の取り違えが残存しうる）。
- **密な段落の言い換え/節落ち**: 数値や因果が詰まった段落で、原文に無い言い換え・脱落が生じている箇所がある（例: 第1章「三大管理の相互関係」の工程-原価の説明）。**条文・数値・定義の一字一句は原典PDFで確認**。
- **図は未クロップ**: 図・グラフ・フロー図は`（図: 説明）`プレースホルダのみ（位置と内容説明は記載）。実画像のクロップ埋め込みは未実施（Phase 2）。
- **ページ番号**: 各ページ境界の`<!-- p.NN -->`は原書の印字ノンブル。図版頁等で連番が飛ぶことがある。
