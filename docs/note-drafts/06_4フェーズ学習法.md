# 【働きながら総監に合格した】1年間スケジュール完全版｜4フェーズ学習法で合格ラインに届く勉強配分

> **この記事でわかること**
> - 受験申込から合格発表までの約1年間を4フェーズに分割する学習戦略
> - 各フェーズで何に注力すべきか、具体的な行動指針
> - 択一式と記述式の配点バランスから導く、最も効率的な学習配分

---

## なぜ「フェーズ分け」が必要なのか

総合技術監理部門の合格率は一般部門より低い。一般部門と同じ感覚で「直前に過去問を回す」だけでは合格は難しい。

理由は明確で、総監には一般部門のような学協会指針や白書がない。唯一の公式情報源は「総合技術監理 キーワード集」であり、これと過去問を起点に自分で体系的な学習を組み立てる必要がある。

合格者に共通するのは、約1年の学習期間をフェーズに分けてメリハリをつけている点である。以下に、4つのフェーズとその具体的な行動指針を示す。


## フェーズ1: 前提知識の習得（4月~5月）

最初の2か月は「総監の全体像を掴む」段階である。

- キーワード集を通読する。すべてを暗記する必要はない。5つの管理（経済性管理・人的資源管理・情報管理・安全管理・社会環境管理）がそれぞれ何を扱い、どのように関連するかの全体像を把握することが目的
- 過去問（択一式・記述式の両方）を3~5年分ざっと読む。問題を解くのではなく、出題の傾向と範囲を知る
- 一般部門との違いを認識する。総監は「専門技術の深さ」ではなく「管理技術の広さと統合力」を問う試験であることを、この段階で腹落ちさせておく

フェーズ1で重要なのは、完璧を求めないことである。キーワード集の内容を完全に理解してからフェーズ2に進もうとすると、時間が足りなくなる。7割程度の理解で次に進み、フェーズ2以降の学習で理解を深めるのが現実的なアプローチだ。


## フェーズ2: 筆記試験対策（5月~7月）

学習の中核となるフェーズである。受験申込書の作成と、択一式・記述式の対策を並行して進める。

**受験申込書の作成**

受験申込書に記載する業務経歴（5つの業務）と業務内容の詳細は、記述式試験の論文題材に直結する。この段階で5つの管理の視点・トレードオフ・成果を整理しておくと、フェーズ3の記述式対策がスムーズになる。

申込書は「提出書類」であると同時に「記述式・口頭試験の設計図」でもある。ここに手を抜くと、後のフェーズすべてに響く。

**択一式対策**

キーワード集の内容を中心に、過去問で頻出する論点を重点的に学習する。過去問を解いて正誤を確認するだけでなく、各選択肢がキーワード集のどの項目に対応するかを紐づけると、知識の体系化が進む。

計算問題（NPV、PERT、損益分岐点など）は毎年3~5問出題される。解法パターンが決まっているため、パターンを押さえれば確実に得点できる。

**記述式対策**

過去問の前文を読み、テーマの抽出・設定条件の整理・要求事項の把握を練習する。最初は答案を書かなくてよい。骨子（各設問に何を書くか）を作成し、5つの管理の視点とトレードオフが網羅されているかを確認する訓練を繰り返す。

過去の出題テーマや択一式の全問解説は、[doboku-note](https://doboku-note.com/category/pe-comprehensive-management)に収録している。


## フェーズ3: 最終対策（7月~10月）

筆記試験直前の仕上げと、試験後の口頭試験準備を並行するフェーズである。

**試験直前（7月）**

- 択一式: 模擬試験形式で時間を計って解く。40問を2時間で解く時間感覚を身体に覚えさせる
- 記述式: 答案用紙のフォーマットに実際に手書きする。1枚を書くのにかかる時間（標準は約25分）を計測し、Step 1~5の時間配分を確定する

**試験後（8月~10月）**

試験が終わったら、記述式の内容を記憶が新鮮なうちに再現しておく。口頭試験で記述内容について深く問われるため、自分が何を書いたかを正確に把握しておくことが不可欠だ。

合わせて、受験申込書の業務経歴を改めて見直す。口頭試験では、業務経歴の内容を「総監の視点」から説明できるかが問われる。


## フェーズ4: 口頭試験対策（10月~1月）

筆記試験の合格通知を受けてからが本番である。

- 業務経歴の5つの業務について、それぞれ5つの管理の視点から説明できるよう整理する
- 記述式で書いた内容について、「なぜその施策を選んだのか」「他にどのような選択肢があったか」「トレードオフをどう判断したか」を論理的に説明する準備をする
- 模擬面接を実施する。独学では気づけない説明の曖昧さが、第三者の指摘で浮き彫りになる


## 択一式と記述式のバランス

筆記試験は択一式と記述式の合計で60%以上の得点が必要である。配点バランスの異なる3つのパターンで合否をシミュレーションしてみる。

- パターン1（理想型）: 択一式60% + 記述式60% = 合計60% --- 合格
- パターン2（記述式偏重）: 択一式45% + 記述式75% = 合計60% --- 計算上は合格可能だが、択一式45%は稀
- パターン3（択一式偏重）: 択一式75% + 記述式45% = 合計60% --- 口頭試験で記述内容を深く問われ、苦しくなる

択一式が60%を大きく下回っての合格は現実的には稀であり、バランスよく対策することが合格への最短経路となる。記述式に自信があっても、択一式を軽視してはならない。


## 日常業務を学習に活かす

試験対策は机上の学習だけでは不十分である。日常業務において5つの管理間のトレードオフの発生に注目し、解決策を意識することが、特に記述式対策に直結する。

具体的には、キーワード集の用語を日常業務の内容に当てはめてみることだ。「この工程の遅延は経済性管理と安全管理のトレードオフだ」「この人事異動は人的資源管理と情報管理の両面から検討すべきだ」という視点で日々の業務を捉え直す。

この習慣が、記述式で求められる「総監の視点による分析・提言」の実践的な訓練になる。
