# note記事 企画立案 — 技術士（総合技術監理部門）

**策定日**: 2026-04-13
**対象**: 技術士 総合技術監理部門 受験者
**資産状況**: キーワード解説 約700記事 + 過去問 H21〜R07（primary/secondary）
**関連**: ロードマップ・Phase計画・商品ラインナップは [`docs/project/04_コンテンツロードマップ.md`](../project/04_コンテンツロードマップ.md) に統合済み（2026-04-13）

## 基本方針

過去問そのものを有料化するのではなく、**「合格者の思考プロセス」「時短パッケージ」「完成品」**を有料化する。サイトの無料コンテンツ（SEO資産）とカニバリさせない。

### サイト（無料） vs note（有料）の役割分担

| 領域 | サイト（無料） | note（有料） |
|---|---|---|
| キーワード解説 | 700記事（網羅） | 絞り込み・横串整理 |
| 過去問 | 択一・論文すべて掲載 | 論文の"完成答案"と添削 |
| 学習法 | 概要ロードマップ | 実行可能テンプレ・時短術 |

## 柱A: 論文対策（最優先・コアの売れ筋）

総監受験者は既に建設部門合格者で情報リテラシーが高い。**「完成品」と「採点者の視点」**に金を払う層。

### A-1. 総監論文 骨組みテンプレート：5管理を横串で書く技術 ★最優先

- **価格**: ¥1,980
- **内容**:
  - 800字論文の構造分解
  - 5管理の配置順と比率
  - トレードオフの書き方
  - 採点者が見る3つのポイント
  - 時間配分（構想→記述→見直し）
- **差別化**: サイトに散在する書き方ノウハウを「型」として1冊化

### A-2. R01〜R07 論文合格答案 実例集（7年×2問=14本）

- **価格**: ¥2,480（最高単価）
- **内容**: 過去7年分の論文問題に対する合格水準答案＋講評
- **差別化**: 無料サイトにない「完成答案」。最も売れる想定

### A-3. 総監論文 使えるネタ帳50：5管理別の事例集

- **価格**: ¥1,480
- **内容**: インフラ老朽化・DX・気候変動・BCPなど頻出テーマを5管理視点で整理
- **制作**: 700キーワード資産の再編集で容易
