## North Star Metric

### 週間エンゲージドセッション数

1回の訪問で **2ページ以上閲覧** したセッションの **週間合計数**

- **定義**: GA4の「エンゲージドセッション」（2ページ以上閲覧 or 10秒以上滞在 or コンバージョン発生）の週間合計
- **現在値**: 0（未公開）
- **目標値**:
  - 公開1ヶ月後: 500/週
  - 3ヶ月後: 2,000/週
  - 6ヶ月後: 5,000/週

### なぜこの指標か

1. **単なるPVではなく「学習・参照として役立った」ことを示す** — 1ページだけ見て離脱したユーザーは価値を得ていない可能性が高い
2. **収益の先行指標** — エンゲージドセッションが多いほど広告表示回数・アフィリエイトCTR・AI チャット利用率が上がる
3. **コンテンツ品質のフィードバック** — 2ページ目に遷移するということは、1ページ目の内容が信頼に値すると判断された証拠
4. **アクション可能** — 内部リンク改善、関連コンテンツ推薦、目次構造改善など具体施策で直接向上できる

## Input Metrics

### 1. インデックス済みページ数

- **定義**: Google Search Console で「有効」と表示されるページ数
- **NSM との関係**: ページ数↑ → 検索流入の入口が増える → セッション数の母数が増加
- **現在値**: 0（未公開）
- **目標値**: 公開1ヶ月後 150ページ、3ヶ月後 250ページ
- **施策例**:
  - 新規カテゴリのコンテンツ追加（砂防、港湾の拡充）
  - 既存PDFの追加取り込み（`/pdf-to-mdx`）
  - サイトマップ最適化

### 2. 検索クリック率（CTR）

- **定義**: GSCにおける検索表示に対するクリック率の平均
- **NSM との関係**: CTR↑ → 同じ検索露出でもサイトへの流入が増える → セッション増
- **現在値**: 0%（未公開）
- **目標値**: 3ヶ月後 3%以上
- **施策例**:
  - タイトル・descriptionの最適化（`/seo-audit`）
  - 構造化データ（FAQ、HowTo）の追加
  - 検索意図に合致したページタイトルの改善

### 3. セッションあたりページ閲覧数

- **定義**: GA4の「セッションあたりのページビュー数」の平均
- **NSM との関係**: 回遊性↑ → 2ページ以上閲覧する割合が直接増加
- **現在値**: 0（未公開）
- **目標値**: 3ヶ月後 2.0以上
- **施策例**:
  - 関連コンテンツの相互リンク強化
  - サイドバーの「関連記事」セクション追加
  - パンくずリスト・カテゴリナビゲーションの改善
  - AI チャットからの関連ページ提案

### 4. 週間リピーター率

- **定義**: 過去7日間のユーザーのうち、2回以上訪問したユーザーの割合
- **NSM との関係**: リピーター↑ → 安定的なエンゲージドセッションの基盤
- **現在値**: 0%（未公開）
- **目標値**: 3ヶ月後 15%以上
- **施策例**:
  - ブックマーク促進（「このページを保存」UI）
  - 更新通知（RSS/メール配信）
  - 資格試験カレンダーに連動したコンテンツ推薦
