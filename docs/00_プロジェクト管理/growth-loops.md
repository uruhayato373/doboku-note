# doboku-note 成長ループ分析

作成日: 2026-03-18

## 現状サマリー

- **主要流入チャネル**: SEO（検索流入）— 未公開のため想定
- **現在機能しているループ**: なし（未公開）
- **コンテンツ資産**: 227ページ（6カテゴリ）
- **NSM**: 週間エンゲージドセッション数

---

## ループ評価

### 1. 技術リファレンス SEO ループ（推奨度: ★★★★★）

**仕組み**:

```
技術ノート公開
  → 技術者が業務中に検索（「騒音 環境基準 評価マニュアル」等）
  → サイト訪問・ブックマーク
  → 社内共有（「この基準はここに整理されてる」）
  → 被リンク増加（自治体・コンサルの参考リンク）
  → ドメイン権威向上
  → さらに多くの検索キーワードで上位表示
  → （ループ）
```

| 基準 | 評価 | 根拠 |
|---|---|---|
| 適合度 | 5/5 | 公的技術資料の構造化はまさにこのループのためのコンテンツ |
| 現在の成熟度 | 2/5 | コンテンツ227ページあり。未公開なのでSEO効果ゼロ |
| 実装コスト | S | 公開するだけで始動。サイトマップとmeta最適化のみ |
| 成長速度 | 中期（3-6ヶ月） | SEOインデックス→上位表示に時間がかかる |
| 複利効果 | 高 | 被リンク蓄積 → ドメイン権威 → 新規ページも上位表示しやすくなる |

**具体的アクション**:
1. サイト公開・サイトマップ送信
2. 主要ページのtitle/descriptionをSEO最適化
3. 構造化データ（FAQ、BreadcrumbList）の追加
4. 各ページのcanonical URL設定

**ループ係数の推定**:
- 1ページあたり月間検索流入: 20〜50（初期）→ 100〜300（6ヶ月後）
- 被リンク獲得率: 100ページあたり月1〜3本（公的資料引用サイトの特性上、自治体・研究機関からの被リンクが期待できる）
- サイクル期間: 3〜6ヶ月（SEOの性質上、効果は遅延するが複利的に加速）

### 2. 資格試験 SEO ループ（推奨度: ★★★★☆）

**仕組み**:

```
試験関連コンテンツ公開（施工管理技士・技術士）
  → 受験者が試験前に検索（「施工管理技士 河川 出題傾向」等）
  → サイト訪問・学習
  → 合格後に後輩・同僚に共有
  → SNS/口コミで認知拡大
  → 翌年の受験者がさらに検索
  → （ループ）
```

| 基準 | 評価 | 根拠 |
|---|---|---|
| 適合度 | 4/5 | 現在のコンテンツは技術資料中心。試験対策への橋渡しが必要 |
| 現在の成熟度 | 1/5 | 試験対策に特化したコンテンツはまだない |
| 実装コスト | M | 過去問解説・出題傾向分析のコンテンツ作成が必要 |
| 成長速度 | 中期（季節性あり） | 試験シーズンに急増、オフシーズンは減少 |
| 複利効果 | 中 | 毎年同じ試験があるため安定するが、爆発的な複利は期待しにくい |

**具体的アクション**:
1. 施工管理技士の出題範囲と既存コンテンツのマッピング
2. 「この技術ノートは施工管理技士○○分野に該当」のタグ付け
3. 試験カレンダーページの作成
4. 試験シーズン前（4〜5月、9〜10月）にSNS発信

**季節性パターン**:

| 月 | イベント | 想定流入倍率 |
|---|---|---|
| 4-5月 | 1級施工管理技士 学習開始 | ×1.5 |
| 6月 | 1級施工管理技士 一次試験 | ×3.0 |
| 7月 | 技術士 二次試験（筆記） | ×2.0 |
| 9-10月 | 2級施工管理技士 学習開始 | ×1.5 |
| 10月 | 技術士 二次試験（口頭） | ×2.0 |
| 11月 | 2級施工管理技士 試験 | ×2.5 |

### 3. コンテンツ拡張ループ（推奨度: ★★★★☆）

**仕組み**:

```
既存ページ公開
  → GSC で検索クエリデータ取得
  → ユーザーが実際に検索しているが未カバーのキーワード発見
  → 新規ページ追加（ロングテール対応）
  → 検索流入増加
  → さらに多くの検索クエリデータ
  → （ループ）
```

| 基準 | 評価 | 根拠 |
|---|---|---|
| 適合度 | 5/5 | PDF→MDX変換スキルが整備済み。拡張コストが低い |
| 現在の成熟度 | 3/5 | スキル（/pdf-to-mdx等）が整備済み。データがまだない |
| 実装コスト | S | 既存スキルで自動化可能 |
| 成長速度 | 中期 | GSCデータ蓄積に2〜3ヶ月必要 |
| 複利効果 | 高 | ページ数増 → データ増 → さらに的確なコンテンツ追加 |

**具体的アクション**:
1. 公開後2ヶ月目から `/fetch-gsc-data` で週次クエリ分析開始
2. 「表示あり・クリックなし」のクエリを特定 → コンテンツ追加
3. `/pdf-to-mdx` で未取り込みの公的資料を優先度順に変換
4. 月2回のコンテンツ追加サイクルを確立

### 4. AI チャット エンゲージメントループ（推奨度: ★★★☆☆）

**仕組み**:

```
AI チャット提供（無料枠）
  → 技術者が質問（「盛土の締固め基準は？」）
  → 的確な回答 + 関連ページへのリンク
  → ユーザーが関連ページを回遊（エンゲージドセッション↑）
  → 「便利だ」と認識 → ブックマーク・共有
  → 再訪問 → 有料転換
  → （ループ）
```

| 基準 | 評価 | 根拠 |
|---|---|---|
| 適合度 | 4/5 | 227ページの構造化コンテンツはRAGに最適 |
| 現在の成熟度 | 0/5 | 未実装 |
| 実装コスト | L | RAGパイプライン、LLM API費用、課金システム |
| 成長速度 | 中〜長期 | 構築後の利用定着に時間がかかる |
| 複利効果 | 高 | 利用データ → 回答品質改善 → 利用率↑ → データ↑ |

**具体的アクション**:
1. Phase 2（公開2〜3ヶ月後）で MVP 構築
2. Cloudflare Workers AI + Vectorize で低コスト実装
3. 無料枠（月10質問）で利用率を検証
4. 質問ログからコンテンツ追加のヒントを得る（ループ3と接続）

### 5. 教育機関引用ループ（推奨度: ★★☆☆☆）

**仕組み**:

```
体系的な技術資料を公開
  → 大学・高専の教員が講義で引用
  → 学生がアクセス
  → レポート・論文で参照（被リンク）
  → ドメイン権威向上
  → （ループ）
```

| 基準 | 評価 | 根拠 |
|---|---|---|
| 適合度 | 3/5 | 教育向けに最適化されたコンテンツではない |
| 現在の成熟度 | 0/5 | 未公開のため接点なし |
| 実装コスト | S | 特別な実装不要（コンテンツの質で勝負） |
| 成長速度 | 長期（1年以上） | 教育機関の採用サイクルは年度単位 |
| 複利効果 | 中 | .ac.jp からの被リンクはSEO的に高価値だが獲得は遅い |

**具体的アクション**:
1. 当面は能動的に追わない（ループ1-3の結果として自然発生を待つ）
2. 1年後にアクセスログで .ac.jp ドメインからの流入を確認
3. 流入があれば教育向けページ（用語集、基礎解説）を強化

## 推奨実装順序

| 優先度 | ループ | 理由 |
|---|---|---|
| **1位** | 技術リファレンスSEO | コスト最小、既存資産を活かせる、全ての基盤 |
| **2位** | コンテンツ拡張 | ループ1のデータを燃料に自己強化 |
| **3位** | 資格試験SEO | 季節性を活かした追加流入源 |
| **4位** | AIチャットエンゲージメント | 差別化の柱だが、まずトラフィックが必要 |
| **5位** | 教育機関引用 | 自然発生を待つ。能動施策は不要 |

## 30-60-90日ロードマップ

### 30日目: サイト公開 + ループ1 始動

- サイト公開、サイトマップ送信
- GA4/GSC 計測開始
- 主要50ページのtitle/description最適化
- AdSense配置最適化 + アフィリエイトリンク設置

### 60日目: ループ2 始動 + データ分析

- GSCデータ分析（`/fetch-gsc-data`）
- 「表示あり・クリックなし」クエリの特定
- 未カバーキーワード向け新規ページ10件追加
- 試験シーズンに向けた試験対策タグ付け

### 90日目: ループ3・4 準備 + 検証

- 資格試験関連コンテンツのマッピング完了
- AIチャットMVP設計・プロトタイプ着手
- 最初の90日の成果レビュー（`/weekly-review`）
- 成長ループの実効性を数値で検証

## ループ間の相乗効果

```
ループ1: 技術リファレンスSEO
  ├─→ トラフィック → ループ2 の燃料（GSCデータ）
  ├─→ 被リンク蓄積 → ループ3 の効果増幅
  └─→ ユーザーベース → ループ4 の利用者

ループ2: コンテンツ拡張
  ├─→ ページ数増 → ループ1 の検索流入入口拡大
  └─→ カバレッジ拡大 → ループ4 のRAG精度向上

ループ3: 資格試験SEO
  ├─→ 季節トラフィック → ループ1 のドメイン権威強化
  └─→ 受験者コミュニティ → ループ4 の有料転換源

ループ4: AIチャット
  ├─→ 質問ログ → ループ2 のコンテンツ追加ヒント
  └─→ エンゲージメント → NSM 直接向上
```
