# 設計思想

最終更新: 2026-03-31

---

## 核心原則

**doboku-note は「1級土木施工管理技士の受験者が迷わず合格に近づけるサイト」に集中する。**

他分野のコンテンツは Obsidian で品質管理し、体系化できた段階で順次公開する。

---

## 3層アーキテクチャ

| 層 | 環境 | 役割 | 状態 |
|---|---|---|---|
| **ステージング** | Obsidian（~/obsidian） | 全分野の下書き・品質管理・体系化 | 非公開 |
| **プロダクション** | doboku-note（本リポジトリ） | 1級土木施工管理に特化した公開サイト | 公開 |
| **アプリ** | iOSアプリ | 1級土木の過去問演習 | 開発中 |

### コンテンツの流れ

PDF / 書籍 / 公開情報 → **Obsidian**（下書き・体系化・品質チェック）→ 公開判断 → **doboku-note**（MD→MDX変換・SEO最適化・収益化導線）→ **iOSアプリ**（MDX→JSON変換・過去問データ）

### 一方通行の原則

- コンテンツは Obsidian → doboku-note の一方向で流れる
- doboku-note 側で直接コンテンツを作成・編集しない（緊急の修正を除く）
- Obsidian が唯一のソース・オブ・トゥルース

## Obsidian（ステージング）の設計

### フォルダ構成

| フォルダ | 内容 | 公開対象 |
|---|---|---|
| `exam/1doboku/` | 1級土木施工管理技士（最優先） | doboku-note + iOSアプリ |
| `exam/2doboku/` | 2級土木施工管理技士 | 将来 |
| `exam/pe/` | 技術士 | 将来 |
| `exam/admin-scrivener/` | 行政書士 | 将来 |
| `civil/` | 土木工学一般（テキスト・仕様書等） | 1級土木に関連する部分のみ |
| `law/` | 法律（憲法・民法・行政法等） | 行政書士対策として将来 |
| `note-articles/` | note有料記事の下書き | note.com |

### ノートの frontmatter 規約

| フィールド | 型 | 説明 |
|---|---|---|
| `title` | string | ノートのタイトル |
| `tags` | list | 分類タグ（例: `#1doboku`, `#concrete`, `#exam`） |
| `source` | string | 出典（PDF名、書籍名、URL等） |
| `status` | string | `draft` / `review` / `ready` / `published` |
| `target` | string | 公開先: `doboku-note` / `note-article` / `ios-app` / `none` |
| `exam-topic` | string | 試験の出題分野（例: `土工`, `コンクリート`, `施工管理`） |
| `date created` | date | 作成日 |
| `date modified` | date | 更新日 |

### status の定義

| status | 意味 | 次のアクション |
|---|---|---|
| `draft` | 下書き。内容が不完全 | 執筆を続ける |
| `review` | 内容は書けた。正確性・網羅性の確認待ち | `/audit-staging` で品質チェック |
| `ready` | 品質チェック通過。公開可能 | `/promote-to-site` でdoboku-noteに移動 |
| `published` | doboku-noteに公開済み | 更新がある場合のみ再promote |

## doboku-note（プロダクション）の設計

### 1級土木施工管理技士に絞る理由

1. **ユーザー体験**: 受験者が「ここだけで合格できる」と感じる一貫した体験
2. **検証速度**: 7月試験に向けて4-6月に需要ピーク → 短期間でフィードバック
3. **資産の集中**: 既存コンテンツが最も充実（土木一般編40 + 施工管理編100+ + 問題集24ファイル）
4. **導線の明確化**: サイト→note有料記事→iOSアプリ、全て同じユーザーに向く

### サイト構成（1級土木特化）

| ナビバー項目 | 内容 | ソース |
|---|---|---|
| **試験ガイド** | 出題傾向、得点戦略、学習ルート | exam-guide/ |
| **土木一般** | 土工・コンクリート・基礎工・測量 | civil-general/ |
| **施工管理** | 品質・安全・工程・環境・法規 | construction-management/ |
| **過去問** | 第1次(14年分) + 第2次(5分野) | exam-questions/ |
| **参考書・講座** | アフィリエイト記事 | certification/ |

### 現在の非1級土木コンテンツの扱い

| カテゴリ | ファイル数 | 対応 |
|---|---|---|
| 道路法 | 98 | ナビバーから除外。SEOインデックスは維持 |
| 憲法・民法・行政法 | 85 | ナビバーから除外 |
| 河川・水理学 | 67 | 1級土木の出題範囲に該当する部分のみリンクで接続 |
| 漁港設計 | 53 | ナビバーから除外 |
| 設計便覧・技術管理規定 | 150 | ナビバーから除外 |

**除外 ≠ 削除**。ページは残しSEOインデックスを維持する。ナビバーに表示しないだけ。

## iOSアプリの設計

### 役割分担

| | doboku-note | iOSアプリ |
|---|---|---|
| 解説 | 詳細な技術解説（テキスト全文） | アプリ内は要約のみ。「詳しくはdoboku-noteで」 |
| 演習 | 過去問を読む（閲覧型） | 過去問を解く（インタラクティブ型） |
| 学習管理 | なし | 正答率、チェック機能、学習記録 |

### データの流れ

Obsidian（過去問の正確性を確認）→ doboku-note（MDX）→ MDX→JSON変換スクリプト → iOSアプリ（bundled JSON）

| strategy-advisor | 変更なし |
| seo-auditor | 変更なし |

## 判断基準: いつ他分野を公開するか

1級土木で以下の条件を満たした後、次の分野を検討する:

| 条件 | 基準値 |
|---|---|
| 月間オーガニック検索流入 | ≥ 10,000 ユーザー |
| 1級土木コンテンツの体系化 | 試験全分野をカバー |
| note有料記事 | 月間売上 ≥ ¥30,000 |
| iOSアプリ | App Store公開済み |

全条件を満たしたら、次の候補（2級土木 or 技術士）を Obsidian から promote する。
