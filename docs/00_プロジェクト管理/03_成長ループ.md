## 6つのループ評価

### 1. 技術リファレンス SEO ループ（★★★★★）

**仕組み**: 技術ノートを公開 → 技術者が業務中に検索 → ブックマーク・社内共有 → 被リンク増加 → ドメイン権威向上 → 新規ページも上位表示しやすくなる → さらに検索流入増

| 基準 | 評価 | 根拠 |
|---|---|---|
| 適合度 | 5/5 | 公的技術資料の構造化はこのループに最適 |
| 現在の成熟度 | 2/5 | 766ページあり。SEO効果が出始める段階 |
| 実装コスト | S | 公開済み。title/description最適化で加速 |
| 成長速度 | 中期（3-6ヶ月） | SEOインデックス→上位表示に時間がかかる |
| 複利効果 | 高 | 被リンク蓄積→ドメイン権威→新規ページも上位に |

**アクション**: title/description最適化、構造化データ追加、内部リンク強化

### 2. 資格試験 SEO ループ（★★★★☆）

**仕組み**: 試験対策コンテンツ公開 → 受験者が試験前に検索 → 学習・ブックマーク → 合格後に後輩・同僚に共有 → 翌年の受験者がさらに検索

| 基準 | 評価 | 根拠 |
|---|---|---|
| 適合度 | 4/5 | 試験対策コンテンツの拡充が進行中 |
| 現在の成熟度 | 2/5 | 試験対策ガイド・問題集が変換済み |
| 実装コスト | M | 既存資産の再構成で対応可能 |
| 成長速度 | 中期（季節性あり） | 試験シーズンに急増、オフシーズンは減少 |
| 複利効果 | 中 | 毎年同じ試験があるため安定的に蓄積 |

**季節性**: 6月(2級)・7月(1級/技術士二次)・10月(1級二次)・11月(技術士一次/行政書士)

### 3. コンテンツ拡張ループ（★★★★☆）

**仕組み**: 既存ページ公開 → GSCで検索クエリ取得 → 未カバーのキーワード発見 → 新規ページ追加 → 検索流入増 → さらに多くのクエリデータ

| 基準 | 評価 | 根拠 |
|---|---|---|
| 適合度 | 5/5 | PDF→MDX変換スキルが整備済み。拡張コスト低い |
| 現在の成熟度 | 3/5 | 変換スキル整備済み。GSCデータの蓄積待ち |
| 実装コスト | S | 既存スキルで自動化可能 |
| 成長速度 | 中期 | GSCデータ蓄積に2〜3ヶ月必要 |
| 複利効果 | 高 | ページ数増→データ増→的確なコンテンツ追加 |

### 4. note 有料コンテンツ収益ループ（★★★★☆）

**仕組み**: 無料リファレンスで信頼構築 → 試験対策の切り口で有料記事（note.com）を販売 → 収益でコンテンツ投資 → 無料コンテンツ充実 → SEO流入増 → 有料記事の見込み客増

| 基準 | 評価 | 根拠 |
|---|---|---|
| 適合度 | 5/5 | 既存672ページの再構成で有料商品を作れる |
| 現在の成熟度 | 1/5 | 商品設計完了、テスト販売準備中 |
| 実装コスト | M | 記事執筆は必要だが、プラットフォームコストはゼロ |
| 成長速度 | 短〜中期 | 試験直前期に需要集中（予測しやすい） |
| 複利効果 | 高 | 記事は一度作れば毎年の試験シーズンに繰り返し売れる |

**棲み分け原則**: 無料=リファレンス・基礎知識、有料=再構成・要点整理・テンプレート

### 5. 教育機関引用ループ（★★☆☆☆）

**仕組み**: 体系的な技術資料を公開 → 大学・高専の教員が講義で引用 → 学生がアクセス → レポート・論文で参照 → .ac.jp からの被リンクでドメイン権威向上

| 基準 | 評価 | 根拠 |
|---|---|---|
| 適合度 | 3/5 | 教育向けに最適化されたコンテンツではない |
| 現在の成熟度 | 0/5 | 接点なし |
| 実装コスト | S | 特別な実装不要。コンテンツの質で勝負 |
| 成長速度 | 長期（1年以上） | 教育機関の採用サイクルは年度単位 |
| 複利効果 | 中 | .ac.jpからの被リンクはSEO的に高価値だが遅い |

**方針**: 当面は能動的に追わず、ループ1-3の結果として自然発生を待つ

## 推奨実装順序

| 順位 | ループ | 理由 |
|---|---|---|
| 1位 | 技術リファレンスSEO | コスト最小、既存資産活用、全ループの基盤 |
| 2位 | コンテンツ拡張 | ループ1のデータを燃料に自己強化 |
| 3位 | 資格試験SEO | 季節性を活かした追加流入源。note有料記事の集客導線 |
| 4位 | note有料コンテンツ | 高収益。ループ1-3で集客した見込み客を収益化 |
| 5位 | 教育機関引用 | 自然発生を待つ |

## ループ間の相乗効果

- ループ1（技術リファレンス）→ トラフィックがループ3（コンテンツ拡張）のGSCデータを生む
- ループ2（資格試験）→ 受験者流入がループ4（note有料記事）の見込み客になる
- ループ3（コンテンツ拡張）→ ページ数増がループ1の検索入口を拡大する
- ループ4（note収益）→ 収益がコンテンツ投資に回り、ループ1-3を加速する

全ループが互いを強化するフライホイール構造。起点はループ1（SEO流入）。
