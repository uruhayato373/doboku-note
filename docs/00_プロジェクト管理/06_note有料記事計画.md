## 棲み分け原則

| | doboku-note.com（無料） | note.com（有料） |
|---|---|---|
| 役割 | リファレンス・基礎知識・網羅的解説 | 再構成・要点整理・テンプレート・ドリル |
| 読者行動 | 検索で来て調べる | 「合格したい」動機で購入する |
| コンテンツ例 | 共通仕様書の全文解説、道路法の逐条解説 | 「1級土木 頻出50選」「技術士 論文テンプレ」 |

**原則: 無料サイトに既にある内容をそのまま有料化しない。無料=素材、有料=加工品。**

## 収益ファネル

doboku-note.com 無料コンテンツ（SEO検索流入）→ 信頼構築（専門性を証明）→ 試験対策ページ末尾のCTA → note 単品購入 → 価値を実感 → 定期マガジン購読 → 合格後に後輩へ口コミ → 新規流入

**CTA配置ルール**: 試験対策と直結するページのみに限定。全ページに貼らない。

| リスク | 対策 |
