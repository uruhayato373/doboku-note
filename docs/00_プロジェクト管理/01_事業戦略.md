## ビジョン

土木工学・施工管理・河川・道路・法律の技術知識を体系的に整理し、技術者と資格試験受験者の学習を支援する。

## 2事業の構造

**判断基準: Claude Code で自動化できる割合が高い事業に集中する。**

| 事業 | 役割 | 収益モデル |
|---|---|---|
| **doboku-note**（Webサイト） | SEO集客の入口。信頼構築の場 | AdSense + アフィリエイト + note有料記事 |
| **iOSアプリ** | スキマ時間の学習体験 | 広告 + サブスク（¥600/月） |

2事業は相互送客で成長を加速する:

- doboku-note → アプリ: 試験対策ページで「スキマ時間に過去問演習」を訴求 → DL
- アプリ → doboku-note: 「詳しい解説はdoboku-noteで」→ サイトPV増・E-E-A-T向上

### 捨てたもの

| 捨てたもの | 理由 |
|---|---|
| 書籍（KDP） | 校正・構成・プロモーションに人間の判断が大きく、自動化困難 |
| Udemy講座 | 顔出し・声出し・動画編集が必須。Claude Code の恩恵ゼロ |

## Pre-Mortem（失敗シナリオと対策）

| シナリオ | 対策 |
|---|---|
| アプリ開発が楽しくてサイト収益化を忘れる | 4月第1週はAdSense配置のみ。アプリは第2週から |
| 機能を盛り込みすぎてリリースが遅れる | MVP = 出題 + 正解表示 + チェック機能のみ |
| 7月の試験に間に合わない | 6月末TestFlight必須。間に合わなければ10月ターゲットに切替 |
| ダウンロードされない | 無料+全問解説でDL障壁を最小化。全試験ページにCTA |
| サブスク課金されない | 課金率0%でもAdMob広告だけで月1〜3万円を確保 |
| 既存競合（累計60万DL）に勝てない | 市場の5%で十分。差別化はモダンUI + サイト連携 + 2次対応 |
