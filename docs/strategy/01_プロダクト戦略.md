## Q1: 顧客は誰か？どんな洞察があるか？

### 対象セグメント（2026-07 実売反映）

規模（受験者数）は収益を予測しないことが実売で判明したため、**支払意思の実証度 × 実売シグナル**で優先度を決める（詳細な根拠・転換率は [11_STP分析2026-07.md](./11_STP分析2026-07.md)）。

| セグメント | 支払意思 | 実売シグナル（2026-05〜06） | 優先度 |
|---|---|---|---|
| **技術士（総合技術監理部門）受験者** | 極高・実証 | ¥160,480 / 56 件（収益エンジン） | 最優先（維持） |
| **技術士（建設部門 2 次）受験者** | 高・実証（転換 16.8%） | ¥88,100 / 59 件（成長株） | 最優先（拡大） |
| **1 級土木施工管理技士受験者** | 未実証（買い切り実売ゼロ） | 流入最大・note 売上 ¥0 | 高（マネタイズ設計が課題） |
| **2 級土木施工管理技士受験者** | 低（¥500〜2,480） | ¥2,400 / 4 件 | 低（会員で回収） |
| コンクリ系（主任技士・診断士） | 未実証 | note 未公開・¥0 | 据え置き（2027 判断） |

> 策定時（2026-04）の想定「Phase 1 = 総監＋1 級土木の 2 軸」は実売構造とずれた。実際に稼ぐのは「高支払意思 × 高切迫 × 差別化された立場（発注者視点）」のセグメントで、建設部門 2 次が第 2 の柱に育っている。

### 5 つの洞察

1. **「体験者の一次情報」を強く求めている** — 情報整理記事より合格者本人の論文・勉強記録・解答再現が圧倒的に信頼される。総監受験者に特に顕著
2. **体系的リファレンスが存在しないブルーオーシャン** — 総監キーワード集の体系的 Web 解説は市場に存在しない（2026-04-05 競合調査時点）
3. **受験前後でニーズが変わる** — 受験前は「網羅性・正確性」を求め、試験直後〜合格発表前は「解答再現・他者との比較」、合格後は「後輩への推薦」に変わる
4. **建設業の業務特性でスキマ時間学習ニーズが高い** — 現場監理職は長時間労働かつ移動が多い。スマホ + 短時間コンテンツの需要が大きい
5. **合格後に口コミで波及する** — 受験者コミュニティは SNS よりも社内推薦・勉強会経由で広がる。一人の合格者が複数の後輩を誘導するパターンが多い

## Q2: 顧客の主要な問題は何か？

| # | 問題 | 根拠・データ |
|---|---|---|
| 1 | **「ここだけで合格できる」ワンストップ学習リソースがない** | 技術士総監の無料 Web コンテンツは部分的（pejp.net・kope.info 等）。通し学習できる無料サービスは不在（競合調査 2026-04-05） |
| 2 | **合格体験者による一次情報コンテンツがほぼ存在しない** | 総監受験記を一次情報で発信しているブログ・YouTube はほぼ存在しない。情報整理屋中心のコンテンツが大半（03_事業戦略.md §競合環境） |
| 3 | **知識の断片化 — キーワード・過去問・論文構成が繋がっていない** | 現行サービスは過去問演習または解説記事のどちらか一方。キーワード理解 → 過去問演習 → 論文への実践という学習経路が成立しない |

## Q3: 解決策は何か？なぜこの方法が正しいか？

### 解決策

**「体系リファレンス × 合格体験者ポジション」のハイブリッド**

- **体系リファレンス（Web）**: 技術士総監 743 ファイルを中核に、建設部門・1 級/2 級土木・コンクリ系を加えた体系的 MDX コンテンツ。キーワード → 過去問 → 論文の学習経路を 1 ドメインで完結させる
- **合格体験者ポジション（note・YouTube）**: 運営者本人の受験記・解答再現・論文全文を「他人が絶対に書けない一次情報」として展開。E-E-A-T（経験・専門性・権威性・信頼性）を全軸で担保

### なぜこれが正しいか

| 検証軸 | 判断 |
|---|---|
| 競合が作れるか | **No** — 体系リファレンス（1,000 ファイル超）と合格体験（論文全文）を同一ドメインで持つ競合はゼロ（競合調査） |
| 自動化できるか | **Yes（一部）** — リファレンスは Claude Code で量産可能。SNS 投稿は TTS + 機械生成で人手ゼロ化 |
| 顧客の支払い意思があるか | **Yes・実証済み** — note 有料が 2026-06 に月 ¥217,760 を計上。総監パック ¥5,480〜9,800・建設部門科目 ¥2,980 が実際に売れている（[11_STP分析2026-07.md](./11_STP分析2026-07.md)） |
| SEO で勝てるか | **Yes（ロングテール）** — 情報系キーワードは大手スクールの独壇場。技術用語・過去問のロングテールは競合が弱く、総監キーワードはブルーオーシャン |

## Q4: どんな顧客体験を提供するか？一番大事なメリットは何か？

### 4 ステップ学習ジャーニー

```
[検索 → 発見]          [深掘り]              [習得・演習]          [口コミ]
Google 検索             サイト無料コンテンツ    note 有料商品         合格後
キーワード/過去問で       総監 743 ページ         模範解答・論文・パック   後輩・同僚に共有
上位表示               建設部門/1級2級土木      総監¥1,980〜9,800     → 次年度受験者が
（流入の85%が            ↓ 過去問演習は           建設部門¥2,480〜4,980  サイトを検索
 organic search）       ↓ PWA 過去問アプリ       ↓ スキマ時間演習
                       （資格別×共通エンジン・   （PWA・凍結中）
                        着手条件未達で凍結中）
```

### 最重要メリット

> **受験者が初めて「ここだけで総監を攻略できる」と感じる唯一のサービス**

他のサービスは「情報整理記事のみ」か「過去問演習のみ」か「高額有料講座」のいずれか。doboku-note は無料リファレンス（広さ）＋合格者一次情報（深さ）＋過去問アプリ（定着）を 1 ドメインで提供する唯一の入口となる。

## Q5: どう成功を定義・測定するか？

### NSM（North Star Metric）

> **月間オーガニック検索流入ユーザー数**

オーガニック流入はサービス価値（コンテンツ品質 × SEO）の結果指標であり、note 購買 / iOS DL / 広告収益の全収益チャネルの上流にある。

### 3 層 KPI

| 層 | 指標 | 目標 | 現況（2026-07） |
|---|---|---|---|
| **教育成功** | 技術士総監 2 次 合格率貢献（アンケートNPS） | NPS ≥ +40 | 未計測 |
| **NSM（流入）** | 月間オーガニック UU | 10,000 UU | organic 3,105 users/28日（top-100 集計・全体はこれ以上） |
| **収益** | 月間合計収益 | 次段階へ | **達成域：2026-06 note 有料で ¥217,760** |

### Phase 別成功基準

| Phase | 完了条件 | 状態 |
|---|---|---|
| **Phase 1** | 1 級土木 + 技術士総監の「ここだけで合格」体験が成立 | ✅ 成立（総監 743 ページ・土木ガイドが最大流入） |
| **Phase 2** | Web 月収 ¥15,000 達成 + 筆記合格発表 | ✅ 達成（月 ¥217,760・筆記合格判明済み） |
| **Phase 3（現在）** | 建設部門の収益化（実証済み）＋ 1 級土木のマネタイズ設計＋ PWA 判断 | 進行中 |

> 旧「Phase 2 着手条件 ¥15,000/月」は 2026-06 実績 ¥217,760 で大幅達成済み。現在の焦点は Phase 3＝**建設部門 2 次の深掘り（実証済み成長株）と 1 級土木の未収益化ギャップの解消**（[11_STP分析2026-07.md](./11_STP分析2026-07.md) の T 結論）。

### 収益 KPI（実績 → 目標）

| 時期 | 主な収益源 | 実績/目標 |
|---|---|---|
| 2026-06（実績） | note 有料（総監 ¥127,260 + 建設部門 ¥88,100 + 土木 ¥2,400） | **¥217,760（実績）** |
| 2026-07〜09 | 建設部門 11 科目網羅 + 総監（夏の試験期） | 実績の維持〜拡大 |
| 2026-10〜12 | 総監 10 月リローンチ + 1 級土木マネタイズ検証 | 上振れを狙う |
