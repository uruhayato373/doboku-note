# 検索キーワード戦略 — 狙う読者 × 検索語 × 受け皿のページ

最終更新: 2026-09-27

## 結論

- 検索は **4 つのクラスター** で持つ。資格名・土木公務員・施工管理の転職・技術図書（共通仕様書など）。クラスターごとに狙う読者と受け皿のページを決め、機械の正本は [`search-strategy.json`](../../config/search-strategy.json)。
- 改善の中心は **11〜30 位で表示がある検索語を 1 桁へ上げる** こと。新しいページを増やすより、既に表示されているページの手直しの方が早く効く。
- KPI ツリー（[15_KPIツリー.md](./15_KPIツリー.md)）の「サイト」の段に、クラスター別の **1 桁順位の検索語数** と **表示回数** を置く。順位の件数そのものを売上の代わりにしない。
- Google 検索は流入全体の一部（自然検索の大半は Bing。[measurement-incidents.md](../../.claude/knowledge/reference/measurement-incidents.md)）。改善候補（ページ単位）は Google の検索語×ページ集計（GSC）で出す。Bing は毎週の CI（`fetch-bing-webmaster`）で検索語とページを別々に取れるが、検索語×ページの組が無いので、クラスター別に「1 桁の検索語数」と「11〜30 位の検索語」だけを別枠で出す（`npm run report-search-opportunities` の [Bing]）。2026-09-27 時点で資格名クラスターの Bing の検索語 102 件はすべて 1 桁で、11〜30 位の候補は 0 件＝Bing では既に上位にいて、伸ばす余地は Google 側にある。

## クラスター

| クラスター | 狙う読者 | 検索語の型 | 受け皿 | 2026-08-25〜09-21 |
|---|---|---|---|---|
| 資格名 | 受験を決めた人・受験中の人 | 資格名＋解答例・年度・論文・キーワード | `/exam/` の過去問・ガイド・キーワード | 表示 392・1 桁 22・11〜30 位 39 |
| 土木公務員 | 自治体・国の土木職（発注者） | 公務員・土木職・発注者＋資格・実務 | 資格ハブ・公務員向けガイド・`/practice/` | 表示 12・1 桁 1・11〜30 位 6 |
| 施工管理の転職 | 施工管理を続けるか迷う人 | 転職・辞めたい・年収・キャリア | 1 級土木のキャリア記事・`/topics/` | 表示 32・1 桁 0・11〜30 位 4 |
| 技術図書 | 共通仕様書・基準書を実務で引く人 | 発行元（地整・都道府県）＋共通仕様書 | `/standards/` | 表示 236・1 桁 22・11〜30 位 18 |

- **資格名** は商品（note・ココナラ）に最も近い。年度の解答例（「1級土木 2次 解答例 令和7年」11 位など）とキーワード記事（技術士 CPD）が 11〜20 位に多い。
- **土木公務員** は運営者の経歴（元・自治体の土木職）が最も効く。検索量は小さいが競合が少なく、1 ページ目に届く位置（10〜15 位）にいる。方針は [13_土木公務員SEO戦略2026-08.md](./13_土木公務員SEO戦略2026-08.md)。
- **施工管理の転職** は表示が小さく、平均 60 位台。アフィリエイト（転職一本）の入口なので、既存のキャリア記事で年収・辞めたい理由の検索意図に答えているかを先に直す。
- **技術図書** は `/standards/` 公開後 1 か月で表示 236 まで伸び、発行元名＋共通仕様書の語が 10〜12 位に並ぶ。ページ名・見出しに発行元名と「土木工事共通仕様書」を正確に入れ、章の目次から探しやすくするだけで 1 ページ目に入る見込みがある。国・都道府県の技術図書を「見やすく整理した入口」として広げるのは、このクラスターで 1 桁が取れてから。

## 改善サイクル

1. **候補を出す（機械）**: `npm run report-search-opportunities` がクラスターごとに、11〜30 位で表示のある検索語をページ単位に束ねて並べる。SEO Rank Watch で観察中のページ・既にカードがあるページ・旧 URL（`/docs/`）には印が付く。
2. **起票する（週次）**: 週次レビューが印の無い候補を上から最大 3 件、バックログへ起票する。カードには対象ページ、検索語と順位・表示、直す箇所（title・description・冒頭で答えること・見出し・内部リンク）を書く。
3. **直す（既存ページ）**: 検索語に対して、タイトルと冒頭で答えているか、発行元名・年度などの語が正確か、関連ページからリンクされているかを直す。新しいページは作らない。
4. **確かめる（月次）**: 反映から 28 日後の集計で、対象の検索語の順位と表示を比べる。1 キーワードを 7 日単位で追う実験は既存の SEO Rank Watch（[seo-rank-watch.md](../../.claude/knowledge/reference/seo-rank-watch.md)）に登録して行う。

- **旧 URL（`/docs/`）が 11〜30 位にあるとき** は本文を直さない。新 URL への転送と内部リンクが正しいかを確かめ、Google の置き換えを待つ。
- **受け皿の外のページが出ているとき** は、狙いのページへの内部リンクを足すか、そのページを受け皿として認めるかを決める。

## 月次で見ること

- クラスター別の表示・クリック・1 桁の検索語数・11〜30 位の検索語数と、約 28 日前との差（同じ長さの期間どうし）。
- 起票したカードの対象ページで、順位が上がったか。上がらなければ、検索意図とページの中身がずれていないかを見直す。
- クラスターの追加・削除や受け皿の変更は月次でだけ行い、`search-strategy.json` とこの文書を同時に直す。
