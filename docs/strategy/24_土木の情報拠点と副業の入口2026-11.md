# 土木の情報拠点と副業の入口（2026-11）

最終更新: 2026-11-11（運営者が方向を決めた。戦略文書 01・02・18 への反映は DN-1119）

## 結論

**55 歳までの doboku-note は、「発注者の目で配線した土木の情報拠点」に育てる。** 試験（施工管理・技術士）・制度（建設業許可・経審）・基準（共通仕様書・法令）・政策（白書）を一か所でつなぎ、いまは施工管理の教材へ、運営者の行政書士の登録後は許可・経審・補助金の代行へ送る。行政書士・中小企業診断士・技術士は別々の仕事にせず、「地方の中小建設業者の書類・経営・技術をまとめて見る人」という一本の看板に束ねる。新しいサイト・アカウントは作らない。

この文書は、2026-11-11 の運営者との検討を引き継ぐための記録で、なぜその結論になったか・何を退けたかを残す。やることは DN-1119（戦略文書への反映）・DN-1120（入口記事と導線）・DN-1121（経審の点数ツール）、行政書士領域の展開計画は DN-0491。

## 判断の契約（共通事業方針）

- 読者の課題: 一人親方・中小建設業者が、技術者の要件を満たせず建設業許可や入札の等級を取れない・保てない。相談先が手続き・経営・技術でばらばら。
- HARM: M（受注・収入）と A（資格・事業の継続）。
- 提供価値と支払う理由: 資格で要件を満たす近道と、そのための教材。登録後は申請の代行。窓口が 1 つで、発注者の目で書類を見る。
- 需要の証拠: 教材は実売がある（2026-07 の note 総額 ¥275,140）。**事業者向けの検索需要は未検証**（下の「実測」）。
- 次の検証: 悩みから入る記事 1 本（DN-1120）と経審の点数ツール（DN-1121）を出し、公開から 28 日・84 日の表示と検索語を見る。

## 1. 検討の流れ（問いと答え）

| 運営者の問い | 答え | 根拠 |
|---|---|---|
| 行政書士・診断士・技術士で副業の計画を立てられるか | 立てられる。3 つを 1 本の看板に束ねる | 報酬を得て補助金の申請書類を作れるのは行政書士だけ（行政書士法 19 条・令和 8 年 1 月施行の改正）。診断士の計画づくりと組むと、計画→申請→実行を 1 人で完結できる。技術士・元発注者はほかにない組み合わせ |
| 資格の教材を行政書士・診断士へ広げるのはどうか | やる。ただし合格後。切り口は「技術者・公務員が働きながら取る」に絞る | 払い手は受験者個人で、技術士の教材と同じ型。一方で大手予備校と無料動画の激戦区で、合格するまで権威が無い。試験は診断士が 8 月・10 月、行政書士が 11 月で、技術士（7 月）の後の谷を埋める |
| 診断士＋IT・AI で建設 DX のコンサルはどうか | 本命にしない。記事 1 本で反応を見るまで | 行政 DX 向けの note は 2 か月で ¥600 だった（払い手がいなかった）。今回は払い手が建設会社なので条件は違うが、IT ベンダーが無料で営業に来る市場で、払う理由が見えていない |
| 建設業許可・経審の記事で事業者を拾い、施工管理の資格へ送れるか | 送れる。入口は「技術者がいない」という悩みに絞る | 施工管理技士は、営業所技術者の要件と経審の技術職員の点数を左右する。受験者個人に加えて、会社が経費で払う理由がある |
| 将来、自分が代行する入口にもなるか | なる。時間差が味方になる | SEO は育つのに 1〜2 年かかり、代行ができるのは登録後。いま書けば、始める時点で検索に載っている。許可の更新（5 年ごと）・決算変更届と経審（毎年）は継続収入で、電子申請なら遠隔でも受けられる |
| 共通仕様書・白書・政策まで集める拠点に育てられるか | 育てられる。条件は「写す」でなく「つなぐ」 | 文書ページは集客の柱ではなく土台（専門性の評価・過去問の根拠・運営者の看板）。原文の写しは国土交通省の PDF に勝てない |
| AI をどう使うか | AI が量を、運営者が判断を受け持つ | 収集・整理・照合・SEO・配信の切り分けは AI。何を集めるか・どうつなぐか・最終の正誤は運営者。大量の自動生成ページは検索で減点される |

## 2. 退けた案と、その理由

- **「建設業許可 取り方」のような広い語を狙う** — 行政書士事務所と都道府県の手引きが上位を占める。検索する人は代行を頼みたい人で、教材につながらない。
- **新しいサイト・アカウントを作る** — 面を増やさない方針を変えない。行政書士・診断士の教材も、建設業の読者と重なる切り口で doboku-note の中に置く。
- **あらゆる文書を集める** — 手が回らなくなるか、写しだけの薄いページが増える。集める基準は「発注者の判断が足せるか」。
- **建設 DX コンサルを本命にする** — 再開の条件は、実測で月 1 万円を超えるか、運営者の退職が 2 年以内に入ること。
- **3 つを同時に始める** — 順番は、建設業許可・経審から教材への導線（いまから）→ 行政書士・診断士の教材（合格後）→ 代行（登録後）。

## 4. 導線（制度が橋になる）

| 制度 | 施工管理技士との関係 |
|---|---|
| 建設業許可 | 営業所ごとに営業所技術者が要る。1級・2級は資格だけで要件を満たせる。資格が無ければ実務経験の証明が要る |
| 特定建設業の許可 | 営業所技術者は原則 1級（または技術士） |
| 経審の技術職員の点数 | 資格の区分で点数が変わり、入札の等級に効く（区分ごとの点数は DN-1121 で告示と照合する） |
| 現場への配置 | 下請への発注が大きい工事では監理技術者（1級）が要る |

| 入口の検索（悩み） | 誰が | 送る先 |
|---|---|---|
| 営業所技術者の資格が無い／実務経験を証明できない | 許可を取りたい一人親方・小さな会社 | 2級土木の教材 |
| 500 万円以上の工事を請けたい | 一人親方 | 2級土木の教材 |
| 特定建設業に要る 1級がいない／監理技術者が足りない | 中小の会社 | 1級土木の経験記述 |
| 経審の技術職員の点数を上げたい | 経営者・総務 | 点数のツール → 1級・2級の教材 |
| 技術者が辞めると許可はどうなるか | 経営者 | 後継の資格者を育てる |

検索語が実在するかは、DN-1120 で Google サジェストと GSC で確かめてから題名を決める。

| 段階 | サイトの役割 | 収入 |
|---|---|---|
| いま〜行政書士の合格 | 技術者の要件・経審の記事で検索に拾われ、施工管理の教材へ送る | 教材 |
| 合格〜登録 | 記事を育て、事業者の悩みの実例をためる | 教材 |
| 登録後 | 同じ記事から許可・経審・補助金の代行の相談へ送る | 教材と代行 |

## 5. 集めるもの・集めないもの

| 集める | 集めない |
|---|---|
| 過去問の正誤の根拠になる共通仕様書の章（DN-0879） | 原文を写しただけの文書一覧 |
| 許可・経審を、技術者の要件の側から解説したもの | 手続きの一般論（行政書士事務所と同じ内容） |
| 白書・政策を、試験と現場の言葉に直したもの | ニュースの要約 |
| 発注者から見た施工の勘所 | 守秘に触れる個別の事例 |

## 6. 測り方

- 平常時のクリック（試験の当日ページを除く）。
- 文書ページ（/standards・/docs・/laws）から資格・教材ページへ流れた数。文書ページ自体のクリックでは測らない。
- 入口記事とツールの、事業者向けの語での表示。

KPI の木と `config/business-direction.json` に足すかは DN-1119 で決める。

## 7. 守ること・未確認

- 行政書士の登録前は、一般的な解説まで。報酬を得た書類作成・個別の相談の案内は書かない（副業の線引きは `/exam/pe-construction/guide/fukugyou-dokuritsu`）。
- 登録と受託をいつから始められるかは未確認。運営者が勤め先の決まりを確かめる。
- 運営者が以前の職場で関わった事業者の案件は受けない。前の職場が特定できる話は書かない。
- 法令は改正が多い。名称（専任技術者→営業所技術者）・金額の基準・検定合格後の実務経験の年数・経審の点数は、公開前に一次情報で確かめる。この検討の中で出た数値は照合していない。
- 能動の時間は資格の教材が先。文書の区画は低い手間で積む層として扱う。
- 中小企業診断士は、運営者が過去問を 1 年分解いてから受験を決める。資格レジストリでの扱いは DN-1119。

## 8. 見直す条件

- 入口記事とツールを出して 3 か月、事業者向けの語で表示が出ない → 受験者向けの入口（資格手当・取るメリット）に絞る。
- 文書ページから資格・教材ページへの遷移が増えない → 文書の区画は増やさず、過去問の根拠リンクだけ続ける。
