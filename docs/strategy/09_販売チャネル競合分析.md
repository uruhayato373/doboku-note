## 1. 競合ポジショニングマップ

### 1.1 マップの軸

- **横軸 = 権威性の源泉**: 「実績型」（合格・添削実績・元職位）か「物量・ツール型」（記事数・AI 活用・教材形式）か
- **縦軸 = 価格帯**: 低価格（〜¥1,000）／中価格（¥1,000〜3,000）／高価格（¥3,000〜12,000）／サブスク

### 1.3 マップから読める構造

1. **「実績型 × 高価格」の右上は空いている** — 実績型で高価格を張るのは sosou_nino（サブスク）と gijyutsushi（最大¥9,500）のみ。「合格者 × 元公務員（発注者）× 買い切り高単価パック」の枠は doboku-note しか立っていない。全記事パック ¥9,800 はこの空白を取りに行く商品。
2. **低価格帯はレッドオーシャンかつ「量産だけでは売れない」** — study_room358（PDF 185 本でフォロワー22）が傍証。例外はどぼくじら（¥500×500部超）で、これは「2級・暗記・赤シート」という**フォーマットの的中**であり量産の勝利ではない。
3. **フォロワー規模と商品力は別変数** — miyabi_labo（332）・kensetsu_dx_data（318）・どぼくじら（280）は中規模オーディエンスで回っている。sosou_nino（3,801）だけが桁違いで、これは毎日更新×共同マガジンの**配信頻度とリーチの蓄積**による。商品の質では説明できない。
4. **高価格の検証済みアンカーは2つ** — sosou_nino の月額¥9,900と、gijyutsushi の「R8必須8題＋おまけ」¥9,500。いずれも会員数・販売数は未確認なので、WTPの確証ではなく掲載価格の上限観測として扱う。gijutsushisokan の旧¥12,000商品は最新取得で確認できず、現行の価格根拠から外す。

## 2. doboku-note の差別化余地

### 2.1 「元公務員（発注者）合格者」は chansato_st と差別化できるか → **できる（市場が別・深さが別）**

| 観点 | chansato_st | doboku-note |
|---|---|---|
| 主戦場 | 1級・2級土木の**経験記述添削**（cocona 800名超） | 技術士総監・建設部門の**模範解答**＋土木セコカンは従 |
| 元公務員の使い方 | 添削者の信頼性担保（採点者目線） | **論述内容そのもの**（発注者視点の課題設定・住民対応・総合調整を答案に書き込む） |
| 商品形態 | 添削サービス＋LINE 2ステップ販売 | 買い切り教材（模範解答・パック） |

- 正面衝突するのは「1級・2級土木の経験記述」領域だけで、そこでも chansato_st は**添削（労働集約）**、doboku-note は**完成答案集（教材）**と商品形態が違う。
- ただし doboku-note が伴走メンバーシップ（添削）を立ち上げると正面競合になる。その際の差別化は (1) **保有資格の厚み**（総監＋建設部門＋1級土木ほか計6資格 — chansato_st は施工管理系中心）、(2) **サイト＋note の教材資産との一体化**（添削だけ売る競合に対し「教材で学び → 添削で仕上げる」導線を自前で持つ）、(3) **定員制の希少性運用**。
- **学ぶべき点**: chansato_st の「無料配布 → 高単価」2ステップ販売と cocona での実績の見せ方（添削件数の公開）は、伴走メンバーシップ設計（→ `content/note/1級・2級土木/noteコンテンツ計画.md`）にそのまま輸入する。

### 2.2 「模範解答の深さ・発注者視点」は kensetsu_dx_data・gijyutsushi に優位か → **優位を主張できる（ただし主張の仕方に条件）**

- **kensetsu_dx_data（¥1,080〜1,980・AI 制作）**: 制作手法が最も近い（NotebookLM・Claude・白書紐付け）。差は「AI で作ったものを、誰がどの実務経験で検収したか」。doboku-note は元発注者（全11分野の発注・監督・積算審査）＋合格3科目の検収者がいる。**価格 1.5〜2 倍（¥2,480〜3,980）はこの検収者の差で正当化できる**。逆に言うと、訴求で「AI 活用」を前面に出すと kensetsu_dx_data と同じ棚に並んで価格だけ高い商品になる。**前面に出すのは「元公務員（発注者）が書いた／検収した」であり、制作手法ではない**。
- **gijyutsushi（R8必須8題＋おまけ ¥9,500・A判定実績）**: 「A 判定答案」訴求は強い。対抗軸は (1) **科目の網羅**（gijyutsushi は必須中心、doboku-note は必須Ⅰ＋選択11科目に展開済み）、(2) **発注者視点コメント**（A 判定実績は「受かった答案」、発注者視点は「採点側の問題意識」— 出題者は発注行政側であり、こちらは競合が構造的に真似できない）、(3) 価格は BK-I ¥3,480 ＜ ¥9,500 で下から入って科目パック ¥4,980 で並ぶ。**価格で殴り合う必要はなく、視点の独自性で別商品化する**。

### 2.3 sosou_nino に「質の勝負」で勝てる根拠 → **勝負の土俵を変えれば勝てる（物量・頻度の土俵では永久に勝てない）**

sosou_nino の強さは 6,312 記事・64 マガジン・毎日更新・フォロワー 3,801 という**蓄積とリーチ**であり、後発が同じ土俵で追うのは不可能。質の勝負が成立する根拠は次の 3 点。

1. **物量は買い手にとってコストでもある** — 64 マガジンは「どれを買えばいいか分からない」を生む。doboku-note は 17 ペルソナ × 立場別という**構造化された全集**＋「3分で自分の1冊が決まる」無料ハブ記事（→ 総監 noteコンテンツ計画.md 末尾のハブ記事設計）で「迷わせない」を差別化価値にする。
2. **ペルソナ特化のフル模範論文は物量で代替できない** — 「自治体 下水道担当の立場で書いた R03-R07 フル論文」は、毎日更新の汎用記事を何百本積んでも代替されない。買い手は自分の 1 本が欲しい。
3. **買い切り vs サブスクの構造差** — sosou_nino の総監プラン ¥9,900/月は 3 ヶ月購読で約 ¥30,000。doboku-note は全記事パック ¥9,800 買い切りで「総額が読める・解約管理不要」。**比較訴求の弾として「月額換算」を LP に持てる**（名指しはしない）。
4. **借りられるものは借りる** — sosou_nino の共同マガジン戦略（他クリエイターのリーチ活用）は、フォロワー約25の doboku-note にこそ必要な手法。総監・建設部門系の共同マガジンへの参加（または非競合クリエイターとの相互収録）を集客施策として検討する（→ §4 アクション3）。

### 2.x 無料キャリア note は「販売競合」ではなく「集客競合」

キャリア（転職）系の無料 note は、有料商品を奪い合う相手ではない。奪い合うのは**読者の可処分時間と検索流入**であり、収益化の経路も広告・アフィリエイトで別系統になる。したがって本書（販売チャネルの価格・品揃え）の分析対象からは外し、**勝ち型と差別化は `07_競合調査.md`「転職メディア競合（キャリア記事の勝ち型）」で扱う**。

価格比較の土俵に乗せない代わりに、集客面では note → サイトのキャリア hub → 柱記事という動線の質で比べる。

### 6.2 doboku-note もくじの現状ギャップ（実測 2026-07-06）

- L1/L2 もくじ4本は**生 Markdown リンクの羅列**（土木もくじ=リンク37・カード1、L1=リンク69・カード2）。1リンクあたり約40字で、導入文・カードがほぼ無い。

### 6.3 リライトの型（差別化を効かせる）

1. **状況別診断 →「まず1冊」**（比較型/チェックリスト型・selling-structures §7/§6）: 競合で診断導線を持つのは事実上ゼロ（自社「総監マガジンの歩き方」のみ）。sosou_nino の物量に対する「迷わせない」差別化（§2.3-1）をもくじ本体でも効かせる。
2. **有料は〈太字見出し＋2〜4文の導入（誰向け/何が入る/どう使う）＋ bare URL 単独行カード〉**: A型に追いつく。文言・価格は note のリンクカードが表示するので **¥は本文に書かない**（gijyutsushi は ¥ をインライン併記するが、カードと重複するので doboku-note はクリーンに保つ）。
3. **硬派ブランドを崩さない**: 競合は絵文字ヘッダー多用（sosou/gijyutsushi）。doboku-note は絵文字禁止のまま「発注者・合格者視点」の信頼で差別化する。
4. **社会的証明の軽い活用**: どぼくじら「500部突破」・chansato_st「cocona 800名」のように、競合は実績を明示する。doboku-note も「発注者＝出題者側の視点」「合格者が書いた/監修した」を各セクション冒頭に一文で置く（誇大・合否約束はしない＝selling-structures §制約）。

この6章を根拠に、もくじ4本を「導入 → 状況別まず1冊 → 有料（導入文＋カード）→ ロングテール列挙温存 → 無料 → 会員/逆引き」へ全面リライトする（`content/note/*/もくじ` article.md）。
