# チャネル別の商品設計（2026-11）

最終更新: 2026-11-02（KPI の目標とココナラの打ち手は運営者が承認）

## 結論

**note を本店、KDP を発見の場、ココナラを人手のサービスの場**に分け、同じ中身を 2 つのチャネルで安く売らない。受取の 9 割は note から来ており、1 件の手取りもパックが最も大きいので、デジタル教材の新商品はまず note に出し、単価はパックで上げる。KDP は 1 冊の手取りが note のマガジンの 3 分の 1 ほどなので、新刊は作らず既刊を保つ。ココナラは評価 0 が最大の壁なので、PDF ではなく添削だけに絞り、入口の価格で評価を集めてから本命の添削へ進める。

正本の値（役割・手数料・SWOT・4C・KGI/KPI）は `config/channel-strategy.json`、数字は `npm run channel-economics` と管理画面 戦略＞資格と市場＞チャネル設計 で見る。競合の価格と品揃えの詳細は [09_販売チャネル競合分析.md](./09_販売チャネル競合分析.md)、KPI の木は [15_KPIツリー.md](./15_KPIツリー.md)。

## 判断の契約（共通事業方針）

- 読者の課題: 記述式の答案を自力で仕上げられない受験者が、試験前に「書ける形」を短時間で手に入れたい。自分の答案を誰かに直してほしい人も一部にいる。
- HARM: A（資格・成長）。
- 提供価値と支払う理由: note＝答案の型と模範解答をまとめて、時間を買う。ココナラ＝自分の答案を合格者が直す（note ではできない）。KDP＝過去問をまとめて手元で読む。
- 需要の証拠: note の販売 347 件（2026-05〜10）。KDP のロイヤリティ 月 ¥6,000〜10,000。ココナラは受注 4 件で、直近 30 日は閲覧 781・受注 0。
- 次の検証: ココナラの入口の価格で評価が集まるか（下の「ココナラ」）、KDP が note の同じ商品を食っているか（未検証）。

## 2. チャネルの役割と売るもの

| チャネル | 役割 | 売る | 売らない |
|---|---|---|---|
| note | 本店 | 最新年度の模範解答と予想問題・資格ごとのまるごとパック・比較の基準の単品 | 人手の添削・指導 |
| KDP | 発見の場（Amazon の検索で note に来ない読者に届く） | 択一の過去問の網羅（読み放題で読まれる）・旧年度の模範解答集 | note の最新年度・予想問題・パックと同じ中身を note より安く |
| ココナラ | 人手のサービスの場 | 経験記述・小論文・論文の添削、骨子からの指導 | note と同じ PDF 教材・作成代行 |

- **KDP**: 価格は今のままにする。70% 帯の上限 ¥1,650 に置いた本を値上げすると 35% 帯に落ちて、1 冊の手取りが下がる。新刊は note で売れた商品の旧年度・択一の網羅だけにし、note の最新年度と同時には出さない。
- **note**: 単独で 1 件も売れていない有料商品 86 本は、パックにまとめるか売り場から外す。パックの値上げ余地はある（競合 note の中央値は 2026-07 の ¥10,450 から 10 月の ¥15,140 へ上昇）が、上げるかは販売の山の前に 1 商品で試してから決める。

## 5. ココナラ: 伸びない理由と打ち手

**事実**: 出品は 34 件のうち 32 件が休止（30 件は廃止＝retired、2 件は不在の休止）。出品中は 2 件（土木の経験記述の添削 ¥6,000・主任技士の小論文の添削 ¥5,000）。直近 30 日は閲覧 781・お気に入り 0・受注 0。最後の売上は 9/25。評価は 0。2級土木の二次（10/25）が終わり、季節の山も過ぎた。

**読み**（推測）: 閲覧はあるのに買われないのは、評価 0 で高評価の競合（累計 1,000 件超・評価 4.97）と並べられるため。価格は相場の中にあり、主因ではない。

**打ち手**（2026-11-02 に運営者が承認。作業時間が上限なので、受けられる件数の範囲で）。2 の入口の添削に合わせて、[04_収益化戦略.md](./04_収益化戦略.md) の現在の方針 4 をココナラの添削に限って改めた:

1. **主任技士の小論文の添削を本試験（11/29）まで前に出す**。競合がほぼいない唯一の型で、閲覧も 83→191 と伸びている。サイトの主任技士の記事から出品へ送る。
2. **入口の添削を ¥2,000〜3,000 で 1 本置き、評価を集める**（技術士の論文 1 問・経験記述 1 テーマなど範囲を絞る）。評価 5 件を 2027-03 までの目標にする。競合の YOSHI＠技術士（¥2,000〜2,500・98 件・評価 4.95）がこの型で売れている。
3. **季節の前にだけ開く**: 1級二次（試験の 4〜8 週前の 8〜9 月）・2級二次（9〜10 月）の添削は、収益カレンダー（`config/revenue-calendar.json`）の CTA 切り替えの日に再開し、試験後に休止する。
4. **PDF の出品は戻さない**（note と同じ中身を安く売ることになり、note の手取りを削る）。
