## ビジョン

土木・建設系の実務資格試験対策ハブとして、技術ノートとアプリで受験者と技術者の学習を支援する。**現況（2026-07）**: 技術士総監・技術士建設部門・1 級/2 級土木を稼働、コンクリート主任技士・診断士を下書き整備中。将来的に行政書士（建設業許可等の法務系）等へ段階的に拡張する。

**軸**: 運営者本人が技術士総監 2 次筆記試験に合格済み（＋建設部門は道路・河川・都市計画の 3 科目合格）。合格体験（学習ログ・解答再現・論文全文）と発注者視点を中核差別化に据え、情報整理屋中心の競合に対する決定的優位を形成する。

## 事業構造

**判断基準: Claude Code で自動化できる割合が高い事業に集中する。+ 合格体験者ポジションを活かせる事業に重点投資する。**

| 事業 | 役割 | 収益モデル | 状態（2026-07） |
|---|---|---|---|
| **doboku-note**（Webサイト） | SEO集客の入口。信頼構築の場 | AdSense + アフィリエイト（転職一本）+ note有料記事 | **稼働中**（流入の 85% が organic search） |
| **note 有料（模範解答・論文・パック）** | 一次情報による高単価商品 | 総監 ¥1,980〜9,800 / 建設部門 ¥2,480〜4,980 / 土木 会員＋買い切り | **稼働中・主力**（2026-06 月 ¥217,760） |
| **YouTube / SNS（TTS 量産）** | サイト送客（自動化） | 広告収益＋動線 | **稼働中だが流入寄与は実測 1% 未満**（要再評価） |
| **PWA 過去問演習アプリ** | スキマ時間の過去問演習（資格別 PWA × 共通エンジン） | 無料＋AdSense → note 買い切りアンロック → メンバーシップ | **凍結中**（iOS から移管。[05_プロダクト/06_PWA過去問アプリ設計方針.md](../products/06_PWA過去問アプリ設計方針.md)） |
| Kindle（KDP） | 論点別再構成の物販 | 買い切り（印税 70%） | **凍結解除・試作段階**（[Kindle 管理SSOT](../../content/kindle/strategy.md)） |

各事業は相互送客で成長を加速する:

- doboku-note → note 有料: 記事内 CTA で熱量の高い受験者に模範解答・パックを販売（実証済みの主動線）
- YouTube/SNS → doboku-note: 概要欄・プロフィールから記事リンクで送客（現状の流入寄与は小）
- doboku-note/note → PWA: 「過去問演習はアプリで」（PWA 稼働後）
- PWA → doboku-note: 「詳しい解説はサイトで」→ サイトPV増・E-E-A-T向上

### 捨てたもの

| 捨てたもの | 理由 |
|---|---|
| 書籍アフィリエイト（Amazon） | note とカニバる。2026-06-25 完全廃止。アフィリは転職一本に集約 |
| Udemy講座 | 動画編集が必須。YouTube で代替可能 |
| 受験記型YouTube | TTS 量産に転換。受験記コンテンツは note 有料に集約 |
| iOS ネイティブアプリ | Apple 手数料 30%・$99/年を回避するため過去問用途は PWA へ移管 |

## 競合環境（要約）

競合の詳細・市場規模・SEO 脅威度の真実源は資格別に分離済み。ここでは事業戦略上の要点のみ記す。

| 論点 | 要点 | 真実源 |
|---|---|---|
| **資格別 市場・競合サイト・SEO 脅威度** | 大手スクールが情報系キーワードを独占（正面勝負は不利）。総監はキーワード集の体系的 Web 解説が市場に不在＝ブルーオーシャン。建設部門 2 次はフル模範解答の Web 無料公開が空白 | [07_競合調査.md](./07_競合調査.md)（資格別統合版） |
| **note 有料・SNS の価格/ポジション** | 「実績型 × 高価格 × 買い切り」の枠は doboku-note のみ。全資格で現行価格維持が妥当 | [09_販売チャネル競合分析.md](./09_販売チャネル競合分析.md) |
| **実売で検証した勝ち筋** | 高流入の広い資格でなく「高 WTP × 高切迫 × 発注者視点」が稼ぐ。建設部門 2 次の転換 16.8% が最高 | [11_STP分析2026-07.md](./11_STP分析2026-07.md) |

**構造的な独自性**: 複数の土木・建設資格を同一サイトで横断学習でき、**運営者自身が合格者（総監・建設部門 3 科目）＝発注者（出題者側）視点**という組み合わせは競合に存在しない。

## 成長戦略：3つのループ × ロングテールSEO

### SEO戦略の基本方針

| 方針 | 理由 |
|---|---|
| **情報系キーワードを避ける** | 「試験日程」「勉強法」「合格率」は大手スクールの独壇場 |
| **ロングテールに集中する** | 「令和7年 土木一般 問3 解説」「技術士 総監 フォロワーシップ」等 |
| **技術士総監を優先公開する** | 競合が弱いブルーオーシャン |
| **★合格体験ベースのE-E-A-T強化** | 運営者は総監合格者（土木系公務員〔発注者〕の退職者）。合格者の体験記事で「経験」軸を圧倒的に強化 |
| **構造化データで強化する** | Quiz/FAQ schema で検索結果の表示面積を拡大 |

### 1. 技術リファレンス SEO ループ（★★★★★）

**仕組み**: 体系的な技術ノートを公開 → 技術者が業務中に検索 → ブックマーク・社内共有 → 被リンク増加 → ドメイン権威向上 → 新規ページも上位表示しやすくなる

| 基準 | 評価 |
|---|---|
| 適合度 | 5/5 |
| 現在の成熟度 | 4/5（1,000 ファイル超・土木ガイドが最大流入を獲得） |
| 実装コスト | S（公開済み。SEO最適化で加速） |
| 成長速度 | 中期（3-6ヶ月） |
| 複利効果 | 高 |

### 2. 資格試験 SEO ループ（★★★★☆）

**仕組み**: 試験対策コンテンツ公開 → 受験者が試験前に検索 → 学習・ブックマーク → 合格後に後輩・同僚に共有 → 翌年の受験者がさらに検索

| 基準 | 評価 |
|---|---|
| 適合度 | 4/5 |
| 現在の成熟度 | 2/5 |
| 実装コスト | M |
| 成長速度 | 中期（季節性あり） |

**季節性**:
- 4月: 1級土木申込締切
- 6月: 2級土木第一次試験
- 7月5日: 1級土木第一次試験
- **7月中旬: 技術士二次試験**（買い手＝受験生の需要ピーク）
- 10月: 1級土木第二次試験
- **10月末: 技術士 筆記合格発表**（買い手の口頭試験対策需要が立つ。運営者は合格済みのため iOS 着手条件は Web 収益のみ）
- 11月: 技術士一次試験 / RCCM
- **2027年3月: 技術士 最終合格発表 ← サイト全面ブランディング更新**

### ★ 3. 合格体験ループ（★★★★★・v3で新設）

**仕組み**: 運営者が試験を受ける → 学習過程・解答再現・論文構成を note/YouTube で公開 → 次年度受験者の購買動機になる → リピート販売（合格体験商品は年サイクルで継続販売可能）

| 基準 | 評価 |
|---|---|
| 適合度 | 5/5（他人が絶対に書けない独占コンテンツ） |
| 現在の成熟度 | **4/5・実証済み**（note 有料が 2026-06 に月 ¥217,760。総監パック・建設部門模範解答が実売） |
| 実装コスト | S（試験勉強と自然に重なる） |
| 成長速度 | 速（試験直後の熱量で一気に立ち上がる） |
| 複利効果 | 極大（合格後の権威性でサイト全体のE-E-A-Tが上がる） |

### ループ間の相乗効果

- ループ1（技術リファレンス）→ トラフィックがSEOデータを生む
- ループ2（資格試験）→ 受験者流入が note 有料記事の見込み客になる
- **★ループ3（合格体験）→ ループ1/2 に「受験合格者による」という権威性を注入**

全ループが互いを強化するフライホイール構造。起点はループ1（SEO流入）→ ループ3（合格体験）で一気に跳ね上がる設計。

### 現況の焦点（[11_STP分析2026-07.md](./11_STP分析2026-07.md) の T 結論）

## Pre-Mortem（失敗シナリオと対策）

| シナリオ | 対策 |
|---|---|
| 運営の熱量・継続性が落ちる | 退職者で時間は確保しやすいが、週次レビューで更新習慣を担保。完璧を捨て「積み上げ」を徹底 |
| 計画を立てるだけで実装が進まない | 「Sコスト」タスクは当日中に完了。週次レビューで検出 |
| 情報系キーワードに時間を使ってしまう | ロングテール＋合格体験に集中 |
| 大手スクールが総監SEOに本腰 | 「無料×体系的×**合格者本人**」の組み合わせは大手が真似しにくい |
| 1 級土木の高流入を収益化できないまま放置 | 会員ラボのローンチ／ガイド→有料導線を近接で検証（最大の機会損失） |
| SNS 量産が流入に結実しない | 直接収益を前提にせず、間接効果（指名検索・Direct）で評価。工数は実証済みチャネルへ再配分 |
| note プラットフォーム依存 | 収益比率のモニタリング。自前課金（Stripe）は PWA 側で検討（[04_収益化戦略.md](./04_収益化戦略.md)） |

> 旧 v3 の受験リスク行（試験勉強で更新停止／筆記不合格／試験後の熱量喪失）は運営者の総監合格判明で失効・削除済み。「note が売れない」も 2026-06 実績で否定された。
