> [!important] 現在の方針（2026-11-01・運営者承認、方針 4 は 2026-11-04 改定）
> 根拠の数字（2026-05〜10 の実績）と運用の絞り込みは [2026-11-01 の提案](../reviews/critical/2026-11-01-revenue-focus-and-ops-slimming.md)。
> 1. **主戦場は技術士の筆記期（5〜7 月）**。受取の約 8 割（総監・建設部門）がここに集まるので、翌年の予想問題・パックを 4 月末までに揃える（制作は 2〜4 月）。
> 2. **谷（8〜4 月）は試験の 0〜8 週前の答案パックで埋める**（1級二次・2級二次・主任技士・技術士の口頭と一次）。新しい商品の型は作らない。
> 3. **単価はパックで上げる**。どの資格も「まるごとパック（¥5,000〜12,000）＋比較の基準としての単品」に揃える。
> 4. **展開中（active）の資格は、展開できる商品をすべて展開する**（2026-11-04 運営者指示で改定。舗装・測量士・コンクリート技士・上下水道・建築・管工事を含む）。販売 0 や売上が見えないことを理由に追加制作を止めない。順番は試験日から逆算し、技術士の筆記（方針 1）の制作を先に守る。売り先は下の表に従い、新しい型は作らない。候補（candidate）の昇格は運営者が決める。**新しいチャネルへの展開は止めたまま**にする。KDP は維持だけ（新しい作業をしない）。**転職アフィリは 2026-11-03 の運営者指示で「育てる」に変えた**（市場価値を確かめるための複数登録を軸にする。設計は [転職アフィリエイト訴求設計 §13](../marketing/転職アフィリエイト訴求設計.md)）。ココナラは人手の添削・指導だけを、入口の添削（¥2,000〜3,000・評価を集める）と試験の 4〜8 週前の季節の再開に限って動かす（2026-11-02 運営者承認・PDF の出品は戻さない）。SNS は保留を続ける。
> 5. **計測の穴を先に塞ぐ**（販売明細と商品の分類の結びつき・費用と作業時間）。
> 6. 年間の段取りは試験日から逆算する（制作開始・CTA の切り替え・販売・判定）。

チャネルごとの役割・1 件あたりの手取り・KPI は [22_チャネル別商品設計2026-11.md](./22_チャネル別商品設計2026-11.md) を参照する。

## 商品の種類ごとの売り先（2026-10-15 決定）

過去問の分析から作る「全部パック」も含め、商品の種類で売り先を分ける。新しい商品はこの表のどれに当たるかで置き場を決める。

| 商品の種類 | 売り先 |
|---|---|
| 記述式の模範解答・論文・予想問題 | note |
| 添削・診断・作成代行（人が手を入れるもの） | ココナラ |
| 択一の過去問（解説付き） | KDP と iOS 択一アプリ（サイトの全問無料は続ける） |

技術士一次は、この決定より前から note で過去問 PDF（全 560 問）を売っていて、KDP の 4 冊と中身が重なる。KDP の日本の取り分は 35% に落ちているので、サイトからは KDP へ張らず note の PDF へ送る。KDP は Amazon の中の検索で買われる前提にする（2026-10-26 運営者決定。同日に合本 d-00 は ¥1,250 へ改定）。
