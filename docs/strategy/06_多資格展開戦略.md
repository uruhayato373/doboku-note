# 多資格展開戦略 v2.0

最終更新: 2026-09-26（v2.0: 展開の判断材料を正本に配線し、判断の軸を「受験者が自分で答案を組み立てる区分」に置き直した）

> [!important] この文書の役割
> 展開する資格を決めるときの**判断の軸**と**判断の記録**だけを持つ。受験者数・売上・競合の数は写さない（写しは古くなる）。値は正本から並べた `npm run qualification-market`、または管理画面 戦略＞展開の判断（`/strategy/market`）で見る。展開状態の正本は `.claude/config/qualification-registry.json` の `portfolio`（active / candidate / declined）。

## 判断の軸

| 軸 | 見るもの | 正本 |
|---|---|---|
| 売れる形か | 受験者が自分で答案を組み立てる区分（経験記述・論文）があるか | `exam-formats.json` |
| 市場の大きさ | その区分の受験者数（択一だけの区分は数えない） | `exam-stats.json` |
| 年間の平準化 | 買われる時期（試験日の `buyWindowWeeks` 週前〜試験日）が既存の山と重ならないか | `exam-calendar.json`・`annual-roadmap.json` |
| 競合の空き | YouTube・note・ココナラの強い売り手の数、X・Instagram の追跡数 | `market-scan.json` と市場スキャン（`.claude/state/market/history/`）・`*-competitors.json` |
| 自社の実績 | 資格×区分の売上 | `sales-log.json` を `product-lineup.json` で資格へ写す |
| 信頼性 | 運営者の経験（元自治体土木職・技術士合格）で答案の真正性を担保できるか | 人が判断する |

- 混み具合は「強い売り手の数」で測る（YouTube＝1 万再生以上の動画を持つチャンネル、note＝検索上位で有料記事を出す作者、ココナラ＝評価 10 件以上のサービス。閾値は `market-scan.json`）。タイトルがその資格のものだけを数え、別資格や無関係の大型チャンネルを混ぜない。
- 市場スキャンは四半期に 1 回（`npm run scan-qualification-market -- --coconala`・期限は `npm run check-competitor-scan-due`）。取り直したら月次レビューで判断を見直す。

## 実売から分かったこと（2026-09）

- 売上は自分で答案を組み立てる商品（ペルソナ別の論文・想定工事・模範解答）に集中し、択一の商品はほとんど売れていない。問題と正答は無料で手に入るが、「自分の立場で書いた答案」は手に入らないことが支払いの理由と読める（推測）。
- 売上は技術士の筆記試験（7 月）の直前に集中し、8 月以降に落ちる。秋から春に買われる時期を持つ資格が平準化に効く。
- 資格別・月別の値は `npm run qualification-market -- --json`（`salesByMonth`）と `/metrics/business`。

## 施工管理技術検定（令和 6 年度改正後）の見方

- 経験記述が残る: 土木・建築・電気工事（電気は与えられた条件に答える問 A/B 選択型）。
- 経験記述が変わった、または無くなった: 管工事（「施工記述」へ。自分の経験に基づく設問かは未確認）・造園（廃止）。
- 建設機械は第二次の筆記が記述（1 級）または択一（2 級）で、実技がある。
- 区分ごとの詳細と未確認の点は `exam-formats.json`（候補の資格は調査担当の読み取りで、主担当の原文照合は展開を決めたときに行う）。

## 判断の記録

| 日付 | 判断 | 理由 |
|---|---|---|
| 2026-05-26〜07-07 | v1.1〜v1.3 でコンクリート 3 資格・2 級土木・技術士建設部門の順に展開を決め、現在はすべて展開中 | 当時の市場評価と実売（建設部門を前倒しした結果、転換率が最も高かった）。詳細は git 履歴の v1.3 |
| 2026-05-26 | 技術士 情報工学部門は参入しない | 市場が小さい（建設部門の数十分の一）、土木の読者と重ならない、運営者の経験で権威性を担保できない、既存資産が流用できない |
| 2026-09-26 | 判断の軸を「自分で答案を組み立てる区分」に置き直し、全資格の材料（出題形式・受験者数・売上・競合）を正本に配線 | 売上の集中と季節性（上記）。受験者数の多さだけでは売れる資格を選べない |
